Base de conhecimento

Respostas curtas para problemas comuns. Use os guias quando precisar do passo a passo completo.

Overlay do OBS em branco

Confira o dock primeiro. Se estiver vazio, corrija a fonte ou plataforma. Se funcionar, abra a URL exata do overlay em um navegador normal e confirme o mesmo session, depois atualize a fonte de navegador do OBS.

Abrir solução de problemas do OBS

Sessão errada

As páginas de fonte, dock, overlay, bot e Event Flow precisam usar o mesmo ID de sessão. Trate IDs como nomes de salas: grafias diferentes são salas diferentes.

dock.html?session=YOUR_SESSION

Abrir sessões, senhas e modos de retransmissão

Atualizar sem perder configurações

Exporte as configurações primeiro, não desinstale a extensão numa atualização comum e use a transferência completa de sessão criptografada do aplicativo quando também precisar mover cookies e logins.

Abrir atualizações seguras, backups e recuperação

O OBS não recebe o TTS

O TTS básico do sistema costuma tocar no computador, mas não na fonte de navegador do OBS. Use um modo de TTS do provedor ou navegador, como Kokoro, Piper, Kitten, eSpeak, compatível com OpenAI ou provedor na nuvem, ou encaminhe o áudio do sistema separadamente.

Abrir guia de configuração de TTS

Kokoro não fala português ou espanhol

As vozes integradas do Kokoro são em inglês. Para português, use Piper com pipervoice=pt_BR-faber-medium, ou eSpeak com espeakvoice=pt-br. Para espanhol, use Piper com pipervoice=es_ES-davefx-medium, ou eSpeak com espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Abrir configuração de provedores TTS

Funciona no Chrome, mas não no aplicativo de desktop

O aplicativo de desktop usa sessões do Electron, não seu perfil normal do Chrome. Entre na janela da fonte do aplicativo ou use a extensão do Chrome se a plataforma bloquear navegadores integrados ou de aplicativos.

Abrir modos do aplicativo independente

De qual servidor local preciso?

Ativar servidor local (Enable Local Server) é um retransmissor WebSocket para páginas compatíveis do SSN. API de controle local serve para scripts e ferramentas de IA no mesmo computador. A hospedagem sem interface executa o aplicativo de desktop completo num servidor Linux. O servidor de mídia do Event Flow serve apenas mídia local aprovada.

TikTok falha ou muda de modo

Anote o modo do aplicativo, provedor de assinatura, texto de status, versão e se o chat está visível no modo Standard. Teste um modo do TikTok por vez.

Abrir modos de TikTok no aplicativo

O chat do YouTube não aparece

Confirme que a transmissão está ao vivo, o chat está visível e você usa a opção certa do YouTube: chat ao vivo, comentários estáticos, captura Standard ou modo WebSocket/API.

Abrir guia de configuração do YouTube

As respostas do bot não são enviadas

Ler chat não é o mesmo que publicar. Confira suporte a respostas da plataforma, login, função da conta, modo de fonte, resposta do provedor e limites de requisições.

Abrir o guia de configuração do bot de chat com IA

Event Flow não faz nada

Confirme que o evento de origem chega ao dock. Para ações de áudio, mídia e OBS, mantenha actions.html?session=YOUR_SESSION aberto com a mesma sessão.
