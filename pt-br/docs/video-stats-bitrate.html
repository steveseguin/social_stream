Estatísticas de vídeo e taxa de bits

Mostre a taxa de bits da transmissão recebida no canto superior direito do dock do Social Stream Ninja.

Importante: O SSN não lê automaticamente a taxa de bits do OBS nem de uma plataforma. Ele consulta a API de estatísticas do servidor de vídeo que recebe sua transmissão.

Para que serve

Isso oferece ao apresentador ou produtor um pequeno indicador de taxa de bits ao vivo no dock. É útil quando o OBS, um codificador móvel ou outro emissor envia para seu próprio servidor de retransmissão ou ingestão.

O SSN também normaliza os dados disponíveis de latência, buffer, perda de pacotes, tempo ativo, codecs e espectadores em um evento de metadados video_stats . O indicador padrão do dock mostra apenas a taxa de bits.

Compatibilidade

  • SRT Live Server / SLS: JSON /stats ao endpoint que contém um objeto publishers .
  • Belabox Cloud: sua resposta JSON de estatísticas de receptor ou retransmissor no formato SRT.
  • NGINX RTMP: XML do módulo de status do NGINX RTMP.
  • Node Media Server: sua API JSON de transmissões, com autenticação HTTP Basic opcional.
O OBS não é uma fonte de estatísticas: O OBS pode enviar vídeo a um servidor compatível, mas OBS WebSocket e as fontes de navegador do SSN não fornecem esses dados.

Como usar

  1. Ative o endpoint HTTP de estatísticas do servidor compatível e confirme que o computador do SSN consegue abrir a URL.
  2. No SSN Configurações globais, ative Consulta de estatísticas de vídeo.
  3. Selecione o tipo de fonte e informe a URL de estatísticas.
  4. Para SRT ou Belabox, informe o ID exato do emissor, como publish/live/feed1. O SSN usa esse valor automaticamente quando a resposta contém apenas um emissor.
  5. Para NGINX RTMP ou Node Media Server, informe o aplicativo e a chave ou nome de transmissão, como live e feed1.
  6. Adicione autorização se necessário. O campo de chave de API SRT é enviado como o valor completo do cabeçalho Authorization . O Node Media Server usa nome de usuário e senha como autenticação HTTP Basic.
  7. Escolha um intervalo de consulta de 1 a 60 segundos; o padrão é cinco segundos.
  8. Nas opções do dock, ative Mostrar metadados de taxa de bits, se disponíveis, no canto superior direito (Show bitrate metadata if available; top-right), depois abra ou atualize o link do dock.
  9. Comece a enviar vídeo. A taxa aparece após uma resposta válida de transmissão online.

Se nada aparecer

  • Confirme que as duas opções de estatísticas de vídeo estejam ativadas no SSN.
  • Confirme que o endpoint responde em até cinco segundos e que o tipo de fonte e os identificadores de transmissão correspondem.
  • 127.0.0.1 significa o computador que executa o SSN. Use o endereço LAN do servidor se ele estiver em outro dispositivo.
  • O indicador desaparece quando a transmissão está offline, a taxa de bits falta ou é zero, ou nenhuma estatística nova chega por cerca de 130 segundos.

Avançado: protocolo, formatos e unidades

O SSN faz uma requisição HTTP ou HTTPS do tipo GET no intervalo configurado, sem cache e com tempo limite de cinco segundos.

SRT Live Server / SLS e Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate é em Kbps; RTT e buffer de recepção são em milissegundos; taxa de recepção e largura de banda são em Mbps; tempo ativo é em segundos; perdas/descartes são contagens de pacotes ou bytes.

NGINX RTMP

A URL precisa retornar XML de status do NGINX RTMP. O SSN procura o aplicativo e a transmissão configurados. Ele lê bw_video como bytes por segundo e divide por 1024 para obter bitrateKbps. Também lê o tempo de transmissão e metadados opcionais dos codecs de vídeo e áudio.

Node Media Server

O SSN solicita STATS_URL/APPLICATION/STREAM_NAME. Os campos podem estar no nível superior ou dentro de data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

A taxa de bits é em Kbps, espectadores são uma contagem e duração é em segundos.

Evento normalizado do SSN

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
CampoUnidade/tipo
bitrateKbpsKbps, número inteiro
rttMs / bufferMsMilissegundos
recvRateMbps / bandwidthMbpsMbps
Campos de perda/descarteContagens de pacotes ou bytes
uptimeSeconds / durationSecondsSegundos
onlineBooleano; false oculta o valor no dock

O dock aceita meta.bitrateKbps, com meta.bitrate e meta.kbps como alternativas. Valores abaixo de 1000 são mostrados como Kbps arredondados; valores maiores aparecem em Mbps com uma casa decimal. A URL de estatísticas, a chave de transmissão e as credenciais nunca são enviadas aos overlays.
