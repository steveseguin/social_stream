Repassar chat entre plataformas

Configure intencionalmente um repasse entre Twitch e YouTube, escolha os remetentes e diagnostique mensagens repetidas.

Todos os guias 1. Confirme que ambos os chats aceitam respostas 2. Crie Twitch → YouTube no Event Flow 3. Adicione o sentido de retorno 4. Entenda os ecos 5. Restrinja o que você repassa Solução de problemas

1. Confirme que ambos os chats aceitam respostas

Conecte seus chats do Twitch e do YouTube Live à mesma sessão do SSN. Confirme que ambos aparecem no dock e envie uma resposta manual a cada um a partir de uma mensagem com aba de origem conhecida. Use seus próprios canais de teste. Uma fonte de captura somente leitura não pode enviar mensagens de repasse.

Mantenha abertos somente os chats de destino pretendidos para esta configuração. Um destino de plataforma pode incluir várias abas de fontes elegíveis nessa plataforma. Se usar uma conta de bot separada do Twitch, conclua Contas de bot para respostas primeiro.

2. Crie Twitch → YouTube no Event Flow

Abra: Editor do Event Flow no menu do SSN (também disponível na seção da sobreposição Actions). Crie um fluxo e dê a ele um nome claro, como Twitch para YouTube.

  1. Adicione uma ação Da origem (From Source) de Usuário e origem (User & Source). Escolha Twitch como origem.
  2. Adicione uma ação Repassar chat (Relay Chat) e conecte a saída do gatilho à entrada da ação.
  3. Selecione essa ação. Defina Destino do repasse (Relay Destination) como YouTube, e mantenha o modelo de mensagem [{source}] {username}: {message}.
  4. Selecione Salvar fluxo (Save Flow) e ative o fluxo salvo. Mantenha o SSN ativo.
  5. Envie uma nova mensagem normal no seu próprio chat de teste do Twitch. Confirme que uma cópia identificada chega ao YouTube.

O YouTube Shorts tem seu próprio tipo de fonte e destino. Escolha YouTube Shorts quando apropriado; não é intercambiável com YouTube.

3. Adicione o sentido de retorno

Crie um segundo fluxo chamado YouTube para Twitch: Da origem: YouTube → Repassar chat: Twitch. Salve e ative. Envie uma nova mensagem de cada lado e confirme que cada uma produz uma única cópia na outra plataforma.

Mantenha Repassar todas as mensagens (!NÃO RECOMENDADO!) desativado ao usar estes fluxos para que um segundo sistema de repasse não faça o mesmo trabalho. Verifique também se outro bot ou serviço de multistream já está conectando os chats.

4. Entenda os ecos

Um eco é uma mensagem enviada pelo SSN que é capturada novamente no chat de destino. As ações atuais Relay Chat ignoram automaticamente os ecos reconhecidos. Elas também excluem a aba de origem.

Para ocultar o eco capturado do dock e das sobreposições, adicione uma ação Filtro de ecos (Reflection Filter) no início do fluxo relevante e selecione Bloquear todos (Block All). Permitir primeiro (Allow First) mantém um eco correspondente dentro da janela configurada; Permitir todos (Allow All) os exibe. Isso controla a exibição após a captura, não o destino do repasse.

As propriedades atuais de Relay Chat não têm uma caixa "No Reflections". Use o filtro de ecos separado para controlar a exibição. Se um serviço externo reescrever uma mensagem repassada, o reconhecimento automático pode não detectá-la.

5. Restrinja o que você repassa

Para comandos, adicione uma condição Mensagem começa com (Message Starts With) definida como ! e conecte-a por uma porta lógica NOT ; combine esse resultado com sua condição de origem usando AND antes de Relay Chat. Veja o Guia do Event Flow para conectar portas lógicas. Teste tanto uma mensagem normal quanto um comando.

Se optar pelo repasse global mais simples, use Configurações e ferramentas globais → Comandos → Escolher destinos de repasse e insira twitch,youtube. Uma lista vazia significa todos os destinos elegíveis. Essa lista controla os destinos, não quais plataformas de entrada podem disparar um repasse. Desative o par de fluxos de repasse do Event Flow antes de ativar esta alternativa.

Os campos de permissão/bloqueio por função de conta do SSApp na mesma seção Comandos podem restringir quais contas enviam repasses. Use a função atribuída ao remetente pretendido; uma função sem correspondência pode deixar o repasse sem destino elegível.

Solução de problemas

  • Nada é enviado: tente novamente uma resposta manual, confira o login e a permissão de publicar, ative o fluxo salvo e verifique as restrições de destino e função de conta.
  • As mensagens se multiplicam: desative primeiro os fluxos de repasse. Verifique fontes de captura duplicadas, a opção global Repassar todas e bots externos de repasse antes de testar novamente um sentido.
  • Só o dock mostra duplicatas: inspecione a política de exibição do Filtro de ecos e as configurações globais de eco em Mensagem - Visibilidade.
  • Destino incorreto no YouTube: confira YouTube versus YouTube Shorts e feche chats elegíveis indesejados.

As ações de Testar fluxo podem enviar mensagens reais. Use destinos controlados; um teste sintético não comprova o encaminhamento de contas da fonte real.
