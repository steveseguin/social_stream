Para que serve o Event Flow

Execute um fluxo personalizado com uma tecla do Stream Deck ou chamada de API HTTP/WebSocket/P2P.

Event Flow é o editor de automação avançada. Use quando os interruptores do painel não forem suficientes: filtre chat, acione mídia, retransmita mensagens, chame webhooks ou controle o OBS.

Antes de qualquer exemplo

  1. Use uma plataforma de teste e uma sessão do Social Stream.
  2. Abra o dock e confirme que o chat chega.
  3. Abrir actions.html?session=YOUR_SESSION se o exemplo reproduzir áudio, mídia ou controlar OBS.
  4. Teste com uma mensagem fictícia ou acionador seguro antes de entrar ao vivo.
  5. Exporte um fluxo funcionando antes de fazer uma grande alteração.

Correções comuns

  • Nada acontece: confirme primeiro que o evento de origem chega ao dock.
  • Áudio ou mídia não toca: mantenha actions.html aberto com a mesma sessão e confira o Guia de hospedagem de mídia do Event Flow.
  • A ação de OBS falha: confira o OBS WebSocket v5, a porta 4455, senha e permissões.
  • O fluxo dispara demais: adicione um filtro mais restrito de plataforma, evento, palavra-chave ou usuário.
