Visão geral

O SSN pode ler texto de chat capturado de qualquer fonte compatível; a plataforma de chat não precisa ter um recurso próprio de TTS. Seu dock ou sobreposição com TTS ativado fala as mensagens que recebe, conforme seus filtros e configurações de TTS. Comece pelo guia curto de configuração; esta página aborda opções de voz e configurações avançadas. Compare provedores, ouça amostras e veja as configurações.

Início rápido: Use dock.html?session=YOUR_SESSION&speech=en-US. O padrão é TTS do sistema. Para um provedor gratuito no OBS, adicione também &ttsprovider=kokoro. Mantenha esta página aberta e conectada; somente uma cópia deve falar.

Onde o TTS é usado?

  • Social Stream Ninja: Lê mensagens do chat do público em várias áreas
  • CAPTION.Ninja: Oferece legendas, transcrição e tradução com TTS
  • Ambos os serviços oferecem opções premium e gratuitas de TTS
TTS do sistema não é sinônimo de todo TTS gratuito:
  • As vozes do sistema dependem do navegador e do sistema operacional. O OBS pode não disponibilizar vozes utilizáveis, mesmo quando Chrome/Edge funcionam.
  • Uma voz ausente é diferente de fala reproduzida fora da captura de áudio do OBS. O roteamento de áudio não corrige a falta de suporte à fala.
  • Provedores gratuitos como Kokoro, Piper, Kitten e eSpeak geram áudio da página. Não é necessário pagar para usar TTS no OBS.
  • Verifique a disponibilidade da voz e depois a captura de áudio.

Opções de provedores de TTS

TTS do sistema (gratuito)

  • Usa as vozes integradas do sistema operacional
  • Suporte limitado de idiomas conforme a instalação do sistema
  • A disponibilidade de vozes e o roteamento de áudio dependem do navegador e do sistema operacional; teste no player real
  • A compatibilidade varia bastante entre navegadores

Estas são capacidades típicas, não garantias para toda instalação. O OBS usa seu próprio navegador integrado e não herda a lista de vozes de um Chrome/Edge instalado. Um teste bem-sucedido no aplicativo SSN não testa uma fonte de navegador separada no OBS.

Limitações do navegador:
  • Nem todos os navegadores suportam síntese de voz igualmente (algumas versões do Firefox têm vozes limitadas)
  • O Chrome oferece opções de TTS com tecnologia Google
  • O Edge oferece TTS da Microsoft e vozes dos pacotes de idioma do Windows
  • O Safari exige interação do usuário para iniciar o áudio
  • Verifique vozes disponíveis para seu navegador

Métodos de captura de áudio TTS do Windows para OBS

Áudio da página: provedores locais gratuitos e de nuvem

Os provedores locais baseados no navegador e os provedores de áudio em nuvem do SSN reproduzem o áudio gerado pela página:

  • Basta ativar "Control audio via OBS" na fonte de navegador
  • Sem necessidade de cabos de áudio virtuais
  • Funciona com o aplicativo SSN e fontes de navegador do OBS

Métodos de captura de TTS do sistema

Importante: Primeiro, confirme que o TTS do sistema gera fala. O navegador integrado do OBS pode não disponibilizar uma voz utilizável do sistema. Se não gerar fala, alterar o roteamento de áudio não ajudará. Escolha outro provedor ou gere a fala em um navegador compatível e capture seu áudio.

Especificamente para TTS do sistema:

  • Não suponha que o OBS disponibilize as mesmas vozes do Chrome ou Edge
  • Suporte limitado entre navegadores (Firefox pode não ter algumas vozes TTS)
  • Chrome oferece opções do Google; Edge tem opções da Microsoft
  • Se a fala for reproduzida fora da fonte de navegador da cena, capture essa saída separadamente

Downloads para roteamento: VB-Audio Virtual Cable | Voicemeeter | Audio Router (legado)

Primeiro, tente capturar o navegador que fala pelo áudio de aplicativo ou desktop no OBS, quando compatível. Os métodos com cabo virtual abaixo são alternativas opcionais; não adicionam suporte a fala ao OBS.

Método 1: rota de áudio padrão com cabo virtual

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Método 2: roteamento por aplicativo no Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Método 3: roteamento por aplicativo no Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Método 4: software Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Método 5: Voicemeeter (avançado)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Testar sua configuração

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Alternativas: Use um provedor gratuito integrado, como Kokoro, Piper, Kitten ou eSpeak, um provedor de nuvem ou um servidor próprio de TTS.

Instalar pacotes de idioma adicionais

Windows 11

  1. Acesse Iniciar > Configurações > Hora e idioma > Fala
  2. Em Gerenciar vozes, clique em Adicionar vozes
  3. Selecione os idiomas desejados e clique em Adicione
  4. Reinicie os navegadores para atualizar as vozes disponíveis

Windows 10

Siga as instruções do guia oficial da Microsoft para instalar pacotes de idioma.

Dica: Algumas vozes de terceiros podem não aparecer nos navegadores devido a problemas de compatibilidade. O Firefox costuma mostrar mais vozes do sistema que navegadores baseados em Chromium.

Parâmetros de URL para configuração de TTS

Parâmetros básicos

Parâmetro Descrição Exemplo
&speech Ativar TTS com código de idioma &speech=en-US
&pitch Tom da voz (0.1 a 2.0) &pitch=1.2
&volume Nível de volume (0.0 a 1.0) &volume=0.8
&rate Velocidade de fala (0.1 a 10.0) &rate=1.5
&voice Correspondência parcial do nome da voz &voice=google
&ttsprovider Selecionar provedor: kokoro, piper, kitten, espeak, openai, customtts, localtts, elevenlabs, google, speechify, gemini &ttsprovider=customtts

Parâmetros avançados

Parâmetro Descrição
&simpletts Não dizer "diz" nem "alguém diz"
&simpletts2 Não ler nomes do chat
&ttscommand Ativar comando personalizado de TTS (padrão: !say)
&readevents Incluir eventos da transmissão no TTS
&skipmessages=3 Ler apenas uma a cada 3 mensagens

Configuração do provedor de TTS

TTS Kokoro (gratuito, integrado)

  • Ativar com ?ttsprovider=kokoro
  • Executado no navegador por WebGPU/WASM — sem servidor
  • Funciona diretamente com a fonte de navegador do OBS
  • Seleção de voz: &voicekokoro=af_bella
  • Controle de velocidade: &kokorospeed=1.2
  • Escolha uma voz para o idioma: &voicekokoro=ef_dora para espanhol ou &voicekokoro=pf_dora para português brasileiro. Alterar &speech= sozinho não altera a voz selecionada. Os IDs de voz existentes em inglês continuam funcionando.

TTS Piper (gratuito, integrado)

  • Ativar com ?ttsprovider=piper
  • TTS neural rápido e eficiente em CPU, executado no navegador
  • Seleção de voz: &pipervoice=en_US-hfc_female-medium
  • Vozes em português: &pipervoice=pt_BR-faber-medium ou &pipervoice=pt_BR-edresson-low
  • Vozes em espanhol: &pipervoice=es_ES-davefx-medium ou &pipervoice=es_MX-ald-medium
  • Controle de velocidade: &piperspeed=1.0

TTS Kitten (gratuito, integrado)

  • Ativar com ?ttsprovider=kitten
  • TTS leve baseado em ONNX, executado no navegador
  • Seleção de voz: &kittenvoice=expr-voice-4-f

eSpeak-NG (gratuito, integrado)

  • Ativar com ?ttsprovider=espeak
  • TTS clássico de código aberto, funciona em qualquer hardware
  • Seleção de voz: &espeakvoice=en
  • Exemplo em português: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Exemplo em espanhol: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Controle de velocidade: &espeakspeed=175

Exemplos de TTS em português e espanhol

  • Português, melhor qualidade local gratuita testada no SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Português, alternativa mais rápida testada no SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Espanhol, melhor qualidade local gratuita testada no SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Espanhol, alternativa mais rápida testada no SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Para vozes de nuvem, use um provedor e voz/idioma que ofereçam suporte ao idioma desejado, como Google Cloud, ElevenLabs, Speechify, Gemini ou um servidor local compatível com OpenAI.

TTS OpenAI / servidor local

  • Ativar com ?ttsprovider=openai
  • Use ?ttsprovider=customtts ou ?ttsprovider=localtts para um endpoint próprio
  • Usa a API da OpenAI por padrão ou qualquer servidor local compatível
  • Endpoint personalizado: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Importante: localhost e 127.0.0.1 significam o mesmo computador que reproduz a página de TTS. Se o OBS estiver em um computador diferente do servidor de TTS, use o IP de rede local do computador servidor.
  • Sem necessidade de chave de API para servidores locais
  • Se o servidor local tiver problemas de CORS ou rede local no Chrome/OBS, execute npm run local-tts-bridge no computador do OBS e aponte o SSN para http://127.0.0.1:8124/v1/audio/speech
  • O SSN envia { model, input, voice, response_format, speed } e aceita áudio binário, URLs de áudio em JSON e áudio base64 em JSON
  • A reprodução de endpoints personalizados/locais atualmente usa buffer; o SSN ainda não reproduz trechos de áudio em streaming de forma progressiva
  • Voz: &voiceopenai=af_bella, velocidade: &openaispeed=1.0. Use um nome de voz compatível com seu servidor; vozes Kokoro são como af_bella, enquanto vozes no estilo openedai-speech/OpenAI podem ser como nova ou echo.
  • Veja: Guia de síntese de voz local com IA para configuração de servidor próprio

Google Cloud TTS

  • Ativar com ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Vozes de qualidade profissional
  • Seleção de voz: &voicegoogle=en-GB-Standard-A
  • Idioma: &googlelang=en-US

TTS Gemini

  • Ativar com ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Modelo: &geminimodel=gemini-2.5-flash-preview-tts
  • Voz: &voicegemini=Kore, idioma: &geminilang=th-TH
  • Instruções de estilo: &geministyle=Read aloud in a warm tone.

TTS ElevenLabs

  • Ativar com ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • ID da voz: &voice11=YOUR_VOICE_ID
  • Modelo: &elevenlabsmodel=eleven_multilingual_v2
  • Parâmetros: estabilidade, similaridade e estilo podem ser ajustados

TTS Fish Audio

Escolha Fish Audio e insira sua chave de API, com um ID de voz opcional. O modelo padrão é s2.1-pro-free. Configuração, opções de modelo e limitações de acesso do navegador.

TTS Speechify

  • Ativar com ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Voz: &voicespeechify=henry
  • Modelo: &speechifymodel=simba-3.0 (padrão), ou &speechifymodel=simba-3.2 para inglês.
  • Velocidade de fala: &speechifyspeed=1.2 (intervalo de 0.5 a 3.0; normal é 1.0).
  • Guia de configuração, vozes, velocidade e volume do Speechify

Solução de problemas

Problemas comuns

  • Nenhum áudio é reproduzido: Verifique se o TTS está ativado, se a página que produz o TTS está aberta e se a fonte de navegador não está no mudo. Em um navegador normal, clique uma vez na página.
  • Vozes não aparecem: Reinicie o navegador após instalar pacotes de idioma
  • O OBS não captura: Se não houver fala, verifique primeiro a disponibilidade da voz/provedor. Se houver fala, verifique Controlar áudio pelo OBS (Control audio via OBS), o mudo do mixer e as faixas de saída, ou capture o navegador externo que está falando
  • O endpoint local funciona no teste do aplicativo, mas não no OBS: O OBS é um navegador separado. Verifique o endpoint a partir do computador do OBS, especialmente ao usar 127.0.0.1.
  • Somente a primeira letra ou as primeiras palavras são lidas: remova ttsquick da URL do OBS, se houver.
  • Problemas do Safari: Safari tem suporte limitado a TTS automático
  • Serviço premium não funciona: Verifique a chave de API e se o provedor foi especificado corretamente

Boas práticas

  • Use um provedor que gere áudio da página para simplificar a configuração do OBS; há provedores locais gratuitos disponíveis
  • Teste sua configuração com frases simples antes de entrar ao vivo
  • Considere os riscos de conteúdo gerado por usuários com TTS
  • Tenha um controle para desativar rapidamente o TTS, se necessário
