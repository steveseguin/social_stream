API de controle local e MCP

Permita que uma ferramenta de IA ou um script no mesmo computador inspecione e controle o aplicativo Social Stream Ninja para desktop.

Escolha este serviço quando

Use a API de controle local quando um software no computador do SSApp precisar de controles aprovados do aplicativo e das fontes. Use o adaptador MCP incluído quando um cliente de IA compatível precisar receber esses controles como ferramentas.

Isso é separado de Arquivo > Ativar servidor local (File > Enable Local Server), que inicia um relay WebSocket para páginas do Social Stream. Veja Explicação dos servidores e serviços locais se não tiver certeza de qual serviço precisa.

1. Baixe o aplicativo normal para desktop

Instale a versão atual do Social Stream Ninja pelos downloads para Windows, macOS ou Linux. O suporte a MCP está incluído no aplicativo baixado. Você não precisa do repositório de código-fonte, Node, Python nem de um pacote MCP separado.

2. Ative o controle local por IA

  1. Abrir Arquivo > IA local / Automação (File > Local AI / Automation).
  2. Ative API de controle local e deixe o aplicativo reiniciar.
  3. Volte ao mesmo menu e escolha Copiar configuração MCP (Copy MCP Setup).
  4. Cole o JSON copiado nas configurações de MCP da ferramenta de IA e reinicie essa ferramenta.

A configuração copiada contém o caminho exato do executável instalado, a porta e os argumentos específicos da plataforma. O executável baixado do Social Stream Ninja inicia seu próprio adaptador MCP leve quando o cliente de IA o executa com --ssapp-mcp.

3. Deixe o MCP descobrir os recursos

Após a conexão, o cliente MCP solicita automaticamente as ferramentas ao Social Stream Ninja. O adaptador lê os recursos atuais do aplicativo em execução e fornece ao LLM os esquemas das ferramentas suportadas, as versões do aplicativo/API e as instruções de operação. O agente deve consultar primeiro os recursos, depois o status, e usar os IDs estáveis das fontes retornados pelo aplicativo.

O uso normal de MCP não exige extração de conteúdo de sites nem instalação de skills. O usuário pode simplesmente pedir ao agente conectado que inspecione ou controle o Social Stream Ninja.

Controles locais disponíveis

  • Liste, inspecione, adicione, atualize e remova fontes.
  • Inicie, pare ou recarregue uma fonte ou um conjunto filtrado.
  • Altere a visibilidade, o estado de áudio e o modo de conexão das fontes.
  • Leia e atualize as configurações globais suportadas retornadas pela descoberta de recursos.
  • Leia o status do aplicativo, da sessão, das fontes, dos processos, da captura e da mídia local.
  • Acompanhe eventos delimitados de fontes capturadas e eventos de operação ou status que permitem retomada.
  • Capture e inspecione com segurança páginas de fontes compatíveis e janelas pertencentes ao SSApp.
  • Execute interações aprovadas em páginas, janelas e caixas de diálogo com confirmação.
  • Recarregue ou encerre o aplicativo normalmente com confirmação explícita.

Os recursos informados pelo aplicativo em execução são a referência. Versões antigas podem oferecer menos controles.

Acesso HTTP direto para scripts locais

Scripts no mesmo computador podem usar a API de loopback sem MCP. Ela escuta apenas em 127.0.0.1 e não exige token.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

Use os recursos anunciados em vez de presumir que todas as versões do aplicativo têm os mesmos controles. Para exemplos de curl prontos para copiar e colar que adicionam, listam, iniciam, inspecionam e param uma fonte, consulte o passo a passo da API HTTP do servidor.

IA local em um VPS Ubuntu

A API também pode atender uma ferramenta de IA executada no mesmo servidor Linux que uma instância do SSApp sem interface. Mantenha-a vinculada ao loopback e use o AppImage baixado como comando MCP.

Novo seguidor Executar Social Stream Ninja sem interface gráfica para Xvfb, perfis persistentes, comandos de inicialização, systemd e o caminho separado de controle remoto. Ele também inclui uma configuração MCP para AppImage no Linux que você pode colar em um cliente executado no VPS.

Skill opcional para agentes

Agentes que aceitam skills instaláveis podem baixar a skill completa Control Social Stream. Você também pode ler as instruções online, com o Referência da API e histórico de versões. A skill adiciona orientações de fluxo de trabalho, mas não é necessária para a conectividade MCP.

Links de descoberta legíveis por máquina também estão listados em llms.txt.

Somente local

Esta interface destina-se à IA e à automação executadas no mesmo computador que o SSApp. Não a exponha nem crie túneis para usá-la como API de controle remoto na nuvem. Usuários remotos e o Stream Deck devem usar a conexão WebRTC ou WebSocket existente do Social Stream. A API local não oferece execução arbitrária de JavaScript, cookies, segredos de login, configurações sem restrições nem acesso direto ao sistema de arquivos.

Para os endpoints completos, esquemas de comandos, descoberta de versões e limites de segurança, veja a referência técnica de automação.
