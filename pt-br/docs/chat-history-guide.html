Histórico do chat e pontos de fidelidade

Como o armazenamento local de mensagens afeta o histórico, os pontos e o reconhecimento de espectadores.

Todos os guias Histórico local Manter os pontos funcionando Histórico de mensagens existente

O que faz o banco de dados local de mensagens

O SSN salva as mensagens capturadas em um banco de dados do navegador ou da instalação desktop que faz a captura. A página de histórico do chat usa esse banco para consultar mensagens anteriores.

O Desativar a base de dados local de mensagens impede o armazenamento de novas mensagens. A captura ao vivo e a exibição no dock podem continuar, portanto ver mensagens no dock não confirma que o histórico está sendo salvo.

A detecção de quem conversa pela primeira vez e o reconhecimento de espectadores baseado no histórico também dependem do banco de dados local.

Manter os pontos de fidelidade funcionando

O ganho de pontos e os processadores dos comandos !points, !leaderboard e !rewards são executados quando as mensagens capturadas são armazenadas. Desativar o banco de dados local interrompe esses processadores, mesmo quando as opções de pontos estão ativadas.

  1. Encontre Desativar a base de dados local de mensagens nas configurações do SSN e deixe essa opção desativada.
  2. Em Sistema de pontos, ative os pontos de fidelidade e os comandos de chat que deseja usar.
  3. Peça a um espectador para enviar uma mensagem e depois !points. Confira a conta dele na plataforma correta.

Os saldos são armazenados separadamente do histórico de mensagens. Use Sistema de pontos → Backup e restauração → Exportar pontos para fazer backup. Compartilhar um ID de sessão com outra instalação não sincroniza nenhum dos bancos de dados.

Veja: guia de pontos de fidelidade para saber sobre ganhos, rankings, recompensas e backups.

Como o histórico existente é usado

Quando o registro de pontos está vazio e ainda não foi inicializado nem redefinido, o SSN pode calcular os pontos iniciais a partir do histórico salvo. Isso é executado uma vez para inicializar os saldos.

As interações do histórico usam as regras de pontuação ao vivo: a primeira interação válida recebe pontos base, e as seguintes podem receber bônus de sequência. Só é possível considerar o histórico disponível; guarde uma exportação dos pontos ao migrar ou recuperar uma instalação.
