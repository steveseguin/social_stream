Guia de novos participantes do chat

Marque novos participantes com destaque, selo de folha ou aviso sonoro opcional.

O que este recurso faz

A detecção de novos participantes adiciona firsttime=true à primeira mensagem de chat armazenada de um espectador naquela fonte. O dock usa esse indicador para sombrear o fundo, emitir um bipe só na primeira participação e mostrar o selo opcional de folha.

Configuração necessária

  1. Abra o painel do Social Stream Ninja.
  2. Mantenha Desativar a base de dados local de mensagens no estado desativado.
  3. Ative Detecção de novos participantes do chat.
  4. Deixe o dock ou overlay aberto com o mesmo ID de sessão.
Importante: A base de dados local é necessária. Se estiver desativada, o Social Stream Ninja não consegue saber se alguém é novo.

Opções de exibição

  • Sombreamento do fundo: ativado por padrão no dock. Mantenha Sem sombreamento de fundo para novos participantes desativado se quiser o destaque.
  • Selo de folha: ative Marcar novos participantes com um selo personalizado para adicionar um pequeno selo de folha antes dos selos do participante.
  • Bipe do dock para participantes novos: ative se quiser que o bipe do dock aconteça apenas para novos participantes.
  • Bipe para participantes novos ou que voltam: ative se também quiser um som para espectadores que voltarem após 8 horas ou mais sem falar.

Usar o indicador em overlays personalizados

Overlays personalizados podem procurar data.firsttime === true. Se a opção de selo de folha estiver ativada, o selo será incluído em chatbadges antes que a mensagem chegue aos overlays.

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

Se não aparecer

  1. Confirme que Desativar a base de dados local de mensagens desativado.
  2. Confirme que Detecção de novos participantes do chat ativado.
  3. Confirme que Sem sombreamento de fundo para novos participantes desativado se quiser o destaque.
  4. Confirme que Marcar novos participantes com um selo personalizado ativado se quiser o selo de folha.
  5. Teste com uma combinação de usuário e fonte que ainda não esteja na base local.
