Como instalar fontes personalizadas

  • Windows: Clique com o botão direito no arquivo .ttf ou .otf → selecione "Instalar" ou "Instalar para todos os usuários" → reinicie o navegador.
  • macOS: Dê um clique duplo no arquivo .ttf ou .otf → clique em "Instalar Fonte" no Catálogo de Fontes → reinicie o navegador.
  • Linux: Copie os arquivos de fonte para ~/.local/share/fonts/ → execute fc-cache -fv → reinicie o navegador.

Após a instalação, atualize esta página para ver suas novas fontes. Se uma fonte não aparecer, tente o botão "Testar Local Fonts API" (somente navegadores Chromium).

Usar uma fonte específica pela URL

  • Parâmetro: Acrescente ?font=<Font%20Family%20Name> à URL. Espaços e símbolos precisam ser codificados para URL.
  • Aplica-se à variável CSS: Seu site usa --font-family; esta página também a respeita. Exemplo: ?font=Segoe%20UI.
  • Aspas desnecessárias: Não inclua aspas no parâmetro; elas não são necessárias na variável CSS.
  • Somente instaladas: O parâmetro funciona apenas com fontes já instaladas no sistema. Ele não baixa fontes da web.

Compatibilidade (aplicativos Ninja)

  • VDO.Ninja: Gerados ?font= os links funcionam com sobreposições/cenas que respeitam a variável --font-family variável.
  • SocialStream.Ninja: Use o mesmo ?font= para substituir a fonte padrão nos widgets compatíveis.
  • Caption.Ninja: Aplicar ?font= às sobreposições de legendas que aceitam famílias de fontes personalizadas.

Esses aplicativos aceitam a substituição de font-family quando o parâmetro ?font= é suportado em suas URLs ou links de incorporação. Esta ferramenta gera valores corretamente codificados e prontos para usar.

Solução de problemas (Windows)

  • Nome exato da família: Use o nome de família da fonte (não o nome do arquivo). Confira Configurações → Personalização → Fontes para encontrar o nome correto da família.
  • Escopo correto de instalação: Se você instalou uma fonte para outro usuário do Windows ou apenas por uma conta de administrador, sua sessão do navegador pode não vê-la. Instale "para todos os usuários", se necessário.
  • Formatos suportados: Os navegadores usam TrueType/OpenType/WOFF. Fontes antigas Type 1 e algumas fontes bitmap não funcionam.
  • Disponibilidade de peso/estilo: Se apenas a versão Bold estiver instalada, o texto Normal poderá usar outra fonte. Experimente uma amostra em negrito ou instale também a versão Regular.
  • Limites de privacidade: Os navegadores não permitem listar todas as fontes sem permissão. Esta página detecta fontes a partir de uma grande lista conhecida e, opcionalmente, da Local Fonts API.
  • Local Fonts API: No Chromium, em origens seguras (https/localhost), clicar em "Testar Local Fonts API" pode listar as famílias exatas instaladas após a concessão de permissão.

Dicas de uso manual

  • Forçar uma fonte: No seu CSS: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • Testar um nome qualquer: Use a caixa de busca para testar qualquer família; se encontrada, ela aparece nos resultados com uma amostra.
  • Codificação: Monte links assim: ?font=Segoe%20UI (os links gerados abaixo usam a codificação correta).
  • Fontes CJK e de outros sistemas de escrita: A amostra inclui caracteres latinos, números e símbolos. Substitua por texto do sistema de escrita desejado para verificar a composição dos caracteres.

Nota: esta página não instala nem baixa fontes; apenas detecta e exibe famílias já disponíveis para seu navegador.
