Poradnik konfiguracji YouTube

Świadomie wybierz czat na żywo, komentarze, przechwytywanie Standard lub tryb API.

Zacznij od Obsługiwanych witryn

Najpierw wyszukaj YouTube. Social Stream rozdziela czat na żywo i statyczne komentarze, ponieważ są to różne sposoby pracy.

Konfiguracja czatu na żywo

  1. Upewnij się, że transmisja rzeczywiście trwa lub czat na żywo jest dostępny.
  2. Otwórz stronę czatu na żywo YouTube lub stronę źródła odpowiednią dla trybu.
  3. Potwierdź, że dok odbiera wiadomości, zanim otworzysz OBS.
  4. Użyj tego samego identyfikatora sesji w doku i nakładce.

Jeśli YouTube prosi o logowanie lub uprawnienia, wykonaj ten krok w tej samej przeglądarce/aplikacji, która przechwytuje czat.

Uwagi dotyczące API i OAuth

  • Tryb API może udostępniać inne rodziny zdarzeń niż przechwytywanie widocznej strony.
  • Dane subskrybentów mogą być opóźniane przez YouTube i obejmować wyłącznie publiczne subskrypcje.
  • Akcje zapisu wymagają szerszych zakresów niż przechwytywanie czatu tylko do odczytu.
  • Aplikacja komputerowa nie współdzieli automatycznie zwykłych plików cookie Chrome.

Pełna konfiguracja: Konfiguracja projektu YouTube.

Typowe rozwiązania

  • Brak czatu: potwierdź, że transmisja trwa, a czat jest widoczny.
  • Chrome działa, ale aplikacja nie: zaloguj się do YouTube w aplikacji lub użyj rozszerzenia.
  • Tryb API nie działa: sprawdź OAuth, zakresy, dane uwierzytelniające projektu i limit.
  • Pusto w OBS: najpierw przetestuj dok, a następnie adres nakładki w zwykłej przeglądarce.
