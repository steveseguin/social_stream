Lokalne API sterowania i MCP

Pozwól narzędziu AI lub skryptowi na tym samym komputerze sprawdzać i sterować aplikacją komputerową Social Stream Ninja.

Kiedy wybrać tę usługę

Aplikacja komputerowa→Lokalne API sterowania→Klient MCP

Użyj lokalnego API sterowania, gdy oprogramowanie na komputerze SSApp potrzebuje zatwierdzonego sterowania aplikacją i źródłami. Użyj dołączonego adaptera MCP, gdy zgodny klient AI ma otrzymać to sterowanie jako narzędzia.

To coś innego niż File > Enable Local Server, które uruchamia przekaźnik WebSocket dla stron Social Stream. Zobacz Objaśnienie lokalnych serwerów i usług jeśli nie wiesz, której usługi potrzebujesz.

1. Pobierz zwykłą aplikację komputerową

Zainstaluj bieżące wydanie Social Stream Ninja ze Pobieranie dla Windows, macOS lub Linux. Obsługa MCP jest dołączona do pobranej aplikacji. Nie potrzebujesz repozytorium źródeł, Node, Pythona ani osobnego pakietu MCP.

2. Włącz lokalne sterowanie AI

  1. Otwórz Plik > Lokalne AI / Automatyzacja (File > Local AI / Automation).
  2. Włącz Lokalne API sterowania i pozwól aplikacji uruchomić się ponownie.
  3. Wróć do tego samego menu i wybierz Kopiuj konfigurację MCP.
  4. Wklej skopiowany JSON do ustawień MCP używanych przez narzędzie AI, a następnie uruchom je ponownie.

Skopiowana konfiguracja zawiera dokładną ścieżkę zainstalowanego pliku wykonywalnego, port i argumenty właściwe dla platformy. Pobrany plik wykonywalny Social Stream Ninja uruchamia własny lekki adapter MCP, gdy klient AI uruchamia go z --ssapp-mcp.

3. Pozwól MCP wykryć możliwości

Po połączeniu klient MCP automatycznie prosi Social Stream Ninja o narzędzia. Adapter odczytuje bieżące możliwości uruchomionej aplikacji i przekazuje LLM obsługiwane schematy narzędzi, wersje aplikacji/API i instrukcje obsługi. Agent powinien najpierw wywołać capabilities, potem status i używać stabilnych identyfikatorów źródeł zwracanych przez aplikację.

Zwykłe użycie MCP nie wymaga odczytywania witryny ani instalowania umiejętności. Użytkownik może po prostu poprosić połączonego agenta o sprawdzenie lub sterowanie Social Stream Ninja.

Dostępne lokalne sterowanie

  • Wyświetlaj listę, sprawdzaj, dodawaj, aktualizuj i usuwaj źródła.
  • Uruchamiaj, zatrzymuj lub przeładowuj jedno źródło albo przefiltrowany zestaw.
  • Zmieniaj widoczność źródła, wyciszenie i tryb połączenia.
  • Odczytuj i aktualizuj obsługiwane ustawienia globalne zwracane przez wykrywanie możliwości.
  • Odczytuj status aplikacji, sesji, źródła, procesu, przechwytywania i lokalnych multimediów.
  • Śledź ograniczone strumienie zdarzeń przechwyconych źródeł oraz wznawialne zdarzenia operacji lub statusu.
  • Przechwytuj i bezpiecznie sprawdzaj obsługiwane strony źródeł i okna należące do SSApp.
  • Wykonuj zatwierdzone interakcje ze stronami, oknami i oknami dialogowymi z potwierdzeniem.
  • Przeładuj lub poprawnie zamknij aplikację z jawnym potwierdzeniem.

Możliwości uruchomionej aplikacji są wiążące. Starsze wersje mogą udostępniać mniej elementów sterowania.

Bezpośredni dostęp HTTP dla lokalnych skryptów

Skrypty na tym samym komputerze mogą używać API loopback bez MCP. Nasłuchuje wyłącznie na 127.0.0.1 i nie wymaga tokenu.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

Korzystaj z ogłaszanych możliwości zamiast zakładać, że każda wersja aplikacji ma to samo sterowanie. Gotowe do skopiowania curl przykłady dodawania, wyświetlania, uruchamiania, sprawdzania i zatrzymywania źródła znajdziesz w przewodniku po API HTTP serwera.

Lokalne AI na VPS Ubuntu

API może też obsługiwać narzędzie AI działające na tym samym serwerze Linux co instancja SSApp bez interfejsu. Pozostaw je przypisane do loopback i użyj pobranego AppImage jako polecenia MCP.

Obserwacja Uruchamianie Social Stream Ninja bez interfejsu aby poznać Xvfb, trwałe profile, polecenia startowe, systemd i osobną ścieżkę zdalnego sterowania. Zawiera też Konfiguracja MCP dla Linux AppImage którą możesz wkleić do klienta działającego na VPS.

Opcjonalna umiejętność agenta

Agenci obsługujący instalowane umiejętności mogą pobrać pełną umiejętność Control Social Stream. Możesz też przeczytać jej instrukcje online, z Dokumentacja API i historii wersji. Umiejętność dodaje wskazówki dotyczące pracy, ale nie jest potrzebna do łączności MCP.

Łącza wykrywania czytelne maszynowo są również wymienione w llms.txt.

Tylko lokalnie

Ten interfejs jest przeznaczony dla AI i automatyzacji działających na tym samym komputerze co SSApp. Nie udostępniaj go ani nie tuneluj jako chmurowego API zdalnego sterowania. Zdalni użytkownicy i Stream Deck powinni używać istniejącego połączenia WebRTC lub WebSocket Social Stream. Lokalne API nie udostępnia wykonywania dowolnego JavaScript, plików cookie, sekretów logowania, nieograniczonych ustawień ani surowego dostępu do systemu plików.

Pełne punkty końcowe, schematy poleceń, wykrywanie wersji i granice bezpieczeństwa znajdziesz w technicznej dokumentacji automatyzacji.
