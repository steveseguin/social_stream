Uruchamianie OBS i Social Stream jako administrator

Kroki w Windows do jednorazowego testu lub trwałego ustawienia, z odpowiadającymi sobie przykładami dla obu aplikacji.

Używaj tylko przy potwierdzonym problemie z uprawnieniami

OBS i Social Stream zwykle nie powinny potrzebować dostępu administratora. Uruchamiaj obie normalnie, chyba że potwierdzono różnicę uprawnień Windows lub pomoc techniczna wyraźnie poprosiła o taki test.

Pusty połączony czat, stary adres źródła przeglądarkowego lub nieaktualną pamięć podręczną OBS zwykle naprawia się przez zastąpienie adresu URL i odświeżenie pamięci podręcznej, a nie trybem administratora.

Jeśli jedna aplikacja ma podwyższone uprawnienia, a druga nie, Windows może ograniczać ich współpracę. Aby przetestować różnicę uprawnień, najpierw zamknij obie aplikacje i uruchom je na tym samym poziomie uprawnień.

Jednorazowy test administratora

  1. Zamknij OBS Studio i aplikację komputerową Social Stream.
  2. Kliknij prawym przyciskiem skrót OBS Studio i wybierz Uruchom jako administrator (Run as administrator).
  3. Zatwierdź monit kontroli konta użytkownika Windows.
  4. Jeśli testujesz różnicę między dwiema aplikacjami, kliknij skrót Social Stream prawym przyciskiem, wybierz Uruchom jako administrator (Run as administrator)i zatwierdź również jego monit.
  5. Powtórz dokładnie czynności, które wcześniej się nie udały. Po zakończeniu zamknij obie aplikacje; jednorazowe podwyższenie uprawnień kończy się przy ich zamknięciu.

Najpierw wybierz ten test. Pozwala to sprawdzić, czy podwyższenie uprawnień ma znaczenie, bez trwałej zmiany którejkolwiek aplikacji.

Zawsze uruchamiaj Social Stream jako administrator

  1. Zamknij Social Stream.
  2. Kliknij prawym przyciskiem jego skrót i wybierz Otwórz lokalizację pliku (Open file location). Jeśli Windows otworzy inny skrót, kliknij go prawym przyciskiem i wybierz Otwórz lokalizację pliku (Open file location) ponownie.
  3. Kliknij prawym przyciskiem socialstream.exe i wybierz Właściwości.
  4. Otwórz Zgodność karcie.
  5. Wybierz Uruchom ten program jako administrator (Run this program as an administrator), a następnie wybierz Zastosuj i OK.

Typowa instalacja dla pojedynczego użytkownika to:

%LOCALAPPDATA%\Programs\socialstream\socialstream.exe

Ścieżka może się różnić, jeśli wybrano inne miejsce instalacji.

Zawsze uruchamiaj OBS jako administrator

  1. Zamknij OBS Studio.
  2. Kliknij prawym przyciskiem skrót OBS Studio i wybierz Otwórz lokalizację pliku (Open file location).
  3. Kliknij prawym przyciskiem obs64.exe i wybierz Właściwości.
  4. Otwórz Zgodność karcie.
  5. Wybierz Uruchom ten program jako administrator (Run this program as an administrator), a następnie wybierz Zastosuj i OK.

Domyślna ścieżka 64-bitowego OBS to zwykle:

%ProgramFiles%\obs-studio\bin\64bit\obs64.exe

Ścieżka może się różnić dla instalacji przenośnych lub niestandardowych.

Ponowne wyłączenie trybu administratora

  1. Zamknij aplikację.
  2. Otwórz dla pliku wykonywalnego Właściwości → Zgodność karcie.
  3. Wyczyść Uruchom ten program jako administrator (Run this program as an administrator), a następnie wybierz Zastosuj i OK.
  4. Zrób to samo dla drugiej aplikacji, aby OBS i Social Stream wróciły do tego samego zwykłego poziomu uprawnień.

Nie wyłączaj kontroli konta użytkownika. Informacje o aplikacjach z podwyższonymi uprawnieniami znajdziesz w wyjaśnieniu trybu administratora Microsoft.
