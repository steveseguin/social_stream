Bezpieczne aktualizacje, kopie zapasowe i odzyskiwanie

Przed aktualizacją, ponowną instalacją, resetowaniem lub zmianą kanału wydań utwórz jedną użyteczną kopię zapasową.

Zasada bezpieczeństwa

  1. Najpierw wyeksportuj ustawienia. Przechowuj wyeksportowany plik poza folderem aplikacji lub rozpakowanego rozszerzenia.
  2. Nie odinstalowuj rozszerzenia przeglądarki tylko po to, aby je zaktualizować. Odinstalowanie usuwa ustawienia zapisane przez tę instalację rozszerzenia.
  3. Zachowaj jedną działającą kopię. Podczas rozwiązywania problemów z uszkodzoną konfiguracją nie nadpisuj jedynej kopii zapasowej.
  4. Po aktualizacji przeładuj strony źródeł. Ponownie otwórz wygenerowane linki do doku i nakładek oraz odśwież zapisane źródła przeglądarkowe OBS, jeśli ich adresy się zmieniły.

Kopia zapasowa rozszerzenia przeglądarki (Chrome, Edge, Firefox)

  1. Otwórz panel sterowania Social Stream Ninja i przewiń do Ustawienia globalne i narzędzia.
  2. Otwórz Eksport / import.
  3. Wybierz Eksportuj na dysk, wybierz bezpieczne miejsce i zachowaj .data rozszerzenie w nazwie pliku.
  4. Sprawdź, czy zapisany .data plik istnieje przed aktualizacją, odinstalowaniem lub resetowaniem czegokolwiek.
  5. Użyj Importuj ustawienia , aby później przywrócić ten plik.

Chrome Web Store i inne rozszerzenia instalowane ze sklepów: aktualizacje zwykle instalują się w istniejącym miejscu i zachowują ustawienia. Nie odinstalowuj i nie instaluj ponownie rozszerzenia tylko po to, aby wymusić aktualizację.

Ręczna aktualizacja wersji rozpakowanej: pobierz i rozpakuj nową wersję, zastąp stare pliki rozszerzenia, a następnie wybierz Przeładuj (Reload) na chrome://extensions. Pozostaw rozpakowany folder na miejscu i przeładuj otwarte karty czatu. Zobacz instalacja ręczna.

Zachowaj prywatność plików kopii zapasowych. Eksport ustawień może zawierać hasło sesji, adresy webhooków lub źródeł oraz inną prywatną konfigurację. Nie publikuj go.

Kopia zapasowa aplikacji komputerowej

Kopia zapasowaMenuZastosowanie
Kopia zapasowa ustawień (Settings Backup) File → Settings Backup → Export Settings… Zwykłe aktualizacje, przenoszenie ustawień i pierwszy etap odzyskiwania. Import odbywa się przez Importuj ustawienia… (Import Settings…).
Przenoszenie całej sesji (Full Session Transfer) File → Advanced Full Session Transfer Przenoszenie lub zachowanie całego profilu aplikacji komputerowej, w tym lokalnych sesji i stanu logowania. Tworzy zaszyfrowany .ssappbk plik.

Standardowy eksport ustawień jest właściwym wyborem przy większości aktualizacji. Full Session Transfer jest dostępne tylko w aplikacji komputerowej; zajmuje więcej miejsca i podczas przywracania zastępuje profil docelowy. Aplikacja najpierw zachowuje pre-restore-* kopię bieżącego profilu.

Aplikacja komputerowa nie aktualizuje się automatycznie. Zainstalowanie nowszej wersji na istniejącej instalacji powinno zachować obecny profil. Mimo to najpierw wykonaj eksport, zwłaszcza przed ponowną instalacją, przejściem między wersją przenośną a instalowaną, zmianą kanału wydań lub próbą resetowania.

Jeśli ustawienia już zniknęły

  1. Przestań resetować i ponownie instalować. Kolejne zmiany mogą nadpisać najlepszą kopię do odzyskania danych.
  2. Jeśli aplikacja lub rozszerzenie nadal zawiera przydatny stan, wyeksportuj go przed wykonaniem innych czynności.
  3. Zaimportuj najnowszą sprawdzoną .data lub .json kopię zapasową ustawień.
  4. Aby utworzyć kopię całego profilu aplikacji komputerowej, użyj Zaawansowane przenoszenie całej sesji (Advanced Full Session Transfer).
  5. Jeśli uszkodzona jest tylko lista źródeł w aplikacji komputerowej, wypróbuj Wyczyść wszystkie źródła (Clear All Sources). Ma węższy zakres niż Full Reset i służy do zachowania sesji, plików cookie oraz ustawień.
  6. Używaj Full Reset dopiero po wykonaniu kopii zapasowej lub zaakceptowaniu całkowitego wyczyszczenia danych lokalnych.

Jeśli nie masz eksportu, ale zachował się stary adres doku, narzędzie odzyskiwania z linku do doku może odtworzyć identyfikator sesji, hasło oraz ustawienia z parametrów URL zawarte w tym linku. Nie odtworzy ustawień ani kont źródeł, których nigdy nie było w adresie.

Co obejmuje standardowa kopia zapasowa ustawień

Obecny test przenoszenia ustawień aplikacji komputerowej sprawdza zapis i ponowny odczyt stanu Social Stream z pamięci podręcznej oraz wybranych ustawień aplikacji. Eksport rozszerzenia przeglądarki obejmuje identyfikator sesji, opcjonalne hasło, stan oraz obiekt ustawień.

  • Ustawienia źródeł i ustawienia globalne zawarte w zapisanym stanie.
  • Identyfikator sesji Social Stream i opcjonalne hasło sesji.
  • Wybrane preferencje aplikacji komputerowej używane przez aplikację.

Kopia zapasowa rozszerzenia przeglądarki .data nie obejmuje plików cookie przeglądarki ani sesji logowania w witrynach. W aplikacji komputerowej standardowy eksport ustawień również nie kopiuje wszystkich plików cookie ani logowań w witrynach; gdy trzeba przenieść cały profil aplikacji, użyj dostępnego tylko w aplikacji komputerowej Full Session Transfer.
