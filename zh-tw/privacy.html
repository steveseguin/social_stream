Social Stream Ninja 隱私權政策

最後更新：2026 年 9 月 8 日

Social Stream Ninja 是用於擷取、轉送、顯示和自動化直播聊天及相關直播事件的開源軟體。本政策適用於 Social Stream Ninja 瀏覽器擴充功能、代管的 Social Stream Ninja 頁面和疊加畫面、通常稱為 SSAPP 的獨立桌面應用程式，以及適用於 Elgato Stream Deck 的原生 Social Stream Ninja 外掛程式。

1. 範圍和整體原則

使用 Social Stream Ninja 核心軟體無需中央使用者帳號。但根據您的設定，軟體可能存取、處理、儲存和傳輸在某些法律下屬於個人資訊的資訊。

在許多情況下，軟體在您的裝置本機執行，並由您控制。但某些功能使用第三方平台、使用者設定的目標或代管輔助服務，這些服務可能接收執行所請求功能所需的資料。

2. 軟體可能處理的資訊

根據您啟用的功能，Social Stream Ninja 可能處理以下類別的資訊：

  • 驗證資訊：使用者輸入或所連接服務授予的 OAuth 存取權杖、更新權杖、API 金鑰、用戶端 ID、用戶端密鑰、頻道或房間憑證、工作階段權杖、密碼及類似授權資料。
  • 個人通訊：從所連接平台接收的聊天訊息、回覆、聊天命令、管理動作、會員訊息、贊助訊息、支持訊息，以及其他使用者提交的通訊內容。
  • 瀏覽歷史和頁面脈絡：支援的頁面 URL、分頁資訊、頻道名稱、使用者名稱、影片 ID、房間 ID、直播識別碼，以及連接或監控來源所需的相關頁面脈絡。
  • 網站內容：聊天 DOM 內容、訊息內容、事件內容、直播中繼資料、觀眾數量、徽章、表情、個人資料影像，以及支援的頁面或 API 上提供的其他內容。
  • 個人識別資訊和個人資料：使用者名稱、顯示名稱、頭像、帳號或頻道 ID、徽章、名稱色彩、會員狀態、追蹤者/訂閱者標籤及類似個人資料中繼資料。
  • 設定和本機應用程式資料：設定、已連接來源、自訂命令、封鎖清單、允許清單、本機快取、檔案控制代碼資訊，以及維持軟體在裝置上執行所需的其他資料。
  • 可選的媒體和檔案資料：如果啟用可選的擷取、匯出、跑馬燈、記錄或檔案功能，軟體可能處理所選本機檔案、匯出檔案、分頁/媒體擷取資料或使用者建立的備份。

3. 資訊的使用方式

Social Stream Ninja 可能將這些資訊用於：

  • 連接支援的聊天、事件和直播來源。
  • 顯示聊天訊息、疊加畫面、儀表板、提醒、候補名單、投票、計分板及相關介面。
  • 執行使用者啟用的管理、篩選、自動化、轉送、機器人、TTS、AI、翻譯或匯出功能。
  • 向第三方平台進行驗證並維護來源工作階段。
  • 快取查詢結果並維護本機應用程式狀態，使軟體在各工作階段之間持續運作。
  • 將資料傳送至使用者明確設定的目標，例如 webhook、本機檔案、本機 websocket 端點、第三方機器人或其他服務。

4. 本機儲存和裝置儲存

Social Stream Ninja 將大量工作資料儲存在使用者裝置本機。根據使用的介面，這可能包括瀏覽器儲存空間、localStorage、sessionStorage、IndexedDB、擴充功能儲存空間、Electron 應用程式儲存空間，以及使用者選擇的可選檔案。

這些本機資料可能包括設定、已連接來源詳細資訊、快取的頻道或個人資料查詢結果、使用者啟用時的訊息歷史，以及已啟用功能所需的驗證/工作階段資料。

獨立桌面應用程式也可能在裝置上保留設定和來源儲存空間的本機復原備份。這些本機備份可能包含 OAuth 權杖或其他工作階段狀態，讓應用程式能在重新啟動或故障後還原先前可用的工作階段。

Stream Deck 外掛程式將其 Social Stream Ninja 工作階段 ID 和連接偏好儲存在 Stream Deck 本機外掛程式設定中。移除外掛程式或清除其設定會從 Stream Deck 中移除該外掛程式設定。

5. 資料可能離開裝置的情況

根據您使用軟體的方式，資訊可能在以下情況下傳出裝置：

我們不出售使用者資料。

Social Stream Ninja 的設計不會在本政策所述傳輸之外移轉使用者資料。這些傳輸可能發生於使用已連接平台、使用者啟用的功能、使用者設定的目標、必要的輔助或服務提供者時，或安全和法律義務要求時。

  • 已連接平台和 API：連接 YouTube、Twitch、Kick、Facebook、Discord 或其他支援的服務時，軟體會向這些平台傳送請求，並可能接收或傳輸聊天、事件、個人資料和驗證相關資料。
  • 代管輔助服務：某些功能使用輔助端點或代管頁面進行驗證、查詢、傳輸、聊天，或提供備援資源。目前版本中的範例包括用於驗證交換、查詢或代管頁面的 Social Stream Ninja 或相關輔助網域。
  • Stream Deck 控制項：Stream Deck 外掛程式將設定的工作階段 ID 和請求的命令資料傳送至使用者選擇的 Social Stream Ninja websocket 或 HTTP 端點。啟用 HTTP 備援時，命令資料可能編碼在請求 URL 中。
  • 使用者設定的目標：如果啟用 webhook、轉送、機器人、AI 提供者、TTS 提供者、直播工具、websocket 伺服器或其他整合，軟體可能將訊息內容、使用者名稱、頭像、事件承載資料和相關中繼資料轉送至這些目標。
  • 對等連接或傳輸服務：如果使用 VDO.Ninja、WebRTC、TURN 轉送、隱藏的 iframe 橋接或以 websocket 為基礎的傳輸，資料可能經過這些系統。可選的 websocket 傳輸可能不採用端對端加密。

6. YouTube 和其他以 OAuth 為基礎的功能

有限使用： Social Stream Ninja 對從 Google API 接收的資訊的使用遵循 Chrome 線上應用程式商店使用者資料政策，包括其「有限使用」要求.

使用 YouTube API 服務或其他以 OAuth 為基礎的整合時，Social Stream Ninja 可能請求所選功能所需的授權權杖及相關帳號存取權限。

  • YouTube：根據啟用的 YouTube 功能，軟體可能存取 YouTube 直播聊天訊息、訊息中繼資料、頻道資訊、頭像資訊、直播狀態、管理端點，以及觀眾或訂閱者統計資訊。
  • 代管驗證輔助服務：在某些版本和模式中，OAuth 授權碼交換或權杖重新整理可能透過代管輔助服務處理，而不是完全在裝置上處理。如果使用此模式，授權碼、更新權杖和相關權杖請求資料可能經過該輔助服務，以完成登入。
  • 本機權杖儲存：根據所用功能和登入流程，權杖可能儲存在使用者裝置本機；如果需要遠端交換或重新整理，也可能傳送至輔助服務。
  • Google 政策：您對 YouTube 功能的使用還須遵守 Google 隱私權政策。您可以透過 Google 帳戶權限設定撤銷 Google 存取權限。

7. 桌面應用程式錯誤回報

獨立桌面應用程式包含可選的錯誤回報功能，除非使用者啟用，否則該功能處於停用狀態。

  • 啟用後，桌面應用程式可能將錯誤訊息、堆疊追蹤、應用程式版本、隨機安裝 ID、脈絡及經過淨化的設定傳送至開發者的錯誤回報端點。
  • 截至撰寫時，桌面應用程式內的揭露說明指出，OAuth 權杖、工作階段資料和備份憑證不會包含在這些回報中。
  • 截至撰寫時，桌面應用程式內的揭露說明指出，這些回報透過 Cloudflare Worker 端點傳送，並保留 30 天。使用者應在啟用此功能前查看目前應用程式內的揭露說明。

8. 第三方服務和使用者設定的整合

Social Stream Ninja 可以與多種第三方平台和使用者選擇的服務互動。它們的隱私權政策、條款、安全控制和保留做法獨立於本政策，且可能存在重大差異。

如果將軟體設定為向第三方服務傳送資料，您有責任審查這些服務，並決定是否有權向其傳送該資料。

9. 保留、刪除和使用者控制

由於 Social Stream Ninja 的許多功能在本機執行，保留期間通常取決於使用者的裝置和設定。

  • 本機設定、快取、權杖和備份可能保留在裝置上，直到使用者清除儲存空間、移除來源、重設應用程式、刪除匯出檔案、撤銷權杖或解除安裝軟體。
  • 使用者設定的第三方目標可能根據自身政策保留轉送資料的副本。
  • 代管輔助服務或 API 可能根據其自身做法記錄或保留技術請求資料。本政策不保證第三方服務的任何具體保留期間。

10. 安全與風險

  • 不保證絕對安全：沒有任何軟體或網路服務是絕對安全的。使用 Social Stream Ninja 的風險由您自行承擔。
  • 工作階段和來源憑證：如果直播 ID、房間 ID、權杖、密碼或轉送連結遭他人知曉，這些人可能根據您的設定查看或插入資料。
  • 傳輸風險：WebRTC、TURN、websocket、webhook、轉送和第三方 API 流量可能向承載這些流量所需的服務揭露資訊。

11. 使用者責任

使用者決定將哪些網站、帳號、聊天和服務連接至 Social Stream Ninja，擷取什麼資料，顯示哪些疊加畫面，儲存哪些檔案，以及向哪些外部服務轉送資料。

  • 您有責任確保自己有權且具有合法依據，對透過軟體處理的任何資料進行收集、處理、顯示、儲存、匯出或轉送。
  • 您有責任遵守適用於相關服務及您所處理資料涉及之個人的服務條款、隱私條款和當地法律。
  • 您應將權杖、密碼、房間 ID、直播 ID 和匯出資料視為敏感資訊。

12. 賠償與不提供保證

Social Stream Ninja 依「現狀」和「可用狀態」提供，不附帶任何明示或默示保證，包括適售性、特定用途適用性及不侵權的默示保證。

使用本軟體即表示您同意，作者、貢獻者和服務提供者不對因您的設定或軟體使用而產生的請求、損害、責任或損失負責，包括與第三方內容、資料收集、資料轉送或法律遵循有關的請求。

本隱私權政策可能不時更新。政策變更後繼續使用軟體，即表示您接受修訂後的政策。
