1.下載實際文件

  1. 下載 beta 原始碼 ZIP，或開啟 測試版儲存庫 並選擇 代碼 → 下載 ZIP.
  2. 將 ZIP 解壓縮到您可以保留的資料夾中，例如 C:\SSN\social_stream-beta\.不要在壓縮檔案內進行編輯。這些是頁面原始檔；編輯單獨的副本不需要重新安裝 SSN。
  3. 找到上表所示的文件。将其复制到原件旁边：例如 poll.html 變為 my-poll.html。對於 themes/featured-styles/featured-modern.html，保留副本 themes/featured-styles/.
  4. 在文字/程式碼編輯器中開啟副本。讓您的 AI 工具存取該檔案及其所需的引用樣式/腳本。將 HTML 儲存為 .html，不是 .html.txt.

保留解壓縮後的資料夾結構。 單一下載的 HTML 檔案可以在其旁邊載入腳本、樣式表、字體、圖像、音訊或 JSON。 GitHub 的頁面視圖和瀏覽器的「儲存頁面」並不是一個可靠的完整包。每個類型指南都會標識有用的文件，但完整提取的資料夾是保留依賴項的最簡單方法。

參考文獻，例如 ../../shared/utils/chatHtml.js 與載入它的頁面相關。將該頁面移到根目錄會破壞路徑。將本地圖稿和字體也複製到專案中，然後使用相對 URL。將下載的版本放在一起；您編輯的副本不會自動接收未來的 SSN 修復。

2. 保留會話和連線設定

啟動SSN，連接源，並確認原始疊加運作正常。複製 完整生成的鏈接 來自相關SSN工具。之後的值 session= 識別您的 SSN 會話；它不是 YouTube 頻道、Twitch 使用者名稱、檔案名稱或投票標題。

https://socialstream.ninja/poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

此範例使用佔位符。 SSN 和頁面必須使用相同的實際會話和任何配置的密碼。更改檔案名稱不會更改會話。保持 SSN 並捕獲運行：覆蓋層接收資料；它本身不捕獲平台聊天。

  • ? 開始查詢； 後續設定使用 &。複製值而不是重新輸入它們。在 HTML 來源屬性中，寫入 &amp;；在 browser/OBS URL 欄位中使用普通的 & 符號。
  • 保留傳輸設定： server, server2, server3，本地端點、標籤和版本值是特定於頁面的。不要僅僅因為另一個覆蓋支援它就添加伺服器標誌。
  • 也保留片段： 之後的一切 # 可能很重要。例如，AI Event Overlay 使用私有 #aieventauth=... 顯示令牌。
  • 在共用範例中使用佔位符。 將您的真實會話連結、密碼和私人顯示令牌保留在公共螢幕截圖、儲存庫和 AI 提示範例之外。

当副本为空时，请先检查原始生成的链接。部分頁面提示缺少設定；其他人則保持隱藏或重定向。明确提供正确的会话可以避免依赖那些特定于页面的默认值。

3.開啟OBS中的文件

直接從電腦開啟編輯後的 HTML。无需安装或启动服务器。

  1. 將複製的 HTML 檔案拖曳到 Chrome 或 Edge 中。從地址欄複製其完整地址；它開始於 file:///.
  2. 複製所有內容 ? 在您的工作 SSN 覆蓋連結中繼續並將其新增至該檔案地址的末尾。這會保留您的會話、密碼、其他設定以及任何 # 結局。
  3. 在瀏覽器中開啟組合位址進行測試。
  4. 在 OBS 中，新增 瀏覽器來源。將 本機檔案 取消選取並將完整位址貼到 URL。設定設計的寬度和高度。

例如，這個 SSN 連結：

https://socialstream.ninja/poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

成為 Windows 上下載的投票副本的地址：

file:///C:/SSN/social_stream-beta/my-poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

使用您的實際文件地址和複製的設定。在 macOS 上，位址開頭為 file:///Users/...；在 Linux 上通常以 file:///home/....複製瀏覽器地址可以為您處理空格和斜線。

設定一次。 OBS 將位址與來源一起儲存。將下載的資料夾保留在相同位置，並在使用疊加層時保持 SSN 和您的聊天來源運作。儲存設計變更後，使用 重新整理目前頁面快取 在來源屬性中。

為什麼不選取本機檔案？ URL 欄位可讓您包含 ?session=....僅使用檔案選擇器選擇 HTML 不會新增這些設定。

可選：使用帶有啟動器的本機檔案複選框

OBS的檔案選擇器選擇檔案；它不會新增您產生的查詢設定。對於未經修改的基於查詢的接收器，小型本機啟動器可以導航至具有附加設定的編輯頁面：

  1. 将以下内容另存为 launch-my-poll.html ，位於下列選項旁： my-poll.html.
  2. 將佔位符託管 URL 替換為您完整複製的 SSN 連結。改變 ./my-poll.html 為您實際編輯的檔名。將連結保留在引號內，與普通 & 字元。
  3. 雙擊啟動器進行測試。在OBS中，選擇 本機檔案 並選擇 發射器.它使用查詢和片段重定向到本地覆蓋。
<!DOCTYPE html>
<html lang="en">
<meta charset="utf-8">
<title>My local overlay launcher</title>
<p>Opening the local overlay...</p>
<script>
var copiedLink = new URL("https://socialstream.ninja/poll.html?session=YOUR_SESSION");
var localPage = new URL("./my-poll.html", window.location.href);
localPage.search = copiedLink.search;
localPage.hash = copiedLink.hash;
window.location.replace(localPage.href);
</script>
</html>

對於巢狀主題，請將啟動器放在該主題副本旁邊。保持啟動器的私密性，因為它包含您的連接連結。下載的獨立匯出已嵌入其配置，而是遵循自己的匯出指令。

OBS 在以下文件中記錄了其文件/URL 模式、尺寸、自訂 CSS 和刷新控件 瀏覽器原始碼參考.

4.改變設計，或讓AI來做

對於僅 CSS 更改，請保留託管連結並使用 OBS 自訂 CSS 領域.它僅適用於該來源，因此開啟相同 URL 的普通瀏覽器不會顯示這些覆蓋。對於已編輯的 HTML 文件，請在其現有樣式後附加覆蓋，或在其後連結本機樣式表。提供您的商標、字體檔案、品牌顏色、畫布尺寸和視覺參考。

部分頁面支持 &css= 或 &b64css=；支援每頁。 poll.html兩者都沒有讀取。在使用 URL 選項之前檢查頁面的解析器。網頁通常無法從另一台電腦的本機磁碟載入任意字體或圖像。

更改标记时，保留脚本引用的 ID/类。如果 JavaScript 在每次更新时重建一个元素，则永久艺术作品必须位于该元素之外，或者由渲染器重新创建。如果您希望编辑仅影响您的设计，请复制共享样式表/脚本并更改页面的引用。

5. 防止傳入的聊天內容成為程式碼

訊息、名稱、標題、金額、元資料和媒體連結可以源自檢視者或外部服務。在自訂渲染器插入它們的位置進行清理。透過 SSN 接收到的字串沒有執行它的權限。對純字段使用純 DOM 文字；對訊息正文支援的 HTML 使用打包的清理程序。參見 OWASP 對安全接收器和 HTML 清理的解釋.

在SSN中， textonly 僅適用於 chatmessage.如果為 true，則將該正文呈現為文字文字。否則，它可能包含表情和允許的格式。將其他普通欄位渲染為文字；媒體領域，例如 chatimg 和 contentimg 是 URL/數據，而不是 HTML 片段。

<!-- Example for a copied page at the repository root. -->
<script src="./libs/objects.js"></script>
<script src="./shared/utils/chatHtml.js"></script>
<script>
function renderChatBody(element, data) {
    var message = String(data.chatmessage == null ? "" : data.chatmessage);
    if (data.textonly) {
        element.textContent = message;
    } else {
        element.innerHTML = SocialStreamChatHTML.sanitize(message);
    }
}
// Names, amounts, titles, and other plain fields use textContent:
// nameElement.textContent = String(data.chatname || "");
</script>

保留現有的等效消毒劑，而不是添加第二種。對於嵌套文件，調整相對腳本路徑。在頁面現有媒體/連結策略下驗證 URL 後，使用 DOM 屬性建立頭像和連結。不要將原始名稱插入屬性字串或將原始顏色插入樣式標記；在設定各個屬性之前驗證樣式。 HTML 清理並不能讓字串安全地作為 JavaScript 或 AI 指令執行。

在獨立預覽中測試渲染器

  • 使用簡單的名稱，例如 Guest <b>One</b>：括號應保留文字。
  • 試試 chatmessage: "<b>Hello</b>" 帶有 textonly: true，則為假。文字標記和允許的格式化內容應採取各自的路徑。
  • 檢查支援的表情和純圖像訊息，以便安全更改不會刪除這些功能。
  • 讓人工智慧測試無害的探針，例如 <img src=x onerror="window.__ssnInjectionProbe=1"> 在更改的渲染器中。它不得執行、設定標記或保留可執行事件屬性。也測試腳本方案連結。在本地運行探測器，而不是在公共聊天中運行探測器。

通過的探測僅檢查所使用的路徑。將測試重點放在因設計而變更的渲染器和欄位上。

6. 分別測試佈局、連接和OBS

  1. 佈局： 使用頁面記錄的預覽/演示模式（如果可用）或虛構的本地範例。測試長名稱/訊息、缺少頭像、空白資料和預期行數。
  2. SSN发货： 保持SSN活躍並使用 建立測試訊息 與同一屆會議。常用的Extension API攝取模式需要 擴充功能的遠端 API 控制 啟用。使用隔離的測試設定；提交的測試可以觸發配置的自動化。
  3. 實際觸發： 為特色卡片提供 Dock 訊息、發送民意調查投票、選擇贈品獲勝者、更改股票代碼文字或啟動計時器。簡單的聊天並不是一個通用的測試。
  4. 實拍： 確認實際的來源訊息/事件到達原始和編輯的頁面。模擬事件證明渲染，而不是平台擷取。
  5. OBS： 檢查來源的最終大小、透明度、動畫、音訊、字體和分層。練習顯示/隱藏、清除/重置和刷新。瀏覽器和OBS有獨立的儲存和會話；瀏覽器登入或localStorage不會自動共用。

對於在記憶體中收集資料的頁面，卸載或刷新可能會遺失狀態。在啟用自動刷新或隱藏時關閉之前，請檢查類型指南。主機管理的顯示器有不同的恢復行為。刪除 demo/preview 在期待即時數據之前進行標記。

為您的 AI 提供有用的文件和參考

  • docs/event-reference.html：規格欄位、命名事件、元資料、媒體和捐款值。
  • docs/customoverlays.md：自訂接收器和連接範例。
  • 事件和提醒相容性：設計可以從來源取得哪些事件/欄位。
  • 測試訊息指南 和 createtestmessage.html：範例有效負載和交付模式。
  • libs/objects.js 和 shared/utils/chatHtml.js：包裝展示消毒。
  • shared/utils/chatBadges.js 和 shared/utils/contentImage.js：現有徽章和影像處理。
  • js/transport-dedupe.js, js/local-server-url.js，以及 shared/overlay-control-transport.js：頁面載入時現有的傳輸支援。

當複製不起作用時

症狀檢查
找不到文件再次將 HTML 拖曳到瀏覽器並複製其目前檔案位址。檢查檔案名稱是否以 .html 結尾，而不是 .html.txt。
缺少腳本、字體或圖像保持提取的資料夾結構完整，將編輯後的副本放在原始資料夾旁邊。檢查所有新增的圖稿和字體是否位於預期的資料夾中。
空或「等待」顯示檢查會話、密碼、完整查詢/片段、SSN 的運作狀態、啟用的功能以及符合的輸入。比較原始產生的 URL。
在浏览器中工作，在 OBS 中不同檢查寬度/高度、舊的自訂 CSS、字體可用性、快取和不同的瀏覽器儲存。儲存後刷新。
標誌在更新時消失渲染器可以替換其容器。在其外部放置永久裝飾或更新渲染模板。
狀態重置或動作觸發兩次檢查刷新/卸載設定、重複輸出/控制實例以及頁面的現有重複資料刪除/狀態行為。
特殊情況：讀取單獨資料檔案的頁面

地圖讀取本機 JSON 文件 fetch()，瀏覽器在從磁碟開啟時可以阻止它。對於簡單的地圖重新設計，請使用其託管連結和 OBS 自訂 CSS。對於編輯後的 HTML 副本，請要求 AI 在頁面中包含所需的地圖數據，以便直接從磁碟開啟。託管是專門需要它的頁面的高級選項，而不是這些覆蓋層的正常設定步驟。

停在最小的已確認問題處。重新設計不應需要更改捕獲腳本或發明新的事件欄位。如果共享公共分叉，請包含其支援資產，並將私人啟動器排除在上傳之外。
