可以列印什麼？

Windows 獨立應用程式可向已安裝的 Windows 印表機靜默傳送工作。流程可組合任何可用值，例如觀眾名稱、贊助、產品、訊息或計數器值，並控制文字大小和對齊。

相容性規則： 印表機必須顯示為可運作的 Windows 列印佇列。Social Stream 透過已安裝的 Windows 驅動程式列印；不會傳送原始 ESC/POS、ZPL 或廠商 SDK 指令。

快速設定

  1. 透過 USB 連接印表機，開啟電源並安裝 Windows 驅動程式。先列印 Windows 測試頁。
  2. 在 Social Stream 中開啟 全域設定與工具 → 印表機控制（Printer Control）.
  3. 選擇 尋找印表機（Find printers） 並選擇 Windows 顯示的精確佇列名稱。
  4. 輸入實際紙張寬度，通常為 58, 80，或 62 毫米，取決於裝置及紙材。
  5. 將 固定標籤長度 設為 0 ，讓收據長度隨內容調整。對於模切標籤，輸入標籤沿進紙方向的長度，單位為毫米。
  6. 選擇 列印對齊測試。若缺少某條邊，請增加該側的安全邊界並再次測試。

預設左右各 2 毫米安全邊界適用於許多平價 58 毫米收據印表機，但實際可列印區域由驅動程式決定。請保持 使用可列印區域（Use printable area） 處於選取狀態，除非已測試其他設定。

收據紙捲、連續貼紙或模切標籤？

收據紙捲

最適合可變長度的購買憑條、排隊票及支持者收據。固定標籤長度保留為 0，讓內容決定紙張長度。

連續貼紙捲

適合文字量不同的黏貼式姓名條。行為類似收據紙，但切紙須由印表機或驅動程式處理。

模切標籤

最適合一致的徽章及產品標籤。設定精確的固定長度，並在 Windows 列印喜好設定中設定相同紙材。

印表機範例適用用途連線與紙材說明
通用「POS-58」低成本 58 毫米連續收據通常使用 USB 和直接熱感。型號名稱及驅動程式因賣家而異。Social Stream 的實體開發測試使用了基本 POS-58 列印佇列。
Epson TM-T20III較成熟的收據印表機選項USB 型號；支援 80 毫米紙張，使用隨附寬度轉接器也支援 58 毫米紙張。
Brother QL-800USB 貼紙及地址/姓名標籤直接熱感，支援最寬 62 毫米紙材、模切或連續紙捲，配有自動切刀。
Brother QL-820NWB共用或連網標籤工作站支援 USB、Ethernet、Wi-Fi 和 Bluetooth，以及 Brother 的模切與連續標籤系列。
Zebra ZD220較寬的產品、運送、腕帶或耐用標籤USB 桌上型標籤印表機，適用於約 25–112 毫米紙材；提供直接熱感及熱轉印設定。

這些只是範例，不是保證相容的清單。購買前，請確認確切型號有目前可用的 Windows 驅動程式、支援你的標籤尺寸，並顯示為正常 Windows 印表機。

使用 Event Flow 列印贊助標籤

💰 贊助 / 小費（Donation / Tip）最低金額： 10
→
🖨️ 列印熱感標籤（Print Thermal Label）{username}
{donation}
24 pt · 粗體 · 置中
  1. 開啟 Event Flow 編輯器 並建立流程。
  2. 加入 贊助 / 小費（Donation / Tip） 觸發器。設定 最低金額（Minimum Amount） ，僅在希望列印較大贊助時設定。
  3. 新增 列印熱感標籤（Print Thermal Label） ，從 Integrations 中加入，並將觸發器連接至它。
  4. 將標籤文字設為 {username}，加入新行，然後 {donation}。選擇字型大小、字重、對齊方式及份數。
  5. 通常將動作的印表機及固定長度覆寫值留空或設為 0，以使用全域 Printer Control 設定。
  6. 開啟 測試流程（Test Flow），輸入名稱，啟用 含贊助（Has Donation），輸入金額並執行測試。這會在獨立應用程式中傳送真實列印工作。

其他實用預留位置包含 {message}, {source}, {donationAmount}，以及 {counterValue}。前面節點建立的值也可用於列印範本。

買家使用粗體，商品保持一般字重

選擇 字重 → 選取文字（**粗體**）（Weight → Selected text），然後輸入：

**{username}**
{subtitle}

使用單層大括號。近期商務整合將產品標題放在 subtitle；數量可能透過以下欄位提供： {meta.commerce.quantity}。若前面的節點建立了 buyer，使用 **{buyer}** 作為替代。Shopify 和 eBay 不提供買家身分，因此這些來源應使用本機訂單計數器或僅產品標籤。只有包覆在以下標記中的文字 ** 會變為粗體；不需要自訂 JavaScript 或 HTML。現有 All bold 和 Normal 標籤保留原格式。

對於銷售，使用 Event Type 並指定 purchase；Donation / Tip 要求 hasDonation ，因此不會符合大多數銷售。請使用 gift 或 giftfunded ，當標籤代表已完成的禮物時使用，並依需要篩選供應商。若希望整場直播使用連續訂單編號，請在列印動作前加入 Counter。請參閱 商務事件欄位.

該動作提供 meta.thermalPrintResult.success 以及選用的錯誤/代碼，供後續流程步驟使用。成功表示工作已提交，不表示紙張已輸出。重試狀態不確定的工作前，請檢查 Windows 佇列，以免重複列印標籤。

Counter 為購買編號，不是為不重複買家編號。若要讓同一買家的每次購買重用同一 ID，需要獨立的買家至 ID 對應，並在每場直播開始時明確重設。User Memory 的 reason 欄位是描述性文字，不是專用買家 ID 計數器。

Whatnot 商品標籤

下載 Whatnot 範例流程。它會以粗體列印買家、列印商品名稱，並在提供時列印訂單 ID。付款失敗通知會另外列印 付款失敗 標籤，包含該通知中可用的資訊。

  1. 在獨立應用程式中設定 印表機控制（Printer Control） ，使其符合印表機和紙張尺寸，並執行對齊測試。
  2. 開啟 Event Flow 編輯器，選擇 匯入，並選取下載的 JSON 檔案。
  3. 選擇 Whatnot：商品標籤 + 付款警告。檢查兩個列印動作；它們繼承全域印表機和標籤長度。
  4. 啟用並儲存流程。保持 Whatnot 來源開啟，並啟用直播事件擷取。

範例匯入後處於停用狀態。它使用 事件類型（進階）→ 自訂事件（Event Type (Advanced) → Custom Event） 用於 product_sold 和 payment_failed，並使用 Whatnot 來源篩選器。出價及拍賣結束通知不會列印標籤。

銷售標籤不代表付款已確認。此範例在每則通知到達時列印；不會等待付款、修改先前標籤或指派買家編號。缺少的欄位列印為空白。不含買家、商品或訂單資訊的失敗通知無法識別先前標籤。請參閱 Whatnot 事件欄位.

可預期的固定長度標籤

3 × 1 英吋標籤（包含 Munbyn BT320 設定）： 當 1 英吋邊為進紙方向時，使用 76.2 毫米寬度和 25.4 毫米固定長度。在 Windows 列印喜好設定中比對該紙材及方向。從 12–14 pt 文字開始，測試較長的買家和商品名稱。

對齊測試的側邊框標示在所選可列印區域設定及安全邊界之後的安全寬度。方框高度隨測試文字變化；它不描繪整張標籤，也不會接觸紙張的實體邊緣。

  • 沿進紙方向測量。 62 × 29 毫米標籤通常使用 62 毫米紙寬及 29 毫米固定標籤長度。
  • Windows 設定也須相符。 在印表機驅動程式的列印喜好設定中，選擇精確的標籤紙材、方向、間隙/標記偵測及切刀行為。
  • 固定長度就是固定長度。 Social Stream 不會為固定長度工作增加收據進紙空間。內容過高時，可能被裁切或溢出，取決於驅動程式。
  • 使用實際可能出現的最長資料測試。 較長的觀眾名稱、產品變體、貨幣標籤及多行內容需要更多空間或較小字型。
  • 驅動程式限制仍然適用。 Windows 或印表機驅動程式可能限制非常短的自訂頁面；Social Stream 要求的最小長度為 20 毫米。

直播創意

  • 列印支持者姓名貼紙，用於牆面、道具、地圖或實體進度板。
  • 購買到達時建立商品訂單、委託、飲品或取貨標籤。
  • 列印抽獎票或贈獎參加憑條，並在列印動作前加入限流及資格檢查。
  • 製作 VIP 徽章、團隊分配、挑戰憑證或贊助里程碑標籤。
  • 為在實況主旁工作的製作人列印簡短的審核或訂單處理佇列。
列印個人資料前先考量。 避免列印地址、電子郵件、付款資訊或私人訊息。熱感紙也會因熱、光及時間而褪色，因此不適合長期存檔。

常見解決方式

  • 沒有顯示印表機： 確認 Windows 可列印測試頁，然後重新啟動 Social Stream 並再次選擇 Find printers。
  • 工作回報成功，但沒有列印： 開啟該印表機的 Windows 佇列，檢查暫停、離線、缺紙、驅動程式或連接埠錯誤。
  • 邊緣被切掉： 保持 Use printable area 啟用，並增加該側安全邊界。
  • 空白紙太多： 收據使用固定長度 0，減少底部邊界和進紙量，或為標籤紙材設定精確長度。
  • 一張標籤變成兩張： 內容高於固定標籤，或 Windows 使用了錯誤紙材尺寸。減少文字、字型大小、行距和邊界。
  • Test Flow 使用了錯誤的印表機： 在 Print Thermal Label 節點上選擇印表機覆寫值。直接在編輯器中測試時，空白覆寫值使用 Windows 預設印表機。
