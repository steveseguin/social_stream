保持最後三個警報可見

  1. 開啟 多平台直播提醒 → 多則提醒 / 事件清單.
  2. 選擇 最近三則 — 透明。這使得堆疊、緊湊卡和 保持警報直至更換。變更 可見的警報 對於不同的計數。
  3. 選擇 預覽範例事件 看看虛構的 Twitch、YouTube 和 Facebook 事件。此预览不会连接到您的流。
  4. 複製多流警報框連結。在 OBS Studio 或 Streamlabs Desktop 中，加入 瀏覽器來源 到您的场景并粘贴链接。從 900 × 700 畫布開始，然後調整其大小以適合您的卡片。
  5. 連結 SSN 中的事件來源。新事件加入堆疊並替換最舊的未固定卡。

打開範例堆疊 · 瀏覽堆疊警報樣式

使用緊湊的受眾事件列表

開啟 動態 / 事件 並選擇 最近三則 — 透明。受眾預設隱藏標題、時間戳記、元資料、點擊功能、數數、廣告通知和休閒活動。它保留關注、訂閱、付費支援和其他選定的事件類別。如果您想單獨自訂其隱藏項目，請關閉預設。

使用 選擇出現哪些事件 過濾類別，以及 要監控的來源 來過濾平台。套裝 刪除之後的事件 为零或留空以保留行直到被替换。 預覽受眾群體列表.

歷史和控制

啟用 刷新後記住可見事件 当其浏览器源重新加载时保持面板填充。历史记录是该浏览器、会话和板名称的本地记录； OBS和你的普通浏览器有单独的存储。保留设置范围为 1 至 168 小时。恢复的行使用当前过滤器，不会重播声音或触发自动化。在多重警报中，此选项需要堆叠。

賦予不同的場景不同的 董事會名稱。彈出指令針對對應的板名稱和表面。發送到斷開連接的覆蓋層的命令不是保存的狀態變更。暫停將新到達的事件保存在最多 500 個事件的堆疊和提要緩衝區中；簡歷顯示它們。如果該緩衝區已滿，則其最早的等待事件將被取代。單一警報模式使用其配置的佇列限制。

插銷 切换最新卡的密码；固定的卡片占据可见的插槽。如果每个插槽都已固定，请取消固定卡以接纳新事件。 移除 刪除最新的卡。 清除 刪除可見事件、等待事件和該板的已儲存歷史記錄。多重警報還提供跳過、靜音、取消靜音和重播功能。重播是顯示操作，而不是新的捐贈或事件流觸發器。

對於私人事件儀表板，啟用 顯示操作員按鈕 固定或删除单独的行。在受众浏览器源中关闭此选项。

連接您想要顯示的事件

两个叠加层都使用您的 SSN 源提供的事件。覆盖样式不会添加平台权限或新的事件订阅。

來源設定和事件報道
Twitch使用 Twitch EventSub 對於您的帳戶有權存取的關注、訂閱、禮物、歡呼和突襲。僅聊天捕獲不會取代 EventSub。
Facebook標準 Facebook 捕獲可以將可見的星星捐款轉化為付費支援行。 Facebook API 聊天捕獲不提供星星數量。對於追蹤者和支持者訂閱，請使用將這些通知傳送至 SSN 的事件提供者； Facebook 聊天擷取本身並不能提供這些功能。
YouTube会员资格、礼物、Super Chats、Super Stickers 和珠宝取决于所选的捕获模式。公共订阅者通知需要其 API 路径。參見 事件相容性.
Kick 和 TikTok使用可用的支援活動的來源進行關注、訂閱或贈送禮物。選擇您要顯示的事件類別；喜歡和加入可以隱藏。
Streamlabs 和 StreamElementsSSN 可以擷取現有的提供者事件來源。連線 SSN 中的提供者並保持其來源處於活動狀態。可用事件取決於提供者連線和來源模式。您可以使用SSN的顯示器，同時保留事件或提示的提供者。
其他 SSN 来源捐贈金額和認可的關注、會員資格、禮物和攻擊事件可以使用相同的顯示。參見 事件參考 對於特定於來源的欄位和支援的操作。

如果缺少真實事件，請先檢查它是否出現在 SSN 的活動來源中。檢查來源連接和事件權限（如果不存在）；檢查覆蓋過濾器和最小數量（如果存在）。

取自 Streamlabs 或 StreamElements

對於 Streamlabs 事件清單的始終可見行為，請使用 顯示多個警報 + 保持警報直至更換 在多重警報中，或在事件中預設的受眾。 可見警報/最大事件 設定計數。歷史記錄選項可在同一瀏覽器中恢復最近可見的卡片。使用類別篩選器和最小值控制項來選擇顯示的支援。

您可以將 SSN 的連結直接加入為 OBS 或 Streamlabs Desktop 中的瀏覽器來源。它不需要 SSN 操作員底座。使用圖庫中的 SSN 樣式，然後調整顏色和間距以適合您的場景。
