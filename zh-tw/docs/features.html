功能

匯聚各處聊天，讓觀眾出現在畫面上，打造屬於自己的每一場直播。

探索 126 個直播創意 · 預覽貼圖獎勵

多平台聊天整合

同時與你在各直播平台的觀眾互動。Social Stream Ninja 將數十個平台的聊天訊息匯聚到一個易於管理的控制面板中。

  • 與 Facebook、YouTube、Twitch、Zoom 等平台進行即時雙向聊天
  • 大多數平台無需登入或 API 金鑰
  • 透過多頻道來源圖示區分平台
  • 在平台之間自動轉送訊息

精選聊天疊加畫面

使用美觀、可自訂的疊加畫面，直接在直播中突出展示觀眾的精彩訊息。

  • 透過可停駐的控制面板選取訊息
  • 自動或手動選取訊息
  • 可透過 CSS 自訂，與直播視覺風格完美融合
  • 動畫選項，包括淡入淡出和滑動效果
  • 訊息排隊，有序展示精選內容

機器人指令與自動回覆

透過自訂指令和回覆，與觀眾建立自動化互動。

  • 常見互動的內建指令
  • 透過可撰寫指令碼的外掛檔案自訂指令邏輯
  • 自動問候和回覆
  • 訊息篩選與管理

AI 與 LLM 整合

選擇語音搭檔、聊天機器人、瀏覽器助手或專用 AI 處理工具，無需將直播的其他部分綁定到單一供應商。

  • 能夠聽到你並接收所選直播聊天訊息的語音搭檔
  • 主要聊天機器人和私人聊天機器人，支援自訂指示和觸發規則
  • 本機模型或雲端供應商，包括 OpenAI、Gemini、xAI、Bedrock、OpenRouter、Groq 和自訂相容 API
  • 內容審核、翻譯、摘要、RAG 上下文和疊加畫面建立
  • 選用的 ChatGPT 瀏覽器擷取，無需 API 金鑰

文字轉語音

透過文字轉語音，讓聊天訊息有聲有色，提升直播互動和無障礙體驗。

  • 支援免費的系統 TTS
  • 整合付費 TTS 服務（Google Cloud、ElevenLabs、Speechify）
  • 多語言支援
  • 可自訂聲音、音調和語速
  • 支援 OBS 音訊擷取

強大的 API

透過強大的 API 整合選項擴充 Social Stream Ninja 的能力。

  • 支援用於第三方整合的 webhook
  • 用於遠端控制的伺服器 API
  • 贊助整合（NinjaBacker：免費，平台佣金 0%、Stripe、Ko-Fi、Buy Me A Coffee）
  • MIDI／Streamdeck 控制
  • 支援 OBS 遠端場景控制

深度自訂

透過豐富的功能和外觀自訂選項，讓 Social Stream Ninja 真正符合你的需要。

  • 透過 CSS 樣式全面掌控視覺效果
  • 預設樣式的範本和佈景主題
  • 支援自訂 JavaScript
  • 透過 URL 參數輕鬆設定
  • 來源篩選和品牌選項

進階直播工具

使用專為參與和互動設計的專業工具，提升你的直播體驗。

  • 互動小遊戲，包括 Battle Royal
  • 帶佇列管理的抽獎系統
  • 捲動致謝名單和贊助罐展示
  • 文字雲和自訂 GIF 指令
  • 圖形化投票系統
  • 可搜尋的聊天記錄資料庫
  • 私人 AI 聊天機器人介面
  • 多模態 AI 搭檔功能
