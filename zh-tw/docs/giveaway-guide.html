你的第一次抽獎

觀眾輸入 !enter 到聊天中。你在 SSN 中收集報名，然後點選 抽出獲勝者.

找到控制項 進行抽獎 在 OBS 中顯示 設定的含義 按鈕的作用 疑難排解

1. 找到抽獎工具

如果你已經能看到 抽獎工具, 報名設定，以及 執行抽獎，表示你已經找對了位置，無需再尋找其他抽獎彈出視窗。

否則，請開啟 SSN 主設定選單。使用瀏覽器擴充功能時，點選瀏覽器的擴充功能／拼圖圖示，然後選擇 Social Stream Ninja。在桌面應用程式中，使用包含疊加畫面連結的 SSN 設定選單。搜尋 giveaway 並展開 抽獎選項。如果看到新手歡迎畫面，請選擇 切換到完整模式.

  1. 觀眾報名在正常擷取的聊天中
  2. 由你執行抽獎在 SSN 設定選單中
  3. OBS 顯示結果使用複製的顯示連結

以下列內容開頭的連結： https://socialstream.ninja/giveaway.html?session=... 會開啟觀眾顯示頁面。如果連結中有 &managed 在該連結中時，你從 SSN 控制抽獎；顯示頁面沒有報名或抽獎按鈕。

2. 進行簡單的免費抽獎

開始前，保持 SSN 啟用並連接聊天來源。檢查普通觀眾訊息能否出現在 SSN 聊天停駐面板中。

  1. 保留基本設定。 將 抽獎 ID 作為 default （留空也表示預設）， 報名關鍵字 作為 !enter，以及 訊息符合方式 作為 整則訊息符合。將 僅會員可報名 和 允許重複獲勝 關閉。
  2. 檢查票券和點數獎品。 普通免費抽獎請使用 回合類型：抽獎, 每張票的點數：0, 每位獲勝者的點數獎品：0，以及 獎品數量：1。此功能不需要忠誠度點數系統。
  3. 點選「開放報名」。 告訴觀眾：「輸入 !enter ，在聊天中報名抽獎。」觀眾在你正在擷取的聊天中報名，例如 YouTube 或 Twitch，無需抽獎連結。
  4. 檢查報名情況。 點選 重新整理狀態 更新選單中的計數，或 管理抽獎和歷程記錄 查看名字。重複輸入 !enter 不會讓同一觀眾取得額外的免費報名次數。
  5. 點選「關閉報名」，然後點選「抽出獲勝者」。 SSN 會從符合資格的報名中隨機選擇一份。選單回報獲勝者，已連線的顯示頁面展示同一結果。抽獎也會自動關閉報名。
  6. 如需再次抽獎，點選「新回合」，然後點選「開放報名」。 新回合的報名清單為空；觀眾必須重新報名。先前的結果會保留在歷程記錄中。
「報名已開放 - 0 份符合資格的報名」不是錯誤。 抽獎正在接受報名，但上次狀態檢查尚未發現報名。讓一位觀眾傳送 !enter ，在報名開放後傳送，然後點選 重新整理狀態。聊天到達時，彈出選單中的計數不會自動更新。

狀態也可能顯示票券數量。每份免費報名算作一張票；票價設為零時，不會收取點數。

SSN 負責選出獲勝者。如果獎品是禮物、遊戲啟用碼或其他物品，需要由你自行安排交付。 點數獎品 專門用於發放 SSN 忠誠度點數。

3. 在 OBS 中顯示抽獎

  1. 位於 展示，選擇一個 抽獎顯示: 獲勝者卡片 直接顯示結果； 姓名捲軸 會在揭曉前循環顯示名字； 社群轉盤 透過旋轉轉盤揭曉結果。
  2. 選擇一個 樣式、選用的 顯示標題，以及 透明（OBS） 作為背景。 佈景主題面板 會新增背景面板。
  3. 點選 預覽顯示 檢查外觀。它使用範例名字，不會開放報名、新增真實觀眾或執行你的實際抽獎。
  4. 點選 [複製連結] ，位於下列選項旁： 抽獎工具。在 OBS 中新增一個 瀏覽器來源 ，將連結貼到 URL 欄位。起始寬度為 1280 ，高度為 720.
  5. 保持 SSN 執行，並使用其 開放報名, 關閉報名，以及 抽出獲勝者 按鈕。此受管理的顯示頁面不需要 OBS「互動」操作。

變更展示設定後重新複製連結 並取代 OBS 中的 URL。使用正常複製的連結，不要使用預覽 URL。保留你自己的 SSN 選單提供的工作階段和任何密碼，以便顯示頁面連接到你的抽獎。

[編輯連結] 將現有疊加畫面 URL 載入選單的連結設定中。第一次抽獎不需要使用它。 [?] 會開啟簡短說明文字。

報名設定的含義

設定含義
抽獎 ID為目前控制的抽獎命名。使用 default 來執行一個抽獎。它與你的工作階段 ID 無關。多個抽獎需要不同的 ID 和相符合的顯示連結。
報名關鍵字觀眾輸入的內容，例如 !enter 或 !raffle。請告知觀眾你實際設定的關鍵字。
整則訊息符合整則訊息必須為 !enter，忽略大小寫及頭尾空格。 !enter please 不符合。
關鍵字可在任意位置（獨立詞語）允許這樣的訊息： I'd like to join !enter please。關鍵字必須用空格分隔； !enter! 不是相同的關鍵字。
僅會員可報名需要擷取的訊息包含會員資訊。開放式抽獎請關閉；它不表示「任何正在觀看的人」或「任何追蹤者」。支援情況取決於聊天來源。
允許重複獲勝允許同一觀眾在目前回合贏得多個獎品。關閉時，獲勝者會從該回合符合資格的抽獎池中移除。新回合允許先前的獲勝者重新報名。
票券和點數獎品選用的 SSN 忠誠度點數設定及其他遊戲類型。免費抽獎請將費用和點數獎品保留為零。這些點數與 Twitch 頻道點數分開。
獎品數量該回合允許產生多少個結果。請在開放報名前設定。如果要抽出多個獲勝者，請點選 抽出獲勝者 ，每個獎品點選一次；這些抽獎之間不要建立新回合。

在有人加入前設定報名規則。一旦有報名，修改選單欄位不會變更目前回合的規則。要變更規則，請取消該回合、建立新回合、完成設定，再次開放報名。管理器會顯示該回合實際儲存的規則。

免費報名按各聊天來源提供的身分追蹤。同一個人在兩個平台報名，不會自動識別為同一人。

按鈕的作用

按鈕用於
開放報名接受報名，或在尚未抽出任何獲勝者前重新開放暫停的回合。重新開放會保留現有報名，並且必須使用相同的已鎖定規則。
關閉報名停止接受新報名，保留目前抽獎池。
抽出獲勝者關閉報名並選出一位獲勝者。必須至少有一份符合資格的報名。如果設定為一個獎品，該回合隨後即告結束。
取消並退款在抽獎前取消。所有預留的購票點數都會退回。此動作無法撤銷已抽出的結果。
新回合以空抽獎池重新開始，並保留先前歷程記錄。報名初始為關閉狀態。已預留點數的付費回合必須先取消並退款。
重新整理狀態讀取目前計數和最新結果，不變更抽獎。
管理抽獎和歷程記錄查看參與者和已儲存的規則、在抽獎前移除報名、查看結果，或匯出歷程記錄／備份。

如果出現問題

  • 報名仍為零？ 點選 重新整理狀態。確認觀眾訊息出現在 SSN 中、訊息到達時已開放報名、關鍵字符合，且未啟用僅限會員。免費關鍵字抽獎的票價必須為零。同時進行的免費抽獎應使用不同關鍵字。
  • 測試訊息無法報名？ 機器人、私人、歷史、重播和帶有經濟系統測試標記的訊息會被排除。使用 預覽顯示 用於檢查外觀；要演練真實報名擷取，請在開放報名後透過已連線的聊天傳送關鍵字。
  • 顯示頁面只寫著「等待抽獎」？ 保持 SSN 主機執行，使用從相同工作階段複製的連結，並點選 重新整理狀態。檢查選單和顯示頁面是否使用相同的抽獎 ID。預覽 URL 只顯示範例資料。
  • 抽獎頁面沒有按鈕？ 對於受管理的觀眾顯示頁面，這是預期行為。返回 抽獎選項 ，位於 SSN 中。
  • 回合已完成或規則被鎖定？ 使用 新回合 ，用於完成抽獎後。要放棄尚未抽出的回合，請使用 取消並退款 ，然後再 新回合.
  • 重新啟動了 SSN？ 已儲存的回合會保留在該本機瀏覽器／應用程式設定檔中；開放中的回合會關閉以供檢查。請使用相同工作階段，重新整理狀態，並在重新開放前檢查。切換工作階段會選擇另一組獨立的抽獎。
