設定第一個提醒

  1. 開啟 Multi-Alerts → Event animations & sound effects。
  2. 先啟用提醒，再選擇事件。100 美元贊助預設組合會填入兩個金額限制，並在未選擇聲音時提供合成的 Thank you 聲音。
  3. 可新增直接指向 GIF、圖片或影片的 URL，也可上傳媒體。GIPHY 頁面連結不是直接媒體 URL。GIF 圖片沒有音訊，請另選聲音。
  4. 選擇聲音，點擊 Listen 在本機試聽。自訂 URL 和上傳選項位於選擇器下方。
  5. 先使用 Test alert，再將 Multi-Alerts 連結新增為 OBS 瀏覽器來源。

金額限制與優先順序

贊助和 Bits 使用貨幣助手估算的美元值。若僅針對 100 美元，將上下限都設為 100；若針對至少 100 美元，將上限留空。上下限留空則允許任意金額；其他事件類型不應設定金額限制。

採用第一條符合的提醒。請將具體規則放在廣泛規則前面。平台和類別篩選器仍然生效。

預覽與聲音

Test alert 會開啟本機預覽並將其置於前景，不會向直播頻道傳送事件。預覽使用目前疊加畫面設定、篩選器、媒體和時間參數。音量位於 Sound & Timing。

Clear sound 會移除自訂聲音覆寫設定，但預設提醒音仍有效。關閉 Play alert sound 可將疊加畫面音訊靜音。Enable alert 可暫停規則並保留設定。Reset alert 只清除該條規則。

語音短句標為合成錄音。對於姓名或變動的文字，請使用 Event Flow 編輯器的 Speak Text 操作。

Event Flow 與 OBS 效果

使用 Event Flow 範本安排順序動作和 OBS 效果。其媒體與聲音操作在 Flow Actions 疊加畫面中播放。每個事件的聲音只使用一個疊加畫面，避免重複播放。使用 OBS 範本前，需要先選定來源和濾鏡。
