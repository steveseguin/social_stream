首次發言者指南

用醒目顯示、葉子徽章或選用提示音標記全新的聊天參與者。

此功能的作用

首次發言者偵測會新增 firsttime=true 到該來源中為該觀眾儲存的第一則聊天訊息。停駐面板可利用此旗標新增背景底色、僅首次發言提示音和選用的葉子徽章。

必要設定

  1. 開啟 Social Stream Ninja 彈出選單。
  2. 保持 停用本機訊息資料庫 處於關閉狀態。
  3. 開啟 首次發言者偵測.
  4. 使用相同工作階段 ID，保持停駐面板或疊加畫面開啟。
重要： 此功能需要本機資料庫。如果停用了資料庫，Social Stream Ninja 就無法判斷某人是否為新觀眾。

顯示選項

  • 背景底色： 停駐面板預設啟用。請保持 不為首次發言者新增背景底色 處於關閉狀態，即可醒目顯示。
  • 葉子徽章： 開啟 用自訂徽章標記首次發言者 ，在聊天參與者的徽章前加上小葉子徽章。
  • 停駐面板首次發言提示音： 如果希望停駐面板僅在有人首次發言時播放提示音，請開啟此項。
  • 新觀眾或回歸觀眾提示音： 如果也希望為安靜 8 小時以上後再次發言的觀眾播放提示音，請開啟此項。

在自訂疊加畫面中使用此旗標

自訂疊加畫面可以檢查 data.firsttime === true。如果啟用了葉子徽章選項，徽章會包含在 chatbadges ，在訊息到達疊加畫面之前完成。

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

如果沒有顯示

  1. 確認 停用本機訊息資料庫 處於關閉狀態。
  2. 確認 首次發言者偵測 處於開啟狀態。
  3. 確認 不為首次發言者新增背景底色 處於關閉狀態，才能醒目顯示。
  4. 確認 用自訂徽章標記首次發言者 處於開啟狀態，才能顯示葉子徽章。
  5. 使用尚未儲存在本機資料庫中的使用者名稱／來源組合進行測試。
