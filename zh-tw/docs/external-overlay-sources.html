Discord StreamKit 與 TikFinity 來源

將第三方疊加畫面連結用作 Social Stream Ninja 中的唯讀聊天來源。

瞭解兩個連結的差異

這些設定使用兩個不同的連結：

  • 輸入連結： 貼到 Social Stream Ninja 中的 Discord StreamKit 或 TikFinity URL。Social Stream 從中讀取訊息。
  • 輸出連結： 你的 Social Stream 停駐面板或疊加畫面 URL。開啟停駐面板測試訊息，然後將疊加畫面 URL 新增到 OBS。

如果只想在畫面上展示 Discord 或 TikFinity 的原始設計，請直接將其連結貼到 OBS 瀏覽器來源。如果需要統一聊天、TTS、篩選、訊息醒目顯示或其他 Social Stream 功能，再將它用作 Social Stream 來源。

應該使用哪個選項？

Discord StreamKit

透過 Discord 官方聊天小工具，讀取一個 Discord 伺服器頻道中的新文字訊息。

  • 需要 Discord 桌面應用程式保持開啟。
  • 無需在伺服器中安裝機器人。
  • 唯讀：Social Stream 無法透過 StreamKit 回覆 Discord。

TikFinity OBS 停駐面板

使用 TikFinity 作為 TikTok LIVE 聊天和事件的備用讀取器。

  • 需要 TikFinity 保持開啟並連線。
  • 適用於 TikTok 直連模式缺少或遺失訊息的情況。
  • 唯讀：如需回覆，請使用 TikTok 直連模式。
避免重複： 不要同時用直連來源和這些備用來源之一擷取同一個聊天。
Discord

設定 Discord StreamKit

  1. 開啟 Discord StreamKit 疊加畫面.
  2. 選擇 為 OBS 安裝 ，並在 Discord 提示時授權 StreamKit。
  3. 選擇 聊天 小工具，然後選擇要擷取的伺服器和文字頻道。
  4. 複製聊天小工具的安裝連結。它應以下列內容開頭： https://streamkit.discord.com/overlay/chat/.
  5. 在 Social Stream 桌面應用程式中開啟 來源和設定 -> Discord.
  6. 選擇 使用 Discord StreamKit URL，貼上連結並新增來源。
  7. 擷取期間保持 Discord 桌面應用程式執行。

使用 Social Stream 瀏覽器擴充功能時，啟用 Discord ，位於選用聊天服務下，然後在瀏覽器分頁中開啟產生的 StreamKit Chat 連結。

  • Social Stream 會略過頁面首次開啟時已經可見的訊息。請在來源就緒後傳送新的測試訊息。
  • 它會擷取新文字、名字、基本格式、表情符號和顯示的名稱顏色。
  • 它不會擷取 Discord 通話或舊訊息記錄，也無法可靠地提供所有頭像、附件、回覆和角色詳細資料。
TikTok 備用方案

設定 TikFinity OBS 停駐面板

  1. 開啟 TikFinity 並將其連接到 TikTok LIVE 帳號。
  2. 前往 疊加畫面 -> OBS 停駐面板.
  3. 使用齒輪按鈕選擇停駐面板應顯示的事件，包括聊天。
  4. 複製 Dock 1 或 Dock 2 的 URL。
  5. 在 Social Stream 桌面應用程式中選擇 其他聊天網站.
  6. 貼上 TikFinity 停駐面板 URL，並啟用新來源。
  7. 直播期間保持 TikFinity 開啟並連線。
  • 此來源在設定中標為 TikFinity，但其訊息在 Social Stream 內使用一般的 tiktok 來源類型。
  • 這是備用讀取器，不是傳送 TikTok 回覆的方式。
  • 瀏覽器擴充功能使用者也可以開啟支援的 TikFinity Activity Feed 小工具 URL，其中包含 /widget/vite/src/activity-feed/.

請遵循 附擷圖的 TikFinity 設定指南 ，查看使用者名稱、OBS 停駐面板設定和 SSApp 步驟。關於 TikTok 直連模式和回覆選項，請參閱 TikTok 指南.

驗證完整工作流程

  1. 使用你的工作階段 ID 開啟 Social Stream 停駐面板。
  2. 在所選 Discord 頻道或 TikTok LIVE 聊天中傳送一則新的測試訊息。
  3. 確認它在 Social Stream 停駐面板中只出現一次，且名稱和文字正確。
  4. 將你選擇的 Social Stream 疊加畫面 URL 新增為 OBS 瀏覽器來源，使用相同的工作階段 ID。
  5. 再傳送一則訊息，確認它在停駐面板和 OBS 中都只出現一次。
  6. 讓來源執行幾分鐘，確認後續訊息仍持續到達。

參閱 OBS 快速入門 ，查看停駐面板和瀏覽器來源的設定步驟。

如果訊息沒有出現

  • 使用新訊息測試。已有訊息刻意不匯入。
  • 確認 Discord 或 TikFinity 仍保持開啟、已登入且已連線。
  • 確認複製的連結指向聊天小工具或 OBS 停駐面板，而非其設定頁面。
  • 變更所選伺服器、頻道、停駐面板或事件後，請重新載入或重新建立 Social Stream 來源。
  • 排查 OBS 前先檢查 Social Stream 停駐面板。如果停駐面板為空，問題還不在 OBS。
  • 請將複製的來源連結視為私人設定資訊。不要公開，也不要在分享螢幕時暴露。
