建立測試訊息

向 Social Stream 工作階段傳送可控的模擬訊息和事件。

此工具的作用

此 建立測試訊息頁面 將模擬 Social Stream 承載資料傳送至停駐面板、疊加畫面、提醒或 Event Flow 設定。用它測試，無需等候真實聊天訊息、贊助、會員、突襲、獎勵或其他事件。

盡可能使用測試工作階段。 提交的訊息會像傳入的工作階段流量一樣運作，可能觸發提醒、聲音、webhook、OBS 動作或其他自動化。

SSApp 或擴充功能快速入門

  1. 開啟 Social Stream Ninja，並確認服務處於作用中。
  2. 位於 全域設定與工具 → 運作方式，啟用 擴充功能的遠端 API 控制。SSApp 使用相同的設定名稱。
  3. 從 Social Stream 或以下位置複製工作階段 ID： session= 值，位於停駐面板或疊加畫面 URL 中。
  4. 開啟 建立測試訊息 並輸入該工作階段 ID。
  5. 將 傳送方式（Send Via） 設為 擴充功能 API 接收（Extension API ingest） 用於一般測試。
  6. 選擇預設組合、調整欄位，然後選擇 載入預設組合（Load Preset）.
  7. 檢查 Payload JSON，然後選擇 提交（Submit）.
  8. 確認項目出現在停駐面板或目標疊加畫面中，並且預期的自動化已執行。

可以在 URL 中包含工作階段： createtestmessage.html?session=YOUR_SESSION_ID.

範例：一則模擬的 1,000 KICKs 訊息

這會建立一則價值 1,000 KICKs 的 Kick 樣式支持訊息，不會建立 1,000 則獨立訊息。

  1. 選擇 聊天訊息（Chat Message） 預設組合。
  2. 設定 輸入 為 Kick.
  3. 輸入測試名稱和訊息。
  4. 設定 含贊助（Has Donation） 為 1000 KICKs.
  5. 選擇 從欄位更新 JSON（Update JSON from Fields），檢查 JSON 並提交。

最小承載資料為：

{
  "type": "kick",
  "chatname": "Test Supporter",
  "chatmessage": "Thanks for the stream!",
  "hasDonation": "1000 KICKs"
}

使用 聊天訊息（Chat Message） 用於本範例。 贊助 / Cheer 預設組合包含 Twitch 專屬的 cheer 欄位。

使用預設組合和自訂 JSON

預設組合為常見情況提供起始承載資料，例如贊助、訂閱者、贈送訂閱、突襲、獎勵、觀眾更新、首次聊天者和列車事件。

  • 載入預設組合（Load Preset） 使用所選預設組合和目前欄位值取代 JSON。
  • 從欄位更新 JSON（Update JSON from Fields） 根據可見欄位建立基本訊息。
  • 您可以直接編輯 承載資料 JSON（Payload JSON） 以測試特定欄位或事件結構。
  • hasDonation 帶有可見的支持金額，例如 1000 KICKs 或 $10.00.
  • 僅包含 event 當測試真實的具名事件時。一般贊助樣式聊天列可以使用 hasDonation 本身。

有關欄位定義和真實平台範例，請參閱 事件參考.

選擇正確的傳遞模式

傳送方式（Send Via）適用情境必要設定
擴充功能 API 接收（Extension API ingest）測試一般停駐面板、疊加畫面、提醒、Event Flow 或 SSApp。相同的工作階段 ID，以及 擴充功能的遠端 API 控制 已啟用。
直接傳送至通道 1目標停駐面板開啟時使用了 &server.目標必須監聽相符的伺服器通道。
直接傳送至通道 4測試使用以下設定的目標： &server2，包括相容的事件頁面。目標必須監聽相符的伺服器通道。

如果不確定，使用 擴充功能 API 接收（Extension API ingest）.

常見解決方式

  • 沒有內容出現： 確認目標頁面已開啟，並使用相同工作階段 ID。
  • Extension API ingest 失敗： 啟用 擴充功能的遠端 API 控制，然後重新載入停駐面板或疊加畫面並重試。
  • 直接模式顯示已傳送，但沒有內容出現： 使用 Extension API ingest，除非目標 URL 具有相符的 &server 或 &server2 模式。
  • 觸發了錯誤的事件： 檢查 Payload JSON 是否殘留其他預設組合的欄位。
  • Kick 測試表現得像 Twitch： 使用 Chat Message 預設組合，並設定 type 和 hasDonation 如上所示。
  • 自動化執行不只一次： 檢查同一工作階段是否開啟了多個停駐面板、動作頁面或 Event Flow 實例。
