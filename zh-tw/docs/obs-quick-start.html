OBS 快速入門

透過最少的步驟將聊天顯示在 OBS 中。

1. 選定一個工作階段 ID

自訂一個簡短的工作階段 ID，並在所有位置使用。聊天來源、停駐面板與 OBS 疊加畫面透過它找到彼此。

YOUR_SESSION_ID

2. 啟動聊天來源

  1. 安裝或開啟 Social Stream Ninja。
  2. 開啟所用平台的聊天來源並保持開啟。
  3. 傳送或等待一則聊天訊息，以確認來源正常運作。

不確定使用哪種來源模式？參閱 平台設定選擇器.

3. 開啟停駐面板

停駐面板是您的測試畫面。在變更 OBS 設定前先開啟它。

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

4. 新增 OBS 瀏覽器來源

在 OBS 中新增瀏覽器來源並貼上疊加畫面 URL。

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

若要使用一般聊天疊加畫面配置，請使用下列頁面中的範本： 範本庫.

5. OBS 空白時

依此順序逐項檢查。

  • 先確認停駐面板收到訊息。如果停駐面板為空，問題還不在 OBS。
  • 確認 OBS URL 具有相同的 session.
  • 變更 URL 選項後重新整理 OBS 瀏覽器來源。
  • 檢查來源聊天頁面或應用程式來源視窗是否仍在執行。
