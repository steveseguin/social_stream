名額看板與近期銷售

追蹤可用名額，並將近期購買記錄保留在畫面上。在 SSN 中控制，在 OBS 中展示。

揭曉名額 ↓球隊看板 ↓近期銷售 ↓Whatnot / eBay Live ↓

名額看板

編號名額

開啟範例預覽 ↗
  1. 建立看板在 營利 → 名額看板與近期銷售，選擇編號方塊。設定 120 個名額、20 欄，可得到 20 × 6 的網格。
  2. 標記認領選取一個方塊，然後 為此名額記錄銷售 ，請先核對付款。使用 僅標記為已認領 ，僅預留名額而不產生銷售記錄。
  3. 揭曉物品輸入分配的物品，然後選擇 揭曉。使用 設為可認領 可更正名額，或使用 退款並重新開放 同時移除其關聯銷售。

SSN 顯示你的分配結果。它不會出售名額或隨機分配獎品。

具名名額

球隊拆卡

球隊拆卡會按球隊、球員或其他具名名額分配拆出的卡片。

  1. 選擇 球隊方塊.
  2. 貼上球隊名稱，每行一個。此清單決定名額數量。
  3. 將每個已購買名額標記為已認領。準備好後再揭曉。
開啟球隊預覽 ↗

認領由主播控制。SSN 不會根據聊天訊息或拍賣結束來推斷某個球隊名額已被購買。

在 Whatnot 或 eBay Live 直播期間

  1. 擷取你的直播在 SSN 中開啟你的直播並啟用 擷取直播事件。Whatnot 需要顯示拍賣底列的直播檢視。eBay Live 支援聊天頁或直播頁。
  2. 核對銷售位於 近期銷售，在下列選項中選擇 Whatnot 或 eBay Live： 拍賣物品助手 並儲存。 使用拍賣物品 會複製最後擷取到的名稱。請在銷售平台核對物品和付款，然後輸入銷售總額和幣別。
  3. 先確認，再揭曉對於某個名額，選取其方塊，然後選擇 為此名額記錄銷售 。 確認銷售並認領名額 會同時記錄兩者。準備展示分配的物品時，再新增揭曉文字。

助手提供的是操作員草稿。它絕不會將出價或拍賣結束轉換為銷售。新的拍賣更新不會變更你的草稿。啟用 顯示近期銷售 可選擇觀眾看到的顯示內容；如需同時顯示看板和銷售，請分別使用兩個 OBS 來源。

如需退款，請使用 退款並重新開放 ，可移除關聯銷售並釋放名額。 移除 只移除銷售記錄。替換後的看板與舊看板的銷售記錄彼此獨立。

直播擷取與商店連線的差異

Whatnot 和 eBay Live 擷取會提供物品、出價和拍賣狀態。獨立的 eBay 賣家連線 會接收所選商品刊登的已付款訂單事件，可自動填入近期銷售。請勿手動確認商店連線已經記錄的同一筆購買。其他自動來源包括 Shopify、Fourthwall、Ko-fi 和 Buy Me a Coffee。

助手只保留從所選平台最後擷取到的物品，五分鐘沒有更新後即失效，重新啟動時會清空。如果開啟了多個直播，請核對物品。助手為空時，需要在啟用後收到新的拍賣更新。

eBay：在賣家控制台檢查付款狀態 · Whatnot：拍賣付款失敗

銷售記錄

近期購買

提醒消失後，仍將實際購買記錄保留在畫面上。可選擇精簡清單、六卡片展示牆，或放在活動旁邊的長條。

清單預覽 ↗展示牆預覽 ↗長條預覽 ↗

從商店收集

開啟 顯示近期銷售 和 收集已連接商店的購買記錄，然後儲存銷售選項。

使用 SSN 新收到的 Shopify、eBay 賣家、Fourthwall、Ko-fi 和 Buy Me a Coffee 的 購買 事件。

自行確認銷售

輸入物品，可選填銷售總額和幣別。選擇 確認銷售.

適合在核對購買後記錄 Whatnot、eBay Live 或線下銷售。這些項目會顯示 主播已確認.

更正和退款

移除錯誤或已退款的銷售記錄。為新一場直播清空展示牆。

出價、小費、禮物和沙箱測試不會填入此顯示。認領看板名額不會建立銷售記錄。

價格、歷程記錄與隱私

已連接的購買資料來源並不總是提供物品價格，因此自動產生的項目會留空價格。要顯示已知價格，請移除該項目並手動確認。對於多件物品，請輸入該項目的總額，而非單件價格。系統不會用標價、最高出價或贊助金額替代。

SSN 會在目前的安裝中保留最新的 100 筆記錄，重新啟動後也會保留。啟用後才開始收集，不會完整匯入訂單記錄。系統會在已儲存的 2,000 個傳遞 ID 範圍內忽略重複傳遞。退款記錄需要手動移除。

此顯示不包含買家姓名、地址、付款詳細資料或尚未揭曉的物品文字。示範連結使用明確標註的虛構資料。

OBS 設定

  1. 選擇顯示方式在看板控制項中選擇「名額／球隊看板」、「近期銷售清單」、展示牆或長條。
  2. 複製 OBS 連結新增尺寸為 1920 × 1080 的瀏覽器來源。透明區域可透出攝影機畫面。
  3. 在 SSN 中控制保持 SSN 開啟。變更會立即儲存。 OBS 商品控制停駐面板 也提供相同控制項，可按喜好選用。
選用的 URL 設定

&view=board, sales, wall 或 ticker 選擇版面配置。 &limit=6 顯示最多六筆近期記錄（上限為 24 筆）。 &prices=0 隱藏價格。 &label=Recently%20sold 設定銷售標題。 &onlytype=shopify,ebay 篩選銷售來源。

保留複製連結中的工作階段、密碼和轉送設定。未連線或沒有內容時，顯示保持透明；設定訊息絕不會出現在觀眾疊加畫面上。

API 與 Event Flow 整合

這些控制項擴充了現有的 commerceControl API。SSN、Stream Deck 自訂 API 動作和選用的 OBS 停駐面板會讀取同一個 getCommerceState 回應。

{"action":"commerceControl","value":{"command":"boardSpot","data":{"id":"12","status":"claimed"}}}

指令： boardSave （title、style、columns，以及 count 或按行分隔的標籤）， boardSpot （id、status、result）， boardVisibility （visible）， saleAdd （title，選用的 amount/currency/quantity/platform；選用的 boardId 和 spotId 用於認領名額）， saleRemove （id，選用的 reopenSpot）， salesClear，以及 salesSettings （visible、automatic，選用的 auctionSource：whatnot、ebay 或空字串）。將這些欄位放入 data。這些編輯不會發出購買事件，也不會觸發付費獎勵。

在 Event Flow，使用現有的 商品與支持 動作。選擇看板或銷售指令，並在下列位置輸入欄位： 看板／銷售欄位。字串值可使用變數，例如 {subtitle}。銷售動作應符合已確認的購買事件。如果流程手動新增了同一筆銷售，請關閉自動收集。
