影片統計與位元率

在 Social Stream Ninja 停駐面板右上角顯示傳入串流的位元率。

重要： SSN 不會自動從 OBS 或直播平台讀取位元率。它會輪詢接收直播的影片伺服器統計 API。
用途相容性使用方法如果沒有顯示任何內容進階：通訊協定、格式及單位

用途

這會為主持人或製作人在停駐面板中提供小型即時位元率讀數。當 OBS、行動編碼器或其他傳送端將影片發佈至自己的中繼或接收伺服器時很有用。

SSN 也會將可用的延遲、緩衝、封包遺失、執行時間、編解碼器及觀眾資料正規化為 video_stats 中繼資料事件。標準停駐面板讀數僅顯示位元率。

相容性

  • SRT Live Server / SLS： JSON /stats 端點，其中包含 publishers 物件內。
  • Belabox Cloud： 其 SRT 風格的 JSON 接收端/中繼統計回應。
  • NGINX RTMP： 來自 NGINX RTMP 狀態模組的 XML。
  • Node Media Server： 其 JSON 串流 API，可選用 HTTP Basic 驗證。
OBS 不是統計來源： OBS 可向相容伺服器傳送影片，但 OBS WebSocket 和 SSN 瀏覽器來源不提供這些資料。

使用方法

  1. 啟用相容伺服器的 HTTP 統計端點，並確認執行 SSN 的電腦能開啟其 URL。
  2. 在 SSN 中 全域設定，啟用 影片統計輪詢.
  3. 選擇來源類型並輸入統計 URL。
  4. 對於 SRT 或 Belabox，輸入精確的發佈者 ID，例如 publish/live/feed1。回應僅包含一個發佈者時，SSN 會自動使用它。
  5. 對於 NGINX RTMP 或 Node Media Server，輸入應用程式和串流金鑰/名稱，例如 live 和 feed1.
  6. 若有需要，加入授權。SRT API 金鑰欄位會作為完整的 Authorization 標頭傳送。Node Media Server 將使用者名稱/密碼用作 HTTP Basic 驗證。
  7. 選擇 1 至 60 秒的輪詢間隔；預設為 5 秒。
  8. 在停駐面板選項中啟用 若可用，在右上角顯示位元率中繼資料，然後開啟或重新整理停駐面板連結。
  9. 開始發佈影片。收到有效的上線回應後會顯示位元率。

如果沒有顯示任何內容

  • 確認 SSN 中兩項影片統計選項都已啟用。
  • 確認端點在 5 秒內回應，且來源類型及串流識別碼相符。
  • 127.0.0.1 指執行 SSN 的電腦。若伺服器位於其他裝置，請使用其區域網路位址。
  • 當直播離線、位元率缺失或為零，或約 130 秒未收到新統計資料時，讀數會消失。

進階：通訊協定、格式及單位

SSN 執行 HTTP 或 HTTPS GET ，依設定的間隔執行，停用快取，逾時為 5 秒。

SRT Live Server / SLS 與 Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate 的單位為 Kbps；RTT 和接收緩衝為毫秒；接收速率與頻寬為 Mbps；執行時間為秒；遺失/捨棄值為封包數量或位元組數。

NGINX RTMP

該 URL 必須傳回 NGINX RTMP 狀態 XML。SSN 比對設定的應用程式與串流，並讀取 bw_video 作為每秒位元組數，並除以 1024 得到 bitrateKbps。它也讀取直播時間以及選用的影片/音訊編解碼器中繼資料。

Node Media Server

SSN 請求 STATS_URL/APPLICATION/STREAM_NAME。欄位可位於最上層或 data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

位元率單位為 Kbps，觀眾為人數，時長單位為秒。

正規化 SSN 事件

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
欄位單位/類型
bitrateKbpsKbps，整數
rttMs / bufferMs毫秒
recvRateMbps / bandwidthMbpsMbps
遺失/捨棄欄位封包數量或位元組數
uptimeSeconds / durationSeconds秒
online布林值； false 會隱藏停駐面板中的數值

停駐面板接受 meta.bitrateKbps，帶有 meta.bitrate 和 meta.kbps 作為備用值。低於 1000 的值以四捨五入後的 Kbps 顯示；更大的值以 Mbps 顯示，保留一位小數。統計 URL、串流金鑰及憑證絕不會傳送至疊加畫面。
