主持人設定

由您決定哪些內容
顯示在螢幕上。

這些獎勵使用 SSN 自己的忠誠點數餘額，而非 Twitch 或 Kick 原生頻道點數。只有希望啟用此互動時才開啟。

預設限制：螢幕顯示 6 秒、每位觀眾冷卻 60 秒、每張貼圖冷卻 20 秒，以及 3 秒間隔。冷卻期間的請求會被拒絕且不收費。

  1. 開啟 點數系統 → 貼圖獎勵 ，位於 SSN 控制項中。啟用點數系統與貼圖獎勵。
  2. 選擇一個或多個套組並設定價格。為節目設定冷卻時間與顯示時長。
  3. 新增產生的 貼圖疊加畫面 工作階段連結，作為 OBS 瀏覽器來源。接受兌換時保持其執行。
  4. 也可新增 &stickers 至多類型提醒或事件串流 URL。只使用一個貼圖顯示頁面，以免獎勵顯示兩次。
  5. 告訴觀眾使用 !stickers 查看已啟用選單，以及 !sticker rocket 進行兌換。來源聊天回覆為選用，需要受支援的回傳連線。

貼圖連線使用標準 SSN iframe 橋，即使聊天使用伺服器模式也是如此。僅本機部署需要能夠存取該橋。

使用 GIPHY 表情

複製直接的 GIF 或 WebP 媒體連結，而非 GIPHY 頁面位址，並將其新增為自訂貼圖。使用時會從託管方取得圖片；該託管方必須允許載入圖片。

自訂代碼為 hype 變為 !sticker custom-hype。靜態 PNG、JPEG 與 WebP 圖片也可使用。請使用您有權展示的作品。

如需平靜的配置，新增 &motion=off 以停止內建貼圖動畫。GIF 內容仍會動，因此如果不希望有動態，請選擇靜態圖片。選用的 &size=400 和 &hidecaption 可調整播放器。
