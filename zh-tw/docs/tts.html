概述

SSN 可以朗讀從任意支援來源擷取的聊天文字；聊天平台本身不需提供 TTS 功能。 啟用 TTS 的停駐面板或疊加畫面會依篩選器及 TTS 設定，朗讀收到的訊息。先閱讀 簡明設定指南；本頁介紹語音選項和進階設定。 比較提供者、試聽範例並查看設定。

快速開始： 使用 dock.html?session=YOUR_SESSION&speech=en-US。預設使用 System TTS。若要使用免費的 OBS 供應商，還需加入 &ttsprovider=kokoro。保持此頁面開啟並連接；僅應有一個副本發聲。

TTS 用於哪些位置？

  • Social Stream Ninja： 在多個介面中朗讀觀眾聊天訊息
  • CAPTION.Ninja： 提供字幕、轉錄及結合 TTS 的翻譯
  • 兩項服務均提供付費及免費 TTS 選項
System TTS 不等於所有免費 TTS：
  • 系統語音取決於瀏覽器及作業系統。即使 Chrome/Edge 可用，OBS 也可能不提供任何可用語音。
  • 語音無法使用與語音在 OBS 音訊擷取之外播放是不同問題。音訊路由無法彌補缺少的語音支援。
  • Kokoro、Piper、Kitten 及 eSpeak 等免費供應商則產生頁面音訊。在 OBS 中使用 TTS 不必付費。
  • 先檢查語音可用性，再檢查音訊擷取。

TTS 供應商選項

System TTS（免費）

  • 使用作業系統內建語音
  • 語言支援受系統安裝情況限制
  • 語音可用性及音訊路由取決於瀏覽器和作業系統；請在實際播放器中測試
  • 瀏覽器相容性差異很大

系統語音可用性

這些是典型能力，並非對所有安裝環境的保證。OBS 使用自己的嵌入式瀏覽器，不會繼承已安裝 Chrome/Edge 的語音清單。SSN 應用程式測試成功不代表獨立的 OBS 瀏覽器來源也已通過測試。

Chrome

✓ 在支援的安裝環境中可使用系統語音

Edge

✓ 在支援的安裝環境中可使用系統語音

Microsoft 語音 + Windows TTS 套件

Firefox

⚠ 支援有限

Opera

⚠ 支援有限

瀏覽器限制：
  • 不同瀏覽器對文字轉語音的支援不同（部分 Firefox 版本的語音有限）
  • Chrome 提供由 Google 支援的 TTS 選項
  • Edge 支援 Microsoft TTS 及 Windows 語言套件語音
  • Safari 需要使用者互動才能開始播放音訊
  • 檢查 可用語音 供你的瀏覽器使用

適用於 OBS 的 Windows TTS 音訊擷取方法

頁面音訊：免費本機及雲端供應商

SSN 的瀏覽器內本機供應商及雲端音訊供應商透過頁面播放產生的音訊：

  • 只需在瀏覽器來源中啟用「Control audio via OBS」
  • 不需虛擬音訊線
  • 適用於 SSN 應用程式及 OBS 瀏覽器來源

System TTS 擷取方法

重要： 首先確認 System TTS 能產生語音。OBS 的嵌入式瀏覽器可能不提供可用的系統語音。若未產生語音，修改音訊路由不會有幫助。請選擇其他供應商，或在受支援的瀏覽器中產生語音並擷取其音訊。

專門針對 System TTS：

  • 不要假設 OBS 提供與 Chrome 或 Edge 相同的語音
  • 各瀏覽器支援有限（Firefox 可能缺少部分 TTS 語音）
  • Chrome 提供 Google 選項，Edge 提供 Microsoft 選項
  • 若語音在場景瀏覽器來源之外播放，請單獨擷取該輸出

音訊路由工具下載： VB-Audio Virtual Cable | Voicemeeter | Audio Router（舊版）

在支援的情況下，先嘗試用 OBS 應用程式音訊或桌面音訊擷取正在發聲的瀏覽器。下方虛擬音訊線方法是選用替代方案；不會為 OBS 增加語音支援。

方法 1：使用虛擬音訊線的預設音訊路由

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

方法 2：Windows 10 應用程式路由

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

方法 3：Windows 11 應用程式路由

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

方法 4：Audio Router 軟體

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

方法 5：Voicemeeter（進階）

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

測試你的設定

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
替代方案： 使用 Kokoro、Piper、Kitten 或 eSpeak 等免費內建供應商、雲端供應商或自行託管 TTS 伺服器。

安裝其他語言套件

Windows 11

  1. 前往 開始 > 設定 > 時間與語言 > 語音
  2. 位於 管理語音，點選 加入語音
  3. 選擇所需語言並點選 新增
  4. 重新啟動瀏覽器以更新可用語音

Windows 10

請按照以下資料中的說明操作： Microsoft 官方指南 ，了解語言套件安裝方法。

提示： 部分第三方語音可能因相容性問題未出現在瀏覽器中。Firefox 通常比以 Chromium 為基礎的瀏覽器顯示更多系統語音。

TTS 設定的 URL 參數

基本參數

參數 說明 範例
&speech 使用語言代碼啟用 TTS &speech=en-US
&pitch 語音音高（0.1 至 2.0） &pitch=1.2
&volume 音量（0.0 至 1.0） &volume=0.8
&rate 語速（0.1 至 10.0） &rate=1.5
&voice 部分比對語音名稱 &voice=google
&ttsprovider 選擇供應商：kokoro、piper、kitten、espeak、openai、customtts、localtts、elevenlabs、google、speechify、gemini &ttsprovider=customtts

進階參數

參數 說明
&simpletts 不說「says」或「someone says」
&simpletts2 完全不朗讀聊天使用者名稱
&ttscommand 啟用自訂 TTS 指令（預設：!say）
&readevents 將直播事件納入 TTS
&skipmessages=3 每3則訊息只朗讀1則

TTS 供應商設定

Kokoro TTS（免費、內建）

  • 透過以下內容啟用 ?ttsprovider=kokoro
  • 透過 WebGPU/WASM 在瀏覽器中執行 — 不需伺服器
  • 可直接搭配 OBS 瀏覽器來源使用
  • 語音選擇： &voicekokoro=af_bella
  • 速度控制： &kokorospeed=1.2
  • 選擇該語言的語音： &voicekokoro=ef_dora 用於西班牙語，或 &voicekokoro=pf_dora 用於巴西葡萄牙語。變更 &speech= 本身不會變更所選語音。現有英語語音 ID 仍可使用。

Piper TTS（免費、內建）

  • 透過以下內容啟用 ?ttsprovider=piper
  • 在瀏覽器中執行、快速且適合 CPU 的神經網路 TTS
  • 語音選擇： &pipervoice=en_US-hfc_female-medium
  • 葡萄牙語語音： &pipervoice=pt_BR-faber-medium 或 &pipervoice=pt_BR-edresson-low
  • 西班牙語語音： &pipervoice=es_ES-davefx-medium 或 &pipervoice=es_MX-ald-medium
  • 速度控制： &piperspeed=1.0

Kitten TTS（免費、內建）

  • 透過以下內容啟用 ?ttsprovider=kitten
  • 在瀏覽器中執行的輕量 ONNX TTS
  • 語音選擇： &kittenvoice=expr-voice-4-f

eSpeak-NG（免費、內建）

  • 透過以下內容啟用 ?ttsprovider=espeak
  • 經典開放原始碼 TTS，可在任意硬體上執行
  • 語音選擇： &espeakvoice=en
  • 葡萄牙語範例： &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • 西班牙語範例： &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 速度控制： &espeakspeed=175

葡萄牙語和西班牙語 TTS 範例

  • 葡萄牙語，在 SSN 中測試的最佳免費本機音質： ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • 葡萄牙語，在 SSN 中測試的最快備用方案： ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • 西班牙語，在 SSN 中測試的最佳免費本機音質： ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • 西班牙語，在 SSN 中測試的最快備用方案： ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 對於雲端語音，請使用支援目標語言的供應商語音/語言，例如 Google Cloud、ElevenLabs、Speechify、Gemini 或 OpenAI 相容本機伺服器。

OpenAI / 本機伺服器 TTS

  • 透過以下內容啟用 ?ttsprovider=openai
  • 使用 ?ttsprovider=customtts 或 ?ttsprovider=localtts 用於自行託管端點
  • 預設使用 OpenAI API，也可使用任意相容的本機伺服器
  • 自訂端點： &openaiendpoint=http://localhost:8880/v1/audio/speech
  • 重要： localhost 和 127.0.0.1 指播放 TTS 頁面的同一台電腦。若 OBS 與 TTS 伺服器不在同一台電腦上，請改用伺服器電腦的區域網路 IP。
  • 本機伺服器不需 API 金鑰
  • 若本機伺服器在 Chrome/OBS 中遇到 CORS 或本機網路問題，執行 npm run local-tts-bridge ，在 OBS 電腦上執行，並將 SSN 指向 http://127.0.0.1:8124/v1/audio/speech
  • SSN 傳送 { model, input, voice, response_format, speed } ，並支援二進位音訊、JSON 音訊 URL 及 JSON base64 音訊
  • 目前自訂/本機端點播放採用緩衝方式；SSN 尚不支援逐步播放串流音訊片段
  • 語音： &voiceopenai=af_bella，速度： &openaispeed=1.0。使用伺服器支援的語音名稱；Kokoro 語音類似 af_bella，而 openedai-speech/OpenAI 風格的語音可能類似 nova 或 echo.
  • 請參閱 本機 AI TTS 指南 ，了解自行託管伺服器設定。

Google Cloud TTS

  • 透過以下內容啟用 ?ttsprovider=google&ttskey=YOUR_API_KEY
  • 專業品質語音
  • 語音選擇： &voicegoogle=en-GB-Standard-A
  • 語言： &googlelang=en-US

Gemini TTS

  • 透過以下內容啟用 ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • 模型： &geminimodel=gemini-2.5-flash-preview-tts
  • 語音： &voicegemini=Kore，語言： &geminilang=th-TH
  • 風格指示： &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • 透過以下內容啟用 ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • 語音 ID： &voice11=YOUR_VOICE_ID
  • 模型： &elevenlabsmodel=eleven_multilingual_v2
  • 參數：可調整穩定性、相似度及風格

Fish Audio TTS

選擇 Fish Audio 並輸入 API 金鑰，可選填語音 ID。預設模型為 s2.1-pro-free. 設定、模型選項及瀏覽器存取限制.

Speechify TTS

  • 透過以下內容啟用 ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • 語音： &voicespeechify=henry
  • 模型： &speechifymodel=simba-3.0 （預設），或 &speechifymodel=simba-3.2 用於英語。
  • 朗讀速度： &speechifyspeed=1.2 （範圍 0.5 至 3.0；正常為 1.0）。
  • Speechify 設定、語音、速度及音量指南

疑難排解

常見問題

  • 沒有音訊播放： 檢查 TTS 是否啟用、產生 TTS 的頁面是否開啟，以及瀏覽器來源是否未靜音。在一般瀏覽器中，先點選頁面一次。
  • 語音未顯示： 安裝語言套件後重新啟動瀏覽器
  • OBS 未擷取： 若沒有語音，先檢查語音/供應商可用性。若已有語音，檢查 透過 OBS 控制音訊、混音器靜音及輸出軌道，或擷取正在發聲的外部瀏覽器
  • 本機端點在應用程式測試中可用，但在 OBS 中無效： OBS 是獨立瀏覽器。請在 OBS 電腦上檢查端點，尤其是使用 127.0.0.1.
  • 只朗讀第一個字母或開頭幾個詞： 移除 ttsquick ，若 OBS URL 中存在則移除。
  • Safari 問題： Safari 對自動 TTS 的支援有限
  • 付費服務無效： 檢查 API 金鑰並確認供應商指定正確

最佳做法

  • 使用產生頁面音訊的供應商可簡化 OBS 設定；有免費本機供應商可選
  • 直播前用簡單短句測試設定
  • 使用 TTS 時考量使用者產生內容的風險
  • 準備一個開關，以便需要時快速停用 TTS
