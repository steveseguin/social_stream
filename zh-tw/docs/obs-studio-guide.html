指南 /OBS工作室

您的第一個 OBS 設定。

將相機、螢幕和聲音結合在一起。進行測試錄製，然後上線。

01

讓 OBS 進行第一次設定

  1. 安裝 OBS Studio 並打開它。
  2. 選擇 工具 → 自動設定精靈.
  3. 选择流式传输或录制，按照提示操作，然后应用设置。

當您的電腦要求時允許存取攝影機、麥克風和螢幕擷取。

选择后，屏幕截图会以全尺寸打开。标签可能因 OBS 版本而略有不同。

06

讓你的聲音更容易被聽到

  1. 選擇您的麥克風 設定 → 音頻.
  2. 正常說話。瞄準周圍的山峰 −12 至 −6 dBFS；避免達到 0。
  3. 降低遊戲、音樂和警報滑桿，直到語音清晰為止。

每個聲音捕捉一次。 對整個輸出設備使用桌面音頻，或單獨的應用程式擷取。捕獲兩者可以使聲音加倍。

應用程式音訊、macOS 和麥克風過濾器

Windows：使用 應用程式音訊捕獲.在 macOS 13+ 上，使用 OBS 的 macOS 音訊/螢幕截圖.

麥克風 → 濾鏡：嘗試輕噪音抑制，然後是壓縮器和限制器。一次加入一個並聆聽。

08

新增聊天或提醒疊加

  1. 從 Social Stream Ninja 複製覆蓋 URL。
  2. 選擇 來源 → + → 瀏覽器 並且貼上它。保留其會話和密碼選項。
  3. 設定疊加大小；使用 1920 × 1080 用於全片幅風景疊加。
  4. 對於 TTS 或警報，啟用 透過 OBS 控制音訊.

將其放在遊戲或相機上方。發送測試訊息；如果使用特色訊息覆蓋，請在 SSN 底座中選擇一個。

空白疊加或重複音訊？

檢查會話是否與您的聊天來源相符。刷新瀏覽器來源。僅保留一份播放 TTS 的副本。

對於持續聊天，請先關閉自動關閉和場景啟動刷新。 SSN 叠加设置 · TTS 設定.

09

記錄一分鐘。然後就去直播吧。

  1. 選擇錄音資料夾 設定 → 輸出.
  2. 新聞 開始錄製（Start Recording）。說話、播放聲音和切換場景。
  3. 停下來觀看文件。檢查音量、取景和口型同步。
  4. 設定平台的標題和可見性，然後 開始直播（Start Streaming）。檢查其預覽和串流健康狀況；有些平台還需要 上線.

開始直播可以讓您公開直播。 如果可以的話，請使用私人測試。完成後，停止直播並確認平台活動已結束。

录音格式和独立音轨

MKV 可以容忍中斷的錄音。使用 文件 → Remux 录音 隨後為 MP4。目前的 OBS 還提供彈性混合 MP4/MOV。

對於單獨的編輯軌道，請在軌道 1 上保留完整的混音，然後將麥克風/遊戲分配給高級音訊屬性中的其他軌道，並在「錄製」下啟用它們。
