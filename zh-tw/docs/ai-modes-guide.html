「ChatGPT」的兩種不同含義

選項是什麼對話
ChatGPT API 服務SSN 使用你的 API 金鑰和所選模型向 OpenAI 傳送提示詞。SSN/API 對話，與 chatgpt.com 獨立。
ChatGPT 瀏覽器來源擴充功能會讀取已開啟的下列頁面中呈現的新使用者和 ChatGPT 對話： chatgpt.com 分頁。你開啟的瀏覽器對話，不使用 API 金鑰。

重要： 連接 OpenAI API 不會將 SSN 接入既有的 ChatGPT 網頁或語音對話。OpenAI API 管理自己的對話狀態。

選項 1：ChatGPT 瀏覽器夥伴（實驗性）

如果你已在 Chrome 中使用 ChatGPT，又不想使用 API 金鑰，這最符合你的需求。SSN 可將頁面上的新文字對話擷取為下列來源類型： openai，就像擷取聊天來源一樣。

擷取 ChatGPT 對話

  1. 安裝並啟用 Social Stream Ninja Chrome 擴充功能。
  2. 在彈出選單中，主動啟用 ChatGPT 來源。
  3. 開啟 https://chatgpt.com/ ，啟用來源後重新載入頁面。
  4. 使用同一工作階段開啟 SSN 停駐面板。
  5. 傳送一則新的 ChatGPT 訊息。新的使用者和 ChatGPT 對話應出現在停駐面板中；既有歷史會被刻意忽略。

將即時聊天傳送到已開啟的 ChatGPT 分頁

  1. 使用私人或不公開列出的直播，以及一般 ChatGPT 文字對話進行測試。
  2. 位於 管理，啟用 轉送所有訊息.
  3. 設定 選擇轉送目標 為 openai ，讓擷取的觀眾訊息只傳送到 ChatGPT 分頁。
  4. 保持 ChatGPT 分頁開啟。新回覆會以下列形式返回 SSN： openai 訊息。
  5. 使用 ChatGPT 音訊或 SSN 的 TTS／疊加畫面輸出，將這些回覆用於直播。

實驗性： 網頁控制項可能改變，轉送所有訊息可能淹沒對話，而 ChatGPT 語音模式可能不像一般文字頁面那樣接受注入文字。傳送每則觀眾訊息之前，請先使用篩選器或測試直播。

選項 2：在 SSN 中設定 AI 服務

需要 SSN 產生回覆、審核訊息、翻譯聊天、搜尋知識庫或建構疊加畫面時，應設定 AI 服務。

服務類型選項說明
本機Ollama; Local Gemma; Local Qwen無需雲端 API 金鑰。效能取決於電腦和模型資源。
自訂／本機伺服器自訂 OpenAI 相容 API適用於 llama.cpp、LM Studio、vLLM 和相容閘道。Ollama 應使用其原生選項。
雲端OpenAI, Gemini, DeepSeek, xAI, AWS Bedrock, OpenRouter, Groq, OpenCode Zen金鑰、存取權限、計費、配額和模型名稱均由各服務提供者管理。

  1. 開啟 聊天機器人和 AI 服務 ，位於 SSN 彈出選單中。
  2. 開啟 設定 LLM 服務提供者 ，並選擇你實際使用的服務。
  3. 輸入端點、模型、API 金鑰或本機資源設定。
  4. 選擇 測試所選聊天機器人。顯示已連線，只能證明服務回應了測試。
  5. 啟用需要使用該服務的獨立功能：主機器人、私人機器人、共同主持、審核、翻譯、RAG 或建構器。

選項 3：語音 AI 共同主持

共同主持專為「一邊與 AI 對話，一邊讓它查看即時聊天」的流程設計。麥克風和所選即時聊天訊息進入同一個共同主持工作階段，回答可在直播中朗讀。

  1. 開啟 cohost.html?session=YOUR_SESSION.
  2. 選擇語音／即時服務，或 SSN 彈出選單中設定的 LLM。
  3. 明確選擇麥克風和 音訊回覆，然後按 啟動共同主持.
  4. 使用 OpenAI Realtime 時，將 Live Chat 保持為 僅上下文 — 提問時才回答 ，適合希望 AI 記住近期觀眾訊息卻不打斷對話的情況。選擇 問題和提及 或 每則訊息 以自動朗讀回覆；這些模式不會向平台聊天發文。
  5. 使用 OpenAI Realtime 時，在 OBS 中擷取共同主持瀏覽器或應用程式的音訊，並使用 cohost-overlay.html?session=YOUR_SESSION 顯示舞台頭像和對話泡泡。疊加畫面不會接收同一條 WebRTC 語音串流。如果支援，可在共同主持輸出裝置選擇器中選擇虛擬音訊線； &forcetts 會刻意新增獨立的疊加畫面語音。
  6. 選用的直播工具預設關閉。在 SSN 彈出選單中啟用 Spotify、OBS 場景名稱允許清單或精選聊天控制，然後在下列位置為控制器啟用相同工具： 共同主持直播控制 ，位於共同主持頁面。
  7. 若要降低 OpenAI 延遲，可選擇 Mini 模型、Low 推理強度和 Fast 輪流發言速度。Full quality 和較高推理強度可改善複雜回答，但會增加延遲與 API 費用；Fast 可能打斷自然停頓。診斷面板顯示測得的首次輸出延遲。
  8. OpenAI 攝影機與螢幕分享輸入為選用項目，預設值為 無視訊。選取後，SSN 會在每次直接語音或文字要求時傳送一張目前圖像；這不是連續視訊串流，可能增加 API 費用和延遲。
  9. 保持對話泡泡可見，或提供字幕，讓觀眾即使聽不到 AI 語音也能跟上對話。

OpenAI Realtime 使用在下列位置設定的 OpenAI 專案金鑰： ChatGPT API ，位於 SSN 彈出選單中。標準金鑰保留在 SSN 擴充功能或桌面應用程式的背景服務，背景服務為共同主持頁面建立短期 Realtime 用戶端密鑰。隨後麥克風和 AI 語音音訊透過 WebRTC 傳輸。回覆最多輸出 512 個 token，診斷面板顯示累計用量和延遲。SSN 會檢查靜默工作階段並重新連接失敗的傳輸；恢復後的工作階段會重新套用指令和效能設定，但無法還原先前的語音對話。這會建立一個 SSN 共同主持工作階段，不會接管 ChatGPT 網站或桌面應用程式中既有的對話。

開啟詳細 AI 共同主持指南

選項 4：主直播聊天機器人

主機器人評估擷取到的觀眾訊息，可在疊加畫面中回答、透過 TTS 朗讀，或傳回受支援平台的聊天。

  1. 設定並測試 AI 服務。
  2. 啟用 主 AI 聊天機器人.
  3. 選擇觸發詞、僅限管理員行為、頻率限制、歷史記錄和提示指令。
  4. 首次安全測試時，啟用 機器人回覆僅傳送到機器人疊加畫面頁面.
  5. 開啟 bot.html?session=YOUR_SESSION ，如需朗讀回覆，請啟用 TTS。
  6. 確認目標平台支援發文後，才關閉僅疊加畫面模式。

平台回覆通常使用已登入的帳號。如果需要獨立身分，可在受支援的平台使用專用 YouTube、Twitch 或 Kick 機器人帳號。

開啟 AI 聊天機器人設定指南

選項 5：私人一對一機器人

chatbot.html 是私人助手和提示詞測試頁面。啟用 聊天機器人 — 私人介面，使用你的工作階段開啟頁面，並使用已設定的 LLM 服務。

私人機器人獨立於主直播聊天機器人，目前不共享它的 RAG 資料集或其他聊天歷史。

選項 6：AI 處理工具

工具功能說明安全起步
內容過濾機器人對收到的訊息分類、清理或攔截。先使用非攔截模式並檢查結果。
翻譯翻譯收到的聊天，以及選用的直播主傳送訊息。先測試一種語言，在確認可靠之前不要使用攔截模式。
RAG 知識庫讓主機器人從上傳的資源檔案中檢索相關文字。使用最新、主題集中的文字或 Markdown 檔案。
聊天摘要允許使用者透過下列方式觸發 AI 摘要： !summary.檢查歷史記錄量、費用和私人內容。

選項 7：AI 疊加畫面建構器

使用 aiprompt.html 來描述、產生、預覽和儲存疊加畫面。使用 aioverlay.html 作為儲存後用於 OBS 輸出的頁面。

開啟 AI 疊加畫面建構器指南

常見解決方式

  • 已連線，但沒有即時回覆： 啟用主機器人或所需 AI 功能；只設定服務不會處理聊天。
  • 共同主持看到聊天卻不說話： 僅上下文模式會刻意等待直播主詢問聊天內容。切換到問題和提及或每則訊息，即可自動回覆。
  • ChatGPT 瀏覽器來源沒有動靜： 啟用 ChatGPT 選項，重新載入 chatgpt.com，用新一輪對話測試，不要使用既有歷史。
  • 機器人略過大多數訊息： 檢查觸發詞、僅限管理員模式、頻率限制，以及要求模型選擇性回覆的指令。
  • 出現文字但沒有聲音： 確認產生 TTS 的頁面已開啟，且 OBS 正在擷取該頁面的音訊。
  • 機器人無法發文： 檢查平台傳回支援、登入狀態、帳號權限和頻率限制。
