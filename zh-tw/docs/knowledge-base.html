知識庫

常見問題的簡短解答。需要完整操作步驟時，請查看指南。

OBS 疊加畫面為空白

先檢查停駐面板。如果停駐面板為空，請修正來源／平台。如果停駐面板正常，請在普通瀏覽器中開啟完全相同的疊加畫面 URL，確認使用相同的 session，然後重新整理 OBS 瀏覽器來源。

開啟 OBS 疑難排解

工作階段錯誤

來源、停駐面板、疊加畫面、機器人和 Event Flow 頁面必須使用相同工作階段 ID。可將工作階段 ID 當作房間名稱：拼字不同，就屬於不同房間。

dock.html?session=YOUR_SESSION

開啟工作階段、密碼與轉送模式

更新時保留設定

先匯出設定，一般更新時不要解除安裝擴充功能；如果還需移轉 Cookie 和登入狀態，請使用桌面應用程式的加密完整工作階段傳輸。

開啟安全更新、備份與復原

OBS 聽不到 TTS

普通系統 TTS 往往透過電腦發聲，而不經過 OBS 瀏覽器來源。可使用供應商／瀏覽器 TTS 模式，例如 Kokoro、Piper、Kitten、eSpeak、相容於 OpenAI 的服務或雲端供應商，也可單獨路由系統音訊。

開啟 TTS 設定指南

Kokoro 無法說葡萄牙語或西班牙語

內建 Kokoro 聲音是英語聲音。葡萄牙語請使用 Piper 並設定 pipervoice=pt_BR-faber-medium，或使用 eSpeak 並設定 espeakvoice=pt-br。西班牙語請使用 Piper 並設定 pipervoice=es_ES-davefx-medium，或使用 eSpeak 並設定 espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

開啟 TTS 供應商設定

Chrome 正常，但桌面應用程式不正常

桌面應用程式使用 Electron 工作階段，不使用一般 Chrome 設定檔。請在應用程式的來源視窗內登入；當平台阻止內嵌／應用程式瀏覽器環境時，改用 Chrome 擴充功能方式。

開啟獨立應用程式模式

我需要哪種本機伺服器？

啟用本機伺服器 是供支援的 SSN 頁面使用的 WebSocket 轉送服務。 本機控制 API 供同機指令碼和 AI 工具使用。無頭託管是在 Linux 伺服器上執行完整桌面應用程式。Event Flow 媒體伺服器僅提供獲准的本機媒體。

開啟本機伺服器和服務說明

TikTok 失敗或切換模式

記錄應用程式模式、簽章供應商、狀態文字、應用程式版本，以及標準模式下聊天是否可見。每次只測試一種 TikTok 模式。

開啟 TikTok 應用程式模式

沒有 YouTube 聊天

確認正在直播、即時聊天可見，並使用正確的 YouTube 路徑：即時聊天、靜態留言、標準擷取或 WebSocket／API 模式。

開啟 YouTube 設定指南

機器人回覆無法傳送

讀取聊天與發佈聊天並不相同。請檢查平台回傳支援、帳號登入、帳號角色、來源模式、供應商回應和頻率限制。

開啟 AI 聊天機器人設定指南

Event Flow 沒有反應

確認來源事件已到達停駐面板。對於音訊、媒體和 OBS 動作，請保持 actions.html?session=YOUR_SESSION 使用相同工作階段保持開啟。
