如何安裝自訂字型

  • Windows： 以滑鼠右鍵點擊 .ttf 或 .otf 檔案 → 選擇「安裝」或「為所有使用者安裝」 → 重新啟動瀏覽器。
  • macOS： 按兩下 .ttf 或 .otf 檔案 → 在「字體簿」中點擊「安裝字型」 → 重新啟動瀏覽器。
  • Linux： 將字型檔案複製至 ~/.local/share/fonts/ → 執行 fc-cache -fv → 重新啟動瀏覽器。

安裝後重新整理本頁，即可查看新字型。如果字型未出現，請嘗試「Try Local Fonts API」按鈕（僅限 Chromium 瀏覽器）。

透過 URL 使用指定字型

  • 參數： 附加 ?font=<Font%20Family%20Name> 加入 URL。空格和符號必須進行 URL 編碼。
  • 套用至 CSS 變數： 您的網站使用 --font-family；本頁也遵循該設定。例如： ?font=Segoe%20UI.
  • 無需引號： 參數中不要包含引號；CSS 變數不需要引號。
  • 僅已安裝： 該參數僅適用於系統上已安裝的字型，不會下載網頁字型。

相容性（Ninja 應用程式）

  • VDO.Ninja: 已產生 ?font= 連結適用於遵循以下變數的疊加畫面/場景： --font-family 變數。
  • SocialStream.Ninja: 使用相同的 ?font= 參數，以覆寫支援的元件中的預設字型。
  • Caption.Ninja: 套用 ?font= 用於支援自訂字型家族的字幕疊加畫面。

當以下參數受支援時，這些應用程式接受 font-family 覆寫： ?font= 參數在其 URL 或內嵌連結中受支援。本工具產生正確編碼的值，供直接使用。

疑難排解（Windows）

  • 精確的字型家族名稱： 使用字型的 字型家族 名稱（不是檔案名稱）。請在「設定 → 個人化 → 字型」中查看正確的字型家族標籤。
  • 正確的安裝範圍： 如果為另一個 Windows 使用者安裝字型，或只透過系統管理員帳號安裝，目前瀏覽器工作階段可能看不到它。如有需要，請選擇「為所有使用者安裝」。
  • 支援的格式： 瀏覽器使用 TrueType/OpenType/WOFF。舊版 Type 1 和某些點陣字型無法使用。
  • 字重/樣式可用性： 如果只安裝了 Bold，Normal 文字可能改用其他字型。嘗試粗體範例，或同時安裝 Regular。
  • 隱私限制： 未經許可，瀏覽器不允許完整列舉字型。本頁透過大型已知字型清單及可選的 Local Fonts API 進行偵測。
  • Local Fonts API： 在 Chromium 的安全來源（https/localhost）上，點擊「Try Local Fonts API」，授權後可以列出已安裝字型家族的確切名稱。

手動使用提示

  • 強制使用字型： 在 CSS 中： font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • 測試任意名稱： 使用搜尋框嘗試任意字型家族；找到後會顯示在結果中，並附帶範例。
  • 編碼： 建立如下連結： ?font=Segoe%20UI （下方產生的連結使用正確編碼）。
  • 中日韓和其他文字字型： 範例包含拉丁字母、數字和符號。替換為特定文字系統的文字以驗證字形塑形。

注意：本頁不會安裝或下載字型，只偵測並預覽瀏覽器已經可用的字型家族。
