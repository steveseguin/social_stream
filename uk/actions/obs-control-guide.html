Керування OBS через Social Stream Ninja

Керуйте OBS безпосередньо з Event Flow — Streamer.bot не потрібен. Цей посібник описує налаштування, усі тригери й дії OBS, практичні приклади та старіші елементи керування доком/джерелом браузера.

1. Підключіть Flow Actions до OBS

OBS WebSocket v5 вбудований в OBS 28 і новіші версії. Social Stream Ninja використовує його для повного керування OBS та подій медіа.

  1. В OBS відкрийте Інструменти → Налаштування сервера WebSocket.
  2. Увімкніть сервер WebSocket. Залиште стандартний порт 4455; за бажанням установіть пароль.
  3. У Social Stream Ninja відкрийте Flow Actions розділ і задайте URL OBS WebSocket та необов’язковий пароль.
  4. Скопіюйте URL Flow Actions і залиште його відкритим. Для дій оверлею/звуку рекомендовано джерело браузера OBS.
  5. Використовуйте Тестер OBS WebSocket щоб підтвердити підключення перед створенням сценарію.
Приклад прямого URL
https://socialstream.ninja/actions.html?session=YOUR_SESSION&obsws=ws://127.0.0.1:4455

Додайте &obspw=YOUR_PASSWORD лише коли OBS вимагає автентифікації. Додайте &obsdebug=1 щоб під час діагностики показувати невеликий значок стану підключення.
Залишайте сторінку Flow Actions запущеною. Це міст, який отримує дії Event Flow і надсилає запити OBS WebSocket. Якщо це джерело браузера OBS, вимкніть Вимикати джерело, коли воно не видиме (Shutdown source when not visible) коли джерело має продовжувати керувати OBS, залишаючись прихованим.
Подія чату / трансляції │ ▼ Social Stream Ninja Event Flow │ той самий ID сесії ▼ Сторінка Flow Actions (actions.html) │ OBS WebSocket v5 · ws://127.0.0.1:4455 ▼ OBS Studio

2. Додайте вузли OBS до сценарію

  1. Відкрийте Редактор потоків подій і створіть або відредагуйте сценарій.
  2. Перетягніть тригер на полотно.
  3. Розгорніть OBS Studio у списку дій і перетягніть потрібну дію OBS.
  4. З’єднайте тригер із дією, задайте точні назви сцен/джерел OBS, збережіть і ввімкніть сценарій.
Назви в OBS мають збігатися точно, включно з пробілами й розділовими знаками. Дії джерел спрямовані на назву входу OBS, а не на позначку елемента сцени, якщо її перейменували окремо.

Set Text Source та змінні сценарію

Текстове поле підтримує звичайні підстановки повідомлень, як-от {username}, {message}, {source}, і {donation}, а також значення, додані попередніми вузлами сценарію, як-от {counterValue}, {counterTarget}, і {counterRemaining}.

{username}: now {counterValue}, need {counterTarget}
Для джерела Text (GDI+) або Text (FreeType 2) вимкніть Читати з файлу (Read from file). Інакше OBS може продовжувати показувати вміст файлу замість тексту, надісланого Event Flow.

Керування медіаджерелом

Відтворити / призупинити

Відтворити (Play) продовжує призупинене медіа. Призупинити (Pause) зберігає поточну позицію.

Перезапустити / зупинити

Перезапустити (Restart) починає спочатку. Зупинити (Stop) завершує відтворення та скидає джерело.

Наступний / попередній

Переходить між елементами джерел із підтримкою списку відтворення, як-от VLC Video Source. Медіаджерело з одним файлом може ігнорувати ці дії.

Гучність, вимкнення звуку та фільтри

Установити гучність джерела (Set Source Volume) використовує дБ відповідно до шкали мікшера OBS: 0 dB означає незмінне підсилення, від’ємні значення тихіші, а -100 dB фактично дає тишу. Вимкнення звуку — окремий стан. Toggle Filter змінює лише стан увімкнення наявного фільтра, а не його налаштування.

Буфер повтору (Replay Buffer)

Спочатку ввімкніть Replay Buffer у Налаштування OBS → Вивід. Використовуйте Керувати буфером повтору (Control Replay Buffer) для запуску/зупинки, а потім Зберегти буфер повтору (Save Replay Buffer) для запису останнього буферизованого фрагмента на диск.

Попередження щодо виходу в ефір: Start/Stop Streaming і Start/Stop Recording виконуються негайно. Використовуйте обмежувальні тригери, дозволи та паузи, щоб звичайні повідомлення чату випадково їх не запускали.

5. Корисні приклади

Щогодинне повідомлення під час трансляції OBS

У редакторі Event Flow виберіть Почати з шаблону → Середній рівень → Щогодинне повідомлення під час трансляції OBS. Спочатку він вимкнений і містить три гілки в одному сценарії:

  • Початок трансляції OBS → Установити стан перемикача: ON
  • Часовий інтервал (3600 секунд) → Перемикач ON/OFF → Надіслати повідомлення
  • Зупинка трансляції OBS → Установити стан перемикача: OFF

Обидві дії Set Gate State уже спрямовані на той самий перемикач, початковий стан якого — OFF. Відредагуйте Надіслати повідомлення (Send Message) щоб вибрати платформу чату (у прикладі Twitch) і повідомлення. Виберіть платформу або All Platforms; Reply to Source не може відповісти на подію OBS або спрацювання таймера.

Підключення Flow Actions до OBS, залиште Social Stream і цільовий чат підключеними, а потім збережіть та ввімкніть сценарій перед початком трансляції. Перемикач очікує події початку від OBS; завантаження під час уже активної трансляції не переводить його в ON. Перезапуск Social Stream також скидає перемикач в OFF.

Час спрацьовування: інтервал працює за власним розкладом, тому перше нагадування може надійти раніше ніж через годину після початку трансляції. Далі нагадування повторюються щогодини, доки перемикач у стані ON. Для іншої частоти змініть Time Interval; значення вимірюється в секундах.

Текст лічильника в OBS

Розмістіть Установити текст джерела (Set Text Source) після шляху лічильника/перевірки та використовуйте:

{username}: now {counterValue}, need {counterTarget}

Запустити щось після відео

Завершення медіа OBS (OBS Media Ended) (відфільтруйте до Intro Video) → Змінити сцену (Change Scene) до Main.

Перезапуск медіа з чату

Повідомлення дорівнює (Message Equals) !replayintro → умова дозволу → Керувати медіаджерелом: перезапустити.

Оновити сторінку сповіщень

Повідомлення дорівнює (Message Equals) !refreshalerts → умова модератора → Оновити джерело браузера (Refresh Browser Source).

Приглушити музику для сповіщення

Установити гучність джерела (Set Source Volume) до -24 dB → дія сповіщення → Затримка → повернути до 0 dB.

Сценарій повторів

Початок трансляції OBS (OBS Stream Started) → Керувати буфером повтору: запустити; окрема довірена команда запускає Зберегти буфер повтору (Save Replay Buffer).

7. Усунення неполадок

ПроблемаПеревірте
Нічого не відбуваєтьсяСценарій збережено й увімкнено; Flow Actions відкрито; обидва використовують той самий ID сесії.
OBS не підключаєтьсяСервер WebSocket увімкнений, URL — ws://127.0.0.1:4455, а пароль збігається. Порт 4444 — застарілий стандартний порт v4.
Сцену/джерело/фільтр не знайденоСкопіюйте точну назву з OBS. Для видимості вкажіть Scene або Group, якщо елемент вкладений або розміщений не в поточній сцені.
Текст не змінюєтьсяВикористовуйте Text (GDI+) або Text (FreeType 2), перевірте назву джерела та вимкніть Читати з файлу (Read from file).
