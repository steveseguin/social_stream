Режими окремого застосунку

Для чого потрібен застосунок

Настільний застосунок керує вікнами джерел Social Stream поза звичайним браузером. Він може допомогти впорядкувати джерела й розв’язати деякі проблеми обмеження фонових вкладок браузера. Це не Chrome, і він автоматично не використовує ваш вхід або cookie Chrome.

Назви режимів

Деякі джерела мають кілька режимів підключення. Правильний режим залежить від платформи, стану входу та потреби в докладніших подіях або простому захопленні сторінки.

РежимПросте поясненняВикористовуйте, коли
StandardЗастосунок відкриває звичайну сторінку платформи/джерела та читає відображену сторінку.Вам потрібні найпростіше захоплення видимої сторінки, вхід або ручна перевірка.
WebSocket/APIДжерело підключається через API платформи, сокет або сторінку джерела Social Stream.Платформа підтримує його, а ви хочете кращої надійності у фоні чи докладніших даних подій.
Опитування/застарілийШлях сумісності, який перевіряє оновлення замість бажаного сокетного шляху наживо.Новіший з’єднувач не працює або потрібен резервний варіант для платформи.
TikTok AutoЗастосунок вибирає найкращий шлях TikTok і може перейти на резервний, якщо один не працює.Ви не впевнені, який режим TikTok використовувати.

Використовуйте режим Standard, коли

  • Платформа працює, коли видно сторінку ефіру або окремий чат.
  • Сайту потрібно, щоб ви ввійшли, виконали запит або тримали відкритою видиму панель чату.
  • Ви порівнюєте поведінку застосунку з розширенням Chrome.
  • Вам потрібен найзрозуміліший шлях перевірки: відкрити сторінку, побачити чат, перевірити док, а потім OBS.

Режим Standard усе одно може не працювати, якщо платформа змінює структуру сторінки, блокує вбудовані браузери/браузери застосунків, вимагає CAPTCHA або приховує чат за входом.

Використовуйте режим WebSocket або API, коли

  • Джерело явно підтримує режим WebSocket/API.
  • Вам потрібне джерело, яке краще працює у фоні.
  • Вам потрібні родини подій, яких звичайне зчитування сторінки може не надавати.
  • Ви можете налаштувати токени постачальника, дозволи облікового запису, області доступу API або сторінку джерела.

Режим WebSocket/API не завжди кращий. Якщо автентифікація, токени, доступ постачальника чи API платформи не працюють, Standard може бути швидшою перевіркою.

TikTok у застосунку

TikTok у настільному застосунку має не один режим. Завжди записуйте активний набір налаштувань перед усуненням несправностей.

Шлях TikTokВипадок використанняПоширена причина збою
АвтоматичноПерша спроба для більшості користувачів.Застосунок може перейти на резервний режим, тому перевіряйте текст стану.
StandardЗахоплення видимої сторінки TikTok.Вхід, CAPTCHA, перенаправлена сторінка або прихований чат.
Локальний підписувач (Local Signer)Вбудовані в застосунок шляхи читання й підтримки відповідей.Сесія/cookie TikTok у застосунку мають бути чинними.
Опитування/сумісністьРезервний варіант, коли сокетні шляхи або підпис не працюють.Менш функціональний, ніж бажаний з’єднувач.
Проксі або власний підписРозширені конфігурації.Доступність постачальника, API-ключ, ID кімнати або обмеження частоти.

Для звичайної першої спроби додайте TikTok, залиште набір налаштувань Auto, активуйте джерело та стежте за текстом стану застосунку.

Що перевірити перед OBS

  1. Переконайтеся, що джерело застосунку активоване.
  2. Переконайтеся, що у вікні джерела виконано вхід, якщо платформа його потребує.
  3. Переконайтеся, що док отримує чат із тим самим ID сесії.
  4. Лише після того, як док запрацює, додайте або оновіть URL оверлею OBS.
  5. Якщо Chrome працює, а застосунок — ні, пам’ятайте, що сесії застосунку й Chrome окремі.

Поширені рішення

  • У Chrome вхід виконано, а в застосунку — ні: увійдіть на платформу у вікні джерела застосунку або використовуйте розширення для захоплення.
  • Джерело показує активність, але чат не надходить: перевірте режим, вікно джерела, URL ефіру/ім’я користувача та сесію дока.
  • Застосунок використовує неправильні файли джерел: перевірте, чи застосунок використовує вбудовані, кешовані, віддалені, бета-, стабільні або локальні ресурси Social Stream.
  • TikTok не працює: запишіть поточний набір налаштувань, текст стану, версію застосунку та чи перейшло джерело на резервний режим.
  • OBS порожній: спочатку перевірте док. Якщо він порожній, проблема ще не в OBS.

Пов’язаний посібник: Вибір налаштування платформи.
