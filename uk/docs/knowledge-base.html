Порожній оверлей OBS

Спочатку перевірте док. Якщо док порожній, виправте джерело/платформу. Якщо док працює, відкрийте точну URL-адресу оверлею у звичайному браузері й перевірте однаковий session, а потім оновіть браузерне джерело OBS.

Відкрити усунення несправностей OBS

Неправильна сесія

Сторінки джерела, дока, оверлею, бота й Event Flow повинні використовувати однаковий ID сесії. Сприймайте ID сесій як назви кімнат: різне написання означає різні кімнати.

dock.html?session=YOUR_SESSION

Відкрити сесії, паролі та режими пересилання

Оновлення без втрати налаштувань

Спочатку експортуйте налаштування, не видаляйте розширення під час звичайного оновлення та використовуйте зашифроване перенесення повної сесії настільного застосунку, якщо потрібно також перенести cookie й входи.

Відкрити безпечні оновлення, резервні копії та відновлення

OBS не чує TTS

Звичайний системний TTS часто відтворює звук через комп’ютер, але не через браузерне джерело OBS. Використовуйте режим TTS постачальника/браузера, наприклад Kokoro, Piper, Kitten, eSpeak, сумісний з OpenAI або хмарний сервіс, чи окремо спрямуйте системний звук.

Відкрити посібник із налаштування TTS

Kokoro не говорить португальською чи іспанською

Вбудовані голоси Kokoro — англійські. Для португальської використовуйте Piper із pipervoice=pt_BR-faber-medium, або eSpeak із espeakvoice=pt-br. Для іспанської використовуйте Piper із pipervoice=es_ES-davefx-medium, або eSpeak із espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Відкрити налаштування постачальників TTS

Chrome працює, а настільний застосунок — ні

Настільний застосунок використовує сесії Electron, а не ваш звичайний профіль Chrome. Увійдіть у вікні джерела застосунку або використовуйте розширення Chrome, коли платформа блокує вбудовані браузери чи браузери застосунків.

Відкрити режими окремого застосунку

Який локальний сервер мені потрібен?

Enable Local Server — це ретранслятор WebSocket для підтримуваних сторінок SSN. Локальний API керування призначений для скриптів та інструментів ШІ на тому самому комп’ютері. Хостинг без графічного інтерфейсу запускає повний настільний застосунок на сервері Linux. Медіасервер Event Flow надає лише схвалені локальні медіафайли.

Відкрити пояснення локальних серверів і сервісів

TikTok не працює або змінює режими

Запишіть режим застосунку, постачальника підпису, текст стану, версію застосунку та чи видно чат у режимі Standard. Перевіряйте по одному режиму TikTok.

Відкрити режими TikTok у застосунку

Чат YouTube відсутній

Переконайтеся, що ефір триває, чат наживо видимий і ви використовуєте правильний шлях YouTube: чат наживо, статичні коментарі, захоплення Standard або режим WebSocket/API.

Відкрити посібник із налаштування YouTube

Відповіді бота не надсилаються

Читання чату не означає можливість надсилати в нього повідомлення. Перевірте підтримку зворотного надсилання платформою, вхід в обліковий запис, його роль, режим джерела, відповідь постачальника та обмеження частоти.

Відкрити посібник із налаштування чат-бота ШІ

Event Flow нічого не робить

Переконайтеся, що подія джерела надходить у док. Для дій зі звуком, медіа й OBS тримайте actions.html?session=YOUR_SESSION відкритим із тією самою сесією.
