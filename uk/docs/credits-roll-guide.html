Посібник із фінальних титрів

Зберіть людей, які брали участь у трансляції, а потім подякуйте їм у фінальних титрах.

Рекомендоване налаштування для фінальної сцени

Використовуйте Фонове збирання коли джерело браузера титрів існує лише у фінальній сцені або може вивантажуватися, коли приховане. Застосунок або розширення збирає активність під час трансляції, тому сторінка титрів не мусить залишатися відкритою.

  1. Залишайте Social Stream Ninja активним і звичайні джерела чату в режимі захоплення протягом усієї трансляції.
  2. Відкрити Фінальні титри → Увімкніть і налаштуйте.
  3. Виберіть стиль відображення та задайте Режим запуску до Фонове збирання перед початком трансляції.
  4. Скопіюйте оновлене посилання титрів і додайте його як джерело браузера OBS у фінальній сцені.
  5. Використовуйте Перевірити титри коли джерело браузера завантажене, щоб перевірити підключення й вигляд.
  6. Наприкінці трансляції перемкніться на фінальну сцену, щоб OBS завантажив або показав джерело титрів.
  7. Виберіть Запустити титри, або запустіть creditsStart зі Stream Deck або API.
Порядок важливий: якщо OBS вимикає приховане джерело браузера, покажіть фінальну сцену перед вибором Запустити титри. Збирання продовжує працювати в режимі Background, але джерело має бути підключене для отримання команди запуску.

Що роблять чотири засоби керування

КеруванняРезультат
Запустити титриЗапускає справжній зібраний список. У режимі Auto/Manual показані записи видаляються після завершення титрів, якщо не ввімкнено збереження або повторення. Нова активність, отримана під час титрів, залишається для наступного запуску. Фонові дані зберігаються до скидання.
Попередній переглядЗапускає поточний справжній список без видалення записів. Використовуйте для перевірки макета перед ефіром.
Перевірити титриНадсилає вбудовані приклади учасників трансляції, учасників каналу й донаторів. Не додає, не замінює та не очищує справжній збережений список.
Скинути збережені титриОчищує збережений фоновий список і наказує підключеній сторінці титрів очистити локальний список.

Якщо Перевірити титри повідомляє, що джерело титрів не підключене, завантажте або покажіть джерело браузера OBS і повторіть спробу.

Хто з’являється в титрах

Титри можуть розпізнавати захоплених учасників чату, членство/підписки та активність донатів. Для людини потрібна захоплена подія з іменем і типом платформи; Social Stream не може перелічити мовчазних глядачів, про яких платформа ніколи не повідомляє.

  • Учасник трансляції: захоплене повідомлення або іменована подія активності.
  • Учасник/підписник: захоплене поле членства або підтримувана подія підписки/членства.
  • Донатор: захоплений елемент зі значенням донату. Підтримувані валюти нормалізуються для сортування й необов’язкового показу суми. Оновлення серій TikTok враховують лише приріст у межах тієї самої серії. Подарунки з невідомою ціною все одно включають донатора, не додаючи вигаданої доларової суми. Перерахунок монет/діамантів TikTok є оцінкою, а не гарантованою виплатою.
  • Ідентичність: однакове ім’я на двох різних платформах вважається двома окремими ідентичностями джерел.

За типовим ранжуванням кожна захоплена дія додає 1 бал, членство — 50 балів, а кожен нормалізований долар донату — 100 балів. Список групується в VIP Supporters, Regular Supporters і Stream Participants. Увімкніть Пріоритет донатів щоб натомість використовувати зрозуміліші групи Stream Donors, Channel Members і Stream Participants.

Швидке налаштування, фільтри та збережені дані

  • Повторювати прихильників: вмикає повторення, збереження даних оверлею, фільтр лише прихильників, пріоритет донатів і суми донатів.
  • Лише донатори: вмикає повторення, збереження даних оверлею, фільтр лише донаторів і суми донатів.
  • Включати лише прихильників: включає донаторів і розпізнаних учасників/підписників, але виключає тих, хто лише спілкувався в чаті.
  • Включати лише донаторів: потребує захопленої ознаки донату.
  • Зберігати список титрів у цьому оверлеї: зберігає зібрані сторінкою дані Auto/Manual після оновлень і перемикань джерела та не дозволяє завершеному запуску Start видалити список.
  • Безперервно повторювати титри: перезапускає анімацію та включає новозібрану активність у наступний цикл.
Дані фонового збирання вже зберігаються застосунком/розширенням для поточної сесії. Вони зберігаються після закриття сторінки титрів і залишаються доступними до використання Скинути збережені титри .

Подробиці налаштування OBS

  1. Спочатку завершіть налаштування титрів, потім скопіюйте URL титрів, щоб він містив вибрані параметри URL.
  2. Додайте цей URL як джерело браузера OBS. Звичайне джерело 1920 × 1080 добре підходить для повноекранних стилів.
  3. Для Auto або Manual залишайте джерело завантаженим протягом усієї трансляції. Повторне використання того самого джерела OBS у кожній сцені надійніше, ніж створення окремих копій.
  4. Для фонового збирання джерело може бути відсутнє або вивантажене під час трансляції. Воно має бути підключене лише перед надсиланням Start, Preview або Test.
  5. Використовуйте Preview або Test для перевірки розміру шрифту, швидкості, категорій, прозорості й фінального повідомлення перед ефіром.
Параметр OBS: «Shutdown source when not visible» зупиняє збирання Auto/Manual, оскільки збирач працює на сторінці. Цей параметр сумісний із фоновим збиранням, якщо показати джерело перед надсиланням команди запуску.

Керування через Stream Deck і API

Офіційний плагін Stream Deck надає дії Start, Preview, Test і Reset для титрів. Ті самі команди доступні через API віддаленого керування Social Stream:

ДіяПриклад HTTP
creditsStarthttps://io.socialstream.ninja/SESSION_ID/creditsStart
creditsPreviewhttps://io.socialstream.ninja/SESSION_ID/creditsPreview
creditsTesthttps://io.socialstream.ninja/SESSION_ID/creditsTest
creditsResethttps://io.socialstream.ninja/SESSION_ID/creditsReset

Замініть SESSION_ID на активну сесію Social Stream. Увімкніть віддалене керування розширенням через API у Global settings → Mechanics. Джерело браузера титрів має бути підключене, щоб Start, Preview або Test з’явилися на екрані.

Поширені проблеми

  • Перевірка працює, але справжній список порожній: тестові записи вбудовані й не підтверджують збирання активності. Переконайтеся, що потрібний режим запуску вибрано перед трансляцією та що джерела чату захоплювали дані.
  • Після повторного відкриття налаштувань немає засобів керування: Start і Preview показуються для режимів Manual і Background. Auto натомість запускається через видимість.
  • Джерело титрів не підключено: завантажте/покажіть джерело OBS, переконайтеся, що воно має поточний скопійований URL і сесію, потім повторіть спробу.
  • Учасників чату бракує: Для Auto/Manual сторінка титрів має залишатися завантаженою. Для окремої фінальної сцени використовуйте фонове збирання.
  • Учасників або донаторів бракує: переконайтеся, що джерело платформи створило іменовану подію членства або донату та що Only donors/Only supporters її не виключає.
  • Імена зникли після завершення титрів: увімкніть Зберігати список титрів у цьому оверлеї, скористайтеся Preview або режимом Background. Звичайний запуск Start із даними, зібраними сторінкою, видаляє показані записи, коли збереження й повторення вимкнені.
  • Старі імена залишаються: виберіть Скинути збережені титри перед наступною трансляцією. Фонові дані зберігаються для кожної сесії Social Stream до скидання.
