Посібник із нових учасників чату

Позначайте зовсім нових учасників чату виділенням, значком листка або необов’язковим звуковим сигналом.

Що робить ця функція

Визначення нових учасників чату додає firsttime=true до першого збереженого повідомлення глядача для цього джерела. Док може використовувати цей прапорець для підсвічування фону, сигналу лише для нових учасників і необов’язкового значка листка.

Обов’язкове налаштування

  1. Відкрийте спливне вікно Social Stream Ninja.
  2. Залиште Вимкнути локальну базу даних повідомлень вимкненим.
  3. Увімкніть Визначення нових учасників чату.
  4. Залиште док або оверлей відкритим із тим самим ID сесії.
Важливо: Локальна база даних обов’язкова. Якщо вона вимкнена, Social Stream Ninja не може визначити, чи користувач новий.

Параметри відображення

  • Підсвічування фону: типово ввімкнено в доку. Залиште Без підсвічування фону нових учасників чату вимкненим, якщо потрібне виділення.
  • Значок листка: увімкніть Позначати нових учасників чату власним значком щоб додати невеликий значок листка перед значками учасника чату.
  • Сигнал дока для нових учасників чату: увімкніть, якщо сигнал дока має звучати лише для нових учасників чату.
  • Сигнал для нових учасників чату або тих, хто повернувся: увімкніть, якщо також потрібен звук для глядачів, які повертаються після 8 або більше годин мовчання.

Використання прапорця у власних оверлеях

Власні оверлеї можуть перевіряти data.firsttime === true. Якщо значок листка ввімкнено, він включається в chatbadges перед надходженням повідомлення до оверлеїв.

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

Якщо не відображається

  1. Переконайтеся, що Вимкнути локальну базу даних повідомлень вимкнено.
  2. Переконайтеся, що Визначення нових учасників чату увімкнено.
  3. Переконайтеся, що Без підсвічування фону нових учасників чату вимкнено, якщо очікуєте виділення.
  4. Переконайтеся, що Позначати нових учасників чату власним значком увімкнено, якщо очікуєте значок листка.
  5. Перевірте з поєднанням імені користувача та джерела, яке ще не збережене в локальній базі даних.
