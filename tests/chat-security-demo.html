What this test includes
Production code: the complete Twitch capture script; processIncomingMessage, applyBotActions, sendToDestinations, sendDataP2P; bundled sanitizers; and the full Dock/Featured page with its normal iframe listener and TTS processing.
Local substitutes: a Twitch-shaped DOM, Chrome messaging/configuration, offline transports, database I/O, and disabled optional integrations. Event Flow has no configured rules. TTS audio output is muted after message processing. The source fixture blocks inline handlers via CSP; receiver pages allow their normal inline scripts. The server redirects the bridge iframe locally and blocks external resources. A timeout or processing error is reported as an error, never as protection.
This demonstrates application behavior in a browser. It does not connect to Twitch, run inside OBS, or demonstrate a Chromium exploit. Detailed review.
