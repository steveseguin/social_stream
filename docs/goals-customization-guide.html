Show a different GIF as your fundraiser grows

Use one custom overlay containing the goal bar and your artwork. The bar already calculates progress; the artwork should follow that same progress instead of counting donations separately. This recipe needs an edited copy of the overlay, not an extra built-in setting.

  1. In SSN, configure Tip Jar and Goal Meter with Fluid Goal Bar, your title, goal, and donation filters. For this fixed $500 money goal, leave Hype Cup Scoring off and recurring or advancing goals disabled. Make the original link work before customizing it.
  2. Follow Download and keep the file structure below to create my-goal.html. Save your five GIFs beside that file, using the names in the table. Use matching canvas sizes so the artwork does not jump or stretch when it changes.
  3. Give your editor or AI tool the copied source and GIFs. Use the milestone instructions below together with the full customization prompt. Ask for one image beside the existing bar.
  4. Preview the edited copy at each milestone, then follow Session and OBS to connect it using your original link settings. Add the combined overlay as one OBS Browser Source.

Rehearse without changing live totals

Open your edited copy with the preview settings below. Change startamount to the values in the prompt and refresh between checks. Preview uses sample data and disables live connections, saved totals, and sound.

file:///C:/SSN/social_stream-beta/my-goal.html?preview&style=bar&goal=500&startamount=125

At $125, the first milestone GIF should appear beside a 25%-full bar. Remove preview and the rehearsal startamount before using your real session and its original settings. Check restored totals and resets separately in a test session, because preview does not save totals.

Already added a GIF as a separate OBS source? It can play beside the goal, but it does not automatically know the goal's progress. Use the combined custom overlay for automatic milestone changes.

Choose the right starting page

The Tip Jar / Goal Meter can present different metrics and styles from the same tipjar.html. First configure the intended metric in SSN, then keep that generated URL when changing the design. Hype scoring in this goal is different from the viewer/chatter counter in hype.html.

Download and keep the file structure

  1. Download the source ZIP and extract it. These guides use the beta source; keep the files from one download together.
  2. Copy tipjar.html to my-goal.html beside the original. If choosing a different page or theme, keep its copy in that file's original folder.
  3. Open the copied HTML and its referenced CSS/JS in your editor or AI tool. Add supplied artwork/fonts to the same project and use relative paths. Start with CSS overrides; include the renderer when changing generated markup.

The following files help you find the design and behavior. This is a reading list, not a complete dependency bundle: keep the extracted folder intact, including images, fonts, scripts, and any data files.

Connect your copy and open it in OBS

Start SSN and make the original generated overlay URL work first. The session= value connects to that SSN session; it is not your channel name or this file's name. Keep SSN, the relevant feature, and its data sources running.

  1. Drag your edited HTML file into Chrome or Edge. Copy its address from the address bar; it starts with file:///.
  2. Copy everything from ? onward in your working SSN overlay link and add it to the end of that file address. Keep all settings, including the session, password, and any # ending.
  3. Open the result in a browser, then set an OBS Browser Source's URL to the same address with Local file unchecked. Match the source dimensions to your intended design.

For the starting file above, the local address looks like this; your actual link may contain additional required options:

file:///C:/SSN/social_stream-beta/my-goal.html?session=YOUR_SESSION

Use the actual file address on your computer. OBS saves it with the source; keep the downloaded folder in the same place. After saving design changes, refresh the Browser Source. The shared setup guide includes Mac examples and an optional launcher for the Local file checkbox.

Where to change the design

Change the jar artwork, fill colors, bar track, goal label, amount typography, and completion animation. Start with the existing style and color controls described in the goal guide. For custom artwork, keep the assets beside your copy and update only its referenced path.

The goal's metric, completion/reset rules, persistence, and donor counting belong to its behavior. Keep these while changing presentation. Do not convert raw coins, gifted subscriptions, and USD into one unlabelled number. Preserve a numeric donoValue of zero when the source supplies it.

Test this overlay type

Use a preview or test setup first. The test-message guide explains how to send fictional payloads through SSN; a test submitted to your production session can trigger its existing automations.

  1. Try the page's preview mode (?preview with your style options) first; remove preview when connecting the real session.
  2. Use sample support events matching the chosen metric. Check zero, partial progress, goal reached, and progress beyond the goal.
  3. Check reset/carryover settings and a source refresh between rehearsals. Inspect currency labels, long titles, and any sound or completion effect in OBS.

Also run the input-rendering checks against the render paths you changed. After saving edits, refresh the OBS Browser Source between rehearsals and repeat the visible interaction. Browser previews do not establish live capture or OBS behavior.
