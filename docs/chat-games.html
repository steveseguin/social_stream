01 / Work it out together

Signal Lock

1?4?

Chat has 90 seconds to crack four digits. Every guess gives everyone a clue. Great for puzzle fans, study breaks, gaming lobbies, and smaller communities.

How to play

Type !code 1234. Digits range from 1 to 6, and can repeat. “Exact” means the correct digit and position. The other count shows correct digits in different positions.

The first valid guess starts the clock. Five seconds between each viewer’s guesses; identical guesses are ignored.

02 / Let the room decide

Crowd Quest

A five-stop space trip guided by chat. Choose routes, manage shared supplies, and bring home discoveries. A relaxed fit for talk, art, music, cozy gaming, and variety streams.

How to play

Type !vote 1, !vote 2, or !vote 3. Each chapter gives the crew 30 seconds to choose. One vote per viewer; the latest valid choice replaces their previous vote.

The first vote starts each chapter. Outcomes are shown before voting. Ties are random, and routes needing more supplies than the crew has are unavailable.

Put it on stream

  1. In SSN, open Interactive Games → Select Game.
  2. Choose Signal Lock or Crowd Quest and add its session link as an OBS Browser Source. Start at 1280 × 900.
  3. Keep SSN and your chat sources running. Show the on-screen command and let chat start the round.

The host can pause or restart using OBS’s Interact window. Add &clean to hide host buttons, &transparent for a transparent page background, or &chroma for green. Add &demo only for an isolated preview. A round ends with a ten-second result screen, then automatically moves on.

These games use no loyalty points, purchases, external media, or viewer login page. They only read the chosen SSN chat session; they do not send commands back to chat. Host buttons act locally. The same person on two platforms counts as two players. Up to 1,000 distinct players per round.

Old favorites, new moments

Word Chain has a refreshed layout with clearer scores and a readable word trail. Its familiar rules remain: chain alphabetic words of at least three letters, starting with the last letter of the previous word. It checks letter patterns, not a dictionary.

Try Chat Garden for a creative break, Pixel Battle for collaborative art, or Pet Race for a quick intermission.

Beyond chat

Let viewers make the decision and you make it real: choose your next drawing color, the next song from a shortlist, or a stretch break. SSN’s existing polls, queues, and host-approved sticker rewards offer other ways to participate. Keep your session and control links private; viewers only need the chat instructions.
