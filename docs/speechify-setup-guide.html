Read your chat with Speechify

Set up a voice, change how it reads, and send the sound to your viewers.

Before you start

This works with eBay Live or any source whose text messages reach SSN. First, confirm you can see new chat in your SSN dock. If you cannot, follow the getting-started guide before setting up speech.

You need internet access and a Speechify API account and key. Installing the Speechify reading app alone does not connect it to SSN. Check API access and usage charges in your Speechify account. Chat selected for speech is sent to Speechify.

Get a key · Set up SSN · Change voice · Read faster · OBS audio · Viewer volume · Troubleshooting

1. Get your Speechify API key

  1. Open the Speechify developer platform and sign in or create an account.
  2. Open API Keys. Copy an existing key, or create one if needed.
  3. Keep the key ready to paste into SSN. You do not need to install an SDK or run code.

These account steps follow Speechify's official quickstart.

Keep your key and generated SSN link private. The link can contain your API key. Do not post it in chat or include it in screenshots.

2. Select Speechify in SSN

  1. Open the desktop app's Sources and Settings, or the SSN extension popup.
  2. Find Main chat overlay & control dock, then expand Message — Text to Speech. You can also search settings for text to speech.
  3. Turn on Enable TTS in dock.
  4. Set TTS Service Provider to Speechify.
  5. Paste your key into Speechify API Key. For a first English voice, enter henry in Speechify Voice ID.
  6. Leave Speed at its default for your first test. Leave the optional Model and language switches off.

3. Open the updated dock link

  1. Use copy link beside Main chat overlay & control dock.
  2. Open that newly copied link in the browser where you want speech to play. If using OBS, follow the next OBS section.
  3. In a normal browser, click inside the dock once if audio is blocked.
  4. Send a short message in your own connected chat. Confirm the new message appears and is spoken.

Keep the source connected and the TTS dock open. New eligible messages are read in sequence; filters and TTS controls can exclude messages. Busy chat can build a queue.

After changing voice, speed, or provider, copy the link again. Replace the old URL wherever speech plays. Refreshing a page that still has the old URL can keep the old settings.

Choose another voice

Change Speechify Voice ID, then open the updated dock link. Speechify lists henry, george, carly, and sabrina as built-in examples. Use an exact API voice ID, not just a display name from the reading app.

To find more, use Speechify's Choose a voice instructions. Its voice-list API returns the voices your account can use; copy the selected voice's id into SSN. Match the voice to the model supported by your SSN settings. SSN currently offers English (simba-english) and Multilingual (simba-multilingual); a voice advertised only for a newer model may not work with those.

Change the settings under Main chat overlay & control dock if that is the page reading chat. Featured Chat and the chat bot have separate TTS settings.

Make it read faster

  1. Under Speechify TTS Options, turn on the switch beside Speed.
  2. Try 1.2 as a modest increase from the normal value of 1.0.
  3. Copy the updated dock link and replace the URL in your browser or OBS source. Compare the same short sentence at both settings.

The switch must be on for the setting to be included in the link. SSN sends this speed value to Speechify; its effect needs checking with your selected voice and account. If the speed stays the same, see the compatibility note below.

Speaking faster is different from starting sooner. Speed does not remove the time Speechify needs to generate the audio. Shorter messages and turning off username reading can help the queue keep up.

Send Speechify audio through OBS

  1. In the scene you use for streaming, go to Sources → + → Browser. Name the source SSN Speechify.
  2. Paste the updated SSN dock link into URL.
  3. Tick Control audio via OBS, then click OK.
  4. Send a short chat message and look for movement in that source's Audio Mixer meter.
  5. Make a short recording and play it back to confirm the voice is in the output.

For audio without visible chat, keep the Browser Source active and position it outside the visible canvas. Do not rely on a source that is shut down when hidden to keep reading.

Want to hear it yourself too? Open Advanced Audio Properties from the Audio Mixer and set that source's Audio Monitoring to Monitor and Output. Avoid Monitor Only (mute output) when viewers should hear it. Avoid capturing the monitoring device a second time.

An OBS custom dock is a control panel. For these instructions, use a Browser Source in your scene. Keep only one copy speaking to avoid doubled voices.

Reference: OBS Browser Source documentation.

Make it louder for viewers

  1. In SSN's dock TTS settings, enable Volume of speech and set it to 1.0 (100%). Update the dock URL again. If you lowered the dock's own volume slider, turn it back up.
  2. In OBS, unmute SSN Speechify and raise its mixer fader toward 0.0 dB if it was turned down.
  3. If it is still too quiet, open that audio source's Filters, add a Gain audio filter, and try a small boost such as +3 dB.
  4. Record speech alongside your microphone and background audio. Listen back and adjust the balance. Reduce gain if speech distorts or the meter reaches the red end.

SSN's volume stops at 100%; extra boost belongs in your outgoing audio mix. Turning up your headphones alone does not make the stream louder. OBS documents Gain and other audio filters here.

Streaming directly through eBay or another app? SSN does not inject sound into that app automatically. It must receive the TTS audio through its selected audio input. The steps depend on your computer and streaming setup; tell support which app sends the stream and which microphone/audio input it uses.

If something does not work

  • No text in the dock: fix source capture first. Speechify cannot read messages SSN has not received.
  • Still the old voice: check you changed the dock's settings, selected Speechify, and replaced the old URL. Close or mute any other speaking copies.
  • Text arrives but no speech: check the TTS switch, API key, account access/usage limits, and voice ID. In a normal browser, click the page once.
  • You hear it but viewers do not: check the OBS source meter, mute state, output track, and monitoring mode. Test a recording.
  • Echo or repeated speech: leave one TTS page speaking and avoid capturing both its direct output and monitoring audio.
  • Speed does not change: check the Speed switch and new URL first. If both are correct, report the SSApp version and voice/model so the Speechify integration can be checked.

Compatibility note — September 8, 2026: These instructions were checked against SSN's settings and source code and Speechify's public documentation. Live Speechify generation and speed changes have not been verified with an authenticated account for this guide. Speechify's current API documentation differs from SSN's existing integration; a provider compatibility issue may need a code fix if correct settings still fail.

For help, share your app version, voice ID, what step failed, and whether audio runs in SSApp, a browser, or OBS. Remove API keys and private session links from screenshots.
