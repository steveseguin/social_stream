Social Stream Ninja · Guides

Set up alerts, chat commands and reminders

Add sounds for stream events, answers to common questions, and occasional chat reminders. Start with one command and one alert, then add the rest. Fixed replies do not need an AI bot or an Event Flow.

Connect chat · Commands · Reminders · Alerts and sounds · Troubleshooting

1. Connect your chat

  1. Open the Social Stream Ninja desktop app or browser extension, turn capture on, and connect your live chat. See the setup guides if you have not connected a source yet.
  2. Sign in to the account you want to post replies from. Confirm a viewer's message appears in your Social Stream chat dock.
  3. Send a message from the dock to the intended platform and check that it appears in the platform's own chat. Reading chat and posting replies are separate capabilities.

TikTok: for chat replies, use a signed-in Standard connection or the desktop app's Local Signer reply path. Compatibility (WebSocket) mode does not send replies. Follow the TikTok connection guide if messages appear in the dock but replies do not reach TikTok.

2. Add custom command replies

  1. Open Social Stream settings and search for Auto-responder.
  2. Enable a command entry. In Triggering command(s), enter !discord. In Message to respond with, enter your Discord invite link and a short invitation.
  3. Enable Trigger only if full message matches exactly if commands should work only when sent on their own.
  4. Set Trigger timeout (ms) to 10000 for a ten-second cooldown. Leave Reply to all instead of just the source off to answer in the originating chat.
  5. Optionally enter youtube,tiktok under Limit to specific sites to accept these commands only from those platforms.
  6. Have a viewer send the command in the platform chat. Check that it arrives in the dock and produces one reply in the intended platform chat.
  7. Add another command entry for each answer you want to provide.

Replace the bracketed placeholders below with your own details. Replies are limited to 200 characters in the settings; split long lists across commands or link to a page containing the full list.

CommandExample reply
!deviceI play on [device model] with [accessories/settings].
!gunsmithsMy current loadout codes: [codes or a link to your list].
!socialFind my channels here: [your social links or profile page].
!discordJoin our Discord: [your invite link].
!followEnjoying the stream? Please like and follow or subscribe!

Command names are yours to choose. For example, enter !device, idevice in one entry to accept either spelling. These replies post the text and links you enter; they do not look up your device, loadouts, or social profiles automatically.

3. Add an automatic reminder

  1. In settings, find Send fixed messages at intervals and enable a message entry.
  2. Enter a short Message to broadcast, such as Enjoying the stream? Please like and follow or subscribe!
  3. Set Interval between broadcasts in minutes to 15. Leave Starting time offset at 0 for no extra delay before the timer starts. An interval of zero sends only once.
  4. Enable Skip auto-message if chat is too quiet if you want reminders to pause during quiet periods.

Timed messages broadcast to eligible connected chats. Keep only the intended destinations enabled for sending. Use a command such as !follow instead if you want a reminder only when someone asks.

4. Add alerts and your own sounds

  1. Open Multi-Alerts in settings. Enable the follow, subscription/member, and donation alert categories you want to display, and choose their styles.
  2. Open Sound & Timing, enable Play alert sound, and choose the volume.
  3. Expand Per-type custom sounds (override above). Use the separate Follow sound, Subscription sound, and Donation sound fields to upload your files or supply direct audio URLs. Use Listen to preview a selected sound.
  4. For a custom image, GIF, or video, open Event animations & sound effects, enable a rule, select its event, and add media. Leave amount limits blank when the alert should apply to any donation amount. See animation and sound alerts for rule options.
  5. Copy your configured Multi-Alerts link and add it as a Browser Source in OBS. Use the link from your own settings so the overlay connects to your session.
  6. Use Test alert to check the local preview. After changing settings, copy the updated link into OBS. Check the browser source's audio in OBS before going live.

An event rule can specify its own sound, overriding the category sound. Use one place to configure each sound so the result is easy to manage.

YouTube: free channel subscribers use the Follow alert category; paid memberships use Subscription. New subscriber alerts need the API connection signed in as the channel owner. They can be delayed or incomplete and cover public subscriptions only. Use the YouTube event guide to choose the connection for the alerts you need.

Donations and gifts: alerts display events your connected source supplies, such as YouTube Super Chats and TikTok gifts. An external tipping service needs its own supported connection; adding the overlay alone does not connect a payment account.

If something does not work

  • No command reply: check that the entry is enabled, the command matches, the cooldown has elapsed, and the account can send to that chat. Check source restrictions and message filters. Test with a viewer account rather than a message posted by the bot itself.
  • Replies appear in extra chats: turn off Reply to all instead of just the source and check your sending destinations.
  • No live alerts: confirm the event reaches Social Stream, then check the overlay's session link and event/platform filters. A preview shows the appearance; it does not connect a platform or prove a live event was received.
  • No sound: check Play alert sound, volume, and the OBS browser source's audio settings. Open a custom audio URL directly to confirm it plays without signing in. In a normal browser, click the overlay if playback is blocked.
  • Repeated replies or sounds: check for duplicate enabled commands, another bot answering the same command, or two active alert sources playing the same sound.
