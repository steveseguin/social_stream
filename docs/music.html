Show the current song

  1. Open Interactive > Music > Now Playing and enable Music.
  2. Select and connect a source below.
  3. In Now Playing Overlay, set Overlay input to Selected Music source.
  4. Copy the overlay link into an OBS Browser Source. Choose a style and hide options in the same panel.

Existing Spotify overlay links keep showing Spotify. Music uses one selected input for its overlay and Event Flow. Its overlay clears the track if it loses contact with SSN.

Choose a source

Spotify

Enable and connect Spotify in Spotify Setup & Configuration. Playback controls and song requests continue to use that account.

What's Now Playing

Connect your DJ software or media player in What's Now Playing, then enable its web server. Enter its address in Music, usually http://127.0.0.1:8899. For a DJ computer on your local network, use that computer's address and web server port.

Tracks without playback timing show artist and title without a progress bar. Set the expiry interval to suit your sets so old track information clears when the source stops updating.

File (SSApp)

Set your player or DJ helper to overwrite a current-song file, then choose that file in Music. Select one of these formats:

  • Artist - Title: one line, for example Example Artist - Example Song.
  • Separate lines: artist on line 1 and title on line 2.
  • JSON: the object below. Only title is required.
{"title":"Example Song","artist":"Example Artist","album":"Example Album"}

JSON can also include a string id, an HTTPS imageUrl, status (playing, paused or stopped), and numeric durationMs and progressMs in milliseconds. Leave unknown values out. An empty file clears the track. Files must be 64 KB or smaller. The selected path stays on the SSApp computer.

Chat commands and Event Flow

When Music is enabled, its Song commands setting owns Spotify's !song, !np and their configured aliases. Choose Built-in dock replies for a simple response in SSN, or Event Flow for custom responses. Built-in replies use the existing Spotify command permissions. Playback and queue commands remain Spotify-specific.

For a platform chat reply, choose Event Flow and add the Music Song Command template in the editor. It starts disabled. Review the command and destination, then enable it. Configure permissions and a Rate Limiter in your flow as needed.

Get Now Playing adds the selected track to the current flow without changing the originating chat. Use {meta.music.message} for a complete response, including when no song is available, or format {meta.music.track.name}, {meta.music.track.artist} and {meta.music.track.album} yourself.

Track Changed can drive Show Text, OBS Set Text, TTS or a webhook. Playback Changed works when the selected source reports playback status. Initial connection and reconnect snapshots do not announce tracks. Music updates do not trigger Any Message flows.

Keep automatic Spotify dock announcements off if a flow already announces the same Spotify track.
