Choose the right starting page

Choose the page for the number you want to show. hype.html shows viewer/chatter statistics; meta.html presents structured updates; leaderboard.html ranks activity/support; scoreboard.html presents configured points. A visual redesign should not silently change what a number measures.

Download and keep the file structure

  1. Download the source ZIP and extract it. These guides use the beta source; keep the files from one download together.
  2. Copy scoreboard.html to my-scoreboard.html beside the original. If choosing a different page or theme, keep its copy in that file's original folder.
  3. Open the copied HTML and its referenced CSS/JS in your editor or AI tool. Add supplied artwork/fonts to the same project and use relative paths. Start with CSS overrides; include the renderer when changing generated markup.

The following files help you find the design and behavior. This is a reading list, not a complete dependency bundle: keep the extracted folder intact, including images, fonts, scripts, and any data files.

Connect your copy and open it in OBS

Start SSN and make the original generated overlay URL work first. The session= value connects to that SSN session; it is not your channel name or this file's name. Keep SSN, the relevant feature, and its data sources running.

  1. From the extracted repository's top folder, start a local static server using the local HTTP instructions.
  2. In the full copied overlay link, replace only the hosted page address with the local address of your edited file. Preserve everything from ? onward, including any # fragment. Keep password and transport options exactly as generated.
  3. Open the result in a browser, then set an OBS Browser Source's URL to the same address with Local file unchecked. Match the source dimensions to your intended design.

For the starting file above, the local address looks like this; your actual link may contain additional required options:

http://127.0.0.1:8000/my-scoreboard.html?session=YOUR_SESSION

For a direct disk URL or OBS's Local file checkbox, follow the disk-file and launcher instructions. Selecting an unconfigured stock HTML file alone does not supply the session. If local-file restrictions block assets or the connection, use local HTTP. A copied page does not add itself to SSN's theme dropdown.

Where to change the design

Style rows, rank badges, platform icons, value columns, panel backgrounds, and rank-change animation. Keep stable user identity, ties, sorting, and the selected period/category. The source's actual counters and metadata should drive the values; ordinary text saying "100 viewers" is not a viewer update.

Check the target's empty state. Some views deliberately remain hidden until a snapshot or matching activity arrives. Use that page's own demo/preview options where available; a generic ?demo is not supported by every counter.

Test this overlay type

Use a preview or test setup first. The test-message guide explains how to send fictional payloads through SSN; a test submitted to your production session can trigger its existing automations.

  1. For scoreboard.html use ?preview; for leaderboard.html use ?demo to inspect a populated layout. Remove the preview/demo flag for the live link.
  2. For Hype/metadata, use the test tool's viewer-update payload or the actual host counter; plain chat alone does not prove the counter works.
  3. Test ties, rank changes, large values, zero, long names, missing avatars, and the chosen time period. Verify the numbers against the host's corresponding view.

Also run the input-rendering checks against the render paths you changed. After saving edits, refresh the OBS Browser Source between rehearsals and repeat the visible interaction. Browser previews do not establish live capture or OBS behavior.
