Getting Started (Browser Extension)

1. Installation

Before you can use Social Stream Ninja, you'll need to install it first. There are multiple ways to install the browser extension:

  • Manual Installation (recommended): For the most up-to-date version, install manually in developer mode.
  • Chrome Web Store: Install via Chrome Web Store for the easiest setup experience.

For detailed installation instructions, please visit the Download page.

2. Basic Setup

Once installed, follow these steps to start using Social Stream Ninja:

  1. Open your streaming platform's chat in a browser (or use the pop-out chat feature if available)
  2. Click the Social Stream Ninja extension icon in your browser toolbar
  3. Click "Enable Extension" to turn it on (the icon should turn green)
  4. Open the "Dashboard Link" provided in the extension popup
  5. Open the "Overlay Link" in OBS as a browser source

Note: For the best experience, keep chat windows visible (not minimized) when using the browser extension.

3. Connecting to Different Platforms

Social Stream Ninja works with 100+ platforms. Here's how to connect to the most popular ones:

YouTube

  • Open YouTube Live chat
  • Click the "Pop out chat" button in the top-right corner
  • Ensure the Social Stream Ninja extension is enabled (green icon)

Twitch

  • Open Twitch chat for your channel
  • Click the gear icon and select "Pop out chat"
  • Ensure the Social Stream Ninja extension is enabled (green icon)

Facebook

  • Open your Facebook Live broadcast (as a viewer or publisher)
  • Ensure you're connected to WiFi or Ethernet (not mobile data)
  • Ensure the Social Stream Ninja extension is enabled (green icon)

Discord, Slack, WhatsApp, etc.

  • First, enable these platforms in the extension settings (toggle switch)
  • Open the web versions of these platforms in your browser
  • Ensure the Social Stream Ninja extension is enabled (green icon)

Customization (Browser Extension)

URL Parameters

You can customize both the dashboard and overlay by adding parameters to their URL. Some examples:

Dashboard Parameters:

&darkmode - Enables dark mode for the dashboard
&scale=2 - Doubles the size/resolution of all elements
&hidesource - Hides platform icons (YouTube, Twitch, etc.)
&compact - Removes spacing between name and message
&inline - Flows the message beside the name while keeping normal spacing
&autoshow - Auto-features messages as they appear (about 2 per 3 seconds)

Overlay Parameters:

&showtime=20000 - Auto-hides selected messages after 20 seconds
&showsource - Shows the platform icons next to usernames
&fade - Makes featured messages fade in instead of popping up
&swipe - Makes featured messages swipe in from the left
¢er - Centers featured messages on screen

For easier URL management, try our URL Parameter Editor Tool.

CSS Customization

There are several ways to customize the appearance with CSS:

Method 1: OBS Browser Source CSS

In OBS, you can add custom CSS to the browser source:

  1. Add your overlay as a Browser Source in OBS
  2. Check the "Custom CSS" option
  3. Enter your custom CSS in the text box
body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }

:root {
    --comment-color: #090;
    --comment-bg-color: #DDD;
    --comment-border-radius: 10px;
    --comment-font-size: 30px;
    --author-border-radius: 10px;
    --author-bg-color: #FF0000;
    --author-avatar-border-color: #FF0000;
    --author-font-size: 32px;
    --author-color: blue;
    --font-family: "Arial", sans-serif;
}

.hl-name {
    padding: 2px 10px !important;
}

Method 2: Extension Menu Settings

Add CSS directly through the extension menu:

  1. Click the Social Stream Ninja extension icon
  2. Find the CSS/JavaScript settings section
  3. Enter your custom CSS or JavaScript
  4. The CSS will be appended to the URL as base64 encoded data

Method 3: Use Custom Templates

Choose from pre-styled templates that include CSS built-in:

  • Browse our Templates Gallery
  • Select a template that matches your stream's style
  • Replace YOURSESSIONID in the template URL with your session ID
  • Add the template URL as a browser source in OBS

Example: https://socialstream.ninja/themes/pretty.html?session=YOURSESSIONID

Different colors for chat names

Name colors need two settings: a general color source under Message - Styling and the Dock display toggle under Message - Visibility.

Open the chat name colors guide for screenshots, color choices, troubleshooting, and CSS examples.

Self-hosted fonts & styling

Bring your own fonts to dock.html or featured.html without relying on Google/System fonts.

  • Host your .woff2/.ttf/.otf files and load them with @font-face.
  • Apply CSS via OBS custom CSS or URL params like &css=, &b64css=, &font=, or &googlefont=.
  • Works the same in the Chrome extension, Electron app, and hosted pages.

Advanced Features (Browser Extension)

Text-to-Speech

Social Stream Ninja can read chat messages aloud using Text-to-Speech technology:

Setting Up TTS:

  1. Add &speech=en-US to your featured.html or dock.html URL
  2. For other languages, use a provider and voice that supports that language. For example, Portuguese can use Piper &pipervoice=pt_BR-faber-medium or eSpeak &espeakvoice=pt-br, while Spanish can use Piper &pipervoice=es_ES-davefx-medium or eSpeak &espeakvoice=es.
  3. Customize voice settings with parameters like &pitch=1&volume=1&rate=1

Free Local TTS Options (no API key):

  • Kokoro TTS: Built-in browser AI, excellent quality — &ttsprovider=kokoro
  • Piper TTS: Fast, lightweight neural TTS — &ttsprovider=piper
  • eSpeak-NG: Lightweight language fallback, including Portuguese &espeakvoice=pt-br and Spanish &espeakvoice=es
  • Kitten TTS: Smallest footprint, CPU-only — &ttsprovider=kitten
  • Self-hosted server: Run Kokoro-FastAPI or openedai-speech locally via Docker — &ttsprovider=openai&openaiendpoint=http://localhost:8880/v1/audio/speech

Premium Cloud TTS Options:

  • Google Cloud TTS: Professional-quality voices (requires Google API key)
  • ElevenLabs: Ultra-realistic voices with custom voice training
  • Speechify: Natural-sounding premium voices

Want to keep it local and private? See the Local AI TTS Guide for full setup instructions including self-hosted server options and OBS audio capture.

Queuing and Pinning Messages

Organize how messages appear in your overlay:

Queuing Messages:

  1. Hold CTRL (or Cmd on Mac) while clicking messages in the dashboard
  2. Click the "Next in Queue" button to display them one by one
  3. Messages will appear in your overlay in the order they were queued

Pinning Messages:

  1. Hold ALT while clicking a message in the dashboard
  2. The message will stay pinned at the top of the dashboard
  3. To unpin, hold ALT and click the pinned message again

Event Flow Editor

The Event Flow Editor is a powerful node-based automation system for building custom workflows. It's the "advanced automation" layer that lets you script your own routing logic.

What You Can Do:

  • Relay chat between platforms with smart filters (e.g., mirror Twitch to Discord but block commands)
  • Build custom commands with AND/OR/NOT logic gates
  • Trigger overlays and audio based on specific events or keywords
  • Control OBS scenes and sources automatically
  • Create raffles and giveaways with queue management

Getting Started:

  1. Open the Event Flow editor from the main dashboard menu
  2. Create a new flow and add source nodes (e.g., "Twitch Message")
  3. Connect logic nodes to filter messages (Contains Keyword, User Role, etc.)
  4. Add action nodes to respond (Send Chat, Play Audio, Display Overlay)
  5. Test with the built-in simulator before going live

Flow Actions Overlay:

For audio, media overlays, and OBS actions to work, you need to add the Flow Actions page as a browser source in OBS:

  1. In the popup, find the "Flow Actions" section and copy the URL
  2. Add it as a Browser Source in OBS (1920×1080 recommended)
  3. Keep the overlay open (hidden is fine, but don't close it)

Important: Enable "No Reflections" when relaying chat to prevent infinite echo loops. For detailed documentation, see the Event Flow Guide. For Kick reward sounds or media, use the Kick Channel Points / Rewards guide.

Bot Commands & Auto-Response

Create interactive bot commands and automated responses for your chat.

Built-in Commands:

  • !joke - Sends a random geeky dad joke
  • !hi - Auto-greets viewers
  • !cycle - Allows viewers to change OBS scenes (with permission)

Setting Up Auto-Response:

  1. Open the extension popup and find the Bot/Auto-Response section
  2. Enable the commands you want to use
  3. Keep your chat window visible (not minimized) for responses to work
  4. Ensure you're logged into the platform with posting permissions

Creating Custom Commands:

For more complex commands, use the Event Flow Editor:

  1. Create a new flow with a Message source
  2. Add a "Contains Keyword" node to detect your command (e.g., "!social")
  3. Connect a "Send Chat" action with your response
  4. Optionally add User Role filters for mod-only commands

Requirements: Auto-responses work best with Chromium-based browsers. Chat windows must remain visible, and you must have permission to post on the platform.

Webhooks & Integrations

Connect external donation platforms to display tips and purchases in your stream overlay.

Prerequisites:

  1. Note your Session ID from the extension popup
  2. Keep Social Stream Ninja enabled
  3. Under Global settings and tools → Mechanics, enable remote API control of extension
  4. Use your normal generated dock and overlay links; do not add &server, &server2, or &server3 for donation webhooks
  5. Reload the dock once if it was already open
Only one API toggle is needed: remote API control lets the background script normalize donation webhooks and deliver them like normal messages. The other API transport toggles can remain off.

The normalized donation is shared with chat, alerts, Event Flow, and the Tip Jar/Goal Meter.

Supported Platforms:

Platform Webhook URL Event Type
Stripe https://io.socialstream.ninja/{sessionID}/stripe checkout.session.completed
Ko-Fi https://io.socialstream.ninja/{sessionID}/kofi Donations (public only)
Buy Me A Coffee https://io.socialstream.ninja/{sessionID}/bmac donation.created, membership.started
Fourthwall https://io.socialstream.ninja/{sessionID}/fourthwall ORDER_PLACED

Stripe Setup:

  1. Create a Stripe Payment Link
  2. Important: Add custom fields to your payment link:
    • Display Name or Username (required) - without this field, donations will be rejected
    • Message (optional) - allows donors to leave a message
  3. Go to Stripe Webhooks and create a new endpoint
  4. Set URL to: https://io.socialstream.ninja/YOUR_SESSION_ID/stripe
  5. Select event: checkout.session.completed
  6. No signature verification needed (keep your session ID private instead)

Testing: Use Stripe's Test Mode with card 4242 4242 4242 4242, any future expiry, any CVC.

Ko-Fi Setup:

  1. Sign in to Ko-Fi Webhook Settings
  2. Paste https://io.socialstream.ninja/YOUR_SESSION_ID/kofi into Webhook URL, then click Update
  3. Enable remote API control of extension, then reload an already-open dock
  4. Click Send single tip test and confirm exactly one alert appears
  5. Only public donations will appear (private donations are filtered out)

Buy Me A Coffee Setup:

  1. Sign in to Buy Me A Coffee and navigate to Settings → Webhooks
  2. Add webhook URL: https://io.socialstream.ninja/YOUR_SESSION_ID/bmac
  3. Both one-time donations and new memberships are supported

Fourthwall Setup:

  1. Go to your Fourthwall admin: Settings → For Developers → Webhooks
  2. Create webhook with URL: https://io.socialstream.ninja/YOUR_SESSION_ID/fourthwall
  3. Subscribe to ORDER_PLACED events
Security Note: Keep your session ID private. Anyone with your session ID can send fake donation events to your overlay.

Exporting Chat via Webhook:

You can also export chat data to external services:

  • Configure an outbound webhook URL in settings
  • Chat messages are sent as POST requests with JSON payload
  • Use this to log chats, trigger external automations, or sync with other tools

Troubleshooting (Browser Extension)

Solutions for common issues with the browser extension

Chat Stops When Background/Minimized

Chat messages stop appearing when browser windows are in the background or minimized. This happens because browsers throttle background tabs to save resources.

Disable Browser Throttling
  • Chrome/Edge/Brave:
    1. Open chrome://flags/#enable-throttle-display-none-and-visibility-hidden-cross-origin-iframes
    2. Set to "Disabled"
    3. Also disable chrome://flags/#calculate-native-win-occlusion
    4. Restart your browser
  • Disable Performance Throttling:
    1. Go to chrome://settings/performance
    2. Disable "Throttle Javascript timers in background"
Alternative Approaches
  • Keep Windows Visible: Arrange windows so they're not minimized; even a small visible portion can prevent throttling.
  • Use Virtual Desktops: On Windows, use Win+Tab to create two virtual desktops, with chat windows on one and OBS on the other.
  • Try the Standalone App: The Social Stream Ninja desktop app avoids many browser throttling issues.

Blue Bar Appears / Auto-Responder Not Working

A blue debugging bar appears or automated responses don't work when trying to use bot commands or auto-responses.

Check Chat Window Visibility
  • When using YouTube or Twitch, make sure the pop-out chat window is open and visible
  • For some platforms, you may need to keep the main window open alongside the pop-out
Browser Compatibility
  • Auto-responder works best with Chromium-based browsers (Chrome, Edge, Brave)
  • Firefox has limited support for extension features

Stream Events Capture

Capture non-chat events like new followers, subscriptions, raids, and donations.

How to Enable:

  1. Open the Social Stream Ninja app
  2. Go to settings and find "Capture Stream Events"
  3. Enable it to start receiving alerts

Note: Donations (Super Chats, Bits, Tips) forward automatically. The toggle is primarily for follower/subscriber alerts.

Events Captured:

  • YouTube: Memberships, Super Chats, subscriber counts
  • Twitch: Subscribers, followers, bits, raids, channel points
  • TikTok: Followers, gifts, viewer counts
  • Kick: Subscriptions, tips, follow alerts

See the Event Reference for complete event payload documentation.

Event Flow Editor

Build powerful automations with the node-based Event Flow Editor.

What You Can Do:

  • Relay chat between platforms with smart filters
  • Trigger overlays and audio based on events or keywords
  • Control OBS scenes and sources automatically
  • Build custom commands with logic gates (AND/OR/NOT)
  • Create raffles and games with queue management

Getting Started:

  1. Open the Event Flow editor from the app's menu
  2. Create a flow with source nodes (Message, Timer, Manual Trigger)
  3. Add logic nodes to filter (Contains Keyword, User Role, etc.)
  4. Connect action nodes (Send Chat, Play Audio, Display Overlay)
  5. Test with the simulator before going live

Flow Actions Overlay:

Add the Flow Actions URL as a browser source in OBS for audio/overlay actions to work. Find the URL in the app's "Flow Actions" section.

For detailed documentation, see the Event Flow Guide. For Kick reward sounds or media, use the Kick Channel Points / Rewards guide.

Available Actions:

  • Switch OBS scenes
  • Play audio clips
  • Execute Event Flow triggers

Troubleshooting (Standalone App)

Solutions for common issues with the standalone application

Platform Connection Issues

Having trouble connecting to specific platforms in the standalone app.

Authentication Problems
  • For Facebook, TikTok, and Instagram, use the "Sign in" button first
  • Ensure you're using the same login credentials as your browser
  • Check if you need to grant additional permissions to the app
Network Issues
  • Check your internet connection
  • Disable VPN if it's interfering with connections
  • Try using a different DNS provider

Settings Not Saving

Your configuration or settings aren't being saved between sessions.

Permission Issues
  • Ensure the app has write permissions in its installation directory
  • Run the app as administrator (Windows) if needed
  • Check if your antivirus is blocking file writes
Export Settings
  • Use the export feature to save your settings
  • Save the exported file to a secure location
  • Import settings if they're lost after an update
