StreamElements Widget Importer
Choose the widget, confirm your SSN session, then download one ready-to-use HTML file for OBS. No coding or URL editing is needed.
Works with both SSN versions: use either the Windows desktop app or the Chrome extension to capture chat. The downloaded HTML file displays that chat in OBS.
Start-to-finish setup
  1. Open SSN and confirm a real chat message appears in its dock.
  2. Choose the widget zip, folder, or files below.
  3. Check the SSN Session ID / Stream ID below. It is filled automatically when you open this importer from SSN and saved inside the downloaded file.
  4. Use Demo Preview to check the design, then Live Preview to check real chat.
  5. Click Download OBS HTML.
  6. In OBS, add a Browser Source, enable Local file, and select the downloaded HTML file. Do not add the session ID in OBS.
Keep the SSN app or extension running while streaming. You may close this importer and StreamElements after downloading.

What gets converted
Best fit: StreamElements or Streamlabs chat widgets with HTML, CSS, JS, fields, data, and local assets. SSN payloads are mapped into the SE-style event fields those widgets expect.
SSN chatnameSE-style data.displayName, data.nick
SSN chatmessageSE-style data.text, renderedText
SSN chatbadgesSE-style data.badges where URLs or badge labels exist
SSN typeSE-style service
SSN mid, id, or meta.messageIdSE-style data.msgId for delete-message support
SSN membership, subtitle, badges, and role hintsSE-style subscriber, moderator, VIP, or broadcaster flags when detectable
SSN hasDonation, donation, and contentimgSE-style data.amount and attachment image data where available
Known limits
  • Chat widgets are the main target; goals, alerts, loyalty, store, tips, and account API features are only shimmed if their code falls back cleanly.
  • Widgets that require private StreamElements or Streamlabs API tokens, overlay-store state, full jQuery plugins, or platform emote APIs may need manual edits.
  • Local packaged images, fonts, audio, and video are embedded; remote URLs stay remote and may still fail if the source blocks OBS/browser access.
  • The export is a single HTML file with the session embedded, but ?session=... and &password=... in the OBS URL still override it.
  • Common live overrides: &limit=30, &direction=top, &direction=bottom, and &hideAfter=20.

Exported HTML is ready

Your SSN session is already saved inside the downloaded file. You do not need to paste a session ID or edit a URL in OBS.

  1. Keep Social Stream Ninja running and confirm chat appears in its dock.
  2. In OBS, add a new Browser Source.
  3. Enable Local file and browse to the downloaded HTML file.
  4. Set the source size for your layout, then click OK.

For a quick visual test without live chat, open the file with ?demo.
