설치된 글꼴 감지기

브라우저에서 사용할 수 있는 글꼴과 실시간 예시를 표시하며 사이트 전체에 적용할 URL 매개변수를 제공합니다.

사용자 지정 글꼴 설치 방법

  • Windows: .ttf 또는 .otf 파일을 마우스 오른쪽 버튼으로 클릭 → ‘설치’ 또는 ‘모든 사용자용으로 설치’ 선택 → 브라우저 재시작.
  • macOS: .ttf 또는 .otf 파일을 두 번 클릭 → 서체 관리자에서 ‘서체 설치’ 클릭 → 브라우저 재시작.
  • Linux: 글꼴 파일을 다음 위치에 복사하세요: ~/.local/share/fonts/ → 다음을 실행하세요: fc-cache -fv → 브라우저를 재시작하세요.

설치 후 이 페이지를 새로고침하면 새 글꼴이 표시됩니다. 글꼴이 보이지 않으면 ‘Local Fonts API 사용’ 버튼을 눌러 보세요(Chromium 브라우저 전용).

URL로 특정 글꼴 사용

  • 매개변수: 추가할 항목: ?font=<Font%20Family%20Name> 를 URL에 추가하세요. 공백과 기호는 URL 인코딩해야 합니다.
  • 적용되는 CSS 변수: 사이트에서 사용하는 값: --font-family이며 이 페이지도 해당 설정을 따릅니다. 예: ?font=Segoe%20UI.
  • 따옴표 불필요: 매개변수에 따옴표를 넣지 마세요. CSS 변수에는 필요하지 않습니다.
  • 설치된 글꼴만: 이 매개변수는 시스템에 이미 설치된 글꼴에만 적용됩니다. 웹 글꼴을 다운로드하지 않습니다.

호환성 (Ninja 앱)

  • VDO.Ninja: 생성됨 ?font= 링크는 다음을 따르는 오버레이/장면에서 작동합니다: --font-family 변수.
  • SocialStream.Ninja: 동일한 값을 사용하세요: ?font= 매개변수로 지원되는 위젯의 기본 글꼴을 재정의하세요.
  • Caption.Ninja: 적용 (Apply) ?font= 를 사용자 지정 글꼴 패밀리를 지원하는 자막 오버레이에 추가하세요.

이 앱들은 다음 매개변수를 지원하는 경우 글꼴 패밀리를 재정의할 수 있습니다: ?font= . URL이나 삽입 링크에서 지원되어야 합니다. 이 도구는 바로 사용할 수 있도록 올바르게 인코딩한 값을 생성합니다.

문제 해결 (Windows)

  • 정확한 글꼴 패밀리 이름: 글꼴의 다음 정보를 사용하세요: 패밀리 이름을 사용하고 파일 이름은 사용하지 마세요. 설정 → 개인 설정 → 글꼴에서 정확한 패밀리 이름을 확인하세요.
  • 올바른 설치 범위: 다른 Windows 사용자나 관리자 계정에만 글꼴을 설치했다면 현재 브라우저 세션에서 보이지 않을 수 있습니다. 필요하면 ‘모든 사용자용으로 설치’를 사용하세요.
  • 지원 형식: 브라우저는 TrueType/OpenType/WOFF를 사용합니다. 오래된 Type 1과 일부 비트맵 글꼴은 작동하지 않습니다.
  • 굵기/스타일 제공 여부: Bold만 설치되어 있으면 보통 굵기의 텍스트가 대체 글꼴로 표시될 수 있습니다. 굵은 예시를 사용하거나 Regular도 설치하세요.
  • 개인정보 보호 제한: 브라우저는 권한 없이 모든 글꼴을 조회하도록 허용하지 않습니다. 이 페이지는 알려진 글꼴 목록과 선택적인 Local Fonts API로 감지합니다.
  • Local Fonts API: Chromium의 안전한 출처(https/localhost)에서는 ‘Local Fonts API 사용’을 클릭하고 권한을 허용하면 설치된 정확한 글꼴 패밀리를 나열할 수 있습니다.

수동 사용 팁

  • 글꼴 강제 지정: CSS에서: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • 임의의 이름 테스트: 검색창에서 원하는 패밀리 이름을 입력하세요. 찾으면 예시와 함께 결과에 표시됩니다.
  • 인코딩: 링크 구성 예: ?font=Segoe%20UI (아래에서 생성한 링크에는 올바른 인코딩이 적용됩니다).
  • CJK 및 문자 체계별 글꼴: 예시에는 라틴 문자, 숫자, 기호가 포함됩니다. 원하는 문자 체계의 텍스트로 바꿔 글자 조합이 올바른지 확인하세요.

참고: 이 페이지는 글꼴을 설치하거나 다운로드하지 않습니다. 브라우저에서 이미 사용할 수 있는 글꼴 패밀리만 감지하고 미리 보여 줍니다.
