진행자 설정

화면에 나올 것은
직접 선택하세요.

이 보상은 Twitch나 Kick의 플랫폼 채널 포인트가 아닌 SSN 자체 참여 포인트 잔액을 사용합니다. 이런 상호작용을 원할 때만 활성화하세요.

기본 제한: 화면에 6초 표시, 시청자별 60초, 스티커별 20초, 표시 사이 3초 간격. 대기시간 중 요청은 포인트를 차감하지 않고 거절됩니다.

  1. 열기 포인트 시스템 → 스티커 보상 (Points System → Sticker rewards) 를 SSN 제어에서 여세요. 포인트 시스템과 스티커 보상을 활성화하세요.
  2. 팩을 하나 이상 선택하고 가격을 정하세요. 방송에 맞게 재사용 대기시간과 표시 시간을 설정하세요.
  3. 생성된 다음 링크를 추가하세요: 스티커 오버레이 세션 링크를 OBS 브라우저 소스로 추가하세요. 보상 사용을 받는 동안 활성 상태로 유지하세요.
  4. 또는 다음을 추가하세요: &stickers 를 다중 알림 또는 이벤트 스트림 URL에 추가하세요. 보상이 두 번 표시되지 않도록 스티커 화면은 하나만 사용하세요.
  5. 시청자에게 다음 명령을 사용하도록 안내하세요: !stickers 로 활성 메뉴를 보고 !sticker rocket 로 보상을 사용하게 하세요. 소스 채팅 답장은 선택 사항이며 지원되는 답장 전송 연결이 필요합니다.

스티커 연결은 채팅이 서버 모드를 사용해도 표준 SSN iframe 브리지를 사용합니다. 로컬 전용 배포에서도 해당 브리지에 접근할 수 있어야 합니다.

같은 설정 패널에서 사용자 지정 보상을 최대 12개 추가하세요. 이름, 짧은 코드, 고정 가격, 직접 HTTPS 이미지 URL을 선택하세요. 시청자는 승인된 메뉴에서 선택하며 임의의 이미지 URL을 제출할 수 없습니다.

GIPHY 반응 사용

GIPHY 페이지 주소 대신 직접 GIF 또는 WebP 미디어 링크를 복사하여 사용자 지정 스티커로 추가하세요. 사용 시 호스팅 서버에서 이미지를 가져오므로 해당 서버가 이미지 로드를 허용해야 합니다.

사용자 지정 코드 hype 로 바뀝니다: !sticker custom-hype이 됩니다. 정적 PNG, JPEG, WebP 이미지도 사용할 수 있습니다. 표시할 권한이 있는 이미지를 사용하세요.

차분한 배치를 원하면 다음을 추가하세요: &motion=off 로 내장 스티커 움직임을 멈추세요. 애니메이션 GIF 자체는 계속 움직이므로 움직임이 전혀 없어야 한다면 정적 이미지를 선택하세요. 선택적으로 &size=400 그리고 &hidecaption 로 플레이어를 조절할 수 있습니다.
