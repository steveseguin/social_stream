나만의 소셜 스트림 오버레이 디자인

각 오버레이 제품군에 대한 가이드와 함께 OBS에서 로컬 오버레이 디자인을 다운로드, 사용자 정의, 연결 및 테스트합니다.

유형을 선택하세요다운로드세션 IDOBS에서 열기디자인과 AI안전한 입력테스트AI에 제공할 파일문제 해결

다시 디자인하려는 오버레이를 선택하세요

파일 다운로드→디자인 변경→OBS에서 열기

기존 페이지의 색상, 글꼴, 레이아웃, 아트웍 및 모션을 변경할 수 있습니다. 는 HTML 파일 은 페이지입니다. 는 OBS URL 은 이를 가리키며 세션 및 디스플레이 설정을 제공합니다. 작은 스타일을 변경하려면 호스팅된 페이지에서 OBS 사용자 정의 CSS를 사용하세요. 더 깊은 변경을 위해서는 소스를 다운로드하고 자신만의 복사본을 실행하세요.

이 가이드는 테마를 포함하여 오버레이 제품군을 다룹니다. 사용하는 기능에 대한 수신자를 선택하세요. 채팅 페이지, 선택한 메시지 페이지, 설문조사는 모두 동일한 입력을 사용하지 않습니다.

기성 디자인을 시작하려면 오버레이 갤러리 또는 템플릿 갤러리. 기존 StreamElements/Streamlabs 채팅 스킨의 경우 다음을 따르세요. 가져오기 가이드. 가져온 자체 포함 HTML에는 자체 내보내기/설정 지침이 있습니다.

1. 실제 파일을 다운로드합니다.

  1. 베타 소스 ZIP 다운로드, 또는 베타 저장소 을 열고 다음을 선택하세요: 코드 → ZIP 다운로드.
  2. 다음과 같이 보관할 수 있는 폴더에 ZIP을 추출합니다. C:\SSN\social_stream-beta\. 압축된 아카이브 내부를 편집하지 마십시오. 이는 페이지 소스 파일입니다. 별도의 복사본을 편집할 때 SSN를 다시 설치할 필요가 없습니다.
  3. 위 표에 표시된 파일을 찾으세요. 원본 옆에 복제하세요. 예를 들어 poll.html 로 바뀝니다: my-poll.html. 다음의 경우: themes/featured-styles/featured-modern.html, 복사본을 보관하세요 themes/featured-styles/.
  4. 텍스트/코드 편집기에서 복사본을 엽니다. AI 도구에 해당 파일과 필요한 참조 스타일/스크립트에 대한 액세스 권한을 부여하세요. HTML을 다른 이름으로 저장 .html그렇지 않다 .html.txt.

추출된 폴더 구조를 유지합니다. 다운로드한 단일 HTML 파일은 그 옆에 스크립트, 스타일시트, 글꼴, 이미지, 오디오 또는 JSON을 로드할 수 있습니다. GitHub의 페이지 보기와 브라우저의 "페이지 저장"은 신뢰할 수 있는 완전한 번들이 아닙니다. 각 유형 가이드는 유용한 파일을 식별하지만 전체 추출된 폴더는 종속성을 유지하는 가장 간단한 방법입니다.

social_stream-beta/
    poll.html
    my-poll.html
    currency.js
    js/
    libs/
    shared/
    thirdparty/
    media/
    sources/images/
    themes/
        featured-styles/
            featured-modern.html
            my-featured.html
    docs/
        event-reference.html

다음과 같은 참고문헌이 있다. ../../shared/utils/chatHtml.js 은 그것을 로드하는 페이지에 상대적입니다. 해당 페이지를 루트로 이동하면 경로가 끊어집니다. 로컬 아트웍과 글꼴도 프로젝트에 복사한 다음 상대 URL을 사용하세요. 다운로드한 버전을 함께 보관하세요. 편집된 사본은 향후 SSN 수정 사항을 자동으로 받지 않습니다.

2. 세션 및 연결 설정을 유지합니다.

SSN를 시작하고 소스를 연결한 후 원본 오버레이가 작동하는지 확인합니다. 복사 생성된 링크 전체 관련 SSN 도구에서. 이후의 가치 session= 는 SSN 세션을 식별합니다. YouTube 채널, Twitch 사용자 이름, 파일 이름 또는 설문 조사 제목이 아닙니다.

https://socialstream.ninja/poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

이 예에서는 자리 표시자를 사용합니다. SSN와 페이지는 동일한 실제 세션과 구성된 비밀번호를 사용해야 합니다. 파일 이름을 변경해도 세션은 변경되지 않습니다. SSN를 유지하고 캡처를 실행합니다. 오버레이가 데이터를 수신합니다. 플랫폼 채팅 자체는 캡처하지 않습니다.

  • ? 쿼리를 시작합니다. 후속 설정 사용 &. 값을 다시 입력하는 대신 복사하세요. HTML 소스 속성에 다음을 작성합니다. &amp;; browser/OBS URL 필드에 일반 앰퍼샌드를 사용하십시오.
  • 전송 설정을 유지합니다. server, server2, server3, 로컬 끝점, 레이블 및 버전 값은 페이지마다 다릅니다. 단지 다른 오버레이가 지원한다고 해서 서버 플래그를 추가하지 마세요.
  • 조각도 보존합니다. 그 이후의 모든 것 # 중요할 수 있다. 예를 들어 AI 이벤트 오버레이는 비공개를 사용합니다. #aieventauth=... 토큰을 표시합니다.
  • 공유된 예에서는 자리 표시자를 사용합니다. 공개 스크린샷, 저장소 및 AI 프롬프트 예제에서 실제 세션 링크, 비밀번호 및 개인 디스플레이 토큰을 유지하세요.

복사본이 비어 있는 경우 원본 생성 링크를 먼저 확인하세요. 일부 페이지에서는 누락된 설정을 묻는 메시지가 표시됩니다. 나머지는 숨겨진 상태로 유지되거나 리디렉션됩니다. 올바른 세션을 명시적으로 제공하면 해당 페이지별 기본값에 의존하는 것을 방지할 수 있습니다.

3. OBS에서 파일을 엽니다.

편집된 HTML을 컴퓨터에서 직접 엽니다. 설치하거나 시작할 서버가 없습니다.

  1. 복사한 HTML 파일을 Chrome이나 Edge로 드래그하세요. 주소 표시줄에서 전체 주소를 복사하세요. 그것은로 시작한다 file:///.
  2. 다음의 모든 항목을 복사합니다. ? 작업 중인 SSN 오버레이 링크에서 계속해서 해당 파일 주소 끝에 추가하세요. 이렇게 하면 세션, 비밀번호, 기타 설정 등이 유지됩니다. # 결말.
  3. 결합된 주소를 브라우저에서 열어서 테스트해 보세요.
  4. OBS에서 다음을 추가하세요: 브라우저 소스. 다음은 그대로 두세요: 로컬 파일 선택을 취소하고 전체 주소를 붙여넣으세요. URL. 디자인의 너비와 높이를 설정합니다.

예를 들어 다음 SSN 링크는 다음과 같습니다.

https://socialstream.ninja/poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

는 Windows에서 다운로드한 설문 사본의 주소가 됩니다.

file:///C:/SSN/social_stream-beta/my-poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

실제 파일 주소와 복사된 설정을 사용하세요. macOS에서 주소는 다음으로 시작됩니다. file:///Users/...; Linux에서는 일반적으로 다음으로 시작합니다. file:///home/.... 브라우저 주소를 복사하면 공백과 슬래시가 자동으로 처리됩니다.

한번 설정해 보세요. OBS는 소스와 함께 주소를 저장합니다. 다운로드한 폴더를 같은 위치에 유지하고 오버레이를 사용할 때 SSN와 채팅 소스를 계속 실행하세요. 디자인 변경 사항을 저장한 후 사용하세요. 현재 페이지의 캐시 새로고침 (Refresh cache of current page) 소스 속성에서.

로컬 파일을 선택하지 않은 상태로 두는 이유는 무엇입니까? URL 필드를 사용하면 다음을 포함할 수 있습니다. ?session=.... 파일 선택기만으로 HTML을 선택하면 해당 설정이 추가되지 않습니다.

선택 사항: 실행기와 함께 로컬 파일 확인란을 사용합니다.

OBS의 파일 선택기는 파일을 선택합니다. 생성된 쿼리 설정은 추가되지 않습니다. 수정되지 않은 쿼리 기반 수신기의 경우 작은 로컬 실행 프로그램은 다음 설정이 첨부된 편집된 페이지로 이동할 수 있습니다.

  1. 다음을 다른 이름으로 저장하세요. launch-my-poll.html (다음 항목 옆에 있음): my-poll.html.
  2. 자리 표시자 호스팅 URL을 완전히 복사된 SSN 링크로 바꿉니다. 변경 ./my-poll.html 실제 편집된 파일 이름으로. 링크를 따옴표 안에 보통 그대로 유지하세요. & 문자입니다.
  3. 런처를 두 번 클릭하여 테스트하세요. OBS에서 다음을 선택합니다. 로컬 파일 그리고 다음을 선택하세요. 런처. 쿼리 및 조각이 포함된 로컬 오버레이로 리디렉션됩니다.
<!DOCTYPE html>
<html lang="en">
<meta charset="utf-8">
<title>My local overlay launcher</title>
<p>Opening the local overlay...</p>
<script>
var copiedLink = new URL("https://socialstream.ninja/poll.html?session=YOUR_SESSION");
var localPage = new URL("./my-poll.html", window.location.href);
localPage.search = copiedLink.search;
localPage.hash = copiedLink.hash;
window.location.replace(localPage.href);
</script>
</html>

중첩된 테마의 경우 해당 테마 사본 옆에 런처를 배치하세요. 런처에는 연결 링크가 포함되어 있으므로 비공개로 유지하세요. 이미 구성이 포함된 다운로드된 자체 포함 내보내기는 자체 내보내기 지침을 따릅니다.

OBS는 파일/URL 모드, 크기, 사용자 정의 CSS 및 새로 고침 컨트롤을 다음 문서에 문서화합니다. 브라우저 소스 참조.

4. 디자인을 변경하거나 AI에게 요청하세요.

CSS 전용 변경의 경우 호스팅 링크를 유지하고 OBS를 사용하세요. 사용자 지정 CSS 필드. 해당 소스에만 적용되므로 동일한 URL을 여는 일반 브라우저에는 해당 재정의가 표시되지 않습니다. 편집된 HTML 파일의 경우 기존 스타일 뒤에 재정의를 추가하거나 그 뒤에 로컬 스타일시트를 연결합니다. 로고, 글꼴 파일, 브랜드 색상, 캔버스 크기 및 시각적 참조를 제공하십시오.

일부 페이지에서는 지원됩니다. &css= 또는 &b64css=; 지원은 페이지별로 이루어집니다. poll.html예를 들어 둘 다 읽지 않습니다. URL 옵션을 사용하기 전에 페이지의 파서를 확인하세요. 웹 페이지는 일반적으로 다른 컴퓨터의 로컬 디스크에서 임의의 글꼴이나 이미지를 로드할 수 없습니다.

마크업을 변경할 때 스크립트에서 참조하는 ID/클래스를 유지하세요. JavaScript가 업데이트할 때마다 요소를 다시 작성하는 경우 영구 아트워크는 해당 요소 외부에 존재하거나 렌더러에 의해 다시 생성되어야 합니다. 편집 내용이 디자인에만 영향을 미치도록 하려면 공유 스타일시트/스크립트를 복사하고 페이지 참조를 변경하세요.

5. 들어오는 채팅이 코드가 되는 것을 방지

메시지, 이름, 제목, 금액, 메타데이터 및 미디어 링크는 뷰어 또는 외부 서비스에서 생성될 수 있습니다. 사용자 정의 렌더러가 삽입하는 지점에서 삭제합니다. SSN를 통해 받은 문자열은 실행할 수 있는 권한이 아닙니다. 일반 필드에는 일반 DOM 텍스트를 사용하십시오. 메시지 본문에서 지원되는 HTML에 대해 패키지된 새니타이저를 사용하세요. 참조 OWASP의 안전 싱크 및 HTML 삭제에 대한 설명.

SSN에서는, textonly 다음에만 적용됩니다. chatmessage. true이면 해당 본문을 리터럴 텍스트로 렌더링합니다. 그렇지 않으면 감정 표현과 허용되는 형식이 포함될 수 있습니다. 다른 일반 필드를 텍스트로 렌더링합니다. 등의 미디어 분야 chatimg 그리고 contentimg 는 HTML 스니펫이 아닌 URL/데이터입니다.

  • 안전 변경으로 인해 해당 기능이 제거되지 않도록 지원되는 감정 표현과 이미지 전용 메시지를 확인하세요.

통과 프로브는 연습된 경로만 확인합니다. 디자인에 따라 변경된 렌더러 및 필드에 테스트 초점을 맞추세요.

6. 레이아웃, 연결, OBS를 별도로 테스트

  1. 레이아웃: 가능한 경우 페이지의 문서화된 미리보기/데모 모드를 사용하거나 가상의 로컬 샘플을 사용하십시오. 긴 이름/메시지, 누락된 아바타, 빈 데이터 및 예상 행 수를 테스트합니다.
  2. SSN 배송: SSN를 활성 상태로 유지하고 사용 테스트 메시지 만들기 (Create Test Message) 같은 세션으로요. 일반적인 Extension API 수집 모드에는 다음이 필요합니다. 확장 프로그램 원격 API 제어 활성화되었습니다. 격리된 테스트 설정을 사용하세요. 제출된 테스트는 구성된 자동화를 트리거할 수 있습니다.
  3. 실제 트리거: 추천 카드에 대한 Dock 메시지 기능, 설문조사에 대한 투표 투표 보내기, 경품 당첨자 선택, 티커에 대한 티커 텍스트 변경 또는 타이머 타이머 시작. 일반 채팅은 보편적인 테스트가 아닙니다.
  4. 실제 캡처: 실제 소스 메시지/이벤트가 원본 페이지와 편집된 페이지에 도달하는지 확인합니다. 모의 이벤트는 플랫폼 캡처가 아닌 렌더링을 증명합니다.
  5. OBS: 소스의 최종 크기, 투명도, 애니메이션, 오디오, 글꼴 및 레이어링을 확인하세요. 표시/숨기기, 지우기/재설정 및 새로 고침을 실행해 보세요. 브라우저와 OBS에는 별도의 저장소와 세션이 있습니다. 브라우저 로그인 또는 localStorage는 자동으로 공유되지 않습니다.

메모리에 데이터를 수집하는 페이지의 경우 로드를 해제하거나 새로 고치면 상태가 손실될 수 있습니다. 자동 새로 고침 또는 숨김 시 종료를 활성화하기 전에 유형 가이드를 확인하세요. 호스트 관리 디스플레이에는 복구 동작이 다릅니다. 제거 demo/preview 라이브 데이터를 기대하기 전에 플래그를 지정합니다. 이후 MP4의 경우

비어 있음 또는 "대기 중" 표시세션, 비밀번호, 전체 쿼리/조각, SSN의 실행 상태, 활성화된 기능 및 일치하는 입력을 확인하세요. 원래 생성된 URL을 비교하세요.

특별한 경우: 별도의 데이터 파일을 읽는 페이지

지도는 다음을 사용하여 로컬 JSON 파일을 읽습니다. fetch(), 디스크에서 열 때 브라우저가 차단할 수 있습니다. 간단한 지도 스타일을 변경하려면 OBS Custom CSS와 함께 호스팅된 링크를 사용하세요. 편집된 HTML 사본의 경우 페이지가 디스크에서 직접 열릴 수 있도록 필요한 지도 데이터를 페이지에 포함하도록 AI에 요청하세요. 호스팅은 이러한 오버레이에 대한 일반적인 설정 단계가 아니라 특별히 필요한 페이지를 위한 고급 옵션입니다.

확인된 가장 작은 문제에서 중지하세요. 스타일 변경 시 캡처 스크립트를 변경하거나 새 이벤트 필드를 만들 필요가 없습니다. 공개 포크를 공유하는 경우 지원 자산을 포함하고 비공개 실행 프로그램을 해당 업로드에서 제외하세요.
