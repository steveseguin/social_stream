첫 경품 추첨

시청자가 입력: !enter 를 채팅에 입력합니다. SSN에서 참가를 모은 다음 다음을 클릭하세요: 당첨자 추첨.

제어 찾기 경품 추첨 진행 OBS에 표시 설정의 의미 버튼의 역할 문제 해결

1. 경품 추첨 도구 찾기

이미 다음이 보인다면: 경품 추첨 도구, 참가 설정, 그리고 경품 추첨 실행, 올바른 위치에 있습니다. 별도의 경품 추첨 팝업을 찾을 필요가 없습니다.

그렇지 않으면 SSN 기본 설정 메뉴를 여세요. 브라우저 확장 프로그램에서는 브라우저의 확장 프로그램/퍼즐 조각 아이콘을 클릭한 뒤 다음을 클릭하세요: Social Stream Ninja. 데스크톱 앱에서는 오버레이 링크가 있는 SSN 설정 메뉴를 사용하세요. 검색어: giveaway 그리고 다음을 펼치세요: 경품 추첨 옵션. 초보자 환영 화면이 보이면 다음을 선택하세요: 전체 모드로 전환.

  1. 시청자 참가평소 캡처하는 채팅에서
  2. 진행자가 추첨합니다SSN 설정 메뉴에서
  3. OBS가 결과를 표시합니다복사한 표시 링크 사용

다음으로 시작하는 링크: https://socialstream.ninja/giveaway.html?session=... 는 시청자 화면을 엽니다. 다음이 있으면: &managed 가 링크에 있으면 SSN에서 추첨을 제어합니다. 표시 화면에는 참가 또는 추첨 버튼이 없습니다.

2. 간단한 무료 경품 추첨 진행

시작하기 전에 SSN을 켜고 채팅 소스를 연결해 두세요. 일반 시청자 메시지가 SSN 채팅 도크에 나타나는지 확인하세요.

  1. 기본 설정을 유지하세요. 유지: 경품 추첨 ID 형식: default (비워 두어도 기본값), 참가 키워드 형식: !enter, 그리고 메시지 일치 방식 형식: 메시지 전체 일치. 다음은 그대로 두세요: 회원만 참가 가능 그리고 중복 당첨 허용 꺼짐.
  2. 참가권 및 포인트 경품을 확인하세요. 일반 무료 추첨에는 다음을 사용하세요: 라운드 유형: 경품 추첨, 참가권당 포인트: 0, 당첨자당 포인트 경품: 0, 그리고 경품 수: 1. 이 작업에는 참여 포인트 시스템이 필요하지 않습니다.
  3. 참가 접수 시작을 클릭하세요. 시청자에게 이렇게 알려 주세요: '다음을 입력하세요: !enter 를 채팅에 입력하면 경품 추첨에 참가합니다.' YouTube나 Twitch처럼 캡처 중인 채팅에서 참가하며 추첨 링크는 필요하지 않습니다.
  4. 참가 기록을 확인하세요. 클릭: 상태 새로고침 로 메뉴의 개수를 업데이트하거나, 경품 추첨 및 기록 관리 로 이름을 확인하세요. 다음을 반복해도: !enter 로 반복해도 같은 시청자에게 무료 참가가 추가되지 않습니다.
  5. 참가 마감을 클릭한 다음 당첨자 추첨을 클릭하세요. SSN이 유효한 참가자 중 무작위로 선택합니다. 메뉴에 당첨자가 표시되고 연결된 화면도 같은 결과를 보여줍니다. 추첨하면 참가 접수도 자동으로 닫힙니다.
  6. 다른 추첨을 진행하려면 새 라운드, 참가 접수 시작 순서로 클릭하세요. 새 라운드는 빈 참가 목록으로 시작하므로 시청자가 다시 참가해야 합니다. 이전 결과는 기록에 남습니다.
'Entries open - 0 eligible entries'는 오류가 아닙니다. 추첨이 참가를 받고 있지만 마지막 상태 확인 시 참가자가 없었습니다. 시청자에게 다음을 보내게 하세요: !enter 를 참가 접수 시작 후 보낸 다음 다음을 클릭하세요: 상태 새로고침. 팝업의 개수는 채팅이 도착해도 자동으로 업데이트되지 않습니다.

상태에는 참가권 수도 표시될 수 있습니다. 무료 참가마다 참가권 하나로 계산하며 가격이 0이면 포인트를 차감하지 않습니다.

SSN이 당첨자를 선택합니다. 경품이 선물, 게임 키 또는 다른 물품이면 전달은 직접 준비해야 합니다. 다음 항목: 포인트 경품 은 SSN 참여 포인트를 지급하는 경품입니다.

3. OBS에 경품 추첨 표시

  1. 다음 항목 아래에서: 표시 방식, 다음을 선택하세요: 경품 추첨 표시 화면: 당첨자 카드 는 결과를 바로 보여줍니다; 이름 릴 은 공개 전에 이름들을 순환합니다; 커뮤니티 룰렛 은 돌아가는 룰렛으로 결과를 공개합니다.
  2. 선택: 스타일, 선택적 표시 제목, 그리고 투명(OBS) 를 배경으로 선택하세요. 테마 패널 은 배경 패널을 추가합니다.
  3. 클릭: 표시 미리보기 로 모양을 확인하세요. 샘플 이름을 사용하며 참가 접수를 열거나 실제 시청자를 추가하거나 실제 추첨을 실행하지 않습니다.
  4. 클릭: [링크 복사] (다음 항목 옆에 있음): 경품 추첨 도구. OBS에서 다음을 추가하세요: 브라우저 소스 그리고 URL 필드에 링크를 붙여넣으세요. 시작 너비: 1280 및 높이: 720.
  5. SSN을 계속 실행하고 다음 버튼을 사용하세요: 참가 접수 시작, 참가 마감, 그리고 당첨자 추첨 버튼을 사용하세요. 이 관리형 화면에는 OBS '상호작용' 단계가 필요하지 않습니다.

표시 설정을 변경한 뒤 링크를 다시 복사하세요 그리고 OBS URL을 교체하세요. 미리보기 URL 대신 일반 복사 링크를 사용하세요. 표시 화면이 자신의 추첨에 연결되도록 본인의 SSN 메뉴에 있는 세션과 비밀번호를 유지하세요.

[링크 편집] 은 기존 오버레이 URL을 메뉴의 링크 설정으로 불러옵니다. 첫 추첨에는 필요하지 않습니다. [?] 는 짧은 도움말을 엽니다.

참가 설정의 의미

설정의미
경품 추첨 ID제어할 경품 추첨의 이름입니다. 사용: default 를 추첨 하나에 사용하세요. 세션 ID와는 별개입니다. 여러 추첨에는 서로 다른 ID와 일치하는 표시 링크가 필요합니다.
참가 키워드시청자가 입력할 내용입니다. 예: !enter 또는 !raffle. 실제로 설정한 키워드를 시청자에게 알려 주세요.
메시지 전체 일치전체 메시지가 다음이어야 합니다: !enter, 대소문자와 앞뒤 공백은 무시합니다. !enter please 는 일치하지 않습니다.
메시지 어디에나 키워드 포함(별도 단어)다음과 같은 메시지를 허용합니다: I'd like to join !enter please. 키워드는 공백으로 구분되어야 합니다; !enter! 는 같은 키워드가 아닙니다.
회원만 참가 가능캡처한 메시지에 멤버십 정보가 있어야 합니다. 누구나 참가할 추첨이면 꺼 두세요. '시청 중인 누구나' 또는 '모든 팔로워'라는 뜻은 아닙니다. 지원 여부는 채팅 소스에 따라 다릅니다.
중복 당첨 허용같은 시청자가 현재 라운드에서 여러 경품에 당첨될 수 있게 합니다. 끄면 당첨자는 해당 라운드의 추첨 대상에서 제외됩니다. 새 라운드에서는 이전 당첨자가 다시 참가할 수 있습니다.
참가권 및 포인트 경품선택적 SSN 참여 포인트 설정 및 다른 게임 유형입니다. 무료 추첨은 비용과 포인트 경품을 0으로 유지하세요. Twitch 채널 포인트와는 별개입니다.
경품 수라운드에서 허용할 결과 수입니다. 참가를 열기 전에 설정하세요. 여러 당첨자를 뽑으려면 다음을 클릭하세요: 당첨자 추첨 를 경품마다 한 번씩 클릭하세요. 각 추첨 사이에 새 라운드를 만들지 마세요.

사람들이 참가하기 전에 규칙을 설정하세요. 참가 기록이 생긴 뒤 메뉴 필드를 바꿔도 활성 라운드 규칙은 바뀌지 않습니다. 바꾸려면 라운드를 취소하고 새 라운드를 만든 뒤 설정하고 참가를 다시 여세요. 관리자는 라운드에 실제 저장된 규칙을 보여줍니다.

무료 참가는 각 채팅 소스가 제공한 식별 정보로 추적합니다. 같은 사람이 두 플랫폼에서 참가해도 자동으로 한 사람으로 인식하지는 않습니다.

버튼의 역할

버튼용도
참가 접수 시작참가를 받거나 당첨자가 추첨되기 전에 일시 중지한 라운드를 다시 엽니다. 다시 열면 기존 참가 기록이 유지되며 잠긴 규칙을 그대로 사용해야 합니다.
참가 마감현재 참가자 풀을 유지하면서 새 참가를 중지합니다.
당첨자 추첨참가를 마감하고 당첨자 한 명을 선택합니다. 유효한 참가 기록이 하나 이상 있어야 합니다. 경품을 하나로 설정했다면 라운드가 완료됩니다.
취소 및 환불추첨 전에 취소합니다. 예약된 참가권 포인트를 돌려줍니다. 이미 추첨한 결과는 되돌릴 수 없습니다.
새 라운드이전 기록은 유지하고 빈 참가자 풀로 다시 시작합니다. 처음에는 참가가 닫혀 있습니다. 포인트가 예약된 유료 라운드는 먼저 취소/환불해야 합니다.
상태 새로고침추첨을 변경하지 않고 현재 개수와 최신 결과를 읽습니다.
경품 추첨 및 기록 관리참가자와 저장된 규칙을 확인하고 추첨 전에 참가 기록을 제거하며 결과를 검토하거나 기록/백업을 내보냅니다.

작동하지 않을 때

  • 참가가 여전히 0개인가요? 클릭: 상태 새로고침. 시청자 메시지가 SSN에 나타나는지, 도착했을 때 참가 접수가 열려 있었는지, 키워드가 일치하는지, 회원 전용이 꺼져 있는지 확인하세요. 무료 키워드 추첨의 참가권 가격은 0이어야 합니다. 동시에 진행하는 무료 추첨마다 다른 키워드를 사용하세요.
  • 테스트 메시지로 참가되지 않나요? 봇, 비공개, 과거 기록, 재생된 메시지, 경제 테스트로 표시된 메시지는 제외됩니다. 사용: 표시 미리보기 로 모양을 확인하세요. 실제 참가 캡처를 연습하려면 참가 접수를 연 뒤 연결된 채팅으로 키워드를 보내세요.
  • 화면에 'Waiting for giveaway'만 표시되나요? SSN 호스트를 계속 실행하고 같은 세션에서 복사한 링크를 사용한 뒤 다음을 클릭하세요: 상태 새로고침. 메뉴와 표시 화면이 같은 Giveaway ID를 사용하는지 확인하세요. 미리보기 URL은 샘플 데이터만 표시합니다.
  • 경품 추첨 페이지에 버튼이 없나요? 관리형 시청자 화면에서는 정상입니다. 다음으로 돌아가세요: 경품 추첨 옵션 (SSN에서).
  • 라운드가 완료되었거나 규칙이 잠겼나요? 사용: 새 라운드 를 추첨이 완료된 뒤 사용하세요. 아직 추첨하지 않은 라운드를 포기하려면 다음을 사용하세요: 취소 및 환불 를 먼저 선택한 다음 새 라운드.
  • SSN을 다시 시작했나요? 저장된 라운드는 해당 로컬 브라우저/앱 프로필에 남으며 진행 중인 라운드는 검토를 위해 닫힙니다. 같은 세션을 사용하고 상태를 새로고침한 뒤 검토 후 다시 여세요. 세션을 변경하면 별도의 추첨 모음이 선택됩니다.
