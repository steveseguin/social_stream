감열 프린터와 방송 라벨

구매, 후원, 채팅 이벤트를 실제 영수증, 스티커, 티켓 또는 수령 태그로 바꾸세요.

무엇을 인쇄할 수 있나요?

Windows 독립 실행형 앱은 Windows에 설치된 프린터로 대화상자 없이 인쇄 작업을 보낼 수 있습니다. 흐름은 시청자 이름, 후원, 상품, 메시지, 카운터 값 등의 사용 가능한 값을 조합하고 글자 크기와 정렬을 제어할 수 있습니다.

호환성 규칙: 프린터가 정상 작동하는 Windows 프린터 대기열로 표시되어야 합니다. Social Stream은 설치된 Windows 드라이버로 인쇄하며 원시 ESC/POS, ZPL 또는 제조사 SDK 명령을 보내지 않습니다.

빠른 설정

  1. 프린터를 USB로 연결하고 켠 뒤 Windows 드라이버를 설치하세요. 먼저 Windows 테스트 페이지를 인쇄하세요.
  2. Social Stream에서 다음을 여세요: 전체 설정 및 도구 → 프린터 제어.
  3. 선택: 프린터 찾기 (Find printers) 를 선택하고 Windows에 표시된 정확한 대기열 이름을 고르세요.
  4. 실제 용지 너비를 입력하세요. 일반적인 값은 58, 80, 또는 62 mm이며 장치와 용지에 따라 다릅니다.
  5. 유지: 고정 라벨 길이 (Fixed label length) 값: 0 으로 두면 내용 크기에 맞는 영수증이 됩니다. 규격 재단 용지는 공급 방향의 라벨 길이를 밀리미터로 입력하세요.
  6. 선택: 인쇄 정렬 테스트 (Print alignment test)를 선택하세요. 가장자리가 누락되면 해당 방향의 안전 여백을 늘리고 다시 시험하세요.

기본 좌우 안전 여백 2 mm는 많은 저가 58 mm 영수증 프린터에 적합하지만 실제 인쇄 가능 영역은 드라이버가 결정합니다. 유지할 옵션: 인쇄 가능 영역 사용 (Use printable area) 은 다른 설정을 시험한 경우가 아니면 선택 상태로 유지하세요.

영수증 롤, 연속 스티커, 규격 재단 라벨 중 무엇을 쓸까요?

영수증 롤

길이가 달라지는 구매 전표, 대기표, 후원 영수증에 적합합니다. 고정 라벨 길이를 0으로 두고 내용에 따라 용지 길이가 정해지게 하세요.

연속 스티커 롤

텍스트 양이 다른 접착식 이름 띠에 적합합니다. 영수증 용지처럼 작동하지만 절단은 프린터나 드라이버가 처리해야 합니다.

규격 재단 라벨

일정한 배지와 상품 라벨에 적합합니다. 정확한 고정 길이를 설정하고 Windows 인쇄 기본 설정에서도 같은 용지를 지정하세요.

프린터 예시유용한 용도연결 및 용지 참고 사항
일반 'POS-58'저렴한 58 mm 연속 영수증보통 USB 및 직접 감열 방식입니다. 모델 이름과 드라이버는 판매자마다 다릅니다. Social Stream의 실제 개발 테스트에는 기본 POS-58 대기열을 사용했습니다.
Epson TM-T20III더 널리 사용되는 영수증 프린터 선택지USB 모델. 80 mm 용지와 포함된 너비 어댑터를 이용한 58 mm 용지를 지원합니다.
Brother QL-800USB 스티커 및 주소/이름 라벨직접 감열 방식, 최대 62 mm 용지, 규격 재단 또는 연속 롤, 자동 커터.
Brother QL-820NWB공유 또는 네트워크 라벨 인쇄 환경Brother의 규격 재단 및 연속 라벨과 함께 USB, Ethernet, Wi-Fi, Bluetooth를 지원합니다.
Zebra ZD220더 넓은 상품, 배송, 손목밴드 또는 내구성 라벨약 25~112 mm 용지용 USB 데스크톱 라벨 프린터. 직접 감열 및 열전사 구성이 있습니다.

이는 호환성을 보장하는 목록이 아닌 예시입니다. 구매 전에 정확한 모델에 최신 Windows 드라이버가 있고 라벨 크기를 지원하며 일반 Windows 프린터로 표시되는지 확인하세요.

이벤트 흐름으로 후원 라벨 인쇄

💰 후원 / 팁최소 금액: 10
→
🖨️ 감열 라벨 인쇄{username}
{donation}
24 pt · 굵게 · 가운데 정렬
  1. 다음을 여세요: Event Flow 편집기 를 열고 흐름을 만드세요.
  2. 추가할 항목: 후원 / 팁 (Donation / Tip) 트리거를 추가하세요. 설정할 항목: 최소 금액 (Minimum Amount) 으로 큰 후원만 인쇄하도록 제한할 수 있습니다.
  3. 추가: 감열 라벨 인쇄 (Print Thermal Label) 를 통합에서 추가하고 트리거를 연결하세요.
  4. 라벨 텍스트를 다음으로 설정하세요: {username}로 설정하고 줄을 바꾼 뒤 {donation}를 입력하세요. 글꼴 크기, 굵기, 정렬, 매수를 선택하세요.
  5. 보통 동작의 프린터 및 고정 길이 재정의 값을 비우거나 0으로 두어 전역 프린터 제어 설정이 적용되게 하세요.
  6. 열기 흐름 테스트 (Test Flow)를 열고 이름을 입력한 뒤 다음을 활성화하세요: 후원 금액 (Has Donation)를 활성화하고 금액을 입력한 뒤 테스트를 실행하세요. 독립 실행형 앱에서는 실제 인쇄 작업이 전송됩니다.

그 밖의 유용한 자리표시자: {message}, {source}, {donationAmount}, 그리고 {counterValue}등이 있습니다. 앞선 노드에서 만든 값도 인쇄 템플릿에 사용할 수 있습니다.

구매자는 굵게, 상품은 보통으로

선택: 굵기 → 선택한 텍스트 (**bold**) (Weight → Selected text (**bold**))를 선택한 뒤 다음을 입력하세요:

**{username}**
{subtitle}

중괄호는 한 겹으로 사용하세요. 최근 커머스 통합은 상품 제목을 다음에 넣습니다: subtitle에 저장합니다. 수량은 {meta.commerce.quantity}로 제공될 수 있습니다. 앞선 노드가 다음 값을 만든다면 buyer에서 다음을 사용하세요: **{buyer}** 를 대신 사용하세요. Shopify와 eBay는 구매자 신원을 제외하므로 해당 소스에는 로컬 주문 카운터나 상품 전용 태그를 사용하세요. 텍스트를 감싸는 표시: ** 로 감싼 텍스트만 굵게 표시되며 사용자 지정 JavaScript나 HTML은 필요하지 않습니다. 기존 All bold 및 Normal 라벨은 서식을 유지합니다.

판매에는 Event Type과 다음을 사용하세요: purchase를 사용하세요. Donation / Tip에는 hasDonation 가 필요하므로 대부분의 판매와 일치하지 않습니다. 사용할 값: gift 또는 giftfunded 를 완료된 선물 라벨에 사용하고 필요하면 제공업체를 필터링하세요. 방송 중 연속 주문 번호를 사용하려면 인쇄 동작 앞에 카운터를 추가하세요. 참고: 커머스 이벤트 필드.

동작이 제공하는 값: meta.thermalPrintResult.success 및 이후 흐름 단계에서 사용할 선택적 오류/코드를 제공합니다. 성공은 작업이 제출되었다는 뜻이지 종이가 나왔다는 뜻은 아닙니다. 결과가 불확실한 작업을 재시도하기 전에 Windows 대기열을 확인하여 중복 라벨을 피하세요.

카운터는 고유 구매자가 아닌 구매 건수를 셉니다. 같은 구매자의 모든 구매에 같은 ID를 재사용하려면 별도의 구매자-ID 매핑과 방송 시작 시 명시적인 초기화가 필요합니다. 사용자 기억의 reason 필드는 설명 텍스트이며 전용 구매자 ID 카운터가 아닙니다.

Whatnot 상품 라벨

Whatnot 예제 흐름 다운로드하세요. 구매자는 굵게, 상품 이름과 제공된 주문 ID도 인쇄합니다. 결제 실패 알림은 별도의 결제 실패 라벨을 해당 알림에 있는 정보와 함께 인쇄합니다.

  1. 독립 실행형 앱에서 다음을 설정하세요: 프린터 제어 에서 프린터와 용지 크기를 설정하고 정렬 테스트를 실행하세요.
  2. 다음을 여세요: Event Flow 편집기에서 다음을 선택하세요: 가져오기 (Import)를 선택하고 다운로드한 JSON 파일을 선택하세요.
  3. 선택: Whatnot: 상품 라벨 + 결제 경고 (Whatnot: Item Labels + Payment Warnings)를 선택하세요. 두 인쇄 동작을 모두 검토하세요. 전역 프린터와 라벨 길이를 상속합니다.
  4. 흐름을 활성화하고 저장하세요. 방송 이벤트 캡처를 활성화한 상태로 Whatnot 소스를 열어 두세요.

예제는 비활성 상태로 가져옵니다. 사용하는 항목: 이벤트 유형(고급) → 사용자 지정 이벤트 (Event Type (Advanced) → Custom Event) 대상: product_sold 그리고 payment_failed에 사용하며 Whatnot 소스 필터를 적용합니다. 입찰과 경매 종료 알림은 라벨을 인쇄하지 않습니다.

판매 라벨은 결제를 확인하지 않습니다. 이 예제는 알림이 도착할 때마다 인쇄하며 결제를 기다리거나 이전 라벨을 수정하거나 구매자 번호를 부여하지 않습니다. 누락된 필드는 비워 인쇄합니다. 구매자, 상품, 주문 정보가 없는 실패 알림으로는 이전 라벨을 식별할 수 없습니다. 참고: Whatnot 이벤트 필드.

예상대로 출력하는 고정 길이 라벨

3 × 1인치 라벨(Munbyn BT320 설정 포함): 1인치 쪽이 공급 방향이면 너비 76.2 mm, 고정 길이 25.4 mm를 사용하세요. Windows 인쇄 기본 설정에서 용지와 방향을 맞추세요. 12~14 pt 텍스트로 시작하고 긴 구매자 이름과 상품 이름으로 시험하세요.

정렬 테스트의 양쪽 테두리는 선택한 인쇄 가능 영역 설정과 안전 여백을 적용한 뒤의 안전 너비를 표시합니다. 상자 높이는 테스트 텍스트에 따라 정해지며 전체 라벨의 윤곽이나 실제 종이 가장자리를 표시하지 않습니다.

  • 용지 공급 방향으로 측정하세요. 62 × 29 mm 라벨은 보통 용지 너비 62 mm, 고정 라벨 길이 29 mm를 사용합니다.
  • Windows 설정도 맞추세요. 프린터 드라이버의 인쇄 기본 설정에서 정확한 라벨 용지, 방향, 간격/마크 감지, 커터 동작을 선택하세요.
  • 고정 길이는 그대로 유지됩니다. Social Stream은 고정 길이 작업에 영수증 배출 여백을 추가하지 않습니다. 내용이 너무 길면 드라이버에 따라 잘리거나 다음 장으로 넘어갈 수 있습니다.
  • 실제로 사용할 가장 긴 데이터로 시험하세요. 긴 시청자 이름, 상품 옵션, 통화 표시, 여러 줄 텍스트에는 더 많은 공간이나 더 작은 글꼴이 필요합니다.
  • 드라이버 제한은 여전히 적용됩니다. Windows나 프린터 드라이버가 너무 짧은 사용자 지정 페이지 길이를 제한할 수 있습니다. Social Stream은 최소 20 mm를 요청합니다.

방송 아이디어

  • 벽, 소품, 지도 또는 실제 진행 보드에 붙일 후원자 이름 스티커를 인쇄하세요.
  • 구매가 들어올 때 상품 주문, 커미션, 음료 또는 수령 태그를 만드세요.
  • 인쇄 동작 전에 빈도 제한과 자격 확인을 거쳐 추첨 티켓이나 경품 추첨 참가권을 인쇄하세요.
  • VIP 배지, 팀 배정, 도전 토큰 또는 후원 목표 달성 라벨을 만드세요.
  • 방송자 옆에서 일하는 제작자를 위해 짧은 관리 또는 주문 처리 대기열을 인쇄하세요.
개인정보를 인쇄하기 전에 생각하세요. 주소, 이메일, 결제 정보, 비공개 메시지는 피하세요. 감열지는 열, 빛, 시간이 지나면 바래므로 장기 보관용으로 적합하지 않습니다.

일반적인 해결 방법

  • 프린터가 나타나지 않음: Windows에서 테스트 페이지가 인쇄되는지 확인한 뒤 Social Stream을 다시 시작하고 프린터 찾기를 다시 선택하세요.
  • 작업이 성공했다고 하지만 아무것도 인쇄되지 않음: 해당 프린터의 Windows 대기열을 열고 일시 중지, 오프라인, 용지, 드라이버, 포트 오류를 확인하세요.
  • 가장자리가 잘림: 인쇄 가능 영역 사용을 켠 채 해당 방향의 안전 여백을 늘리세요.
  • 빈 종이가 너무 많이 나옴: 영수증에는 고정 길이 0을 사용하고 아래 여백과 배출량을 줄이거나 라벨 용지의 정확한 길이를 설정하세요.
  • 라벨 하나가 두 장으로 나뉨: 내용이 고정 라벨보다 길거나 Windows에서 잘못된 용지 크기를 사용 중입니다. 텍스트, 글꼴 크기, 줄 간격, 여백을 줄이세요.
  • 흐름 테스트에서 잘못된 프린터를 사용함: 감열 라벨 인쇄 노드에서 프린터 재정의 값을 선택하세요. 편집기에서 직접 시험할 때 재정의 값이 비어 있으면 Windows 기본 프린터를 사용합니다.
