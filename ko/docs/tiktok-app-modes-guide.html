TikTok 앱 모드

먼저 Auto를 사용하고 상태 문구에서 안내할 때만 모드를 변경하세요.

간단하게 시작하기

데스크톱 앱에 TikTok을 추가하고, 특정 오류를 해결하는 경우가 아니라면 프리셋을 Auto로 유지하세요.

모드 선택

모드사용할 때주의할 사항
자동일반적인 첫 설정.앱이 여러 대체 연결 상태로 전환될 수 있습니다.
표준 (Standard)표시되는 페이지 캡처나 수동 로그인/인증이 필요할 때.리디렉션, CAPTCHA, 숨겨진 채팅, 잘못된 라이브 URL.
로컬 서명기 (Local Signer)앱 자체의 읽기 기능이나 답변 지원 경로가 필요할 때.앱 내 TikTok 세션/쿠키가 유효해야 합니다.
호환성(WebSocket)호환성 커넥터 설정을 시험할 때.이전 명칭은 Polling입니다. 현재 앱에서도 서명이 필요하며 답장을 보낼 수 없습니다. 다음을 참고하세요: 서명 안내.
프록시/사용자 지정 서명제공업체/API 키가 필요한 고급 설정입니다.제공업체 제한, 방 ID, 서명 오류, 요청 속도 제한.

실패 시 수집할 정보

  • 데스크톱 앱 버전과 베타 모드 활성화 여부.
  • 현재 선택한 TikTok 프리셋/모드.
  • 앱에 표시된 정확한 상태 문구나 오류 메시지.
  • 앱 안에서 TikTok 계정에 로그인했는지 여부.
  • Standard 모드의 라이브 페이지에 채팅이 보이는지 여부.
  • OBS를 테스트하기 전에 도크에 수신되는 내용이 있는지 여부.

지원 사이트 확인

기본적인 브라우저 확장 프로그램 TikTok 설정은 공개 TikTok 설정 안내부터 확인하세요.

일반적인 해결 방법

  • Auto가 실패할 때: Standard를 사용해 페이지 표시와 로그인이 정상인지 확인하세요.
  • Standard가 다른 페이지로 이동할 때: 캡처 페이지를 표시하고 사용자 이름/라이브 URL을 확인한 뒤 요청이 나오면 TikTok 인증을 완료하세요.
  • 답변이 실패할 때: TikTok 세션/쿠키와 현재 모드의 답변 전송 지원 여부를 확인하세요.
  • 메시지가 중복되거나 누락될 때: 중복된 TikTok 소스 창/탭을 닫고 모드를 하나씩 테스트하세요.
