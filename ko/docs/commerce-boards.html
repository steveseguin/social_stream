배정 보드 및 최근 판매

이용 가능한 칸을 추적하고 최근 구매를 화면에 유지하세요. SSN에서 제어하고 OBS에 표시합니다.

칸 공개 ↓팀 보드 ↓최근 판매 ↓Whatnot / eBay Live ↓

배정 보드

번호 칸

샘플 미리보기 열기 ↗
  1. 보드 만들기다음 위치에서: Monetization → Spot boards & recent sales, 번호 타일을 선택하세요. 20 × 6 격자를 만들려면 칸 120개와 열 20개를 사용하세요.
  2. 배정 표시타일을 선택한 다음 이 칸의 판매 기록 를 결제 확인 후 선택하세요. 사용: 배정 완료만 표시 를 사용하면 판매 항목 없이 예약할 수 있습니다.
  3. 상품 공개배정된 상품을 입력하고 다음을 선택하세요: 공개. 사용: 이용 가능으로 변경 로 칸을 수정하거나, 환불 및 다시 열기 로 연결된 판매도 제거하세요.

SSN은 배정 결과를 표시합니다. 칸을 판매하거나 경품을 무작위로 배정하지 않습니다.

이름이 있는 칸

팀 브레이크

팀 브레이크는 개봉한 카드를 팀, 선수 또는 이름이 지정된 다른 구분에 따라 나눕니다.

  1. 선택: 팀 타일.
  2. 팀 이름을 한 줄에 하나씩 붙여넣으세요. 이 목록으로 칸 수가 결정됩니다.
  3. 구매된 각 칸을 배정 완료로 표시하세요. 준비되면 공개하세요.
팀 미리보기 열기 ↗

배정은 진행자가 제어합니다. SSN은 채팅 메시지나 경매 종료로 팀 구매를 추론하지 않습니다.

Whatnot 또는 eBay Live 방송 중

  1. 방송 캡처SSN에서 방송을 열고 다음을 활성화하세요: 방송 이벤트 캡처. Whatnot은 경매 하단 영역이 보이는 방송 보기가 필요합니다. eBay Live는 채팅 또는 방송 페이지를 지원합니다.
  2. 판매 확인다음 항목 아래에서: 최근 판매, 다음에서 Whatnot 또는 eBay Live를 선택하세요: 경매 상품 도우미 그리고 저장하세요. 경매 상품 사용 은 마지막으로 캡처한 이름을 복사합니다. 판매 플랫폼에서 상품과 결제를 확인한 다음 판매 총액과 통화를 입력하세요.
  3. 확인 후 공개칸의 경우 해당 타일을 선택하고 다음을 선택하세요: 이 칸의 판매 기록 를 먼저 완료하세요. 판매 확인 및 칸 배정 는 둘을 함께 기록합니다. 배정된 상품을 보여줄 준비가 되면 공개할 텍스트를 추가하세요.

도우미는 운영자용 초안입니다. 입찰이나 경매 종료를 판매로 전환하지 않습니다. 새로운 경매 업데이트는 초안을 바꾸지 않습니다. 활성화: 최근 판매 표시 를 활성화해 시청자 표시 화면을 선택하세요. 보드와 판매를 모두 표시하려면 별도 OBS 소스를 사용하세요.

환불하려면 다음을 사용하세요: 환불 및 다시 열기 를 연결된 판매에 사용하면 판매를 제거하고 칸을 다시 이용 가능하게 합니다. 제거 는 판매 항목만 제거합니다. 교체한 보드는 이전 보드의 판매와 별도로 유지됩니다.

실시간 캡처와 스토어 연결 비교

Whatnot과 eBay Live 캡처는 상품, 입찰, 경매 상태를 제공합니다. 별도의 eBay 판매자 연결 은 선택한 등록 상품의 결제 완료 주문 이벤트를 받아 최근 판매를 자동으로 채울 수 있습니다. 스토어 연결이 이미 기록한 구매를 수동으로 다시 확인하지 마세요. 다른 자동 소스로는 Shopify, Fourthwall, Ko-fi, Buy Me a Coffee가 있습니다.

도우미는 선택한 플랫폼에서 마지막으로 캡처한 상품만 유지하며, 업데이트 없이 5분이 지나면 만료되고 재시작 시 지워집니다. 여러 방송을 열었다면 상품을 확인하세요. 도우미가 비어 있으면 활성화한 뒤 새 경매 업데이트가 필요합니다.

eBay: 판매자 콘솔에서 결제 상태 확인 · Whatnot: 경매 결제 실패

켜기: 최근 판매 표시 그리고 연결된 스토어 구매 수집, 그런 다음 판매 옵션을 저장하세요.

SSN이 받은 새로운 Shopify, eBay 판매자, Fourthwall, Ko-fi, Buy Me a Coffee의 purchase 이벤트를 사용합니다.

직접 판매 확인

상품과 선택적으로 판매 총액 및 통화를 입력하세요. 선택: 판매 확인.

구매를 확인한 뒤 Whatnot, eBay Live 또는 대면 판매에 유용합니다. 이 행에는 다음이 표시됩니다: 진행자 확인.

수정 및 환불

잘못 입력했거나 환불된 판매를 제거하세요. 새 방송을 시작하려면 월을 비우세요.

입찰, 팁, 선물, 샌드박스 테스트는 여기에 추가되지 않습니다. 보드 칸 배정은 판매를 생성하지 않습니다.

가격, 기록, 개인정보 보호

연결된 구매 피드에서 상품 가격이 항상 제공되지는 않으므로 자동 행은 가격을 비워 둡니다. 알고 있는 가격을 표시하려면 해당 행을 제거한 뒤 수동으로 확인하세요. 여러 상품이면 개별 가격이 아니라 해당 항목의 총액을 입력하세요. 등록 가격, 최고 입찰액, 후원 금액으로 대신 채우지 않습니다.

SSN은 재시작 후에도 이 설치 환경의 최근 항목 100개를 유지합니다. 수집은 활성화한 시점부터 시작되며 전체 주문 기록을 가져오는 기능이 아닙니다. 저장된 ID 2,000개 범위 내에서는 중복 전달 ID를 무시합니다. 환불은 수동으로 제거해야 합니다.

구매자 이름, 주소, 결제 정보, 아직 공개하지 않은 상품 텍스트는 이 화면에 포함되지 않습니다. 데모 링크는 가상임을 명확히 표시한 데이터를 사용합니다.

OBS 설정

  1. 표시 방식 선택보드 제어에서 배정/팀 보드, 최근 판매 목록, 월 또는 띠를 선택하세요.
  2. OBS 링크 복사1920 × 1080 브라우저 소스를 추가하세요. 투명한 공간으로 카메라가 보입니다.
  3. SSN에서 제어SSN을 켜 두세요. 변경 사항은 즉시 저장됩니다. 다음 도구: OBS 상품 제어 도크 에도 같은 제어가 있어 원하면 사용할 수 있습니다.
선택적 URL 설정

&view=board, sales, wall 또는 ticker 로 레이아웃을 선택합니다. &limit=6 는 최근 항목을 최대 6개 표시합니다(최댓값 24개). &prices=0 로 가격을 숨깁니다. &label=Recently%20sold 로 판매 제목을 설정합니다. &onlytype=shopify,ebay 로 판매 소스를 필터링합니다.

복사한 링크의 세션, 비밀번호, 릴레이 설정을 유지하세요. 연결이 없거나 표시할 내용이 없으면 투명하게 유지되며, 설정 메시지는 시청자 오버레이에 나타나지 않습니다.

API 및 Event Flow 통합

이 제어는 기존의 commerceControl API를 확장합니다. SSN, Stream Deck 사용자 지정 API 동작, 선택적 OBS 도크는 모두 같은 다음 응답을 읽습니다: getCommerceState 응답.

{"action":"commerceControl","value":{"command":"boardSpot","data":{"id":"12","status":"claimed"}}}

명령: boardSave (title, style, columns, count 또는 줄바꿈으로 구분한 labels), boardSpot (id, status, result), boardVisibility (visible), saleAdd (title, 선택적 amount/currency/quantity/platform; 칸을 배정하려면 선택적 boardId와 spotId), saleRemove (id, 선택적 reopenSpot), salesClear, 그리고 salesSettings (visible, automatic, 선택적 auctionSource: whatnot, ebay 또는 빈 문자열). 이 필드들을 다음에 넣으세요: data. 이 수정으로 구매 이벤트가 발생하거나 유료 보상이 실행되지는 않습니다.

다음 위치에서: Event Flow, 기존의 다음 동작을 사용하세요: 상품 및 후원 동작을 사용하세요. 보드 또는 판매 명령을 선택하고 다음에 해당 필드를 입력하세요: 보드/판매 필드. 문자열 값에는 다음과 같은 변수를 사용할 수 있습니다: {subtitle}. 판매 동작에는 확인된 구매 이벤트를 조건으로 사용하세요. 흐름에서 같은 판매를 수동으로 추가한다면 자동 수집을 끄세요.
