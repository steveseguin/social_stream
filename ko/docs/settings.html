설정 참고 문서

Social Stream Ninja 팝업의 모든 스위치, 텍스트 입력란, 드롭다운을 설명 및 적용 범위와 함께 살펴보세요.

팝업 제어 항목 목록과 오버레이 URL 매개변수 색인 사이를 전환하세요. 두 화면 모두 같은 설정 데이터를 사용해 일관성을 유지합니다.

이 페이지는 다음에서 최신 데이터를 불러옵니다: popup.html . 확장 프로그램과 데스크톱 앱의 변경 사항을 반영합니다. 검색란으로 키워드를 찾거나 다음 위치의 설정 정의 파일을 여세요: shared/config/settingsDefinitions.js 에서 설명과 적용 범위를 보완하세요.

채팅 참여자마다 다른 색상을 지정하고 싶으신가요? 다음을 참고하세요: 채팅 이름 색상 가이드. 일반 색상 옵션과 도크 표시 스위치를 모두 활성화해야 합니다.

popup.html에서 설정을 불러오는 중…

쿼리 문자열로 오버레이를 조정하고 싶으신가요? 화면과 카테고리별로 정리한 전체 URL 옵션을 살펴보세요. 데이터 생성 원본: parameters.md . 다음을 통해 내보냅니다: shared/config/urlParameters.js . 문서와 앱 내 도움말에서 활용할 수 있습니다.

URL 매개변수 색인 불러오는 중…

설명이 빠졌거나 오래된 내용을 발견했나요? 다음을 편집해 참고 문서를 업데이트하세요: shared/config/settingsDefinitions.js 또는 GitHub에 이슈를 등록하세요.
