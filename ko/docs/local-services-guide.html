로컬 서버 및 서비스 설명

Social Stream Ninja는 여러 로컬 서비스를 사용합니다. 원하는 작업에 맞는 서비스를 선택하세요.

모니터 없이 Linux 홈 서버 또는 VPS에서 전체 데스크톱 앱 실행 헤드리스 SSApp 호스팅 새로운 공개 API는 없습니다. 원격 제어는 일반 Social Stream 세션을 사용합니다.
승인된 로컬 오디오, 이미지 또는 동영상 파일을 이벤트 흐름에서 재생 로컬 미디어 서버 http://127.0.0.1:3001

1. 로컬 서버 활성화

File 메뉴의 이 옵션은 데스크톱 앱 안에서 방과 채널을 구분하는 WebSocket 릴레이를 시작합니다. 지원되는 Social Stream 페이지는 같은 컴퓨터에서 채팅과 명령을 교환하는 데 이를 사용할 수 있습니다. 페이지별 서버 라우팅을 위한 대체 엔드포인트입니다.

Social Stream 웹사이트를 호스팅하거나 자체적으로 플랫폼을 캡처하거나 HTTP 자동화 API를 제공하지는 않습니다. 다음 가이드부터 보세요: 로컬 서버 활성화 가이드.

2. 로컬 제어 API 및 MCP

이 선택적 루프백 API를 통해 SSApp 컴퓨터의 프로그램은 지원되는 소스와 설정을 관리하고, 상태와 진단 정보를 읽고, 앱 또는 소스 창을 검사하고, 캡처한 이벤트를 구독할 수 있습니다. 내장 MCP 어댑터는 이러한 작업을 호환 AI 클라이언트에 도구로 제공합니다.

다음 메뉴에서 활성화하세요: 파일 > 로컬 AI / 자동화(File > Local AI / Automation)입니다. 다음과는 별개입니다: 로컬 서버 활성화 (Enable Local Server). 참고: 로컬 제어 API 및 MCP 가이드.

3. 헤드리스 홈 서버 또는 VPS

헤드리스 모드는 소스 창을 숨긴 상태로 전체 Electron 데스크톱 앱을 실행합니다. Linux에서는 여전히 Xvfb 같은 디스플레이 백엔드가 필요합니다. 모니터 없이 전용 컴퓨터에서 채팅을 계속 캡처하려는 경우에 유용합니다.

헤드리스 모드는 공개 제어 API를 만들지 않습니다. 원격 제어는 Social Stream의 일반 WebRTC 또는 WebSocket 전송 방식을 사용합니다. 참고: 헤드리스 호스팅 가이드.

4. 로컬 미디어 서버

로컬 이벤트 흐름 미디어를 사용할 수 있으면 데스크톱 앱이 이 서버를 자동으로 시작합니다. 프로필별 임의 토큰 경로를 통해 SSApp에서 승인된 파일과 일부 런타임 리소스만 제공합니다.

일반 웹 서버나 파일 서버가 아닙니다. 참고: 이벤트 흐름용 미디어 파일 에서 로컬 파일, 업로드, 클라우드 호스팅 중 선택하세요.

서버 폴백은 별개입니다

다음과 같은 설정은 API 서버로 채팅 메시지 전송 (Send chat messages to API server) 그리고 도크가 서버를 통해 확장 프로그램에 명령 전송 (Dock sends its commands to Extension via server) 채팅과 명령의 라우팅 방식을 선택합니다. 생성되는 URL 플래그에는 다음이 포함됩니다: server, server2, 그리고 server3.

이 설정들은 일반적으로 Social Stream의 호스팅 WebSocket 서비스를 사용합니다. 지원되는 페이지에 다음도 있으면 localserver가 있으면 데스크톱 앱의 로컬 릴레이를 대신 사용합니다. 참고: 세션, 비밀번호, 릴레이 및 서버 모드 에서 라우팅 제어를 확인하세요.

새로 생성한 링크를 사용하세요. 라우팅 플래그는 페이지마다 다릅니다. 한 페이지의 서버 플래그를 다른 페이지에 복사하고 의미가 같다고 가정하지 마세요.

기타 임시 로컬 포트

일부 로그인 및 계정 연결 절차는 잠시 루프백 콜백 포트를 열었다가 절차가 끝나면 닫습니다. 이러한 임시 수신기는 일반 SSN 서버나 자동화 API가 아닙니다.
