방송에 오버레이 사용

Social Stream Ninja의 세션 ID를 입력한 뒤 다음을 선택하세요: 오버레이 열기 를 카드에서 선택하세요. 링크를 OBS 브라우저 소스에 복사하세요. 강조 오버레이는 도크에서 선택한 메시지를 표시하며 다중 알림은 수신 이벤트를 표시합니다.

어울리는 세트

각 링크를 별도 OBS 브라우저 소스로 추가하세요. 강조 메시지는 도크에서 선택하며 알림은 수신 이벤트에 반응합니다.

이 입력란의 값은 이 페이지에만 머무르며 저장되지 않습니다. 서버 모드, 필터, 자동 숨김 및 기타 옵션은 앱의 해당 프리셋을 사용하세요.

일치하는 오버레이가 없습니다. 다른 검색어를 입력하거나 모든 오버레이를 선택하세요.
