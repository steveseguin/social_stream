자주 찾는 도움말

문제에 맞는 가이드부터 시작하세요

  • 지식 베이스빈 오버레이, 잘못된 세션, OBS 오디오, TikTok, YouTube, 봇에 대한 짧은 답변.
  • OBS 빠른 시작세션, 도크 링크, 오버레이 링크, 첫 OBS 브라우저 소스.
  • OBS 문제 해결저장된 URL 교체, 브라우저 소스 캐시 새로고침, 빈 오버레이 진단을 안내합니다.
  • Windows 관리자 모드OBS와 Social Stream 간 권한 불일치가 확인된 경우에만 해당합니다.
  • 플랫폼 설정 선택기팝아웃 채팅, 스위치 활성화가 필요한 페이지, 앱 소스 창 또는 소스 페이지를 선택하세요.
  • AI 챗봇 설정제공업체 연결, 기본 봇 제어, 안전한 라이브 테스트, 답장 라우팅, 흔한 실패.
  • 자주 쓰는 해결 방법누락된 채팅, 빈 오버레이, 플랫폼 스위치, 권한 확인.
  • 고급 지원 자료지원 절차와 AI 에이전트를 위한 자세한 안내 경로.

기능 요청

새 플랫폼이나 기능 지원이 필요한가요? 알려 주세요!

Social Stream Ninja는 이미 100개 이상의 플랫폼을 지원하지만 커뮤니티 수요에 따라 더 추가할 수 있습니다. 새 플랫폼 통합이나 기능을 요청하려면:

  1. 이미 지원되는지 다음에서 확인하세요: 지원 플랫폼 목록
  2. 참여할 곳: Discord 커뮤니티 에 참여하여 #feature-requests 채널에 게시하세요
  3. 또는 다음을 만드세요: GitHub 이슈 에 요청의 자세한 내용을 적어 주세요

참고: 요청된 모든 플랫폼을 지원할 수는 없습니다. 사용자 수가 많고 기술적으로 통합할 수 있는 플랫폼을 우선합니다.

자주 묻는 지원 질문

대개 브라우저 성능 제한 때문에 발생합니다. 다음 해결 방법을 시도하세요:

  • 브라우저 성능 제한 비활성화: 다음으로 이동하세요: chrome://flags/#enable-throttle-display-none-and-visibility-hidden-cross-origin-iframes 로 이동하여 'Disabled'로 설정하세요
  • 다음도 비활성화하세요: chrome://flags/#calculate-native-win-occlusion
  • 브라우저 확장 프로그램 대신 독립 실행형 데스크톱 앱을 사용해 보세요

파란색 디버깅 바가 보이거나 자동 응답이 작동하지 않는다면:

  • 팝아웃 채팅 창이 열려 있고 보이는지 확인하세요
  • Firefox 대신 Chromium 기반 브라우저(Chrome, Edge, Brave)를 사용해 보세요
  • 플랫폼에서 채팅할 권한이 있는지 확인하세요(일부는 구독 필요)
  • Chrome을 다음으로 시작하세요: --silent-debugger-extension-api 플래그로 파란색 바를 숨기세요

보안상의 이유로 Discord, Slack, Telegram, WhatsApp, Google Meet은 확장 프로그램 메뉴 설정에서 해당 스위치를 켜야 합니다.

사용하려는 각 플랫폼의 지원 스위치를 켜고 다음을 확인하세요: 고급 기능 가이드 에서 자세한 내용을 확인하세요.
