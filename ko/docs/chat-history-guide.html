채팅 기록과 충성도 포인트

로컬 메시지 저장이 기록, 포인트, 시청자 인식에 미치는 영향.

모든 가이드 로컬 기록 포인트가 작동하도록 유지하기 기존 메시지 기록

로컬 메시지 데이터베이스의 역할

SSN은 메시지를 캡처하는 브라우저 또는 데스크톱 설치 환경의 데이터베이스에 캡처한 메시지를 저장합니다. 채팅 기록 페이지는 이 데이터베이스로 이전 메시지를 조회합니다.

다음 항목: 로컬 메시지 데이터베이스 비활성화 설정은 새 메시지 저장을 중단합니다. 실시간 캡처와 도크 표시는 계속될 수 있으므로 도크에서 메시지가 보인다고 기록이 저장되는 것은 아닙니다.

첫 채팅 참여자 감지와 기록을 바탕으로 한 시청자 인식도 로컬 데이터베이스에 의존합니다.

충성도 포인트가 작동하도록 유지하기

포인트 적립과 다음 명령의 처리: !points, !leaderboard 그리고 !rewards 는 캡처한 메시지가 저장될 때 실행됩니다. 로컬 메시지 데이터베이스를 비활성화하면 포인트 옵션이 켜져 있어도 이 처리가 중단됩니다.

  1. 찾기: 로컬 메시지 데이터베이스 비활성화 옵션을 SSN 설정에서 찾아 꺼진 상태로 두세요.
  2. 다음 위치에서: 포인트 시스템에서 충성도 포인트와 사용할 채팅 명령을 활성화하세요.
  3. 시청자에게 메시지를 보낸 다음 아래 명령을 보내도록 요청하세요: !points. 올바른 플랫폼의 계정을 확인하세요.

잔액은 메시지 기록과 별도로 저장됩니다. 백업에는 다음을 사용하세요: 포인트 시스템 → 백업 및 복원 → 포인트 내보내기 (Points System → Backup & Restore → Export Points) . 다른 설치 환경과 세션 ID를 공유해도 두 데이터베이스 중 어느 것도 동기화되지 않습니다.

다음을 참조하세요: 충성도 포인트 안내 에서 적립, 순위, 보상, 백업을 확인하세요.

기존 기록의 사용 방식

포인트 원장이 비어 있고 아직 초기화되거나 재설정된 적이 없다면 SSN이 저장된 채팅 기록으로 초기 포인트를 계산할 수 있습니다. 잔액을 초기화하기 위해 한 번 실행됩니다.

과거 참여에도 실시간 적립 규칙이 적용됩니다. 조건에 맞는 첫 참여는 기본 포인트를 받고, 이후 참여는 연속 참여 보너스를 받을 수 있습니다. 사용 가능한 메시지 기록만 반영할 수 있으므로 설치 환경을 이전하거나 복구할 때 포인트 내보내기 파일을 보관하세요.
