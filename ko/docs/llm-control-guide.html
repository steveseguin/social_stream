로컬 제어 API 및 MCP

같은 컴퓨터의 AI 도구나 스크립트가 Social Stream Ninja 데스크톱 앱을 확인하고 제어하도록 합니다.

이 서비스가 필요한 경우1. 일반 데스크톱 앱 다운로드2. 로컬 AI 제어 활성화3. MCP가 기능을 탐색하도록 설정사용 가능한 로컬 제어로컬 스크립트의 직접 HTTP 접근로컬 전용

이 서비스가 필요한 경우

데스크톱 앱→로컬 제어 API→MCP 클라이언트

SSApp 컴퓨터의 소프트웨어가 승인된 앱 및 소스 제어를 필요로 할 때 로컬 제어 API를 사용하세요. 호환 AI 클라이언트가 이 제어 기능을 도구로 받아야 할 때 내장 MCP 어댑터를 사용하세요.

이는 다음 기능과 별개입니다: File > Enable Local Server와 다릅니다. 이 기능은 Social Stream 페이지용 WebSocket 릴레이를 시작합니다. 참고: 로컬 서버 및 서비스 설명 에서 어떤 서비스가 필요한지 확인하세요.

1. 일반 데스크톱 앱 다운로드

최신 Social Stream Ninja 릴리스를 다음에서 설치하세요: Windows, macOS 또는 Linux 다운로드입니다. 다운로드한 앱에 MCP 지원이 포함되어 있습니다. 소스 저장소, Node, Python 또는 별도의 MCP 패키지는 필요하지 않습니다.

2. 로컬 AI 제어 활성화

  1. 열기 파일 > 로컬 AI / 자동화(File > Local AI / Automation).
  2. 활성화 로컬 제어 API 을 선택하고 앱이 다시 시작되도록 하세요.
  3. 같은 메뉴로 돌아가 다음을 선택하세요: MCP 설정 복사 (Copy MCP Setup).
  4. 복사한 JSON을 AI 도구에서 사용하는 MCP 설정에 붙여 넣고 도구를 다시 시작하세요.

복사한 설정에는 설치된 실행 파일의 정확한 경로, 포트, 플랫폼별 인수가 포함됩니다. AI 클라이언트가 다음 인수로 실행하면 다운로드한 Social Stream Ninja 실행 파일이 자체 경량 MCP 어댑터를 시작합니다: --ssapp-mcp.

3. MCP가 기능을 탐색하도록 설정

연결되면 MCP 클라이언트가 Social Stream Ninja에 도구 목록을 자동으로 요청합니다. 어댑터는 실행 중인 앱의 현재 기능을 읽고 지원되는 도구 스키마, 앱/API 버전, 사용 지침을 LLM에 제공합니다. 에이전트는 먼저 capabilities를 호출한 뒤 status를 호출하고, 앱이 반환한 안정적인 소스 ID를 사용해야 합니다.

일반적인 MCP 사용에는 웹사이트 스크래핑이나 스킬 설치가 필요하지 않습니다. 사용자는 연결된 에이전트에게 Social Stream Ninja를 확인하거나 제어해 달라고 요청하면 됩니다.

사용 가능한 로컬 제어

  • 소스를 나열, 검사, 추가, 업데이트, 제거합니다.
  • 소스 하나 또는 필터로 선택한 여러 소스를 시작, 중지, 다시 로드합니다.
  • 소스 표시 여부, 음소거 상태, 연결 모드를 변경합니다.
  • 기능 탐색에서 반환한 지원되는 전역 설정을 읽고 업데이트합니다.
  • 앱, 세션, 소스, 프로세스, 캡처, 로컬 미디어 상태를 읽습니다.
  • 범위가 제한된 캡처 소스 이벤트와 재개 가능한 작업 또는 상태 이벤트를 구독합니다.
  • 지원되는 소스 페이지와 SSApp 소유 창을 캡처하고 안전하게 검사합니다.
  • 확인을 거쳐 승인된 페이지, 창, 대화상자 상호작용을 수행합니다.
  • 명시적인 확인을 거쳐 앱을 다시 로드하거나 정상 종료합니다.

실행 중인 앱이 제공하는 기능이 기준입니다. 이전 버전에서는 더 적은 제어 기능이 제공될 수 있습니다.

로컬 스크립트의 직접 HTTP 접근

같은 컴퓨터의 스크립트는 MCP 없이 루프백 API를 사용할 수 있습니다. 수신 주소는 다음으로 한정됩니다: 127.0.0.1 이며 토큰은 필요하지 않습니다.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

모든 앱 버전에 같은 제어 기능이 있다고 가정하지 말고 앱이 제공하는 기능을 사용하세요. 복사해서 사용할 수 있는 curl 예제로 소스를 추가, 나열, 시작, 검사, 중지하려면 다음을 참고하세요: 서버 HTTP API 단계별 안내.

Ubuntu VPS의 로컬 AI

이 API는 헤드리스 SSApp 인스턴스와 같은 Linux 서버에서 실행되는 AI 도구에도 사용할 수 있습니다. 루프백에 바인딩한 상태를 유지하고 다운로드한 AppImage를 MCP 명령으로 사용하세요.

팔로우 Social Stream Ninja 헤드리스 실행 에서 Xvfb, 영구 프로필, 시작 명령, systemd 및 별도의 원격 제어 방식을 확인하세요. 여기에는 다음도 포함됩니다: Linux AppImage MCP 구성 을 VPS에서 실행 중인 클라이언트에 붙여 넣을 수 있습니다.

선택 사항: 에이전트 스킬

설치형 스킬을 지원하는 에이전트는 다음을 이용할 수 있습니다: 전체 Control Social Stream 스킬 다운로드. 또는 다음도 가능합니다: 온라인 지침 읽기, 사용 옵션: API 참고 문서 그리고 버전 기록. 스킬은 작업 절차 안내를 추가하지만 MCP 연결에 필수는 아닙니다.

기계가 읽을 수 있는 기능 탐색 링크는 다음에도 나와 있습니다: llms.txt.

로컬 전용

이 인터페이스는 SSApp과 같은 컴퓨터에서 실행되는 AI 및 자동화를 위한 것입니다. 이를 클라우드 원격 제어 API로 공개하거나 터널링하지 마세요. 원격 사용자와 Stream Deck은 Social Stream의 기존 WebRTC 또는 WebSocket 연결을 사용해야 합니다. 로컬 API는 임의의 JavaScript 실행, 쿠키, 로그인 비밀 정보, 무제한 설정 접근 또는 원시 파일 시스템 접근을 제공하지 않습니다.

전체 엔드포인트, 명령 스키마, 버전 탐색 및 보안 경계는 다음을 참고하세요: 기술 자동화 참고 문서.
