Event Flow 활용 예시

경품 추첨, 유료 참가권, 게임 경품, 복구 가이드

작은 예시 하나씩 따라 하며 유용한 자동화를 만드세요.

Event Flow의 용도

Stream Deck 키 또는 HTTP/WebSocket/P2P API 호출로 사용자 지정 작업 흐름 실행.

Event Flow는 고급 자동화 편집기입니다. 팝업 스위치만으로 부족할 때 채팅 필터링, 미디어 실행, 메시지 릴레이, 웹훅 호출, OBS 제어에 사용하세요.

예시를 시작하기 전

  1. 테스트 플랫폼 하나와 Social Stream 세션 하나를 사용하세요.
  2. 도크를 열고 채팅이 도착하는지 확인하세요.
  3. 열기 actions.html?session=YOUR_SESSION 를 예시가 오디오나 미디어를 재생하거나 OBS를 제어할 때 여세요.
  4. 생방송 전에 가상 메시지나 안전한 트리거로 테스트하세요.
  5. 크게 수정하기 전에 작동하는 흐름을 내보내세요.

활용 아이디어

예시트리거동작
키워드 소리메시지 포함 문자열 !hype다음에서 오디오 클립 재생: actions.html.
Kick 보상 미디어보상/채널 포인트 이벤트이미지, 동영상 또는 소리를 표시/재생하세요.
첫 채팅 참여자첫 채팅 참여자 플래그 또는 필터메시지를 강조 표시하거나 환영 오버레이를 표시하세요.
후원 알림hasDonation 또는 후원 이벤트알림 오버레이, 웹훅 또는 OBS 장면 동작으로 보내세요.
웹훅 릴레이플랫폼/유형 필터선택한 페이로드를 서비스에 POST로 보내세요.
무작위 소리 선택키워드 + RANDOM 게이트클립 두 개 중 하나를 무작위로 재생 — 참고: 편집기 가이드의 미니 흐름 D.

Kick 보상 미디어 예시

이는 가장 흔한 실용 Event Flow 패턴입니다. 보상을 감지한 뒤 Flow Actions를 통해 미디어를 재생합니다.

전체 상세 설명: Kick 보상 소리/미디어 가이드.

일반적인 해결 방법

  • 아무 일도 일어나지 않음: 먼저 소스 이벤트가 도크에 도착하는지 확인하세요.
  • 오디오나 미디어가 재생되지 않음: 유지: actions.html 를 같은 세션으로 열어 두고 다음을 확인하세요: Event Flow 미디어 호스팅 가이드.
  • OBS 동작 실패: OBS WebSocket v5, 포트 4455, 비밀번호, 권한을 확인하세요.
  • 흐름이 너무 자주 실행됨: 플랫폼, 이벤트, 키워드 또는 사용자 필터를 더 엄격하게 추가하세요.
