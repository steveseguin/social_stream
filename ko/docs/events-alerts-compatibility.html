이벤트 및 알림 호환성

일반 채팅, 후원, 이벤트 페이로드를 혼동하지 않고 캡처한 플랫폼 이벤트를 Multi Alerts에 연결하세요.

이벤트 소스부터 시작

Multi Alerts는 Social Stream이 이미 캡처한 이벤트를 표시합니다. 자체적으로 Twitch, Kick, YouTube, TikTok 또는 다른 플랫폼에 로그인하지 않습니다.

  1. 이벤트를 제공하는 플랫폼 소스를 연결하고 활성화하세요.
  2. 해당 소스 페이지 또는 독립 실행형 앱 소스 창을 활성 상태로 유지하세요.
  3. 소스, 팝업, 도크, Multi Alerts URL에서 같은 Social Stream 세션 ID를 사용하세요.
  4. 플랫폼 연결을 디버깅하기 전에 옵션에서 알림 오버레이를 테스트하세요.

미리보기가 성공하면 알림 레이아웃이 작동함을 확인할 수 있습니다. 플랫폼 소스가 해당 실시간 이벤트를 받을 권한이 있다는 것을 입증하지는 않습니다.

표준 모드와 WebSocket 모드 비교

플랫폼표준 캡처WebSocket / API 캡처
YouTube 유료 메시지, 멤버십, 멤버십 선물, 시청자 업데이트, 제한적인 페이지 감지 이벤트. 공통 유료/회원 이벤트와 회원 마일스톤, 최근 공개 구독자 알림, 지원되는 개수 업데이트.
Twitch 채팅에 렌더링된 보상, 구독 선물 알림, 시청자 업데이트, 일부 페이지 전용 알림. EventSub는 계정과 권한 범위가 허용하는 경우 팔로워, 구독, 갱신, 응원, 레이드, 보상, 지원되는 개수/상태 이벤트를 추가합니다.
Kick 채팅 및 선물, 보상, 시청자 업데이트용 가벼운 페이지 표식. 인증된 경우 공식 팔로우, 구독, 선물, 보상 사용, KICKs, 채팅 관리, 라이브 상태 이벤트.

이벤트 기반 알림에는 일반적으로 WebSocket 모드가 적합합니다. 렌더링된 채팅만 필요하거나 인증할 수 없는 경우에는 표준 캡처가 유용합니다.

원하는 알림 유형 활성화

Social Stream 설정에서 Multi Alerts 옵션을 여세요. 팔로우, 구독, 후원, 비트, 레이드마다 활성화, 스타일, 소리, 모양 제어가 있습니다. 경매 및 하이프 열차 알림은 전용 선택적 활성화 제어가 필요합니다.

  • 사용: 알림 대기열 사용 를 여러 이벤트가 함께 도착할 수 있을 때 사용하세요.
  • 이벤트가 도크에서는 작동하지만 Multi Alerts에서는 작동하지 않으면 소스 필터를 확인하세요.
  • 소액 팁이나 응원이 빠지면 최소 금액/후원 필터를 확인하세요.
  • 자동 재생 규칙으로 사용자 지정 알림 오디오가 차단되면 브라우저 페이지와 한 번 상호작용하세요.

생방송 전 미리보기

미리보기 제어로 선택한 카테고리, 텍스트, 금액, 미디어, 소리, 애니메이션, 대기열 동작을 확인하세요.

각 도구가 사용하는 필드

도구호환성 규칙
Multi Alerts표준 이름을 분류합니다: event 이름, 별칭, hasDonation, 멤버십 필드, 선택한 meta 값을 공통 카테고리로 분류합니다.
Event Flow정확히 일치시킬 항목: type, event, 소스가 전송하는 필드를 확인하세요. 실시간 이벤트에 의존하기 전에 Test Message 도구를 사용하세요.
음성 읽기이벤트 행은 후원형이 아니면 기본적으로 건너뜁니다. 추가: &readevents 를 후원이 아닌 이벤트 메시지도 읽어야 할 때 추가하고 일반 음성 읽기 필터를 적용하세요.
후원함 / 목표 미터일반 모드는 후원 금액을 사용합니다. 하이프 모드는 멤버십, 갱신, 멤버십 선물 필드도 점수로 계산할 수 있습니다.
사용자 지정 오버레이 / API 소비자이벤트 참고 문서의 표준 페이로드 필드를 사용하세요. 문서화된 별칭은 하위 호환성을 위해서만 받으세요.

사용: 테스트 메시지 만들기 에서 예상 이벤트와 다음을 확인하세요: Event Flow 활용 예시 에서 작동하는 자동화 예시를 확인하세요.

실제 알림이 빠질 때

  1. 소스가 이벤트를 받았는지 자체 로그, 도크 또는 API 출력에서 확인하세요.
  2. 소스와 Multi Alerts 페이지가 같은 세션 ID와 비밀번호를 사용하는지 확인하세요.
  3. 해당 카테고리가 활성화되어 있고 소스 또는 채널 필터로 제외되지 않는지 확인하세요.
  4. 후원과 비트의 최솟값 필터를 확인하세요.
  5. Twitch나 Kick에서 채팅은 작동하지만 보호된 이벤트는 작동하지 않으면 다시 로그인하세요.
  6. 실제 이벤트를 관찰할 수 있을 만큼 소스 창을 활성 상태로 유지하세요. 미리보기만으로 플랫폼의 전체 경로를 테스트할 수는 없습니다.

여러 장치나 연결 모드를 사용한다면 다음을 검토하세요: 세션, 비밀번호, 릴레이 모드.
