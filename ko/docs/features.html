다중 플랫폼 채팅 통합

모든 방송 플랫폼의 시청자와 동시에 소통하세요. Social Stream Ninja는 수십 개 플랫폼의 채팅 메시지를 관리하기 쉬운 하나의 대시보드로 통합합니다.

  • Facebook, YouTube, Twitch, Zoom 등의 실시간 양방향 채팅
  • 대부분의 플랫폼에서 로그인이나 API 키 불필요
  • 플랫폼을 구분하는 여러 채널 소스 아이콘
  • 플랫폼 간 자동 메시지 릴레이

선택한 채팅 오버레이

아름답고 맞춤 설정 가능한 오버레이로 시청자의 멋진 메시지를 방송에 바로 강조 표시하세요.

  • 도킹 가능한 대시보드에서 메시지 선택
  • 자동 또는 수동 메시지 선택
  • 방송 디자인에 어울리도록 CSS로 맞춤 설정 가능
  • 페이드와 스와이프 효과를 포함한 애니메이션 옵션
  • 체계적인 강조 표시를 위한 메시지 대기열

봇 명령 및 자동 응답

사용자 지정 명령과 응답으로 시청자와의 상호작용을 자동화하세요.

  • 일반적인 상호작용용 내장 명령
  • 스크립트 플러그인 파일로 사용자 지정 명령 로직 구현
  • 자동 인사 및 응답
  • 메시지 필터링 및 채팅 관리

AI 및 LLM 통합

방송 전체를 한 제공자에 묶지 않고 음성 공동 진행자, 챗봇, 브라우저 도우미 또는 특정 AI 처리 도구를 선택하세요.

  • 내 말을 듣고 선택한 실시간 채팅 메시지를 받을 수 있는 음성 공동 진행자
  • 사용자 지정 지침과 트리거 규칙이 있는 기본 및 비공개 챗봇
  • OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq, 사용자 지정 호환 API 등 로컬 모델 또는 클라우드 제공자
  • 채팅 관리, 번역, 요약, RAG 맥락, 오버레이 제작
  • API 키가 필요 없는 선택적 ChatGPT 브라우저 캡처

텍스트 음성 변환

음성 읽기로 채팅 메시지에 목소리를 더해 방송의 참여도와 접근성을 높이세요.

  • 무료 시스템 음성 읽기 지원
  • 프리미엄 음성 읽기 서비스 통합(Google Cloud, ElevenLabs, Speechify)
  • 다국어 지원
  • 음성, 높낮이, 말하기 속도 맞춤 설정
  • OBS 오디오 캡처 지원

강력한 API

강력한 API 통합 옵션으로 Social Stream Ninja의 기능을 확장하세요.

  • 외부 통합용 웹훅 지원
  • 원격 제어용 서버 API
  • 후원 통합(NinjaBacker: 무료, 플랫폼 수수료 0%, Stripe, Ko-Fi, Buy Me A Coffee)
  • MIDI/Streamdeck 제어
  • OBS 원격 장면 지원

세밀한 맞춤 설정

기능과 모양의 폭넓은 맞춤 설정으로 Social Stream Ninja를 나에게 맞게 만드세요.

  • 모양을 완전히 제어하는 CSS 스타일
  • 스타일이 적용된 템플릿 및 테마
  • 사용자 지정 JavaScript 지원
  • 간편한 설정을 위한 URL 매개변수
  • 소스 필터링 및 브랜딩 옵션

고급 방송 도구

참여와 상호작용을 위한 전문 도구 모음으로 방송을 발전시키세요.

  • Battle Royal 등을 포함한 상호작용 미니게임
  • 대기열 관리가 있는 경품 추첨 시스템
  • 크레딧 롤 및 후원함 표시
  • 워드 클라우드 및 사용자 지정 GIF 명령
  • 그래픽 투표 시스템
  • 검색 가능한 채팅 기록 데이터베이스
  • 비공개 AI 챗봇 인터페이스
  • 멀티모달 AI 공동 진행자 기능
