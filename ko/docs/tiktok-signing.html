TikTok 서명이란?

TikTok 라이브 채팅 피드의 연결 요청에는 암호화 서명이 필요합니다. 데스크톱 앱이 사용하는 제삼자 서명 서비스는 Euler Stream에서 운영합니다. 일반적인 사용에는 계정이나 API 키가 필요하지 않습니다. 앱이 Euler의 무료 등급을 자동으로 사용합니다.

이 서비스는 앱과 TikTok 사이에서 작동하므로 사용자 측에 문제가 없어도 TikTok 소스가 멈출 수 있습니다. 서명 서버가 중단되었거나, 요청 제한에 걸렸거나, TikTok 측 변경으로 일시적으로 작동하지 않을 수 있습니다.

"서명 서버를 사용할 수 없음 (Sign Server Unavailable)"

이 상태는 앱이 서명 서비스에서 유효한 서명을 받지 못했다는 뜻입니다. 일반적인 원인:

  • 요청 속도 제한. 무료 등급에는 IP 주소별 제한이 있습니다(분당 몇 번의 연결, 시간별 및 일별 상한. 다음 문서: Euler 요청 속도 제한참고). 소스를 반복해서 삭제하고 추가하거나 모드를 빠르게 전환하면 할당량이 소모되어 오류가 계속됩니다.
  • 서명 서버 중단. Euler가 간혹 중단되거나 과부하 상태가 됩니다. 대개 몇 시간 내에 해결되며 사용자 측에서 변경할 필요가 없습니다.
  • TikTok 변경. TikTok이 라이브 인프라를 업데이트하면 Euler가 수정하기 전까지 모든 사용자의 서명이 실패할 수 있습니다.

순서대로 시도할 사항:

  • 소스를 Auto에 연결된 상태로 두고 자동으로 다시 시도하도록 하세요. 소스를 반복해서 다시 추가하지 마세요.
  • 계속 실패한다면 한 시간 동안 중지하여 IP별 요청 제한이 초기화되도록 한 뒤 한 번만 다시 연결하세요.
  • TikTok 관련 수정이 자주 배포되므로 최신 앱 버전을 사용하는지 확인하세요.
  • TikTok 소스를 다음으로 전환하세요: 표준 (Standard) 모드(페이지 캡처)를 임시 대안으로 사용하세요. 라이브 페이지를 직접 열며 서명 서버를 전혀 사용하지 않습니다.
  • 자주 요청 제한에 걸린다면 아래 안내에 따라 본인의 무료 Euler API 키를 추가하세요.

본인의 Euler API 키 추가

본인의 키를 사용하면 익명 사용자의 IP별 할당량을 공유하는 대신 전용 할당량을 받습니다.

  • 무료 계정과 키를 만드세요: Euler Stream 대시보드.
  • 데스크톱 앱에서 TikTok 소스를 편집하고 연결 프리셋 선택기를 여세요.
  • 선택: Euler Signing (Advanced) 을 선택하고 API 키를 붙여 넣으세요. Euler Proxy (API Key) 도 사용할 수 있지만 답변 전송은 지원하지 않습니다.
  • 저장한 뒤 소스를 한 번 다시 연결하세요.

서명 서버를 사용하지 않는 모드

모드작동 방식장단점
표준 (Standard)TikTok 라이브 페이지를 열고 그 페이지에서 채팅을 캡처합니다. 서명 서비스를 사용하지 않습니다.라이브 페이지를 열어 두어야 하며 TikTok 로그인이나 인증을 요청할 수 있습니다.
로컬 서명기 (Local Signer)Euler 대신 가벼운 TikTok 창에서 요청에 로컬로 서명합니다.앱 안에서 TikTok에 로그인했을 때 가장 잘 작동합니다. 익명 모드에서는 일부 채팅이 누락될 수 있습니다.

호환성(WebSocket)(이전 명칭: 폴링 (Polling) ) 모드는 현재 데스크톱 앱에서 서명된 WebSocket을 사용합니다. 서명 없는 HTTP 폴링을 제공하지 않으며 답장을 보낼 수 없습니다. Euler 서명을 사용하므로 해당 서비스의 장애와 제한에도 영향을 받습니다.

TikTok에 답변 보내기

도크에서 TikTok으로 채팅 메시지를 보내려면 데스크톱 앱 안에서 TikTok 계정에 로그인해야 합니다. 앱이 사용자 이름으로 게시하려면 TikTok 세션이 필요합니다. 로그인하지 않았거나 TikTok 연결이 끊겼다면 발신 메시지는 다른 플랫폼으로만 전송됩니다.

Euler Proxy 모드는 로그인 상태와 관계없이 답변 전송을 지원하지 않습니다.
