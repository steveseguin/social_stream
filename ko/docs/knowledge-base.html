빈 OBS 오버레이

먼저 도크를 확인하세요. 도크가 비어 있으면 소스/플랫폼 문제를 해결하세요. 도크가 작동하면 일반 브라우저에서 정확한 오버레이 URL을 열고 동일한 값을 사용하는지 확인하세요: session를 확인한 뒤 OBS 브라우저 소스를 새로고침하세요.

잘못된 세션

소스, 도크, 오버레이, 봇, 이벤트 흐름 페이지는 모두 같은 세션 ID를 사용해야 합니다. 세션 ID를 방 이름처럼 생각하세요. 철자가 다르면 다른 방입니다.

dock.html?session=YOUR_SESSION

설정을 잃지 않고 업데이트

먼저 설정을 내보내고, 일반 업데이트 중에는 확장 프로그램을 제거하지 마세요. 쿠키와 로그인도 옮겨야 한다면 데스크톱 앱의 암호화된 전체 세션 전송을 사용하세요.

안전한 업데이트, 백업 및 복구 열기

OBS에서 음성 읽기가 들리지 않음

일반 시스템 음성 읽기는 컴퓨터에서 소리가 나도 OBS 브라우저 소스에서는 들리지 않는 경우가 많습니다. Kokoro, Piper, Kitten, eSpeak, OpenAI 호환 또는 클라우드 제공업체 등의 제공업체/브라우저 음성 읽기 모드를 사용하거나 시스템 오디오를 별도로 라우팅하세요.

음성 읽기 설정 가이드 열기

Kokoro가 포르투갈어나 스페인어를 말하지 않음

내장 Kokoro 음성은 영어 음성입니다. 포르투갈어는 Piper의 pipervoice=pt_BR-faber-medium또는 eSpeak의 espeakvoice=pt-br를 사용하세요. 스페인어는 Piper의 pipervoice=es_ES-davefx-medium또는 eSpeak의 espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

음성 읽기 제공업체 설정 열기

Chrome에서는 되지만 데스크톱 앱에서는 안 됨

데스크톱 앱은 일반 Chrome 프로필이 아닌 Electron 세션을 사용합니다. 앱 소스 창 안에서 로그인하거나, 플랫폼이 내장/앱 브라우저 환경을 차단하면 Chrome 확장 프로그램 방식을 사용하세요.

독립 실행형 앱 모드 열기

어떤 로컬 서버가 필요한가요?

로컬 서버 활성화 (Enable Local Server) 는 지원되는 SSN 페이지용 WebSocket 릴레이입니다. 로컬 제어 API 는 같은 컴퓨터의 스크립트와 AI 도구용입니다. 헤드리스 호스팅은 Linux 서버에서 전체 데스크톱 앱을 실행합니다. 이벤트 흐름 미디어 서버는 승인된 로컬 미디어만 제공합니다.

로컬 서버와 서비스 설명 열기
