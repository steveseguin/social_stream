YouTube 프로젝트 설정

키 보안을 약화하지 않고 SSN 독립 실행형 데스크톱 앱용 Google Cloud 프로젝트를 만드는 방법.

개요

이 설정의 용도

데스크톱 앱에서 다음을 사용하려는 경우에만 설정하세요: 본인의 YouTube API 할당량 . Social Stream Ninja의 기본 공유 프로젝트를 대신합니다.

중요: 아래 세 값은 모두 다음에서 가져와야 합니다: 동일한 Google Cloud 프로젝트:
  • OAuth 클라이언트 ID
  • OAuth 클라이언트 보안 비밀번호
  • API 키
Google Cloud의 다음 두 입력란을 혼동하지 마세요:
  • 승인된 JavaScript 원본 (Authorized JavaScript origins) 에는 경로 없이 출처만 입력해야 합니다.
  • 승인된 리디렉션 URI (Authorized redirect URIs) 에는 전체 /sources/websocket/youtube.html 경로를 포함해야 합니다.
1단계

프로젝트 만들기

  1. Google Cloud Console을 여세요.
  2. 새 프로젝트를 만들거나 전용으로 사용할 기존 프로젝트를 선택하세요.
  3. 활성화 YouTube Data API v3.
  4. OAuth 동의 화면 설정을 여세요.
  5. 앱이 테스트 상태라면 본인의 Google 계정을 테스트 사용자로 추가하세요.
2단계

OAuth 클라이언트 만들기

  1. 사용자 인증 정보를 만드세요.
  2. 선택: OAuth 클라이언트 ID.
  3. 유형 선택: 웹 애플리케이션.
  4. 아래에 표시된 정확한 출처와 리디렉션 URI를 추가하세요.
필드 값
승인된 JavaScript 원본 (Authorized JavaScript origins) http://localhost:8181
http://localhost:8080
승인된 리디렉션 URI (Authorized redirect URIs) http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
3단계

API 키 안전하게 만들기

  1. 생성할 항목: API 키 를 같은 프로젝트에서 만드세요.
  2. 해당 키의 제한사항을 여세요.
  3. 다음 항목 아래에서: API 제한사항에서 허용 대상을 다음으로 제한하세요: YouTube Data API v3 만.
  4. 데스크톱 앱에는 HTTP 리퍼러 제한을 사용하지 마세요.

데스크톱 앱 규칙: HTTP 리퍼러 제한은 브라우저 페이지용이며 이 로컬 데스크톱 인증 흐름용이 아닙니다.

4단계

데스크톱 앱에 값 붙여 넣기

  1. 데스크톱 앱 안에서 YouTube 소스 페이지를 여세요.
  2. 붙여 넣을 값: OAuth 클라이언트 ID, OAuth 클라이언트 보안 비밀번호, 그리고 API 키.
  3. 클릭: 저장.
  4. 필요하면 로그아웃하세요.
  5. 클릭: YouTube로 로그인.
  6. 외부 브라우저 창에서 Google 로그인을 완료하세요.
예상 결과: 모든 값이 일치하면 Google 로그인이 작동하고 데스크톱 앱은 기본 공유 프로젝트 대신 저장한 YouTube 프로젝트를 사용합니다.
보안

인증 정보 안전하게 보관하기

  • 클라이언트 보안 비밀번호와 API 키는 민감한 정보로 취급하세요.
  • 스크린샷, 채팅 로그, 버그 보고서에 붙여 넣지 마세요.
  • 실수로 노출했다면 교체하거나 삭제하세요.
  • 실험하려면 전용 테스트 프로젝트를 사용하세요.
  • 테스트가 끝나면 임시 프로젝트를 삭제하세요.
문제 해결

일반적인 문제

  • redirect_uri_mismatch: 리디렉션 URI가 정확히 일치하지 않습니다.
  • invalid_client: 클라이언트 ID와 클라이언트 보안 비밀번호가 일치하지 않습니다.
  • quotaExceeded: API 키 프로젝트의 YouTube 할당량이 소진되었습니다.
  • 계정 확인 실패: 이전 버전에서는 OAuth와 API 키가 서로 다른 프로젝트에서 왔을 때 발생할 수 있었습니다.
