개요

SSN은 지원되는 모든 소스에서 캡처한 채팅 텍스트를 읽을 수 있습니다. 채팅 플랫폼 자체의 TTS 기능은 필요하지 않습니다. TTS가 켜진 도크 또는 오버레이는 필터와 TTS 설정에 따라 수신한 메시지를 읽습니다. 먼저 참고하세요: 간단한 설정 가이드를 참고하세요. 이 페이지에서는 음성 옵션과 고급 설정을 설명합니다. 제공업체를 비교하고 샘플을 듣고 설정을 확인하세요.

빠른 시작: 사용: dock.html?session=YOUR_SESSION&speech=en-US을 사용하세요. 기본값은 시스템 TTS입니다. OBS용 무료 제공업체를 사용하려면 다음도 추가하세요: &ttsprovider=kokoro. 이 페이지를 열고 연결된 상태로 유지하며 한 페이지만 읽게 하세요.

TTS는 어디에 사용되나요?

  • Social Stream Ninja: 여러 영역에서 시청자 채팅 메시지를 읽어 줍니다
  • CAPTION.Ninja: 자막, 받아쓰기, 번역과 TTS 제공
  • 두 서비스 모두 유료 및 무료 TTS 옵션 제공
시스템 TTS와 모든 무료 TTS는 같은 것이 아닙니다:
  • 시스템 음성은 브라우저와 운영체제에 따라 다릅니다. Chrome/Edge에서 작동하더라도 OBS에는 사용할 수 있는 음성이 없을 수 있습니다.
  • 사용 가능한 음성이 없는 문제는 OBS가 캡처하지 않는 곳에서 음성이 재생되는 문제와 다릅니다. 오디오 라우팅으로 음성 지원 문제를 해결할 수는 없습니다.
  • Kokoro, Piper, Kitten, eSpeak 같은 무료 제공업체는 페이지 오디오를 생성합니다. OBS에서 TTS를 사용하기 위해 결제할 필요는 없습니다.
  • 먼저 음성 사용 가능 여부를 확인한 뒤 오디오 캡처를 확인하세요.

TTS 제공업체 옵션

시스템 TTS (무료)

  • 운영체제의 내장 음성 사용
  • 시스템에 설치된 언어만 지원
  • 음성 사용 가능 여부와 오디오 라우팅은 브라우저와 운영체제에 따라 다릅니다. 실제 재생 환경에서 테스트하세요
  • 브라우저별 호환성 차이가 큽니다

로컬 / 무료 TTS 옵션 (API 키 불필요)

완전히 로컬에서 실행되는 AI TTS를 원하시나요? Social Stream Ninja에는 여러 고품질 AI 음성이 내장되어 브라우저에서 실행됩니다. API 키, 클라우드, 추가 설치가 필요하지 않습니다. 참고: 로컬 AI 음성 읽기 가이드 에서 설정 안내와 자체 호스팅 서버 옵션을 확인하세요.

시스템 음성 사용 가능 여부

일반적인 기능이며 모든 설치 환경에서 보장되지는 않습니다. OBS는 자체 내장 브라우저를 사용하며 설치된 Chrome/Edge의 음성 목록을 이어받지 않습니다. SSN 앱 테스트가 성공해도 별도의 OBS 브라우저 소스를 테스트한 것은 아닙니다.

브라우저 제한:
  • 모든 브라우저가 텍스트 음성 변환을 똑같이 지원하지는 않습니다(일부 Firefox 버전은 음성이 제한됨)
  • Chrome은 Google 기반 TTS 옵션을 제공합니다
  • Edge는 Microsoft TTS와 Windows 언어 팩 음성을 지원합니다
  • Safari에서 오디오를 시작하려면 사용자 조작이 필요합니다
  • 확인: 사용 가능한 음성 (현재 브라우저)

OBS용 Windows TTS 오디오 캡처 방법

페이지 오디오: 무료 로컬 및 클라우드 제공업체

SSN의 브라우저 기반 로컬 제공업체와 클라우드 오디오 제공업체는 생성한 오디오를 페이지에서 재생합니다:

  • 브라우저 소스에서 ‘Control audio via OBS’만 켜면 됩니다
  • 가상 오디오 케이블 불필요
  • SSN 앱 및 OBS 브라우저 소스와 함께 사용 가능

시스템 TTS 캡처 방법

중요: 먼저 시스템 TTS가 음성을 생성하는지 확인하세요. OBS 내장 브라우저에는 사용 가능한 시스템 음성이 없을 수 있습니다. 음성이 생성되지 않으면 오디오 라우팅을 바꿔도 도움이 되지 않습니다. 다른 제공업체를 선택하거나 지원되는 브라우저에서 음성을 생성하고 해당 브라우저의 오디오를 캡처하세요.

시스템 TTS의 경우:

  • OBS에 Chrome이나 Edge와 같은 음성이 제공된다고 가정하지 마세요
  • 브라우저마다 지원이 제한됨(Firefox에는 일부 TTS 음성이 없을 수 있음)
  • Chrome은 Google 기반 옵션을, Edge는 Microsoft 옵션을 제공합니다
  • 음성이 장면의 브라우저 소스 밖에서 재생된다면 해당 출력을 별도로 캡처하세요

라우팅 도구 다운로드: VB-Audio Virtual Cable | Voicemeeter | Audio Router (레거시)

지원되는 환경이라면 먼저 OBS의 응용 프로그램 또는 데스크톱 오디오로 음성이 나오는 브라우저를 캡처해 보세요. 아래 가상 케이블 방식은 선택 가능한 대안이며 OBS에 음성 지원을 추가하지 않습니다.

방법 1: 가상 케이블을 사용하는 기본 오디오 경로

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

방법 2: Windows 10 앱별 라우팅

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

방법 3: Windows 11 앱별 라우팅

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

방법 4: Audio Router 소프트웨어

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

방법 5: Voicemeeter (고급)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

설정 테스트

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
대안: Kokoro, Piper, Kitten, eSpeak 같은 무료 내장 제공업체, 클라우드 제공업체 또는 자체 호스팅 TTS 서버를 사용하세요.

추가 언어 팩 설치

Windows 11

  1. 이동할 위치: 시작 > 설정 > 시간 및 언어 > 음성
  2. 다음 항목 아래에서: 음성 관리에서 다음을 클릭하세요: 음성 추가
  3. 원하는 언어를 선택하고 다음을 클릭하세요: 추가:
  4. 사용 가능한 음성을 갱신하려면 브라우저를 재시작하세요

Windows 10

다음 자료의 지침을 따르세요: Microsoft 공식 가이드 에서 언어 팩 설치 방법을 확인하세요.

팁: 일부 제삼자 음성은 호환성 문제로 브라우저에 나타나지 않을 수 있습니다. Firefox는 Chromium 기반 브라우저보다 더 많은 시스템 음성을 표시하는 경우가 많습니다.

TTS 제공업체 설정

Kokoro TTS (무료, 내장)

  • 활성화 매개변수: ?ttsprovider=kokoro
  • WebGPU/WASM으로 브라우저에서 실행되며 서버가 필요하지 않습니다
  • OBS 브라우저 소스에서 직접 작동
  • 음성 선택: &voicekokoro=af_bella
  • 속도 조절: &kokorospeed=1.2
  • 해당 언어의 음성 선택: &voicekokoro=ef_dora 는 스페인어에, 다음은 &voicekokoro=pf_dora 는 브라질 포르투갈어입니다. 다음 설정: &speech= 만 바꿔서는 선택된 음성이 변경되지 않습니다. 기존 영어 음성 ID도 계속 사용할 수 있습니다.

Piper TTS (무료, 내장)

  • 활성화 매개변수: ?ttsprovider=piper
  • 브라우저에서 실행되는 빠르고 CPU 부담이 적은 신경망 TTS
  • 음성 선택: &pipervoice=en_US-hfc_female-medium
  • 포르투갈어 음성: &pipervoice=pt_BR-faber-medium 또는 &pipervoice=pt_BR-edresson-low
  • 스페인어 음성: &pipervoice=es_ES-davefx-medium 또는 &pipervoice=es_MX-ald-medium
  • 속도 조절: &piperspeed=1.0

Kitten TTS (무료, 내장)

  • 활성화 매개변수: ?ttsprovider=kitten
  • 브라우저에서 실행되는 가벼운 ONNX 기반 TTS
  • 음성 선택: &kittenvoice=expr-voice-4-f

eSpeak-NG (무료, 내장)

  • 활성화 매개변수: ?ttsprovider=espeak
  • 어떤 하드웨어에서도 작동하는 전통적인 오픈 소스 TTS
  • 음성 선택: &espeakvoice=en
  • 포르투갈어 예시: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • 스페인어 예시: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 속도 조절: &espeakspeed=175

포르투갈어 및 스페인어 TTS 예시

  • SSN에서 테스트한 무료 로컬 포르투갈어 중 가장 높은 품질: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • SSN에서 테스트한 포르투갈어 중 가장 빠른 대안: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • SSN에서 테스트한 무료 로컬 스페인어 중 가장 높은 품질: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • SSN에서 테스트한 스페인어 중 가장 빠른 대안: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 클라우드 음성은 Google Cloud, ElevenLabs, Speechify, Gemini 또는 OpenAI 호환 로컬 서버처럼 대상 언어를 지원하는 제공업체의 음성/언어를 사용하세요.

OpenAI / 로컬 서버 TTS

  • 활성화 매개변수: ?ttsprovider=openai
  • 사용: ?ttsprovider=customtts 또는 ?ttsprovider=localtts 는 자체 호스팅 엔드포인트에 사용합니다
  • 기본적으로 OpenAI API를 사용하며 호환되는 로컬 서버도 사용 가능
  • 사용자 지정 엔드포인트: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • 중요: localhost 그리고 127.0.0.1 는 TTS 페이지를 재생하는 컴퓨터를 뜻합니다. OBS와 TTS 서버가 서로 다른 컴퓨터에 있다면 서버 컴퓨터의 LAN IP를 사용하세요.
  • 로컬 서버에는 API 키 불필요
  • 로컬 서버가 Chrome/OBS에서 CORS 또는 로컬 네트워크 문제를 일으키면 다음을 실행하세요: npm run local-tts-bridge 를 OBS 컴퓨터에서 실행하고 SSN의 주소를 다음으로 지정하세요: http://127.0.0.1:8124/v1/audio/speech
  • SSN이 전송하는 형식: { model, input, voice, response_format, speed } 이며 바이너리 오디오, JSON 오디오 URL, JSON base64 오디오를 지원합니다
  • 현재 사용자 지정/로컬 엔드포인트 재생은 버퍼링 방식이며 SSN은 스트리밍 오디오 조각을 점진적으로 재생하지 않습니다
  • 음성: &voiceopenai=af_bella, 속도: &openaispeed=1.0입니다. 서버가 지원하는 음성 이름을 사용하세요. Kokoro 음성의 예: af_bella이며 openedai-speech/OpenAI 형식의 음성은 다음과 같을 수 있습니다: nova 또는 echo.
  • 다음을 참조하세요: 로컬 AI 음성 읽기 가이드 에서 자체 호스팅 서버 설정을 확인하세요

Google Cloud TTS

  • 활성화 매개변수: ?ttsprovider=google&ttskey=YOUR_API_KEY
  • 전문가 수준의 음성 품질
  • 음성 선택: &voicegoogle=en-GB-Standard-A
  • 언어: &googlelang=en-US

Gemini TTS

  • 활성화 매개변수: ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • 모델: &geminimodel=gemini-2.5-flash-preview-tts
  • 음성: &voicegemini=Kore, 언어: &geminilang=th-TH
  • 스타일 지시문: &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • 활성화 매개변수: ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • 음성 ID: &voice11=YOUR_VOICE_ID
  • 모델: &elevenlabsmodel=eleven_multilingual_v2
  • 매개변수: 안정성, 유사도, 스타일 조절 가능

Fish Audio TTS

Fish Audio를 선택하고 API 키를 입력하세요. 필요하면 음성 ID도 지정할 수 있습니다. 기본 모델: s2.1-pro-free. 설정, 모델 옵션, 브라우저 접근 제한.

Speechify TTS

  • 활성화 매개변수: ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • 음성: &voicespeechify=henry
  • 모델: &speechifymodel=simba-3.0 (기본값) 또는 &speechifymodel=simba-3.2 는 영어에 사용합니다.
  • 말하기 속도: &speechifyspeed=1.2 (범위 0.5–3.0, 기본 속도 1.0).
  • Speechify 설정, 음성, 속도, 볼륨 가이드

문제 해결

일반적인 문제

  • 오디오가 재생되지 않을 때: TTS가 켜져 있고 음성을 생성하는 페이지가 열려 있으며 브라우저 소스가 음소거되지 않았는지 확인하세요. 일반 브라우저에서는 페이지를 한 번 클릭하세요.
  • 음성이 표시되지 않을 때: 언어 팩을 설치한 뒤 브라우저를 재시작하세요
  • OBS가 캡처하지 못할 때: 음성이 없다면 먼저 음성/제공업체 사용 가능 여부를 확인하세요. 음성이 있다면 다음을 확인하세요: OBS를 통해 오디오 제어(Control audio via OBS), 믹서 음소거, 출력 트랙을 확인하거나 음성을 재생하는 외부 브라우저를 캡처하세요
  • 로컬 엔드포인트가 앱 테스트에서는 작동하지만 OBS에서는 안 될 때: OBS는 별도의 브라우저입니다. OBS 컴퓨터에서 엔드포인트를 확인하세요. 특히 다음을 사용할 때 주의하세요: 127.0.0.1.
  • 첫 글자나 첫 단어만 읽을 때: 제거할 항목: ttsquick 가 OBS URL에 있으면 제거하세요.
  • Safari 문제: Safari의 자동 TTS 지원은 제한적입니다
  • 유료 서비스가 작동하지 않을 때: API 키와 제공업체 지정이 올바른지 확인하세요

권장 방법

  • OBS를 간단하게 설정하려면 페이지 오디오를 생성하는 제공업체를 사용하세요. 무료 로컬 제공업체도 있습니다
  • 방송을 시작하기 전에 간단한 문장으로 설정을 테스트하세요
  • TTS로 시청자가 작성한 내용을 읽을 때의 위험을 고려하세요
  • 필요할 때 TTS를 빠르게 끌 수 있는 스위치를 준비하세요

이 브라우저의 시스템 음성 확인

이 목록의 대상: 이 가이드를 표시하는 브라우저의 시스템 TTS 음성만. OBS, 별도의 SSN 앱 창, Kokoro 등의 제공업체는 테스트하지 않습니다. 목록이 비어 있어도 SSN의 다른 TTS 제공업체를 사용할 수 없다는 뜻은 아닙니다.
