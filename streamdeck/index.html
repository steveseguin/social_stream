2 · Connect

Connect your session once

1

Copy the ID

Use Copy ID above, or copy it from Settings in the Chrome extension.

2

Add Setup

In the Stream Deck app, drag the Social Stream Ninja Setup action onto a key.

3

Paste and test

Paste the ID into Setup and choose Test Connection. The key shows Online when it works.

Keep SSApp or the extension running. Once Online, add Preset Command keys; they all share this connection.
