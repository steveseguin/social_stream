FÜHRER / OBS STUDIO

Ihr erstes OBS-Setup.

Bringen Sie Kamera, Bildschirm und Ton zusammen. Machen Sie eine Testaufnahme und gehen Sie dann live.

Hier beginnenSzenenEncoderPlattformeinstellungenAudioÜberlagerungen
01

Lassen Sie OBS die erste Einrichtung durchführen

  1. Installiere OBS Studio und öffnen Sie es.
  2. Wähle Extras → Autokonfigurationsassistent.
  3. Wählen Sie „Streaming“ oder „Aufnahme“, befolgen Sie die Anweisungen und übernehmen Sie die Einstellungen.

Erlauben Sie den Zugriff auf Kamera, Mikrofon und Bildschirmaufnahmen, wenn Ihr Computer Sie dazu auffordert.

Screenshots werden bei Auswahl in voller Größe geöffnet. Die Etiketten können je nach OBS-Version leicht variieren.

Szenenumschaltung und macOS

Verwenden Sie auf macOS macOS Bildschirmaufnahme für ein Fenster oder eine Anzeige.

Szenenänderungen werden normalerweise direkt ausgegeben. Studiomodus können Sie eine Szene vorbereiten und dann drücken Übergang. Gemeinsame Quellen- und Audioänderungen können sich weiterhin auf die Live-Ausgabe auswirken.

Wähle Vorhandenes hinzufügen um eine Quelle in einer anderen Szene wiederzuverwenden.

04

Gönnen Sie Ihrer CPU eine Pause

In Einstellungen → Ausgabe, wählen Sie eine Hardware H.264 Encoder. Dedizierte Hardware übernimmt die Videokomprimierung und reduziert so die CPU-Auslastung.

Keine Hardwareoption? Benutzen x264 → sehr schnell und beginnen bei 720p30.

Fehlender Encoder oder überlasteter Computer?

Überprüfen Sie die Hardwareunterstützung und aktualisieren Sie Ihren Grafiktreiber. OBS benötigt weiterhin GPU-Kapazität zum Zeichnen von Szenen; Obergrenze des Spiel-FPS oder niedrigere Ausgabe-FPS, wenn es zurückfällt.

Wenn der Hardware-Encoder Ihres Mac CBR nicht bereitstellen kann, verwenden Sie x264. Encoder-Kompatibilität.

05

Für manuelle Ausgabeeinstellungen wählen Sie Ausgabe → Erweitert → Streaming: CBR, 2-Sekunden-Keyframes, und AAC-Stereoanlage. Öffnen Sie unten Ihre Plattform.

06

Sorgen Sie dafür, dass Ihre Stimme leicht zu hören ist

  1. Wählen Sie Ihr Mikrofon aus Einstellungen → Audio.
  2. Sprechen Sie normal. Streben Sie nach Gipfeln in der Umgebung −12 bis −6 dBFS; Vermeiden Sie es, 0 zu treffen.
  3. Schieben Sie die Spiel-, Musik- und Alarm-Schieberegler nach unten, bis die Sprache klar zu verstehen ist.

Nehmen Sie jeden Ton einmal auf. Verwenden Sie Desktop Audio für das gesamte Ausgabegerät oder separate Anwendungserfassung. Durch die Aufnahme beider Aufnahmen kann der Ton verdoppelt werden.

App-Audio, macOS und Mikrofonfilter

Windows: verwenden Audioaufnahme der Anwendung. Verwenden Sie auf macOS 13+ OBSs macOS Audio-/Bildschirmaufnahme.

Mikrofon → Filter: Versuchen Sie es mit einer leichten Rauschunterdrückung, dann mit einem Kompressor und einem Limiter. Fügen Sie einen nach dem anderen hinzu und hören Sie zu.

Echo vermeiden: Erfassen Sie Ihr Überwachungsgerät nicht erneut über Desktop Audio. Dadurch kann auch „Nur Monitor“-Audio an die Zuschauer gesendet werden. Halten Sie den Live-Player der Plattform stumm.

08

Fügen Sie ein Chat- oder Benachrichtigungs-Overlay hinzu

  1. Kopieren Sie die Overlay-URL von Social Stream Ninja.
  2. Wähle Quellen → + → Browser und fügen Sie es ein. Behalten Sie die Sitzungs- und Passwortoptionen bei.
  3. Legen Sie die Overlay-Größe fest. verwenden 1920 × 1080 für eine Vollbild-Landschaftsüberlagerung.
  4. Für TTS oder Warnungen aktivieren Audio über OBS steuern (Control audio via OBS).

Platzieren Sie es über Ihrem Spiel oder Ihrer Kamera. Senden Sie eine Testnachricht. Wählen Sie eine im SSN-Dock aus, wenn Sie das Overlay mit hervorgehobenen Nachrichten verwenden.

Leeres Overlay oder wiederholtes Audio?

Überprüfen Sie, ob die Sitzung mit Ihrer Chat-Quelle übereinstimmt. Aktualisieren Sie die Browserquelle. Behalten Sie nur eine Kopie, die TTS spielt.

Lassen Sie für dauerhaften Chat das automatische Herunterfahren und die Aktualisierung der Szenenaktivierung zunächst deaktiviert. SSN Overlay-Setup · TTS-Setup.

09

Nehmen Sie eine Minute auf. Dann gehen Sie live.

  1. Wählen Sie einen Aufnahmeordner in Einstellungen → Ausgabe.
  2. Drücken Sie Aufnahme starten. Sprechen Sie, spielen Sie Ton ab und wechseln Sie Szenen.
  3. Halten Sie an und schauen Sie sich die Datei an. Überprüfen Sie Lautstärke, Bildausschnitt und Lippensynchronisation.
  4. Legen Sie dann den Titel und die Sichtbarkeit Ihrer Plattform fest Streaming starten. Überprüfen Sie die Vorschau und den Stream-Zustand. Einige Plattformen erfordern auch Live gehen.

Mit „Streaming starten“ können Sie öffentlich live live gehen. Nutzen Sie einen privaten Test, sofern verfügbar. Wenn Sie fertig sind, beenden Sie das Streaming und bestätigen Sie, dass das Plattformereignis beendet ist.

Aufnahmeformat und separate Audiospuren

MKV toleriert eine unterbrochene Aufnahme. Benutzen Datei → Remux-Aufnahmen für MP4 danach. Der aktuelle OBS bietet auch robustes Hybrid MP4/MOV.

Für separate Bearbeitungsspuren belassen Sie einen vollständigen Mix auf Spur 1, weisen Sie dann in den erweiterten Audioeigenschaften zusätzlichen Spuren Mikrofon/Spiel zu und aktivieren Sie sie unter Aufnahme.

10

Wenn etwas nicht stimmt

Öffnen Ansicht → Statistiken um den Engpass zu identifizieren.

Netzwerkausfälle
Niedrigere Bitrate; Versuchen Sie es mit kabelgebundenem Ethernet.

Rendering-Verzögerung
Cap-Game-FPS; Vereinfachen Sie die Szene.

Codierungsverzögerung
Verwenden Sie Hardware-Kodierung oder niedrigere Ausgabe-FPS.

Stille Ausgabe
Stummschaltung, Überwachungsmodus und Audiospur prüfen.
