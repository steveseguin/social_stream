Bot-Befehle

Integrierte Bot-Befehle

Social Stream Ninja enthält mehrere integrierte Befehle, die Zuschauer im Chat verwenden oder die du über die API auslösen kannst.

Befehl Beschreibung So aktivierst du es
!joke Antwortet mit einem zufälligen nerdigen Flachwitz Über den Schalter im Erweiterungsmenü aktivieren
hi Begrüßt automatisch alle, die „hi“ in den Chat schreiben Über den Schalter im Erweiterungsmenü aktivieren
!cycle Erlaubt Zuschauern bei Aktivierung, OBS-Szenen zu wechseln Über den Schalter im Erweiterungsmenü aktivieren

Hinweis: Bot-Befehle funktionieren nur, wenn der automatische Antwortdienst richtig eingerichtet ist und du auf den jeweiligen Plattformen Nachrichten posten darfst.

Automatische Antworten einrichten

Damit der automatische Antwortdienst richtig funktioniert:

  1. Stelle sicher, dass du auf der Plattform (YouTube, Twitch usw.) angemeldet bist
  2. Stelle sicher, dass das Chatfenster sichtbar und nicht minimiert ist
  3. Sende zuerst manuell eine Testnachricht, um die Berechtigungen zu prüfen
  4. Aktiviere die Schalter der gewünschten Befehle im Erweiterungsmenü

Wenn beim Auslösen automatischer Antworten eine blaue Debugging-Leiste erscheint, kannst du sie ausblenden. Starte dazu Chrome mit der Option --silent-debugger-extension-api .

Server-API

Übersicht

Social Stream Ninja bietet eine leistungsfähige API, mit der du jeden Aspekt deiner Streaming-Einrichtung programmatisch steuern kannst. Der API-Server kann sowohl Befehle an deine Einrichtung senden als auch eingehende Nachrichten aus zusammengeführten Chatdiensten empfangen.

Overlay-Verwaltung

Steuere hervorgehobene Nachrichten, leere Overlays und ändere die Darstellung von Inhalten in deinem Stream.

Webhook-Integration

Empfange Ereignisse von Drittanbieterdiensten wie Stripe, Ko-Fi und Buy Me A Coffee.

Nachrichtenexport

Exportiere Chatnachrichten in eine Datei oder leite sie per Webhook (POST) für eigene Integrationen weiter.

Erforderliche Einstellungen (Global settings → Mechanics):

  • 🎮 Fernsteuerung (StreamDeck/Bitfocus): Aktivieren „Fernsteuerung der Erweiterung über API aktivieren“ (Enable remote API control of extension) (Schalter 1) — Verbinden mit Kanal 1
  • 📡 Chat-Listener (Python-/Node-Apps): Aktiviere Schalter 1 + „Chatnachrichten an API-Server senden“ (Send chat messages to API server) (Schalter 3) — Verbinden mit Kanal 4

Siehe vollständige API-Dokumentation für ausführliche Einrichtungsanleitungen und Codebeispiele.

API-Endpunkte und Verbindungsmethoden

HTTP GET/POST

https://io.socialstream.ninja/{sessionID}/{action}/{target}/{value}

Ideal für einfache Befehle von Stream Deck oder eigenen Skripten.

WebSocket

wss://io.socialstream.ninja:443

Für bidirektionale Echtzeitkommunikation mit automatischer Wiederverbindung.

Wenn du Peer-to-Peer-Verbindungen bevorzugst und den WebSocket-Modus nicht aktivieren möchtest, kannst du das Social Stream Ninja WebRTC SDK verwenden. Es enthält Node- und Browserbeispiele wie den Social Stream Ninja Listener.

Server-Sent Events

https://io.socialstream.ninja/sse/{sessionID}

Für Echtzeitaktualisierungen vom Server in eine Richtung.

Kanalsystem

Die API verwendet ein Kanalsystem zur Nachrichtenweiterleitung:

	- Channel 1: Remote control commands (default for StreamDeck/Bitfocus)
	- Channel 2: Dock page output
	- Channel 3: Extension receives commands from Dock
	- Channel 4: Chat messages from Extension (use this to receive Twitch/YouTube chat!)
	- Channel 5: Waitlist/giveaway communication
	- Channels 6-9: Reserved for future use

Verbinde dich mit deinem gewünschten Kanal:

// To receive chat messages (listen on channel 4):
wss://io.socialstream.ninja/join/SESSION_ID/4

// To send commands (channel 1 default):
wss://io.socialstream.ninja/join/SESSION_ID

Gängige API-Befehle

Aktion Beschreibung Beispiel
sendChat Sendet eine Nachricht an alle verbundenen Chatplattformen https://io.socialstream.ninja/SESSIONID/sendChat/null/Hello everyone!
sendEncodedChat Sendet eine URL-kodierte Nachricht an alle Plattformen https://io.socialstream.ninja/SESSIONID/sendEncodedChat/null/Hello%20everyone%21
clearOverlay Entfernt die hervorgehobene Nachricht aus dem Overlay https://io.socialstream.ninja/SESSIONID/clearOverlay
nextInQueue Zeigt die nächste Nachricht in der Warteschlange an https://io.socialstream.ninja/SESSIONID/nextInQueue
autoShow Schaltet das automatische Hervorheben von Nachrichten um https://io.socialstream.ninja/SESSIONID/autoShow/toggle
blockUser Blockiert einen Benutzer einer bestimmten Plattform https://io.socialstream.ninja/SESSIONID/blockUser/null/{"chatname":"username","type":"twitch"}
extContent Sendet externe Inhalte als Chatnachricht https://io.socialstream.ninja/SESSIONID/extContent/null/{"chatname":"User","chatmessage":"Hello"}
pin Heftet eine bestehende Dock-Nachricht anhand ihrer Nachrichten-ID oder ein vollständiges Nachrichtenobjekt an. Voraussetzung: dock.html muss in derselben Sitzung geöffnet sein. https://io.socialstream.ninja/SESSIONID/pin/null/MESSAGE_MID
unpin Löst eine angeheftete Dock-Nachricht anhand ihrer Nachrichten-ID. Verwende das Feld bzw. Pfadsegment target für ein benanntes Dock. https://io.socialstream.ninja/SESSIONID/unpin/null/MESSAGE_MID
nextPinned Hebt die erste angeheftete Dock-Nachricht hervor. https://io.socialstream.ninja/SESSIONID/nextPinned
removefromwaitlist Entfernt den ersten aktiven Wartelisteneintrag oder den nummerierten aktiven Eintrag in value https://io.socialstream.ninja/SESSIONID/removefromwaitlist/null/1
highlightwaitlist Hebt den ersten aktiven Wartelisteneintrag oder den nummerierten aktiven Eintrag in value https://io.socialstream.ninja/SESSIONID/highlightwaitlist/null/1
stopentries / startentries Stoppt neue Wartelisteneinträge oder lässt sie wieder zu, ohne die bestehende Liste zu leeren. openentries und resumeentries sind Aliase für startentries. https://io.socialstream.ninja/SESSIONID/stopentries
selectwinner Wählt einen oder mehrere zufällige Gewinner aus Warteliste/Auslosung https://io.socialstream.ninja/SESSIONID/selectwinner/null/1
downloadwaitlist Lädt die aktuelle Warteliste als TSV-Datei von der laufenden Social-Stream-Seite/App herunter https://io.socialstream.ninja/SESSIONID/downloadwaitlist
drawmode Schaltet den Auslosungsmodus ein/aus. Bei folgender Einstellung wird sein Zustand umgeschaltet: value entspricht toggle https://io.socialstream.ninja/SESSIONID/drawmode/null/toggle
waitlistmessage Legt die Titelmeldung der Warteliste oder Auslosung auf der Wartelistenseite fest https://io.socialstream.ninja/SESSIONID/waitlistmessage/null/Type%20!join%20to%20enter
resetwaitlist Leert die Warteliste und öffnet die Anmeldung wieder https://io.socialstream.ninja/SESSIONID/resetwaitlist

StreamDeck & Companion

StreamDeck-Integration

Social Stream Ninja unterstützt StreamDeck über mehrere Wege: native HTTP-Aktionen und Bitfocus-Companion-Integration.

HTTP-/API-Methode

Verwende die StreamDeck-Aktion „Website“ mit aktiviertem „GET request in background“, um Befehle direkt an die API zu senden.

Bitfocus Companion

Native Integration mit vorgefertigten Aktionen, Echtzeitrückmeldungen und Variablen für dynamische Inhalte.

Companion-Integration

Bitfocus Companion ermöglicht die umfassende Steuerung von Social Stream Ninja über WebSocket- oder HTTP-APIs.

Aktion Beschreibung API-Methode
Hervorgehobene Nachricht entfernen Entfernt die aktuell hervorgehobene Nachricht aus dem Overlay WebSocket/HTTP
Nächste in der Warteschlange Zeigt die nächste wartende Nachricht an WebSocket/HTTP
Automatische Anzeige umschalten Aktiviert/deaktiviert das automatische Hervorheben von Nachrichten WebSocket/HTTP
Chatnachricht senden Sendet eine Nachricht an alle verbundenen Plattformen WebSocket/HTTP

Dynamische Variablen

  • featured_message – Text der aktuell hervorgehobenen Nachricht
  • featured_username – Benutzername der aktuell hervorgehobenen Nachricht
  • queue_size – Anzahl der Nachrichten in der Warteschlange

KI-Integration

KI-Chatbot-Modus

Social Stream Ninja bietet eine umfassende KI-Integration für KI-gestützte Chatantworten, Moderation und mehr in deinen Streams. Wähle je nach Bedarf lokale oder cloudbasierte KI-Anbieter.

Automatische Chatantworten

Lass die KI automatisch mit deinen Zuschauern interagieren, Fragen beantworten und das Gespräch lebendig halten, während du dich auf deine Inhalte konzentrierst.

Inhaltsmoderation

Nutze KI zur Chatmoderation: Sie erkennt potenziell schädliche Nachrichten und behandelt sie automatisch nach deinen Vorgaben. Wähle zwischen nicht blockierenden und strikt blockierenden Modi.

RAG-Suche

Retrieval-Augmented Generation ermöglicht der KI, deine eigene Wissensbasis zu durchsuchen und genaue Antworten speziell zu deinen Inhalten zu geben.

Mehrere Bot-Instanzen

Verwende verschiedene Bot-Instanzen für unterschiedliche Zwecke: öffentlicher Chatbot, privater Einzelchat-Bot, Zensurbot und sogar ein multimodaler KI-Co-Host, der sehen und hören kann.

Unterstützte KI-Anbieter

Social Stream Ninja unterstützt mehrere KI-Anbieter, von vollständig lokalen Browser-/Laufzeitmodellen bis hin zu gehosteten APIs:

Ollama (native lokale API)

Kostenlose, auf Datenschutz ausgelegte, selbst gehostete KI-Modelle, die über Ollamas eigene API auf deinem Computer laufen.

Local Gemma 4

Führe Gemma 4 im Browser aus, nachdem du die Modelldateien auf deinen eigenen Asset-Host gespiegelt hast; der SSN-largefiles-Host enthält derzeit keine Gemma-Dateien.

Local Qwen 3.5

Führe Qwen 3.5 im Browser mit deinen selbst gehosteten Modelldateien aus, um lokale, private Antworten zu erhalten.

ChatGPT / OpenAI

OpenAI-APIs einschließlich moderner Chat- und Echtzeit-Sprachmodelle.

Google Gemini

Google-Gemini-Modelle, darunter aktuelle Gemini-2.5-Textmodelle und multimodale Live-Optionen.

DeepSeek

Effiziente, kostengünstige KI-Modelle, die für Gespräche optimiert sind.

xAI (Grok)

xAI-Grok-APIs, einschließlich Echtzeit-Sprachsitzungen mit kurzlebigen Client-Secrets.

AWS Bedrock

KI-Modelle für Unternehmen von verschiedenen Anbietern, darunter Claude und Llama.

OpenRouter

Zugriff auf mehrere KI-Modelle über eine einheitliche API-Schnittstelle.

Groq

OpenAI-kompatible Chat-Inferenz mit geringer Latenz für schnelle Gesprächsantworten.

Eigene API (OpenAI-kompatibel)

Verbinde llama.cpp, LM Studio, vLLM oder einen anderen OpenAI-kompatiblen Endpunkt.

Hinweis: Ollama verwendet seine eigene native API. Für llama.cpp, LM Studio, vLLM oder andere OpenAI-kompatible Server wähle Eigene API.

Integration der Sprachausgabe

Social Stream Ninja bietet umfangreiche TTS-Unterstützung für Bot-Nachrichten und hervorgehobene Chatinhalte:

System-Sprachausgabe

Kostenlose integrierte Sprachausgabe über die Sprachsynthese deines Betriebssystems.

Kokoro

Kostenlose lokale Sprachausgabe über WebGPU/CPU für datenschutzbewusste Benutzer.

Kitten TTS

Leichtgewichtige Sprachausgabe im Browser, die ein kleines Modell für die lokale Spracherzeugung herunterlädt.

ElevenLabs

Premium-Sprachsynthese mit natürlich klingenden, anpassbaren Stimmen.

Google Cloud TTS

Hochwertige Stimmen mit umfangreichen Sprach- und Anpassungsoptionen.

Gemini (Sprachausgabe-Vorschau)

Googles neuronale Sprachmodelle als Vorschau mit wählbaren Stimmen und Sprachen.

Speechify

KI-gestützte Sprachausgabe mit natürlich klingender Stimmumwandlung.

OpenAI TTS

OpenAI-Sprachsynthese mit wählbaren Stimmen, Modellen und optionalen kompatiblen Endpunkten.

Hinweis: Für die Sprachausgabe muss die passende Overlay-Seite in OBS geöffnet sein. Jeder TTS-Anbieter bietet andere Stimmen, Latenzen, Preise oder Hardwareanforderungen.

Bot-Instanzen und Overlays

Social Stream Ninja bietet mehrere Bot-Instanzen für unterschiedliche Anwendungsfälle:

Bot-Typ URL Beschreibung
Haupt-Chatbot /bot.html Hauptbot-Overlay mit optionaler Sprachausgabe und öffentlichen Chatantworten
Private Chatoberfläche /chatbot.html Eigene Seite für einen Einzelchat-Bot, der weder den RAG-Datensatz noch den Chatverlauf des Hauptbots teilt
Zensurbot (läuft im Hintergrund) Filtert, bereinigt oder blockiert eingehende Nachrichten automatisch
KI-Co-Host /cohost.html Multimodale KI, die deinen Bildschirm sehen, Audio hören und interagieren kann

KI-Integration einrichten

So richtest du die KI-Integration im aktuellen Menü ein:

1

LLM-Anbieter auswählen und verbinden

Wähle deinen Anbieter unter LLM-Anbieter konfigurieren (Configure LLM Service Provider) und fülle die passenden Felder aus:

  • Ollama: Installiere es lokal und lege bei Bedarf den Endpunkt fest
  • Local Gemma / Local Qwen: Verwende gehostete Browser-Modelldateien und optional einen abweichenden Modellordner; Qwen kann SSN largefiles verwenden, Gemma benötigt deinen eigenen gespiegelten Ordner
  • ChatGPT, Gemini, DeepSeek, xAI, Groq, OpenRouter, Bedrock: API-Schlüssel und bevorzugtes Modell hinzufügen
  • Eigene API: Gib einen OpenAI-kompatiblen Endpunkt, eine Modell-ID und optional einen API-Schlüssel ein
2

Ausgewählten Chatbot testen

Verwende die integrierte Schaltfläche Ausgewählten Chatbot testen , um Anbieter, Modell und Zugangsdaten zu prüfen, bevor du live gehst.

3

Bot-Verhalten einrichten

Passe das Verhalten des Bots im Chat an:

  • LLM-KI-Chatbot aktivieren (Enable the LLM AI chat bot)
  • Lege Bot-Namen, Auslöserwörter und Ratenlimit für Antworten fest
  • Wähle, ob Antworten zurück in den Chat oder nur auf die Bot-Overlay-Seite gehen
  • Eigene Anweisungen für Tonfall, Rolle und Moderationsregeln hinzufügen
4

Optionale Extras aktivieren

Aktiviere die gewünschten Zusatzfunktionen für den Bot:

  • Aktiviere die Sprachausgabe für Bot-Antworten und wähle einen Anbieter
  • Wähle automatisches Ausblenden nach fester Zeit, abhängig von der Nachrichtenlänge oder nach der Sprachausgabe für /bot.html; verwende clearBotOverlay zum manuellen Leeren
  • Aktiviere RAG und lade Dokumente hoch, um wissensbasierte Antworten zu erhalten
  • Aktiviere den Zensurbot zur Moderation oder für den strikten Blockiermodus
  • Öffnen /bot.html, /chatbot.html, oder /cohost.html je nach Bedarf in OBS oder einem Browser

Steuerung per MIDI & Tastenkürzel

MIDI-Integration

Steuere Social Stream Ninja mit MIDI-Controllern, Tastenkürzeln oder StreamDeck mit MIDI-Plugins.

Voraussetzungen für die Einrichtung

  1. Aktiviere die MIDI-Unterstützung in den Erweiterungseinstellungen
  2. Installiere ein virtuelles MIDI-Loopback-Gerät (z. B. loopMIDI)
  3. Richte deinen MIDI-Controller oder dein StreamDeck-MIDI-Plugin ein
CC-Nummer Wert Aktion Hinweise
102 1 „1“ in den Chat senden Schnelle Reaktion
102 2 „LUL“ in den Chat senden Emote-Reaktion
102 3 Einen Witz erzählen Löst eine Bot-Antwort aus
102 4 Overlay leeren Entfernt die hervorgehobene Nachricht

Tipp: MIDI-Steuerung funktioniert am besten mit physischen Controllern, lässt sich aber auch über virtuelle MIDI-Geräte auslösen.

Tastenkürzel-Unterstützung

Verwende Tastenkürzel für den schnellen Zugriff auf häufige Funktionen.

Tastenkürzel lassen sich in den Menüeinstellungen einrichten und funktionieren systemweit, wenn der Browser den Fokus hat oder die App verwendet wird.

Webhook-Integration

Spendendienste

Social Stream Ninja kann Spenden und Ereignisse von Drittanbieterdiensten über Webhooks empfangen; einige beliebte Dienste sind unten aufgeführt:

Stripe

Verarbeite Kreditkartenspenden direkt über dein Stripe-Konto.

  • Erstelle einen Zahlungslink auf stripe.com
  • Gehe im Stripe-Dashboard zu Developers → Webhooks
  • Endpunkt hinzufügen: https://io.socialstream.ninja/SESSIONID/stripe
  • Wähle das Ereignis checkout.session.completed
  • Hinzufügen &server an deine Dock-URL

Ko-Fi

Erhalte Kaffeespenden von deinen Unterstützern.

  • Melde dich bei deinem Ko-Fi-Konto an
  • Gehe zu Webhook-Einstellungen
  • Hinzufügen https://io.socialstream.ninja/SESSIONID/kofi als Webhook-URL
  • Hinzufügen &server an deine Dock-URL
  • Teste mit der Schaltfläche „Send Single Donation Test“

Buy Me A Coffee

Sammle Spenden über die beliebte Plattform Buy Me A Coffee.

  • Melde dich bei deinem Buy-Me-A-Coffee-Konto an
  • Gehe zu den Webhook-Einstellungen
  • Hinzufügen https://io.socialstream.ninja/SESSIONID/bmac als Webhook-URL
  • Hinzufügen &server an deine Dock-URL, um Ereignisse zu empfangen
  • Spenden- und Mitgliedschaftsereignisse werden unterstützt

Sicherheitshinweis: Halte deine Sitzungs-ID geheim, denn jeder, der sie kennt, kann falsche Spenden an dein Overlay senden. Die Webhook-URL sollte als vertrauliche Information behandelt werden.

Integration externer Dienste

Social Stream Ninja kann auch Daten an Drittanbieterdienste senden:

Dienst URL-Parameter Beschreibung
Singular Live &singular=IDENTIFIER Sendet ausgewählte Nachrichten an Singular Live für das Overlay hervorgehobener Nachrichten
H2R &h2r=IDENTIFIER Sendet ausgewählte Nachrichten an einen lokalen H2R-Server
Allgemeines POST &postserver=URL Sendet ausgewählte Nachrichten per POST an einen eigenen Endpunkt
Allgemeines PUT &putserver=URL Sendet ausgewählte Nachrichten per PUT an einen eigenen Endpunkt

Diese Parameter sollten an die URL der Dock-Seite angehängt werden.

Eigenes JavaScript

Du kannst eigene Befehle und Funktionen erstellen, indem du den JavaScript-Code anpasst:

  2. Bearbeite die Datei, um eigene Funktionen hinzuzufügen

Eigene Overlays

Eigene Overlays erstellen

Du kannst vollständig eigene Chat-Overlays von Grund auf erstellen, passend zum Stil und zur Funktion deines Streams. Social Stream Ninja bietet dafür eine flexible Grundlage.

Mit einer Vorlage beginnen

Beginne mit unserer Overlay-Beispielvorlage, um die Grundlagen zu verstehen:

// View the sample overlay
https://socialstream.ninja/sampleoverlay?session=SESSIONID

Diese minimale Vorlage enthält nur den wesentlichen Code für ein funktionierendes Overlay.

Beispieloverlay anzeigen

Wichtige anpassbare Funktionen

  • Zwischen hervorgehobenen Nachrichten und der Anzeige aller Nachrichten wechseln
  • Passe das Erscheinungsbild mit CSS an
  • Eigene Animationen für neue Nachrichten hinzufügen
  • Eigene Nachrichtenfilterung umsetzen
  • Interaktive Elemente mit JavaScript hinzufügen

Umsetzungsschritte

  1. Lade die HTML-Datei des Beispieloverlays herunter
  2. Bearbeite das HTML für dein eigenes Layout
  3. Passe das CSS an die gewünschte Darstellung an
  4. Passe das JavaScript nach Bedarf für eigenes Verhalten an
  5. Speichere die Datei lokal, um sie in OBS als Browserquelle zu verwenden

Timer-API

Fernsteuerung von timer.html

Die Timer-Seite hat bewusst einen begrenzten Funktionsumfang: ein Timer, optionale Bedienfelder, Warnzustände, Überzeit und einige Darstellungsstile.

Nützliche Aktionen sind starttimer, pausetimer, resettimer, timeradd, timersubtract, und settimer.

{
  "action": "settimer",
  "value": {
    "seconds": 300,
    "label": "Interview",
    "mode": "countdown",
    "style": "stage",
    "warnSeconds": 60,
    "dangerSeconds": 15
  }
}

Um den aktuellen Timer-Zustand abzufragen, verwende gettimerstate mit einem Callback-Token.

{ "action": "gettimerstate", "get": "timer-state-1" }

Verwende die Seite mit timer.html?session=YOUR_SESSION&server wenn du ihn direkt über den API-Server steuern möchtest.

Befehle für verwaltete Gewinnspiele

startgiveaway, closegiveaway, drawgiveaway, resetgiveaway, und getgiveawaystate steuern den eigenen Gewinnspiel-Pool mit denselben API-/Stream-Deck-Bedienelementen. Die Auslosung schließt die Teilnahme automatisch. Eine neue Runde bewahrt den bisherigen Gewinnerverlauf und verwirft unbezahlte Reservierungen. „Cancel and refund“ erstattet ausstehende Ticketzahlungen. Bezahlte Tickets, Number Hunt, Coin Flip Pot und Event Flow verwenden denselben Host-Dienst. Einrichtung, Darstellungen, Befehlswerte und Wiederherstellung.
