Overlay-Galerie

Vorschau für Chat, hervorgehobene Nachrichten und Benachrichtigungen in deinem Stream.

Einrichtungsanleitung Chat-Widget importieren Verkaufs-Overlays
Ein Overlay für deinen Stream verwenden

Gib die Sitzungs-ID aus Social Stream Ninja ein und wähle dann Overlay öffnen auf einer Karte. Kopiere diesen Link in eine OBS-Browser-Quelle. Featured-Overlays zeigen im Dock ausgewählte Nachrichten; Mehrfachbenachrichtigungen zeigen eingehende Ereignisse.

ZUSAMMENPASSENDES SET

Füge jeden Link als separate OBS-Browser-Quelle hinzu. Hervorgehobene Nachrichten kommen aus deinem Dock; Benachrichtigungen reagieren auf eingehende Ereignisse.

Diese Felder bleiben auf dieser Seite und werden nicht gespeichert. Verwende für Servermodus, Filter, automatisches Ausblenden und andere Optionen die entsprechende Voreinstellung in der App.

Keine passenden Overlays. Probiere eine andere Suche oder wähle „Alle Overlays“.
