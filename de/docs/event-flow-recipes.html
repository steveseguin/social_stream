Event-Flow-Beispiele

Anleitung zu Gewinnspielen, bezahlten Losen, Spielpreisen und Wiederherstellung

Erstelle nützliche Automatisierungen Schritt für Schritt mit kleinen Beispielen.

Wofür Event Flow gedacht ist

Eigenen Ablauf über eine Stream-Deck-Taste oder einen HTTP-/WebSocket-/P2P-API-Aufruf ausführen.

Event Flow ist der Editor für erweiterte Automatisierungen. Verwende ihn, wenn Popup-Schalter nicht ausreichen: Chat filtern, Medien auslösen, Nachrichten weiterleiten, Webhooks aufrufen oder OBS steuern.

Vor jeder Anleitung

  1. Verwende eine Testplattform und eine Social-Stream-Sitzung.
  2. Öffne das Dock und prüfe, ob Chat ankommt.
  3. Öffnen actions.html?session=YOUR_SESSION wenn das Beispiel Audio oder Medien abspielt oder OBS steuert.
  4. Teste vor dem Livestart mit einer künstlichen Nachricht oder einem sicheren Auslöser.
  5. Exportiere einen funktionierenden Flow vor einer größeren Änderung.

Häufige Lösungen

  • Nichts passiert: prüfe zuerst, ob das Quellereignis im Dock ankommt.
  • Audio oder Medien werden nicht abgespielt: lass actions.html mit derselben Sitzung geöffnet und prüfe dann den Leitfaden zum Medienhosting für Event Flow.
  • OBS-Aktion schlägt fehl: prüfe OBS WebSocket v5, Port 4455, Passwort und Berechtigungen.
  • Flow wird zu oft ausgelöst: füge einen strengeren Plattform-, Ereignis-, Schlüsselwort- oder Benutzerfilter hinzu.
