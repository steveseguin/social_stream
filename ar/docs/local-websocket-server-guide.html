وضعا WebSocket المستضاف والخادم المحلي

استخدم مسارات WebSocket المستضافة في Social Stream لإعدادات إضافة Chrome وتطبيق سطح المكتب المعتادة. شغّل مرحّلًا محليًا فقط عندما تحتاج إليه تحديدًا.

أي وضع ينبغي أن أستخدم؟تفعيل وضع WebSocket المستضافما تفعله معاملات الخادم الثلاثةمتقدم: استخدام خادم SSApp المحليخيارات محلية متقدمةالمشكلات الشائعةأدلة ذات صلة

أي وضع ينبغي أن أستخدم؟

ينبغي لمعظم المستخدمين عدم تفعيل الخادم المحلي. يمكن لإضافة Chrome وإعدادات SSApp العادية استخدام خدمة WebSocket المستضافة في Social Stream بتفعيل مفاتيح التوجيه أدناه. الخادم المحلي بديل متقدم للمرحّل المستضاف.

الوضعمتى تستخدمه
WebRTC عادياحتفظ بالإعدادات الافتراضية عندما تكون لوحة الإرساء والتراكبات متصلة بالفعل بصورة موثوقة. لا تحتاج إلى معاملات خادم.
WebSocket مستضافخيار الرجوع المعتاد إلى الخادم لإضافة Chrome أو SSApp. يستخدم مرحّل Social Stream العام المستضاف ولا يتطلب ملف > تفعيل الخادم المحلي (File > Enable Local Server).
الخادم المحلي (Local Server)للاستخدام المتقدم فقط: استضف المرحّل بنفسك على جهاز SSApp، أو استخدمه عندما يتعذر على شبكة إقليمية أو مؤسسية أو مقيدة الوصول إلى خدمة WebSocket العامة المستضافة.

تفعيل وضع WebSocket المستضاف

  1. افتح النافذة المنبثقة لإضافة Social Stream Ninja أو لوحة الإعدادات في SSApp.
  2. افتح الإعدادات والأدوات العامة > آليات العمل - الاتصالات والتكاملات (Global settings and tools > Mechanics - Connections & Integrations).
  3. تفعيل تمكين لوحة الإرساء من استخدام خادم API والنشر عبره. يضيف هذا server إلى الروابط المُنشأة المدعومة.
  4. تفعيل إرسال الرسائل إلى لوحة الإرساء من الإضافة عبر الخادم. يضيف هذا server2 وينقل الدردشة الملتقطة إلى لوحة الإرساء.
  5. إذا أردت الردود أو أوامر الإشراف والمصادر التي تنتقل من لوحة الإرساء إلى الإضافة، ففعّل ترسل لوحة الإرساء أوامرها إلى الإضافة عبر الخادم. يضيف هذا server3.
  6. اترك تجريبي/مؤقت: إرسال الدردشة الموجّهة عبر API أيضًا إلى اتصالات لوحة الإرساء والتراكبات العادية معطلًا ما لم تكن تختبر تحديدًا الإيصال الإضافي.
  7. اترك اتصالات نظير إلى نظير عبر الشبكة المحلية فقط معطلًا للإعداد المستضاف العادي.
  8. انسخ روابط جديدة للوحة الإرساء والتراكبات، واستبدل عناوين URL القديمة المحفوظة في OBS، وأعد فتح أي صفحات كانت تعمل بالفعل.

إذا أتاحت لوحة الإرساء تفعيل الرجوع إلى الخادم (Enable Server Fallback)، فإن هذا الاختصار يفعّل مساري الرجوع للدردشة والأوامر معًا. افتح قسم الإعدادات هذا وتأكد من أن مفتاح تمكين لوحة الإرساء من استخدام خادم API والنشر عبره الأول مفعّل أيضًا للحصول على إعداد المسارات الثلاثة الكامل.

ما تفعله معاملات الخادم الثلاثة

المعاملالاتجاهاستخدم
serverمسار لوحة الإرساء/APIيتيح لصفحات لوحة الإرساء وAPI المدعومة استخدام مسار الخادم المستضاف والنشر عبره.
server2من الإضافة إلى لوحة الإرساءيرسل رسائل الدردشة الملتقطة إلى لوحة الإرساء عبر الخادم المستضاف.
server3من لوحة الإرساء إلى الإضافةيعيد الردود والأوامر المدعومة إلى الإضافة. وهو اختياري للوحة إرساء مخصصة للعرض فقط.

قد يحتوي رابط لوحة الإرساء ثنائي الاتجاه المُنشأ على:

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID&server&server2&server3

انسخ الروابط المُنشأة بدلًا من إضافة المعاملات يدويًا إلى كل صفحة. يختلف دعم التوجيه بين لوحة الإرساء والتراكبات والتنبيهات والألعاب وصفحات الأدوات.

متقدم: استخدام خادم SSApp المحلي

يستبدل الخادم المحلي نقطة نهاية WebSocket العامة المستضافة بمرحّل يعمل داخل تطبيق سطح المكتب Social Stream Ninja. استخدمه عندما تريد عمدًا استضافة المرحّل بنفسك أو يتعذر الوصول إلى الخادم العام من شبكتك أو منطقتك.

هذا مرحّل وليس مضيف موقع. لا يقدم واجهة SSN ولا يلتقط دردشة المنصات بمفرده ولا يكشف واجهة التحكم المحلية API.

  1. أكمل إعداد مفاتيح المسارات المستضافة أعلاه. تظل اتجاهات server, server2، و server3 نفسها سارية.
  2. في SSApp، اختر ملف > تفعيل الخادم المحلي (File > Enable Local Server). تعرض القائمة المنفذ المحدد.
  3. انسخ روابط جديدة للوحة الإرساء والتراكبات. يضيف SSApp localserver والقيمة النشطة لـ localserverport حيث يكون ذلك مدعومًا.
  4. استبدل عناوين URL القديمة المحفوظة في OBS وأعد فتح الصفحات النشطة.
  5. أرسل رسالة اختبار وهمية، ثم اختبر ردًا أو أمرًا من لوحة الإرساء إذا كان server3 مفعّل.

تستخدم عمليات التثبيت الجديدة عادةً 127.0.0.1:3003. قد تستمر نسخة جرت ترقيتها وكانت تستخدم المنفذ 3000 في استخدامه. قد يحتوي رابط لوحة إرساء محلي ثنائي الاتجاه مُنشأ على:

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID&server&server2&server3&localserver&localserverport=3003

للألعاب المصغرة، فعّل إرسال الرسائل إلى لوحة الإرساء من الإضافة عبر الخادم وانسخ رابط اللعبة بعد اختيارها. روابط الألعاب المحلية التي تتضمن server2 تستقبل الدردشة الملتقطة مباشرة من SSApp، حتى دون فتح لوحة إرساء. يحافظ تغيير الألعاب على الوضع المحلي والمنفذ.

يستخدم مثال API وأداة رسالة الاختبار WebSocket في الوضع المحلي. لا يقبل المرحّل المحلي عناوين HTTP GET أو POST أو خطافات الويب الخاصة بواجهة API العامة. تحتاج مستقبلات خطافات الويب العامة إلى المرحّل المستضاف؛ أما المستقبلات الموثوقة الخاصة بالمزودين فهي خدمات منفصلة.

لا يجعل الخادم المحلي كل الميزات تعمل دون إنترنت. لا تزال Waitlist وWord Cloud وCustom GIF Commands وطلبات chatbot الخاصة وجسور التحكم بالذكاء الاصطناعي والمقدّم المشارك تستخدم WebRTC لبعض الاتصالات أو كلها. وقد تظل ملفات الموقع ودردشة المنصات وخدمات الذكاء الاصطناعي والصوت والموسيقى والدفع الخارجية بحاجة إلى اتصال بالإنترنت.

خيارات محلية متقدمة

استخدام منفذ آخر

  1. اختر ملف > تعيين منفذ الخادم المحلي (File > Set Local Server Port).
  2. اختر منفذًا غير مستخدم من 1024 عبر 65535.
  3. انسخ روابط مُنشأة حديثًا كي تتضمن قيمة localserverport.
  4. استبدل عناوين URL المحفوظة في OBS وأعد فتح الصفحات النشطة.

لا يغير تعديل هذا المنفذ واجهة التحكم المحلية API على 17777 أو خادم الوسائط المحلي على 3001.

وصول اختياري عبر LAN موثوقة

ملف > السماح باتصالات الخادم المحلي من LAN ‏(File > Allow Local Server Connections from the LAN) يغيّر المرحّل من الاستماع على loopback فقط إلى الاستماع على واجهات شبكة الكمبيوتر. يجب أن يتصل العميل على جهاز آخر بعنوان LAN لجهاز SSApp، وليس 127.0.0.1.

لا يتضمن وضع LAN مصادقة أو تشفيرًا. استخدمه فقط على شبكة خاصة موثوقة. لا تعِد توجيه منفذه ولا تكشفه للإنترنت. للتحكم المعتاد بين الأجهزة عبر الإنترنت، استخدم نقل WebRTC أو WebSocket المستضاف الحالي في Social Stream.

المشكلات الشائعة

المشكلةما يجب التحقق منه
تظل لوحة الإرساء أو التراكب فارغًاتأكد من أن المصدر والصفحة يستخدمان الجلسة وكلمة المرور نفسيهما. في الوضع المستضاف، تأكد من أن server و server2 موجودة في رابط لوحة إرساء نُسخ حديثًا.
تصل الدردشة لكن الردود تفشلمسارا الرسائل الواردة والأوامر منفصلان. فعّل ترسل لوحة الإرساء أوامرها إلى الإضافة عبر الخادم حتى يتضمن الرابط server3.
WebSocket المستضاف لا يتصلقد تحظر شبكة إقليمية أو شبكة شركة أو مدرسة أو شبكة مصفاة المرحّل العام. جرّب شبكة أخرى أولًا؛ ويمكن لمستخدمي SSApp المتقدمين استخدام Local Server بدلًا منه.
يستخدم الرابط المنفذ 3000 لكن SSApp يعرض 3003استبدل الرابط القديم. تضيف عمليات التثبيت الجديدة localserverport=3003؛ قد تحتفظ النسخ الأقدم عمدًا بالمنفذ 3000.
الخادم المحلي لا يبدأقد يستخدم برنامج آخر المنفذ. اختر منفذًا آخر غير مستخدم وأعد تشغيل المرحّل وانسخ الروابط مجددًا.
الانضمام إلى الألعاب يعمل بصورة متقطعةانسخ رابط اللعبة مجددًا بعد تحديد الإعداد المسبق. تأكد من تطابق جلسته و localserverport، ومسار الدردشة الواردة مع SSApp. لا تتغير عناوين URL المحفوظة في OBS تلقائيًا عند تبديل Local Server أو تغيير منفذه.
يعرض Event Flows خطأ في تحميل الخلفيةيتعلق هذا بملفات الموقع لا بمرحّل الدردشة. أعد محاولة التحميل عند استعادة الاتصال. يحافظ تبديل المرحّل على أصل تخزين Event Flow المحدد؛ وقد يفتح التشغيل المنفصل دون إنترنت الواجهة المضمّنة بتخزينها الخاص.
جهاز LAN لا يستطيع الاتصالتأكد من تفعيل الوصول من LAN، ومن استخدام العميل عنوان LAN لجهاز SSApp، ومن سماح جدار الحماية بالمنفذ المحدد.
