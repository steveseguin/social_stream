الطابعات الحرارية وملصقات البث

حوّل المشتريات والتبرعات وأحداث الدردشة إلى إيصالات أو ملصقات أو تذاكر أو بطاقات استلام فعلية.

ما الذي يمكن طباعته؟

يستطيع تطبيق Windows المستقل إرسال مهام بصمت إلى طابعة مثبتة في Windows. يمكن للتدفق الجمع بين أي قيم متاحة مثل اسم مشاهد أو تبرع أو منتج أو رسالة أو قيمة عداد، والتحكم في حجم النص ومحاذاته.

قاعدة التوافق: يجب أن تظهر الطابعة كقائمة طباعة Windows عاملة. يطبع Social Stream عبر برنامج تشغيل Windows المثبت؛ ولا يرسل أوامر ESC/POS أو ZPL خامًا أو أوامر SDK للمصنّع.

إعداد سريع

  1. وصّل الطابعة عبر USB وشغّلها وثبّت برنامج تشغيلها في Windows. اطبع صفحة اختبار Windows أولًا.
  2. في Social Stream، افتح الإعدادات والأدوات العامة → التحكم في الطابعة (Printer Control).
  3. اختر العثور على الطابعات (Find printers) واختر اسم قائمة الطباعة الدقيق الذي يعرضه Windows.
  4. أدخل عرض الورق الفعلي، وغالبًا يكون 58, 80، أو 62 mm حسب الجهاز والورق.
  5. اترك طول الملصق الثابت (Fixed label length) على 0 لإيصال بحجم المحتوى. للورق المقصوص مسبقًا، أدخل طول الملصق باتجاه التغذية بالمليمتر.
  6. اختر طباعة اختبار محاذاة (Print alignment test). إذا كانت حافة مفقودة، فزد الهامش الآمن لتلك الجهة واختبر مجددًا.

تناسب الهوامش الآمنة الافتراضية 2 mm يسارًا ويمينًا كثيرًا من طابعات الإيصالات الرخيصة بعرض 58 mm، لكن برنامج التشغيل يحدد مساحة الطباعة الفعلية. أبقِ استخدام المساحة القابلة للطباعة (Use printable area) محددًا ما لم تكن اختبرت إعدادًا مختلفًا.

بكرة إيصالات أم ملصقات مستمرة أم ملصقات مقصوصة مسبقًا؟

بكرة إيصالات

الأنسب لإيصالات الشراء وتذاكر الانتظار وإيصالات الداعمين متغيرة الطول. اترك طول الملصق الثابت عند 0 ودع المحتوى يحدد طول الورق.

بكرة ملصقات مستمرة

مناسب لأشرطة أسماء لاصقة بكميات نص متفاوتة. يعمل كورق الإيصالات، لكن يجب أن تتولى الطابعة أو برنامج التشغيل القص.

ملصقات مقصوصة مسبقًا

الأنسب للشارات وملصقات المنتجات المتجانسة. اضبط الطول الثابت الدقيق وهيّئ نوع الورق نفسه في تفضيلات الطباعة في Windows.

مثال طابعةمفيد لـملاحظات الاتصال والورق
طابعة «POS-58» عامةإيصالات مستمرة منخفضة التكلفة بعرض 58 mmعادةً USB وحرارية مباشرة. تختلف أسماء الطرازات وبرامج التشغيل حسب البائع. استُخدمت قائمة طباعة POS-58 أساسية في اختبار Social Stream الفعلي أثناء التطوير.
Epson TM-T20IIIخيار أكثر رسوخًا لطابعات الإيصالاتطراز USB؛ يدعم ورق 80 mm وورق 58 mm باستخدام محوّل العرض المرفق.
Brother QL-800ملصقات USB وملصقات عناوين وأسماءطباعة حرارية مباشرة وورق حتى 62 mm، وبكرات مقصوصة مسبقًا أو مستمرة، مع قاطع تلقائي.
Brother QL-820NWBمحطة ملصقات مشتركة أو شبكيةتدعم USB وEthernet وWi-Fi وBluetooth مع مجموعة ملصقات Brother المقصوصة مسبقًا والمستمرة.
Zebra ZD220ملصقات أعرض للمنتجات أو الشحن أو الأساور أو الاستخدام المتينطابعة ملصقات USB مكتبية لورق بعرض نحو 25–112 mm؛ متاحة بإعدادات حرارية مباشرة ونقل حراري.

هذه أمثلة وليست قائمة توافق مضمونة. قبل الشراء، تأكد من أن الطراز المحدد لديه برنامج تشغيل Windows حالي، ويدعم أبعاد ملصقاتك، ويظهر كطابعة Windows عادية.

طباعة ملصق تبرع باستخدام Event Flow

💰 تبرع / إكرامية (Donation / Tip)الحد الأدنى للمبلغ: 10
→
🖨️ طباعة ملصق حراري (Print Thermal Label){username}
{donation}
24 pt · عريض · في الوسط
  1. افتح محرر Event Flow وأنشئ تدفقًا.
  2. أضف محفز تبرع / إكرامية (Donation / Tip) . اضبط الحد الأدنى للمبلغ (Minimum Amount) إذا كان ينبغي طباعة التبرعات الأكبر فقط.
  3. أضف طباعة ملصق حراري (Print Thermal Label) من Integrations واربط المحفز به.
  4. اضبط نص الملصق على {username}، وأضف سطرًا جديدًا، ثم {donation}. اختر حجم الخط وسُمكه ومحاذاته وعدد النسخ.
  5. اترك عادةً تجاوزات الطابعة والطول الثابت في الإجراء فارغة أو 0 لتطبيق إعدادات Printer Control العامة.
  6. افتح اختبار التدفق (Test Flow)، وأدخل اسمًا، وفعّل تتضمن تبرعًا (Has Donation)، وأدخل مبلغًا، وشغّل الاختبار. يرسل هذا مهمة طباعة حقيقية في التطبيق المستقل.

تشمل النصوص النائبة المفيدة الأخرى {message}, {source}, {donationAmount}، و {counterValue}. يمكن أيضًا استخدام القيم التي أنشأتها عقد سابقة في قالب الطباعة.

اجعل اسم المشتري عريضًا والعنصر عاديًا

اختر سُمك الخط → النص المحدد (**عريض**) (Weight → Selected text (**bold**))، ثم أدخل:

**{username}**
{subtitle}

استخدم أقواسًا معقوفة مفردة. تضع تكاملات التجارة الحديثة عنوان المنتج في subtitle؛ وقد تتوفر الكمية في {meta.commerce.quantity}. إذا كانت عقدتك السابقة تنشئ buyer، استخدم **{buyer}** بدلًا من ذلك. يحذف Shopify وeBay هوية المشتري، لذا استخدم عداد طلبات محليًا أو بطاقة منتج فقط لهذين المصدرين. فقط النص المحاط بـ ** يصبح عريضًا؛ ولا يلزم JavaScript أو HTML مخصص. تحتفظ ملصقات All bold وNormal الحالية بتنسيقها.

للمبيعات، استخدم Event Type مع purchase؛ يتطلب Donation / Tip hasDonation ولن يطابق معظم المبيعات. استخدم gift أو giftfunded عندما يشير الملصق إلى هدية مكتملة، وصفِّ المزود عند الحاجة. أضف Counter قبل إجراء الطباعة عندما تريد رقم طلب متسلسلًا واحدًا للبث. راجع حقول أحداث التجارة.

يتيح الإجراء meta.thermalPrintResult.success وخطأ أو رمزًا اختياريًا لخطوات التدفق التالية. النجاح يعني إرسال المهمة وليس خروج الورق. تحقق من قائمة طباعة Windows قبل إعادة محاولة مهمة غير مؤكدة لتجنب الملصقات المكررة.

يرقّم Counter المشتريات، وليس المشترين الفريدين. يتطلب استخدام معرّف واحد لكل مشتريات المشتري نفسه ربطًا منفصلًا بين المشتري والمعرّف وإعادة تعيين صريحة عند بداية كل بث. حقل السبب في User Memory نص وصفي وليس عدادًا مخصصًا لمعرّفات المشترين.

ملصقات عناصر Whatnot

تنزيل تدفق Whatnot النموذجي. يطبع اسم المشتري بخط عريض واسم العنصر ومعرّف الطلب عند توفره. ويطبع إشعار فشل الدفع ملصقًا منفصلًا بعنوان فشل الدفع بالتفاصيل المتاحة في ذلك الإشعار.

  1. في التطبيق المستقل، هيّئ التحكم في الطابعة (Printer Control) لطابعتك وحجم الورق، وشغّل اختبار المحاذاة.
  2. افتح محرر Event Flow، اختر استيراد (Import)، وحدد ملف JSON المُنزَّل.
  3. اختر Whatnot: ملصقات العناصر + تحذيرات الدفع. راجع إجراءَي الطباعة؛ فكلاهما يرث الطابعة العامة وطول الملصق العام.
  4. فعّل التدفق واحفظه. أبقِ مصدر Whatnot مفتوحًا مع تفعيل التقاط أحداث البث.

يُستورد المثال معطلًا. يستخدم نوع الحدث (متقدم) → حدث مخصص (Event Type (Advanced) → Custom Event) لـ product_sold و payment_failed، مع عامل تصفية مصدر Whatnot. لا تطبع المزايدات وإشعارات انتهاء المزاد ملصقات.

ملصق البيع لا يؤكد الدفع. يطبع هذا المثال كل إشعار عند وصوله؛ ولا ينتظر الدفع أو يعدّل ملصقًا سابقًا أو يخصص أرقام مشترين. تُطبع الحقول المفقودة فارغة. لا يستطيع إشعار فشل لا يحتوي على تفاصيل المشتري أو العنصر أو الطلب تحديد الملصق السابق. راجع حقول أحداث Whatnot.

ملصقات بطول ثابت دون مفاجآت

ملصقات 3 × 1 بوصة (بما فيها إعداد Munbyn BT320): استخدم عرض 76.2 mm وطولًا ثابتًا 25.4 mm عندما يكون جانب البوصة الواحدة هو اتجاه التغذية. طابق نوع الورق واتجاهه في Printing Preferences في Windows. ابدأ بخط 12–14 pt واختبر اسم مشتري وعنصر طويلين.

تحدد الحدود الجانبية لاختبار المحاذاة العرض الآمن بعد إعداد المساحة القابلة للطباعة والهوامش الآمنة المحددة. يتبع ارتفاع الصندوق نص الاختبار؛ ولا يحدد الملصق كاملًا أو يلامس حواف الورق الفعلية.

  • قِس في اتجاه تغذية الورق. يستخدم ملصق 62 × 29 mm عادةً عرض ورق 62 mm وطول ملصق ثابت 29 mm.
  • طابق إعداد Windows أيضًا. حدد نوع الملصق الدقيق واتجاهه واستشعار الفجوات أو العلامات وسلوك القاطع في Printing Preferences لبرنامج تشغيل الطابعة.
  • الثابت يعني ثابتًا. لا يضيف Social Stream مساحة تغذية الإيصالات إلى مهمة ثابتة الطول. قد يُقص المحتوى الطويل جدًا أو يمتد خارج الملصق حسب برنامج التشغيل.
  • اختبر أطول بيانات واقعية. تحتاج أسماء المشاهدين الطويلة ومتغيرات المنتجات وتسميات العملات والأسطر المتعددة إلى مساحة أكبر أو خط أصغر.
  • تظل قيود برنامج التشغيل سارية. قد يفرض Windows أو برنامج تشغيل الطابعة حدًا على الصفحات المخصصة القصيرة جدًا؛ يطلب Social Stream حدًا أدنى 20 mm.

أفكار للبث

  • اطبع ملصقات بأسماء الداعمين لجدار أو قطعة ديكور أو خريطة أو لوحة تقدم فعلية.
  • أنشئ بطاقات طلبات المنتجات أو الأعمال المكلفة أو المشروبات أو الاستلام عند وصول المشتريات.
  • اطبع تذاكر سحب أو قسائم مشاركة، مع تحديد المعدل وفحص الأهلية قبل إجراء الطباعة.
  • أنشئ شارات VIP أو تعيينات فرق أو رموز تحديات أو ملصقات إنجازات التبرع.
  • اطبع قائمة انتظار قصيرة للإشراف أو تنفيذ الطلبات لمنتج يعمل بجوار مقدم البث.
فكّر قبل طباعة البيانات الشخصية. تجنب العناوين والبريد الإلكتروني وتفاصيل الدفع والرسائل الخاصة. يبهت الورق الحراري أيضًا بالحرارة والضوء والوقت، لذا فهو غير مناسب للأرشفة.

حلول شائعة

  • لا تظهر طابعة: تأكد من أن Windows يستطيع طباعة صفحة اختبار، ثم أعد تشغيل Social Stream واختر Find printers مجددًا.
  • تبلغ المهمة عن النجاح لكن لا يُطبع شيء: افتح قائمة Windows لتلك الطابعة وافحص أخطاء الإيقاف المؤقت أو عدم الاتصال أو الورق أو برنامج التشغيل أو المنفذ.
  • إحدى الحواف مقطوعة: أبقِ Use printable area مفعّلًا وزد الهامش الآمن لتلك الجهة.
  • يوجد ورق فارغ أكثر من اللازم: استخدم طولًا ثابتًا 0 للإيصالات، وقلّل الهامش السفلي والتغذية، أو اضبط الطول الدقيق لورق الملصقات.
  • ملصق واحد يصبح اثنين: المحتوى أطول من الملصق الثابت، أو يستخدم Windows حجم ورق خاطئًا. قلّل النص وحجم الخط وتباعد الأسطر والهوامش.
  • تُستخدم طابعة خاطئة في Test Flow: اختر تجاوزًا للطابعة في عقدة Print Thermal Label. يستخدم التجاوز الفارغ طابعة Windows الافتراضية عند الاختبار مباشرة في المحرر.
