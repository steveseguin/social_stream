استخدام مظهر دردشة StreamElements

استورد أداة دردشة مخصصة وعاينها مع Social Stream Ninja ونزّل ملفًا لـOBS.

ما الذي يعمل؟

أداة الاستيراد مخصصة لـ أدوات الدردشة المخصصة المصممة لـStreamElements أو Streamlabs، بما فيها مكوّن الدردشة في حزمة مظهر. تحتاج إلى ملفات مصدر الأداة. ولا تستورد الأداة حساب StreamElements كاملًا أو مظهرًا من رابط تراكب.

استخدم إما تطبيق SSN لسطح مكتب Windows أو إضافة Chrome لالتقاط الدردشة. يعرض المظهر المستورد تلك الدردشة في OBS. يعتمد التوافق على الأداة؛ وقد تحتاج ميزات الحساب مثل الأهداف والولاء والمتاجر والتنبيهات إلى تحويل يدوي.

1. الحصول على ملفات الأداة

ابدأ بملف ZIP أو المجلد الأصلي من المصمم. ابحث عن HTML وCSS وJavaScript، بالإضافة إلى أي ملفات JSON للحقول والبيانات والصور والخطوط. اختر أداة دردشة واحدة عندما تحتوي الحزمة على عدة تصاميم.

لديك رابط تثبيت فقط؟ اطلب من المصمم مصدر أداة الدردشة، أو استخدم الشفرة المتاحة في محرر الأداة المخصصة في StreamElements. لا يمكن تحويل لقطة شاشة أو فيديو أو رابط مصدر متصفح وحده.

شفرة أداتي موجودة في محرر StreamElements

افتح محرر شفرة الأداة المخصصة. احفظ كل جزء متاح كملف نص عادي منفصل: html.txt, css.txt, js.txt, fields.txt و data.txt. انسخ المحتوى دون إضافة تنسيق أو تغيير JSON. إذا لم يتوفر ملف بيانات، تستخدم أداة الاستيراد القيم الافتراضية في fields.

اختر جميع هذه الملفات معًا باستخدام اختيار ملفات (Choose Files). أدرج أي رسومات أو خطوط محلية؛ اختيار مجلد (Choose Folder) يحافظ على مسارات المجلدات. راجع مرجع محرر شفرة StreamElements لمعرفة بنية الشفرة والحقول.

استورد فقط الشفرة التي تثق بها: يعمل JavaScript الخاص بالأداة في المعاينة والتراكب المُنزَّل.

2. فتح أداة الاستيراد

في قائمة SSN، أسفل قسم تراكبات دردشة منسقة مسبقًا، ابحث عن الخيار استيراد مظهر دردشة StreamElements / Streamlabs. يملأ هذا جلستك الحالية. يمكنك أيضًا البحث في القائمة عن StreamElements أو افتح أداة الاستيراد مباشرة.

استخدم اختيار ZIP ‏(Choose ZIP), اختيار ملفات (Choose Files) أو اختيار مجلد (Choose Folder). تُحمَّل معاينة تجريبية بعد معالجة الملفات. تحقق من أي تحذيرات استيراد؛ واستخدم اختيار الملفات المتقدم (Advanced file selection) إذا اكتُشفت ملفات مصدر غير صحيحة.

3. الاتصال والمعاينة

  1. أبقِ SSN قيد التشغيل وتأكد من ظهور رسالة حقيقية في لوحة إرساء الدردشة.
  2. تحقق من حقل معرّف جلسة SSN / معرّف البث. إذا كان فارغًا، فانسخه من خيارات الجلسة (Session Options) في SSN. هذا ليس اسم المستخدم في Twitch أو YouTube.
  3. أدخل كلمة مرور الجلسة الاختيارية إذا كنت تستخدمها.
  4. استخدم معاينة تجريبية (Demo Preview) للرسائل النموذجية، ثم معاينة مباشرة (Live Preview) وأرسل رسالة دردشة جديدة إلى بثك.
  5. إذا كان سجل الرسائل (Message history) يظهر، فاضبط إزالة الرسائل بعد مدة محددة أو الحد الأقصى لعدد الرسائل.

تعمل Demo Preview دون جلسة وتستخدم رسائل نموذجية فقط. تحتاج Live Preview إلى وصول دردشة من SSN؛ ولا يعني فراغ المعاينة وحده فشل الاتصال.

4. التنزيل والإضافة إلى OBS

  1. انقر على تنزيل HTML لـOBS ‏(Download OBS HTML) واحفظه في مكان دائم.
  2. في OBS، أضف مصدر المتصفح، فعّل ملف محلي، وحدد ملف HTML ذلك.
  3. اضبط العرض والارتفاع لمساحة الدردشة، ثم أرسل رسالة أخرى للتحقق منها.

جلستك مضمّنة بالفعل؛ لا يلزم تعديل الرابط في OBS. استخدم الملف المُنزَّل كمصدر المتصفح. أبقِ SSN ومصادر التقاط الدردشة قيد التشغيل؛ ويمكنك إغلاق أداة الاستيراد وStreamElements.

يحتوي الملف المُصدَّر على معرّف جلستك وكلمة المرور الاختيارية. احتفظ به خاصًا. لتغيير الجلسة أو كلمة المرور أو إعدادات الأداة لاحقًا، استورد الملفات الأصلية مجددًا ونزّل بديلًا، ثم حدّث مصدر OBS.

إذا لم يعمل شيء

  • لم يُعثر على شفرة أداة: استخدم ملفات المصدر الأصلية. الصور وملفات الحقول والبيانات وحدها وملفات SSN المحولة سابقًا ليست مصدر أداة.
  • المعاينة التجريبية فارغة أو تبدو خاطئة: تحقق من HTML/CSS/JS ضمن Advanced file selection. قدم ملفات الحقول والبيانات المطابقة وجميع الأصول.
  • المعاينة التجريبية تعمل، لكن Live Preview فارغة: أرسل رسالة جديدة، وافحص لوحة إرساء SSN، وطابق معرّف الجلسة وكلمة المرور.
  • المعاينة المباشرة تعمل، لكن OBS فارغ: تحقق من ملف HTML المحلي المحدد وأبعاد مصدر المتصفح وظهوره، ثم حدّث ذاكرته المؤقتة.
  • خطوط أو رسومات مفقودة: افحص ملخص التصدير. تظل الموارد البعيدة التي تعذر تضمينها بحاجة إلى رابط يمكن الوصول إليه واتصال بالإنترنت.
  • الرسائل تختفي: اضبط Message history إذا كانت الأداة تتيحه. تتحكم بعض الأدوات في إزالة الرسائل عبر JavaScript الخاص بها.
  • واجهات API للحساب أو الإضافات تفشل: تحتاج بعض الأدوات إلى تغييرات في الشفرة. استخدم توجيه التحويل في أداة الاستيراد أو اطلب المساعدة مع ملفات الأداة الأصلية ولقطة شاشة للمشكلة، دون مشاركة بيانات اعتماد جلستك.

خيارات أخرى: مظاهر دردشة مدمجة, CSS مخصص، أو استكشاف مشكلات OBS وإصلاحها.
