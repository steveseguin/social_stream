شرح الخوادم والخدمات المحلية

يستخدم Social Stream Ninja عدة خدمات محلية مختلفة. اختر الخدمة المناسبة لما تريد فعله.

1. تفعيل الخادم المحلي

يشغّل هذا الخيار من قائمة File مرحّل WebSocket داخل تطبيق سطح المكتب يميز الغرف والقنوات. يمكن لصفحات Social Stream المدعومة استخدامه لتبادل الدردشة والأوامر على الجهاز نفسه. وهو نقطة نهاية بديلة لتوجيه الخادم الخاص بكل صفحة.

لا يستضيف موقع Social Stream، ولا يلتقط منصة بمفرده، ولا يوفر واجهة HTTP API للأتمتة. ابدأ بـ دليل تفعيل الخادم المحلي.

2. واجهة التحكم المحلية API وMCP

تتيح واجهة loopback API الاختيارية للبرامج على جهاز SSApp إدارة المصادر والإعدادات المدعومة وقراءة الحالة والتشخيص وفحص نوافذ التطبيق أو المصادر ومتابعة الأحداث الملتقطة. يقدم محوّل MCP المضمّن هذه العمليات كأدوات لعملاء الذكاء الاصطناعي المتوافقين.

فعّله ضمن ملف > ذكاء اصطناعي محلي / أتمتة (File > Local AI / Automation). وهو منفصل عن تفعيل الخادم المحلي (Enable Local Server). راجع دليل واجهة التحكم المحلية API وMCP.

3. خادم منزلي أو VPS دون واجهة مرئية

يشغّل وضع التشغيل دون واجهة مرئية تطبيق سطح المكتب Electron كاملًا مع إخفاء نوافذ مصادره. وعلى Linux يظل بحاجة إلى خلفية عرض مثل Xvfb. يفيد ذلك عندما ينبغي لجهاز مخصص مواصلة التقاط الدردشة دون شاشة متصلة.

لا ينشئ وضع التشغيل دون واجهة مرئية واجهة تحكم API عامة. يستخدم التحكم عن بُعد نقل WebRTC أو WebSocket المعتاد في Social Stream. راجع دليل الاستضافة دون واجهة مرئية.

4. خادم الوسائط المحلي

يشغّل تطبيق سطح المكتب هذه الخدمة تلقائيًا عند توفر وسائط Event Flow محلية. وهي تقدم فقط الملفات المصرح بها عبر SSApp وأصول تشغيل محددة، عبر مسار برمز عشوائي خاص بكل ملف شخصي.

ليس خادم ويب أو ملفات عامًا. راجع ملفات الوسائط لـEvent Flow للاختيار بين الملفات المحلية والرفع والاستضافة السحابية.

الرجوع إلى الخادم مختلف

إعدادات مثل إرسال رسائل الدردشة إلى خادم API و ترسل لوحة الإرساء أوامرها إلى الإضافة عبر الخادم تحدد كيفية توجيه الدردشة والأوامر. تتضمن معاملات URL المُنشأة لها server, server2، و server3.

تستخدم تلك الإعدادات عادةً خدمة WebSocket المستضافة في Social Stream. وعندما تتضمن صفحة مدعومة أيضًا localserver، فتستخدم مرحّل تطبيق سطح المكتب المحلي بدلًا من ذلك. راجع الجلسات وكلمات المرور والمرحّل وأوضاع الخادم لمعرفة عناصر تحكم التوجيه.

استخدم روابط أُنشئت حديثًا. خيارات التوجيه خاصة بكل صفحة. لا تنسخ خيار خادم من صفحة إلى أخرى وتفترض أن له المعنى نفسه.

منافذ محلية مؤقتة أخرى

تفتح بعض مسارات تسجيل الدخول وربط الحساب منفذ استدعاء رجوع على loopback لفترة قصيرة وتغلقه عند انتهائها. هذه المنافذ المؤقتة ليست خوادم SSN عامة أو واجهات API للأتمتة.
