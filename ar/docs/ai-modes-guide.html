الخيار 1: رفيق متصفح ChatGPT (تجريبي)

هذا أقرب خيار إذا كنت تستخدم ChatGPT في Chrome بالفعل ولا تريد مفتاح API. يستطيع SSN التقاط الرسائل النصية الجديدة من الصفحة بنوع المصدر openai، تماماً كما يلتقط مصدر دردشة.

التقاط محادثة ChatGPT

  1. ثبّت إضافة Social Stream Ninja لمتصفح Chrome وفعّلها.
  2. في النافذة المنبثقة، فعّل خيار التفعيل الاختياري ChatGPT .
  3. افتح https://chatgpt.com/ وأعد تحميل الصفحة بعد تفعيل المصدر.
  4. افتح لوحة إرساء SSN باستخدام الجلسة نفسها.
  5. أرسل رسالة جديدة في ChatGPT. ينبغي أن تظهر رسائل المستخدم وChatGPT الجديدة في لوحة الإرساء؛ ويُتجاهل السجل الموجود عمداً.

إرسال الدردشة المباشرة إلى علامة تبويب ChatGPT المفتوحة

  1. اختبر ببث خاص أو غير مدرج ومحادثة نصية عادية في ChatGPT.
  2. ضمن الإدارة، فعّل تمرير جميع الرسائل.
  3. اضبط اختيار وجهات التمرير إلى openai كي تُرسل رسائل المشاهدين الملتقطة إلى علامة تبويب ChatGPT فقط.
  4. أبقِ علامة تبويب ChatGPT مفتوحة. تعود ردودها الجديدة إلى SSN على هيئة رسائل openai .
  5. استخدم صوت ChatGPT أو مخرجات تحويل النص إلى كلام أو التراكب في SSN لعرض تلك الردود في البث.

تجريبي: قد تتغير عناصر تحكم صفحات الويب، وقد يغمر تمرير جميع الرسائل المحادثة، وقد لا يقبل وضع ChatGPT Voice النص المحقون كما تقبله صفحة النص العادية. استخدم المرشحات أو بثاً تجريبياً قبل إرسال كل رسالة من المشاهدين.

الخيار 2: ضبط مزوّد ذكاء اصطناعي داخل SSN

استخدم مزوّداً عندما ينبغي أن يولّد SSN ردوداً، أو يشرف على الرسائل، أو يترجم الدردشة، أو يبحث في قاعدة معرفة، أو يبني تراكبات.

نوع المزوّدالخياراتملاحظات
محليOllama؛ Local Gemma؛ Local Qwenدون مفتاح API سحابي. يعتمد الأداء على الحاسوب وأصول النموذج.
خادم مخصص / محليواجهة API مخصصة متوافقة مع OpenAIلـ llama.cpp وLM Studio وvLLM والبوابات المتوافقة. ينبغي لـ Ollama استخدام خياره الأصلي.
سحابيOpenAI وGemini وDeepSeek وxAI وAWS Bedrock وOpenRouter وGroq وOpenCode Zenيتحكم كل مزوّد في مفاتيحه وإمكانية الوصول والفوترة والحصص وأسماء النماذج.
تجربةSSN Hosted Trial LLMتجريبي وقد يُعطّل أو يُفرض عليه حد للمعدل.
  1. افتح روبوتات الدردشة وخدمات الذكاء الاصطناعي (Chat Bots and AI services) في نافذة SSN المنبثقة.
  2. افتح تهيئة مزوّد خدمة LLM ‏(Configure LLM Service Provider) واختر المزوّد الذي تستخدمه بالفعل.
  3. أدخل نقطة النهاية أو النموذج أو مفتاح API أو إعدادات الأصول المحلية.
  4. اختر اختبار روبوت الدردشة المحدد (Test selected chat bot). تثبت نتيجة Connected فقط أن المزوّد أجاب عن الاختبار.
  5. فعّل الميزة المنفصلة التي ينبغي أن تستخدمه — الروبوت الأساسي أو الخاص أو المقدّم المشارك أو الإشراف أو الترجمة أو RAG أو المنشئ.

الخيار 3: مقدّم مشارك صوتي بالذكاء الاصطناعي

صُمم المقدّم المشارك تحديداً لمسار عمل «التحدث إلى الذكاء الاصطناعي أثناء اطلاعه أيضاً على الدردشة المباشرة». يغذي الميكروفون ورسائل الدردشة المباشرة المحددة جلسة المقدّم المشارك نفسها، ويمكن نطق الرد في البث.

  1. افتح cohost.html?session=YOUR_SESSION.
  2. اختر مزوّداً صوتياً أو آنياً، أو نموذج LLM المضبوط في نافذة SSN المنبثقة.
  3. حدد الميكروفون صراحةً و الاستجابة الصوتية (Audio Response)، ثم اضغط بدء المقدّم المشارك (Start Co-host).
  4. مع OpenAI Realtime، اترك Live Chat مضبوطاً على السياق فقط — الإجابة عند السؤال (Context only - answer when asked) عندما تريد أن يتذكر الذكاء الاصطناعي أحدث رسائل المشاهدين دون مقاطعة. اختر الأسئلة والإشارات (Questions and mentions) أو كل رسالة (Every message) لردود تلقائية منطوقة؛ لا تنشر هذه الأوضاع في دردشة المنصة.
  5. مع OpenAI Realtime، التقط صوت متصفح أو تطبيق المقدّم المشارك في OBS واستخدم cohost-overlay.html?session=YOUR_SESSION للصورة الرمزية وفقاعة الكلام في المنصة. لا يتلقى التراكب تدفق صوت WebRTC نفسه. استخدم منتقي جهاز إخراج المقدّم المشارك لاختيار كابل افتراضي عند توفر الدعم؛ أما &forcetts يضيف عمداً صوتاً منفصلاً للتراكب.
  6. تكون أدوات البث الاختيارية معطّلة افتراضياً. فعّل Spotify أو قائمة مسموحة بأسماء مشاهد OBS أو التحكم في الدردشة المميزة في نافذة SSN المنبثقة، ثم جهّز الأدوات نفسها ضمن عناصر تحكم المقدّم المشارك في البث في صفحة المقدّم المشارك.
  7. لتقليل زمن استجابة OpenAI، اختر نموذج Mini واستدلال Low وتناوب الأدوار Fast. يمكن لـ Full quality والاستدلال الأعلى تحسين الإجابات الصعبة مقابل تأخير وتكلفة API أكبر؛ وقد يقاطع Fast الوقفات الطبيعية. تعرض التشخيصات الزمن المقاس حتى أول مخرج.
  8. إدخال الكاميرا ومشاركة الشاشة في OpenAI اختياري، وإعداده الافتراضي هو دون فيديو (No Video). عند اختياره، يرسل SSN صورة حالية واحدة مع كل طلب مباشر صوتي أو مكتوب؛ وليس تدفق فيديو مستمراً، وقد يزيد تكلفة API وزمن الاستجابة.
  9. أبقِ فقاعة الكلام ظاهرة، أو وفّر تسميات توضيحية، كي لا يحتاج المشاهدون إلى سماع صوت الذكاء الاصطناعي لمتابعة المحادثة.

يستخدم OpenAI Realtime مفتاح مشروع OpenAI المضبوط ضمن ChatGPT API في نافذة SSN المنبثقة. يبقى المفتاح القياسي في خلفية إضافة SSN أو تطبيق سطح المكتب، التي تنشئ سر عميل Realtime قصير الأجل لصفحة المقدّم المشارك. ينتقل صوت الميكروفون وصوت الذكاء الاصطناعي بعدها عبر WebRTC. تقتصر الردود على 512 رمز إخراج، وتعرض التشخيصات الاستخدام التراكمي وزمن الاستجابة. يفحص SSN الجلسات الهادئة ويعيد توصيل قنوات النقل الفاشلة؛ وتعيد الجلسة المستردة تطبيق تعليماتها وإعدادات أدائها، لكنها لا تستطيع استعادة المحادثة الصوتية السابقة. ينشئ هذا جلسة مقدّم مشارك في SSN؛ ولا يستحوذ على محادثة موجودة في موقع ChatGPT أو تطبيق ChatGPT لسطح المكتب.

افتح الدليل المفصل للمقدّم المشارك بالذكاء الاصطناعي

الخيار 4: روبوت الدردشة المباشرة الأساسي

يقيّم الروبوت الأساسي رسائل المشاهدين الملتقطة، ويمكنه الرد في تراكب أو عبر تحويل النص إلى كلام أو داخل دردشات المنصات المدعومة.

  1. اضبط مزوّد ذكاء اصطناعي واختبره.
  2. فعّل روبوت الدردشة الأساسي بالذكاء الاصطناعي.
  3. اختر الكلمات المشغّلة، وقصر التفاعل على المشرفين، وحدود المعدل، والسجل، وتعليمات الطلب.
  4. لاختبار أول آمن، فعّل إرسال ردود الروبوت إلى صفحة تراكب الروبوت فقط.
  5. افتح bot.html?session=YOUR_SESSION وفعّل تحويل النص إلى كلام إذا كان ينبغي نطق الردود.
  6. لا تعطل وضع التراكب فقط إلا بعد التأكد من أن منصة الوجهة تدعم النشر.

تستخدم ردود المنصة عادةً الحساب الذي سجّلت الدخول إليه. لهوية منفصلة، استخدم حساب روبوت مخصصاً على YouTube أو Twitch أو Kick حيث يكون مدعوماً.

الخيار 5: روبوت خاص لمحادثة فردية

chatbot.html صفحة مساعد خاص واختبار للطلبات. فعّل روبوت الدردشة — الواجهة الخاصة (Chat Bot - Private Interface)، وافتح الصفحة باستخدام جلستك، واستخدم مزوّد LLM المضبوط.

الروبوت الخاص منفصل عن روبوت الدردشة المباشرة الأساسي، ولا يشاركه حالياً مجموعة بيانات RAG أو سجل دردشة آخر.

الخيار 7: منشئ التراكبات بالذكاء الاصطناعي

استخدم aiprompt.html لوصف تراكب وتوليده ومعاينته وحفظه. استخدم aioverlay.html كصفحة إخراج OBS بعد حفظه.

افتح دليل منشئ التراكبات بالذكاء الاصطناعي

حلول شائعة

  • متصل، لكن لا يوجد رد مباشر: فعّل الروبوت الأساسي أو ميزة الذكاء الاصطناعي المطلوبة؛ فإعداد المزوّد وحده لا يعالج الدردشة.
  • يرى المقدّم المشارك الدردشة لكنه يظل صامتاً: ينتظر Context only عمداً أن يسأل مقدم البث عن الدردشة. انتقل إلى Questions and mentions أو Every message للحصول على ردود تلقائية.
  • مصدر متصفح ChatGPT صامت: فعّل خيار التقاط ChatGPT الاختياري، وأعد تحميل chatgpt.com، واختبر برسالة جديدة بدلاً من السجل الموجود.
  • يتخطى الروبوت معظم الرسائل: تحقق من الكلمات المشغّلة، ووضع المشرفين فقط، وحدود المعدل، وتعليمات النموذج بشأن الرد الانتقائي.
  • يظهر النص دون صوت: تأكد من أن الصفحة المنتجة للصوت مفتوحة، وأن OBS يلتقط صوت تلك الصفحة.
  • لا يستطيع الروبوت النشر: تحقق من دعم الرد إلى المنصة، وحالة تسجيل الدخول، وصلاحيات الحساب، وحدود المعدل.

مراجع إضافية: إعداد تحويل النص إلى كلام, تحويل النص إلى كلام بالذكاء الاصطناعي محلياً، و تكامل الذكاء الاصطناعي مع الأوامر وAPI.
