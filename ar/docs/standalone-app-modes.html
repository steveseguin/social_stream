أوضاع التطبيق المستقل

افهم نوافذ المصادر ووضعَي Standard وWebSocket وإعدادات TikTok المسبقة.

الغرض من التطبيقأسماء الأوضاعمتى تستخدم وضع Standardمتى تستخدم وضع WebSocket أو APITikTok داخل التطبيقما يجب التحقق منه قبل OBSحلول شائعة

الغرض من التطبيق

يدير تطبيق سطح المكتب نوافذ مصادر Social Stream خارج متصفحك العادي. قد يساعد في تنظيم المصادر وبعض مشكلات تقييد نشاط علامات تبويب المتصفح. وهو مختلف عن Chrome، ولا يشارك تسجيل دخول Chrome أو ملفات تعريف ارتباطه تلقائيًا.

أسماء الأوضاع

لبعض المصادر أكثر من وضع اتصال. يعتمد الوضع المناسب على المنصة وحالة تسجيل الدخول وما إذا كنت تحتاج إلى أحداث أغنى أو التقاط صفحة بسيط.

الوضعالمعنى المبسطمتى يُستخدم
Standardيفتح التطبيق صفحة منصة أو مصدر عادية ويقرأ الصفحة المعروضة.تحتاج إلى أبسط التقاط لصفحة مرئية أو تسجيل دخول أو تحقق يدوي.
WebSocket/APIيتصل المصدر عبر API للمنصة أو مقبس أو صفحة مصدر Social Stream.تدعمه المنصة وتريد موثوقية أفضل في الخلفية أو بيانات أحداث أغنى.
الاستقصاء/القديم (Polling/Legacy)مسار توافق يفحص التحديثات بدلًا من استخدام مسار المقبس المباشر المفضل.يفشل الموصل الأحدث أو يلزم بديل خاص بالمنصة.
TikTok Autoيختار التطبيق أفضل مسار TikTok وقد ينتقل إلى بديل إذا فشل أحدها.لست متأكدًا من وضع TikTok المناسب.

متى تستخدم وضع Standard

  • تعمل المنصة عندما تستطيع رؤية صفحة البث المباشر أو الدردشة المنبثقة.
  • يتطلب الموقع تسجيل الدخول أو حل مطالبة أو إبقاء لوحة دردشة مرئية مفتوحة.
  • تقارن سلوك التطبيق بإضافة Chrome.
  • تحتاج إلى مسار التشخيص الأكثر ألفة: افتح الصفحة، وشاهد الدردشة، واختبر لوحة الإرساء، ثم OBS.

قد يفشل وضع Standard إذا غيّرت المنصة تخطيط صفحتها أو حظرت المتصفحات المضمّنة أو متصفحات التطبيقات أو طلبت CAPTCHA أو أخفت الدردشة خلف تسجيل دخول.

متى تستخدم وضع WebSocket أو API

  • يدعم المصدر تحديدًا وضع WebSocket/API.
  • تريد مصدرًا يستطيع مواصلة العمل بصورة أفضل في الخلفية.
  • تحتاج إلى مجموعات أحداث قد لا يتيحها استخراج محتوى الصفحة العادي.
  • يمكنك التعامل مع رموز المزود وأذونات الحساب ونطاقات API أو إعداد صفحة المصدر.

وضع WebSocket/API ليس أفضل دائمًا. إذا فشلت المصادقة أو الرموز أو وصول المزود أو API المنصة، فقد يكون وضع Standard الاختبار الأسرع.

TikTok داخل التطبيق

TikTok في تطبيق سطح المكتب ليس وضعًا واحدًا. دوّن دائمًا الإعداد المسبق النشط قبل حل المشكلات.

مسار TikTokحالة الاستخدامموضع الفشل الشائع
تلقائي (Auto)الخيار الأول لمعظم المستخدمين.قد ينتقل التطبيق إلى بديل، لذا تحقق من نص الحالة.
Standardالتقاط صفحة TikTok المرئية.تسجيل الدخول أو CAPTCHA أو صفحة أعيد توجيهها أو دردشة مخفية.
الموقّع المحلي (Local Signer)مسارات قراءة ودعم ردود أصلية في التطبيق.يجب أن تكون جلسة TikTok وملفات تعريف الارتباط داخل التطبيق صالحة.
الاستقصاء/التوافق (Polling/Compatibility)بديل عند فشل مسارات المقبس أو التوقيع.أقل شمولًا من الموصل المفضل.
وكيل أو توقيع مخصصإعدادات متقدمة.توفر المزود أو مفتاح API أو معرّف الغرفة أو حدود المعدل.

للمحاولة الأولى المعتادة، أضف TikTok واترك الإعداد المسبق على Auto، وفعّل المصدر، وراقب نص حالة التطبيق.

ما يجب التحقق منه قبل OBS

  1. تأكد من تفعيل مصدر التطبيق.
  2. تأكد من تسجيل الدخول في نافذة المصدر إذا كانت المنصة تتطلب ذلك.
  3. تأكد من أن لوحة الإرساء تستقبل الدردشة بمعرّف الجلسة نفسه.
  4. بعد عمل لوحة الإرساء فقط، أضف رابط تراكب OBS أو حدّثه.
  5. إذا عمل Chrome ولم يعمل التطبيق، فتذكر أن جلسات التطبيق وجلسات Chrome منفصلة.

حلول شائعة

  • الحساب مسجل في Chrome لكن ليس في التطبيق: سجّل الدخول إلى المنصة داخل نافذة مصدر التطبيق، أو استخدم الإضافة كمسار للالتقاط.
  • المصدر يقول إنه نشط لكن لا تصل دردشة: تحقق من الوضع ونافذة المصدر ورابط البث المباشر أو اسم المستخدم وجلسة لوحة الإرساء.
  • التطبيق يستخدم ملفات مصادر خاطئة: تحقق مما إذا كان التطبيق يستخدم ملفات Social Stream المضمّنة أو المخزنة مؤقتًا أو البعيدة أو beta أو المستقرة أو المحلية.
  • TikTok يفشل: سجّل الإعداد المسبق الحالي ونص الحالة وإصدار التطبيق وما إذا كان المصدر انتقل إلى وضع بديل.
  • OBS فارغ: اختبر لوحة الإرساء أولًا. إذا كانت فارغة، فالمشكلة ليست OBS بعد.
