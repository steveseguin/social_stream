البدء من المواقع المدعومة

ابحث عن YouTube أولًا. يفصل Social Stream الدردشة المباشرة عن التعليقات الثابتة لأن لكل منهما مسار عمل مختلفًا.

إعداد الدردشة المباشرة

  1. تأكد من أن البث مباشر بالفعل أو أن الدردشة المباشرة متاحة.
  2. افتح صفحة دردشة YouTube المباشرة أو صفحة المصدر الخاصة بالوضع.
  3. تأكد من أن لوحة الإرساء تتلقى الرسائل قبل فتح OBS.
  4. استخدم معرّف الجلسة نفسه في لوحة الإرساء والتراكب.

إذا طلب YouTube تسجيل الدخول أو أذونات، فأكمل هذه الخطوة في المتصفح أو التطبيق نفسه الذي ينفّذ الالتقاط.

ملاحظات API وOAuth

  • يمكن لوضع API إتاحة فئات أحداث تختلف عما يتيحه التقاط الصفحة الظاهرة.
  • قد يؤخر YouTube بيانات المشتركين، وقد تشمل الاشتراكات العامة فقط.
  • تحتاج إجراءات الكتابة إلى نطاقات أقوى من التقاط الدردشة للقراءة فقط.
  • لا يشارك تطبيق سطح المكتب تلقائيًا ملفات تعريف الارتباط في Chrome العادي.

الإعداد الكامل: إعداد مشروع YouTube.

حلول شائعة

  • لا توجد دردشة: تأكد من أن البث مباشر وأن الدردشة ظاهرة.
  • يعمل Chrome لكن التطبيق لا يعمل: سجّل الدخول إلى YouTube داخل التطبيق أو استخدم مسار الإضافة.
  • وضع API يفشل: تحقق من OAuth والنطاقات وبيانات اعتماد المشروع والحصة.
  • OBS فارغ: اختبر لوحة الإرساء أولًا، ثم رابط التراكب في متصفح عادي.
