نظرة عامة

يمكن لـ SSN قراءة نص الدردشة الملتقط من أي مصدر مدعوم؛ ولا يلزم أن تتضمن منصة الدردشة ميزة TTS خاصة بها. تنطق لوحة الإرساء أو التراكب المفعّل فيه TTS الرسائل التي يتلقاها، وفقًا لمرشحاته وإعدادات TTS. ابدأ بـ دليل الإعداد المختصر؛ تتناول هذه الصفحة خيارات الأصوات والإعدادات المتقدمة. قارن المزودين واستمع إلى العينات واطلع على الإعدادات.

بدء سريع: استخدم dock.html?session=YOUR_SESSION&speech=en-US. يستخدم هذا System TTS افتراضيًا. لاستخدام موفّر مجاني في OBS، أضف أيضًا &ttsprovider=kokoro. أبقِ هذه الصفحة مفتوحة ومتصلة؛ يجب أن تنطق نسخة واحدة فقط.

أين يُستخدم TTS؟

  • Social Stream Ninja: يقرأ رسائل دردشة الجمهور بصوت مسموع في عدة مواضع
  • CAPTION.Ninja: يوفر تسميات توضيحية مغلقة ونسخًا نصيًا وترجمة مع TTS
  • تقدّم الخدمتان خيارات مدفوعة ومجانية لتحويل النص إلى كلام
System TTS لا يشمل كل خيارات TTS المجانية:
  • تعتمد أصوات النظام على المتصفح ونظام التشغيل. قد لا يتيح OBS أي أصوات صالحة للاستخدام حتى عندما يعمل Chrome أو Edge.
  • غياب الصوت المطلوب يختلف عن تشغيل الكلام خارج التقاط الصوت في OBS. لا يمكن لتوجيه الصوت إصلاح غياب دعم النطق.
  • أما الموفّرون المجانيون مثل Kokoro وPiper وKitten وeSpeak فيُنتجون صوت الصفحة. لا يلزم الدفع لاستخدام TTS في OBS.
  • تحقق من توفر الصوت المطلوب، ثم من التقاط الصوت.

خيارات موفّري TTS

System TTS (مجاني)

  • يستخدم الأصوات المدمجة في نظام تشغيلك
  • دعم لغات محدود وفقًا لما هو مثبت على النظام
  • يعتمد توفر الأصوات وتوجيه الصوت على المتصفح ونظام التشغيل؛ اختبر في المشغّل الفعلي
  • يختلف التوافق بين المتصفحات بدرجة كبيرة

خيارات TTS المحلية والمجانية (لا تتطلب مفتاح API)

هل تريد TTS بالذكاء الاصطناعي يعمل محليًا بالكامل؟ هناك عدة أصوات ذكاء اصطناعي عالية الجودة مدمجة مباشرة في Social Stream Ninja وتعمل في متصفحك — بلا مفتاح API أو سحابة أو تثبيت إضافي. راجع دليل تحويل النص إلى كلام بالذكاء الاصطناعي محلياً للحصول على تعليمات الإعداد وخيارات الخادم الذي تستضيفه بنفسك.
المزود التكلفة الالتقاط في OBS الميزات
Kokoro TTS مجاني مباشر ذكاء اصطناعي يعمل في المتصفح، بجودة ممتازة وعشرات الأصوات
Piper TTS مجاني مباشر تحويل نص إلى كلام عصبي سريع يعمل في المتصفح ومناسب للمعالج المركزي
Kitten TTS مجاني مباشر يعمل في المتصفح باستخدام نموذج ONNX خفيف
eSpeak-NG مجاني مباشر تقليدي ومفتوح المصدر ويعمل على أي عتاد

خيارات TTS المدفوعة والسحابية (صوت مباشر من المتصفح)

المزود التكلفة الالتقاط في OBS الميزات
OpenAI TTS تُطبّق تكاليف API (أو مجانًا محليًا) مباشر جودة عالية؛ ويدعم أيضًا الخوادم المحلية عبر نقطة نهاية مخصصة
Google Cloud تُطبّق تكاليف API مباشر جودة احترافية بلغات متعددة
ElevenLabs تتوفر خطة مجانية مباشر تدريب أصوات مخصصة ونطق طبيعي
Speechify تُطبّق تكاليف API مباشر أصوات عالية الجودة بلغات متعددة
تحويل النص إلى كلام من Gemini تُطبّق تكاليف API مباشر واجهة API للغة التوليدية من Google

هذه إمكانات معتادة وليست ضمانات لكل تثبيت. يستخدم OBS متصفحه المضمّن الخاص ولا يرث قائمة أصوات Chrome أو Edge المثبت. نجاح اختبار تطبيق SSN لا يختبر مصدر متصفح منفصلًا في OBS.

قيود المتصفح:
  • لا تدعم جميع المتصفحات تحويل النص إلى كلام بالمستوى نفسه (بعض إصدارات Firefox لديها أصوات محدودة)
  • يوفر Chrome خيارات TTS من Google
  • يدعم Edge تحويل النص إلى كلام من Microsoft وأصوات حزم اللغات في Windows
  • يتطلب Safari تفاعل المستخدم لبدء الصوت
  • تحقق من الأصوات المتاحة لمتصفحك

طرق التقاط صوت TTS في Windows من أجل OBS

صوت الصفحة: موفّرون محليون مجانيون وموفّرون سحابيون

يشغّل موفّرو SSN المحليون الذين يعملون في المتصفح وموفّرو الصوت السحابيون الصوت المُنشأ عبر الصفحة:

  • ما عليك سوى تفعيل «التحكم في الصوت عبر OBS» (Control audio via OBS) في مصدر المتصفح
  • لا حاجة إلى كابلات صوت افتراضية
  • يعمل مع تطبيق SSN ومصادر المتصفح في OBS

طرق التقاط System TTS

مهم: تأكد أولًا من أن System TTS يُنتج كلامًا. قد لا يتيح المتصفح المضمّن في OBS صوت نظام صالحًا للاستخدام. إذا لم يُنتج كلامًا، فلن يفيد تغيير توجيه الصوت. اختر موفّرًا آخر، أو أنشئ الكلام في متصفح مدعوم والتقط صوت ذلك المتصفح.

بالنسبة إلى System TTS تحديدًا:

  • لا تفترض أن OBS يتيح الأصوات نفسها التي يتيحها Chrome أو Edge
  • دعم محدود عبر المتصفحات (قد يفتقر Firefox إلى بعض أصوات TTS)
  • يوفر Chrome خيارات من Google، ويوفر Edge خيارات من Microsoft
  • إذا كان الكلام يُشغّل خارج مصدر المتصفح في المشهد، فالتقط ذلك الإخراج على حدة

تنزيلات توجيه الصوت: VB-Audio Virtual Cable | Voicemeeter | Audio Router (قديم)

جرّب أولًا التقاط صوت المتصفح الذي ينطق عبر التقاط صوت التطبيق أو سطح المكتب في OBS، حيثما كان ذلك مدعومًا. طرق الكابل الافتراضي أدناه بدائل اختيارية؛ ولا تضيف دعم النطق إلى OBS.

الطريقة 1: مسار الصوت الافتراضي باستخدام كابل افتراضي

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

الطريقة 2: توجيه صوت التطبيق في Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

الطريقة 3: توجيه صوت التطبيق في Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

الطريقة 4: برنامج Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

الطريقة 5: Voicemeeter (متقدم)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

اختبار إعدادك

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
بدائل: استخدم موفّرًا مجانيًا مدمجًا مثل Kokoro أو Piper أو Kitten أو eSpeak، أو موفّرًا سحابيًا، أو خادم TTS تستضيفه بنفسك.

تثبيت حزم لغات إضافية

Windows 11

  1. انتقل إلى ابدأ (Start) > الإعدادات (Settings) > الوقت واللغة (Time & Language) > الكلام (Speech)
  2. ضمن إدارة الأصوات، انقر على إضافة أصوات
  3. اختر اللغات المطلوبة وانقر على أضف
  4. أعِد تشغيل المتصفحات لتحديث الأصوات المتاحة

Windows 10

اتبع التعليمات الواردة في دليل Microsoft الرسمي لتثبيت حزم اللغات.

نصيحة: قد لا تظهر بعض أصوات الجهات الخارجية في المتصفحات بسبب مشكلات التوافق. غالبًا ما يعرض Firefox أصوات نظام أكثر من المتصفحات المبنية على Chromium.

ضبط موفّر TTS

Kokoro TTS (مجاني ومدمج)

  • فعّله باستخدام ?ttsprovider=kokoro
  • يعمل في المتصفح عبر WebGPU/WASM — لا حاجة إلى خادم
  • يعمل مباشرة مع مصدر المتصفح في OBS
  • اختيار الصوت: &voicekokoro=af_bella
  • التحكم في السرعة: &kokorospeed=1.2
  • اختر صوتًا للغة: &voicekokoro=ef_dora للإسبانية أو &voicekokoro=pf_dora للبرتغالية البرازيلية. تغيير &speech= وحده لا يغيّر الصوت المحدد. تظل معرّفات الأصوات الإنجليزية الحالية تعمل.

Piper TTS (مجاني ومدمج)

  • فعّله باستخدام ?ttsprovider=piper
  • تحويل نص إلى كلام عصبي سريع يعمل في المتصفح ومناسب للمعالج المركزي
  • اختيار الصوت: &pipervoice=en_US-hfc_female-medium
  • أصوات برتغالية: &pipervoice=pt_BR-faber-medium أو &pipervoice=pt_BR-edresson-low
  • أصوات إسبانية: &pipervoice=es_ES-davefx-medium أو &pipervoice=es_MX-ald-medium
  • التحكم في السرعة: &piperspeed=1.0

Kitten TTS (مجاني ومدمج)

  • فعّله باستخدام ?ttsprovider=kitten
  • تحويل نص إلى كلام خفيف يعتمد على ONNX ويعمل في المتصفح
  • اختيار الصوت: &kittenvoice=expr-voice-4-f

eSpeak-NG (مجاني ومدمج)

  • فعّله باستخدام ?ttsprovider=espeak
  • تحويل نص إلى كلام تقليدي مفتوح المصدر يعمل على أي عتاد
  • اختيار الصوت: &espeakvoice=en
  • مثال بالبرتغالية: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • مثال بالإسبانية: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • التحكم في السرعة: &espeakspeed=175

أمثلة TTS بالبرتغالية والإسبانية

  • البرتغالية، أفضل جودة محلية مجانية اختُبرت في SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • البرتغالية، أسرع بديل احتياطي اختُبر في SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • الإسبانية، أفضل جودة محلية مجانية اختُبرت في SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • الإسبانية، أسرع بديل احتياطي اختُبر في SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • للأصوات السحابية، استخدم صوتًا ولغة لدى موفّر يدعم اللغة المطلوبة، مثل Google Cloud أو ElevenLabs أو Speechify أو Gemini أو خادم محلي متوافق مع OpenAI.

TTS عبر OpenAI أو خادم محلي

  • فعّله باستخدام ?ttsprovider=openai
  • استخدم ?ttsprovider=customtts أو ?ttsprovider=localtts لنقطة نهاية تستضيفها بنفسك
  • يستخدم API الخاصة بـ OpenAI افتراضيًا، أو أي خادم محلي متوافق
  • نقطة نهاية مخصصة: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • مهم: localhost و 127.0.0.1 يعنيان الجهاز نفسه الذي يشغّل صفحة TTS. إذا كان OBS على جهاز مختلف عن خادم TTS، فاستخدم عنوان IP الخاص بجهاز الخادم على الشبكة المحلية بدلًا من ذلك.
  • لا يلزم مفتاح API للخوادم المحلية
  • إذا واجه الخادم المحلي مشكلات CORS أو الشبكة المحلية في Chrome/OBS، فشغّل npm run local-tts-bridge على جهاز OBS ووجّه SSN إلى http://127.0.0.1:8124/v1/audio/speech
  • يرسل SSN { model, input, voice, response_format, speed } ويدعم الصوت الثنائي وروابط الصوت في JSON والصوت بترميز base64 في JSON
  • يُخزّن تشغيل الصوت من نقاط النهاية المخصصة أو المحلية مؤقتًا حاليًا؛ ولا يشغّل SSN مقاطع الصوت المتدفقة تدريجيًا بعد
  • الصوت: &voiceopenai=af_bella، السرعة: &openaispeed=1.0. استخدم اسم صوت يدعمه خادمك؛ تبدو أصوات Kokoro مثل af_bella، بينما قد تبدو أصوات openedai-speech أو الأصوات بنمط OpenAI مثل nova أو echo.
  • راجع دليل تحويل النص إلى كلام بالذكاء الاصطناعي محلياً لإعداد خادم تستضيفه بنفسك

Google Cloud TTS

  • فعّله باستخدام ?ttsprovider=google&ttskey=YOUR_API_KEY
  • أصوات بجودة احترافية
  • اختيار الصوت: &voicegoogle=en-GB-Standard-A
  • اللغة: &googlelang=en-US

تحويل النص إلى كلام من Gemini

  • فعّله باستخدام ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • النموذج (Model): &geminimodel=gemini-2.5-flash-preview-tts
  • الصوت: &voicegemini=Kore، اللغة: &geminilang=th-TH
  • تعليمات الأسلوب: &geministyle=Read aloud in a warm tone.

تحويل النص إلى كلام من ElevenLabs

  • فعّله باستخدام ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • معرّف الصوت: &voice11=YOUR_VOICE_ID
  • النموذج (Model): &elevenlabsmodel=eleven_multilingual_v2
  • يمكن ضبط المعلمات: stability وsimilarity وstyle

تحويل النص إلى كلام من Fish Audio

اختر Fish Audio وأدخل مفتاح API، مع معرّف صوت اختياري. النموذج الافتراضي هو s2.1-pro-free. الإعداد وخيارات النماذج وقيود وصول المتصفح.

تحويل النص إلى كلام من Speechify

  • فعّله باستخدام ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • الصوت: &voicespeechify=henry
  • النموذج (Model): &speechifymodel=simba-3.0 (الافتراضي)، أو &speechifymodel=simba-3.2 للإنجليزية.
  • سرعة النطق: &speechifyspeed=1.2 (النطاق من 0.5 إلى 3.0؛ والقيمة العادية 1.0).
  • دليل إعداد Speechify والأصوات والسرعة ومستوى الصوت

استكشاف المشكلات وإصلاحها

المشكلات الشائعة

  • لا يُشغّل أي صوت: تحقق من تفعيل TTS ومن فتح الصفحة التي تنتج الكلام ومن عدم كتم مصدر المتصفح. في المتصفح العادي، انقر على الصفحة مرة واحدة.
  • الأصوات لا تظهر: أعِد تشغيل المتصفح بعد تثبيت حزم اللغات
  • OBS لا يلتقط الصوت: إذا لم يوجد كلام، فتحقق أولًا من توفر الصوت والموفّر. وإذا كان الكلام موجودًا، فتحقق من التحكم بالصوت عبر OBS (Control audio via OBS)، وكتم الصوت في المازج، ومسارات الإخراج، أو التقط صوت المتصفح الخارجي الذي ينطق
  • نقطة النهاية المحلية تعمل في اختبار التطبيق ولكنها لا تعمل في OBS: OBS متصفح منفصل. تحقق من نقطة النهاية من جهاز OBS، خصوصًا عند استخدام 127.0.0.1.
  • يُقرأ الحرف الأول أو الكلمات الأولى فقط: أزِل ttsquick من رابط OBS إن كانت موجودة.
  • مشكلات Safari: دعم TTS التلقائي في Safari محدود
  • الخدمة المدفوعة لا تعمل: تحقق من مفتاح API ومن تحديد الموفّر بشكل صحيح

أفضل الممارسات

  • استخدم موفّرًا يُنتج صوت الصفحة لتبسيط إعداد OBS؛ تتوفر موفّرات محلية مجانية
  • اختبر إعدادك بعبارات بسيطة قبل بدء البث المباشر
  • راعِ مخاطر المحتوى الذي ينشئه المستخدمون عند استخدام TTS
  • وفّر مفتاح تبديل لتعطيل TTS سريعًا عند الحاجة
