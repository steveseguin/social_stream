Guida ai nuovi partecipanti della chat

Segnala chi scrive per la prima volta con un'evidenziazione, un badge a foglia o un suono facoltativo.

Cosa fa questa funzione

Il rilevamento di chi scrive per la prima volta aggiunge firsttime=true al primo messaggio memorizzato di uno spettatore per quella sorgente. Il dock può usare questo indicatore per colorare lo sfondo, emettere un bip solo al primo messaggio e mostrare il badge a foglia facoltativo.

Configurazione necessaria

  1. Apri il popup di Social Stream Ninja.
  2. Mantieni Disattiva il database locale dei messaggi in stato disattivato.
  3. Attiva Rilevamento di chi scrive per la prima volta.
  4. Lascia aperto il dock o l'overlay con lo stesso ID di sessione.
Importante: Il database locale è necessario. Se è disattivato, Social Stream Ninja non può capire se una persona è nuova.

Opzioni di visualizzazione

  • Colore di sfondo: attivo per impostazione predefinita nel dock. Mantieni Nessun colore di sfondo per chi scrive per la prima volta disattivato se vuoi l'evidenziazione.
  • Badge a foglia: attiva Contrassegna chi scrive per la prima volta con un badge personalizzato per aggiungere un piccolo badge a foglia prima degli altri badge del partecipante.
  • Bip del dock per chi scrive per la prima volta: attiva questa opzione se vuoi che il bip del dock suoni solo per chi scrive per la prima volta.
  • Bip per partecipanti nuovi o di ritorno: attiva questa opzione se vuoi un suono anche per gli spettatori che tornano dopo almeno 8 ore di inattività.

Usare l'indicatore negli overlay personalizzati

Gli overlay personalizzati possono cercare data.firsttime === true. Se l'opzione del badge a foglia è attiva, il badge viene incluso in chatbadges prima che il messaggio raggiunga gli overlay.

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

Se non compare

  1. Verifica che Disattiva il database locale dei messaggi sia disattivato.
  2. Verifica che Rilevamento di chi scrive per la prima volta sia attivo.
  3. Verifica che Nessun colore di sfondo per chi scrive per la prima volta sia disattivato se ti aspetti un'evidenziazione.
  4. Verifica che Contrassegna chi scrive per la prima volta con un badge personalizzato sia attivo se ti aspetti il badge a foglia.
  5. Prova con una combinazione di nome utente e sorgente non già memorizzata nel database locale.
