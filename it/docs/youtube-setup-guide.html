Guida alla configurazione YouTube

Scegli consapevolmente chat live, commenti, acquisizione Standard o modalità API.

Parti dai Siti supportati

Cerca prima YouTube. Social Stream separa la chat live dai commenti statici perché sono flussi di lavoro diversi.

Configurazione della chat live

  1. Assicurati che la trasmissione sia davvero in diretta o che la chat live sia disponibile.
  2. Apri la pagina chat live YouTube o la pagina sorgente specifica della modalità.
  3. Verifica che il dock riceva messaggi prima di aprire OBS.
  4. Usa lo stesso ID di sessione nel dock e nell'overlay.

Se YouTube chiede accesso o autorizzazioni, completa quel passaggio nello stesso contesto browser/app che esegue l'acquisizione.

Note su API e OAuth

  • La modalità API può esporre famiglie di eventi diverse dall'acquisizione della pagina visibile.
  • I dati degli iscritti possono arrivare in ritardo da YouTube e includere solo le iscrizioni pubbliche.
  • Le azioni di scrittura richiedono ambiti più ampi dell'acquisizione chat di sola lettura.
  • L'app desktop non condivide automaticamente i normali cookie di Chrome.

Configurazione completa: Configurazione del progetto YouTube.

Soluzioni ai problemi comuni

  • Nessuna chat: verifica che la trasmissione sia in diretta e che la chat sia visibile.
  • Funziona in Chrome ma non nell'app: accedi a YouTube dentro l'app oppure usa il percorso dell'estensione.
  • La modalità API non funziona: controlla OAuth, ambiti, credenziali del progetto e quota.
  • Schermata vuota in OBS: prova prima il dock, poi l'URL dell'overlay in un browser normale.
