Selettore della configurazione delle piattaforme

Scegli il percorso di acquisizione più semplice prima di aprire OBS.

Inizia dalla pagina dei siti supportati

Cerca prima la tua piattaforma. Fai clic e leggi la breve nota di configurazione prima di provare un metodo più complesso.

Usa la normale estensione browser quando

  • La piattaforma funziona nel tuo normale browser.
  • Hai già effettuato l'accesso all'account corretto.
  • La pagina dei siti supportati dice di aprire il sito o la chat in finestra separata.

Inizia qui per YouTube, Twitch, Facebook, Discord, Slack, WhatsApp e la maggior parte delle sorgenti basate sul browser.

Usa una finestra separata o solo chat quando

  • La piattaforma ha un URL separato per la chat in finestra.
  • La normale pagina della diretta è pesante o inaffidabile.
  • Vuoi una finestra più piccola che mostri solo la chat.

Per le note specifiche di ogni piattaforma, consulta Siti supportati.

Usa l'app desktop quando

  • Le schede del browser vengono nascoste, limitate o scaricate dalla memoria.
  • Vuoi gestire le finestre sorgente nell'app.
  • Usi un'integrazione specifica dell'app, come alcune modalità TikTok.

Configurazione desktop: Guida all'app autonoma.

Usa una pagina sorgente quando

  • La piattaforma richiede un URL sorgente Social Stream dedicato.
  • La configurazione richiede un canale, una stanza, un token o un passaggio di accesso.
  • La piattaforma non viene acquisita da una normale scheda browser.

Le pagine sorgente sono normali. Significano soltanto che Social Stream richiede una pagina speciale per quella piattaforma.

Scelta rapida

SituazioneUsa
Sito chat supportato standardEstensione browser
Il sito dice di aprire la chat in una finestra separataFinestra separata/solo chat
La scheda browser nascosta smette di aggiornarsiApp desktop
La configurazione richiede stanza/canale/tokenPagina sorgente
Automazione personalizzata o dati in arrivoComandi/API o sorgente personalizzata

Nel dubbio, inizia dalla riga corrispondente più semplice. Potrai cambiare metodo in seguito.
