API di controllo locale e MCP

Consenti a uno strumento IA o a uno script sullo stesso computer di esaminare e controllare l'app desktop Social Stream Ninja.

Scegli questo servizio quando1. Scarica la normale app desktop2. Abilita il controllo IA locale3. Lascia che MCP rilevi le funzionalitàControlli locali disponibiliAccesso HTTP diretto per script localiSolo locale

Scegli questo servizio quando

App desktop→API di controllo locale→Cliente MCP

Usa l'API di controllo locale quando un programma sul computer SSApp richiede controlli approvati dell'app e delle sorgenti. Usa l'adattatore MCP incluso quando un client IA compatibile deve ricevere questi controlli come strumenti.

È separato da File > Enable Local Server, che avvia un relay WebSocket per le pagine Social Stream. Vedi Spiegazione dei server e servizi locali se non sei sicuro di quale servizio ti serva.

1. Scarica la normale app desktop

Installa la versione attuale di Social Stream Ninja dai download per Windows, macOS o Linux. Il supporto MCP è incluso nell'app scaricata. Non servono il repository dei sorgenti, Node, Python o un pacchetto MCP separato.

2. Abilita il controllo IA locale

  1. Apri File > IA locale / Automazione (Local AI / Automation).
  2. Attiva API di controllo locale e lascia che l'app si riavvii.
  3. Torna allo stesso menu e scegli Copia configurazione MCP.
  4. Incolla il JSON copiato nelle impostazioni MCP dello strumento IA, poi riavvia quello strumento.

La configurazione copiata contiene il percorso esatto dell'eseguibile installato, la porta e gli argomenti specifici della piattaforma. L'eseguibile Social Stream Ninja scaricato avvia il proprio adattatore MCP leggero quando il client IA lo lancia con --ssapp-mcp.

3. Lascia che MCP rilevi le funzionalità

Una volta connesso, il client MCP richiede automaticamente a Social Stream Ninja i suoi strumenti. L'adattatore legge le capacità effettive dell'app in esecuzione e fornisce all'LLM gli schemi degli strumenti supportati, le versioni app/API e le istruzioni operative. L'agente deve chiamare prima le capacità, poi lo stato, e usare gli ID stabili delle sorgenti restituiti dall'app.

Per il normale uso MCP non sono richiesti scraping di siti o installazione di skill. L'utente può semplicemente chiedere all'agente connesso di esaminare o controllare Social Stream Ninja.

Controlli locali disponibili

  • Elenca, esamina, aggiungi, aggiorna e rimuovi sorgenti.
  • Avvia, arresta o ricarica una sorgente oppure un insieme filtrato.
  • Modifica visibilità della sorgente, stato audio e modalità di connessione.
  • Leggi e aggiorna le impostazioni globali supportate restituite dal rilevamento delle capacità.
  • Leggi lo stato di app, sessione, sorgente, processo, acquisizione e media locali.
  • Segui flussi limitati di eventi delle sorgenti acquisite ed eventi riprendibili di operazioni o stato.
  • Acquisisci ed esamina in sicurezza le pagine sorgente supportate e le finestre di proprietà di SSApp.
  • Esegui interazioni approvate con pagine, finestre e finestre di dialogo, con conferma.
  • Ricarica o chiudi correttamente l'app con conferma esplicita.

Le capacità dell'app in esecuzione sono autorevoli. Le versioni precedenti possono esporre meno controlli.

Accesso HTTP diretto per script locali

Gli script sullo stesso computer possono usare l'API di loopback senza MCP. Ascolta solo su 127.0.0.1 e non richiede un token.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

Usa le capacità dichiarate invece di presumere che ogni versione dell'app abbia gli stessi controlli. Per esempi da copiare e incollare curl che aggiungono, elencano, avviano, esaminano e arrestano una sorgente, vedi la guida pratica all'API HTTP del server.

IA locale su un VPS Ubuntu

L'API può servire anche uno strumento IA in esecuzione sullo stesso server Linux di un'istanza SSApp headless. Mantienila associata al loopback e usa l'AppImage scaricata come comando MCP.

Follow Esegui Social Stream Ninja in modalità headless per Xvfb, profili persistenti, comandi di avvio, systemd e il percorso separato del controllo remoto. Include anche una Configurazione MCP dell'AppImage Linux da incollare in un client in esecuzione sul VPS.

Skill facoltativa per l'agente

Gli agenti che supportano skill installabili possono scaricare la skill completa Control Social Stream. Puoi anche leggerne le istruzioni online, con il Riferimento API e registro delle versioni. La skill aggiunge indicazioni sul flusso di lavoro, ma non serve per la connessione MCP.

I link di rilevamento leggibili dalle macchine sono elencati anche in llms.txt.

Solo locale

Questa interfaccia serve per IA e automazioni in esecuzione sullo stesso computer di SSApp. Non esporla, neppure tramite tunnel, come API cloud di controllo remoto. Gli utenti remoti e Stream Deck devono usare la connessione WebRTC o WebSocket esistente di Social Stream. L'API locale non offre esecuzione JavaScript arbitraria, cookie, segreti di accesso, impostazioni senza restrizioni o accesso grezzo al filesystem.

Per tutti gli endpoint, gli schemi dei comandi, il rilevamento delle versioni e i confini di sicurezza, vedi il riferimento tecnico delle automazioni.
