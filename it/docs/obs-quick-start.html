Guida rapida a OBS

Porta la chat in OBS con il minor numero di passaggi.

1. Scegli un ID sessione

Crea un ID sessione breve e usalo ovunque. È il modo in cui sorgente chat, dock e overlay OBS si trovano.

YOUR_SESSION_ID

2. Avvia una sorgente chat

  1. Installa o apri Social Stream Ninja.
  2. Apri la sorgente chat della tua piattaforma e lasciala aperta.
  3. Invia o attendi un messaggio chat per sapere che la sorgente funziona.

Non sai quale modalità sorgente usare? Vedi il Selettore della configurazione delle piattaforme.

3. Apri il dock

Il dock è la tua schermata di test. Aprilo prima di modificare le impostazioni OBS.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

4. Aggiungi una sorgente browser OBS

In OBS, aggiungi una sorgente browser e incolla l'URL dell'overlay.

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

Per i normali layout overlay chat, usa un template dalla Galleria dei template.

5. Se OBS è vuoto

Controlla una cosa alla volta, in quest'ordine.

  • Conferma prima che il dock riceva messaggi. Se il dock è vuoto, OBS non è ancora il problema.
  • Conferma che l'URL OBS abbia lo stesso session.
  • Aggiorna la sorgente browser OBS dopo aver modificato le opzioni URL.
  • Controlla che la pagina chat sorgente o la finestra sorgente dell'app siano ancora in esecuzione.

Altri dettagli: Risoluzione dei problemi.
