Statistiche video e bitrate

Mostra il bitrate della diretta in ingresso nell'angolo in alto a destra del dock Social Stream Ninja.

Importante: SSN non legge automaticamente il bitrate da OBS o da una piattaforma di streaming. Interroga l'API delle statistiche del server video che riceve la tua diretta.

A cosa serve

Fornisce al conduttore o al produttore una piccola indicazione live del bitrate nel dock. È utile quando OBS, un encoder mobile o un altro mittente pubblicano sul tuo server di inoltro o ingresso.

SSN normalizza anche i dati disponibili su latenza, buffer, perdita di pacchetti, tempo di attività, codec e spettatori in un evento di metadati video_stats . L'indicazione standard del dock mostra solo il bitrate.

Compatibilità

  • SRT Live Server / SLS: JSON /stats endpoint contenente un publishers oggetto.
  • Belabox Cloud: la sua risposta JSON di statistiche del ricevitore/relay in stile SRT.
  • NGINX RTMP: XML del modulo di stato NGINX RTMP.
  • Node Media Server: la sua API JSON degli stream, con autenticazione HTTP Basic facoltativa.
OBS non è una sorgente di statistiche: OBS può inviare video a un server compatibile, ma OBS WebSocket e le sorgenti browser SSN non forniscono questi dati.

Come usarlo

  1. Attiva l'endpoint HTTP delle statistiche del server compatibile e verifica che il computer su cui gira SSN possa aprirne l'URL.
  2. In SSN Impostazioni globali, attiva Polling delle statistiche video.
  3. Seleziona il tipo di sorgente e inserisci l'URL delle statistiche.
  4. Per SRT o Belabox, inserisci l'ID publisher esatto, ad esempio publish/live/feed1. SSN lo usa automaticamente quando la risposta contiene un solo publisher.
  5. Per NGINX RTMP o Node Media Server, inserisci applicazione e chiave/nome dello stream, ad esempio live e feed1.
  6. Aggiungi l'autorizzazione se richiesta. Il campo della chiave API SRT viene inviato come valore completo dell'intestazione Authorization . Node Media Server usa nome utente/password come autenticazione HTTP Basic.
  7. Scegli un intervallo di polling da 1 a 60 secondi; il valore predefinito è cinque secondi.
  8. Nelle opzioni del dock, attiva Mostra metadati del bitrate se disponibili; in alto a destra, poi apri o aggiorna il link del dock.
  9. Inizia a pubblicare video. Il bitrate compare dopo una risposta online valida.

Se non compare nulla

  • Verifica che entrambe le opzioni delle statistiche video siano attive in SSN.
  • Verifica che l'endpoint risponda entro cinque secondi e che il tipo di sorgente e gli identificatori del flusso corrispondano.
  • 127.0.0.1 indica il computer su cui gira SSN. Usa l'indirizzo LAN del server quando è un altro dispositivo.
  • L'indicazione scompare quando la diretta è offline, il bitrate manca o è zero, oppure non arrivano statistiche aggiornate per circa 130 secondi.

Avanzate: protocollo, formati e unità

SSN esegue una richiesta HTTP o HTTPS GET all'intervallo configurato, con cache disattivata e timeout di cinque secondi.

SRT Live Server / SLS e Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate è in Kbps; RTT e buffer di ricezione sono in millisecondi; velocità di ricezione e larghezza di banda sono in Mbps; tempo di attività in secondi; valori di perdita/scarto in conteggi di pacchetti o byte.

NGINX RTMP

L'URL deve restituire XML di stato NGINX RTMP. SSN cerca l'applicazione e lo stream configurati. Legge bw_video come byte al secondo e divide per 1024 per bitrateKbps. Legge anche la durata della diretta ed eventuali metadati dei codec video/audio.

Node Media Server

SSN richiede STATS_URL/APPLICATION/STREAM_NAME. I campi possono essere al primo livello oppure dentro data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

Il bitrate è in Kbps, gli spettatori sono un conteggio e la durata è in secondi.

Evento SSN normalizzato

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
CampoUnità/tipo
bitrateKbpsKbps, numero intero
rttMs / bufferMsMillisecondi
recvRateMbps / bandwidthMbpsMbps
Campi di perdita/scartoConteggi dei pacchetti o byte
uptimeSeconds / durationSecondsSecondi
onlineBooleano; false nasconde il valore nel dock

Il dock accetta meta.bitrateKbps, con meta.bitrate e meta.kbps come alternative. I valori inferiori a 1000 vengono mostrati come Kbps arrotondati; quelli maggiori come Mbps arrotondati a un decimale. URL delle statistiche, chiave dello stream e credenziali non vengono mai inviati agli overlay.
