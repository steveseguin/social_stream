Base di conoscenza

Risposte brevi ai problemi comuni. Usa le guide quando ti serve la procedura completa.

Overlay OBS vuoto

Controlla prima il dock. Se è vuoto, correggi la sorgente/piattaforma. Se funziona, apri l'URL esatto dell'overlay in un normale browser e conferma lo stesso session, poi aggiorna la sorgente browser OBS.

Apri la risoluzione dei problemi OBS

Sessione errata

Le pagine di sorgente, dock, overlay, bot ed Event Flow devono usare lo stesso ID sessione. Considera gli ID sessione come nomi di stanze: una scrittura diversa significa stanze diverse.

dock.html?session=YOUR_SESSION

Apri sessioni, password e modalità relay

Aggiorna senza perdere le impostazioni

Esporta prima le impostazioni, non disinstallare l'estensione durante un aggiornamento normale e usa il trasferimento crittografato dell'intera sessione dell'app desktop quando devi spostare anche cookie e accessi.

Apri aggiornamenti sicuri, backup e recupero

OBS non sente la sintesi vocale

La normale sintesi vocale di sistema spesso si sente dal computer ma non dalla sorgente browser OBS. Usa una modalità TTS con provider/nel browser come Kokoro, Piper, Kitten, eSpeak, compatibile con OpenAI o un provider cloud, oppure instrada l'audio di sistema separatamente.

Apri la guida alla configurazione della sintesi vocale

Kokoro non parla portoghese o spagnolo

Le voci Kokoro integrate sono inglesi. Per il portoghese, usa Piper con pipervoice=pt_BR-faber-medium, oppure eSpeak con espeakvoice=pt-br. Per lo spagnolo, usa Piper con pipervoice=es_ES-davefx-medium, oppure eSpeak con espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Apri la configurazione dei provider TTS

Chrome funziona ma l'app desktop no

L'app desktop usa sessioni Electron, non il normale profilo Chrome. Accedi nella finestra sorgente dell'app oppure usa l'estensione Chrome quando la piattaforma blocca i browser incorporati/delle app.

Apri le modalità dell'app autonoma

Quale server locale mi serve?

Abilita server locale è un relay WebSocket per le pagine SSN supportate. API di controllo locale serve per script e strumenti IA sullo stesso computer. L'hosting headless esegue l'app desktop completa su un server Linux. Il server multimediale Event Flow serve solo media locali approvati.

Apri la spiegazione dei server e servizi locali

TikTok non funziona o cambia modalità

Annota modalità dell'app, provider di firma, testo di stato, versione dell'app e se la chat è visibile in modalità Standard. Prova una modalità TikTok alla volta.

Apri le modalità TikTok dell'app

Manca la chat YouTube

Conferma che la trasmissione sia in diretta, che la chat dal vivo sia visibile e che tu stia usando il percorso YouTube corretto: chat dal vivo, commenti statici, acquisizione Standard o modalità WebSocket/API.

Apri la guida alla configurazione YouTube

Le risposte del bot non vengono inviate

Leggere la chat non equivale a pubblicare in chat. Controlla il supporto all'invio di risposte della piattaforma, l'accesso all'account, il ruolo dell'account, la modalità sorgente, la risposta del provider e i limiti di frequenza.

Apri la guida alla configurazione del bot di chat IA

Event Flow non fa nulla

Conferma che l'evento della sorgente raggiunga il dock. Per audio, media e azioni OBS, mantieni actions.html?session=YOUR_SESSION aperto con la stessa sessione.

Apri le ricette Event Flow
