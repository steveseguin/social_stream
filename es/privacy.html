Política de privacidad de Social Stream Ninja

Última actualización: 8 de septiembre de 2026

Social Stream Ninja es un software de código abierto para capturar, retransmitir, mostrar y automatizar el chat en vivo y los eventos relacionados con transmisiones. Esta política se aplica a la extensión de navegador de Social Stream Ninja, sus páginas y superposiciones alojadas, la aplicación de escritorio independiente conocida habitualmente como SSAPP y el complemento nativo de Social Stream Ninja para Elgato Stream Deck.

1. Alcance y enfoque general

Social Stream Ninja no requiere una cuenta de usuario central para utilizar el software principal. Sin embargo, según cómo lo configures, el software puede acceder, procesar, almacenar y transmitir información que algunas leyes pueden considerar información personal.

En muchos casos, el software funciona localmente en tu dispositivo y bajo tu control. Sin embargo, algunas funciones utilizan plataformas de terceros, destinos configurados por el usuario o servicios auxiliares alojados, y esos servicios pueden recibir los datos necesarios para realizar la función solicitada.

2. Información que el software puede procesar

Según las funciones que actives, Social Stream Ninja puede procesar las siguientes categorías de información:

  • Información de autenticación: Tokens de acceso OAuth, tokens de renovación, claves de API, ID de cliente, secretos de cliente, credenciales de canales o salas, tokens de sesión, contraseñas y datos de autorización similares introducidos por el usuario o concedidos por un servicio conectado.
  • Comunicaciones personales: Mensajes de chat, respuestas, comandos de chat, acciones de moderación, mensajes de membresía, donación o apoyo y otras comunicaciones enviadas por usuarios y recibidas de plataformas conectadas.
  • Historial web y contexto de páginas: URL de páginas compatibles, información de pestañas, nombres de canales y de usuarios, ID de videos y salas, identificadores de transmisiones y contexto relacionado de páginas necesario para conectarse a una fuente o supervisarla.
  • Contenido de sitios web: Contenido DOM del chat, contenido de mensajes y eventos, metadatos de transmisiones, recuentos de espectadores, insignias, emotes, imágenes de perfil y otros contenidos disponibles en páginas o API compatibles.
  • Información de identificación personal y datos de perfil: Nombres de usuario, nombres visibles, avatares, ID de cuentas o canales, insignias, colores de nombres, estado de membresía, etiquetas de seguidores/suscriptores y metadatos de perfil similares.
  • Configuración y datos locales de la aplicación: Ajustes, fuentes conectadas, comandos personalizados, listas de bloqueo y de permitidos, cachés locales, información de identificadores de archivos y otros datos necesarios para que el software siga funcionando en tu dispositivo.
  • Datos opcionales de medios y archivos: Si activas funciones opcionales de captura, exportación, ticker, registro o archivos, el software puede procesar archivos locales seleccionados, archivos exportados, datos de captura de pestañas o medios y copias de seguridad creadas por el usuario.

3. Cómo se utiliza la información

Social Stream Ninja puede utilizar esa información para:

  • Conectarse a fuentes compatibles de chat, eventos y transmisiones.
  • Mostrar mensajes de chat, superposiciones, paneles, alertas, listas de espera, encuestas, marcadores e interfaces relacionadas.
  • Realizar funciones de moderación, filtrado, automatización, retransmisión, bots, TTS, IA, traducción o exportación que active el usuario.
  • Autenticarse con plataformas de terceros y mantener las sesiones de las fuentes.
  • Guardar consultas en caché y mantener el estado local de la aplicación para que el software siga funcionando entre sesiones.
  • Enviar datos a destinos configurados explícitamente por el usuario, como webhooks, archivos locales, endpoints WebSocket locales, bots de terceros u otros servicios.

4. Almacenamiento local y en el dispositivo

Social Stream Ninja almacena una cantidad considerable de datos de funcionamiento localmente en el dispositivo del usuario. Según el entorno utilizado, puede incluir almacenamiento del navegador, localStorage, sessionStorage, IndexedDB, almacenamiento de la extensión, almacenamiento de la aplicación Electron y archivos opcionales elegidos por el usuario.

Estos datos locales pueden incluir ajustes, detalles de fuentes conectadas, consultas de canales o perfiles en caché, historial de mensajes si el usuario lo activa y datos de autenticación/sesión necesarios para las funciones activadas.

La aplicación de escritorio independiente también puede conservar en el dispositivo copias locales de recuperación de ajustes y almacenamiento de fuentes. Esas copias pueden incluir tokens OAuth u otros datos de sesión para que la aplicación pueda restaurar una sesión anterior operativa tras un reinicio o fallo.

El complemento de Stream Deck almacena su ID de sesión de Social Stream Ninja y sus preferencias de conexión en los ajustes locales del complemento de Stream Deck. Eliminar el complemento o borrar sus ajustes elimina esa configuración de Stream Deck.

5. Cuándo pueden salir datos de tu dispositivo

Según cómo utilices el software, la información puede transmitirse fuera del dispositivo en las siguientes situaciones:

No vendemos datos de usuarios.

Social Stream Ninja no está diseñado para transferir datos de usuarios más allá de las transmisiones descritas en esta política, que pueden producirse al utilizar plataformas conectadas, funciones activadas por el usuario, destinos configurados por el usuario, proveedores auxiliares o de servicios necesarios, o cuando lo exijan obligaciones de seguridad o legales.

  • Plataformas y API conectadas: Cuando conectas YouTube, Twitch, Kick, Facebook, Discord u otros servicios compatibles, el software envía solicitudes a esas plataformas y puede recibir o transmitir datos de chat, eventos, perfiles y autenticación.
  • Servicios auxiliares alojados: Algunas funciones utilizan endpoints auxiliares o páginas alojadas para autenticación, consultas, transporte, chat o recursos alternativos. Los ejemplos de las versiones actuales incluyen dominios de Social Stream Ninja o auxiliares relacionados utilizados para intercambios de autenticación, consultas o páginas alojadas.
  • Controles de Stream Deck: El complemento de Stream Deck envía el ID de sesión configurado y los datos del comando solicitado al endpoint WebSocket o HTTP de Social Stream Ninja elegido por el usuario. Cuando se activa la alternativa HTTP, los datos del comando pueden codificarse en la URL de la solicitud.
  • Destinos configurados por el usuario: Si activas webhooks, retransmisores, bots, proveedores de IA, proveedores TTS, herramientas para streamers, servidores WebSocket u otras integraciones, el software puede reenviar contenido de mensajes, nombres de usuario, avatares, datos de eventos y metadatos relacionados a esos destinos.
  • Servicios entre pares o de transporte: Si utilizas VDO.Ninja, WebRTC, retransmisores TURN, puentes iframe ocultos o transportes basados en WebSocket, los datos pueden pasar por esos sistemas. El transporte WebSocket opcional puede no estar cifrado de extremo a extremo.

6. YouTube y otras funciones basadas en OAuth

Uso limitado: El uso por parte de Social Stream Ninja de la información recibida de las API de Google cumple con la Política de datos del usuario de Chrome Web Store, incluidos sus requisitos de Uso limitado.

Cuando utilizas los Servicios de API de YouTube u otras integraciones basadas en OAuth, Social Stream Ninja puede solicitar tokens de autorización y el acceso relacionado a la cuenta necesario para la función que elijas utilizar.

  • YouTube: El software puede acceder a mensajes del chat en vivo de YouTube, metadatos de mensajes, información de canales y avatares, estado de transmisiones, endpoints de moderación y estadísticas de espectadores o suscriptores, según las funciones de YouTube que actives.
  • Servicios auxiliares alojados de autenticación: En algunas versiones y modos, el intercambio de códigos OAuth o la renovación de tokens pueden realizarse mediante un servicio auxiliar alojado en lugar de íntegramente en el dispositivo. Si utilizas ese modo, los códigos de autorización, tokens de renovación y datos relacionados de solicitudes de tokens pueden pasar por dicho servicio para completar el inicio de sesión.
  • Almacenamiento local de tokens: Según la función y el proceso de inicio de sesión utilizados, los tokens pueden almacenarse localmente en el dispositivo del usuario y también enviarse a servicios auxiliares si se necesita un intercambio o una renovación remotos.
  • Política de Google: Tu uso de las funciones de YouTube también está sujeto a la Política de privacidad de Google. Puedes revocar el acceso de Google desde los ajustes de permisos de tu cuenta de Google.

7. Informes de errores de la aplicación de escritorio

La aplicación de escritorio independiente incluye una función opcional de informes de errores, desactivada salvo que el usuario la active.

  • Si se activa, la aplicación de escritorio puede enviar mensajes de error, trazas de pila, versión de la aplicación, un ID de instalación aleatorio, contexto y ajustes depurados de datos sensibles al endpoint de informes de errores del desarrollador.
  • En el momento de redactar esta política, el aviso de la aplicación de escritorio indica que los tokens OAuth, los datos de sesión y las credenciales de copias de seguridad se excluyen de esos informes.
  • En el momento de redactar esta política, el aviso de la aplicación de escritorio indica que estos informes se envían mediante un endpoint de Cloudflare Worker y se conservan durante 30 días. Los usuarios deben revisar el aviso actual de la aplicación antes de activar esta función.

8. Servicios de terceros e integraciones configuradas por el usuario

Social Stream Ninja puede interactuar con una amplia variedad de plataformas de terceros y servicios elegidos por el usuario. Sus políticas de privacidad, condiciones, controles de seguridad y prácticas de conservación son independientes de esta política y pueden diferir sustancialmente.

Si configuras el software para enviar datos a servicios de terceros, eres responsable de revisar esos servicios y decidir si tienes permiso para enviarles dichos datos.

9. Conservación, eliminación y control del usuario

Como gran parte de Social Stream Ninja funciona localmente, la conservación suele depender del dispositivo y la configuración del usuario.

  • Los ajustes locales, cachés, tokens y copias de seguridad pueden permanecer en el dispositivo hasta que el usuario borre el almacenamiento, elimine fuentes, restablezca la aplicación, elimine archivos exportados, revoque tokens o desinstale el software.
  • Los destinos de terceros configurados por el usuario pueden conservar copias de los datos reenviados conforme a sus propias políticas.
  • Los servicios auxiliares alojados o las API pueden registrar o conservar datos técnicos de las solicitudes según sus propias prácticas. Esta política no garantiza ningún período concreto de conservación para servicios de terceros.

10. Seguridad y riesgos

  • Sin garantía absoluta de seguridad: Ningún software ni servicio conectado a la red es perfectamente seguro. Utilizas Social Stream Ninja bajo tu propia responsabilidad.
  • Credenciales de sesión y fuentes: Si otras personas conocen un ID de transmisión, ID de sala, token, contraseña o enlace de retransmisión, podrían ver o insertar datos según tu configuración.
  • Riesgo de transporte: El tráfico de WebRTC, TURN, WebSocket, webhooks, retransmisión y API de terceros puede revelar información a los servicios necesarios para transportar dicho tráfico.

11. Responsabilidad del usuario

El usuario decide qué sitios, cuentas, chats y servicios conectar a Social Stream Ninja; qué datos capturar; qué superposiciones mostrar; qué archivos guardar; y a qué servicios externos retransmitir los datos.

  • Eres responsable de asegurarte de contar con el derecho y la base jurídica para recopilar, procesar, mostrar, almacenar, exportar o reenviar cualquier dato que manejes con el software.
  • Eres responsable de cumplir las condiciones de servicio, las condiciones de privacidad y las leyes locales aplicables a los servicios y personas cuyos datos proceses.
  • Debes tratar los tokens, contraseñas, ID de salas, ID de transmisiones y datos exportados como información sensible.

Social Stream Ninja se proporciona «tal cual» y «según disponibilidad», sin garantías de ningún tipo, expresas ni implícitas, incluidas garantías implícitas de comerciabilidad, idoneidad para un fin concreto y no infracción.

Al utilizar el software, aceptas que el autor, los colaboradores y los proveedores de servicios no son responsables de reclamaciones, daños, responsabilidades o pérdidas derivados de tu configuración o uso del software, incluidas reclamaciones relacionadas con contenido de terceros, recopilación o reenvío de datos, o cumplimiento legal.

13. Cambios en esta política

Esta Política de privacidad puede actualizarse periódicamente. Seguir utilizando el software después de un cambio en la política significa que aceptas la política revisada.
