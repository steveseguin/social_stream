Control de OBS con Social Stream Ninja

Controla OBS directamente desde Event Flow, sin necesitar Streamer.bot. Esta guía cubre la configuración, todos los activadores y acciones de OBS, recetas prácticas y los controles antiguos de panel/fuente de navegador.

1. Conecta Flow Actions a OBS

OBS WebSocket v5 está integrado en OBS 28 y versiones posteriores. Social Stream Ninja lo utiliza para el control completo de OBS y eventos multimedia.

  1. En OBS, abre Herramientas → Ajustes del servidor WebSocket.
  2. Activa el servidor WebSocket. Mantén el puerto predeterminado 4455; establece una contraseña si lo deseas.
  3. En Social Stream Ninja, abre el Flow Actions sección y configura la URL de OBS WebSocket y la contraseña opcional.
  4. Copia la URL de Flow Actions y mantenla abierta. Se recomienda una fuente de navegador de OBS para acciones de superposición/audio.
  5. Usa: Probador de OBS WebSocket para confirmar la conexión antes de crear un flujo.
Ejemplo de URL directa
https://socialstream.ninja/actions.html?session=YOUR_SESSION&obsws=ws://127.0.0.1:4455

Añade &obspw=YOUR_PASSWORD solo cuando OBS requiera autenticación. Añade &obsdebug=1 para mostrar una pequeña insignia de estado de conexión durante el diagnóstico.
Mantén la página Flow Actions en ejecución. Es el puente que recibe acciones de Event Flow y envía solicitudes OBS WebSocket. Si es una fuente de navegador de OBS, desactiva Apagar fuente cuando no sea visible (Shutdown source when not visible) cuando la fuente deba seguir controlando OBS mientras esté oculta.
Evento de chat / transmisión │ ▼ Event Flow de Social Stream Ninja │ mismo ID de sesión ▼ Página Flow Actions (actions.html) │ OBS WebSocket v5 · ws://127.0.0.1:4455 ▼ OBS Studio

2. Añade nodos de OBS a un flujo

  1. Abre: Editor de Event Flow y crea o edita un flujo.
  2. Arrastra un activador al lienzo.
  3. Despliega OBS Studio en la lista de acciones y arrastra la acción de OBS que necesites.
  4. Conecta el activador a la acción, configura los nombres exactos de escenas/fuentes de OBS, guarda y activa el flujo.
Los nombres de OBS deben coincidir exactamente, incluidos espacios y puntuación. Las acciones de fuentes se dirigen al nombre de la entrada de OBS, no a la etiqueta del elemento de escena si se cambió por separado.

Establecer fuente de texto y variables del flujo

El campo de texto admite los marcadores habituales de mensajes como {username}, {message}, {source}, y {donation}, además de valores añadidos por nodos anteriores del flujo como {counterValue}, {counterTarget}, y {counterRemaining}.

{username}: now {counterValue}, need {counterTarget}
Para una fuente Texto (GDI+) o Texto (FreeType 2), desactiva Leer desde archivo (Read from file). De lo contrario, OBS puede seguir mostrando el contenido del archivo en vez del texto enviado por Event Flow.

Controles de fuente multimedia

Reproducir / Pausar

Reproducir reanuda medios pausados. Pausar conserva su posición actual.

Reiniciar / Detener

Reiniciar empieza desde el principio. Detener termina la reproducción y restablece la entrada.

Siguiente / Anterior

Avanza por entradas con listas de reproducción, como Fuente de video VLC. Una fuente multimedia de un solo archivo puede ignorar estas acciones.

Volumen, silencio y filtros

Establecer volumen de fuente (Set Source Volume) utiliza dB, igual que la escala del mezclador de OBS: 0 dB mantiene la ganancia; los valores negativos reducen el volumen y -100 dB equivale prácticamente a silencio. Silenciar es un estado independiente. Alternar filtro solo cambia la activación de un filtro existente; no edita sus ajustes.

Búfer de repetición

Primero activa el búfer de repetición en Ajustes de OBS → Salida. Usa Controlar búfer de repetición (Control Replay Buffer) para iniciarlo/detenerlo, luego Guardar búfer de repetición (Save Replay Buffer) para escribir en disco el segmento reciente almacenado en el búfer.

Aviso sobre la salida en vivo: Iniciar/Detener transmisión e Iniciar/Detener grabación actúan inmediatamente. Utiliza activadores restrictivos, permisos y tiempos de espera para que los mensajes normales del chat no los activen accidentalmente.

5. Recetas útiles

Mensaje cada hora mientras OBS transmite en vivo

En el editor Event Flow, elige Empezar con una plantilla → Intermedio → Mensaje cada hora mientras OBS transmite en vivo. Empieza desactivado y contiene tres ramas en un solo flujo:

  • Transmisión de OBS iniciada → Estado de puerta: ON
  • Intervalo de tiempo (3600 segundos) → Interruptor ON/OFF → Enviar mensaje
  • Transmisión de OBS detenida → Estado de puerta: OFF

Ambas acciones Establecer estado de puerta ya apuntan al mismo interruptor, cuyo valor predeterminado es OFF. Edita Enviar mensaje (Send Message) para elegir tu plataforma de chat (el ejemplo usa Twitch) y el mensaje. Elige una plataforma o Todas las plataformas; Responder a la fuente no puede responder a un evento de OBS ni a un temporizador.

Conecta Flow Actions a OBS, mantén conectados Social Stream y el chat de destino, y guarda y activa el flujo antes de iniciar tu transmisión. El interruptor espera un evento de inicio de OBS; cargarlo durante una transmisión existente no lo pone en ON. Reiniciar Social Stream también restablece el interruptor a OFF.

Tiempos: el intervalo sigue su propio horario, así que el primer recordatorio puede llegar antes de que pase una hora desde el inicio de la transmisión. Los siguientes se repiten cada hora mientras el interruptor está en ON. Cambia el valor de Intervalo de tiempo para otra frecuencia; se mide en segundos.

Texto del contador en OBS

Coloca Establecer fuente de texto (Set Text Source) después de la ruta de contador/comprobación y utiliza:

{username}: now {counterValue}, need {counterTarget}

Ejecutar algo después de un video

Medios de OBS finalizados (OBS Media Ended) (filtra por Intro Video) → Cambiar escena (Change Scene) a Main.

Reinicio de medios controlado por el chat

El mensaje es igual a (Message Equals) !replayintro → condición de permisos → Controlar fuente multimedia: Reiniciar.

Actualizar una página de alertas

El mensaje es igual a (Message Equals) !refreshalerts → condición de moderador → Actualizar fuente de navegador (Refresh Browser Source).

Bajar la música durante una alerta

Establecer volumen de fuente (Set Source Volume) a -24 dB → acción de alerta → Espera → restaurar a 0 dB.

Flujo de repetición

Transmisión de OBS iniciada (OBS Stream Started) → Controlar búfer de repetición: Iniciar; un comando de confianza independiente ejecuta Guardar búfer de repetición (Save Replay Buffer).

7. Solución de problemas

ProblemaComprueba
No ocurre nadaEl flujo está guardado y activado; Flow Actions está abierto; ambos utilizan el mismo ID de sesión.
OBS no se conectaEl servidor WebSocket está activado, la URL es ws://127.0.0.1:4455, y la contraseña coincide. El puerto 4444 es el valor predeterminado obsoleto de v4.
No se encuentra la escena/fuente/filtroCopia el nombre exacto de OBS. Para la visibilidad, configura Escena o Grupo cuando el elemento esté anidado o fuera de la escena actual.
El texto no cambiaUtiliza Texto (GDI+) o Texto (FreeType 2), confirma el nombre de la entrada y desactiva Leer desde archivo (Read from file).
Fin de medios nunca se activaUtiliza OBS WebSocket v5 y una entrada multimedia real. Los medios en bucle no alcanzan el estado finalizado.
Siguiente/Anterior no hace nadaUtiliza una fuente compatible con listas de reproducción, como Fuente de video VLC.
Falla el guardado de la repeticiónActiva el búfer de repetición en los ajustes de Salida de OBS e inícialo antes de guardar.
Las acciones se detienen al cambiar de escenaDesactiva Apagar fuente cuando no sea visible (Shutdown source when not visible) en la fuente de navegador de Flow Actions, o mantén la página abierta en otro lugar.
Orden de diagnóstico: abre el probador → confirma GetVersion → confirma escenas/entradas → prueba la solicitud individual → prueba el Event Flow completo.
