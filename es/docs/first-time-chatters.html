Guía de participantes que escriben por primera vez

Identifica a quienes escriben por primera vez con un resaltado, una insignia de hoja o una señal sonora opcional.

Qué hace esta función

La detección de participantes nuevos añade firsttime=true al primer mensaje de chat guardado de un espectador para esa fuente. El panel puede utilizar ese indicador para resaltar el fondo, emitir un pitido solo la primera vez y mostrar la insignia de hoja opcional.

Configuración necesaria

  1. Abre la ventana emergente de Social Stream Ninja.
  2. Mantén Desactivar la base de datos local de mensajes en estado desactivado.
  3. Activa Detección de participantes nuevos.
  4. Deja abierto el panel o la superposición con el mismo ID de sesión.
Importante: La base de datos local es necesaria. Si está desactivada, Social Stream Ninja no puede saber si alguien es nuevo.

Opciones de visualización

  • Resaltado de fondo: activado de forma predeterminada en el panel. Mantén Sin resaltado de fondo para quienes escriben por primera vez desactivado si quieres el resaltado.
  • Insignia de hoja: activa Marcar a quienes escriben por primera vez con una insignia personalizada para anteponer una pequeña insignia de hoja a las insignias del participante.
  • Pitido del panel para quienes escriben por primera vez: activa esta opción si quieres que el pitido del panel suene solo para quienes escriban por primera vez.
  • Pitido para participantes nuevos o que regresan: activa esta opción si también quieres un sonido para los espectadores que regresen tras 8 horas o más sin escribir.

Usar el indicador en superposiciones personalizadas

Las superposiciones personalizadas pueden buscar data.firsttime === true. Si está activada la opción de insignia de hoja, la insignia se incluye en chatbadges antes de que el mensaje llegue a las superposiciones.

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

Si no aparece

  1. Confirma que Desactivar la base de datos local de mensajes esté desactivado.
  2. Confirma que Detección de participantes nuevos esté activado.
  3. Confirma que Sin resaltado de fondo para quienes escriben por primera vez esté desactivado si esperas ver un resaltado.
  4. Confirma que Marcar a quienes escriben por primera vez con una insignia personalizada esté activado si esperas ver la insignia de hoja.
  5. Prueba con una combinación de nombre de usuario y fuente que no esté guardada en la base de datos local.
