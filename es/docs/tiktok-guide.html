Guía de TikTok

Cómo conectar TikTok en Social Stream Ninja, elegir el modo adecuado, enviar respuestas y usar TikFinity como alternativa cuando haga falta.

Descripción general

Empieza aquí

TikTok es una de las plataformas más difíciles de mantener estable porque cambia su comportamiento con frecuencia y no todas las cuentas ven lo mismo.

Recomendación rápida:
  • Empieza con TikTok WS + Auto.
  • Si necesitas responder, cambia a Standard.
  • Si Standard falla, prueba Firmante local (Local Signer).
  • Si TikTok sigue perdiendo mensajes, usa Dock de OBS de TikFinity mediante Otros sitios de chat.
Importante: Los problemas de TikTok no siempre son causados por SSN. La falta de mensajes, los fallos de autenticación y la limitación de solicitudes pueden deberse a TikTok, al estado de la cuenta o a restricciones regionales.
Modos

¿Qué opción de TikTok debería usar?

Opción Ideal para Respuestas
TikTok WS + Auto La mejor opción predeterminada para la mayoría. Usa primero WebSocket y cambia a Polling si hace falta. No
Standard Ideal si quieres enviar respuestas desde SSN y usar la página de TikTok Live dentro de la aplicación. Sí
TikTok WS + Local Signer Alternativa cuando Standard falla, pero aún quieres responder. Sí
Sondeo (Polling) Modo de compatibilidad. Más lento, pero útil cuando fallan las rutas de WebSocket. No
Euler Proxy / Euler Signing Opciones avanzadas de firma para usuarios con su propia clave API o configuración personalizada. Normalmente no
Dock de OBS de TikFinity Alternativa de solo lectura cuando los modos nativos de TikTok pierden demasiado chat o no se conectan. No
Paso 1

Conectar TikTok en SSN

  1. Abre la aplicación independiente.
  2. Haz clic en el botón TikTok en la barra lateral izquierda.
  3. Introduce el nombre de usuario de TikTok, la URL del directo o el valor solicitado.
  4. Elige el modo o configuración predefinida de TikTok que quieras.
  5. Haz clic en Activar fuente (Activate source).
Paso 2

Si necesitas responder

  1. Usa Standard primero.
  2. Haz clic en Iniciar sesión si es necesario.
  3. Abrir Mostrar página de captura (Show capture page).
  4. Asegúrate de haber iniciado sesión con la cuenta de TikTok que debe enviar los mensajes.
Paso 3

Si Standard es inestable

  1. Prueba Firmante local (Local Signer).
  2. Mantén abierta la ventana de firma.
  3. Si WebSocket sigue fallando, prueba Sondeo (Polling).
  4. Si TikTok sigue perdiendo demasiado chat, cambia a la alternativa de TikFinity de abajo.
Respuestas

Cómo responder al chat de TikTok

La compatibilidad con respuestas depende de tener una sesión válida de TikTok iniciada.

  • Mejor modo para responder: Standard
  • Modo alternativo para responder: Firmante local (Local Signer)
  • No está pensado para responder: Auto, Polling, TikFinity como alternativa
Regla práctica: si lo más importante es la fiabilidad de lectura, empieza con Auto o Polling. Si lo más importante es responder, usa Standard o Local Signer.
Alternativa

Cómo usar el Dock de OBS de TikFinity

TikFinity puede funcionar como fuente de respaldo cuando TikTok pierde u oculta demasiado chat.

  1. Abre TikFinity.
  2. Ve a Overlay -> OBS Docks.
  3. Elige un espacio de Dock y configúralo para chat.
  4. Copia la URL del Dock.
  5. En SSN, haz clic en Otros sitios de chat.
  6. Pega la URL del Dock de TikFinity.
  7. Activa la nueva fuente y mantén TikFinity abierto mientras estés en directo.
  • Es un lector de respaldo, no una herramienta para responder.
  • Si ya usas widgets del feed de actividad de TikFinity, SSN también puede funcionar con páginas compatibles de widgets de TikFinity en flujos de trabajo basados en navegador.

Para una explicación completa de esta alternativa y Discord StreamKit, consulta Fuentes de Discord StreamKit y TikFinity. Para detalles sobre los datos de eventos, consulta la Referencia de eventos.

Solución de problemas

Problemas frecuentes de TikTok

«Dice que no estoy en directo»

  • El chat de TikTok solo funciona cuando la cuenta está realmente en directo.
  • Empieza a transmitir primero y luego prueba Recargar (Reload).
  • Las pruebas después de terminar una transmisión suelen fallar.

«La ventana de autenticación se cierra»

  • Usa Mostrar página de captura (Show capture page) para poder ver el inicio de sesión o el CAPTCHA.
  • Prueba Recargar (Reload) después de iniciar sesión.
  • Si es posible, cierra las pestañas o aplicaciones adicionales de TikTok en el mismo dispositivo.

«Faltan mensajes»

  • Puede ser una limitación de TikTok, no siempre un fallo de SSN.
  • Prueba otro modo antes de decidir que una ruta es siempre la mejor.
  • Usa TikFinity como alternativa si funciona mejor con tu cuenta.

«Los mensajes se duplican después de reconectar»

  • Actualiza primero a la versión más reciente de la aplicación.
  • Detén la fuente por completo y luego vuelve a conectarla desde cero.
  • Si sigue duplicando mensajes, cambia de modo o usa TikFinity temporalmente.

«Me limitan las solicitudes constantemente»

  • Cierra otras pestañas, aplicaciones o visores duplicados de TikTok en el mismo dispositivo.
  • Espera unos minutos antes de volver a intentarlo.
  • Prueba otro modo o método de firma.

«¿Qué debería probar primero?»

  • Auto para leer
  • Standard para responder
  • Local Signer si Standard es inestable
  • TikFinity si el problema es TikTok
Extensión

Si usas la extensión del navegador

  • Abre en el navegador la página de TikTok Live del emisor y mantén activada la extensión.
  • Inicia sesión si necesitas eventos de página solo para usuarios autenticados o para el anfitrión en tu propio directo.
  • Las páginas de feed de actividad de TikFinity también pueden funcionar en configuraciones de SSN basadas en navegador.
  • La aplicación independiente sigue ofreciendo la mayor selección de modos de TikTok y las opciones alternativas más claras.
