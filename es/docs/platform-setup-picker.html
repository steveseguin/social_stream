Selector de configuración de plataformas

Elige la forma de captura más sencilla antes de abrir OBS.

Empieza por la página de sitios compatibles

Busca primero tu plataforma. Haz clic en ella y lee la breve nota de configuración antes de probar un método más complicado.

Usa la extensión normal del navegador cuando

  • La plataforma funciona en tu navegador habitual.
  • Ya has iniciado sesión con la cuenta adecuada.
  • La página de sitios compatibles indica que abras el sitio o el chat en una ventana emergente.

Empieza aquí para YouTube, Twitch, Facebook, Discord, Slack, WhatsApp y la mayoría de las fuentes del navegador.

Usa una ventana emergente o solo de chat cuando

  • La plataforma tiene una URL separada para abrir el chat en una ventana emergente.
  • La página normal del directo consume muchos recursos o es poco fiable.
  • Quieres una ventana más pequeña que solo muestre el chat.

Para consultar las notas específicas de cada plataforma, consulta Sitios compatibles.

Usa la aplicación de escritorio cuando

  • Las pestañas del navegador se están ocultando, limitando o descartando.
  • Quieres gestionar las ventanas de fuentes dentro de la aplicación.
  • Usas una integración específica de la aplicación, como algunos modos de TikTok.

Configuración de escritorio: Guía de la aplicación independiente.

Usa una página de fuente cuando

  • La plataforma necesita una URL de fuente específica de Social Stream.
  • La configuración pide un canal, una sala, un token o que inicies sesión.
  • La plataforma no se captura desde una pestaña normal del navegador.

Las páginas de fuente son normales. Solo significan que Social Stream necesita una página especial para esa plataforma.

Decisión rápida

SituaciónUsa
Sitio de chat compatible estándarExtensión del navegador
El sitio indica que abras el chat en una ventana emergenteVentana emergente o solo de chat
Una pestaña oculta deja de actualizarseAplicación de escritorio
La configuración pide sala, canal o tokenPágina de fuente
Automatización personalizada o datos entrantesComandos/API o fuente personalizada

Si tienes dudas, empieza por la opción más sencilla que encaje. Puedes cambiar de método después.
