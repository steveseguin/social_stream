Referencia de ajustes

Explora todos los interruptores, campos de texto y menús desplegables del panel de Social Stream Ninja, con descripciones y ámbitos de aplicación.

Alterna entre el catálogo de controles del panel y el índice de parámetros de URL de los overlays. Ambas vistas usan la configuración compartida para mantener la coherencia.

Esta página obtiene datos en tiempo real de popup.html para mantenerse sincronizada con la extensión y la aplicación de escritorio. Usa el campo de búsqueda para filtrar por palabra clave o abre el archivo de definición de ajustes en shared/config/settingsDefinitions.js para ampliar las descripciones y los ámbitos de aplicación.

¿Quieres dar un color diferente a cada participante del chat? Sigue la guía de colores de nombres del chat; deben estar activadas tanto la opción general de color como la opción de visualización del dock.

Los datos se generan a partir de parameters.md y se exportan mediante shared/config/urlParameters.js para que puedan usarse en la documentación y las ayudas de la aplicación.
