Usa un overlay en tu directo

Introduce el ID de sesión de Social Stream Ninja y elige Abrir overlay en una tarjeta. Copia ese enlace en una fuente de navegador de OBS. Los overlays de destacados muestran mensajes seleccionados desde tu dock; las alertas múltiples muestran eventos entrantes.

CONJUNTO A JUEGO

Añade cada enlace como una fuente de navegador de OBS independiente. Los mensajes destacados proceden de tu dock; las alertas responden a eventos entrantes.

Estos campos se quedan en esta página y no se guardan. Para modo servidor, filtros, ocultación automática y otras opciones, usa el ajuste predefinido correspondiente en la aplicación.

No hay overlays coincidentes. Prueba otra búsqueda o elige Todos los overlays.
