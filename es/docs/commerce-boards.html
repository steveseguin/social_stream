Tableros de plazas y ventas recientes

Lleva el control de las plazas disponibles y mantén las compras recientes en pantalla. Se controla desde SSN y se muestra en OBS.

Revelar plazas ↓Tableros de equipos ↓Ventas recientes ↓Whatnot / eBay Live ↓

Tablero de plazas

Plazas numeradas

Abrir vista previa de ejemplo ↗
  1. Crea el tableroEn Monetización → Tableros de plazas y ventas recientes (Monetization → Spot boards & recent sales), elige casillas numeradas. Usa 120 plazas y 20 columnas para una cuadrícula de 20 × 6.
  2. Marcar una asignaciónSelecciona una casilla y luego Registrar venta para esta plaza (Record sale for this spot) después de comprobar el pago. Usa Marcar solo como asignada (Mark claimed only) para una reserva sin entrada de venta.
  3. Revelar el artículoIntroduce el artículo asignado y selecciona Revelar (Reveal). Usa Marcar como disponible (Make available) para corregir una plaza, o Reembolsar y reabrir (Refund & reopen) para eliminar también su venta vinculada.

SSN muestra tus asignaciones. No vende plazas ni asigna premios al azar.

Plazas con nombre

Aperturas por equipos

Una apertura de cartas por equipos reparte las cartas abiertas por equipo, jugador u otra plaza con nombre.

  1. Elige Casillas de equipos.
  2. Pega los nombres de tus equipos, uno por línea. Esa lista determina el número de plazas.
  3. Marca cada plaza comprada como asignada. Revélala cuando esté todo listo.
Abrir vista previa de equipos ↗

El anfitrión controla las asignaciones. SSN no deduce una compra de equipo a partir de un mensaje de chat ni del final de una subasta.

Durante un programa de Whatnot o eBay Live

  1. Captura tu programaAbre tu programa en SSN y activa Capturar eventos del directo (Capture Stream Events). Whatnot necesita la vista del programa con el pie de subasta visible. eBay Live admite la página del chat o del directo.
  2. Comprueba la ventaEn Ventas recientes, elige Whatnot o eBay Live en Asistente de artículos de subasta y guarda. Usar artículo de subasta (Use auction item) copia el último nombre capturado. Comprueba el artículo y el pago en la plataforma de venta e introduce el total y la moneda.
  3. Confirma y luego revelaPara una plaza, selecciona su casilla y elige Registrar venta para esta plaza (Record sale for this spot) primero. Confirmar venta y asignar plaza (Confirm sale & claim spot) registra ambas cosas juntas. Añade el texto de revelación cuando quieras mostrar el artículo asignado.

El asistente es un borrador para el operador. Nunca convierte una puja ni el fin de una subasta en una venta. Las actualizaciones nuevas de subasta no modifican tu borrador. Activa Mostrar ventas recientes para seleccionar la presentación para la audiencia; usa fuentes de OBS separadas para el tablero y las ventas si quieres mostrar ambos.

Para un reembolso, usa Reembolsar y reabrir (Refund & reopen) en una venta vinculada para eliminarla y liberar la plaza. Eliminar (Remove) solo elimina la entrada de venta. Un tablero de sustitución se mantiene separado de las ventas del anterior.

Captura en directo frente a conexión a una tienda

La captura de Whatnot y eBay Live proporciona el artículo, la puja y el estado de la subasta. La conexión separada de conexión de vendedor de eBay recibe eventos de pedidos pagados de anuncios seleccionados; puede rellenar las ventas recientes automáticamente. Evita confirmar manualmente una compra que tu conexión a la tienda ya registra. Otras fuentes automáticas son Shopify, Fourthwall, Ko-fi y Buy Me a Coffee.

El asistente conserva solo el último artículo capturado de la plataforma seleccionada, caduca tras cinco minutos sin actualizaciones y se vacía al reiniciar. Comprueba el artículo si tienes varios programas abiertos. Un asistente vacío necesita una nueva actualización de subasta después de activarse.

eBay: comprueba el estado del pago en la consola del vendedor · Whatnot: pagos de subastas fallidos

Correcciones y reembolsos

Elimina errores o ventas reembolsadas. Vacía el muro para un programa nuevo.

Las pujas, propinas, regalos y pruebas de sandbox no lo rellenan. Asignar plazas no crea ventas.

Precios, historial y privacidad

Las fuentes de compras conectadas no proporcionan precios de los artículos de forma uniforme, por lo que las filas automáticas los dejan vacíos. Para mostrar un precio conocido, elimina esa fila y confírmala manualmente. Para varios artículos, introduce el total de esa entrada, no un precio por artículo. No se sustituye por el precio del anuncio, la puja más alta ni el importe de una donación.

SSN conserva las 100 entradas más recientes en esta instalación, incluso tras reiniciar. La recopilación empieza al activarla; no importa todo el historial de pedidos. Se ignoran los ID de entrega repetidos dentro de la ventana de 2.000 ID guardados. Los reembolsos requieren eliminación manual.

Esta pantalla no incluye nombres de compradores, direcciones, datos de pago ni texto de artículos sin revelar. Los enlaces de demostración usan datos ficticios claramente identificados.

Configuración de OBS

  1. Elige una presentaciónSelecciona Tablero de plazas/equipos, Lista de ventas recientes, Muro o Franja en los controles del tablero.
  2. Copiar enlace de OBS (Copy OBS link)Añade una fuente de navegador de 1920 × 1080. El espacio transparente deja ver tu cámara.
  3. Contrólalo en SSNMantén SSN encendido. Los cambios se guardan inmediatamente. El dock de control de productos de OBS tiene los mismos controles si lo prefieres.
Ajustes opcionales de URL

&view=board, sales, wall o ticker elige el diseño. &limit=6 muestra hasta seis entradas recientes (máximo 24). &prices=0 oculta los precios. &label=Recently%20sold establece el encabezado de ventas. &onlytype=shopify,ebay filtra las fuentes de ventas.

Conserva los ajustes de sesión, contraseña y retransmisión del enlace copiado. Si no hay conexión o contenido, la pantalla permanece transparente; los mensajes de configuración nunca aparecen en el overlay de la audiencia.

Integración con API y Event Flow

Estos controles amplían la API existente commerceControl . SSN, las acciones personalizadas de API de Stream Deck y el dock opcional de OBS leen la misma respuesta getCommerceState .

{"action":"commerceControl","value":{"command":"boardSpot","data":{"id":"12","status":"claimed"}}}

Comandos: boardSave (title, style, columns, count o labels separados por saltos de línea), boardSpot (id, status, result), boardVisibility (visible), saleAdd (title, amount/currency/quantity/platform opcionales; boardId y spotId opcionales para asignar una plaza), saleRemove (id, reopenSpot opcional), salesClear, y salesSettings (visible, automatic, auctionSource opcional: whatnot, ebay o una cadena vacía). Coloca esos campos en data. Estas ediciones no emiten eventos de compra ni activan recompensas de pago.

En Event Flow, usa la acción existente Productos y apoyo . Elige un comando de tablero o ventas e introduce sus campos en Campos de tableros / ventas. Los valores de cadena admiten variables como {subtitle}. Haz coincidir un evento de compra confirmada para las acciones de venta. Desactiva la recopilación automática si tu flujo añade manualmente la misma venta.
