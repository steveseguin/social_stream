Inicio rápido de TikTok

Empieza aquí si solo necesitas que funcione el chat de TikTok Live.

1. Busca TikTok

Abre: Sitios compatibles y busca TikTok. Esto confirma la regla básica de configuración antes de empezar a cambiar OBS.

2. Abre la página de TikTok Live

Para la extensión del navegador, abre la página del directo del creador y mantén visible el chat.

https://www.tiktok.com/@CHANNEL/live

Si las pestañas del navegador siguen pausando u ocultando el chat, prueba la aplicación de escritorio.

3. Usa un solo ID de sesión

Elige un ID de sesión corto. Usa exactamente ese ID en la fuente de TikTok, el Dock y OBS.

YOUR_SESSION_ID

4. Revisa el Dock antes de OBS

Abre el Dock con tu ID de sesión. Envía o espera un mensaje de chat de TikTok.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

5. Añade la superposición a OBS

Añade una fuente de navegador en OBS y usa el mismo ID de sesión.

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

Configuración de plantillas: Inicio rápido de plantillas de superposición.

Si TikTok no aparece

  • Asegúrate de que la página de TikTok Live esté realmente en directo.
  • Mantén visible el chat al usar la extensión del navegador.
  • Confirma que el Dock y OBS usen el mismo ID de sesión.
  • Actualiza el Dock después de cambiar el ID de sesión.
  • Prueba la aplicación de escritorio si el navegador limita la actividad de la pestaña.
