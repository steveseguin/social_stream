Respuestas desde tus archivos

Prepara, importa y prueba una base de conocimiento para tu bot de chat.

Configura primero el bot de chat

1. Preparar→2. Importar→3. Probar

1. Prepara archivos por tema

Usa un archivo pequeño de texto o Markdown por tema: planes, envíos, devoluciones u horarios. Mantén juntos los nombres, precios, fechas, condiciones y excepciones.

Usa encabezados claros y datos completos. Sustituye las referencias vagas por el nombre del producto o plan.

Opcional: pide ayuda a una IA para preparar los archivos

Pide a una IA capaz que organice el material desordenado. Compara su borrador con el original: una respuesta bien redactada también puede alterar un dato.

Copia este prompt y añade tu material original:

Organize the source material into short Markdown files, one topic per file.
Keep every name, price, date, URL, condition, and exception exactly.
Use clear headings and complete facts in the source language.
Do not invent answers or silently resolve conflicting facts.
List missing or conflicting facts separately for my review.
Return each filename followed by its contents.

Comprueba todos los precios, plazos, restricciones y enlaces antes de guardar los archivos.

2. Importa y elige las respuestas

Abre Chat Bots and AI services → Chat Bot - Primary → Chat bot knowledge. Activa la base de conocimiento y añade tus archivos.

Deja desactivado el enriquecimiento con IA en la primera importación. Opcionalmente añade resúmenes y etiquetas de búsqueda mediante el servicio de IA seleccionado, que puede cobrar por el procesamiento.

Compara la búsqueda por palabras clave y la búsqueda semántica local para inglés. Para otros idiomas, empieza por palabras clave y prueba preguntas reales en el idioma de tus espectadores. El modelo semántico incluido está diseñado para inglés.

Activa «Answer only from my files» para basar las respuestas factuales en tu base de conocimiento.

¿Deben recibir respuesta los comentarios sin información suficiente?

Con «Do not screen out any of the bot’s replies» activado, el bot puede saludar, pedir aclaraciones o reconocer que falta información. De lo contrario, las preguntas sin respuesta pueden quedar en silencio.

3. Comprueba antes del directo

Durante las pruebas, envía las respuestas solo a la superposición. Haz una pregunta con respuesta conocida, reformúlala y pregunta algo que los archivos no cubran.

Respuesta conocidaOtra forma de preguntarInformación ausente

Compara las respuestas con los datos originales. Aclara el contenido, sustituye las importaciones obsoletas y repite las mismas preguntas.
