Para qué sirve la aplicación

La aplicación de escritorio administra ventanas de fuentes de Social Stream fuera de tu navegador habitual. Puede ayudarte a organizar fuentes y resolver algunos problemas de limitación de actividad de las pestañas. No es lo mismo que Chrome y no comparte automáticamente tu inicio de sesión ni tus cookies de Chrome.

Nombres de los modos

Algunas fuentes tienen más de un modo de conexión. El modo adecuado depende de la plataforma, del estado de inicio de sesión y de si necesitas eventos más completos o una captura sencilla de la página.

ModoSignificado sencilloCuándo usarlo
StandardLa aplicación abre una página normal de la plataforma o fuente y lee la página renderizada.Necesitas la captura de página visible, el inicio de sesión o la verificación manual más sencillos.
WebSocket/APILa fuente se conecta mediante una API de la plataforma, un socket o una página de fuente de Social Stream.La plataforma lo admite y quieres más fiabilidad en segundo plano o datos de eventos más completos.
Sondeo/Antiguo (Polling/Legacy)Una vía de compatibilidad que consulta las actualizaciones en vez de utilizar la conexión en vivo por socket preferida.El conector nuevo falla o necesitas una alternativa específica de la plataforma.
TikTok automático (Auto)La aplicación elige la mejor vía para TikTok y puede recurrir a una alternativa si falla.No sabes qué modo de TikTok utilizar.

Cuándo usar el modo estándar

  • La plataforma funciona cuando puedes ver la página en vivo o el chat emergente.
  • El sitio necesita que inicies sesión, resuelvas una verificación o mantengas abierto un panel de chat visible.
  • Estás comparando el comportamiento de la aplicación con el de la extensión de Chrome.
  • Necesitas el procedimiento más conocido de solución de problemas: abrir la página, ver el chat, probar el panel y luego OBS.

El modo estándar también puede fallar si la plataforma cambia el diseño de su página, bloquea navegadores integrados o de aplicaciones, pide un CAPTCHA u oculta el chat tras un inicio de sesión.

Cuándo usar WebSocket o API

  • La fuente admite específicamente el modo WebSocket/API.
  • Quieres una fuente que funcione mejor en segundo plano.
  • Necesitas tipos de eventos que la captura normal de páginas quizá no ofrezca.
  • Puedes gestionar tokens del proveedor, permisos de cuentas, ámbitos de API o la configuración de páginas de fuentes.

El modo WebSocket/API no siempre es mejor. Si fallan la autenticación, los tokens, el acceso del proveedor o una API de la plataforma, el modo estándar puede ser la prueba más rápida.

TikTok en la aplicación

TikTok en la aplicación de escritorio no tiene un único modo. Anota siempre qué ajuste está activo antes de resolver problemas.

Vía de TikTokCaso de usoPunto de fallo habitual
AutomáticoPrimera opción para la mayoría de los usuarios.La aplicación puede utilizar una alternativa, así que comprueba el texto de estado.
StandardCaptura de la página visible de TikTok.Inicio de sesión, CAPTCHA, página redirigida o chat oculto.
Firmante local (Local Signer)Vías de lectura y respuesta propias de la aplicación.La sesión y las cookies de TikTok en la aplicación deben ser válidas.
Sondeo/Compatibilidad (Polling/Compatibility)Alternativa cuando fallan las conexiones por socket o los mecanismos de firma.Ofrece menos datos que el conector preferido.
Proxy o firma personalizadaConfiguraciones avanzadas.Disponibilidad del proveedor, clave de API, ID de sala o límites de solicitudes.

Para una primera prueba normal, añade TikTok, deja el ajuste en Auto, activa la fuente y observa el texto de estado de la aplicación.

Qué comprobar antes de OBS

  1. Confirma que la fuente de la aplicación esté activada.
  2. Confirma que hayas iniciado sesión en la ventana de la fuente si la plataforma lo requiere.
  3. Confirma que el panel recibe chat con el mismo ID de sesión.
  4. Solo después de que funcione el panel, añade o actualiza la URL de la superposición de OBS.
  5. Si Chrome funciona pero la aplicación no, recuerda que las sesiones de la aplicación y de Chrome son independientes.

Soluciones habituales

  • Chrome tiene la sesión iniciada, pero la aplicación no: inicia sesión en la plataforma dentro de la ventana de la fuente de la aplicación o utiliza la extensión para capturar.
  • La fuente aparece activa, pero no llega chat: comprueba el modo, la ventana de la fuente, la URL en vivo o el nombre de usuario y la sesión del panel.
  • La aplicación utiliza archivos de fuentes incorrectos: comprueba si la aplicación utiliza archivos de Social Stream incluidos, en caché, remotos, beta, estables o locales.
  • TikTok falla: anota el ajuste actual, el texto de estado, la versión de la aplicación y si la fuente cambió a un modo alternativo.
  • OBS está en blanco: prueba primero el panel. Si está vacío, el problema todavía no está en OBS.
