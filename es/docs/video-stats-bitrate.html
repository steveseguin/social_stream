Estadísticas de vídeo y tasa de bits

Muestra la tasa de bits de la transmisión entrante en la esquina superior derecha del dock de Social Stream Ninja.

Importante: SSN no lee automáticamente la tasa de bits de OBS ni de una plataforma de streaming. Consulta la API de estadísticas del servidor de vídeo que recibe tu transmisión.

Para qué sirve

Proporciona al presentador o productor un pequeño indicador de tasa de bits en directo en el dock. Resulta útil cuando OBS, un codificador móvil u otro emisor envía vídeo a tu propio servidor de retransmisión o recepción.

SSN también normaliza los datos disponibles de latencia, búfer, pérdida de paquetes, tiempo de actividad, códecs y espectadores en un evento de metadatos video_stats . El indicador estándar del dock solo muestra la tasa de bits.

Compatibilidad

  • SRT Live Server / SLS: JSON /stats al endpoint que contiene un objeto publishers .
  • Belabox Cloud: su respuesta JSON de estadísticas del receptor o retransmisor con formato SRT.
  • NGINX RTMP: XML del módulo de estado de NGINX RTMP.
  • Node Media Server: su API JSON de transmisiones, con autenticación HTTP Basic opcional.
OBS no es una fuente de estadísticas: OBS puede enviar vídeo a un servidor compatible, pero OBS WebSocket y las fuentes de navegador de SSN no proporcionan estos datos.

Cómo usarlo

  1. Activa el endpoint HTTP de estadísticas del servidor compatible y comprueba que el equipo que ejecuta SSN pueda abrir su URL.
  2. En SSN Ajustes globales, activa Sondeo de estadísticas de vídeo.
  3. Selecciona el tipo de fuente e introduce la URL de estadísticas.
  4. Para SRT o Belabox, introduce el ID exacto del emisor, como publish/live/feed1. SSN lo usa automáticamente cuando la respuesta contiene un solo emisor.
  5. Para NGINX RTMP o Node Media Server, introduce la aplicación y la clave o el nombre de la transmisión, como live y feed1.
  6. Añade autorización si hace falta. El campo de clave de API de SRT se envía como el valor completo del encabezado Authorization . Node Media Server usa el nombre de usuario y la contraseña como autenticación HTTP Basic.
  7. Elige un intervalo de sondeo de 1 a 60 segundos; el valor predeterminado es de cinco segundos.
  8. En las opciones del dock, activa Mostrar metadatos de tasa de bits si están disponibles; esquina superior derecha (Show bitrate metadata if available; top-right), y luego abre o actualiza el enlace del dock.
  9. Empieza a enviar vídeo. La tasa de bits aparece después de una respuesta válida que indique que la transmisión está activa.

Si no aparece nada

  • Comprueba que ambas opciones de estadísticas de vídeo estén activadas en SSN.
  • Comprueba que el endpoint responda en cinco segundos y que coincidan el tipo de fuente y los identificadores de la transmisión.
  • 127.0.0.1 se refiere al equipo que ejecuta SSN. Usa la dirección LAN del servidor cuando esté en otro dispositivo.
  • El indicador desaparece cuando la transmisión está desconectada, la tasa de bits falta o es cero, o no llegan estadísticas nuevas durante unos 130 segundos.

Avanzado: protocolo, formatos y unidades

SSN realiza una solicitud HTTP o HTTPS de tipo GET con el intervalo configurado, sin caché y con un tiempo de espera de cinco segundos.

SRT Live Server / SLS y Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate está en Kbps; RTT y búfer de recepción, en milisegundos; velocidad de recepción y ancho de banda, en Mbps; tiempo de actividad, en segundos; pérdidas/descartes, en recuentos de paquetes o bytes.

NGINX RTMP

La URL debe devolver XML de estado de NGINX RTMP. SSN busca la aplicación y la transmisión configuradas. Lee bw_video como bytes por segundo y divide entre 1024 para obtener bitrateKbps. También lee el tiempo de transmisión y metadatos opcionales de los códecs de vídeo y audio.

Node Media Server

SSN solicita STATS_URL/APPLICATION/STREAM_NAME. Los campos pueden estar en el nivel superior o dentro de data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

La tasa de bits se expresa en Kbps, los espectadores son un recuento y la duración se expresa en segundos.

Evento normalizado de SSN

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
CampoUnidad/tipo
bitrateKbpsKbps, número entero
rttMs / bufferMsMilisegundos
recvRateMbps / bandwidthMbpsMbps
Campos de pérdidas/descartesRecuentos de paquetes o bytes
uptimeSeconds / durationSecondsSegundos
onlineBooleano; false oculta el valor del dock

El dock acepta meta.bitrateKbps, con meta.bitrate y meta.kbps como alternativas. Los valores inferiores a 1000 se muestran redondeados en Kbps; los mayores se muestran en Mbps con un decimal. La URL de estadísticas, la clave de transmisión y las credenciales nunca se envían a los overlays.
