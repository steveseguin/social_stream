Base de conocimientos

Respuestas breves para problemas comunes. Usa las guías cuando necesites instrucciones completas.

Superposición vacía en OBS

Revisa primero el Dock. Si está vacío, corrige la fuente/plataforma. Si funciona, abre la URL exacta de la superposición en un navegador normal y confirma el mismo session, y luego actualiza la fuente de navegador de OBS.

Abrir solución de problemas de OBS

Sesión incorrecta

La fuente, el Dock, la superposición, el bot y las páginas de Event Flow deben usar el mismo ID de sesión. Trata los ID de sesión como nombres de salas: una escritura distinta significa una sala distinta.

dock.html?session=YOUR_SESSION

Abrir sesiones, contraseñas y modos de relé

Actualizar sin perder los ajustes

Exporta primero los ajustes, no desinstales la extensión durante una actualización rutinaria y usa la transferencia cifrada de sesión completa de la aplicación de escritorio si también necesitas mover cookies e inicios de sesión.

Abrir actualizaciones seguras, copias de seguridad y recuperación

OBS no oye la síntesis de voz

La síntesis de voz del sistema suele sonar por el equipo, pero no por la fuente de navegador de OBS. Usa un modo de proveedor/navegador, como Kokoro, Piper, Kitten, eSpeak, uno compatible con OpenAI o un proveedor en la nube, o dirige el audio del sistema por separado.

Abrir guía de configuración de síntesis de voz

Kokoro no habla portugués ni español

Las voces integradas de Kokoro son en inglés. Para portugués, usa Piper con pipervoice=pt_BR-faber-medium, o eSpeak con espeakvoice=pt-br. Para español, usa Piper con pipervoice=es_ES-davefx-medium, o eSpeak con espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Abrir configuración de proveedores de síntesis de voz

Funciona en Chrome, pero no en la aplicación de escritorio

La aplicación de escritorio usa sesiones de Electron, no tu perfil habitual de Chrome. Inicia sesión dentro de la ventana de origen de la aplicación o usa la extensión de Chrome cuando la plataforma bloquee los navegadores integrados o de aplicaciones.

Abrir modos de la aplicación independiente

¿Qué servidor local necesito?

Habilitar servidor local (Enable Local Server) es un relé WebSocket para páginas compatibles de SSN. API de control local es para scripts y herramientas de IA en el mismo equipo. El alojamiento sin interfaz ejecuta la aplicación de escritorio completa en un servidor Linux. El servidor multimedia de Event Flow solo sirve archivos locales autorizados.

TikTok falla o cambia de modo

Anota el modo de la aplicación, el proveedor de firma, el texto de estado, la versión y si el chat es visible en modo Standard. Prueba un modo de TikTok cada vez.

Abrir modos de TikTok en la aplicación

Falta el chat de YouTube

Confirma que la transmisión esté en vivo, que el chat sea visible y que uses la ruta correcta de YouTube: chat en vivo, comentarios estáticos, captura Standard o modo WebSocket/API.

Abrir guía de configuración de YouTube

Las respuestas del bot no se envían

Leer chat no es lo mismo que publicarlo. Revisa la compatibilidad de envío a la plataforma, el inicio de sesión, el rol de cuenta, el modo de fuente, la respuesta del proveedor y los límites de frecuencia.

Abrir la guía de configuración del bot de chat con IA

Event Flow no hace nada

Confirma que el evento de origen llegue al Dock. Para acciones de audio, medios y OBS, mantén actions.html?session=YOUR_SESSION abierto con la misma sesión.
