Descripción general

SSN puede leer texto de chat capturado de cualquier fuente compatible; la plataforma de chat no necesita su propia función TTS. Tu panel o superposición con TTS activado lee los mensajes que recibe, según sus filtros y ajustes TTS. Empieza por la guía breve de configuración; esta página cubre las opciones de voz y los ajustes avanzados. Compara proveedores, escucha muestras y consulta los ajustes.

Inicio rápido: Usa dock.html?session=YOUR_SESSION&speech=en-US. Utiliza la voz del sistema de forma predeterminada. Para un proveedor gratuito en OBS, añade también &ttsprovider=kokoro. Mantén esta página abierta y conectada; solo debe hablar una copia.

¿Dónde se utiliza TTS?

  • Social Stream Ninja: Lee en voz alta los mensajes del público en varias áreas
  • CAPTION.Ninja: Ofrece subtítulos, transcripción y traducción con TTS
  • Ambos servicios ofrecen opciones TTS prémium y gratuitas
La voz del sistema no es lo mismo que todas las opciones TTS gratuitas:
  • Las voces del sistema dependen del navegador y del sistema operativo. OBS puede no ofrecer voces utilizables, aunque funcionen en Chrome/Edge.
  • Que falte una voz no es lo mismo que la voz se reproduzca fuera de la captura de audio de OBS. El enrutamiento de audio no puede solucionar la falta de compatibilidad con voz.
  • Los proveedores gratuitos como Kokoro, Piper, Kitten y eSpeak generan audio en la página. No es necesario pagar para utilizar TTS en OBS.
  • Comprueba la disponibilidad de voces y luego la captura de audio.

Limitaciones del navegador:
  • No todos los navegadores admiten texto a voz por igual (algunas versiones de Firefox tienen voces limitadas)
  • Chrome ofrece opciones TTS de Google
  • Edge admite TTS de Microsoft y voces de paquetes de idioma de Windows
  • Safari requiere interacción del usuario para iniciar el audio
  • Comprueba voces disponibles de tu navegador

Métodos de captura de audio TTS de Windows para OBS

Audio de página: proveedores locales gratuitos y en la nube

Los proveedores locales de SSN basados en navegador y sus proveedores de audio en la nube reproducen el audio generado mediante la página:

  • Solo activa «Controlar audio mediante OBS» en la fuente de navegador
  • No se necesitan cables de audio virtuales
  • Funciona con la aplicación SSN y fuentes de navegador de OBS

Métodos de captura de la voz del sistema

Importante: Primero confirma que la voz del sistema genere audio. El navegador integrado de OBS puede no ofrecer una voz del sistema utilizable. Si no genera voz, cambiar el enrutamiento de audio no ayudará. Elige otro proveedor o genera voz en un navegador compatible y captura su audio.

Para la voz del sistema en particular:

  • No supongas que OBS ofrece las mismas voces que Chrome o Edge
  • Compatibilidad limitada entre navegadores (Firefox puede carecer de algunas voces TTS)
  • Chrome ofrece opciones de Google; Edge tiene opciones de Microsoft
  • Si la voz se reproduce fuera de la fuente de navegador de la escena, captura esa salida por separado

Descargas de herramientas de enrutamiento: VB-Audio Virtual Cable | Voicemeeter | Audio Router (antiguo)

Prueba primero a capturar el navegador que habla mediante audio de aplicación o de escritorio de OBS, donde se admita. Los métodos de cable virtual siguientes son alternativas opcionales; no añaden compatibilidad de voz a OBS.

Método 1: ruta de audio predeterminada con un cable virtual

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Método 2: enrutamiento por aplicación en Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Método 3: enrutamiento por aplicación en Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Método 4: software Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Método 5: Voicemeeter (avanzado)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Prueba tu configuración

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Alternativas: Utiliza un proveedor integrado gratuito como Kokoro, Piper, Kitten o eSpeak, un proveedor en la nube o un servidor TTS propio.

Instalar paquetes de idioma adicionales

Windows 11

  1. Ve a Inicio > Configuración > Hora e idioma > Voz
  2. En Administrar voces, haz clic en Añadir voces
  3. Selecciona los idiomas deseados y haz clic en Añade
  4. Reinicia los navegadores para actualizar las voces disponibles

Windows 10

Sigue las instrucciones de la guía oficial de Microsoft para instalar paquetes de idioma.

Consejo: Algunas voces de terceros pueden no aparecer en los navegadores por problemas de compatibilidad. Firefox suele mostrar más voces del sistema que los navegadores basados en Chromium.

Parámetros de URL para configurar TTS

Parámetros básicos

Parámetro Descripción Ejemplo
&speech Activar TTS con código de idioma &speech=en-US
&pitch Tono de voz (0,1 a 2,0) &pitch=1.2
&volume Nivel de volumen (0,0 a 1,0) &volume=0.8
&rate Velocidad de lectura (0,1 a 10,0) &rate=1.5
&voice Coincidencia parcial del nombre de voz &voice=google
&ttsprovider Seleccionar proveedor: kokoro, piper, kitten, espeak, openai, customtts, localtts, elevenlabs, google, speechify, gemini &ttsprovider=customtts

Parámetros avanzados

Parámetro Descripción
&simpletts No decir «dice» ni «alguien dice»
&simpletts2 No leer los nombres de chat
&ttscommand Activar comando TTS personalizado (predeterminado: !say)
&readevents Incluir eventos de la transmisión en TTS
&skipmessages=3 Leer solo uno de cada 3 mensajes

Configuración del proveedor TTS

Kokoro TTS (gratis, integrado)

  • Activar con ?ttsprovider=kokoro
  • Se ejecuta en el navegador mediante WebGPU/WASM; no necesita servidor
  • Funciona directamente con la fuente de navegador de OBS
  • Selección de voz: &voicekokoro=af_bella
  • Control de velocidad: &kokorospeed=1.2
  • Elige una voz para el idioma: &voicekokoro=ef_dora para español o &voicekokoro=pf_dora para portugués de Brasil. Cambiar &speech= por sí solo no cambia la voz seleccionada. Los ID de voces en inglés existentes siguen funcionando.

Piper TTS (gratis, integrado)

  • Activar con ?ttsprovider=piper
  • TTS neuronal rápido y adecuado para CPU que se ejecuta en el navegador
  • Selección de voz: &pipervoice=en_US-hfc_female-medium
  • Voces en portugués: &pipervoice=pt_BR-faber-medium o &pipervoice=pt_BR-edresson-low
  • Voces en español: &pipervoice=es_ES-davefx-medium o &pipervoice=es_MX-ald-medium
  • Control de velocidad: &piperspeed=1.0

Kitten TTS (gratis, integrado)

  • Activar con ?ttsprovider=kitten
  • TTS ligero basado en ONNX que se ejecuta en el navegador
  • Selección de voz: &kittenvoice=expr-voice-4-f

eSpeak-NG (gratis, integrado)

  • Activar con ?ttsprovider=espeak
  • TTS clásico de código abierto, funciona en cualquier equipo
  • Selección de voz: &espeakvoice=en
  • Ejemplo en portugués: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Ejemplo en español: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Control de velocidad: &espeakspeed=175

Ejemplos de TTS en portugués y español

  • Portugués, mejor calidad local gratuita probada en SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Portugués, alternativa más rápida probada en SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Español, mejor calidad local gratuita probada en SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Español, alternativa más rápida probada en SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Para voces en la nube, utiliza una voz/idioma de un proveedor compatible con el idioma de destino, como Google Cloud, ElevenLabs, Speechify, Gemini o un servidor local compatible con OpenAI.

TTS de OpenAI / servidor local

  • Activar con ?ttsprovider=openai
  • Usa ?ttsprovider=customtts o ?ttsprovider=localtts para un endpoint de servidor propio
  • Utiliza la API de OpenAI de forma predeterminada o cualquier servidor local compatible
  • Endpoint personalizado: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Importante: localhost y 127.0.0.1 significan la misma computadora que reproduce la página TTS. Si OBS está en una computadora distinta del servidor TTS, utiliza la IP de la red local del servidor.
  • No se necesita clave de API para servidores locales
  • Si el servidor local tiene problemas de CORS o de red local en Chrome/OBS, ejecuta npm run local-tts-bridge en la computadora con OBS y dirige SSN a http://127.0.0.1:8124/v1/audio/speech
  • SSN envía { model, input, voice, response_format, speed } y admite audio binario, URL de audio en JSON y audio en base64 en JSON
  • La reproducción de endpoints personalizados/locales actualmente almacena el audio antes de reproducirlo; SSN todavía no reproduce progresivamente fragmentos de audio en streaming
  • Voz: &voiceopenai=af_bella, velocidad: &openaispeed=1.0. Utiliza un nombre de voz que admita tu servidor; las voces de Kokoro son como af_bella, mientras que las voces de openedai-speech o del estilo de OpenAI pueden ser nova o echo.
  • Consulta: Guía de TTS local con IA para configurar un servidor propio

Google Cloud TTS

  • Activar con ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Voces de calidad profesional
  • Selección de voz: &voicegoogle=en-GB-Standard-A
  • Idioma: &googlelang=en-US

Gemini TTS

  • Activar con ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Modelo: &geminimodel=gemini-2.5-flash-preview-tts
  • Voz: &voicegemini=Kore, idioma: &geminilang=th-TH
  • Instrucciones de estilo: &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • Activar con ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • ID de voz: &voice11=YOUR_VOICE_ID
  • Modelo: &elevenlabsmodel=eleven_multilingual_v2
  • Se pueden ajustar los parámetros de estabilidad, similitud y estilo

Fish Audio TTS

Elige Fish Audio e introduce tu clave de API, con un ID de voz opcional. El modelo predeterminado es s2.1-pro-free. Configuración, opciones de modelos y limitaciones de acceso del navegador.

Speechify TTS

  • Activar con ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Voz: &voicespeechify=henry
  • Modelo: &speechifymodel=simba-3.0 (predeterminado), o &speechifymodel=simba-3.2 para inglés.
  • Velocidad de lectura: &speechifyspeed=1.2 (intervalo de 0,5 a 3,0; lo normal es 1,0).
  • Guía de configuración, voces, velocidad y volumen de Speechify

Solución de problemas

Problemas habituales

  • No se reproduce audio: Comprueba que TTS esté activado, que la página que produce la voz esté abierta y que la fuente de navegador no esté silenciada. En un navegador normal, haz clic una vez en la página.
  • No aparecen voces: Reinicia el navegador después de instalar paquetes de idioma
  • OBS no captura: Si no hay voz, comprueba primero la disponibilidad de voces/proveedores. Si hay voz, comprueba Controlar audio vía OBS (Control audio via OBS), el silencio del mezclador y las pistas de salida, o captura el navegador externo que esté hablando
  • El endpoint local funciona en la prueba de la aplicación, pero no en OBS: OBS es un navegador independiente. Comprueba el endpoint desde la computadora con OBS, especialmente si utilizas 127.0.0.1.
  • Solo se lee la primera letra o las primeras palabras: elimina ttsquick de la URL de OBS si está presente.
  • Problemas en Safari: Safari tiene compatibilidad limitada con TTS automático
  • El servicio prémium no funciona: Comprueba la clave de API y que el proveedor esté especificado correctamente

Buenas prácticas

  • Utiliza un proveedor que genere audio de página para simplificar la configuración de OBS; hay proveedores locales gratuitos
  • Prueba la configuración con frases sencillas antes de transmitir en vivo
  • Considera los riesgos del contenido generado por usuarios al usar TTS
  • Ten un interruptor para desactivar TTS rápidamente si es necesario
