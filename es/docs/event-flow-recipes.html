Para qué sirve Event Flow

Ejecutar un flujo personalizado desde una tecla de Stream Deck o una llamada de API HTTP/WebSocket/P2P.

Event Flow es el editor de automatización avanzado. Úsalo cuando no basten los interruptores del menú: filtra el chat, activa medios, reenvía mensajes, llama a webhooks o controla OBS.

Antes de cualquier receta

  1. Usa una plataforma de prueba y una sesión de Social Stream.
  2. Abre el Dock y confirma que llegue el chat.
  3. Abrir actions.html?session=YOUR_SESSION si la receta reproduce audio, medios o controla OBS.
  4. Prueba con un mensaje ficticio o un disparador seguro antes de transmitir.
  5. Exporta un flujo que funcione antes de hacer una edición importante.

Soluciones habituales

  • No ocurre nada: confirma primero que el evento de origen llegue al Dock.
  • El audio o los medios no se reproducen: mantén actions.html abierto con la misma sesión y luego comprueba la guía de alojamiento multimedia de Event Flow.
  • Falla la acción de OBS: comprueba OBS WebSocket v5, el puerto 4455, la contraseña y los permisos.
  • El flujo se activa demasiado: añade un filtro más estricto de plataforma, evento, palabra clave o usuario.
