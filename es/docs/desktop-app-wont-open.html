Windows y macOS a veces piden confirmación adicional antes de ejecutar una aplicación descargada fuera de sus tiendas. Es especialmente habitual con una versión nueva, una aplicación poco descargada o una versión privada/personalizada.

Nunca ignores un aviso de seguridad salvo que estés de acuerdo con hacerlo y entiendas por completo lo que estás permitiendo. Continúa solo si descargaste la aplicación de la página oficial de versiones de Social Stream Ninja o recibiste una versión personalizada de alguien de confianza. Si tienes dudas, detente e informa del aviso.

Si el aviso dice que la aplicación contiene malware, dañará tu computadora o identifica una amenaza concreta, no la permitas. Guarda una captura y consulta la sección de solución de problemas a continuación.

Windows: «Windows protegió su PC»

Mensaje de ejemplo Microsoft Defender SmartScreen impidió el inicio de una aplicación desconocida.

Este aviso normalmente significa que Windows todavía no tiene suficiente información de reputación sobre esa descarga exacta. No es lo mismo que una detección de malware.

  1. Confirma que el archivo proceda de la página oficial de versiones.
  2. En la ventana azul del aviso, selecciona Más información.
  3. Comprueba que el nombre de la aplicación sea Social Stream Ninja o empiece por socialstreamninja.
  4. Si entiendes el aviso y estás de acuerdo con continuar, selecciona Ejecutar de todas formas. Si no, cierra el aviso y utiliza una de las alternativas siguientes.

Las versiones de Windows están autofirmadas y se envían a VirusTotal como comprobación adicional de seguridad y reputación. Un certificado autofirmado no se trata igual que uno emitido por una autoridad comercial de confianza para Windows, por lo que Windows puede mostrar Editor desconocido o volver a cuestionar un archivo recién publicado.

Conoce cómo funciona la reputación de Microsoft SmartScreen.

Windows: Defender bloqueó o eliminó el archivo

Mensajes posibles Amenaza encontrada, Aplicación potencialmente no deseada encontrada, Esta aplicación se ha bloqueado o Amenaza en cuarentena
  1. Abrir Seguridad de Windows desde el menú Inicio.
  2. Selecciona Protección contra virus y amenazas, luego Historial de protección.
  3. Abre la entrada que menciona el instalador de Social Stream Ninja o la aplicación portátil.
  4. Lee el nombre de la detección y la ruta del archivo afectado.
  5. Si se trata únicamente de un aviso de reputación o de aplicación potencialmente no deseada, el archivo procede de la página oficial de versiones y entiendes y aceptas plenamente la decisión, selecciona Acciones > Permitir en el dispositivo. Es posible que necesites volver a descargar el archivo.
Detente si Windows identifica una amenaza de malware concreta. No elijas Permitir hasta confirmar el origen de la descarga y compartir el nombre de la detección o una captura con soporte.

instrucciones de Microsoft sobre el historial de protección

Windows: Control inteligente de aplicaciones bloqueó la aplicación

Control inteligente de aplicaciones es distinto del aviso normal de SmartScreen. Windows no proporciona una excepción para una sola aplicación mediante Ejecutar de todas formas para ella.

  • En una computadora del trabajo o de la escuela, pide al administrador que apruebe la aplicación.
  • En una computadora personal, utiliza la extensión del navegador o aplicación web Lite si no quieres cambiar un ajuste de seguridad que afecta a todo el dispositivo.
  • Control inteligente de aplicaciones se puede administrar en Seguridad de Windows > Control de aplicaciones y navegador, pero cambiarlo afecta a la protección de todas las aplicaciones. Revisa la explicación de Microsoft antes de decidir.

macOS: aviso de desarrollador o notarización

Mensajes posibles Apple no puede comprobar si la aplicación contiene software malicioso, o no se puede verificar al desarrollador

Las versiones oficiales de macOS están concebidas para estar firmadas y notarizadas. Una versión privada o personalizada de terceros podría no estar notarizada, y una aplicación recién descargada puede seguir necesitando aprobación al abrirla por primera vez.

  1. Confirma que la aplicación proceda de la página oficial de versiones o de alguien cuya versión personalizada sea de confianza.
  2. Intenta abrir la aplicación una vez y luego cierra el aviso.
  3. Abre: Menú Apple > Ajustes del Sistema > Privacidad y seguridad.
  4. Desplázate a la sección Seguridad y busca el mensaje sobre la aplicación bloqueada.
  5. Si entiendes el aviso y estás de acuerdo con continuar, selecciona Abrir igualmente, autentícate si se te solicita y luego selecciona Abrir.

Esto crea una excepción para esa aplicación. No requiere desactivar Gatekeeper para todas las aplicaciones.

guía de Apple para abrir aplicaciones descargadas de forma segura

macOS: «La aplicación está dañada» o «Dañará tu computadora»

No utilices un comando de Terminal para eliminar la información de cuarentena de la aplicación. Estos mensajes pueden indicar una descarga incompleta o modificada, una firma no válida o un problema de seguridad detectado por macOS.

  1. Mueve esa copia a la Papelera.
  2. Descarga de nuevo la versión actual de macOS desde la página oficial de versiones.
  3. Abre la nueva copia sin modificar el paquete de la aplicación.
  4. Si el mensaje vuelve a aparecer, toma una captura con el texto completo y la versión de macOS, y contacta con soporte.

Si Abrir igualmente no aparece, intenta abrir la aplicación una vez más y vuelve a comprobar Privacidad y seguridad. En un Mac administrado, este ajuste puede estar controlado por el administrador.

Linux: AppImage no se inicia

AppImage puede necesitar permiso para ejecutarse:

  1. Haz clic derecho en AppImage y abre Propiedades (Properties).
  2. En Permisos, activa Permitir ejecutar el archivo como un programa. El texto varía según el entorno de escritorio.
  3. Vuelve a abrir AppImage.

También puedes conceder permiso desde una terminal:

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

Si el error menciona chrome-sandbox, aislamiento SUID, AppArmor o espacios de nombres sin privilegios, sigue la guía de aislamiento de AppImage.

Alternativas más seguras que ignorar un aviso

No necesitas ignorar un aviso del sistema operativo para utilizar Social Stream Ninja.

  • Informa del aviso: envía una captura y los detalles que se indican a continuación para que se pueda investigar.
  • Prueba una versión oficial anterior: si una versión nueva es la única que se bloquea o falla, vuelve a la página oficial de versiones y utiliza la versión anterior más reciente que te funcionó. Exporta primero tus ajustes cuando sea posible.
  • Utiliza la extensión de Chrome: instala la versión de Chrome Web Store en vez de la aplicación de escritorio.
  • Utiliza la aplicación web: abre Social Stream Ninja Lite cuando sus funciones más limitadas sean suficientes.
Las versiones anteriores no contienen las correcciones más recientes. Descárgalas solo de la página oficial de versiones y vuelve a una versión actual una vez que se entienda el problema.

Si todavía no se abre

Envía estos detalles a soporte:

  • Una captura de pantalla del aviso completo.
  • Tu sistema operativo y su versión.
  • El nombre exacto del archivo que descargaste.
  • Si se trata del instalador, la aplicación portátil, AppImage, la versión oficial de macOS o una versión personalizada.
  • Si esa misma copia se abrió correctamente antes.
  • En Windows, el nombre de la detección del Historial de protección, si aparece.
