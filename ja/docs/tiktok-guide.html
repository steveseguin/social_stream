TikTokガイド

Social Stream NinjaでTikTokを接続し、適切なモードを選び、返信を送り、必要に応じてTikFinityを代替手段として使う方法を説明します。

概要

ここから開始

TikTokは頻繁に動作を変更し、アカウントによって見える内容も異なるため、安定性を保つのが特に難しいプラットフォームです。

まずおすすめの設定：
  • 最初の設定： TikTok WS + Auto.
  • 返信する必要がある場合は、次へ切り替えてください： 標準（Standard）.
  • Standardが不安定な場合は、次を試してください： ローカル署名（Local Signer）.
  • TikTokでチャットの取りこぼしが続く場合は、次を使ってください： TikFinity OBS Dock 経由： その他のチャットサイト（Other chat sites）.
重要： TikTokの問題は必ずしもSSNが原因ではありません。メッセージの欠落、認証失敗、動作制限は、TikTok自体、アカウントの状態、地域固有の制限によって起こることがあります。
モード

どのTikTokオプションを使うべき？

選択肢 適した用途 返信
TikTok WS + Auto 多くのユーザーに適した標準の選択肢です。まずWebSocketを使い、必要に応じてPollingへ切り替えます。 不要
標準（Standard） SSNから返信し、アプリ内でTikTokのライブページを使用したい場合に適しています。 はい
TikTok WS + Local Signer Standardが不安定でも返信を使いたい場合の代替手段です。 はい
ポーリング（Polling） 互換モードです。遅めですが、WebSocket方式が動かない場合に役立ちます。 不要
Euler Proxy / Euler Signing 独自のAPIキーやカスタム構成を持つユーザー向けの高度な署名オプションです。 通常は不可
TikFinity OBS Dock TikTokのネイティブ接続モードで取りこぼしが多い場合や接続できない場合の、読み取り専用の代替手段です。 不要
手順1

SSNでTikTokに接続する

  1. 単体アプリを開きます。
  2. クリックするボタン： TikTok 。左サイドバーにあります。
  3. TikTokユーザー名、ライブURL、または求められた値を入力します。
  4. 使用したいTikTokモードまたはプリセットを選びます。
  5. クリックする項目： ソースを有効化（Activate source）.
手順2

返信が必要な場合

  1. 使う項目： 標準（Standard） モードを最初に試してください。
  2. クリックする項目： ログイン （必要な場合）。
  3. 開く項目： 取得ページを表示（Show capture page）.
  4. メッセージを送信したいTikTokアカウントにログインしていることを確認してください。
手順3

Standardが不安定な場合

  1. 試す項目： ローカル署名（Local Signer）.
  2. 署名用ウィンドウを開いたままにしてください。
  3. WebSocketが引き続き失敗する場合は、次を試してください： ポーリング（Polling）.
  4. それでもチャットの取りこぼしが多い場合は、下のTikFinityによる代替接続へ切り替えてください。
返信

TikTokチャットに返信する方法

返信には、有効なログイン済みTikTokセッションが必要です。

  • 返信に最適なモード： 標準（Standard）
  • 返信用の代替モード： ローカル署名（Local Signer）
  • 返信には使用しないもの： Auto、Polling、TikFinityによる代替
実用上の目安： 読み取りの安定性を重視するならAutoかPollingから始めます。返信を重視するならStandardかLocal Signerを使ってください。
代替手段

TikFinity OBS Dockの使い方

TikTok自体が多くのチャットを落としたり隠したりしている場合、TikFinityを予備ソースとして利用できます。

  1. TikFinityを開きます。
  2. 移動先： Overlay -> OBS Docks.
  3. ドック枠を1つ選び、チャット用に設定します。
  4. ドックURLをコピーします。
  5. SSNで次をクリックします： その他のチャットサイト（Other chat sites）.
  6. TikFinityのドックURLを貼り付けます。
  7. 新しいソースを有効にし、配信中はTikFinityを開いたままにします。
  • これは予備の読み取り手段で、返信用ツールではありません。
  • すでにTikFinityのアクティビティフィードウィジェットを使用している場合、対応するTikFinityウィジェットページをブラウザ版のSSN構成でも利用できます。

この代替手段とDiscord StreamKitの詳しい手順は、次をご覧ください： Discord StreamKitとTikFinityのソース。イベントペイロードの詳細は、次をご覧ください： イベントリファレンス.

トラブル対処

TikTokでよくある問題

「オフラインと表示される」

  • TikTokチャットは、そのアカウントが実際にライブ配信中の場合にのみ動作します。
  • 先にライブ配信を開始し、その後、次を試してください： 再読み込み（Reload）.
  • 配信終了後のテストは、多くの場合失敗します。

「認証ウィンドウが閉じる」

  • 使う項目： 取得ページを表示（Show capture page） で、ログインやCAPTCHAを確認できます。
  • 試す項目： 再読み込み（Reload） を、ログイン後に試してください。
  • 可能なら、同じ端末で開いている余分なTikTokタブやアプリを閉じてください。

「メッセージが欠ける」

  • これはTikTok側の制限である可能性があり、必ずしもSSNの不具合ではありません。
  • 1つの方式が常に最適だと決める前に、他のモードも試してください。
  • 自分のアカウントでTikFinityの方が安定している場合は、代替手段として使用してください。

「再接続後にメッセージが重複する」

  • まずアプリを最新ビルドに更新してください。
  • ソースを完全に停止し、改めて接続し直してください。
  • それでも重複する場合は、モードを切り替えるか、一時的にTikFinityを使ってください。

「何度もレート制限にかかる」

  • 同じ端末で開いている他のTikTokタブ、アプリ、重複した視聴画面を閉じてください。
  • 再試行する前に数分待ってください。
  • 別のモードまたは署名方式を試してください。

「まず何を試せばよい？」

  • 読み取りにはAuto
  • 返信にはStandard
  • Standardが不安定ならLocal Signer
  • TikTok自体に問題があるならTikFinity
拡張機能

ブラウザ拡張機能を使う場合

  • ブラウザで配信者のTikTokライブページを開き、拡張機能を有効にしておきます。
  • 自分のライブで、認証済みユーザー限定または配信者限定のページイベントが必要な場合はログインしてください。
  • TikFinityのアクティビティフィードページは、ブラウザを使ったSSN構成でも動作します。
  • 単体アプリでは引き続き、最も多くのTikTokモードと分かりやすい代替接続を利用できます。
