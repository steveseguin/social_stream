Event Flowレシピ

プレゼント企画、有料チケット、ゲーム景品、復旧ガイド

小さなレシピを1つずつ作り、便利な自動化を組み立てましょう。

Event Flowの用途

Stream DeckキーやHTTP・WebSocket・P2P API呼び出しから、独自のワークフローを実行.

Event Flowは高度な自動化エディターです。ポップアップのスイッチだけでは足りない場合に、チャットのフィルタリング、メディアの再生、メッセージ転送、Webhook呼び出し、OBS操作を行えます。

レシピを始める前に

  1. テスト用プラットフォーム1つとSocial Streamセッション1つを使います。
  2. ドックを開き、チャットが届くことを確認します。
  3. 開く項目： actions.html?session=YOUR_SESSION を、音声・メディア再生やOBS操作をするレシピで使います。
  4. 配信前に、疑似メッセージや安全なトリガーでテストしてください。
  5. 大きく編集する前に、動作するフローをエクスポートしてください。

レシピのアイデア

レシピトリガー操作
キーワードでサウンド再生メッセージに含む文字（Message contains） !hype音声クリップの再生先： actions.html.
Kick報酬のメディア報酬・チャンネルポイントイベント画像・動画を表示するか、音を再生します。
初めてのチャット参加者初回チャットのフラグまたはフィルターメッセージを注目表示するか、歓迎オーバーレイを表示します。
寄付アラートhasDonation または寄付イベントアラートオーバーレイ、Webhook、OBSシーン操作へ送ります。

ランダムなサウンド選択キーワード + RANDOMゲート2つのクリップからランダムに1つ再生します。参照先： エディターガイドのmicro-flow D.

よくある問題の対処

  • 何も起こらない場合： まずソースイベントがドックへ届くことを確認してください。
  • 音声やメディアが再生されない場合： 次を開いたままにします： actions.html を同じセッションで開き、次を確認します： Event Flowのメディアホスティングガイド.
  • OBS操作が失敗する場合： OBS WebSocket v5とポートを確認します： 4455、パスワード、権限を確認してください。
  • フローが頻繁に実行されすぎる場合： プラットフォーム、イベント、キーワード、ユーザーのフィルターをさらに絞ってください。
