YouTubeプロジェクトの設定

キーの安全性を損なわずに、SSN単体デスクトップアプリ用のGoogle Cloudプロジェクトを作成する方法を説明します。

概要

この設定の用途

デスクトップアプリに次を使用させたい場合にのみ設定してください： 自分のYouTube API割り当て 。Social Stream Ninjaの標準の共有プロジェクトの代わりに使います。

重要： 以下の3つの値はすべて、次から取得する必要があります： 同じGoogle Cloudプロジェクト:
  • OAuthクライアントID
  • OAuthクライアントシークレット
  • APIキー
Google Cloudの次の2つの欄を混同しないでください：
  • 承認済みのJavaScript生成元 には、パスを含めずオリジンだけを指定します。
  • 承認済みのリダイレクトURI には、完全な次のパスを含める必要があります： /sources/websocket/youtube.html です。
手順1

プロジェクトを作成する

  1. Google Cloud Consoleを開きます。
  2. 新しいプロジェクトを作成するか、専用の既存プロジェクトを選びます。
  3. 有効化 YouTube Data API v3.
  4. OAuth同意画面の設定を開きます。
  5. アプリがテスト中の場合は、自分のGoogleアカウントをテストユーザーとして追加します。
手順2

OAuthクライアントを作成する

  1. 認証情報を作成します。
  2. 選ぶ項目： OAuthクライアントID.
  3. 種類を次にします： ウェブアプリケーション.
  4. 以下に示す正確なオリジンとリダイレクトURIを追加します。
フィールド 値
承認済みのJavaScript生成元 http://localhost:8181
http://localhost:8080
承認済みのリダイレクトURI http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
手順3

APIキーを安全に作成する

  1. 次を作成します： APIキー を同じプロジェクト内で作成します。
  2. そのキーの制限設定を開きます。
  3. 次のセクションで： APIの制限で、対象を次に制限します： YouTube Data API v3 のみです。
  4. デスクトップアプリにはHTTPリファラー制限を使用しないでください。

デスクトップアプリでのルール： HTTPリファラー制限はブラウザページ用で、このローカルデスクトップ認証フロー向けではありません。

手順4

値をデスクトップアプリに貼り付ける

  1. デスクトップアプリ内のYouTubeソースページを開きます。
  2. 次を貼り付けます： OAuthクライアントID, OAuthクライアントシークレット、および APIキー.
  3. クリックする項目： 保存（Save）.
  4. 必要に応じてログアウトします。
  5. クリックする項目： YouTubeでログイン（Sign in with YouTube）.
  6. 外部ブラウザウィンドウでGoogleログインを完了します。
期待する結果： すべて一致していればGoogleログインが成功し、デスクトップアプリは標準の共有プロジェクトの代わりに、保存したYouTubeプロジェクトを使用します。
セキュリティ

認証情報を安全に保つ

  • クライアントシークレットとAPIキーは機密情報として扱ってください。
  • スクリーンショット、チャットログ、不具合報告に貼り付けないでください。
  • 誤って公開した場合は、更新または削除してください。
  • 試している段階では、専用のテストプロジェクトを使ってください。
  • テストが終わったら、一時的なプロジェクトを削除してください。
トラブル対処

よくある問題

  • redirect_uri_mismatch: リダイレクトURIが完全に一致していません。
  • invalid_client: クライアントIDとクライアントシークレットが一致していません。
  • quotaExceeded: APIキーのプロジェクトで、YouTubeの割り当てを使い切っています。
  • アカウントの検証に失敗： 古いビルドでは、OAuthとAPIキーが別のプロジェクト由来の場合に起こることがありました。
