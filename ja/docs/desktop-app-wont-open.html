デスクトップアプリが開かない

画面に表示された正確なメッセージに沿って、Social Stream Ninjaを安全に起動してください。

まずはこちら

WindowsやmacOSは、アプリストア以外からダウンロードしたアプリの実行前に、追加確認を求めることがあります。新しいリリース、ダウンロード数の少ないアプリ、非公開・独自ビルドでは特によく見られます。

何を許可するのか十分に理解し、自分で問題ないと判断できる場合を除き、セキュリティ警告を回避しないでください。 公式のSocial Stream Ninjaリリースページからダウンロードしたか、信頼できる人から独自ビルドを受け取った場合だけ続行してください。不明な場合は中止し、警告を報告してください。

マルウェアが含まれる、コンピューターに損害を与える、特定の脅威名がある、といった警告の場合は許可しないでください。スクリーンショットを保存し、以下のトラブル対処を確認します。

1. 入手元を確認する公式リリースページを開く を確認し、不明な場合は新しくダウンロードしてください。
2. メッセージを確認する警告の文面により、以下のどの手順を使うかが決まります。
3. 警告を記録するサポートが必要になったときのため、閉じる前にスクリーンショットを撮ってください。

Windows：「WindowsによってPCが保護されました」

メッセージの例 Microsoft Defender SmartScreenが、認識されていないアプリの起動を防いだという警告です。

通常、この警告は、そのダウンロードに対する評価情報がWindowsにまだ十分ないことを示します。マルウェアの検出とは異なります。

  1. ファイルの入手元が次であることを確認します： 公式リリースページ.
  2. 青い警告ウィンドウで次を選択します： 詳細情報（More info）.
  3. アプリ名がSocial Stream Ninjaであるか、次で始まることを確認してください： socialstreamninja.
  4. 警告の意味を理解し、続行してよいと判断した場合に選ぶ項目： 実行（Run anyway）。それ以外の場合は警告を閉じ、以下の代替手段を使ってください。

Windows版は自己署名され、安全性と評価の追加確認としてVirusTotalに提出しています。自己署名証明書は、Windowsが信頼する商用認証局の証明書と同じには扱われないため、Windowsに次の表示が出る場合があります： 不明な発行元（Unknown publisher） または新しく公開されたファイルで再び確認される場合があります。

Microsoft SmartScreenの評価の仕組みを知る.

Windows：Defenderがファイルをブロック・削除した

表示される可能性のあるメッセージ 脅威が見つかりました、望ましくない可能性のあるアプリが見つかりました、このアプリはブロックされています、脅威を隔離しました
  1. 開く項目： Windowsセキュリティ をスタートメニューから開きます。
  2. 選択する項目： ウイルスと脅威の防止、次に 保護の履歴（Protection history）.
  3. Social Stream Ninjaのインストーラーまたはポータブルアプリに関する項目を開きます。
  4. 検出名と対象ファイルのパスを確認します。
  5. アプリの評判または望ましくない可能性のあるアプリに関する警告だけで、公式リリースページから入手しており、その選択を十分理解して問題ないと判断した場合は、次を選択します： 操作 > デバイスで許可（Actions > Allow on device）。ファイルをもう一度ダウンロードする必要がある場合があります。
Windowsが具体的なマルウェアの脅威名を示している場合は、中止してください。 入手元を確認し、検出名またはスクリーンショットをサポートに共有するまでは、許可を選ばないでください。

Microsoftの保護の履歴の手順

Windows：Smart App Controlがアプリをブロックした

Smart App Controlは通常のSmartScreen警告とは異なります。Windowsには、これに対するアプリ1つだけの 実行（Run anyway） 例外設定は用意されていません。

  • 職場や学校のコンピューターでは、管理者にアプリの承認を依頼してください。
  • 個人用のコンピューターでは、次を使ってください： ブラウザ拡張機能 または Liteウェブアプリ を、端末全体のセキュリティ設定を変えたくない場合に使ってください。
  • Smart App Controlを管理する場所： Windowsセキュリティ > アプリとブラウザーコントロールで管理できますが、変更するとすべてのアプリの保護に影響します。判断する前にMicrosoftの説明を確認してください。

その他のWindowsメッセージ

メッセージ対処方法
「セキュリティとパフォーマンスのため、このWindowsのモードではMicrosoftによって検証されたアプリのみを実行します」WindowsのSモードである可能性があります。このモードではMicrosoft Storeのアプリだけを実行できます。Sモードの解除は端末全体に適用され、元に戻せない選択なので、まずブラウザ版やLite版を検討してください。 MicrosoftのSモードガイドを読む.
「このアプリはシステム管理者によってブロックされています」職場、学校、家庭、またはセキュリティポリシーでコンピューターが管理されています。管理者によるアプリの承認が必要です。
「Windows Defenderファイアウォールがこのアプリの一部の機能をブロックしました」これはネットワークアクセスに関するもので、アプリの起動可否の問題ではありません。許可する場合は信頼できるプライベートネットワークだけにしてください。通常、パブリックネットワークへのアクセスは不要です。
「このアプリはお使いのPCでは実行できません」そのコピーを削除し、現在のWindows x64版をダウンロードし直してください。ダウンロードが完了していることと、macOSやLinuxのファイルを選んでいないことを確認します。

macOS：開発者・公証に関する警告

表示される可能性のあるメッセージ アプリに悪意のあるソフトウェアが含まれているかAppleで確認できない、または開発者を検証できない

公式macOSリリースは、署名と公証を行う方針です。非公開版や第三者の独自ビルドは公証されていない場合があり、新しくダウンロードしたアプリでは初回起動の承認が必要なこともあります。

  1. アプリの入手元が次であることを確認します： 公式リリースページ または、独自ビルドを信頼できる人から入手したことを確認してください。
  2. 一度アプリを開こうとしてから、警告を閉じます。
  3. 開く項目： Appleメニュー > システム設定 > プライバシーとセキュリティ.
  4. セキュリティのセクションまでスクロールし、ブロックされたアプリに関するメッセージを探します。
  5. 警告の意味を理解し、続行してよいと判断した場合に選ぶ項目： このまま開く（Open Anyway）を選び、求められたら認証し、次を選択します： 開く項目：.

そのアプリだけを例外として許可します。すべてのアプリに対してGatekeeperをオフにする必要はありません。

ダウンロードしたアプリを安全に開くためのAppleのガイド

macOS：「アプリが壊れている」または「コンピューターに損害を与える」

ターミナルコマンドでアプリの隔離情報を削除しないでください。これらのメッセージは、ダウンロードの不完全・改変、署名の無効、macOSが検出したセキュリティ問題を示す場合があります。

  1. そのコピーをゴミ箱に移動します。
  2. 公式リリースページから、現在のmacOS版をもう一度ダウンロードしてください。
  3. アプリのバンドルを変更せず、新しいコピーを開きます。
  4. 再びメッセージが出る場合は、文面全体とmacOSのバージョンがわかるスクリーンショットを撮り、サポートに連絡してください。

次の場合： このまま開く（Open Anyway） がない場合は、アプリをもう一度開こうとしてから「プライバシーとセキュリティ」を再確認します。管理対象のMacでは、管理者がこの設定を制御している場合があります。

Linux：AppImageが起動しない

AppImageに実行権限が必要な場合があります：

  1. AppImageを右クリックして次を開きます： プロパティ.
  2. アクセス権で次を有効にします： プログラムとして実行可能（Allow executing file as program）。デスクトップ環境によって表現が異なります。
  3. AppImageをもう一度開きます。

ターミナルから実行権限を付けることもできます：

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

エラーに次が含まれる場合： chrome-sandbox, SUIDサンドボックス、AppArmor、非特権の名前空間に関するエラーの場合は、次のガイドに従ってください： AppImageサンドボックスガイド.

警告を回避するより安全な代替手段

Social Stream Ninjaを使うために、OSの警告を無視する必要はありません。

  • 警告を報告する： 調査できるよう、スクリーンショットと以下の情報を送ってください。
  • 以前の公式リリースを試す： 新しいバージョンだけがブロックまたは失敗する場合は、公式リリースページで、以前に動いた最新の旧バージョンを使ってください。可能なら先に設定をエクスポートします。
  • Chrome拡張機能を使う： インストールするもの： Chrome Web Store版 をデスクトップアプリの代わりに使います。
  • ウェブアプリを使う： 開く項目： Social Stream Ninja Lite を、機能が少なくても十分な場合に使います。
古いリリースには最新の修正が含まれません。公式リリースページからのみ入手し、原因がわかったら現在のバージョンへ戻してください。

それでも開かない場合

次の情報をサポートに送ってください：

  • 警告全体が写ったスクリーンショット。
  • OSとそのバージョン。
  • ダウンロードした正確なファイル名。
  • インストーラー、ポータブルアプリ、AppImage、公式macOSリリース、独自ビルドのどれか。
  • 同じコピーを以前に正常に開けたかどうか。
  • Windowsの場合、保護の履歴に表示された検出名。
