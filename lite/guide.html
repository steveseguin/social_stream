Get chat into your overlay

Lite connects supported chat sources from your browser or OBS. With the regular overlay link, keep Lite running in a tab or OBS dock. The experimental standalone OBS mode captures and displays chat in one Browser Source.

Setup · OBS-only setups · Sources · Existing setups · Troubleshooting

1. Set up your overlay

  1. Open Lite. A session ID and overlay URL are generated automatically and remembered in this browser.
  2. Connect one of the sources below. Use its Options button for channel settings.
  3. Choose Copy link. In OBS, add a Browser source and paste the link into its URL field. You can also use Open dock overlay to check it in a browser.
  4. Choose Send test message in Lite. Confirm it appears in the open overlay. A message in Lite's Activity feed alone does not confirm that the overlay received it.

For a transparent overlay or different message order, open the options beside Chat Overlay Link. After changing these options, copy the updated URL into OBS.

2. Choose your sources

For an OBS-only setup, choose one of the two workflows below. You do not need a separate desktop browser tab if capture runs in OBS.

SourceWhat to do
YouTubeSign in with YouTube. Lite looks for your live broadcast. In Options, you can supply a Video ID or Live Chat ID for a specific broadcast. Polling is the default; the optional streaming API is marked beta. The broadcast must have an available live chat.
TwitchSign in with Twitch. Lite uses your own channel by default; set a different channel in Options. If your authorization expires, sign in again.
KickEnter the channel name in Options and connect. If automatic lookup fails, check the channel spelling, then use the manual chatroom settings if needed.
TikTokThe integration is currently hidden in the standard Lite panel. It requires a compatible TikTok Chat Reader proxy; a prefilled address does not guarantee service availability. Use the full app for the available TikTok capture options.

Disconnect stops that source. For YouTube and Twitch, it keeps your sign-in so you can use Connect again. Sign out removes the saved authorization in this browser.

3. Use your existing Social Stream setup

To feed an existing dock or overlay, open the session options in Lite and enter its session ID. Choose Save session ID or press Enter. Changing the ID switches where Lite sends messages; update any browser-source URLs that should follow it.

Use only one capture method per channel in the same session. Running Lite alongside extension or desktop capture of the same chat can produce duplicates. You can use Lite for one channel and the full app for other sources.

Lite's generated link uses the default session password. Password-protected or custom-server setups may need the full app's connection controls. Lite does not replace the full app's capture, automation, moderation, or overlay customization controls.

Activity's Donations only and Text-to-speech controls apply to the Lite activity view. Keep the main Lite page open when using its activity popout. Treat your overlay URL as private if you do not want others joining that session.

Run entirely inside OBS

Option A: Lite dock + regular overlay

  1. Open Run entirely inside OBS in Lite and copy the OBS custom dock URL (lite/index.html?view=dock).
  2. Add it under OBS's Custom Browser Docks. Sign in and configure sources in that dock. Source Options and session settings remain accessible there.
  3. Copy the dock's regular overlay URL into an OBS Browser Source. Keep the Lite dock loaded while capturing. The source only displays messages, so it does not need its own provider sign-in.

This is the simplest OBS-only workflow: capture lives in the dock and display lives in the Browser Source. Closing the dock stops its capture. A desktop browser is not required once setup is complete.

Option B: One capture-and-overlay Browser Source (experimental)

  1. Add the Standalone capture + overlay URL (lite/index.html?view=overlay) as an OBS Browser Source.
  2. Open Interact to configure sources. If already configured, press Escape in Interact to reopen setup. Sign-in pages and setup controls are visible in this source, so configure it off-air.
  3. Choose Show overlay. The page now displays its own incoming chat on a transparent background. It does not need another Lite tab, dock, or relay connection, and does not feed other session overlays.
  4. Leave Shutdown source when not visible and Refresh browser source when scene becomes active off to avoid interrupting capture when changing scenes. See OBS Browser Source properties.

Saved valid YouTube/Twitch credentials reconnect on startup. For Kick, opt into Reconnect this Kick channel automatically in OBS modes in its Options. Configure the channel first. TikTok remains hidden. Layout starts with all messages visible and speech off, independently of the normal activity view's saved preferences.

OBS docks, OBS Browser Sources, and desktop browsers may use different cookie/storage profiles. Do not assume that configuring a dock signs in an independent Browser Source. If sign-in cannot complete inside your OBS Browser Source, use Option A. Native OBS provider authentication still needs live validation; this mode is experimental.

Use one capture location per channel. Do not keep a dock capturing the same channel as a standalone capture-and-overlay source. Use OBS's existing-source option when reusing the same capture source across scenes.

Troubleshooting

My overlay is blank
Check that Lite is still open and the overlay uses the same session ID. Send a test message. If a test arrives but live chat does not, check the source's status and channel. If neither arrives, check the overlay URL and whether your network blocks the relay connection.
Copy link is blocked
Click the visible overlay URL, then copy the selected text with your keyboard or device's copy menu.
A source is idle or shows an error
Check its Options and error text. Reconnect after fixing the settings. YouTube and Twitch may require another sign-in if authorization has expired.
I see duplicate messages
Check for a second Lite tab, extension capture, or desktop capture of the same channel and session. Keep only the intended capture running.
Settings disappeared
Settings are stored in this browser's local storage. A different browser, private window, or cleared site data uses a different set of settings.
