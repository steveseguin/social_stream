ออกแบบโอเวอร์เลย์แชทของคุณเอง

ปรับแต่งการแชทแบบเลื่อน เอาต์พุต Dock และธีมการแชท ในขณะที่ยังคงแสดงข้อความและการเชื่อมต่ออยู่

คู่มือการออกแบบภาพซ้อนทับทั้งหมดเลือกไฟล์ดาวน์โหลดเซสชันและ OBSการออกแบบพรอมต์ AIทดสอบ

เลือกหน้าเริ่มต้นที่ถูกต้อง

เริ่มจาก sampleoverlay.html สำหรับรายการสนทนาของผู้ฟัง หรือคัดลอกธีมที่เลือกไว้ใน แกลเลอรีโอเวอร์เลย์ ใช้ dock.html เมื่อคุณต้องการคุณสมบัติการแสดงผลและการโต้ตอบของ Dock chat-overlay.html เปลี่ยนเส้นทางไปยังเอาต์พุตซ้อนทับ AI ที่บันทึกไว้ ไม่ใช่ตัวแสดงแชทตัวอย่างนี้

ดาวน์โหลดและเก็บโครงสร้างไฟล์ไว้

  1. ดาวน์โหลด ZIP ต้นทาง แล้วดึงออกมา คำแนะนำเหล่านี้ใช้แหล่งเบต้า เก็บไฟล์จากการดาวน์โหลดครั้งเดียวไว้ด้วยกัน
  2. คัดลอก sampleoverlay.html เป็น my-chat.html ข้างต้นฉบับ หากเลือกหน้าหรือธีมอื่น ให้เก็บสำเนาไว้ในโฟลเดอร์ต้นฉบับของไฟล์นั้น
  3. เปิด HTML ที่คัดลอกและ CSS/JS ที่อ้างอิงในตัวแก้ไขหรือเครื่องมือ AI ของคุณ เพิ่มอาร์ตเวิร์ก/แบบอักษรที่ให้มาในโปรเจ็กต์เดียวกัน และใช้พาธแบบสัมพันธ์ เริ่มต้นด้วยการแทนที่ CSS รวมตัวแสดงผลเมื่อเปลี่ยนมาร์กอัปที่สร้างขึ้น

ไฟล์ต่อไปนี้ช่วยคุณค้นหาการออกแบบและลักษณะการทำงาน นี่คือรายการที่จะอ่าน ไม่ใช่ชุดการพึ่งพาที่สมบูรณ์: เก็บโฟลเดอร์ที่แยกออกมาไว้ครบถ้วน รวมถึงรูปภาพ แบบอักษร สคริปต์ และไฟล์ข้อมูลใดๆ

themes/compact-clean.htmlตัวอย่างธีมแชทในโฟลเดอร์ย่อย เก็บสำเนาของคุณไว้ในธีม / .

เชื่อมต่อสำเนาของคุณและเปิดใน OBS

เริ่ม SSN และทำให้ URL โอเวอร์เลย์ที่สร้างขึ้นดั้งเดิมใช้งานได้ก่อน ที่ session= ค่าเชื่อมต่อกับเซสชัน SSN นั้น ไม่ใช่ชื่อช่องของคุณหรือชื่อไฟล์นี้ ให้ SSN คุณลักษณะที่เกี่ยวข้อง และแหล่งข้อมูลทำงานต่อไป

  1. ลากไฟล์ HTML ที่แก้ไขของคุณไปที่ Chrome หรือ Edge คัดลอกที่อยู่จากแถบที่อยู่ มันเริ่มต้นด้วย file:///.
  2. คัดลอกทุกอย่างจาก ? เป็นต้นไปในลิงก์โอเวอร์เลย์ SSN ที่ทำงานของคุณ และเพิ่มไปที่ส่วนท้ายของที่อยู่ไฟล์นั้น เก็บการตั้งค่าทั้งหมดไว้ รวมถึงเซสชัน รหัสผ่าน และอื่นๆ # สิ้นสุด
  3. เปิดผลลัพธ์ในเบราว์เซอร์ จากนั้นตั้งค่า OBS Browser Source's URL ไปยังที่อยู่เดียวกันกับ ไฟล์ในเครื่อง (Local file) ไม่ได้เลือก จับคู่มิติข้อมูลแหล่งที่มากับการออกแบบที่คุณต้องการ

สำหรับไฟล์เริ่มต้นด้านบน ที่อยู่ภายในเครื่องจะเป็นดังนี้ ลิงก์จริงของคุณอาจมีตัวเลือกที่จำเป็นเพิ่มเติม:

file:///C:/SSN/social_stream-beta/my-chat.html?session=YOUR_SESSION

ใช้ที่อยู่ไฟล์จริงบนคอมพิวเตอร์ของคุณ OBS จะบันทึกพร้อมกับแหล่งที่มา เก็บโฟลเดอร์ที่ดาวน์โหลดมาไว้ที่เดิม หลังจากบันทึกการเปลี่ยนแปลงการออกแบบแล้ว ให้รีเฟรชแหล่งที่มาของเบราว์เซอร์ ที่ คู่มือการตั้งค่าที่ใช้ร่วมกัน รวมตัวอย่าง Mac และตัวเรียกใช้งานเสริมสำหรับช่องทำเครื่องหมายไฟล์ในเครื่อง

จะเปลี่ยนการออกแบบได้ที่ไหน

เปลี่ยนพื้นหลังของการ์ด การพิมพ์ชื่อ ช่องว่างภายใน อวตาร ตราสัญลักษณ์ และการเคลื่อนไหวเข้า/ออก ในตัวอย่างให้ปฏิบัติตาม addMessageToOverlay เพื่อดูว่าแถวใดถูกสร้างขึ้น ในธีม ให้ตรวจสอบตัวเลือกของตัวเอง รักษาการลบ การเรียงลำดับ ขีดจำกัด และเวลา การแชทเป็นแถวที่แยกจากกัน ดังนั้นทดสอบการมาถึงอย่างรวดเร็วและการ์ดที่น่าสนใจเพียงใบเดียว

คงค่า chatmessage โหมด HTML แสดงอารมณ์ผ่านน้ำยาฆ่าเชื้อที่มีอยู่ ชื่อและป้ายกำกับปกติเป็นช่องธรรมดา textonly ใช้กับเนื้อหาข้อความเท่านั้น เรนเดอร์ contentimg แม้ว่าร่างกายจะว่างเปล่าก็ตาม หากจัดสไตล์ Dock แบบเต็ม ให้ใช้ตัวเลือกการแสดงผลเพื่อให้มุมมองผู้ชมที่เลือกไม่แสดงการควบคุมที่ไม่ต้องการ

ทดสอบประเภทการซ้อนทับนี้

ใช้การตั้งค่าตัวอย่างหรือทดสอบก่อน ที่ คำแนะนำข้อความทดสอบ อธิบายวิธีการส่งเพย์โหลดสมมติผ่าน SSN การทดสอบที่ส่งไปยังเซสชันการใช้งานจริงของคุณสามารถทริกเกอร์การทำงานอัตโนมัติที่มีอยู่ได้

  1. ส่งแถวทดสอบแชทหลายแถวพร้อมชื่อและแพลตฟอร์มที่แตกต่างกัน ตรวจสอบการซ้อน การห่อ และการถอดออกเมื่อถึงขีดจำกัด
  2. ส่งข้อความข้อความอย่างเดียวที่มี <b>วงเล็บตัวอักษร</b> จากนั้นจึงส่งข้อความแสดงอารมณ์ในโหมด HTML รายการแรกจะต้องแสดงมาร์กอัปตามตัวอักษร ส่วนที่สองควรเก็บอิโมติคอนที่ได้รับอนุญาตไว้
  3. ลองใช้ข้อความเฉพาะเนื้อหาเท่านั้น ชื่อยาว รูปประจำตัวที่หายไป ป้ายการบริจาค และการลบผ่าน Dock ตรวจสอบแหล่งที่มาทั้งแบบแคบและแบบเต็มความกว้าง

เรียกใช้ การตรวจสอบการเรนเดอร์อินพุต กับเส้นทางการเรนเดอร์ที่คุณเปลี่ยน หลังจากบันทึกการแก้ไข ให้รีเฟรช OBS Browser Source ระหว่างการซ้อม และทำซ้ำการโต้ตอบที่มองเห็นได้ การแสดงตัวอย่างเบราว์เซอร์ไม่ได้สร้างการจับภาพสดหรือพฤติกรรมของ OBS
