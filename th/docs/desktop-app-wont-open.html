เปิดแอปเดสก์ท็อปไม่ได้

ใช้ข้อความตรงตามที่เห็นบนหน้าจอเพื่อทำให้ Social Stream Ninja ทำงานอย่างปลอดภัย

เริ่มที่นี่

บางครั้ง Windows และ macOS ขอการยืนยันเพิ่มก่อนเรียกใช้แอปที่ดาวน์โหลดจากนอกร้านแอป พบบ่อยโดยเฉพาะกับรุ่นใหม่ แอปที่ดาวน์โหลดไม่บ่อย หรือรุ่นส่วนตัว/ปรับแต่ง

อย่าข้ามคำเตือนความปลอดภัย เว้นแต่คุณยอมรับและเข้าใจสิ่งที่อนุญาตอย่างเต็มที่ ดำเนินการต่อเฉพาะเมื่อดาวน์โหลดจากหน้าเผยแพร่ Social Stream Ninja อย่างเป็นทางการ หรือได้รับรุ่นปรับแต่งจากคนที่ไว้ใจ หากไม่แน่ใจ ให้หยุดและรายงานคำเตือนแทน

หากคำเตือนบอกว่าแอปมีมัลแวร์ จะทำให้คอมพิวเตอร์เสียหาย หรือระบุชื่อภัยคุกคามเฉพาะ อย่าอนุญาต เก็บภาพหน้าจอและดูส่วนแก้ปัญหาด้านล่าง

1. ยืนยันแหล่งที่มาเปิดหน้าเผยแพร่อย่างเป็นทางการ และดาวน์โหลดสำเนาใหม่หากไม่แน่ใจ
2. เทียบข้อความที่พบข้อความในคำเตือนเป็นตัวกำหนดว่าควรใช้ขั้นตอนใดด้านล่าง
3. เก็บคำเตือนไว้ถ่ายภาพหน้าจอก่อนปิด เผื่อต้องขอความช่วยเหลือ
WindowsSmartScreen, Defender หรือ Smart App Control macOSคำเตือน Gatekeeper ผู้พัฒนา หรือการรับรอง notarization Linuxข้อผิดพลาดสิทธิ์หรือแซนด์บ็อกซ์ AppImage

Windows: "Windows ป้องกันพีซีของคุณ"

ข้อความตัวอย่าง Microsoft Defender SmartScreen ป้องกันไม่ให้แอปที่ไม่รู้จักเริ่มทำงาน

ปกติคำเตือนนี้หมายถึง Windows ยังมีข้อมูลชื่อเสียงไม่พอสำหรับไฟล์ดาวน์โหลดนั้น ไม่เหมือนการตรวจพบมัลแวร์

  1. ยืนยันว่าไฟล์มาจาก หน้าเผยแพร่อย่างเป็นทางการ.
  2. ในหน้าต่างคำเตือนสีน้ำเงิน เลือก ข้อมูลเพิ่มเติม (More info).
  3. ตรวจว่าชื่อแอปคือ Social Stream Ninja หรือขึ้นต้นด้วย socialstreamninja.
  4. หากเข้าใจคำเตือนและยอมรับที่จะดำเนินการต่อ ให้เลือก เรียกใช้อยู่ดี (Run anyway) มิฉะนั้น ให้ปิดคำเตือนและใช้ทางเลือกด้านล่าง

รุ่น Windows ลงลายเซ็นด้วยตนเองและส่งให้ VirusTotal เพื่อตรวจความปลอดภัยและชื่อเสียงเพิ่มเติม ใบรับรองที่ลงลายเซ็นเองไม่ได้รับการปฏิบัติเหมือนใบรับรองจากผู้ออกเชิงพาณิชย์ที่ Windows เชื่อถือ Windows จึงอาจแสดง ผู้เผยแพร่ที่ไม่รู้จัก (Unknown publisher) หรือถามยืนยันไฟล์ที่เพิ่งเผยแพร่อีกครั้ง

เรียนรู้การทำงานของชื่อเสียง Microsoft SmartScreen.

Windows: Defender บล็อกหรือลบไฟล์

ข้อความที่อาจพบ พบภัยคุกคาม พบแอปที่อาจไม่พึงประสงค์ แอปนี้ถูกบล็อก หรือกักกันภัยคุกคามแล้ว
  1. เปิด ความปลอดภัยของ Windows (Windows Security) จากเมนู Start
  2. เลือก การป้องกันไวรัสและภัยคุกคาม (Virus & threat protection), จากนั้น ประวัติการป้องกัน (Protection history).
  3. เปิดรายการที่กล่าวถึงตัวติดตั้ง Social Stream Ninja หรือแอปพกพา
  4. อ่านชื่อการตรวจพบและเส้นทางไฟล์ที่ได้รับผล
  5. หากเป็นเพียงคำเตือนชื่อเสียงของแอปหรือแอปที่อาจไม่พึงประสงค์ ไฟล์มาจากหน้าเผยแพร่อย่างเป็นทางการ และคุณเข้าใจและยอมรับการตัดสินใจนี้อย่างเต็มที่ ให้เลือก การดำเนินการ (Actions) > อนุญาตบนอุปกรณ์ (Allow on device) คุณอาจต้องดาวน์โหลดไฟล์ใหม่
หยุดหาก Windows ระบุชื่อภัยคุกคามมัลแวร์เฉพาะ อย่าเลือก Allow จนกว่าจะยืนยันแหล่งดาวน์โหลดและส่งชื่อการตรวจพบหรือภาพหน้าจอให้ฝ่ายช่วยเหลือแล้ว

คำแนะนำ Protection History ของ Microsoft

Windows: Smart App Control บล็อกแอป

Smart App Control ต่างจากคำเตือน SmartScreen ปกติ Windows ไม่มีตัวเลือก เรียกใช้อยู่ดี (Run anyway) สำหรับยกเว้นเฉพาะแอปนี้

  • บนคอมพิวเตอร์ที่ทำงานหรือโรงเรียน ให้ขอผู้ดูแลระบบอนุมัติแอป
  • บนคอมพิวเตอร์ส่วนตัว ให้ใช้ ส่วนขยายเบราว์เซอร์ หรือ เว็บแอป Lite หากไม่ต้องการเปลี่ยนการตั้งค่าความปลอดภัยทั้งอุปกรณ์
  • จัดการ Smart App Control ได้ใน ความปลอดภัยของ Windows > การควบคุมแอปและเบราว์เซอร์ (App & browser control) แต่การเปลี่ยนค่านี้มีผลต่อการป้องกันทุกแอป อ่านคำอธิบายของ Microsoft ก่อนตัดสินใจ

คำถามที่พบบ่อย Smart App Control ของ Microsoft

ข้อความ Windows อื่น ๆ

ข้อความสิ่งที่ควรทำ
"เพื่อความปลอดภัยและประสิทธิภาพ Windows โหมดนี้ใช้ได้เฉพาะแอปที่ Microsoft ตรวจสอบแล้ว"คอมพิวเตอร์น่าจะอยู่ใน Windows S mode ซึ่งใช้ได้เฉพาะแอป Microsoft Store การออกจาก S mode มีผลทั้งอุปกรณ์และย้อนกลับไม่ได้ จึงควรพิจารณาเวอร์ชันเบราว์เซอร์หรือ Lite ก่อน อ่านคู่มือ S mode ของ Microsoft.
"ผู้ดูแลระบบของคุณบล็อกแอปนี้"คอมพิวเตอร์ถูกควบคุมด้วยนโยบายที่ทำงาน โรงเรียน ครอบครัว หรือความปลอดภัย ผู้ดูแลเครื่องต้องอนุมัติแอป
"Windows Defender Firewall บล็อกฟีเจอร์บางอย่างของแอปนี้"นี่เกี่ยวกับการเข้าถึงเครือข่าย ไม่ใช่ว่าแอปเริ่มทำงานได้หรือไม่ หากเลือกอนุญาต ให้ใช้เฉพาะเครือข่ายส่วนตัวที่ไว้ใจ ปกติไม่จำเป็นต้องอนุญาตเครือข่ายสาธารณะ
"แอปนี้ทำงานบนพีซีของคุณไม่ได้"ลบสำเนานั้นแล้วดาวน์โหลดรุ่น Windows x64 ปัจจุบันใหม่ ตรวจว่าดาวน์โหลดเสร็จและไม่ได้เลือกไฟล์ macOS หรือ Linux

macOS: คำเตือนผู้พัฒนาหรือการรับรอง notarization

ข้อความที่อาจพบ Apple ตรวจสอบซอฟต์แวร์อันตรายในแอปไม่ได้ หรือยืนยันผู้พัฒนาไม่ได้

รุ่น macOS อย่างเป็นทางการตั้งใจให้มีลายเซ็นและการรับรอง notarization ส่วนรุ่นส่วนตัวหรือรุ่นปรับแต่งจากบุคคลอื่นอาจไม่มีการรับรอง และแอปที่เพิ่งดาวน์โหลดอาจยังต้องอนุมัติเมื่อเปิดครั้งแรก

  1. ยืนยันว่าแอปมาจาก หน้าเผยแพร่อย่างเป็นทางการ หรือจากผู้สร้างรุ่นปรับแต่งที่คุณไว้ใจ
  2. ลองเปิดแอปหนึ่งครั้ง แล้วปิดคำเตือน
  3. เปิด เมนู Apple > การตั้งค่าระบบ (System Settings) > ความเป็นส่วนตัวและความปลอดภัย (Privacy & Security).
  4. เลื่อนลงไปส่วน Security และหาข้อความเกี่ยวกับแอปที่ถูกบล็อก
  5. หากเข้าใจคำเตือนและยอมรับที่จะดำเนินการต่อ ให้เลือก เปิดอยู่ดี (Open Anyway), ยืนยันตัวตนหากระบบถาม แล้วเลือก เปิด.

เป็นการยกเว้นให้แอปนั้น ไม่ต้องปิด Gatekeeper สำหรับทุกแอป

คู่มือ Apple สำหรับเปิดแอปที่ดาวน์โหลดอย่างปลอดภัย

macOS: "แอปเสียหาย" หรือ "จะทำให้คอมพิวเตอร์เสียหาย"

อย่าใช้คำสั่ง Terminal เพื่อลบข้อมูลกักกันของแอป ข้อความเหล่านี้อาจหมายถึงดาวน์โหลดไม่ครบหรือถูกแก้ไข ลายเซ็นไม่ถูกต้อง หรือ macOS ตรวจพบปัญหาความปลอดภัย

  1. ย้ายสำเนานั้นลงถังขยะ
  2. ดาวน์โหลดรุ่น macOS ปัจจุบันใหม่จากหน้าเผยแพร่อย่างเป็นทางการ
  3. เปิดสำเนาใหม่โดยไม่แก้ไขแพ็กเกจแอป
  4. หากข้อความกลับมา ให้ถ่ายภาพหน้าจอที่แสดงข้อความทั้งหมดและเวอร์ชัน macOS แล้วติดต่อฝ่ายช่วยเหลือ

หาก เปิดอยู่ดี (Open Anyway) ไม่ปรากฏ ให้ลองเปิดแอปอีกครั้งแล้วตรวจ Privacy & Security ใหม่ บน Mac ที่มีผู้ดูแลระบบ การตั้งค่านี้อาจถูกควบคุมโดยผู้ดูแล

Linux: AppImage เริ่มทำงานไม่ได้

AppImage อาจต้องได้รับสิทธิ์ให้ทำงาน:

  1. คลิกขวา AppImage แล้วเปิด คุณสมบัติ (Properties).
  2. ใน Permissions เปิด อนุญาตให้เรียกใช้ไฟล์เป็นโปรแกรม (Allow executing file as program) ข้อความแตกต่างกันตามระบบเดสก์ท็อป
  3. เปิด AppImage อีกครั้ง

คุณให้สิทธิ์จากเทอร์มินัลได้เช่นกัน:

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

หากข้อผิดพลาดกล่าวถึง chrome-sandbox, SUID sandbox, AppArmor หรือ unprivileged namespaces ให้ทำตาม คู่มือแซนด์บ็อกซ์ AppImage.

ทางเลือกที่ปลอดภัยกว่าการข้ามคำเตือน

คุณไม่จำเป็นต้องข้ามคำเตือนของระบบปฏิบัติการเพื่อใช้ Social Stream Ninja

  • รายงานคำเตือน: ส่งภาพหน้าจอและรายละเอียดที่ระบุด้านล่างเพื่อให้ตรวจสอบได้
  • ลองรุ่นเก่าอย่างเป็นทางการ: หากมีเพียงรุ่นใหม่ที่ถูกบล็อกหรือทำงานไม่ได้ ให้กลับไปหน้าเผยแพร่อย่างเป็นทางการและใช้รุ่นเก่าล่าสุดที่เคยใช้งานได้ ส่งออกการตั้งค่าก่อนหากทำได้
  • ใช้ส่วนขยาย Chrome: ติดตั้ง เวอร์ชัน Chrome Web Store แทนแอปเดสก์ท็อป
  • ใช้เว็บแอป: เปิด Social Stream Ninja Lite หากชุดฟีเจอร์ที่เล็กกว่านั้นเพียงพอ
รุ่นเก่าไม่มีการแก้ไขล่าสุด ดาวน์โหลดเฉพาะจากหน้าเผยแพร่อย่างเป็นทางการ และกลับมาใช้รุ่นปัจจุบันเมื่อเข้าใจปัญหาแล้ว

หากยังเปิดไม่ได้

ส่งรายละเอียดต่อไปนี้ให้ฝ่ายช่วยเหลือ:

  • ภาพหน้าจอที่แสดงคำเตือนครบถ้วน
  • ระบบปฏิบัติการและเวอร์ชันของคุณ
  • ชื่อไฟล์ที่ดาวน์โหลดอย่างถูกต้องครบถ้วน
  • เป็นตัวติดตั้ง แอปพกพา AppImage รุ่น macOS อย่างเป็นทางการ หรือรุ่นปรับแต่ง
  • สำเนาเดียวกันนี้เคยเปิดสำเร็จมาก่อนหรือไม่
  • บน Windows ให้ส่งชื่อการตรวจพบจาก Protection History หากมี
