TikTok เชื่อมต่อไม่ได้? ลอง TikFinity

ใช้ TikFinity Activity Feed เป็นแหล่งแชตสำรองใน Social Stream Ninja

ควรใช้เมื่อใด

หากโหมดเชื่อมต่อ TikTok โดยตรงของ SSN ล้มเหลวหรือพลาดข้อความบ่อย TikFinity เป็นอีกวิธีในการรับแชต LIVE ซึ่งอาจช่วยได้เมื่อ TikTok บล็อกหรือจำกัดการเชื่อมต่อจากเครือข่ายของคุณ ตราบใดที่ TikFinity ยังเชื่อมต่อกับสตรีมได้

การเชื่อมต่อนี้รับแชตและกิจกรรมที่รองรับ แต่ไม่ส่งข้อความตอบกลับ TikTok คุณไม่จำเป็นต้องใช้ OBS เพื่อใช้ TikFinity OBS Dock เป็นแหล่งข้อมูล SSN

  • บัญชี TikFinity: ลงชื่อเข้าใช้ TikFinity หรือสร้างบัญชีฟรีหากระบบร้องขอ เซสชันเบราว์เซอร์ที่มีอยู่อาจลงชื่อเข้าใช้ไว้แล้ว
  • บัญชี TikTok: การตั้งค่าแบบอ่านอย่างเดียวนี้ใช้ชื่อผู้ใช้ ไม่ต้องลงชื่อเข้าใช้บัญชี TikTok นั้น เราทดสอบกับบัญชี LIVE สาธารณะอื่นแล้ว บัญชีที่เลือกต้องกำลังไลฟ์และ TikFinity เข้าถึงได้
  • เปิด TikFinity ไว้: เปิดแท็บแดชบอร์ด TikFinity หลักหนึ่งแท็บไว้และให้เชื่อมต่อตลอดสตรีม

SSApp: direct TikFinity Desktop connection (beta)

Development builds after SSApp 0.4.32 also offer TikFinity Desktop (Local API, Beta) in the existing TikTok Connection dropdown. If that choice is missing, use the Activity Feed instructions below.

  1. เรียก TikFinity Desktop on the same computer as SSApp. Sign in to TikFinity and connect your LIVE stream there.
  2. Check TikFinity's Event API. SSApp connects to its local endpoint automatically; no API key or dock URL is needed.
  3. Stop your existing SSApp TikTok capture, choose TikFinity Desktop (Local API, Beta), and activate it.
  4. Wait for Receiving LIVE events from TikFinity Desktop and check a new message in the SSN dock. Hover over the connection status for recent activity information.

This captures the stream selected in TikFinity, regardless of the username entered in SSApp. It is read-only. Use only one capture source for that stream to avoid duplicates. The local API can provide likes and viewer counts as well as chat and gifts; SSN's existing event filters still apply.

Connected to TikFinity Desktop confirms the local connection only. If LIVE events stop, check TikFinity's dashboard and selected stream. SSApp reconnects when Desktop closes its local connection; it cannot repair TikFinity's upstream connection.

1. กรอกชื่อผู้ใช้ TikTok ใน TikFinity

  1. เปิด การตั้งค่า TikFinityหากเปิดแดชบอร์ด TikFinity อยู่แล้ว ให้ใช้เมนู การตั้งค่า แทนการเปิดแท็บใหม่ ลงชื่อเข้าใช้ TikFinity หากระบบร้องขอ
  2. ใน เชื่อมต่อบัญชี TikTok (Connect TikTok Account)กรอกชื่อผู้ใช้ TikTok ของ LIVE สาธารณะที่ต้องการเก็บข้อมูล ใช้ชื่อผู้ใช้บัญชี ไม่ใช่ชื่อที่แสดง
  3. การตั้งค่าชื่อผู้ใช้บันทึกอัตโนมัติ ไม่มีปุ่ม Save แยกให้กดในขั้นตอนนี้ รอให้ TikFinity เชื่อมต่อและตรวจสอบว่ามีกิจกรรมใหม่เข้ามา
ใช้แดชบอร์ดเพียงแท็บเดียว: สลับระหว่าง Setup และ OBS Docks ในแท็บ TikFinity เดียวกัน หากเปิดแดชบอร์ดใหม่แล้วขัดจังหวะแท็บแรก ให้เก็บแท็บล่าสุดที่เชื่อมต่ออยู่และปิดแท็บแดชบอร์ดส่วนเกิน เปิดแหล่งรับข้อมูล SSN แยกไว้ต่อไป

2. เลือกสิ่งที่ Activity Feed แสดง

  1. ในแท็บ TikFinity เดิม ไปที่ Overlays → OBS Docksหรือเปิด TikFinity OBS Docks.
  2. เลือก Dock 1 หรือ Dock 2เปิดปุ่มรูปเฟือง/การตั้งค่า
  3. ตรวจสอบ แสดงแชต (Show Chat) และทุกหมวดหมู่กิจกรรมที่ต้องการเห็น ได้แก่ การติดตาม การแชร์ ของขวัญ การสมัครสมาชิก หีบสมบัติ และการเข้าร่วม
  4. คลิก บันทึก ในการตั้งค่าแผงด็อก ปุ่ม Save นี้แยกจากการตั้งค่าชื่อผู้ใช้ที่บันทึกอัตโนมัติ
  5. คัดลอก URL ของแผงด็อกนั้น ใช้ URL จากหน้า TikFinity ของคุณเอง

In the new TikFinity dashboard, copy the Activity Feed's browser-source URL, which looks like https://widgets.tikfinity.com/YOUR_TOKEN. Keep this token private. Older URLs such as https://tikfinity.zerody.one/widget/activity-feed?cid=YOUR_ID&did=1 are also supported. Keep the complete copied URL. Do not paste the Setup or OBS Docks configuration page into SSN.

ช่องทำเครื่องหมายเหล่านี้ควบคุมสิ่งที่วิดเจ็ต TikFinity แสดง SSN มีตัวกรองเหตุการณ์ของตนเองด้วย การเปิดหมวดหมู่ที่นี่ไม่ได้ลบล้างตัวกรอง SSN

การตั้งค่าการแสดงแผงด็อกบันทึกแยกในแต่ละเบราว์เซอร์ หากหน้ารับข้อมูลใน SSApp แสดงหมวดหมู่ต่างจากตัวอย่างใน Chrome ให้เปิดปุ่มรูปเฟืองในหน้ารับข้อมูลนั้นแล้วเลือกหมวดหมู่ด้วย

3. เพิ่ม URL แผงด็อกใน Social Stream Ninja

  1. ใน SSApp ให้เปิด แหล่งข้อมูลและการตั้งค่า (Sources and Settings) แล้วเลือก เพิ่มแหล่งข้อมูลอื่น (Add other source) (เรียกว่า เว็บไซต์แชตอื่น ในเวอร์ชันเก่า)
  2. วาง URL ของ TikFinity Activity Feed ให้ครบ เพิ่มแหล่งข้อมูลแล้วเปิดใช้งาน SSApp จะตรวจพบ TikFinity โดยอัตโนมัติ
  3. หยุดแหล่ง TikTok โดยตรงที่เก็บ LIVE เดียวกัน เพื่อไม่ให้ข้อความเข้ามาซ้ำสองครั้ง
  4. เปิดทั้งแดชบอร์ด TikFinity และแหล่งรับข้อมูลใน SSApp ไว้

คุณสามารถกลับมาดูคู่มือนี้ได้ข้างตัวเลือก การเชื่อมต่อ TikTok ในการกำหนดค่าแหล่ง TikTok ของ SSApp

4. ตรวจสอบข้อความใหม่ใน SSN

  1. เปิดแผงด็อกแชต SSN แล้วรอข้อความ TikTok ใหม่ อย่าใช้ข้อความเก่าที่ยังเห็นใน TikFinity เพื่อทดสอบการเก็บข้อมูล
  2. ตรวจสอบว่าข้อความใหม่ปรากฏครั้งเดียวทั้งใน TikFinity และ SSN พร้อมชื่อและข้อความที่ถูกต้อง
  3. สังเกตการติดตาม การแชร์ หรือของขวัญเมื่อเกิดขึ้น ในการตั้งค่า SSN ให้เปิด จับอีเวนต์สตรีม "joined" หากต้องการการเข้าร่วม และตรวจสอบว่าตัวกรองการบริจาค/เหตุการณ์อนุญาตกิจกรรมที่ต้องการ
  4. ปล่อยให้ทำงานสักสองสามนาที แล้วตรวจสอบว่าข้อความภายหลังยังเข้ามาต่อเนื่อง
  5. ใช้ URL โอเวอร์เลย์ SSN ปกติของคุณใน OBS พร้อมเซสชัน SSN เดียวกัน ดู เริ่มใช้ OBS อย่างรวดเร็ว หากจำเป็น

SSN จัดข้อความเหล่านี้เป็น TikTok สำหรับตัวกรองแหล่งข้อมูลและโอเวอร์เลย์ที่มีอยู่ กิจกรรมที่รองรับได้แก่ แชต ของขวัญและชุดของขวัญต่อเนื่อง การติดตาม การแชร์ การสมัครสมาชิก การเข้าร่วม และหีบสมบัติ Activity Feed ไม่แสดงยอดไลก์หรือจำนวนผู้ชม

รหัสอีโมจิในตัวของ TikTok เช่น [laughcry] และ [wow] แสดงเป็นภาพในแหล่ง SSN ที่อัปเดตแล้ว โหมดข้อความล้วนตั้งใจเก็บเป็นข้อความแทน โหลดแหล่ง TikFinity ใหม่หลังเปลี่ยนการตั้งค่านั้น

หากมีบางอย่างหายไป

  • ปรากฏเฉพาะโลโก้ TikFinity: ตรวจสอบว่าบัญชี TikTok ที่เลือกกำลังไลฟ์และแดชบอร์ดหลักของ TikFinity เชื่อมต่ออยู่ การเปิดวิดเจ็ตเพียงอย่างเดียวไม่ได้สร้างการเชื่อมต่อต้นทางกับ TikTok
  • TikFinity มีข้อความเก่า แต่ SSN ว่างเปล่า: รอกิจกรรมใหม่ ตรวจสอบ URL แผงด็อกให้ครบ แล้วโหลดแหล่ง SSN ใหม่ หากวิดเจ็ตเองหยุดรับข้อความใหม่ ให้เชื่อมต่อ TikFinity ใหม่ก่อน
  • ไม่มีแชตใน Dock 2: เปิดปุ่มรูปเฟือง เปิด Show Chat แล้วกด Save
  • ของขวัญ การเข้าร่วม หรือเหตุการณ์อื่นหายไป: ตรวจสอบหมวดหมู่ของแผงด็อกและตัวกรองเหตุการณ์/การบริจาคของ SSN จะตรวจสอบหมวดหมู่ไม่ได้จนกว่าเหตุการณ์นั้นจะเกิดขึ้น
  • หน้า TikFinity อีกหน้าขัดจังหวะการเชื่อมต่อ: เปิดแท็บแดชบอร์ดหลักเพียงแท็บเดียว ใช้เมนูในแท็บนั้นเพื่อเปลี่ยนส่วน หน้าต่างรับข้อมูล Activity Feed แยกต่างหาก
  • ทุกอย่างปรากฏซ้ำสองครั้ง: เก็บแหล่งรับข้อมูลสำหรับ LIVE นั้นไว้เพียงแหล่งเดียว ข้อความเหมือนกันที่มี ID ข้อความ TikTok ต่างกันอาจเป็นข้อความแยกที่ส่งมาจริง
  • ตอบกลับไม่ได้: การเก็บข้อมูล TikFinity เป็นแบบอ่านอย่างเดียว ดู ตัวเลือกการเชื่อมต่อ TikTok โดยตรง สำหรับการรองรับการตอบกลับ
