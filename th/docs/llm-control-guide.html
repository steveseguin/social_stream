Local Control API และ MCP

ให้เครื่องมือ AI หรือสคริปต์บนคอมพิวเตอร์เครื่องเดียวกันตรวจสอบและควบคุมแอปเดสก์ท็อป Social Stream Ninja

เลือกบริการนี้เมื่อ1. ดาวน์โหลดแอปเดสก์ท็อปปกติ2. เปิดการควบคุมด้วย AI ภายในเครื่อง3. ให้ MCP ตรวจสอบความสามารถที่มีการควบคุมภายในเครื่องที่มีให้การเข้าถึง HTTP โดยตรงสำหรับสคริปต์ภายในเครื่องใช้ภายในเครื่องเท่านั้น

เลือกบริการนี้เมื่อ

แอปเดสก์ท็อป→API ควบคุมภายในเครื่อง→ไคลเอนต์ MCP

ใช้ Local Control API เมื่อซอฟต์แวร์บนคอมพิวเตอร์ที่รัน SSApp ต้องการการควบคุมแอปและแหล่งข้อมูลที่อนุญาต ใช้อะแดปเตอร์ MCP ที่มาพร้อมแอปเมื่อควรส่งการควบคุมเหล่านั้นเป็นเครื่องมือให้ไคลเอนต์ AI ที่รองรับ

สิ่งนี้แยกจาก File > Enable Local Server ซึ่งเริ่มเซิร์ฟเวอร์ส่งต่อ WebSocket สำหรับหน้า Social Stream ดู ทำความเข้าใจเซิร์ฟเวอร์และบริการในเครื่อง หากยังไม่แน่ใจว่าต้องใช้บริการใด

1. ดาวน์โหลดแอปเดสก์ท็อปปกติ

ติดตั้ง Social Stream Ninja รุ่นปัจจุบันจาก หน้าดาวน์โหลดสำหรับ Windows, macOS หรือ Linux แอปที่ดาวน์โหลดมารองรับ MCP อยู่แล้ว ไม่ต้องมีซอร์สโค้ดของโครงการ Node, Python หรือแพ็กเกจ MCP แยกต่างหาก

2. เปิดการควบคุมด้วย AI ภายในเครื่อง

  1. เปิด File > Local AI / Automation.
  2. เปิดใช้ API ควบคุมภายในเครื่อง แล้วปล่อยให้แอปเริ่มใหม่
  3. กลับไปที่เมนูเดิมแล้วเลือก คัดลอกการตั้งค่า MCP (Copy MCP Setup).
  4. วาง JSON ที่คัดลอกไว้ลงในการตั้งค่า MCP ของเครื่องมือ AI แล้วเริ่มเครื่องมือนั้นใหม่

การตั้งค่าที่คัดลอกมีเส้นทางไฟล์โปรแกรมที่ติดตั้งจริง พอร์ต และอาร์กิวเมนต์เฉพาะแพลตฟอร์ม ไฟล์โปรแกรม Social Stream Ninja ที่ดาวน์โหลดมาจะเริ่มอะแดปเตอร์ MCP ขนาดเล็กของตัวเองเมื่อไคลเอนต์ AI เรียกใช้ด้วย --ssapp-mcp.

3. ให้ MCP ตรวจสอบความสามารถที่มี

เมื่อเชื่อมต่อแล้ว ไคลเอนต์ MCP จะขอรายการเครื่องมือจาก Social Stream Ninja โดยอัตโนมัติ อะแดปเตอร์อ่านความสามารถจริงของแอปที่กำลังทำงาน แล้วส่งโครงสร้างเครื่องมือที่รองรับ เวอร์ชันแอป/API และคำแนะนำการใช้งานให้ LLM เอเจนต์ควรเรียก capabilities ก่อน ตามด้วย status และใช้รหัสแหล่งข้อมูลถาวรที่แอปส่งกลับ

การใช้ MCP ตามปกติไม่ต้องดึงข้อมูลจากเว็บไซต์หรือติดตั้ง skill ผู้ใช้เพียงขอให้เอเจนต์ที่เชื่อมต่ออยู่ตรวจสอบหรือควบคุม Social Stream Ninja ได้

การควบคุมภายในเครื่องที่มีให้

  • แสดงรายการ ตรวจสอบ เพิ่ม อัปเดต และลบแหล่งข้อมูล
  • เริ่ม หยุด หรือโหลดแหล่งข้อมูลหนึ่งรายการหรือกลุ่มที่กรองไว้ใหม่
  • เปลี่ยนการมองเห็นแหล่งข้อมูล สถานะปิดเสียง และโหมดการเชื่อมต่อ
  • อ่านและอัปเดตการตั้งค่าส่วนกลางที่รองรับซึ่งการตรวจสอบความสามารถส่งกลับมา
  • อ่านสถานะแอป เซสชัน แหล่งข้อมูล กระบวนการ การเก็บข้อมูล และสื่อภายในเครื่อง
  • ติดตามอีเวนต์ที่เก็บจากแหล่งข้อมูลภายในขอบเขตที่กำหนด และอีเวนต์การทำงานหรือสถานะที่ติดตามต่อจากจุดเดิมได้
  • จับภาพและตรวจสอบหน้าแหล่งข้อมูลที่รองรับและหน้าต่างของ SSApp อย่างปลอดภัย
  • โต้ตอบกับหน้าเว็บ หน้าต่าง และกล่องโต้ตอบที่อนุญาตหลังได้รับการยืนยัน
  • โหลดแอปใหม่หรือปิดแอปอย่างเรียบร้อยเมื่อได้รับการยืนยันอย่างชัดเจน

ความสามารถที่แอปซึ่งกำลังทำงานรายงานเป็นข้อมูลอ้างอิงที่ถูกต้อง เวอร์ชันเก่าอาจมีการควบคุมน้อยกว่า

การเข้าถึง HTTP โดยตรงสำหรับสคริปต์ภายในเครื่อง

สคริปต์บนคอมพิวเตอร์เครื่องเดียวกันสามารถใช้ loopback API โดยไม่ต้องใช้ MCP โดย API รับการเชื่อมต่อเฉพาะที่ 127.0.0.1 และไม่ต้องใช้โทเค็น

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

ใช้ความสามารถที่แอปรายงาน แทนการสมมติว่าแอปทุกเวอร์ชันมีการควบคุมเหมือนกัน สำหรับตัวอย่าง curl ที่คัดลอกไปใช้เพื่อเพิ่ม แสดงรายการ เริ่ม ตรวจสอบ และหยุดแหล่งข้อมูลได้ ดู คู่มือใช้งาน HTTP API ของเซิร์ฟเวอร์.

AI ภายในเครื่องบน Ubuntu VPS

API นี้ยังให้บริการเครื่องมือ AI ที่ทำงานบนเซิร์ฟเวอร์ Linux เดียวกับ SSApp แบบ headless ได้ ให้ผูก API กับ loopback ต่อไป และใช้ AppImage ที่ดาวน์โหลดมาเป็นคำสั่ง MCP

ติดตาม เรียก Social Stream Ninja แบบไร้หน้าจอ สำหรับ Xvfb โปรไฟล์ถาวร คำสั่งเริ่มต้น systemd และช่องทางควบคุมระยะไกลที่แยกต่างหาก อีกทั้งยังมี การตั้งค่า MCP สำหรับ Linux AppImage ที่นำไปวางในไคลเอนต์ซึ่งทำงานบน VPS ได้

skill เสริมสำหรับเอเจนต์

เอเจนต์ที่รองรับการติดตั้ง skill สามารถ ดาวน์โหลด skill Control Social Stream ฉบับเต็ม คุณยังสามารถ อ่านคำแนะนำออนไลน์ พร้อมด้วย เอกสารอ้างอิง API และ บันทึกเวอร์ชัน skill นี้เพิ่มคำแนะนำเกี่ยวกับขั้นตอนการทำงาน แต่ไม่จำเป็นต่อการเชื่อมต่อ MCP

ลิงก์สำหรับตรวจสอบความสามารถที่เครื่องอ่านได้ยังระบุไว้ใน llms.txt.

ใช้ภายในเครื่องเท่านั้น

อินเทอร์เฟซนี้ใช้สำหรับ AI และระบบอัตโนมัติที่ทำงานบนคอมพิวเตอร์เครื่องเดียวกับ SSApp อย่าเปิดให้เข้าถึงจากภายนอกหรือทำทันเนลเพื่อใช้เป็น API ควบคุมระยะไกลบนคลาวด์ ผู้ใช้ระยะไกลและ Stream Deck ควรใช้การเชื่อมต่อ WebRTC หรือ WebSocket ที่ Social Stream มีอยู่แล้ว API ภายในเครื่องไม่เปิดให้เรียกใช้ JavaScript ตามอำเภอใจ เข้าถึงคุกกี้ ความลับสำหรับเข้าสู่ระบบ การตั้งค่าโดยไม่จำกัด หรือระบบไฟล์โดยตรง

ดูปลายทางทั้งหมด โครงสร้างคำสั่ง การตรวจสอบเวอร์ชัน และขอบเขตความปลอดภัยได้ใน เอกสารอ้างอิงทางเทคนิคสำหรับระบบอัตโนมัติ.
