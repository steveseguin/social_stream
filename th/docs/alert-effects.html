การแจ้งเตือนด้วยภาพเคลื่อนไหวและเสียง

ตั้งค่าการแจ้งเตือนแรก

  1. เปิด Multi-Alerts → Event animations & sound effects
  2. เปิดการแจ้งเตือน แล้วเลือกอีเวนต์ ค่าที่ตั้งไว้สำหรับการบริจาค $100 จะกรอกขีดจำกัดยอดเงินทั้งสองค่า และใส่เสียงสังเคราะห์ Thank you หากยังไม่ได้เลือกเสียง
  3. เพิ่ม URL โดยตรงของ GIF รูปภาพ หรือวิดีโอ หรืออัปโหลดสื่อได้ ลิงก์หน้า GIPHY ไม่ใช่ URL สื่อโดยตรง ภาพ GIF ไม่มีเสียง ให้เลือกเสียงแยกต่างหาก
  4. เลือกเสียงแล้วกด Listen เพื่อฟังในเครื่อง ตัวเลือก URL กำหนดเองและอัปโหลดอยู่ใต้ตัวเลือกเสียง
  5. ใช้ Test alert แล้วเพิ่มลิงก์ Multi-Alerts เป็นแหล่งเบราว์เซอร์ใน OBS

ขีดจำกัดยอดเงินและลำดับความสำคัญ

การบริจาคและบิตใช้มูลค่า USD โดยประมาณจากตัวช่วยสกุลเงิน หากต้องการเฉพาะ $100 ให้ตั้งขีดจำกัดทั้งสองเป็น 100 หากต้องการ $100 ขึ้นไป ให้เว้นค่าสูงสุดว่าง ขีดจำกัดที่ว่างยอมรับทุกยอดเงิน ส่วนอีเวนต์ประเภทอื่นไม่ควรตั้งขีดจำกัดยอดเงิน

ใช้การแจ้งเตือนแรกที่ตรงเงื่อนไข วางกฎเฉพาะก่อนกฎกว้าง ๆ ตัวกรองแพลตฟอร์มและหมวดหมู่ยังมีผล

ตัวอย่างและเสียง

Test alert เปิดและโฟกัสตัวอย่างในเครื่อง ไม่ส่งอีเวนต์ไปยังช่องถ่ายทอดสด ตัวอย่างใช้การตั้งค่าโอเวอร์เลย์ ตัวกรอง สื่อ และเวลาปัจจุบันของคุณ ระดับเสียงอยู่ใน Sound & Timing

Clear sound ล้างเสียงกำหนดเองที่ใช้แทน แต่เสียงแจ้งเตือนเริ่มต้นยังทำงาน ปิด Play alert sound เพื่อปิดเสียงโอเวอร์เลย์ สวิตช์ Enable alert ใช้พักกฎโดยเก็บการตั้งค่าไว้ ส่วน Reset alert ล้างเฉพาะกฎนั้น

วลีที่มีเสียงพูดจะระบุว่าเป็นเสียงบันทึกสังเคราะห์ หากต้องการอ่านชื่อหรือข้อความที่เปลี่ยนไป ให้ใช้การกระทำ Speak Text ในตัวแก้ไข Event Flow

Event Flow และเอฟเฟกต์ OBS

ใช้เทมเพลต Event Flow สำหรับลำดับการทำงานและเอฟเฟกต์ OBS การสั่งเล่นสื่อและเสียงเหล่านั้นจะทำงานในโอเวอร์เลย์ Flow Actions ใช้โอเวอร์เลย์เดียวสำหรับเสียงของแต่ละอีเวนต์เพื่อไม่ให้ได้ยินซ้ำ เทมเพลต OBS ต้องเลือกแหล่งข้อมูลและฟิลเตอร์ก่อนใช้
