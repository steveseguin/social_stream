ทำให้ชื่อในแชตมีสีต่างกัน

เลือกวิธีที่แผงด็อกแสดงหรือสร้างสีชื่อผู้ใช้

ตั้งค่าอย่างรวดเร็ว

ไม่ต้องตั้งค่าส่วนกลาง: เลือกหนึ่งตัวเลือกในส่วนต่อไปนี้ของแผงด็อก: สีชื่อผู้ใช้ นี้
  1. เปิดการตั้งค่าส่วนขยายหรือแอปเดสก์ท็อป Social Stream Ninja
  2. ใน โอเวอร์เลย์แชตหลักและแผงด็อกควบคุม (Main chat overlay & control dock) ขยาย สีชื่อผู้ใช้.
  3. เปิด สร้างสีให้ชื่อที่ไม่มีสี วิธีนี้คงสีที่แพลตฟอร์มแชตให้มา และเติมสีให้ชื่อที่ยังไม่มี
  4. ใช้ลิงก์แผงด็อกที่อัปเดต URL ของแผงด็อกหรือแหล่งเบราว์เซอร์ OBS เดิมก็ใช้ได้หากเพิ่ม &randomcolor แล้วรีเฟรช

เลือกพฤติกรรมสี

ใช้ตัวเลือกสีหลักครั้งละหนึ่งตัว เพื่อให้ผลลัพธ์คาดการณ์ได้

ตัวเลือกแผงด็อก ผลลัพธ์ เหมาะกับ
สร้างสีให้ชื่อที่ไม่มีสี คงสีชื่อที่แพลตฟอร์มให้มา และกำหนดสีคงที่เมื่อไม่มีสี ผู้ใช้ส่วนใหญ่
สร้างสีให้ทุกชื่อ กำหนดสีที่สร้างอย่างสม่ำเสมอให้ทุกชื่อผู้ใช้ แทนสีจากแพลตฟอร์ม แชตที่ชื่อทุกคนมีสีหลากหลาย
ใช้สีชื่อผู้ใช้จากแหล่งข้อมูล แสดงสีเฉพาะเมื่อแพลตฟอร์มแชตให้มา แพลตฟอร์มอย่าง Twitch ที่ให้สีชื่อผู้ใช้

สีที่สร้างมีความคงที่: แผงด็อกคำนวณแฮชจากรหัสผู้ใช้ ชื่อผู้ใช้ หรือชื่อที่แสดง เพื่อให้คนเดิมใช้สีเดิม การตั้งค่าสีส่วนกลางยังใช้ได้เมื่อต้องเพิ่มสีในเพย์โหลดขาออกและส่วนแสดงผลอื่น

หากชื่อยังเป็นสีเดียวกัน

  1. ยืนยันว่าเปิดตัวเลือกหนึ่งในส่วนต่อไปนี้ของแผงด็อก: สีชื่อผู้ใช้ นี้
  2. สำหรับแพลตฟอร์มที่ไม่มีสีชื่อผู้ใช้ ให้เลือก สร้างสีให้ชื่อที่ไม่มีสี.
  3. ตรวจสอบว่า URL แผงด็อกมี &color, &randomcolor, หรือ &randomcolorall.
  4. รีเฟรชแท็บแผงด็อกหรือแหล่งเบราว์เซอร์ OBS ที่เปิดอยู่ก่อนแล้ว
  5. ตรวจ CSS กำหนดเองว่ามีกฎบังคับทุก .hl-name ให้เป็นสีเดียวกัน

ควบคุมเพิ่มเติมด้วย CSS

เพิ่ม CSS ผ่านการตั้งค่าแผงด็อก ตัวเลือก &css= หรือ &b64css= ใน URL หรือ CSS กำหนดเองของแหล่งเบราว์เซอร์ OBS ใช้ !important เมื่อแทนที่สีชื่อที่แพลตฟอร์มให้มา

ใช้สีเดียวสำหรับทุกชื่อ

.hl-name {
  color: #ffd166 !important;
}

เลือกสีตามแพลตฟอร์ม

.highlight-chat[data-source-type="youtube"] .hl-name {
  color: #ff5a5f !important;
}

.highlight-chat[data-source-type="twitch"] .hl-name {
  color: #b794f4 !important;
}

.highlight-chat[data-source-type="kick"] .hl-name {
  color: #53fc18 !important;
}

เน้นผู้ดูแลแชตและ VIP

.highlight-chat.mod .hl-name {
  color: #5eead4 !important;
}

.highlight-chat.vip .hl-name {
  color: #f472b6 !important;
}

CSS ระบุแพลตฟอร์มหรือบทบาทเป็นเป้าหมายได้แน่นอน แต่แผงด็อกมาตรฐานไม่ได้ใส่ชื่อผู้ใช้เป็นคลาสหรือแอตทริบิวต์ CSS หากต้องการกฎสีคงที่รายคน ให้ใช้สีที่สร้างในตัว หรือ โอเวอร์เลย์กำหนดเอง ที่จับคู่ชื่อผู้ใช้กับสีใน JavaScript
