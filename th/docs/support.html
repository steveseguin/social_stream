การสนับสนุน

รับความช่วยเหลือ Social Stream Ninja รายงานปัญหา หรือร่วมพัฒนาโปรเจ็กต์

แนวทางขอความช่วยเหลือที่พบบ่อย

เริ่มจากคู่มือที่ตรงปัญหา

  • ฐานความรู้คำตอบสั้นสำหรับโอเวอร์เลย์ว่าง เซสชันผิด เสียง OBS, TikTok, YouTube และบอต
  • เริ่มใช้ OBS อย่างรวดเร็วเซสชัน ลิงก์แผงด็อก ลิงก์โอเวอร์เลย์ และแหล่งเบราว์เซอร์ OBS แรก
  • การแก้ปัญหา OBSแทน URL ที่บันทึก รีเฟรชแคชแหล่งเบราว์เซอร์ และวินิจฉัยโอเวอร์เลย์ว่าง
  • โหมดผู้ดูแลระบบ Windowsเฉพาะเมื่อยืนยันว่าระดับสิทธิ์ OBS และ Social Stream ไม่ตรงกัน
  • ตัวช่วยเลือกการตั้งค่าแพลตฟอร์มเลือกแชตแยก หน้าที่ต้องเปิดสวิตช์ หน้าต่างแหล่งข้อมูลแอป หรือหน้าแหล่งข้อมูล
  • ตั้งค่าแชตบอต AIการเชื่อมต่อผู้ให้บริการ ตัวควบคุม Primary bot ทดสอบสดอย่างปลอดภัย เส้นทางตอบกลับ และข้อผิดพลาดที่พบบ่อย
  • วิธีแก้ที่พบบ่อยแชตหาย โอเวอร์เลย์ว่าง สวิตช์แพลตฟอร์ม และตรวจสิทธิ์
  • คลังความช่วยเหลือขั้นสูงแนวทางเชิงลึกสำหรับขั้นตอนช่วยเหลือและเอเจนต์ AI

ขอฟีเจอร์

ต้องการรองรับแพลตฟอร์มหรือฟีเจอร์ใหม่? แจ้งเรา!

แม้ Social Stream Ninja รองรับกว่า 100 แพลตฟอร์มแล้ว เรายังพร้อมเพิ่มตามความต้องการชุมชน หากต้องการขอเชื่อมแพลตฟอร์มหรือฟีเจอร์ใหม่:

  1. ตรวจว่ารองรับแล้วหรือไม่ใน แพลตฟอร์มที่รองรับ รายการ
  2. เข้าร่วม ชุมชน Discord แล้วโพสต์ในช่อง #feature-requests
  3. หรือสร้าง issue บน GitHub พร้อมรายละเอียดคำขอ

หมายเหตุ: ไม่ใช่ทุกแพลตฟอร์มที่ขอจะรองรับได้ เราให้ความสำคัญกับแพลตฟอร์มที่มีผู้ใช้มากและเชื่อมต่อได้จริงทางเทคนิค

  3. ส่ง pull request พร้อมคำอธิบายการเปลี่ยนแปลงชัดเจน

คำถามช่วยเหลือที่พบบ่อย

มักเกิดจากเบราว์เซอร์ลดการทำงาน ลองวิธีต่อไปนี้:

  • ปิดการลดการทำงานของเบราว์เซอร์: ไปที่ chrome://flags/#enable-throttle-display-none-and-visibility-hidden-cross-origin-iframes แล้วตั้งเป็น "Disabled"
  • ปิดเพิ่มด้วยสำหรับ chrome://flags/#calculate-native-win-occlusion
  • ลองแอปเดสก์ท็อปแบบแยกแทนส่วนขยายเบราว์เซอร์

หากเห็นแถบดีบักสีน้ำเงินหรือการตอบอัตโนมัติไม่ทำงาน:

  • ตรวจว่าหน้าต่างแชตแยกเปิดอยู่และมองเห็นได้
  • ลองเบราว์เซอร์ที่ใช้ Chromium (Chrome, Edge, Brave) แทน Firefox
  • ตรวจว่าคุณมีสิทธิ์แชตบนแพลตฟอร์ม (บางแห่งต้องสมัครสมาชิก)
  • เริ่ม Chrome ด้วย --silent-debugger-extension-api แฟล็กเพื่อซ่อนแถบสีน้ำเงิน

เพื่อความปลอดภัย Discord, Slack, Telegram, WhatsApp และ Google Meet ต้องเปิดสวิตช์ในเมนูการตั้งค่าส่วนขยาย

เปิดสวิตช์รองรับแต่ละแพลตฟอร์มที่ต้องการใช้ และดู คู่มือฟีเจอร์ขั้นสูง สำหรับรายละเอียดเพิ่มเติม
