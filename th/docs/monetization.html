ตั้งค่า →

สามขั้นตอน

เชื่อมต่อกับ OBS

  1. เลือกการแสดงผลของคุณเปิด การสร้างรายได้ ในป๊อปอัป SSN เพิ่มสินค้า เชื่อมร้านค้า หรือเปิด กระดานช่องและการขายล่าสุด.
  2. บันทึก แล้วคัดลอกลิงก์ใช้ บันทึกการตั้งค่า สำหรับผู้ให้บริการ การควบคุมบอร์ดบันทึกทันที คัดลอกลิงก์ OBS ของส่วนแสดงผล
  3. เพิ่มแหล่งข้อมูลเบราว์เซอร์ใน OBSวางลิงก์ เริ่มที่ 800 × 600 สำหรับการ์ดสินค้า หรือ 1920 × 1080 สำหรับบอร์ด ให้ SSN ทำงานอยู่

เฉพาะส่วนแสดงผลเท่านั้นที่ปรากฏบนสตรีม ควบคุมใน SSN ส่วน แผงด็อกควบคุม OBS เป็นตัวเลือกเสริม

สินค้าและลิงก์สนับสนุน

สินค้าและลิงก์สนับสนุน

  1. เพิ่มลิงก์สาธารณะ ชื่อ และรูปภาพหรือราคาตามต้องการ
  2. เลือก ร้านค้า, ของขวัญ, การสนับสนุน หรือ เข้าร่วม แล้วบันทึก
  3. ใช้ แสดง / ถัดไป / ซ่อน / แสดงต่อ เพื่อควบคุมโชว์เคส

ลิงก์สินค้าใช้โปรโมตสินค้า เชื่อมร้านค้าแยกต่างหากเพื่อรับการแจ้งเตือนการซื้อ

การควบคุมสินค้า →ตั้งค่าร้านค้า →
คิวอาร์โค้ด การหมุนเวียน และตัวเลือกแสดงผล

บันทึกลิงก์สาธารณะได้สูงสุด 20 ลิงก์ ปักหมุดหนึ่งรายการหรือหมุนเวียน แต่ละรายการแสดงอย่างน้อย 15 วินาที แชร์ลิงก์สาธารณะในแชตด้วยสำหรับผู้ชมที่ดูบนโทรศัพท์

เลือก Showcase, Support card หรือ Activity alerts เป็นแหล่งข้อมูล OBS แยกกัน ตัวเลือกรูปแบบกะทัดรัด ขนาด มุม และการแสดงตามเวลาอยู่ใน Overlay link options ราคาที่ป้อนเองเป็นข้อมูล ณ เวลานั้น การซื้อไม่ลบสินค้าที่เพิ่มเอง

ดูตัวอย่าง →
การขายกับการประมูลต่างกันอย่างไร

เฉพาะคำสั่งซื้อที่ชำระเงินแล้วของผู้ขายที่เชื่อมต่อเท่านั้นที่สร้างการแจ้งเตือนการซื้อได้ การเสนอราคา การประมูลสิ้นสุด หรือสต็อกเปลี่ยนไม่ได้ยืนยันการชำระเงิน ราคารีเฟรชประมาณนาทีละครั้ง

การซื้อครั้งแรกลบรายการสินค้าที่เลือกนั้นออกจากการหมุนเวียนโชว์เคส การซื้อครั้งต่อไปยังแจ้งเตือน ไม่มีข้อมูลตัวตนผู้ซื้อ การคืนเงินไม่เปิดรายการกลับ การเชื่อมผู้ขายต้องมีบริการ eBay ของ SSN พร้อมใช้งาน

ของขวัญ Throne

ป้อนชื่อผู้ใช้ บันทึก แล้ววาง Webhook URL ของ SSN ลงใน Throne

ดูตัวอย่าง →
อันดับของขวัญและการสมทบทุน

ของขวัญที่สำเร็จเพิ่มอันดับของคุณ การสมทบทุนแสดงการแจ้งเตือน อันดับเพิ่มเมื่อระดมทุนของขวัญครบ SSN ไม่คาดเดาว่าซื้อรายการใดในรายการสิ่งที่อยากได้

ให้ SSN เชื่อมต่ออยู่ อันดับเก็บเฉพาะในระบบติดตั้งนี้ การคืนเงินและยกเลิกไม่ย้อนอันดับ ของขวัญที่ไม่ระบุชื่อยังคงไม่ระบุชื่อ

การตั้งค่าเว็บฮุก Throne

การนำเข้าและยืนยัน

ตรวจสอบราคาที่นำเข้าและรายการที่ขาด ใช้การป้อนเองหากนำเข้าไม่ได้ การลบสินค้าออกจาก Amazon ไม่ได้ยืนยันว่ามีการซื้อ ใช้สกุลเงินเดียวต่อชุดลำดับ

หลังตรวจสอบการซื้อ ให้เลือก ยืนยันว่าซื้อรายการปัจจุบันแล้ว (Confirm current item bought) Undo ย้อนกลับการยืนยันล่าสุดได้ระหว่างการรัน SSN ครั้งปัจจุบัน ตรวจสอบการแชร์สาธารณะและการตั้งค่าที่อยู่ของรายการสิ่งที่อยากได้

ทิป NinjaBacker

เชื่อม Stripe ที่ NinjaBacker ป้อนชื่อผู้ใช้และ Tip ID ส่วนตัวใน SSN

ดูตัวอย่าง →
Live feed หรือเว็บฮุกแบบเชื่อถือได้?

Live feed ตั้งค่าง่ายที่สุด เว็บฮุกแบบเชื่อถือได้เก็บคิวทิปที่มีลายเซ็นไว้นานสูงสุดเจ็ดวัน รวมช่วงที่ SSN ปิดอยู่ ทำตามคำแนะนำการตั้งค่าแล้วส่งทิปทดสอบจากแดชบอร์ด

Tip ID ส่วนตัวจะไม่อยู่ใน URL โอเวอร์เลย์ ทิปไม่ระบุชื่อยังคงไม่ระบุชื่อ การคืนเงินไม่ย้อนการแจ้งเตือนหรือรางวัล
