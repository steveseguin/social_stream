เอกสารอ้างอิงการตั้งค่า

ดูทุกสวิตช์ ช่องข้อความ และรายการแบบเลื่อนลงจากป๊อปอัป Social Stream Ninja พร้อมคำอธิบายบริบทและขอบเขต

สลับระหว่างแค็ตตาล็อกตัวควบคุมป๊อปอัปและดัชนีพารามิเตอร์ URL โอเวอร์เลย์ ทั้งสองมุมมองใช้การกำหนดค่าร่วมเพื่อให้สอดคล้องกัน

หน้านี้ดึงข้อมูลสดจาก popup.html เพื่อให้ตรงกับส่วนขยายและแอปเดสก์ท็อป ใช้ช่องค้นหากรองตามคีย์เวิร์ด หรือเปิดไฟล์นิยามการตั้งค่าที่ shared/config/settingsDefinitions.js เพื่อเพิ่มรายละเอียดคำอธิบายและขอบเขต

ต้องการให้ผู้แชตแต่ละคนมีสีต่างกันหรือไม่? ทำตาม คู่มือสีชื่อแชต ต้องเปิดทั้งตัวเลือกสีทั่วไปและสวิตช์แสดงสีของแผงด็อก

กำลังโหลดการตั้งค่าจาก popup.html…

ต้องการปรับโอเวอร์เลย์ผ่านสตริงพารามิเตอร์หรือไม่? ดูรายการสวิตช์ URL ทั้งหมด แยกตามส่วนและหมวดหมู่ ข้อมูลสร้างจาก parameters.md และส่งออกผ่าน shared/config/urlParameters.js เพื่อใช้ในเอกสารและตัวช่วยภายในแอป

กำลังโหลดดัชนีพารามิเตอร์ URL…

รายละเอียดขาดหายหรือพบข้อมูลล้าสมัย? อัปเดตเอกสารโดยแก้ไข shared/config/settingsDefinitions.js หรือเปิด issue บน GitHub
