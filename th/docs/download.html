ดาวน์โหลด Social Stream Ninja

เลือกวิธีติดตั้งที่เหมาะกับคุณที่สุด

ส่วนขยายเบราว์เซอร์เทียบกับแอปแบบสแตนด์อโลน

ทั้งสองแบบใช้งานได้ดี เลือกแบบที่เหมาะกับวิธีทำงานของคุณ

ส่วนขยายเบราว์เซอร์

  • ใช้การลงชื่อเข้าใช้ที่มีอยู่ในเบราว์เซอร์โดยอัตโนมัติ
  • มีปัญหาจากการบล็อกของเว็บไซต์น้อยกว่า เพราะทำงานภายในเว็บไซต์ที่คุณกำลังดู
  • ติดตั้งรวดเร็วผ่านเว็บสโตร์หรือติดตั้งด้วยตนเอง
ข้อควรจำ: หากต้องการเก็บข้อมูลอย่างต่อเนื่อง ให้เปิดแท็บเว็บไซต์ค้างไว้และให้มองเห็น เบราว์เซอร์หลายตัวจะลดการทำงานของแท็บที่ย่อหรืออยู่เบื้องหลัง

แอปแบบสแตนด์อโลน

  • เก็บข้อมูลในเบื้องหลัง โดยไม่ต้องเปิดหน้าต่างเบราว์เซอร์ค้างไว้หรือให้มองเห็น
  • ไม่ต้องใช้ส่วนขยาย อัปเดตอัตโนมัติ และมีเครื่องมือเสริม เช่น อยู่ด้านบนเสมอและความโปร่งใส
  • มีตัวเลือกเชื่อมต่อ WebSocket โดยตรงเพิ่มเติม
ข้อควรจำ: บางเว็บไซต์อาจจำกัดการเข้าถึงผ่านแอปและต้องใช้วิธีแก้เพิ่มเติม คุณจะลงชื่อเข้าใช้ภายในแอป ซึ่งแยกจากเซสชันเบราว์เซอร์

มีการอัปเดตทุกสองสามสัปดาห์หลังผ่านการตรวจสอบ

ดาวน์โหลด AppImage

Windows หรือ macOS ขัดขวางการเปิดแอปอยู่หรือไม่?

ใช้ข้อความเตือนที่ปรากฏบนหน้าจอเพื่อค้นหาขั้นตอนที่ปลอดภัยสำหรับ SmartScreen, Defender, Smart App Control, การตรวจสอบผู้พัฒนาใน macOS, คำเตือนการรับรอง หรือข้อผิดพลาด AppImage บน Linux

เปิดคู่มือความปลอดภัยของแอปเดสก์ท็อป

ใช้แอปที่ดาวน์โหลดกับเอเจนต์ AI ในเครื่อง

SSApp 0.4.7 ขึ้นไปมีโหมดเปิดใช้งาน MCP ในตัว ไม่ต้องเช็กเอาต์ซอร์ส ติดตั้ง Node หรือใช้อะแดปเตอร์แยก หลังติดตั้ง ให้เปิด File > Local AI / Automation แล้วคัดลอกการตั้งค่า MCP ที่สร้างขึ้น

ดูการตั้งค่า AI ในเครื่องและ MCP

Social Stream Ninja Lite

เชื่อมต่อแชต YouTube, Twitch หรือ Kick โดยไม่ต้องติดตั้งส่วนขยายหรือแอปเดสก์ท็อป เปิด Lite ในแท็บเบราว์เซอร์หรือแผงด็อกกำหนดเองของ OBS แล้วใช้ลิงก์โอเวอร์เลย์ใน OBS

  • ไม่ต้องเปิดแท็บเบราว์เซอร์แยก หากเก็บข้อมูลในแผงด็อก OBS
  • มีแหล่งข้อมูล เครื่องมืออัตโนมัติ และตัวเลือกปรับแต่งน้อยกว่าแอปเต็ม
  • โหมดแหล่งเบราว์เซอร์เดียวแบบทดลองรวมการเก็บและแสดงแชตไว้ด้วยกัน การลงชื่อเข้าใช้ผู้ให้บริการใน OBS อาจแตกต่างกันไป

ลิงก์โอเวอร์เลย์ทั่วไปต้องเปิด Lite ค้างไว้ในแท็บหรือแผงด็อก สำหรับการตั้งค่าที่ใช้เฉพาะ OBS ดู คู่มือ Lite สำหรับ OBS.

การติดตั้งบน Firefox

1

ดาวน์โหลดไฟล์ XPI

ดาวน์โหลดไฟล์ส่วนขยาย Firefox ที่ลงลายเซ็นแล้ว

ดาวน์โหลด XPI
2

ติดตั้งใน Firefox

เปิด Firefox แล้วติดตั้งส่วนขยาย:

  • ไปที่ about:addons ใน Firefox
  • คลิกไอคอนรูปเฟือง (การตั้งค่า)
  • เลือก ‘Install Add-on From File...’
  • เลือกไฟล์ XPI ที่ดาวน์โหลด
3

ข้อจำกัดของ Firefox

เวอร์ชัน Firefox มีข้อจำกัดบางอย่างเมื่อเทียบกับ Chrome:

  • ไม่มีโมเดลเสียง TTS รวมมาให้ ใช้ได้เฉพาะเสียงระบบ
  • ไม่มีฟีเจอร์จับภาพแท็บและดีบักเกอร์
  • ไม่รองรับฟีเจอร์ตอบกลับอัตโนมัติ

การติดตั้ง AppImage บน Linux

เคล็ดลับสำหรับผู้ใช้ Linux

บางดิสทริบิวชันอาจพบข้อผิดพลาดแซนด์บ็อกซ์เมื่อเรียกใช้ AppImage ของเรา ดูคู่มือแก้ปัญหาแซนด์บ็อกซ์ หากพบข้อผิดพลาดเกี่ยวกับการตั้งค่า SUID sandbox

1

ดาวน์โหลด AppImage

ดาวน์โหลดไฟล์ AppImage ลงในคอมพิวเตอร์

2

อนุญาตให้ไฟล์เรียกทำงานได้

คลิกขวาที่ไฟล์ เลือก Properties แล้วเลือก Permissions จากนั้นทำเครื่องหมาย ‘Allow executing file as program’ หรือใช้เทอร์มินัล: chmod +x SocialStreamNinja.AppImage

3

เปิดแอปพลิเคชัน

ดับเบิลคลิก AppImage เพื่อเปิด Social Stream Ninja หรือเรียกใช้จากเทอร์มินัล: ./SocialStreamNinja.AppImage

คำถามที่พบบ่อย

เวอร์ชัน Chrome Web Store ติดตั้งง่ายกว่า แต่จะอัปเดตทุกสองสามสัปดาห์เนื่องจากกระบวนการตรวจสอบของ Google การติดตั้งด้วยตนเองต้องใช้โหมดนักพัฒนาซอฟต์แวร์ แต่ช่วยให้เข้าถึงการอัปเดตและฟีเจอร์ล่าสุดได้ทันทีที่เผยแพร่
หากอัปเดตส่วนขยายด้วยการแทนที่ไฟล์แล้วโหลดใหม่ การตั้งค่าจะยังอยู่ แต่หากถอนการติดตั้งส่วนขยายทั้งหมด การตั้งค่าจะหายไป แนะนำให้ส่งออกการตั้งค่าก่อนถอนการติดตั้งทั้งหมด
หากต้องการอัปเดต ให้ดาวน์โหลดเวอร์ชันล่าสุด แทนที่ไฟล์เก่าด้วยไฟล์ใหม่ แล้วโหลดส่วนขยายใหม่หรือรีสตาร์ตเบราว์เซอร์ ไม่ต้องถอนการติดตั้งก่อน แนะนำให้สำรองการตั้งค่าก่อนอัปเดต
คำเตือนเกี่ยวกับ Manifest v2 ปรากฏเพราะ Google ระบุว่าการรองรับเวอร์ชันนี้ล้าสมัยแล้ว เราแนะนำให้อัปเดตเป็น Manifest v3 ก่อนอัปเดต ให้ส่งออกการตั้งค่า แล้วติดตั้งส่วนขยายเวอร์ชัน v3 ขณะนี้มีทั้งสองเวอร์ชัน แต่ v2 มีการสนับสนุนจำกัดและจะหยุดทำงานในที่สุด
แอปแบบสแตนด์อโลนไม่ต้องใช้ส่วนขยายเบราว์เซอร์ อัปเดตตัวเองอัตโนมัติ และมีฟีเจอร์เพิ่มเติม เช่น ปักหน้าต่างให้อยู่ด้านบนเสมอและพื้นหลังโปร่งใส อีกทั้งมีโอกาสได้รับผลจากการลดการทำงานของเบราว์เซอร์เมื่อย่อหน้าต่างน้อยกว่า
