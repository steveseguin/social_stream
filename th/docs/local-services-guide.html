1. เปิดเซิร์ฟเวอร์ภายใน (Enable Local Server)

ตัวเลือกในเมนู File นี้เริ่มเซิร์ฟเวอร์ส่งต่อ WebSocket ภายในแอปเดสก์ท็อปที่แยกห้องและช่องได้ หน้า Social Stream ที่รองรับใช้บริการนี้แลกเปลี่ยนแชตและคำสั่งบนคอมพิวเตอร์เครื่องเดียวกันได้ เป็นปลายทางทางเลือกสำหรับการกำหนดเส้นทางเซิร์ฟเวอร์ของแต่ละหน้า

บริการนี้ไม่ได้โฮสต์เว็บไซต์ Social Stream ไม่ได้เก็บข้อมูลแพลตฟอร์มด้วยตัวเอง และไม่ได้ให้บริการ HTTP API สำหรับระบบอัตโนมัติ เริ่มจาก คู่มือ Enable Local Server.

2. API ควบคุมภายในเครื่องและ MCP

loopback API ที่เปิดใช้ตามต้องการนี้ช่วยให้โปรแกรมบนคอมพิวเตอร์ที่รัน SSApp จัดการแหล่งข้อมูลและการตั้งค่าที่รองรับ อ่านสถานะและข้อมูลวินิจฉัย ตรวจสอบหน้าต่างแอปหรือแหล่งข้อมูล และติดตามอีเวนต์ที่เก็บได้ อะแดปเตอร์ MCP ที่มาพร้อมแอปนำเสนอการทำงานเหล่านั้นเป็นเครื่องมือให้ไคลเอนต์ AI ที่รองรับ

เปิดใช้งานที่ File > Local AI / Automation โดยแยกจาก เปิดเซิร์ฟเวอร์ภายใน (Enable Local Server) ดู คู่มือ Local Control API และ MCP.

3. เซิร์ฟเวอร์ที่บ้านหรือ VPS แบบ headless

โหมด headless เรียกใช้แอปเดสก์ท็อป Electron เต็มรูปแบบโดยซ่อนหน้าต่างแหล่งข้อมูล บน Linux ยังต้องมีระบบแสดงผลเบื้องหลัง เช่น Xvfb เหมาะสำหรับคอมพิวเตอร์เฉพาะงานที่ต้องเก็บแชตต่อเนื่องโดยไม่ต่อจอภาพ

โหมด headless ไม่ได้สร้าง API ควบคุมสาธารณะ การควบคุมระยะไกลใช้การรับส่งผ่าน WebRTC หรือ WebSocket ตามปกติของ Social Stream ดู คู่มือโฮสต์แบบ headless.

4. เซิร์ฟเวอร์สื่อภายในเครื่อง

แอปเดสก์ท็อปเริ่มบริการนี้โดยอัตโนมัติเมื่อมีสื่อ Event Flow ภายในเครื่อง โดยให้บริการเฉพาะไฟล์ที่อนุมัติผ่าน SSApp และทรัพยากรรันไทม์ที่เลือกไว้ ผ่านเส้นทางโทเค็นสุ่มเฉพาะโปรไฟล์

บริการนี้ไม่ใช่เว็บเซิร์ฟเวอร์หรือไฟล์เซิร์ฟเวอร์สำหรับใช้งานทั่วไป ดู ไฟล์สื่อสำหรับ Event Flow เพื่อเลือกระหว่างไฟล์ภายในเครื่อง การอัปโหลด และการโฮสต์บนคลาวด์

Server Fallback เป็นคนละอย่างกัน

การตั้งค่า เช่น ส่งข้อความแชตไปยังเซิร์ฟเวอร์ API และ แผงด็อกส่งคำสั่งไปยังส่วนขยายผ่านเซิร์ฟเวอร์ ใช้เลือกวิธีกำหนดเส้นทางแชตและคำสั่ง แฟล็กใน URL ที่สร้างขึ้นประกอบด้วย server, server2, และ server3.

โดยปกติการตั้งค่าเหล่านี้ใช้บริการ WebSocket ที่ Social Stream โฮสต์ไว้ หากหน้าที่รองรับมี localserver จะใช้เซิร์ฟเวอร์ส่งต่อภายในของแอปเดสก์ท็อปแทน ดู เซสชัน รหัสผ่าน รีเลย์ และโหมดเซิร์ฟเวอร์ สำหรับการควบคุมการกำหนดเส้นทาง

ใช้ลิงก์ที่สร้างใหม่ แฟล็กกำหนดเส้นทางเป็นค่าของแต่ละหน้า อย่าคัดลอกแฟล็กเซิร์ฟเวอร์จากหน้าหนึ่งไปอีกหน้าแล้วคิดว่าจะมีความหมายเดียวกัน

พอร์ตภายในเครื่องชั่วคราวอื่น ๆ

ขั้นตอนลงชื่อเข้าใช้และเชื่อมบัญชีบางอย่างจะเปิดพอร์ต callback บน loopback ชั่วคราว แล้วปิดเมื่อขั้นตอนสิ้นสุด ตัวรับการเชื่อมต่อชั่วคราวเหล่านี้ไม่ใช่เซิร์ฟเวอร์ SSN หรือ API สำหรับระบบอัตโนมัติทั่วไป
