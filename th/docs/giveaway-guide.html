การแจกของรางวัลครั้งแรก

ผู้ชมพิมพ์ !enter ในแชต คุณรวบรวมผู้เข้าร่วมใน SSN แล้วคลิก จับผู้ชนะ.

หาส่วนควบคุม จัดการแจกของรางวัล แสดงใน OBS ความหมายของการตั้งค่า ปุ่มทำอะไร การแก้ปัญหา

1. หาเครื่องมือแจกของรางวัล

หากเห็นอยู่แล้วว่า เครื่องมือแจกของรางวัล, ตั้งค่าการเข้าร่วม, และ เริ่มแจกของรางวัล แสดงว่าอยู่ถูกที่แล้ว ไม่มีป๊อปอัปแจกของรางวัลเพิ่มเติมให้หา

มิฉะนั้นเปิดเมนูตั้งค่าหลัก SSN หากใช้ส่วนขยายเบราว์เซอร์ ให้คลิกไอคอนส่วนขยาย/จิ๊กซอว์ของเบราว์เซอร์ แล้ว Social Stream Ninja ในแอปเดสก์ท็อป ใช้เมนูตั้งค่า SSN ที่มีลิงก์โอเวอร์เลย์ ค้นหา giveaway และขยาย ตัวเลือกแจกของรางวัล หากเห็นหน้าต้อนรับผู้เริ่มต้น ให้เลือก สลับเป็นโหมดเต็ม.

  1. ผู้ชมเข้าร่วมในแชตปกติที่คุณจับข้อมูล
  2. คุณควบคุมการจับรางวัลในเมนูตั้งค่า SSN
  3. OBS แสดงผลใช้ลิงก์หน้าจอที่คัดลอก

ลิงก์ที่ขึ้นต้นด้วย https://socialstream.ninja/giveaway.html?session=... เปิดหน้าจอผู้ชม เมื่อใช้ &managed ในลิงก์นั้น คุณควบคุมการแจกจาก SSN หน้าจอไม่มีปุ่มเข้าร่วมหรือจับรางวัล

2. แจกของรางวัลฟรีแบบง่าย

ก่อนเริ่ม ให้เปิด SSN และเชื่อมต่อแหล่งแชตไว้ ตรวจว่าข้อความผู้ชมปกติปรากฏในแผงด็อก SSN

  1. คงการตั้งค่าพื้นฐาน คงค่า รหัสแจกของรางวัล เป็น default (เว้นว่างก็หมายถึงค่าเริ่มต้น), คำสำคัญสำหรับเข้าร่วม เป็น !enter, และ จับคู่ข้อความ เป็น ข้อความตรงทั้งประโยค คงค่า เฉพาะสมาชิกเท่านั้นที่เข้าร่วมได้ และ อนุญาตให้ชนะซ้ำ ปิดไว้
  2. ตรวจ Tickets and point prizes สำหรับการจับรางวัลฟรีปกติ ใช้ ประเภทรอบ: Giveaway, แต้มต่อตั๋ว: 0, รางวัลแต้มต่อผู้ชนะ: 0, และ จำนวนรางวัล: 1 ไม่ต้องใช้ระบบสะสมแต้มสำหรับสิ่งนี้
  3. คลิก Open entries บอกผู้ชมว่า: “พิมพ์ !enter ในแชตเพื่อเข้าร่วมแจกของรางวัล” ผู้ชมเข้าร่วมในแชตที่คุณจับ เช่น YouTube หรือ Twitch ไม่ต้องใช้ลิงก์แจกของรางวัล
  4. ตรวจผู้เข้าร่วม คลิก รีเฟรชสถานะ เพื่ออัปเดตจำนวนในเมนู หรือ จัดการการแจกของรางวัลและประวัติ เพื่อตรวจรายชื่อ การส่งซ้ำ !enter ไม่เพิ่มสิทธิ์เข้าร่วมฟรีให้ผู้ชมคนเดิม
  5. คลิก Close entries แล้ว Draw winner SSN สุ่มเลือกผู้เข้าร่วมที่มีสิทธิ์ เมนูรายงานผู้ชนะ และหน้าจอที่เชื่อมต่อแสดงผลเดียวกัน การจับปิดรับอัตโนมัติด้วย
  6. หากต้องการแจกอีกครั้ง คลิก New round แล้ว Open entries รอบใหม่เริ่มด้วยรายชื่อว่าง ผู้ชมต้องเข้าร่วมใหม่ ผลก่อนหน้ายังอยู่ในประวัติ
“Entries open - 0 eligible entries” ไม่ใช่ข้อผิดพลาด กำลังเปิดรับ แต่การตรวจสถานะล่าสุดไม่พบผู้เข้าร่วม ให้ผู้ชมส่ง !enter หลังเปิดรับ แล้วคลิก รีเฟรชสถานะ จำนวนในป๊อปอัปไม่อัปเดตอัตโนมัติเมื่อแชตเข้ามา

สถานะอาจแสดงจำนวนตั๋วด้วย การเข้าร่วมฟรีหนึ่งครั้งนับเป็นหนึ่งตั๋ว เมื่อราคาตั๋วเป็นศูนย์จะไม่หักแต้ม

SSN เลือกผู้ชนะ หากรางวัลเป็นของขวัญ คีย์เกม หรือสิ่งของอื่น คุณจัดส่งเอง ส่วน รางวัลแต้ม มอบแต้มสะสม SSN โดยเฉพาะ

3. แสดงการแจกของรางวัลใน OBS

  1. ใน การนำเสนอ, เลือก หน้าจอแจกของรางวัล: การ์ดผู้ชนะ แสดงผลโดยตรง; วงล้อชื่อ หมุนชื่อก่อนเปิดผล; วงล้อชุมชน เปิดผลด้วยวงล้อหมุน
  2. เลือก สไตล์, ตัวเลือกเพิ่มเติม ชื่อที่แสดง, และ โปร่งใส (OBS) สำหรับพื้นหลัง แผงตามธีม เพิ่มแผงพื้นหลัง
  3. คลิก ดูตัวอย่างหน้าจอ เพื่อตรวจหน้าตา ใช้ชื่อจำลอง ไม่เปิดรับ ไม่เพิ่มผู้ชมจริง และไม่จับรางวัลจริงของคุณ
  4. คลิก [คัดลอกลิงก์] ข้าง เครื่องมือแจกของรางวัล ใน OBS เพิ่ม แหล่งเบราว์เซอร์ (Browser Source) แล้ววางลิงก์ในช่อง URL เริ่มด้วยความกว้าง 1280 และความสูง 720.
  5. เปิด SSN ทิ้งไว้และใช้ปุ่ม เปิดรับผู้เข้าร่วม, ปิดรับผู้เข้าร่วม, และ จับผู้ชนะ ปุ่ม ไม่ต้องใช้ขั้นตอน “Interact” ของ OBS สำหรับหน้าจอที่จัดการแบบนี้

คัดลอกลิงก์ใหม่หลังเปลี่ยนการแสดงผล แล้วแทน URL ใน OBS ใช้ลิงก์ปกติที่คัดลอก ไม่ใช่ URL ตัวอย่าง คงเซสชันและรหัสผ่านจากเมนู SSN ของคุณไว้เพื่อให้หน้าจอเชื่อมกับการแจกของคุณ

[แก้ไขลิงก์] โหลด URL โอเวอร์เลย์เดิมเข้าสู่การตั้งค่าลิงก์ของเมนู ไม่จำเป็นสำหรับการแจกครั้งแรก [?] เปิดข้อความช่วยเหลือสั้น ๆ

ความหมายของการตั้งค่าเข้าร่วม

การตั้งค่าความหมาย
รหัสแจกของรางวัลระบุชื่อการแจกที่กำลังควบคุม ใช้ default สำหรับการแจกหนึ่งรายการ แยกจากรหัสเซสชัน การแจกหลายรายการต้องมีรหัสต่างกันและลิงก์หน้าจอตรงกัน
คำสำคัญสำหรับเข้าร่วมสิ่งที่ผู้ชมพิมพ์ เช่น !enter หรือ !raffle บอกผู้ชมให้ใช้คำสำคัญที่คุณตั้งจริง
ข้อความตรงทั้งประโยคข้อความทั้งหมดต้องเป็น !enter โดยไม่แยกตัวพิมพ์ใหญ่เล็กและไม่สนช่องว่างรอบข้อความ !enter please ไม่ตรงเงื่อนไข
มีคำสำคัญที่ใดก็ได้ (แยกเป็นคำ)ยอมรับข้อความ เช่น I'd like to join !enter please คำสำคัญต้องแยกด้วยช่องว่าง; !enter! ไม่ใช่คำสำคัญเดียวกัน
เฉพาะสมาชิกเท่านั้นที่เข้าร่วมได้ต้องมีข้อมูลสมาชิกในข้อความที่จับได้ ปิดไว้สำหรับการแจกที่เปิดให้ทุกคน ไม่ได้หมายถึง “ทุกคนที่ดู” หรือ “ผู้ติดตามทุกคน” การรองรับขึ้นอยู่กับแหล่งแชต
อนุญาตให้ชนะซ้ำให้ผู้ชมคนเดิมชนะมากกว่าหนึ่งรางวัลภายในรอบปัจจุบัน หากปิด ผู้ชนะจะถูกนำออกจากกลุ่มที่มีสิทธิ์ในรอบนั้น รอบใหม่ให้ผู้ชนะก่อนหน้าเข้าร่วมได้อีก
ตั๋วและรางวัลแต้มการตั้งค่าแต้มสะสม SSN เพิ่มเติมและเกมประเภทอื่น คงค่าใช้จ่ายและรางวัลแต้มเป็นศูนย์สำหรับแจกฟรี แต้มเหล่านี้แยกจากแต้มช่อง Twitch
จำนวนรางวัลจำนวนผลลัพธ์ที่รอบอนุญาต ตั้งก่อนเปิดรับ หากมีผู้ชนะหลายคน ให้คลิก จับผู้ชนะ หนึ่งครั้งต่อรางวัล อย่าสร้างรอบใหม่ระหว่างการจับเหล่านั้น

ตั้งกฎก่อนคนเข้าร่วม เมื่อมีผู้เข้าร่วมแล้ว การเปลี่ยนช่องในเมนูไม่เปลี่ยนกฎรอบที่ทำงาน หากต้องการเปลี่ยน ให้ยกเลิกรอบ สร้างรอบใหม่ ตั้งค่า และเปิดรับอีกครั้ง ตัวจัดการแสดงกฎที่บันทึกจริงสำหรับรอบ

การเข้าร่วมฟรีติดตามตามตัวตนที่แต่ละแหล่งแชตให้มา คนเดียวกันที่เข้าร่วมสองแพลตฟอร์มไม่ได้ถูกระบุเป็นคนเดียวโดยอัตโนมัติ

ปุ่มทำอะไร

ปุ่มใช้เพื่อ
เปิดรับผู้เข้าร่วมรับผู้เข้าร่วม หรือเปิดรอบที่พักไว้ใหม่ก่อนจับผู้ชนะ การเปิดใหม่คงผู้เข้าร่วมเดิมและต้องใช้กฎที่ล็อกไว้ชุดเดิม
ปิดรับผู้เข้าร่วมหยุดรับใหม่โดยคงกลุ่มปัจจุบัน
จับผู้ชนะปิดรับและเลือกผู้ชนะหนึ่งคน ต้องมีผู้เข้าร่วมที่มีสิทธิ์อย่างน้อยหนึ่งคน หากตั้งหนึ่งรางวัล รอบจะเสร็จสิ้น
ยกเลิกและคืนเงินยกเลิกก่อนจับรางวัล แต้มที่จองไว้ซื้อตั๋วจะคืน ไม่สามารถย้อนผลที่จับไปแล้ว
รอบใหม่เริ่มใหม่ด้วยกลุ่มว่างและเก็บประวัติก่อนหน้าไว้ เริ่มโดยปิดรับ รอบเสียแต้มที่มีแต้มจองต้องยกเลิก/คืนก่อน
รีเฟรชสถานะอ่านจำนวนปัจจุบันและผลล่าสุดโดยไม่เปลี่ยนการแจก
จัดการการแจกของรางวัลและประวัติตรวจผู้เข้าร่วมและกฎที่บันทึก นำผู้เข้าร่วมออกก่อนจับ ตรวจผล หรือส่งออกประวัติ/ข้อมูลสำรอง

หากบางอย่างไม่ทำงาน

  • ยังไม่มีผู้เข้าร่วม? คลิก รีเฟรชสถานะ ตรวจว่าข้อความผู้ชมปรากฏใน SSN เปิดรับอยู่เมื่อข้อความมาถึง คำสำคัญตรงกัน และปิดเฉพาะสมาชิก สำหรับการจับรางวัลฟรีด้วยคำสำคัญ ราคาตั๋วต้องเป็นศูนย์ ใช้คำสำคัญต่างกันสำหรับการแจกฟรีที่เปิดพร้อมกัน
  • ข้อความทดสอบเข้าร่วมไม่ได้? ไม่รวมข้อความบอต ส่วนตัว ประวัติ เล่นซ้ำ และข้อความที่ระบุว่าทดสอบระบบแต้ม ใช้ ดูตัวอย่างหน้าจอ เพื่อตรวจหน้าตา หากต้องการซ้อมจับผู้เข้าร่วมจริง ให้ส่งคำสำคัญผ่านแชตที่เชื่อมต่อหลังเปิดรับ
  • หน้าจอแสดงแค่ “Waiting for giveaway”? เปิดตัวหลัก SSN ทิ้งไว้ ใช้ลิงก์ที่คัดลอกจากเซสชันเดียวกัน แล้วคลิก รีเฟรชสถานะ ตรวจว่าเมนูและหน้าจอใช้ Giveaway ID เดียวกัน URL ตัวอย่างแสดงเฉพาะข้อมูลจำลอง
  • ไม่มีปุ่มบนหน้าแจกของรางวัล? เป็นพฤติกรรมปกติของหน้าจอผู้ชมที่ควบคุมจากตัวหลัก กลับไปที่ ตัวเลือกแจกของรางวัล ใน SSN
  • รอบเสร็จแล้วหรือกฎถูกล็อก? ใช้ รอบใหม่ หลังจับรางวัลเสร็จ หากต้องการทิ้งรอบที่ยังไม่จับ ใช้ ยกเลิกและคืนเงิน ก่อน แล้ว รอบใหม่.
  • เริ่ม SSN ใหม่หรือไม่? รอบที่บันทึกยังอยู่ในโปรไฟล์เบราว์เซอร์/แอปในเครื่อง รอบที่เปิดจะปิดเพื่อตรวจสอบ ใช้เซสชันเดิม รีเฟรชสถานะ และตรวจสอบก่อนเปิดใหม่ การเปลี่ยนเซสชันเลือกชุดการแจกแยกต่างหาก

พร้อมใช้ตั๋วเสียแต้ม รางวัลแต้ม แจกหลายรายการ Stream Deck หรือ Event Flow หรือยัง? อ่านต่อที่ การแจกของรางวัล ตั๋ว และรางวัลแต้ม.
