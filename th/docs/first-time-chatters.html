คู่มือผู้แชตครั้งแรก

ทำเครื่องหมายผู้แชตใหม่ด้วยไฮไลต์ ตราใบไม้ หรือเสียงเตือนที่เลือกเปิดได้

ฟีเจอร์นี้ทำอะไร

การตรวจผู้แชตครั้งแรกเพิ่ม firsttime=true ลงในข้อความแชตแรกของผู้ชมที่บันทึกสำหรับแหล่งนั้น แผงด็อกใช้แฟล็กนี้เพื่อแรเงาพื้นหลัง ส่งเสียงเฉพาะครั้งแรก และแสดงตราใบไม้เพิ่มเติมได้

การตั้งค่าที่จำเป็น

  1. เปิดป๊อปอัป Social Stream Ninja
  2. คงค่า ปิดฐานข้อมูลข้อความในเครื่อง ปิดไว้
  3. เปิด การตรวจผู้แชตครั้งแรก.
  4. เปิดแผงด็อกหรือโอเวอร์เลย์ด้วยรหัสเซสชันเดียวกันทิ้งไว้
สำคัญ: ต้องมีฐานข้อมูลในเครื่อง หากปิดฐานข้อมูล Social Stream Ninja จะบอกไม่ได้ว่าใครเป็นคนใหม่

ตัวเลือกแสดงผล

  • สีพื้นหลัง: เปิดตามค่าเริ่มต้นในแผงด็อก คงค่า ไม่แรเงาพื้นหลังผู้แชตครั้งแรก ปิดไว้หากต้องการไฮไลต์
  • ตราใบไม้: เปิด ทำเครื่องหมายผู้แชตครั้งแรกด้วยตรากำหนดเอง เพื่อเติมตราใบไม้เล็ก ๆ หน้าตราของผู้แชต
  • เสียงเตือนในแผงด็อกสำหรับผู้แชตครั้งแรก: เปิดหากต้องการให้เสียงแผงด็อกดังเฉพาะผู้แชตครั้งแรก
  • เสียงเตือนผู้แชตใหม่หรือกลับมา: เปิดหากต้องการเสียงสำหรับผู้ชมที่กลับมาหลังเงียบไปตั้งแต่ 8 ชั่วโมงขึ้นไปด้วย

การใช้แฟล็กในโอเวอร์เลย์กำหนดเอง

โอเวอร์เลย์กำหนดเองตรวจหา data.firsttime === true หากเปิดตัวเลือกตราใบไม้ ตราจะรวมอยู่ใน chatbadges ก่อนข้อความถึงโอเวอร์เลย์

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

หากไม่แสดง

  1. ยืนยันว่า ปิดฐานข้อมูลข้อความในเครื่อง ปิดอยู่
  2. ยืนยันว่า การตรวจผู้แชตครั้งแรก เปิดอยู่
  3. ยืนยันว่า ไม่แรเงาพื้นหลังผู้แชตครั้งแรก ปิดอยู่หากต้องการไฮไลต์
  4. ยืนยันว่า ทำเครื่องหมายผู้แชตครั้งแรกด้วยตรากำหนดเอง เปิดอยู่หากต้องการตราใบไม้
  5. ทดสอบด้วยคู่ชื่อผู้ใช้/แหล่งข้อมูลที่ยังไม่บันทึกในฐานข้อมูลในเครื่อง
