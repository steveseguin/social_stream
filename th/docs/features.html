ฟีเจอร์

รวมแชตของคุณ นำผู้ชมขึ้นหน้าจอ และสร้างเอกลักษณ์ให้ทุกสตรีม

สำรวจ 126 ไอเดียสตรีม · ดูตัวอย่างรางวัลสติกเกอร์

การรวมแชตหลายแพลตฟอร์ม

เชื่อมต่อผู้ชมจากทุกแพลตฟอร์มสตรีมพร้อมกัน Social Stream Ninja รวมข้อความแชตจากหลายสิบแพลตฟอร์มไว้ในแดชบอร์ดเดียวที่จัดการง่าย

  • รับส่งข้อความแชตสดสองทางกับ Facebook, YouTube, Twitch, Zoom และอื่น ๆ
  • แพลตฟอร์มส่วนใหญ่ไม่ต้องเข้าสู่ระบบหรือใช้คีย์ API
  • ไอคอนแหล่งข้อมูลหลายช่องเพื่อแยกแพลตฟอร์ม
  • ส่งต่อข้อความระหว่างแพลตฟอร์มอัตโนมัติ

โอเวอร์เลย์แชตไฮไลต์

นำข้อความดีที่สุดจากผู้ชมขึ้นสตรีมโดยตรงด้วยโอเวอร์เลย์สวยงามที่ปรับแต่งได้

  • เลือกข้อความผ่านแดชบอร์ดที่จัดเป็นแผงด็อกได้
  • เลือกข้อความอัตโนมัติหรือด้วยตนเอง
  • ปรับแต่งด้วย CSS ให้เข้ากับภาพลักษณ์สตรีมของคุณ
  • ตัวเลือกภาพเคลื่อนไหวรวมเอฟเฟกต์จางและเลื่อน
  • เข้าคิวข้อความเพื่อแสดงเด่นอย่างเป็นระเบียบ

คำสั่งบอตและตอบกลับอัตโนมัติ

สร้างการโต้ตอบอัตโนมัติกับผู้ชมด้วยคำสั่งและคำตอบกำหนดเอง

  • คำสั่งในตัวสำหรับการโต้ตอบทั่วไป
  • ตรรกะคำสั่งกำหนดเองด้วยไฟล์ปลั๊กอินที่เขียนสคริปต์ได้
  • ทักทายและตอบกลับอัตโนมัติ
  • กรองและดูแลข้อความ

การเชื่อมต่อ AI และ LLM

เลือกผู้ช่วยดำเนินรายการด้วยเสียง แชตบอต เพื่อนร่วมสนทนาในเบราว์เซอร์ หรือเครื่องมือประมวลผล AI เฉพาะทาง โดยไม่ผูกส่วนอื่นของสตรีมไว้กับผู้ให้บริการรายเดียว

  • ผู้ช่วยดำเนินรายการด้วยเสียงที่ได้ยินคุณและรับข้อความแชตสดที่เลือก
  • แชตบอตหลักและส่วนตัวพร้อมคำสั่งและกฎเรียกใช้งานกำหนดเอง
  • โมเดลในเครื่องหรือผู้ให้บริการคลาวด์ รวม OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq และ API กำหนดเองที่เข้ากันได้
  • การดูแลแชต การแปล การสรุป บริบท RAG และการสร้างโอเวอร์เลย์
  • เลือกจับ ChatGPT ในเบราว์เซอร์ได้โดยไม่ใช้คีย์ API

การแปลงข้อความเป็นเสียงพูด

ทำให้ข้อความแชตมีชีวิตด้วยการแปลงข้อความเป็นเสียงพูด ช่วยให้สตรีมน่าสนใจและเข้าถึงได้มากขึ้น

  • รองรับ TTS ของระบบฟรี
  • เชื่อมต่อบริการ TTS พรีเมียม (Google Cloud, ElevenLabs, Speechify)
  • รองรับหลายภาษา
  • ปรับเสียง ระดับเสียงสูงต่ำ และอัตราพูดได้
  • รองรับการจับเสียง OBS

API ที่ครอบคลุม

ขยายความสามารถ Social Stream Ninja ด้วยตัวเลือกเชื่อมต่อ API ที่ครบครัน

  • รองรับ Webhook สำหรับเชื่อมต่อบริการภายนอก
  • API เซิร์ฟเวอร์สำหรับควบคุมระยะไกล
  • การเชื่อมต่อการบริจาค (NinjaBacker: ฟรี ค่าคอมมิชชันแพลตฟอร์ม 0%, Stripe, Ko-Fi, Buy Me A Coffee)
  • ควบคุมผ่าน MIDI/Streamdeck
  • รองรับควบคุมฉาก OBS ระยะไกล

ปรับแต่งได้ละเอียด

ทำให้ Social Stream Ninja เป็นแบบของคุณด้วยตัวเลือกปรับแต่งมากมายทั้งฟังก์ชันและหน้าตา

  • ตกแต่งด้วย CSS เพื่อควบคุมภาพได้เต็มที่
  • เทมเพลตและธีมตกแต่งสำเร็จ
  • รองรับ JavaScript กำหนดเอง
  • พารามิเตอร์ URL เพื่อตั้งค่าได้ง่าย
  • ตัวกรองแหล่งข้อมูลและตัวเลือกแบรนด์

เครื่องมือสตรีมขั้นสูง

พัฒนาสตรีมด้วยชุดเครื่องมือมืออาชีพที่ออกแบบเพื่อการมีส่วนร่วมและโต้ตอบ

  • มินิเกมโต้ตอบรวม Battle Royal
  • ระบบแจกของรางวัลพร้อมจัดการคิว
  • แสดงเครดิตเลื่อนและโหลทิป
  • เมฆคำและคำสั่ง GIF กำหนดเอง
  • ระบบสำรวจความคิดเห็นแบบกราฟิก
  • ฐานข้อมูลประวัติแชตพร้อมค้นหา
  • อินเทอร์เฟซแชตบอต AI ส่วนตัว
  • ความสามารถผู้ช่วยดำเนินรายการ AI หลายสื่อ

ความช่วยเหลือจากชุมชน ชุมชน Discord ที่มีการพูดคุยต่อเนื่อง ขึ้นอยู่กับผู้ให้บริการ
