ฐานความรู้

คำตอบสั้น ๆ สำหรับปัญหาที่พบบ่อย ใช้คู่มือเมื่อต้องการขั้นตอนโดยละเอียด

โอเวอร์เลย์ใน OBS ว่างเปล่าใช้เซสชันผิดอัปเดตโดยไม่เสียการตั้งค่าOBS ไม่ได้ยินเสียง TTSKokoro ไม่พูดภาษาโปรตุเกสหรือสเปนใช้งานใน Chrome ได้ แต่ในแอปเดสก์ท็อปไม่ได้Event Flow ไม่ทำงาน

โอเวอร์เลย์ใน OBS ว่างเปล่า

ตรวจสอบแผงด็อกก่อน หากแผงด็อกว่าง ให้แก้ปัญหาที่แหล่งข้อมูล/แพลตฟอร์ม หากแผงด็อกทำงานได้ ให้เปิด URL ของโอเวอร์เลย์ที่ใช้อยู่ในเบราว์เซอร์ปกติ แล้วยืนยันว่าใช้ค่าเดียวกันสำหรับ session แล้วรีเฟรชแหล่งข้อมูลเบราว์เซอร์ใน OBS

เปิดคู่มือแก้ปัญหา OBS

ใช้เซสชันผิด

หน้าแหล่งข้อมูล แผงด็อก โอเวอร์เลย์ บอต และ Event Flow ต้องใช้รหัสเซสชันเดียวกัน ให้มองรหัสเซสชันเป็นชื่อห้อง: สะกดต่างกันก็ถือว่าเป็นคนละห้อง

dock.html?session=YOUR_SESSION

เปิดคู่มือเซสชัน รหัสผ่าน และโหมดส่งต่อ

อัปเดตโดยไม่เสียการตั้งค่า

ส่งออกการตั้งค่าก่อน อย่าถอนการติดตั้งส่วนขยายระหว่างการอัปเดตตามปกติ และใช้การย้ายเซสชันทั้งหมดแบบเข้ารหัสของแอปเดสก์ท็อปเมื่อต้องย้ายคุกกี้และข้อมูลการเข้าสู่ระบบด้วย

เปิดคู่มืออัปเดต สำรองข้อมูล และกู้คืนอย่างปลอดภัย

OBS ไม่ได้ยินเสียง TTS

TTS ปกติของระบบมักส่งเสียงผ่านคอมพิวเตอร์ แต่ไม่ผ่านแหล่งข้อมูลเบราว์เซอร์ของ OBS ให้ใช้โหมด TTS จากผู้ให้บริการ/เบราว์เซอร์ เช่น Kokoro, Piper, Kitten, eSpeak, บริการที่เข้ากันได้กับ OpenAI หรือผู้ให้บริการคลาวด์ หรือแยกเส้นทางเสียงของระบบต่างหาก

เปิดคู่มือตั้งค่า TTS

Kokoro ไม่พูดภาษาโปรตุเกสหรือสเปน

เสียง Kokoro ที่มีมาให้เป็นเสียงภาษาอังกฤษ สำหรับภาษาโปรตุเกส ให้ใช้ Piper กับ pipervoice=pt_BR-faber-medium หรือใช้ eSpeak กับ espeakvoice=pt-br สำหรับภาษาสเปน ให้ใช้ Piper กับ pipervoice=es_ES-davefx-medium หรือใช้ eSpeak กับ espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

เปิดการตั้งค่าผู้ให้บริการ TTS

ใช้งานใน Chrome ได้ แต่ในแอปเดสก์ท็อปไม่ได้

แอปเดสก์ท็อปใช้เซสชัน Electron แยกจากโปรไฟล์ Chrome ปกติ ให้ลงชื่อเข้าใช้ในหน้าต่างแหล่งข้อมูลของแอป หรือใช้ส่วนขยาย Chrome เมื่อแพลตฟอร์มบล็อกเบราว์เซอร์แบบฝังหรือเบราว์เซอร์ในแอป

เปิดคู่มือโหมดแอปแบบสแตนด์อโลน

ต้องใช้เซิร์ฟเวอร์ภายในแบบใด?

เปิดเซิร์ฟเวอร์ภายใน (Enable Local Server) คือเซิร์ฟเวอร์ส่งต่อ WebSocket สำหรับหน้า SSN ที่รองรับ API ควบคุมภายในเครื่อง ใช้กับสคริปต์และเครื่องมือ AI บนเครื่องเดียวกัน การโฮสต์แบบ headless เรียกใช้แอปเดสก์ท็อปเต็มรูปแบบบนเซิร์ฟเวอร์ Linux ส่วนเซิร์ฟเวอร์สื่อ Event Flow ให้บริการเฉพาะสื่อภายในเครื่องที่อนุมัติแล้ว

เปิดคำอธิบายเซิร์ฟเวอร์และบริการภายในเครื่อง

TikTok ไม่ทำงานหรือเปลี่ยนโหมด

บันทึกโหมดแอป ผู้ให้บริการลงลายเซ็น ข้อความสถานะ เวอร์ชันแอป และว่าแชตมองเห็นได้ในโหมด Standard หรือไม่ ทดสอบโหมด TikTok ทีละโหมด

เปิดโหมด TikTok ในแอป

แชต YouTube ไม่ปรากฏ

ยืนยันว่าสตรีมกำลังถ่ายทอดสด แชตสดมองเห็นได้ และใช้วิธีเชื่อมต่อ YouTube ถูกต้อง ได้แก่ แชตสด ความคิดเห็นปกติ การเก็บข้อมูลแบบ Standard หรือโหมด WebSocket/API

เปิดคู่มือตั้งค่า YouTube

บอตส่งคำตอบไม่ได้

การอ่านแชตกับการส่งแชตเป็นคนละอย่างกัน ตรวจสอบว่าแพลตฟอร์มรองรับการส่งกลับหรือไม่ รวมถึงการเข้าสู่ระบบบัญชี บทบาทบัญชี โหมดแหล่งข้อมูล การตอบกลับจากผู้ให้บริการ และข้อจำกัดอัตราการใช้งาน

เปิดคู่มือตั้งค่าแชตบอต AI

Event Flow ไม่ทำงาน

ยืนยันว่าอีเวนต์จากแหล่งข้อมูลมาถึงแผงด็อก สำหรับแอ็กชันเสียง สื่อ และ OBS ให้เปิด actions.html?session=YOUR_SESSION โดยใช้เซสชันเดียวกัน

เปิดตัวอย่างการตั้งค่า Event Flow
