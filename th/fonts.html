เครื่องมือตรวจจับฟอนต์ที่ติดตั้ง

แสดงฟอนต์ที่เบราว์เซอร์ใช้ได้ พร้อมตัวอย่างแบบสดและพารามิเตอร์ URL เพื่อใช้ฟอนต์ทั่วทั้งเว็บไซต์

วิธีติดตั้งฟอนต์กำหนดเอง

  • Windows: คลิกขวาที่ไฟล์ .ttf หรือ .otf → เลือก "Install" หรือ "Install for all users" → เริ่มเบราว์เซอร์ใหม่
  • macOS: ดับเบิลคลิกไฟล์ .ttf หรือ .otf → คลิก "Install Font" ใน Font Book → เริ่มเบราว์เซอร์ใหม่
  • Linux: คัดลอกไฟล์ฟอนต์ไปยัง ~/.local/share/fonts/ → เรียกใช้ fc-cache -fv → เริ่มเบราว์เซอร์ใหม่

หลังติดตั้ง ให้รีเฟรชหน้านี้เพื่อดูฟอนต์ใหม่ หากฟอนต์ไม่ปรากฏ ให้ลองปุ่ม "ลองใช้ Local Fonts API" (เฉพาะเบราว์เซอร์ Chromium)

กำลังตรวจจับ…

ใช้ฟอนต์ที่ระบุผ่าน URL

  • พารามิเตอร์: ต่อท้าย ?font=<Font%20Family%20Name> ใน URL ต้องเข้ารหัสช่องว่างและสัญลักษณ์สำหรับ URL
  • ใช้กับตัวแปร CSS: เว็บไซต์ของคุณใช้ --font-family หน้านี้ใช้ค่านี้ด้วย ตัวอย่าง: ?font=Segoe%20UI.
  • ไม่ต้องใส่อัญประกาศ: ไม่ต้องใส่เครื่องหมายอัญประกาศในพารามิเตอร์ เพราะตัวแปร CSS ไม่ต้องใช้
  • เฉพาะที่ติดตั้ง: พารามิเตอร์นี้ใช้ได้กับฟอนต์ที่ติดตั้งในระบบแล้วเท่านั้น ไม่ได้ดาวน์โหลดเว็บฟอนต์

ความเข้ากันได้ (แอป Ninja)

  • VDO.Ninja: ที่สร้างแล้ว ?font= ลิงก์ใช้ได้กับโอเวอร์เลย์/ฉากที่รองรับตัวแปร --font-family นี้
  • SocialStream.Ninja: ใช้ค่าเดียวกันสำหรับ ?font= เพื่อแทนที่ฟอนต์เริ่มต้นในวิดเจ็ตที่รองรับ
  • Caption.Ninja: ใช้ (Apply) ?font= ให้กับโอเวอร์เลย์คำบรรยายที่รองรับตระกูลฟอนต์กำหนดเอง

แอปเหล่านี้ยอมรับการแทนที่ font-family เมื่อรองรับพารามิเตอร์ ?font= ใน URL หรือลิงก์ฝัง เครื่องมือนี้สร้างค่าที่เข้ารหัสอย่างถูกต้องเพื่อใช้ได้ทันที

การแก้ปัญหา (Windows)

  • ชื่อตระกูลที่ตรงกัน: ใช้ชื่อ ตระกูล ของฟอนต์ (ไม่ใช่ชื่อไฟล์) ตรวจสอบที่ Settings → Personalization → Fonts เพื่อดูชื่อตระกูลที่ถูกต้อง
  • ขอบเขตการติดตั้งที่ถูกต้อง: หากคุณติดตั้งฟอนต์ให้ผู้ใช้ Windows คนอื่นหรือผ่านบัญชีผู้ดูแลระบบเท่านั้น เซสชันเบราว์เซอร์ของคุณอาจมองไม่เห็น ติดตั้งแบบ “สำหรับผู้ใช้ทั้งหมด” หากจำเป็น
  • รูปแบบที่รองรับ: เบราว์เซอร์ใช้ TrueType/OpenType/WOFF ฟอนต์ Type 1 แบบเก่าและฟอนต์บิตแมปบางชนิดจะใช้ไม่ได้
  • น้ำหนัก/สไตล์ที่มี: หากติดตั้งเฉพาะ Bold ข้อความ Normal อาจใช้ฟอนต์สำรอง ลองตัวอย่างตัวหนาหรือติดตั้ง Regular เพิ่มด้วย
  • ข้อจำกัดด้านความเป็นส่วนตัว: เบราว์เซอร์ไม่อนุญาตให้แสดงรายการฟอนต์ทั้งหมดโดยไม่ได้รับสิทธิ์ หน้านี้ตรวจจากรายการฟอนต์ที่รู้จักจำนวนมาก และใช้ Local Fonts API ได้หากเลือก
  • Local Fonts API: ใน Chromium บนต้นทางที่ปลอดภัย (https/localhost) การคลิก “ลองใช้ Local Fonts API” สามารถแสดงรายชื่อตระกูลฟอนต์ที่ติดตั้งจริงได้หลังอนุญาต

เคล็ดลับการใช้ด้วยตนเอง

  • บังคับใช้ฟอนต์: ใน CSS ของคุณ: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • ทดสอบชื่อที่ต้องการ: ใช้ช่องค้นหาเพื่อลองชื่อตระกูลใดก็ได้ หากพบ จะปรากฏในผลลัพธ์พร้อมตัวอย่าง
  • การเข้ารหัส: สร้างลิงก์ในลักษณะนี้: ?font=Segoe%20UI (ลิงก์ที่สร้างด้านล่างใช้การเข้ารหัสที่ถูกต้อง)
  • ฟอนต์ CJK และระบบอักษรต่าง ๆ: ตัวอย่างมีอักษรละติน ตัวเลข และสัญลักษณ์ แทนที่ด้วยข้อความของระบบอักษรที่ต้องการเพื่อตรวจสอบการจัดรูปอักษร

หมายเหตุ: หน้านี้ไม่ได้ติดตั้งหรือดาวน์โหลดฟอนต์ แต่ตรวจจับและแสดงตัวอย่างตระกูลฟอนต์ที่เบราว์เซอร์เข้าถึงได้อยู่แล้วเท่านั้น
