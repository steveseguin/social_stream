2 · เชื่อมต่อ

เชื่อมต่อเซสชันของคุณหนึ่งครั้ง

1

คัดลอกรหัส

ใช้ Copy ID ด้านบน หรือคัดลอกจากการตั้งค่าในส่วนขยาย Chrome

2

เพิ่มการตั้งค่า

ในแอป Stream Deck ให้ลากการดำเนินการตั้งค่า Social Stream Ninja ไปยังคีย์

3

วางและทดสอบ

วาง ID ลงในการตั้งค่าและเลือกทดสอบการเชื่อมต่อ ปุ่มจะแสดงออนไลน์เมื่อทำงาน

ให้ SSApp หรือส่วนขยายทำงานต่อไป เมื่อออนไลน์แล้ว ให้เพิ่มปุ่ม Preset Command พวกเขาทั้งหมดแบ่งปันการเชื่อมต่อนี้

ทำอะไรได้บ้าง

ตัวควบคุมที่เหมาะกับขั้นตอนการไลฟ์

แชตและโอเวอร์เลย์แสดงข้อความเด่น ยกเลิกปักหมุด ล้าง และเลื่อนดูข้อความในคิว
ตัวจับเวลาและโพลเริ่ม หยุดชั่วคราว รีเซ็ต ปรับเวลา และจัดการโพลสด
แหล่งข้อมูล SSAppเริ่ม หยุด เริ่มใหม่ ปิดเสียง แสดง และเปลี่ยนโหมดของแหล่งข้อมูลที่รองรับ
เครดิตเริ่ม ดูตัวอย่าง ทดสอบ และรีเซ็ตเครดิตที่รวบรวมไว้ด้วยปุ่มเดียว
Stream Deck +หมุนปุ่มเพื่อปรับตัวจับเวลา และเรียกดูแชตล่าสุดบนแถบสัมผัส

คำสั่งจะปรับให้เข้ากับสิ่งที่ SSApp หรือส่วนขยายของคุณรองรับ การควบคุมแหล่งที่มาจำเป็นต้องมี SSApp หน้าปัดต้องมี Stream Deck +
