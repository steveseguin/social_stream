นโยบายความเป็นส่วนตัวของ Social Stream Ninja

ปรับปรุงล่าสุด: 8 กันยายน 2026

Social Stream Ninja เป็นซอฟต์แวร์โอเพนซอร์สสำหรับเก็บ ส่งต่อ แสดง และทำงานอัตโนมัติกับแชตสดและเหตุการณ์สตรีมที่เกี่ยวข้อง นโยบายนี้ใช้กับส่วนขยายเบราว์เซอร์ Social Stream Ninja หน้าเว็บและโอเวอร์เลย์ Social Stream Ninja ที่ให้บริการบนเซิร์ฟเวอร์ แอปเดสก์ท็อปแบบแยกที่มักเรียกว่า SSAPP และปลั๊กอิน Social Stream Ninja แบบเนทีฟสำหรับ Elgato Stream Deck

1. ขอบเขตและแนวทางทั่วไป

Social Stream Ninja ไม่กำหนดให้มีบัญชีผู้ใช้ส่วนกลางเพื่อใช้ซอฟต์แวร์หลัก อย่างไรก็ตาม ซอฟต์แวร์อาจเข้าถึง ประมวลผล จัดเก็บ และส่งข้อมูลที่อาจถือเป็นข้อมูลส่วนบุคคลตามกฎหมายบางฉบับ ทั้งนี้ขึ้นอยู่กับการตั้งค่าของคุณ

ในหลายกรณี ซอฟต์แวร์ทำงานภายในอุปกรณ์และอยู่ภายใต้การควบคุมของคุณ อย่างไรก็ตาม บางฟีเจอร์ใช้แพลตฟอร์มของบุคคลที่สาม ปลายทางที่ผู้ใช้กำหนด หรือบริการช่วยเหลือบนเซิร์ฟเวอร์ และบริการเหล่านั้นอาจได้รับข้อมูลที่จำเป็นต่อการทำงานของฟีเจอร์ที่ร้องขอ

2. ข้อมูลที่ซอฟต์แวร์อาจประมวลผล

Social Stream Ninja อาจประมวลผลข้อมูลประเภทต่อไปนี้ โดยขึ้นอยู่กับฟีเจอร์ที่คุณเปิดใช้:

  • ข้อมูลยืนยันตัวตน: โทเคนเข้าถึง OAuth โทเคนต่ออายุ คีย์ API รหัสไคลเอนต์ ความลับของไคลเอนต์ ข้อมูลรับรองช่องหรือห้อง โทเคนเซสชัน รหัสผ่าน และข้อมูลอนุญาตที่คล้ายกันซึ่งผู้ใช้ป้อนหรือบริการที่เชื่อมต่อมอบให้
  • การสื่อสารส่วนบุคคล: ข้อความแชต การตอบกลับ คำสั่งแชต การดำเนินการดูแลแชต ข้อความสมาชิก ข้อความบริจาค ข้อความสนับสนุน และการสื่อสารอื่นที่ผู้ใช้ส่งเข้ามาจากแพลตฟอร์มที่เชื่อมต่อ
  • ประวัติการท่องเว็บและบริบทของหน้า: URL ของหน้าที่รองรับ ข้อมูลแท็บ ชื่อช่อง ชื่อผู้ใช้ รหัสวิดีโอ รหัสห้อง ตัวระบุสตรีม และบริบทของหน้าที่เกี่ยวข้องซึ่งจำเป็นต่อการเชื่อมต่อหรือเฝ้าดูแหล่งข้อมูล
  • เนื้อหาเว็บไซต์: เนื้อหา DOM ของแชต เนื้อหาข้อความ เนื้อหาเหตุการณ์ เมทาดาทาของสตรีม จำนวนผู้ชม ป้าย อีโมต รูปโปรไฟล์ และเนื้อหาอื่นที่มีอยู่ในหน้าหรือ API ที่รองรับ
  • ข้อมูลที่ระบุตัวบุคคลได้และข้อมูลโปรไฟล์: ชื่อผู้ใช้ ชื่อที่แสดง อวาตาร์ รหัสบัญชีหรือช่อง ป้าย สีชื่อ สถานะสมาชิก ป้ายผู้ติดตาม/สมาชิก และเมทาดาทาโปรไฟล์ที่คล้ายกัน
  • การตั้งค่าและข้อมูลแอปในเครื่อง: การตั้งค่า แหล่งข้อมูลที่เชื่อมต่อ คำสั่งกำหนดเอง รายการบล็อก รายการอนุญาต แคชในเครื่อง ข้อมูลตัวอ้างอิงไฟล์ และข้อมูลอื่นที่จำเป็นเพื่อให้ซอฟต์แวร์ทำงานบนอุปกรณ์ของคุณต่อไป
  • ข้อมูลสื่อและไฟล์แบบเลือกใช้ได้: หากคุณเปิดฟีเจอร์เสริมสำหรับการจับภาพ การส่งออก แถบข้อความเลื่อน การบันทึก หรือไฟล์ ซอฟต์แวร์อาจประมวลผลไฟล์ในเครื่องที่เลือก ไฟล์ที่ส่งออก ข้อมูลที่จับจากแท็บ/สื่อ หรือข้อมูลสำรองที่ผู้ใช้สร้าง

3. วิธีใช้ข้อมูล

Social Stream Ninja อาจใช้ข้อมูลนั้นเพื่อ:

  • เชื่อมต่อกับแหล่งแชต เหตุการณ์ และสตรีมที่รองรับ
  • แสดงข้อความแชต โอเวอร์เลย์ แดชบอร์ด การแจ้งเตือน รายการรอ โพล กระดานคะแนน และส่วนติดต่อที่เกี่ยวข้อง
  • ทำงานด้านการดูแลแชต การกรอง ระบบอัตโนมัติ การส่งต่อ บอต TTS, AI, การแปล หรือการส่งออกที่ผู้ใช้เปิดใช้
  • ยืนยันตัวตนกับแพลตฟอร์มของบุคคลที่สามและรักษาเซสชันของแหล่งข้อมูล
  • แคชผลการค้นข้อมูลและรักษาสถานะของแอปในเครื่อง เพื่อให้ซอฟต์แวร์ทำงานต่อเนื่องระหว่างเซสชัน
  • ส่งข้อมูลไปยังปลายทางที่ผู้ใช้ตั้งค่าไว้อย่างชัดเจน เช่น เว็บฮุก ไฟล์ในเครื่อง เอนด์พอยต์ websocket ในเครื่อง บอตของบุคคลที่สาม หรือบริการอื่น

4. พื้นที่จัดเก็บในเครื่องและบนอุปกรณ์

Social Stream Ninja จัดเก็บข้อมูลการทำงานจำนวนมากไว้ภายในอุปกรณ์ของผู้ใช้ โดยอาจใช้พื้นที่จัดเก็บของเบราว์เซอร์ localStorage, sessionStorage, IndexedDB, พื้นที่จัดเก็บของส่วนขยาย พื้นที่จัดเก็บของแอป Electron และไฟล์เสริมที่ผู้ใช้เลือก ทั้งนี้ขึ้นอยู่กับส่วนที่ใช้งาน

ข้อมูลในเครื่องนี้อาจรวมถึงการตั้งค่า รายละเอียดแหล่งข้อมูลที่เชื่อมต่อ แคชผลการค้นช่องหรือโปรไฟล์ ประวัติข้อความหากผู้ใช้เปิดใช้ และข้อมูลยืนยันตัวตน/เซสชันที่จำเป็นสำหรับฟีเจอร์ที่เปิดใช้

แอปเดสก์ท็อปแบบแยกอาจเก็บข้อมูลสำรองเพื่อกู้คืนการตั้งค่าและพื้นที่จัดเก็บของแหล่งข้อมูลไว้ในอุปกรณ์ด้วย ข้อมูลสำรองในเครื่องเหล่านั้นอาจมีโทเคน OAuth หรือสถานะเซสชันอื่น เพื่อให้แอปกู้คืนเซสชันที่เคยทำงานได้หลังรีสตาร์ตหรือเกิดข้อขัดข้อง

ปลั๊กอิน Stream Deck เก็บรหัสเซสชัน Social Stream Ninja และการตั้งค่าการเชื่อมต่อไว้ในการตั้งค่าปลั๊กอินภายในเครื่องของ Stream Deck การลบปลั๊กอินหรือล้างการตั้งค่าจะลบการกำหนดค่าปลั๊กอินนั้นออกจาก Stream Deck

5. กรณีที่ข้อมูลอาจออกจากอุปกรณ์ของคุณ

ข้อมูลอาจส่งออกจากอุปกรณ์ในกรณีต่อไปนี้ โดยขึ้นอยู่กับวิธีที่คุณใช้ซอฟต์แวร์:

เราไม่ขายข้อมูลผู้ใช้

Social Stream Ninja ไม่ได้ออกแบบมาเพื่อโอนข้อมูลผู้ใช้นอกเหนือจากการรับส่งที่อธิบายในนโยบายนี้ ซึ่งอาจเกิดขึ้นเมื่อคุณใช้แพลตฟอร์มที่เชื่อมต่อ ฟีเจอร์ที่ผู้ใช้เปิด ปลายทางที่ผู้ใช้กำหนด ผู้ให้บริการหรือบริการช่วยเหลือที่จำเป็น หรือเมื่อมีหน้าที่ด้านความปลอดภัยหรือกฎหมายกำหนด

  • แพลตฟอร์มและ API ที่เชื่อมต่อ: เมื่อคุณเชื่อมต่อ YouTube, Twitch, Kick, Facebook, Discord หรือบริการอื่นที่รองรับ ซอฟต์แวร์จะส่งคำขอไปยังแพลตฟอร์มเหล่านั้น และอาจรับหรือส่งข้อมูลแชต เหตุการณ์ โปรไฟล์ และข้อมูลเกี่ยวกับการยืนยันตัวตน
  • บริการช่วยเหลือบนเซิร์ฟเวอร์: บางฟีเจอร์ใช้เอนด์พอยต์ช่วยเหลือหรือหน้าเว็บบนเซิร์ฟเวอร์สำหรับการยืนยันตัวตน การค้นข้อมูล การรับส่ง แชต หรือทรัพยากรสำรอง ตัวอย่างในรุ่นปัจจุบัน ได้แก่ โดเมนของ Social Stream Ninja หรือโดเมนช่วยเหลือที่เกี่ยวข้องซึ่งใช้สำหรับแลกเปลี่ยนข้อมูลยืนยันตัวตน ค้นข้อมูล หรือให้บริการหน้าเว็บ
  • ตัวควบคุม Stream Deck: ปลั๊กอิน Stream Deck ส่งรหัสเซสชันที่ตั้งค่าไว้และข้อมูลคำสั่งที่ร้องขอไปยังเอนด์พอยต์ websocket หรือ HTTP ของ Social Stream Ninja ที่ผู้ใช้เลือก เมื่อเปิด HTTP สำรอง ข้อมูลคำสั่งอาจถูกเข้ารหัสไว้ใน URL ของคำขอ
  • ปลายทางที่ผู้ใช้กำหนด: หากคุณเปิดเว็บฮุก ตัวส่งต่อ บอต ผู้ให้บริการ AI ผู้ให้บริการ TTS เครื่องมือสตรีมเมอร์ เซิร์ฟเวอร์ websocket หรือการเชื่อมต่ออื่น ซอฟต์แวร์อาจส่งต่อเนื้อหาข้อความ ชื่อผู้ใช้ อวาตาร์ เพย์โหลดเหตุการณ์ และเมทาดาทาที่เกี่ยวข้องไปยังปลายทางเหล่านั้น
  • บริการเพียร์หรือบริการรับส่งข้อมูล: หากคุณใช้ VDO.Ninja, WebRTC, ตัวส่งต่อ TURN, บริดจ์ iframe ที่ซ่อนอยู่ หรือช่องทางรับส่งที่ใช้ websocket ข้อมูลอาจผ่านระบบเหล่านั้น ช่องทาง websocket แบบเลือกใช้ได้อาจไม่มีการเข้ารหัสตั้งแต่ต้นทางถึงปลายทาง

6. YouTube และฟีเจอร์อื่นที่ใช้ OAuth

การใช้อย่างจำกัด (Limited Use): การใช้ข้อมูลที่ได้รับจาก Google APIs ของ Social Stream Ninja เป็นไปตาม นโยบายข้อมูลผู้ใช้ของ Chrome Web Store รวมถึงข้อกำหนด Limited Use.

เมื่อคุณใช้ YouTube API Services หรือการเชื่อมต่ออื่นที่ใช้ OAuth, Social Stream Ninja อาจขอโทเคนอนุญาตและสิทธิ์เข้าถึงบัญชีที่เกี่ยวข้องซึ่งจำเป็นต่อฟีเจอร์ที่คุณเลือกใช้

  • YouTube: ซอฟต์แวร์อาจเข้าถึงข้อความแชตสด YouTube เมทาดาทาของข้อความ ข้อมูลช่อง ข้อมูลอวาตาร์ สถานะสตรีม เอนด์พอยต์การดูแลแชต และสถิติผู้ชมหรือผู้ติดตาม ทั้งนี้ขึ้นอยู่กับฟีเจอร์ YouTube ที่คุณเปิดใช้
  • บริการช่วยยืนยันตัวตนบนเซิร์ฟเวอร์: ในบางรุ่นและบางโหมด การแลกเปลี่ยนรหัส OAuth หรือการต่ออายุโทเคนอาจทำผ่านบริการช่วยเหลือบนเซิร์ฟเวอร์ แทนที่จะทำทั้งหมดบนอุปกรณ์ หากใช้โหมดนั้น รหัสยืนยันตัวตน โทเคนต่ออายุ และข้อมูลคำขอโทเคนที่เกี่ยวข้องอาจผ่านบริการช่วยเหลือนั้นเพื่อดำเนินการลงชื่อเข้าใช้ให้เสร็จ
  • การเก็บโทเคนในเครื่อง: โทเคนอาจจัดเก็บไว้ในอุปกรณ์ของผู้ใช้ และอาจส่งไปยังบริการช่วยเหลือด้วย หากต้องแลกเปลี่ยนหรือต่ออายุโทเคนจากระยะไกล ทั้งนี้ขึ้นอยู่กับฟีเจอร์และขั้นตอนการลงชื่อเข้าใช้
  • นโยบายของ Google: การใช้ฟีเจอร์ YouTube ของคุณยังอยู่ภายใต้ นโยบายความเป็นส่วนตัวของ Google คุณสามารถเพิกถอนสิทธิ์เข้าถึงของ Google ได้ในการตั้งค่าสิทธิ์ของบัญชี Google

7. การรายงานข้อผิดพลาดของแอปเดสก์ท็อป

แอปเดสก์ท็อปแบบแยกมีฟีเจอร์รายงานข้อผิดพลาดแบบเลือกใช้ได้ ซึ่งจะปิดอยู่จนกว่าผู้ใช้จะเปิด

  • หากเปิดใช้ แอปเดสก์ท็อปอาจส่งข้อความข้อผิดพลาด สแต็กเทรซ รุ่นแอป รหัสการติดตั้งแบบสุ่ม บริบท และการตั้งค่าที่ผ่านการกรองข้อมูลแล้วไปยังเอนด์พอยต์รายงานข้อผิดพลาดของผู้พัฒนา
  • ณ เวลาที่เขียนนี้ คำชี้แจงในแอปเดสก์ท็อประบุว่ารายงานเหล่านั้นไม่รวมโทเคน OAuth ข้อมูลเซสชัน และข้อมูลรับรองในข้อมูลสำรอง
  • ณ เวลาที่เขียนนี้ คำชี้แจงในแอปเดสก์ท็อประบุว่ารายงานเหล่านี้ส่งผ่านเอนด์พอยต์ Cloudflare Worker และเก็บไว้ 30 วัน ผู้ใช้ควรอ่านคำชี้แจงปัจจุบันในแอปก่อนเปิดฟีเจอร์นี้

8. บริการของบุคคลที่สามและการเชื่อมต่อที่ผู้ใช้กำหนด

Social Stream Ninja สามารถทำงานร่วมกับแพลตฟอร์มของบุคคลที่สามและบริการที่ผู้ใช้เลือกได้หลากหลาย นโยบายความเป็นส่วนตัว ข้อกำหนด การควบคุมความปลอดภัย และแนวปฏิบัติการเก็บรักษาข้อมูลของบริการเหล่านั้นแยกจากนโยบายนี้ และอาจแตกต่างกันอย่างมีนัยสำคัญ

หากคุณตั้งค่าซอฟต์แวร์ให้ส่งข้อมูลไปยังบริการของบุคคลที่สาม คุณมีหน้าที่ตรวจสอบบริการเหล่านั้นและตัดสินใจว่าคุณได้รับอนุญาตให้ส่งข้อมูลดังกล่าวไปที่นั่นหรือไม่

9. การเก็บรักษา การลบ และการควบคุมข้อมูลโดยผู้ใช้

เนื่องจาก Social Stream Ninja ทำงานในเครื่องเป็นส่วนใหญ่ ระยะเวลาเก็บรักษาจึงมักขึ้นอยู่กับอุปกรณ์และการตั้งค่าของผู้ใช้

  • การตั้งค่าในเครื่อง แคช โทเคน และข้อมูลสำรองอาจอยู่บนอุปกรณ์จนกว่าผู้ใช้จะล้างพื้นที่จัดเก็บ ลบแหล่งข้อมูล รีเซ็ตแอป ลบไฟล์ที่ส่งออก เพิกถอนโทเคน หรือถอนการติดตั้งซอฟต์แวร์
  • ปลายทางของบุคคลที่สามที่ผู้ใช้กำหนดอาจเก็บสำเนาข้อมูลที่ส่งต่อตามนโยบายของตนเอง
  • บริการช่วยเหลือบนเซิร์ฟเวอร์หรือ API อาจบันทึกหรือเก็บข้อมูลทางเทคนิคของคำขอตามแนวปฏิบัติของตนเอง นโยบายนี้ไม่รับประกันระยะเวลาเก็บรักษาที่เฉพาะเจาะจงสำหรับบริการของบุคคลที่สาม

10. ความปลอดภัยและความเสี่ยง

  • ไม่มีการรับประกันความปลอดภัยอย่างสมบูรณ์: ไม่มีซอฟต์แวร์หรือบริการเครือข่ายใดปลอดภัยอย่างสมบูรณ์ คุณใช้ Social Stream Ninja โดยยอมรับความเสี่ยงเอง
  • ข้อมูลรับรองเซสชันและแหล่งข้อมูล: หากผู้อื่นทราบรหัสสตรีม รหัสห้อง โทเคน รหัสผ่าน หรือลิงก์ส่งต่อข้อมูล บุคคลเหล่านั้นอาจดูหรือแทรกข้อมูลได้ ขึ้นอยู่กับการตั้งค่าของคุณ
  • ความเสี่ยงในการรับส่งข้อมูล: การรับส่งข้อมูลผ่าน WebRTC, TURN, websocket, webhook, ตัวส่งต่อ และ API ของบุคคลที่สามอาจเปิดเผยข้อมูลต่อบริการที่จำเป็นในการรับส่งข้อมูลนั้น

11. ความรับผิดชอบของผู้ใช้

ผู้ใช้เป็นผู้ตัดสินใจว่าจะเชื่อมต่อเว็บไซต์ บัญชี แชต และบริการใดกับ Social Stream Ninja จะเก็บข้อมูลใด จะแสดงโอเวอร์เลย์ใด จะบันทึกไฟล์ใด และจะส่งต่อข้อมูลไปยังบริการภายนอกใด

  • คุณมีหน้าที่ตรวจสอบว่าคุณมีสิทธิและฐานทางกฎหมายในการเก็บ ประมวลผล แสดง จัดเก็บ ส่งออก หรือส่งต่อข้อมูลใด ๆ ที่คุณจัดการด้วยซอฟต์แวร์นี้
  • คุณมีหน้าที่ปฏิบัติตามข้อกำหนดการให้บริการ ข้อกำหนดความเป็นส่วนตัว และกฎหมายท้องถิ่นที่ใช้กับบริการและบุคคลซึ่งคุณประมวลผลข้อมูล
  • คุณควรปฏิบัติต่อโทเคน รหัสผ่าน รหัสห้อง รหัสสตรีม และข้อมูลที่ส่งออกในฐานะข้อมูลอ่อนไหว

12. การชดใช้ค่าเสียหายและการไม่รับประกัน

Social Stream Ninja ให้บริการ "ตามสภาพ" และ "ตามที่มีให้ใช้" โดยไม่มีการรับประกันใด ๆ ไม่ว่าโดยชัดแจ้งหรือโดยนัย รวมถึงการรับประกันโดยนัยด้านความเหมาะสมในการจำหน่าย ความเหมาะสมสำหรับวัตถุประสงค์เฉพาะ และการไม่ละเมิดสิทธิ

เมื่อใช้ซอฟต์แวร์ คุณตกลงว่าผู้พัฒนา ผู้มีส่วนร่วม และผู้ให้บริการไม่ต้องรับผิดชอบต่อข้อเรียกร้อง ความเสียหาย ความรับผิด หรือความสูญเสียที่เกิดจากการตั้งค่าหรือการใช้ซอฟต์แวร์ของคุณ รวมถึงข้อเรียกร้องเกี่ยวกับเนื้อหาของบุคคลที่สาม การเก็บข้อมูล การส่งต่อข้อมูล หรือการปฏิบัติตามกฎหมาย

13. การเปลี่ยนแปลงนโยบายนี้

นโยบายความเป็นส่วนตัวนี้อาจมีการปรับปรุงเป็นครั้งคราว การใช้ซอฟต์แวร์ต่อหลังเปลี่ยนแปลงนโยบายหมายความว่าคุณยอมรับนโยบายฉบับแก้ไข
