选择正确的起始页

先使用 sampleoverlay.html 获取观众聊天列表，或复制在 叠加层图库。使用 dock.html 当你需要Dock的显示和交互功能时。 chat-overlay.html 重定向到保存的AI叠加输出；它不是这个示例聊天渲染器。

下载并保存文件结构

  1. 下载源ZIP 并提取它。这些指南使用测试版源；将一次下载的文件放在一起。
  2. 复制 sampleoverlay.html 为 my-chat.html 原文旁边。如果选择不同的页面或主题，请将其副本保留在该文件的原始文件夹中。
  3. 在编辑器或 AI 工具中打开复制的 HTML 及其引用的 CSS/JS。将提供的图稿/字体添加到同一项目并使用相对路径。从 CSS 覆盖开始；更改生成的标记时包括渲染器。

  1. 将编辑后的 HTML 文件拖到 Chrome 或 Edge 中。从地址栏复制其地址；它开始于 file:///.
  2. 复制所有内容 ? 继续在您的工作 SSN 覆盖链接中并将其添加到该文件地址的末尾。保留所有设置，包括会话、密码和任何 # 结局。

哪里需要改变设计

更改卡片背景、名称排版、填充、头像、徽章和进入/退出动作。在示例中，请遵循 addMessageToOverlay 查看行的创建位置；在主题中，检查其自己的选择器。保留删除、排序、限制和时间安排。聊天是一系列单独的行，因此请测试快速到达以及一张有吸引力的卡片。

保持 chatmessage HTML 模式通过现有的消毒剂表达情感。名称和普通标签是普通字段； textonly 仅适用于消息正文。渲染 contentimg 即使身体是空的。如果设计整个 Dock 的样式，请使用其显示选项，以便所选受众视图不会显示不需要的控件。

测试此覆盖类型

首先使用预览或测试设置。的 测试消息指南 解释了如何通过SSN发送虚构的有效负载；提交到生产会话的测试可以触发其现有的自动化。

  1. 发送多个不同名称和平台的测试聊天行；当达到限制时，检查堆放、包装和移除。
  2. 发送一条包含<b>文字括号</b>的纯文本消息，然后发送一条 HTML 模式表情消息。第一个必须显示文字标记；第二个应该保留允许的表情。
  3. 尝试仅包含内容的消息、长名称、缺少头像、捐赠标签以及通过 Dock 进行删除。检查窄幅和全角源。

同时运行 输入渲染检查 针对您更改的渲染路径。保存编辑后，在排练之间刷新 OBS 浏览器源并重复可见的交互。浏览器预览不会建立实时捕获或 OBS 行为。
