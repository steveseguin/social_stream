01

让 OBS 进行第一次设置

  1. 安装 OBS Studio 并打开它。
  2. 选择 工具 → 自动配置向导.
  3. 选择流式传输或录制，按照提示操作，然后应用设置。

当您的计算机请求时允许访问摄像头、麦克风和屏幕捕获。

选择后，屏幕截图会以全尺寸打开。标签可能因 OBS 版本而略有不同。

缺少编码器或计算机过载？

检查硬件支持并更新您的图形驱动程序。 OBS 仍然需要 GPU 能力来绘制场景；如果落后，则限制游戏 FPS 或降低输出 FPS。

如果您的 Mac 硬件编码器无法提供 CBR，请使用 x264。 编码器兼容性.

06

让你的声音更容易被听到

  1. 选择您的麦克风 设置 → 音频.
  2. 正常说话。瞄准周围的山峰 −12 至 −6 dBFS；避免达到 0。
  3. 降低游戏、音乐和警报滑块，直到语音清晰为止。

每个声音捕捉一次。 对整个输出设备使用桌面音频，或单独的应用程序捕获。捕获两者可以使声音加倍。

应用程序音频、macOS 和麦克风过滤器

Windows：使用 应用程序音频捕获.在 macOS 13+ 上，使用 OBS 的 macOS 音频/屏幕截图.

麦克风 → 滤镜：尝试轻噪声抑制，然后是压缩器和限制器。一次添加一个并聆听。

08

添加聊天或提醒叠加

  1. 从 Social Stream Ninja 复制覆盖 URL。
  2. 选择 来源 → + → 浏览器 并粘贴它。保留其会话和密码选项。
  3. 设置叠加大小；使用 1920 × 1080 用于全画幅风景叠加。
  4. 对于 TTS 或警报，启用 通过 OBS 控制音频.

将其放在游戏或相机上方。发送测试消息；如果使用特色消息覆盖，请在 SSN 底座中选择一个。

空白叠加或重复音频？

检查会话是否与您的聊天来源匹配。刷新浏览器源。仅保留一份播放 TTS 的副本。

对于持续聊天，请首先关闭自动关闭和场景激活刷新。 SSN 叠加设置 · TTS 设置.

09

记录一分钟。然后去直播吧。

  1. 选择录音文件夹 设置 → 输出.
  2. 新闻 开始录制（Start Recording）。说话、播放声音和切换场景。
  3. 停下来观看文件。检查音量、取景和口型同步。
  4. 设置平台的标题和可见性，然后 开始直播（Start Streaming）。检查其预览和流健康状况；有些平台还需要 上线.

开始直播可以让您公开直播。 如果可以的话，使用私人测试。完成后，停止直播并确认平台活动已结束。

录音格式和独立音轨

MKV 可以容忍中断的录制。使用 文件 → Remux 录音 随后为 MP4。当前的 OBS 还提供弹性混合 MP4/MOV。

对于单独的编辑轨道，请在轨道 1 上保留完整的混音，然后将麦克风/游戏分配给高级音频属性中的其他轨道，并在“录制”下启用它们。
