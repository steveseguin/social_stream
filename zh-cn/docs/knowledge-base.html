知识库

常见问题的简短解答。需要完整操作步骤时，请查看指南。

OBS 叠加层为空白

先检查停靠面板。如果停靠面板为空，请修复来源/平台。如果停靠面板正常，请在普通浏览器中打开完全相同的叠加层 URL，确认使用相同的 session，然后刷新 OBS 浏览器源。

打开 OBS 故障排除

会话错误

来源、停靠面板、叠加层、机器人和 Event Flow 页面必须使用相同会话 ID。可将会话 ID 当作房间名称：拼写不同，就属于不同房间。

dock.html?session=YOUR_SESSION

打开会话、密码与中继模式

更新时保留设置

先导出设置，常规更新时不要卸载扩展；如果还需迁移 Cookie 和登录状态，请使用桌面应用的加密完整会话传输。

打开安全更新、备份与恢复

OBS 听不到 TTS

普通系统 TTS 往往通过电脑发声，而不经过 OBS 浏览器源。可使用提供商/浏览器 TTS 模式，例如 Kokoro、Piper、Kitten、eSpeak、兼容 OpenAI 的服务或云端提供商，也可单独路由系统音频。

打开 TTS 设置指南

Kokoro 无法说葡萄牙语或西班牙语

内置 Kokoro 声音是英语声音。葡萄牙语请使用 Piper 并设置 pipervoice=pt_BR-faber-medium，或使用 eSpeak 并设置 espeakvoice=pt-br。西班牙语请使用 Piper 并设置 pipervoice=es_ES-davefx-medium，或使用 eSpeak 并设置 espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

打开 TTS 提供商配置

Chrome 正常，但桌面应用不正常

桌面应用使用 Electron 会话，不使用常规 Chrome 配置。请在应用的来源窗口内登录；当平台阻止内嵌/应用浏览器环境时，改用 Chrome 扩展方式。

打开独立应用模式

我需要哪种本地服务器？

启用本地服务器 是供受支持 SSN 页面使用的 WebSocket 中继。 本地控制 API 供同机脚本和 AI 工具使用。无头托管是在 Linux 服务器上运行完整桌面应用。Event Flow 媒体服务器仅提供获准的本地媒体。

打开本地服务器和服务说明

TikTok 失败或切换模式

记录应用模式、签名提供商、状态文本、应用版本，以及标准模式下聊天是否可见。每次只测试一种 TikTok 模式。

打开 TikTok 应用模式

没有 YouTube 聊天

确认正在直播、实时聊天可见，并使用正确的 YouTube 路径：实时聊天、静态评论、标准捕获或 WebSocket/API 模式。

打开 YouTube 设置指南

机器人回复无法发送

读取聊天与发布聊天并不相同。请检查平台回发支持、账号登录、账号角色、来源模式、提供商响应和频率限制。

打开 AI 聊天机器人设置指南

Event Flow 没有反应

确认来源事件已到达停靠面板。对于音频、媒体和 OBS 操作，请保持 actions.html?session=YOUR_SESSION 使用相同会话保持打开。

打开 Event Flow 实用示例
