TikTok 无法连接？试试 TikFinity。

在 Social Stream Ninja 中使用 TikFinity Activity Feed 作为备用聊天来源。

何时使用

如果 SSN 的直接 TikTok 模式持续失败或遗漏消息，TikFinity 提供另一种接收 LIVE 聊天的方式。当 TikTok 阻止或限制来自您网络的连接时，它可能有帮助，前提是 TikFinity 仍能连接该直播。

此连接接收聊天和支持的活动，不会发送 TikTok 回复。使用 TikFinity 的以下功能不需要 OBS： OBS 停靠面板（OBS Dock） 作为 SSN 来源。

  • TikFinity 账号： 登录 TikFinity，或在提示时创建免费账号。现有浏览器会话可能已经登录。
  • TikTok 账号： 此只读设置使用用户名，不需要登录该 TikTok 账号。我们使用另一个公开 LIVE 账号进行了测试。所选账号必须正在直播，且 TikFinity 能够访问。
  • 保持 TikFinity 运行： 整个直播期间，让一个主 TikFinity 仪表板标签页保持打开并连接。

SSApp：直接连接 TikFinity 桌面（测试版）

SSApp 0.4.32 之后的开发版本还提供 TikFinity 桌面版（本地 API，测试版） 在现有的 TikTok 连接下拉列表中。如果缺少该选项，请使用下面的活动源说明。

  1. 运行 TikFinity 桌面版 与 SSApp 在同一台计算机上。登录 TikFinity 并在那里连接您的直播。
  2. 检查 TikFinity 的 事件API. SSApp 自动连接到其本地端点；不需要 API 密钥或停靠 URL。
  3. 停止你现有的SSApp TikTok捕获，选择 TikFinity 桌面版（本地 API，测试版），并激活它。
  4. 等待 从 TikFinity 桌面接收 LIVE 事件 并在SSN坞中查看新消息。将鼠标悬停在连接状态上可获取最近的活动信息。

这会捕获 TikFinity 中选择的流，无论 SSApp 中输入的用户名如何。它是只读的。该流仅使用一个捕获源以避免重复。本地API可以提供点赞和观看次数以及聊天和礼物； SSN 现有的事件过滤器仍然适用。

连接 TikFinity 桌面 仅确认本地连接。如果 LIVE 活动停止，请检查 TikFinity 的仪表板和选定的流。当Desktop关闭其本地连接时SSApp重新连接；它无法修复 TikFinity 的上游连接。

1. 在 TikFinity 中输入 TikTok 用户名

  1. 打开 TikFinity 设置。如果已有打开的 TikFinity 仪表板，请使用其 设置 导航，而不是另开标签页。登录 TikFinity 如果出现提示。
  2. 位于 连接 TikTok 账号（Connect TikTok Account），输入想捕获的公开 LIVE 的 TikTok 用户名。使用账号用户名，而不是显示名称。
  3. 用户名设置自动保存，此步骤没有单独的 Save 按钮。等待 TikFinity 连接，并确认有新活动到达。
使用一个仪表板标签页： 在同一 TikFinity 标签页中切换 Setup 和 OBS Docks。如果打开另一个仪表板会中断第一个，请保留最新连接的标签页，关闭多余的仪表板标签页。保持单独的 SSN 捕获来源运行。

2. 选择 Activity Feed 显示的内容

  1. 在同一个 TikFinity 标签页中，前往 Overlays → OBS Docks，或打开 TikFinity OBS Docks.
  2. 选择 停靠面板 1（Dock 1） 或 停靠面板 2（Dock 2）。打开其齿轮/设置按钮。
  3. 检查 显示聊天（Show Chat） 并勾选它及想查看的每个活动类别：关注、分享、礼物、订阅、宝箱和加入。
  4. 点击 保存 在停靠面板设置中。此 Save 按钮与自动保存的用户名设置是分开的。
  5. 复制该停靠面板 URL。使用您自己的 TikFinity 页面提供的 URL。

在新的 TikFinity 仪表板，复制活动源的浏览器源 URL，如下所示 https://widgets.tikfinity.com/YOUR_TOKEN.将此令牌保密。较旧的网址，例如 https://tikfinity.zerody.one/widget/activity-feed?cid=YOUR_ID&did=1 也得到支持。保留完整复制的 URL。请勿将设置或 OBS Docks 配置页粘贴到 SSN 中。

这些复选框控制 TikFinity 组件显示的内容。SSN 也有自己的事件筛选器；在这里启用某个类别不会覆盖 SSN 筛选器。

停靠面板显示偏好分别保存在每个浏览器中。如果 SSApp 捕获页面显示的类别与 Chrome 预览不同，请打开该捕获页面中的齿轮按钮，也为它选择类别。

3. 将停靠面板 URL 添加到 Social Stream Ninja

  1. 在 SSApp 中，打开 来源与设置 并选择 添加其他来源（Add other source） （称为 其他聊天网站 在旧版本中）。
  2. 粘贴完整的 TikFinity Activity Feed URL，添加来源并启用它。SSApp 会自动检测 TikFinity。
  3. 停止任何正在捕获同一 LIVE 的直接 TikTok 来源，以免消息到达两次。
  4. 让 TikFinity 仪表板和 SSApp 捕获来源都保持运行。

您可以在以下选项旁再次找到本指南： TikTok 连接 选项，位于 SSApp TikTok 来源配置中。

4. 在 SSN 中检查新消息

  1. 打开 SSN 聊天停靠面板，等待一条 新 TikTok 消息。不要将 TikFinity 中仍可见的旧消息用作捕获测试。
  2. 确认新消息在 TikFinity 和 SSN 中各出现一次，且名称和文本正确。
  3. 关注、分享或礼物发生时观察它。在 SSN 设置中，启用 捕获“joined”直播事件 如果需要加入通知，并检查打赏/事件筛选器是否允许所需活动。
  4. 保持运行几分钟，检查后续消息是否继续到达。
  5. 在 OBS 中使用常规 SSN 叠加层 URL，并使用相同 SSN 会话。请参阅 OBS 快速入门 （如有需要）。

SSN 将这些消息视为 TikTok 用于来源筛选器和现有叠加层。支持的活动包括聊天、礼物和礼物连送、关注、分享、订阅、加入和宝箱。Activity Feed 不显示点赞或观众数量。

内置 TikTok 表情代码，例如 [laughcry] 和 [wow] 在更新后的 SSN 来源中会渲染为图像。纯文本模式会有意保留文本；更改该设置后，请重新加载 TikFinity 来源。

如果有内容缺失

  • 只出现 TikFinity 标志： 检查所选 TikTok 账号是否正在直播，以及 TikFinity 主仪表板是否已连接。仅打开组件不会建立上游 TikTok 连接。
  • TikFinity 有旧消息，但 SSN 是空的： 等待新活动，确认完整的停靠面板 URL，并重新加载 SSN 来源。如果组件本身停止接收新消息，请先重新连接 TikFinity。
  • Dock 2 中没有聊天： 打开齿轮按钮，启用 Show Chat，然后 Save。
  • 礼物、加入或其他事件缺失： 检查停靠面板类别和 SSN 自身的事件/打赏筛选器。事件实际发生前，无法验证该类别。
  • 另一个 TikFinity 页面中断连接： 保持一个主仪表板标签页打开。使用其导航切换区段；Activity Feed 捕获窗口是单独的。
  • 所有内容都出现两次： 该 LIVE 只保留一个捕获来源。内容相同但 TikTok 消息 ID 不同的重复消息，也可能是真实的独立消息。
  • 回复不起作用： TikFinity 捕获为只读。请参阅 直接 TikTok 连接选项 了解回复支持。
