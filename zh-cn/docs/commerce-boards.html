名额看板与近期销售

追踪可用名额，并将近期购买记录保留在屏幕上。在 SSN 中控制，在 OBS 中展示。

揭晓名额 ↓球队看板 ↓近期销售 ↓Whatnot / eBay Live ↓

名额看板

编号名额

打开示例预览 ↗
  1. 创建看板在 变现 → 名额看板与近期销售，选择编号方块。设置 120 个名额、20 列，可得到 20 × 6 的网格。
  2. 标记认领选择一个方块，然后 为此名额记录销售 ，请先核对付款。使用 仅标记为已认领 ，仅预留名额而不生成销售记录。
  3. 揭晓物品输入分配的物品，然后选择 揭晓。使用 设为可认领 可更正名额，或使用 退款并重新开放 同时移除其关联销售。

SSN 显示你的分配结果。它不会出售名额或随机分配奖品。

具名名额

球队拆卡

球队拆卡会按球队、球员或其他具名名额分配拆出的卡片。

  1. 选择 球队方块.
  2. 粘贴球队名称，每行一个。此列表决定名额数量。
  3. 将每个已购买名额标记为已认领。准备好后再揭晓。
打开球队预览 ↗

认领由主播控制。SSN 不会根据聊天消息或拍卖结束来推断某个球队名额已被购买。

在 Whatnot 或 eBay Live 直播期间

  1. 捕获你的直播在 SSN 中打开你的直播并启用 捕获直播事件。Whatnot 需要显示拍卖底栏的直播视图。eBay Live 支持聊天页或直播页。
  2. 核对销售位于 近期销售，在以下选项中选择 Whatnot 或 eBay Live： 拍卖物品助手 并保存。 使用拍卖物品 会复制最后捕获到的名称。请在销售平台核对物品和付款，然后输入销售总额和币种。
  3. 先确认，再揭晓对于某个名额，选择其方块，然后选择 为此名额记录销售 。 确认销售并认领名额 会同时记录两者。准备展示分配的物品时，再添加揭晓文本。

助手提供的是操作员草稿。它绝不会将出价或拍卖结束转换为销售。新的拍卖更新不会更改你的草稿。启用 显示近期销售 可选择观众看到的显示内容；如需同时显示看板和销售，请分别使用两个 OBS 源。

如需退款，请使用 退款并重新开放 ，可移除关联销售并释放名额。 移除 只移除销售记录。替换后的看板与旧看板的销售记录彼此独立。

直播捕获与商店连接的区别

Whatnot 和 eBay Live 捕获会提供物品、出价和拍卖状态。独立的 eBay 卖家连接 会接收所选商品刊登的已付款订单事件，可自动填充近期销售。请勿手动确认商店连接已经记录的同一笔购买。其他自动来源包括 Shopify、Fourthwall、Ko-fi 和 Buy Me a Coffee。

助手只保留从所选平台最后捕获到的物品，五分钟没有更新后即失效，重启时会清空。如果打开了多个直播，请核对物品。助手为空时，需要在启用后收到新的拍卖更新。

eBay：在卖家控制台检查付款状态 · Whatnot：拍卖付款失败

近期购买

提醒消失后，仍将实际购买记录保留在画面上。可选择精简列表、六卡片展示墙，或放在活动旁边的条带。

列表预览 ↗展示墙预览 ↗条带预览 ↗

从商店收集

开启 显示近期销售 和 收集已连接商店的购买记录，然后保存销售选项。

使用 SSN 新收到的 Shopify、eBay 卖家、Fourthwall、Ko-fi 和 Buy Me a Coffee 的 购买 事件。

自行确认销售

输入物品，可选填销售总额和币种。选择 确认销售.

适合在核对购买后记录 Whatnot、eBay Live 或线下销售。这些条目会显示 主播已确认.

更正和退款

移除错误或已退款的销售记录。为新一场直播清空展示墙。

出价、小费、礼物和沙盒测试不会填充此显示。认领看板名额不会创建销售记录。

价格、历史记录与隐私

已连接的购买数据源并不总是提供物品价格，因此自动生成的条目会留空价格。要显示已知价格，请移除该条目并手动确认。对于多件物品，请输入该条目的总额，而非单件价格。系统不会用标价、最高出价或打赏金额替代。

SSN 会在当前安装中保留最新的 100 条记录，重启后也会保留。启用后才开始收集，不会完整导入订单历史。系统会在已保存的 2,000 个投递 ID 范围内忽略重复投递。退款记录需要手动移除。

此显示不包含买家姓名、地址、付款详情或尚未揭晓的物品文本。演示链接使用明确标注的虚构数据。

OBS 设置

  1. 选择显示方式在看板控件中选择“名额 / 球队看板”、“近期销售列表”、展示墙或条带。
  2. 复制 OBS 链接添加尺寸为 1920 × 1080 的浏览器源。透明区域可透出摄像头画面。
  3. 在 SSN 中控制保持 SSN 开启。更改会立即保存。 OBS 商品控制停靠面板 也提供相同控件，可按喜好选用。
可选 URL 设置

&view=board, sales, wall 或 ticker 选择布局。 &limit=6 显示最多六条近期记录（上限为 24 条）。 &prices=0 隐藏价格。 &label=Recently%20sold 设置销售标题。 &onlytype=shopify,ebay 筛选销售来源。

保留复制链接中的会话、密码和中继设置。未连接或没有内容时，显示保持透明；设置消息绝不会出现在观众叠加层上。

API 与 Event Flow 集成

这些控件扩展了现有的 commerceControl API。SSN、Stream Deck 自定义 API 操作和可选的 OBS 停靠面板会读取同一个 getCommerceState 响应。

{"action":"commerceControl","value":{"command":"boardSpot","data":{"id":"12","status":"claimed"}}}

命令： boardSave （title、style、columns，以及 count 或按行分隔的标签）， boardSpot （id、status、result）， boardVisibility （visible）， saleAdd （title，可选 amount/currency/quantity/platform；可选 boardId 和 spotId 用于认领名额）， saleRemove （id，可选 reopenSpot）， salesClear，以及 salesSettings （visible、automatic，可选 auctionSource：whatnot、ebay 或空字符串）。将这些字段放入 data。这些编辑不会发出购买事件，也不会触发付费奖励。

在 Event Flow，使用现有的 商品与支持 操作。选择看板或销售命令，并在以下位置输入字段： 看板 / 销售字段。字符串值可使用变量，例如 {subtitle}。销售操作应匹配已确认的购买事件。如果流程手动添加了同一笔销售，请关闭自动收集。
