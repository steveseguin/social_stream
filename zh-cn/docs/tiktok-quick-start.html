TikTok 快速入门

只需要让 TikTok Live 聊天运行时，请先使用本指南。

1. 搜索 TikTok

打开 支持的网站 页面并搜索 TikTok。在开始更改 OBS 之前，先确认基本设置规则。

2. 打开 TikTok 直播页面

使用浏览器扩展时，打开创作者的直播页面，并保持聊天可见。

https://www.tiktok.com/@CHANNEL/live

如果浏览器标签页不断暂停或隐藏聊天，请尝试桌面应用方式。

3. 使用同一个会话 ID

选择一个简短的会话 ID。在 TikTok 来源、停靠面板和 OBS 中使用完全相同的 ID。

YOUR_SESSION_ID

4. 在 OBS 之前先检查停靠面板

使用会话 ID 打开停靠面板。发送或等待一条 TikTok 聊天消息。

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

5. 将叠加层添加到 OBS

在 OBS 中添加浏览器源，并使用相同会话 ID。

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

模板设置： 叠加层模板快速入门.

如果 TikTok 没有显示

  • 确认 TikTok 直播页面确实正在直播。
  • 使用浏览器扩展时保持聊天可见。
  • 确认停靠面板和 OBS 使用相同会话 ID。
  • 更改会话 ID 后刷新停靠面板。
  • 如果浏览器标签页受到限速，请尝试桌面应用。
