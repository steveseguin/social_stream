TikTok 签名

了解签名服务器是什么、为何有时失败，以及如何重新连接。

什么是 TikTok 签名？

TikTok 要求对其直播聊天流的连接请求进行加密签名。桌面应用通过第三方签名服务签署这些请求，该服务由以下方运营： Euler Stream。正常使用无需账号或 API 密钥，应用会自动使用 Euler 的免费层级。

由于此服务位于应用与 TikTok 之间，即使您这边没有问题，TikTok 来源也可能停止工作：签名服务器可能宕机、受到速率限制，或因 TikTok 端变更而暂时失效。

“签名服务器不可用（Sign Server Unavailable）”

此状态表示应用未能从签名服务获取有效签名。常见原因：

  • 速率限制。 免费层级按 IP 地址限制（每分钟少量连接，并设有每小时和每日上限，参阅 Euler 的速率限制）。反复删除并重新添加来源，或快速切换模式，会耗尽配额并使错误持续。
  • 签名服务器中断。 Euler 偶尔会宕机或过载。这通常会在数小时内解决，无需您更改设置。
  • TikTok 变更。 TikTok 更新直播基础设施时，可能导致所有人的签名失效，直到 Euler 发布修复。

按顺序执行：

  • 让来源保持 Auto 连接，并让它自行重试。避免反复重新添加来源。
  • 如果反复失败，请停止一小时，让按 IP 计算的速率限制重置，然后只重新连接一次。
  • 确保使用最新应用版本，TikTok 修复会频繁发布。
  • 将 TikTok 来源切换到 标准 模式（页面捕获）作为可靠的临时方案。它直接加载直播页面，完全不使用签名服务器。
  • 如果经常遇到速率限制，请添加自己的免费 Euler API 密钥（见下文）。

添加自己的 Euler API 密钥

自己的密钥提供专属配额，无需共享匿名的每 IP 额度。

  • 在以下位置创建免费账号和密钥： Euler Stream 仪表板.
  • 在桌面应用中，编辑 TikTok 来源并打开连接预设选择器。
  • 选择 Euler Signing（高级） 并粘贴 API 密钥。 Euler Proxy（API 密钥） 也可使用，但不支持发送回复。
  • 保存后重新连接来源一次。

不使用签名服务器的模式

模式工作原理取舍
标准加载 TikTok 直播页面并从中捕获聊天。不涉及签名服务。需要保持直播页面打开；可能提示进行 TikTok 登录或验证。
本地签名器在轻量 TikTok 窗口中本地签署请求，不使用 Euler。在应用内登录 TikTok 时效果最好；匿名模式可能遗漏部分聊天。

兼容模式（WebSocket），旧称 轮询（Polling） ，在当前桌面应用中使用带签名的 WebSocket。它不提供无签名的 HTTP 轮询，也无法发送回复。该模式使用 Euler 签名，因此也会受到该服务中断和限制的影响。

向 TikTok 发送回复

从停靠面板向 TikTok 回发聊天消息，需要在桌面应用内登录 TikTok 账号；应用需要您的 TikTok 会话才能以您的身份发布。如果未登录，或 TikTok 连接中断，传出消息只会到达其他平台。

请注意，无论登录状态如何，Euler Proxy 模式都不支持回复。
