忠诚度积分和奖励

抽奖、付费票券、游戏奖品与恢复指南

奖励参与积分，让观众兑换已批准的奖励，并备份他们的余额。

所有指南 1. 启用参与积分 2. 检查和管理余额 3. 提供贴纸奖励 4. 添加可选 Event Flow 奖励 5. 迁移时保留积分 故障排除

1. 启用参与积分

  1. 打开 SSN 的 全局设置和工具 → 积分系统。开启 启用忠诚度积分系统.
  2. 先使用 每次参与获得积分：1 和 参与时间窗口（分钟）：15，再根据直播需要调整。
  3. 启用 !points, !leaderboard，以及 !rewards 命令，以启用相应的聊天回复。
  4. 保持 SSN 和来源聊天持续捕获。请测试观众发送一条普通消息，然后检查 管理用户积分.

积分奖励的是捕获到的参与活动，不是静默观看时长，也不是每一条消息。获奖后，观众需要在参与时间窗口结束后再次发送符合条件的消息，才能再次赚取积分。连续参与可获得额外奖励。在同一时间窗口内重复发消息，不会重复获得积分。

2. 检查和管理余额

观众使用 !points 查看余额，并使用 !leaderboard 查看排名（需启用）。回复需要能向聊天回发消息的来源；如果没有收到回复，请通过以下方式检查余额： 管理用户积分 ，再判断是否没有赚到积分。

!points 显示可用余额、已获得积分、支出和预留积分。 !leaderboard 和忠诚度排行榜按照累计获得的积分排序并显示。兑换奖励会减少可用余额，而积分排名仍以累计获得的积分为准。

使用 管理用户积分 查看特定观众和平台，或使用 查看排行榜 查看概览。账号以用户名和来源类型为键：Twitch 与 YouTube 上的相同名字拥有独立余额。不要假定观众的账号会自动关联。

3. 提供贴纸奖励

  1. 在 积分系统 → 贴纸奖励，启用贴纸奖励，并选择希望提供的贴纸包。根据赚取积分的速度设置合适的价格。
  2. 复制 OBS 浏览器源 链接添加到 OBS，并保持贴纸源加载。
  3. 在 计时与聊天回复，设置显示时长、每位观众冷却时间、每张贴纸冷却时间和安静间隔。按需启用命令回复。
  4. 让测试观众输入 !stickers 列出已启用的贴纸代码和价格，然后使用 !sticker rocket ，前提是该代码已启用且积分足够。
  5. 宣布奖励前，请检查显示的贴纸和剩余余额。

选择目录时即完成批准。 启用的贴纸会自动兑换，没有逐次兑换审批队列。对于自定义图片或 GIF，由你提供并批准直接 HTTPS 资源 URL。观众不能通过贴纸命令提交任意图片。

处于冷却中或叠加层离线时，请求会被拒绝且不扣积分。如果扣费后显示投递失败，SSN 会尝试退款，并报告需要主播纠正的失败。叠加层已连接不代表 OBS 当前正在显示该场景。

参阅 贴纸包与设置 ，查看预览、自定义图片和 GIF 选项。 !stickers 是贴纸目录命令； !rewards 列出通用的积分奖励命令。

4. 添加可选 Event Flow 奖励

对于自定义操作，请使用现有 Event Flow 编辑器及其 花费积分 操作。在扣费之前设置准确的命令条件，并设置 要花费的金额，并在成功扣除积分后连接付费操作。请在流程中加入冷却时间。

启用奖励前，分别测试余额不足和余额充足的情况。自定义操作在收费后失败，不会自动继承贴纸系统的投递/退款行为。将付费命令连接到媒体或外部操作前，请检查失败处理。参阅 Event Flow.

5. 迁移时保留积分

积分保存在本地浏览器/应用存储中。与另一台电脑或另一处安装共享会话 ID，不会同步余额。

  1. 使用 积分系统 → 备份与恢复 → 导出积分 ，并保留 JSON 文件。
  2. 在目标安装中，先导出已有积分，然后使用 导入积分 并选择预期的导入模式。
  3. 谨慎选择： 合并 保留较高的积分值； 替换 覆盖现有积分数据。检查导入结果，在“管理用户积分”中抽查观众和平台，确认余额后再恢复奖励。

将专用的积分导出文件与以下备份一同保存： 设置备份. 重置所有积分 会清空积分账本；仅在导出后有意重置时使用。

故障排除

  • 余额没有变化： 检查捕获、总开关、参与时间窗口和观众的平台账号。
  • 聊天历史记录已禁用： 积分获取和积分命令依赖本地消息数据库。请参阅 聊天历史记录指南.
  • 贴纸显示不可用： 检查贴纸包/代码选择、余额是否充足、冷却状态，以及 OBS 贴纸源是否已加载。
  • 迁移后积分丢失： 将积分导出文件导入到负责捕获的安装中；仅有会话链接并不等于备份。
