可以打印什么？

Windows 独立应用可向已安装的 Windows 打印机静默发送任务。流程可组合任何可用值，例如观众名称、打赏、产品、消息或计数器值，并控制文字大小和对齐。

兼容性规则： 打印机必须显示为可工作的 Windows 打印队列。Social Stream 通过已安装的 Windows 驱动程序打印；不会发送原始 ESC/POS、ZPL 或厂商 SDK 命令。

快速设置

  1. 通过 USB 连接打印机，打开电源并安装 Windows 驱动程序。先打印 Windows 测试页。
  2. 在 Social Stream 中打开 全局设置和工具 → 打印机控制（Printer Control）.
  3. 选择 查找打印机（Find printers） 并选择 Windows 显示的准确队列名称。
  4. 输入实际纸张宽度，通常为 58, 80，或 62 毫米，取决于设备及耗材。
  5. 将 固定标签长度 设为 0 ，以使收据长度随内容调整。对于模切标签，输入标签沿进纸方向的长度，单位为毫米。
  6. 选择 打印对齐测试。若缺少某条边，请增加该侧的安全边距并再次测试。

默认左右各 2 毫米安全边距适用于许多廉价 58 毫米小票打印机，但实际可打印区域由驱动程序决定。请保持 使用可打印区域（Use printable area） 处于选中状态，除非已测试其他设置。

小票纸卷、连续贴纸还是模切标签？

小票纸卷

最适合可变长度的购买凭条、排队票及支持者收据。固定标签长度保留为 0，让内容决定纸张长度。

连续贴纸卷

适合文字量不同的粘贴式姓名条。行为类似小票纸，但切纸须由打印机或驱动程序处理。

模切标签

最适合统一的徽章及产品标签。设置准确的固定长度，并在 Windows 打印首选项中配置相同耗材。

打印机示例适用用途连接与耗材说明
通用“POS-58”低成本 58 毫米连续收据通常使用 USB 和直接热敏。型号名称及驱动程序因卖家而异。Social Stream 的实体开发测试使用了基本 POS-58 打印队列。
Epson TM-T20III较成熟的小票打印机选项USB 型号；支持 80 毫米纸张，使用随附宽度适配器也支持 58 毫米纸张。
Brother QL-800USB 贴纸及地址/姓名标签直接热敏，支持最宽 62 毫米耗材、模切或连续纸卷，配有自动切刀。
Brother QL-820NWB共享或联网标签工作站支持 USB、Ethernet、Wi-Fi 和 Bluetooth，以及 Brother 的模切与连续标签系列。
Zebra ZD220较宽的产品、运输、腕带或耐用标签USB 桌面标签打印机，适用于约 25–112 毫米耗材；提供直接热敏及热转印配置。

这些只是示例，不是保证兼容的列表。购买前，请确认具体型号有当前可用的 Windows 驱动程序、支持你的标签尺寸，并显示为正常 Windows 打印机。

使用 Event Flow 打印打赏标签

💰 打赏 / 小费（Donation / Tip）最低金额： 10
→
🖨️ 打印热敏标签（Print Thermal Label）{username}
{donation}
24 pt · 粗体 · 居中
  1. 打开 Event Flow 编辑器 并创建流程。
  2. 添加 打赏 / 小费（Donation / Tip） 触发器。设置 最低金额（Minimum Amount） ，仅当希望打印较大打赏时设置。
  3. 添加 打印热敏标签（Print Thermal Label） ，从 Integrations 中添加，并将触发器连接到它。
  4. 将标签文字设为 {username}，添加新行，然后 {donation}。选择字号、字重、对齐方式及份数。
  5. 通常将动作的打印机及固定长度覆盖值留空或设为 0，以使用全局 Printer Control 设置。
  6. 打开 测试流程（Test Flow），输入名称，启用 含打赏（Has Donation），输入金额并运行测试。这会在独立应用中发送真实打印任务。

其他实用占位符包括 {message}, {source}, {donationAmount}，以及 {counterValue}。前面节点创建的值也可用于打印模板。

买家加粗，商品保持普通字重

选择 字重 → 选中文字（**粗体**）（Weight → Selected text），然后输入：

**{username}**
{subtitle}

使用单层花括号。近期商务集成将产品标题放在 subtitle；数量可能通过以下字段提供： {meta.commerce.quantity}。如果前面的节点创建了 buyer，使用 **{buyer}** 作为替代。Shopify 和 eBay 不提供买家身份，因此这些来源应使用本地订单计数器或仅产品标签。只有包裹在以下标记中的文字 ** 会变为粗体；不需要自定义 JavaScript 或 HTML。现有 All bold 和 Normal 标签保留原格式。

对于销售，使用 Event Type 并指定 purchase；Donation / Tip 要求 hasDonation ，因此不会匹配大多数销售。请使用 gift 或 giftfunded ，当标签代表已完成的礼物时使用，并按需过滤提供商。若希望整场直播使用连续订单编号，请在打印动作前添加 Counter。参见 商务事件字段.

该动作提供 meta.thermalPrintResult.success 以及可选的错误/代码，供后续流程步骤使用。成功表示任务已提交，不表示纸张已输出。重试状态不确定的任务前，请检查 Windows 队列，以免重复打印标签。

Counter 为购买编号，不是为唯一买家编号。若要让同一买家的每次购买复用同一 ID，需要独立的买家到 ID 映射，并在每场直播开始时明确重置。User Memory 的 reason 字段是描述性文字，不是专用买家 ID 计数器。

Whatnot 商品标签

下载 Whatnot 示例流程。它会加粗打印买家、打印商品名，并在提供时打印订单 ID。付款失败通知会另外打印 付款失败 标签，包含该通知中可用的信息。

  1. 在独立应用中配置 打印机控制（Printer Control） ，使其匹配打印机和纸张尺寸，并运行对齐测试。
  2. 打开 Event Flow 编辑器，选择 导入，并选择下载的 JSON 文件。
  3. 选择 Whatnot：商品标签 + 付款警告。检查两个打印动作；它们继承全局打印机和标签长度。
  4. 启用并保存流程。保持 Whatnot 来源打开，并启用直播事件捕获。

示例导入后处于禁用状态。它使用 事件类型（高级）→ 自定义事件（Event Type (Advanced) → Custom Event） 用于 product_sold 和 payment_failed，并使用 Whatnot 来源过滤器。竞价和拍卖结束通知不会打印标签。

销售标签不代表付款已确认。此示例在每条通知到达时打印；不会等待付款、修改先前标签或分配买家编号。缺少的字段打印为空白。不含买家、商品或订单信息的失败通知无法识别先前标签。参见 Whatnot 事件字段.

可预测的固定长度标签

3 × 1 英寸标签（包括 Munbyn BT320 配置）： 当 1 英寸边为进纸方向时，使用 76.2 毫米宽度和 25.4 毫米固定长度。在 Windows 打印首选项中匹配该耗材及方向。从 12–14 pt 文字开始，测试较长的买家和商品名。

对齐测试的侧边框标示在所选可打印区域设置和安全边距之后的安全宽度。方框高度随测试文字变化；它不描绘整个标签，也不会接触纸张的物理边缘。

  • 沿进纸方向测量。 62 × 29 毫米标签通常使用 62 毫米纸宽及 29 毫米固定标签长度。
  • Windows 设置也须匹配。 在打印机驱动程序的打印首选项中，选择准确的标签耗材、方向、间隙/标记检测及切刀行为。
  • 固定长度就是固定长度。 Social Stream 不会为固定长度任务增加小票进纸空间。内容过高时，可能被裁切或溢出，具体取决于驱动程序。
  • 使用实际可能出现的最长数据测试。 较长的观众名称、产品变体、货币标签及多行内容需要更多空间或更小字号。
  • 驱动程序限制仍然适用。 Windows 或打印机驱动程序可能限制非常短的自定义页面；Social Stream 请求的最小长度为 20 毫米。

直播创意

  • 打印支持者姓名贴纸，用于墙面、道具、地图或实体进度板。
  • 购买到达时创建商品订单、委托、饮品或取货标签。
  • 打印抽奖票或赠奖参加凭条，并在打印动作前加入限流及资格检查。
  • 制作 VIP 徽章、团队分配、挑战凭证或打赏里程碑标签。
  • 为在主播旁工作的制作人打印简短的审核或订单处理队列。
打印个人数据前先考虑。 避免打印地址、电子邮件、付款信息或私信。热敏纸还会因热、光及时间而褪色，因此不适合长期存档。

常见解决办法

  • 没有显示打印机： 确认 Windows 可打印测试页，然后重启 Social Stream 并再次选择 Find printers。
  • 任务报告成功，但没有打印： 打开该打印机的 Windows 队列，检查暂停、离线、缺纸、驱动程序或端口错误。
  • 边缘被切掉： 保持 Use printable area 启用，并增加该侧安全边距。
  • 空白纸太多： 收据使用固定长度 0，减少底部边距和进纸量，或为标签耗材设置准确长度。
  • 一张标签变成两张： 内容高于固定标签，或 Windows 使用了错误耗材尺寸。减少文字、字号、行距和边距。
  • Test Flow 使用了错误的打印机： 在 Print Thermal Label 节点上选择打印机覆盖值。直接在编辑器中测试时，空白覆盖值使用 Windows 默认打印机。
