首次发言者指南

用高亮、叶子徽章或可选提示音标记全新的聊天参与者。

此功能的作用

首次发言者检测会添加 firsttime=true 到该来源中为该观众存储的第一条聊天消息。停靠面板可利用此标志添加背景底色、仅首次发言提示音和可选的叶子徽章。

必要设置

  1. 打开 Social Stream Ninja 弹出菜单。
  2. 保持 禁用本地消息数据库 处于关闭状态。
  3. 开启 首次发言者检测.
  4. 使用相同会话 ID，保持停靠面板或叠加层打开。
重要： 此功能需要本地数据库。如果禁用了数据库，Social Stream Ninja 就无法判断某人是否为新观众。

显示选项

  • 背景底色： 停靠面板默认启用。请保持 不为首次发言者添加背景底色 处于关闭状态，即可显示高亮。
  • 叶子徽章： 开启 用自定义徽章标记首次发言者 ，在聊天参与者的徽章前加上小叶子徽章。
  • 停靠面板首次发言提示音： 如果希望停靠面板仅在有人首次发言时播放提示音，请开启此项。
  • 新观众或回归观众提示音： 如果也希望为安静 8 小时以上后再次发言的观众播放提示音，请开启此项。

在自定义叠加层中使用此标志

自定义叠加层可以检查 data.firsttime === true。如果启用了叶子徽章选项，徽章会包含在 chatbadges ，在消息到达叠加层之前完成。

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

如果没有显示

  1. 确认 禁用本地消息数据库 处于关闭状态。
  2. 确认 首次发言者检测 处于开启状态。
  3. 确认 不为首次发言者添加背景底色 处于关闭状态，才能显示高亮。
  4. 确认 用自定义徽章标记首次发言者 处于开启状态，才能显示叶子徽章。
  5. 使用尚未存储在本地数据库中的用户名/来源组合进行测试。
