概述

SSN 可以朗读从任意支持来源捕获的聊天文字；聊天平台本身无需提供 TTS 功能。 启用 TTS 的停靠面板或叠加层会根据过滤器及 TTS 设置，朗读收到的消息。先阅读 简明设置指南；本页介绍语音选项和高级设置。 比较提供商、试听示例并查看设置。

快速开始： 使用 dock.html?session=YOUR_SESSION&speech=en-US。默认使用 System TTS。若要使用免费的 OBS 提供商，还需添加 &ttsprovider=kokoro。保持此页面打开并连接；仅应有一个副本发声。

TTS 用于哪些位置？

  • Social Stream Ninja： 在多个界面中朗读观众聊天消息
  • CAPTION.Ninja： 提供字幕、转录及结合 TTS 的翻译
  • 两项服务均提供付费及免费 TTS 选项
System TTS 不等于所有免费 TTS：
  • 系统语音取决于浏览器及操作系统。即使 Chrome/Edge 可用，OBS 也可能不提供任何可用语音。
  • 语音不可用与语音在 OBS 音频捕获之外播放是不同问题。音频路由无法弥补缺失的语音支持。
  • Kokoro、Piper、Kitten 及 eSpeak 等免费提供商则生成页面音频。在 OBS 中使用 TTS 不必付费。
  • 先检查语音可用性，再检查音频捕获。

TTS 提供商选项

System TTS（免费）

  • 使用操作系统内置语音
  • 语言支持受系统安装情况限制
  • 语音可用性及音频路由取决于浏览器和操作系统；请在实际播放器中测试
  • 浏览器兼容性差异很大

本地 / 免费 TTS 选项（无需 API 密钥）

想要完全本地的 AI TTS？ Social Stream Ninja 直接内置多种高品质 AI 语音，在浏览器中运行 — 无需 API 密钥、云端或额外安装。参见 本地 AI TTS 指南 ，了解设置说明及自托管服务器选项。
提供商 费用 OBS 捕获 功能
Kokoro TTS 免费 直接 浏览器内 AI，音质出色，提供数十种语音
Piper TTS 免费 直接 在浏览器中运行、快速且适合 CPU 的神经网络 TTS
Kitten TTS 免费 直接 在浏览器中运行的轻量 ONNX 模型
eSpeak-NG 免费 直接 经典开源方案，可在任意硬件上运行

付费 / 云端 TTS 选项（浏览器直接播放音频）

提供商 费用 OBS 捕获 功能

Google Cloud 适用 API 费用 直接 专业品质，支持多种语言
ElevenLabs 提供免费额度 直接 自定义语音训练，音色自然
Speechify 适用 API 费用 直接 高品质语音，支持多种语言
Gemini TTS 适用 API 费用 直接 Google 生成式语言 API

系统语音可用性

这些是典型能力，并非对所有安装环境的保证。OBS 使用自己的嵌入式浏览器，不会继承已安装 Chrome/Edge 的语音列表。SSN 应用测试成功不代表单独的 OBS 浏览器源也已通过测试。

Chrome

✓ 在支持的安装环境中可使用系统语音

Google 提供的语音 + 系统语音

Edge

✓ 在支持的安装环境中可使用系统语音

Microsoft 语音 + Windows TTS 包

Firefox

⚠ 支持有限

仅支持本地系统语言

Opera

⚠ 支持有限

基于 Chromium；可用语音因安装环境而异

浏览器限制：
  • 不同浏览器对文本转语音的支持不同（部分 Firefox 版本的语音有限）
  • Chrome 提供由 Google 支持的 TTS 选项
  • Edge 支持 Microsoft TTS 及 Windows 语言包语音
  • Safari 需要用户交互才能开始播放音频
  • 检查 可用语音 供你的浏览器使用

适用于 OBS 的 Windows TTS 音频捕获方法

页面音频：免费本地及云端提供商

SSN 的浏览器内本地提供商及云端音频提供商通过页面播放生成的音频：

  • 只需在浏览器源中启用“Control audio via OBS”
  • 无需虚拟音频线
  • 适用于 SSN 应用及 OBS 浏览器源

System TTS 捕获方法

重要： 首先确认 System TTS 能生成语音。OBS 的嵌入式浏览器可能不提供可用的系统语音。若未生成语音，修改音频路由不会有帮助。请选择其他提供商，或在受支持的浏览器中生成语音并捕获其音频。

专门针对 System TTS：

  • 不要假设 OBS 提供与 Chrome 或 Edge 相同的语音
  • 各浏览器支持有限（Firefox 可能缺少部分 TTS 语音）
  • Chrome 提供 Google 选项，Edge 提供 Microsoft 选项
  • 若语音在场景浏览器源之外播放，请单独捕获该输出

音频路由工具下载： VB-Audio Virtual Cable | Voicemeeter | Audio Router（旧版）

在支持的情况下，先尝试用 OBS 应用音频或桌面音频捕获正在发声的浏览器。下方虚拟音频线方法是可选替代方案；不会为 OBS 增加语音支持。

方法 1：使用虚拟音频线的默认音频路由

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

方法 2：Windows 10 应用路由

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

方法 3：Windows 11 应用路由

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

方法 4：Audio Router 软件

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

方法 5：Voicemeeter（高级）

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

测试你的设置

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
替代方案： 使用 Kokoro、Piper、Kitten 或 eSpeak 等免费内置提供商、云端提供商或自托管 TTS 服务器。

安装其他语言包

Windows 11

  1. 前往 开始 > 设置 > 时间和语言 > 语音
  2. 位于 管理语音，点击 添加语音
  3. 选择所需语言并点击 添加
  4. 重启浏览器以刷新可用语音

Windows 10

请按照以下资料中的说明操作： Microsoft 官方指南 ，了解语言包安装方法。

提示： 部分第三方语音可能因兼容性问题未出现在浏览器中。Firefox 通常比基于 Chromium 的浏览器显示更多系统语音。

TTS 配置的 URL 参数

基本参数

参数 说明 示例
&speech 使用语言代码启用 TTS &speech=en-US
&pitch 语音音高（0.1 至 2.0） &pitch=1.2
&volume 音量（0.0 至 1.0） &volume=0.8
&rate 语速（0.1 至 10.0） &rate=1.5
&voice 部分匹配语音名称 &voice=google
&ttsprovider 选择提供商：kokoro、piper、kitten、espeak、openai、customtts、localtts、elevenlabs、google、speechify、gemini &ttsprovider=customtts

高级参数

参数 说明
&simpletts 不说“says”或“someone says”
&simpletts2 完全不朗读聊天用户名
&ttscommand 启用自定义 TTS 命令（默认：!say）
&readevents 将直播事件纳入 TTS
&skipmessages=3 每3条消息只朗读1条

TTS 提供商配置

Kokoro TTS（免费、内置）

  • 通过以下内容启用 ?ttsprovider=kokoro
  • 通过 WebGPU/WASM 在浏览器中运行 — 无需服务器
  • 可直接配合 OBS 浏览器源使用
  • 语音选择： &voicekokoro=af_bella
  • 速度控制： &kokorospeed=1.2
  • 选择该语言的语音： &voicekokoro=ef_dora 用于西班牙语，或 &voicekokoro=pf_dora 用于巴西葡萄牙语。更改 &speech= 本身不会改变所选语音。现有英语语音 ID 仍然可用。

Piper TTS（免费、内置）

  • 通过以下内容启用 ?ttsprovider=piper
  • 在浏览器中运行、快速且适合 CPU 的神经网络 TTS
  • 语音选择： &pipervoice=en_US-hfc_female-medium
  • 葡萄牙语语音： &pipervoice=pt_BR-faber-medium 或 &pipervoice=pt_BR-edresson-low
  • 西班牙语语音： &pipervoice=es_ES-davefx-medium 或 &pipervoice=es_MX-ald-medium
  • 速度控制： &piperspeed=1.0

Kitten TTS（免费、内置）

  • 通过以下内容启用 ?ttsprovider=kitten
  • 在浏览器中运行的轻量 ONNX TTS
  • 语音选择： &kittenvoice=expr-voice-4-f

eSpeak-NG（免费、内置）

  • 通过以下内容启用 ?ttsprovider=espeak
  • 经典开源 TTS，可在任意硬件上运行
  • 语音选择： &espeakvoice=en
  • 葡萄牙语示例： &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • 西班牙语示例： &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 速度控制： &espeakspeed=175

葡萄牙语和西班牙语 TTS 示例

  • 葡萄牙语，在 SSN 中测试的最佳免费本地音质： ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • 葡萄牙语，在 SSN 中测试的最快备用方案： ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • 西班牙语，在 SSN 中测试的最佳免费本地音质： ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • 西班牙语，在 SSN 中测试的最快备用方案： ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 对于云端语音，请使用支持目标语言的提供商语音/语言，例如 Google Cloud、ElevenLabs、Speechify、Gemini 或 OpenAI 兼容本地服务器。

OpenAI / 本地服务器 TTS

  • 通过以下内容启用 ?ttsprovider=openai
  • 使用 ?ttsprovider=customtts 或 ?ttsprovider=localtts 用于自托管端点
  • 默认使用 OpenAI API，也可使用任意兼容的本地服务器
  • 自定义端点： &openaiendpoint=http://localhost:8880/v1/audio/speech
  • 重要： localhost 和 127.0.0.1 指播放 TTS 页面的同一台电脑。如果 OBS 与 TTS 服务器不在同一台电脑上，请改用服务器电脑的局域网 IP。
  • 本地服务器无需 API 密钥
  • 若本地服务器在 Chrome/OBS 中遇到 CORS 或本地网络问题，运行 npm run local-tts-bridge ，在 OBS 电脑上运行，并将 SSN 指向 http://127.0.0.1:8124/v1/audio/speech
  • SSN 发送 { model, input, voice, response_format, speed } ，并支持二进制音频、JSON 音频 URL 及 JSON base64 音频
  • 目前自定义/本地端点播放采用缓冲方式；SSN 尚不支持逐步播放流式音频片段
  • 语音： &voiceopenai=af_bella，速度： &openaispeed=1.0。使用服务器支持的语音名称；Kokoro 语音类似 af_bella，而 openedai-speech/OpenAI 风格的语音可能类似 nova 或 echo.
  • 请参阅 本地 AI TTS 指南 ，了解自托管服务器设置。

Google Cloud TTS

  • 通过以下内容启用 ?ttsprovider=google&ttskey=YOUR_API_KEY
  • 专业品质语音
  • 语音选择： &voicegoogle=en-GB-Standard-A
  • 语言： &googlelang=en-US

Gemini TTS

  • 通过以下内容启用 ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • 模型： &geminimodel=gemini-2.5-flash-preview-tts
  • 语音： &voicegemini=Kore，语言： &geminilang=th-TH
  • 风格指令： &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • 通过以下内容启用 ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • 语音 ID： &voice11=YOUR_VOICE_ID
  • 模型： &elevenlabsmodel=eleven_multilingual_v2
  • 参数：可调整稳定性、相似度及风格

Fish Audio TTS

选择 Fish Audio 并输入 API 密钥，可选填语音 ID。默认模型为 s2.1-pro-free. 设置、模型选项及浏览器访问限制.

Speechify TTS

  • 通过以下内容启用 ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • 语音： &voicespeechify=henry
  • 模型： &speechifymodel=simba-3.0 （默认），或 &speechifymodel=simba-3.2 用于英语。
  • 朗读速度： &speechifyspeed=1.2 （范围 0.5 至 3.0；正常为 1.0）。
  • Speechify 设置、语音、速度及音量指南

故障排除

常见问题

  • 没有音频播放： 检查 TTS 是否启用、生成 TTS 的页面是否打开，以及浏览器源是否未静音。在普通浏览器中，先点击页面一次。
  • 语音未显示： 安装语言包后重启浏览器
  • OBS 未捕获： 若没有语音，先检查语音/提供商可用性。若已有语音，检查 通过 OBS 控制音频、混音器静音及输出轨道，或捕获正在发声的外部浏览器
  • 本地端点在应用测试中可用，但在 OBS 中无效： OBS 是独立浏览器。请在 OBS 电脑上检查端点，尤其是使用 127.0.0.1.
  • 只朗读第一个字母或开头几个词： 移除 ttsquick ，如 OBS URL 中存在则移除。
  • Safari 问题： Safari 对自动 TTS 的支持有限
  • 付费服务无效： 检查 API 密钥并确保提供商指定正确

最佳实践

  • 使用生成页面音频的提供商可简化 OBS 设置；有免费本地提供商可选
  • 直播前用简单短句测试设置
  • 使用 TTS 时考虑用户生成内容的风险
  • 准备一个开关，以便需要时快速禁用 TTS
