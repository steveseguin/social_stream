直播商品和观众链接

将变现叠加层用作 OBS 浏览器来源供观众观看。从 SSN、Stream Deck 或 API 操作它。控制停靠面板可单独使用相同 API；操作员控件不应出现在观众叠加层上。

1. 添加商品或支持链接

打开变现 > 商品与支持链接 > 设置商品和链接。粘贴公开 HTTPS 链接并选择 从链接加载详情。快速导入支持公开的 Gumroad、itch.io、Ko-fi、Buy Me a Coffee 和 Fourthwall 页面。自定义域名、重定向、私密页面和没有公开元数据的页面可能需要手动输入。现有 Shopify 和 Fourthwall API 导入选项仍可使用。

检查标题、图片、价格、币种和用途。快速导入会特意将价格留空。选择 添加商品或链接，启用“商品与支持链接”，然后 保存设置。手动卡片无需商家账号。

购物、礼物、支持和加入描述链接的用途，不会改变后续付款事件的分类。卡片是保存的快照；库存和价格以结账页面为准。

2. 控制显示内容

将现有的商品与支持链接叠加层 URL 添加到 OBS。推广内容使用展示或支持卡片；选择两者以同时包含活动提醒。

  • 立即显示 在已保存的行上执行时，会固定该商品并覆盖定期卡片计划。
  • 下一个商品 固定下一个已保存商品。
  • 隐藏商品 隐藏推广卡片。购买和礼物提醒继续显示。
  • 恢复计划 恢复保存的首个商品或轮播设置。

使用控件前设置显示／隐藏秒数。零表示持续到再次更改；1–3600 表示在相应秒数后恢复保存的计划。实时覆盖会在 SSN 重启时重置。未保存的行会被标记，且其立即显示按钮保持禁用，直到保存设置。状态显示选中商品名称和剩余秒数；不会声称 OBS 正在直播或该来源可见。控件通过精确的已保存 URL 识别商品，因此在列表中移动商品不会破坏自动化。

3. 发布一个观众链接

打开显示选项 > 公开观众页面，并选择 发布已保存链接。此操作明确发布所有已保存的商品／支持链接，包括标题、图片、价格和用途。分享 复制观众链接 给观众。商品二维码现在使用此固定页面，因此叠加层轮播后，观众仍可找到商品。

保存的更改和实时控件会更新同一个 URL。观众页面每 15 秒检查更新，并标记精选商品。推广卡片隐藏时，其他链接仍可访问。SSN 离线时，上次发布的目录仍可访问；页面显示保存时间，精选表示上次保存的选择或轮播，不证明创作者正在直播。

取消发布 移除页面；商品二维码恢复为各商品链接。已打开的观众页面会在下一次成功检查时清空。之前分享的 URL 会停止加载，直到您再次发布。从同一设备重新发布会恢复相同 URL。请保留 SSN 设备配置文件：更新或移除页面需要其中的私有发布密钥。

如果 API 不可用，本地控件仍可使用。更新失败会保留上次发布的页面，并在 SSN 打开期间重试。弹出菜单会报告失败。发布需要部署可选的 public-shop 服务；无需商店或支付账号。

Event Flow 和远程控制

在 Event Flow 中，添加 商品与支持 操作，位于叠加层操作组中。选择显示、下一个、隐藏或恢复；可选填精确的已保存商品 URL 和秒数。使用合适的现有触发器，例如自己的版主命令，不要允许每条聊天消息都更改商品。

在 Stream Deck 插件中，从以下分类添加预设命令按键： 商品与支持：显示商品、下一个商品、隐藏商品和恢复商品。显示包含已保存商品选择器；选择刷新商品和状态以加载列表。无法使用的已保存选择会继续显示，不会悄悄更换。您仍可粘贴公开商品 URL，或留空以使用当前／首个商品。下一个和隐藏可选填秒数。按键等待 SSN 确认本地更改，与公开页面更新无关。可添加可选的商品状态按键，在按键可见时每五秒刷新选中／隐藏／计划状态。属性检查器和 SSN 显示完整商品名称；小型状态按键会截短长名称。使用现有 P2P 或 WebSocket 连接。

现有的经过身份验证的会话远程 API 接受相同控制：

{"action":"commerceControl","command":"show","url":"https://example.com/product","seconds":30}

命令为 show, next, hide 和 resume。省略 URL 可显示当前／首个商品。必须启用主持人控制。切勿向观众分享私有会话／控制 URL；请使用已发布的观众链接。

这些操作仅广播现有的 monetization_update 显示状态。它们不会创建打赏、购买、聊天帖子或 Event Flow 付款触发器。现有的 hasDonation 行为不变。

确认控制何时完成

商品与支持操作会等待 SSN 回复，再继续流程。对于普通事件载荷， meta.commerceControlResult 包含 success ，以及产生的 commerce 控制状态或 error。失败会停止该链中的后续操作；原始购买或打赏仍可供其他流程和叠加层使用。该状态确认 SSN 的选择、隐藏状态或计划；OBS 可见性是独立的。

如果八秒内未收到回复，操作会报告超时。控制可能已生效：重试下一个之前，请检查弹出菜单或停靠面板状态。外部远程客户端应使用现有请求／响应协议并检查返回结果，而不是将命令已发送视为成功。

其他效果有各自的反馈。打印热敏标签会报告 meta.thermalPrintResult；成功提交作业并不能确认纸张已打印。同步 Webhook 操作可以返回 HTTP 状态和响应，并可在失败时阻止继续执行。这些是操作结果，不是新的付款事件。参见 事件参考 了解控制结果约定。
