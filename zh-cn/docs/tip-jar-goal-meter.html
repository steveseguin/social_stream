打赏罐与目标计量器指南

选择计入的内容、设置支持者分值、将叠加层添加到 OBS，并排查看起来不正确的总额。

打赏模式还是热度计分？

模式计入的内容适合
普通打赏罐Super Chat、Cheers/Bits、小费及其他附带打赏金额的数据金额或原生单位目标
打赏次数每个符合条件的付费事件计为一次，不考虑金额例如 7 / 20 次 Super Chat 的目标
热度杯计分（Hype Cup Scoring）打赏、会员/订阅、续费及赠送会员/订阅统一的支持者积分目标
将 Jar 改为 Bar 仅改变外观。 若会员或订阅应推进目标，请启用 Hype Cup Scoring。

选择样式

打开安全的样式预览图库 ，比较浅色或深色背景上的示例布局。预览不会连接到实时叠加层，也不会读取或保存打赏总额。在图库中粘贴现有打赏罐链接，即可复制带样式的链接，并保留会话、目标及过滤器设置。

现有样式默认保留原外观。启用 新版外观 (&refresh），仅在想使用更新的间距、颜色及排版时启用。下方的新样式可单独选择。

所有样式使用相同的打赏总额、过滤器、计数目标、热度计分及循环目标。可在以下位置选择： 样式、目标与过滤器 → 显示样式（Style, Goal, and Filters → Display Style）.

启用 隐藏美元符号 在同一部分中（或添加 &hidecurrency 到叠加层 URL）以显示 0.00 / 500 而不是 $0.00 / $500。此选项默认关闭，仅改变目标显示；打赏值、换算以及 Bits 或其他单位标签保持不变。

  • 罐子（Jar）：带掉落物品的经典杯子。
  • 目标计量器（Goal Meter）：深色面板中显示进度条及最近支持者。
  • 流动目标条（Fluid Goal Bar）：宽幅动画条，适合醒目展示目标。
  • 紧凑条（Compact Bar）：适合角落的小进度条； 垂直条（Vertical Bar）：适合侧边栏的温度计。
  • 极低：大号总额及百分比； 仅文字（Text Only）：简单的文字读数。
  • 目标卡片（Goal Card） (style=card）：带有大号总额及细进度条的紧凑面板。
  • 进度环（Progress Ring） (style=ring）：在目标总额上方显示圆形百分比。
  • 下三分之一字幕条（Lower Third） (style=lowerthird）：宽而矮的面板，标题位于总额旁。
  • 分段条（Segmented Bar） (style=segmented）：带有二十个进度分段的目标面板。
  • 玻璃尖罐 (style=glassjar)：一个有盖的罐子，当吸头从槽中落下时，罐子就会充满。
  • 3D旋转罐 (style=jar3d)：具有真实 3D 液位的可转动玻璃圆柱体。
  • 啤酒杯 (style=beermug), 咖啡杯 (style=coffeemug），以及 药水瓶 (style=potion)：随着液位上升，泡沫、蒸汽和气泡。
  • 存钱罐 (style=piggybank) 和 宝箱 (style=chest）：猪在捐赠时摇晃，随着目标填满，箱子盖打开得更大。
  • 温度计 (style=thermometer)：带有刻度和上升柱的玻璃温度计。
  • 电池 (style=battery), 经验栏 (style=xpbar），以及 生命条 (style=healthbar): 游戏风格的条形在填充时改变颜色。
  • 像素栏 (style=pixelbar), 霓虹灯管 (style=neonbar），以及 终端 (style=terminal）：复古块仪表、发光管和等宽读数。
  • 里程碑轨迹 (style=milestones) 和 拨号 (style=gauge）：五个亮起的检查点，或一根扫针。

随着目标的提高，物理罐子会被填满，每次捐赠都会掉落一个物品，并在表面产生波纹。拾取掉落的物品 掉落物品 (&dropitem=coins，还有 gems, stars, bills，或 hearts）；它也适用于经典的 Jar。 &jarlabel=TIPS 设置玻璃尖罐贴纸， &hidetitle 和 &hidepercent 修剪罐子周围的文字，以及 &nospin 停止 3D 罐子旋转。安 &accent=%23ffcc88 或显式填充颜色对液体重新着色；否则每个罐子都会保持自己的颜色。

目标栏的工作方式相同：每个目标栏都保持自己的颜色范围（例如，电池和生命栏从红色到绿色），直到您设置强调色或明确的填充颜色，并且 &fillmode=solid 或 &fillmode=gradient 改变了颜色的应用方式。当捐款到达时，每个条都会闪烁，并且 &hidetitle 或 &hidepercent 修剪其周围的文本。

新面板支持 Default、Neon 和 Gold 主题。现有填充颜色设置也适用；进度环使用随进度变化的纯色描边。叠加层以外的背景为 OBS 保持透明。

四种新面板的可选控件包括 panelopacity=0.5 (0–1), accent=%2366d9b2 （六位十六进制颜色）， amountsize=32 （12–96 像素），以及 hidepercent。进度填充的明确起始/结束颜色优先于强调色。留空则使用各样式的默认值。进度条文字大小及“仅进度条”适用于 Fluid Goal Bar；自定义罐子图片仅适用于 Jar。

进行设置

  1. 在 Social Stream Ninja 中激活 YouTube、Twitch 或其他来源。
  2. 打开 打赏罐和目标进度条，然后打开其选项。
  3. 仅打赏目标应关闭 Hype Cup Scoring。混合支持者目标则启用它。
  4. 选择目标衡量打赏金额还是符合条件的打赏次数。
  5. 选择显示样式、目标、标题、来源/事件过滤器及持久保存行为。
  6. 复制更新后的 Tip Jar 链接，并将其添加为 OBS 浏览器源。
会话检查： 来源和复制的叠加层 URL 必须使用相同的会话 ID。请将会话和密码值保密。

统计 YouTube Super Chat 次数，而非金额

  1. 将 热度杯计分（Hype Cup Scoring） 关闭。
  2. 设置 目标衡量方式 为 符合条件的打赏次数.
  3. 设置 来源过滤器 为 YouTube.
  4. 设置 付费事件过滤器 为 仅 Super Chat（Super Chats only）.
  5. 设置目标值，例如 20。叠加层显示的进度示例为 7 / 20 Super Chats.

Super Chat 金额不影响计数目标：$1 和 $100 的 Super Chat 都各增加一次。会员、赠送会员、Super Sticker 和 YouTube Gifts 不会推进仅限 Super Chat 的目标。

其他计数目标： 付费事件过滤器可仅统计 Super Sticker，或合并 Super Chat 与 Super Sticker。使用 计数单位标签 以覆盖自动标签。

热度分值如何计算

  • 订阅/会员积分： 为每次新会员/订阅或续费指定固定积分。
  • 赠送订阅/会员积分： 为每份礼物指定固定积分。5 份的组合贡献 5 × giftpoints.
  • 每 USD 打赏积分： 是支持的现金打赏换算为 USD 后应用的倍数。
  • 积分单位标签： 会改变显示标签。使用 $ 不会让会员积分变成确切现金价值。
混合目标过滤器： 将 打赏类型过滤器 在 所有打赏（All donations） ，使会员和礼物也计入。指定打赏单位过滤器目前会将热度计分限制为匹配的打赏行。

YouTube 礼物并非全都相同

YouTube 事件含义计数方式
Super Chat / Super Sticker附带货币金额的付费消息普通或热度模式
赠送会员有人为其他观众购买了会员热度模式使用礼物数量 × 配置的礼物积分
礼物接收者一位观众从赠送组合中获得了一份会员默认不计分，以防重复计数
Jewels / 虚拟礼物具有原生单位数量的独立虚拟礼物事件使用匹配的原生单位过滤器

赠送会员事件提供会员数量及会员等级，但不提供购买价格或创作者净收入。无法从该事件计算其确切现金价值。

避免重复计数： 启用 也统计每位礼物接收者 仅在应将接收者积分加到原始赠礼组合之上时使用。

目标完成与保存的总额

  • 普通打赏目标会保留总额，除非请求重置。
  • 热度目标默认在完成后重置；完成延迟控制完成数值保持可见的时间。
  • 保留超额积分（Carry extra points） 会保留超出已完成目标的积分。
  • 保留总额并推进目标 会创建累计滚动目标。
  • 循环目标增量 会创建循环等级。
  • 在会话之间保留金额 会将金额和历史保存在该浏览器或 OBS 配置文件中。
持久保存的总额按普通/热度模式及当前来源/单位过滤器分开保存，但不按 Social Stream 会话 ID 区分。复用同一浏览器配置文件用于不同目标前，请重置已保存金额。

故障排除

症状检查内容
没有任何更新来源已激活、叠加层已打开、会话 ID 一致，且过滤器匹配该事件。
Super Chat 被计入，但会员不计入启用 Hype Cup Scoring，并将打赏类型保持为 All donations。
赠送会员增加的数值低于预期它们使用固定礼物积分，而非无法取得的购买价格。
达到目标后总额下降热度默认重置；需要累计总额时使用滚动目标。
旧金额重新出现已在同一浏览器或 OBS 配置文件中启用持久保存。
赠送会员出现两次禁用单独的礼物接收者计数。
Super Chat 计数包含 Super Sticker将 Paid event filter 设为 Super Chats only。
赠送会员推进热度目标启用 Exclude YouTube gifted memberships，或从热度计分中排除所有赠礼。

弹出菜单的测试按钮目前仅测试打赏行。遇到会员或礼物问题时，先用同一会话的 Dock 或 Events Dashboard 确认事件到达，再排查目标。
