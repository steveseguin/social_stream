OBS 快速入门

通过最少的步骤将聊天显示在 OBS 中。

1. 选定一个会话 ID

自定义一个简短的会话 ID，并在所有位置使用。聊天来源、停靠面板和 OBS 叠加层通过它找到彼此。

YOUR_SESSION_ID

2. 启动聊天来源

  1. 安装或打开 Social Stream Ninja。
  2. 打开所用平台的聊天来源并保持打开。
  3. 发送或等待一条聊天消息，以确认来源正常工作。

不确定使用哪种来源模式？参见 平台设置选择器.

3. 打开停靠面板

停靠面板是您的测试画面。在更改 OBS 设置前先打开它。

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

4. 添加 OBS 浏览器来源

在 OBS 中添加浏览器来源并粘贴叠加层 URL。

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

对于普通聊天叠加层布局，请使用以下页面中的模板： 模板库.

5. OBS 空白时

按此顺序逐项检查。

  • 先确认停靠面板收到消息。如果停靠面板为空，问题还不在 OBS。
  • 确认 OBS URL 具有相同的 session.
  • 更改 URL 选项后刷新 OBS 浏览器来源。
  • 检查来源聊天页面或应用来源窗口是否仍在运行。
