“ChatGPT”的两种不同含义

选项是什么对话
ChatGPT API 服务SSN 使用你的 API 密钥和所选模型向 OpenAI 发送提示词。SSN/API 对话，与 chatgpt.com 独立。
ChatGPT 浏览器来源扩展会读取已打开的以下页面中呈现的新用户和 ChatGPT 对话： chatgpt.com 标签页。你打开的浏览器对话，不使用 API 密钥。

重要： 连接 OpenAI API 不会将 SSN 接入已有的 ChatGPT 网页或语音对话。OpenAI API 管理自己的对话状态。

选项 1：ChatGPT 浏览器伙伴（实验性）

如果你已在 Chrome 中使用 ChatGPT，又不想使用 API 密钥，这最符合你的需求。SSN 可将页面上的新文本对话捕获为以下来源类型： openai，就像捕获聊天来源一样。

捕获 ChatGPT 对话

  1. 安装并启用 Social Stream Ninja Chrome 扩展。
  2. 在弹出菜单中，主动启用 ChatGPT 来源。
  3. 打开 https://chatgpt.com/ ，启用来源后重新加载页面。
  4. 使用同一会话打开 SSN 停靠面板。
  5. 发送一条新的 ChatGPT 消息。新的用户和 ChatGPT 对话应出现在停靠面板中；已有历史会被有意忽略。

将实时聊天发送到已打开的 ChatGPT 标签页

  1. 使用私人或不公开列出的直播，以及普通 ChatGPT 文字对话进行测试。
  2. 位于 管理，启用 转发所有消息.
  3. 设置 选择转发目标 为 openai ，让捕获的观众消息只发送到 ChatGPT 标签页。
  4. 保持 ChatGPT 标签页打开。新回复会以以下形式返回 SSN： openai 消息。
  5. 使用 ChatGPT 音频或 SSN 的 TTS／叠加层输出，将这些回复用于直播。

实验性： 网页控件可能改变，转发所有消息可能淹没对话，而 ChatGPT 语音模式可能不像普通文字页面那样接受注入文本。发送每条观众消息之前，请先使用过滤器或测试直播。

选项 2：在 SSN 中配置 AI 服务

需要 SSN 生成回复、审核消息、翻译聊天、搜索知识库或构建叠加层时，应配置 AI 服务。

服务类型选项说明
本地Ollama; Local Gemma; Local Qwen无需云端 API 密钥。性能取决于计算机和模型资源。
自定义／本地服务器自定义 OpenAI 兼容 API适用于 llama.cpp、LM Studio、vLLM 和兼容网关。Ollama 应使用其原生选项。
云端OpenAI, Gemini, DeepSeek, xAI, AWS Bedrock, OpenRouter, Groq, OpenCode Zen密钥、访问权限、计费、配额和模型名称均由各服务提供商管理。
试用SSN 托管试用 LLM实验性功能，可能被关闭或限流。
  1. 打开 聊天机器人和 AI 服务 ，位于 SSN 弹出菜单中。
  2. 打开 配置 LLM 服务提供商 ，并选择你实际使用的服务。
  3. 输入端点、模型、API 密钥或本地资源设置。
  4. 选择 测试所选聊天机器人。显示已连接，只能证明服务响应了测试。
  5. 启用需要使用该服务的独立功能：主机器人、私人机器人、联合主持、审核、翻译、RAG 或构建器。

选项 3：语音 AI 联合主持

联合主持专为“一边与 AI 对话，一边让它查看实时聊天”的流程设计。麦克风和所选实时聊天消息进入同一个联合主持会话，回答可在直播中朗读。

  1. 打开 cohost.html?session=YOUR_SESSION.
  2. 选择语音／实时服务，或 SSN 弹出菜单中配置的 LLM。
  3. 明确选择麦克风和 音频回复，然后按 启动联合主持.
  4. 使用 OpenAI Realtime 时，将 Live Chat 保持为 仅上下文 — 提问时才回答 ，适合希望 AI 记住近期观众消息却不打断对话的情况。选择 问题和提及 或 每条消息 以自动朗读回复；这些模式不会向平台聊天发帖。
  5. 使用 OpenAI Realtime 时，在 OBS 中捕获联合主持浏览器或应用的音频，并使用 cohost-overlay.html?session=YOUR_SESSION 显示舞台头像和对话气泡。叠加层不会接收同一条 WebRTC 语音流。如果支持，可在联合主持输出设备选择器中选择虚拟音频线； &forcetts 会有意添加独立的叠加层语音。
  6. 可选直播工具默认关闭。在 SSN 弹出菜单中启用 Spotify、OBS 场景名称允许列表或精选聊天控制，然后在以下位置为控制器启用相同工具： 联合主持直播控制 ，位于联合主持页面。
  7. 要降低 OpenAI 延迟，可选择 Mini 模型、Low 推理强度和 Fast 轮流发言速度。Full quality 和更高推理强度可改善复杂回答，但会增加延迟与 API 费用；Fast 可能打断自然停顿。诊断面板显示测得的首次输出延迟。
  8. OpenAI 摄像头与屏幕共享输入为可选项，默认设置是 无视频。选中后，SSN 会在每次直接语音或文字请求时发送一张当前图像；这不是连续视频流，可能增加 API 费用和延迟。
  9. 保持对话气泡可见，或提供字幕，让观众即使听不到 AI 语音也能跟上对话。

OpenAI Realtime 使用在以下位置配置的 OpenAI 项目密钥： ChatGPT API ，位于 SSN 弹出菜单中。标准密钥保留在 SSN 扩展或桌面应用的后台，后台为联合主持页面创建短期 Realtime 客户端密钥。随后麦克风和 AI 语音音频通过 WebRTC 传输。回复最多输出 512 个 token，诊断面板显示累计用量和延迟。SSN 会检查静默会话并重新连接失败的传输；恢复后的会话会重新应用指令和性能设置，但无法还原之前的语音对话。这会创建一个 SSN 联合主持会话，不会接管 ChatGPT 网站或桌面应用中已有的对话。

打开详细 AI 联合主持指南

选项 4：主直播聊天机器人

主机器人评估捕获到的观众消息，可在叠加层中回答、通过 TTS 朗读，或回发到受支持平台的聊天。

  1. 配置并测试 AI 服务。
  2. 启用 主 AI 聊天机器人.
  3. 选择触发词、仅限管理员行为、频率限制、历史记录和提示指令。
  4. 首次安全测试时，启用 机器人回复仅发送到机器人叠加层页面.
  5. 打开 bot.html?session=YOUR_SESSION ，如需朗读回复，请启用 TTS。
  6. 确认目标平台支持发帖后，才关闭仅叠加层模式。

平台回复通常使用已登录的账户。如果需要独立身份，可在受支持的平台使用专用 YouTube、Twitch 或 Kick 机器人账户。

打开 AI 聊天机器人设置指南

选项 5：私人一对一机器人

chatbot.html 是私人助手和提示词测试页面。启用 聊天机器人 — 私人界面，使用你的会话打开页面，并使用已配置的 LLM 服务。

私人机器人独立于主直播聊天机器人，目前不共享它的 RAG 数据集或其他聊天历史。

工具功能说明安全起步
内容过滤机器人对收到的消息分类、净化或拦截。先使用非拦截模式并检查结果。
翻译翻译收到的聊天，以及可选的主播发送消息。先测试一种语言，在确认可靠之前不要使用拦截模式。
RAG 知识库让主机器人从上传的资源文件中检索相关文本。使用最新、主题集中的文本或 Markdown 文件。
聊天总结允许用户通过以下方式触发 AI 总结： !summary.检查历史记录量、费用和私人内容。

选项 7：AI 叠加层构建器

使用 aiprompt.html 来描述、生成、预览和保存叠加层。使用 aioverlay.html 作为保存后用于 OBS 输出的页面。

打开 AI 叠加层构建器指南

常见解决办法

  • 已连接，但没有实时回复： 启用主机器人或所需 AI 功能；只设置服务不会处理聊天。
  • 联合主持看到聊天却不说话： 仅上下文模式会刻意等待主播询问聊天内容。切换到问题和提及或每条消息，即可自动回复。
  • ChatGPT 浏览器来源没有动静： 启用 ChatGPT 选项，重新加载 chatgpt.com，用新一轮对话测试，不要使用已有历史。
  • 机器人跳过大多数消息： 检查触发词、仅限管理员模式、频率限制，以及要求模型选择性回复的指令。
  • 出现文字但没有声音： 确认生成 TTS 的页面已打开，且 OBS 正在捕获该页面的音频。
  • 机器人无法发帖： 检查平台回发支持、登录状态、账户权限和频率限制。
