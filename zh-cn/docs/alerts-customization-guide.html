设计自定义警报和事件源

重新设计 Multi-Alerts 和捐赠、订阅、礼物、关注和其他支持操作的事件行的样式。

要使最近的警报在 OBS 或 Streamlabs Desktop 中可见，请从 图解事件叠加指南.

选择正确的起始页

使用 multi-alerts.html 用于定时警报演示和 events.html 或 themes/events/index.html 获取正在运行的事件列表。它们具有不同的渲染和队列行为。从为您已使用的工具生成的 URL 开始。

选择活动源样式

打开 活动源/事件 → 启用和自定义 → 源样式，选择布局，然后将更新的链接复制到您的浏览器或 OBS 浏览器源中。打开 自定义提要外观 调整颜色和间距。将字段留空以使用样式的默认值。

例如，附加 &style=twitch&accent=%23e5b94f&padding=8&fontsize=14 以获得带有金色口音的更密集的活动列表。

选择活动源中显示的内容

在 活动源/事件 → 启用和自定义，打开 选择出现哪些事件 或 行内容和行为。将控件关闭并将字段留空以保留默认视图。更改后复制更新的链接。这些控制仅影响此提要；普通聊天仍然被排除在外。

每一行根据其事件名称属于一个类别。指定的会员资格、礼物和购买项目即使包含金额，也会保留其类别。提示与 hasDonation 并且没有识别的事件名称属于付费消息类别，包括 Twitch DOM 位。普通聊天中的会员徽章不会将其变成会员活动。

为了更精细地控制，请使用 filterevents=supersticker,watch_streak 隐藏确切的事件名称。匹配忽略大小写并使用 feed 的现有事件别名；它不搜索消息文本。类别和确切名称排除与现有来源、仅限捐赠、仅限有天赋的订阅者和最小值过滤器相结合。启用多个过滤器可能不会留下任何匹配的事件。请参阅 事件参考 对于特定于源的有效负载。

  • hidemessage, hidecontentimg, hideplatformicons, hideeventlabels 和 hideamounts 隐藏相应的行元素。他们不会丢弃事件或更改点击功能发送的内容。内联表情是消息文本的一部分。这些控件不会编辑消息文本、元数据或 Hype Train 详细信息中写入的金额或名称。
  • nofeature 禁用此 feed 中的点击功能。元数据详细信息仍然可以打开。
  • hidecategorytag hides only the generic category tag, such as Donation or Event, while keeping the descriptive event label. In the popup, enable Hide category tag ；对应的设置项： 行内容和行为.
  • eventduration=60 60 秒后从此 feed 中删除一行。空白或 0 保持现有的保留行为；正值范围为 1 到 86,400 秒。 Hype Train更新重新启动计时器；结束的火车最多 30 秒后仍然消失。删除不会清除已发送到精选叠加层的事件。
  • hideempty 当没有事件可见时隐藏等待消息。

  2. 复制所有内容 ? 继续在您的工作 SSN 覆盖链接中并将其添加到该文件地址的末尾。保留所有设置，包括会话、密码和任何 # 结局。

哪里需要改变设计

更改警报框架、版式、图标位置、进度/计时装饰和动作。在 Multi-Alerts 中，大部分布局是在 multi-alerts.js；当要求人工智能改变结构时包括它。对于孤立的分支，也复制该脚本并仅更新复制的 HTML 脚本引用。

保留事件分类和过滤器。付费聊天行可以使用 hasDonation 不带 event: "donation"；平台也有特定的事件名称。使用 事件参考 和 兼容性指南 选择样本。将原始显示金额和任何数字美元覆盖分开。

测试此覆盖类型

首先使用预览或测试设置。的 测试消息指南 解释了如何通过SSN发送虚构的有效负载；提交到生产会话的测试可以触发其现有的自动化。

  1. 使用测试消息工具发送您的来源支持的特定关注、订阅、礼物、突袭或付费消息；检查哪些字段实际存在。
  2. 发送两个靠近的警报来检查队列和退出动画。测试带有捐赠标签和长名称的空消息。
  3. 对于事件源，检查滚动、过滤和任何点击功能行为。对于声音效果，请检查 OBS 中的源音频以及图片。

同时运行 输入渲染检查 针对您更改的渲染路径。保存编辑后，在排练之间刷新 OBS 浏览器源并重复可见的交互。浏览器预览不会建立实时捕获或 OBS 行为。
