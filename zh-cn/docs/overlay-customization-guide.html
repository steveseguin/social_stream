1.下载实际文件

  1. 下载 beta 源代码 ZIP，或打开 测试版存储库 并选择 代码 → 下载 ZIP.
  2. 将 ZIP 解压到您可以保留的文件夹中，例如 C:\SSN\social_stream-beta\.不要在压缩档案内进行编辑。这些是页面源文件；编辑单独的副本不需要重新安装 SSN。
  3. 找到上表所示的文件。将其复制到原件旁边：例如 poll.html 变为 my-poll.html。对于 themes/featured-styles/featured-modern.html，保留副本 themes/featured-styles/.
  4. 在文本/代码编辑器中打开副本。让您的 AI 工具访问该文件及其所需的引用样式/脚本。将 HTML 保存为 .html，不是 .html.txt.

保留解压后的文件夹结构。 单个下载的 HTML 文件可以在其旁边加载脚本、样式表、字体、图像、音频或 JSON。 GitHub 的页面视图和浏览器的“保存页面”并不是一个可靠的完整包。每个类型指南都会标识有用的文件，但完整提取的文件夹是保留依赖项的最简单方法。

social_stream-beta/
    poll.html
    my-poll.html
    currency.js
    js/
    libs/
    shared/
    thirdparty/
    media/
    sources/images/
    themes/
        featured-styles/
            featured-modern.html
            my-featured.html
    docs/
        event-reference.html

参考文献，例如 ../../shared/utils/chatHtml.js 与加载它的页面相关。将该页面移动到根目录会破坏路径。将本地图稿和字体也复制到项目中，然后使用相对 URL。将下载的版本放在一起；您编辑的副本不会自动接收未来的 SSN 修复。

2. 保留会话和连接设置

启动SSN，连接源，并确认原始叠加工作正常。复制 完整生成的链接 来自相关SSN工具。之后的值 session= 识别您的 SSN 会话；它不是 YouTube 频道、Twitch 用户名、文件名或投票标题。

https://socialstream.ninja/poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

该示例使用占位符。 SSN 和页面必须使用相同的实际会话和任何配置的密码。更改文件名不会更改会话。保持 SSN 并捕获运行：覆盖层接收数据；它本身不捕获平台聊天。

  • ? 开始查询； 后续设置使用 &。复制值而不是重新输入它们。在 HTML 源属性中，写入 &amp;；在 browser/OBS URL 字段中使用普通的 & 符号。
  • 保留传输设置： server, server2, server3，本地端点、标签和版本值是特定于页面的。不要仅仅因为另一个覆盖支持它就添加服务器标志。
  • 也保留片段： 之后的一切 # 可能很重要。例如，AI Event Overlay 使用私有 #aieventauth=... 显示令牌。
  • 在共享示例中使用占位符。 将您的真实会话链接、密码和私人显示令牌保留在公共屏幕截图、存储库和 AI 提示示例之外。

当副本为空时，请先检查原始生成的链接。部分页面提示缺少设置；其他人则保持隐藏或重定向。明确提供正确的会话可以避免依赖那些特定于页面的默认值。

3.打开OBS中的文件

直接从计算机打开编辑后的 HTML。无需安装或启动服务器。

  1. 将复制的 HTML 文件拖到 Chrome 或 Edge 中。从地址栏中复制其完整地址；它开始于 file:///.
  2. 复制所有内容 ? 在您的工作 SSN 覆盖链接中继续并将其添加到该文件地址的末尾。这会保留您的会话、密码、其他设置以及任何 # 结局。
  3. 在浏览器中打开组合地址进行测试。
  4. 在 OBS 中，添加 浏览器来源。将 本地文件 取消选中并将完整地址粘贴到 URL。设置设计的宽度和高度。

例如，这个 SSN 链接：

https://socialstream.ninja/poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

成为 Windows 上下载的投票副本的地址：

file:///C:/SSN/social_stream-beta/my-poll.html?session=YOUR_SESSION&password=YOUR_PASSWORD&server2

使用您的实际文件地址和复制的设置。在 macOS 上，地址开头为 file:///Users/...；在 Linux 上通常以 file:///home/....复制浏览器地址可以为您处理空格和斜杠。

设置一次。 OBS 将地址与源一起保存。将下载的文件夹保留在同一位置，并在使用叠加层时保持 SSN 和您的聊天源运行。保存设计更改后，使用 刷新当前页面缓存 在源属性中。

为什么不选中本地文件？ URL 字段可让您包含 ?session=....仅使用文件选择器选择 HTML 不会添加这些设置。

可选：使用带有启动器的本地文件复选框

OBS的文件选择器选择文件；它不会添加您生成的查询设置。对于未经修改的基于查询的接收器，小型本地启动器可以导航到带有附加设置的编辑页面：

  1. 将以下内容另存为 launch-my-poll.html ，位于以下选项旁： my-poll.html.
  2. 将占位符托管 URL 替换为您完整复制的 SSN 链接。改变 ./my-poll.html 为您实际编辑的文件名。将链接保留在引号内，与普通 & 字符。
  3. 双击启动器进行测试。在OBS中，选择 本地文件 并选择 发射器.它使用查询和片段重定向到本地覆盖。
<!DOCTYPE html>
<html lang="en">
<meta charset="utf-8">
<title>My local overlay launcher</title>
<p>Opening the local overlay...</p>
<script>
var copiedLink = new URL("https://socialstream.ninja/poll.html?session=YOUR_SESSION");
var localPage = new URL("./my-poll.html", window.location.href);
localPage.search = copiedLink.search;
localPage.hash = copiedLink.hash;
window.location.replace(localPage.href);
</script>
</html>

对于嵌套主题，请将启动器放在该主题副本旁边。保持启动器的私密性，因为它包含您的连接链接。下载的独立导出已嵌入其配置，而是遵循其自己的导出指令。

OBS 在以下文件中记录了其文件/URL 模式、尺寸、自定义 CSS 和刷新控件 浏览器源码参考.

4.改变设计，或者让AI来做

对于仅 CSS 更改，请保留托管链接并使用 OBS 自定义 CSS 领域.它仅适用于该源，因此打开相同 URL 的普通浏览器不会显示这些覆盖。对于已编辑的 HTML 文件，请在其现有样式后附加覆盖，或在其后链接本地样式表。提供您的徽标、字体文件、品牌颜色、画布尺寸和视觉参考。

部分页面支持 &css= 或 &b64css=；支持每页。 poll.html两者都没有读取。在使用 URL 选项之前检查页面的解析器。网页通常无法从另一台计算机的本地磁盘加载任意字体或图像。

更改标记时，保留脚本引用的 ID/类。如果 JavaScript 在每次更新时重建一个元素，则永久艺术作品必须位于该元素之外，或者由渲染器重新创建。如果您希望编辑仅影响您的设计，请复制共享样式表/脚本并更改页面的引用。

5. 防止传入的聊天内容成为代码

消息、名称、标题、金额、元数据和媒体链接可以源自查看者或外部服务。在自定义渲染器插入它们的位置进行清理。通过 SSN 接收到的字符串没有执行它的权限。对纯字段使用纯 DOM 文本；对消息正文支持的 HTML 使用打包的清理程序。参见 OWASP 对安全接收器和 HTML 清理的解释.

在SSN中， textonly 仅适用于 chatmessage.如果为 true，则将该正文呈现为文字文本。否则，它可能包含表情和允许的格式。将其他普通字段渲染为文本；媒体领域，例如 chatimg 和 contentimg 是 URL/数据，而不是 HTML 片段。

<!-- Example for a copied page at the repository root. -->
<script src="./libs/objects.js"></script>
<script src="./shared/utils/chatHtml.js"></script>
<script>
function renderChatBody(element, data) {
    var message = String(data.chatmessage == null ? "" : data.chatmessage);
    if (data.textonly) {
        element.textContent = message;
    } else {
        element.innerHTML = SocialStreamChatHTML.sanitize(message);
    }
}
// Names, amounts, titles, and other plain fields use textContent:
// nameElement.textContent = String(data.chatname || "");
</script>

保留现有的等效消毒剂，而不是添加第二种。对于嵌套文件，调整相对脚本路径。在页面现有媒体/链接策略下验证 URL 后，使用 DOM 属性构建头像和链接。不要将原始名称插入属性字符串或将原始颜色插入样式标记；在设置各个属性之前验证样式。 HTML 清理并不能使字符串安全地作为 JavaScript 或 AI 指令执行。

在独立预览中测试渲染器

  • 使用简单的名称，例如 Guest <b>One</b>：括号应保留文本。
  • 试试 chatmessage: "<b>Hello</b>" 带有 textonly: true，则为假。文字标记和允许的格式化内容应采用各自的路径。
  • 检查支持的表情和纯图像消息，以便安全更改不会删除这些功能。
  • 让人工智能测试无害的探针，例如 <img src=x onerror="window.__ssnInjectionProbe=1"> 在更改的渲染器中。它不得执行、设置标记或保留可执行事件属性。还测试脚本方案链接。在本地运行探测器，而不是在公共聊天中运行探测器。

通过的探测仅检查所使用的路径。将测试重点放在因设计而更改的渲染器和字段上。

6. 分别测试布局、连接和OBS

  1. 布局： 使用页面记录的预览/演示模式（如果可用）或虚构的本地示例。测试长名称/消息、缺少头像、空数据和预期行数。
  2. SSN发货： 保持SSN活跃并使用 创建测试消息 与同一届会议。常用的Extension API摄取模式需要 扩展的远程 API 控制 启用。使用隔离的测试设置；提交的测试可以触发配置的自动化。
  3. 实际触发： 为特色卡片提供 Dock 消息、发送民意调查投票、选择赠品获胜者、更改股票代码文本或启动计时器。简单的聊天并不是一个通用的测试。
  4. 实拍： 确认实际的源消息/事件到达原始和编辑的页面。模拟事件证明渲染，而不是平台捕获。
  5. OBS： 检查源的最终大小、透明度、动画、音频、字体和分层。练习显示/隐藏、清除/重置和刷新。浏览器和OBS有独立的存储和会话；浏览器登录或localStorage不会自动共享。

对于在内存中收集数据的页面，卸载或刷新可能会丢失状态。在启用自动刷新或隐藏时关闭之前，请检查类型指南。主机管理的显示器具有不同的恢复行为。删除 demo/preview 在期待实时数据之前进行标记。
