Social Stream Ninja 隐私政策

最后更新：2026 年 9 月 8 日

Social Stream Ninja 是用于捕获、转发、显示和自动化直播聊天及相关直播事件的开源软件。本政策适用于 Social Stream Ninja 浏览器扩展、托管的 Social Stream Ninja 页面和叠加层、通常称为 SSAPP 的独立桌面应用，以及适用于 Elgato Stream Deck 的原生 Social Stream Ninja 插件。

1. 范围和总体原则

使用 Social Stream Ninja 核心软件无需中央用户账号。但根据您的配置，软件可能访问、处理、存储和传输在某些法律下属于个人信息的信息。

在许多情况下，软件在您的设备本地运行，并由您控制。但某些功能使用第三方平台、用户配置的目标或托管辅助服务，这些服务可能接收执行所请求功能所需的数据。

2. 软件可能处理的信息

根据您启用的功能，Social Stream Ninja 可能处理以下类别的信息：

  • 身份验证信息：用户输入或所连接服务授予的 OAuth 访问令牌、刷新令牌、API 密钥、客户端 ID、客户端密钥、频道或房间凭据、会话令牌、密码及类似授权数据。
  • 个人通信：从所连接平台接收的聊天消息、回复、聊天命令、管理操作、会员消息、打赏消息、支持消息，以及其他用户提交的通信内容。
  • 浏览历史和页面上下文：支持的页面 URL、标签页信息、频道名称、用户名、视频 ID、房间 ID、直播标识符，以及连接或监控来源所需的相关页面上下文。
  • 网站内容：聊天 DOM 内容、消息内容、事件内容、直播元数据、观众数量、徽章、表情、个人资料图像，以及支持的页面或 API 上提供的其他内容。
  • 个人身份信息和个人资料数据：用户名、显示名称、头像、账号或频道 ID、徽章、名称颜色、会员状态、关注者/订阅者标签及类似个人资料元数据。
  • 配置和本地应用数据：设置、已连接来源、自定义命令、屏蔽列表、允许列表、本地缓存、文件句柄信息，以及维持软件在设备上运行所需的其他数据。
  • 可选的媒体和文件数据：如果启用可选的捕获、导出、滚动条、日志或文件功能，软件可能处理所选本地文件、导出文件、标签页/媒体捕获数据或用户创建的备份。

3. 信息的使用方式

Social Stream Ninja 可能将这些信息用于：

  • 连接支持的聊天、事件和直播来源。
  • 显示聊天消息、叠加层、仪表板、提醒、等候名单、投票、记分板及相关界面。
  • 执行用户启用的管理、筛选、自动化、转发、机器人、TTS、AI、翻译或导出功能。
  • 向第三方平台进行身份验证并维护来源会话。
  • 缓存查询结果并维护本地应用状态，使软件在各会话之间持续工作。
  • 将数据发送到用户明确配置的目标，例如 webhook、本地文件、本地 websocket 端点、第三方机器人或其他服务。

4. 本地存储和设备存储

Social Stream Ninja 将大量工作数据存储在用户设备本地。根据使用的界面，这可能包括浏览器存储、localStorage、sessionStorage、IndexedDB、扩展存储、Electron 应用存储，以及用户选择的可选文件。

这些本地数据可能包括设置、已连接来源详情、缓存的频道或个人资料查询结果、用户启用时的消息历史，以及已启用功能所需的身份验证/会话数据。

独立桌面应用也可能在设备上保留设置和来源存储的本地恢复备份。这些本地备份可能包含 OAuth 令牌或其他会话状态，让应用能在重启或故障后恢复之前可用的会话。

Stream Deck 插件将其 Social Stream Ninja 会话 ID 和连接偏好存储在 Stream Deck 本地插件设置中。移除插件或清除其设置会从 Stream Deck 中移除该插件配置。

5. 数据可能离开设备的情况

根据您使用软件的方式，信息可能在以下情况下传出设备：

我们不出售用户数据。

Social Stream Ninja 的设计不会在本政策所述传输之外转移用户数据。这些传输可能发生于使用已连接平台、用户启用的功能、用户配置的目标、必要的辅助或服务提供商时，或安全和法律义务要求时。

  • 已连接平台和 API：连接 YouTube、Twitch、Kick、Facebook、Discord 或其他支持的服务时，软件会向这些平台发送请求，并可能接收或传输聊天、事件、个人资料和身份验证相关数据。
  • 托管辅助服务：某些功能使用辅助端点或托管页面进行身份验证、查询、传输、聊天，或提供回退资源。当前版本中的示例包括用于身份验证交换、查询或托管页面的 Social Stream Ninja 或相关辅助域名。
  • Stream Deck 控件：Stream Deck 插件将配置的会话 ID 和请求的命令数据发送到用户选择的 Social Stream Ninja websocket 或 HTTP 端点。启用 HTTP 回退时，命令数据可能编码在请求 URL 中。
  • 用户配置的目标：如果启用 webhook、转发、机器人、AI 提供商、TTS 提供商、直播工具、websocket 服务器或其他集成，软件可能将消息内容、用户名、头像、事件载荷和相关元数据转发到这些目标。
  • 对等连接或传输服务：如果使用 VDO.Ninja、WebRTC、TURN 转发、隐藏的 iframe 桥接或基于 websocket 的传输，数据可能经过这些系统。可选的 websocket 传输可能不采用端到端加密。

6. YouTube 和其他基于 OAuth 的功能

有限使用： Social Stream Ninja 对从 Google API 接收的信息的使用遵循 Chrome 网上应用店用户数据政策，包括其“有限使用”要求.

使用 YouTube API 服务或其他基于 OAuth 的集成时，Social Stream Ninja 可能请求所选功能所需的授权令牌及相关账号访问权限。

  • YouTube：根据启用的 YouTube 功能，软件可能访问 YouTube 直播聊天消息、消息元数据、频道信息、头像信息、直播状态、管理端点，以及观众或订阅者统计信息。
  • 托管身份验证辅助服务：在某些版本和模式中，OAuth 授权码交换或令牌刷新可能通过托管辅助服务处理，而不是完全在设备上处理。如果使用此模式，授权码、刷新令牌和相关令牌请求数据可能经过该辅助服务，以完成登录。
  • 本地令牌存储：根据所用功能和登录流程，令牌可能存储在用户设备本地；如果需要远程交换或刷新，也可能发送到辅助服务。
  • Google 政策：您对 YouTube 功能的使用还须遵守 Google 隐私政策。您可以通过 Google 账号权限设置撤销 Google 访问权限。

7. 桌面应用错误报告

独立桌面应用包含可选的错误报告功能，除非用户启用，否则该功能处于禁用状态。

  • 启用后，桌面应用可能将错误消息、堆栈跟踪、应用版本、随机安装 ID、上下文及经过净化的设置发送到开发者的错误报告端点。
  • 截至撰写时，桌面应用内的披露说明指出，OAuth 令牌、会话数据和备份凭据不会包含在这些报告中。
  • 截至撰写时，桌面应用内的披露说明指出，这些报告通过 Cloudflare Worker 端点发送，并保留 30 天。用户应在启用此功能前查看当前应用内的披露说明。

8. 第三方服务和用户配置的集成

Social Stream Ninja 可以与多种第三方平台和用户选择的服务交互。它们的隐私政策、条款、安全控制和保留做法独立于本政策，且可能存在重大差异。

如果将软件配置为向第三方服务发送数据，您有责任审查这些服务，并决定是否有权向其发送该数据。

9. 保留、删除和用户控制

由于 Social Stream Ninja 的许多功能在本地运行，保留期限通常取决于用户的设备和配置。

  • 本地设置、缓存、令牌和备份可能保留在设备上，直到用户清除存储、移除来源、重置应用、删除导出文件、撤销令牌或卸载软件。
  • 用户配置的第三方目标可能根据自身政策保留转发数据的副本。
  • 托管辅助服务或 API 可能根据其自身做法记录或保留技术请求数据。本政策不保证第三方服务的任何具体保留期限。

10. 安全与风险

  • 不保证绝对安全：没有任何软件或网络服务是绝对安全的。使用 Social Stream Ninja 的风险由您自行承担。
  • 会话和来源凭据：如果直播 ID、房间 ID、令牌、密码或转发链接被他人知晓，这些人可能根据您的配置查看或注入数据。
  • 传输风险：WebRTC、TURN、websocket、webhook、转发和第三方 API 流量可能向承载这些流量所需的服务披露信息。

11. 用户责任

用户决定将哪些网站、账号、聊天和服务连接到 Social Stream Ninja，捕获什么数据，显示哪些叠加层，保存哪些文件，以及向哪些外部服务转发数据。

  • 您有责任确保自己有权且具有合法依据，对通过软件处理的任何数据进行收集、处理、显示、存储、导出或转发。
  • 您有责任遵守适用于相关服务及您所处理数据涉及的个人的服务条款、隐私条款和当地法律。
  • 您应将令牌、密码、房间 ID、直播 ID 和导出数据视为敏感信息。

Social Stream Ninja 按“现状”和“可用状态”提供，不附带任何明示或默示保证，包括适销性、特定用途适用性及不侵权的默示保证。
