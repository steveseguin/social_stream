Передайте чат в оверлей

Lite подключает поддерживаемые источники чата из браузера или OBS. При использовании обычной ссылки на оверлей держите Lite открытым во вкладке или док-панели OBS. Экспериментальный автономный режим OBS захватывает и показывает чат в одном источнике браузера.

Настройка · Настройки только в OBS · Источники · Существующие настройки · Устранение неполадок

1. Настройте оверлей

  1. Откройте Lite. ID сеанса и URL оверлея создаются автоматически и запоминаются в этом браузере.
  2. Подключите один из источников ниже. Используйте его Варианты кнопку для настройки канала.
  3. Выберите Копировать ссылку. В OBS добавьте Браузер источник и вставьте ссылку в поле URL. Также можно использовать Открыть оверлей док-панели для проверки в браузере.
  4. Выберите Отправить тестовое сообщение в Lite. Убедитесь, что оно появилось в открытом оверлее. Сообщение только в ленте активности Lite не подтверждает, что оверлей его получил.

Для прозрачного оверлея или другого порядка сообщений откройте параметры рядом с Ссылка на оверлей чата. После изменения этих параметров скопируйте обновлённый URL в OBS.

2. Выберите источники

Для работы только в OBS выберите один из двух вариантов ниже. Если захват выполняется в OBS, отдельная вкладка настольного браузера не нужна.

ИсточникЧто делать
YouTubeВойдите через YouTube. Lite ищет вашу прямую трансляцию. В параметрах можно задать Video ID или Live Chat ID конкретного эфира. По умолчанию используется опрос; дополнительный потоковый API помечен как beta. У трансляции должен быть доступен чат.
TwitchВойдите через Twitch. По умолчанию Lite использует ваш канал; другой можно задать в параметрах. Если срок авторизации истёк, войдите снова.
KickВведите имя канала в параметрах и подключитесь. Если автоматический поиск не сработает, проверьте написание канала, затем при необходимости используйте ручные настройки комнаты чата.
TikTokСейчас интеграция скрыта в стандартной панели Lite. Ей нужен совместимый прокси TikTok Chat Reader; заранее заполненный адрес не гарантирует доступность сервиса. Доступные варианты захвата TikTok используйте в полном приложении.

Отключить останавливает этот источник. Для YouTube и Twitch вход сохраняется, чтобы можно было использовать Подключить (Connect) снова. Выйти удаляет сохранённую авторизацию в этом браузере.

3. Используйте существующую настройку Social Stream

Для передачи в существующую док-панель или оверлей откройте параметры сеанса Lite и введите его ID. Выберите Сохранить ID сеанса или нажмите Enter. Изменение ID переключает место отправки сообщений Lite; обновите URL источников браузера, которые должны следовать за ним.

Используйте только один способ захвата каждого канала в одном сеансе. Одновременный захват одного чата через Lite и расширение или настольное приложение может создавать дубликаты. Можно использовать Lite для одного канала, а полное приложение — для остальных источников.

Созданная Lite ссылка использует пароль сеанса по умолчанию. Для сеансов с паролем или собственным сервером могут потребоваться настройки подключения полного приложения. Lite не заменяет управление захватом, автоматизацией, модерацией и оформлением оверлеев в полном приложении.

Элементы управления в разделе «Активность» Только пожертвования и Озвучивание текста относятся к представлению активности Lite. При использовании отдельного окна активности держите основную страницу Lite открытой. Считайте URL оверлея приватным, если не хотите, чтобы другие подключались к сеансу.

Работа полностью внутри OBS

Вариант A: док-панель Lite + обычный оверлей

  1. Открыть Работа полностью внутри OBS в Lite и скопируйте URL пользовательской док-панели OBS (lite/index.html?view=dock).
  2. Добавьте его в OBS в разделе Пользовательские док-панели браузера. Войдите в аккаунты и настройте источники в этой док-панели. Параметры источников и сеанса остаются доступны там.
  3. Скопируйте обычный URL оверлея из док-панели в источник браузера OBS. Во время захвата держите док-панель Lite открытой. Источник только показывает сообщения, поэтому отдельный вход в аккаунт провайдера ему не нужен.

Это самый простой вариант работы только в OBS: захват находится в док-панели, отображение — в источнике браузера. Закрытие док-панели останавливает захват. После настройки настольный браузер не требуется.

Вариант B: один источник браузера для захвата и оверлея (экспериментально)

  1. Добавьте URL автономного захвата и оверлея (lite/index.html?view=overlay) как источник браузера OBS.
  2. Открыть Взаимодействовать для настройки источников. Если они уже настроены, нажмите Escape в окне взаимодействия, чтобы снова открыть настройку. Страницы входа и элементы настройки видны в этом источнике, поэтому настраивайте его вне эфира.
  3. Выберите Показать оверлей. Теперь страница сама показывает входящий чат на прозрачном фоне. Ей не нужна другая вкладка Lite, док-панель или ретрансляционное соединение; она не передаёт сообщения другим оверлеям сеанса.
  4. Оставьте Отключать источник, когда он не виден и Обновлять источник браузера при активации сцены выключенным, чтобы не прерывать захват при смене сцен. См. Свойства источника браузера OBS.

Сохранённые действительные данные YouTube/Twitch восстанавливают подключение при запуске. Для Kick включите Автоматически переподключать этот канал Kick в режимах OBS в его параметрах. Сначала настройте канал. TikTok остаётся скрытым. Изначально все сообщения видимы, а озвучивание выключено, независимо от сохранённых предпочтений обычного представления активности.

Док-панели OBS, источники браузера OBS и настольные браузеры могут использовать разные профили cookies/хранилища. Не считайте, что настройка док-панели выполняет вход и в независимый источник браузера. Если вход внутри источника браузера OBS не завершается, используйте вариант A. Вход у провайдеров непосредственно в OBS ещё требует проверки в реальных условиях; режим экспериментальный.

Используйте одно место захвата на канал. Не оставляйте док-панель захватывать тот же канал, что и автономный источник захвата и оверлея. При использовании одного источника захвата в нескольких сценах выбирайте существующий источник OBS.

Устранение неполадок

Мой оверлей пуст
Убедитесь, что Lite остаётся открытым, а оверлей использует тот же ID сеанса. Отправьте тестовое сообщение. Если тест приходит, а чат — нет, проверьте статус источника и канал. Если не приходит ничего, проверьте URL оверлея и не блокирует ли сеть соединение с ретранслятором.
Копирование ссылки заблокировано
Нажмите на видимый URL оверлея, затем скопируйте выделенный текст клавиатурой или через меню копирования устройства.
Источник неактивен или показывает ошибку
Проверьте параметры и текст ошибки. После исправления настроек подключитесь заново. Для YouTube и Twitch может понадобиться повторный вход, если срок авторизации истёк.
Я вижу повторяющиеся сообщения
Проверьте, не захватывает ли тот же канал и сеанс вторая вкладка Lite, расширение или настольное приложение. Оставьте только нужный захват.
Настройки исчезли
Настройки сохраняются в локальном хранилище этого браузера. Другой браузер, приватное окно или очистка данных сайта используют другой набор настроек.
