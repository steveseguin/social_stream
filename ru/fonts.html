Показывает доступные браузеру шрифты и их образцы, а также даёт URL-параметр для применения шрифта ко всему сайту.

Как установить собственные шрифты

  • Windows: Щёлкните правой кнопкой файл .ttf или .otf → выберите «Установить» или «Установить для всех пользователей» → перезапустите браузер.
  • macOS: Дважды щёлкните файл .ttf или .otf → нажмите «Установить шрифт» в приложении «Шрифты» → перезапустите браузер.
  • Linux: Скопируйте файлы шрифтов в ~/.local/share/fonts/ → выполните fc-cache -fv → перезапустите браузер.

После установки обновите страницу, чтобы увидеть новые шрифты. Если шрифт не появился, попробуйте кнопку «Попробовать Local Fonts API» (только в браузерах на базе Chromium).

Использование определённого шрифта через URL

  • Параметр: Добавьте ?font=<Font%20Family%20Name> к URL. Пробелы и символы необходимо кодировать для URL.
  • Применяется к CSS-переменной: Ваш сайт использует --font-family; эта страница также учитывает её. Пример: ?font=Segoe%20UI.
  • Кавычки не нужны: Не заключайте значение параметра в кавычки; они не нужны в CSS-переменной.
  • Только установленные: Параметр работает только для шрифтов, уже установленных в вашей системе. Он не загружает веб-шрифты.

Совместимость (приложения Ninja)

  • VDO.Ninja: Создано ?font= ссылки работают с оверлеями/сценами, учитывающими --font-family переменную.
  • SocialStream.Ninja: Используйте то же значение ?font= параметр для замены стандартного шрифта в поддерживаемых виджетах.
  • Caption.Ninja: Применить ?font= к оверлеям субтитров, поддерживающим собственные семейства шрифтов.

Эти приложения позволяют переопределять семейство шрифта, если ?font= параметр поддерживается в их URL или ссылках для встраивания. Этот инструмент создаёт правильно закодированные значения, готовые к использованию.

Устранение неполадок (Windows)

  • Точное название семейства: Используйте семейство семейства шрифта (не имя файла). Точное название семейства смотрите в разделе Параметры → Персонализация → Шрифты.
  • Правильная область установки: Если шрифт установлен для другого пользователя Windows или только через учётную запись администратора, текущий браузер может его не видеть. При необходимости установите его «для всех пользователей».
  • Поддерживаемые форматы: Браузеры используют TrueType/OpenType/WOFF. Устаревшие Type 1 и некоторые растровые шрифты не поддерживаются.
  • Наличие начертания/стиля: Если установлено только начертание Bold, обычный текст может отображаться другим шрифтом. Попробуйте полужирный образец или также установите Regular.
  • Ограничения конфиденциальности: Браузеры не позволяют получить полный список шрифтов без разрешения. Эта страница проверяет большой список известных шрифтов и при необходимости использует Local Fonts API.
  • Local Fonts API: В Chromium на защищённых адресах (https/localhost) кнопка «Попробовать Local Fonts API» может показать точный список установленных семейств после предоставления разрешения.

Советы по ручному использованию

  • Принудительно задать шрифт: В вашем CSS: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • Проверка произвольного названия: Введите любое семейство в строке поиска; если оно найдено, оно появится в результатах с образцом.
  • Кодирование: Создавайте ссылки такого вида: ?font=Segoe%20UI (в созданных ниже ссылках используется правильное кодирование).
  • Шрифты CJK и других систем письма: Образец содержит латиницу, цифры и символы. Замените его текстом нужной системы письма, чтобы проверить отображение знаков.

Примечание: эта страница не устанавливает и не загружает шрифты; она только находит и показывает семейства, уже доступные браузеру.
