Обзор

SSN может читать захваченный текст чата из любого поддерживаемого источника; платформе чата не нужна собственная функция TTS. Ваша док-панель или оверлей с включённым TTS озвучивает получаемые сообщения с учётом своих фильтров и настроек озвучивания. Начните с краткого руководства по настройке; эта страница описывает варианты голосов и расширенные настройки. Сравните провайдеров, послушайте образцы и посмотрите настройки.

Быстрый старт: Используйте dock.html?session=YOUR_SESSION&speech=en-US. По умолчанию используется System TTS. Для бесплатного провайдера в OBS добавьте также &ttsprovider=kokoro. Оставьте эту страницу открытой и подключённой; озвучивать должна только одна копия.

Где используется озвучивание текста?

  • Social Stream Ninja: Читает сообщения зрителей в нескольких интерфейсах
  • CAPTION.Ninja: Предлагает скрытые субтитры, транскрипцию и перевод с озвучиванием
  • Оба сервиса предлагают платные и бесплатные варианты TTS
System TTS — лишь один из вариантов бесплатного озвучивания:
  • Системные голоса зависят от браузера и операционной системы. OBS может не предоставлять ни одного пригодного голоса, даже если Chrome/Edge работает.
  • Отсутствие голоса и воспроизведение речи вне захвата звука OBS — разные проблемы. Маршрутизация звука не добавляет отсутствующую поддержку речи.
  • Бесплатные провайдеры вроде Kokoro, Piper, Kitten и eSpeak вместо этого создают звук страницы. Для озвучивания текста в OBS платить не обязательно.
  • Сначала проверьте доступность голосов, затем захват звука.

Варианты провайдеров озвучивания

System TTS (бесплатный)

  • Использует встроенные голоса вашей операционной системы
  • Ограниченная поддержка языков в зависимости от установленной системы
  • Доступность голосов и маршрутизация звука зависят от браузера и операционной системы; проверяйте в реальном проигрывателе
  • Совместимость браузеров существенно различается

Локальное / бесплатное озвучивание текста (без ключа API)

Хотите полностью локальное ИИ-озвучивание? В Social Stream Ninja встроено несколько качественных ИИ-голосов, которые работают в вашем браузере — без ключа API, облака или дополнительной установки. Доступность системных голосов

Это типичные возможности, а не гарантии для каждой установки. OBS использует собственный встроенный браузер и не наследует список голосов установленного Chrome/Edge. Успешный тест в приложении SSN не проверяет отдельный источник «Браузер» в OBS.

Ограничения браузеров:
  • Браузеры поддерживают озвучивание текста по-разному (в некоторых версиях Firefox выбор голосов ограничен)
  • Chrome предлагает варианты TTS от Google
  • Edge поддерживает TTS Microsoft и голоса языковых пакетов Windows
  • Для запуска звука в Safari требуется действие пользователя
  • Проверьте доступные голоса для вашего браузера

Способы захвата звука TTS Windows для OBS

Звук страницы: бесплатные локальные и облачные провайдеры

Локальные браузерные провайдеры SSN и облачные аудиопровайдеры воспроизводят созданный звук через страницу:

  • Просто включите «Управлять аудио через OBS» (Control audio via OBS) в источнике «Браузер»
  • Виртуальные аудиокабели не нужны
  • Работает с приложением SSN и источниками «Браузер» OBS

Способы захвата System TTS

Важно: Сначала убедитесь, что System TTS создаёт речь. Встроенный браузер OBS может не предоставлять пригодный системный голос. Если речь не создаётся, изменение маршрутизации звука не поможет. Выберите другого провайдера или создавайте речь в поддерживаемом браузере и захватывайте его звук.

Именно для System TTS:

  • Не считайте, что OBS предоставляет те же голоса, что Chrome или Edge
  • Ограниченная поддержка в разных браузерах (в Firefox могут отсутствовать некоторые голоса TTS)
  • Chrome предлагает варианты Google, а Edge — Microsoft
  • Если речь воспроизводится вне источника «Браузер» в сцене, захватывайте этот вывод отдельно

Скачать средства маршрутизации: VB-Audio Virtual Cable | Voicemeeter | Audio Router (устаревший)

Сначала попробуйте захватить говорящий браузер через звук приложения или рабочего стола в OBS, если это поддерживается. Способы с виртуальным кабелем ниже — необязательные альтернативы; они не добавляют поддержку речи в OBS.

Способ 1: стандартная маршрутизация звука с виртуальным кабелем

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Способ 2: маршрутизация приложения в Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Способ 3: маршрутизация приложения в Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Способ 4: программа Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Способ 5: Voicemeeter (для опытных пользователей)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Проверка настройки

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Альтернативы: Используйте бесплатного встроенного провайдера, например Kokoro, Piper, Kitten или eSpeak, облачного провайдера либо собственный сервер TTS.

Установка дополнительных языковых пакетов

Windows 11

  1. Перейдите в Пуск > Параметры > Время и язык > Речь
  2. В разделе Управление голосами (Manage Voices), нажмите Добавить голоса (Add Voices)
  3. Выберите нужные языки и нажмите Добавить
  4. Перезапустите браузеры, чтобы обновить список доступных голосов

Windows 10

Следуйте инструкциям в официальном руководстве Microsoft по установке языковых пакетов.

Совет: Некоторые сторонние голоса могут не появляться в браузерах из-за проблем совместимости. Firefox часто показывает больше системных голосов, чем браузеры на базе Chromium.

Параметры URL для настройки озвучивания

Основные параметры

Параметр Описание Пример
&speech Включить озвучивание с кодом языка &speech=en-US
&pitch Высота голоса (от 0.1 до 2.0) &pitch=1.2
&volume Уровень громкости (от 0.0 до 1.0) &volume=0.8
&rate Скорость речи (от 0.1 до 10.0) &rate=1.5
&voice Частичное совпадение названия голоса &voice=google
&ttsprovider Выберите провайдера: kokoro, piper, kitten, espeak, openai, customtts, localtts, elevenlabs, google, speechify, gemini &ttsprovider=customtts

Расширенные параметры

Параметр Описание
&simpletts Не произносить «говорит» или «кто-то говорит»
&simpletts2 Вообще не читать имена участников чата
&ttscommand Включить собственную команду озвучивания (по умолчанию: !say)
&readevents Включить события стрима в озвучивание
&skipmessages=3 Читать только каждое третье сообщение

Настройка провайдера озвучивания

Kokoro TTS (бесплатный, встроенный)

  • Включите с помощью ?ttsprovider=kokoro
  • Работает в браузере через WebGPU/WASM — сервер не нужен
  • Работает непосредственно с источником «Браузер» OBS
  • Выбор голоса: &voicekokoro=af_bella
  • Управление скоростью: &kokorospeed=1.2
  • Выберите голос для языка: &voicekokoro=ef_dora для испанского или &voicekokoro=pf_dora для бразильского португальского. Изменение &speech= само по себе не меняет выбранный голос. Существующие ID английских голосов продолжают работать.

Piper TTS (бесплатный, встроенный)

  • Включите с помощью ?ttsprovider=piper
  • Быстрое нейросетевое озвучивание в браузере с низкой нагрузкой на CPU
  • Выбор голоса: &pipervoice=en_US-hfc_female-medium
  • Португальские голоса: &pipervoice=pt_BR-faber-medium или &pipervoice=pt_BR-edresson-low
  • Испанские голоса: &pipervoice=es_ES-davefx-medium или &pipervoice=es_MX-ald-medium
  • Управление скоростью: &piperspeed=1.0

Kitten TTS (бесплатный, встроенный)

  • Включите с помощью ?ttsprovider=kitten
  • Компактное озвучивание на основе ONNX, работающее в браузере
  • Выбор голоса: &kittenvoice=expr-voice-4-f

eSpeak-NG (бесплатный, встроенный)

  • Включите с помощью ?ttsprovider=espeak
  • Классическое озвучивание с открытым исходным кодом, работает на любом оборудовании
  • Выбор голоса: &espeakvoice=en
  • Пример на португальском: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Пример на испанском: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Управление скоростью: &espeakspeed=175

Примеры озвучивания на португальском и испанском

  • Португальский, лучшее бесплатное локальное качество из проверенных в SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Португальский, самый быстрый запасной вариант из проверенных в SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Испанский, лучшее бесплатное локальное качество из проверенных в SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Испанский, самый быстрый запасной вариант из проверенных в SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Для облачных голосов используйте голос/язык провайдера, поддерживающий нужный язык, например Google Cloud, ElevenLabs, Speechify, Gemini или локальный сервер, совместимый с OpenAI.

Озвучивание OpenAI / локальный сервер

  • Включите с помощью ?ttsprovider=openai
  • Используйте ?ttsprovider=customtts или ?ttsprovider=localtts для собственной конечной точки
  • По умолчанию использует API OpenAI или любой совместимый локальный сервер
  • Своя конечная точка: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Важно: localhost и 127.0.0.1 означают тот же компьютер, на котором воспроизводится страница TTS. Если OBS работает на другом компьютере, чем сервер TTS, используйте вместо этого IP-адрес компьютера с сервером в локальной сети.
  • Для локальных серверов ключ API не требуется
  • Если у локального сервера возникают проблемы CORS или доступа к локальной сети в Chrome/OBS, запустите npm run local-tts-bridge на компьютере с OBS и укажите в SSN http://127.0.0.1:8124/v1/audio/speech
  • SSN отправляет { model, input, voice, response_format, speed } и поддерживает двоичное аудио, URL аудио в JSON и аудио base64 в JSON
  • Воспроизведение с собственной/локальной конечной точки пока буферизуется; SSN ещё не воспроизводит потоковые фрагменты аудио по мере их получения
  • Голос: &voiceopenai=af_bella, скорость: &openaispeed=1.0. Используйте название голоса, поддерживаемого вашим сервером; голоса Kokoro выглядят так: af_bella, а голоса openedai-speech/в стиле OpenAI могут выглядеть так: nova или echo.
  • См. Руководство по локальному ИИ-озвучиванию для настройки собственного сервера

Google Cloud TTS

  • Включите с помощью ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Голоса профессионального качества
  • Выбор голоса: &voicegoogle=en-GB-Standard-A
  • Язык: &googlelang=en-US

Озвучивание Gemini

  • Включите с помощью ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Модель: &geminimodel=gemini-2.5-flash-preview-tts
  • Голос: &voicegemini=Kore, язык: &geminilang=th-TH
  • Инструкции по стилю: &geministyle=Read aloud in a warm tone.

Озвучивание ElevenLabs

  • Включите с помощью ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • ID голоса: &voice11=YOUR_VOICE_ID
  • Модель: &elevenlabsmodel=eleven_multilingual_v2
  • Можно настроить параметры стабильности, сходства и стиля

Озвучивание Fish Audio

Выберите Fish Audio и введите ключ API, при желании указав ID голоса. Модель по умолчанию — s2.1-pro-free. Настройка, варианты моделей и ограничения доступа браузера.

Озвучивание Speechify

  • Включите с помощью ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Голос: &voicespeechify=henry
  • Модель: &speechifymodel=simba-3.0 (по умолчанию) или &speechifymodel=simba-3.2 для английского.
  • Скорость речи: &speechifyspeed=1.2 (от 0.5 до 3.0; обычная — 1.0).
  • Руководство по настройке Speechify, голосам, скорости и громкости

Устранение неполадок

Частые проблемы

  • Звук не воспроизводится: Проверьте, включено ли озвучивание текста, открыта ли страница, которая его создаёт, и не отключён ли звук источника «Браузер». В обычном браузере нажмите на страницу один раз.
  • Голоса не отображаются: Перезапустите браузер после установки языковых пакетов
  • OBS не захватывает звук: Если речи нет, сначала проверьте доступность голоса/провайдера. Если речь есть, проверьте Управлять аудио через OBS, отключение звука в микшере и дорожки вывода либо захватите внешний браузер, воспроизводящий речь
  • Локальная конечная точка работает при тестировании в приложении, но не в OBS: OBS — отдельный браузер. Проверьте конечную точку с компьютера OBS, особенно если используете 127.0.0.1.
  • Читается только первая буква или первые слова: удалите ttsquick из URL OBS, если он присутствует.
  • Проблемы Safari: Safari ограниченно поддерживает автоматическое озвучивание
  • Платный сервис не работает: Проверьте ключ API и правильность выбора провайдера

Рекомендации

  • Для более простой настройки OBS используйте провайдера, который создаёт звук страницы; доступны бесплатные локальные варианты
  • Проверьте настройку простыми фразами перед выходом в эфир
  • Учитывайте риски пользовательского содержимого при озвучивании
  • Предусмотрите переключатель для быстрого отключения озвучивания при необходимости

Проверить системные голоса этого браузера

Здесь перечислены Только голоса System TTS в браузере, где открыто это руководство. Здесь не проверяются OBS, отдельное окно приложения SSN или провайдеры вроде Kokoro. Пустой список не означает, что другие провайдеры TTS в SSN недоступны.
