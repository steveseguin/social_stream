Руководство по настройке YouTube

Осознанно выберите живой чат, комментарии, захват Standard или режим API.

Начните с поддерживаемых сайтов

Сначала найдите YouTube. Social Stream разделяет живой чат и обычные комментарии, поскольку способы работы с ними различаются.

Выберите режим

СитуацияПопробуйте сначалаПримечания

Настройка живого чата

  1. Убедитесь, что трансляция действительно идёт или доступен живой чат.
  2. Откройте страницу живого чата YouTube или страницу источника для выбранного режима.
  3. Убедитесь, что док получает сообщения, прежде чем открывать OBS.
  4. Используйте одинаковый ID сессии в доке и оверлее.

Если YouTube запрашивает вход или разрешения, выполните это в той же среде браузера/приложения, где идёт захват.

Примечания по API и OAuth

  • Режим API может предоставлять другие семейства событий, чем захват видимой страницы.
  • YouTube может задерживать данные подписчиков; они могут включать только публичные подписки.
  • Действия записи требуют более широких областей доступа, чем захват чата только для чтения.
  • Настольное приложение не использует cookie обычного Chrome автоматически.

Полная настройка: Настройка проекта YouTube.

Решение частых проблем

  • Нет чата: убедитесь, что идёт эфир и чат виден.
  • В Chrome работает, а в приложении нет: войдите в YouTube внутри приложения или используйте расширение.
  • Режим API не работает: проверьте OAuth, области доступа, учётные данные проекта и квоту.
  • В OBS ничего не отображается: сначала проверьте док, затем URL оверлея в обычном браузере.
