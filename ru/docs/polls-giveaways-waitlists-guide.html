Опросы, розыгрыши и списки ожидания

Ваш первый розыгрыш: пошаговые инструкции со снимками экрана

Руководство по розыгрышам, платным билетам, игровым призам и восстановлению

Проводите голосования в чате, выбирайте победителя или организуйте очередь зрителей.

Все руководства 1. Выберите инструмент 2. Проведите опрос с вариантами ответа 3. Выберите победителя 4. Организуйте очередь зрителей 5. Проверьте работу и восстановление

1. Выберите инструмент

Цель Открыть в SSN
Предложите чату выбрать следующее занятие Графический опрос → Параметры опроса
Выбрать случайного участника Список ожидания / выбор победителя, с включённым режимом выбора победителя
Принимайте зрителей по очереди Список ожидания / выбор победителя, с выключенным режимом выбора победителя

Добавьте созданную ссылку этого раздела как источник «Браузер» OBS. Держите SSN и источники чата включёнными, сохраните параметры сеанса, пароля и сервера. Параметр Инструмент розыгрыша предлагает отдельный список участников с карточкой победителя, лентой имён и колесом сообщества. Для управления используйте его панель параметров; список ожидания и выбор победителя остаются доступны отдельно.

2. Проведите опрос с вариантами ответа

  1. Открыть Графический опрос → Параметры опроса. Задайте Тип опроса на Выбор из вариантов.
  2. Введите Во что сыграем дальше? как вопрос и Adventure, Puzzle как варианты через запятую. Установите Сопоставление голосов на Только точное совпадение голоса.
  3. Оставьте Разрешить несколько голосов от пользователя и Взвешивание голосов по пожертвованиям выключенным для простого опроса с одним голосом. Включите Включить опрос.
  4. Скопируйте созданную ссылку опроса в OBS. Попросите зрителей отправить 1 или 2 в качестве всего сообщения. Совпадающий текст варианта тоже подходит.
  5. Выберите Завершить опрос для завершения голосования. Запишите результат перед выбором Сбросить опрос для следующего раунда.

Опросы со свободным ответом принимают голоса с хештегами; Хештег в любом месте допускает хештег внутри более длинного сообщения. Сохранить текущий опрос сохраняет предустановку для повторного использования, а не постоянную запись результатов зрителей. Повторные голоса одного участника игнорируются, если не разрешено несколько голосов.

Отдельные инструменты розыгрышей

Пошаговое описание со снимками экрана смотрите в Ваш первый розыгрыш. Откройте Инструмент розыгрышей → Параметры розыгрыша. Задайте ключевое слово, выберите совпадение всего сообщения или отдельного слова и при желании ограничьте участие платными подписчиками. Нажмите Открыть приём заявок, затем Выбрать победителя когда будете готовы. Выбор победителя автоматически закрывает приём. До розыгрыша его можно закрывать и открывать с теми же правилами. Новый раунд очищает текущий список, сохраняет прежние результаты в истории и оставляет приём закрытым.

Выберите Карточка победителя, Лента имён, или Колесо сообществаи один из шести стилей. Предпросмотр использует вымышленные имена и никогда не подключается к вашему сеансу. Скопируйте созданную giveaway.html?session=YOUR_SESSION&managed ссылку в OBS. Управляемый экран зрителей не содержит операторских кнопок или сведений о сеансе. Стиль и заголовок задаются ссылкой; правила участия хранятся на хосте и применяются при открытии приёма.

Управляемые экраны с одинаковым идентификатором розыгрыша используют список и победителя хоста. Бесплатные заявки по ключевому слову имеют равные шансы; платные розыгрыши учитывают число билетов. Повторы определяются внутри платформы по переданному идентификатору, имени пользователя или отображаемому имени; разные платформы считаются разными участниками. Если повторные победы отключены, победитель удаляется из подходящих участников текущего раунда. В новом раунде он может вступить снова. Список вмещает до 10 000 участников; для больших списков колесо показывает выборку не более 120 имён, но победитель всегда выбирается из всех подходящих билетов.

Не закрывайте SSN. Раунды сохраняются в локальном профиле браузера или приложения отдельно для каждого сеанса. При перезапуске открытые раунды закрываются для проверки, но не удаляются. После обновления зрительская страница получает текущий результат. Ограничение платными подписчиками требует источника с соответствующими данными. Исторические, повторно воспроизведённые, личные сообщения, сообщения ботов и сообщения только с событиями исключаются. Текст бесплатной заявки должен совпадать с заданным ключевым словом; сумма пожертвования не влияет на шансы.

API, Stream Deck и Event Flow

Одни и те же действия хоста обслуживают кнопки меню, существующий HTTP/WebSocket API и Stream Deck. Для сбора заявок или выбора победителя экран розыгрыша не обязан быть открыт. В Event Flow используйте Розыгрыш / Билеты действие. См. руководство по баллам и автоматизации о платных билетах, игровых призах и интеграциях.

ДействиеДействие
startgiveawayОткрыть или возобновить приём перед розыгрышем. Необязательное значение: {"giveawayId":"default","config":{"keyword":"!enter","match":"exact","membersOnly":false,"removeWinner":true}}. Без явных правил сохраняйте правила существующего раунда либо используйте настройки меню для нового.
closegiveawayЗакрыть приём, сохранив участников.
drawgiveawayЗакрыть приём и выбрать одного подходящего победителя. Для пустого списка возвращается ошибка.
resetgiveawayСоздать пустой раунд с закрытым приёмом; отправить прежний раунд и победителей в архив. Сначала отмените незавершённые платные резервирования с возвратом средств.
getgiveawaystateПолучить число участников, состояние приёма, правила участия и последних победителей.
{"action":"drawgiveaway","get":"draw-1"}

Запросы Stream Deck по протоколу 2 используют те же названия действий и получают сопоставленные ответы хоста. Ответы описывают состояние розыгрыша, а не видимость OBS. Старое отдельное колесо сообщества остаётся доступным, если не указывать managed; у него собственный локальный список участников, не управляемый этими действиями хоста. Локальное хранилище теперь разделено по сеансу и паролю, точное совпадение означает всё сообщение, а выбор использует криптографически надёжную случайность.

3. Выберите победителя

  1. Открыть Список ожидания / выбор победителя → Включить и настроить. Включите триггер и задайте понятную команду, например !join.
  2. Включите Использовать режим выбора победителя вместо очереди. Скопируйте обновлённую ссылку в источник «Браузер» OBS.
  3. Сообщите зрителям команду вступления и условия допуска. Если используете Участвовать могут только подписчики, сначала убедитесь, что источник передаёт сведения о платной подписке.
  4. Убедитесь, что число участников растёт. Выберите Остановить приём по окончании приёма, затем Выбрать победителя.
  5. Используйте Скачать список для сохранения списка перед Сбросить розыгрыш очищает раунд.

4. Организуйте очередь зрителей

Используйте тот же список ожидания, но отключите режим выбора победителя и скопируйте обновлённый URL. Зрители вступают заданной командой.

Кнопка Что делать
Выделить первого участника Привлеките внимание к следующему зрителю.
Удалить первого участника Перейдите дальше, когда зритель завершит участие.
Выбрать имя Выберите участника случайно вместо порядка очереди.
Остановить приём Закройте очередь для новых участников.
Скачать список / сбросить очередь Сохраните копию TSV, затем очистите список после завершения.

Параметром повторного вступления задайте, могут ли удалённые зрители вернуться. Необязательные команды управления списком ожидания доступны только модераторам, ведущему и администраторам: !wlstop, !wlremove, !wlreset, !wlpick, и !wlhighlight. Включайте их намеренно; сама команда вступления зрителя их не включает.

5. Проверьте работу и восстановление

Используйте разных вымышленных пользователей в тестовые сообщения для проверки голосования и вступления. Один человек на двух платформах не определяется надёжно как общий участник. Перед приглашением зрителей убедитесь, что результат виден в OBS.

  • Нет голосов: проверьте включение опроса, завершение голосования, точность совпадения и не голосовал ли пользователь ранее.
  • Нет заявок: проверьте триггер списка ожидания, точную команду, остановку приёма и ограничение платными подписчиками.
  • Есть счётчик, но нет списка: режим выбора победителя показывает участников и победителей вместо обычной очереди.
  • В OBS другой результат: замените сохранённый URL, проверьте сеанс и пароль и не запускайте независимо настроенные копии страниц опроса.

О кнопках на оборудовании или в OBS читайте в Настройка Stream Deck и Док-панель управления OBS.
