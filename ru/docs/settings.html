Справочник настроек

Просмотрите все переключатели, текстовые поля и списки меню Social Stream Ninja с описаниями и областями действия.

Переключайтесь между каталогом элементов меню и индексом параметров URL оверлеев. Оба используют общую конфигурацию для согласованности.

Эта страница получает актуальные данные из popup.html для согласованности с расширением и настольным приложением. Используйте поиск по ключевому слову или откройте файл определений настроек по адресу shared/config/settingsDefinitions.js для расширения описаний и областей действия.

Хотите задать каждому участнику чата свой цвет? Откройте руководство по цветам имён в чате; нужно включить и общий параметр цвета, и его отображение в док-панели.

Загрузка настроек из popup.html…

Нужно настроить оверлеи через строку запроса? Просмотрите полный список параметров URL по интерфейсам и категориям. Данные создаются из parameters.md и экспортируются через shared/config/urlParameters.js для использования в документации и справке приложения.

Не хватает подробностей или заметили устаревшие данные? Обновите справочник, изменив shared/config/settingsDefinitions.js или создайте задачу на GitHub.
