Kohalik AI TTS-juhend

Käivitage vestlushääli oma arvutis. Enamik striimijaid vajab ainult sisseehitatud hääli.

Kas mul on seda vaja?

„Kohalik” tähendab kas SSN-i sisseehitatud häält, mis töötab brauseris, või teie enda käitatavat kõneserverit.

Ma tahan…Tehke seda

See töötab kõigi SSN-i jäädvustatud vestlustega. Häält esitab SSN-i pleier, mitte YouTube ega Twitch. Erinevalt Süsteem TTS, loovad kohalikud tehisintellekti hääled ise heli, mida OBS saab jäädvustada. Võrrelge teenusepakkujaid ja kuulake näidiseid.

Sisseehitatud hääled (ei ole vaja installida)

Need töötavad SSN-is teie brauseris. Serverit, Dockerit ega API-võtit pole vaja.

Seadistage see neljas etapis

  1. Lisa &speech=en-US&ttsprovider=kokoro oma dock.html link. (Või piper, kitten, espeak.)
  2. Lisage see link OBS-i allikana Brauseri allikas. See on leht, mis teeb häält.
  3. Selle omadustes lülitage sisse Heli juhtimine OBS-i kaudu.
  4. Saatke lühike testvestlussõnum, näiteks Testing local TTS.
dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=kokoro
Esimene kasutamine on aeglane. Kokoro ja Piper laadivad esmalt alla oma mudelid (umbes 50–200 MB). Hilisemad laadimised kasutavad neid uuesti, kuid käivitamiseks kulub siiski veidi aega. OBS hoiab oma koopiat Chrome'ist eraldi.

Hääled, kiirus ja muud keeled: pakkuja seaded. Kas eelistate klõpsamist? Kasutage seadistusjuhend.

Ühendage oma TTS-server

Server pakub rohkem hääli, häälte kloonimist või üht häält, mida saate eri tööriistades kasutada. SSN suhtleb sellega nagu OpenAI-ga ühilduv kõneserver. API-võtit pole vaja.

  1. Käivitage oma server. Kokoro-FastAPI on kõige lihtsam.
  2. Avage SSN-is TTS-i pakkujate loend ja valige Kohandatud / Kohalik TTS-i lõpp-punkt.
  3. sisse Kohandatud / kohaliku API lõpp-punkt, sisestage oma serveri aadress, näiteks http://127.0.0.1:8880/v1/audio/speech.
  4. Jätke API võti tühjaks.
  5. Valige hääl, mida teie server tunneb: af_bella Kokoro jaoks, nova openedai-speechi jaoks.
  6. Kopeerige link OBS-i ja saatke testvestlussõnum.
OBS teises arvutis? Lugege kohaliku hosti reegel esiteks. Kas brauser on blokeerinud? Kasutage sild.

localhost-aadressi reegel

See on kõige levinum viga.

localhost ja 127.0.0.1 tähendab alati "sama arvutit". Kui OBS on ühes arvutis ja kõneserver teises, 127.0.0.1 OBS-is viitab OBS-i arvutile.

Kontrollige ka, kas tulemüür lubab porti ja kas Docker on selle avaldanud (-p 8880:8880).

Kokoro-FastAPI

Kokoro-FastAPI käitab Kokorot kohaliku serverina. Töötab protsessoril; GPU-d pole vaja.

  1. Avage terminal (käsuviip, PowerShell või terminal) ja käivitage üks järgmistest: 
    docker run -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu:v0.2.2

    NVIDIA GPU (kiirem):

    docker run --gpus all -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-gpu:v0.2.0post4
    Esimesel käivitamisel laaditakse ühekordselt alla umbes 1,5–2 GB.
  2. Avatud http://localhost:8880/web/. Peaksite nägema häälte testimise lehte (saadaval 67+).
  3. Kasutage seda linki (muutke aadressi, kui server asub teises arvutis): 
    dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=customtts&openaiendpoint=http://127.0.0.1:8880/v1/audio/speech&voiceopenai=af_bella
Kasutage Kokoro häälnimesid, nagu af_bella, af_sarah, am_adam või bf_emma. OpenAI nimed nagu nova või alloy ei pruugi töötada.

Käivitage see automaatselt Dockeriga:

docker run -d --restart unless-stopped -p 8880:8880 ghcr.io/remsky/kokoro-fastapi-cpu:v0.2.2

openedai-speech (Piper ja XTTS-v2)

Arhiveeritud projekt. openedai-speech arhiveeriti 2026. aasta jaanuaris ja projekt peab end suuresti aegunuks. See sobib endiselt näiteks, kuid ei saa uuendusi. Hoidke see kohalikus võrgus. Ärge kunagi avage selle porti internetile, sest sisselogimine puudub.

Valik A: kerge Piper-server (CPU)

Alla 1 GB. Hääli ei klooni.

docker run -d --restart unless-stopped -p 8000:8000 ghcr.io/matatonic/openedai-speech-min

Hääled: alloy, echo, fable, onyx, nova, shimmer.

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=openai&openaiendpoint=http://localhost:8000/v1/audio/speech&voiceopenai=nova
Selle käitamine lähtekoodist Windowsis (HTTP 500 vead)

Lisage selle virtuaalkeskkonna Scripts kaust asukohta PATH esmalt. Muidu ei leia see piper.exe või ffmpeg.exe.

cd openedai-speech
$env:Path = "$PWD\.venv\Scripts;$env:Path"
.\.venv\Scripts\python.exe speech.py --xtts_device none -H 127.0.0.1 -P 8000

Valik B: XTTS-v2 hääle kloonimine (GPU)

Vajab täisserverit, mitte openedai-speech-min. Planeerige umbes 4 GB GPU-mälu. CPU töötab, kuid on aeglane.

Seadistage XTTS-v2 neljas etapis
  1. Hankige server ja käivitage see: 
    git clone https://github.com/matatonic/openedai-speech.git
cd openedai-speech
Copy-Item sample.env speech.env
docker compose up -d
    Kasutage macOS-is või Linuxis cp sample.env speech.env. Docker vajab GPU-juurdepääsu. Mudel laaditakse alla esimesel kasutamisel.
  2. Tehke puhas näidisklipp häälest, mida teil on luba kasutada. Mono, 22050 Hz, 6–30 sekundit: 
    ffmpeg -i input.mp3 -ac 1 -ar 22050 -t 6 -y voices/me.wav
  3. sisse config/voice_to_speaker.yaml, lisage see olemasoleva alla tts-1-hd jaotisesse (säilitage seal juba olevad hääled): 
    tts-1-hd:
  me:
    model: xtts
    speaker: voices/me.wav
    language: en
    Muutke me nimele, mille SSN saadab.
  4. Käivitage docker compose restart, seejärel kasutage: 
    dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=customtts&openaiendpoint=http://127.0.0.1:8000/v1/audio/speech&openaimodel=tts-1-hd&voiceopenai=me&openaiformat=wav
openaimodel=tts-1-hd on nõutav. Ilma selleta saadab SSN tts-1, ning server kasutab selle asemel Piperit. voiceopenai peab ühtima teie häälenimega YAML-failis.

Kas brauser on blokeerinud? Käivitage sild ja muutke ainult openaiendpoint juurde http://127.0.0.1:8124/v1/audio/speech.

Kohalik TTS-sild

Väike SSN-i abitööriist. See võtab vastu SSN-i päringu, edastab selle teie kõneserverile ja tagastab heli brauseritele sobival viisil. Vajab Node.js-i.

Lihtsaim reegel: käivitage sild OBS-i arvutis. Siis kasutab OBS alati http://127.0.0.1:8124/v1/audio/speech, isegi kui kõneserver asub teises arvutis.
  1. Öelge sillale, kus teie server asub. PowerShell: 
    $env:SSN_TTS_TARGET="http://127.0.0.1:8880/v1/audio/speech"
    Server teises arvutis? Kasutage selle kohalikku IP-d, näiteks http://192.168.x.x:8880/v1/audio/speech.
  2. SSN-kaustas käivitage node scripts/local-tts-bridge.cjs. Jätke see tööle.
  3. Suunake SSN sillale: 
    dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=customtts&openaiendpoint=http://127.0.0.1:8124/v1/audio/speech&voiceopenai=af_bella

macOS/Linux, ühel real: SSN_TTS_TARGET="http://127.0.0.1:8880/v1/audio/speech" node scripts/local-tts-bridge.cjs. Jaotises local-tts-bridge kaust, node server.cjs teeb sama. Muutke porti kasutades SSN_TTS_BRIDGE_PORT=8125. Kõik valikud: silla README.

GPT-SoVITS režiim

GPT-SoVITS kasutab oma /tts vormingut. Sild teisendab päringud selle jaoks sobivaks.

$env:SSN_TTS_REF_AUDIO_PATH="C:\voices\speaker.wav"
$env:SSN_TTS_REF_TEXT="Reference audio transcript here."
$env:SSN_TTS_TARGET="http://127.0.0.1:9880/tts"
node scripts/local-tts-bridge.cjs --mode gptsovits
dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=customtts&openaiendpoint=http://127.0.0.1:8124/v1/audio/speech&openaiformat=wav
F5-TTS-serveri režiim

Mõned F5-TTS-i ühilduvuskihid kasutavad /synthesize_speech/?text=...&voice=.... Sild teisendab nende päringud sobivaks.

$env:SSN_TTS_TARGET="http://127.0.0.1:7860/synthesize_speech/"
node scripts/local-tts-bridge.cjs --mode f5
dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=customtts&openaiendpoint=http://127.0.0.1:8124/v1/audio/speech&voiceopenai=default_en&openaiformat=wav

Hääle kloonimine

Kloonimine ei ole SSN-i seade. See on mõne kõneserveri funktsioon. SSN saadab vestlusteksti; server valib kloonitud hääle.

  1. Salvestage ühe kõneleja puhas, tavaliselt 3–30 sekundi pikkune klipp vähese taustamüraga.
  2. Mõned serverid vajavad ka klipis öeldud täpseid sõnu.
  3. Server muudab klipi hääleprofiiliks.
  4. SSN saadab vestlusteksti koos ttsprovider=customtts.
  5. Server tagastab heli (tavaliselt WAV või MP3) ja SSN esitab selle.
Kloonige ainult hääli, mis teile kuuluvad või teil on luba kasutada.
XTTS-v2 on vaikimisi mitteäriline. Selle Coqui Public Model License lubab ainult mitteärilist kasutamist. Rahaks muudetud otseülekanne ei pruugi selle alla kuuluda. Kontrollige esmalt litsentsi või küsige luba.

Kui GPU-mälu on 6 GB või vähem, alustage OpenAI-ga ühilduvate serverite väikeste mudelitega. Suuremad mudelid töötavad ka siis, kui neid majutatakse mujal.

Viige heli OBS-i

OBS-i brauseriallikas (soovitatav)

Töötab sisseehitatud häälte ja teie enda serveriga.

  1. Lisage a Brauseri allikas oma dock.html TTS link.
  2. Lülitage sisse Heli juhtimine OBS-i kaudu.
  3. Klõpsake OK. TTS kuvatakse nüüd OBS-mikseris.

SSN-i töölauarakendus

Töölauarakendus kasutab samu lingiseadeid, kuid heli tuleb rakendusest, mitte OBS-ist. Jäädvustage see, kasutades Töölauaheli või Helisisendi jäädvustamine. TTS-i muudest helidest eraldamiseks suunake rakenduse heli virtuaalkaablisse: heli suunamise juhised.

Ärge ajage segamini rakenduse testi ja OBS-i. Rakenduse nupuga Test katsetatakse ühendust rakendusest. Kui link on OBS-is, peab OBS serveriga ühenduse saama ja heli esitama.
Rohkem teavet töölauarakenduse kohta

Rakenduseakendes on brauseri juurdepääsupiirangud (CORS) leebemad kui Chrome’is. Brauseripäringutest keelduvate serverite jaoks on sild siiski kõige kindlam valik. Sisseehitatud Kokoro puhul saab rakendus kasutada oma ninjafy.tts teed, selle asemel et mudelit brauserisse laadida.

Süsteem TTS (&speech=en-US ilma teenusepakkujata) sõltub OBS-ile saadaolevatest häältest. Sageli pole neid üldse või ei tekita need jäädvustatavat heli. Kasutage selle asemel mõnda ülaltoodud teenusepakkujat.

Serveriehitajatele

Kuidas SSN suhtleb kohandatud serveriga. Teil on seda vaja ainult siis, kui ehitate või silute seda.

chat text -> SSN -> your endpoint (or the bridge) -> TTS server -> audio -> SSN plays it
Mida SSN saadab

Koos ttsprovider=customtts, localtts või openai, saadab SSN JSON-vormingus POST-päringu:

POST /v1/audio/speech
{
  "model": "tts-1",
  "input": "Chat message text",
  "voice": "af_bella",
  "response_format": "mp3",
  "speed": 1.0
}

Kui API-võtit pole määratud, ei saada SSN Authorization-päist.

Mida SSN saab taasesitada
VastusTöötab?Märkmed

JSON heli URL-igaJahKontrollid url, audio_url, output_url, data.url, ja esimene data[] üksus.

Vormingud: mp3 on väike ja laialdaselt toetatud. wav sobib kloonimisserveritele ja sildade testimiseks. Kasutage opus ainult siis, kui nii server kui ka brauser seda toetavad.

Voogedastust veel ei toetata. SSN ootab kogu vastuse ja esitab selle siis. Hoidke vestlussõnumid lühikesed.
