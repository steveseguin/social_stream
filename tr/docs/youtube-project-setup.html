YouTube Proje Kurulumu

Anahtar güvenliğinizi zayıflatmadan SSN Bağımsız masaüstü uygulaması için Google Cloud projesi oluşturma.

Genel bakış

Bu kurulum ne içindir

Bunu yalnızca masaüstü uygulamasının şunu kullanmasını istiyorsanız kullanın: kendi YouTube API kotanızı Social Stream Ninja'nın varsayılan paylaşılan projesi yerine.

Önemli: aşağıdaki üç değer de şu kaynaktan gelmelidir: aynı Google Cloud projesi:
  • OAuth İstemci Kimliği
  • OAuth İstemci Gizli Anahtarı
  • API Anahtarı
Google Cloud'daki bu iki alanı karıştırmayın:
  • Yetkilendirilmiş JavaScript kaynakları yalnızca kaynak adresini içermelidir; yol içermemelidir.
  • Yetkilendirilmiş yönlendirme URI'leri tam olarak şu /sources/websocket/youtube.html yolunu içermelidir.
1. Adım

Projeyi oluşturun

  1. Google Cloud Console'u açın.
  2. Yeni proje oluşturun veya bu iş için ayrılmış mevcut birini seçin.
  3. Şunu etkinleştirin: YouTube Data API v3.
  4. OAuth izin ekranı ayarlarını açın.
  5. Uygulama test aşamasındaysa Google hesabınızı test kullanıcısı olarak ekleyin.
2. Adım

OAuth istemcisini oluşturun

  1. Kimlik bilgilerini oluşturun.
  2. Seçin: OAuth istemci kimliği.
  3. Tür olarak şunu kullanın: Web uygulaması.
  4. Aşağıda gösterilen kaynak adreslerini ve yönlendirme URI'lerini aynen ekleyin.
Alan Değer
Yetkilendirilmiş JavaScript kaynakları http://localhost:8181
http://localhost:8080
Yetkilendirilmiş yönlendirme URI'leri http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
3. Adım

API anahtarını güvenle oluşturun

  1. Şunu oluşturun: API anahtarı aynı projede.
  2. Bu anahtarın kısıtlamalarını açın.
  3. Şu bölümde: API kısıtlamaları, şu API ile sınırlayın: YouTube Data API v3 yalnızca.
  4. Masaüstü uygulaması için HTTP yönlendiren kısıtlamalarını kullanmayın.

Masaüstü uygulaması kuralı: HTTP yönlendiren kısıtlamaları tarayıcı sayfaları içindir; bu yerel masaüstü kimlik doğrulama akışı için değildir.

4. Adım

Değerleri masaüstü uygulamasına yapıştırın

  1. Masaüstü uygulamasında YouTube kaynak sayfasını açın.
  2. Şunu yapıştırın: OAuth İstemci Kimliği, OAuth İstemci Gizli Anahtarı, ve API Anahtarı.
  3. Tıklayın: Kaydet.
  4. Gerekirse çıkış yapın.
  5. Tıklayın: YouTube ile giriş yap.
  6. Harici tarayıcı penceresinde Google girişini tamamlayın.
Beklenen sonuç: her şey eşleşiyorsa Google girişi çalışır ve masaüstü uygulaması varsayılan paylaşılan proje yerine kaydedilmiş YouTube projenizi kullanır.
Güvenlik

Kimlik bilgilerini güvende tutun

  • İstemci Gizli Anahtarı ve API anahtarını hassas bilgi olarak değerlendirin.
  • Bunları ekran görüntülerine, sohbet kayıtlarına veya hata raporlarına yapıştırmayın.
  • Yanlışlıkla ifşa ederseniz yenileyin veya silin.
  • Deneme yapıyorsanız ayrı bir test projesi kullanın.
  • Test bittikten sonra geçici projeleri silin.
Sorun giderme

Yaygın sorunlar

  • redirect_uri_mismatch: yönlendirme URI'si tam eşleşmiyor.
  • invalid_client: İstemci Kimliği ve İstemci Gizli Anahtarı eşleşmiyor.
  • quotaExceeded: API anahtarı projenizin YouTube kotası tükenmiş.
  • Hesap doğrulaması başarısız: eski sürümlerde OAuth ve API anahtarı farklı projelerden geldiğinde bu olabiliyordu.
