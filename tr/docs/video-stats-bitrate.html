Video İstatistikleri ve Bit Hızı

Gelen yayının bit hızını Social Stream Ninja Paneli'nin sağ üstünde gösterin.

Önemli: SSN bit hızını OBS'den veya yayın platformundan otomatik okumaz. Yayınınızı alan video sunucusunun istatistik API'sini yoklar.

Ne için kullanılır

Bu, sunucuya veya yapımcıya Panel'de küçük, canlı bir bit hızı göstergesi sağlar. OBS, mobil kodlayıcı veya başka gönderici kendi aktarma ya da yayın alma sunucunuza yayın yapıyorsa kullanışlıdır.

SSN ayrıca mevcut gecikme, arabellek, paket kaybı, çalışma süresi, kodek ve izleyici verilerini şu biçime normalleştirir: video_stats üst veri etkinliği. Standart Panel göstergesi yalnızca bit hızını gösterir.

Uyumluluk

  • SRT Live Server / SLS: JSON /stats şunu içeren uç nokta: publishers nesnesi.
  • Belabox Cloud: SRT tarzı JSON alıcı/aktarıcı istatistik yanıtı.
  • NGINX RTMP: NGINX RTMP durum modülünden XML.
  • Node Media Server: isteğe bağlı HTTP Basic kimlik doğrulamalı JSON yayın API'si.
OBS istatistik kaynağı değildir: OBS uyumlu sunucuya video gönderebilir ancak OBS WebSocket ve SSN tarayıcı kaynakları bu veriyi sağlamaz.

Nasıl kullanılır

  1. Uyumlu sunucunun HTTP istatistik uç noktasını etkinleştirin ve SSN'yi çalıştıran bilgisayarın URL'sini açabildiğini doğrulayın.
  2. SSN'de Genel ayarlar, şunu etkinleştirin: Video istatistiklerini yoklama.
  3. Kaynak türünü seçip istatistik URL'sini girin.
  4. SRT veya Belabox için tam yayıncı kimliğini girin; örneğin publish/live/feed1. Yanıtta tek yayıncı varsa SSN onu otomatik kullanır.
  5. NGINX RTMP veya Node Media Server için uygulama ve yayın anahtarını/adını girin; örneğin live ve feed1.
  6. Gerekiyorsa yetkilendirme ekleyin. SRT API anahtarı alanı şu başlığın tamamı olarak gönderilir: Authorization başlığı olarak. Node Media Server kullanıcı adı/parolayı HTTP Basic kimlik doğrulaması olarak kullanır.
  7. 1–60 saniye arasında yoklama aralığı seçin; varsayılan beş saniyedir.
  8. Panel seçeneklerinde şunu etkinleştirin: Varsa bit hızı üst verisini göster; sağ üst, ardından Panel bağlantısını açın veya yenileyin.
  9. Video yayınlamaya başlayın. Geçerli çevrimiçi yanıtın ardından bit hızı görünür.

Hiçbir şey görünmüyorsa

  • SSN'de her iki video istatistiği seçeneğinin de etkin olduğunu doğrulayın.
  • Uç noktanın beş saniye içinde yanıt verdiğini, kaynak türünün ve yayın tanımlayıcılarının eşleştiğini doğrulayın.
  • 127.0.0.1 SSN'yi çalıştıran bilgisayarı ifade eder. Sunucu başka cihazdaysa LAN adresini kullanın.
  • Yayın çevrimdışıysa, bit hızı eksik veya sıfırsa ya da yaklaşık 130 saniye yeni istatistik gelmezse gösterge kaybolur.

Gelişmiş: protokol, biçimler ve birimler

SSN, HTTP veya HTTPS üzerinden şu isteği yapar: GET ayarlanan aralıkla, önbellekleme kapalı ve beş saniye zaman aşımıyla.

SRT Live Server / SLS ve Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate Kbps'dir; RTT ve alma arabelleği milisaniye, alma hızı ve bant genişliği Mbps, çalışma süresi saniye, kayıp/düşme değerleri paket sayısı veya bayttır.

NGINX RTMP

URL, NGINX RTMP durum XML'i döndürmelidir. SSN yapılandırılmış uygulama ve yayını eşleştirir. Şunu okur: bw_video saniyede bayt olarak ve 1024'e bölerek şu değeri elde eder: bitrateKbps. Ayrıca yayın süresini ve isteğe bağlı video/ses kodek üst verilerini okur.

Node Media Server

SSN şunu ister: STATS_URL/APPLICATION/STREAM_NAME. Alanlar en üst düzeyde veya şu nesnenin içinde olabilir: data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

Bit hızı Kbps, izleyici değeri adet ve süre saniye cinsindendir.

Normalleştirilmiş SSN etkinliği

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}

Panel şunu kabul eder: meta.bitrateKbps, şu alanla: meta.bitrate ve meta.kbps yedek değerler olarak. 1000 altı değerler yuvarlanmış Kbps; daha büyük değerler bir ondalığa yuvarlanmış Mbps olarak gösterilir. İstatistik URL'si, yayın anahtarı ve kimlik bilgileri katmanlara hiçbir zaman gönderilmez.
