Installer des polices personnalisées

  • Windows : Faites un clic droit sur le fichier .ttf ou .otf → sélectionnez « Installer » ou « Installer pour tous les utilisateurs » → redémarrez le navigateur.
  • macOS : Double-cliquez sur le fichier .ttf ou .otf → cliquez sur « Installer la police » dans Livre des polices → redémarrez le navigateur.
  • Linux : Copiez les fichiers de polices vers ~/.local/share/fonts/ → exécutez fc-cache -fv → redémarrez le navigateur.

Après l’installation, actualisez cette page pour voir les nouvelles polices. Si une police n’apparaît pas, essayez le bouton « Essayer l’API des polices locales », réservé aux navigateurs Chromium.

Détection…

Utiliser une police précise via l’URL

  • Paramètre : Ajoutez ?font=<Font%20Family%20Name> à l’URL. Les espaces et symboles doivent être encodés pour URL.
  • S’applique à la variable CSS : Votre site utilise --font-family; cette page la respecte également. Exemple : ?font=Segoe%20UI.
  • Guillemets inutiles : N’incluez pas de guillemets dans le paramètre ; ils ne sont pas nécessaires dans la variable CSS.
  • Polices installées uniquement : Ce paramètre fonctionne uniquement avec les polices déjà installées sur le système. Il ne télécharge pas de polices Web.

Compatibilité avec les applications Ninja

  • VDO.Ninja : Généré ?font= fonctionnent avec les incrustations/scènes qui respectent la variable --font-family .
  • SocialStream.Ninja : Utilisez la même valeur ?font= pour remplacer la police par défaut dans les widgets compatibles.
  • Caption.Ninja : Appliquer ?font= aux incrustations de sous-titres prenant en charge les familles personnalisées.

Ces applications acceptent le remplacement de font-family lorsque le paramètre ?font= est pris en charge dans leurs URL ou liens d’intégration. Cet outil génère des valeurs correctement encodées et prêtes à l’emploi.

Dépannage sous Windows

  • Nom exact de la famille : Utilisez le nom de famille exact de la police, pas le nom du fichier. Vérifiez Paramètres → Personnalisation → Polices pour trouver le bon libellé de famille.
  • Portée d’installation correcte : Si la police est installée pour un autre utilisateur Windows ou uniquement via un compte administrateur, votre navigateur peut ne pas la voir. Installez-la « pour tous les utilisateurs » si nécessaire.
  • Formats pris en charge : Les navigateurs utilisent TrueType/OpenType/WOFF. Les anciennes polices Type 1 et certaines polices bitmap ne fonctionnent pas.
  • Disponibilité des graisses/styles : Si seule la variante Bold est installée, le texte normal peut utiliser une police de repli. Essayez un exemple en gras ou installez aussi Regular.
  • Limites de confidentialité : Les navigateurs n’autorisent pas l’énumération complète des polices sans permission. Cette page utilise une longue liste connue et, facultativement, l’API des polices locales.
  • API des polices locales : Dans Chromium sur une origine sécurisée, https/localhost, cliquer sur « Essayer l’API des polices locales » peut lister les familles exactes installées après autorisation.

Conseils d’utilisation manuelle

  • Imposer une police : Dans votre CSS : font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • Tester un nom quelconque : Utilisez la recherche pour tester une famille ; si elle est trouvée, elle apparaît dans les résultats avec un exemple.
  • Encodage : Créez des liens tels que : ?font=Segoe%20UI (les liens générés ci-dessous utilisent l’encodage approprié).
  • Polices CJK et d’autres écritures : L’exemple comprend des caractères latins, chiffres et symboles. Remplacez-le par du texte de l’écriture voulue pour vérifier son rendu.

Remarque : cette page n’installe ni ne télécharge de polices ; elle détecte et prévisualise uniquement les familles déjà accessibles au navigateur.
