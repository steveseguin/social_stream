Recevoir le chat dans votre incrustation

Lite connecte les sources de chat compatibles depuis votre navigateur ou OBS. Avec le lien d’incrustation normal, gardez Lite ouvert dans un onglet ou dock OBS. Le mode OBS autonome expérimental capture et affiche le chat dans une seule source Navigateur.

Configuration · Configurations entièrement dans OBS · Sources · Configurations existantes · Dépannage

1. Configurer votre incrustation

  1. Ouvrez Lite. Un identifiant de session et une URL d’incrustation sont générés automatiquement et mémorisés dans ce navigateur.
  2. Connectez l’une des sources ci-dessous. Utilisez son bouton Options pour les paramètres de chaîne.
  3. Choisir Copier le lien (Copy link). Dans OBS, ajoutez une Navigateur et collez le lien dans son champ URL. Vous pouvez aussi utiliser Ouvrir l’incrustation du dock (Open dock overlay) pour la vérifier dans un navigateur.
  4. Choisir Envoyer un message de test (Send test message) dans Lite. Vérifiez son apparition dans l’incrustation ouverte. Un message dans le fil d’activité Lite seul ne prouve pas sa réception par l’incrustation.

Pour un fond transparent ou un ordre de messages différent, ouvrez les options à côté de Lien de l’incrustation de chat (Chat Overlay Link). Après avoir modifié ces options, copiez l’URL mise à jour dans OBS.

2. Choisir vos sources

Pour une configuration entièrement dans OBS, choisissez l’un des deux parcours ci-dessous. Aucun onglet de navigateur distinct n’est nécessaire si OBS effectue la capture.

SourceQue faire
YouTubeConnectez-vous avec YouTube. Lite recherche votre diffusion en direct. Dans Options, vous pouvez fournir un Video ID ou Live Chat ID pour une diffusion précise. L’interrogation est utilisée par défaut ; l’API de streaming facultative est indiquée bêta. Le direct doit disposer d’un chat accessible.
TwitchConnectez-vous avec Twitch. Lite utilise votre propre chaîne par défaut ; choisissez-en une autre dans Options. Si l’autorisation expire, reconnectez-vous.
KickSaisissez le nom de chaîne dans Options et connectez-vous. Si la recherche automatique échoue, vérifiez l’orthographe, puis utilisez si nécessaire les paramètres manuels de salon.
TikTokL’intégration est actuellement masquée dans le panneau Lite standard. Elle nécessite un proxy TikTok Chat Reader compatible ; une adresse préremplie ne garantit pas sa disponibilité. Utilisez l’application complète pour les options de capture TikTok disponibles.

Déconnecter arrête cette source. Pour YouTube et Twitch, la connexion reste conservée afin d’utiliser Connecter (Connect) à nouveau. Se déconnecter (Sign out) supprime l’autorisation enregistrée dans ce navigateur.

3. Utiliser votre configuration Social Stream existante

Pour alimenter un dock ou une incrustation existants, ouvrez les options de session Lite et saisissez leur identifiant de session. Choisissez Enregistrer l’identifiant de session (Save session ID) ou appuyez sur Entrée. Modifier l’identifiant change la destination des messages de Lite ; actualisez les URL de sources Navigateur qui doivent suivre ce changement.

Utilisez une seule méthode de capture par chaîne dans une même session. Exécuter Lite en parallèle de l’extension ou de la capture de bureau du même chat peut créer des doublons. Vous pouvez utiliser Lite pour une chaîne et l’application complète pour les autres sources.

Le lien généré par Lite utilise le mot de passe de session par défaut. Les configurations protégées par mot de passe ou à serveur personnalisé peuvent nécessiter les contrôles de connexion de l’application complète. Lite ne remplace pas ses contrôles de capture, automatisation, modération ou personnalisation des incrustations.

Les contrôles Dons uniquement (Donations only) et Synthèse vocale (Text-to-speech) de la vue Activité s’appliquent à la vue d’activité Lite. Gardez la page principale Lite ouverte lorsque vous utilisez sa fenêtre d’activité détachée. Considérez l’URL d’incrustation comme privée si vous ne souhaitez pas que d’autres rejoignent la session.

Fonctionner entièrement dans OBS

Option A : dock Lite et incrustation normale

  1. Ouvrir Fonctionner entièrement dans OBS dans Lite et copiez l’ URL du dock personnalisé OBS (OBS custom dock URL) (lite/index.html?view=dock).
  2. Ajoutez-la sous Docks navigateur personnalisés. Connectez-vous et configurez les sources dans ce dock. Les options de sources et paramètres de session y restent accessibles.
  3. Copiez l’URL d’incrustation normale du dock dans une source Navigateur OBS. Gardez le dock Lite chargé pendant la capture. La source affiche uniquement les messages et n’a donc pas besoin de sa propre connexion au fournisseur.

C’est le parcours le plus simple entièrement dans OBS : le dock capture, la source Navigateur affiche. Fermer le dock arrête sa capture. Un navigateur de bureau n’est plus nécessaire après la configuration.

Option B : une source Navigateur pour capture et incrustation, expérimental

  1. Ajoutez le déclencheur URL autonome de capture et d’incrustation (Standalone capture + overlay URL) (lite/index.html?view=overlay) comme source Navigateur OBS.
  2. Ouvrir Interagir (Interact) pour configurer les sources. Si elles sont déjà configurées, appuyez sur Échap dans Interagir pour rouvrir la configuration. Les pages de connexion et contrôles de configuration sont visibles dans cette source ; configurez-la donc hors antenne.
  3. Choisir Afficher l’incrustation (Show overlay). La page affiche désormais son propre chat entrant sur un fond transparent. Elle n’a pas besoin d’un autre onglet Lite, dock ou relais et n’alimente pas les autres incrustations de session.
  4. Laissez Arrêter la source lorsqu’elle n’est pas visible (Shutdown source when not visible) et Actualiser la source Navigateur lorsque la scène devient active (Refresh browser source when scene becomes active) pour éviter d’interrompre la capture lors d’un changement de scène. Consultez les propriétés de la source Navigateur OBS.

Les identifiants YouTube/Twitch valides enregistrés permettent la reconnexion au démarrage. Pour Kick, activez Reconnecter automatiquement cette chaîne Kick dans les modes OBS (Reconnect this Kick channel automatically in OBS modes) dans ses options. Configurez d’abord la chaîne. TikTok reste masqué. La disposition commence avec tous les messages visibles et la voix désactivée, indépendamment des préférences enregistrées de la vue d’activité normale.

Les docks OBS, sources Navigateur OBS et navigateurs de bureau peuvent utiliser des profils de cookies/stockage différents. Configurer un dock ne connecte pas nécessairement une source Navigateur indépendante. Si la connexion ne peut pas aboutir dans la source Navigateur OBS, utilisez l’option A. L’authentification native des fournisseurs dans OBS nécessite encore une validation réelle ; ce mode est expérimental.

Utilisez un seul emplacement de capture par chaîne. Ne laissez pas un dock capturer la même chaîne qu’une source autonome de capture et d’incrustation. Utilisez l’option de source existante d’OBS pour réutiliser la même capture dans plusieurs scènes.

Dépannage

Mon incrustation est vide
Vérifiez que Lite est toujours ouvert et que l’incrustation utilise la même session. Envoyez un message de test. Si le test arrive mais pas le chat réel, vérifiez l’état et la chaîne de la source. Si aucun n’arrive, vérifiez l’URL d’incrustation et un éventuel blocage réseau de la connexion au relais.
La copie du lien est bloquée
Cliquez sur l’URL visible de l’incrustation, puis copiez le texte sélectionné avec le clavier ou le menu de copie de votre appareil.
Une source est inactive ou affiche une erreur
Vérifiez ses options et le texte d’erreur. Reconnectez après correction. YouTube et Twitch peuvent nécessiter une nouvelle connexion si l’autorisation a expiré.
Les messages sont en double
Recherchez un deuxième onglet Lite, une capture par extension ou par application de bureau de la même chaîne et session. Gardez uniquement la capture souhaitée.
Les paramètres ont disparu
Les paramètres sont conservés dans le stockage local de ce navigateur. Un autre navigateur, une fenêtre privée ou l’effacement des données du site utilise un autre ensemble de paramètres.
