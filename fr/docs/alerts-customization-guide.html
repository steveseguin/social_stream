Concevoir des alertes personnalisées et des flux d'événements

Restylez Multi-Alerts et les lignes d'événements pour les dons, les abonnements, les cadeaux, les suivis et autres actions prises en charge.

Pour que les alertes récentes restent visibles dans OBS ou Streamlabs Desktop, commencez par guide illustré de superposition d'événements.

Choisissez la bonne page de démarrage

Utilisez multi-alerts.html pour les présentations d'alertes chronométrées et events.html ou themes/events/index.html pour une liste d'événements en cours d'exécution. Ils ont un comportement de rendu et de file d'attente différent. Commencez par l'URL générée pour l'outil que vous utilisez déjà.

Choisissez un style de flux d'activité

Ouvrir Flux d'activité / Événements → Activer et personnaliser → Style de flux, choisissez une mise en page, puis copiez le lien mis à jour dans votre navigateur ou dans OBS Source du navigateur. Ouvert Personnaliser l'apparence du flux pour ajuster les couleurs et l’espacement. Laissez un champ vide pour utiliser le style par défaut.

Ajoutez ces options à votre existant events.html?session=YOUR_SESSION_ID lien avec &. Conservez votre session, votre mot de passe et vos options de connexion.

  • accent, pagebg, cardbg, textcolor, et mutedcolor: CSS couleurs. Encoder une couleur hexadécimale # comme %23 dans le URL, ou omettez le #.
  • fontsize=14: taille du texte, 10 à 40 pixels. padding=8, gap=4, et radius=6: remplissage des lignes, espace entre les événements et rayon des coins, chacun de 0 à 40 pixels.
  • noheader masque le titre de la page ; noanimation désactive l'animation d'entrée.
  • Combinez les styles avec lightmode, transparent, font, googlefont, scale, notime, et hidemeta. Le mode transparent remplace l'arrière-plan de la page ; les arrière-plans des cartes restent réglables séparément.

Par exemple, ajoutez &style=twitch&accent=%23e5b94f&padding=8&fontsize=14 pour une liste d’activités plus dense avec un accent doré.

Choisissez ce qui apparaît dans le flux d'activité

Dans Flux d'activité / Événements → Activer et personnaliser, ouvrez Choisissez quels événements apparaissent ou Contenu et comportement des lignes. Laissez les contrôles désactivés et les champs vides pour conserver la vue par défaut. Copiez le lien mis à jour après les avoir modifiés. Ces contrôles affectent uniquement ce flux ; le chat ordinaire reste exclu.

Chaque ligne appartient à une catégorie en fonction de son nom d'événement. Les adhésions nominatives, les cadeaux et les achats conservent leur catégorie même lorsqu'ils comportent un montant. Conseils avec hasDonation et aucun nom d'événement reconnu n'appartient à la catégorie des messages payants, y compris les Twitch bits DOM. Les badges d'adhésion sur le chat ordinaire n'en font pas un événement d'adhésion.

Pour un contrôle plus fin, utilisez filterevents=supersticker,watch_streak pour masquer les noms exacts des événements. La correspondance ignore la casse et utilise les alias d'événement existants du flux ; il ne recherche pas le texte du message. Les exclusions de catégorie et de nom exact se combinent avec les filtres existants de source, de dons uniquement, d'abonnements offerts uniquement et de valeur minimale. L'activation de plusieurs filtres peut ne laisser aucun événement correspondant. Voir le référence des événements pour les charges utiles spécifiques à la source.

  • hidemessage, hidecontentimg, hideplatformicons, hideeventlabels et hideamounts masquer les éléments de ligne correspondants. Ils ne suppriment pas l'événement et ne modifient pas ce que le clic vers la fonctionnalité envoie. Les émoticônes en ligne font partie du texte du message. Les montants ou les noms écrits dans le texte du message, les métadonnées ou les détails Hype Train ne sont pas expurgés par ces contrôles.
  • nofeature désactive le clic vers une fonctionnalité dans ce flux. Les détails des métadonnées peuvent toujours être ouverts.
  • hidecategorytag hides only the generic category tag, such as Donation or Event, while keeping the descriptive event label. In the popup, enable Hide category tag sous Contenu et comportement des lignes.
  • eventduration=60 supprime une ligne de ce flux après 60 secondes. Vide ou 0 conserve le comportement de rétention existant ; les valeurs positives vont de 1 à 86 400 secondes. Les mises à jour Hype Train redémarrent leur minuteur ; les trains terminés disparaissent toujours après 30 secondes maximum. La suppression n'efface pas un événement déjà envoyé à une superposition sélectionnée.
  • hideempty masque le message en attente lorsqu'aucun événement n'est visible.

Téléchargez et conservez la structure du fichier

  1. Téléchargez le ZIP source et extrayez-le. Ces guides utilisent la source bêta ; conservez les fichiers d’un téléchargement ensemble.
  2. Copier multi-alerts.html à my-alerts.html à côté de l'original. Si vous choisissez une page ou un thème différent, conservez sa copie dans le dossier d'origine de ce fichier.
  3. Ouvrez le code HTML copié et son CSS/JS référencé dans votre éditeur ou outil d'IA. Ajoutez les illustrations/polices fournies au même projet et utilisez des chemins relatifs. Commencez par les remplacements CSS ; inclure le moteur de rendu lors de la modification du balisage généré.

Les fichiers suivants vous aident à trouver la conception et le comportement. Il s'agit d'une liste de lecture, pas d'un ensemble de dépendances complet : conservez le dossier extrait intact, y compris les images, les polices, les scripts et tous les fichiers de données.

Connectez votre copie et ouvrez-la dans OBS

Démarrez SSN et faites fonctionner en premier l'URL de superposition générée d'origine. Le session= se connecte à cette session SSN ; ce n'est pas le nom de votre chaîne ou le nom de ce fichier. Gardez SSN, la fonctionnalité concernée et ses sources de données en cours d'exécution.

  1. Faites glisser votre fichier HTML modifié vers Chrome ou Edge. Copiez son adresse depuis la barre d'adresse ; ça commence par file:///.
  2. Copiez tout depuis ? dans votre lien de superposition SSN de travail et ajoutez-le à la fin de cette adresse de fichier. Conservez tous les paramètres, y compris la session, le mot de passe et tout # fin.
  3. Ouvrez le résultat dans un navigateur, puis définissez la source du navigateur OBS. URL à la même adresse avec Fichier local décoché. Faites correspondre les dimensions source à votre conception prévue.

Pour le fichier de départ ci-dessus, l'adresse locale ressemble à ceci ; votre lien réel peut contenir des options supplémentaires requises :

file:///C:/SSN/social_stream-beta/my-alerts.html?session=YOUR_SESSION

Utilisez l'adresse réelle du fichier sur votre ordinateur. OBS l'enregistre avec la source ; conservez le dossier téléchargé au même endroit. Après avoir enregistré les modifications de conception, actualisez la source du navigateur. Le guide de configuration partagé inclut des exemples Mac et un lanceur facultatif pour la case à cocher Fichier local.

Où modifier le design

Modifiez le cadre d'alerte, la typographie, le placement des icônes, la décoration de progression/timing et le mouvement. Dans Multi-Alerts, une grande partie de la mise en page est créée dans multi-alerts.js; incluez-le lorsque vous demandez à l’IA de modifier la structure. Pour un fork isolé, copiez également ce script et mettez à jour uniquement la référence de script HTML copiée.

Préserver la classification et les filtres des événements. Une ligne de chat payante peut utiliser hasDonation sans event: "donation"; les plateformes ont également des noms d’événements spécifiques. Utilisez le référence des événements et guide de compatibilité pour choisir les échantillons. Conservez séparément le montant affiché d’origine et tout remplacement numérique en USD.

Testez ce type de superposition

Utilisez d'abord une configuration d'aperçu ou de test. Le guide des messages de test explique comment envoyer des charges utiles fictives via SSN ; un test soumis à votre session de production peut déclencher ses automatisations existantes.

  1. Utilisez l'outil de message de test pour envoyer le message spécifique de suivi, d'abonnement, de cadeau, de raid ou payant pris en charge par votre source ; vérifiez quels champs sont réellement présents.
  2. Envoyez deux alertes rapprochées pour vérifier la file d'attente et quitter les animations. Testez un message vide avec une étiquette de don et un nom long.
  3. Pour les flux d'événements, vérifiez le défilement, le filtrage et tout comportement de fonctionnalité au clic. Pour les effets sonores, vérifiez la source audio dans OBS ainsi que l'image.

Exécutez également le vérifications du rendu des entrées par rapport aux chemins de rendu que vous avez modifiés. Après avoir enregistré les modifications, actualisez la source du navigateur OBS entre les répétitions et répétez l'interaction visible. Les aperçus du navigateur n'établissent pas de capture en direct ni de comportement OBS.
