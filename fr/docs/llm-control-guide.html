API de contrôle local et MCP

Permettez à un outil IA ou à un script sur le même ordinateur d'inspecter et de contrôler l'application de bureau Social Stream Ninja.

Quand choisir ce service

Application de bureau→API de contrôle local→Client MCP

Utilisez l'API de contrôle local lorsque des logiciels sur l'ordinateur SSApp ont besoin de commandes approuvées de l'application et des sources. Utilisez l'adaptateur MCP inclus lorsqu'un client IA compatible doit recevoir ces commandes comme outils.

Cela est distinct de Fichier > Activer le serveur local (File > Enable Local Server), qui démarre un relais WebSocket pour les pages Social Stream. Voir Comprendre les serveurs et services locaux si vous ne savez pas quel service utiliser.

1. Télécharger l'application de bureau habituelle

Installez la version actuelle de Social Stream Ninja depuis les téléchargements Windows, macOS ou Linux. La prise en charge MCP est incluse dans l'application téléchargée. Vous n'avez pas besoin du dépôt source, de Node, de Python ni d'un paquet MCP séparé.

2. Activer le contrôle IA local

  1. Ouvrir Fichier > IA locale / Automatisation (File > Local AI / Automation).
  2. Activer API de contrôle local et laissez l'application redémarrer.
  3. Revenez au même menu et choisissez Copier la configuration MCP (Copy MCP Setup).
  4. Collez le JSON copié dans les paramètres MCP de l'outil IA, puis redémarrez cet outil.

La configuration copiée contient le chemin exact de l'exécutable installé, le port et les arguments propres à la plateforme. L'exécutable Social Stream Ninja téléchargé démarre son propre adaptateur MCP léger lorsque le client IA le lance avec --ssapp-mcp.

3. Laisser MCP découvrir les capacités

Une fois connecté, le client MCP demande automatiquement ses outils à Social Stream Ninja. L'adaptateur lit les capacités actuelles de l'application en cours et fournit au LLM les schémas des outils pris en charge, les versions de l'application/de l'API et les instructions de fonctionnement. L'agent doit d'abord consulter les capacités, puis l'état, et utiliser les identifiants stables des sources renvoyés par l'application.

Aucune extraction de site web ni installation de compétence n'est requise pour l'utilisation normale de MCP. Un utilisateur peut simplement demander à l'agent connecté d'inspecter ou de contrôler Social Stream Ninja.

Commandes locales disponibles

  • Lister, inspecter, ajouter, modifier et supprimer les sources.
  • Démarrer, arrêter ou recharger une source ou un ensemble filtré.
  • Modifier la visibilité, l'état de mise en sourdine et le mode de connexion des sources.
  • Lire et modifier les paramètres globaux pris en charge renvoyés par la découverte des capacités.
  • Lire l'état de l'application, de la session, des sources, des processus, de la capture et des médias locaux.
  • Suivre les événements limités des sources capturées et les événements d'opération ou d'état pouvant être repris.
  • Capturer et inspecter de façon sûre les pages sources prises en charge et les fenêtres appartenant à SSApp.
  • Effectuer les interactions approuvées avec les pages, fenêtres et boîtes de dialogue avec confirmation.
  • Recharger ou fermer proprement l'application avec confirmation explicite.

Les capacités de l'application en cours font autorité. Les anciennes versions peuvent proposer moins de commandes.

Accès HTTP direct pour les scripts locaux

Les scripts sur le même ordinateur peuvent utiliser l'API locale sans MCP. Elle écoute uniquement sur 127.0.0.1 et ne nécessite aucun jeton.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

Utilisez les capacités annoncées plutôt que de supposer que chaque version de l'application possède les mêmes commandes. Pour des exemples à copier-coller de curl qui ajoutent, listent, démarrent, inspectent et arrêtent une source, consultez le guide pas à pas de l'API HTTP du serveur.

IA locale sur un VPS Ubuntu

L'API peut aussi servir un outil IA fonctionnant sur le même serveur Linux qu'une instance SSApp sans interface. Gardez-la liée à l'adresse locale de bouclage et utilisez l'AppImage téléchargée comme commande MCP.

Suivi Exécuter Social Stream Ninja sans interface pour Xvfb, les profils persistants, les commandes de démarrage, systemd et le circuit distinct de contrôle à distance. Il inclut aussi une configuration MCP de l'AppImage Linux à coller dans un client exécuté sur le VPS.

Compétence d'agent facultative

Les agents prenant en charge les compétences installables peuvent télécharger la compétence complète Control Social Stream. Vous pouvez aussi lire ses instructions en ligne, avec l'option référence API et historique des versions. La compétence ajoute des conseils de fonctionnement, mais n'est pas nécessaire à la connexion MCP.

Les liens de découverte lisibles par machine sont aussi répertoriés dans llms.txt.

Local uniquement

Cette interface est destinée à l'IA et aux automatisations exécutées sur le même ordinateur que SSApp. Ne l'exposez pas et ne créez pas de tunnel pour en faire une API de contrôle distant cloud. Les utilisateurs distants et Stream Deck doivent utiliser la connexion WebRTC ou WebSocket existante de Social Stream. L'API locale ne fournit ni exécution JavaScript arbitraire, ni cookies, ni secrets de connexion, ni paramètres sans restriction, ni accès brut au système de fichiers.

Pour tous les points de terminaison, schémas de commandes, mécanismes de découverte des versions et limites de sécurité, consultez la référence technique de l'automatisation.
