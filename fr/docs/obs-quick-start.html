Démarrage rapide OBS

Affichez le chat dans OBS avec un minimum d'étapes.

1. Choisir un identifiant de session

Choisissez un identifiant de session court et utilisez-le partout. Il permet à la source de chat, au Dock et à l'incrustation OBS de se retrouver.

YOUR_SESSION_ID

2. Démarrer une source de chat

  1. Installez ou ouvrez Social Stream Ninja.
  2. Ouvrez la source de chat de votre plateforme et laissez-la ouverte.
  3. Envoyez ou attendez un message de chat pour vérifier que la source fonctionne.

Vous ne savez pas quel mode de source utiliser ? Consultez le Sélecteur de configuration de plateforme.

3. Ouvrir le Dock

Le Dock est votre écran de test. Ouvrez-le avant de modifier les paramètres OBS.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

4. Ajouter une source navigateur OBS

Dans OBS, ajoutez une source navigateur et collez l'URL de l'incrustation.

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

Pour les dispositions ordinaires d'incrustations de chat, utilisez un modèle de la Galerie de modèles.

5. Si OBS reste vide

Vérifiez un élément à la fois, dans cet ordre.

  • Vérifiez d'abord que le Dock reçoit les messages. S'il est vide, le problème ne vient pas encore d'OBS.
  • Vérifiez que l'URL OBS contient le même session.
  • Actualisez la source navigateur OBS après avoir modifié les options URL.
  • Vérifiez que la page source de chat ou la fenêtre source de l'application est toujours en cours d'exécution.
