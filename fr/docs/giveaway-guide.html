Votre premier tirage au sort

Les spectateurs tapent !enter dans le chat. Vous recueillez les inscriptions dans SSN, puis cliquez sur Tirer un gagnant (Draw winner).

Trouver les commandes Organiser un tirage au sort Afficher dans OBS Signification des paramètres Rôle des boutons Dépannage

1. Trouver l'outil de tirage au sort

Si vous voyez déjà Outil de tirage au sort (Giveaway Tool), Configuration des inscriptions, et Lancer le tirage, vous êtes au bon endroit. Il n'y a pas de fenêtre de tirage supplémentaire à trouver.

Sinon, ouvrez le menu principal des paramètres SSN. Avec l'extension de navigateur, cliquez sur l'icône d'extensions/en forme de puzzle du navigateur, puis sur Social Stream Ninja. Dans l'application de bureau, utilisez le menu des paramètres SSN contenant vos liens d'incrustation. Recherchez giveaway et développez Options du tirage (Giveaway Options). Si l'écran d'accueil pour débutants s'affiche, choisissez Passer au mode complet (Switch to full mode).

  1. Les spectateurs s'inscriventDans votre chat capturé habituel
  2. Vous effectuez le tirageDans le menu des paramètres SSN
  3. OBS affiche le résultatAvec le lien d'affichage copié

Le lien commençant par https://socialstream.ninja/giveaway.html?session=... ouvre l'affichage public. Avec &managed dans ce lien, vous contrôlez le tirage depuis SSN ; l'affichage ne comporte aucun bouton d'inscription ou de tirage.

2. Organiser un tirage gratuit simple

Avant de commencer, gardez SSN activé et vos sources de chat connectées. Vérifiez que les messages ordinaires des spectateurs apparaissent dans votre Dock de chat SSN.

  1. Conservez les paramètres de base. Laissez Identifiant du tirage (Giveaway ID) comme default (vide signifie aussi la valeur par défaut), Mot-clé d'inscription comme !enter, et Correspondance des messages comme Message exact (Exact message). Laissez Seuls les membres peuvent participer et Autoriser les gagnants répétés désactivé.
  2. Vérifiez Tickets and point prizes. Pour un tirage gratuit normal, utilisez Type de manche : tirage au sort (Giveaway), Points par ticket : 0, Prix en points par gagnant : 0, et Nombre de prix : 1. Vous n'avez pas besoin du système de points de fidélité pour cela.
  3. Cliquez sur Open entries. Dites aux spectateurs : « Tapez !enter dans le chat pour participer au tirage. » Ils participent dans le chat que vous capturez, par exemple YouTube ou Twitch. Ils n'ont pas besoin du lien du tirage.
  4. Vérifiez les inscriptions. Cliquez sur Actualiser l'état (Refresh status) pour mettre à jour le nombre dans le menu, ou Gérer les tirages et l'historique pour inspecter les noms. Répéter !enter ne donne pas d'inscriptions gratuites supplémentaires au même spectateur.
  5. Cliquez sur Close entries, puis sur Draw winner. SSN sélectionne au hasard une inscription admissible. Le menu indique le gagnant et les affichages connectés montrent le même résultat. Le tirage ferme aussi automatiquement les inscriptions.
  6. Pour un autre tirage, cliquez sur New round, puis sur Open entries. La nouvelle manche démarre avec une liste d'inscriptions vide ; les spectateurs doivent s'inscrire à nouveau. Les résultats précédents restent dans l'historique.
« Entries open - 0 eligible entries » n'est pas une erreur. Le tirage accepte les inscriptions, mais la dernière vérification d'état n'en a trouvé aucune. Demandez à un spectateur d'envoyer !enter après l'ouverture des inscriptions, puis cliquez sur Actualiser l'état (Refresh status). Le compteur de la fenêtre ne se met pas à jour automatiquement à l'arrivée des messages.

L'état peut aussi afficher un nombre de tickets. Chaque inscription gratuite compte pour un ticket ; si le prix du ticket est zéro, aucun point n'est débité.

SSN sélectionne le gagnant. Si votre prix est un cadeau, une clé de jeu ou un autre article, vous organisez vous-même sa remise. Un Prix en points attribue spécifiquement des points de fidélité SSN.

3. Afficher le tirage dans OBS

  1. Sous Présentation, choisissez un Affichage du tirage: Carte du gagnant (Winner card) affiche directement le résultat ; Défilement des noms (Name reel) fait défiler les noms avant la révélation ; Roue communautaire (Community wheel) révèle le résultat avec une roue qui tourne.
  2. Choisissez un Style, un champ facultatif Titre d'affichage, et Transparent (OBS) pour le fond. Panneau à thème (Themed panel) ajoute un panneau de fond.
  3. Cliquez sur Aperçu de l'affichage pour vérifier l'apparence. Cela utilise des noms d'exemple ; cela n'ouvre pas les inscriptions, n'ajoute pas de vrais spectateurs et n'effectue pas votre véritable tirage.
  4. Cliquez sur [copier le lien] à côté de Outil de tirage au sort (Giveaway Tool). Dans OBS, ajoutez une Source navigateur et collez ce lien dans son champ URL. Commencez avec une largeur de 1280 et une hauteur de 720.
  5. Gardez SSN en cours d'exécution et utilisez ses Ouvrir les inscriptions (Open entries), Fermer les inscriptions (Close entries), et Tirer un gagnant (Draw winner) boutons. Aucune étape « Interagir » dans OBS n'est nécessaire pour cet affichage géré.

Copiez à nouveau le lien après avoir modifié les paramètres de présentation et remplacez l'URL dans OBS. Utilisez le lien copié normal, pas l'URL d'aperçu. Conservez la session et tout mot de passe de votre propre menu SSN pour que l'affichage se connecte à votre tirage.

[modifier le lien] charge une URL d'incrustation existante dans les paramètres de lien du menu. Vous n'en avez pas besoin pour un premier tirage. [?] ouvre le court texte d'aide.

Signification des paramètres d'inscription

ParamètreSignification
Identifiant du tirage (Giveaway ID)Nomme le tirage contrôlé. Utilisez default pour un tirage. Il est distinct de votre identifiant de session. Plusieurs tirages nécessitent des identifiants distincts et des liens d'affichage correspondants.
Mot-clé d'inscriptionCe que les spectateurs tapent, par exemple !enter ou !raffle. Indiquez aux spectateurs le mot-clé que vous avez réellement configuré.
Message exact (Exact message)Le message entier doit être !enter, sans tenir compte des majuscules ni des espaces au début et à la fin. !enter please ne correspond pas.
Mot-clé n'importe où (mot séparé)Autorise un message tel que I'd like to join !enter please. Le mot-clé doit être séparé par des espaces ; !enter! n'est pas le même mot-clé.
Seuls les membres peuvent participerNécessite des informations d'abonnement dans le message capturé. Laissez cette option désactivée pour un tirage ouvert ; elle ne signifie pas « toute personne qui regarde » ni « tout follower ». La prise en charge dépend de la source de chat.
Autoriser les gagnants répétésPermet au même spectateur de gagner plusieurs prix dans la manche en cours. Lorsque cette option est désactivée, un gagnant est retiré du groupe admissible de cette manche. Une nouvelle manche permet aux anciens gagnants de participer à nouveau.
Tickets et prix en points (Tickets and point prizes)Paramètres facultatifs de points de fidélité SSN et autres types de jeux. Laissez les coûts et les prix en points à zéro pour un tirage gratuit. Ils sont distincts des points de chaîne Twitch.
Nombre de prixNombre de résultats autorisés dans la manche. Définissez-le avant d'ouvrir les inscriptions. Pour plusieurs gagnants, cliquez sur Tirer un gagnant (Draw winner) une fois par prix ; ne créez pas de nouvelle manche entre ces tirages.

Définissez les règles d'inscription avant l'arrivée des participants. Dès qu'il existe des inscriptions, modifier les champs du menu ne change pas les règles de la manche active. Pour les modifier, annulez la manche, créez-en une nouvelle, configurez-la et rouvrez les inscriptions. Le gestionnaire montre les règles réellement enregistrées pour la manche.

Les inscriptions gratuites sont suivies à l'aide de l'identité fournie par chaque source de chat. Une même personne participant sur deux plateformes n'est pas automatiquement reconnue comme une seule personne.

Rôle des boutons

BoutonUtilisez-le pour
Ouvrir les inscriptions (Open entries)Accepter les inscriptions ou rouvrir une manche en pause avant tout tirage. La réouverture conserve les inscriptions existantes et doit utiliser les mêmes règles verrouillées.
Fermer les inscriptions (Close entries)Arrêter les nouvelles inscriptions tout en conservant le groupe actuel.
Tirer un gagnant (Draw winner)Fermer les inscriptions et sélectionner un gagnant. Il doit y avoir au moins une inscription admissible. Avec un seul prix configuré, la manche est alors terminée.
Annuler et rembourserAnnuler avant le tirage. Tous les points réservés aux tickets sont restitués. Cela ne peut pas annuler un résultat déjà tiré.
Nouvelle manche (New round)Repartir avec un groupe vide et conserver l'historique précédent. Les inscriptions sont fermées au départ. Les manches payantes avec des points réservés doivent d'abord être annulées/remboursées.
Actualiser l'état (Refresh status)Lire le nombre actuel et le dernier résultat sans modifier le tirage.
Gérer les tirages et l'historiqueInspecter les participants et les règles enregistrées, retirer une inscription avant le tirage, consulter les résultats ou exporter l'historique/des sauvegardes.

Si quelque chose ne fonctionne pas

  • Toujours zéro inscription ? Cliquez sur Actualiser l'état (Refresh status). Vérifiez que le message du spectateur apparaît dans SSN, que les inscriptions étaient ouvertes à son arrivée, que le mot-clé correspond et que l'option réservée aux membres est désactivée. Pour un tirage gratuit par mot-clé, le prix du ticket doit être zéro. Donnez des mots-clés différents aux tirages gratuits simultanés.
  • Les messages de test ne s'inscrivent pas ? Les messages de bots, privés, historiques, rejoués et marqués comme tests d'économie sont exclus. Utilisez Aperçu de l'affichage pour vérifier l'apparence ; pour répéter la capture réelle des inscriptions, envoyez le mot-clé dans un chat connecté après avoir ouvert les inscriptions.
  • L'affichage indique seulement « Waiting for giveaway » ? Gardez l'hôte SSN en cours d'exécution, utilisez le lien copié depuis la même session et cliquez sur Actualiser l'état (Refresh status). Vérifiez que le menu et l'affichage utilisent le même Giveaway ID. Une URL d'aperçu montre uniquement des données d'exemple.
  • Aucun bouton sur la page du tirage ? C'est normal pour l'affichage public géré. Revenez à Options du tirage (Giveaway Options) dans SSN.
  • La manche est terminée ou les règles sont verrouillées ? Utilisez Nouvelle manche (New round) après un tirage terminé. Pour abandonner une manche sans tirage, utilisez Annuler et rembourser d'abord, puis Nouvelle manche (New round).
  • SSN a redémarré ? Les manches enregistrées restent dans ce profil local de navigateur/application ; les manches ouvertes se ferment pour vérification. Utilisez la même session, actualisez l'état et vérifiez avant de rouvrir. Changer de session sélectionne un ensemble distinct de tirages.
