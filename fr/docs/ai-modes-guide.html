Deux sens différents de « ChatGPT »

OptionDescriptionConversation
Fournisseur API ChatGPTSSN envoie des prompts à OpenAI avec votre clé API et le modèle choisi.Une conversation SSN/API, distincte de chatgpt.com.

Important : connecter l’API OpenAI ne relie pas SSN à une conversation ChatGPT web ou vocale existante. L’API OpenAI gère son propre état de conversation.

Option 1 : compagnon ChatGPT dans le navigateur (expérimental)

C’est l’option la plus proche si vous utilisez déjà ChatGPT dans Chrome et ne voulez pas de clé API. SSN peut capturer les nouveaux tours textuels de la page sous le type de source openai, comme pour une source de chat.

Capturer une conversation ChatGPT

  1. Installez et activez l’extension Chrome Social Stream Ninja.
  2. Dans le menu, activez l’option ChatGPT source.
  3. Ouvrir https://chatgpt.com/ et rechargez la page après avoir activé la source.
  4. Ouvrez le Dock SSN avec la même session.
  5. Envoyez un nouveau message ChatGPT. Les nouveaux tours utilisateur et ChatGPT devraient apparaître dans le Dock ; l’historique existant est volontairement ignoré.

Envoyer le chat en direct dans l’onglet ChatGPT ouvert

  1. Testez avec un direct privé ou non répertorié et une conversation ChatGPT textuelle classique.
  2. Sous Gestion, activez Relayer tous les messages.
  3. Définissez Choisir les destinations du relais à openai pour envoyer les messages capturés du public uniquement à l’onglet ChatGPT.
  4. Gardez l’onglet ChatGPT ouvert. Ses nouvelles réponses reviennent dans SSN comme openai messages.
  5. Utilisez l’audio ChatGPT ou la sortie de synthèse vocale/incrustation SSN pour diffuser ces réponses.

Expérimental : les commandes de la page peuvent changer, le relais global peut saturer une conversation et le mode vocal de ChatGPT peut ne pas accepter le texte injecté comme la page textuelle classique. Utilisez des filtres ou un direct de test avant d’envoyer tous les messages.

  2. Ouvrir Configurer le fournisseur LLM et choisissez le fournisseur que vous utilisez réellement.

  5. Activez la fonction distincte qui doit l’utiliser : bot principal, bot privé, coprésentateur, modération, traduction, RAG ou générateur.

Option 3 : coprésentateur vocal IA

Le coprésentateur est conçu pour parler à l’IA pendant qu’elle voit aussi le chat en direct. Votre microphone et les messages sélectionnés alimentent la même session, et sa réponse peut être diffusée à voix haute.

  1. Ouvrir cohost.html?session=YOUR_SESSION.
  2. Choisissez un fournisseur vocal/temps réel ou le LLM configuré dans le menu SSN.
  3. Sélectionnez explicitement votre microphone et Réponse audio, puis appuyez sur Démarrer le coprésentateur.
  4. Avec OpenAI Realtime, laissez Live Chat sur Contexte uniquement - répondre sur demande si vous voulez que l’IA retienne les messages récents sans interrompre. Choisissez Questions et mentions ou Chaque message pour des réponses vocales automatiques ; ces modes ne publient pas dans le chat de la plateforme.
  5. Avec OpenAI Realtime, capturez dans OBS l’audio du navigateur/de l’application du coprésentateur et utilisez cohost-overlay.html?session=YOUR_SESSION pour l’avatar de scène et la bulle. L’incrustation ne reçoit pas le même flux vocal WebRTC. Utilisez le sélecteur de sortie du coprésentateur pour un câble virtuel si c’est pris en charge ; &forcetts ajoute volontairement une voix séparée à l’incrustation.
  6. Les outils facultatifs du direct sont désactivés par défaut. Activez Spotify, une liste de noms de scènes OBS autorisées ou le contrôle des messages en vedette dans le menu SSN, puis armez les mêmes outils sous Commandes du direct par le coprésentateur sur la page du coprésentateur.
  7. Pour réduire la latence OpenAI, choisissez Mini, un raisonnement Low et une prise de parole Fast. Full quality et un raisonnement élevé peuvent améliorer les réponses difficiles, avec plus de délai et de coût API ; Fast peut couper des pauses naturelles. Diagnostics affiche le délai mesuré avant la première sortie.
  8. L’entrée caméra et partage d’écran d’OpenAI est facultative et réglée par défaut sur Aucune vidéo. Si cette option est choisie, SSN envoie une image actuelle à chaque demande vocale ou saisie directe ; ce n’est pas une vidéo continue et cela peut ajouter du coût API et de la latence.
  9. Gardez la bulle de texte visible ou fournissez des sous-titres pour que le public puisse suivre sans entendre la voix IA.

OpenAI Realtime utilise la clé de projet OpenAI configurée sous API ChatGPT dans le menu SSN. La clé standard reste dans le processus d’arrière-plan de l’extension/application, qui crée un secret client Realtime temporaire pour la page du coprésentateur. Le microphone et la voix IA transitent ensuite sur WebRTC. Les réponses sont limitées à 512 tokens de sortie et Diagnostics indique consommation cumulée et latence. SSN vérifie les sessions silencieuses et reconnecte les transports défaillants ; une session récupérée réapplique instructions et performances, mais ne peut pas restaurer la conversation vocale précédente. Cela crée une session de coprésentateur SSN ; cela ne reprend pas une conversation existante du site ou de l’application ChatGPT.

Option 4 : bot principal de chat en direct

Le bot principal évalue les messages capturés du public et peut répondre dans une incrustation, par synthèse vocale ou dans les chats de plateformes compatibles.

  1. Configurez et testez un fournisseur IA.
  2. Activez le Bot IA principal du chat.
  3. Choisissez les mots déclencheurs, le mode réservé aux modérateurs, les limites de fréquence, l’historique et les instructions.
  4. Pour un premier test prudent, activez Les réponses du bot vont UNIQUEMENT à sa page d’incrustation.
  5. Ouvrir bot.html?session=YOUR_SESSION et activez la synthèse vocale si les réponses doivent être lues.
  6. Ne désactivez le mode incrustation uniquement qu’après avoir confirmé que la plateforme cible permet la publication.

Les réponses utilisent normalement le compte connecté. Pour une identité distincte, utilisez un compte bot YouTube, Twitch ou Kick dédié lorsque c’est pris en charge.

Option 5 : bot privé individuel

chatbot.html est une page d’assistance privée et de test de prompts. Activez Bot de chat - Interface privée, ouvrez la page avec votre session et utilisez le fournisseur LLM configuré.

Le bot privé est distinct du bot principal de chat en direct et ne partage actuellement ni son jeu de données RAG ni les autres historiques de chat.

Solutions courantes

  • Connecté, mais aucune réponse en direct : activez le bot principal ou la fonction IA concernée ; configurer le fournisseur seul ne traite pas le chat.
  • Le coprésentateur voit le chat, mais ne parle pas : Context only attend volontairement que le streamer pose une question sur le chat. Passez à Questions and mentions ou Every message pour obtenir des réponses automatiques.
  • La source navigateur ChatGPT est silencieuse : activez l’option ChatGPT, rechargez chatgpt.com, puis testez avec un nouveau tour plutôt qu’avec l’historique existant.
  • Le bot ignore la plupart des messages : vérifiez les mots déclencheurs, le mode modérateur uniquement, les limites de fréquence et l’instruction du modèle de répondre sélectivement.
  • Le texte apparaît, mais aucun son : confirmez que la page produisant la synthèse vocale est ouverte et qu’OBS capture son audio.
  • Le bot ne peut pas publier : vérifiez la prise en charge des réponses, la connexion, les permissions du compte et les limites de fréquence.
