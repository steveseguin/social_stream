Sélecteur de configuration de plateforme

Choisissez la capture la plus simple avant d'ouvrir OBS.

Commencer par la page des sites pris en charge

Recherchez d'abord votre plateforme. Cliquez dessus et lisez la courte note de configuration avant d'essayer une méthode plus complexe.

Utiliser l'extension de navigateur normale lorsque

  • La plateforme fonctionne dans votre navigateur habituel.
  • Vous êtes déjà connecté au bon compte.
  • La page des sites pris en charge indique d'ouvrir le site ou le chat détaché.

Commencez ici pour YouTube, Twitch, Facebook, Discord, Slack, WhatsApp et la plupart des sources dans le navigateur.

Utiliser une fenêtre détachée ou de chat seul lorsque

  • La plateforme possède une URL distincte de chat détaché.
  • La page normale du direct est lourde ou peu fiable.
  • Vous souhaitez une petite fenêtre affichant uniquement le chat.

Pour les notes précises sur chaque plateforme, consultez Sites pris en charge.

Utiliser l'application de bureau lorsque

  • Les onglets du navigateur sont masqués, ralentis ou déchargés.
  • Vous souhaitez que les fenêtres sources soient gérées dans l'application.
  • Vous utilisez une intégration propre à l'application, comme certains modes TikTok.

Configuration de bureau : Guide de l'application autonome.

Utiliser une page source lorsque

  • La plateforme nécessite une URL source Social Stream dédiée.
  • La configuration demande une chaîne, un salon, un jeton ou une étape de connexion.
  • La plateforme n'est pas capturée depuis un onglet de navigateur normal.

Les pages sources sont normales. Elles signifient simplement que Social Stream a besoin d'une page spéciale pour cette plateforme.

Décision rapide

SituationUtilisez
Site de chat standard pris en chargeExtension de navigateur
Le site demande de détacher le chatFenêtre détachée/de chat seul
Un onglet masqué cesse de se mettre à jourApplication de bureau
La configuration demande un salon/une chaîne/un jetonPage source
Automatisation personnalisée ou données entrantesCommandes/API ou source personnalisée

En cas de doute, commencez par la ligne correspondante la plus simple. Vous pourrez changer de méthode plus tard.
