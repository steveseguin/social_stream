Trois étapes

Connecter à OBS

  1. Choisissez votre affichageOuvrir Monétisation dans la fenêtre SSN. Ajoutez un produit, connectez une boutique ou ouvrez Tableaux de places et ventes récentes.
  2. Enregistrez, puis copiez son lienUtilisez Enregistrer la configuration pour les fournisseurs. Les commandes des tableaux s'enregistrent immédiatement. Copiez le lien OBS de l'affichage.
  3. Ajouter une source navigateur OBSCollez le lien. Commencez à 800 × 600 pour une carte produit, ou 1920 × 1080 pour un tableau. Gardez SSN en cours d'exécution.

Seul l'affichage apparaît dans le direct. Contrôlez-le dans SSN ; un Dock de contrôle OBS est facultatif.

Produits et liens de soutien

Produits et liens de soutien

  1. Ajoutez un lien public, un nom et éventuellement une image ou un prix.
  2. Choisir Boutique, Cadeau, Assistance ou Rejoindre, puis enregistrez.
  3. Utilisez Afficher / Suivant / Masquer / Reprendre (Show / Next / Hide / Resume) pour contrôler la vitrine.

Un lien de produit sert à promouvoir un article. Connectez la boutique séparément pour les alertes d'achat.

Commandes de produits →Configuration de boutique →
Codes QR, rotation et options d'affichage

Enregistrez jusqu'à 20 liens publics. Épinglez-en un ou faites-les défiler ; chacun reste visible au moins 15 secondes. Partagez aussi le lien public dans le chat pour les spectateurs sur téléphone.

Choisissez Showcase, Support card ou Activity alerts pour des sources OBS distinctes. Le style compact, l'échelle, le coin et l'affichage temporisé sont dans Overlay link options. Les prix manuels sont des instantanés ; les achats ne retirent pas les produits manuels.

Différences entre ventes et enchères

Seules les commandes payées du vendeur connecté peuvent produire des alertes d'achat. Une offre, une enchère terminée ou un changement de stock ne prouvent pas le paiement. Les prix s'actualisent environ une fois par minute.

Le premier achat retire l'annonce sélectionnée de la rotation de la vitrine. Les achats suivants déclenchent toujours une alerte. L'identité de l'acheteur est omise ; les remboursements ne rouvrent pas les entrées. La connexion vendeur nécessite que le service SSN eBay soit disponible.

Cadeaux Throne

Saisissez votre nom d'utilisateur, enregistrez, puis collez l'URL Webhook de SSN dans Throne.

Aperçu →
Rangs de cadeaux et contributions

Les cadeaux terminés augmentent votre rang. Les contributions affichent une alerte ; le rang augmente lorsque le cadeau est entièrement financé. SSN ne devine pas quel article de la liste de souhaits a été acheté.

Gardez SSN connecté. Le rang est local à cette installation ; les remboursements et annulations ne le réduisent pas. Les cadeaux anonymes restent anonymes.

Importation et confirmation

Vérifiez les prix importés et les articles manquants ; utilisez la saisie manuelle si l'importation échoue. Retirer un article d'Amazon ne prouve pas un achat. Utilisez une seule devise par liste progressive.

Après avoir vérifié l'achat, choisissez Confirmer l'achat de l'article actuel (Confirm current item bought). Undo couvre la dernière confirmation pendant l'exécution actuelle de SSN. Vérifiez les paramètres de partage public et d'adresse de votre liste de souhaits.

Pourboires NinjaBacker

Connectez Stripe sur NinjaBacker. Saisissez votre nom d'utilisateur et votre Tip ID privé dans SSN.

Aperçu →
Flux en direct ou webhook fiable ?

Le flux en direct est la configuration la plus simple. Le webhook fiable met les pourboires signés en file d'attente pendant jusqu'à sept jours, y compris lorsque SSN est éteint. Suivez les instructions de configuration et envoyez un pourboire de test depuis le tableau de bord.

Le Tip ID privé ne figure pas dans les URL d'incrustation. Les pourboires anonymes restent anonymes. Les remboursements n'annulent pas les alertes ni les récompenses.

Event Flow →
Détails des événements et de la livraison

Utilisez Event Type pour purchase, gift, giftcontribution ou giftfunded. Donation correspond à hasDonation. Un financement participatif terminé est une étape marquante, pas un nouveau paiement. Les modifications manuelles des tableaux/ventes ne déclenchent jamais de récompenses d'achat.

Commencez par un seul circuit sonore par événement. Les annonces sont à activer. Shopify et eBay omettent l'identité de l'acheteur ; imprimez plutôt les détails du produit. Le retour de livraison ne prouve ni la visibilité dans OBS, ni l'impression papier, ni l'exécution de la commande. Retour des commandes.
