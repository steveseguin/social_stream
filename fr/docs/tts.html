Vue d’ensemble

SSN peut lire le texte capturé depuis toute source prise en charge ; la plateforme de chat n’a pas besoin de sa propre fonction de synthèse vocale. Votre dock ou incrustation avec synthèse vocale lit les messages reçus selon ses filtres et paramètres vocaux. Commencez par le guide de configuration rapide; cette page couvre les options de voix et les réglages avancés. Comparez les fournisseurs, écoutez des exemples et consultez les paramètres.

Démarrage rapide : Utilisez dock.html?session=YOUR_SESSION&speech=en-US. La synthèse vocale système est utilisée par défaut. Pour un fournisseur gratuit dans OBS, ajoutez aussi &ttsprovider=kokoro. Gardez cette page ouverte et connectée ; une seule instance doit parler.

Où la synthèse vocale est-elle utilisée ?

  • Social Stream Ninja : Lit les messages des spectateurs dans plusieurs interfaces
  • CAPTION.Ninja : Propose sous-titrage, transcription et traduction avec synthèse vocale
  • Les deux services proposent des options de synthèse vocale gratuites et premium
La synthèse vocale système ne représente pas toutes les options gratuites :
  • Les voix système dépendent du navigateur et du système d’exploitation. OBS peut n’exposer aucune voix utilisable, même si Chrome/Edge fonctionne.
  • Une voix indisponible est différente d’une voix diffusée hors de la capture audio d’OBS. Le routage audio ne corrige pas l’absence de prise en charge vocale.
  • Les fournisseurs gratuits comme Kokoro, Piper, Kitten et eSpeak génèrent plutôt du son dans la page. La synthèse vocale dans OBS ne nécessite pas de paiement.
  • Vérifiez d’abord la disponibilité de la voix, puis la capture audio.

Limites des navigateurs :
  • Les navigateurs ne prennent pas tous en charge la synthèse vocale de la même façon ; certaines versions de Firefox ont peu de voix
  • Chrome propose des options de synthèse vocale Google
  • Edge prend en charge les voix Microsoft TTS et les packs de langues Windows
  • Safari exige une interaction utilisateur pour démarrer le son
  • Vérifiez voix disponibles pour votre navigateur

Méthodes de capture audio de la synthèse vocale Windows pour OBS

Son de page : fournisseurs locaux gratuits et cloud

Les fournisseurs locaux dans le navigateur et les fournisseurs audio cloud de SSN diffusent le son généré dans la page :

  • Activez simplement « Contrôler l’audio via OBS » dans la source Navigateur
  • Aucun câble audio virtuel nécessaire
  • Fonctionne avec l’application SSN et les sources Navigateur OBS

Méthodes de capture de la synthèse vocale système

Important : Vérifiez d’abord que la synthèse système génère de la parole. Le navigateur intégré d’OBS peut n’exposer aucune voix système utilisable. S’il ne génère aucune voix, modifier le routage audio ne résoudra rien. Choisissez un autre fournisseur ou générez la voix dans un navigateur compatible et capturez son audio.

Pour la synthèse vocale système en particulier :

  • Ne supposez pas qu’OBS expose les mêmes voix que Chrome ou Edge
  • Prise en charge variable selon le navigateur ; Firefox peut manquer de certaines voix
  • Chrome propose des options Google et Edge des options Microsoft
  • Si la voix est diffusée hors de la source Navigateur de scène, capturez cette sortie séparément

Téléchargements pour le routage : VB-Audio Virtual Cable | Voicemeeter | Audio Router (ancien)

Essayez d’abord de capturer le navigateur qui parle avec la capture audio d’application ou de bureau d’OBS, lorsque c’est pris en charge. Les méthodes par câble virtuel ci-dessous sont des alternatives facultatives ; elles n’ajoutent pas de prise en charge vocale à OBS.

Méthode 1 : sortie audio par défaut avec un câble virtuel

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Méthode 2 : routage par application sous Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Méthode 3 : routage par application sous Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Méthode 4 : logiciel Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Méthode 5 : Voicemeeter, avancé

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Tester votre configuration

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Autres possibilités : Utilisez un fournisseur gratuit intégré comme Kokoro, Piper, Kitten ou eSpeak, un fournisseur cloud ou un serveur vocal auto-hébergé.

Installer des packs de langues supplémentaires

Windows 11

  1. Ouvrez Démarrer > Paramètres > Heure et langue > Voix
  2. Sous Gérer les voix, cliquez sur Ajouter des voix
  3. Sélectionnez les langues souhaitées et cliquez sur Ajouter
  4. Redémarrez les navigateurs pour actualiser les voix disponibles

Windows 10

Suivez les instructions du guide officiel Microsoft pour installer les packs de langues.

Conseil : Certaines voix tierces peuvent ne pas apparaître dans les navigateurs en raison de problèmes de compatibilité. Firefox affiche souvent davantage de voix système que les navigateurs Chromium.

Paramètres d’URL de configuration de la synthèse vocale

Paramètres de base

Paramètre Description Exemple

Paramètre Description

Configuration des fournisseurs de synthèse vocale

Synthèse vocale Kokoro, gratuite et intégrée

  • Activer avec ?ttsprovider=kokoro
  • Fonctionne dans le navigateur via WebGPU/WASM ; aucun serveur requis
  • Fonctionne directement avec une source Navigateur OBS
  • Sélection de voix : &voicekokoro=af_bella
  • Contrôle de vitesse : &kokorospeed=1.2
  • Choisissez une voix pour la langue : &voicekokoro=ef_dora pour l’espagnol ou &voicekokoro=pf_dora pour le portugais brésilien. Modifier &speech= seul ne change pas la voix sélectionnée. Les identifiants de voix anglaises existants fonctionnent toujours.

Synthèse vocale Piper, gratuite et intégrée

  • Activer avec ?ttsprovider=piper
  • Synthèse neuronale rapide et légère pour le CPU, exécutée dans le navigateur
  • Sélection de voix : &pipervoice=en_US-hfc_female-medium
  • Voix portugaises : &pipervoice=pt_BR-faber-medium ou &pipervoice=pt_BR-edresson-low
  • Voix espagnoles : &pipervoice=es_ES-davefx-medium ou &pipervoice=es_MX-ald-medium
  • Contrôle de vitesse : &piperspeed=1.0

Synthèse vocale Kitten, gratuite et intégrée

  • Activer avec ?ttsprovider=kitten
  • Synthèse vocale ONNX légère, exécutée dans le navigateur
  • Sélection de voix : &kittenvoice=expr-voice-4-f

eSpeak-NG, gratuit et intégré

  • Activer avec ?ttsprovider=espeak
  • Synthèse vocale open source classique, compatible avec tout matériel
  • Sélection de voix : &espeakvoice=en
  • Exemple portugais : &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Exemple espagnol : &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Contrôle de vitesse : &espeakspeed=175

Exemples de synthèse vocale en portugais et espagnol

  • Portugais, meilleure qualité locale gratuite testée dans SSN : ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Portugais, solution de repli la plus rapide testée dans SSN : ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Espagnol, meilleure qualité locale gratuite testée dans SSN : ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Espagnol, solution de repli la plus rapide testée dans SSN : ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Pour les voix cloud, utilisez une voix/langue de fournisseur compatible avec la langue cible, par exemple Google Cloud, ElevenLabs, Speechify, Gemini ou un serveur local compatible OpenAI.

Synthèse vocale OpenAI / serveur local

  • Activer avec ?ttsprovider=openai
  • Utilisez ?ttsprovider=customtts ou ?ttsprovider=localtts pour un point d’accès auto-hébergé
  • Utilise par défaut l’API OpenAI ou tout serveur local compatible
  • Point d’accès personnalisé : &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Important : localhost et 127.0.0.1 désignent l’ordinateur qui lit la page de synthèse vocale. Si OBS se trouve sur un autre ordinateur que le serveur vocal, utilisez l’adresse IP locale du serveur.
  • Aucune clé API nécessaire pour les serveurs locaux
  • Si le serveur local rencontre des problèmes CORS ou de réseau local dans Chrome/OBS, exécutez npm run local-tts-bridge sur l’ordinateur OBS et configurez SSN pour utiliser http://127.0.0.1:8124/v1/audio/speech
  • SSN envoie { model, input, voice, response_format, speed } et prend en charge le son binaire, les URL audio en JSON et le son en base64 JSON
  • La lecture des points d’accès personnalisés/locaux utilise actuellement une mise en mémoire tampon ; SSN ne lit pas encore progressivement les fragments audio reçus en streaming
  • Voix : &voiceopenai=af_bella, vitesse : &openaispeed=1.0. Utilisez un nom de voix pris en charge par votre serveur ; les voix Kokoro ressemblent à af_bella, tandis que les voix de type openedai-speech/OpenAI peuvent ressembler à nova ou echo.
  • Consultez : Guide de synthèse vocale IA locale pour configurer un serveur auto-hébergé

Google Cloud TTS

  • Activer avec ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Voix de qualité professionnelle
  • Sélection de voix : &voicegoogle=en-GB-Standard-A
  • Langue : &googlelang=en-US

Synthèse vocale Gemini

  • Activer avec ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Modèle : &geminimodel=gemini-2.5-flash-preview-tts
  • Voix : &voicegemini=Kore, langue : &geminilang=th-TH
  • Instructions de style : &geministyle=Read aloud in a warm tone.

Synthèse vocale ElevenLabs

  • Activer avec ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • Identifiant de voix : &voice11=YOUR_VOICE_ID
  • Modèle : &elevenlabsmodel=eleven_multilingual_v2
  • Paramètres réglables : stabilité, similarité, style

Synthèse vocale Fish Audio

Choisissez Fish Audio et saisissez votre clé API, avec un identifiant de voix facultatif. Le modèle par défaut est s2.1-pro-free. Configuration, options de modèles et limites d’accès du navigateur.

Synthèse vocale Speechify

  • Activer avec ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Voix : &voicespeechify=henry
  • Modèle : &speechifymodel=simba-3.0 (par défaut), ou &speechifymodel=simba-3.2 pour l’anglais.
  • Vitesse de parole : &speechifyspeed=1.2 (plage de 0.5 à 3.0 ; valeur normale : 1.0).
  • Guide de configuration, voix, vitesse et volume Speechify

Dépannage

Problèmes courants

  • Aucun son diffusé : Vérifiez que la synthèse vocale est activée, que sa page est ouverte et que la source Navigateur n’est pas muette. Dans un navigateur ordinaire, cliquez une fois sur la page.
  • Les voix n’apparaissent pas : Redémarrez le navigateur après l’installation des packs de langues
  • OBS ne capture pas : En l’absence de voix, vérifiez d’abord la disponibilité de la voix/du fournisseur. Si la voix est bien produite, vérifiez Contrôler l’audio via OBS, le mode muet du mixeur et les pistes de sortie, ou capturez le navigateur externe qui parle
  • Le point d’accès local fonctionne dans le test de l’application, mais pas dans OBS : OBS est un navigateur distinct. Vérifiez le point d’accès depuis l’ordinateur OBS, notamment si vous utilisez 127.0.0.1.
  • Seule la première lettre ou les premiers mots sont lus : supprimez ttsquick de l’URL OBS s’il est présent.
  • Problèmes Safari : Safari limite la synthèse vocale automatique
  • Le service premium ne fonctionne pas : Vérifiez la clé API et assurez-vous que le fournisseur est correctement indiqué

Bonnes pratiques

  • Utilisez un fournisseur générant du son de page pour simplifier la configuration OBS ; des fournisseurs locaux gratuits sont disponibles
  • Testez votre configuration avec des phrases simples avant le direct
  • Tenez compte des risques du contenu utilisateur lu à voix haute
  • Prévoyez un interrupteur pour désactiver rapidement la synthèse vocale si nécessaire
