Guide des nouveaux participants au chat

Signalez les nouveaux participants par une mise en évidence, un badge feuille ou un signal sonore facultatif.

Rôle de cette fonctionnalité

La détection des nouveaux participants ajoute firsttime=true au premier message de chat enregistré d'un spectateur pour cette source. Le Dock peut utiliser cet indicateur pour la coloration de fond, un bip réservé aux nouveaux participants et le badge feuille facultatif.

Configuration requise

  1. Ouvrez la fenêtre Social Stream Ninja.
  2. Gardez Désactiver la base de données locale des messages à l’état désactivé.
  3. Activez Détection des nouveaux participants au chat.
  4. Laissez votre Dock ou incrustation ouvert avec le même identifiant de session.
Important : La base de données locale est nécessaire. Si elle est désactivée, Social Stream Ninja ne peut pas déterminer si quelqu'un est nouveau.

Options d'affichage

  • Coloration de fond : activée par défaut dans le Dock. Gardez Aucune coloration de fond pour les nouveaux participants désactivé si vous souhaitez la mise en évidence.
  • Badge feuille : activez Marquer les nouveaux participants avec un badge personnalisé pour ajouter un petit badge feuille devant les badges du participant.
  • Bip du Dock pour les nouveaux participants : activez cette option si vous souhaitez que le bip du Dock se déclenche uniquement pour les nouveaux participants.
  • Bip pour les nouveaux participants ou ceux qui reviennent : activez cette option si vous souhaitez aussi un son pour les spectateurs qui reviennent après au moins 8 heures de silence.

Utiliser l'indicateur dans des incrustations personnalisées

Les incrustations personnalisées peuvent rechercher data.firsttime === true. Si l'option de badge feuille est activée, le badge est inclus dans chatbadges avant que le message n'atteigne les incrustations.

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

Si cela ne s'affiche pas

  1. Vérifiez que Désactiver la base de données locale des messages est désactivé.
  2. Vérifiez que Détection des nouveaux participants au chat est activé.
  3. Vérifiez que Aucune coloration de fond pour les nouveaux participants est désactivé si vous souhaitez une mise en évidence.
  4. Vérifiez que Marquer les nouveaux participants avec un badge personnalisé est activé si vous souhaitez le badge feuille.
  5. Testez avec une combinaison nom d'utilisateur/source qui n'est pas déjà enregistrée dans la base de données locale.
