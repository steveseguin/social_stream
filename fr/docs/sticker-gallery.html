Configuration de l'hôte

Vous choisissez ce qui
apparaît à l’écran.

Ces récompenses utilisent le solde de fidélité propre à SSN, pas les points de chaîne natifs de Twitch ou Kick. Activez-les uniquement si vous souhaitez proposer cette interaction.

Limites par défaut : 6 secondes à l’écran, 60 secondes par spectateur, 20 secondes par sticker et un intervalle de 3 secondes. Les demandes pendant un délai d’attente sont refusées sans prélèvement de points.

  1. Ouvrir Système de points → Récompenses de stickers (Points System → Sticker rewards) dans les contrôles SSN. Activez le système de points et les récompenses de stickers.
  2. Choisissez un ou plusieurs packs et leurs prix. Réglez les délais et la durée pour votre émission.
  3. Ajoutez le lien généré Incrustation de stickers comme source Navigateur OBS. Gardez-la active tant que vous acceptez les échanges de points.
  4. Vous pouvez aussi ajouter &stickers à l’URL de Multi Alerts ou du flux d’événements. Utilisez un seul affichage de stickers pour éviter de montrer la récompense deux fois.
  5. Dites aux spectateurs d’utiliser !stickers pour afficher le menu activé et !sticker rocket pour échanger leurs points. Les réponses dans le chat source sont facultatives et nécessitent une connexion prenant en charge le renvoi de messages.

La connexion des stickers utilise le pont iframe SSN standard, même si votre chat utilise le mode serveur. Un déploiement exclusivement local doit pouvoir accéder à ce pont.

Exprimez votre personnalité

Votre mascotte.
Votre GIF préféré.

Ajoutez jusqu’à 12 récompenses personnalisées depuis le même panneau de paramètres. Choisissez un nom, un code court, un prix fixe et une URL HTTPS directe d’image. Les spectateurs choisissent dans votre menu approuvé ; ils ne peuvent pas soumettre d’URL d’image arbitraires.

Utiliser une réaction GIPHY

Copiez un lien direct vers un GIF ou WebP plutôt que l’adresse de la page GIPHY, puis ajoutez-le comme sticker personnalisé. L’image est récupérée depuis son hébergeur lors de l’utilisation ; celui-ci doit autoriser le chargement de l’image.

Un code personnalisé hype devient !sticker custom-hype. Les images statiques PNG, JPEG et WebP fonctionnent aussi. Utilisez des créations que vous êtes autorisé à afficher.

Pour une présentation calme, ajoutez &motion=off pour arrêter le mouvement intégré des stickers. Les GIF animés continuent de bouger ; choisissez donc des images fixes si vous ne voulez aucune animation. Les options facultatives &size=400 et &hidecaption permettent de régler le lecteur.
