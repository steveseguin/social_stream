Sources Discord StreamKit et TikFinity

Utilisez un lien d'incrustation tiers comme source de chat en lecture seule dans Social Stream Ninja.

Comprendre les deux liens

Ces configurations utilisent deux liens différents :

  • Lien d'entrée : l'URL Discord StreamKit ou TikFinity que vous collez dans Social Stream Ninja. Social Stream y lit les messages.
  • Lien de sortie : l'URL de votre Dock ou incrustation Social Stream. Ouvrez le Dock pour tester les messages, puis ajoutez une URL d'incrustation à OBS.

Si vous souhaitez uniquement afficher le design d'origine de Discord ou TikFinity à l'écran, collez son lien directement dans une source navigateur OBS. Utilisez-le comme source Social Stream pour obtenir un chat unifié, la synthèse vocale, le filtrage, la mise en avant des messages ou d'autres fonctionnalités Social Stream.

Quelle option choisir ?

Discord StreamKit

Lit les nouveaux messages texte d'un salon de serveur Discord via le widget Chat officiel de Discord.

  • Nécessite que l'application de bureau Discord reste ouverte.
  • Ne nécessite pas l'installation d'un bot sur le serveur.
  • Lecture seule : Social Stream ne peut pas répondre à Discord via StreamKit.

Dock OBS TikFinity

Utilise TikFinity comme lecteur de repli pour le chat et les événements TikTok LIVE.

  • Nécessite que TikFinity reste ouvert et connecté.
  • Utile lorsque les modes TikTok directs manquent des messages ou les perdent.
  • Lecture seule : utilisez un mode TikTok direct si vous avez besoin de répondre.
Évitez les doublons : ne capturez pas simultanément le même chat avec une source directe et l'une de ces sources de repli.
Discord

Configurer Discord StreamKit

  1. Ouvrez : Incrustation Discord StreamKit.
  2. Choisir Installer pour OBS (Install for OBS) et autorisez StreamKit lorsque Discord le demande.
  3. Sélectionnez le widget Chat , puis choisissez le serveur et le salon textuel à capturer.
  4. Copiez le lien d'installation du widget Chat. Il doit commencer par https://streamkit.discord.com/overlay/chat/.
  5. Dans l'application de bureau Social Stream, ouvrez Sources et paramètres -> Discord (Sources and Settings -> Discord).
  6. Choisir Utiliser une URL Discord StreamKit, collez le lien et ajoutez la source.
  7. Gardez l'application de bureau Discord ouverte pendant la capture.

Avec l'extension de navigateur Social Stream, activez Discord dans les services de chat facultatifs et ouvrez le lien StreamKit Chat généré dans un onglet du navigateur.

  • Social Stream ignore les messages déjà visibles à la première ouverture de la page. Envoyez un nouveau message de test une fois la source prête.
  • La capture inclut les nouveaux textes, les noms, la mise en forme de base, les émojis et la couleur du nom affichée.
  • Elle ne capture pas les appels Discord ni l'historique des anciens messages, et ne fournit pas systématiquement tous les avatars, pièces jointes, réponses et détails des rôles.
Solution de repli TikTok

Configurer un Dock OBS TikFinity

  1. Ouvrez TikFinity et connectez-le au compte TikTok LIVE.
  2. Accédez à Incrustations -> Docks OBS (Overlays -> OBS Docks).
  3. Utilisez le bouton d'engrenage pour choisir les événements que le Dock doit afficher, y compris le chat.
  4. Copiez l'URL de Dock 1 ou Dock 2.
  5. Dans l'application de bureau Social Stream, choisissez Autres sites de chat.
  6. Collez l'URL du Dock TikFinity et activez la nouvelle source.
  7. Gardez TikFinity ouvert et connecté pendant votre direct.
  • La source porte le nom TikFinity dans la configuration, mais ses messages utilisent le type de source habituel tiktok dans Social Stream.
  • Il s'agit d'un lecteur de repli, pas d'un moyen d'envoyer des réponses TikTok.
  • Les utilisateurs de l'extension de navigateur peuvent également ouvrir une URL prise en charge du widget Activity Feed de TikFinity contenant /widget/vite/src/activity-feed/.

Suivez le Guide de configuration TikFinity avec captures d'écran pour le nom d'utilisateur, les paramètres du Dock OBS et les étapes SSApp. Pour les modes TikTok directs et les options de réponse, consultez le Guide TikTok.

Valider le fonctionnement complet

  1. Ouvrez le Dock Social Stream avec votre identifiant de session.
  2. Envoyez un nouveau message de test dans le salon Discord sélectionné ou le chat TikTok LIVE.
  3. Vérifiez qu'il apparaît une seule fois dans le Dock Social Stream avec le bon nom et le bon texte.
  4. Ajoutez l'URL de votre incrustation Social Stream préférée à une source navigateur OBS avec le même identifiant de session.
  5. Envoyez un autre message et vérifiez qu'il apparaît une seule fois dans le Dock et dans OBS.
  6. Laissez la source fonctionner plusieurs minutes et vérifiez que les messages suivants continuent d'arriver.

Voir Démarrage rapide OBS si vous avez besoin des étapes relatives au Dock et à la source navigateur.

Si les messages n'apparaissent pas

  • Testez avec un nouveau message. Les messages existants ne sont volontairement pas importés.
  • Vérifiez que Discord ou TikFinity est toujours ouvert, connecté au compte et connecté au service.
  • Vérifiez que le lien copié correspond au widget Chat ou au Dock OBS, pas à sa page de configuration.
  • Rechargez ou recréez la source Social Stream après avoir changé le serveur, le salon, le Dock ou les événements sélectionnés.
  • Vérifiez le Dock Social Stream avant de dépanner OBS. Si le Dock est vide, le problème ne vient pas encore d'OBS.
  • Traitez les liens de sources copiés comme des informations privées de configuration. Ne les publiez pas et ne les exposez pas lors d'un partage d'écran.
