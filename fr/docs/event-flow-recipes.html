À quoi sert Event Flow

Lancer un flux personnalisé depuis une touche Stream Deck ou un appel API HTTP/WebSocket/P2P.

Event Flow est l’éditeur avancé d’automatisation. Utilisez-le lorsque les interrupteurs du menu ne suffisent pas : filtrer le chat, lancer des médias, relayer des messages, appeler des webhooks ou contrôler OBS.

Avant toute recette

  1. Utilisez une plateforme de test et une session Social Stream.
  2. Ouvrez le Dock et confirmez que le chat arrive.
  3. Ouvrir actions.html?session=YOUR_SESSION si la recette joue de l’audio, un média ou contrôle OBS.
  4. Testez avec un message fictif ou un déclencheur sans risque avant le direct.
  5. Exportez un flux fonctionnel avant une modification importante.

Solutions courantes

  • Rien ne se passe : confirmez d’abord que l’événement source arrive dans le Dock.
  • L’audio ou le média ne se lance pas : gardez actions.html ouvert avec la même session, puis vérifiez le guide d’hébergement multimédia Event Flow.
  • L’action OBS échoue : vérifiez OBS WebSocket v5, le port 4455, le mot de passe et les permissions.
  • Le flux se déclenche trop souvent : ajoutez un filtre plus strict de plateforme, événement, mot-clé ou utilisateur.
