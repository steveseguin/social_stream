# Original SSN sticker artwork

## Studio Symbols

`studio.svg`, `maker.svg`, and `support.svg` are original hand-authored vector artwork for music, making, and appreciation. They use local SVG paths only, with transparent backgrounds and no scripts, fonts, external references, or downloads. These simpler symbols complement the three illustrated packs below. All six packs offer a static version and two movement options; existing pack IDs and viewer commands are preserved.

The visual polish pass attempted additional raster generation, but the image service rejected its expired authentication. No generated-image provenance is claimed for these vector files.

Three original illustrations generated for Social Stream Ninja's inspiration page and opt-in loyalty rewards. Each is reused for static and CSS-animated variations; no extra image download is needed for a motion variant.

Files: `rocket.webp`, `cat.webp`, `goose.webp` (1254 × 1254, transparent WebP). Generated PNGs were converted to WebP at quality 0.88 with alpha retained. Total packaged artwork is about 710 KiB. Browser code lives under `shared/stickers/`.
