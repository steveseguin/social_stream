Erste Schritte (Browser-Erweiterung)

1. Installation

Bevor du Social Stream Ninja nutzen kannst, musst du es installieren. Es gibt mehrere Möglichkeiten, die Browser-Erweiterung zu installieren:

  • Manuelle Installation (empfohlen): Für die aktuellste Version installiere sie manuell im Entwicklermodus.
  • Chrome Web Store: Installiere über den Chrome Web Store für die einfachste Einrichtung.

Eine ausführliche Installationsanleitung findest du auf der Downloadseite.

2. Grundeinrichtung

Führe nach der Installation diese Schritte aus, um Social Stream Ninja zu nutzen:

  1. Öffne den Chat deiner Streaming-Plattform in einem Browser (oder nutze den Popout-Chat, falls verfügbar)
  2. Klicke in der Symbolleiste deines Browsers auf das Erweiterungssymbol von Social Stream Ninja
  3. Klicke zum Einschalten auf „Enable Extension“ (das Symbol sollte grün werden)
  4. Öffne den „Dashboard Link“ im Erweiterungs-Popup
  5. Öffne den „Overlay Link“ in OBS als Browser-Quelle

Hinweis: Für eine optimale Nutzung der Browser-Erweiterung lasse Chatfenster sichtbar (nicht minimiert).

3. Verbindung mit verschiedenen Plattformen

Social Stream Ninja funktioniert mit über 100 Plattformen. So verbindest du die beliebtesten:

YouTube

  • Öffne den YouTube-Livechat
  • Klicke oben rechts auf „Pop out chat“
  • Stelle sicher, dass die Social-Stream-Ninja-Erweiterung aktiviert ist (grünes Symbol)

Twitch

  • Öffne den Twitch-Chat für deinen Kanal
  • Klicke auf das Zahnradsymbol und wähle „Pop out chat“
  • Stelle sicher, dass die Social-Stream-Ninja-Erweiterung aktiviert ist (grünes Symbol)

Facebook

  • Öffne deine Facebook-Liveübertragung (als Zuschauer oder Sender)
  • Stelle sicher, dass du per WLAN oder Ethernet verbunden bist (nicht über mobile Daten)
  • Stelle sicher, dass die Social-Stream-Ninja-Erweiterung aktiviert ist (grünes Symbol)

Discord, Slack, WhatsApp usw.

  • Aktiviere diese Plattformen zuerst in den Erweiterungseinstellungen (Schalter)
  • Öffne die Webversionen dieser Plattformen in deinem Browser
  • Stelle sicher, dass die Social-Stream-Ninja-Erweiterung aktiviert ist (grünes Symbol)

Anpassung (Browser-Erweiterung)

URL-Parameter

Du kannst Dashboard und Overlay anpassen, indem du Parameter zu ihrer URL hinzufügst. Einige Beispiele:

Dashboard-Parameter:

&darkmode – Aktiviert den Dunkelmodus für das Dashboard
&scale=2 – Verdoppelt Größe/Auflösung aller Elemente
&hidesource – Blendet Plattform-Symbole aus (YouTube, Twitch usw.)
&compact – Entfernt den Abstand zwischen Name und Nachricht
&inline – Zeigt die Nachricht neben dem Namen mit normalen Abständen
&autoshow – Hebt Nachrichten automatisch hervor, sobald sie erscheinen (etwa 2 pro 3 Sekunden)

Overlay-Parameter:

&showtime=20000 – Blendet ausgewählte Nachrichten nach 20 Sekunden automatisch aus
&showsource – Zeigt die Plattform-Symbole neben Benutzernamen
&fade – Lässt hervorgehobene Nachrichten sanft einblenden
&swipe – Lässt hervorgehobene Nachrichten von links hereingleiten
¢er – Zentriert hervorgehobene Nachrichten auf dem Bildschirm

Für eine einfachere Verwaltung der URLs probiere unseren URL-Parameter-Editor.

CSS-Anpassung

Es gibt mehrere Möglichkeiten, das Aussehen mit CSS anzupassen:

Methode 1: CSS der OBS-Browser-Quelle

In OBS kannst du der Browser-Quelle eigenes CSS hinzufügen:

  1. Füge dein Overlay als Browser-Quelle in OBS hinzu
  2. Aktiviere die Option „Custom CSS“
  3. Gib dein eigenes CSS in das Textfeld ein
body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }

:root {
    --comment-color: #090;
    --comment-bg-color: #DDD;
    --comment-border-radius: 10px;
    --comment-font-size: 30px;
    --author-border-radius: 10px;
    --author-bg-color: #FF0000;
    --author-avatar-border-color: #FF0000;
    --author-font-size: 32px;
    --author-color: blue;
    --font-family: "Arial", sans-serif;
}

.hl-name {
    padding: 2px 10px !important;
}

Methode 2: Einstellungen im Erweiterungsmenü

Füge CSS direkt über das Erweiterungsmenü hinzu:

  1. Klicke auf das Erweiterungssymbol von Social Stream Ninja
  2. Suche den Einstellungsbereich für CSS/JavaScript
  3. Gib dein eigenes CSS oder JavaScript ein
  4. Das CSS wird als Base64-kodierte Daten an die URL angehängt

Methode 3: Eigene Vorlagen verwenden

Wähle aus vorgefertigten Vorlagen mit integriertem CSS:

  • Entdecke unsere Vorlagengalerie
  • Wähle eine Vorlage, die zum Stil deines Streams passt
  • Ersetze YOURSESSIONID in der Vorlagen-URL durch deine Sitzungs-ID
  • Füge die Vorlagen-URL als Browser-Quelle in OBS hinzu

Beispiel: https://socialstream.ninja/themes/pretty.html?session=YOURSESSIONID

Erweiterte Funktionen (Browser-Erweiterung)

Sprachausgabe

Social Stream Ninja kann Chatnachrichten mithilfe von Text-to-Speech vorlesen:

TTS einrichten:

  1. Hinzufügen &speech=en-US zu deiner featured.html- oder dock.html-URL
  2. Für andere Sprachen verwende einen Anbieter und eine Stimme, die diese Sprache unterstützen. Für Portugiesisch kannst du beispielsweise Piper verwenden &pipervoice=pt_BR-faber-medium oder eSpeak &espeakvoice=pt-br, während für Spanisch Piper verwendet werden kann &pipervoice=es_ES-davefx-medium oder eSpeak &espeakvoice=es.
  3. Passe die Stimme mit Parametern an, etwa &pitch=1&volume=1&rate=1

Kostenlose lokale TTS-Optionen (ohne API-Schlüssel):

  • Kokoro TTS: Integrierte Browser-KI, hervorragende Qualität — &ttsprovider=kokoro
  • Piper TTS: Schnelle, schlanke neuronale TTS — &ttsprovider=piper
  • eSpeak-NG: Ressourcenschonende Sprachausweichlösung, auch für Portugiesisch &espeakvoice=pt-br und Spanisch &espeakvoice=es
  • Kitten TTS: Geringster Ressourcenbedarf, nur CPU — &ttsprovider=kitten
  • Selbst gehosteter Server: Betreibe Kokoro-FastAPI oder openedai-speech lokal über Docker — &ttsprovider=openai&openaiendpoint=http://localhost:8880/v1/audio/speech

Premium-Cloud-TTS-Optionen:

  • Google Cloud TTS: Stimmen in professioneller Qualität (Google-API-Schlüssel erforderlich)
  • ElevenLabs: Ultrarealistische Stimmen mit Training eigener Stimmen
  • Speechify: Natürlich klingende Premium-Stimmen

Möchtest du alles lokal und privat halten? Siehe Leitfaden für lokale KI-Sprachausgabe für die vollständige Einrichtungsanleitung einschließlich selbst gehosteter Server und Audioerfassung in OBS.

KI-Co-Hosts, Chatbots und Browser-Begleiter

Social Stream Ninja kann KI auf verschiedene Arten nutzen. Wähle zuerst den Arbeitsablauf und dann einen Anbieter.

  • Sprach-Co-Host: sprich per Mikrofon, während Fragen aus dem Livechat in dieselbe Co-Host-Sitzung gelangen.
  • ChatGPT-Browser-Begleiter: erfasse Chat oder leite ihn experimentell an einen geöffneten chatgpt.com Tab ohne API-Schlüssel.
  • Haupt-Chatbot: beantworte ausgewählte Zuschauer in einem Overlay, per TTS oder in unterstützten Chats.
  • Verarbeitungswerkzeuge: Moderation, Übersetzung, Zusammenfassungen, RAG-Wissenssuche und KI-erstellte Overlays.

KI-Einrichtung auswählen

Nachrichten einreihen und anheften

Lege fest, wie Nachrichten in deinem Overlay erscheinen:

Nachrichten einreihen:

  1. Halte STRG (oder Cmd auf dem Mac) gedrückt, während du im Dashboard auf Nachrichten klickst
  2. Klicke auf „Next in Queue“, um sie nacheinander anzuzeigen
  3. Nachrichten erscheinen in deinem Overlay in der Reihenfolge, in der sie eingereiht wurden

Nachrichten anheften:

  1. Halte ALT gedrückt, während du im Dashboard auf eine Nachricht klickst
  2. Die Nachricht bleibt oben im Dashboard angeheftet
  3. Halte zum Lösen ALT gedrückt und klicke erneut auf die angeheftete Nachricht

Stream-Ereignisse erfassen

Erfasse Ereignisse außerhalb des Chats wie neue Follower, Abonnements, Raids und Spenden von deinen Streaming-Plattformen.

So aktivierst du die Funktion:

  1. Klicke auf das Erweiterungssymbol von Social Stream Ninja
  2. Suche „Capture Stream Events“ Schalter in den Einstellungen
  3. Aktiviere die Option, um Benachrichtigungen zu empfangen

Hinweis: Spendenartige Ereignisse (Super Chats, Bits, Trinkgelder) werden unabhängig von diesem Schalter automatisch weitergeleitet. Der Schalter ist hauptsächlich für Follower- und Abonnentenbenachrichtigungen gedacht.

Erfasste Ereignisse nach Plattform:

  • Neue Mitgliedschaften und verschenkte Mitgliedschaften
  • Mitgliedschafts-Upgrades und Meilensteine
  • Super-Chat- und Super-Sticker-Spenden
  • Abonnenten- und Zuschauerzahlen

Twitch

  • Neue Abonnenten, erneuerte und verschenkte Abonnements
  • Follower und Followerzahl
  • Bits/Cheers und eingelöste Kanalpunkte
  • Raids mit Zuschauerzahl

TikTok, Kick und andere

  • Follower und Geschenke (TikTok)
  • Abonnements und Trinkgelder (Kick)
  • Zuschauerzahlen auf den meisten Plattformen

Eine vollständige Liste der Ereignisnutzdaten und Datenfelder findest du in der Ereignisreferenz Dokumentation.

Anleitung für erstmalige Chatter öffnen

Event-Flow-Editor

Der Event-Flow-Editor ist ein leistungsfähiges knotenbasiertes Automatisierungssystem zum Erstellen eigener Abläufe. Er bildet die Ebene für erweiterte Automatisierung, mit der du deine eigene Weiterleitungslogik erstellen kannst.

Was du tun kannst:

  • Chat zwischen Plattformen weiterleiten mit intelligenten Filtern (z. B. Twitch nach Discord spiegeln, aber Befehle blockieren)
  • Eigene Befehle erstellen mit AND/OR/NOT-Logikgattern
  • Overlays und Audio auslösen anhand bestimmter Ereignisse oder Schlüsselwörter
  • OBS steuern Szenen und Quellen automatisch
  • Verlosungen und Gewinnspiele erstellen mit Warteschlangenverwaltung

Erste Schritte:

  1. Öffne den Event-Flow-Editor über das Hauptmenü des Dashboards
  2. Erstelle einen neuen Flow und füge Quellknoten hinzu (z. B. „Twitch Message“)
  3. Verbinde Logikknoten zum Filtern von Nachrichten (Contains Keyword, User Role usw.)
  4. Füge Aktionsknoten für die Antwort hinzu (Send Chat, Play Audio, Display Overlay)
  5. Teste vor dem Livestream mit dem integrierten Simulator

Flow-Actions-Overlay:

Damit Audio, Medien-Overlays und OBS-Aktionen funktionieren, musst du die Flow-Actions-Seite als Browser-Quelle in OBS hinzufügen:

Fehlerbehebung (Browser-Erweiterung)

Lösungen für häufige Probleme mit der Browser-Erweiterung

Chat stoppt im Hintergrund oder bei minimiertem Fenster

Chatnachrichten erscheinen nicht mehr, wenn Browserfenster im Hintergrund oder minimiert sind. Das liegt daran, dass Browser Tabs im Hintergrund drosseln, um Ressourcen zu sparen.

Browser-Drosselung deaktivieren
  • Chrome/Edge/Brave:
    1. Öffnen chrome://flags/#enable-throttle-display-none-and-visibility-hidden-cross-origin-iframes
    2. Setze die Option auf „Disabled“
    3. Deaktiviere außerdem chrome://flags/#calculate-native-win-occlusion
    4. Starte deinen Browser neu
  • Leistungsdrosselung deaktivieren:
    1. Gehe zu chrome://settings/performance
    2. Deaktiviere „Throttle Javascript timers in background“
Alternative Vorgehensweisen
  • Fenster sichtbar lassen: Ordne die Fenster so an, dass sie nicht minimiert sind; schon ein kleiner sichtbarer Bereich kann eine Drosselung verhindern.
  • Virtuelle Desktops verwenden: Erstelle unter Windows mit Win+Tab zwei virtuelle Desktops, einen für die Chatfenster und einen für OBS.
  • Eigenständige App ausprobieren: Die Social-Stream-Ninja-Desktop-App vermeidet viele Probleme durch Browser-Drosselung.

Blaue Leiste erscheint / automatische Antworten funktionieren nicht

Beim Versuch, Bot-Befehle oder automatische Antworten zu verwenden, erscheint eine blaue Debugging-Leiste oder automatische Antworten funktionieren nicht.

Sichtbarkeit des Chatfensters prüfen
  • Stelle bei YouTube oder Twitch sicher, dass das Popout-Chatfenster geöffnet und sichtbar ist
  • Bei manchen Plattformen musst du möglicherweise zusätzlich zum Popout das Hauptfenster geöffnet lassen
Browser-Kompatibilität
  • Automatische Antworten funktionieren am besten mit Chromium-basierten Browsern (Chrome, Edge, Brave)
  • Firefox unterstützt die Erweiterungsfunktionen nur eingeschränkt
