Videostatistiken und Bitrate

Zeige die Bitrate des eingehenden Streams oben rechts im Social-Stream-Ninja-Dock.

Wichtig: SSN liest die Bitrate nicht automatisch aus OBS oder einer Streaming-Plattform. Es fragt die Statistik-API des Videoservers ab, der deinen Stream empfängt.

Wofür es gedacht ist

Dies gibt Hosts oder Produzenten eine kleine Live-Bitratenanzeige im Dock. Das ist nützlich, wenn OBS, ein mobiler Encoder oder ein anderer Sender an deinen eigenen Relay- oder Ingest-Server sendet.

SSN normalisiert außerdem verfügbare Daten zu Latenz, Puffer, Paketverlust, Laufzeit, Codecs und Zuschauern in einem video_stats Metadatenereignis. Die normale Dock-Anzeige zeigt nur die Bitrate.

Kompatibilität

  • SRT Live Server / SLS: JSON /stats Endpunkt mit einem publishers Objekt stehen.
  • Belabox Cloud: seine JSON-Antwort mit Empfänger-/Relay-Statistiken im SRT-Stil ab.
  • NGINX RTMP: XML aus dem NGINX-RTMP-Statusmodul.
  • Node Media Server: seine JSON-Stream-API ab, mit optionaler HTTP-Basic-Authentifizierung.
OBS ist keine Statistikquelle: OBS kann Video an einen kompatiblen Server senden, aber OBS WebSocket und SSN-Browser-Quellen liefern diese Daten nicht.

So verwendest du es

  1. Aktiviere den HTTP-Statistikendpunkt des kompatiblen Servers und prüfe, ob der Computer mit SSN dessen URL öffnen kann.
  2. In SSN Globale Einstellungen, aktiviere Videostatistiken abfragen.
  3. Wähle den Quelltyp und gib die Statistik-URL ein.
  4. Gib für SRT oder Belabox die exakte Publisher-ID ein, etwa publish/live/feed1. SSN verwendet ihn automatisch, wenn die Antwort nur einen Sender enthält.
  5. Gib für NGINX RTMP oder Node Media Server Anwendung und Stream-Schlüssel/-Namen ein, etwa live und feed1.
  6. Füge bei Bedarf die Authentifizierung hinzu. Das SRT-API-Schlüsselfeld wird als vollständiger Authorization Header gesendet. Node Media Server verwendet Benutzername/Passwort als HTTP-Basic-Authentifizierung.
  7. Wähle ein Abfrageintervall von 1 bis 60 Sekunden; der Standard beträgt fünf Sekunden.
  8. Aktiviere in den Dock-Optionen Bitraten-Metadaten anzeigen, falls verfügbar; oben rechts, öffne oder aktualisiere dann den Dock-Link.
  9. Beginne mit dem Senden des Videos. Die Bitrate erscheint nach einer gültigen Online-Antwort.

Wenn nichts erscheint

  • Prüfe, ob beide Videostatistik-Optionen in SSN aktiviert sind.
  • Prüfe, ob der Endpunkt innerhalb von fünf Sekunden antwortet und Quelltyp sowie Stream-Kennungen übereinstimmen.
  • 127.0.0.1 bezeichnet den Computer, auf dem SSN läuft. Verwende die LAN-Adresse des Servers, wenn er auf einem anderen Gerät läuft.
  • Die Anzeige verschwindet, wenn der Stream offline ist, die Bitrate fehlt oder null beträgt oder etwa 130 Sekunden lang keine aktuellen Statistiken eintreffen.

Erweitert: Protokoll, Formate und Einheiten

SSN führt einen HTTP- oder HTTPS- GET im konfigurierten Intervall mit deaktiviertem Cache und einem Zeitlimit von fünf Sekunden aus.

SRT Live Server / SLS und Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate wird in Kbps angegeben; RTT und Empfangspuffer in Millisekunden; Empfangsrate und Bandbreite in Mbps; Laufzeit in Sekunden; Verlust-/Drop-Werte als Paketanzahl oder Bytes.

NGINX RTMP

Die URL muss NGINX-RTMP-Status-XML liefern. SSN gleicht die konfigurierte Anwendung und den Stream ab. Es liest bw_video als Bytes pro Sekunde und teilt durch 1024 für bitrateKbps. Außerdem werden Stream-Laufzeit und optionale Video-/Audiocodec-Metadaten gelesen.

Node Media Server

SSN fragt STATS_URL/APPLICATION/STREAM_NAME. Felder können auf der obersten Ebene oder innerhalb von data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

Bitrate in Kbps, Zuschauer als Anzahl und Dauer in Sekunden.

Normalisiertes SSN-Ereignis

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
FeldEinheit/Typ
bitrateKbpsKbps, ganze Zahl
rttMs / bufferMsMillisekunden
recvRateMbps / bandwidthMbpsMbps
Verlust-/Drop-FelderPaketanzahl oder Bytes
uptimeSeconds / durationSecondsSekunden
onlineBoolescher Wert; false blendet den Dock-Wert aus

Das Dock akzeptiert meta.bitrateKbps, mit meta.bitrate und meta.kbps als Ausweichwerte. Werte unter 1000 werden als gerundete Kbps angezeigt; größere Werte als Mbps mit einer Nachkommastelle. Statistik-URL, Stream-Schlüssel und Zugangsdaten werden nie an Overlays gesendet.
