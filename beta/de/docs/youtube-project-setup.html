YouTube-Projekt einrichten

So erstellst du ein Google-Cloud-Projekt für die eigenständige SSN-Desktop-App, ohne die Sicherheit deines Schlüssels zu schwächen.

Übersicht

Wofür diese Einrichtung gedacht ist

Verwende dies nur, wenn die Desktop-App dein eigenes YouTube-API-Kontingent statt des standardmäßig gemeinsam genutzten Projekts von Social Stream Ninja verwenden soll.

Wichtig: Alle drei folgenden Werte müssen aus dem selben Google-Cloud-Projekt stammen:
  • OAuth-Client-ID
  • OAuth-Client-Secret
  • API-Schlüssel
Verwechsle diese beiden Felder in Google Cloud nicht:
  • Autorisierte JavaScript-Ursprünge dürfen nur den Ursprung enthalten, ohne Pfad.
  • Autorisierte Weiterleitungs-URIs müssen den vollständigen /sources/websocket/youtube.html Pfad enthalten.
Schritt 1

Projekt erstellen

  1. Öffne die Google Cloud Console.
  2. Erstelle ein neues Projekt oder wähle ein eigenes bestehendes aus.
  3. Aktivieren YouTube Data API v3.
  4. Öffne die Einstellungen des OAuth-Zustimmungsbildschirms.
  5. Wenn sich die App im Teststatus befindet, füge dein Google-Konto als Testnutzer hinzu.
Schritt 2

OAuth-Client erstellen

  1. Erstelle Anmeldedaten.
  2. Wähle OAuth-Client-ID.
  3. Verwende den Typ Webanwendung.
  4. Füge die unten gezeigten exakten Ursprünge und Weiterleitungs-URIs hinzu.
Feld Wert
Autorisierte JavaScript-Ursprünge http://localhost:8181
http://localhost:8080
Autorisierte Weiterleitungs-URIs http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
Schritt 3

API-Schlüssel sicher erstellen

  1. Erstelle einen API-Schlüssel im selben Projekt.
  2. Öffne die Einschränkungen dieses Schlüssels.
  3. Unter API-Einschränkungen, beschränke ihn auf YouTube Data API v3 nur.
  4. Verwende für die Desktop-App keine HTTP-Referrer-Einschränkungen.

Regel für die Desktop-App: HTTP-Referrer-Einschränkungen sind für Browserseiten gedacht, nicht für diesen lokalen Desktop-Anmeldeablauf.

Schritt 4

Werte in die Desktop-App einfügen

  1. Öffne die YouTube-Quellseite in der Desktop-App.
  2. Füge folgende Werte ein: OAuth-Client-ID, OAuth-Client-Secret, und API-Schlüssel.
  3. Klicke auf Speichern.
  4. Melde dich bei Bedarf ab.
  5. Klicke auf Mit YouTube anmelden.
  6. Schließe die Google-Anmeldung im externen Browserfenster ab.
Erwartetes Ergebnis: wenn alles übereinstimmt, funktioniert die Google-Anmeldung und die Desktop-App verwendet dein gespeichertes YouTube-Projekt statt des standardmäßig gemeinsam genutzten.
Sicherheit

Anmeldedaten sicher aufbewahren

  • Behandle Client-Secret und API-Schlüssel als vertraulich.
  • Füge sie nicht in Screenshots, Chatprotokolle oder Fehlerberichte ein.
  • Wenn du sie versehentlich offenlegst, ersetze oder lösche sie.
  • Verwende für Experimente ein eigenes Testprojekt.
  • Lösche temporäre Projekte nach Abschluss deiner Tests.
Fehlerbehebung

Häufige Probleme

  • redirect_uri_mismatch: die Weiterleitungs-URI stimmt nicht exakt überein.
  • invalid_client: Client-ID und Client-Secret stimmen nicht überein.
  • quotaExceeded: das YouTube-Kontingent deines API-Schlüssel-Projekts ist aufgebraucht.
  • Kontovalidierung fehlgeschlagen: bei älteren Versionen konnte dies passieren, wenn OAuth und API-Schlüssel aus unterschiedlichen Projekten stammten.
