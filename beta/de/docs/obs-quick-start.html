OBS-Schnellstart

Bringe Chat mit möglichst wenigen Schritten in OBS.

1. Eine Sitzungs-ID wählen

Denke dir eine kurze Sitzungs-ID aus und verwende sie überall. Darüber finden sich Chatquelle, Dock und OBS-Overlay.

YOUR_SESSION_ID

2. Eine Chatquelle starten

  1. Installiere oder öffne Social Stream Ninja.
  2. Öffne die Chatquelle für deine Plattform und lass sie geöffnet.
  3. Sende eine Chatnachricht oder warte auf eine, damit du weißt, dass die Quelle funktioniert.

Unsicher, welchen Quellmodus du verwenden sollst? Siehe die Auswahlhilfe zur Plattformeinrichtung.

3. Das Dock öffnen

Das Dock ist deine Testansicht. Öffne es, bevor du OBS-Einstellungen änderst.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

4. Eine OBS-Browserquelle hinzufügen

Füge in OBS eine Browserquelle hinzu und füge die Overlay-URL ein.

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

Verwende für normale Chat-Overlay-Layouts eine Vorlage aus der Vorlagengalerie.

5. Wenn OBS leer bleibt

Prüfe jeweils einen Punkt in dieser Reihenfolge.

  • Prüfe zuerst, ob das Dock Nachrichten empfängt. Ist das Dock leer, liegt das Problem noch nicht bei OBS.
  • Prüfe, ob die OBS-URL denselben Wert für diesen Parameter verwendet: session.
  • Lade nach Änderungen der URL-Optionen die OBS-Browserquelle neu.
  • Prüfe, ob die Quell-Chatseite oder das Quellfenster der App noch läuft.
