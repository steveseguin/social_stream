Installierte Schriftarten erkennen

Listet Schriftarten auf, die dein Browser verwenden kann, zeigt ein Live-Beispiel und liefert einen URL-Parameter, um die Schriftart auf der gesamten Website anzuwenden.

Eigene Schriftarten installieren

  • Windows: Rechtsklick auf die .ttf- oder .otf-Datei → „Installieren“ oder „Für alle Benutzer installieren“ wählen → Browser neu starten.
  • macOS: Doppelklicke auf die .ttf- oder .otf-Datei → klicke in der Schriftsammlung auf „Schrift installieren“ → starte deinen Browser neu.
  • Linux: Kopiere Schriftdateien nach ~/.local/share/fonts/ → führe aus: fc-cache -fv → starte deinen Browser neu.

Aktualisiere diese Seite nach der Installation, um deine neuen Schriftarten zu sehen. Wenn eine Schriftart nicht erscheint, probiere „Try Local Fonts API“ (nur Chromium-Browser).

Eine bestimmte Schriftart über die URL verwenden

  • Parameter: Anhängen: ?font=<Font%20Family%20Name> zur URL hinzu. Leerzeichen und Symbole müssen URL-kodiert werden.
  • Gilt für CSS-Variable: Deine Website verwendet --font-family; auch diese Seite berücksichtigt sie. Beispiel: ?font=Segoe%20UI.
  • Keine Anführungszeichen nötig: Füge dem Parameter keine Anführungszeichen hinzu; die CSS-Variable benötigt sie nicht.
  • Nur installierte: Der Parameter funktioniert nur für bereits auf deinem System installierte Schriftarten. Er lädt keine Webfonts herunter.

Kompatibilität (Ninja-Apps)

  • VDO.Ninja: Erzeugt ?font= Links funktionieren mit Overlays/Szenen, die die --font-family Variable berücksichtigen.
  • SocialStream.Ninja: Verwende denselben ?font= Parameter, um die Standardschriftart in unterstützten Widgets zu überschreiben.
  • Caption.Ninja: Übernehmen ?font= zu Untertitel-Overlays, die eigene Schriftfamilien unterstützen.

Diese Apps erlauben das Überschreiben von font-family, wenn der ?font= Parameter in ihren URLs oder Einbettungslinks unterstützt wird. Dieses Tool erzeugt korrekt kodierte Werte zur direkten Verwendung.

Fehlerbehebung (Windows)

  • Exakter Familienname: Verwende den Familie Namen der Schriftfamilie (nicht den Dateinamen). Den richtigen Familiennamen findest du unter Einstellungen → Personalisierung → Schriftarten.
  • Passender Installationsbereich: Wenn du eine Schriftart für einen anderen Windows-Nutzer oder nur über ein Administratorkonto installiert hast, sieht deine Browsersitzung sie möglicherweise nicht. Installiere sie bei Bedarf „für alle Benutzer“.
  • Unterstützte Formate: Browser verwenden TrueType/OpenType/WOFF. Alte Type-1-Schriftarten und einige Bitmap-Schriftarten funktionieren nicht.
  • Verfügbare Stärken/Stile: Wenn nur Bold installiert ist, kann normaler Text auf eine Ersatzschrift zurückfallen. Probiere ein fettes Beispiel oder installiere zusätzlich Regular.
  • Datenschutzgrenzen: Browser erlauben ohne Zustimmung keine vollständige Auflistung der Schriftarten. Diese Seite erkennt sie anhand einer umfangreichen bekannten Liste und optional über die Local Fonts API.
  • Local Fonts API: In Chromium mit sicheren Ursprüngen (https/localhost) kann „Try Local Fonts API“ nach deiner Zustimmung die exakt installierten Schriftfamilien auflisten.

Tipps zur manuellen Nutzung

  • Schriftart erzwingen: In deinem CSS: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • Beliebigen Namen testen: Probiere im Suchfeld eine beliebige Schriftfamilie aus; wenn sie gefunden wird, erscheint sie mit einem Beispiel in den Ergebnissen.
  • Kodierung: Erstelle Links wie: ?font=Segoe%20UI (die unten erzeugten Links verwenden die richtige Kodierung).
  • CJK- und andere Schriftsysteme: Das Beispiel enthält lateinische Buchstaben, Ziffern und Symbole. Ersetze es durch Text im gewünschten Schriftsystem, um die Zeichendarstellung zu prüfen.

Hinweis: Diese Seite installiert oder lädt keine Schriftarten herunter; sie erkennt und zeigt nur Familien, die deinem Browser bereits zur Verfügung stehen.
