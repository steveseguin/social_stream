الجلسات وكلمات المرور والمرحّل وأوضاع الخادم

تربط جلسة واحدة متطابقة المصادر ولوحات الإرساء والتراكبات والتنبيهات وصفحات API. يجب أن تتطابق معاملات التوجيه أيضًا.

نموذج الاتصال

  1. يلتقط مصدر دردشة أو حدثًا وينشره في جلسة Social Stream.
  2. تنضم لوحة الإرساء وتراكب Featured وMulti Alerts وEvent Flow والصفحات الأخرى إلى الجلسة نفسها.
  3. إذا ضُبطت كلمة مرور، يجب أن تستخدم كل صفحة منضمة كلمة المرور نفسها.
  4. إذا فُعّل توجيه الخادم، يجب أن تستخدم الصفحات النشطة الروابط المُنشأة حديثًا بمعاملات التوجيه المطابقة.
Source → same session ID + password + routing mode → Dock / overlay / API consumer

معرّف الجلسة وكلمة المرور

افتح الإعدادات والأدوات العامة → خيارات الجلسة (Global settings and tools → Session Options) لعرض معرّف الجلسة الحالي وضبط كلمة مرور اختيارية.

القيمةالقاعدة
معرّف الجلسةاحتفظ به دون تغيير ما لم تنوِ استبدال كل رابط مصدر ولوحة إرساء وتراكب وتكامل يستخدمه.
كلمة المروراختيارية، لكن يجب أن تتطابق في كل مكان بعد ضبطها. انسخ الروابط المُنشأة حديثًا بعد إضافتها أو تغييرها.
الرابط المُنشأتعامل مع الرابط كاملًا كبيانات خاصة عندما يتضمن كلمة مرور أو معاملات حساسة أخرى.

فضّل نسخ الروابط المُنشأة. تتضمن بالفعل الجلسة وكلمة المرور وإصدار الصفحة وخيارات التوجيه المدعومة الحالية. الروابط المعدّلة يدويًا سبب شائع للصفحات الفارغة.

تفعيل الرجوع إلى الخادم للقراءة والرد

استخدم هذا عندما تتصل لوحة الإرساء أو الدردشة الموحدة لكن لا تصل الرسائل، أو عندما تفشل الردود لأن مسار النظير إلى النظير المعتاد محظور أو غير موثوق.

يعمل عنصرا الرجوع معًا كزوج: إرسال رسائل الدردشة إلى خادم API (للمستمعين الخارجيين) ينقل الدردشة الواردة إلى مسار الخادم، بينما ترسل لوحة الإرساء أوامرها إلى الإضافة عبر الخادم يعيد الردود وأوامر لوحة الإرساء.

الطريقة السريعة

  1. افتح رابط لوحة الإرساء المُنشأ أو أعد تحميله.
  2. أرسل رسالة اختبار وهمية من Social Stream Ninja.
  3. إذا ظهر إشعار تفعيل الرجوع إلى الخادم (Enable Server Fallback) ، فحدده وأكّد. يفعّل Social Stream Ninja مساري خادم الدردشة الواردة وأوامر الرد معًا.
  4. انسخ روابط لوحة الإرساء والتراكبات المُنشأة حديثًا. أعد فتح نوافذ المتصفح العادية و استبدل أي روابط محفوظة لمصادر متصفح OBS.

الطريقة اليدوية في تطبيق سطح المكتب

  1. افتح تطبيق سطح المكتب Social Stream. في لوحة المصادر والإعدادات الجانبية اليمنى، وسّع الإعدادات والأدوات العامة.
  2. وسّع آليات العمل - الاتصالات والتكاملات (Mechanics - Connections & Integrations).
  3. فعّل إرسال رسائل الدردشة إلى خادم API (للمستمعين الخارجيين). هذا مسار الدردشة الواردة والقراءة.
  4. فعّل ترسل لوحة الإرساء أوامرها إلى الإضافة عبر الخادم. هذا مسار الرد والتحكم.
  5. انسخ الروابط المُنشأة حديثًا وأعد فتحها. الصفحات القديمة المفتوحة وروابط OBS المحفوظة لا تحدّث نفسها.

لا تفعّل جميع خيارات الخادم. تفعيل التحكم عن بُعد عبر API, تمكين لوحة الإرساء من استخدام خادم API والنشر عبره، وخيار الإيصال الإضافي المؤقت غير مطلوبة للرجوع المعتاد للقراءة والرد. قد ينتج الإيصال الإضافي رسائل مكررة.

الأوضاع الافتراضية وأوضاع المرحّل وخادم API

التحكمما يغيرهمتى تستخدمه
الروابط الافتراضية نقل النظير والجلسة المعتاد في Social Stream، دون إضافة معامل خادم. معظم إعدادات الجهاز الواحد وإعدادات OBS العادية.
تفعيل التحكم عن بُعد في الإضافة عبر API يفعّل التحكم في الإضافة عبر HTTP/WebSocket ومعالجة خطافات الويب الواردة. تطبيقات خارجية أو تحكم Stream Deck/API أو خطافات ويب تبرعات واردة مدعومة.
تمكين لوحة الإرساء من استخدام خادم API والنشر عبره يضيف معامل الصفحة server للتوجيه حيث يكون مدعومًا. يحتاج سير عمل Dock/Featured إلى التحكم عن بُعد عبر خادم API بدلًا من مساره المعتاد.
إرسال رسائل الدردشة إلى خادم API يوجّه الدردشة الملتقطة إلى مسار مستمع خادم API ويضيف server2 إلى الروابط المُنشأة المدعومة. تحتاج لوحة الإرساء إلى الرجوع للخادم للدردشة الواردة، أو يجب أن يستقبل Python أو Node أو مستمع WebSocket خارجي آخر الدردشة.
إرسال الدردشة الموجّهة عبر API بالطريقة العادية أيضًا إيصال إضافي مؤقت عبر المسارين. فقط أثناء انتقال مقصود يجمع بين الأوضاع؛ فقد يكرر الرسائل.
أوامر لوحة الإرساء عبر الخادم يضيف server3 حيث يكون مدعومًا حتى تعود أوامر لوحة الإرساء عبر مسار الخادم. اتصالات النظراء محظورة أو غير موثوقة، وتحتاج أوامر لوحة الإرساء إلى الإضافة إلى الخادم.

حول localserver

تقبل بعض الصفحات localserver وتستخدم نقطة نهاية WebSocket محلية على ws://127.0.0.1:3000. أضف localserverport=PORT لاختيار منفذ آخر بين 1024 و65535. تعود القيم غير الصالحة أو المحذوفة بأمان إلى المنفذ 3000. لاحظ أن عمليات التثبيت الجديدة لتطبيق سطح المكتب Social Stream تشغّل خادمها المحلي على المنفذ 3003 بدلًا منه، وتدرج localserverport=3003 في الروابط التي تنشئها — لذلك إذا كتبت رابطًا يدويًا لتثبيت جديد، فأضف ذلك المعامل بنفسك. أضف هذه المعاملات فقط عندما يكون الخادم المحلي قيد التشغيل فعلًا وتدعمها الصفحة المحددة.

للقطات الشاشة وخطوات إعداد WebSocket المستضاف أو الخادم المحلي المتقدم، راجع وضعا WebSocket المستضاف والخادم المحلي.

معاملات التوجيه خاصة بكل صفحة. server, server2, server3, localserver، و localserverport لا تملك سلوكًا موحدًا في كل تراكب. استخدم الرابط المُنشأ للصفحة المحددة بدلًا من نسخ معاملات أداة أخرى.

بعد تغيير جلسة أو مفتاح توجيه

  1. انسخ رابط لوحة الإرساء أو التراكب المُنشأ حديثًا.
  2. أغلق صفحات المتصفح النشطة التي تستخدم الرابط القديم وأعد فتحها.
  3. استبدال الرابط في مصادر متصفح OBS المحفوظة وتحديث ذاكرتها المؤقتة.
  4. أعد تحميل صفحات المصادر أو تفعيلها إذا تغير معرّف الجلسة أو كلمة المرور.
  5. أرسل رسالة اختبار وهمية واحدة وتأكد من وصولها إلى لوحة الإرساء قبل اختبار التراكب النهائي.

قائمة فحص لوحة إرساء أو تراكب فارغ

  1. قارن قيمة session= كاملة في المصدر ولوحة الإرساء والتراكب.
  2. تحقق مما إذا كان أحد الروابط يفتقر إلى password=.
  3. تحقق مما إذا كان رابط OBS القديم يفتقر إلى معاملات توجيه الخادم الحالية.
  4. أزل معاملات التوجيه المضافة يدويًا وانسخ رابطًا مُنشأ حديثًا إذا كانت الأوضاع غير واضحة.
  5. اختبر لوحة الإرساء أولًا. إذا استقبلت الرسائل، فانتقل إلى تشخيص عوامل تصفية الأحداث وخيارات URL في التراكب.
  6. راجع حل مشكلات OBS و مرجع الأوامر وAPI لفحوص أعمق.
