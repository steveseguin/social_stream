أغراض Event Flow

تشغيل سير عمل مخصص من مفتاح Stream Deck أو استدعاء HTTP/WebSocket/P2P API.

Event Flow هو محرر الأتمتة المتقدم. استخدمه عندما لا تكفي مفاتيح النافذة المنبثقة: لتصفية الدردشة أو تشغيل الوسائط أو تمرير الرسائل أو استدعاء Webhooks أو التحكم في OBS.

قبل أي وصفة

  1. استخدم منصة اختبار واحدة وجلسة Social Stream واحدة.
  2. افتح لوحة الإرساء وتأكد من وصول الدردشة.
  3. افتح actions.html?session=YOUR_SESSION إذا كانت الوصفة تشغّل صوتاً أو وسائط أو تتحكم في OBS.
  4. اختبر برسالة وهمية أو مشغّل آمن قبل البث المباشر.
  5. صدّر تدفقاً يعمل قبل إجراء تعديل كبير.

حلول شائعة

  • لا يحدث شيء: تأكد أولاً من وصول حدث المصدر إلى لوحة الإرساء.
  • لا يُشغّل الصوت أو الوسائط: أبقِ actions.html مفتوحاً بالجلسة نفسها، ثم تحقق من دليل استضافة وسائط Event Flow.
  • يفشل إجراء OBS: تحقق من OBS WebSocket v5 والمنفذ 4455، وكلمة المرور، والصلاحيات.
  • يُشغّل التدفق كثيراً: أضف مرشحاً أكثر تقييداً للمنصة أو الحدث أو الكلمة المفتاحية أو المستخدم.
