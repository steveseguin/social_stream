إعداد مشروع YouTube

كيفية إنشاء مشروع Google Cloud لتطبيق SSN Standalone لسطح المكتب دون إضعاف أمان مفتاحك.

نظرة عامة

الغرض من هذا الإعداد

استخدم هذا فقط إذا كنت تريد أن يستخدم تطبيق سطح المكتب حصة YouTube API الخاصة بك بدلًا من المشروع المشترك الافتراضي لـ Social Stream Ninja.

مهم: يجب أن تأتي القيم الثلاث أدناه من مشروع Google Cloud نفسه:
  • معرّف عميل OAuth (OAuth Client ID)
  • سر عميل OAuth (OAuth Client Secret)
  • مفتاح API
لا تخلط بين هذين الحقلين في Google Cloud:
  • أصول JavaScript المعتمدة (Authorized JavaScript origins) يجب أن تكون الأصل فقط، دون مسار.
  • عناوين URI المعتمدة لإعادة التوجيه (Authorized redirect URIs) يجب أن تتضمن المسار الكامل /sources/websocket/youtube.html .
الخطوة 1

إنشاء المشروع

  1. افتح Google Cloud Console.
  2. أنشئ مشروعًا جديدًا أو اختر مشروعًا موجودًا مخصصًا لهذا الغرض.
  3. تفعيل YouTube Data API v3.
  4. افتح إعدادات شاشة موافقة OAuth.
  5. إذا كان التطبيق في وضع الاختبار، فأضف حساب Google الخاص بك كمستخدم اختبار.
الخطوة 2

إنشاء عميل OAuth

  1. أنشئ بيانات الاعتماد.
  2. اختر معرّف عميل OAuth (OAuth client ID).
  3. استخدم النوع تطبيق ويب (Web application).
  4. أضف الأصول وعناوين URI لإعادة التوجيه الموضحة أدناه كما هي تمامًا.
الحقل القيمة
أصول JavaScript المعتمدة (Authorized JavaScript origins) http://localhost:8181
http://localhost:8080
عناوين URI المعتمدة لإعادة التوجيه (Authorized redirect URIs) http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
الخطوة 3

إنشاء مفتاح API بأمان

  1. أنشئ مفتاح API (API key) في المشروع نفسه.
  2. افتح قيود ذلك المفتاح.
  3. ضمن قيود API (API restrictions)، قيّده بـ YouTube Data API v3 فقط.
  4. لا تستخدم قيود مُحيل HTTP لتطبيق سطح المكتب.

قاعدة تطبيق سطح المكتب: قيود المُحيل HTTP مخصصة لصفحات المتصفح، وليست لمسار المصادقة المحلي هذا في تطبيق سطح المكتب.

الخطوة 4

لصق القيم في تطبيق سطح المكتب

  1. افتح صفحة مصدر YouTube داخل تطبيق سطح المكتب.
  2. الصق معرّف عميل OAuth (OAuth Client ID), سر عميل OAuth (OAuth Client Secret)، و مفتاح API.
  3. انقر على حفظ (Save).
  4. سجّل الخروج عند الحاجة.
  5. انقر على تسجيل الدخول باستخدام YouTube (Sign in with YouTube).
  6. أكمل تسجيل الدخول إلى Google في نافذة المتصفح الخارجي.
النتيجة المتوقعة: إذا تطابق كل شيء، يعمل تسجيل الدخول إلى Google ويستخدم تطبيق سطح المكتب مشروع YouTube المحفوظ لديك بدلًا من المشروع المشترك الافتراضي.
الأمان

الحفاظ على أمان بيانات الاعتماد

  • تعامل مع سر العميل ومفتاح API باعتبارهما معلومات حساسة.
  • لا تلصقها في لقطات الشاشة أو سجلات الدردشة أو تقارير الأخطاء.
  • إذا كشفتها عن طريق الخطأ، فاستبدلها أو احذفها.
  • استخدم مشروع اختبار مخصصًا إذا كنت تجرّب.
  • احذف المشروعات المؤقتة بعد الانتهاء من الاختبار.
استكشاف المشكلات وإصلاحها

مشكلات شائعة

  • redirect_uri_mismatch: عنوان URI لإعادة التوجيه لا يطابق تمامًا.
  • invalid_client: معرّف العميل وسر العميل غير متطابقين.
  • quotaExceeded: نفدت حصة YouTube لمشروع مفتاح API الخاص بك.
  • فشل التحقق من الحساب: في الإصدارات الأقدم، كان هذا قد يحدث عندما تأتي بيانات OAuth ومفتاح API من مشروعين مختلفين.
