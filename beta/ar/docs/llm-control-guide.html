واجهة التحكم المحلية API وMCP

اسمح لأداة ذكاء اصطناعي أو برنامج نصي على الجهاز نفسه بفحص تطبيق سطح المكتب Social Stream Ninja والتحكم فيه.

متى تختار هذه الخدمة1. تنزيل تطبيق سطح المكتب المعتاد2. تفعيل التحكم المحلي بالذكاء الاصطناعي3. ترك MCP يكتشف الإمكاناتعناصر التحكم المحلية المتاحةوصول HTTP مباشر للبرامج النصية المحليةمحلي فقط

متى تختار هذه الخدمة

التطبيق المكتبي→واجهة التحكم المحلية API→عميل MCP

استخدم واجهة التحكم المحلية API عندما يحتاج برنامج على جهاز SSApp إلى عناصر تحكم مصرح بها في التطبيق والمصادر. واستخدم محوّل MCP المضمّن عندما ينبغي لعميل ذكاء اصطناعي متوافق تلقي هذه العناصر كأدوات.

هذا منفصل عن ملف > تفعيل الخادم المحلي (File > Enable Local Server)، الذي يشغّل مرحّل WebSocket لصفحات Social Stream. راجع شرح الخوادم والخدمات المحلية إذا لم تكن متأكدًا من الخدمة التي تحتاجها.

1. تنزيل تطبيق سطح المكتب المعتاد

ثبّت الإصدار الحالي من Social Stream Ninja من تنزيلات Windows أو macOS أو Linux. دعم MCP مضمّن في التطبيق الذي تنزّله. لا تحتاج إلى مستودع المصدر أو Node أو Python أو حزمة MCP منفصلة.

2. تفعيل التحكم المحلي بالذكاء الاصطناعي

  1. افتح ملف > ذكاء اصطناعي محلي / أتمتة (File > Local AI / Automation).
  2. تفعيل واجهة التحكم المحلية API ودع التطبيق يعيد التشغيل.
  3. عُد إلى القائمة نفسها واختر نسخ إعداد MCP (Copy MCP Setup).
  4. الصق JSON المنسوخ في إعدادات MCP التي تستخدمها أداة الذكاء الاصطناعي، ثم أعد تشغيل الأداة.

يتضمن الإعداد المنسوخ المسار الدقيق للملف التنفيذي المثبت والمنفذ والمعاملات الخاصة بالمنصة. يشغّل ملف Social Stream Ninja التنفيذي المُنزَّل محوّل MCP الخفيف الخاص به عندما يشغّله عميل الذكاء الاصطناعي باستخدام --ssapp-mcp.

3. ترك MCP يكتشف الإمكانات

بعد الاتصال، يطلب عميل MCP تلقائيًا من Social Stream Ninja قائمة أدواته. يقرأ المحوّل الإمكانات الفعلية للتطبيق العامل ويقدم إلى LLM مخططات الأدوات المدعومة وإصدارات التطبيق وAPI وتعليمات التشغيل. ينبغي للوكيل استدعاء capabilities أولًا، ثم status، واستخدام معرّفات المصادر الثابتة التي يعيدها التطبيق.

لا يتطلب استخدام MCP المعتاد استخراج محتوى المواقع أو تثبيت مهارة. يمكن للمستخدم ببساطة أن يطلب من الوكيل المتصل فحص Social Stream Ninja أو التحكم فيه.

عناصر التحكم المحلية المتاحة

  • سرد المصادر وفحصها وإضافتها وتحديثها وإزالتها.
  • تشغيل مصدر واحد أو مجموعة مصفاة أو إيقافها أو إعادة تحميلها.
  • تغيير ظهور المصدر وحالة كتمه ووضع اتصاله.
  • قراءة الإعدادات العامة المدعومة التي يعيدها اكتشاف الإمكانات وتحديثها.
  • قراءة حالة التطبيق والجلسة والمصادر والعمليات والالتقاط والوسائط المحلية.
  • متابعة أحداث المصادر الملتقطة ضمن حدود، وأحداث العمليات أو الحالة القابلة للاستئناف.
  • التقاط صفحات المصادر المدعومة والنوافذ التابعة لـSSApp وفحصها بأمان.
  • تنفيذ التفاعلات المصرح بها مع الصفحات والنوافذ ومربعات الحوار مع التأكيد.
  • إعادة تحميل التطبيق أو إغلاقه بطريقة منظمة بعد تأكيد صريح.

الإمكانات التي يعلنها التطبيق العامل هي المرجع المعتمد. قد تتيح الإصدارات الأقدم عناصر تحكم أقل.

وصول HTTP مباشر للبرامج النصية المحلية

يمكن للبرامج النصية على الجهاز نفسه استخدام واجهة loopback API دون MCP. وهي تستمع فقط على 127.0.0.1 ولا تتطلب رمزًا.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

استخدم الإمكانات المُعلَنة بدلًا من افتراض أن كل إصدار من التطبيق يملك عناصر التحكم نفسها. للاطلاع على أمثلة curl قابلة للنسخ واللصق لإضافة مصدر وسرده وتشغيله وفحصه وإيقافه، راجع شرح واجهة HTTP API للخادم.

ذكاء اصطناعي محلي على VPS بنظام Ubuntu

يمكن لواجهة API أيضًا خدمة أداة ذكاء اصطناعي تعمل على خادم Linux نفسه الذي يشغّل نسخة SSApp دون واجهة مرئية. أبقِ الواجهة مرتبطة بـloopback واستخدم AppImage الذي نزّلته كأمر MCP.

متابعة تشغيل Social Stream Ninja دون واجهة مرئية لمعرفة Xvfb والملفات الشخصية الدائمة وأوامر بدء التشغيل وsystemd ومسار التحكم عن بُعد المنفصل. يتضمن أيضًا تهيئة MCP لملف AppImage في Linux يمكنك لصقه في عميل يعمل على VPS.

مهارة وكيل اختيارية

يمكن للوكلاء الذين يدعمون المهارات القابلة للتثبيت تنزيل مهارة Control Social Stream الكاملة. يمكنك أيضًا قراءة تعليماتها عبر الإنترنت، مع مرجع API و سجل الإصدارات. تضيف المهارة إرشادات لسير العمل، لكنها ليست مطلوبة لاتصال MCP.

تتوفر أيضًا روابط اكتشاف قابلة للقراءة آليًا في llms.txt.

محلي فقط

هذه الواجهة للذكاء الاصطناعي والأتمتة العاملين على الجهاز نفسه الذي يشغّل SSApp. لا تكشفها للشبكة أو تمررها عبر نفق كواجهة تحكم سحابية عن بُعد. ينبغي للمستخدمين البعيدين وStream Deck استخدام اتصال WebRTC أو WebSocket الحالي في Social Stream. لا تتيح الواجهة المحلية تنفيذ JavaScript اعتباطي أو ملفات تعريف الارتباط أو أسرار تسجيل الدخول أو الإعدادات غير المقيدة أو الوصول الخام إلى نظام الملفات.

للاطلاع على نقاط النهاية الكاملة ومخططات الأوامر واكتشاف الإصدارات وحدود الأمان، راجع مرجع الأتمتة التقني.
