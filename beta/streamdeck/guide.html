Connect once

  1. Download the plugin and open the .streamDeckPlugin file to install it.
  2. Keep SSApp or the Social Stream Ninja Chrome extension running and enabled. Copy your session ID from Stream Deck Setup in SSApp, or Settings in the extension.
  3. In the Stream Deck app, drag Setup onto a key and select it. Expand Setup and connection and paste your ID or full overlay URL.
  4. Keep Peer-to-peer (default) selected. Enter your session password if you use one, then choose Test Connection. Look for Online on the Setup key.
  5. Add a Preset Command key, choose a command, and fill in any required value. Press the key to run it.

All SSN actions and profiles share one connection. Keep your session ID and password private.

WebSocket and full overlay URLs

For WebSocket mode, enable SSN's remote API control and select WebSocket in the plugin. Keep the default host io.socialstream.ninja, TLS on, send channel 1 and listen channel 2 unless you use a custom server.

Pasting a full overlay URL can also import its password and connection mode. Check those settings before testing.

Control a desktop app source

  1. Add a Preset Command key and choose a desktop source command, such as Start source or Set mute.
  2. Choose the source by name. Stopped sources remain available so you can start them again.
  3. For Set mute, choose Mute or Unmute. For Set visibility, choose Show or Hide. Visibility controls the source window in the desktop app.

Use Refresh sources after changing sources in SSApp. If a saved source is unavailable, its value stays saved until you choose another. Use Edit ID or JSON for a manual source ID or advanced options.

The key preview shows the icon and title. Enter a short custom title to distinguish multiple sources; line breaks are supported.

Timer Dial gestures

Turn

Add or subtract one step. Default ±10 seconds.

Hold down and turn

Six steps per click. Default ±1 minute. Doesn’t start or pause.

Press

Start or pause the timer.

Tap the screen

Refresh the display. Doesn’t start or pause.

Hold the screen

Reset to the starting duration and pause.

Example: start at 5:00. Turn right once → 5:10. Hold the dial down and turn right once → 6:10. Press/release → countdown starts. Press/release again → pause. Hold the screen → 5:00.

Set Seconds per turn in the inspector. All Timer Dials share one SSN timer; add the SSN timer overlay to OBS to show it.

Chat Review: browse, pin, feature

  1. Open the default Social Stream dock with the same session. In WebSocket mode also enable Send chat messages to API server in SSN; chat uses channel 4. P2P receives the normal feed.
  2. Turn counterclockwise for older messages; clockwise for newer messages. The display's position/count tells you where you are.
  3. Press the dial to pin the displayed message in the dock.
  4. Tap the touchscreen above it to feature the next pinned message. This can be different from the message you are reviewing if the dock already has pinned messages.
  5. Hold that touchscreen area to unpin the reviewed message.

Only messages received while Chat Review is visible are listed. Empty? Chat relay may be off, or nothing new has arrived.

Run a custom Event Flow workflow

  1. Open Event Flow in SSN and create a dedicated flow.
  2. Add Run from Stream Deck / API from Stream Deck & API. Set the trigger name to intermission.
  3. Connect it to an action, such as Show Text, and set the text. Save and enable the flow.
  4. For visual/audio actions, open the Flow Actions overlay with the same session; add that URL as an OBS Browser Source for your audience.
  5. Add a Preset Command key, select Event Flow workflows → Run workflow, then Refresh workflows and choose your saved flow.
  6. Press once. A check mark acknowledges that SSN accepted the run. Delays and external integrations continue afterward.

After renaming, disabling or deleting the trigger, refresh and reselect it.

Advanced: pass values or use the API

In the Value field:

{"trigger":"intermission","flowId":"YOUR_FLOW_ID","data":{"name":"Back in five minutes"}}

Use {meta.workflow.data.name} in an action's text template. Omit flowId to run every enabled flow with that exact trigger name. Names are case-sensitive. Each press starts a run; add a Rate Limiter (THROTTLE) node if you want a cooldown. A delayed run can overlap a later press.

API clients use the same connection: {"action":"triggerWorkflow","value":{"trigger":"intermission"}}. getWorkflowTriggers lists enabled, saved triggers. Older hosts hide these presets until their capabilities advertise support.

Event Flow and API examples

What the key shows

  • Setup / Offline / Connecting / Online: connection status, not OBS visibility.
  • Check mark: SSN accepted the command. It doesn’t confirm OBS or external webhooks.
  • Alert: open Help and diagnostics on the selected action for the error.
  • Query keys: show the result (queue size, timer, etc.) for about three seconds.
  • Product State: updates every five seconds while visible.
  • Reset Collected Credits: press twice within two seconds (the key says Press Again). Multi Actions reset directly.
  • Other resets and removals: run on the first press.

Read the icons

The large symbol is the feature; the small badge is the operation.

  • Triangle: start/show. Two bars: pause. Square: stop or hide.
  • Triangle + vertical bar: next. Arrow around a circle: reset/restart.
  • Plus/minus: add/remove. Cross: clear. Pencil: set/edit.
  • “i”, list or “#”: read state, list items or count. Eye: preview. Flask: test.
  • Waitlist and giveaway both use a trophy, so check the key title.

When a command does nothing

  1. Check that Setup says Online and uses the same session ID and password as SSN.
  2. Check the required destination is running: dock for queues/pins, Credits page for credits, Flow Actions for media/OBS, writable source for Send Chat, enabled saved products for commerce.
  3. For workflows, save and enable the flow, confirm the trigger name, and refresh the picker. The flow needs a Run from Stream Deck / API trigger.
  4. Read the selected action's Help and diagnostics. After a timeout, check the destination before pressing again; a lost acknowledgement does not prove failure.
  5. If a preset is unavailable, update SSApp or the extension and the Stream Deck plugin, then test the connection again.

HTTP fallback is optional in WebSocket mode. It can help when the socket connects without relaying responses. Do not change default channels unless your receiver uses the same custom routing.

Report a problem with the action, expected result, observed result and sanitized diagnostics. Do not share session IDs, passwords or private source URLs.
