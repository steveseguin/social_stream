Cómo instalar fuentes personalizadas

  • Windows: Haz clic derecho en el archivo .ttf o .otf → selecciona «Instalar» o «Instalar para todos los usuarios» → reinicia tu navegador.
  • macOS: Haz doble clic en el archivo .ttf o .otf → haz clic en «Instalar tipo de letra» en Catálogo Tipográfico → reinicia tu navegador.
  • Linux: Copia los archivos de fuentes a ~/.local/share/fonts/ → ejecuta fc-cache -fv → reinicia tu navegador.

Después de instalar, actualiza esta página para ver tus fuentes nuevas. Si una fuente no aparece, prueba el botón «Probar Local Fonts API» (solo en navegadores Chromium).

Detectando…

Utilizar una fuente concreta mediante URL

  • Parámetro: Añade ?font=<Font%20Family%20Name> a la URL. Los espacios y símbolos deben codificarse para URL.
  • Se aplica a la variable CSS: Tu sitio utiliza --font-family; esta página también lo respeta. Ejemplo: ?font=Segoe%20UI.
  • No hacen falta comillas: No incluyas comillas en el parámetro; no son necesarias en la variable CSS.
  • Solo instaladas: El parámetro solo funciona con fuentes ya instaladas en tu sistema. No descarga fuentes web.

Compatibilidad (aplicaciones Ninja)

  • VDO.Ninja: Generado ?font= los enlaces funcionan con superposiciones/escenas que respeten la --font-family variable.
  • SocialStream.Ninja: Usa el mismo ?font= parámetro para sustituir la fuente predeterminada en widgets compatibles.
  • Caption.Ninja: Aplicar ?font= a las superposiciones de subtítulos que admitan familias de fuentes personalizadas.

Estas aplicaciones permiten sustituir font-family cuando el ?font= parámetro esté admitido en sus URL o enlaces de inserción. Esta herramienta genera valores correctamente codificados y listos para usar.

Solución de problemas (Windows)

  • Nombre exacto de la familia: Utiliza el nombre de familia de la fuente (no el nombre del archivo). Comprueba Configuración → Personalización → Fuentes para encontrar la etiqueta correcta de la familia.
  • Ámbito de instalación correcto: Si instalaste una fuente para otro usuario de Windows o solo mediante una cuenta de administrador, tu sesión del navegador podría no verla. Instálala «para todos los usuarios» si es necesario.
  • Formatos compatibles: Los navegadores utilizan TrueType/OpenType/WOFF. Las fuentes antiguas Type 1 y algunas fuentes de mapa de bits no funcionan.
  • Disponibilidad de grosor/estilo: Si solo está instalada la variante en negrita, el texto normal puede utilizar otra fuente. Prueba una muestra en negrita o instala también la variante regular.
  • Límites de privacidad: Los navegadores no permiten enumerar todas las fuentes sin permiso. Esta página las detecta a partir de una amplia lista conocida y de la API opcional Local Fonts.
  • API Local Fonts: En Chromium, desde orígenes seguros (https/localhost), hacer clic en «Probar Local Fonts API» puede enumerar exactamente tus familias instaladas tras conceder permiso.

Consejos de uso manual

  • Forzar una fuente: En tu CSS: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • Probar un nombre cualquiera: Utiliza la búsqueda para probar cualquier familia; si se encuentra, aparece en los resultados con una muestra.
  • Codificación: Crea enlaces como: ?font=Segoe%20UI (los enlaces generados abajo utilizan la codificación adecuada).
  • Fuentes CJK y de otras escrituras: La muestra incluye caracteres latinos, números y símbolos. Sustitúyela por texto de la escritura específica para comprobar su forma.

Nota: esta página no instala ni descarga fuentes; solo detecta y previsualiza familias que tu navegador ya tiene disponibles.
