Configura tu primera alerta

  1. Abre Multi-Alerts → Animaciones de eventos y efectos de sonido (Event animations & sound effects).
  2. Activa una alerta y luego elige el evento. El ajuste predefinido de donación de 100 USD rellena ambos límites de importe y añade un sonido sintético de agradecimiento si no hay ninguno seleccionado.
  3. Añade opcionalmente una URL directa de GIF, imagen o video, o sube un archivo multimedia. Un enlace a una página de GIPHY no es una URL directa de archivo. Las imágenes GIF no tienen audio; elige un sonido aparte.
  4. Elige un sonido y utiliza Escuchar (Listen) para oírlo localmente. Las opciones de URL personalizada y subida están debajo del selector.
  5. Utiliza Probar alerta (Test alert) y luego añade tu enlace de Multi-Alerts como fuente de navegador de OBS.

Límites de importe y prioridad

Las donaciones y los bits utilizan valores estimados en USD del conversor de divisas. Para exactamente 100 USD, fija ambos límites en 100. Para 100 USD o más, deja el máximo en blanco. Los límites vacíos permiten cualquier importe; otros tipos de evento no deberían tener límites de importe.

Se aplica la primera alerta que coincida. Coloca las reglas específicas antes que las generales. Los filtros de plataforma y categoría siguen aplicándose.

Vista previa y sonido

Probar alerta (Test alert) abre y enfoca la vista previa local. No envía ningún evento a tus canales en vivo. La vista previa utiliza tus ajustes actuales de superposición, filtros, archivos multimedia y tiempos. El volumen está en Sonido y tiempos (Sound & Timing).

Borrar sonido (Clear sound) elimina el sonido personalizado; se sigue aplicando el audio predeterminado de la alerta. Desactiva Reproducir sonido de alerta (Play alert sound) para silenciar el audio de la superposición. Activar alerta (Enable alert) permite pausar una regla conservando sus ajustes. Restablecer alerta (Reset alert) borra solo esa regla.

Las frases habladas están etiquetadas como grabaciones sintéticas. Para nombres o texto variable, utiliza la acción Leer texto (Speak Text) del editor Event Flow.

Event Flow y efectos de OBS

Utiliza plantillas de Event Flow para secuencias y efectos de OBS. Esas acciones multimedia y de sonido se reproducen en la superposición Flow Actions. Utiliza una superposición para el sonido de cada evento para evitar escucharlo dos veces. Las plantillas de OBS necesitan una fuente y un filtro seleccionados antes de usarse.
