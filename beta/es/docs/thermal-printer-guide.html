Impresoras térmicas y etiquetas para transmisiones

Convierte compras, donaciones y eventos del chat en recibos físicos, pegatinas, boletos o etiquetas de recogida.

¿Qué puede imprimir?

La aplicación independiente de Windows puede enviar trabajos sin diálogo de impresión a una impresora instalada en Windows. Un flujo puede combinar cualquier valor disponible, como nombre de espectador, donación, producto, mensaje o valor de contador, y controlar el tamaño y la alineación del texto.

Regla de compatibilidad: la impresora debe aparecer como una cola de impresión operativa en Windows. Social Stream imprime mediante el controlador de Windows instalado; no envía comandos ESC/POS, ZPL ni del SDK del fabricante directamente.

Configuración rápida

  1. Conecta la impresora por USB, enciéndela e instala su controlador de Windows. Imprime primero una página de prueba de Windows.
  2. En Social Stream, abre Ajustes y herramientas globales → Control de impresora (Printer Control).
  3. Selecciona Buscar impresoras (Find printers) y elige el nombre exacto de la cola que muestra Windows.
  4. Introduce el ancho físico del papel, normalmente 58, 80, o 62 mm según el dispositivo y el papel.
  5. Deja Longitud fija de etiqueta en 0 para un recibo ajustado al contenido. Para papel troquelado, introduce en milímetros la longitud de la etiqueta en la dirección de avance.
  6. Selecciona Imprimir prueba de alineación. Si falta un borde, aumenta el margen seguro de ese lado y vuelve a probar.

Los márgenes seguros izquierdo y derecho predeterminados de 2 mm son adecuados para muchas impresoras de recibos económicas de 58 mm, pero el controlador determina el área imprimible real. Mantén Usar área imprimible (Use printable area) seleccionado, salvo que hayas probado otro ajuste.

¿Rollo de recibos, adhesivo continuo o etiqueta troquelada?

Rollo de recibos

Ideal para comprobantes de compra de longitud variable, turnos y recibos de colaboradores. Deja la longitud fija en 0 para que el contenido determine la longitud del papel.

Rollo adhesivo continuo

Ideal para tiras adhesivas con nombres y cantidades de texto variables. Se comporta como papel de recibos, pero la impresora o el controlador deben encargarse del corte.

Etiquetas troqueladas

Ideal para credenciales y etiquetas de producto uniformes. Establece la longitud fija exacta y configura el mismo papel en las Preferencias de impresión de Windows.

Imprimir una etiqueta de donación con Event Flow

💰 Donación / PropinaImporte mínimo: 10
→
🖨️ Imprimir etiqueta térmica{username}
{donation}
24 pt · negrita · centrado
  1. Abre: Editor de Event Flow y crea un flujo.
  2. Añade el Donación / Propina (Donation / Tip) como disparador. Establece Importe mínimo (Minimum Amount) si solo deben imprimirse las donaciones más grandes.
  3. Añade Imprimir etiqueta térmica (Print Thermal Label) desde Integraciones y conecta el disparador a él.
  4. Establece el texto de la etiqueta en {username}, añade un salto de línea y luego {donation}. Elige el tamaño de letra, el grosor, la alineación y las copias.
  5. Normalmente, deja en blanco o en 0 las opciones de impresora y longitud fija de la acción para aplicar los ajustes globales de Control de impresora.
  6. Abrir Probar flujo (Test Flow), introduce un nombre, activa Tiene donación (Has Donation), introduce un importe y ejecuta la prueba. Esto envía un trabajo de impresión real en la aplicación independiente.

Otros marcadores útiles incluyen {message}, {source}, {donationAmount}, y {counterValue}. Los valores creados por nodos anteriores también pueden usarse en la plantilla de impresión.

Comprador en negrita y artículo en texto normal

Elige Grosor → Texto seleccionado (**negrita**), y luego introduce:

**{username}**
{subtitle}

Usa llaves simples. Las integraciones comerciales recientes colocan el título del producto en subtitle; la cantidad puede estar disponible como {meta.commerce.quantity}. Si el nodo anterior crea buyer, usa **{buyer}** en su lugar. Shopify y eBay omiten la identidad del comprador, así que usa un contador local de pedidos o una etiqueta solo con el producto para esas fuentes. Solo el texto entre ** se pone en negrita; no se necesita JavaScript ni HTML personalizado. Las etiquetas existentes de Todo en negrita y Normal conservan su formato.

Para ventas, usa Tipo de evento con purchase; Donación / Propina requiere hasDonation y no coincidirá con la mayoría de las ventas. Usa gift o giftfunded cuando la etiqueta indique un regalo completado, y filtra el proveedor si hace falta. Añade un Contador antes de la acción de impresión si quieres un número de pedido consecutivo para la transmisión. Consulta los campos de eventos de comercio.

La acción expone meta.thermalPrintResult.success y un error o código opcional para los siguientes pasos del flujo. El éxito significa que se envió el trabajo, no que salió papel. Revisa la cola de Windows antes de reintentar un trabajo dudoso para evitar etiquetas duplicadas.

Un contador numera compras, no compradores únicos. Reutilizar un ID para todas las compras del mismo comprador requiere una asignación independiente de comprador a ID y un reinicio explícito al comienzo de cada transmisión. El campo de motivo de User Memory es texto descriptivo, no un contador específico de ID de comprador.

Etiquetas de artículos de Whatnot

Descargar el flujo de ejemplo de Whatnot. Imprime el comprador en negrita, el nombre del artículo y un ID de pedido cuando se proporciona. Un aviso de fallo de pago imprime una etiqueta aparte de PAGO FALLIDO con los detalles disponibles en ese aviso.

  1. En la aplicación independiente, configura Control de impresora (Printer Control) para tu impresora y tamaño de papel, y ejecuta su prueba de alineación.
  2. Abre: Editor de Event Flow, elige Importar (Import), y selecciona el archivo JSON descargado.
  3. Selecciona Whatnot: etiquetas de artículos + avisos de pago. Revisa las dos acciones de impresión; heredan la impresora global y la longitud de etiqueta.
  4. Activa el flujo y guárdalo. Mantén abierta la fuente de Whatnot con la captura de eventos de transmisión habilitada.

El ejemplo se importa desactivado. Usa Tipo de evento (avanzado) → Evento personalizado para product_sold y payment_failed, con un filtro de fuente de Whatnot. Las pujas y los avisos de fin de subasta no imprimen etiquetas.

Una etiqueta de venta no confirma el pago. Este ejemplo imprime cada aviso al recibirlo; no espera al pago, no modifica una etiqueta anterior ni asigna números de comprador. Los campos ausentes se imprimen en blanco. Un aviso de fallo sin datos del comprador, el artículo o el pedido no puede identificar la etiqueta anterior. Consulta los campos de eventos de Whatnot.

Etiquetas de longitud fija sin sorpresas

Etiquetas de 3 × 1 pulgadas (incluida una configuración de Munbyn BT320): usa 76,2 mm de ancho y 25,4 mm de longitud fija cuando el lado de 1 pulgada esté en la dirección de avance. Haz coincidir ese papel y orientación en las Preferencias de impresión de Windows. Empieza con texto de 12–14 pt y prueba nombres largos de comprador y artículo.

Los bordes laterales de la prueba de alineación marcan el ancho seguro tras aplicar el área imprimible seleccionada y los márgenes seguros. La altura del recuadro sigue el texto de prueba; no delimita la etiqueta completa ni toca los bordes físicos del papel.

  • Mide en la dirección de avance. Una etiqueta de 62 × 29 mm normalmente usa un ancho de papel de 62 mm y una longitud fija de etiqueta de 29 mm.
  • Hazlo coincidir también en Windows. Selecciona el papel exacto de las etiquetas, la orientación, la detección de separaciones o marcas y el comportamiento del cortador en las Preferencias de impresión del controlador.
  • Fijo significa fijo. Social Stream no añade espacio de avance de recibos a un trabajo de longitud fija. El contenido demasiado alto puede recortarse o desbordarse, según el controlador.
  • Prueba con los datos más largos que sea razonable esperar. Los nombres largos de espectadores, variantes de productos, etiquetas de moneda y varias líneas necesitan más espacio o una letra más pequeña.
  • Los límites del controlador siguen aplicándose. Windows o el controlador de la impresora pueden limitar las páginas personalizadas muy cortas; Social Stream solicita un mínimo de 20 mm.

Ideas para transmisiones

  • Imprime pegatinas con nombres de colaboradores para una pared, un objeto, un mapa o un tablero físico de progreso.
  • Crea etiquetas de pedidos de merchandising, encargos, bebidas o recogidas a medida que llegan las compras.
  • Imprime boletos de rifa o participaciones en sorteos, con límites de frecuencia y comprobaciones de elegibilidad antes de la acción de impresión.
  • Crea credenciales VIP, asignaciones de equipo, fichas de desafíos o etiquetas de hitos de donaciones.
  • Imprime una breve cola de moderación o preparación de pedidos para un productor que trabaje junto al streamer.
Piénsalo antes de imprimir datos personales. Evita direcciones, correos electrónicos, datos de pago o mensajes privados. El papel térmico también pierde intensidad con el calor, la luz y el tiempo, por lo que no sirve para archivo permanente.

Soluciones habituales

  • No aparece ninguna impresora: confirma que Windows pueda imprimir una página de prueba, reinicia Social Stream y vuelve a seleccionar Buscar impresoras.
  • El trabajo indica éxito, pero no se imprime nada: abre la cola de Windows para esa impresora y comprueba si hay errores de pausa, desconexión, papel, controlador o puerto.
  • Se recorta un borde: mantén activado Usar área imprimible y aumenta el margen seguro de ese lado.
  • Sobra demasiado papel en blanco: usa una longitud fija de 0 para recibos, reduce el margen inferior y el avance, o establece la longitud exacta del papel de etiquetas.
  • Una etiqueta se convierte en dos: el contenido es más alto que la etiqueta fija o Windows usa un tamaño de papel incorrecto. Reduce el texto, el tamaño de letra, el interlineado y los márgenes.
  • Se usa una impresora incorrecta en Probar flujo: elige una impresora específica en el nodo Print Thermal Label. Si dejas esa opción vacía, al probar directamente en el editor se usa la impresora predeterminada de Windows.
