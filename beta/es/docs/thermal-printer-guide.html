Configúralo en 6 pasos

Antes de empezar: se necesita la aplicación independiente de Windows. La impresora debe aparecer como una impresora normal de Windows. Social Stream imprime mediante el controlador de Windows. No envía comandos ESC/POS ni ZPL sin procesar, ni comandos del SDK del fabricante.
  1. Conecta la impresora por USB, enciéndela e instala su controlador de Windows. Imprime una página de prueba de Windows para comprobar que funciona.
  2. En Social Stream, abre Ajustes y herramientas globales → Mecánica - Conexiones e integraciones → Control de impresora.
  3. Haz clic en Buscar impresoras (Find printers). Elige tu impresora por el nombre que muestra Windows.
  4. Introduce Ancho del papel (mm). Normalmente es 58, 80, o 62.
  5. Deja Longitud fija de etiqueta en 0 para papel de recibos. Para etiquetas troqueladas, introduce la longitud de la etiqueta en mm (en la dirección de avance del papel).
  6. Haz clic en Imprimir prueba. Si se corta un borde, aumenta el margen de seguridad de ese lado y vuelve a probar.

Los márgenes de seguridad predeterminados de 2 mm a izquierda y derecha sirven para muchas impresoras económicas de recibos de 58 mm. El controlador determina el área imprimible real, así que mantén Usar área imprimible (Use printable area) activado salvo que hayas probado otra configuración.

Imprime una etiqueta cuando alguien done

💰 Donación / PropinaImporte mínimo: 10
→
🖨️ Imprimir etiqueta térmica{username}
{donation}
24 pt · negrita · centrado
  1. Abre: Editor de Event Flow y crea un flujo nuevo.
  2. Añade el Donación / Propina (Donation / Tip) como disparador. Establece Importe mínimo (Minimum Amount) si solo deben imprimirse las donaciones más grandes.
  3. Añade Imprimir etiqueta térmica (Print Thermal Label) (en Integraciones) y conecta el disparador.
  4. Escribe {username}, una nueva línea y luego {donation}. Elige el tamaño de letra, el grosor, la alineación y el número de copias.
  5. Deja vacíos los ajustes de impresora y longitud fija de la acción, o con valor 0. Se usarán los ajustes de Control de impresora.
  6. Haz clic en Probar flujo (Test Flow). Introduce un nombre, activa Tiene donación (Has Donation), añade un importe y ejecútalo. Se imprimirá una etiqueta real.

Otros marcadores útiles: {message}, {source}, {donationAmount}, y {counterValue}. También funcionan los valores creados en pasos anteriores del flujo.

Imprime ventas, regalos y números de pedido

Quiero imprimir…Haz esto
VentasUsa Tipo de evento con purchase. Donación / Propina (Donation / Tip) necesita hasDonation, por lo que omite la mayoría de las ventas.
Regalos completadosUsa gift o giftfunded. Filtra por proveedor si es necesario.

Consulta: campos de eventos de comercio para ver qué incluye cada venta.

Comprador en negrita y artículo en texto normal

  1. Configura Grosor a Texto seleccionado.
  2. Introduce este texto para la etiqueta:
**{username}**
{subtitle}
  • Solo el texto entre ** se pone en negrita. No hace falta HTML ni JavaScript.
  • Usa llaves simples. Las ventas incluyen el nombre del producto en {subtitle}. La cantidad puede estar en {meta.commerce.quantity}.
  • Si un paso anterior crea buyer, usa **{buyer}** en su lugar.
  • Shopify y eBay no envían el nombre del comprador. Usa un contador de pedidos o una etiqueta que solo muestre el producto.
  • Las etiquetas configuradas como Todo en negrita o Normal conservan su aspecto.
Para crear flujos: resultados de impresión y números de comprador

La acción añade meta.thermalPrintResult.success, además de un error o código si algo falla, para los pasos posteriores. El éxito significa que el trabajo se envió a Windows, no que salió papel. Comprueba la cola de impresión de Windows antes de reintentar para evitar etiquetas duplicadas.

Un contador numera compras, no compradores únicos. Para dar el mismo número a cada compra de una persona, necesitas una lista independiente de comprador a número, reiniciada al comienzo de cada transmisión. El campo de motivo de Memoria de usuario es texto simple, no un contador de compradores.

Etiquetas de artículos de Whatnot

Descargar el flujo de ejemplo de Whatnot. Imprime el comprador en negrita, el nombre del artículo y un identificador de pedido si existe. Si falla un pago, imprime otra etiqueta marcada PAGO FALLIDO con los datos que incluya ese aviso.

  1. En la aplicación independiente, configura Control de impresora (Printer Control) y ejecuta su prueba de impresión.
  2. Abre: Editor de Event Flow, haz clic en Importar (Import), y elige el archivo descargado.
  3. Selecciona Whatnot: etiquetas de artículos + avisos de pago. Comprueba ambas acciones de impresión. Usan la impresora y la longitud de etiqueta de Control de impresora.
  4. Activa el flujo y guarda. Se importa desactivado.
  5. Mantén abierta tu fuente de Whatnot con la captura de eventos de transmisión activada.
Una etiqueta de venta no significa que esté pagada. Cada aviso se imprime al llegar. El flujo no espera al pago, no corrige etiquetas anteriores ni asigna números de comprador. Los campos ausentes se imprimen vacíos. Un aviso de error sin comprador, artículo ni datos de pedido no permite identificar a qué etiqueta corresponde.
Cómo funciona el flujo de ejemplo

Usa Tipo de evento (avanzado) → Evento personalizado para product_sold y payment_failed, filtrados para Whatnot. Las pujas y los avisos de fin de subasta no se imprimen. Consulta los campos de eventos de Whatnot.

Elige el papel

Rollo de recibos

Para comprobantes de compra, turnos y recibos de cualquier longitud. Deja la longitud fija de etiqueta en 0.

Rollo adhesivo continuo

Para tiras adhesivas con nombres de cualquier longitud. Funciona como papel de recibos, pero la impresora o el controlador deben cortarlo.

Etiquetas troqueladas

Para credenciales y etiquetas de producto del mismo tamaño. Configura la longitud fija exacta y elige el mismo papel en Preferencias de impresión de Windows.

Configura correctamente las etiquetas de tamaño fijo

Etiquetas de 3 × 1 pulgadas (también con Munbyn BT320): configura el ancho en 76.2 mm y la longitud fija en 25.4 mm cuando el lado de 1 pulgada avance primero. Elige el mismo papel y orientación en Preferencias de impresión de Windows. Empieza con texto de 12–14 pt.
ReglaPor qué
Mide en la dirección de avanceUna etiqueta de 62 × 29 mm suele tener 62 mm de ancho y una longitud fija de 29 mm.
Haz coincidir también WindowsConfigura el mismo papel, orientación, detección de huecos/marcas y cortador en las Preferencias de impresión del controlador.
Fijo significa fijoNo se añade avance adicional. El texto demasiado alto puede cortarse o pasar a otra etiqueta, según el controlador.
Prueba el texto más largoLos nombres largos, las opciones de producto y las líneas adicionales necesitan más espacio o texto más pequeño.
Las etiquetas muy cortas pueden no funcionarSocial Stream solicita al menos 20 mm. El controlador puede limitar de todos modos los tamaños de página cortos.

Los bordes laterales de la prueba de impresión muestran el ancho seguro. Su altura sigue el texto de prueba. No dibuja el contorno de toda la etiqueta.

Ideas para la transmisión

  • Pegatinas con nombres de seguidores para una pared, accesorio, mapa o tablero de progreso.
  • Etiquetas de mercancía, encargos, bebidas o recogida a medida que llegan pedidos.
  • Boletos de sorteo. Añade límites de frecuencia y comprobaciones de participación antes del paso de impresión.
  • Credenciales VIP, selecciones de equipo, fichas de retos o etiquetas de hitos.
  • Una lista breve de tareas para un productor sentado a tu lado.
No imprimas información privada. Omite direcciones, correos, datos de pago y mensajes privados. El papel térmico también se desvanece con el calor, la luz y el tiempo.

Solucionar problemas

ProblemaPrueba esto
No aparece ninguna impresoraComprueba que Windows pueda imprimir una página de prueba. Reinicia Social Stream y vuelve a hacer clic en Buscar impresoras.
Indica éxito, pero no imprime nadaAbre la cola de la impresora en Windows. Busca errores de pausa, desconexión, papel, controlador o puerto.
Se corta un bordeMantén activada Usar área imprimible. Aumenta el margen de seguridad de ese lado.
Demasiado papel en blancoUsa longitud fija 0 para recibos. Reduce el margen inferior y el avance adicional. Para etiquetas, configura la longitud exacta.
Una etiqueta se imprime en dosEl texto es más alto que la etiqueta o Windows tiene configurado un tamaño de papel incorrecto. Usa menos texto, una fuente más pequeña, menos espaciado o márgenes menores.
Probar flujo usa la impresora incorrectaElige una impresora específica en el paso Imprimir etiqueta térmica. Si está vacío, las pruebas en el editor usan la impresora predeterminada de Windows.
