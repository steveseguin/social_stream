Configuración del proyecto de YouTube

Cómo crear un proyecto de Google Cloud para la aplicación de escritorio SSN Standalone sin reducir la seguridad de tu clave.

Descripción general

Para qué sirve esta configuración

Utiliza esto solo si quieres que la aplicación de escritorio use tu propia cuota de API de YouTube en vez del proyecto compartido predeterminado de Social Stream Ninja.

Importante: los tres valores siguientes deben proceder del mismo proyecto de Google Cloud:
  • ID de cliente OAuth
  • Secreto de cliente OAuth
  • Clave de API
No confundas estos dos campos en Google Cloud:
  • Orígenes autorizados de JavaScript deben contener solo el origen, sin ruta.
  • URI de redirección autorizados deben incluir la ruta completa /sources/websocket/youtube.html .
Paso 1

Crea el proyecto

  1. Abre Google Cloud Console.
  2. Crea un proyecto nuevo o elige uno existente dedicado a este uso.
  3. Activa YouTube Data API v3.
  4. Abre los ajustes de la pantalla de consentimiento OAuth.
  5. Si la aplicación está en modo de prueba, añade tu cuenta de Google como usuario de prueba.
Paso 2

Crea el cliente OAuth

  1. Crea las credenciales.
  2. Elige ID de cliente OAuth.
  3. Utiliza el tipo Aplicación web.
  4. Añade los orígenes y URI de redirección exactos que se muestran a continuación.
Campo Valor
Orígenes autorizados de JavaScript http://localhost:8181
http://localhost:8080
URI de redirección autorizados http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
Paso 3

Crea la clave de API de forma segura

  1. Crea una Clave de API en el mismo proyecto.
  2. Abre las restricciones de esa clave.
  3. En Restricciones de API, restríngela a YouTube Data API v3 solamente.
  4. No utilices restricciones de referente HTTP para la aplicación de escritorio.

Regla para la aplicación de escritorio: Las restricciones de referentes HTTP son para páginas del navegador, no para este proceso de autenticación local de escritorio.

Paso 4

Pega los valores en la aplicación de escritorio

  1. Abre la página de la fuente de YouTube dentro de la aplicación de escritorio.
  2. Pega el ID de cliente OAuth, Secreto de cliente OAuth, y Clave de API.
  3. Haz clic en Guardar.
  4. Cierra sesión si es necesario.
  5. Haz clic en Iniciar sesión con YouTube.
  6. Completa el inicio de sesión de Google en la ventana del navegador externo.
Resultado esperado: si todo coincide, el inicio de sesión de Google funciona y la aplicación de escritorio utiliza tu proyecto de YouTube guardado en vez del proyecto compartido predeterminado.
Seguridad

Protege las credenciales

  • Trata el secreto de cliente y la clave de API como datos confidenciales.
  • No los pegues en capturas de pantalla, registros de chat ni informes de errores.
  • Si los expones por accidente, cámbialos o elimínalos.
  • Utiliza un proyecto de prueba dedicado si estás experimentando.
  • Elimina los proyectos temporales cuando termines las pruebas.
Solución de problemas

Problemas habituales

  • redirect_uri_mismatch: el URI de redirección no coincide exactamente.
  • invalid_client: el ID de cliente y el secreto de cliente no coinciden.
  • quotaExceeded: tu proyecto de clave de API agotó la cuota de YouTube.
  • Falló la validación de la cuenta: en versiones anteriores, esto podía ocurrir cuando OAuth y la clave de API pertenecían a proyectos distintos.
