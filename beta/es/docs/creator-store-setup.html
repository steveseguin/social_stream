Conecta las alertas en 5 pasos

  1. Abrir Monetización → Alertas de Fourthwall, Ko-fi y Buy Me a Coffee y elige tu Proveedor.
  2. Haz clic en Ajuste del receptor y activa control remoto de la extensión mediante API (remote API control of extension).
  3. Vuelve a Monetización y haz clic en Copiar URL del webhook.
  4. Pégala en la configuración de webhooks del proveedor (pasos más abajo).
  5. Mantén Social Stream Ninja en ejecución.
¿Está funcionando? «Receptor conectado» solo significa que SSN está escuchando. La línea del último evento se actualiza al llegar un evento real (se reinicia al volver a abrir SSN).
Mantén privada la URL del webhook. Es la única protección de estas alertas (no se comprueba ningún secreto de firma). Sirve para alertas, pero no como prueba de pago para enviar pedidos. Nunca la publiques ni la uses en un código QR.

Vista previa de alerta de ejemplo solo muestra el aspecto. No afecta a los totales, Event Flow ni al webhook.

NinjaBacker, Throne, Amazon y eBay: consulta la guía de monetización. Shopify: consulta Configurar Shopify.

Fourthwall

  1. En Fourthwall, abre Ajustes → Para desarrolladores → Webhooks.
  2. Crea un webhook y pega la URL de Fourthwall que aparece en SSN.
  3. Marca los eventos que quieras (consulta la tabla).
  4. Guarda y mantén SSN en ejecución.
Evento de FourthwallAparece como
ORDER_PLACEDUna compra. Su valor de donación se sigue sumando para mantener la compatibilidad con configuraciones anteriores.
GIFT_PURCHASEUn regalo.
DONATIONUna donación.
SUBSCRIPTION_PURCHASEDUna nueva membresía.

Los pedidos de tarjetas regalo no suman su valor dos veces. Los eventos de prueba se omiten.

Ko-fi

  1. Abrir Webhooks de Ko-fi.
  2. Pega la URL de Ko-fi que aparece en SSN en URL del webhook y guarda.
  3. Mantén SSN en ejecución.

Las propinas públicas, las membresías, los pedidos y los encargos usan este mismo enlace. Los pagos privados se excluyen. Los pedidos y los encargos aparecen como compras y no se suman a los totales de donaciones. Ko-fi no informa de las membresías canceladas.

Haz las pruebas con la vista previa de SSN. Los pagos de prueba de Ko-fi parecen reales y pueden activar alertas, totales y acciones. No los uses mientras estén activas las recompensas de pago.

Buy Me a Coffee

  1. En tu panel de creador, abre Integraciones y elige Nuevo webhook.
  2. Ponle un nombre y pega la URL de Buy Me a Coffee que aparece en SSN.
  3. Marca los eventos que quieras (consulta la tabla).
  4. Guarda y deja activado el envío. Si algo falla, consulta allí el historial de entregas.
EventoAparece como
donation.createdUna donación.
extra_purchase.createdUna compra.
commission_order.createdUna compra.
wishlist_payment.createdUna aportación para un regalo.
membership.startedUn anuncio de nueva membresía (no un cobro aparte).

Las notas ocultas y los colaboradores anónimos siguen ocultos. Las pruebas del panel (live_mode: false) se omiten. Los reembolsos no reducen los totales.

Importar un producto de Fourthwall

  1. En Fourthwall, ve a Ajustes → Para desarrolladores (Settings → For Developers) y crea un Token de Storefront. No uses una clave de API de administrador.
  2. En SSN, abre Productos y enlaces de apoyo → Configurar productos y enlaces → Importar un producto de Fourthwall.
  3. Pega el enlace público del producto y el token. Haz clic en Cargar detalles del producto.
  4. Comprueba el nombre, la imagen, el precio y el enlace. El enlace debe pertenecer a la misma tienda que el token.
  5. Elige una finalidad: Shop (Tienda), Gift (Regalo), Support (Apoyo) o Join (Unirse).
  6. Haz clic en Añadir producto o enlace, activa Productos y enlaces de apoyo, y haz clic en Guardar configuración.
Qué hace la importación
  • Carga un producto público y disponible cada vez.
  • El token determina en qué tienda se busca. Se usa una vez y luego se borra. Nunca se guarda ni se envía a las superposiciones.
  • Si las variantes o los paquetes tienen precios distintos, el precio se deja en blanco.
  • Es una instantánea. Los precios, las existencias y las imágenes no se actualizan; vuelve a importar o edítalos cuando cambien.
  • Puedes guardar hasta 20 productos. Si añades el mismo otra vez, se crea una segunda copia.

Muestra productos y códigos QR en la transmisión

También puedes añadir a mano cualquier enlace público (Shopify, Tiltify, Patreon, etc.). Eso no conecta las alertas de pago.

  1. En Superposición de OBS para, elige Productos y enlaces de apoyo.
  2. Abrir Opciones del enlace de superposición y elige una Vista de la superposición: Solo escaparate de productos, Solo tarjeta de apoyo, Solo alertas de actividad, o Escaparate y alertas.
  3. Haz clic en Copiar enlace de OBS (Copy OBS link) y añádelo a OBS como Fuente de navegador (Browser Source). Empieza con 800 × 600. Usa una fuente por vista.
  4. En Opciones de visualización, fija el primer producto o alterna entre ellos, y activa Mostrar código QR.
  5. Escanea el código QR con el teléfono en la composición final de OBS.
¿No se puede escanear el código QR? No reduzcas ni recortes demasiado la superposición. Para compartir un enlace en el chat, haz clic en Copiar enlace público.
Alertas, multi-alerts y Event Flow
  • El escaparate muestra la imagen del producto. La tarjeta de apoyo, más pequeña, no.
  • Las alertas de actividad funcionan por sí solas y nunca muestran el código QR de un producto no relacionado.
  • Multi-alerts y el feed de actividad funcionan con la misma sesión y no necesitan una lista de productos. La vista de actividad de Monetización requiere que la lista de productos esté activada.
  • En Event Flow, el disparador Donation sigue incluyendo las filas con hasDonation. Usa Event Type para compras o regalos completados. Consulta el correspondencia de eventos.

Si no aparece nada

ProblemaPrueba esto
El receptor está apagadoActiva control remoto de la extensión mediante API (remote API control of extension). Los otros interruptores de API tienen funciones distintas.
DesconectadoMantén SSN encendido y comprueba tu conexión a internet. Esta es la conexión de SSN, no la del proveedor.
No se recibió ningún eventoComprueba el proveedor seleccionado, la URL y su configuración de webhooks.
Evento omitidoSe excluyen las pruebas, los pagos privados, los eventos no compatibles y los importes incorrectos.
Llegó el evento, pero no aparece la superposiciónComprueba la sesión, la contraseña, los filtros, las reglas de SSN y que la fuente de OBS esté visible. La mayoría de las compras no son donaciones.
Las alertas aparecen dos vecesNo envíes el mismo pago a través del proveedor y de otro servicio.
Falló la importaciónComprueba el enlace del producto y el token de Storefront, y que el producto sea público y esté disponible. Siempre puedes introducirlo a mano.

Este es un feed de alertas en directo, no un registro de pedidos. Usa el panel del proveedor para pagos, reembolsos y envíos. Las alertas de Tiltify y Patreon aún no son compatibles.
