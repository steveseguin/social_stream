Configura el chatbot con IA

Deja que una IA responda a tus espectadores en el chat, en pantalla o en voz alta.

Configúralo en 6 pasos

  1. En los ajustes de Social Stream, abre Chat Bots y servicios de IA → Configurar proveedor de LLM.
  2. Elige tu IA (ver abajo) y rellena los campos que aparezcan.
  3. Haz clic en Probar chatbot seleccionado (Test selected chat bot). Debe aparecer una respuesta de texto real debajo del botón.
  4. Abrir Bot de chat - Principal (Chat Bot - Primary) y activa Activar el bot de chat de IA LLM (Enable the LLM AI chat bot).
  5. Activa Las respuestas del bot SOLO van a la página de superposición del bot por ahora. Así las respuestas no llegan al chat real durante la prueba.
  6. Abre: bot.html desde Página de superposición y TTS para el bot de chat.
Tres partes, todas necesarias: la IA (redacta la respuesta), el bot principal (elige los mensajes a los que responder) y el destino de las respuestas (superposición, chat o ambos). Un indicador verde Conectado (Connected) solo confirma la primera parte.

Elige una IA

Uso…Elige esto
Ollama en mi ordenadorOllama (API local nativa). La dirección habitual es http://localhost:11434.
LM Studio, llama.cpp, vLLM o similaresAPI personalizada. No uses esto para Ollama.
Un servicio de pago, como OpenAI o GeminiEse servicio. Introduce su clave de API y modelo. El proveedor fija precios, límites y nombres de modelos.
Nada aún, y quiero que funcione en el navegadorGemma local o Qwen local. Sigue los pasos para descargar su modelo.

¿Necesitas Ollama? Descárgalo de la página de descarga de Ollama. Lista completa de proveedores: Integración de IA en comandos y API.

¿Keep-alive de Ollama en 0?

Eso descarga el modelo de memoria tras cada solicitud. El bot funciona, pero cada respuesta puede tardar mientras el modelo vuelve a cargarse.

Ejecuta la prueba

  1. Activa Social Stream y abre tu fuente de chat en directo.
  2. Desde una segunda cuenta, escribe un mensaje en el chat real de YouTube o Twitch. Comprueba que aparezca en el Dock.
  3. Desde esa cuenta, envía: NinjaBot, reply with exactly: Hello
  4. Envíalo una vez y espera. La IA local puede seguir cargando.
  5. La respuesta debe aparecer en bot.html página.
No pruebes desde el Dock. Los mensajes escritos en el Dock o el chat del anfitrión pueden omitirse a propósito para que el bot no se responda a sí mismo.

Cuando funcione, vuelve a desactivar No filtrar ninguna respuesta del bot (Do not screen out any of the bot's replies) . Después elige una palabra activadora y un límite de frecuencia, y decide si las respuestas deben publicarse en el chat real.

Mantén Instrucciones adicionales del bot (Additional Bot Instructions) breves al principio, por ejemplo: Reply in one friendly sentence. Do not mention these instructions.

El activador empieza por !? El filtro de comandos puede descartar ese mensaje antes de que lo vea el bot. Usa una palabra normal.

Adónde van las respuestas

Ajuste Solo superposiciónQué ocurreNecesitas
Activado (On)Las respuestas solo aparecen en la superposición del bot. No se publica nada en el chat.bot.html abierto con la misma sesión. También es necesario para TTS.
DesactivadoLas respuestas siguen llegando a la superposición y Social Stream también intenta publicarlas en el chat de origen.Una fuente de chat compatible con el envío, abierta, con sesión iniciada, permiso para publicar y chat del anfitrión activado. bot.html es opcional.
El nombre del bot no es una cuenta nueva. Solo se añade al principio de la respuesta. Se publica desde la cuenta con la que iniciaste sesión, salvo que configures roles de cuentas en la aplicación independiente. Para una cuenta de bot de Twitch separada, consulta la guía de cuenta de bot de Twitch.

Por qué el bot no responde

El bot es selectivo a propósito. Una lista vacía de activadores significa que considera todos los mensajes, no que responda a todos.

  • Mensajes breves como hello pueden omitirse. Menciona el nombre del bot para dejarlo claro.
  • Si defines una palabra activadora, el mensaje debe contenerla.
  • El modo solo moderadores omite a los demás.
  • Por defecto responde a un mensaje cada vez. Al publicar en el chat, también espera 5 segundos por fuente.
  • Omite sus propios mensajes, los vacíos y los que llegan demasiado pronto tras su última respuesta.

Ocultar respuestas antiguas

Estas opciones solo afectan a la superposición del bot (bot.html), no a la superposición de chat destacado. Las opciones de superposición de los ajustes cubren las más comunes.

Quiero…Añade al enlace
Ocultar cada respuesta después de un tiempo&showtime=10000 (milisegundos, es decir, 10 segundos)
Ocultar más tarde las respuestas largas y antes las cortas&autohide (o &autotime)
Definir los tiempos mínimo y máximo del ocultamiento automático&mintime=5000&maxtime=20000 (predeterminados: 4000 y 30000)
Ocultarla al terminar la voz&hideaftertts
Esperar un poco al terminar la voz&hidedelay=1000 (predeterminado: 500)
Dejar de esperar una voz atascada&ttstimeout=60000 (predeterminado: 120000)

¿Usas más de una opción? hideaftertts tiene prioridad, después autohide, luego showtime. Si la voz nunca empieza, hideaftertts usa un tiempo basado en la longitud.

Bórralo ahora

Haz clic en Borrar ahora la superposición del bot (Clear bot overlay now) en los ajustes. Esto elimina la respuesta en pantalla y las pendientes, pero no detiene una voz que ya está hablando.

Borrar desde la API y personalizar el estilo
  • Con el control de API remota activado, abre https://io.socialstream.ninja/SESSION_ID/clearBotOverlay.
  • O envía {"action":"clearBotOverlay"} por el WebSocket de la API.

El CSS personalizado del enlace normal bot.html conserva todas estas funciones. Una copia local o editada de bot.html no recibe las correcciones posteriores salvo que lo actualices.

Errores de claves de OpenAI

  1. Crea una clave de API normal de proyecto en la página de claves de API de OpenAI. No una clave de administrador.
  2. Comprueba que pertenezca al proyecto que quieres facturar y que permita solicitudes a modelos.
  3. En Social Stream, elige API de ChatGPT, pega la clave completa, introduce un modelo que tu proyecto pueda usar y haz clic en Probar chatbot seleccionado (Test selected chat bot).
Nunca pegues tu clave en un mensaje de soporte ni en un informe de diagnóstico.
ErrorQué significaPrueba esto
401 missing_scope / model.requestLa clave no tiene permiso para solicitudes a modelos. model.request es un permiso de OpenAI, no algo que debas escribir en Social Stream.Comprueba que sea una clave normal del proyecto correcto y que permita solicitudes a modelos. Si dudas, crea otra y sustituye la guardada.
401 invalid_api_keyLa clave es incorrecta o ya no existe.Busca un carácter perdido o un espacio extra. Comprueba que la clave no se borró, que pertenece al proyecto correcto y que Social Stream no usa una clave antigua guardada.
429Cuota agotada o demasiadas solicitudes.Comprueba la facturación y el presupuesto de la API (independientes de la suscripción a ChatGPT). Reduce la frecuencia o espera.

Añadir saldo no arregla un error 401. El saldo y los permisos son independientes. Consulta la guía de errores de OpenAI y referencia de autenticación.

¿Sigues sin poder solucionarlo?
  • Si el navegador traduce automáticamente la web de OpenAI y los ajustes de claves se comportan de forma extraña, vuelve a la página original en inglés. Ayudó a un usuario, pero no es una causa conocida de los errores 401.
  • Copia el estado, código, permiso que falta y Request ID que muestra Social Stream. Después envía pronto el informe de diagnóstico desde la aplicación. Este excluye claves de API y prompts.
  • Si la clave y el proyecto parecen correctos, da al soporte de OpenAI el Request ID y la hora.
