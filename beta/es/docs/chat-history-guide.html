Historial de chat y puntos de fidelidad

Cómo afecta el almacenamiento local de mensajes al historial, los puntos y el reconocimiento de espectadores.

Todas las guías Historial local Mantener los puntos en funcionamiento Historial de mensajes existente

Qué hace la base de datos local de mensajes

SSN guarda los mensajes capturados en una base de datos del navegador o de la instalación de escritorio que realiza la captura. La página de historial de chat usa esa base de datos para consultar mensajes anteriores.

El Desactivar la base de datos local de mensajes impide guardar mensajes nuevos. La captura en directo y la visualización en el dock pueden continuar, así que ver mensajes en el dock no confirma que se esté guardando el historial.

La detección de usuarios que escriben por primera vez y el reconocimiento de espectadores basado en el historial también dependen de la base de datos local.

Mantener los puntos de fidelidad en funcionamiento

La obtención de puntos y los controladores de los comandos !points, !leaderboard y !rewards se ejecutan al guardar los mensajes capturados. Desactivar la base de datos local de mensajes detiene esos controladores, aunque los interruptores de puntos estén activados.

  1. Busca Desactivar la base de datos local de mensajes en los ajustes de SSN y déjala desactivada.
  2. En Sistema de puntos, activa los puntos de fidelidad y los comandos de chat que quieras usar.
  3. Pide a un espectador que envíe un mensaje y después !points. Comprueba su cuenta en la plataforma correspondiente.

Los saldos se guardan por separado del historial de mensajes. Usa Sistema de puntos → Copia de seguridad y restauración → Exportar puntos para hacer una copia de seguridad. Compartir un ID de sesión con otra instalación no sincroniza ninguna de las dos bases de datos.

Consulta: guía de puntos de fidelidad para obtener información sobre puntos, clasificaciones, recompensas y copias de seguridad.

Cómo se usa el historial existente

Cuando el registro de puntos está vacío y aún no se ha inicializado ni restablecido, SSN puede calcular los puntos iniciales a partir del historial guardado. Esto se ejecuta una sola vez para inicializar los saldos.

Las interacciones del historial usan las reglas de obtención de puntos en directo: la primera interacción válida obtiene los puntos base y las siguientes pueden recibir bonificaciones por racha. Solo se puede usar el historial disponible; guarda una exportación de puntos al trasladar o recuperar una instalación.
