API de control local y MCP

Permite que una herramienta de IA o un script en la misma computadora inspeccione y controle la aplicación de escritorio de Social Stream Ninja.

Cuándo elegir este servicio

Aplicación de escritorio→API de control local→Cliente MCP

Utiliza la API de control local cuando un programa de la computadora con SSApp necesite controles aprobados de la aplicación y las fuentes. Utiliza el adaptador MCP incluido cuando un cliente de IA compatible deba recibir esos controles como herramientas.

Esto es independiente de Archivo > Activar servidor local (File > Enable Local Server), que inicia un retransmisor WebSocket para las páginas de Social Stream. Consulta Explicación de servidores y servicios locales si no sabes qué servicio necesitas.

1. Descarga la aplicación de escritorio habitual

Instala la versión actual de Social Stream Ninja desde las descargas de Windows, macOS o Linux. La compatibilidad con MCP está incluida en la aplicación descargada. No necesitas el repositorio de código fuente, Node, Python ni un paquete MCP independiente.

2. Activa el control local con IA

  1. Abrir Archivo > IA local / Automatización (File > Local AI / Automation).
  2. Activa API de control local y deja que la aplicación se reinicie.
  3. Vuelve al mismo menú y elige Copiar configuración MCP (Copy MCP Setup).
  4. Pega el JSON copiado en los ajustes MCP de la herramienta de IA y luego reiníciala.

La configuración copiada contiene la ruta exacta del ejecutable instalado, el puerto y los argumentos específicos de la plataforma. El ejecutable descargado de Social Stream Ninja inicia su propio adaptador MCP ligero cuando el cliente de IA lo ejecuta con --ssapp-mcp.

3. Deja que MCP descubra las funciones

Una vez conectado, el cliente MCP solicita automáticamente las herramientas de Social Stream Ninja. El adaptador consulta las capacidades actuales de la aplicación en ejecución y proporciona al LLM los esquemas de herramientas compatibles, las versiones de la aplicación/API y las instrucciones de uso. El agente debe consultar primero las capacidades, luego el estado, y utilizar los ID estables de las fuentes devueltos por la aplicación.

El uso normal de MCP no requiere extraer datos del sitio web ni instalar habilidades. El usuario puede simplemente pedir al agente conectado que inspeccione o controle Social Stream Ninja.

Controles locales disponibles

  • Enumerar, inspeccionar, añadir, actualizar y eliminar fuentes.
  • Iniciar, detener o recargar una fuente o un conjunto filtrado.
  • Cambiar la visibilidad de las fuentes, su estado de silencio y el modo de conexión.
  • Leer y actualizar los ajustes globales compatibles devueltos por el descubrimiento de capacidades.
  • Consultar el estado de la aplicación, la sesión, las fuentes, los procesos, la captura y los archivos multimedia locales.
  • Seguir eventos limitados de fuentes capturadas y eventos reanudables de operaciones o estado.
  • Capturar e inspeccionar de forma segura páginas de fuentes compatibles y ventanas de SSApp.
  • Realizar interacciones aprobadas con páginas, ventanas y diálogos, con confirmación.
  • Recargar o cerrar correctamente la aplicación con confirmación explícita.

Las capacidades de la aplicación en ejecución son la referencia definitiva. Las versiones anteriores pueden ofrecer menos controles.

Acceso HTTP directo para scripts locales

Los scripts de la misma computadora pueden utilizar la API de bucle local sin MCP. Solo escucha en 127.0.0.1 y no requiere un token.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

Utiliza las capacidades anunciadas en vez de suponer que todas las versiones tienen los mismos controles. Para ejemplos de curl que puedes copiar y pegar para añadir, enumerar, iniciar, inspeccionar y detener una fuente, consulta el tutorial de la API HTTP del servidor.

IA local en un VPS con Ubuntu

La API también puede servir a una herramienta de IA que se ejecute en el mismo servidor Linux que una instancia de SSApp sin interfaz. Mantenla vinculada al bucle local y utiliza la AppImage descargada como comando MCP.

Seguimiento Ejecutar Social Stream Ninja sin interfaz visible para Xvfb, perfiles persistentes, comandos de inicio, systemd y la vía independiente de control remoto. También incluye una configuración MCP de AppImage en Linux que puedes pegar en un cliente ejecutado en el VPS.

Habilidad opcional para agentes

Los agentes que admiten habilidades instalables pueden descargar la habilidad completa Control Social Stream. También puedes leer sus instrucciones en línea, con el Referencia de la API y registro de versiones. La habilidad añade orientación sobre el flujo de trabajo, pero no es necesaria para conectarse mediante MCP.

Los enlaces de descubrimiento legibles por máquinas también aparecen en llms.txt.

Solo local

Esta interfaz es para IA y automatizaciones ejecutadas en la misma computadora que SSApp. No la expongas ni crees un túnel hacia ella como API de control remoto en la nube. Los usuarios remotos y Stream Deck deben utilizar la conexión WebRTC o WebSocket existente de Social Stream. La API local no permite ejecutar JavaScript arbitrario, acceder a cookies o secretos de inicio de sesión, cambiar ajustes sin restricciones ni acceder directamente al sistema de archivos.

Para consultar todos los endpoints, esquemas de comandos, detección de versiones y límites de seguridad, consulta la referencia técnica de automatización.
