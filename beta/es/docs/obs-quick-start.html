OBS Quick Start

Get chat into OBS with the fewest moving parts.

1. Use The Links SSN Gives You

SSN already made a session ID for you and puts it in every link it shows, along with your password and connection settings if you use them. Copy those links instead of typing your own; that ID is how your chat source, dock, and OBS overlay find each other.

You will use two of them: Main chat overlay & control dock and Featured chat overlay. Each has a Copy link button.

2. Start A Chat Source

  1. Install or open Social Stream Ninja.
  2. Open the chat source for your platform and leave it open.
  3. Send or wait for one chat message so you know the source is working.

Not sure which source mode to use? See the Platform Setup Picker.

3. Open The Dock

The dock is your test screen. In SSN, click Copy link next to Main chat overlay & control dock and open it in a browser tab before changing OBS settings.

Your link will look something like https://socialstream.ninja/dock.html?session=..., with your own ID and settings after it.

4. Add An OBS Browser Source

In OBS, add a Browser Source and paste one of your copied links as its URL. Pick the one that matches what you want on stream:

  • Scrolling chat (every message): use the Main chat overlay & control dock link. Turn on Hide menu bar under that link in SSN first, then copy it again, so the control bar stays off your stream.
  • One message at a time (click to feature): use the Featured chat overlay link. It stays empty until you click a message in the dock.

For other chat looks, pick a template from the Templates Gallery.

5. If OBS Is Blank

Check one thing at a time, in this order.

  • Confirm the dock receives messages first. If the dock is empty, OBS is not the problem yet.
  • Confirm the OBS URL is a link copied from SSN, with the same session as your dock.
  • If you used the Featured chat overlay, click a message in the dock. It shows nothing until you do.
  • Refresh the OBS browser source after changing URL options.
  • Check that the source chat page or app source window is still running.

More details: Troubleshooting.
