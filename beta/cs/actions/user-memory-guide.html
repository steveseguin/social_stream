Jedna pojmenovaná paměť, mnoho nástrojů

Událost Paměť uživatelů (User Memory) stavový uzel spravuje jednu oddělenou sadu lidí. Každý uzel pro zapamatování, zapomenutí, kontrolu, losování nebo vymazání vybírá tento stavový uzel. Pokud potřebujete samostatný seznam, vytvořte další uzel Paměť uživatelů – například jeden pro lidi, kteří dali vysílání To se mi líbí, a druhý pro účastníky soutěže.
Plná tyrkysová: tato událost se provede dál Fialová přerušovaná: tento uzel používá tuto paměť

Přetáhněte malý fialový postranní kosočtverec na uzel Paměť uživatelů nebo vyberte paměť podle názvu ve vlastnostech uzlu. Operace interně ukládá ID stavového uzlu. Výběr paměti zvýrazní všechny propojené operace a její smazání zobrazí varování před přerušením těchto vazeb.

Nastavení

  1. Přetáhněte Stavové uzly → Paměť uživatelů na plátno.
  2. Pojmenujte jej podle seznamu, který spravuje, například Způsobilí díky Heart Me, Dali vysílání To se mi líbí, nebo Účastníci losování.
  3. Vyberte Tato relace aplikace nebo Ukládat mezi restarty.
  4. Přidejte potřebné kontroly a akce a každou propojte s pojmenovanou pamětí pomocí postranního kosočtverce nebo rozbalovací nabídky.
  5. Běžnou cestu událostí propojte tyrkysovými čarami a použijte Test toku (Test Flow) se dvěma různými uživatelskými jmény před živým použitím.

Pravidlo identity: uživatelé jsou určeni kombinací platformy a ID uživatele. Zobrazované uživatelské jméno slouží pouze jako náhradní identifikátor. Anonymní nebo souhrnná událost bez identity uživatele se bezpečně ignoruje.

Praktické postupy

TikTok Heart Me nebo člen týmu → ? TTS

Pomocí události dárku zapamatujte odesílatele; nepokoušejte se z jediného řádku dárku vytvořit trvalou roli „člen“.

TikTok gift event + “Heart Me” match → AND → Remember User ···→ [Heart Me Eligible]
? command + TikTok source + (TikTok Team Member OR User Is Remembered) → AND → Speak Text ? command + NOT TikTok source → AND ────────────────────────────────→ Speak Text
  • Pro stav člena týmu či fanouška TikToku zvolte Role uživatele → Člen týmu TikTok. Čte přímo příchozí údaje odznaků a úrovní TikToku; zobrazovací nastavení „považovat za členy“ v hlavním překryvu chatu není potřeba.
  • Data dárků se liší podle režimu zachytávání. Běžné nastavení je Typ události → Jiný: gift a také Zpráva obsahuje: Heart Me. Ověřte zachycený řádek v Testu toku / Přehledu událostí a porovnávejte nejvhodnější pole poskytované vaším zdrojem.
  • Obě větve stále vyžadují úvodní ?, takže ostatní platformy čtou všem, zatímco TikTok zůstává omezený.

Zapamatování lidí, kteří dali To se mi líbí nebo se zapojili

Typ události → Jiný: liked → Zapamatovat uživatele ···→ [Dali vysílání To se mi líbí]

Funguje, když zachycená událost To se mi líbí nebo účasti označuje konkrétního uživatele. Souhrnné aktualizace počtu lajků člověka neurčují, a proto je nelze zapamatovat. Chcete-li nezávislé kontroly nebo losování, použijte samostatnou paměť pro každý druh účasti.

Losování s jedním záznamem na účastníka

Message Starts With !enter → Remember User ···→ [Prize Draw Entrants] Moderator + Message Starts With !draw → AND → Pick Random User ···→ [Prize Draw Entrants] Moderator + Message Starts With !resetdraw → AND → Clear All Users ···→ [Prize Draw Entrants]

Zapněte Odebrat vybraného uživatele pokud se výherci nemají losovat dvakrát. Ve veřejném vysílání chraňte příkazy losování a resetu kontrolou moderátora, správce nebo přesného uživatele.

Reset a trvalé ukládání

Ručně

Použijte Vymazat všechny uživatele nyní ve vlastnostech paměti během vytváření a testování.

Z toku

Použijte Vymazat všechny uživatele nebo obecný Resetovat stavový uzel, s výběrem přesné paměti.

Automatické

Vymazání po nečinnosti, při zahájení nebo ukončení vysílání. Hodnota 0 vypíná reset po nečinnosti.

Napříč restarty

Paměti relace se při spuštění aplikace začínají prázdné. Uložené paměti se znovu načítají, dokud není daná paměť výslovně vymazána.

„Vymazat vše“ má omezený rozsah: znamená to všechny uživatele uvnitř vybrané paměti – nikoli celý stav Event Flow, všechna losování nebo všechny paměti Social Stream Ninja.
