Termotiskárny a štítky pro stream

Proměňte nákupy, dary a události chatu ve fyzické účtenky, samolepky, lístky nebo štítky k vyzvednutí.

Co lze tisknout?

Samostatná aplikace pro Windows může odesílat úlohy na tiskárnu nainstalovanou ve Windows bez tiskového dialogu. Tok může kombinovat libovolné dostupné hodnoty, například jméno diváka, dar, produkt, zprávu nebo hodnotu počítadla, a ovládat velikost a zarovnání textu.

Pravidlo kompatibility: tiskárna se musí zobrazovat jako funkční tisková fronta Windows. Social Stream tiskne přes nainstalovaný ovladač Windows; neposílá přímo příkazy ESC/POS, ZPL ani SDK výrobce.

Rychlé nastavení

  1. Připojte tiskárnu přes USB, zapněte ji a nainstalujte ovladač Windows. Nejprve vytiskněte zkušební stránku Windows.
  2. V Social Stream otevřete Globální nastavení a nástroje → Ovládání tiskárny (Printer Control).
  3. Vyberte Najít tiskárny (Find printers) a vyberte přesný název fronty uvedený ve Windows.
  4. Zadejte skutečnou šířku papíru, obvykle 58, 80, nebo 62 mm podle zařízení a materiálu.
  5. Ponechte Pevná délka štítku (Fixed label length) na 0 pro účtenku s délkou podle obsahu. U vysekávaných štítků zadejte délku ve směru podávání v milimetrech.
  6. Vyberte Vytisknout test zarovnání (Print alignment test). Pokud některý okraj chybí, zvětšete na této straně bezpečný okraj a test zopakujte.

Výchozí bezpečné okraje 2 mm vlevo a vpravo vyhovují mnoha levným účtenkovým tiskárnám 58 mm, ale skutečnou tisknutelnou oblast určuje ovladač. Ponechte Použít tisknutelnou oblast (Use printable area) zapnuté, pokud jste neotestovali jiné nastavení.

Účtenková role, souvislá samolepka, nebo vysekávaný štítek?

Účtenková role

Nejlepší pro nákupní doklady proměnlivé délky, pořadové lístky a účtenky podporovatelů. Ponechte pevnou délku štítku 0 a nechte délku papíru určit obsahem.

Souvislá samolepicí role

Vhodné pro samolepicí jmenné proužky s různým množstvím textu. Chová se jako účtenkový papír, ale řezání musí zajistit tiskárna nebo ovladač.

Vysekávané štítky

Nejlepší pro jednotné jmenovky a produktové štítky. Nastavte přesnou pevnou délku a stejný materiál v Předvolbách tisku Windows.

  1. Otevřete Editor Event Flow a vytvořte tok.
  2. Přidejte Dar / spropitné (Donation / Tip) jako spouštěč. Nastavte Minimální částka (Minimum Amount) pokud se mají tisknout pouze větší dary.
  3. Přidejte Tisk termálního štítku (Print Thermal Label) z Integrations a připojte k ní spouštěč.
  4. Nastavte text štítku na {username}, přidejte nový řádek a poté {donation}. Vyberte velikost a tloušťku písma, zarovnání a počet kopií.
  5. Přepsání tiskárny a pevné délky v akci obvykle ponechte prázdné nebo na 0, aby se použila globální nastavení Printer Control.
  6. Otevřít Test toku (Test Flow), zadejte název, zapněte Částka daru (Has Donation), zadejte částku a spusťte test. V samostatné aplikaci se tím odešle skutečná tisková úloha.

Mezi další užitečné zástupné hodnoty patří {message}, {source}, {donationAmount}, a {counterValue}. V tiskové šabloně lze použít i hodnoty vytvořené předchozími uzly.

Kupujícího tučně, položku běžným písmem

Vyberte Tloušťka → Vybraný text (**tučné**) (Weight → Selected text), poté zadejte:

**{username}**
{subtitle}

Používejte jednoduché složené závorky. Novější obchodní integrace ukládají název produktu do subtitle; množství může být dostupné jako {meta.commerce.quantity}. Pokud dřívější uzel vytváří buyer, použijte **{buyer}** místo toho. Shopify a eBay neuvádějí totožnost kupujícího, proto pro tyto zdroje použijte místní počítadlo objednávek nebo štítek obsahující pouze produkt. Jen text uzavřený v ** bude tučně; vlastní JavaScript ani HTML nejsou potřeba. Stávající štítky All bold a Normal si zachovají formátování.

Pro prodej použijte Event Type s purchase; Donation / Tip vyžaduje hasDonation a nebude odpovídat většině prodejů. Použijte gift nebo giftfunded pokud štítek označuje dokončený dárek, a případně filtrujte poskytovatele. Chcete-li jedno průběžné číslo objednávky pro celý stream, přidejte před tiskovou akci Counter. Viz pole obchodních událostí.

Akce zpřístupňuje meta.thermalPrintResult.success a volitelnou chybu/kód pro další kroky toku. Úspěch znamená, že úloha byla odeslána, nikoli že vyšel papír. Před opakováním nejisté úlohy zkontrolujte frontu Windows, abyste zabránili duplicitním štítkům.

Counter čísluje nákupy, nikoli jednotlivé kupující. Opakované použití jednoho ID pro všechny nákupy stejného kupujícího vyžaduje samostatné přiřazení kupujících k ID a výslovný reset na začátku každého streamu. Pole reason v User Memory je popisný text, nikoli vyhrazené počítadlo ID kupujících.

Štítky položek Whatnot

Stáhnout ukázkový tok Whatnot. Vytiskne kupujícího tučně, název položky a ID objednávky, pokud je k dispozici. Oznámení o selhání platby vytiskne samostatný štítek PLATBA SELHALA s podrobnostmi dostupnými v daném oznámení.

  1. V samostatné aplikaci nastavte Ovládání tiskárny (Printer Control) pro svou tiskárnu a velikost papíru a spusťte test zarovnání.
  2. Otevřete Editor Event Flow, zvolte Importovat (Import), a vyberte stažený soubor JSON.
  3. Vyberte Whatnot: štítky položek + upozornění na platby (Item Labels + Payment Warnings). Zkontrolujte obě tiskové akce; přebírají globální tiskárnu a délku štítku.
  4. Zapněte tok a uložte ho. Nechte zdroj Whatnot otevřený se zapnutým zachytáváním událostí streamu.

Příklad se importuje vypnutý. Používá Event Type (Advanced) → Custom Event pro product_sold a payment_failed, s filtrem zdroje Whatnot. Příhozy a oznámení o končící aukci štítky netisknou.

Prodejní štítek nepotvrzuje platbu. Tento příklad tiskne každé oznámení při doručení; nečeká na platbu, neupravuje dřívější štítek ani nepřiděluje čísla kupujících. Chybějící pole se tisknou prázdná. Oznámení o selhání bez údajů o kupujícím, položce či objednávce nedokáže určit dřívější štítek. Viz pole událostí Whatnot.

Štítky pevné délky bez překvapení

Štítky 3 × 1 palec (včetně nastavení Munbyn BT320): použijte šířku 76.2 mm a pevnou délku 25.4 mm, pokud je směr podávání podél strany o délce 1 palec. Stejný materiál a orientaci nastavte v Předvolbách tisku Windows. Začněte textem 12–14 pt a otestujte dlouhé jméno kupujícího a název položky.

Boční okraje testu zarovnání vyznačují bezpečnou šířku po použití vybraného nastavení tisknutelné oblasti a bezpečných okrajů. Výška rámečku odpovídá testovacímu textu; neobkresluje celý štítek ani nesahá k fyzickým okrajům papíru.

  • Měřte ve směru podávání. Štítek 62 × 29 mm běžně používá šířku papíru 62 mm a pevnou délku štítku 29 mm.
  • Slaďte i Windows. V Předvolbách tisku ovladače tiskárny vyberte přesný materiál štítků, orientaci, detekci mezery/značky a chování řezačky.
  • Pevná znamená pevná. Social Stream nepřidává prostor pro posun účtenkového papíru k úloze s pevnou délkou. Příliš vysoký obsah se může podle ovladače oříznout nebo přetéct.
  • Otestujte nejdelší reálná data. Dlouhá jména diváků, varianty produktů, označení měn a více řádků potřebují více místa nebo menší písmo.
  • Omezení ovladače stále platí. Windows nebo ovladač tiskárny může omezovat velmi krátké vlastní stránky; Social Stream požaduje minimálně 20 mm.

Nápady pro stream

  • Tiskněte samolepky se jmény podporovatelů na zeď, rekvizitu, mapu nebo fyzickou tabuli průběhu.
  • Vytvářejte štítky objednávek zboží, zakázek, nápojů nebo vyzvednutí při příchodu nákupů.
  • Tiskněte losy nebo ústřižky přihlášek do soutěže; před tiskovou akcí použijte omezení četnosti a kontrolu způsobilosti.
  • Vytvářejte VIP jmenovky, přiřazení do týmů, žetony výzev nebo štítky milníků darů.
  • Vytiskněte krátkou frontu moderování nebo expedice pro producenta pracujícího vedle streamera.
Před tiskem osobních údajů se zamyslete. Vyhněte se adresám, e-mailům, platebním údajům a soukromým zprávám. Termopapír navíc působením tepla, světla a času bledne, takže není vhodný pro archivaci.

Běžná řešení

  • Žádná tiskárna se nezobrazuje: ověřte, že Windows dokáže vytisknout zkušební stránku, poté restartujte Social Stream a znovu vyberte Find printers.
  • Úloha hlásí úspěch, ale nic se netiskne: otevřete frontu Windows pro danou tiskárnu a zkontrolujte pozastavení, stav offline a chyby papíru, ovladače nebo portu.
  • Okraj je oříznutý: ponechte Use printable area zapnuté a zvětšete bezpečný okraj na dané straně.
  • Je příliš mnoho prázdného papíru: pro účtenky použijte pevnou délku 0, zmenšete spodní okraj a posun papíru nebo nastavte přesnou délku materiálu štítků.
  • Z jednoho štítku jsou dva: obsah je vyšší než pevný štítek nebo Windows používá nesprávnou velikost materiálu. Zkraťte text a zmenšete písmo, řádkování a okraje.
  • Test Flow používá nesprávnou tiskárnu: vyberte přepsání tiskárny v uzlu Print Thermal Label. Prázdná hodnota při přímém testování v editoru použije výchozí tiskárnu Windows.
