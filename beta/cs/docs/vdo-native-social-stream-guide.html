Nativní aplikace VDO.Ninja + Social Stream Ninja

Přijímejte chat Social Stream Ninja v nativní mobilní aplikaci VDO.Ninja.

Co toto nastavení dělá

Social Stream Ninja běží na počítači, zachytává chat z Twitch, YouTube, Kick nebo jiného zdroje a přeposílá zprávy do nativní aplikace VDO.Ninja v telefonu.

Telefon je přijímač. Nepřipojuje se přímo k Twitch ani k vaší chatovací platformě.

1. Spusťte zdroj Social Stream

  1. Otevřete Social Stream Ninja na počítači, který bude sbírat chat.
  2. Nastavte ID relace Social Stream Ninja.
  3. Otevřete potřebný zdroj platformy, například Twitch, YouTube, Kick nebo TikTok.
  4. Než začnete kontrolovat telefon, ověřte, že zprávy přicházejí do okna zdroje nebo doku Social Stream.

Režim zdroje Twitch WebSocket je v pořádku. Určuje jen to, jak SSN zachytává chat Twitch; je nezávislý na režimu Peer-to-Peer nebo Server v telefonu.

2. Otevřete nastavení vysílání v telefonu

  1. Otevřete nativní aplikaci VDO.Ninja.
  2. Vyberte režim kamery, obrazovky nebo mikrofonu, který chcete použít.
  3. Na obrazovce Publishing Settings přejděte dolů na Social Stream Ninja Integration.

3. Použijte stejné ID relace

Zapněte Social Stream a vložte úplně stejné ID relace, jaké SSN používá na počítači.

4. Vyberte jeden režim připojení

Režim telefonuNastavení SSNKdy použít
Peer-to-Peer Použijte běžný výstup SSN P2P. Nesměrujte chat pouze přes API server. Nejlepší první volba. Funguje přes běžné internetové připojení bez místního serveru.
Server Zapněte Odesílat zprávy chatu na server API v SSN Global > Mechanics. Použijte, pokud je P2P blokované nebo nespolehlivé.

Nekombinujte režimy. Pokud telefon používá Peer-to-Peer, ale SSN odesílá pouze přes režim Server, telefon chat nepřijme. Pokud telefon používá režim Server, ale SSN neodesílá chat na API server, telefon chat nepřijme.

5. Připojte se a otestujte

  1. Klepněte na Připojit (Connect) v nativní aplikaci VDO.Ninja.
  2. Odešlete skutečnou zprávu do chatu nebo použijte testovací zprávu SSN.
  3. Sledujte telefon. Pokud hlásí Social Stream není připojený (Social Stream not connected), zdroj chatu může stále fungovat, ale přenos z SSN do telefonu není připojený.

Běžná selhání

ProjevSkutečná příčinaŘešení
Chat se zobrazuje v SSN, ale telefon hlásí Social Stream not connected. Zdroj platformy funguje, ale výstupní cesta z SSN do telefonu není připojená. Zkontrolujte ID relace, režim připojení a nastavení výstupu SSN.
Na jednom počítači to funguje, ale na druhém se stejným ID relace ne. V režimu Peer-to-Peer SSN používá ID relace jako ID streamu VDO.Ninja. Stejné ID může současně publikovat pouze jedna instance SSN. Zavřete nebo vypněte Social Stream na prvním počítači a poté restartujte SSN na druhém; případně použijte jiné ID relace.
Režim Server nikdy nepřijímá chat. Telefon naslouchá na kanálu API serveru SSN, ale SSN tam chat nepublikuje. Zapněte Odesílat zprávy chatu na server API v SSN Global > Mechanics.
Okno zdroje zobrazuje chat, ale nic se nepřeposílá. Zdroj může být v režimu pouze pro odpovědi nebo bez zachytávání. Vypněte Bot pouze pro odpovědi (bez zachytávání) pro daný zdroj.
Vzdálený telefon nemůže používat režim místního serveru. Režim místního serveru je omezený na počítač nebo místní síť a obvykle není dostupný přes firewall. Použijte Peer-to-Peer nebo veřejný režim Server se zapnutým výstupem chatu SSN na API server.

Emoty BTTV, 7TV a FFZ

Před přeposíláním chatu zapněte v SSN možnosti emotů BTTV, 7TV nebo FFZ. SSN zprávu obohatí ještě před doručením do telefonu.

Zobrazení chatu v nativní aplikaci může u obrázkových emotů stále ukazovat náhradní text, pokud daná sestava aplikace nevykresluje obrázky uvnitř chatu.
