Choose the right starting page

ticker.html displays ticker content sent by SSN. It is separate from a chat-scrolling theme such as themes/overlay-ticker-news.html, which belongs in the chat design guide.

Download and keep the file structure

  1. Download the source ZIP and extract it. These guides use the beta source; keep the files from one download together.
  2. Kopírovat ticker.html na my-ticker.html beside the original. If choosing a different page or theme, keep its copy in that file's original folder.
  3. Open the copied HTML and its referenced CSS/JS in your editor or AI tool. Add supplied artwork/fonts to the same project and use relative paths. Start with CSS overrides; include the renderer when changing generated markup.

The following files help you find the design and behavior. This is a reading list, not a complete dependency bundle: keep the extracted folder intact, including images, fonts, scripts, and any data files.

Connect your copy and open it in OBS

Start SSN and make the original generated overlay URL work first. The session= value connects to that SSN session; it is not your channel name or this file's name. Keep SSN, the relevant feature, and its data sources running.

  1. Drag your edited HTML file into Chrome or Edge. Copy its address from the address bar; it starts with file:///.
  2. Copy everything from ? onward in your working SSN overlay link and add it to the end of that file address. Keep all settings, including the session, password, and any # ending.
  3. Open the result in a browser, then set an OBS Browser Source's URL to the same address with Místní soubor unchecked. Match the source dimensions to your intended design.

For the starting file above, the local address looks like this; your actual link may contain additional required options:

file:///C:/SSN/social_stream-beta/my-ticker.html?session=YOUR_SESSION

Use the actual file address on your computer. OBS saves it with the source; keep the downloaded folder in the same place. After saving design changes, refresh the Browser Source. The shared setup guide includes Mac examples and an optional launcher for the Local file checkbox.

Where to change the design

Change the ticker rail, typography, separators, brand badge, height, and transition style. Preserve the existing text measurement and repeated segments used for continuous scrolling; hard-coded widths often cause a jump when text changes.

The ticker's content arrives in its ticker state, not as any arbitrary chat message. Keep scroll/rotate settings and whitespace choices from the generated link. Test the effect of font loading on measurements and line wrapping.

Copy this AI prompt

Give the AI your copied source files and reference artwork. Replace the bracketed details. Keep the input-safety instructions in the prompt.

Colors/fonts/assets: [supply hex colors and local filenames].

Restyle ticker.html as [design]. Preserve ticker-state updates, scroll/rotate modes, speed, separators, spacing, and content replacement. Keep continuous scrolling seamless after font loading or text changes. Render incoming ticker strings as text, not executable HTML. Do not replace the ticker feed with a generic chat listener.

Test this overlay type

Use a preview or test setup first. The test-message guide explains how to send fictional payloads through SSN; a test submitted to your production session can trigger its existing automations.

  1. Set ticker text in SSN and confirm it appears in the copied page. Change the text while it is scrolling.
  2. Try one short entry, multiple entries, an empty ticker, long text, punctuation, and a non-Latin message.
  3. Check a complete scroll/rotation cycle in OBS for clipping, pauses, and duplicated gaps at the intended source width.

Also run the input-rendering checks against the render paths you changed. After saving edits, refresh the OBS Browser Source between rehearsals and repeat the visible interaction. Browser previews do not establish live capture or OBS behavior.
