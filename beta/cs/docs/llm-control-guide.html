Místní ovládací API a MCP

Umožněte nástroji AI nebo skriptu na stejném počítači prohlížet a ovládat desktopovou aplikaci Social Stream Ninja.

Kdy vybrat tuto službu

Desktopová aplikace→Místní ovládací API→Klient MCP

Místní ovládací API použijte, pokud software na počítači SSApp potřebuje schválené ovládání aplikace a zdrojů. Přibalený adaptér MCP použijte, pokud má kompatibilní klient AI získat toto ovládání jako nástroje.

Je oddělené od Soubor > Zapnout místní server (File > Enable Local Server), který spouští přenos WebSocket pro stránky Social Stream. Viz Vysvětlení místních serverů a služeb pokud si nejste jisti, kterou službu potřebujete.

1. Stáhněte běžnou desktopovou aplikaci

Nainstalujte aktuální vydání Social Stream Ninja ze stránky stažení pro Windows, macOS nebo Linux. Podpora MCP je součástí stažené aplikace. Nepotřebujete zdrojový repozitář, Node, Python ani samostatný balíček MCP.

2. Zapněte místní ovládání AI

  1. Otevřít Soubor > Lokální AI / automatizace (File > Local AI / Automation).
  2. Zapněte Místní ovládací API a nechte aplikaci restartovat.
  3. Vraťte se do stejné nabídky a vyberte Kopírovat nastavení MCP (Copy MCP Setup).
  4. Vložte zkopírované JSON do nastavení MCP používaného nástrojem AI a potom tento nástroj restartujte.

Zkopírované nastavení obsahuje přesnou cestu nainstalovaného spustitelného souboru, port a argumenty pro danou platformu. Stažený spustitelný soubor Social Stream Ninja spustí vlastní nenáročný adaptér MCP, když jej klient AI spustí s --ssapp-mcp.

3. Nechte MCP zjistit možnosti

Po připojení klient MCP automaticky požádá Social Stream Ninja o nástroje. Adaptér načte aktuální schopnosti běžící aplikace a poskytne LLM schémata podporovaných nástrojů, verze aplikace/API a provozní pokyny. Agent by měl nejprve zavolat capabilities, potom status a používat stabilní ID zdrojů vrácená aplikací.

Běžné použití MCP nevyžaduje získávání dat z webu ani instalaci dovednosti. Uživatel může jednoduše požádat připojeného agenta, aby Social Stream Ninja prohlédl nebo ovládal.

Dostupné místní ovládání

  • Vypisovat, prohlížet, přidávat, aktualizovat a odstraňovat zdroje.
  • Spustit, zastavit nebo znovu načíst jeden zdroj nebo filtrovanou sadu.
  • Měnit viditelnost zdrojů, stav ztlumení a režim připojení.
  • Číst a aktualizovat podporovaná globální nastavení vrácená zjišťováním schopností.
  • Číst stav aplikace, relace, zdrojů, procesů, zachytávání a místních médií.
  • Sledovat omezený proud zachycených událostí zdrojů a obnovitelné události operací nebo stavu.
  • Zachytávat a bezpečně prohlížet podporované stránky zdrojů a okna patřící SSApp.
  • Provádět schválené interakce se stránkami, okny a dialogy s potvrzením.
  • Znovu načíst nebo řádně ukončit aplikaci s výslovným potvrzením.

Rozhodující jsou schopnosti běžící aplikace. Starší verze mohou zpřístupňovat méně ovládacích funkcí.

Přímý přístup HTTP pro místní skripty

Skripty na stejném počítači mohou používat API místní smyčky bez MCP. Naslouchá pouze na 127.0.0.1 a nevyžaduje token.

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

Používejte oznámené schopnosti místo předpokladu, že každá verze aplikace má stejné ovládání. Příklady curl pro zkopírování a vložení, které přidají, vypíšou, spustí, prohlédnou a zastaví zdroj, najdete v průvodci serverovým HTTP API.

Místní AI na Ubuntu VPS

API může sloužit také nástroji AI běžícímu na stejném linuxovém serveru jako instance SSApp bez grafického rozhraní. Ponechte jej vázané na místní smyčku a jako příkaz MCP použijte stažený AppImage.

Sledování Provoz Social Stream Ninja bez grafického rozhraní pro Xvfb, trvalé profily, spouštěcí příkazy, systemd a samostatnou cestu dálkového ovládání. Obsahuje také Konfigurace MCP pro Linux AppImage , kterou můžete vložit do klienta běžícího na VPS.

Volitelná dovednost agenta

Agenti podporující instalovatelné dovednosti mohou stáhnout úplnou dovednost Control Social Stream. Můžete také přečíst její pokyny online, s referenční příručka API a protokolu verzí. Dovednost přidává pokyny k pracovním postupům, ale pro připojení MCP není potřeba.

Strojově čitelné odkazy pro zjišťování možností jsou uvedeny také v llms.txt.

Pouze místně

Toto rozhraní je určeno pro AI a automatizaci běžící na stejném počítači jako SSApp. Nezpřístupňujte je ani netunelujte jako cloudové API dálkového ovládání. Vzdálení uživatelé a Stream Deck mají používat stávající připojení WebRTC nebo WebSocket Social Stream. Místní API neposkytuje spouštění libovolného JavaScriptu, soubory cookie, tajné přihlašovací údaje, neomezená nastavení ani nezpracovaný přístup k souborovému systému.

Úplné koncové body, schémata příkazů, zjišťování verzí a bezpečnostní hranice najdete v technické referenční příručce automatizace.
