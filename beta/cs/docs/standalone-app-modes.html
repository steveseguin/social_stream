Režimy samostatné aplikace

Seznamte se s okny zdrojů, standardním režimem, WebSocketem a předvolbami TikToku.

K čemu aplikace slouží

Desktopová aplikace spravuje okna zdrojů Social Stream mimo váš běžný prohlížeč. Pomáhá s organizací zdrojů a některými problémy omezování karet na pozadí. Není totožná s Chromem a automaticky nesdílí vaše přihlášení ani cookies z Chromu.

Názvy režimů

Některé zdroje mají více režimů připojení. Vhodný režim závisí na platformě, stavu přihlášení a na tom, zda potřebujete podrobnější události, nebo jednoduché zachytávání stránky.

RežimJednoduché vysvětleníKdy použít
StandardAplikace otevře běžnou stránku platformy nebo zdroje a čte vykreslenou stránku.Potřebujete nejjednodušší zachytávání viditelné stránky, přihlášení nebo ruční ověření.
WebSocket/APIZdroj se připojuje přes API platformy, socket nebo stránku zdroje Social Stream.Platforma jej podporuje a chcete spolehlivější práci na pozadí nebo podrobnější data událostí.
Dotazování / starší režimKompatibilní způsob připojení, který kontroluje aktualizace namísto preferovaného živého socketu.Novější konektor selhává nebo je potřeba náhradní řešení pro danou platformu.
TikTok AutoAplikace vybere nejlepší způsob připojení TikToku a při selhání může přejít na náhradní.Nejste si jistí, jaký režim TikToku použít.

Kdy použít standardní režim

  • Platforma funguje, když vidíte živou stránku nebo samostatný chat.
  • Web vyžaduje přihlášení, vyřešení výzvy nebo otevřený viditelný panel chatu.
  • Porovnáváte chování aplikace s rozšířením Chrome.
  • Potřebujete nejznámější postup řešení problémů: otevřít stránku, vidět chat, otestovat dok a pak OBS.

Standardní režim může selhat, pokud platforma změní rozložení stránky, zablokuje vložené prohlížeče či prohlížeče aplikací, vyžádá CAPTCHA nebo skryje chat za přihlášením.

Kdy použít režim WebSocket nebo API

  • Zdroj výslovně podporuje režim WebSocket/API.
  • Chcete zdroj, který dokáže lépe fungovat na pozadí.
  • Potřebujete skupiny událostí, které běžné čtení stránky nemusí zpřístupnit.
  • Dokážete nastavit tokeny poskytovatele, oprávnění účtu, rozsahy API nebo stránku zdroje.

Režim WebSocket/API není vždy lepší. Pokud selhává ověřování, tokeny, přístup k poskytovateli nebo API platformy, může být standardní režim rychlejším testem.

TikTok v aplikaci

TikTok v desktopové aplikaci nemá jediný režim. Před řešením problémů si vždy poznamenejte aktivní předvolbu.

Způsob připojení TikTokuPoužitíBěžná příčina selhání
AutomatickyPrvní volba pro většinu uživatelů.Aplikace může přejít na náhradní režim, proto sledujte stavový text.
StandardZachytávání viditelné stránky TikToku.Přihlášení, CAPTCHA, přesměrovaná stránka nebo skrytý chat.
Místní podepisováníZpůsoby čtení a podpory odpovědí přímo v aplikaci.Relace a cookies TikToku v aplikaci musí být platné.
Dotazování / kompatibilitaNáhradní režim při selhání socketu nebo podepisování.Méně podrobné údaje než u preferovaného konektoru.
Proxy nebo vlastní podepisováníPokročilá nastavení.Dostupnost poskytovatele, API klíč, ID místnosti nebo limity požadavků.

Při běžném prvním pokusu přidejte TikTok, ponechte předvolbu Auto, aktivujte zdroj a sledujte stavový text aplikace.

Co ověřit před OBS

  1. Ověřte, že je zdroj v aplikaci aktivovaný.
  2. Pokud platforma vyžaduje přihlášení, ověřte jej v okně zdroje.
  3. Ověřte, že dok přijímá chat se stejným ID relace.
  4. Teprve až bude dok fungovat, přidejte nebo obnovte URL překryvu OBS.
  5. Pokud Chrome funguje, ale aplikace ne, pamatujte, že relace aplikace a Chromu jsou oddělené.

Běžná řešení

  • Chrome je přihlášený, ale aplikace ne: přihlaste se k platformě uvnitř okna zdroje aplikace nebo zachytávejte pomocí rozšíření.
  • Zdroj hlásí aktivní stav, ale chat nepřichází: zkontrolujte režim, okno zdroje, URL živého vysílání či uživatelské jméno a relaci doku.
  • Aplikace používá nesprávné soubory zdrojů: zkontrolujte, zda aplikace používá soubory Social Stream z balíčku, mezipaměti, vzdáleného serveru, bety, stabilní verze nebo místního umístění.
  • TikTok nefunguje: zaznamenejte aktuální předvolbu, stavový text, verzi aplikace a zda zdroj přešel do náhradního režimu.
  • OBS je prázdné: nejprve otestujte dok. Pokud je prázdný, problém zatím není v OBS.
