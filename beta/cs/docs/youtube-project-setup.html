Nastavení projektu YouTube

Jak vytvořit projekt Google Cloud pro desktopovou aplikaci SSN Standalone bez oslabení zabezpečení klíče.

Přehled

K čemu toto nastavení slouží

Použijte pouze tehdy, pokud chcete, aby desktopová aplikace využívala vaši vlastní kvótu YouTube API místo výchozího sdíleného projektu Social Stream Ninja.

Důležité: všechny tři níže uvedené hodnoty musí pocházet ze stejného projektu Google Cloud:
  • OAuth Client ID
  • OAuth Client Secret
  • Klíč API
Nezaměňujte tato dvě pole v Google Cloud:
  • Povolené originy JavaScriptu (Authorized JavaScript origins) musí obsahovat pouze origin bez cesty.
  • Povolené URI přesměrování (Authorized redirect URIs) musí obsahovat celou /sources/websocket/youtube.html cestu.
Krok 1

Vytvoření projektu

  1. Otevřete Google Cloud Console.
  2. Vytvořte nový projekt nebo vyberte vyhrazený stávající projekt.
  3. Zapněte YouTube Data API v3.
  4. Otevřete nastavení obrazovky souhlasu OAuth.
  5. Pokud je aplikace v testovacím režimu, přidejte svůj účet Google jako testovacího uživatele.
Krok 2

Vytvoření klienta OAuth

  1. Vytvořte přihlašovací údaje.
  2. Vyberte ID klienta OAuth (OAuth client ID).
  3. Použijte typ Webová aplikace (Web application).
  4. Přidejte přesné originy a URI přesměrování uvedené níže.
Pole Hodnota
Povolené originy JavaScriptu (Authorized JavaScript origins) http://localhost:8181
http://localhost:8080
Povolené URI přesměrování (Authorized redirect URIs) http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
Krok 3

Bezpečné vytvoření API klíče

  1. Vytvořte API klíč (API key) ve stejném projektu.
  2. Otevřete omezení daného klíče.
  3. V části Omezení API (API restrictions), omezte ho na YouTube Data API v3 pouze.
  4. Pro desktopovou aplikaci nepoužívejte omezení podle HTTP referrer.

Pravidlo desktopové aplikace: Omezení podle HTTP referreru jsou určena pro stránky prohlížeče, ne pro tento místní postup ověřování desktopové aplikace.

Krok 4

Vložení hodnot do desktopové aplikace

  1. Otevřete stránku zdroje YouTube v desktopové aplikaci.
  2. Vložte OAuth Client ID, OAuth Client Secret, a Klíč API.
  3. Klikněte na Uložit.
  4. V případě potřeby se odhlaste.
  5. Klikněte na Přihlásit se přes YouTube (Sign in with YouTube).
  6. Dokončete přihlášení Google v okně externího prohlížeče.
Očekávaný výsledek: pokud vše odpovídá, přihlášení Google funguje a desktopová aplikace používá váš uložený projekt YouTube místo výchozího sdíleného.
Zabezpečení

Bezpečné uchovávání přihlašovacích údajů

  • S Client Secret a API klíčem zacházejte jako s citlivými údaji.
  • Nevkládejte je do snímků obrazovky, záznamů chatu ani hlášení chyb.
  • Pokud je omylem zveřejníte, vyměňte je nebo odstraňte.
  • Při experimentování používejte vyhrazený testovací projekt.
  • Po dokončení testování odstraňte dočasné projekty.
Řešení potíží

Běžné problémy

  • redirect_uri_mismatch: URI přesměrování se přesně neshoduje.
  • invalid_client: Client ID a Client Secret si neodpovídají.
  • quotaExceeded: projekt vašeho API klíče vyčerpal kvótu YouTube.
  • Ověření účtu selhalo: ve starších sestaveních k tomu mohlo dojít, pokud OAuth a API klíč pocházely z různých projektů.
