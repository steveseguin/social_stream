Použijte svůj vzhled chatu StreamElements

Importujte vlastní chatovací widget, prohlédněte si jej se Social Stream Ninja a stáhněte soubor pro OBS.

Co funguje?

Importér je určen pro vlastní chatovací widgety vytvořené pro StreamElements nebo Streamlabs, včetně chatovací části balíčku motivu. Potřebujete zdrojové soubory widgetu. Neimportuje celý účet StreamElements ani motiv z URL překryvu.

Použijte buď Desktopovou aplikaci SSN pro Windows nebo rozšíření Chrome pro zachytávání chatu. Importovaný vzhled tento chat zobrazuje v OBS. Kompatibilita závisí na widgetu; funkce účtu jako cíle, věrnostní systém, obchody a upozornění mohou vyžadovat ruční převod.

1. Získejte soubory widgetu

Začněte původním ZIPem nebo složkou od autora. Hledejte HTML, CSS a JavaScript, případně JSON s poli a daty, obrázky a písma. Pokud balíček obsahuje více návrhů, vyberte jeden chatovací widget.

Máte jen instalační odkaz? Požádejte autora o zdrojové soubory chatovacího widgetu nebo použijte kód dostupný v editoru vlastního widgetu StreamElements. Samotný snímek obrazovky, video ani URL zdroje Prohlížeč nelze převést.

Kód widgetu mám v editoru StreamElements

Otevřete editor kódu vlastního widgetu. Každou dostupnou část uložte jako samostatný soubor prostého textu: html.txt, css.txt, js.txt, fields.txt a data.txt. Zkopírujte obsah bez přidávání formátování a změn JSON. Pokud datový soubor není dostupný, importér použije výchozí hodnoty z polí.

Vyberte všechny tyto soubory společně pomocí tlačítka Vybrat soubory. Přiložte všechny místní obrázky a písma; Vybrat složku zachovává cesty složek. Viz Přehled editoru kódu StreamElements pro strukturu kódu a polí.

Importujte jen kód, kterému důvěřujete: JavaScript widgetu běží v náhledu i staženém překryvu.

2. Otevřete importér

V nabídce SSN pod částí Hotové vzhledy překryvů chatu, vyhledejte možnost Importovat vzhled chatu StreamElements / Streamlabs. Tím se vyplní vaše aktuální relace. V nabídce můžete také vyhledat StreamElements nebo otevřít importér přímo.

Použijte Vybrat ZIP, Vybrat soubory nebo Vybrat složku. Po zpracování souborů se načte ukázkový náhled. Zkontrolujte případná varování importu; použijte Pokročilý výběr souborů pokud byly rozpoznány nesprávné zdrojové soubory.

3. Připojte a zobrazte náhled

  1. Nechte SSN spuštěné a ověřte, že se v jeho doku chatu objeví skutečná zpráva.
  2. V importéru zkontrolujte ID relace SSN / ID vysílání. Pokud je pole prázdné, zkopírujte hodnotu z části Možnosti relace v SSN. Nejde o vaše uživatelské jméno na Twitchi nebo YouTube.
  3. Pokud používáte heslo relace, zadejte jej.
  4. Použijte Ukázkový náhled pro ukázkové zprávy a pak Živý náhled a pošlete novou zprávu do chatu svého vysílání.
  5. Pokud Historie zpráv se objeví, upravte časované odebírání nebo maximální počet zpráv.

Ukázkový náhled funguje bez relace a používá pouze vzorové zprávy. Živý náhled potřebuje chat přicházející z SSN; prázdný náhled sám o sobě neznamená selhání připojení.

4. Stáhněte a přidejte do OBS

  1. Klikněte na Stáhnout HTML pro OBS a uložte jej do trvalého umístění.
  2. V OBS přidejte Zdroj prohlížeče (Browser Source), zapněte Místní soubor, a vyhledejte tento HTML soubor.
  3. Nastavte šířku a výšku oblasti chatu a pošlete další zprávu pro ověření.

Relace je již vložena; v OBS není potřeba upravovat URL. Stažený soubor použijte jako zdroj Prohlížeč. SSN i zdroje zachytávající chat nechte spuštěné; importér a StreamElements můžete zavřít.

Exportovaný soubor obsahuje ID relace a případné heslo. Uchovávejte jej v soukromí. Pokud později chcete změnit relaci, heslo nebo nastavení widgetu, znovu importujte původní soubory, stáhněte náhradu a obnovte zdroj OBS.

Pokud něco nefunguje

  • Kód widgetu nebyl nalezen: použijte původní zdrojové soubory. Obrázky, samotná pole či data ani dříve převedené soubory SSN nejsou zdrojovými soubory widgetu.
  • Ukázka je prázdná nebo vypadá nesprávně: zkontrolujte HTML/CSS/JS v Pokročilém výběru souborů. Dodejte odpovídající soubory polí a dat i všechny prostředky.
  • Ukázka funguje, živý náhled je prázdný: pošlete novou zprávu, zkontrolujte dok SSN a ověřte shodu ID relace a hesla.
  • Živý náhled funguje, OBS je prázdné: zkontrolujte vybraný místní HTML soubor, rozměry a viditelnost zdroje Prohlížeč a poté obnovte jeho mezipaměť.
  • Chybějí písma nebo obrázky: zkontrolujte souhrn exportu. Vzdálené prostředky, které se nepodařilo vložit, stále potřebují dostupnou URL a přístup k internetu.
  • Zprávy mizí: upravte historii zpráv, pokud ji widget nabízí. Některé widgety řídí odebírání vlastním JavaScriptem.
  • API účtu nebo pluginy nefungují: některé widgety vyžadují úpravu kódu. Použijte pokyn pro převod v importéru nebo požádejte o pomoc s původními soubory widgetu a snímkem problému, bez sdílení přihlašovacích údajů relace.

Další možnosti: vestavěné vzhledy chatu, vlastní CSS, nebo řešení problémů s OBS.
