Безпечні оновлення, резервні копії та відновлення

Створіть одну придатну резервну копію перед оновленням, перевстановленням, скиданням або зміною каналів випуску.

Правило безпеки

  1. Спочатку експортуйте налаштування. Збережіть експортований файл поза папкою застосунку або розпакованого розширення.
  2. Не видаляйте розширення браузера лише заради оновлення. Видалення прибирає збережені налаштування цього встановлення розширення.
  3. Зберігайте одну робочу копію. Не перезаписуйте єдину резервну копію під час усунення проблем пошкодженого налаштування.
  4. Після оновлення перезавантажте сторінки джерел. Повторно відкривайте згенеровані посилання дока/оверлеїв і оновлюйте збережені браузерні джерела OBS, коли їхні URL змінилися.

Резервна копія розширення браузера (Chrome, Edge, Firefox)

  1. Відкрийте панель керування Social Stream Ninja й прокрутіть до Загальні налаштування та інструменти.
  2. Відкрити Експорт / імпорт.
  3. Виберіть Експортувати на диск, виберіть безпечне місце та збережіть .data розширення імені файлу.
  4. Переконайтеся, що збережений .data файл наявний, перш ніж щось оновлювати, видаляти чи скидати.
  5. Використовуйте Імпортувати налаштування , щоб пізніше відновити цей файл.

Розширення з Chrome Web Store та інших магазинів: оновлення зазвичай установлюються поверх наявної версії та зберігають налаштування. Не видаляйте й не перевстановлюйте розширення лише для примусового оновлення.

Ручне оновлення розпакованого розширення: завантажте й розпакуйте нову збірку, замініть старі файли розширення та виберіть Перезавантажити (Reload) на chrome://extensions. Залиште розпаковану папку на місці та перезавантажте відкриті вкладки чату. Див. ручне встановлення.

Тримайте резервні копії приватними. Експорт налаштувань може містити пароль сесії, URL вебхуків або джерел та іншу приватну конфігурацію. Не публікуйте його.

Резервна копія настільного застосунку

Резервна копіяМенюПризначення
Резервна копія налаштувань File → Settings Backup → Export Settings… Звичайні оновлення, перенесення налаштувань і початкове відновлення. Імпорт через Імпортувати налаштування… (Import Settings…).
Перенесення повної сесії File → Advanced Full Session Transfer Перенесення або збереження всього профілю настільного застосунку, включно з локальними сесіями та станом входу. Створює зашифрований .ssappbk файл.

Звичайний експорт налаштувань — правильний вибір для більшості оновлень. Full Session Transfer доступний лише в настільному застосунку; він більший і замінює цільовий профіль під час відновлення. Застосунок спочатку зберігає pre-restore-* копію поточного профілю.

Настільний застосунок не оновлюється автоматично. Установлення новішої версії поверх наявної має зберегти наявний профіль. Усе одно спочатку експортуйте, особливо перед перевстановленням, переходом між портативною та встановленою збірками, зміною каналів або спробою скидання.

Якщо налаштування вже зникли

  1. Припиніть скидання й перевстановлення. Подальші зміни можуть перезаписати найкращу копію для відновлення.
  2. Якщо застосунок або розширення ще має корисний стан, експортуйте його перед будь-якими іншими діями.
  3. Імпортуйте найновішу відому справну .data або .json резервну копію налаштувань.
  4. Для резервної копії всього профілю настільного застосунку використовуйте Розширене перенесення повної сесії.
  5. Якщо пошкоджено лише список джерел настільного застосунку, спробуйте Очистити всі джерела (Clear All Sources). Це вужча дія, ніж Full Reset, призначена для збереження сесій, cookie й налаштувань.
  6. Використовуйте Full Reset лише після створення резервної копії або погодження з повним локальним очищенням.

Якщо експорту немає, але є старий URL дока, помічник відновлення з посилання дока може відтворити ID сесії, пароль і налаштування з URL, знайдені в цьому посиланні. Він не може відновити налаштування чи облікові записи джерел, яких ніколи не було в URL.

Що охоплює звичайна резервна копія налаштувань

Поточний тест перенесення налаштувань настільного застосунку перевіряє повний цикл для кешованого стану Social Stream і вибраних налаштувань застосунку. Експорт розширення браузера включає ID сесії, необов’язковий пароль, стан і об’єкт налаштувань.

  • Налаштування джерел і глобальні налаштування, представлені у збереженому стані.
  • ID сесії Social Stream і необов’язковий пароль сесії.
  • Вибрані параметри настільного застосунку, які він використовує.

Резервна копія .data розширення браузера не містить cookie браузера або сесій входу на сайти. У настільному застосунку звичайний експорт налаштувань також не копіює всі cookie чи входи; використовуйте доступний лише в настільному застосунку Full Session Transfer, коли потрібно перенести весь профіль.
