Термопринтери та етикетки стріму

Перетворюйте покупки, донати й події чату на фізичні чеки, наліпки, квитки або етикетки видачі.

Налаштуйте за 6 кроків

Перед початком: потрібен окремий застосунок Windows. Принтер має відображатися як звичайний принтер Windows. Social Stream друкує через драйвер Windows і не надсилає сирі команди ESC/POS, ZPL або SDK виробника.
  1. Підключіть принтер через USB, увімкніть його й установіть драйвер Windows. Надрукуйте тестову сторінку Windows для перевірки.
  2. У Social Stream відкрийте Загальні налаштування й інструменти → Механіка — З'єднання та інтеграції → Керування принтером.
  3. Натисніть Знайти принтери. Виберіть принтер за назвою у Windows.
  4. Уведіть Ширина паперу (мм). Зазвичай це 58, 80, або 62.
  5. Залиште Фіксована довжина етикетки на 0 для чекового паперу. Для висічних етикеток уведіть довжину в мм за напрямком подавання паперу.
  6. Натисніть Тестовий друк. Якщо край обрізано, збільште безпечний відступ із цього боку й перевірте знову.

Безпечні відступи по 2 мм ліворуч і праворуч підходять багатьом недорогим чековим принтерам 58 мм. Реальну область друку визначає драйвер, тож залиште Використовувати область друку (Use printable area) вибраним, якщо ви не перевірили інший варіант.

24 пт · жирний · по центру
  1. Відкрийте Редактор потоків подій і створіть новий потік.
  2. Додайте Донат / чайові тригер. Установіть Мінімальна сума якщо друкувати потрібно лише великі пожертви.
  3. Додайте Надрукувати термоетикетку (Print Thermal Label) (у розділі інтеграцій) і підключіть до нього тригер.
  4. Введіть {username}, новий рядок, а потім {donation}. Виберіть розмір і товщину шрифту, вирівнювання й кількість копій.
  5. Залиште перевизначення принтера й фіксованої довжини в дії порожніми або 0. Буде використано ваші налаштування Printer Control.
  6. Натисніть Перевірити потік (Test Flow). Уведіть назву й увімкніть Містить донат (Has Donation), додайте суму й запустіть. Буде надруковано справжню етикетку.

Інші корисні підстановки: {message}, {source}, {donationAmount}, і {counterValue}. Значення, створені попередніми кроками потоку, також працюють.

Дивіться поля торгових подій для складу даних кожного продажу.

Покупця — жирним, товар — звичайним

  1. Установіть Товщина до Виділений текст.
  2. Уведіть цей текст етикетки:
**{username}**
{subtitle}
  • Лише текст усередині ** стає жирним. HTML і JavaScript не потрібні.
  • Використовуйте одинарні фігурні дужки. У продажах назва товару міститься в {subtitle}. Кількість може бути в {meta.commerce.quantity}.
  • Якщо попередній крок створює buyer, використовуйте **{buyer}** натомість.
  • Shopify та eBay не передають ім'я покупця. Використовуйте для них лічильник замовлень або етикетку лише з товаром.
  • Етикетки з налаштуванням «Усе жирним» або «Звичайний» зберігають вигляд.
Для авторів потоків: результати друку й номери покупців

Дія додає meta.thermalPrintResult.successа в разі збою — помилку або код для наступних кроків. Успіх означає надсилання завдання до Windows, а не вихід паперу. Перед повтором перевірте чергу друку Windows, інакше можливі дублікати етикеток.

Лічильник нумерує покупки, а не унікальних покупців. Щоб усі покупки однієї людини отримували однаковий номер, потрібен окремий список покупець–номер зі скиданням на початку кожного ефіру. Поле причини в User Memory — звичайний текст, а не лічильник номерів покупців.

Етикетки товарів Whatnot

Завантажити приклад потоку Whatnot. Друкує ім'я покупця жирним, назву товару й ID замовлення, якщо він є. У разі збою оплати друкує окрему ОПЛАТА НЕ ВДАЛАСЯ етикетку з тими відомостями, які є в сповіщенні.

  1. В окремому застосунку налаштуйте Керування принтером (Printer Control) і виконайте тестовий друк.
  2. Відкрийте Редактор потоків подій, натисніть Імпортуватиі виберіть завантажений файл.
  3. Виберіть Whatnot: етикетки товарів + попередження про оплату. Перевірте обидві дії друку. Вони використовують принтер і довжину етикетки з Printer Control.
  4. Увімкніть потік і збережіть. Після імпорту він вимкнений.
  5. Залиште джерело Whatnot відкритим з увімкненим захопленням подій ефіру.
Етикетка продажу не означає оплату. Кожне сповіщення друкується після отримання. Потік не чекає оплати, не виправляє стару етикетку й не видає номери покупців. Відсутні поля залишаються порожніми. Сповіщення про помилку без покупця, товару чи даних замовлення не дає визначити потрібну етикетку.
Як працює приклад потоку

Використовує Event Type (Advanced) → Custom Event для product_sold і payment_failedіз фільтром Whatnot. Ставки й сповіщення про завершення аукціону не друкуються. Див. поля подій Whatnot.

Виберіть папір

Рулон чеків

Для квитанцій покупок, талонів черги й чеків будь-якої довжини. Залиште фіксовану довжину етикетки рівною 0.

Безперервний рулон наліпок

Для клейких смужок з ім'ям будь-якої довжини. Працює як чековий папір, але різання має виконувати принтер або драйвер.

Висічені етикетки

Для однакових бейджів і товарних етикеток. Задайте точну фіксовану довжину й виберіть той самий матеріал у налаштуваннях друку Windows.

Бічні межі тестового друку показують безпечну ширину. Висота залежить від тестового тексту. Контур усієї етикетки не малюється.

Ідеї для ефіру

  • Наліпки з іменами тих, хто підтримав, для стіни, реквізиту, карти або дошки прогресу.
  • Етикетки мерчу, індивідуальних замовлень, напоїв або видачі після надходження замовлень.
  • Лотерейні квитки. Перед друком додайте обмеження частоти й перевірки права участі.
  • VIP-бейджі, вибір команд, жетони завдань або етикетки етапів.
  • Короткий список завдань для продюсера поруч із вами.
Не друкуйте особисті дані. Не включайте адреси, email, платіжні дані й приватні повідомлення. Термопапір також вицвітає від тепла, світла й з часом.

Усунення несправностей

ПроблемаЩо спробувати
Принтер не відображаєтьсяПереконайтеся, що Windows друкує тестову сторінку. Перезапустіть Social Stream і знову натисніть «Знайти принтери».
Повідомляється про успіх, але друку немаєВідкрийте чергу принтера у Windows. Перевірте паузу, автономний режим, помилки паперу, драйвера або порту.
Край обрізаєтьсяЗалиште використання області друку ввімкненим. Збільште безпечний відступ із цього боку.
Забагато порожнього паперуДля чеків задайте фіксовану довжину 0. Зменште нижнє поле й додаткове протягування. Для етикеток задайте точну довжину.
Одна етикетка друкується на двохТекст вищий за етикетку або у Windows задано неправильний розмір матеріалу. Зменште текст, шрифт, інтервали чи поля.
Тест потоку використовує не той принтерВиберіть перевизначення принтера в кроці друку термоетикетки. Якщо поле порожнє, тест у редакторі використовує типовий принтер Windows.
