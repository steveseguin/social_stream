Інтеграція чату кількох платформ

Спілкуйтеся з глядачами на всіх своїх платформах одночасно. Social Stream Ninja об’єднує повідомлення чату з десятків платформ в одну зручну панель.

  • Двосторонній живий чат із Facebook, YouTube, Twitch, Zoom та іншими
  • Для більшості платформ не потрібні вхід або ключі API
  • Піктограми джерел кількох каналів для розрізнення платформ
  • Автоматичне пересилання повідомлень між платформами

Оверлей вибраних повідомлень чату

Виділяйте найкращі повідомлення аудиторії просто на трансляції за допомогою красивих оверлеїв, які можна налаштувати.

  • Вибір повідомлень через доковану панель
  • Автоматичний або ручний вибір повідомлень
  • Налаштування CSS для точного поєднання зі стилем трансляції
  • Параметри анімації, включно з ефектами згасання й зсуву
  • Черга повідомлень для впорядкованого виділення

Команди бота й автовідповіді

Створюйте автоматичні взаємодії з аудиторією через власні команди й відповіді.

  • Вбудовані команди для поширених взаємодій
  • Власна логіка команд у програмованому файлі плагіна
  • Автоматичні привітання й відповіді
  • Фільтрація й модерація повідомлень

Інтеграція ШІ та LLM

Виберіть голосового співведучого, чат-бота, браузерного компаньйона або спеціалізовані інструменти обробки ШІ, не прив’язуючи решту трансляції до одного постачальника.

  • Голосовий співведучий, який може чути вас і отримувати вибрані повідомлення живого чату
  • Основний і приватний чат-боти з власними інструкціями та правилами запуску
  • Локальні моделі або хмарні постачальники, зокрема OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq і власні сумісні API
  • Модерація, переклад, підсумки, контекст RAG і створення оверлеїв
  • Необов’язкове браузерне захоплення ChatGPT без ключа API

Озвучення тексту

Оживіть повідомлення чату озвученням тексту, роблячи трансляцію цікавішою й доступнішою.

  • Підтримка безкоштовного системного озвучення
  • Інтеграція преміальних сервісів озвучення (Google Cloud, ElevenLabs, Speechify)
  • Багатомовна підтримка
  • Налаштування голосу, висоти тону й темпу мовлення
  • Підтримка захоплення аудіо OBS

Потужний API

Розширюйте можливості Social Stream Ninja за допомогою потужної інтеграції API.

  • Підтримка вебхуків для сторонніх інтеграцій
  • API сервера для віддаленого керування
  • Інтеграція донатів (NinjaBacker: безкоштовно, 0% комісії платформи, Stripe, Ko-Fi, Buy Me A Coffee)
  • Керування MIDI/Streamdeck
  • Підтримка віддаленого керування сценами OBS
