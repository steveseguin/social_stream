Нативний застосунок VDO.Ninja + Social Stream Ninja

Отримуйте чат Social Stream Ninja в нативному мобільному застосунку VDO.Ninja.

Що робить це налаштування

Social Stream Ninja працює на комп’ютері, захоплює чат із Twitch, YouTube, Kick чи іншого джерела, а потім пересилає ці повідомлення в нативний застосунок VDO.Ninja на вашому телефоні.

Телефон є приймачем. Він не підключається безпосередньо до Twitch або вашої платформи чату.

1. Запустіть джерело Social Stream

  1. Відкрийте Social Stream Ninja на комп’ютері, який збиратиме чат.
  2. Укажіть ID сесії Social Stream Ninja.
  3. Відкрийте потрібне джерело платформи, наприклад Twitch, YouTube, Kick або TikTok.
  4. Перш ніж перевіряти телефон, переконайтеся, що повідомлення з’являються у вікні джерела Social Stream або в доку.

Режим джерела Twitch WebSocket підходить. Він визначає лише спосіб захоплення чату Twitch у SSN і не пов’язаний із режимом Peer-to-Peer або Server на телефоні.

2. Відкрийте налаштування публікації на телефоні

  1. Відкрийте нативний застосунок VDO.Ninja.
  2. Виберіть потрібний режим камери, екрана або мікрофона.
  3. На екрані Publishing Settings прокрутіть униз до Social Stream Ninja Integration.

3. Використовуйте той самий ID сесії

Увімкніть Social Stream і вставте точно той самий ID сесії, який SSN використовує на комп’ютері.

4. Виберіть один режим підключення

Режим телефонаНалаштування SSNВикористовуйте, коли
Peer-to-Peer Використовуйте звичайний вихід P2P SSN. Не спрямовуйте чат лише через сервер API. Найкращий початковий варіант. Працює через звичайне підключення до інтернету без локального сервера.
Сервер Увімкнути Send chat messages to API server у SSN Global > Mechanics. Використовуйте, коли P2P заблоковано або працює нестабільно.

Не змішуйте режими. Якщо телефон у режимі Peer-to-Peer, а SSN надсилає лише через режим Server, телефон не отримає чат. Якщо телефон у режимі Server, але SSN не надсилає чат на сервер API, телефон не отримає чат.

5. Підключіться та перевірте

  1. Торкніться Підключити (Connect) у нативному застосунку VDO.Ninja.
  2. Надішліть справжнє повідомлення в чат або скористайтеся тестовим повідомленням SSN.
  3. Подивіться на телефон. Якщо він показує Social Stream не підключено (Social Stream not connected), джерело чату все ще може працювати, але транспорт SSN до телефона не підключений.

Поширені несправності

СимптомСправжня причинаВиправлення
Чат з’являється в SSN, але телефон показує Social Stream not connected. Джерело платформи працює, але шлях виходу від SSN до телефона не підключений. Перевірте ID сесії, режим підключення та налаштування виходу SSN.
Працює на одному ПК, але не на іншому з тим самим ID сесії. У режимі Peer-to-Peer SSN публікує, використовуючи ID сесії як ID потоку VDO.Ninja. Лише один екземпляр SSN може одночасно публікувати з тим самим ID. Закрийте або вимкніть Social Stream на першому ПК, а потім перезапустіть SSN на другому; або використовуйте інший ID сесії.
Режим Server узагалі не отримує чат. Телефон слухає канал сервера API SSN, але SSN не публікує туди чат. Увімкнути Send chat messages to API server у SSN Global > Mechanics.
У вікні джерела видно чат, але нічого не пересилається. Джерело може бути в режимі лише для відповідей або без захоплення. Вимкніть Бот лише для відповідей (без захоплення) для цього джерела.
Віддалений телефон не може використовувати режим локального сервера. Режим локального сервера обмежений комп’ютером або локальною мережею й зазвичай недоступний через брандмауер. Використовуйте Peer-to-Peer або загальнодоступний режим Server з увімкненим виходом чату SSN на сервер API.

Емоти BTTV, 7TV та FFZ

Увімкніть опції емотів BTTV, 7TV або FFZ у SSN перед пересиланням чату. SSN доповнює повідомлення, перш ніж воно потрапить на телефон.

Чат нативного застосунку все ще може показувати запасний текст замість зображень емотів, якщо ця збірка не відображає зображення всередині повідомлень чату.
