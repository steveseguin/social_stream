Для чого потрібен Event Flow

Запустити власний процес клавішею Stream Deck або викликом HTTP/WebSocket/P2P API.

Event Flow — розширений редактор автоматизацій. Використовуйте його, коли перемикачів спливного вікна недостатньо: фільтруйте чат, запускайте медіа, пересилайте повідомлення, викликайте вебхуки або керуйте OBS.

Перед будь-яким рецептом

  1. Використовуйте одну тестову платформу й одну сесію Social Stream.
  2. Відкрийте док і переконайтеся, що чат надходить.
  3. Відкрити actions.html?session=YOUR_SESSION якщо рецепт відтворює аудіо, медіа або керує OBS.
  4. Перевірте фальшивим повідомленням або безпечним тригером перед виходом у прямий ефір.
  5. Експортуйте робочий потік перед великою зміною.

Приклад медіа для винагород Kick

Це найпоширеніший практичний шаблон Event Flow: знайти відповідну винагороду, потім відтворити медіа через Flow Actions.

Докладний розбір: Посібник зі звуків/медіа винагород Kick.

Поширені рішення

  • Нічого не відбувається: спочатку переконайтеся, що вихідна подія надходить у док.
  • Аудіо або медіа не відтворюється: тримайте actions.html відкритим із тією самою сесією, потім перевірте Посібник із розміщення медіа Event Flow.
  • Дія OBS не працює: перевірте OBS WebSocket v5, порт 4455, пароль і дозволи.
  • Потік спрацьовує надто часто: додайте суворіший фільтр платформи, події, ключового слова або користувача.
