Огляд

SSN може читати захоплений текст чату з будь-якого підтримуваного джерела; платформа чату не потребує власної функції TTS. Ваш док або оверлей із увімкненим TTS озвучує отримані повідомлення відповідно до своїх фільтрів і налаштувань TTS. Почніть із короткого посібника з налаштування; ця сторінка описує варіанти голосів і розширені налаштування. Порівнюйте постачальників, слухайте зразки та переглядайте налаштування.

Швидкий початок: Використовуйте dock.html?session=YOUR_SESSION&speech=en-US. За замовчуванням використовується системне TTS. Для безкоштовного постачальника в OBS також додайте &ttsprovider=kokoro. Залиште цю сторінку відкритою та підключеною; озвучувати має лише одна копія.

Де використовується TTS?

  • Social Stream Ninja: Озвучує повідомлення чату аудиторії в кількох місцях
  • CAPTION.Ninja: Пропонує приховані субтитри, транскрибування та переклад з озвученням
  • Обидва сервіси пропонують платні й безкоштовні варіанти TTS
Системне TTS — лише один із безкоштовних варіантів TTS:
  • Системні голоси залежать від браузера та операційної системи. OBS може не надавати придатних голосів, навіть коли Chrome/Edge працює.
  • Відсутність голосу — це інша проблема, ніж відтворення мовлення поза захопленням звуку OBS. Маршрутизація звуку не виправить відсутність підтримки мовлення.
  • Безкоштовні постачальники, як-от Kokoro, Piper, Kitten та eSpeak, натомість генерують звук сторінки. Для TTS в OBS платити не потрібно.
  • Перевірте доступність голосів, а потім — захоплення звуку.

Варіанти постачальників TTS

Системне TTS (безкоштовне)

  • Використовує вбудовані голоси вашої операційної системи
  • Обмежена підтримка мов залежно від установлених у системі компонентів
  • Доступність голосів і маршрутизація звуку залежать від браузера та операційної системи; перевіряйте в тому програвачі, який фактично використовуєте
  • Сумісність із браузерами суттєво відрізняється

Обмеження браузерів:
  • Не всі браузери однаково підтримують озвучення тексту (деякі версії Firefox мають обмежений набір голосів)
  • Chrome пропонує варіанти TTS від Google
  • Edge підтримує Microsoft TTS і голоси з мовних пакетів Windows
  • Safari потребує дії користувача для початку відтворення звуку
  • Перевірте доступні голоси для вашого браузера

Способи захоплення звуку TTS Windows для OBS

Звук сторінки: безкоштовні локальні та хмарні постачальники

Локальні постачальники SSN, що працюють у браузері, і хмарні постачальники звуку відтворюють згенерований звук через сторінку:

  • Просто ввімкніть «Керувати звуком через OBS» (Control audio via OBS) у джерелі браузера
  • Віртуальні аудіокабелі не потрібні
  • Працює із застосунком SSN і джерелами браузера OBS

Способи захоплення системного TTS

Важливо: Спершу переконайтеся, що системне TTS генерує мовлення. Вбудований браузер OBS може не надавати придатного системного голосу. Якщо мовлення не генерується, зміна маршрутизації звуку не допоможе. Виберіть іншого постачальника або генеруйте мовлення в підтримуваному браузері й захоплюйте звук цього браузера.

Саме для системного TTS:

  • Не припускайте, що OBS надає ті самі голоси, що й Chrome або Edge
  • Обмежена підтримка в різних браузерах (у Firefox деякі голоси TTS можуть бути відсутні)
  • Chrome пропонує варіанти від Google, а Edge — від Microsoft
  • Якщо мовлення відтворюється поза джерелом браузера сцени, захоплюйте цей звук окремо

Завантаження засобів маршрутизації: VB-Audio Virtual Cable | Voicemeeter | Audio Router (застарілий)

Спочатку спробуйте захопити звук браузера, що озвучує текст, через захоплення звуку застосунку або робочого столу в OBS, якщо це підтримується. Наведені нижче способи з віртуальним кабелем — необов’язкові альтернативи; вони не додають OBS підтримку мовлення.

Спосіб 1: стандартний маршрут звуку через віртуальний кабель

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Спосіб 2: маршрут для застосунку у Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Спосіб 3: маршрут для застосунку у Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Спосіб 4: програма Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Спосіб 5: Voicemeeter (розширений)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Перевірка налаштування

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Альтернативи: Використовуйте безкоштовного вбудованого постачальника, як-от Kokoro, Piper, Kitten або eSpeak, хмарного постачальника чи власний сервер TTS.

Установлення додаткових мовних пакетів

Windows 11

  1. Перейдіть до Пуск > Налаштування > Час і мова > Мовлення
  2. У розділі Керувати голосами, натисніть Додати голоси
  3. Виберіть потрібні мови та натисніть Додайте
  4. Перезапустіть браузери, щоб оновити доступні голоси

Windows 10

Дотримуйтеся інструкцій в офіційному посібнику Microsoft для встановлення мовних пакетів.

Порада: Деякі сторонні голоси можуть не з’являтися у браузерах через проблеми сумісності. Firefox часто показує більше системних голосів, ніж браузери на основі Chromium.

Параметри URL для налаштування TTS

Основні параметри

Параметр Опис Приклад
&speech Увімкнути TTS із кодом мови &speech=en-US
&pitch Висота голосу (від 0,1 до 2,0) &pitch=1.2
&volume Рівень гучності (від 0,0 до 1,0) &volume=0.8
&rate Темп мовлення (від 0,1 до 10,0) &rate=1.5
&voice Частковий збіг назви голосу &voice=google
&ttsprovider Виберіть постачальника: kokoro, piper, kitten, espeak, openai, customtts, localtts, elevenlabs, google, speechify, gemini &ttsprovider=customtts

Розширені параметри

Параметр Опис
&simpletts Не говорити «каже» або «хтось каже»
&simpletts2 Взагалі не читати імена учасників чату
&ttscommand Увімкнути власну команду TTS (за замовчуванням: !say)
&readevents Озвучувати події трансляції
&skipmessages=3 Читати лише кожне третє повідомлення

Налаштування постачальника TTS

Kokoro TTS (безкоштовне, вбудоване)

  • Увімкніть за допомогою ?ttsprovider=kokoro
  • Працює у браузері через WebGPU/WASM — сервер не потрібен
  • Працює безпосередньо з джерелом браузера OBS
  • Вибір голосу: &voicekokoro=af_bella
  • Керування швидкістю: &kokorospeed=1.2
  • Виберіть голос для мови: &voicekokoro=ef_dora для іспанської або &voicekokoro=pf_dora для бразильської португальської. Зміна &speech= сама по собі не змінює вибраний голос. Наявні ID англійських голосів продовжують працювати.

Piper TTS (безкоштовне, вбудоване)

  • Увімкніть за допомогою ?ttsprovider=piper
  • Швидке нейронне TTS у браузері з помірним навантаженням на процесор
  • Вибір голосу: &pipervoice=en_US-hfc_female-medium
  • Португальські голоси: &pipervoice=pt_BR-faber-medium або &pipervoice=pt_BR-edresson-low
  • Іспанські голоси: &pipervoice=es_ES-davefx-medium або &pipervoice=es_MX-ald-medium
  • Керування швидкістю: &piperspeed=1.0

Kitten TTS (безкоштовне, вбудоване)

  • Увімкніть за допомогою ?ttsprovider=kitten
  • Легке TTS на основі ONNX, що працює у браузері
  • Вибір голосу: &kittenvoice=expr-voice-4-f

eSpeak-NG (безкоштовне, вбудоване)

  • Увімкніть за допомогою ?ttsprovider=espeak
  • Класичне TTS з відкритим кодом, працює на будь-якому обладнанні
  • Вибір голосу: &espeakvoice=en
  • Приклад португальською: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Приклад іспанською: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Керування швидкістю: &espeakspeed=175

Приклади TTS португальською та іспанською

  • Португальська, найкраща якість безкоштовного локального TTS, перевірена в SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Португальська, найшвидший запасний варіант, перевірений у SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Іспанська, найкраща якість безкоштовного локального TTS, перевірена в SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Іспанська, найшвидший запасний варіант, перевірений у SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Для хмарних голосів використовуйте голос/мову постачальника, що підтримує потрібну мову, наприклад Google Cloud, ElevenLabs, Speechify, Gemini або локальний сервер, сумісний з OpenAI.

OpenAI / TTS на локальному сервері

  • Увімкніть за допомогою ?ttsprovider=openai
  • Використовуйте ?ttsprovider=customtts або ?ttsprovider=localtts для кінцевої точки на власному сервері
  • За замовчуванням використовує API OpenAI або будь-який сумісний локальний сервер
  • Власна кінцева точка: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Важливо: localhost і 127.0.0.1 означають той самий комп’ютер, на якому відтворюється сторінка TTS. Якщо OBS працює на іншому комп’ютері, ніж сервер TTS, натомість використовуйте локальну IP-адресу комп’ютера сервера.
  • Для локальних серверів ключ API не потрібен
  • Якщо локальний сервер має проблеми з CORS або локальною мережею у Chrome/OBS, запустіть npm run local-tts-bridge на комп’ютері OBS та спрямуйте SSN на http://127.0.0.1:8124/v1/audio/speech
  • SSN надсилає { model, input, voice, response_format, speed } і підтримує двійковий звук, URL звуку в JSON та звук у base64 у JSON
  • Відтворення через власну/локальну кінцеву точку наразі буферизується; SSN ще не відтворює потокові фрагменти звуку поступово
  • Голос: &voiceopenai=af_bella, швидкість: &openaispeed=1.0. Використовуйте назву голосу, яку підтримує ваш сервер; голоси Kokoro мають вигляд af_bella, а голоси openedai-speech/у стилі OpenAI можуть мати вигляд nova або echo.
  • Дивіться Посібник із локального озвучення ШІ для налаштування власного сервера

Google Cloud TTS

  • Увімкніть за допомогою ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Голоси професійної якості
  • Вибір голосу: &voicegoogle=en-GB-Standard-A
  • Мова: &googlelang=en-US

Gemini TTS

  • Увімкніть за допомогою ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Модель: &geminimodel=gemini-2.5-flash-preview-tts
  • Голос: &voicegemini=Kore, мова: &geminilang=th-TH
  • Інструкції щодо стилю: &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • Увімкніть за допомогою ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • ID голосу: &voice11=YOUR_VOICE_ID
  • Модель: &elevenlabsmodel=eleven_multilingual_v2
  • Можна налаштувати параметри stability, similarity, style

Fish Audio TTS

Виберіть Fish Audio та введіть свій ключ API, за потреби додавши ID голосу. Модель за замовчуванням — s2.1-pro-free. Налаштування, варіанти моделей та обмеження доступу з браузера.

Speechify TTS

  • Увімкніть за допомогою ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Голос: &voicespeechify=henry
  • Модель: &speechifymodel=simba-3.0 (за замовчуванням) або &speechifymodel=simba-3.2 для англійської.
  • Швидкість мовлення: &speechifyspeed=1.2 (від 0,5 до 3,0; звичайне значення — 1,0).
  • Посібник із налаштування Speechify, голосів, швидкості та гучності

Усунення несправностей

Поширені проблеми

  • Звук не відтворюється: Перевірте, чи ввімкнено TTS, чи відкрита сторінка, яка генерує мовлення, і чи не вимкнено звук джерела браузера. У звичайному браузері один раз натисніть на сторінці.
  • Голоси не відображаються: Перезапустіть браузер після встановлення мовних пакетів
  • OBS не захоплює звук: Якщо мовлення відсутнє, спершу перевірте доступність голосу/постачальника. Якщо мовлення є, перевірте Керувати звуком через OBS (Control audio via OBS), вимкнення звуку в мікшері та вихідні доріжки або захоплюйте звук зовнішнього браузера, що відтворює мовлення
  • Локальна кінцева точка працює під час перевірки в застосунку, але не в OBS: OBS — це окремий браузер. Перевірте кінцеву точку з комп’ютера OBS, особливо якщо використовуєте 127.0.0.1.
  • Читається лише перша літера або перші слова: видаліть ttsquick з URL OBS, якщо він присутній.
  • Проблеми Safari: Safari має обмежену підтримку автоматичного TTS
  • Платний сервіс не працює: Перевірте ключ API та переконайтеся, що постачальника вказано правильно

Рекомендовані практики

  • Для простішого налаштування OBS використовуйте постачальника, який генерує звук сторінки; доступні безкоштовні локальні постачальники
  • Перевірте налаштування простими фразами перед виходом в ефір
  • Враховуйте ризики озвучення створеного користувачами вмісту
  • Майте перемикач, щоб за потреби швидко вимкнути TTS
