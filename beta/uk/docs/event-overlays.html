Показуйте останні події у своєму потоці

Тримайте останні три підписки, підписки та пожертви видимими у вашій сцені "Просто спілкуватися".

Останні три сповіщенняСтрічка активностіСтиліЕлементи керуванняПлатформиПереїзд з Streamlabs

Тримайте останні три сповіщення видимими

  1. Відкрити Сповіщення з різних платформ → Кілька сповіщень / Список подій.
  2. Виберіть Останні 3 — прозоре тло. Це дозволяє складати, компактувати картки та Зберігати сповіщення до заміни. Змініть Видимі сповіщення для іншого підрахунку.
  3. Виберіть Попередній перегляд зразків подій щоб побачити вигадані події Twitch, YouTube і Facebook. Цей попередній перегляд не підключається до вашого потоку.
  4. Скопіюйте посилання Multi-Stream Alert Box. У OBS Studio або Streamlabs Desktop додайте a Джерело браузера (Browser Source) до вашої сцени та вставте посилання. Почніть із полотна 900 × 700 і змініть його розмір відповідно до ваших карток.
  5. Підключіть джерела подій до SSN. Нові події приєднуються до стека та замінюють найстарішу незакріплену картку.

Відкрийте стопку зразків · Переглядайте стилі сповіщень у стосі

Вимкніть Зберігати сповіщення до заміни щоб термін дії кожної картки закінчувався після налаштованої тривалості відображення. Укладка відображає придатні надходження негайно; черга єдиного сповіщення застосовується, коли стекування вимкнено. Звук відтворюється при нових сповіщеннях. Постійне відео відтворюється один раз, а медіа-область ховається після тривалості відображення, а текст залишається видимим.

Використовуйте компактний список подій для аудиторії

Відкрити Активність / Події і виберіть Останні 3 — прозоре тло. Попереднє налаштування аудиторії приховує заголовок, часові мітки, метадані, клацання для функції, кількість, сповіщення про рекламу та випадкову активність. Він зберігає підписки, підписки, платну підтримку та інші вибрані категорії подій. Вимкніть попереднє налаштування, якщо ви хочете налаштувати його приховані елементи окремо.

Використовуйте Виберіть, які події відображатимуться для фільтрації категорій і Джерела для відстеження фільтрувати платформи. встановити Видалити події після до нуля або залиште його порожнім, щоб зберегти рядки до заміни. Попередній перегляд списку аудиторії.

Виберіть стиль і макет

Перегляньте всі стилі списку подій. Кожна картка галереї містить знімок екрана та посилання на ваш сеанс. Multi-Alerts підтримує наявні ілюстрації та теми сповіщень у стеках, а також Broadcast, Outlined, Rounded pills і Neon.

Build a classic stream bar

Three overlays combine into a familiar stream layout: a fundraising bar along the top, recent events in a corner and running totals along the bottom. Each one is its own Browser Source, so you can use any of them alone.

PieceWhere to turn it onWhat it shows
Fundraiser BannerСкарбничка донатів і лічильник цілі: set Display Style to Fundraiser Banner.A flat bar with the goal title, amount raised and goal on one line. Size the source to about 900 × 40. Попередній перегляд
Spotlight event listАктивність / Події: set Feed style to Spotlight.One-line rows that hug the right edge, with the newest event highlighted. It needs no other settings and shows the last three events. Попередній перегляд
Stream stats stripПанель метаданих: open Stream stats, виберіть Stats to show, then set Style preset to Strip.The biggest donation, subs today, bits and the time, with an optional latest chat line. Size the source to your canvas width and about 42 tall. Попередній перегляд

The strip counts donations, subs, bits and follows from the events it receives while it is running, so it does not include anything from before it was added to your scene. Stats, counters and the subathon use the dock feed. To count subscription and follow events, leave Виключити події сповіщень із док-станції off. Totals are saved in the browser showing it and survive a refresh. They clear at midnight, or set Reset totals до Only with the reset button and use Reset stream stats in the popup. A gifted sub counts once for each sub in the gift, and resubs count as subs. Biggest donation compares USD values and shows the amount as the viewer sent it, so large Bits cheers can take the top spot. Test events you send count too, so reset before going live.

Rename a stat from the popup, for example biggestlabel=Biggest D. Використовуйте stats=biggest,donations,subs,bits,follows,lastchat,clock in any order to choose what appears. In Spotlight, textalign=left moves the rows to the left, cardbg і accent set the highlight colors, and textcolor sets the older rows. On the banner, fillstart, trackcolor, bartextcolor, barheight і bartextsize change its look.

Show the latest and top supporters

The Meta Data Bar's Stats to show also has presets for the labels you see on many channels: the latest follower, sub, tip and Bits, the top gifter and top Bits of the day, and your total subs and followers. Each one fills in from events as they arrive. Before the first event, a label shows a dash.

To choose your own set, edit stats= in the link: latestfollow, latestsub, latesttip, latestbits, latestraid, topgifter, topbits, totalsubs і totalfollows work alongside the keys above, and latestfollowlabel=Newest renames one. Latest values and totals carry over midnight; the top lists start again each day. Total subs and followers need a source that reports them, such as Twitch EventSub. Попередній перегляд

Count deaths, wins or anything else

In the Meta Data Bar, list each counter as Name|!command, separated by commas, for example Deaths|!death,Wins|!win. Moderators, the host and admins change them from chat. On YouTube, your own channel is not marked as a moderator, so add your name under "Identify the hosts' name" in SSN. Anyone else's message is ignored unless you turn on Allow viewer adds. That lets each viewer add 1 every five seconds; only moderators can set or reset a count.

Type thisЩо відбувається
!deathAdds one.
!death +3 або !death -1Adds or removes that many.
!death =10Sets the count.
!death resetBack to zero.

Add rules to let support raise a counter on its own. Owed Pushups|!pushup|sub:15|gift:15 adds 15 for each sub and each gifted sub. You can also use bits (per 100 Bits), tip (per $1) and follow. Counters are saved in the browser showing them and only reset when you ask, and Reset stream stats leaves them alone. Попередній перегляд

Run a subathon timer

In the Meta Data Bar, set a Starting time such as 6h, then the minutes each sub, 100 Bits, $1, follow and raid adds. For tiers, list three values: 6,15,40. Увімкніть Show rules to display them, and set a longest time to limit what support can add. Moderators can still go past it. Time for follows can be farmed by unfollowing and refollowing, so leave that at 0 unless you trust your chat. The Cards style gives a large clock.

The clock waits for you. Press Start in the popup, or have a moderator type !subathon start. Moderators can also use pause, add 30m, remove 10m, set 6h і reset. On YouTube, your own channel is not marked as a moderator, so use the popup buttons or add your name under "Identify the hosts' name" in SSN. It keeps running through a refresh, and Reset stream stats does not touch it. Once it reaches zero, new support no longer extends it, but a moderator can use add to bring it back. Support only adds time while the overlay is open, so keep the source active during the event. Попередній перегляд

Історія та елементи керування

Увімкнути Запам'ятати видимі події після оновлення щоб дошка була заповнена, коли її джерело браузера перезавантажується. Історія є локальною для цього браузера, сесії та назви форуму; OBS і ваш звичайний браузер мають окреме сховище. Налаштування збереження коливається від 1 до 168 годин. Відновлені рядки використовують поточні фільтри та не відтворюють звук і не запускають автоматику. У Multi-Alerts ця опція вимагає стекування.

Дайте окремі сцени різними Назви дощок. Спливаючі команди спрямовані на відповідну назву дошки та поверхню. Команди, надіслані до відключеного накладання, не є збереженою зміною стану. Пауза зберігає нові надходження в буфер до 500 подій для стеків і каналів; резюме відображає їх. Якщо цей буфер заповнюється, його найстаріша подія очікування замінюється. Режим єдиного сповіщення використовує налаштований ліміт черги.

Pin перемикає пін-код найновішої картки; закріплені картки займають видимі слоти. Якщо кожен слот закріплено, відкріпіть картку, щоб прийняти нові події. Видалити видаляє найновішу картку. Очистити видаляє видимі події, події, що очікують, і збережену історію дошки. Multi-Alerts також пропонує пропуск, вимкнення звуку, увімкнення звуку та повторне відтворення. Повторне відтворення – це відображувана дія, а не нова пожертва чи тригер потоку подій.

Увімкніть інформаційну панель приватних подій Показати кнопки оператора щоб закріпити або видалити окремі рядки. Залиште цей параметр вимкненим у джерелах веб-переглядача аудиторії.

Обидва накладання використовують події, які надсилають ваші джерела SSN. Стиль накладання не додає дозволи платформи чи нову підписку на подію.

Походить від Streamlabs або StreamElements

Для завжди видимої поведінки списку подій Streamlabs використовуйте Показати кілька сповіщень + Зберігати сповіщення до заміни у Multi-Alerts або попередньо встановлену аудиторію в Events. Видимі сповіщення / Максимальна кількість подій встановлює кількість. Параметр історії відновлює останні видимі картки в тому ж браузері. Використовуйте фільтри категорій і елементи керування мінімальним значенням, щоб вибрати, яка підтримка з’явиться.

Ви можете додати посилання SSN безпосередньо як джерело браузера в OBS або Streamlabs Desktop. Для цього не потрібна док-станція оператора SSN. Використовуйте стиль SSN із галереї, а потім налаштуйте кольори та інтервали відповідно до вашої сцени.
