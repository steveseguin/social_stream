Подключите ИИ за 5 шагов

Это нужно сначала настроить для всех вариантов, кроме вкладки ChatGPT.

  1. Во всплывающем окне Social Stream откройте Чат-боты и сервисы ИИ (Chat Bots and AI services).
  2. Открыть Настроить провайдера языковой модели (Configure LLM Service Provider) и выберите свой ИИ.
  3. Укажите адрес, модель, ключ API или параметры загрузки.
  4. Нажмите Проверить выбранного чат-бота.
  5. Включите использующую его функцию, например основного бота или перевод.
Подключение — ещё не завершение настройки. Это означает только ответ ИИ на тест. Чат не читается, пока вы не включите функцию.

Голосовой соведущий

Общайтесь с ИИ в эфире. Он слышит микрофон, видит предоставленный чат и может отвечать вслух.

  1. Открыть cohost.html?session=YOUR_SESSION.
  2. Выберите голосовой ИИ или ИИ из настроек всплывающего окна.
  3. Выберите микрофон и Голосовой ответ (Audio Response), затем нажмите Запустить соведущего (Start Co-host).
  4. С OpenAI Realtime захватывайте в OBS звук страницы соведущего.
  5. Добавить cohost-overlay.html?session=YOUR_SESSION в OBS для аватара и речевого пузыря.

Ни один вариант не публикует сообщения в чате платформы. Оставьте речевой пузырь видимым, чтобы зрители могли читать.

Подробнее об OpenAI Realtime
  • Использует ключ OpenAI, сохранённый в ChatGPT API. Ключ остаётся в Social Stream. Страница соведущего получает только кратковременный доступ, а звук передаётся через WebRTC.
  • Оверлей не получает голос OpenAI. Выберите виртуальный кабель в выходе соведущего, если поддерживается. &forcetts добавляет второй отдельный голос оверлея.
  • Для скорости: модель Mini, низкий уровень рассуждений, быстрая смена реплик. Полное качество и высокий уровень рассуждений умнее, но медленнее и дороже. Быстрый режим может перебивать на паузах.
  • Камера и демонстрация экрана необязательны. По умолчанию Без видео (No Video). При включении отправляется один снимок на запрос, а не живое видео. Это увеличивает стоимость и задержку.
  • Инструменты Spotify, сцен OBS и выделения чата по умолчанию выключены. Включите их во всплывающем окне, затем в Управление трансляцией через соведущего (Co-host Stream Controls).
  • Ответы ограничены 512 выходными токенами. Диагностика показывает расход и задержку.
  • Переподключается автоматически. Новый сеанс сохраняет инструкции и настройки, но забывает сказанное вслух.
  • Он не управляет беседой на сайте или в приложении ChatGPT.

Полное руководство по ИИ-соведущему

Основной бот для чата

Отвечает зрителям на оверлее, голосом через TTS или в чате, где поддерживается.

  1. Подключите ИИ и проверьте.
  2. Открыть Chat Bot - Primary («Основной бот для чата») и включите Включить ИИ-бота для чата на основе языковой модели.
  3. Настройте слова-триггеры, ограничение для модераторов, частоту, историю и инструкции.
  4. Для безопасной первой проверки включите Ответы бота отправляются ТОЛЬКО на страницу оверлея бота.
  5. Открыть bot.html?session=YOUR_SESSION. Включите TTS для озвучивания ответов.
  6. Отключайте режим «Только оверлей» лишь после проверки поддержки отправки сообщений платформой.

Ответы публикуются от вашего аккаунта. Для отдельного имени используйте аккаунт бота YouTube, Twitch или Kick, где поддерживается.

Полное руководство по ИИ-чат-боту

Личный бот

Личный помощник для проверки запросов.

  1. Включите Приватный интерфейс чат-бота (Chat Bot - Private Interface).
  2. Открыть chatbot.html с вашим сеансом.
Он отделён от основного бота и не использует его знания документов (RAG) или историю чата.

Полное руководство по конструктору ИИ-оверлеев

Вкладка ChatGPT (экспериментально)

Уже используете ChatGPT в Chrome и не хотите ключ API? Social Stream может получать новые сообщения из вкладки ChatGPT, как из любого другого источника чата (тип openai).

Захватывайте вкладку ChatGPT

  1. Установите и включите расширение Social Stream Ninja для Chrome.
  2. Во всплывающем окне включите ChatGPT источник.
  3. Открыть https://chatgpt.com/затем перезагрузите страницу.
  4. Откройте док с тем же сеансом.
  5. Отправьте новое сообщение ChatGPT. Обе стороны должны появиться в доке. Старые сообщения намеренно пропускаются.

Отправляйте живой чат в ChatGPT

  1. Проверяйте в частном эфире или эфире по ссылке, в обычном текстовом чате.
  2. В разделе Управление, включите Пересылка всех сообщений.
  3. Установите назначения пересылки на openaiчтобы сообщения зрителей поступали только в ChatGPT.
  4. Оставьте вкладку открытой. Ответы ChatGPT возвращаются как openai сообщения.
  5. Используйте звук ChatGPT, TTS Social Stream или оверлей для вывода ответов в эфир.
Экспериментально. Сайт ChatGPT может измениться. Пересылка всего чата может перегрузить беседу. Голосовой режим может не принимать введённый текст. Сначала используйте фильтры или тестовый эфир.

Устранение неполадок

ПроблемаЧто попробовать
Подключено, но ответов в чат нетВключите основного бота или нужную функцию. Само подключение ИИ не влияет на чат.
Соведущий видит чат, но молчитВ режиме «Только контекст» это нормально. Спросите о чате или выберите режим с озвучиванием ответов.
Во вкладке ChatGPT ничего нетВключите источник ChatGPT, перезагрузите chatgpt.comи отправьте новое сообщение.
Бот пропускает большинство сообщенийПроверьте слова-триггеры, ограничение для модераторов, частоту и инструкции. Избирательность предусмотрена специально.
Текст виден, но звука нетУбедитесь, что страница со звуком открыта и OBS захватывает её аудио.
Бот не может писать в чатПроверьте поддержку платформы, вход в аккаунт, право писать и ограничения частоты.
