Экспорт настроек для поддержки

Отправьте файлы, которые помогут определить источник неожиданного звука или другой проблемы OBS.

Что экспортировать

При неожиданном звуковом сигнале пожертвования начните с этих двух файлов:

  • Настройки Social Stream Ninja: показывает включённые параметры и созданные ссылки.
  • Коллекция сцен OBS: показывает сцены, источники браузера и медиа, URL источников и глобальные аудиоисточники.

Для звукового сигнала источника «Браузер» профиль OBS обычно не нужен. Экспортируйте его только если поддержка попросит настройки вывода, видео или учётной записи.

Храните экспортированные файлы приватно. Они могут содержать пароли сеансов, URL вебхуков и источников, данные подключённых учётных записей или ключ трансляции. Отправляйте их только человеку, изучающему проблему, и никогда не публикуйте в общедоступном чате или на форуме.

1. Экспортируйте настройки Social Stream Ninja

  1. Откройте панель управления Social Stream Ninja.
  2. Прокрутите до Global settings and tools («Общие настройки и инструменты»).
  3. Если вы уже почти внизу страницы, нажмите ссылку JUMP («Перейти») рядом с «Looking for the Global settings?», чтобы перейти туда.
  4. В Global settings найдите и выберите Export / import («Экспорт / импорт»).
  1. Прокрутите развёрнутый раздел до Настройки экспорта / импорта.
  2. Выберите Export to disk («Экспорт на диск»).
  3. Выберите место сохранения и любое имя файла. Сохраните расширение .data .
  4. Выберите Сохранить, затем отправьте этот файл настроек в поддержку приватно, не редактируя его.

2. Экспортируйте коллекцию сцен OBS

  1. В OBS переключитесь на коллекцию сцен, в которой возникает проблема.
  2. Выберите Коллекция сцен в верхнем меню.
  3. Выберите Экспорт…, выберите папку и сохраните JSON-файл.
  4. Если проблема возникает в нескольких коллекциях, экспортируйте каждую затронутую коллекцию.

3. Экспортируйте профиль OBS только по запросу

  1. Переключитесь на затронутый профиль OBS.
  2. Выберите Профиль в верхнем меню.
  3. Выберите Экспорт…, выберите папку и сохраните JSON-файл.
Профиль может содержать сведения подключённой учётной записи или ключ трансляции. Передавайте его приватно и только при необходимости.

Отправьте пакет для поддержки

Приложите файл настроек Social Stream Ninja (.data) и JSON коллекции сцен OBS. Также укажите название платформы пожертвования и примерное время, когда прозвучал звук.

Если проблему трудно воспроизвести, полезен короткий ролик с одним пожертвованием. Прикладывайте JSON профиля OBS только по прямому запросу поддержки.
