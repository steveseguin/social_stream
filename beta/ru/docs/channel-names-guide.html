Show which channel a message came from

Combining several creators' chats? Turn on Show originating channel name to see which channel received each message, Super Chat, membership, or gift.

Which overlays support channel names?

The same viewer can comment on several streams. The channel label tells you which creator received the message, while the viewer's name still identifies who sent it. Select any screenshot to view it at full size.

The toggle applies to ordinary messages, Super Chats, memberships, and gifts displayed in these views. It labels all messages with an available channel name; there is no paid-items-only switch.

Show channel names in chat and the queue

  1. Open your Social Stream Ninja settings in the desktop app or browser extension.
  2. В Чат tab, open Основной оверлей чата и док-панель управления (Main chat overlay & control dock) (Streaming Chat), then Message ? Visibility. If you are in beginner mode and cannot see this section, choose Переключиться в полный режим in the welcome panel.
  3. Включить (Enable) Show originating channel name. Or search settings for originating channel and select the result under Основной оверлей чата и док-панель управления (Main chat overlay & control dock).
  4. Open the updated Streaming Chat Dock link. If you already have the Dock open in OBS or a browser, update its URL using the steps below.

The queue keeps the channel label

Queue messages as usual. The Dock's channel-name setting also applies when viewing queued items.

Show channel names on the Featured Chat overlay

  1. В Чат tab, open Оверлей выделенного чата, затем Visibility.
  2. Включить (Enable) Show originating channel name there as well.
  3. Copy the updated Featured Chat link into your OBS Browser Source's URL поле.
  4. Select a message in the Dock to feature it. Its channel label appears on the overlay when a channel name is available.

The Dock and Featured Chat have separate settings. Enable both if you want your hosts and your audience to see channel names.

Update an existing browser or OBS link

You can enable channel names directly on an existing dock.html или featured.html link by adding &showchannelname. Keep your existing session, password, and other options.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID&showchannelname
https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID&showchannelname

These are examples; use your own generated links. In OBS, edit the URL in the Browser Source or custom browser dock settings. In a browser, navigate to the updated URL. If your link contains a # fragment, insert &showchannelname before it.

Changing a toggle in SSN updates the generated link. Replace links you previously copied into OBS or saved as bookmarks to apply the option there.

If a channel name is missing

  • Only one search result? Beginner mode can hide the main chat visibility section. Choose Переключиться в полный режим, then search again. You can also use the URL опция without changing menu modes.
  • Check the exact option. Используйте Show originating channel name. Show source name as text next to icon shows the platform, such as YouTube, rather than the creator's channel.
  • Check the page you are viewing. Its URL should contain showchannelname. Updating the Dock does not update a separate Featured Chat Browser Source.
  • Check a new message. Channel details may still be loading when a source first opens. Wait for a new message from each connected channel, then queue or feature it to check the label.
  • Check the source. YouTube capture supplies channel names. Other platforms can show labels when their source supplies a channel name. If only one source stays unlabeled, include the platform and capture mode when asking for help.

This option labels items already appearing in chat; it does not enable capture of additional events. If memberships or gifts are missing entirely, review your YouTube setup and event filters.
