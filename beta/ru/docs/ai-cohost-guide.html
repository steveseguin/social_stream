ИИ-соведущий

ИИ-помощник для разговора в эфире. Он также может читать чат.

Два способа использования

Голосовой соведущий

Говорите с ИИ вслух на cohost.html. Он отвечает вам и может обсудить чат по просьбе.

Настройка

Кнопки дока

Нажмите правой кнопкой на сообщение в Dock. ИИ-аватар прочитает его или подготовит ответ либо лёгкую шутку, которую вы сначала одобрите.

Настройка

Оба показывают аватар и речевой пузырь в OBS через Сценический оверлей ИИ, cohost-overlay.html.

Голосовой соведущий за 8 шагов

Здесь используется OpenAI Realtimeпоэтому нужен ключ OpenAI API. Другие варианты: ниже.

  1. Во всплывающем окне Social Stream выберите ChatGPT API, вставьте ключ API проекта OpenAI и нажмите Проверить выбранного чат-бота.
  2. Откройте cohost.html из всплывающего окна. Не раскрывайте эту ссылку.
  3. Выберите OpenAI Realtime.
  4. Выберите микрофон, в который говорите. Оставьте Голосовой ответ (Audio Response) включённым.
  5. Нажмите Запустить соведущего (Start Co-host).
  6. Оставьте Живой чат на Только контекст (Context only). В любой момент спросите: «Что пишет чат?»
  7. В OBS захватывайте звук со страницы или приложения соведущего. Голос ИИ воспроизводится только там.
  8. Добавить cohost-overlay.html?session=YOUR_SESSION_ID в OBS как браузерный источник для аватара и облачка речи.
Нужна отдельная аудиодорожка в OBS? Выберите виртуальный аудиокабель в поле Вывод соведущего, если ваша система поддерживает. Оставьте речевой пузырь видимым, чтобы зрители без звука могли читать.
Дать ему доступ к экрану или камере? Необязательно. Видео запускается в режиме Без видео (No Video). Если выбрать Демонстрация экрана (Screen Share) или камеру, OpenAI получает один снимок при каждой вашей голосовой или текстовой реплике, а не живое видео. Это может увеличить стоимость и задержку.
Конфиденциальность: ваш микрофон, выбранные экран или камера и сообщения чата, которыми вы делитесь, передаются OpenAI. Зрители не могут через чат заставить соведущего запускать инструменты. Ссылка соведущего истекает через 12 часов, работает только в вашей сессии и удаляется из адресной строки после загрузки страницы.
Подробнее об OpenAI Realtime
  • Оплата списывается с вашего аккаунта OpenAI API. Это отдельный сервис от chatgpt.com, не участвующий в разговорах на сайте или в приложении ChatGPT.
  • Ваш обычный ключ остаётся в Social Stream. Страница соведущего получает только краткосрочный пропуск.
  • Для этого не нужно включать приватного чат-бота.
  • Ответы ограничены 512 выходными токенами. Диагностика показывает общий расход токенов и скорость начала ответов.
  • Если вы перебьёте его, он остановится и отбросит ещё не воспроизведённое аудио.
  • Он хранит до 20 последних сообщений не более 90 секунд, включая сведения о пожертвованиях, спонсорстве, модераторах, событиях и канале. Затем забывает их.
  • При обрыве соединения он переподключается сам и начинает новую сессию до достижения 60-минутного лимита OpenAI. Инструкции и настройки скорости сохраняются, но произнесённое вслух забывается.

Как использует ваш чат

Откройте страницу соведущего с тем же session что и в Social Stream, чтобы он видел ваш живой чат. Выберите режим в разделе Живой чат.

Настройка живого чатаЧто делает
Только контекст — отвечать по запросу (по умолчанию)Помнит последние сообщения и молчит, пока вы не спросите о чате.
Озвучивать ответы на вопросы и упоминанияСамостоятельно отвечает вслух на вопросы и упоминания.
Озвучивать ответ на каждое сообщениеОтвечает вслух на каждое сообщение.

Ни один из этих вариантов не отправляет ответы в чат YouTube, Twitch или Kick. Только контекст (Context only) передаёт чат ИИ только при использовании OpenAI Realtime. Другие провайдеры отслеживают чат, но не передают его ИИ.

Голос без OpenAI

Где запускаетсяКак он вас слышит
Настольное приложение SSNWhisper на вашем компьютере. При первом использовании скачивается около 42 МБ. Затем работает офлайн.
Chrome (ссылка расширения)Распознавание речи Chrome. Может требовать интернет.
Другие браузерыГолос может не работать. Ввод текста, живой чат, камера или экран и ответы ИИ могут по-прежнему работать.

Чтобы проверить, слышит ли он вас, откройте Диагностика. Должно быть указано Слушаю (Desktop Whisper) или Слушаю (OpenAI WebRTC)и ваши слова должны появиться в Распознано (Heard).

Бесплатный ИИ для проверки

  1. Открыть Чат-боты и службы ИИ → Настроить поставщика LLM.
  2. Выберите Пробная размещённая модель SSN (SSN Hosted Trial LLM, экспериментальная).
  3. Оставьте поля конечной точки, токена и модели пустыми.

Во время пробного периода это бесплатно; сервис могут отключить или ограничить частоту запросов. Для постоянного использования добавьте свой токен или используйте локальный ИИ.

Кнопки дока за 5 шагов

  1. Откройте Dock: dock.html?session=YOUR_SESSION_ID.
  2. Добавьте сценический оверлей в OBS: cohost-overlay.html?session=YOUR_SESSION_ID. Добавьте &tts если он должен говорить.
  3. Настройте провайдера ИИ во всплывающем окне. Для быстрой проверки используйте Пробная размещённая модель SSN (SSN Hosted Trial LLM).
  4. Включите Чат-боты и службы ИИ → Чат-бот — Личный интерфейс → Включить личного чат-бота.
  5. Нажмите правой кнопкой на сообщение в Dock и выберите Соведущий (Co-host).
Нет меню соведущего? Оно появляется, только когда Dock обнаружит сценический оверлей в той же сессии.

Изменения глубины рассуждения применяются даже при активном соединении. Диагностика показывает, сколько времени проходит до начала ответа. Состояние сети и нагрузка OpenAI всё равно могут меняться.

Разрешите ему управлять трансляцией

Соведущий может воспроизводить Spotify, переключать сцены OBS или выводить сообщение чата на экран. Всё по умолчанию отключено. OpenAI Realtime поддерживает все три функции. SSN Configured LLM поддерживает только Spotify. Другие провайдеры пока их не поддерживают.

  1. Во всплывающем окне Social Stream включите только нужные инструменты.
  2. Для OBS введите точные разрешённые имена сцен через запятую. Оставьте actions.html подключённым к OBS или используйте браузерный источник OBS с полными разрешениями.
  3. На странице cohost.html, откройте Управление трансляцией через соведущего (Co-host Stream Controls) и включите те же инструменты.
  4. Попросите вслух, например: «переключись на BRB», «выдели последнее сообщение» или «очисти выделенный чат».
Только вы можете запускать инструменты. Зрители этого делать не могут. На один запрос запускается один инструмент; доступны только сцены из вашего списка. Для вывода сообщения нужен открытый Dock. Ответ «готово» означает, что запрос отправлен, а не что OBS или оверлей завершили действие.

Устранение неполадок

ПроблемаЧто попробовать
В Dock нет меню соведущегоСценический оверлей не открыт в той же сессии. Переключатель основного оверлея чат-бота на это не влияет.
Ответ или лёгкая шутка недоступныВключите приватного чат-бота и убедитесь, что Social Stream работает.
Тайм-аут ответа, лёгкой шутки или настроенной LLM SSNПроверьте, что Social Stream включён, сеанс совпадает, личный чат-бот включён и поставщик ИИ доступен.
Страница соведущего не видит чатИспользуйте то же значение session что и во всплывающем окне. Для живого чата выберите любое значение, кроме «Выключен».
Он знает содержимое чата, но молчитВ режиме «Только контекст» это нормально. Спросите, о чём говорят в чате, или выберите другой режим.
В OBS ничего не видноНажмите Проверить оверлей (Test overlay) на странице соведущего и проверьте, появилась ли строка.
Текст есть, но голоса нет (OpenAI)Проверьте Голосовой ответ (Audio Response), разрешение браузера на звук и захват аудио страницы соведущего в OBS. Не используйте &tts для этого.
Два голоса одновременноУдалить &forcetts из ссылки оверлея.
Распознано (Heard) остаётся пустым (настольное приложение)Проверьте, что микрофон не выключен, и дождитесь первой загрузки.
Распознано (Heard) остаётся пустым (Chrome)Разрешите микрофон, проверьте микрофон по умолчанию, интернет и доступность распознавания речи Chrome.
Ответы приходят медленноПопробуйте Mini, низкую глубину рассуждения и быстрое переключение реплик. Сравните строку задержки в Диагностике.
OpenAI постоянно отключаетсяОставьте его работать, пока он повторяет попытки. Диагностика покажет причину сбоя.
Нет инструмента управления эфиромВключите это и во всплывающем окне, и в управлении трансляцией соведущего. Для OBS нужно хотя бы одно название сцены.
Пробный бесплатный ИИ перестал отвечатьСервис может быть отключён или ограничивать частоту запросов. Используйте собственный токен, Ollama или Custom API.
Локальная Gemma не скачиваетсяУкажите в качестве хоста ресурсов свою копию файлов Gemma.
Открыто несколько оверлеевУбедитесь, что метка оверлея совпадает с целью в Dock. По умолчанию это cohost-overlay.
Кнопки отключения звука и громкости
  • Выключить микрофон останавливает передачу вашего голоса соведущему.
  • Выключить голос соведущего, ползунок громкости, выбор выхода и Остановить озвучивание управляют тем, что вы слышите.
  • Выключить передаваемый системный звук работает отдельно и показывается только для провайдеров, которые могут использовать ваш экран.

Как общаются страницы (для разработчиков)

Формат сообщений и устройство системы

Dock и оверлей используют обычный мост сессии Social Stream. Сообщения отправляются как overlayNinja с адресацией по метке.

Озвучить через соведущего (Read on Co-host): Dock отправляет выбранное сообщение напрямую в cohost-overlay.html.

Ответить / Лёгкая подколка (Answer / Light Roast): Dock обращается к приватному чат-боту в фоне, показывает черновик и отправляет его в оверлей только после нажатия «Произнести».

{
  "action": "cohostOverlay",
  "target": "cohost-overlay",
  "meta": {
    "command": "say",
    "text": "The line the avatar should say",
    "speak": true,
    "emotion": "happy"
  }
}
  • В текстовых сценариях дока оверлей даёт изображение и необязательный голос TTS. Для голоса OpenAI захватывайте cohost.html захватывайте отдельно. Оверлей не воспроизводит это аудио WebRTC повторно.
  • Дополнительные детали команды помещаются в metaчтобы формат данных оставался предсказуемым для оверлеев и автоматизации.
