Настройка проекта YouTube

Как создать проект Google Cloud для отдельного настольного SSN, не снижая безопасность ключа.

Обзор

Для чего нужна эта настройка

Используйте это только если хотите, чтобы настольное приложение использовало вашу собственную квоту YouTube API вместо общего проекта Social Stream Ninja по умолчанию.

Важно: все три значения ниже должны быть из одного и того же проекта Google Cloud:
  • ID клиента OAuth
  • Секрет клиента OAuth
  • API-ключ
Не путайте эти два поля в Google Cloud:
  • Разрешённые источники JavaScript (Authorized JavaScript origins) должны содержать только источник, без пути.
  • Разрешённые URI перенаправления (Authorized redirect URIs) должны содержать полный /sources/websocket/youtube.html путь.
Шаг 1

Создайте проект

  1. Откройте Google Cloud Console.
  2. Создайте новый проект или выберите отдельный существующий.
  3. Включить (Enable) YouTube Data API v3.
  4. Откройте настройки экрана согласия OAuth.
  5. Если приложение находится в тестовом режиме, добавьте свой аккаунт Google как тестового пользователя.
Шаг 2

Создайте клиент OAuth

  1. Создайте учётные данные.
  2. Выберите Идентификатор клиента OAuth.
  3. Используйте тип Веб-приложение (Web application).
  4. Добавьте точные источники и URI перенаправления, показанные ниже.
Поле Значение
Разрешённые источники JavaScript (Authorized JavaScript origins) http://localhost:8181
http://localhost:8080
Разрешённые URI перенаправления (Authorized redirect URIs) http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
Шаг 3

Безопасно создайте API-ключ

  1. Создайте API-ключ в том же проекте.
  2. Откройте ограничения этого ключа.
  3. В разделе Ограничения API (API restrictions), ограничьте его использованием YouTube Data API v3 только.
  4. Не используйте ограничения по HTTP referrer для настольного приложения.

Правило для настольного приложения: Ограничения по HTTP referrer предназначены для страниц браузера, а не для этого локального процесса авторизации настольного приложения.

Шаг 4

Вставьте значения в настольное приложение

  1. Откройте страницу источника YouTube внутри настольного приложения.
  2. Вставьте ID клиента OAuth, Секрет клиента OAuth, и API-ключ.
  3. Нажмите Сохранить.
  4. При необходимости выйдите из аккаунта.
  5. Нажмите Войти через YouTube.
  6. Завершите вход Google во внешнем окне браузера.
Ожидаемый результат: если всё совпадает, вход Google работает, а настольное приложение использует ваш сохранённый проект YouTube вместо общего проекта по умолчанию.
Безопасность

Храните учётные данные в безопасности

  • Считайте секрет клиента и API-ключ конфиденциальными.
  • Не помещайте их на снимки экрана, в журналы чата или отчёты об ошибках.
  • Если случайно раскрыли их, замените или удалите.
  • Для экспериментов используйте отдельный тестовый проект.
  • После завершения тестирования удалите временные проекты.
Устранение неполадок

Частые проблемы

  • redirect_uri_mismatch: URI перенаправления не совпадает в точности.
  • invalid_client: ID клиента и секрет клиента не соответствуют друг другу.
  • quotaExceeded: проект вашего API-ключа исчерпал квоту YouTube.
  • Проверка аккаунта не удалась: в старых сборках такое могло происходить, когда OAuth и API-ключ были из разных проектов.
