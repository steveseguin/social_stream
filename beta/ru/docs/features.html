Возможности

Объединяйте чаты, показывайте зрителей на экране и придавайте каждой трансляции свой характер.

Объединение чатов разных платформ

Общайтесь со зрителями сразу на всех платформах трансляции. Social Stream Ninja объединяет сообщения чата с десятков платформ в одной удобной панели.

  • Двусторонний обмен сообщениями в реальном времени с Facebook, YouTube, Twitch, Zoom и другими
  • Для большинства платформ не нужны вход и API-ключи
  • Иконки источников разных каналов для различения платформ
  • Автоматическая пересылка сообщений между платформами

Оверлей выделенного сообщения

Выделяйте лучшие сообщения зрителей прямо в трансляции с помощью красивых настраиваемых оверлеев.

  • Выбор сообщений через закрепляемую панель
  • Автоматический или ручной выбор сообщений
  • Настройка через CSS для гармоничного сочетания со стилем вашей трансляции
  • Варианты анимации, включая плавное появление и сдвиг
  • Очередь сообщений для упорядоченного выделения

Команды бота и автоответы

Создавайте автоматические взаимодействия со зрителями через собственные команды и ответы.

  • Встроенные команды для обычных взаимодействий
  • Собственная логика команд через программируемый файл плагина
  • Автоматические приветствия и ответы
  • Фильтрация и модерация сообщений

Интеграция ИИ и языковых моделей

Выберите голосового соведущего, чат-бота, помощника в браузере или отдельные инструменты обработки ИИ, не привязывая остальные части трансляции к одному провайдеру.

  • Голосовой соведущий, который слышит вас и получает выбранные сообщения чата трансляции
  • Основной и личный чат-боты с собственными инструкциями и правилами запуска
  • Локальные модели и облачные провайдеры, включая OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq и собственные совместимые API
  • Модерация, перевод, сводки, контекст RAG и создание оверлеев
  • Необязательный захват ChatGPT в браузере без API-ключа

Озвучивание текста

Оживите сообщения чата с помощью озвучивания, сделав трансляцию интереснее и доступнее.

  • Поддержка бесплатного системного озвучивания
  • Интеграция платных сервисов озвучивания (Google Cloud, ElevenLabs, Speechify)
  • Поддержка нескольких языков
  • Настраиваемые голос, высота тона и скорость речи
  • Поддержка захвата звука OBS

Мощный API

Расширяйте возможности Social Stream Ninja с помощью интеграции API.

  • Поддержка вебхуков для сторонних интеграций
  • Серверный API для удалённого управления
  • Интеграция пожертвований (NinjaBacker: бесплатно, комиссия платформы 0%, Stripe, Ko-Fi, Buy Me A Coffee)
  • Управление MIDI / Streamdeck
  • Поддержка удалённого управления сценами OBS

Глубокая настройка

Настройте Social Stream Ninja под себя благодаря широким возможностям изменения функций и внешнего вида.

  • Оформление CSS для полного контроля внешнего вида
  • Готовые оформленные шаблоны и темы
  • Поддержка собственного JavaScript
  • Параметры URL для простой настройки
  • Фильтры источников и варианты брендинга

Расширенные инструменты трансляции

Развивайте трансляции с набором профессиональных инструментов для вовлечения и взаимодействия.

  • Интерактивные мини-игры, включая Battle Royal
  • Система розыгрышей с управлением очередью
  • Финальные титры и отображение банки для чаевых
  • Облако слов и собственные команды GIF
  • Графическая система опросов
  • База истории чата с поиском
  • Интерфейс личного ИИ-бота для чата
  • Возможности мультимодального ИИ-соведущего
