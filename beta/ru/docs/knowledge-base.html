Пустой оверлей в OBS

Сначала проверьте док-панель. Если она пустая, исправьте источник или платформу. Если работает, откройте точный URL оверлея в обычном браузере и проверьте одинаковый session, затем обновите источник «Браузер» в OBS.

Открыть устранение неполадок OBS

Неверный сеанс

Источник, док-панель, оверлей, бот и страницы Event Flow должны использовать один идентификатор сеанса. Считайте его названием комнаты: разное написание ведёт в разные комнаты.

dock.html?session=YOUR_SESSION

Открыть сеансы, пароли и режимы ретрансляции

Обновление без потери настроек

Сначала экспортируйте настройки, не удаляйте расширение при обычном обновлении и используйте зашифрованный перенос полного сеанса настольного приложения, если нужно перенести также cookie и данные входа.

Открыть безопасное обновление, резервное копирование и восстановление

OBS не слышит озвучивание

Обычное системное озвучивание часто слышно на компьютере, но не в источнике «Браузер» OBS. Используйте провайдера или браузерное озвучивание: Kokoro, Piper, Kitten, eSpeak, OpenAI-совместимый или облачный сервис. Либо направьте системный звук отдельно.

Открыть руководство по настройке озвучивания

Kokoro не говорит по-португальски или по-испански

Встроенные голоса Kokoro англоязычные. Для португальского используйте Piper с pipervoice=pt_BR-faber-medium, либо eSpeak с espeakvoice=pt-br. Для испанского используйте Piper с pipervoice=es_ES-davefx-medium, либо eSpeak с espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Открыть настройку провайдеров озвучивания

В Chrome работает, а в настольном приложении — нет

Настольное приложение использует сеансы Electron, а не обычный профиль Chrome. Войдите в окне источника приложения или используйте расширение Chrome, если платформа блокирует встроенные браузеры приложений.

Открыть режимы отдельного приложения

Какой локальный сервер нужен?

Включить локальный сервер — ретранслятор WebSocket для поддерживаемых страниц SSN. Локальный API управления предназначен для скриптов и ИИ-инструментов на том же компьютере. Запуск без интерфейса позволяет использовать полное настольное приложение на сервере Linux. Медиасервер Event Flow отдаёт только разрешённые локальные медиафайлы.

Открыть описание локальных серверов и сервисов

TikTok не работает или меняет режимы

Запишите режим приложения, провайдера подписывания, текст статуса, версию приложения и видимость чата в режиме Standard. Проверяйте режимы TikTok по одному.

Открыть режимы TikTok в приложении

Нет чата YouTube

Убедитесь, что трансляция идёт, чат виден и выбран правильный способ работы с YouTube: чат прямого эфира, обычные комментарии, захват Standard или режим WebSocket/API.

Открыть руководство по настройке YouTube

Ответы бота не отправляются

Чтение чата и отправка сообщений — разные возможности. Проверьте поддержку ответов на платформе, вход и роль аккаунта, режим источника, ответ провайдера и ограничения частоты запросов.

Открыть руководство по настройке ИИ-бота для чата

Event Flow ничего не делает

Убедитесь, что событие источника поступает в док-панель. Для звука, медиа и действий OBS держите actions.html?session=YOUR_SESSION открытым с тем же сеансом.
