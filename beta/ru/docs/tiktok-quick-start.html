Быстрый старт TikTok

Начните с этого, если нужно просто запустить чат TikTok Live.

1. Найдите TikTok

Откройте Поддерживаемые сайты и найдите TikTok. Это подтвердит основное правило настройки до изменения OBS.

2. Откройте страницу эфира TikTok

При использовании расширения браузера откройте страницу эфира автора и оставьте чат видимым.

https://www.tiktok.com/@CHANNEL/live

Если вкладки браузера постоянно приостанавливают или скрывают чат, попробуйте настольное приложение.

3. Используйте один ID сессии

Выберите один короткий ID сессии. Используйте в точности этот ID в источнике TikTok, доке и OBS.

YOUR_SESSION_ID

4. Проверьте док до OBS

Откройте док с вашим ID сессии. Отправьте или дождитесь одного сообщения чата TikTok.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

5. Добавьте оверлей в OBS

Добавьте источник «Браузер» в OBS и используйте тот же ID сессии.

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

Настройка шаблона: Быстрый запуск шаблона оверлея.

Если TikTok не появляется

  • Убедитесь, что на странице TikTok действительно идёт эфир.
  • Оставляйте чат видимым при использовании расширения браузера.
  • Убедитесь, что док и OBS используют один ID сессии.
  • Обновите док после изменения ID сессии.
  • Попробуйте настольное приложение, если браузер ограничивает работу вкладки.
