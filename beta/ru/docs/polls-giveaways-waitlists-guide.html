Для всех: скопируйте ссылку инструмента в OBS как Источник «Браузер»и оставьте Social Stream Ninja и источники чата включёнными. Не удаляйте сеанс или пароль.

Проведите опрос за 5 шагов

  1. Открыть Графический опрос → Параметры опроса. Задайте Тип опроса на Выбор из вариантов.
  2. Введите вопрос, например Во что сыграем дальше?и варианты через запятую, например Adventure, Puzzle.
  3. Установите Сопоставление голосов на Только точное совпадение голоса. Включите Включить опрос.
  4. Скопируйте ссылку опроса в OBS. Зрители отправляют только 1 или 2 (или название варианта).
  5. Нажмите Завершить опрос чтобы остановить голосование. Запишите результат, затем нажмите Сбросить опрос для следующего участника.

Полезно знать

  • Каждый зритель получает один голос. Включите Разрешить несколько голосов от пользователя чтобы изменить это.
  • Свободная форма опросы используют голоса с хештегом, например #yes. Хештег в любом месте учитывает хештег внутри более длинного сообщения.
  • Сохранить текущий опрос сохраняет настройки, а не результаты.

Свои цвета или шрифты: Настройте свой графический опрос.

Провести розыгрыш

Впервые? Ваш первый розыгрыш объясняет это со скриншотами.

  1. Открыть Инструмент розыгрышей → Параметры розыгрыша.
  2. Задайте Ключевое слово заявки, например !enter.
  3. Выберите Карточка победителя, Лента имён, или Колесо сообществаи один из шести стилей.
  4. Нажмите Предпросмотр экраназатем скопируйте ссылку в OBS как браузерный источник.
  5. Нажмите Открыть приём заявок. Когда будете готовы, нажмите Выбрать победителя.
  • Розыгрыш автоматически закрывает приём заявок.
  • Новый раунд очищает список участников и сохраняет прежних победителей в истории. Приём заявок изначально закрыт.
  • У каждой заявки одинаковый шанс. Пожертвования его не повышают.
  • Если Разрешить повторные победы не включено, победитель не может выиграть снова в том же раунде.
  • Участвовать могут только подписчики требует платформу, передающую сведения об участии.
Платные билеты, призы за баллы или игры? См. Розыгрыши, билеты и призы в баллах.
Подробнее: шансы, сохранение и ограничения
  • Предпросмотр использует вымышленные имена и не подключается к вашему сеансу. На экране OBS нет элементов управления.
  • Стиль и заголовок задаются в ссылке. Правила участия берутся из всплывающего окна при открытии приёма заявок.
  • Экраны с одним ID розыгрыша показывают общий список участников и победителя.
  • При платных билетах шанс зависит от их количества.
  • Одна заявка на человека на каждой платформе. Один человек на двух платформах учитывается дважды.
  • До 10 000 заявок. Колесо показывает до 120 имён, но выбирает из всех участников.
  • Старые, повторно доставленные, личные сообщения, сообщения ботов и чистые события игнорируются.
  • Раунды сохраняются для каждого сеанса в этом профиле браузера или приложения. Перезапуск закрывает открытые раунды для проверки. Ничего не удаляется.
Управляйте через API, Stream Deck или Event Flow

Всплывающее окно, HTTP/WebSocket API и Stream Deck используют эти общие действия. Открытый экран не нужен. В Event Flow используйте Розыгрыш / Билеты (подробности).

ДействиеЧто делает
startgiveawayОткрыть или возобновить приём заявок. Необязательное значение: {"giveawayId":"default","config":{"keyword":"!enter","match":"exact","membersOnly":false,"removeWinner":true}}. Без configсохраняет правила раунда (или настройки всплывающего окна для нового раунда).
closegiveawayЗакрыть приём заявок. Список участников сохраняется.
drawgiveawayЗакрыть приём заявок и выбрать победителя. Ошибка, если участников нет.
resetgiveawayНовый пустой закрытый раунд. Предыдущие победители переходят в историю. Сначала верните оплату за билеты.
getgiveawaystateПолучить число заявок, состояние приёма, правила и последних победителей.
 
{"action":"drawgiveaway","get":"draw-1"}

Stream Deck (протокол 2) использует те же имена. Его ответ касается розыгрыша, а не показа в OBS.

Старое отдельное колесо сообщества (без managed в ссылке) хранит собственный список участников и игнорирует эти действия.

Быстрый розыгрыш победителя из очереди

  1. Открыть Список ожидания / выбор победителя и разверните настройки. Включите триггер и задайте команду, например !join.
  2. Включите Использовать режим выбора победителя вместо очереди. Скопируйте обновлённую ссылку в OBS.
  3. Сообщите зрителям команду.
  4. Когда приём заявок завершён, нажмите Остановить приём, затем Выбрать победителя.
  5. Нажмите Скачать список чтобы сохранить заявки, затем Сбросить розыгрыш чтобы очистить их.

Организуйте очередь зрителей

Настройка такая же, как для розыгрыша, но режим розыгрыша выключен. Зрители вступают с помощью вашей команды.

КнопкаИспользуйте его, чтобы
Выделить первого участникаПоказать следующего участника.
Удалить первого участникаПерейдите дальше после хода участника.
Выбрать имяВыбрать кого-то случайно, а не по очереди.
Остановить приёмЗакрыть очередь для новых участников.
Скачать список / сбросить очередьСохраните копию в файле TSV, затем очистите список, когда закончите.

Разрешить удалённым участникам вступать снова определяет, могут ли участники снова встать в очередь.

Команды чата для модераторов

Включите Включить команды управления очередью чтобы модераторы, ведущий и администраторы могли управлять очередью из чата.

!wlstop · !wlremove · !wlreset · !wlpick · !wlhighlight

Некоторые принимают число, например !wlpick 3 или !wlremove 2.

Сначала проверьте, затем устраните проблемы

Перед эфиром отправьте несколько тестовые сообщения от разных вымышленных пользователей и проверьте результат в OBS.

ПроблемаЧто попробовать
Голоса не учитываютсяПроверьте, что опрос включён и не завершён, ответ точно совпадает с вариантом и зритель ещё не голосовал.
Никто не может вступитьПроверьте, что триггер включён, команда точная, приём заявок не остановлен и ограничение для участников не блокирует зрителя.
Виден счётчик, но нет спискаЭто режим розыгрыша. Он показывает список участников и победителей, а не очередь.
OBS показывает другоеВставьте ссылку в OBS заново и проверьте сеанс и пароль. Не запускайте две страницы опроса с разными настройками.
