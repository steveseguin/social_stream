Tip Jar and Goal Meter

Put a donation goal on stream that fills up every time someone supports you.

Seadke see üles Animated artwork Pick a look Quick tweaks What counts When the goal fills Probleemide lahendamine

Seadistage see 5 sammuga

  1. Turn on your YouTube, Twitch, or other chat source in Social Stream Ninja.
  2. In the menu, find Tip Jar and Goal Meter and open Style, Goal, and Filters.
  3. Choose a Display Style, such as Fluid Goal Bar.
  4. Under Goal Settings, set Goal target to 500 and enter a Custom Title.
  5. Click [copy link] beside Tip Jar and Goal Meter and add the link to OBS as a Browser Source.

Nothing showing up? The overlay link and Social Stream must use the same session ID. Keep that link private.

Change artwork as the goal fills

For a bar that fills with donations, choose Fluid Goal Bar või Goal Meter. The styles below include built-in animations.

To show your own GIF at 0%, 25%, 50%, 75%, and 100%, customize a copy of the overlay. There is no milestone-GIF picker in the built-in options. Keep the artwork and bar in the same custom overlay so they use the same total.

Follow the step-by-step GIF tutorial for a $500 example, artwork filenames, an AI customization prompt, and preview checks.

What counts toward the goal

Pick one. Changing the look (jar, bar, etc.) never changes what counts.

Money

Super Chats, Bits, tips, and other donations add their value.

$63.50 / $100

Number of donations

Every donation adds one, whatever the amount.

7 / 20 Super Chats

Hype points

Donations plus subs, memberships, and gifted subs.

340 / 1000 points

Count Super Chats instead of money

  1. Leave Hype Cup Scoring off.
  2. Määra Goal measures juurde Number of qualifying donations.
  3. Määra Source filter juurde YouTube.
  4. Määra Paid event filter juurde Super Chats only.
  5. Set the goal, for example 20.

A $1 and a $100 Super Chat each add one. To count Super Stickers too, change the paid event filter. Count unit label changes the word shown.

Count subs and memberships too

  1. Lülitage sisse Hype Cup Scoring.
  2. Leave Donation type filter on All donations.
  3. Set how many points each thing is worth (below).

How YouTube gifts are counted
YouTube eventHow it counts
Super Chat / Super StickerIts value for a money goal, one for a donation-count goal, or your configured donation points in Hype mode. The event must pass your filters.
Gifted membershipsHype only: number of gifts × gift points. YouTube doesn't send the price, so the cash value is unknown.
Someone receiving a giftIgnored by default, so gifts aren't counted twice.
Jewels / virtual giftsUse the matching donation type filter.

Only turn on Count individual gift recipients too if you want to add points on top of the gift itself.

Reusing OBS for a new goal? Saved totals are stored in that browser or OBS profile, not per session. Reset the amount first.

Probleemide lahendamine

ProbleemProovi seda
Nothing updatesCheck the source is on, the session IDs match, and your filters allow that event.
Memberships or subs don't countTurn on Hype Cup Scoring and set Donation type filter to All donations.
Gifted memberships add too littleThey use your gift points setting, not a price. Raise the points.
Gifted memberships count twiceTurn off Count individual gift recipients.
Gifted memberships shouldn't countTurn on Exclude YouTube gifted memberships.
Total drops to zero at the goalHype goals restart by default. Use Keep total and advance target.
An old total comes backKeep amount between sessions is on. Reset the amount.
Super Chat count includes Super StickersSet Paid event filter to Super Chats only.

The test buttons only send donations. To test memberships or gifts, watch the Dock or Activity Feed / Events on the same session and check the event arrives.
