Start Here

Download the correct version→Read the system message→Follow the matching steps

Windows and macOS sometimes ask for extra confirmation before running an app downloaded outside their app stores. This is especially common with a new release, a less frequently downloaded app, or a private/custom build.

Never bypass a security warning unless you are comfortable doing so and fully understand what you are allowing. Only continue if you downloaded the app from the official Social Stream Ninja releases page or received a custom build from someone you trust. If you are unsure, stop and report the warning instead.

If the warning says the app contains malware, will damage your computer, or names a specific threat, do not allow it. Save a screenshot and check the troubleshooting section below.

Windows: "Windows Protected Your PC"

Example message Microsoft Defender SmartScreen prevented an unrecognized app from starting.

This warning normally means Windows does not yet have enough reputation information for that exact download. It is not the same as a malware detection.

  1. Confirm that the file came from the official releases page.
  2. In the blue warning window, select More info.
  3. Check that the app name is Social Stream Ninja or begins with socialstreamninja.
  4. If you understand the warning and are comfortable continuing, select Run anyway. Otherwise, close the warning and use one of the alternatives below.

Windows builds are self-signed and submitted to VirusTotal as an additional safety and reputation check. A self-signed certificate is not treated the same as a certificate issued by a Windows-trusted commercial authority, so Windows may show Unknown publisher or challenge a newly released file again.

Learn how Microsoft SmartScreen reputation works.

Windows: Defender Blocked Or Removed The File

Possible messages Threat found, Potentially unwanted app found, This app has been blocked, or Threat quarantined
  1. Avatud Windows Security from the Start menu.
  2. Select Virus & threat protection, then Protection history.
  3. Open the entry that mentions the Social Stream Ninja installer or portable app.
  4. Read the detection name and affected file path.
  5. If it is only an app-reputation or potentially unwanted app warning, the file came from the official releases page, and you fully understand and are comfortable with the choice, select Actions > Allow on device. You may need to download the file again.
Stop if Windows names a specific malware threat. Do not choose Allow until you have confirmed the download source and shared the detection name or screenshot with support.

Microsoft's Protection History instructions

Windows: Smart App Control Blocked The App

Smart App Control is different from the normal SmartScreen warning. Windows does not provide a one-app Run anyway exception for it.

  • On a work or school computer, ask the administrator to approve the app.
  • On a personal computer, use the browser extension või Lite web app if you do not want to change a device-wide security setting.
  • Smart App Control can be managed under Windows Security > App & browser control, but changing it affects protection for all apps. Review Microsoft's explanation before deciding.

macOS: Developer Or Notarization Warning

Possible messages Apple cannot check the app for malicious software, or the developer cannot be verified

Official macOS releases are intended to be signed and notarized. A private or custom third-party build might not be notarized, and a newly downloaded app can still require first-open approval.

  1. Confirm that the app came from the official releases page or from someone whose custom build you trust.
  2. Try to open the app once, then dismiss the warning.
  3. Avage Apple menu > System Settings > Privacy & Security.
  4. Scroll down to the Security section and find the message about the blocked app.
  5. If you understand the warning and are comfortable continuing, select Open Anyway, authenticate if asked, then select Avatud.

This makes an exception for that app. It does not require turning off Gatekeeper for every application.

Apple's guide to safely opening downloaded apps

macOS: "The App Is Damaged" Or "Will Damage Your Computer"

Do not use a Terminal command to strip the app's quarantine information. These messages can mean the download is incomplete or modified, a signature is invalid, or macOS detected a security problem.

  1. Move that copy to the Trash.
  2. Download the current macOS build again from the official releases page.
  3. Open the new copy without modifying the app bundle.
  4. If the message returns, take a screenshot showing the full wording and the macOS version, then contact support.

If Open Anyway is missing, try opening the app once more and check Privacy & Security again. On a managed Mac, the administrator may control this setting.

Linux: AppImage Will Not Start

The AppImage may need permission to run:

  1. Right-click the AppImage and open Omadused.
  2. Under Permissions, enable Allow executing file as program. The wording varies by desktop.
  3. Open the AppImage again.

You can also grant permission from a terminal:

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

If the error mentions chrome-sandbox, SUID sandbox, AppArmor, or unprivileged namespaces, follow the AppImage sandbox guide.

Safer Alternatives To Bypassing A Warning

You do not have to override an operating-system warning to use Social Stream Ninja.

  • Report the warning: send a screenshot and the details listed below so it can be investigated.
  • Try an older official release: if a new version is the only one being blocked or failing, return to the official releases page and use the most recent older version that worked for you. Export your settings first when possible.
  • Use the Chrome extension: install the Chrome Web Store version instead of the desktop app.
  • Use the web app: open Social Stream Ninja Lite when its smaller feature set is enough.
Older releases do not contain the newest fixes. Download them only from the official releases page, and move back to a current version once the problem is understood.

If It Still Will Not Open

Send support the following details:

  • A screenshot showing the complete warning.
  • Your operating system and version.
  • The exact filename you downloaded.
  • Whether this is the installer, portable app, AppImage, official macOS release, or a custom build.
  • Whether the same copy opened successfully before.
  • On Windows, the detection name from Protection History if one appears.
