Discord StreamKit and TikFinity Sources

Use a third-party overlay link as a read-only chat source in Social Stream Ninja.

Understand The Two Links

These setups use two different links:

  • Input link: the Discord StreamKit or TikFinity URL that you paste into Social Stream Ninja. Social Stream reads messages from it.
  • Output link: your Social Stream dock or overlay URL. Open the dock to test messages, then add an overlay URL to OBS.

If you only want the original Discord or TikFinity design on screen, paste its link directly into an OBS Browser Source. Use it as a Social Stream source when you want one combined chat, TTS, filtering, message highlighting, or other Social Stream features.

Which Option Should I Use?

Discord StreamKit

Reads new text messages from one Discord server channel through Discord's official Chat widget.

  • Requires the Discord desktop app to remain open.
  • Does not require you to install a bot in the server.
  • Read-only: Social Stream cannot reply to Discord through StreamKit.

TikFinity OBS Dock

Uses TikFinity as a fallback reader for TikTok LIVE chat and events.

  • Requires TikFinity to remain open and connected.
  • Useful when direct TikTok modes are missing or dropping messages.
  • Read-only: use a direct TikTok mode if you need replies.
Avoid duplicates: do not capture the same chat with both a direct source and one of these fallback sources at the same time.
Discord

Set Up Discord StreamKit

  1. Avage Discord StreamKit Overlay.
  2. Valige Install for OBS and authorize StreamKit when Discord asks.
  3. Select the Chat widget, then choose the server and text channel you want to capture.
  4. Copy the Chat widget's installation link. It should start with https://streamkit.discord.com/overlay/chat/.
  5. In the Social Stream desktop app, open Sources and Settings -> Discord.
  6. Valige Use a Discord StreamKit URL, paste the link, and add the source.
  7. Keep the Discord desktop app running while you capture.

With the Social Stream browser extension, enable Discord under the optional chat services and open the generated StreamKit Chat link in a browser tab.

  • Social Stream skips messages already visible when the page first opens. Send a new test message after the source is ready.
  • It captures new text, names, basic formatting, emoji, and the displayed name color.
  • It does not capture Discord calls, old message history, or reliably provide every avatar, attachment, reply, and role detail.
TikTok fallback

Set Up A TikFinity OBS Dock

  1. Open TikFinity and connect it to the TikTok LIVE account.
  2. Mine aadressile Overlays -> OBS Docks.
  3. Use the gear button to choose the events the dock should show, including chat.
  4. Copy the URL for Dock 1 or Dock 2.
  5. In the Social Stream desktop app, choose Other chat sites.
  6. Paste the TikFinity dock URL and activate the new source.
  7. Keep TikFinity open and connected while you are live.
  • The source is labelled TikFinity in setup, but its messages use the normal tiktok source type inside Social Stream.
  • This is a fallback reader, not a way to send TikTok replies.
  • Browser-extension users can also open a supported TikFinity Activity Feed widget URL containing /widget/vite/src/activity-feed/.

Validate The Full Workflow

  1. Open the Social Stream dock using your session ID.
  2. Send one new test message in the selected Discord channel or TikTok LIVE chat.
  3. Confirm it appears once in the Social Stream dock with the correct name and text.
  4. Add your preferred Social Stream overlay URL to an OBS Browser Source using the same session ID.
  5. Send another message and confirm it appears once in both the dock and OBS.
  6. Leave the source running for several minutes and confirm later messages continue arriving.

If Messages Do Not Appear

  • Test with a new message. Existing messages are intentionally not imported.
  • Confirm Discord or TikFinity is still open, signed in, and connected.
  • Confirm the copied link is for the Chat widget or OBS Dock, not its setup page.
  • Reload or recreate the Social Stream source after changing the selected server, channel, dock, or events.
  • Check the Social Stream dock before troubleshooting OBS. If the dock is empty, OBS is not the problem yet.
  • Treat copied source links as private setup information. Do not publish them or expose them while screen sharing.
