Rilevatore di font installati

Elenca i font utilizzabili dal browser, mostra un campione in tempo reale e fornisce un parametro URL per applicare il font a tutto il sito.

Come installare font personalizzati

  • Windows: Fai clic destro sul file .ttf o .otf → seleziona "Installa" o "Installa per tutti gli utenti" → riavvia il browser.
  • macOS: Fai doppio clic sul file .ttf o .otf → fai clic su "Installa font" in Libro Font → riavvia il browser.
  • Linux: Copia i file dei font in ~/.local/share/fonts/ → esegui fc-cache -fv → riavvia il browser.

Dopo l'installazione, aggiorna questa pagina per vedere i nuovi font. Se un font non compare, prova il pulsante "Prova API Local Fonts" (solo browser Chromium).

Rilevamento…

Usare un font specifico tramite URL

  • Parametro: Aggiungi ?font=<Font%20Family%20Name> all'URL. Spazi e simboli devono essere codificati nell'URL.
  • Si applica alla variabile CSS: Il sito usa --font-family; anche questa pagina la rispetta. Esempio: ?font=Segoe%20UI.
  • Virgolette non necessarie: Non includere virgolette nel parametro; non servono nella variabile CSS.
  • Solo installati: Il parametro funziona solo per i font già installati sul sistema. Non scarica webfont.

Compatibilità (app Ninja)

  • VDO.Ninja: Generato ?font= i link funzionano con overlay/scene che rispettano la variabile --font-family .
  • SocialStream.Ninja: Usa lo stesso ?font= per sostituire il font predefinito nei widget supportati.
  • Caption.Ninja: Applica ?font= agli overlay dei sottotitoli che supportano famiglie di font personalizzate.

Queste app accettano la sostituzione della famiglia di font quando il parametro ?font= è supportato nei loro URL o link di incorporamento. Questo strumento genera valori codificati correttamente e pronti all'uso.

Risoluzione dei problemi (Windows)

  • Nome esatto della famiglia: Usa il nome della famiglia del font (non il nome del file). Controlla Impostazioni → Personalizzazione → Caratteri per il nome corretto della famiglia.
  • Ambito di installazione corretto: Se hai installato un font per un altro utente Windows o solo tramite un account amministratore, la sessione browser potrebbe non vederlo. Se necessario, installalo “per tutti gli utenti”.
  • Formati supportati: I browser usano TrueType/OpenType/WOFF. I vecchi font Type 1 e alcuni font bitmap non funzionano.
  • Disponibilità di pesi/stili: Se è installato solo Bold, il testo normale potrebbe usare un font alternativo. Prova un campione in grassetto o installa anche Regular.
  • Limiti per la privacy: I browser non consentono l'elenco completo dei font senza autorizzazione. Questa pagina li rileva da un ampio elenco noto e dall'API Local Fonts facoltativa.
  • API Local Fonts: In Chromium su origini sicure (https/localhost), facendo clic su “Prova API Local Fonts” puoi elencare le famiglie esatte installate dopo aver concesso l'autorizzazione.

Suggerimenti per l'uso manuale

  • Forza un font: Nel tuo CSS: font-family: "Your Family", Avenir Next, Sora, Roboto, Helvetica, Arial, sans-serif;
  • Prova un nome qualsiasi: Usa la casella di ricerca per provare qualsiasi famiglia; se viene trovata, compare nei risultati con un campione.
  • Codifica: Crea link come: ?font=Segoe%20UI (i link generati sotto usano la codifica corretta).
  • Font CJK e di sistemi di scrittura: Il campione include caratteri latini, numeri e simboli. Sostituiscilo con testo del sistema di scrittura specifico per verificarne la composizione.

Nota: questa pagina non installa né scarica font; rileva e mostra in anteprima solo le famiglie già disponibili nel browser.
