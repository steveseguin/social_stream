Controllo OBS con Social Stream Ninja

Controlla OBS direttamente da Event Flow, senza bisogno di Streamer.bot. Questa guida tratta configurazione, ogni trigger e azione OBS, ricette pratiche e i controlli precedenti del dock/delle sorgenti browser.

1. Connetti Flow Actions a OBS

OBS WebSocket v5 è integrato in OBS 28 e versioni successive. Social Stream Ninja lo usa per il controllo completo di OBS e gli eventi multimediali.

  1. In OBS, apri Strumenti → Impostazioni server WebSocket.
  2. Attiva il server WebSocket. Mantieni la porta predefinita 4455; imposta una password se desideri.
  3. In Social Stream Ninja, apri la sezione Flow Actions e imposta l'URL OBS WebSocket e la password facoltativa.
  4. Copia l'URL Flow Actions e mantienilo aperto. Per le azioni overlay/audio è consigliata una sorgente browser OBS.
  5. Usa: Tester OBS WebSocket per verificare la connessione prima di creare un flusso.
Esempio di URL diretto
https://socialstream.ninja/actions.html?session=YOUR_SESSION&obsws=ws://127.0.0.1:4455

Aggiungi &obspw=YOUR_PASSWORD solo quando OBS richiede autenticazione. Aggiungi &obsdebug=1 per mostrare un piccolo badge di stato della connessione durante la diagnosi.
Mantieni in esecuzione la pagina Flow Actions. È il bridge che riceve le azioni Event Flow e invia richieste OBS WebSocket. Se è una sorgente browser OBS, disattiva Disattiva la sorgente quando non è visibile quando la sorgente deve continuare a controllare OBS mentre è nascosta.

2. Aggiungi nodi OBS a un flusso

  1. Apri Editor Event Flow e crea o modifica un flusso.
  2. Trascina un trigger nell'area di lavoro.
  3. Espandi OBS Studio nell'elenco Actions e trascina l'azione OBS necessaria.
  4. Collega il trigger all'azione, configura i nomi esatti di scene/sorgenti OBS, salva e attiva il flusso.
I nomi OBS devono corrispondere esattamente, inclusi spazi e punteggiatura. Le azioni delle sorgenti puntano al nome dell'ingresso OBS, non all'etichetta dell'elemento della scena se è stata rinominata separatamente.

Set Text Source e variabili del flusso

Il campo testo supporta i normali segnaposto dei messaggi, ad esempio {username}, {message}, {source}, e {donation}, oltre ai valori aggiunti dai nodi precedenti del flusso, come {counterValue}, {counterTarget}, e {counterRemaining}.

{username}: now {counterValue}, need {counterTarget}
Per una sorgente Testo (GDI+) o Testo (FreeType 2), disattiva Leggi da file. Altrimenti OBS potrebbe continuare a mostrare il contenuto del file anziché il testo inviato da Event Flow.

Controlli della sorgente multimediale

Riproduci / Pausa

Riproduci riprende un contenuto in pausa. Pausa mantiene la posizione corrente.

Riavvia / Ferma

Riavvia riparte dall'inizio. Ferma termina la riproduzione e ripristina l'ingresso.

Successivo / Precedente

Scorre gli ingressi che supportano playlist, come Sorgente video VLC. Una Sorgente multimediale con un solo file potrebbe ignorare queste azioni.

Volume, muto e filtri

Imposta volume sorgente (Set Source Volume) usa i dB, come la scala del mixer OBS: 0 dB corrisponde a guadagno invariato, i valori negativi abbassano il volume e -100 dB è di fatto silenzioso. Muto è uno stato separato. Toggle Filter cambia solo lo stato di attivazione di un filtro esistente; non ne modifica le impostazioni.

Buffer replay

Attiva prima il buffer replay in Impostazioni OBS → Output. Usa Controlla buffer replay (Control Replay Buffer) per avviarlo/fermarlo, poi Salva buffer replay (Save Replay Buffer) per scrivere su disco il segmento recente nel buffer.

Avviso sull'uscita live: Start/Stop Streaming e Start/Stop Recording agiscono immediatamente. Usa trigger restrittivi, autorizzazioni e tempi di attesa affinché i normali messaggi chat non possano attivarli accidentalmente.

5. Ricette utili

Messaggio ogni ora mentre OBS è in diretta

Nell'editor Event Flow, scegli Inizia da un modello → Intermedio → Messaggio ogni ora mentre OBS è in diretta (Start with a template → Intermediate → Hourly message while OBS is live). Parte disattivato e contiene tre rami in un solo flusso:

  • OBS Stream Started → Set Gate State: ON
  • Intervallo di tempo (3600 secondi) → Interruttore ON/OFF → Invia messaggio
  • OBS Stream Stopped → Set Gate State: OFF

Entrambe le azioni Set Gate State puntano già allo stesso interruttore, che ha OFF come predefinito. Modifica Invia messaggio (Send Message) per scegliere piattaforma chat (l'esempio usa Twitch) e messaggio. Scegli una piattaforma o All Platforms; Reply to Source non può rispondere a un evento OBS o a un tick del timer.

Connetti Flow Actions a OBS, mantieni connessi Social Stream e la chat di destinazione, poi salva e attiva il flusso prima di avviare la diretta. L'interruttore attende un evento di avvio OBS; caricarlo durante una diretta già in corso non lo imposta su ON. Anche riavviare Social Stream riporta l'interruttore su OFF.

Temporizzazione: l'intervallo segue una propria cadenza, quindi il primo promemoria potrebbe arrivare prima che sia passata un'ora dall'inizio della diretta. I promemoria successivi si ripetono ogni ora mentre l'interruttore è ON. Cambia il valore Time Interval per una frequenza diversa; è misurato in secondi.

Testo del contatore in OBS

Posiziona Imposta sorgente di testo (Set Text Source) dopo il percorso del contatore/controllo e usa:

{username}: now {counterValue}, need {counterTarget}

Esegui qualcosa dopo un video

Contenuto multimediale OBS terminato (OBS Media Ended) (filtra su Intro Video) → Cambia scena (Change Scene) a Main.

Riavvio dei contenuti multimediali controllato dalla chat

Il messaggio è uguale a (Message Equals) !replayintro → condizione autorizzazione → Controlla sorgente multimediale: riavvia (Control Media Source: Restart).

Aggiorna una pagina di avvisi

Il messaggio è uguale a (Message Equals) !refreshalerts → condizione moderatore → Aggiorna sorgente browser (Refresh Browser Source).

Abbassa la musica per un avviso

Imposta volume sorgente (Set Source Volume) a -24 dB → azione di avviso → Ritardo → ripristina a 0 dB.

Flusso di lavoro del replay

Diretta OBS avviata (OBS Stream Started) → Controlla buffer replay: avvia (Control Replay Buffer: Start); un comando attendibile separato esegue Salva buffer replay (Save Replay Buffer).

7. Risoluzione dei problemi

ProblemaControlla
Non succede nullaIl flusso è salvato e attivo; Flow Actions è aperto; entrambi usano lo stesso ID di sessione.
OBS non si connetteIl server WebSocket è attivo, l'URL è ws://127.0.0.1:4455, e la password corrisponde. La porta 4444 è il vecchio valore predefinito v4.
Scena/sorgente/filtro non trovatoCopia il nome OBS esatto. Per la visibilità, imposta Scene o Group quando l'elemento è annidato o fuori dalla scena corrente.
Il testo non cambiaUsa Testo (GDI+) o Testo (FreeType 2), verifica il nome dell'ingresso e disattiva Leggi da file.
Media Ended non si attiva maiUsa OBS WebSocket v5 e un vero ingresso multimediale. Un contenuto in loop non raggiunge lo stato terminato.
Successivo/Precedente non fa nullaUsa una sorgente con supporto playlist, come Sorgente video VLC.
Il salvataggio del replay non riesceAttiva il buffer replay nelle impostazioni Output di OBS e avvialo prima di salvare.
Le azioni si fermano quando cambia la scenaDisattiva Disattiva la sorgente quando non è visibile nella sorgente browser Flow Actions, oppure mantieni aperta la pagina altrove.
Ordine diagnostico: apri il tester → verifica GetVersion → verifica scene/ingressi → prova la singola richiesta → prova l'intero Event Flow.
