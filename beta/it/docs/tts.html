Panoramica

SSN può leggere il testo chat acquisito da qualsiasi sorgente supportata; la piattaforma chat non deve avere una propria funzionalità TTS. Il dock o l'overlay con TTS attivo legge i messaggi che riceve, in base ai suoi filtri e alle impostazioni TTS. Parti dalla breve guida alla configurazione; questa pagina tratta opzioni vocali e impostazioni avanzate. Confronta i provider, ascolta esempi e guarda le impostazioni.

Avvio rapido: Usa dock.html?session=YOUR_SESSION&speech=en-US. Usa System TTS per impostazione predefinita. Per un provider OBS gratuito, aggiungi anche &ttsprovider=kokoro. Mantieni questa pagina aperta e connessa; deve parlare una sola copia.

Dove viene usato TTS?

  • Social Stream Ninja: Legge ad alta voce i messaggi chat del pubblico in diverse aree
  • CAPTION.Ninja: Offre sottotitoli, trascrizione e traduzione con TTS
  • Entrambi i servizi offrono opzioni TTS premium e gratuite
System TTS non coincide con tutti i TTS gratuiti:
  • Le voci di sistema dipendono dal browser e dal sistema operativo. OBS potrebbe non esporre voci utilizzabili, anche quando Chrome/Edge funziona.
  • Una voce mancante è diversa da una voce riprodotta fuori dall'acquisizione audio di OBS. L'instradamento audio non può risolvere la mancanza del supporto vocale.
  • I provider gratuiti come Kokoro, Piper, Kitten ed eSpeak generano invece audio della pagina. Per usare TTS in OBS non serve pagare.
  • Controlla la disponibilità della voce, poi l'acquisizione audio.

Opzioni dei provider TTS

TTS di sistema (gratuito)

  • Usa le voci integrate del sistema operativo
  • Supporto linguistico limitato in base all'installazione del sistema
  • Disponibilità delle voci e instradamento audio dipendono da browser e sistema operativo; prova nel lettore effettivo
  • La compatibilità varia molto tra browser

Limiti del browser:
  • Non tutti i browser supportano la sintesi vocale allo stesso modo (alcune versioni di Firefox hanno voci limitate)
  • Chrome offre opzioni TTS basate su Google
  • Edge supporta Microsoft TTS e le voci dei pacchetti lingua Windows
  • Safari richiede un'interazione dell'utente per avviare l'audio
  • Controlla voci disponibili per il tuo browser

Metodi di acquisizione audio Windows TTS per OBS

Audio della pagina: provider locali gratuiti e cloud

I provider locali di SSN basati su browser e quelli audio cloud riproducono l'audio generato attraverso la pagina:

  • Attiva semplicemente "Controlla l'audio tramite OBS" nella sorgente browser
  • Non servono cavi audio virtuali
  • Funziona con l'app SSN e le sorgenti browser OBS

Metodi di acquisizione di System TTS

Importante: Verifica prima che System TTS generi la voce. Il browser integrato di OBS potrebbe non esporre una voce di sistema utilizzabile. Se non genera voce, cambiare l'instradamento audio non aiuterà. Scegli un altro provider oppure genera la voce in un browser supportato e acquisisci il suo audio.

Per System TTS nello specifico:

  • Non dare per scontato che OBS esponga le stesse voci di Chrome o Edge
  • Supporto limitato tra browser (Firefox potrebbe non avere alcune voci TTS)
  • Chrome offre opzioni basate su Google, Edge offre opzioni Microsoft
  • Se la voce viene riprodotta fuori dalla sorgente browser della scena, acquisisci quell'uscita separatamente

Download per l'instradamento: VB-Audio Virtual Cable | Voicemeeter | Audio Router (precedente)

Prova prima ad acquisire il browser che parla con l'audio dell'applicazione o del desktop in OBS, dove supportato. I metodi con cavo virtuale qui sotto sono alternative facoltative; non aggiungono il supporto vocale a OBS.

Metodo 1: percorso audio predefinito con un cavo virtuale

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Metodo 2: percorso dell'app in Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Metodo 3: percorso dell'app in Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Metodo 4: software Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Metodo 5: Voicemeeter (avanzato)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Provare la configurazione

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Alternative: Usa un provider gratuito integrato come Kokoro, Piper, Kitten o eSpeak, un provider cloud oppure un server TTS ospitato da te.

Installare pacchetti lingua aggiuntivi

Windows 11

  1. Vai a Start > Impostazioni > Data/ora e lingua > Riconoscimento vocale
  2. Sotto Gestisci voci, fai clic su Aggiungi voci
  3. Seleziona le lingue desiderate e fai clic su Aggiungi
  4. Riavvia i browser per aggiornare le voci disponibili

Windows 10

Segui le istruzioni della guida ufficiale Microsoft per installare i pacchetti lingua.

Suggerimento: Alcune voci di terze parti potrebbero non comparire nei browser per problemi di compatibilità. Firefox spesso mostra più voci di sistema dei browser basati su Chromium.

Configurazione del provider TTS

TTS Kokoro (gratuito, integrato)

  • Attiva con ?ttsprovider=kokoro
  • Funziona nel browser tramite WebGPU/WASM: nessun server necessario
  • Funziona direttamente con la sorgente browser OBS
  • Selezione voce: &voicekokoro=af_bella
  • Controllo della velocità: &kokorospeed=1.2
  • Scegli una voce per la lingua: &voicekokoro=ef_dora per lo spagnolo oppure &voicekokoro=pf_dora per il portoghese brasiliano. Cambiare &speech= da solo non cambia la voce selezionata. Gli ID delle voci inglesi esistenti continuano a funzionare.

TTS Piper (gratuito, integrato)

  • Attiva con ?ttsprovider=piper
  • TTS neurale rapido e leggero sulla CPU, eseguito nel browser
  • Selezione voce: &pipervoice=en_US-hfc_female-medium
  • Voci portoghesi: &pipervoice=pt_BR-faber-medium oppure &pipervoice=pt_BR-edresson-low
  • Voci spagnole: &pipervoice=es_ES-davefx-medium oppure &pipervoice=es_MX-ald-medium
  • Controllo della velocità: &piperspeed=1.0

TTS Kitten (gratuito, integrato)

  • Attiva con ?ttsprovider=kitten
  • TTS leggero basato su ONNX, eseguito nel browser
  • Selezione voce: &kittenvoice=expr-voice-4-f

eSpeak-NG (gratuito, integrato)

  • Attiva con ?ttsprovider=espeak
  • TTS classico open source, funziona su qualsiasi hardware
  • Selezione voce: &espeakvoice=en
  • Esempio in portoghese: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Esempio in spagnolo: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Controllo della velocità: &espeakspeed=175

Esempi TTS in portoghese e spagnolo

  • Portoghese, migliore qualità locale gratuita provata in SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Portoghese, alternativa più rapida provata in SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Spagnolo, migliore qualità locale gratuita provata in SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Spagnolo, alternativa più rapida provata in SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Per le voci cloud, usa una voce/lingua del provider che supporti la lingua desiderata, ad esempio Google Cloud, ElevenLabs, Speechify, Gemini o un server locale compatibile con OpenAI.

TTS OpenAI / server locale

  • Attiva con ?ttsprovider=openai
  • Usa ?ttsprovider=customtts oppure ?ttsprovider=localtts per un endpoint ospitato da te
  • Usa per impostazione predefinita l'API OpenAI oppure qualsiasi server locale compatibile
  • Endpoint personalizzato: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Importante: localhost e 127.0.0.1 indicano lo stesso computer che riproduce la pagina TTS. Se OBS è su un computer diverso dal server TTS, usa invece l'IP LAN del computer del server.
  • Nessuna chiave API necessaria per i server locali
  • Se il server locale ha problemi CORS o di rete locale in Chrome/OBS, esegui npm run local-tts-bridge sul computer OBS e indirizza SSN verso http://127.0.0.1:8124/v1/audio/speech
  • SSN invia { model, input, voice, response_format, speed } e supporta audio binario, URL audio JSON e audio JSON in base64
  • La riproduzione da endpoint personalizzati/locali attualmente usa il buffering; SSN non riproduce ancora progressivamente i blocchi audio in streaming
  • Voce: &voiceopenai=af_bella, velocità: &openaispeed=1.0. Usa un nome di voce supportato dal server; le voci Kokoro hanno nomi come af_bella, mentre le voci openedai-speech/in stile OpenAI potrebbero essere come nova oppure echo.
  • Consulta Guida al TTS con IA locale per configurare un server ospitato da te

Google Cloud TTS

  • Attiva con ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Voci di qualità professionale
  • Selezione voce: &voicegoogle=en-GB-Standard-A
  • Lingua: &googlelang=en-US

TTS Gemini

  • Attiva con ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Modello: &geminimodel=gemini-2.5-flash-preview-tts
  • Voce: &voicegemini=Kore, lingua: &geminilang=th-TH
  • Istruzioni di stile: &geministyle=Read aloud in a warm tone.

TTS ElevenLabs

  • Attiva con ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • ID voce: &voice11=YOUR_VOICE_ID
  • Modello: &elevenlabsmodel=eleven_multilingual_v2
  • Parametri: stabilità, somiglianza e stile sono regolabili

TTS Fish Audio

Scegli Fish Audio e inserisci la chiave API, con un ID voce facoltativo. Il modello predefinito è s2.1-pro-free. Configurazione, opzioni dei modelli e limiti di accesso dal browser.

TTS Speechify

  • Attiva con ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Voce: &voicespeechify=henry
  • Modello: &speechifymodel=simba-3.0 (predefinito), oppure &speechifymodel=simba-3.2 per l'inglese.
  • Velocità di parlato: &speechifyspeed=1.2 (intervallo da 0,5 a 3,0; il valore normale è 1,0).
  • Guida alla configurazione, alle voci, alla velocità e al volume di Speechify

Risoluzione dei problemi

Problemi comuni

  • Nessun audio riprodotto: Verifica che TTS sia attivo, che la pagina che genera TTS sia aperta e che la sorgente browser non sia muta. In un browser normale, fai clic una volta sulla pagina.
  • Le voci non compaiono: Riavvia il browser dopo aver installato i pacchetti lingua
  • OBS non acquisisce: Se non c'è voce, controlla prima la disponibilità di voce/provider. Se la voce c'è, controlla Controlla l'audio tramite OBS, il muto del mixer e le tracce di uscita, oppure acquisisci il browser esterno che sta parlando
  • L'endpoint locale funziona nel test dell'app ma non in OBS: OBS è un browser separato. Controlla l'endpoint dal computer OBS, soprattutto se usi 127.0.0.1.
  • Vengono lette solo la prima lettera o le prime parole: rimuovi ttsquick dall'URL OBS, se presente.
  • Problemi con Safari: Safari ha un supporto limitato per TTS automatico
  • Il servizio premium non funziona: Controlla la chiave API e verifica che il provider sia specificato correttamente

Buone pratiche

  • Usa un provider che genera audio della pagina per semplificare la configurazione OBS; sono disponibili provider locali gratuiti
  • Prova la configurazione con frasi semplici prima di andare in diretta
  • Considera i rischi dei contenuti generati dagli utenti quando usi TTS
  • Tieni a disposizione un interruttore per disattivare rapidamente TTS se necessario
