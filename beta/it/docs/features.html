Funzioni

Riunisci le tue chat, porta il pubblico sullo schermo e dai a ogni diretta il tuo stile.

Esplora 126 idee per le dirette · Anteprima delle ricompense sticker

Integrazione delle chat multipiattaforma

Interagisci contemporaneamente con gli spettatori di tutte le tue piattaforme. Social Stream Ninja riunisce i messaggi di chat di decine di piattaforme in un'unica dashboard facile da gestire.

  • Messaggi di chat bidirezionali in tempo reale con Facebook, YouTube, Twitch, Zoom e altre piattaforme
  • Nessun accesso o chiave API richiesti per la maggior parte delle piattaforme
  • Icone delle sorgenti multicanale per distinguere le piattaforme
  • Inoltro automatico dei messaggi tra piattaforme

Overlay dei messaggi in evidenza

Metti in evidenza i migliori messaggi del pubblico direttamente nella diretta con overlay belli e personalizzabili.

  • Seleziona i messaggi tramite la dashboard agganciabile
  • Selezione automatica o manuale dei messaggi
  • Personalizzabile con CSS per integrarsi perfettamente con lo stile della diretta
  • Opzioni di animazione con effetti di dissolvenza e scorrimento
  • Coda dei messaggi per una messa in evidenza organizzata

Comandi dei bot e risposte automatiche

Crea interazioni automatiche con il pubblico tramite comandi e risposte personalizzati.

  • Comandi integrati per le interazioni comuni
  • Logica personalizzata dei comandi con un file plugin programmabile
  • Saluti e risposte automatici
  • Filtri e moderazione dei messaggi

Integrazione IA e LLM

Scegli un co-conduttore vocale, un bot di chat, un assistente nel browser o strumenti mirati di elaborazione IA senza vincolare il resto della diretta a un unico provider.

  • Co-conduttore vocale che può ascoltarti e ricevere messaggi selezionati della chat in diretta
  • Bot di chat principale e privato con istruzioni personalizzate e regole di attivazione
  • Modelli locali o provider cloud, tra cui OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq e API personalizzate compatibili
  • Moderazione, traduzione, riepiloghi, contesto RAG e creazione di overlay
  • Acquisizione facoltativa di ChatGPT nel browser senza chiave API

Sintesi vocale

Dai voce ai messaggi della chat con la sintesi vocale, rendendo la diretta più coinvolgente e accessibile.

  • Supporto gratuito del TTS di sistema
  • Integrazione di servizi TTS premium (Google Cloud, ElevenLabs, Speechify)
  • Supporto multilingue
  • Voce, tonalità e velocità di lettura personalizzabili
  • Supporto dell'acquisizione audio OBS

API potente

Estendi le funzionalità di Social Stream Ninja con solide opzioni di integrazione API.

  • Supporto webhook per integrazioni esterne
  • API del server per il controllo remoto
  • Integrazione delle donazioni (NinjaBacker: gratuito, commissione della piattaforma 0%, Stripe, Ko-Fi, Buy Me A Coffee)
  • Controllo MIDI/Streamdeck
  • Supporto delle scene OBS remote

Personalizzazione avanzata

Rendi Social Stream Ninja davvero tuo grazie alle numerose opzioni di personalizzazione delle funzioni e dell'aspetto.

  • Stile CSS per un controllo visivo completo
  • Modelli e temi già pronti
  • Supporto per JavaScript personalizzato
  • Parametri URL per una configurazione semplice
  • Filtri delle sorgenti e opzioni di personalizzazione del marchio

Strumenti avanzati per le dirette

Migliora le tue dirette con la nostra serie di strumenti professionali pensati per coinvolgimento e interazione.

  • Minigiochi interattivi, incluso Battle Royal
  • Sistema di estrazioni a premi con gestione della coda
  • Ringraziamenti scorrevoli e visualizzazioni del barattolo delle mance
  • Nuvola di parole e comandi GIF personalizzati
  • Sistema grafico di sondaggi
  • Database della cronologia della chat con ricerca
  • Interfaccia privata del bot di chat IA
  • Funzioni di co-conduttore IA multimodale
