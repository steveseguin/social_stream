Assegna colori diversi ai nomi della chat

Scegli come il dock deve mostrare o generare i colori dei nomi utente.

Configurazione rapida

Non è richiesta un'impostazione globale: scegli un'opzione nella sezione del dock Colori dei nomi utente .
  1. Apri le impostazioni dell'estensione o dell'app desktop Social Stream Ninja.
  2. Sotto Overlay chat principale e dock di controllo (Main chat overlay & control dock), espandi Colori dei nomi utente.
  3. Attiva Genera colori per i nomi senza colore. Mantiene i colori forniti dalla piattaforma chat e aggiunge quelli mancanti.
  4. Usa il link aggiornato del dock. Gli URL esistenti del dock o delle sorgenti browser OBS funzionano anche aggiungendo &randomcolor e aggiornandoli.

Scegli il comportamento dei colori

Usa una sola opzione colore principale alla volta per un risultato prevedibile.

Opzione del dock Risultato Ideale per
Genera colori per i nomi senza colore Mantiene i colori dei nomi forniti dalla piattaforma e assegna un colore coerente quando manca. La maggior parte degli utenti
Genera colori per ogni nome Assegna a ogni nome utente un colore generato coerente, sostituendo quelli della piattaforma. Una chat con colori completamente diversi
Usa i colori dei nomi utente forniti dalla sorgente Mostra un colore solo quando la piattaforma chat ne fornisce uno. Piattaforme come Twitch che forniscono colori dei nomi utente

I colori generati sono stabili: il dock calcola un hash dell'ID utente, del nome utente o del nome visualizzato, così la stessa persona mantiene lo stesso colore. Le impostazioni globali dei colori restano disponibili quando occorre aggiungere colori ai payload in uscita e alle altre interfacce.

Se i nomi sono ancora di un solo colore

  1. Conferma che un'opzione sia attiva nella sezione del dock Colori dei nomi utente .
  2. Per le piattaforme senza colori dei nomi utente, scegli Genera colori per i nomi senza colore.
  3. Controlla che l'URL del dock contenga &color, &randomcolor, oppure &randomcolorall.
  4. Aggiorna le schede del dock o le sorgenti browser OBS già aperte.
  5. Controlla se nel CSS personalizzato c'è una regola che forza ogni .hl-name allo stesso colore.

Più controllo con CSS

Aggiungi CSS dalle impostazioni del dock, dall'opzione &css= oppure &b64css= URL oppure dal CSS personalizzato della sorgente browser OBS. Usa !important quando sostituisci un colore del nome fornito da una piattaforma.

Usa un colore per ogni nome

.hl-name {
  color: #ffd166 !important;
}

Scegli i colori per piattaforma

.highlight-chat[data-source-type="youtube"] .hl-name {
  color: #ff5a5f !important;
}

.highlight-chat[data-source-type="twitch"] .hl-name {
  color: #b794f4 !important;
}

.highlight-chat[data-source-type="kick"] .hl-name {
  color: #53fc18 !important;
}

Evidenzia moderatori e VIP

.highlight-chat.mod .hl-name {
  color: #5eead4 !important;
}

.highlight-chat.vip .hl-name {
  color: #f472b6 !important;
}

Il CSS può selezionare in modo affidabile una piattaforma o un ruolo, ma il dock standard non aggiunge il nome utente come classe o attributo CSS. Per regole di colore fisse per persona, usa i colori generati integrati oppure un overlay personalizzato che associ i nomi utente ai colori in JavaScript.
