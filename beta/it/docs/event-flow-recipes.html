A cosa serve Event Flow

Esegui un flusso personalizzato da un tasto Stream Deck o da una chiamata API HTTP/WebSocket/P2P.

Event Flow è l'editor di automazione avanzata. Usalo quando gli interruttori del popup non bastano: filtra la chat, attiva contenuti multimediali, inoltra messaggi, chiama webhook o controlla OBS.

Prima di ogni esempio

  1. Usa una sola piattaforma di prova e una sola sessione Social Stream.
  2. Apri il dock e verifica che arrivino messaggi.
  3. Apri actions.html?session=YOUR_SESSION se l'esempio riproduce audio o contenuti multimediali, oppure controlla OBS.
  4. Prova con un messaggio simulato o un trigger sicuro prima della diretta.
  5. Esporta un flusso funzionante prima di modificarlo in modo significativo.

Esempio multimediale per ricompense Kick

È lo schema pratico più comune in Event Flow: riconoscere una ricompensa, poi riprodurre contenuti tramite Flow Actions.

Approfondimento completo: Guida a suoni e contenuti delle ricompense Kick.

Soluzioni ai problemi comuni

  • Non succede nulla: prima verifica che l'evento sorgente arrivi nel dock.
  • Audio o contenuti multimediali non vengono riprodotti: lascia actions.html aperto con la stessa sessione, poi controlla Guida all'hosting multimediale di Event Flow.
  • L'azione OBS non riesce: controlla OBS WebSocket v5, porta 4455, password e permessi.
  • Il flusso si attiva troppo spesso: aggiungi un filtro più rigoroso per piattaforma, evento, parola chiave o utente.
