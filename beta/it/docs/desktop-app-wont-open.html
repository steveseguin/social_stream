L'app desktop non si apre

Usa il messaggio esatto sullo schermo per avviare Social Stream Ninja in sicurezza.

Inizia qui

Windows e macOS a volte chiedono un'ulteriore conferma prima di eseguire un'app scaricata al di fuori dei rispettivi store. È particolarmente comune con una nuova release, un'app scaricata poco frequentemente o una build privata o personalizzata.

Non aggirare un avviso di sicurezza se non sei a tuo agio nel farlo e non comprendi pienamente cosa stai autorizzando. Continua solo se hai scaricato l'app dalla pagina ufficiale delle release di Social Stream Ninja o hai ricevuto una build personalizzata da una persona fidata. In caso di dubbi, fermati e segnala l'avviso.

Se l'avviso dice che l'app contiene malware, danneggerà il computer o indica una minaccia specifica, non autorizzarla. Salva una schermata e consulta la sezione di risoluzione dei problemi sotto.

1. Verifica la provenienzaApri la pagina ufficiale delle release e scarica una nuova copia se hai dubbi.
2. Individua il messaggioLe parole dell'avviso determinano quali istruzioni qui sotto si applicano.
3. Conserva l'avvisoFai una schermata prima di chiuderlo, nel caso serva al supporto.
WindowsSmartScreen, Defender o Smart App Control macOSAvviso di Gatekeeper, dello sviluppatore o della notarizzazione LinuxErrore di permessi o sandbox dell'AppImage

Windows: «Windows ha protetto il PC»

Messaggio di esempio Microsoft Defender SmartScreen ha impedito l'avvio di un'app non riconosciuta.

Questo avviso normalmente indica che Windows non ha ancora abbastanza informazioni sulla reputazione di quello specifico download. Non equivale a un rilevamento di malware.

  1. Verifica che il file provenga dalla pagina ufficiale delle release.
  2. Nella finestra blu dell'avviso, seleziona Ulteriori informazioni.
  3. Verifica che il nome dell'app sia Social Stream Ninja o inizi con socialstreamninja.
  4. Se comprendi l'avviso e vuoi proseguire, seleziona Esegui comunque. Altrimenti, chiudi l'avviso e usa una delle alternative indicate sotto.

Le build Windows sono autofirmate e vengono inviate a VirusTotal come ulteriore controllo di sicurezza e reputazione. Un certificato autofirmato non viene trattato come un certificato rilasciato da un'autorità commerciale ritenuta affidabile da Windows, quindi Windows può mostrare Autore sconosciuto oppure chiedere nuovamente conferma per un file appena pubblicato.

Scopri come funziona la reputazione di Microsoft SmartScreen.

Windows: Defender ha bloccato o rimosso il file

Messaggi possibili Minaccia rilevata, App potenzialmente indesiderata rilevata, Questa app è stata bloccata oppure Minaccia in quarantena
  1. Apri Sicurezza di Windows dal menu Start.
  2. Seleziona Protezione da virus e minacce, poi Cronologia protezione.
  3. Apri la voce che menziona il programma di installazione o l'app portatile di Social Stream Ninja.
  4. Leggi il nome del rilevamento e il percorso del file interessato.
  5. Se si tratta solo di un avviso sulla reputazione dell'app o di un'app potenzialmente indesiderata, il file proviene dalla pagina ufficiale delle release e comprendi pienamente la scelta e sei a tuo agio nel procedere, seleziona Azioni > Consenti nel dispositivo. Potrebbe essere necessario scaricare di nuovo il file.
Fermati se Windows indica una minaccia malware specifica. Non scegliere Consenti prima di aver verificato la provenienza del download e condiviso con il supporto il nome del rilevamento o una schermata.

Istruzioni Microsoft per la Cronologia protezione

Windows: Smart App Control ha bloccato l'app

Smart App Control è diverso dal normale avviso SmartScreen. Windows non offre un'eccezione Esegui comunque per una sola app.

  • Su un computer aziendale o scolastico, chiedi all'amministratore di approvare l'app.
  • Su un computer personale, usa la estensione browser oppure app web Lite se non vuoi modificare un'impostazione di sicurezza dell'intero dispositivo.
  • Smart App Control può essere gestito in Sicurezza di Windows > Controllo delle app e del browser, ma modificarlo influisce sulla protezione di tutte le app. Leggi la spiegazione di Microsoft prima di decidere.

Domande frequenti Microsoft su Smart App Control

Altri messaggi di Windows

MessaggioCosa fare
«Per motivi di sicurezza e prestazioni, questa modalità di Windows esegue solo app verificate da Microsoft»Il computer è probabilmente in modalità S di Windows, che esegue solo app del Microsoft Store. Uscire dalla modalità S è una scelta irreversibile che riguarda l'intero dispositivo; valuta prima la versione browser o Lite. Leggi la guida Microsoft alla modalità S.
«Questa app è stata bloccata dall'amministratore di sistema»Il computer è controllato da criteri aziendali, scolastici, familiari o di sicurezza. Chi lo gestisce deve approvare l'app.
«Windows Defender Firewall ha bloccato alcune funzionalità di questa app»Riguarda l'accesso alla rete, non il permesso di avviare l'app. Se scegli di consentire l'accesso, usa solo reti private fidate; normalmente non serve l'accesso alle reti pubbliche.
«Questa app non può essere eseguita nel tuo PC»Elimina quella copia e scarica di nuovo la versione Windows x64 attuale. Assicurati che il download sia completo e di non aver scelto un file per macOS o Linux.

macOS: avviso sullo sviluppatore o sulla notarizzazione

Messaggi possibili Apple non può verificare la presenza di software dannoso nell'app, oppure non può verificare lo sviluppatore

Le release ufficiali per macOS sono pensate per essere firmate e notarizzate. Una build privata o personalizzata di terze parti potrebbe non esserlo, e un'app appena scaricata può comunque richiedere l'approvazione alla prima apertura.

  1. Verifica che l'app provenga dalla pagina ufficiale delle release o da una persona di cui ti fidi per una build personalizzata.
  2. Prova ad aprire l'app una volta, poi chiudi l'avviso.
  3. Apri Menu Apple > Impostazioni di Sistema > Privacy e sicurezza.
  4. Scorri fino alla sezione Sicurezza e trova il messaggio sull'app bloccata.
  5. Se comprendi l'avviso e vuoi proseguire, seleziona Apri comunque, autenticati se richiesto, poi seleziona Apri.

Crea un'eccezione per quell'app. Non richiede di disattivare Gatekeeper per tutte le applicazioni.

Guida Apple all'apertura sicura delle app scaricate

macOS: «L'app è danneggiata» o «Danneggerà il computer»

Non usare un comando del Terminale per rimuovere le informazioni di quarantena dell'app. Questi messaggi possono indicare un download incompleto o modificato, una firma non valida o un problema di sicurezza rilevato da macOS.

  1. Sposta quella copia nel Cestino.
  2. Scarica di nuovo la versione macOS attuale dalla pagina ufficiale delle release.
  3. Apri la nuova copia senza modificare il pacchetto dell'app.
  4. Se il messaggio ricompare, fai una schermata con il testo completo e la versione di macOS, poi contatta il supporto.

Se Apri comunque non compare, prova ad aprire di nuovo l'app e ricontrolla Privacy e sicurezza. Su un Mac gestito, questa impostazione può essere controllata dall'amministratore.

Linux: l'AppImage non si avvia

L'AppImage potrebbe richiedere il permesso di esecuzione:

  1. Fai clic destro sull'AppImage e apri Proprietà.
  2. In Permessi, attiva Consentire l'esecuzione del file come programma. Il testo varia in base all'ambiente desktop.
  3. Apri di nuovo l'AppImage.

Puoi anche concedere il permesso da un terminale:

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

Se l'errore menziona chrome-sandbox, Sandbox SUID, AppArmor o namespace senza privilegi, segui la Guida alla sandbox dell'AppImage.

Alternative più sicure all'aggiramento di un avviso

Non devi necessariamente ignorare un avviso del sistema operativo per usare Social Stream Ninja.

  • Segnala l'avviso: invia una schermata e i dettagli elencati sotto per permettere di analizzare il problema.
  • Prova una release ufficiale precedente: se solo una nuova versione viene bloccata o non funziona, torna alla pagina ufficiale delle release e usa la versione precedente più recente che funzionava. Se possibile, esporta prima le impostazioni.
  • Usa l'estensione Chrome: installa la versione del Chrome Web Store al posto dell'app desktop.
  • Usa l'app web: apri Social Stream Ninja Lite quando le sue funzioni più limitate sono sufficienti.
Le vecchie release non includono le correzioni più recenti. Scaricale solo dalla pagina ufficiale delle release e torna a una versione attuale una volta compreso il problema.

Se continua a non aprirsi

Invia al supporto questi dettagli:

  • Una schermata che mostri l'avviso completo.
  • Il sistema operativo e la sua versione.
  • Il nome esatto del file scaricato.
  • Se si tratta del programma di installazione, dell'app portatile, dell'AppImage, della release ufficiale macOS o di una build personalizzata.
  • Se la stessa copia si era già aperta correttamente.
  • Su Windows, il nome del rilevamento nella Cronologia protezione, se presente.
