Risposte dai tuoi file

Prepara, importa e prova una base di conoscenze per il tuo bot di chat.

Configura prima il bot di chat

1. Prepara→2. Importa→3. Prova

1. Prepara file per argomento

Usa un piccolo file di testo o Markdown per argomento: piani, spedizioni, rimborsi o orari. Mantieni insieme nomi, prezzi, date, condizioni ed eccezioni.

Usa titoli chiari e fatti completi. Sostituisci i riferimenti vaghi con il nome del prodotto o del piano.

Facoltativo: chiedi a un’IA di aiutarti a preparare i file

Chiedi a un’IA capace di organizzare il materiale disordinato. Confronta la bozza con l’originale: anche una risposta ben scritta può modificare un fatto.

Copia questo prompt, poi aggiungi il materiale originale:

Organize the source material into short Markdown files, one topic per file.
Keep every name, price, date, URL, condition, and exception exactly.
Use clear headings and complete facts in the source language.
Do not invent answers or silently resolve conflicting facts.
List missing or conflicting facts separately for my review.
Return each filename followed by its contents.

Controlla tutti i prezzi, le scadenze, le restrizioni e i link prima di salvare i file.

2. Importa e scegli le risposte

Apri Chat Bots and AI services → Chat Bot - Primary → Chat bot knowledge. Attiva la base di conoscenze e aggiungi i file.

Lascia disattivato l’arricchimento IA alla prima importazione. Può aggiungere riepiloghi e tag di ricerca tramite il servizio IA selezionato, che potrebbe addebitare costi di elaborazione.

Per l’inglese, confronta la ricerca per parole chiave con la ricerca semantica locale. Per le altre lingue, inizia dalle parole chiave e prova domande reali nella lingua degli spettatori. Il modello semantico incluso è progettato per l’inglese.

Attiva “Answer only from my files” per basare le risposte fattuali sulla tua base di conoscenze.

Rispondere anche ai commenti senza una risposta disponibile?

Con “Do not screen out any of the bot’s replies” attivato, il bot può salutare, chiedere chiarimenti o segnalare informazioni mancanti. Altrimenti, può non rispondere alle domande senza risposta.

3. Controlla prima della diretta

Durante le prove, invia le risposte solo all’overlay. Fai una domanda con risposta nota, riformulala e chiedi qualcosa che i file non trattano.

Risposta notaFormulazione diversaInformazione mancante

Confronta le risposte con i fatti originali. Chiarisci i contenuti ambigui, sostituisci le importazioni obsolete e ripeti le stesse domande.
