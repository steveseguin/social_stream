Informativa sulla privacy di Social Stream Ninja

Ultimo aggiornamento: 8 settembre 2026

Social Stream Ninja è un software open source per acquisire, inoltrare, visualizzare e automatizzare chat live ed eventi correlati alle dirette. La presente informativa si applica all'estensione browser Social Stream Ninja, alle pagine e agli overlay Social Stream Ninja ospitati, all'app desktop autonoma comunemente chiamata SSAPP e al plugin nativo Social Stream Ninja per Elgato Stream Deck.

1. Ambito e approccio generale

Social Stream Ninja non richiede un account utente centrale per usare il software di base. Tuttavia, a seconda della configurazione, il software può accedere a, trattare, archiviare e trasmettere informazioni che alcune leggi possono considerare dati personali.

In molti casi, il software funziona localmente sul dispositivo e sotto il tuo controllo. Tuttavia, alcune funzionalità usano piattaforme di terze parti, destinazioni configurate dall'utente o servizi ausiliari ospitati, che possono ricevere i dati necessari a eseguire la funzionalità richiesta.

2. Informazioni che il software può trattare

A seconda delle funzionalità attivate, Social Stream Ninja può trattare le seguenti categorie di informazioni:

  • Informazioni di autenticazione: token di accesso OAuth, token di aggiornamento, chiavi API, ID client, segreti client, credenziali di canali o stanze, token di sessione, password e dati di autorizzazione simili inseriti dall'utente o concessi da un servizio connesso.
  • Comunicazioni personali: messaggi chat, risposte, comandi chat, azioni di moderazione, messaggi di abbonamento, donazione e sostegno e altre comunicazioni inviate dagli utenti e ricevute dalle piattaforme connesse.
  • Cronologia web e contesto della pagina: URL delle pagine supportate, informazioni sulle schede, nomi dei canali, nomi utente, ID video, ID stanze, identificatori delle dirette e relativo contesto della pagina necessario per connettersi a una sorgente o monitorarla.
  • Contenuti dei siti web: contenuti DOM della chat, contenuti dei messaggi e degli eventi, metadati delle dirette, conteggi degli spettatori, badge, emote, immagini dei profili e altri contenuti disponibili nelle pagine o API supportate.
  • Informazioni di identificazione personale e dati dei profili: nomi utente, nomi visualizzati, avatar, ID account o canali, badge, colori dei nomi, stato degli abbonamenti, etichette follower/abbonati e metadati simili dei profili.
  • Configurazione e dati locali dell'app: impostazioni, sorgenti connesse, comandi personalizzati, elenchi di blocco e di elementi consentiti, cache locali, informazioni sugli handle dei file e altri dati necessari al funzionamento del software sul dispositivo.
  • Dati facoltativi di file e contenuti multimediali: se attivi funzionalità facoltative di acquisizione, esportazione, ticker, registrazione o file, il software può trattare file locali selezionati, file esportati, dati di acquisizione di schede/contenuti multimediali o backup creati dall'utente.

3. Come vengono usate le informazioni

Social Stream Ninja può usare tali informazioni per:

  • Connettersi a sorgenti di chat, eventi e dirette supportate.
  • Mostrare messaggi chat, overlay, dashboard, avvisi, liste d'attesa, sondaggi, tabelloni dei punteggi e interfacce correlate.
  • Eseguire le funzionalità di moderazione, filtraggio, automazione, inoltro, bot, TTS, AI, traduzione o esportazione attivate dall'utente.
  • Autenticarsi presso piattaforme di terze parti e mantenere le sessioni delle sorgenti.
  • Memorizzare ricerche in cache e mantenere lo stato locale dell'app affinché il software continui a funzionare tra le sessioni.
  • Inviare dati a destinazioni configurate esplicitamente dall'utente, come webhook, file locali, endpoint WebSocket locali, bot di terze parti o altri servizi.

4. Archiviazione locale e sul dispositivo

Social Stream Ninja memorizza una quantità significativa di dati operativi localmente sul dispositivo dell'utente. A seconda dell'ambiente usato, possono essere inclusi archiviazione del browser, localStorage, sessionStorage, IndexedDB, archiviazione dell'estensione, archiviazione dell'app Electron e file facoltativi scelti dall'utente.

Questi dati locali possono includere impostazioni, dettagli delle sorgenti connesse, ricerche di canali o profili in cache, cronologia dei messaggi se attivata dall'utente e dati di autenticazione/sessione necessari alle funzionalità attive.

L'app desktop autonoma può anche conservare sul dispositivo backup locali di ripristino delle impostazioni e dell'archiviazione delle sorgenti. Tali backup locali possono includere token OAuth o altro stato di sessione, così l'app può ripristinare una precedente sessione funzionante dopo un riavvio o un errore.

Il plugin Stream Deck memorizza ID di sessione Social Stream Ninja e preferenze di connessione nelle impostazioni locali del plugin in Stream Deck. Rimuovere il plugin o cancellarne le impostazioni elimina tale configurazione da Stream Deck.

5. Quando i dati possono lasciare il dispositivo

In base a come usi il software, le informazioni possono essere trasmesse fuori dal dispositivo nelle seguenti situazioni:

Non vendiamo i dati degli utenti.

Social Stream Ninja non è progettato per trasferire dati degli utenti oltre alle trasmissioni descritte nella presente informativa, che possono avvenire quando usi piattaforme connesse, funzionalità attivate dall'utente, destinazioni configurate dall'utente, fornitori ausiliari o di servizi necessari, oppure quando lo richiedono obblighi di sicurezza o legali.

  • Piattaforme e API connesse: quando connetti YouTube, Twitch, Kick, Facebook, Discord o altri servizi supportati, il software invia richieste a tali piattaforme e può ricevere o trasmettere dati relativi a chat, eventi, profili e autenticazione.
  • Servizi ausiliari ospitati: alcune funzionalità usano endpoint ausiliari o pagine ospitate per autenticazione, ricerche, trasporto, chat o risorse di ripiego. Esempi nelle versioni attuali includono domini Social Stream Ninja o ausiliari correlati usati per scambio di autenticazione, ricerche o pagine ospitate.
  • Controlli Stream Deck: il plugin Stream Deck invia l'ID di sessione configurato e i dati del comando richiesto all'endpoint WebSocket o HTTP Social Stream Ninja selezionato dall'utente. Quando il ripiego HTTP è attivo, i dati del comando possono essere codificati nell'URL della richiesta.
  • Destinazioni configurate dall'utente: se attivi webhook, inoltri, bot, provider AI, provider TTS, strumenti per streamer, server WebSocket o altre integrazioni, il software può inoltrare contenuti dei messaggi, nomi utente, avatar, payload degli eventi e relativi metadati a tali destinazioni.
  • Servizi peer o di trasporto: se usi VDO.Ninja, WebRTC, relay TURN, bridge iframe nascosti o trasporti basati su WebSocket, i dati possono transitare attraverso questi sistemi. Il trasporto WebSocket facoltativo potrebbe non essere crittografato end-to-end.

6. YouTube e altre funzionalità basate su OAuth

Utilizzo limitato: L'uso da parte di Social Stream Ninja delle informazioni ricevute dalle API Google rispetta le Norme sui dati utente del Chrome Web Store, inclusi i requisiti di utilizzo limitato.

Quando usi YouTube API Services o altre integrazioni basate su OAuth, Social Stream Ninja può richiedere token di autorizzazione e relativo accesso all'account necessari alla funzionalità che scegli di usare.

  • YouTube: il software può accedere a messaggi della chat live YouTube, metadati dei messaggi, informazioni sui canali e sugli avatar, stato della diretta, endpoint di moderazione e statistiche di spettatori o iscritti, a seconda delle funzionalità YouTube attivate.
  • Servizi ospitati di supporto all'autenticazione: in alcune versioni e modalità, lo scambio dei codici OAuth o il rinnovo dei token possono essere gestiti tramite un servizio ausiliario ospitato anziché interamente sul dispositivo. Se usi tale modalità, codici di autorizzazione, token di aggiornamento e dati correlati delle richieste di token possono passare attraverso quel servizio per completare l'accesso.
  • Archiviazione locale dei token: a seconda della funzionalità e del flusso di accesso usati, i token possono essere memorizzati localmente sul dispositivo dell'utente e anche inviati a servizi ausiliari se occorre uno scambio o un rinnovo remoto.
  • Norme Google: l'uso delle funzionalità YouTube è soggetto anche alla Informativa sulla privacy di Google. Puoi revocare l'accesso Google nelle impostazioni delle autorizzazioni del tuo account Google.

7. Segnalazione degli errori dell'app desktop

L'app desktop autonoma include una funzionalità facoltativa di segnalazione errori, disattivata finché l'utente non la attiva.

  • Se attivata, l'app desktop può inviare messaggi di errore, tracce dello stack, versione dell'app, un ID casuale di installazione, contesto e impostazioni depurate da dati sensibili all'endpoint di segnalazione errori dello sviluppatore.
  • Al momento della stesura, l'informativa interna dell'app desktop dichiara che token OAuth, dati di sessione e credenziali di backup sono esclusi da tali segnalazioni.
  • Al momento della stesura, l'informativa interna dell'app desktop dichiara che tali segnalazioni vengono inviate tramite un endpoint Cloudflare Worker e conservate per 30 giorni. Gli utenti devono leggere l'informativa corrente nell'app prima di attivare la funzionalità.

8. Servizi di terze parti e integrazioni configurate dall'utente

Social Stream Ninja può interagire con un'ampia gamma di piattaforme di terze parti e servizi scelti dall'utente. Le loro informative sulla privacy, condizioni, misure di sicurezza e prassi di conservazione sono separate dalla presente informativa e possono differire in modo sostanziale.

Se configuri il software per inviare dati a servizi di terze parti, sei responsabile della valutazione di tali servizi e della decisione se ti è consentito inviare loro quei dati.

9. Conservazione, eliminazione e controllo dell'utente

Poiché gran parte di Social Stream Ninja funziona localmente, la conservazione dipende di solito dal dispositivo e dalla configurazione dell'utente.

  • Impostazioni locali, cache, token e backup possono restare sul dispositivo finché l'utente non cancella l'archiviazione, rimuove le sorgenti, ripristina l'app, elimina i file esportati, revoca i token o disinstalla il software.
  • Le destinazioni di terze parti configurate dall'utente possono conservare copie dei dati inoltrati secondo le proprie informative.
  • I servizi ausiliari ospitati o le API possono registrare o conservare dati tecnici delle richieste secondo le proprie prassi. La presente informativa non garantisce un periodo di conservazione specifico per i servizi di terze parti.

10. Sicurezza e rischi

  • Nessuna garanzia di sicurezza assoluta: nessun software o servizio in rete è perfettamente sicuro. L'uso di Social Stream Ninja è a tuo rischio.
  • Credenziali di sessioni e sorgenti: se un ID stream, ID stanza, token, password o link di inoltro diventa noto ad altri, tali soggetti potrebbero visualizzare o inserire dati in base alla configurazione.
  • Rischio di trasporto: il traffico WebRTC, TURN, WebSocket, webhook, relay e API di terze parti può esporre informazioni ai servizi necessari a trasportarlo.

11. Responsabilità dell'utente

L'utente decide quali siti, account, chat e servizi connettere a Social Stream Ninja; quali dati acquisire; quali overlay mostrare; quali file salvare; e a quali servizi esterni inoltrare dati.

  • Sei responsabile di assicurarti di avere il diritto e la base giuridica per raccogliere, trattare, mostrare, archiviare, esportare o inoltrare qualsiasi dato gestito con il software.
  • Sei responsabile del rispetto delle condizioni di servizio, delle condizioni sulla privacy e delle leggi locali applicabili ai servizi e alle persone di cui tratti i dati.
  • Devi trattare token, password, ID stanze, ID stream e dati esportati come sensibili.

12. Manleva e assenza di garanzie

Social Stream Ninja viene fornito "così com'è" e "secondo disponibilità", senza garanzie di alcun tipo, espresse o implicite, comprese le garanzie implicite di commerciabilità, idoneità a uno scopo particolare e non violazione di diritti.

Usando il software, accetti che autore, collaboratori e fornitori di servizi non siano responsabili per pretese, danni, responsabilità o perdite derivanti dalla tua configurazione o dall'uso del software, comprese pretese relative a contenuti di terze parti, raccolta o inoltro di dati o conformità legale.

La presente Informativa sulla privacy può essere aggiornata periodicamente. L'uso continuato del software dopo una modifica all'informativa implica l'accettazione della versione aggiornata.
