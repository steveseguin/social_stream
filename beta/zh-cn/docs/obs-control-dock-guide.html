OBS 控制停靠面板指南

将常用 Social Stream 控件放在 OBS 内，包括谢幕名单的开始、预览、测试和重置。

快速设置

  1. 在 Social Stream Ninja 中，打开 全局设置和工具 → 工作机制.
  2. 启用 扩展的远程 API 控制。直播期间保持 Social Stream Ninja 运行。
  3. 复制 Social Stream Ninja 中显示的会话 ID。
  4. 在 OBS 中，打开 停靠面板 → 自定义浏览器停靠面板.
  5. 将停靠面板命名为 Social Stream 控件 并使用此 URL：
https://socialstream.ninja/obs-control-dock.html?session=YOUR_SESSION_ID
  1. 选择 应用，关闭设置窗口，然后将新停靠面板放到 OBS 中所需位置。
  2. 确认停靠面板显示 已连接。如果 URL 不含会话，请在停靠面板中输入并选择 保存并连接.

配合直播结束谢幕名单使用

  1. 直播前，设置谢幕名单的 触发模式 为 后台收集。这样即使谢幕名单浏览器来源关闭，应用也能收集聊天参与者、会员和打赏者。
  2. 使用相同会话 ID，将生成的谢幕名单 URL 添加到 OBS 结束场景。
  3. 直播结束时，先切换到结束场景，使谢幕名单浏览器来源完成加载和连接。
  4. 选择 开始致谢名单 ，位于 OBS 控制停靠面板中。
开始前先加载： 后台收集可以在谢幕名单页面关闭时工作，但开始、预览和测试需要已连接的谢幕名单浏览器来源才能显示内容。

请参阅 滚动致谢名单指南 了解收集模式、筛选器以及姓名缺失的故障排查。

各谢幕名单按钮的功能

按钮结果
开始致谢名单播放实际收集的名单。
预览播放真实名单，但不消耗页面收集的条目。
测试谢幕名单显示内置的参与者、会员和打赏者示例。这并不能证明已收集真实姓名。

商品与支持链接

在 Social Stream 中，打开变现，保存并启用商品，然后选择 打开 OBS 控制停靠面板。将该私有控制 URL 复制到 OBS 的自定义浏览器停靠面板。若只需要商品停靠面板，请使用 obs-control-dock.html?session=YOUR_SESSION_ID&commerce.

保持 Social Stream 运行并启用 扩展的远程 API 控制 ，如上所述。将独立的变现叠加层 URL 添加为 OBS 浏览器来源供观众观看。控制停靠面板供您使用；切勿向观众分享其会话 URL。

  • 显示： 选择一个已保存的商品并固定显示。 下一个： 从当前商品前进到下一个。
  • 隐藏商品： 隐藏推广卡片；活动提醒仍会继续。 恢复计划： 恢复已保存的首个商品或轮播设置。
  • 持续时间： 显示、下一个和隐藏操作在指定秒数后恢复已保存的计划。使用 0 可保持覆盖状态，直到再次更改。
  • 状态： 在此部分打开时每五秒刷新一次。它报告 Social Stream 的选择，不代表 OBS 场景是否可见。连接丢失或未确认时，商品按钮会停用，直到状态再次可用。

停靠面板、弹出菜单、Stream Deck 和 Event Flow 共用相同控件。在 Social Stream 中编辑并保存目录。参见 商品控件 了解设置和自动化。

其他控件及其所需页面

  • 精选聊天： 保持普通直播聊天停靠面板和精选叠加层连接到相同会话。
  • 计时器： 如果需要显示计时器，请让计时器页面保持连接到相同会话。
  • 候补名单与抽奖： 先在 Social Stream 中配置候补名单；重置会清除当前条目。

如果 API 连接中断，停靠面板会自动重新连接。绿色的 已连接 状态仅确认控制连接；当命令要显示内容时，目标页面仍须打开。

https://io.socialstream.ninja/SESSION_ID/creditsPreview
https://io.socialstream.ninja/SESSION_ID/creditsTest

替换 SESSION_ID ，使用当前 Social Stream 会话。参见 命令与 API 或 完整 API 沙盒 了解更多操作。

故障排除

  • 需要会话： 使用 Social Stream 中完全相同的会话 ID，不包含单词 session=.
  • 已断开连接： 启用远程 API 控制，确认 Social Stream 正在运行，并在更改 URL 后重新打开停靠面板。
  • 谢幕名单提示没有来源接受命令： 显示结束场景，等待其浏览器来源加载，然后重试。
  • 测试有效但开始播放为空： 测试使用内置姓名。直播前选择后台收集，并确认普通聊天来源正在捕获。
  • 精选聊天按钮没有可见效果： 确认直播聊天停靠面板与精选叠加层使用相同会话且已加载。
