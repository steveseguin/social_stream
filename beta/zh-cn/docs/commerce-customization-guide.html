选择正确的起始页

使用 monetization.html 针对当前受众产品/支持叠加以及 commerce-board.html 用于查看板和已售商品的视图。文档设置页面和 shop.html 店面扮演着不同的角色；店面不是 OBS 操作员控制面板。

下载并保存文件结构

  1. 下载源ZIP 并提取它。这些指南使用测试版源；将一次下载的文件放在一起。
  2. 复制 monetization.html 为 my-products.html 原文旁边。如果选择不同的页面或主题，请将其副本保留在该文件的原始文件夹中。
  3. 在编辑器或 AI 工具中打开复制的 HTML 及其引用的 CSS/JS。将提供的图稿/字体添加到同一项目并使用相对路径。从 CSS 覆盖开始；更改生成的标记时包括渲染器。

  1. 将编辑后的 HTML 文件拖到 Chrome 或 Edge 中。从地址栏复制其地址；它开始于 file:///.
  2. 复制所有内容 ? 继续在您的工作 SSN 覆盖链接中并将其添加到该文件地址的末尾。保留所有设置，包括会话、密码和任何 # 结局。

哪里需要改变设计

更改卡片布局、排版、产品图像框架、价格处理、二维码放置和图板图块。保持 QR 码足够大且清晰以便扫描。包括 thirdparty/qrcode.min.js、翻译脚本以及您选择的页面加载的完整共享商务文件夹。

重用 SSN、Stream Deck、Event Flow 和可选 OBS 坞站已使用的商务状态和控件。保留选定/隐藏/预定状态。将会话详细信息、设置消息、发布凭据和操作员控件保留在观众图形之外。成功更新并不能确定 OBS 是否处于活动状态或显示该源。

测试此覆盖类型

首先使用预览或测试设置。的 测试消息指南 解释了如何通过SSN发送虚构的有效负载；提交到生产会话的测试可以触发其现有的自动化。

  1. 对于主板，使用 commerce-board.html?demo 检查虚构数据。删除已连接显示器的演示。
  2. 使用现有的产品/板控件来选择、隐藏和更改项目。通过 OBS 大小的预览检查长标题、缺失图像、价格格式和 QR 扫描。
  3. 检查空状态和断开状态并重新加载。测试配置的公共产品目标，而无需发布新目录只是为了更改叠加层的样式。

同时运行 输入渲染检查 针对您更改的渲染路径。保存编辑后，在排练之间刷新 OBS 浏览器源并重复可见的交互。浏览器预览不会建立实时捕获或 OBS 行为。
