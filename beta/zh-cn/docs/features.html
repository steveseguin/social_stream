功能

汇聚各处聊天，让观众出现在画面上，打造属于自己的每一场直播。

探索 126 个直播创意 · 预览贴纸奖励

多平台聊天集成

同时与你在各直播平台的观众互动。Social Stream Ninja 将数十个平台的聊天消息汇聚到一个易于管理的控制面板中。

  • 与 Facebook、YouTube、Twitch、Zoom 等平台进行实时双向聊天
  • 大多数平台无需登录或 API 密钥
  • 通过多频道来源图标区分平台
  • 在平台之间自动转发消息

精选聊天叠加层

使用美观、可自定义的叠加层，直接在直播中突出展示观众的精彩消息。

  • 通过可停靠的控制面板选择消息
  • 自动或手动选择消息
  • 可通过 CSS 自定义，与直播视觉风格完美融合
  • 动画选项，包括淡入淡出和滑动效果
  • 消息排队，有序展示精选内容

机器人命令与自动回复

通过自定义命令和回复，与观众建立自动化互动。

  • 常见互动的内置命令
  • 通过可编写脚本的插件文件自定义命令逻辑
  • 自动问候和回复
  • 消息过滤与管理

AI 与 LLM 集成

选择语音搭档、聊天机器人、浏览器助手或专用 AI 处理工具，无需将直播的其他部分绑定到单一提供商。

  • 能够听到你并接收所选直播聊天消息的语音搭档
  • 主聊天机器人和私人聊天机器人，支持自定义指令和触发规则
  • 本地模型或云端提供商，包括 OpenAI、Gemini、xAI、Bedrock、OpenRouter、Groq 和自定义兼容 API
  • 内容审核、翻译、摘要、RAG 上下文和叠加层构建
  • 可选的 ChatGPT 浏览器捕获，无需 API 密钥
比较所有 AI 选项 →

文字转语音

通过文本转语音，让聊天消息有声有色，提升直播互动和无障碍体验。

  • 支持免费的系统 TTS
  • 集成付费 TTS 服务（Google Cloud、ElevenLabs、Speechify）
  • 多语言支持
  • 可自定义声音、音调和语速
  • 支持 OBS 音频捕获

强大的 API

通过强大的 API 集成选项扩展 Social Stream Ninja 的能力。

  • 支持用于第三方集成的 webhook
  • 用于远程控制的服务器 API
  • 打赏集成（NinjaBacker：免费，平台佣金 0%、Stripe、Ko-Fi、Buy Me A Coffee）
  • MIDI/Streamdeck 控制
  • 支持 OBS 远程场景控制

深度自定义

通过丰富的功能和外观自定义选项，让 Social Stream Ninja 真正符合你的需要。

  • 通过 CSS 样式全面掌控视觉效果
  • 预设样式的模板和主题
  • 支持自定义 JavaScript
  • 通过 URL 参数轻松配置
  • 来源过滤和品牌选项

高级直播工具

使用专为参与和互动设计的专业工具，提升你的直播体验。

  • 互动小游戏，包括 Battle Royal
  • 带队列管理的抽奖系统
  • 滚动致谢名单和打赏罐展示
  • 词云和自定义 GIF 命令
  • 图形化投票系统
  • 可搜索的聊天历史数据库
  • 私人 AI 聊天机器人界面
  • 多模态 AI 搭档功能
