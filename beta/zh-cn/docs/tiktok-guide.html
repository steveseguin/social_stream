TikTok 指南

了解如何在 Social Stream Ninja 中连接 TikTok、选择合适模式、发送回复，并在需要时使用 TikFinity 作为回退方式。

概述

从这里开始

TikTok 是最难保持稳定的平台之一，因为它经常改变行为，而且不同账号看到的内容并不总是相同。

快速建议：
  • 先使用 TikTok WS + Auto.
  • 如果需要回复，切换到 标准.
  • 如果 Standard 不稳定，尝试 本地签名器.
  • 如果 TikTok 持续遗漏聊天，使用 TikFinity OBS 停靠面板 通过 其他聊天网站.
重要： TikTok 问题并不总是由 SSN 引起。消息缺失、身份验证失败和限速可能由 TikTok 本身、账号状态或地区限制导致。
模式

应该使用哪个 TikTok 选项？

选项 适合 回复
TikTok WS + Auto 适合大多数用户的默认选项。先使用 WebSocket，必要时回退到 Polling。 否
标准 适合希望从 SSN 发送回复，并在应用内使用 TikTok 直播页面的情况。 是
TikTok WS + Local Signer Standard 不稳定但仍需要回复时的回退方式。 是
轮询（Polling） 兼容模式。较慢，但在 WebSocket 路径失败时有用。 否
Euler Proxy / Euler Signing 适用于拥有 API 密钥或自定义设置的用户的高级签名选项。 通常不支持
TikFinity OBS 停靠面板 当 TikTok 原生模式遗漏太多聊天或无法连接时的只读回退方式。 否
步骤 1

在 SSN 中连接 TikTok

  1. 打开独立应用。
  2. 点击 TikTok 按钮，位于左侧边栏。
  3. 输入 TikTok 用户名、直播 URL 或所要求的值。
  4. 选择所需的 TikTok 模式或预设。
  5. 点击 激活来源.
步骤 2

如果需要回复

  1. 使用 标准 模式，作为首选。
  2. 点击 登录（Sign in） （如有需要）。
  3. 打开 显示捕获页面（Show capture page）.
  4. 确保登录的是应发送消息的 TikTok 账号。
步骤 3

如果 Standard 不稳定

  1. 试试 本地签名器.
  2. 保持签名器窗口打开。
  3. 如果 WebSocket 仍失败，尝试 轮询（Polling）.
  4. 如果 TikTok 仍遗漏太多聊天，请切换到下方 TikFinity 回退方式。
回复

如何向 TikTok 聊天发送回复

回复支持取决于是否拥有有效的已登录 TikTok 会话。

  • 最佳回复模式： 标准
  • 备用回复模式： 本地签名器
  • 不适合回复： Auto、Polling、TikFinity 回退
实用原则： 如果最重视读取可靠性，从 Auto 或 Polling 开始。如果最重视回复，使用 Standard 或 Local Signer。
回退

如何使用 TikFinity OBS Dock

当 TikTok 本身丢失或隐藏太多聊天时，TikFinity 可以作为备用来源。

  1. 打开 TikFinity。
  2. 前往 Overlay -> OBS Docks.
  3. 选择一个停靠面板槽位，并将其配置为聊天。
  4. 复制停靠面板 URL。
  5. 在 SSN 中，点击 其他聊天网站.
  6. 粘贴 TikFinity 停靠面板 URL。
  7. 启用新来源，并在直播时保持 TikFinity 打开。
  • 这是备用读取器，不是回复工具。
  • 如果已经使用 TikFinity 活动信息流组件，SSN 也可以在基于浏览器的工作流中使用支持的 TikFinity 组件页面。

如需此回退方式和 Discord StreamKit 的完整教程，请参阅 Discord StreamKit 与 TikFinity 来源。有关事件载荷详情，请参阅 事件参考.

故障排除

常见 TikTok 问题

“它说我离线了”

  • 只有账号确实正在直播时，TikTok 聊天才能工作。
  • 先开始直播，再尝试 重新加载.
  • 直播结束后测试通常会失败。

“身份验证窗口关闭了”

  • 使用 显示捕获页面（Show capture page） 以便看到登录或验证码。
  • 试试 重新加载 登录之后。
  • 尽可能关闭同一设备上额外的 TikTok 标签页或应用。

“有消息缺失”

  • 这可能是 TikTok 端的限制，并不总是 SSN 错误。
  • 先尝试其他模式，再决定是否某一条路径始终最好。
  • 如果 TikFinity 对您的账号表现更好，就将它用作回退方式。

“重新连接后消息重复”

  • 先更新到最新应用版本。
  • 完全停止来源，然后重新建立干净连接。
  • 如果仍重复，请切换模式或暂时使用 TikFinity。

“我不断受到速率限制”

  • 关闭同一设备上的其他 TikTok 标签页、应用或重复的观看窗口。
  • 等待几分钟再重试。
  • 尝试其他模式或签名路径。

“我应该先尝试什么？”

  • 读取使用 Auto
  • 回复使用 Standard
  • Standard 不稳定时使用 Local Signer
  • TikTok 本身有问题时使用 TikFinity
扩展

如果改用浏览器扩展

  • 在浏览器中打开主播的 TikTok 直播页面，并保持扩展启用。
  • 如果需要自己直播中仅限已验证用户或主持人的页面事件，请登录。
  • TikFinity 活动信息流页面也可用于基于浏览器的 SSN 设置。
  • 独立应用仍提供最广泛的 TikTok 模式选择和最清晰的回退选项。
