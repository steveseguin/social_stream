五步连接提醒

  1. 打开 变现 → Fourthwall、Ko-fi 与 Buy Me a Coffee 提醒 并选择你的 提供商.
  2. 点击 接收器设置 并开启 扩展的远程 API 控制.
  3. 返回 Monetization 并点击 复制 webhook URL.
  4. 粘贴到服务方的 Webhook 设置中，步骤如下。
  5. 保持 Social Stream Ninja 运行。
是否正常工作？ “Receiver connected”只表示 SSN 正在监听。实际事件到达时，最近事件一行才更新，重启时重置。
请勿公开 Webhook URL。 此 URL 是这些提醒唯一的保护方式，不检查签名密钥。它适用于提醒，不应用作发货的付款凭证。切勿公开或放进 QR 码。

预览示例提醒 仅展示外观，不影响累计值、Event Flow 或 Webhook。

NinjaBacker、Throne、Amazon 和 eBay 请参阅 变现指南。Shopify 请参阅 Shopify 设置.

Fourthwall

  1. 在 Fourthwall 中打开 设置 → 开发者选项 → Webhooks.
  2. 创建 Webhook，粘贴 SSN 提供的 Fourthwall URL。
  3. 勾选所需事件，参见表格。
  4. 保存，并保持 SSN 运行。
Fourthwall 事件显示为
ORDER_PLACED购买。为兼容旧设置，仍会计入其捐款价值。
GIFT_PURCHASE礼物。
DONATION捐款。
SUBSCRIPTION_PURCHASED新会员。

礼品卡订单不会重复增加价值。测试事件会被跳过。

Ko-fi

  1. 打开 Ko-fi Webhooks.
  2. 将 SSN 的 Ko-fi URL 粘贴到 Webhook URL 并保存。
  3. 保持 SSN 运行。

公开打赏、会员、商店订单和委托都用同一个链接。私密付款会被排除。商店订单和委托显示为购买，不增加捐款累计值。Ko-fi 不报告已取消会员。

用 SSN 预览测试。 Ko-fi 测试付款看起来像真实付款，会触发提醒、累计值和操作。启用付费奖励时不要使用。

Buy Me a Coffee

  1. 在创作者控制台打开 集成 并选择 新建 webhook.
  2. 设置名称，粘贴 SSN 的 Buy Me a Coffee URL。
  3. 勾选所需事件，参见表格。
  4. 保存并保持投递开启。失败时在那里查看投递记录。
事件显示为
donation.created捐款。
extra_purchase.created购买。
commission_order.created购买。
wishlist_payment.created礼物筹款贡献。
membership.started新会员公告，并非另一笔收费。

隐藏备注和匿名支持者保持隐藏。控制台测试（live_mode: false）会被跳过。退款不会减少累计值。

导入 Fourthwall 商品

  1. 在 Fourthwall 中进入 设置 → 开发者选项 并创建 Storefront 令牌。不要使用管理员 API 密钥。
  2. 在 SSN 中打开 商品与支持链接 → 设置商品和链接 → 导入 Fourthwall 商品.
  3. 粘贴商品公开链接和令牌。点击 加载商品详情.
  4. 核对名称、图片、价格和链接。链接必须来自与令牌相同的商店。
  5. 选择用途：Shop、Gift、Support 或 Join。
  6. 点击 添加商品或链接，开启 商品与支持链接，然后点击 保存设置.
导入会做什么
  • 每次加载一个公开、可购买的商品。
  • 令牌决定搜索哪家商店。只使用一次，随后清除，不保存也不传给覆盖层。
  • 若款式或套装价格不同，价格留空。
  • 这是导入时的快照。价格、库存和图片不会自动更新，变化时请重新导入或编辑。
  • 最多保存 20 个商品。再次添加相同商品会生成第二份。

在直播中显示商品和 QR 码

也可手动添加任何公开链接，例如 Shopify、Tiltify、Patreon。这不会连接付款提醒。

  1. 位于 OBS 覆盖层适用于，选择 商品与支持链接.
  2. 打开 叠加层链接选项 并选择 覆盖层视图：仅商品展示、仅支持卡片、仅活动提醒，或商品展示与提醒。
  3. 点击 复制 OBS 链接 ，然后作为以下来源添加到 OBS： 浏览器来源。从 800 × 600 开始，每种视图使用一个来源。
  4. 在 显示选项，固定第一个商品或轮换显示，并开启 显示二维码.
  5. 查看最终 OBS 布局时，用手机扫描 QR 码。
QR 码无法扫描？ 不要过度缩小或裁剪覆盖层。若要在聊天分享链接，点击 复制公开链接.
提醒、multi-alerts 与 Event Flow
  • 商品展示会显示商品图片，较小的支持卡片不会。
  • 活动提醒可独立使用，不会显示无关商品的 QR 码。
  • Multi-alerts 和活动流在同一会话下即可工作，无需商品列表。Monetization 活动视图需要启用商品列表。
  • 在 Event Flow 中，Donation 触发器仍处理包含以下内容的行： hasDonation。购买或已完成礼物请使用 Event Type。参阅 事件映射.

直播切换商品或共享一个观众链接，请参阅 实时商品控制.
