四步按平台拆分聊天

例如：一个叠加层只显示 Twitch 聊天，另一个只显示 YouTube 聊天；你仍可在同一个 Dock 中阅读全部消息。

  1. 将所有聊天加入 Social Stream Ninja，确认每个来源的新消息都能出现在 直播聊天停靠面板。保留这个 Dock 的完整视图，不要加过滤条件，供自己查看。
  2. 复制生成的 dock.html 链接两份。复制可保留会话、密码、版本和服务器设置。
  3. 在各份链接末尾添加过滤条件，例如 &onlyfrom=twitch&hidemenu （参见 下表).
  4. 将各链接分别添加为 OBS 的 浏览器来源。给它们起清楚的名字，例如 Twitch 聊天 和 YouTube 聊天.

完整示例：

使用 onlyfrom 和 hidefrom 在这里查看。 其他叠加层的选项，例如 onlytype等选项可能不适用于此页面。YouTube Shorts 是独立类型，请添加 youtubeshorts ，前提是采集会报告该值。参见 来源类型.

拆分精选聊天（选中的消息）

  1. 复制生成的 featured.html 链接两份。
  2. 添加 &onlyfrom=twitch 到其中一份，再将 &onlyfrom=youtube 添加到另一份。
  3. 保持 Dock 打开，以便选择消息。
精选聊天的每条链接只接受一个平台。 逗号分隔列表（twitch,youtube）仅适用于 Dock。

过滤条件只决定页面接受哪些精选消息，不会建立独立队列。拒绝某条消息也不会清屏。切换节目环节时，请手动清除精选消息，以免旧消息留在画面上。

同一平台的两个频道

onlyfrom=twitch 表示整个 Twitch，而不是某个 Twitch 频道。频道名称和直播标题不能当作过滤名称。

在一个浏览器标签页中显示聊天和提醒

合并叠加层 将叠加层链接堆叠到一个标签页或一个 OBS 浏览器源中，适合户外直播时用手机阅读聊天。

  1. 粘贴你的 直播聊天停靠面板 链接到最底层。
  2. 粘贴你的 多直播提醒框 链接到最上层。保留包含会话、密码和连接选项的完整链接。
  3. 将 透明 SSN 背景 已勾选。
  4. 开启 允许在此图层中点击和滚动 用于聊天。提醒图层则关闭，以免阻挡聊天操作。
  5. 新闻 预览，然后 显示二维码 并用手机扫描。或按 复制组合链接 粘贴到浏览器源。

浏览器改变尺寸时，像素值保持固定，百分比值随之变化。各叠加层保留自己的内容和设置。

保存、手机与隐私
  • 链接和图层选项会自动保存在此浏览器中，即使尚未完成。隐私浏览模式可能不会保留它们。
  • 组合链接和二维码包含整个布局。在电脑上设置，扫描一次，再在手机上收藏。打开后，布局也会保存到手机浏览器中。
  • 在电脑上修改不会更新旧链接。编辑后请复制或扫描新链接。会话 ID 不会同步这些设置。
  • 组合链接和二维码应像叠加层链接一样保密。
  • SSN 采集仍须运行，手机也必须能连接到原始链接所用的服务器。 localhost 或 127.0.0.1 指的是手机本身。
  • 过长的链接可能无法放入二维码，但仍可复制链接。

OBS 布局：左侧聊天列搭配全屏特效

无需 CSS。 每个图层都有自己的区域。将 OBS 浏览器源设为 1920×1080。从底层开始添加图层，在各图层的以下字段中只填数字（不要逗号或“px”）： 尺寸和位置.

图层宽度高度左侧偏移顶部偏移
1. 实时聊天／停靠面板4501000080
2. Hype 计数器4508000
3. Emoji／表情墙1920108000
4. 精选聊天147010804500
5. NinjaBacker（可选）1920108000

顶部 80 像素放 Hype，下面放聊天列。想让聊天在 Hype 后面铺满全高？将 Live Chat 高度设为 1080 ，顶部偏移量设为 0。场景尺寸不同，需要调整数值。

  1. 粘贴完整的叠加层链接。 从现有的浏览器源复制，可一并保留会话、密码、样式和连接设置。保持勾选 透明 SSN 背景 。OBS 的裁剪、变换、滤镜和自定义 CSS 不在链接中，无法一并转移。
  2. 将 Hype 在列内居中。 在 hype.html 链接时，使用 &align=center。替换所有 align=left 或 align=right，并移除 alignright。想要紧凑的外观，可尝试 &combineall&hidetitle&style=compact&scale=0.75 （替换已有值）。如果样式需要更多空间，请增加 Hype 图层的高度。
  3. 将精选聊天放在聊天列旁边。 设置 左侧位置 = 450 和 宽度 = 1470 一起设置（450 + 1470 = 1920）。把宽 1920 的图层右移会切掉边缘。添加 &center 为 featured.html 可让短消息在该区域居中。若要在整个场景中居中，设为左侧 0、宽度 1920，再使用 &center.
  4. 将 NinjaBacker 放在最后（可选）。 将其观众叠加层链接放在最上层，并设置从右侧进入的动画。组合工具控制区域和顺序，NinjaBacker 控制自身动画。背景必须透明，且网站必须允许嵌入。此图层未包含在已测试的示例中。
  5. 以 1920×1080 预览。 发送带表情的聊天，从 Dock 精选一条消息，并在 SSN 中开启 Hype 数据。普通聊天不会自动选择精选消息。
  6. 将新的组合链接复制到 OBS。 将该浏览器源的宽度设为 1920、高度设为 1080。预览尺寸不会设置这些值。完整适配场景，不要裁剪。每次修改布局后重新复制链接，旧链接仍保留旧布局。
性能： 一个浏览器源仍会运行其中的每个叠加层。OBS 源数量减少不保证 CPU 或内存占用降低。完成后关闭浏览器预览，并在关闭旧源的情况下比较 OBS 表现。M1 Mac 性能和你自己的 NinjaBacker 链接尚未测试。也可将 Live Chat 保持独立，仅组合其余叠加层。
