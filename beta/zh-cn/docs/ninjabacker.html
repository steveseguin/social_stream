在 Social Stream Ninja 中接收 NinjaBacker 小费

在 SSN 中接收小费，然后将提醒或 Tip Jar 添加到 OBS。

实时订阅WebhookOBS 显示测试与排查问题

1. 连接账户

从 SSN 桌面应用或 Chrome 扩展开始。直播期间请保持 SSN 运行。

  1. 打开 NinjaBacker。创建账户并完成 Stripe 设置，即可接受付款。
  2. 在 NinjaBacker 控制面板中打开 Social Stream Ninja，并复制 Private Tip ID。
  3. 在 SSN 中打开收入 > 商店与支持 > 已连接的平台 > NinjaBacker 捐赠 > 设置。输入用户名和私有 Tip ID。
  4. 将投递方式保持为实时订阅（简单），启用 NinjaBacker 捐赠，然后点击保存设置。

如果看不到已连接的平台，请在 SSN 中切换到完整模式。

实时订阅不需要 Webhook。它会在连接期间显示新小费，但不会补播 SSN 关闭时收到的小费。

2. 可选：使用 Webhook

选择可靠 Webhook，可在 SSN 关闭时将小费排队保存最多七天。

  1. 在 NinjaBacker 中打开 Webhook。在 Webhook Signature Secret 下点击 Generate 并复制密钥。如果已在使用密钥，请复制现有密钥。
  2. 在 SSN 的 NinjaBacker 设置中选择可靠 Webhook，粘贴签名密钥，然后点击保存设置。
  3. 在 SSN 中点击复制接收 URL。将其粘贴到 NinjaBacker 的 Webhook URL 字段，然后点击 Save。

接收 URL 以下列内容开头：

https://api.socialstream.ninja/v1/ninjabacker/webhook/...

Tip Jar、聊天面板及其他显示 URL 用于 OBS，不能接收 Webhook 请求。

切换回实时订阅

切换会删除 SSN 接收端中排队的小费。也请清空 NinjaBacker 中的旧 Webhook URL 并保存。

3. 将显示画面添加到 OBS

  1. 要显示提醒，请在商店与支持的 OBS 叠加层对象中选择 NinjaBacker 捐赠。复制叠加层链接。
  2. 要显示累计目标，请打开收入 > Tip Jar 与目标进度条。选择样式和目标，然后复制链接。
  3. 在 OBS 中添加浏览器源，并粘贴显示链接。SSN 和显示画面必须使用同一会话。

Tip Jar 样式与目标设置

向观众分享公开的 NinjaBacker 小费页面。叠加层链接放在 OBS 中，接收 URL 放在 Webhook 字段中。

4. 检查设置

打开 SSN 的 NinjaBacker 提醒叠加层。在 NinjaBacker 中打开 Testing，并点击 Send Test Tip。该叠加层中应出现测试提醒。

查看 Send Test Tip 下方的结果。Webhook accepted 表示请求已被接收，不代表 OBS 已显示提醒。如果失败，请修正 URL 或签名密钥，然后重新测试。控制面板测试会在五分钟内重试。

测试小费不会增加 Tip Jar 金额，不会在聊天中显示为付费捐赠，也不会触发付费奖励。

没有测试提醒？

保持 SSN 运行，并启用 NinjaBacker 捐赠。检查用户名和 Tip ID 是否属于同一账户。使用 Webhook 时，请刷新 NinjaBacker 的 Delivery History，并检查接收 URL 和签名密钥。

出现 HTTP 405 或显示 URL 错误？

从 SSN 的可靠 Webhook 设置中复制接收 URL，保存到 NinjaBacker，然后发送新的测试小费。保存新 URL 后，将停止向旧地址重试。

聊天中显示了小费，但目标没有增加？

检查 Tip Jar 的会话以及来源、捐赠类型和付费事件筛选器。小费金额应使用金额目标。退款不会从 SSN 的提醒或目标中扣除。
