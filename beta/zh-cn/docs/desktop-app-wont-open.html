Windows：“Windows 已保护你的电脑”

消息示例 Microsoft Defender SmartScreen 阻止了无法识别的应用启动。

此警告通常表示 Windows 尚未取得针对这个具体下载文件的足够信誉信息，与检测到恶意软件不同。

  1. 确认文件来自 官方发布页面.
  2. 在蓝色警告窗口中选择 更多信息.
  3. 检查应用名称是否为 Social Stream Ninja，或以以下内容开头： socialstreamninja.
  4. 如果你理解警告并愿意继续，请选择 仍要运行。否则，请关闭警告并使用下方的替代方案之一。

Windows 构建使用自签名，并提交到 VirusTotal 进行额外的安全和信誉检查。自签名证书与 Windows 信任的商业机构签发的证书并不等同，因此 Windows 可能显示 未知发布者 ，或再次要求确认新发布的文件。

了解 Microsoft SmartScreen 信誉机制.

Windows：Defender 阻止或移除了文件

可能出现的消息 “发现威胁”、“发现可能不需要的应用”、“此应用已被阻止”或“威胁已隔离”
  1. 打开 Windows 安全中心 ，可从“开始”菜单进入。
  2. 选择 病毒和威胁防护，然后 保护历史记录.
  3. 打开提及 Social Stream Ninja 安装程序或便携版应用的条目。
  4. 阅读检测名称和受影响的文件路径。
  5. 如果只是应用信誉或潜在不受欢迎应用的警告，文件来自官方发布页面，且你充分理解并愿意接受这一选择，请选择 操作 > 在设备上允许。可能需要重新下载文件。
如果 Windows 指出具体的恶意软件威胁，请停止操作。 在确认下载来源，并向支持人员提供检测名称或截图之前，不要选择“允许”。

Windows：智能应用控制阻止了应用

智能应用控制与普通 SmartScreen 警告不同。Windows 不提供仅针对单个应用的 仍要运行 例外。

  • 在工作或学校电脑上，请管理员批准此应用。
  • 在个人电脑上，使用 浏览器扩展 或 Lite 网页应用 ，适用于不想更改整个设备安全设置的情况。
  • 智能应用控制可在以下位置 Windows 安全中心 > 应用和浏览器控制中管理，但更改它会影响所有应用的保护。决定前请阅读 Microsoft 的说明。

其他 Windows 消息

消息处理方法
“为保障安全性和性能，此 Windows 模式仅运行经 Microsoft 验证的应用”电脑可能处于 Windows S 模式。此模式仅运行 Microsoft Store 应用。退出 S 模式是影响整个设备且不可逆的选择，因此请先考虑浏览器版或 Lite 版。 阅读 Microsoft 的 S 模式指南.
“此应用已被系统管理员阻止”电脑受到工作、学校、家庭或安全策略管理。需要由管理该电脑的人批准此应用。
“Windows Defender 防火墙已阻止此应用的某些功能”这涉及网络访问，而非应用是否可以启动。如果选择允许访问，请仅允许受信任的专用网络；通常不需要允许公用网络访问。
“此应用无法在你的电脑上运行”删除该副本并重新下载当前的 Windows x64 版本。确保下载已完成，并且没有误选 macOS 或 Linux 文件。

macOS：开发者或公证警告

可能出现的消息 Apple 无法检查应用是否含有恶意软件，或无法验证开发者

官方 macOS 发布版本旨在完成签名和公证。私人或第三方自定义构建可能未经过公证，而新下载的应用仍可能需要首次打开批准。

  1. 确认应用来自 官方发布页面 ，或来自你信任其自定义构建的人。
  2. 尝试打开应用一次，然后关闭警告。
  3. 打开 Apple 菜单 > 系统设置 > 隐私与安全性.
  4. 向下滚动到“安全性”部分，找到被阻止应用的相关消息。
  5. 如果你理解警告并愿意继续，请选择 仍要打开，按提示验证身份，然后选择 打开.

这会为该应用设置例外，无需对所有应用关闭 Gatekeeper。

Apple 关于安全打开已下载应用的指南

macOS：“应用已损坏”或“将损坏你的电脑”

不要使用终端命令移除应用的隔离信息。这些消息可能表示下载不完整或被修改、签名无效，或 macOS 检测到了安全问题。

  1. 将该副本移到废纸篓。
  2. 从官方发布页面重新下载当前的 macOS 版本。
  3. 打开新下载的副本，不要修改应用包。
  4. 如果消息再次出现，请截取包含完整措辞和 macOS 版本的画面，然后联系支持人员。

如果 仍要打开 没有出现时，请尝试再次打开应用，然后重新检查“隐私与安全性”。在受管理的 Mac 上，此设置可能由管理员控制。

Linux：AppImage 无法启动

AppImage 可能需要运行权限：

  1. 右键点击 AppImage 并打开 属性.
  2. 在“权限”中启用 允许将文件作为程序执行。不同桌面环境的措辞可能不同。
  3. 再次打开 AppImage。

你也可以通过终端授予权限：

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

如果错误提到 chrome-sandbox, SUID 沙盒、AppArmor 或非特权命名空间，请遵循 AppImage 沙盒指南.

比绕过警告更安全的替代方案

使用 Social Stream Ninja 并不一定要忽略操作系统警告。

  • 报告警告： 发送截图和下方列出的详情，以便调查。
  • 尝试较旧的官方版本： 如果只有新版本被阻止或失败，请返回官方发布页面，使用之前对你有效的最新旧版本。如可行，请先导出设置。
  • 使用 Chrome 扩展： 安装 Chrome 应用商店版本 ，代替桌面应用。
  • 使用网页应用： 打开 Social Stream Ninja Lite ，适用于其较精简的功能已足够的情况。
旧版本不包含最新修复。仅从官方发布页面下载，并在了解问题后恢复使用当前版本。
