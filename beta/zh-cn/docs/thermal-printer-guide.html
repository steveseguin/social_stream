热敏打印机与直播标签

将购买、打赏及聊天事件变成实体收据、贴纸、票券或取货标签。

六步完成设置

开始前： 需要 Windows 独立应用。打印机必须显示为普通 Windows 打印机。Social Stream 通过 Windows 驱动打印，不发送原始 ESC/POS、ZPL 或厂家 SDK 命令。
  1. 通过 USB 连接打印机、开机并安装 Windows 驱动，打印 Windows 测试页确认可用。
  2. 在 Social Stream 中打开 Global settings and tools → Mechanics - Connections & Integrations → Printer Control.
  3. 点击 查找打印机（Find printers）。按 Windows 显示的名称选择打印机。
  4. 输入 纸张宽度（毫米）。通常是 58, 80，或 62.
  5. 将 固定标签长度 设为 0 用于收据纸。模切标签请填写进纸方向的标签长度，单位为毫米。
  6. 点击 打印测试。边缘被裁切时，增大该侧安全边距后重试。

默认左右 2 毫米安全边距适合许多低价 58 毫米收据打印机。实际可打印区域由驱动决定，因此保持 使用可打印区域（Use printable area） 为选中状态，除非已测试其他设置。

有人捐款时打印标签

💰 打赏 / 小费（Donation / Tip）最低金额： 10
→
🖨️ 打印热敏标签（Print Thermal Label）{username}
{donation}
24 pt · 粗体 · 居中
  1. 打开 Event Flow 编辑器 并创建新流程。
  2. 添加 打赏 / 小费（Donation / Tip） 触发器。设置 最低金额（Minimum Amount） ，仅在较大捐款时打印。
  3. 添加 打印热敏标签（Print Thermal Label） （在 Integrations 下），并连接触发器。
  4. 输入 {username}，换行，然后 {donation}。选择字号、字重、对齐和份数。
  5. 将操作中的打印机及固定长度覆盖值留空或设为 0。会使用 Printer Control 设置。
  6. 点击 测试流程（Test Flow）。输入名称，开启 含打赏（Has Donation），填写金额并运行。这会实际打印标签。

其他实用占位符： {message}, {source}, {donationAmount}，以及 {counterValue}。流程前面步骤产生的值也可使用。

买家加粗，商品保持普通字重

  1. 设置 字重 为 选中的文字.
  2. 将以下内容作为标签文字输入：
**{username}**
{subtitle}
  • 只有包在以下符号中的文字 ** 会加粗，无需 HTML 或 JavaScript。
  • 使用单层花括号。销售事件把商品名放在 {subtitle}。数量可能位于 {meta.commerce.quantity}.
  • 如果前面步骤生成 buyer，使用 **{buyer}** 作为替代。
  • Shopify 和 eBay 不发送买家姓名，请使用订单计数器或仅含商品的标签。
  • 已设为 All bold 或 Normal 的标签保持原样。
流程制作者：打印结果与买家编号

操作会添加 meta.thermalPrintResult.success，失败时还会提供错误或代码，供后续步骤使用。成功只表示任务已发给 Windows，不代表已出纸。重试前检查 Windows 打印队列，避免重复标签。

Counter 为购买逐笔编号，而非为独立买家编号。若同一买家的每次购买要使用同一编号，需要单独维护买家与编号对应表，并在每次直播开始时重置。User Memory 的 reason 字段是普通文本，不是买家编号计数器。

Whatnot 商品标签

下载 Whatnot 示例流程。打印加粗的买家名称、商品名及可用的订单 ID。付款失败时另行打印 付款失败 标签，使用该通知包含的详情。

  1. 在独立应用中设置 打印机控制（Printer Control） 并运行测试打印。
  2. 打开 Event Flow 编辑器，点击 导入，选择下载的文件。
  3. 选择 Whatnot：商品标签 + 付款警告。检查两个打印操作，它们使用 Printer Control 的打印机和标签长度。
  4. 开启并保存流程。导入时默认关闭。
  5. 保持 Whatnot 来源打开，并开启直播事件捕获。
销售标签不代表已付款。 每条通知到达后立即打印。流程不等待付款、不修正旧标签、不分配买家编号。缺失字段留空。若失败通知没有买家、商品或订单详情，就无法判断对应哪张标签。

选择纸张

小票纸卷

适用于任意长度的购买小票、排队票和收据。固定标签长度保持 0。

连续贴纸卷

适用于任意长度的姓名贴纸。与收据纸类似，但切纸由打印机或驱动负责。

模切标签

适用于统一尺寸的胸牌和商品标签。设置准确固定长度，并在 Windows 打印首选项中选择相同纸张。

正确设置固定尺寸标签

3 × 1 英寸标签（含 Munbyn BT320）： 将宽度设为 76.2 毫米，固定长度设为 25.4 毫米（1 英寸边为进纸方向时）。在 Windows 打印首选项中选择相同纸张和方向，从 12–14 pt 文字开始。
规则原因
按进纸方向测量62 × 29 毫米标签通常设为宽 62 毫米、固定长 29 毫米。
同时匹配 Windows 设置在驱动的打印首选项中设置相同纸张、方向、间隙／标记感应和切刀。
固定就是固定不会额外进纸。文字过高时，可能因驱动而被裁切或溢出到下一张。
用最长文字测试长姓名、商品选项及额外行需要更多空间或更小字号。
过短标签可能不适用Social Stream 请求至少 20 毫米，驱动仍可能限制短页尺寸。

测试打印的侧边框表示安全宽度，高度随测试文字变化，并非整张标签的边框。

直播创意

  • 用于墙面、道具、地图或进度板的支持者姓名贴纸。
  • 订单到来时打印周边、委托、饮料或取货标签。
  • 抽奖券。在打印前加入频率限制和资格检查。
  • VIP 胸牌、团队选择票、挑战代币或里程碑标签。
  • 给身旁制作人员的简短待办清单。
不要打印私密信息。 排除地址、邮箱、付款信息和私信。热敏纸也会随热、光和时间褪色。

解决问题

问题试试这个
没有显示打印机确认 Windows 能打印测试页，重启 Social Stream，再点击 Find printers。
显示成功但不打印打开 Windows 打印队列，检查暂停、离线、纸张、驱动或端口错误。
边缘被裁切保持 Use printable area 开启，并增大对应侧的安全边距。
空白纸过多收据使用固定长度 0，减少下边距和额外进纸；标签则设置准确长度。
一张标签打印成两张文字高度超过标签，或 Windows 纸张尺寸错误。减少文字、缩小字号、收紧行距或减小边距。
Test Flow 使用了错误打印机在 Print Thermal Label 步骤选择打印机覆盖值。留空时，编辑器测试使用 Windows 默认打印机。
