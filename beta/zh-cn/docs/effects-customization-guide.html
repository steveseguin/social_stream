选择正确的起始页

选择适合您效果的接收器。 confetti.html 对候补获胜者状态做出反应； content.html 处理内容图像； emotes.html 处理情感视觉效果。 actions.html 是Event Flow输出页面。重命名这些文件之一不会更改它侦听的数据。

下载并保存文件结构

  1. 下载源ZIP 并提取它。这些指南使用测试版源；将一次下载的文件放在一起。
  2. 复制 reactions.html 为 my-reactions.html 原文旁边。如果选择不同的页面或主题，请将其副本保留在该文件的原始文件夹中。
  3. 在编辑器或 AI 工具中打开复制的 HTML 及其引用的 CSS/JS。将提供的图稿/字体添加到同一项目并使用相对路径。从 CSS 覆盖开始；更改生成的标记时包括渲染器。

连接您的副本并在 OBS 中打开它

启动SSN并首先使原始生成的覆盖URL起作用。的 session= 值连接到该 SSN 会话；这不是您的频道名称或此文件的名称。保持 SSN、相关功能及其数据源运行。 当您需要上游修复时的

  1. 将编辑后的 HTML 文件拖到 Chrome 或 Edge 中。从地址栏复制其地址；它开始于 file:///.
  2. 复制所有内容 ? 继续在您的工作 SSN 覆盖链接中并将其添加到该文件地址的末尾。保留所有设置，包括会话、密码和任何 # 结局。
  3. 在浏览器中打开结果，然后设置 OBS 浏览器源的 URL 与以下地址相同 本地文件 未检查。将源尺寸与您的预期设计相匹配。

哪里需要改变设计

样式粒子大小、轨迹、寿命、间距、框架和淡出。动画结束时保持清理，这样重复的事件就不会留下数千个隐藏元素。图像和声音文件位于其现有资产文件夹旁边；移动或托管副本时包括这些文件。

在选择启动效果时使用现有的 Event Flow 触发器和操作。新的风格不需要竞争事件配置系统。 GIF/媒体引用是数据：在分配媒体属性之前验证它们，并且不要将传入的字符串转换为脚本或 HTML。

测试此覆盖类型

首先使用预览或测试设置。的 测试消息指南 解释了如何通过SSN发送虚构的有效负载；提交到生产会话的测试可以触发其现有的自动化。

  1. 触发相应的功能：五彩纸屑的等候名单绘制、内容输出的 contentimg 消息、表情效果的表情或配置的 GIF 命令。
  2. 对于 actions.html，在测试设置中使用相关 Event Flow 的测试流程。通用的捐赠信息并不能证明每一条有效途径都有效。
  3. 发送短突发和慢序列；检查 OBS 中的分层、清理、无效/丢失媒体、源大小和音频。

同时运行 输入渲染检查 针对您更改的渲染路径。保存编辑后，在排练之间刷新 OBS 浏览器源并重复可见的交互。浏览器预览不会建立实时捕获或 OBS 行为。
