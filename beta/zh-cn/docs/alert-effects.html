动画与声音提醒

设置第一个提醒

  1. 打开 Multi-Alerts → Event animations & sound effects。
  2. 先启用提醒，再选择事件。100 美元捐赠预设会填入两个金额限制，并在未选择声音时提供合成的 Thank you 声音。
  3. 可添加直接指向 GIF、图片或视频的 URL，也可上传媒体。GIPHY 页面链接不是直接媒体 URL。GIF 图片没有音频，请另选声音。
  4. 选择声音，点击 Listen 在本地试听。自定义 URL 和上传选项位于选择器下方。
  5. 先使用 Test alert，再将 Multi-Alerts 链接添加为 OBS 浏览器来源。

金额限制与优先级

捐赠和 Bits 使用货币助手估算的美元值。若仅针对 100 美元，将上下限都设为 100；若针对至少 100 美元，将上限留空。上下限留空则允许任意金额；其他事件类型不应设置金额限制。

采用第一条匹配的提醒。请将具体规则放在宽泛规则前面。平台和类别过滤器仍然生效。

预览与声音

Test alert 会打开本地预览并将其置于前台，不会向直播频道发送事件。预览使用当前叠加层设置、过滤器、媒体和时间参数。音量位于 Sound & Timing。

Clear sound 会移除自定义声音覆盖设置，但默认提醒音仍有效。关闭 Play alert sound 可将叠加层音频静音。Enable alert 可暂停规则并保留设置。Reset alert 只清除该条规则。

语音短句标为合成录音。对于姓名或变化的文本，请使用 Event Flow 编辑器的 Speak Text 操作。

Event Flow 与 OBS 效果

使用 Event Flow 模板安排顺序动作和 OBS 效果。其媒体与声音操作在 Flow Actions 叠加层中播放。每个事件的声音只使用一个叠加层，避免重复播放。使用 OBS 模板前，需要先选定来源和滤镜。
