Discord StreamKit 与 TikFinity 来源

将第三方叠加层链接用作 Social Stream Ninja 中的只读聊天来源。

了解两个链接的区别

这些设置使用两个不同的链接：

  • 输入链接： 粘贴到 Social Stream Ninja 中的 Discord StreamKit 或 TikFinity URL。Social Stream 从中读取消息。
  • 输出链接： 你的 Social Stream 停靠面板或叠加层 URL。打开停靠面板测试消息，然后将叠加层 URL 添加到 OBS。

如果只想在屏幕上展示 Discord 或 TikFinity 的原始设计，请直接将其链接粘贴到 OBS 浏览器源。如果需要统一聊天、TTS、过滤、消息高亮或其他 Social Stream 功能，再将它用作 Social Stream 来源。

应该使用哪个选项？

Discord StreamKit

通过 Discord 官方聊天小组件，读取一个 Discord 服务器频道中的新文字消息。

  • 需要 Discord 桌面应用保持打开。
  • 无需在服务器中安装机器人。
  • 只读：Social Stream 无法通过 StreamKit 回复 Discord。

TikFinity OBS 停靠面板

使用 TikFinity 作为 TikTok LIVE 聊天和事件的备用读取器。

  • 需要 TikFinity 保持打开并连接。
  • 适用于 TikTok 直连模式缺失或丢失消息的情况。
  • 只读：如需回复，请使用 TikTok 直连模式。
避免重复： 不要同时用直连来源和这些备用来源之一捕获同一个聊天。
Discord

设置 Discord StreamKit

  1. 打开 Discord StreamKit 叠加层.
  2. 选择 为 OBS 安装 ，并在 Discord 提示时授权 StreamKit。
  3. 选择 聊天 小组件，然后选择要捕获的服务器和文字频道。
  4. 复制聊天小组件的安装链接。它应以下列内容开头： https://streamkit.discord.com/overlay/chat/.
  5. 在 Social Stream 桌面应用中打开 来源和设置 -> Discord.
  6. 选择 使用 Discord StreamKit URL，粘贴链接并添加来源。
  7. 捕获期间保持 Discord 桌面应用运行。

使用 Social Stream 浏览器扩展时，启用 Discord ，位于可选聊天服务下，然后在浏览器标签页中打开生成的 StreamKit Chat 链接。

  • Social Stream 会跳过页面首次打开时已经可见的消息。请在来源就绪后发送新的测试消息。
  • 它会捕获新文本、名字、基本格式、表情符号和显示的名称颜色。
  • 它不会捕获 Discord 通话或旧消息历史，也无法可靠地提供所有头像、附件、回复和角色详情。
TikTok 备用方案

设置 TikFinity OBS 停靠面板

  1. 打开 TikFinity 并将其连接到 TikTok LIVE 账号。
  2. 前往 叠加层 -> OBS 停靠面板.
  3. 使用齿轮按钮选择停靠面板应显示的事件，包括聊天。
  4. 复制 Dock 1 或 Dock 2 的 URL。
  5. 在 Social Stream 桌面应用中选择 其他聊天网站.
  6. 粘贴 TikFinity 停靠面板 URL，并激活新来源。
  7. 直播期间保持 TikFinity 打开并连接。
  • 此来源在设置中标为 TikFinity，但其消息在 Social Stream 内使用常规的 tiktok 来源类型。
  • 这是备用读取器，不是发送 TikTok 回复的方式。
  • 浏览器扩展用户也可以打开受支持的 TikFinity Activity Feed 小组件 URL，其中包含 /widget/vite/src/activity-feed/.

请遵循 附截图的 TikFinity 设置指南 ，查看用户名、OBS 停靠面板设置和 SSApp 步骤。关于 TikTok 直连模式和回复选项，请参阅 TikTok 指南.

验证完整工作流程

  1. 使用你的会话 ID 打开 Social Stream 停靠面板。
  2. 在所选 Discord 频道或 TikTok LIVE 聊天中发送一条新的测试消息。
  3. 确认它在 Social Stream 停靠面板中只出现一次，且名称和文本正确。
  4. 将你选择的 Social Stream 叠加层 URL 添加为 OBS 浏览器源，使用相同的会话 ID。
  5. 再发送一条消息，确认它在停靠面板和 OBS 中都只出现一次。
  6. 让来源运行几分钟，确认后续消息仍持续到达。

参阅 OBS 快速入门 ，查看停靠面板和浏览器源的设置步骤。

如果消息没有出现

  • 使用新消息测试。已有消息特意不导入。
  • 确认 Discord 或 TikFinity 仍保持打开、已登录且已连接。
  • 确认复制的链接指向聊天小组件或 OBS 停靠面板，而非其设置页面。
  • 更改所选服务器、频道、停靠面板或事件后，请重新加载或重新创建 Social Stream 来源。
  • 排查 OBS 前先检查 Social Stream 停靠面板。如果停靠面板为空，问题还不在 OBS。
  • 请将复制的来源链接视为私密设置信息。不要公开，也不要在共享屏幕时暴露。
