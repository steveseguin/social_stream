Guide des voix de synthèse vocale

Toutes les options de synthèse vocale au même endroit : fournisseurs, paramètres du lien, voix système et audio OBS.

Commencer ici

Vous débutez avec le TTS ? Suivez le Guide de configuration de la synthèse vocale. Il suffit de 5 étapes. Cette page constitue la référence complète.

SSN lit tout chat capturé sous forme de texte. Votre plateforme n'a pas besoin de son propre TTS. Le dock ou la superposition où le TTS est activé parle, en respectant ses filtres.

Le lien le plus simple active le TTS avec les voix de votre système :

dock.html?session=YOUR_SESSION&speech=en-US

Pour OBS, ajoutez une voix gratuite qui passe par la page :

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper

Gardez cette page ouverte et connectée. Une seule page doit parler.

Le TTS système n'est pas synonyme de TTS gratuit. Les voix système proviennent de votre navigateur et de votre ordinateur. OBS n'en possède souvent aucune, même si Chrome fonctionne. Kokoro, Piper, Kitten et eSpeak sont gratuits et produisent leur propre audio, donc fonctionnent dans OBS. Le TTS dans OBS ne nécessite pas de payer.

Le TTS est aussi disponible dans CAPTION.Ninja, pour les sous-titres, la transcription et la traduction. Les deux proposent des voix gratuites et payantes.

Paramètres du lien

Ajoutez ces paramètres à la fin du lien de votre dock ou de votre superposition.

ParamètreFonctionExemple
&speechActive le TTS avec un code de langue.&speech=en-US
&ttsproviderChoisit le fournisseur (voir ci-dessus).&ttsprovider=kokoro
&volumeVolume, de 0.0 à 1.0.&volume=0.8
&rateVitesse de parole, de 0.1 à 10.0.&rate=1.5
&pitchHauteur de la voix, de 0.1 à 2.0.&pitch=1.2
&voiceVoix système, identifiée par une partie de son nom.&voice=google
&simplettsNe pas dire « dit » ou « quelqu'un dit ».&simpletts
&simpletts2Ne pas lire les noms.&simpletts2
&ttscommandLire uniquement les messages commençant par une commande (par défaut : !say).&ttscommand=!say
&readeventsLire aussi les événements comme les abonnements et les dons.&readevents
&skipmessagesLire un message sur N seulement.&skipmessages=3
&ttsquickCoupe la parole après ce nombre de caractères. Supprimez-le si les messages sont tronqués.&ttsquick=100

Voix système

Le TTS système utilise les voix disponibles dans votre navigateur et votre ordinateur. Les cas ci-dessous sont courants, mais non garantis.

NavigateurVoix système
ChromeOui. Voix Google et voix système.
EdgeOui. Voix Microsoft et modules linguistiques Windows.
FirefoxLimité. Voix système locales uniquement.
OperaLimité. Varie selon l'installation.
SafariNécessite un clic avant de pouvoir lire l'audio.
OBSSon propre navigateur. Il ne récupère pas les voix de Chrome ou d'Edge. Tester dans l'application SSN ne teste pas OBS.

Vérifier les voix système de ce navigateur. Ce lien liste uniquement les voix TTS système du navigateur utilisé. Il ne teste ni OBS ni les fournisseurs comme Kokoro. Une liste vide ne signifie pas que les autres fournisseurs ne fonctionneront pas.

Ajouter des voix dans Windows

  1. Ouvrir Démarrer > Paramètres > Heure et langue > Voix.
  2. Sous Gérer les voix, cliquez sur Ajouter des voix.
  3. Choisissez les langues et cliquez sur Ajouter.
  4. Redémarrez votre navigateur.

Ces étapes concernent Windows 11. Pour Windows 10, consultez le Guide Microsoft. Certaines voix tierces n'apparaissent pas dans les navigateurs. Firefox affiche souvent plus de voix système que les navigateurs basés sur Chrome.

Acheminer le TTS système vers OBS

Vous utilisez un autre fournisseur ? Vous n'en avez pas besoin. Activez Contrôler l’audio via OBS dans la source navigateur. Aucun câble virtuel n'est nécessaire.
  1. Vérifiez d'abord que le TTS système parle réellement. OBS peut n'avoir aucune voix utilisable. Sans parole, le routage ne résoudra rien. Utilisez un autre fournisseur.
  2. Si la voix fonctionne dans un autre navigateur, capturez-le avec la capture audio d'application ou du bureau d'OBS.
  3. Toujours bloqué ? Faites passer le navigateur par un câble audio virtuel (ci-dessous).
Acheminer l'audio par un câble virtuel (Windows)

Téléchargements : VB-Audio Virtual Cable (gratuit) · Voicemeeter · Audio Router (ancien)

MéthodeProcédez ainsi
Tout le PCDéfinissez CABLE Input comme sortie par défaut de Windows (Paramètres audio > Sortie).
Une application, Windows 11Paramètres > Système > Son > Mélangeur de volume. Réglez la sortie du navigateur sur CABLE Input.
Une application, Windows 10Paramètres de son > Préférences de volume des applications et des appareils. Réglez la sortie du navigateur sur CABLE Input.
Audio RouterAncien logiciel. Dirigez le navigateur vers CABLE Input.
VoicemeeterDéfinissez-le comme sortie par défaut de Windows. Envoyez la sortie matérielle vers vos haut-parleurs et la sortie virtuelle vers OBS.

Ensuite, dans OBS, ajoutez Capture d'entrée audio, choisissez CABLE Output (ou la sortie Voicemeeter), puis réglez l'écoute sur Monitoring et sortie. Utilisez Écoute seule si une autre source l'envoie déjà vers le direct.

Test : lancez le TTS, regardez le vumètre OBS, vérifiez que vous l'entendez et réglez les niveaux.

Résoudre les problèmes

ProblèmeÀ essayer
Pas de sonVérifiez que le TTS est activé, que la page qui parle est ouverte et que la source navigateur n'est pas en sourdine. Dans un navigateur classique, cliquez une fois sur la page.
Aucun son dans OBSAucune parole ? Vérifiez d'abord le fournisseur. Si la voix fonctionne, vérifiez Contrôler l’audio via OBS, la sourdine du mixeur et les pistes de sortie. Ou capturez le navigateur qui parle.
La voix cloud ne fonctionne pasVérifiez la clé API et le nom du fournisseur. Sans clé, SSN revient au TTS système, qui peut rester muet dans OBS.
Le serveur local fonctionne dans l'application, mais pas dans OBSOBS est un navigateur distinct. Vérifiez le serveur depuis l'ordinateur d'OBS, surtout avec 127.0.0.1. Consultez le règle de localhost.
Seules la première lettre ou les premiers mots sont lusSupprimer ttsquick du lien OBS.
Les nouvelles voix n'apparaissent pasRedémarrez le navigateur après l'ajout de modules linguistiques.
Safari ne parle pasSafari limite le TTS automatique. Cliquez une fois sur la page pour autoriser l'audio.

Bonnes habitudes

  • Utilisez un fournisseur qui diffuse l'audio par la page. C'est la configuration OBS la plus simple, et des options gratuites existent.
  • Testez avec un court message avant le direct.
  • Les spectateurs peuvent écrire n'importe quoi. Prévoyez un moyen rapide de désactiver le TTS.
