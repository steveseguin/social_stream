Guide TikTok

Comment connecter TikTok à Social Stream Ninja, choisir le bon mode, répondre et utiliser TikFinity en repli si nécessaire.

Vue d’ensemble

Commencer ici

TikTok est l’une des plateformes les plus difficiles à maintenir stable : son comportement change souvent et varie selon les comptes.

Conseil rapide :
  • Commencez par TikTok WS + Auto.
  • Pour répondre, passez à Standard.
  • Si Standard est instable, essayez Signataire local (Local Signer).
  • Si TikTok manque toujours des messages, utilisez Dock OBS TikFinity via Autres sites de chat.
Important : Les problèmes TikTok ne proviennent pas toujours de SSN. Les messages absents, échecs d’authentification et ralentissements peuvent venir de TikTok, de l’état du compte ou de restrictions régionales.
Modes

Quelle option TikTok utiliser ?

Option Idéal pour Réponses
TikTok WS + Auto Meilleur choix par défaut pour la plupart des utilisateurs. Utilise d’abord WebSocket, puis Polling si nécessaire. Non
Standard Idéal pour répondre depuis SSN et utiliser la page TikTok en direct dans l’application. Oui
TikTok WS + Local Signer Solution de repli lorsque Standard est instable mais que vous souhaitez répondre. Oui
Interrogation (Polling) Mode de compatibilité. Plus lent, mais utile lorsque les chemins WebSocket échouent. Non
Euler Proxy / Euler Signing Options de signature avancées pour les utilisateurs ayant leur propre clé API ou une configuration personnalisée. Généralement non
Dock OBS TikFinity Repli en lecture seule lorsque les modes TikTok natifs manquent trop de messages ou ne se connectent pas. Non
Étape 1

Connecter TikTok dans SSN

  1. Ouvrez l’application autonome.
  2. Cliquez sur le bouton TikTok dans la barre latérale gauche.
  3. Saisissez le nom d’utilisateur TikTok, l’URL du direct ou la valeur demandée.
  4. Choisissez le mode ou préréglage TikTok souhaité.
  5. Cliquez sur Activer la source (Activate source).
Étape 2

Si vous avez besoin de répondre

  1. Utilisez Standard comme premier mode.
  2. Cliquez sur Se connecter (Sign in) si nécessaire.
  3. Ouvrir Afficher la page de capture (Show capture page).
  4. Vérifiez que vous êtes connecté au compte TikTok qui doit envoyer les messages.
Étape 3

Si Standard est instable

  1. Essayez Signataire local (Local Signer).
  2. Gardez la fenêtre du signataire ouverte.
  3. Si WebSocket échoue encore, essayez Interrogation (Polling).
  4. Si TikTok manque encore trop de messages, passez au repli TikFinity ci-dessous.
Réponses

Répondre au chat TikTok

La prise en charge des réponses dépend d’une session TikTok connectée valide.

  • Meilleur mode pour répondre : Standard
  • Mode de repli pour répondre : Signataire local (Local Signer)
  • Non destinés aux réponses : Auto, Polling, repli TikFinity
Règle pratique : si la fiabilité de lecture est prioritaire, commencez par Auto ou Polling. Si les réponses sont prioritaires, utilisez Standard ou Local Signer.
Repli

Utiliser le dock OBS TikFinity

TikFinity peut servir de source de secours lorsque TikTok supprime ou masque trop de messages.

  1. Ouvrez TikFinity.
  2. Accédez à Incrustation → Docks OBS (Overlay -> OBS Docks).
  3. Choisissez un emplacement de dock et configurez-le pour le chat.
  4. Copiez l’URL du dock.
  5. Dans SSN, cliquez sur Autres sites de chat.
  6. Collez l’URL du dock TikFinity.
  7. Activez la nouvelle source et gardez TikFinity ouvert pendant le direct.
  • C’est une solution de lecture de secours, pas un outil de réponse.
  • Si vous utilisez déjà les widgets de fil d’activité TikFinity, SSN peut aussi fonctionner avec les pages de widgets TikFinity prises en charge dans les configurations par navigateur.

Pour un guide complet de ce repli et de Discord StreamKit, consultez Sources Discord StreamKit et TikFinity. Pour les détails des données d’événements, consultez la Référence des événements.

Dépannage

Problèmes TikTok courants

« Il est indiqué que je suis hors ligne »

  • Le chat TikTok fonctionne uniquement lorsque le compte est réellement en direct.
  • Lancez d’abord le direct, puis essayez Recharger (Reload).
  • Les tests effectués après la fin d’un direct échouent souvent.

« La fenêtre d’authentification se ferme »

  • Utilisez Afficher la page de capture (Show capture page) pour voir la connexion ou le CAPTCHA.
  • Essayez Recharger (Reload) après connexion.
  • Si possible, fermez les onglets ou applications TikTok supplémentaires sur le même appareil.

« Il manque des messages »

  • Il peut s’agir d’une limitation de TikTok, pas forcément d’un bug SSN.
  • Essayez un autre mode avant de considérer un chemin comme définitivement préférable.
  • Utilisez TikFinity en repli s’il fonctionne mieux pour votre compte.

« Les messages sont en double après reconnexion »

  • Mettez d’abord l’application à jour vers la dernière version.
  • Arrêtez complètement la source, puis reconnectez-la proprement.
  • Si les doublons persistent, changez de mode ou utilisez temporairement TikFinity.

« Je suis constamment limité en fréquence »

  • Fermez les autres onglets, applications ou vues TikTok en double sur le même appareil.
  • Attendez quelques minutes avant de réessayer.
  • Essayez un autre mode ou chemin de signature.

« Que dois-je essayer d’abord ? »

  • Auto pour la lecture
  • Standard pour répondre
  • Local Signer si Standard est instable
  • TikFinity si le problème vient de TikTok
Extension

Si vous utilisez plutôt l’extension de navigateur

  • Ouvrez la page TikTok en direct du diffuseur dans votre navigateur et gardez l’extension activée.
  • Connectez-vous si vous avez besoin d’événements de page réservés aux comptes authentifiés ou à l’animateur sur votre propre direct.
  • Les pages de fil d’activité TikFinity peuvent aussi fonctionner dans les configurations SSN par navigateur.
  • L’application autonome propose toujours le plus grand choix de modes TikTok et les options de repli les plus simples.
