Connecter une IA en 5 étapes

Toutes les options sauf l'onglet ChatGPT nécessitent d'abord cette étape.

  1. Dans le menu Social Stream, ouvrez Bots de chat et services IA.
  2. Ouvrir Configurer le fournisseur LLM et choisissez l'IA utilisée.
  3. Renseignez l'adresse, le modèle, la clé API ou les paramètres de téléchargement.
  4. Cliquez sur Tester le bot de chat sélectionné.
  5. Activez la fonction qui doit l'utiliser, comme le bot principal ou la traduction.
La connexion ne suffit pas. Cela signifie seulement que l'IA a répondu au test. Rien ne lit le chat avant l'activation d'une fonction.

Coanimateur vocal

Parlez à une IA en direct. Elle entend votre micro, voit le chat partagé et peut répondre à voix haute.

  1. Ouvrir cohost.html?session=YOUR_SESSION.
  2. Choisissez une IA vocale ou celle configurée dans le menu.
  3. Choisissez votre micro et Réponse audio, puis appuyez sur Démarrer le coprésentateur.
  4. Avec OpenAI Realtime, capturez l'audio de la page du coanimateur dans OBS.
  5. Ajouter cohost-overlay.html?session=YOUR_SESSION à OBS pour l'avatar et la bulle de dialogue.

Détails d'OpenAI Realtime
  • Utilise la clé OpenAI enregistrée dans API ChatGPT. La clé reste dans Social Stream. La page du coanimateur reçoit seulement un accès temporaire et l'audio passe par WebRTC.
  • L'overlay ne reçoit pas la voix OpenAI. Utilisez le sélecteur de sortie du coanimateur pour un câble virtuel si possible. &forcetts ajoute une seconde voix distincte dans l'overlay.
  • Pour la vitesse : modèle Mini, raisonnement Low et tours Fast. La pleine qualité et un raisonnement élevé sont plus intelligents, mais plus lents et chers. Fast peut intervenir pendant les pauses.
  • La caméra et le partage d'écran sont facultatifs. La valeur par défaut est Aucune vidéo. Une fois activé, une image est envoyée par demande, pas une vidéo en direct. Cela ajoute du coût et du délai.
  • Les outils Spotify, scènes OBS et chat mis en avant sont désactivés par défaut. Activez-les dans le menu, puis dans Commandes du direct par le coprésentateur.
  • Les réponses sont limitées à 512 tokens de sortie. Diagnostics indique l'usage et le délai.
  • Il se reconnecte seul. Une nouvelle session conserve les instructions et réglages, mais oublie les paroles échangées.
  • Il ne reprend pas une conversation du site ou de l'application ChatGPT.

Guide complet du coanimateur IA

Bot principal de chat

Répond aux spectateurs dans un overlay, à voix haute avec le TTS ou dans le chat si pris en charge.

  1. Connecter une IA et testez-la.
  2. Ouvrir Bot de chat - Principal et activez Activer le bot de chat IA LLM.
  3. Configurez les mots déclencheurs, l'accès réservé aux modérateurs, les limites de fréquence, l'historique et les consignes.
  4. Pour un premier test sûr, activez Les réponses du bot vont UNIQUEMENT à sa page d’incrustation.
  5. Ouvrir bot.html?session=YOUR_SESSION. Activez le TTS pour des réponses parlées.
  6. Désactivez Overlay uniquement seulement après avoir vérifié que la plateforme permet la publication.

Les réponses sont publiées depuis votre compte connecté. Pour un autre nom, utilisez un compte bot YouTube, Twitch ou Kick si pris en charge.

Guide complet du chatbot IA

Bot privé

Un assistant individuel, utile pour tester les consignes.

  1. Activez Bot de chat - Interface privée.
  2. Ouvrir chatbot.html avec votre session.
Il est distinct du bot principal. Il ne partage ni ses connaissances documentaires (RAG) ni son historique de chat.

Guide complet du créateur d'overlays IA

Onglet ChatGPT (expérimental)

Vous utilisez déjà ChatGPT dans Chrome sans vouloir de clé API ? Social Stream peut capter les nouveaux messages de cet onglet comme toute autre source de chat (type openai).

Capturer votre onglet ChatGPT

  1. Installez et activez l'extension Social Stream Ninja pour Chrome.
  2. Dans le menu, activez la source ChatGPT source.
  3. Ouvrir https://chatgpt.com/, puis rechargez la page.
  4. Ouvrez le Dock avec la même session.
  5. Envoyez un nouveau message ChatGPT. Les deux côtés doivent apparaître dans le Dock. Les anciens messages sont volontairement ignorés.

Envoyer votre chat en direct à ChatGPT

  1. Testez sur un direct privé ou non répertorié, dans un chat texte normal.
  2. Sous Gestion, activez Relayer tous les messages.
  3. Définissez destinations du relais à openai, pour que les messages des spectateurs aillent uniquement à ChatGPT.
  4. Gardez l'onglet ouvert. Les réponses ChatGPT reviennent comme messages de type openai messages.
  5. Utilisez l'audio ChatGPT, le TTS Social Stream ou un overlay pour diffuser les réponses.
Expérimental. Le site ChatGPT peut changer. Relayer tout le chat peut saturer la conversation. Le mode vocal peut refuser le texte saisi. Commencez avec des filtres ou un direct de test.

Résoudre les problèmes

ProblèmeÀ essayer
Connecté, mais aucune réponse au chatActivez le bot principal ou la fonction souhaitée. Connecter une IA seule ne change rien au chat.
Le coanimateur voit le chat mais reste silencieuxC'est normal en Contexte seul. Interrogez-le sur le chat ou choisissez un mode parlant.
L'onglet ChatGPT n'affiche rienActivez la source ChatGPT, rechargez chatgpt.com, puis envoyez un nouveau message.
Le bot ignore la plupart des messagesVérifiez les mots déclencheurs, la restriction aux modérateurs, les limites et les consignes. Il est volontairement sélectif.
Le texte s'affiche mais aucun sonVérifiez que la page produisant le son est ouverte et qu'OBS capture son audio.
Le bot ne peut pas publier dans le chatVérifiez la prise en charge de la plateforme, votre connexion, les droits de publication et les limites de fréquence.
