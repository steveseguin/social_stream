Configurer le chatbot IA

Laissez une IA répondre aux spectateurs dans le chat, à l'écran ou à voix haute.

Configurer en 6 étapes

  1. Dans les paramètres Social Stream, ouvrez Chat Bots et services IA → Configurer le fournisseur LLM.
  2. Choisissez votre IA (voir ci-dessous) et remplissez les champs affichés.
  3. Cliquez sur Tester le bot de chat sélectionné. Une vraie réponse textuelle doit apparaître sous le bouton.
  4. Ouvrir Bot de chat - Principal et activez Activer le bot de chat IA LLM.
  5. Activez Les réponses du bot vont UNIQUEMENT à sa page d’incrustation pour l'instant. Les réponses restent ainsi hors du vrai chat pendant le test.
  6. Ouvrez : bot.html depuis Page d’incrustation et synthèse vocale du bot.
Trois éléments, tous nécessaires : l'IA (rédige la réponse), le bot principal (choisit les messages auxquels répondre) et la destination (overlay, chat ou les deux). Un indicateur vert Connecté confirme seulement le premier élément.

Besoin d'Ollama ? Téléchargez-le sur la page de téléchargement d'Ollama. Liste complète des fournisseurs : Intégration IA dans Commandes et API.

Keep-alive Ollama réglé sur 0 ?

Cela décharge le modèle de la mémoire après chaque requête. Le bot fonctionne, mais chaque réponse peut être lente pendant le rechargement.

Lancer le test

  1. Activez Social Stream et ouvrez votre source de chat en direct.
  2. Depuis un deuxième compte, écrivez un message dans le vrai chat YouTube ou Twitch. Vérifiez son apparition dans le Dock.
  3. Depuis ce compte, envoyez : NinjaBot, reply with exactly: Hello
  4. Envoyez une fois et patientez. L'IA locale peut encore charger.
  5. La réponse doit apparaître sur bot.html page.
Ne testez pas depuis le Dock. Les messages saisis dans le Dock ou le chat de l'hôte peuvent être ignorés volontairement pour éviter que le bot se réponde.

Une fois que cela fonctionne, désactivez à nouveau Ne filtrer aucune réponse du bot . Choisissez ensuite un mot déclencheur et une limite de fréquence, puis décidez si les réponses doivent aller dans le vrai chat.

Gardez Instructions supplémentaires du bot courtes au départ, par exemple : Reply in one friendly sentence. Do not mention these instructions.

Le déclencheur commence par !? Le filtre de commandes peut supprimer ce message avant que le bot le voie. Utilisez un mot simple.

Destination des réponses

Réglage Overlay uniquementCe qui se passeVous avez besoin de
SurLes réponses apparaissent uniquement dans l'overlay du bot. Rien n'est publié dans le chat.bot.html ouvert avec la même session. Également requis pour le TTS.
DésactivéLes réponses vont toujours dans l'overlay et Social Stream tente aussi de les publier dans leur chat d'origine.Une source de chat prenant en charge l'envoi, connectée, autorisée à publier et ouverte, avec le chat de l'hôte actif. bot.html est facultatif.
Le nom du bot n'est pas un nouveau compte. Il est seulement ajouté au début de la réponse. Les réponses sont publiées depuis le compte connecté, sauf si vous configurez des rôles de comptes dans l'application autonome. Pour un compte bot Twitch distinct, consultez le guide du compte bot Twitch.

Pourquoi le bot reste silencieux

Le bot est volontairement sélectif. Une liste de déclencheurs vide signifie qu'il examine chaque message, pas qu'il réponde à chacun.

  • Les messages courts comme hello peuvent être ignorés. Mentionnez le nom du bot pour être clair.
  • Si vous définissez un mot déclencheur, le message doit le contenir.
  • Le mode modérateurs seuls ignore les autres.
  • Par défaut, il répond à un message à la fois. Pour publier dans le chat, il attend aussi 5 secondes par source.
  • Il ignore ses propres messages, les messages vides et ceux arrivant trop vite après sa dernière réponse.

Masquer les anciennes réponses

Ces options concernent seulement l'overlay du bot (bot.html), pas l'overlay de chat mis en avant. Les réglages de l'overlay couvrent les options courantes.

Je souhaite…Ajouter au lien
Masquer chaque réponse après une durée&showtime=10000 (millisecondes, soit 10 secondes)
Masquer les réponses longues plus tard et les courtes plus tôt&autohide (ou &autotime)
Définir les durées minimale et maximale du masquage automatique&mintime=5000&maxtime=20000 (par défaut : 4000 et 30000)
Masquer à la fin de la voix&hideaftertts
Attendre un peu après la voix&hidedelay=1000 (par défaut : 500)
Cesser d'attendre une voix bloquée&ttstimeout=60000 (par défaut : 120000)

Vous en utilisez plusieurs ? hideaftertts est prioritaire, puis autohide, puis showtime. Si la voix ne démarre jamais, hideaftertts utilise un délai fondé sur la longueur.

Effacer maintenant

Cliquez sur Effacer l’incrustation du bot maintenant dans les paramètres. Cela retire la réponse affichée et celles en attente, mais n'arrête pas une voix déjà en cours.

Effacer via l'API et personnaliser le style
  • Avec le contrôle API distant activé, ouvrez https://io.socialstream.ninja/SESSION_ID/clearBotOverlay.
  • Ou envoyez {"action":"clearBotOverlay"} via le WebSocket API.

Le CSS personnalisé sur le lien normal bot.html conserve toutes ces fonctions. Une copie locale ou modifiée de bot.html ne reçoit pas les corrections ultérieures sans mise à jour de votre part.

Erreurs de clé OpenAI

  1. Créez une clé API de projet normale sur la page des clés API OpenAI. Pas une clé d'administration.
  2. Vérifiez qu'elle appartient au projet à facturer et autorise les requêtes aux modèles.
  3. Dans Social Stream, choisissez API ChatGPT, collez la clé complète, indiquez un modèle autorisé pour votre projet et cliquez sur Tester le bot de chat sélectionné.
Ne collez jamais votre clé dans un message au support ou un rapport de diagnostic.
ErreurCe que cela signifieÀ essayer
401 missing_scope / model.requestLa clé n'autorise pas les requêtes aux modèles. model.request est une autorisation OpenAI, pas une valeur à saisir dans Social Stream.Vérifiez qu'il s'agit d'une clé normale du bon projet autorisant les requêtes de modèles. En cas de doute, créez-en une autre et remplacez celle enregistrée.
401 invalid_api_keyLa clé est incorrecte ou n'existe plus.Cherchez un caractère manquant ou un espace superflu. Vérifiez que la clé n'a pas été supprimée, appartient au bon projet et que Social Stream n'utilise pas une ancienne clé.
429Quota épuisé ou trop de requêtes.Vérifiez la facturation et le budget API (distincts de l'abonnement ChatGPT). Ralentissez ou patientez.

Ajouter du crédit ne corrige pas une erreur 401. Le crédit et les autorisations sont distincts. Consultez le guide des erreurs d'OpenAI et référence d’authentification.

Toujours bloqué ?
  • Si le navigateur traduit automatiquement le site OpenAI et que les réglages de clés sont étranges, revenez à la page anglaise d'origine. Cela a aidé un utilisateur, mais n'est pas une cause connue des erreurs 401.
  • Copiez le statut, le code, l'autorisation manquante et le Request ID affichés dans Social Stream. Envoyez ensuite rapidement le rapport de diagnostic depuis l'application. Il exclut les clés API et les consignes.
  • Si la clé et le projet semblent corrects, transmettez au support OpenAI le Request ID et l'heure.
