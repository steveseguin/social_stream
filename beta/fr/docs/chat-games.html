Surveillez votre nom

Appel éclair (Quick Call)

Trois noms. De nouveaux codes de quatre caractères. Soyez prêt à votre tour.

Essayer l’aperçu →

Comment jouer

Tapez !quick pour rejoindre. À l’appel de votre nom, tapez votre propre code en 30 secondes. Une bonne réponse vous replace dans la file ; un tour manqué oblige à rejoindre de nouveau. L’incrustation classe les cinq meilleurs records personnels. Les codes ignorent la casse.

Fond transparent dans OBS. Ajoutez &clean pour masquer les commandes de l’hôte. Pause fige le jeu ; Effacer les scores ou recharger repart de zéro. Les scores restent uniquement dans cette page. Aucun message de bot, point ou achat. Les temps incluent le délai du direct et du chat : c’est une compétition décontractée. Les codes aléatoires limitent les réponses préparées, sans empêcher la lecture automatisée.

Conçus pour les couches OBS

Jouez par-dessus votre direct

Firefly Catch et Comet Rally laissent le reste de la page transparent ; Maze Raid remplit sa source. Commencez avec une source navigateur de 1280 × 800. Ajoutez &clean pour masquer les boutons de l’hôte et l’état de connexion. Les aperçus montrent un damier pour rendre visibles les zones transparentes.

Trois nouvelles façons de jouer

Attrape-luciole (Firefly Catch): tapez !catch pour commencer, puis attrapez la luciole lorsqu’elle entre dans l’anneau. Un essai par spectateur et par vol ; une capture centrée rapporte 3 points, les autres captures dans l’anneau 1 point. Six vols, puis un gagnant.

Course de comètes (Comet Rally): tapez !boost pour rejoindre une équipe attribuée automatiquement. Chaque spectateur peut accélérer une fois toutes les 3 secondes. Le premier à 20 accélérations gagne, ou le premier après 60 secondes.

Assaut du labyrinthe (Maze Raid): un explorateur automatique plus rapide parcourt des couloirs de brique et de métal avec des panneaux SSN. Le chat normal crée un ennemi avec avatar par participant, jusqu’à 40 par manche. Les assaillants apparaissent à 3 à 8 pas de couloir, poursuivent et attaquent ; le dernier coup gagne. Si l’avatar manque ou échoue, des initiales s’affichent. Le labyrinthe remplit sa source navigateur OBS ; redimensionnez-la selon votre scène.

Les trois jeux redémarrent après un écran de résultats de 8 secondes. Les commandes Pause et Nouvelle manche sont accessibles via Interagir dans OBS. Aucun point n’est dépensé et aucun message de bot n’est envoyé.

01 / Résolvez ensemble

Code du signal (Signal Lock)

1?4?

Le chat a 90 secondes pour trouver quatre chiffres. Chaque essai donne un indice à tout le monde. Idéal pour les amateurs d’énigmes, les pauses d’étude, les salles d’attente de jeux et les petites communautés.

Comment jouer

Tapez !code 1234. Les chiffres vont de 1 à 6 et peuvent se répéter. « Exact » signifie le bon chiffre à la bonne place. L’autre compteur indique les bons chiffres placés ailleurs.

Le premier essai valide lance le chrono. Cinq secondes entre les essais d’un même spectateur ; les essais identiques sont ignorés.

02 / Laissez le public décider

Quête collective (Crowd Quest)

Un voyage spatial en cinq étapes guidé par le chat. Choisissez les routes, gérez des provisions communes et rapportez des découvertes. Un jeu tranquille pour les directs de discussion, d’art, de musique, de jeux cosy et de variété.

Comment jouer

Tapez !vote 1, !vote 2, ou !vote 3. Chaque chapitre laisse 30 secondes à l’équipage pour choisir. Un vote par spectateur ; le dernier choix valide remplace le précédent.

Le premier vote lance chaque chapitre. Les conséquences sont affichées avant le vote. Les égalités sont départagées au hasard, et les routes trop coûteuses en provisions sont indisponibles.

Deux équipes / Une corde

Tir à la corde (Tug of War)

Deux gentils monstres tirent pour l’équipe Corail et l’équipe Menthe. Les bonnes réponses de vos coéquipiers déplacent la corde vers votre camp.

Essayer l’aperçu →

Comment jouer

Tapez !join pour rejoindre la plus petite équipe (au hasard en cas d’égalité). La partie démarre quand chaque camp a un joueur. Les équipes restent fixes pendant la partie ; on peut les rejoindre en cours de route.

Un mot ou une question de calcul simple apparaît toutes les 12 secondes. Tapez le mot ou la réponse directement dans le chat, ou utilisez !answer suivi de votre réponse. Chaque joueur peut gagner une traction par question ; répéter une réponse n’ajoute pas de tractions.

Une avance de 20 tractions remporte la partie. Sinon, le camp en tête après trois minutes gagne ; une corde équilibrée donne un match nul. Après les résultats, les spectateurs rejoignent de nouvelles équipes. Aucun point de fidélité n’est dépensé.

Bouclier de météores (Meteor Shield)

Protégez le vaisseau pendant six vagues de météores. Faites correspondre les boucliers aux couleurs qui arrivent.

Essayer l’aperçu →

Comment jouer

Tapez !shield red.

Six vagues de 12 secondes. Survivez avec des points de coque restants pour gagner. La progression repart à zéro à chaque manche.

Un peu d’addition. Beaucoup d’esprit d’équipe.

Équipe des additions (Sum Squad)

Coopérez pour atteindre exactement 20, puis 30, puis 40.

Essayer l’aperçu →

Comment jouer

Tapez de !add 1 à !add 9. Des spectateurs différents jouent à tour de rôle pour chaque cible ; chacun peut ajouter une fois toutes les 3 secondes. Les dépassements sont ignorés. Atteignez exactement les trois cibles en 90 secondes.

La progression et les scores repartent à zéro à chaque partie. Aucun point n’est dépensé.

Affichez-le en direct

  1. Dans SSN, ouvrez Jeux interactifs → Sélectionner un jeu.
  2. Choisissez un jeu ci-dessus et ajoutez son lien de session comme source navigateur OBS. Commencez à 1280 × 900.
  3. Laissez SSN et vos sources de chat actifs. Affichez la commande à l’écran et laissez le chat commencer la manche.

L’hôte peut mettre en pause ou redémarrer via la fenêtre Interagir d’OBS. Ajoutez &clean pour masquer les boutons de l’hôte, &transparent pour un fond de page transparent, ou &chroma pour le vert. Ajoutez &demo uniquement pour un aperçu isolé. La manche se termine par dix secondes de résultats, puis passe automatiquement à la suite.

Ces jeux n’utilisent ni points de fidélité, ni achats, ni médias externes, ni page de connexion du public. Ils lisent uniquement la session de chat SSN choisie et n’envoient pas de commandes au chat. Les boutons de l’hôte agissent localement. Une même personne sur deux plateformes compte comme deux joueurs. Jusqu’à 1 000 joueurs distincts par manche.

Des classiques, de nouveaux moments

Chaîne de mots (Word Chain) présente une nouvelle disposition, des scores plus clairs et une chaîne de mots lisible. Les règles restent familières : enchaînez des mots alphabétiques d’au moins trois lettres, commençant par la dernière lettre du précédent. Il vérifie les motifs de lettres, pas un dictionnaire.

Essayez Jardin du chat (Chat Garden) pour une pause créative, Bataille de pixels (Pixel Battle) pour créer ensemble, ou Course d’animaux (Pet Race) pour un court entracte.

Au-delà du chat

Laissez les spectateurs décider, puis concrétisez leur choix : prochaine couleur du dessin, prochaine chanson parmi une liste ou pause d’étirement. Les sondages, files d’attente et récompenses de stickers approuvées par l’hôte offrent d’autres façons de participer. Gardez privés vos liens de session et de contrôle ; le public n’a besoin que des consignes du chat.
