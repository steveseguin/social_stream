Les deux affichent un avatar et une bulle de dialogue dans OBS avec Overlay de scène IA, cohost-overlay.html.

Coanimateur vocal en 8 étapes

Cela utilise OpenAI Realtime, vous aurez donc besoin d'une clé API OpenAI. D'autres options figurent ci-dessous.

  1. Dans le menu Social Stream, choisissez API ChatGPT, collez la clé API de votre projet OpenAI et cliquez sur Tester le bot de chat sélectionné.
  2. Ouvrez : cohost.html depuis le menu. Gardez ce lien privé.
  3. Sélectionnez OpenAI Realtime.
  4. Choisissez le microphone dans lequel vous parlez. Gardez Réponse audio sélectionné.
  5. Appuyez sur Démarrer le coprésentateur.
  6. Laissez Chat en direct sur Contexte uniquement. Demandez « Que dit le chat ? » à tout moment.
  7. Dans OBS, capturez l'audio de la page ou de l'application du coanimateur. La voix IA est lue uniquement à cet endroit.
  8. Ajouter cohost-overlay.html?session=YOUR_SESSION_ID à OBS comme source navigateur pour l'avatar et la bulle de dialogue.
Vous voulez une piste audio séparée dans OBS ? Choisissez un câble virtuel dans Sortie du coprésentateur, si votre configuration le permet. Gardez aussi la bulle de dialogue visible pour que les spectateurs qui n'entendent pas puissent suivre.
Lui permettre de voir l'écran ou la caméra ? Facultatif. La vidéo démarre sur Aucune vidéo. Si vous choisissez Partage d’écran ou une caméra, OpenAI reçoit une image à chaque prise de parole ou saisie, pas une vidéo en direct. Cela peut ajouter du coût et du délai.
Confidentialité : votre microphone, l'écran ou la caméra choisis et les messages partagés sont envoyés à OpenAI. Les spectateurs ne peuvent pas utiliser le chat pour faire exécuter des outils au coanimateur. Le lien expire après 12 heures, fonctionne uniquement pour votre session et disparaît de la barre d'adresse au chargement.
En savoir plus sur OpenAI Realtime
  • La facturation passe par votre compte API OpenAI. C'est distinct de chatgpt.com et cela ne rejoint pas une conversation du site ou de l'application ChatGPT.
  • Votre clé standard reste dans Social Stream. La page du coanimateur reçoit seulement un accès de courte durée.
  • Il n'est pas nécessaire d'activer le chatbot privé pour cela.
  • Les réponses sont limitées à 512 tokens de sortie. Diagnostics indique le total des tokens utilisés et la vitesse de début des réponses.
  • Si vous parlez pendant sa réponse, il s'arrête et supprime l'audio non encore lu.
  • Il conserve jusqu'à 20 messages récents pendant 90 secondes au maximum, avec les dons, adhésions, modérateurs, événements et informations de chaîne. Il les oublie ensuite.
  • Il se reconnecte si la connexion tombe et ouvre une nouvelle session avant la limite OpenAI de 60 minutes. Vos instructions et réglages de vitesse sont conservés, mais il oublie la conversation orale.

Comment il utilise votre chat

Ouvrez la page du coanimateur avec la même valeur de session que Social Stream pour qu'il voie le chat en direct. Choisissez le mode dans Chat en direct.

Réglage du chat en directFonction
Contexte seul : répondre sur demande (par défaut)Mémorise les messages récents et reste silencieux jusqu'à votre question sur le chat.
Répondre aux questions et mentions à voix hauteRépond automatiquement aux questions et mentions à voix haute.
Répondre à chaque message à voix hauteRépond à chaque message à voix haute.

Aucune de ces options ne publie de réponses dans le chat YouTube, Twitch ou Kick. Contexte uniquement transmet le chat à l'IA uniquement avec OpenAI Realtime. Les autres fournisseurs observent le chat sans le transmettre à l'IA.

IA gratuite pour les tests

  1. Ouvrir Chat Bots et services IA → Configurer le fournisseur LLM.
  2. Sélectionnez SSN Hosted Trial LLM (expérimental).
  3. Laissez l'endpoint, le jeton et le modèle vides.

Elle est gratuite pendant l'essai et peut être désactivée ou limitée. Pour un usage durable, ajoutez votre jeton ou utilisez une IA locale.

Boutons du Dock en 5 étapes

  1. Ouvrez le Dock : dock.html?session=YOUR_SESSION_ID.
  2. Ajoutez l'overlay de scène à OBS : cohost-overlay.html?session=YOUR_SESSION_ID. Ajoutez &tts si l'overlay doit parler.
  3. Configurez un fournisseur IA dans le menu. Pour un test rapide, utilisez SSN Hosted Trial LLM.
  4. Activez Chat Bots et services IA → Chat Bot - Interface privée → Activer le chatbot privé.
  5. Faites un clic droit sur un message du Dock et choisissez Coprésentateur.
Pas de menu Co-host ? Il apparaît seulement quand le Dock détecte l'overlay de scène sur la même session.

Laissez-le commander votre direct

Le coanimateur peut lancer Spotify, changer de scène OBS ou mettre un message en avant. Tout est désactivé par défaut. OpenAI Realtime prend en charge les trois fonctions. SSN Configured LLM prend uniquement Spotify en charge. Les autres fournisseurs ne les proposent pas encore.

  1. Dans le menu Social Stream, activez uniquement les outils souhaités.
  2. Pour OBS, saisissez les noms exacts des scènes autorisées, séparés par des virgules. Gardez actions.html connecté à OBS, ou utilisez une source navigateur OBS avec les autorisations complètes.
  3. Sur cohost.html, ouvrez Commandes du direct par le coprésentateur et activez les mêmes outils.
  4. Demandez-le à voix haute, par exemple « passe à BRB », « mets le dernier message en avant » ou « efface le chat mis en avant ».
Vous seul pouvez déclencher les outils. Les spectateurs ne le peuvent pas. Il exécute un outil par demande et choisit uniquement les scènes de votre liste. Mettre un message en avant nécessite le Dock ouvert. Une réponse « terminé » signifie que la demande a été envoyée, pas qu'OBS ou l'overlay l'a exécutée jusqu'au bout.

Boutons de sourdine et volume
  • Couper le microphone cesse d'envoyer votre voix au coanimateur.
  • Couper la voix du coprésentateur, le volume, le sélecteur de sortie et Arrêter de parler contrôlent ce que vous entendez.
  • Couper l’audio système partagé est distinct et apparaît uniquement pour les fournisseurs pouvant utiliser votre écran.

Quand la page du coanimateur lit déjà la voix, l'overlay désactive sa propre parole pour éviter de l'entendre deux fois. &forcetts désactive ce comportement.

Communication entre les pages (pour développeurs)

Format des messages et notes de conception

Le Dock et l'overlay utilisent le pont de session habituel de Social Stream. Les messages sont envoyés comme overlayNinja données et ciblés par étiquette.

Lire sur le coprésentateur : le Dock envoie le message choisi directement à cohost-overlay.html.

Réponse / Petite taquinerie : le Dock interroge le chatbot privé en arrière-plan, affiche le brouillon dans le Dock et l'envoie à l'overlay uniquement après un clic sur Speak.

{
  "action": "cohostOverlay",
  "target": "cohost-overlay",
  "meta": {
    "command": "say",
    "text": "The line the avatar should say",
    "speak": true,
    "emotion": "happy"
  }
}
  • Pour les flux textuels du Dock, l'overlay fournit l'image et la voix TTS facultative. Pour la voix OpenAI, capturez l'audio de cohost.html séparément. L'overlay ne rejoue pas cet audio WebRTC.
  • Les détails supplémentaires de commande vont dans meta, pour que les données restent prévisibles pour les overlays et automatisations.
