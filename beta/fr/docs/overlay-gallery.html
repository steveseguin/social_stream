Utiliser une incrustation avec votre direct

Saisissez l'identifiant de session de Social Stream Ninja, puis choisissez Ouvrir l'incrustation sur une carte. Copiez ce lien dans une source navigateur OBS. Les incrustations de mise en avant montrent les messages sélectionnés depuis votre Dock ; les multi-alertes montrent les événements entrants.

ENSEMBLE ASSORTI

Ajoutez chaque lien comme source navigateur OBS distincte. Les messages mis en avant viennent de votre Dock ; les alertes réagissent aux événements entrants.

Ces champs restent sur cette page et ne sont pas enregistrés. Pour le mode serveur, les filtres, le masquage automatique et les autres options, utilisez le préréglage correspondant dans l'application.
