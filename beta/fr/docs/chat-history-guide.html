Rôle de la base de données locale des messages

SSN enregistre les messages capturés dans une base de données du navigateur ou de l’installation de bureau qui effectue la capture. La page d’historique du chat utilise cette base pour consulter les anciens messages.

Le Désactiver la base de données locale des messages empêche l’enregistrement de nouveaux messages. La capture en direct et l’affichage dans le dock peuvent continuer ; voir des messages dans le dock ne prouve donc pas que l’historique est enregistré.

La détection des premiers messages et la reconnaissance des spectateurs fondée sur l’historique dépendent aussi de la base de données locale.

Maintenir les points de fidélité opérationnels

Le gain de points et les gestionnaires des commandes !points, !leaderboard et !rewards s’exécutent lors de l’enregistrement des messages capturés. Désactiver la base de données locale arrête ces gestionnaires, même si les options de points sont activées.

  1. Trouvez Désactiver la base de données locale des messages dans les paramètres SSN et laissez cette option désactivée.
  2. Dans Système de points, activez les points de fidélité et les commandes de chat souhaitées.
  3. Demandez à un spectateur d’envoyer un message, puis !points. Vérifiez son compte sur la bonne plateforme.

Les soldes sont stockés séparément de l’historique des messages. Utilisez Système de points → Sauvegarde et restauration → Exporter les points (Points System → Backup & Restore → Export Points) pour les sauvegarder. Partager un identifiant de session avec une autre installation ne synchronise aucune des deux bases de données.

Consultez : guide des points de fidélité pour les gains, classements, récompenses et sauvegardes.

Utilisation de l’historique existant

Lorsque le registre des points est vide et n’a encore été ni initialisé ni réinitialisé, SSN peut calculer les points initiaux à partir de l’historique enregistré. Ce calcul est effectué une seule fois pour initialiser les soldes.

Les interactions passées suivent les règles de gain en direct : la première interaction admissible rapporte les points de base, et les suivantes peuvent recevoir des bonus de série. Seul l’historique disponible peut être pris en compte ; conservez un export des points lors du déplacement ou de la récupération d’une installation.
