Incrustation OBS vide

Vérifiez d'abord le Dock. S'il est vide, corrigez la source/plateforme. Si le Dock fonctionne, ouvrez l'URL exacte de l'incrustation dans un navigateur normal et vérifiez que la même valeur de session, puis actualisez la source navigateur OBS.

Ouvrir le dépannage OBS

Mauvaise session

Les pages de source, Dock, incrustation, bot et Event Flow doivent utiliser le même identifiant de session. Considérez ces identifiants comme des noms de salons : une orthographe différente désigne un autre salon.

dock.html?session=YOUR_SESSION

Ouvrir le guide des sessions, mots de passe et modes de relais

Mettre à jour sans perdre les paramètres

Exportez d'abord les paramètres, ne désinstallez pas l'extension lors d'une mise à jour ordinaire et utilisez le transfert chiffré de session complète de l'application de bureau lorsque les cookies et connexions doivent aussi être déplacés.

Ouvrir le guide des mises à jour sûres, sauvegardes et récupération

OBS n'entend pas la synthèse vocale

La synthèse vocale simple du système est souvent audible sur l'ordinateur mais pas dans la source navigateur OBS. Utilisez un mode de synthèse vocale par fournisseur/navigateur tel que Kokoro, Piper, Kitten, eSpeak, un service compatible OpenAI ou un fournisseur cloud, ou acheminez séparément le son du système.

Ouvrir le guide de configuration de la synthèse vocale

Kokoro ne parle pas portugais ou espagnol

Les voix Kokoro intégrées sont anglaises. Pour le portugais, utilisez Piper avec pipervoice=pt_BR-faber-medium, ou eSpeak avec espeakvoice=pt-br. Pour l'espagnol, utilisez Piper avec pipervoice=es_ES-davefx-medium, ou eSpeak avec espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Ouvrir la configuration des fournisseurs de synthèse vocale

Cela fonctionne dans Chrome mais pas dans l'application de bureau

L'application de bureau utilise des sessions Electron, pas votre profil Chrome habituel. Connectez-vous dans la fenêtre source de l'application ou utilisez l'extension Chrome lorsque la plateforme bloque les navigateurs intégrés ou d'application.

Ouvrir les modes de l'application autonome

De quel serveur local ai-je besoin ?

Activer le serveur local (Enable Local Server) est un relais WebSocket pour les pages SSN prises en charge. API de contrôle local est destiné aux scripts et outils IA de la même machine. L'hébergement sans interface exécute l'application de bureau complète sur un serveur Linux. Le serveur multimédia Event Flow ne sert que les médias locaux approuvés.

Ouvrir le guide des serveurs et services locaux

TikTok échoue ou change de mode

Notez le mode de l'application, le fournisseur de signature, le texte d'état, la version de l'application et si le chat est visible en mode standard. Testez un mode TikTok à la fois.

Ouvrir les modes TikTok de l'application

Le chat YouTube manque

Vérifiez que la diffusion est en direct, que le chat est visible et que vous utilisez le bon circuit YouTube : chat en direct, commentaires statiques, capture standard ou mode WebSocket/API.

Ouvrir le guide de configuration YouTube

Les réponses du bot ne partent pas

Lire le chat n'est pas la même chose que publier dans le chat. Vérifiez la prise en charge des réponses par la plateforme, la connexion et le rôle du compte, le mode source, la réponse du fournisseur et les limites de débit.

Ouvrir le guide de configuration du bot de chat IA

Event Flow ne fait rien

Vérifiez que l'événement source atteint le Dock. Pour les actions audio, multimédias et OBS, gardez actions.html?session=YOUR_SESSION ouvert avec la même session.

Ouvrir les recettes Event Flow
