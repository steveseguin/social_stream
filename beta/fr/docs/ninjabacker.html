Dons NinjaBacker dans Social Stream Ninja

Recevez des dons dans SSN, puis ajoutez des alertes ou un Tip Jar à OBS.

Flux en directWebhookAffichage OBSTest et dépannage

1. Connectez votre compte

Commencez ici avec l'application de bureau SSN ou l'extension Chrome. Gardez SSN allumé pendant la diffusion.

  1. Ouvrir NinjaBacker. Créez votre compte et terminez la configuration Stripe pour accepter des paiements.
  2. Dans le tableau de bord NinjaBacker, ouvrez Social Stream Ninja et copiez votre Private Tip ID.
  3. Dans SSN, ouvrez Argent > Boutiques et soutien > Plateformes connectées > Dons NinjaBacker > Configuration. Saisissez votre nom d'utilisateur et votre Tip ID privé.
  4. Laissez Livraison sur Flux en direct (simple), activez les dons NinjaBacker et cliquez sur Enregistrer la configuration.

Si Plateformes connectées est masqué, passez en mode complet dans SSN.

Le flux en direct ne nécessite aucun webhook. Il affiche les nouveaux dons pendant la connexion ; il ne rejoue pas ceux reçus lorsque SSN était éteint.

2. Facultatif : utilisez un webhook

Choisissez Webhook fiable pour conserver les dons en attente jusqu'à sept jours lorsque SSN est éteint.

  1. Dans NinjaBacker, ouvrez Webhook. Sous Webhook Signature Secret, cliquez sur Generate et copiez le secret. Si vous utilisez déjà un secret, copiez celui-ci.
  2. Dans la configuration NinjaBacker de SSN, choisissez Webhook fiable, collez le secret de signature et cliquez sur Enregistrer la configuration.
  3. Cliquez sur Copier l'URL du récepteur dans SSN. Collez-la dans le champ Webhook URL de NinjaBacker et cliquez sur Save.

L'URL du récepteur commence par :

https://api.socialstream.ninja/v1/ninjabacker/webhook/...

Les URL du Tip Jar, du dock de chat et des autres affichages vont dans OBS. Elles ne peuvent pas recevoir de requêtes webhook.

Revenir au flux en direct

Le changement supprime les dons en attente dans le récepteur SSN. Effacez aussi l'ancienne Webhook URL dans NinjaBacker et enregistrez.

3. Ajoutez votre affichage dans OBS

  1. Pour les alertes, choisissez Dons NinjaBacker sous Incrustation OBS pour dans Boutiques et soutien. Copiez le lien de l'incrustation.
  2. Pour un objectif progressif, ouvrez Argent > Tip Jar et compteur d'objectif. Choisissez le style et l'objectif, puis copiez son lien.
  3. Dans OBS, ajoutez une source Navigateur et collez le lien d'affichage. Utilisez la même session pour SSN et l'affichage.

Styles du Tip Jar et paramètres d'objectif

Partagez votre page publique de dons NinjaBacker avec les spectateurs. Gardez les liens d'incrustation dans OBS et les URL de récepteur dans le champ webhook.

4. Vérifiez votre configuration

Ouvrez l'incrustation d'alertes NinjaBacker de SSN. Dans NinjaBacker, ouvrez Testing et cliquez sur Send Test Tip. Une alerte de test doit apparaître dans cette incrustation.

Lisez le résultat sous Send Test Tip. Webhook accepted confirme la réception, pas l'affichage d'une alerte dans OBS. En cas d'échec, corrigez l'URL ou le secret de signature et envoyez un nouveau test. Les tests du tableau de bord sont réessayés pendant cinq minutes.

Les dons de test n'ajoutent pas d'argent au Tip Jar, n'apparaissent pas comme dons payants dans le chat et ne déclenchent pas de récompenses payantes.

Aucune alerte de test ?

Gardez SSN allumé et les dons NinjaBacker activés. Vérifiez que le nom d'utilisateur et le Tip ID correspondent au même compte. Pour les webhooks, actualisez Delivery History dans NinjaBacker et vérifiez l'URL du récepteur et le secret de signature.

HTTP 405 ou erreur d'URL d'affichage ?

Copiez l'URL du récepteur depuis la configuration Webhook fiable de SSN, enregistrez-la dans NinjaBacker et envoyez un nouveau don de test. L'enregistrement d'une nouvelle URL arrête les tentatives vers l'ancienne destination.

Les dons apparaissent dans le chat mais pas dans l'objectif ?

Vérifiez la session du Tip Jar et les filtres de source, de type de don et d'événement payant. Utilisez un objectif monétaire pour les montants des dons. Les remboursements ne sont pas déduits des alertes ou objectifs SSN.
