Sterowanie OBS za pomocą Social Stream Ninja

Steruj OBS bezpośrednio z Event Flow — bez potrzeby Streamer.bot. Ten poradnik obejmuje konfigurację, wszystkie wyzwalacze i akcje OBS, praktyczne przepisy oraz starsze elementy sterowania doku/źródła przeglądarkowego.

1. Połącz Flow Actions z OBS

OBS WebSocket v5 jest wbudowany w OBS 28 i nowsze. Social Stream Ninja używa go do pełnego sterowania OBS i zdarzeń multimediów.

  1. W OBS otwórz Narzędzia → Ustawienia serwera WebSocket.
  2. Włącz serwer WebSocket. Zachowaj domyślny port 4455; w razie potrzeby ustaw hasło.
  3. W Social Stream Ninja otwórz Flow Actions sekcję i ustaw adres OBS WebSocket oraz opcjonalne hasło.
  4. Skopiuj adres Flow Actions i pozostaw go otwarty. Dla akcji nakładki/dźwięku zalecane jest źródło przeglądarkowe OBS.
  5. Użyj Tester OBS WebSocket , aby potwierdzić połączenie przed zbudowaniem przepływu.
Przykład bezpośredniego adresu URL
https://socialstream.ninja/actions.html?session=YOUR_SESSION&obsws=ws://127.0.0.1:4455

Dodaj &obspw=YOUR_PASSWORD tylko gdy OBS wymaga uwierzytelniania. Dodaj &obsdebug=1 , aby podczas diagnozowania pokazywać małą odznakę statusu połączenia.
Pozostaw stronę Flow Actions uruchomioną. To most odbierający akcje Event Flow i wysyłający żądania OBS WebSocket. Jeśli działa jako źródło przeglądarkowe OBS, wyłącz Zamknij źródło, gdy nie jest widoczne (Shutdown source when not visible) , gdy źródło musi nadal sterować OBS po ukryciu.

2. Dodaj węzły OBS do przepływu

  1. Otwórz Edytor Event Flow i utwórz lub edytuj przepływ.
  2. Przeciągnij wyzwalacz na obszar roboczy.
  3. Rozwiń OBS Studio na liście akcji i przeciągnij potrzebną akcję OBS.
  4. Połącz wyzwalacz z akcją, skonfiguruj dokładne nazwy scen/źródeł OBS, zapisz i włącz przepływ.
Nazwy OBS muszą pasować dokładnie, łącznie ze spacjami i interpunkcją. Akcje źródeł wskazują nazwę wejścia OBS, a nie etykietę elementu sceny, jeśli zmieniono ją niezależnie.

Set Text Source i zmienne przepływu

Pole tekstowe obsługuje zwykłe znaczniki wiadomości, takie jak {username}, {message}, {source} i {donation}, a także wartości dodane przez wcześniejsze węzły przepływu, takie jak {counterValue}, {counterTarget} i {counterRemaining}.

{username}: now {counterValue}, need {counterTarget}
Dla źródła Text (GDI+) lub Text (FreeType 2) wyłącz Odczyt z pliku (Read from file). W przeciwnym razie OBS może nadal wyświetlać zawartość pliku zamiast tekstu wysłanego przez Event Flow.

Sterowanie źródłem multimediów

Odtwórz / pauza

Odtwórz wznawia wstrzymane multimedia. Pauza utrzymuje bieżącą pozycję.

Uruchom ponownie / zatrzymaj

Uruchom ponownie zaczyna od początku. Zatrzymaj kończy odtwarzanie i resetuje wejście.

Następne / poprzednie

Przechodzi między pozycjami wejść obsługujących listy odtwarzania, takich jak VLC Video Source. Źródło multimediów z pojedynczym plikiem może ignorować te akcje.

Głośność, wyciszenie i filtry

Ustaw głośność źródła (Set Source Volume) używa dB, zgodnie ze skalą miksera OBS: 0 dB oznacza niezmienione wzmocnienie, wartości ujemne są cichsze, a -100 dB praktycznie oznacza ciszę. Wyciszenie to oddzielny stan. Toggle Filter zmienia tylko stan włączenia istniejącego filtra; nie edytuje jego ustawień.

Bufor powtórek

Najpierw włącz bufor powtórek w Ustawienia OBS → Wyjście. Użyj Steruj buforem powtórek (Control Replay Buffer) , aby go uruchomić/zatrzymać, a następnie Zapisz bufor powtórek (Save Replay Buffer) , aby zapisać ostatni buforowany fragment na dysku.

Ostrzeżenie o wyjściu na żywo: Start/Stop Streaming i Start/Stop Recording działają natychmiast. Stosuj restrykcyjne wyzwalacze, uprawnienia i okresy oczekiwania, aby zwykłe wiadomości czatu nie uruchamiały ich przypadkowo.

5. Przydatne przepisy

Wiadomość co godzinę, gdy OBS nadaje

W edytorze Event Flow wybierz Start with a template → Intermediate → Hourly message while OBS is live. Początkowo jest wyłączony i zawiera trzy gałęzie w jednym przepływie:

  • OBS Stream Started → Set Gate State: ON
  • Time Interval (3600 sekund) → ON/OFF Switch → Send Message
  • OBS Stream Stopped → Set Gate State: OFF

Obie akcje Set Gate State już wskazują ten sam przełącznik, który domyślnie ma OFF. Edytuj Wyślij wiadomość , aby wybrać platformę czatu (przykład używa Twitcha) i wiadomość. Wybierz platformę lub All Platforms; Reply to Source nie może odpowiedzieć na zdarzenie OBS ani impuls timera.

Połącz Flow Actions z OBS, pozostaw Social Stream i docelowy czat połączone, a następnie zapisz i włącz przepływ przed rozpoczęciem transmisji. Przełącznik czeka na zdarzenie rozpoczęcia OBS; wczytanie go w trakcie trwającej transmisji nie ustawia go na ON. Ponowne uruchomienie Social Stream również resetuje przełącznik do OFF.

Czas: interwał działa według własnego harmonogramu, więc pierwsze przypomnienie może przyjść wcześniej niż godzinę po rozpoczęciu transmisji. Kolejne powtarzają się co godzinę, gdy przełącznik ma ON. Zmień wartość Time Interval, aby ustawić inną częstotliwość; jest mierzona w sekundach.

Tekst licznika w OBS

Umieść Ustaw źródło tekstowe (Set Text Source) za ścieżką licznika/sprawdzenia i użyj:

{username}: now {counterValue}, need {counterTarget}

Uruchom coś po filmie

Zakończenie multimediów OBS (OBS Media Ended) (filtruj do Intro Video) → Zmień scenę (Change Scene) na Main.

Ponowne uruchomienie multimediów sterowane czatem

Wiadomość równa się (Message Equals) !replayintro → warunek uprawnień → Control Media Source: Restart.

Odśwież stronę alertów

Wiadomość równa się (Message Equals) !refreshalerts → warunek moderatora → Odśwież źródło przeglądarkowe (Refresh Browser Source).

Ścisz muzykę na czas alertu

Ustaw głośność źródła (Set Source Volume) na -24 dB → akcja alertu → Delay → przywróć do 0 dB.

Przepływ powtórek

Rozpoczęcie transmisji OBS (OBS Stream Started) → Control Replay Buffer: Start; oddzielne zaufane polecenie uruchamia Zapisz bufor powtórek (Save Replay Buffer).
