Przegląd

SSN może odczytywać przechwycony tekst czatu z każdego obsługiwanego źródła; platforma czatu nie potrzebuje własnej funkcji TTS. Dok lub nakładka z włączonym TTS odczytuje otrzymane wiadomości zgodnie z filtrami i ustawieniami TTS. Zacznij od krótkiego poradnika konfiguracji; ta strona opisuje opcje głosów i ustawienia zaawansowane. Porównaj dostawców, posłuchaj próbek i zobacz ustawienia.

Szybki start: Użyj dock.html?session=YOUR_SESSION&speech=en-US. Domyślnie używa System TTS. Dla bezpłatnego dostawcy w OBS dodaj również &ttsprovider=kokoro. Pozostaw tę stronę otwartą i połączoną; mówić powinna tylko jedna kopia.

Gdzie używa się TTS?

  • Social Stream Ninja: Odczytuje wiadomości czatu odbiorców w wielu miejscach
  • CAPTION.Ninja: Oferuje napisy, transkrypcję i tłumaczenie z TTS
  • Obie usługi oferują płatne i bezpłatne opcje TTS
System TTS to nie to samo co wszystkie bezpłatne TTS:
  • Głosy systemowe zależą od przeglądarki i systemu operacyjnego. OBS może nie udostępniać żadnych użytecznych głosów, nawet gdy Chrome/Edge działa.
  • Brak głosu to co innego niż odtwarzanie mowy poza przechwytywaniem dźwięku OBS. Routing dźwięku nie naprawi braku obsługi mowy.
  • Bezpłatni dostawcy, tacy jak Kokoro, Piper, Kitten i eSpeak, zamiast tego generują dźwięk strony. TTS w OBS nie wymaga płatności.
  • Sprawdź dostępność głosu, a następnie przechwytywanie dźwięku.

Opcje dostawców TTS

System TTS (bezpłatne)

  • Używa głosów wbudowanych w system operacyjny
  • Ograniczona obsługa języków zależna od instalacji systemu
  • Dostępność głosów i routing dźwięku zależą od przeglądarki i systemu operacyjnego; testuj w rzeczywistym odtwarzaczu
  • Zgodność między przeglądarkami znacznie się różni

Dostępność głosów systemowych

To typowe możliwości, a nie gwarancje dla każdej instalacji. OBS używa własnej wbudowanej przeglądarki i nie dziedziczy listy głosów zainstalowanego Chrome/Edge. Udany test w aplikacji SSN nie testuje oddzielnego źródła przeglądarkowego OBS.

Edge

⚠ Ograniczona obsługa

Ograniczenia przeglądarki:
  • Nie wszystkie przeglądarki obsługują syntezę mowy jednakowo (niektóre wersje Firefoksa mają ograniczone głosy)
  • Chrome oferuje opcje TTS dostarczane przez Google
  • Edge obsługuje TTS Microsoft i głosy z pakietów językowych Windows
  • Safari wymaga interakcji użytkownika, aby rozpocząć odtwarzanie dźwięku
  • Sprawdź dostępne głosy dla Twojej przeglądarki

Metody przechwytywania dźwięku TTS Windows w OBS

Dźwięk strony: bezpłatni dostawcy lokalni i chmurowi

Lokalni dostawcy SSN działający w przeglądarce i chmurowi dostawcy dźwięku odtwarzają wygenerowany dźwięk przez stronę:

  • Po prostu włącz „Control audio via OBS” w źródle przeglądarkowym
  • Nie potrzeba wirtualnych kabli audio
  • Działa z aplikacją SSN i źródłami przeglądarkowymi OBS

Metody przechwytywania System TTS

Ważne: Najpierw potwierdź, że System TTS generuje mowę. Wbudowana przeglądarka OBS może nie udostępniać użytecznego głosu systemowego. Jeśli nie generuje mowy, zmiana routingu dźwięku nie pomoże. Wybierz innego dostawcę albo generuj mowę w obsługiwanej przeglądarce i przechwytuj jej dźwięk.

W szczególności dla System TTS:

  • Nie zakładaj, że OBS udostępnia te same głosy co Chrome lub Edge
  • Ograniczona obsługa w przeglądarkach (Firefox może nie mieć niektórych głosów TTS)
  • Chrome oferuje opcje Google, Edge ma opcje Microsoft
  • Jeśli mowa jest odtwarzana poza źródłem przeglądarkowym sceny, przechwyć to wyjście oddzielnie

Programy do routingu do pobrania: VB-Audio Virtual Cable | Voicemeeter | Audio Router (starsze)

Najpierw spróbuj przechwycić mówiącą przeglądarkę przez dźwięk aplikacji lub pulpitu OBS, tam gdzie jest to obsługiwane. Poniższe metody wirtualnego kabla są opcjonalnymi alternatywami; nie dodają obsługi mowy do OBS.

Metoda 1: domyślny routing dźwięku z wirtualnym kablem

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Metoda 2: routing aplikacji w Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Metoda 3: routing aplikacji w Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Metoda 4: program Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Metoda 5: Voicemeeter (zaawansowane)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Testowanie konfiguracji

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Alternatywy: Użyj bezpłatnego wbudowanego dostawcy, takiego jak Kokoro, Piper, Kitten lub eSpeak, dostawcy chmurowego albo własnego serwera TTS.

Instalowanie dodatkowych pakietów językowych

Windows 11

  1. Przejdź do Start > Ustawienia > Czas i język > Mowa
  2. W sekcji Zarządzaj głosami, kliknij Dodaj głosy
  3. Wybierz żądane języki i kliknij Dodaj
  4. Uruchom ponownie przeglądarki, aby odświeżyć dostępne głosy

Windows 10

Postępuj zgodnie z instrukcjami w oficjalnym poradniku Microsoft , aby zainstalować pakiety językowe.

Wskazówka: Niektóre głosy zewnętrzne mogą nie pojawiać się w przeglądarkach z powodu problemów ze zgodnością. Firefox często pokazuje więcej głosów systemowych niż przeglądarki oparte na Chromium.

Parametry URL konfiguracji TTS

Parametry podstawowe

Parametr Opis Przykład
&speech Włącz TTS z kodem języka &speech=en-US
&pitch Wysokość głosu (od 0.1 do 2.0) &pitch=1.2
&volume Poziom głośności (od 0.0 do 1.0) &volume=0.8
&rate Tempo mowy (od 0.1 do 10.0) &rate=1.5
&voice Częściowe dopasowanie nazwy głosu &voice=google
&ttsprovider Wybierz dostawcę: kokoro, piper, kitten, espeak, openai, customtts, localtts, elevenlabs, google, speechify, gemini &ttsprovider=customtts

Parametry zaawansowane

Parametr Opis
&simpletts Nie mów „mówi” ani „ktoś mówi”
&simpletts2 W ogóle nie odczytuj nazw uczestników czatu
&ttscommand Włącz własne polecenie TTS (domyślnie: !say)
&readevents Uwzględniaj zdarzenia transmisji w TTS
&skipmessages=3 Odczytuj tylko co trzecią wiadomość

Konfiguracja dostawcy TTS

Kokoro TTS (bezpłatne, wbudowane)

  • Włącz za pomocą ?ttsprovider=kokoro
  • Działa w przeglądarce przez WebGPU/WASM — bez serwera
  • Działa bezpośrednio ze źródłem przeglądarkowym OBS
  • Wybór głosu: &voicekokoro=af_bella
  • Sterowanie szybkością: &kokorospeed=1.2
  • Wybierz głos dla języka: &voicekokoro=ef_dora dla hiszpańskiego lub &voicekokoro=pf_dora dla portugalskiego brazylijskiego. Zmiana &speech= sama nie zmienia wybranego głosu. Istniejące identyfikatory głosów angielskich nadal działają.

Piper TTS (bezpłatne, wbudowane)

  • Włącz za pomocą ?ttsprovider=piper
  • Szybki neuronowy TTS działający w przeglądarce, przyjazny dla CPU
  • Wybór głosu: &pipervoice=en_US-hfc_female-medium
  • Głosy portugalskie: &pipervoice=pt_BR-faber-medium lub &pipervoice=pt_BR-edresson-low
  • Głosy hiszpańskie: &pipervoice=es_ES-davefx-medium lub &pipervoice=es_MX-ald-medium
  • Sterowanie szybkością: &piperspeed=1.0

Kitten TTS (bezpłatne, wbudowane)

  • Włącz za pomocą ?ttsprovider=kitten
  • Lekki TTS oparty na ONNX działający w przeglądarce
  • Wybór głosu: &kittenvoice=expr-voice-4-f

eSpeak-NG (bezpłatne, wbudowane)

  • Włącz za pomocą ?ttsprovider=espeak
  • Klasyczny TTS z otwartym kodem, działa na dowolnym sprzęcie
  • Wybór głosu: &espeakvoice=en
  • Przykład portugalski: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Przykład hiszpański: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Sterowanie szybkością: &espeakspeed=175

Przykłady TTS po portugalsku i hiszpańsku

  • Portugalski, najlepsza bezpłatna lokalna jakość przetestowana w SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Portugalski, najszybsza opcja awaryjna przetestowana w SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Hiszpański, najlepsza bezpłatna lokalna jakość przetestowana w SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Hiszpański, najszybsza opcja awaryjna przetestowana w SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Dla głosów chmurowych użyj głosu/języka dostawcy obsługującego język docelowy, takiego jak Google Cloud, ElevenLabs, Speechify, Gemini lub lokalny serwer zgodny z OpenAI.

OpenAI / TTS serwera lokalnego

  • Włącz za pomocą ?ttsprovider=openai
  • Użyj ?ttsprovider=customtts lub ?ttsprovider=localtts dla samodzielnie hostowanego punktu końcowego
  • Domyślnie używa API OpenAI lub dowolnego zgodnego serwera lokalnego
  • Własny punkt końcowy: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Ważne: localhost i 127.0.0.1 oznaczają ten sam komputer, który odtwarza stronę TTS. Jeśli OBS działa na innym komputerze niż serwer TTS, użyj zamiast tego adresu IP komputera serwera w sieci LAN.
  • Lokalne serwery nie wymagają klucza API
  • Jeśli lokalny serwer ma problemy z CORS lub siecią lokalną w Chrome/OBS, uruchom npm run local-tts-bridge na komputerze OBS i skieruj SSN do http://127.0.0.1:8124/v1/audio/speech
  • SSN wysyła { model, input, voice, response_format, speed } i obsługuje binarny dźwięk, adresy dźwięku w JSON oraz dźwięk base64 w JSON
  • Odtwarzanie z własnego/lokalnego punktu końcowego jest obecnie buforowane; SSN nie odtwarza jeszcze stopniowo strumieniowanych fragmentów dźwięku
  • Głos: &voiceopenai=af_bella, szybkość: &openaispeed=1.0. Użyj nazwy głosu obsługiwanej przez serwer; głosy Kokoro wyglądają jak af_bella, natomiast głosy w stylu openedai-speech/OpenAI mogą wyglądać jak nova lub echo.
  • Zobacz Poradnik lokalnego TTS AI do konfiguracji własnego serwera

Google Cloud TTS

  • Włącz za pomocą ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Głosy profesjonalnej jakości
  • Wybór głosu: &voicegoogle=en-GB-Standard-A
  • Język: &googlelang=en-US

Gemini TTS

  • Włącz za pomocą ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Model: &geminimodel=gemini-2.5-flash-preview-tts
  • Głos: &voicegemini=Kore, język: &geminilang=th-TH
  • Instrukcje stylu: &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • Włącz za pomocą ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • Identyfikator głosu: &voice11=YOUR_VOICE_ID
  • Model: &elevenlabsmodel=eleven_multilingual_v2
  • Parametry: można dostosować stabilność, podobieństwo i styl

Fish Audio TTS

Wybierz Fish Audio i wpisz klucz API oraz opcjonalny identyfikator głosu. Domyślny model to s2.1-pro-free. Konfiguracja, opcje modeli i ograniczenia dostępu przeglądarki.

Speechify TTS

  • Włącz za pomocą ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Głos: &voicespeechify=henry
  • Model: &speechifymodel=simba-3.0 (domyślnie) lub &speechifymodel=simba-3.2 dla angielskiego.
  • Szybkość mówienia: &speechifyspeed=1.2 (zakres od 0.5 do 3.0; normalna wartość to 1.0).
  • Poradnik konfiguracji Speechify, głosów, szybkości i głośności

Rozwiązywanie problemów

Typowe problemy

  • Nie odtwarza się żaden dźwięk: Sprawdź, czy TTS jest włączone, strona generująca TTS jest otwarta, a źródło przeglądarkowe nie jest wyciszone. W zwykłej przeglądarce kliknij stronę raz.
  • Głosy się nie pojawiają: Uruchom ponownie przeglądarkę po zainstalowaniu pakietów językowych
  • OBS nie przechwytuje: Jeśli nie ma mowy, najpierw sprawdź dostępność głosu/dostawcy. Jeśli mowa istnieje, sprawdź Steruj dźwiękiem przez OBS (Control audio via OBS), wyciszenie miksera i ścieżki wyjściowe albo przechwyć zewnętrzną przeglądarkę, która mówi
  • Lokalny punkt końcowy działa w teście aplikacji, ale nie w OBS: OBS jest oddzielną przeglądarką. Sprawdź punkt końcowy z komputera OBS, zwłaszcza jeśli używasz 127.0.0.1.
  • Odczytywana jest tylko pierwsza litera lub pierwsze słowa: usuń ttsquick z adresu OBS, jeśli występuje.
  • Problemy z Safari: Safari ma ograniczoną obsługę automatycznego TTS
  • Płatna usługa nie działa: Sprawdź klucz API i upewnij się, że prawidłowo wskazano dostawcę

Dobre praktyki

  • Użyj dostawcy generującego dźwięk strony, aby uprościć konfigurację OBS; dostępni są bezpłatni dostawcy lokalni
  • Przetestuj konfigurację prostymi frazami przed transmisją na żywo
  • Uwzględnij ryzyko treści tworzonych przez użytkowników przy TTS
  • Miej przełącznik pozwalający w razie potrzeby szybko wyłączyć TTS
