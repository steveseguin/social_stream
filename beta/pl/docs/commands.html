Polecenia bota

Wbudowane polecenia bota

Social Stream Ninja zawiera kilka wbudowanych poleceń, których widzowie mogą używać na czacie lub które możesz wywoływać przez API.

Polecenie Opis Jak włączyć
!joke Odpowiada losowym sucharem o tematyce technologicznej Włącz przełącznikiem w menu rozszerzenia
hi Automatycznie wita każdego, kto napisze „hi” na czacie Włącz przełącznikiem w menu rozszerzenia
!cycle Po włączeniu pozwala widzom zmieniać sceny OBS Włącz przełącznikiem w menu rozszerzenia

Uwaga: Polecenia bota działają tylko po poprawnym skonfigurowaniu automatycznych odpowiedzi i uzyskaniu uprawnień do publikowania na odpowiednich platformach.

Konfiguracja automatycznych odpowiedzi

Aby automatyczne odpowiedzi działały poprawnie:

  1. Upewnij się, że jesteś zalogowany na platformie (YouTube, Twitch itd.)
  2. Upewnij się, że okno czatu jest widoczne, a nie zminimalizowane
  3. Najpierw spróbuj ręcznie wysłać wiadomość testową, aby potwierdzić uprawnienia
  4. Włącz przełączniki odpowiednich poleceń w menu rozszerzenia

Jeśli przy automatycznych odpowiedziach pojawia się niebieski pasek debugowania, możesz go ukryć, uruchamiając Chrome z flagą --silent-debugger-extension-api .

API serwera

Przegląd

Social Stream Ninja oferuje rozbudowane API do programowego sterowania każdym elementem konfiguracji transmisji. Serwer API może zarówno wysyłać polecenia do konfiguracji, jak i odbierać przychodzące wiadomości z połączonych usług czatu.

Zarządzanie nakładkami

Steruj wyróżnionymi wiadomościami, czyść nakładki i zmieniaj wygląd treści podczas transmisji.

Integracja webhooków

Odbieraj wydarzenia z usług zewnętrznych, takich jak Stripe, Ko-Fi i Buy Me A Coffee.

Eksport wiadomości

Eksportuj wiadomości czatu do pliku lub przekazuj przez webhook (POST) do własnych integracji.

Wymagane ustawienia (Global settings → Mechanics):

  • 🎮 Zdalne sterowanie (StreamDeck/Bitfocus): Włącz „Włącz zdalne sterowanie rozszerzeniem przez API” (Enable remote API control of extension) (Przełącznik 1) — połącz z kanałem 1
  • 📡 Odbiornik czatu (aplikacje Python/Node): Włącz przełącznik 1 + „Wysyłaj wiadomości czatu do serwera API” (Send chat messages to API server) (Przełącznik 3) — połącz z kanałem 4

Zobacz pełną dokumentację API aby uzyskać szczegółowe instrukcje i przykłady kodu.

Adresy API i metody połączenia

HTTP GET/POST

https://io.socialstream.ninja/{sessionID}/{action}/{target}/{value}

Idealne do prostych poleceń ze Stream Deck lub własnych skryptów.

WebSocket

wss://io.socialstream.ninja:443

Do dwukierunkowej komunikacji w czasie rzeczywistym z automatycznym ponownym łączeniem.

Jeśli wolisz połączenia peer-to-peer bez trybu WebSocket, możesz użyć Social Stream Ninja WebRTC SDK. Zawiera przykłady dla Node i przeglądarki, takie jak Odbiornik Social Stream Ninja.

Server-Sent Events

https://io.socialstream.ninja/sse/{sessionID}

Do jednokierunkowych aktualizacji z serwera w czasie rzeczywistym.

System kanałów

API używa systemu kanałów do kierowania wiadomości:

	- Channel 1: Remote control commands (default for StreamDeck/Bitfocus)
	- Channel 2: Dock page output
	- Channel 3: Extension receives commands from Dock
	- Channel 4: Chat messages from Extension (use this to receive Twitch/YouTube chat!)
	- Channel 5: Waitlist/giveaway communication
	- Channels 6-9: Reserved for future use

Połącz z wybranym kanałem:

// To receive chat messages (listen on channel 4):
wss://io.socialstream.ninja/join/SESSION_ID/4

// To send commands (channel 1 default):
wss://io.socialstream.ninja/join/SESSION_ID

StreamDeck i Companion

Integracja StreamDeck

Social Stream Ninja integruje się ze StreamDeck na kilka sposobów: przez natywne działania HTTP i Bitfocus Companion.

Metoda HTTP/API

Użyj działania „Website” w StreamDeck z włączonym „GET request in background”, aby wysyłać polecenia bezpośrednio do API.

Bitfocus Companion

Natywna integracja z gotowymi działaniami, informacją zwrotną na żywo i zmiennymi do treści dynamicznych.

Integracja Companion

Bitfocus Companion zapewnia rozbudowane sterowanie Social Stream Ninja przez API WebSocket lub HTTP.

Działanie Opis Metoda API
Wyczyść wyróżnioną wiadomość Usuwa aktualnie wyróżnioną wiadomość z nakładki WebSocket/HTTP
Następna w kolejce Wyświetla kolejną oczekującą wiadomość WebSocket/HTTP
Przełącz automatyczny pokaz Włącza/wyłącza automatyczne wyróżnianie wiadomości WebSocket/HTTP
Wyślij wiadomość czatu Wysyła wiadomość na wszystkie połączone platformy WebSocket/HTTP

Zmienne dynamiczne

  • featured_message — tekst bieżącej wyróżnionej wiadomości
  • featured_username — nazwa autora bieżącej wyróżnionej wiadomości
  • queue_size — liczba wiadomości w kolejce

Integracja AI

Tryb bota czatu AI

Social Stream Ninja oferuje szeroką integrację AI, wzbogacając transmisje o odpowiedzi czatu, moderację i inne funkcje. Wybierz lokalnego lub chmurowego dostawcę AI zgodnie z potrzebami.

Automatyczne odpowiedzi na czacie

Pozwól AI automatycznie angażować widzów, odpowiadać na pytania i podtrzymywać rozmowę, gdy skupiasz się na swoich treściach.

Moderacja treści

Używaj AI do moderacji czatu: rozpoznawania potencjalnie szkodliwych wiadomości i automatycznej obsługi według twoich preferencji. Wybierz tryb nieblokujący lub ścisłego blokowania.

Wyszukiwanie RAG

Generowanie wspomagane wyszukiwaniem pozwala AI przeszukiwać własną bazę wiedzy i udzielać dokładnych odpowiedzi dotyczących twoich treści.

Wiele instancji botów

Uruchamiaj różne instancje botów: publicznego bota czatu, prywatnego bota sam na sam, bota cenzurującego, a nawet multimodalnego współprowadzącego AI, który widzi i słyszy.

Obsługiwani dostawcy AI

Social Stream Ninja obsługuje wielu dostawców AI — od w pełni lokalnych modeli przeglądarkowych i wykonawczych po hostowane API:

Ollama (natywne lokalne API)

Darmowe, nastawione na prywatność modele AI działające na twoim komputerze przez własne API Ollama.

Local Gemma 4

Uruchom Gemma 4 w przeglądarce po skopiowaniu plików modelu na własny serwer zasobów; host SSN largefiles obecnie nie zawiera plików Gemma.

Local Qwen 3.5

Uruchom Qwen 3.5 w przeglądarce z własnych hostowanych plików modelu, aby uzyskać lokalne, prywatne odpowiedzi.

ChatGPT / OpenAI

API OpenAI, w tym nowoczesne modele czatu i głosu w czasie rzeczywistym.

Google Gemini

Modele Google Gemini, w tym aktualne opcje tekstowe Gemini 2.5 i multimodalne na żywo.

DeepSeek

Wydajne, ekonomiczne modele AI zoptymalizowane do rozmów.

xAI (Grok)

API xAI Grok, w tym sesje głosowe na żywo przy użyciu krótkotrwałych sekretów klienta.

AWS Bedrock

Modele AI klasy biznesowej różnych dostawców, w tym Claude i Llama.

OpenRouter

Dostęp do wielu modeli AI przez wspólny interfejs API.

Groq

Szybkie generowanie odpowiedzi czatu zgodne z OpenAI o niskim opóźnieniu.

Własne API (zgodne z OpenAI)

Połącz z llama.cpp, LM Studio, vLLM lub inną usługą zgodną z OpenAI.

Uwaga: Ollama używa własnego natywnego API. Dla llama.cpp, LM Studio, vLLM i innych serwerów zgodnych z OpenAI wybierz Własne API.

Integracja syntezy mowy

Social Stream Ninja zapewnia rozbudowaną obsługę TTS wiadomości bota i wyróżnionego czatu:

Systemowy TTS

Darmowy wbudowany TTS korzystający z syntezatora głosu systemu operacyjnego.

Kokoro

Darmowy lokalny TTS wykorzystujący WebGPU/CPU dla osób dbających o prywatność.

Kitten TTS

Lekki TTS przeglądarkowy pobierający mały model do lokalnego generowania głosu.

ElevenLabs

Płatna synteza mowy z naturalnymi, dostosowywanymi głosami.

Google Cloud TTS

Wysokiej jakości głosy z bogatym wyborem języków i opcji dostosowania.

Gemini (próbny TTS)

Próbne neuronowe modele głosu Google z wyborem głosu i języka.

Speechify

Synteza mowy AI z możliwościami naturalnej konwersji głosu.

OpenAI TTS

Synteza mowy OpenAI z wyborem głosów, modeli i opcjonalnych zgodnych usług.

Konfiguracja integracji AI

Aby skonfigurować integrację AI w obecnym menu, wykonaj te kroki:

1

Wybierz i połącz dostawcę LLM

Wybierz dostawcę w sekcji Skonfiguruj dostawcę usługi LLM i uzupełnij odpowiednie pola:

  • Ollama: Zainstaluj lokalnie i w razie potrzeby ustaw adres usługi
  • Local Gemma / Local Qwen: Użyj hostowanych plików modelu przeglądarkowego i opcjonalnego zastąpienia folderu; Qwen może korzystać z SSN largefiles, a Gemma wymaga własnej kopii folderu
  • ChatGPT, Gemini, DeepSeek, xAI, Groq, OpenRouter, Bedrock: Dodaj klucz API i preferowany model
  • Własne API: Wpisz adres zgodny z OpenAI, identyfikator modelu i opcjonalny klucz API
2

Przetestuj wybranego bota czatu

Użyj wbudowanego przycisku Przetestuj wybranego bota czatu aby przed transmisją sprawdzić dostawcę, model i dane uwierzytelniające.

3

Skonfiguruj zachowanie bota

Dostosuj zachowanie bota na czacie:

  • Włącz bota czatu AI LLM
  • Ustaw nazwę bota, słowa wyzwalające i limit częstotliwości odpowiedzi
  • Wybierz, czy odpowiedzi mają wracać na czat, czy trafiać tylko na stronę nakładki bota
  • Dodaj własne instrukcje dotyczące tonu, roli i zasad moderacji
4

Włącz opcjonalne dodatki

Włącz potrzebne funkcje wokół bota:

  • Włącz TTS odpowiedzi bota i wybierz dostawcę
  • Wybierz stały czas, czas zależny od długości wiadomości lub ukrywanie po TTS dla /bot.html; użyj clearBotOverlay do ręcznego czyszczenia
  • Włącz RAG i prześlij dokumenty, aby odpowiedzi korzystały z wiedzy
  • Włącz bota cenzurującego do moderacji lub ścisłego blokowania
  • Otwórz /bot.html, /chatbot.html lub /cohost.html w OBS lub przeglądarce według potrzeb

Sterowanie MIDI i skrótami

Integracja MIDI

Steruj Social Stream Ninja za pomocą kontrolerów MIDI, skrótów klawiaturowych lub StreamDeck z wtyczkami MIDI.

Wymagania konfiguracji

  1. Włącz obsługę MIDI w ustawieniach rozszerzenia
  2. Zainstaluj wirtualne urządzenie pętli MIDI (np. loopMIDI)
  3. Skonfiguruj kontroler MIDI lub wtyczkę MIDI StreamDeck
Numer CC Wartość Działanie Uwagi
102 1 Wyślij „1” na czat Szybka reakcja
102 2 Wyślij „LUL” na czat Reakcja emotką
102 3 Opowiedz dowcip Wywołuje odpowiedź bota
102 4 Wyczyść nakładkę Usuwa wyróżnioną wiadomość

Wskazówka: Sterowanie MIDI najlepiej działa z fizycznymi kontrolerami, ale można je też wywoływać przez urządzenia wirtualne.

Obsługa skrótów klawiaturowych

Używaj skrótów klawiaturowych do szybkiego dostępu do typowych funkcji.

Skróty można skonfigurować w ustawieniach menu; działają w całym systemie, gdy przeglądarka ma fokus lub używana jest aplikacja.

Integracja webhooków

Usługi wpłat

Social Stream Ninja może odbierać wpłaty i wydarzenia z usług zewnętrznych przez webhooki; poniżej kilka popularnych:

Stripe

Przyjmuj wpłaty kartą bezpośrednio na konto Stripe.

  • Utwórz link płatności w stripe.com
  • W panelu Stripe przejdź do Developers → Webhooks
  • Dodaj adres usługi: https://io.socialstream.ninja/SESSIONID/stripe
  • Wybierz wydarzenie checkout.session.completed
  • Dodaj &server do URL doku

Ko-Fi

Przyjmuj wpłaty na kawę od wspierających.

  • Zaloguj się na konto Ko-Fi
  • Otwórz Ustawienia webhooków
  • Dodaj https://io.socialstream.ninja/SESSIONID/kofi jako URL webhooka
  • Dodaj &server do URL doku
  • Przetestuj przyciskiem „Send Single Donation Test”

Buy Me A Coffee

Przyjmuj wpłaty przez popularną platformę Buy Me A Coffee.

  • Zaloguj się na konto Buy Me A Coffee
  • Przejdź do ustawień webhooków
  • Dodaj https://io.socialstream.ninja/SESSIONID/bmac jako URL webhooka
  • Dodaj &server do URL doku, aby odbierać wydarzenia
  • Obsługiwane są zarówno wpłaty, jak i wydarzenia członkostwa

Uwaga o bezpieczeństwie: Zachowaj ID sesji w tajemnicy, ponieważ każda osoba, która je zna, może wysyłać fałszywe wpłaty do nakładki. URL webhooka należy traktować jako poufną informację.

API timera

Zdalne sterowanie timer.html

Strona timera ma celowo wąski zakres: jeden timer, opcjonalne sterowanie operatora, stany ostrzeżeń, czas po terminie i kilka stylów wizualnych.

Przydatne działania obejmują starttimer, pausetimer, resettimer, timeradd, timersubtract i settimer.

{
  "action": "settimer",
  "value": {
    "seconds": 300,
    "label": "Interview",
    "mode": "countdown",
    "style": "stage",
    "warnSeconds": 60,
    "dangerSeconds": 15
  }
}

Aby odczytać bieżący stan timera, użyj gettimerstate z tokenem odpowiedzi zwrotnej.

{ "action": "gettimerstate", "get": "timer-state-1" }

Użyj strony z timer.html?session=YOUR_SESSION&server jeśli chcesz sterować nim bezpośrednio przez serwer API.

Polecenia zarządzanych losowań

startgiveaway, closegiveaway, drawgiveaway, resetgiveaway i getgiveawaystate obsługują dedykowaną pulę losowania przez te same kontrolki API/Stream Deck. Losowanie automatycznie zamyka zapisy. Nowa runda zachowuje historię wcześniejszych zwycięzców i odrzuca nieopłacone rezerwacje. Anulowanie ze zwrotem oddaje nierozliczone opłaty za losy. Płatne losy, Number Hunt, Coin Flip Pot i Event Flow używają tej samej usługi prowadzącego. Konfiguracja, prezentacje, wartości poleceń i odzyskiwanie.
