Przepisy Event Flow

Poradnik losowań, płatnych losów, nagród w grach i odzyskiwania danych

Twórz przydatne automatyzacje, zaczynając od małych przepisów.

Do czego służy Event Flow

Uruchom własny przepływ przyciskiem Stream Deck lub wywołaniem API przez HTTP/WebSocket/P2P.

Event Flow to zaawansowany edytor automatyzacji. Użyj go, gdy przełączniki w oknie rozszerzenia nie wystarczają: filtruj czat, uruchamiaj multimedia, przekazuj wiadomości, wywołuj webhooki lub steruj OBS.

Przed użyciem dowolnego przepisu

  1. Użyj jednej platformy testowej i jednej sesji Social Stream.
  2. Otwórz dok i sprawdź, czy docierają wiadomości czatu.
  3. Otwórz actions.html?session=YOUR_SESSION jeśli przepis odtwarza dźwięk lub multimedia albo steruje OBS.
  4. Przed rozpoczęciem transmisji przetestuj przepływ sztuczną wiadomością lub bezpiecznym wyzwalaczem.
  5. Wyeksportuj działający przepływ przed wprowadzeniem dużej zmiany.

Typowe rozwiązania

  • Nic się nie dzieje: najpierw sprawdź, czy zdarzenie źródłowe dociera do doku.
  • Dźwięk lub multimedia nie są odtwarzane: pozostaw actions.html otwarte w tej samej sesji, a następnie sprawdź Przewodnik po hostowaniu multimediów dla Event Flow.
  • Akcja OBS kończy się niepowodzeniem: sprawdź OBS WebSocket v5, port 4455, hasło i uprawnienia.
  • Przepływ uruchamia się zbyt często: dodaj bardziej restrykcyjny filtr platformy, zdarzenia, słowa kluczowego lub użytkownika.
