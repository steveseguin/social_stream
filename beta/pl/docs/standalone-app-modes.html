Do czego służy aplikacja

Aplikacja komputerowa zarządza oknami źródeł Social Stream poza zwykłą przeglądarką. Może ułatwić organizację źródeł i rozwiązać niektóre problemy z ograniczaniem pracy kart w tle. To nie jest Chrome i nie współdzieli automatycznie Twojego logowania ani plików cookie Chrome.

Nazwy trybów

Niektóre źródła mają więcej niż jeden tryb połączenia. Właściwy tryb zależy od platformy, stanu logowania oraz tego, czy potrzebujesz bogatszych zdarzeń, czy prostego przechwytywania strony.

TrybProste wyjaśnienieKiedy używać
StandardAplikacja otwiera zwykłą stronę platformy/źródła i odczytuje wyrenderowaną stronę.Potrzebujesz najprostszego przechwytywania widocznej strony, logowania lub ręcznej weryfikacji.
WebSocket/APIŹródło łączy się przez API platformy, gniazdo lub stronę źródła Social Stream.Platforma go obsługuje i chcesz większej niezawodności w tle lub bogatszych danych zdarzeń.
Odpytywanie/starszy tryb (Polling/Legacy)Ścieżka zgodności, która sprawdza aktualizacje zamiast korzystać z preferowanego połączenia na żywo przez gniazdo.Nowszy łącznik nie działa lub potrzebna jest ścieżka awaryjna właściwa dla platformy.
TikTok AutoAplikacja wybiera najlepszą ścieżkę TikToka i może przełączyć się na awaryjną, jeśli jedna zawiedzie.Nie wiesz, którego trybu TikToka użyć.

Kiedy używać trybu Standard

  • Platforma działa, gdy widzisz stronę transmisji lub wyskakujące okno czatu.
  • Witryna wymaga zalogowania, rozwiązania monitu lub pozostawienia widocznego panelu czatu.
  • Porównujesz działanie aplikacji z rozszerzeniem Chrome.
  • Potrzebujesz najbardziej znajomej ścieżki diagnozowania: otwórz stronę, zobacz czat, przetestuj dok, a potem OBS.

Tryb Standard nadal może przestać działać, jeśli platforma zmieni układ strony, blokuje przeglądarki osadzone lub w aplikacjach, żąda CAPTCHA albo ukrywa czat za logowaniem.

Kiedy używać trybu WebSocket lub API

  • Źródło wyraźnie obsługuje tryb WebSocket/API.
  • Chcesz źródła, które lepiej radzi sobie z ciągłą pracą w tle.
  • Potrzebujesz rodzin zdarzeń, których zwykłe odczytywanie strony może nie udostępniać.
  • Potrafisz skonfigurować tokeny dostawcy, uprawnienia konta, zakresy API lub stronę źródła.

Tryb WebSocket/API nie zawsze jest lepszy. Jeśli zawodzi uwierzytelnianie, tokeny, dostęp do dostawcy lub API platformy, tryb Standard może pozwolić na szybszy test.

TikTok w aplikacji

TikTok w aplikacji komputerowej nie ma tylko jednego trybu. Przed diagnozowaniem zawsze zanotuj aktywny preset.

Ścieżka TikTokaZastosowanieCzęsta przyczyna problemu
AutoPierwsza próba dla większości użytkowników.Aplikacja może przełączyć się na tryb awaryjny, więc sprawdzaj tekst statusu.
StandardPrzechwytywanie widocznej strony TikToka.Logowanie, CAPTCHA, przekierowana strona lub ukryty czat.
Lokalne podpisywanie (Local Signer)Natywne dla aplikacji ścieżki odczytu i obsługi odpowiedzi.Sesja i pliki cookie TikToka w aplikacji muszą być prawidłowe.
Odpytywanie/zgodność (Polling/Compatibility)Opcja awaryjna, gdy zawodzą ścieżki gniazd lub podpisywania.Mniej rozbudowany niż preferowany łącznik.
Proxy lub własne podpisywanieZaawansowane konfiguracje.Dostępność dostawcy, klucz API, identyfikator pokoju lub limity żądań.

Przy zwykłej pierwszej próbie dodaj TikTok, pozostaw preset Auto, aktywuj źródło i obserwuj tekst statusu aplikacji.

Co sprawdzić przed OBS

  1. Sprawdź, czy źródło w aplikacji jest aktywowane.
  2. Sprawdź, czy zalogowano się w oknie źródła, jeśli platforma wymaga logowania.
  3. Sprawdź, czy dok odbiera czat z tym samym identyfikatorem sesji.
  4. Dopiero po uruchomieniu doku dodaj lub odśwież adres nakładki w OBS.
  5. Jeśli Chrome działa, a aplikacja nie, pamiętaj, że sesje aplikacji i sesje Chrome są oddzielne.

Typowe rozwiązania

  • Chrome jest zalogowany, ale aplikacja nie: zaloguj się do platformy w oknie źródła aplikacji lub użyj rozszerzenia do przechwytywania.
  • Źródło wskazuje aktywność, ale czat nie dociera: sprawdź tryb, okno źródła, adres transmisji/nazwę użytkownika oraz sesję doku.
  • Aplikacja używa niewłaściwych plików źródeł: sprawdź, czy aplikacja używa zasobów Social Stream z pakietu, pamięci podręcznej, zdalnych, beta, stabilnych czy lokalnych.
  • TikTok nie działa: zanotuj bieżący preset, tekst statusu, wersję aplikacji i to, czy źródło przełączyło się na tryb awaryjny.
  • OBS jest pusty: najpierw przetestuj dok. Jeśli dok jest pusty, problem nie dotyczy jeszcze OBS.

Powiązany poradnik: Wybór konfiguracji platformy.
