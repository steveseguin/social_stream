Funkcje

Połącz czaty, pokaż widownię na ekranie i nadaj każdej transmisji własny charakter.

Integracja czatu wielu platform

Łącz się z widzami na wszystkich platformach transmisji jednocześnie. Social Stream Ninja zbiera wiadomości czatu z dziesiątek platform w jednym łatwym w obsłudze panelu.

  • Dwukierunkowe wiadomości czatu na żywo z Facebookiem, YouTube, Twitchem, Zoomem i innymi
  • Dla większości platform logowanie i klucze API nie są potrzebne
  • Ikony źródeł wielu kanałów rozróżniające platformy
  • Automatyczne przekazywanie wiadomości między platformami

Nakładka wyróżnionych wiadomości

Wyróżniaj najlepsze wiadomości widowni bezpośrednio w transmisji dzięki atrakcyjnym, konfigurowalnym nakładkom.

  • Wybieraj wiadomości w panelu z możliwością dokowania
  • Automatyczny lub ręczny wybór wiadomości
  • Możliwość stylizacji CSS, aby idealnie pasować do wyglądu transmisji
  • Opcje animacji, w tym zanikanie i przesuwanie
  • Kolejkowanie wiadomości dla uporządkowanego wyróżniania

Polecenia bota i automatyczne odpowiedzi

Twórz automatyczne interakcje z widownią dzięki własnym poleceniom i odpowiedziom.

  • Wbudowane polecenia do typowych interakcji
  • Własna logika poleceń dzięki plikowi wtyczki ze skryptem
  • Automatyczne powitania i odpowiedzi
  • Filtrowanie wiadomości i moderacja

Integracja AI i LLM

Wybierz głosowego współprowadzącego, bota czatu, towarzysza w przeglądarce lub wyspecjalizowane narzędzia przetwarzania AI — bez wiązania reszty transmisji z jednym dostawcą.

  • Głosowy współprowadzący, który słyszy Cię i otrzymuje wybrane wiadomości czatu na żywo
  • Główny i prywatny bot czatu z własnymi instrukcjami i regułami wyzwalania
  • Modele lokalne lub dostawcy chmurowi, w tym OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq i własne zgodne API
  • Moderacja, tłumaczenie, podsumowania, kontekst RAG i tworzenie nakładek
  • Opcjonalne przechwytywanie ChatGPT w przeglądarce bez klucza API

Synteza mowy

Ożyw wiadomości czatu dzięki zamianie tekstu na mowę, aby transmisja była bardziej angażująca i dostępna.

  • Obsługa bezpłatnego systemowego TTS
  • Integracja płatnych usług TTS (Google Cloud, ElevenLabs, Speechify)
  • Obsługa wielu języków
  • Możliwość dostosowania głosu, wysokości i szybkości mowy
  • Obsługa przechwytywania dźwięku OBS

Rozbudowane API

Rozszerz możliwości Social Stream Ninja dzięki rozbudowanym opcjom integracji API.

  • Obsługa webhooków do integracji z usługami zewnętrznymi
  • API serwera do zdalnego sterowania
  • Integracja wpłat (NinjaBacker: bezpłatnie, 0% prowizji platformy, Stripe, Ko-Fi, Buy Me A Coffee)
  • Sterowanie MIDI/Stream Deck
  • Obsługa zdalnych scen OBS

Rozbudowane dostosowywanie

Dostosuj Social Stream Ninja do siebie dzięki rozbudowanym opcjom zmiany działania i wyglądu.

  • Stylizacja CSS dla pełnej kontroli nad wyglądem
  • Gotowe stylizowane szablony i motywy
  • Obsługa własnego JavaScript
  • Parametry URL ułatwiające konfigurację
  • Filtrowanie źródeł i opcje identyfikacji wizualnej

Zaawansowane narzędzia transmisji

Rozwiń swoje transmisje dzięki zestawowi profesjonalnych narzędzi stworzonych do angażowania widzów i interakcji.

  • Interaktywne minigry, w tym Battle Royal
  • System losowań z zarządzaniem kolejką
  • Napisy końcowe i widoki słoika na napiwki
  • Chmura słów i własne polecenia GIF
  • Graficzny system ankiet
  • Baza historii czatu z wyszukiwaniem
  • Prywatny interfejs bota czatu AI
  • Możliwości multimodalnego współprowadzącego AI
