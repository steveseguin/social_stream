Social Stream Ninja 다운로드

가장 적합한 설치 방법을 선택하세요

브라우저 확장 프로그램과 독립형 앱 비교

둘 다 잘 작동합니다. 작업 방식에 맞는 것을 선택하세요.

브라우저 확장 프로그램

  • 브라우저의 기존 로그인 상태를 자동으로 사용합니다.
  • 현재 보고 있는 사이트 안에서 실행되므로 사이트 차단 문제가 적습니다.
  • 웹 스토어 또는 수동 설치로 빠르게 설치할 수 있습니다.
기억할 점: 계속 수집하려면 사이트 탭을 열어 화면에 표시해 두세요. 많은 브라우저가 최소화되거나 백그라운드에 있는 탭의 실행 빈도를 제한합니다.

독립형 앱

  • 백그라운드에서 수집하므로 브라우저 창을 열어 두거나 화면에 표시할 필요가 없습니다.
  • 확장 프로그램이 필요 없고 자동 업데이트를 지원하며, 항상 위에 표시·투명도 등의 추가 도구를 제공합니다.
  • 직접 WebSocket 연결을 위한 추가 옵션을 제공합니다.
기억할 점: 일부 사이트는 앱 접근을 제한하여 우회 설정이 필요할 수 있습니다. 브라우저 세션과 별도로 앱 안에서 로그인해야 합니다.

Chrome 웹 스토어

Chrome, Edge, Brave 등 Chromium 기반 브라우저에 설치하는 가장 쉬운 방법입니다.

설치 불필요

Social Stream Ninja Lite

확장 프로그램이나 데스크톱 앱을 설치하지 않고 YouTube, Twitch, Kick 채팅에 연결하세요. 브라우저 탭이나 OBS 사용자 지정 도크에서 Lite를 실행하고, 오버레이 링크를 OBS에서 사용하면 됩니다.

  • OBS 도크에서 수집하면 별도의 브라우저 탭이 필요하지 않습니다.
  • 전체 앱에 비해 지원 소스, 자동화 도구, 맞춤 설정 기능이 적습니다.
  • 실험적인 단일 브라우저 소스 모드는 수집과 표시를 함께 처리합니다. OBS 안에서의 제공자 로그인 방식은 다를 수 있습니다.

일반 오버레이 링크를 사용하려면 탭이나 도크에서 Lite를 계속 실행해야 합니다. OBS만 사용하는 설정은 다음을 참고하세요: Lite OBS 가이드.

수동 설치 가이드

1

다운로드 및 압축 해제

ZIP 파일을 다운로드하고 컴퓨터의 폴더에 압축을 풉니다.

ZIP 다운로드
2

브라우저 확장 프로그램 페이지 열기

브라우저의 확장 프로그램 페이지로 이동합니다:

chrome://extensions/ (Chrome용)
edge://extensions/ (Edge용)
brave://extensions/ (Brave용)
3

개발자 모드 활성화

확장 프로그램 페이지 오른쪽 위에서 ‘개발자 모드’를 켭니다.

4

압축을 푼 확장 프로그램 로드

‘압축해제된 확장 프로그램을 로드합니다(Load unpacked)’를 클릭하고 압축을 푼 폴더를 선택합니다.

5

Social Stream Ninja 사용 시작

준비가 끝났습니다! 지원되는 채팅 플랫폼을 열고 Social Stream Ninja 확장 프로그램 아이콘을 눌러 활성화하세요.

Firefox 설치

1

XPI 파일 다운로드

서명된 Firefox 확장 프로그램 파일을 다운로드합니다.

XPI 다운로드
2

Firefox에 설치

Firefox를 열고 확장 프로그램을 설치합니다:

  • 이동할 위치: about:addons (Firefox에서 이 페이지를 여세요)
  • 톱니바퀴 아이콘(설정)을 클릭합니다
  • ‘파일에서 부가 기능 설치(Install Add-on From File...)’를 선택합니다
  • 다운로드한 XPI 파일을 선택합니다
3

Firefox 제한 사항

Firefox 버전에는 Chrome 버전에 비해 다음과 같은 제한이 있습니다:

  • TTS 음성 모델은 포함되지 않습니다. 시스템 음성만 사용합니다
  • 탭 캡처와 디버거 기능은 사용할 수 없습니다
  • 자동 응답 기능은 지원하지 않습니다

Linux AppImage 설치

Linux 사용자 도움말

일부 배포판에서는 AppImage를 실행할 때 샌드박스 오류가 발생할 수 있습니다. 샌드박스 문제 해결 가이드 에서 SUID 샌드박스 설정 오류가 발생할 때의 방법을 확인하세요.

1

AppImage 다운로드

AppImage 파일을 컴퓨터에 다운로드합니다.

2

실행 권한 부여

파일을 마우스 오른쪽 버튼으로 클릭한 뒤 속성, 권한을 선택하고 ‘파일을 프로그램으로 실행 허용’을 선택합니다. 또는 터미널에서 다음을 실행합니다: chmod +x SocialStreamNinja.AppImage

3

앱 실행

AppImage를 두 번 클릭하여 Social Stream Ninja를 실행하거나 터미널에서 다음을 실행합니다: ./SocialStreamNinja.AppImage

자주 묻는 질문

Chrome 웹 스토어 버전은 설치가 쉽지만 Google의 심사 과정 때문에 몇 주에 한 번씩만 업데이트됩니다. 수동 설치는 개발자 모드가 필요하지만, 새 업데이트와 기능이 출시되는 즉시 사용할 수 있습니다.
파일을 교체하고 다시 로드하는 방식으로 확장 프로그램을 업데이트하면 설정이 유지됩니다. 하지만 확장 프로그램을 완전히 제거하면 설정이 사라집니다. 완전히 제거하기 전에 설정을 내보내는 것이 좋습니다.
업데이트하려면 최신 버전을 다운로드해 기존 파일을 새 파일로 교체한 다음, 확장 프로그램을 다시 로드하거나 브라우저를 재시작합니다. 먼저 확장 프로그램을 제거할 필요는 없습니다. 업데이트 전 설정을 백업하는 것이 좋습니다.
Manifest v2 경고는 Google이 해당 버전의 지원을 중단했기 때문에 나타납니다. Manifest v3로 업데이트하는 것을 권장합니다. 먼저 설정을 내보낸 다음 v3 확장 프로그램을 설치하세요. 현재 두 버전을 모두 사용할 수 있지만, v2는 지원이 제한되며 결국 작동하지 않게 됩니다.
독립형 앱은 브라우저 확장 프로그램이 필요 없고 자동 업데이트를 지원합니다. 창 고정(항상 위에 표시), 배경 투명도 같은 추가 기능도 제공합니다. 최소화할 때 브라우저의 실행 빈도 제한에 영향을 받을 가능성도 적습니다.
