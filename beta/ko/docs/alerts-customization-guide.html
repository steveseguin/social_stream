맞춤형 알림 및 이벤트 피드 디자인

기부, 구독, 선물, 팔로우 및 기타 지원되는 작업에 대해 Multi-Alerts 및 이벤트 행의 스타일을 변경합니다.

모든 오버레이 디자인 가이드파일을 선택하세요다운로드세션과 OBS디자인AI 프롬프트테스트

OBS 또는 Streamlabs Desktop에서 최근 경고를 계속 표시하려면 그림이 포함된 이벤트 오버레이 가이드.

올바른 시작 페이지를 선택하세요

사용: multi-alerts.html 시간 제한 알림 프리젠테이션 및 시청자 위치에 대한 events.html 또는 themes/events/index.html 입니다. 렌더링 및 대기열 동작이 다릅니다. 이미 사용하고 있는 도구에 대해 생성된 URL로 시작하세요.

활동 피드 스타일 선택

열기 활동 피드/이벤트 → 활성화 및 사용자 정의 → 피드 스타일, 레이아웃을 선택한 다음 업데이트된 링크를 브라우저 또는 OBS 브라우저 소스에 복사하세요. 열기 피드 모양 맞춤설정 색상과 간격을 조정합니다. 스타일의 기본값을 사용하려면 필드를 비워 두세요.

스타일URL 옵션외관

기존 옵션에 이러한 옵션을 추가하세요. events.html?session=YOUR_SESSION_ID 와 연결하다 &. 세션, 비밀번호, 연결 옵션을 유지하세요.

  • accent, pagebg, cardbg, textcolor, 그리고 mutedcolor: CSS 색상. 16진수 색상을 인코딩합니다. # 형식: %23 URL에서, 또는 생략 #.
  • fontsize=14: 텍스트 크기, 10~40픽셀. padding=8, gap=4, 그리고 radius=6: 행 패딩, 이벤트 사이의 공간 및 모서리 반경(각각 0~40픽셀)
  • noheader 페이지 제목을 숨깁니다. noanimation 진입 애니메이션을 비활성화합니다.
  • 스타일을 결합 lightmode, transparent, font, googlefont, scale, notime, 그리고 hidemeta. 투명 모드는 페이지 배경을 재정의합니다. 카드 배경은 별도로 조정 가능합니다.

예를 들어, 추가 &style=twitch&accent=%23e5b94f&padding=8&fontsize=14 금색 액센트가 있는 더 밀집된 활동 목록입니다.

활동 피드에 표시되는 내용을 선택하세요.

다음 위치에서: 활동 피드/이벤트 → 활성화 및 사용자 정의를 선택하고 다음을 엽니다: 표시할 이벤트 선택 또는 행 내용 및 동작. 기본 보기를 유지하려면 컨트롤을 끄고 필드를 비워 두세요. 업데이트된 링크를 변경한 후 복사하세요. 이러한 제어는 이 피드에만 영향을 미칩니다. 일반 채팅은 제외됩니다.

각 행은 이벤트 이름을 기준으로 하나의 카테고리에 속합니다. 이름이 지정된 멤버십, 선물 및 구매에는 금액이 포함되어 있어도 해당 카테고리가 유지됩니다. 팁 hasDonation Twitch DOM 비트를 포함하여 인식된 이벤트 이름이 유료 메시지 카테고리에 속하지 않습니다. 일반 채팅의 멤버십 뱃지는 멤버십 이벤트로 전환되지 않습니다.

더 세밀하게 제어하려면 다음을 사용하세요. filterevents=supersticker,watch_streak 정확한 이벤트 이름을 숨기려면 일치에서는 대소문자를 무시하고 피드의 기존 이벤트 별칭을 사용합니다. 메시지 텍스트는 검색하지 않습니다. 카테고리 및 정확한 이름 제외는 기존 소스, 기부 전용, 선물 구독 전용 및 최소값 필터와 결합됩니다. 여러 필터를 활성화하면 일치하는 이벤트가 남지 않을 수 있습니다. 참조 이벤트 참고 문서 소스별 페이로드의 경우.

  • hidemessage, hidecontentimg, hideplatformicons, hideeventlabels 그리고 hideamounts 해당 행 요소를 숨깁니다. 이벤트를 삭제하거나 클릭 투 기능이 보내는 내용을 변경하지 않습니다. 인라인 이모티콘은 메시지 텍스트의 일부입니다. 메시지 텍스트, 메타데이터 또는 Hype Train 세부 정보에 기록된 금액이나 이름은 이러한 제어로 수정되지 않습니다.
  • nofeature 이 피드에서 클릭 기능을 비활성화합니다. 메타데이터 세부정보는 계속 열 수 있습니다.
  • hidecategorytag 를 사용하면 후원 또는 이벤트 같은 일반 카테고리 태그만 숨기고 구체적인 이벤트 레이블은 유지합니다. 팝업에서 다음을 켜세요: 카테고리 태그 숨기기 — 선택 위치: 행 내용 및 동작.
  • eventduration=60 60초 후에 이 피드에서 행을 제거합니다. 공백 또는 0 기존 보존 동작을 유지합니다. 양수 값의 범위는 1~86,400초입니다. Hype Train 업데이트가 타이머를 다시 시작합니다. 종료된 열차는 최대 30초 후에도 사라집니다. 제거해도 이미 추천 오버레이로 전송된 이벤트는 지워지지 않습니다.
  • hideempty 이벤트가 표시되지 않으면 대기 메시지를 숨깁니다.

파일 구조를 다운로드하여 보관하세요.

  1. 소스 ZIP 다운로드 그리고 그것을 추출한다. 이 가이드는 베타 소스를 사용합니다. 한 번 다운로드한 파일을 함께 보관하세요.
  2. 복사 multi-alerts.html 대상: my-alerts.html 원본 옆에. 다른 페이지나 테마를 선택하는 경우 해당 파일의 원본 폴더에 복사본을 보관하세요.
  3. 복사한 HTML과 참조된 CSS/JS를 편집기나 AI 도구에서 엽니다. 제공된 아트웍/글꼴을 동일한 프로젝트에 추가하고 상대 경로를 사용하십시오. CSS 재정의로 시작하세요. 생성된 마크업을 변경할 때 렌더러를 포함합니다.

다음 파일은 디자인과 동작을 찾는 데 도움이 됩니다. 이는 전체 종속성 번들이 아닌 읽기 목록입니다. 이미지, 글꼴, 스크립트 및 모든 데이터 파일을 포함하여 추출된 폴더를 그대로 유지하세요.

복사본을 연결하고 OBS에서 엽니다.

SSN를 시작하고 원래 생성된 오버레이 URL이 먼저 작동하도록 만듭니다. 는 session= 값은 해당 SSN 세션에 연결됩니다. 이는 귀하의 채널 이름이나 이 파일의 이름이 아닙니다. SSN, 관련 기능 및 해당 데이터 소스를 계속 실행하세요.

  1. 편집한 HTML 파일을 Chrome이나 Edge로 드래그하세요. 주소 표시줄에서 주소를 복사하세요. 그것은로 시작한다 file:///.
  2. 다음의 모든 항목을 복사합니다. ? 작업 중인 SSN 오버레이 링크에서 계속해서 해당 파일 주소 끝에 추가하세요. 세션, 비밀번호 등을 포함한 모든 설정을 유지합니다. # 결말.
  3. 브라우저에서 결과를 연 다음 OBS 브라우저 소스를 설정합니다. URL 같은 주소로 로컬 파일 선택 해제되었습니다. 원본 치수를 의도한 디자인과 일치시킵니다.

위의 시작 파일의 경우 로컬 주소는 다음과 같습니다. 실제 링크에는 추가 필수 옵션이 포함될 수 있습니다.

file:///C:/SSN/social_stream-beta/my-alerts.html?session=YOUR_SESSION

컴퓨터에 있는 실제 파일 주소를 사용하세요. OBS는 소스와 함께 저장합니다. 다운로드한 폴더를 같은 곳에 보관하세요. 디자인 변경 사항을 저장한 후 브라우저 소스를 새로 고칩니다. 는 공유 설정 가이드 에는 Mac 예제와 로컬 파일 확인란에 대한 선택적 실행 프로그램이 포함되어 있습니다.

디자인을 바꾸는 곳

경고 프레임, 타이포그래피, 아이콘 배치, 진행/타이밍 장식 및 모션을 변경합니다. Multi-Alerts에서는 레이아웃의 대부분이 다음과 같이 생성됩니다. multi-alerts.js; AI에게 구조 변경을 요청할 때 포함하세요. 격리된 포크의 경우 해당 스크립트도 복사하고 복사한 HTML의 스크립트 참조만 업데이트하세요.

이벤트 분류 및 필터를 유지합니다. 유료 채팅 행은 다음을 사용할 수 있습니다. hasDonation 에서 다음을 제외한 경우 event: "donation"; 플랫폼에는 특정 이벤트 이름도 있습니다. 사용 이벤트 참고 문서 그리고 호환성 안내 샘플을 선택합니다. 원래 표시 금액과 숫자로 된 USD 재정의를 별도로 유지하세요.

이 오버레이 유형을 테스트해 보세요.

먼저 미리보기 또는 테스트 설정을 사용하세요. 는 테스트 메시지 가이드 SSN를 통해 가상 페이로드를 보내는 방법을 설명합니다. 프로덕션 세션에 제출된 테스트는 기존 자동화를 트리거할 수 있습니다.

  1. 테스트 메시지 도구를 사용하여 소스가 지원하는 특정 팔로우, 구독, 선물, 레이드 또는 유료 메시지를 보내십시오. 어떤 필드가 실제로 존재하는지 확인하십시오.
