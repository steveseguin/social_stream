VDO.Ninja 네이티브 앱 + Social Stream Ninja

VDO.Ninja 네이티브 모바일 앱에서 Social Stream Ninja 채팅을 수신하세요.

이 설정의 역할

Social Stream Ninja는 컴퓨터에서 실행되어 Twitch, YouTube, Kick 등의 소스에서 채팅을 캡처한 뒤 휴대전화의 VDO.Ninja 네이티브 앱으로 전달합니다.

휴대전화는 수신기입니다. Twitch나 채팅 플랫폼에 직접 연결하지 않습니다.

1. Social Stream 소스 시작

  1. 채팅을 수집할 컴퓨터에서 Social Stream Ninja를 여세요.
  2. Social Stream Ninja 세션 ID를 설정하세요.
  3. Twitch, YouTube, Kick, TikTok 등 필요한 플랫폼 소스를 여세요.
  4. 휴대전화를 확인하기 전에 Social Stream 소스 창이나 도크에 메시지가 표시되는지 확인하세요.

Twitch WebSocket 소스 모드를 사용해도 됩니다. 이 모드는 SSN이 Twitch 채팅을 캡처하는 방법만 제어하며 휴대전화의 Peer-to-Peer 또는 Server 모드와는 별개입니다.

2. 휴대전화에서 송출 설정 열기

  1. VDO.Ninja 네이티브 앱을 여세요.
  2. 사용할 카메라, 화면 또는 마이크 모드를 선택하세요.
  3. Publishing Settings 화면에서 아래로 스크롤하여 Social Stream Ninja Integration으로 이동하세요.

3. 같은 세션 ID 사용

Social Stream을 켜고 컴퓨터의 SSN에서 사용하는 것과 정확히 같은 세션 ID를 붙여 넣으세요.

4. 연결 모드 하나 선택

휴대전화 모드SSN 설정사용할 때
Peer-to-Peer 일반 SSN P2P 출력을 사용하세요. 채팅이 API 서버로만 전달되도록 설정하지 마세요. 먼저 시도하기에 가장 좋습니다. 로컬 서버 없이 일반 인터넷 연결에서 작동합니다.
서버 활성화 API 서버로 채팅 메시지 전송 (Send chat messages to API server) 을 SSN의 Global > Mechanics에서 켜세요. P2P가 차단되거나 불안정할 때 사용하세요.

모드를 혼용하지 마세요. 휴대전화가 Peer-to-Peer인데 SSN이 Server 모드로만 전송하면 휴대전화에 채팅이 수신되지 않습니다. 휴대전화가 Server 모드인데 SSN이 API 서버로 채팅을 보내지 않아도 채팅이 수신되지 않습니다.

5. 연결 및 테스트

  1. 탭할 항목: 연결 (Connect) 을 VDO.Ninja 네이티브 앱에서 탭하세요.
  2. 실제 채팅 메시지를 보내거나 SSN 테스트 메시지를 사용하세요.
  3. 휴대전화를 확인하세요. 표시 내용이 Social Stream 연결 안 됨 (Social Stream not connected)이라고 표시된다면 채팅 소스는 작동 중일 수 있지만 SSN에서 휴대전화로의 전송이 연결되지 않은 상태입니다.

일반적인 실패 사례

증상실제 원인해결 방법
SSN에는 채팅이 표시되지만 휴대전화에는 Social Stream not connected가 표시됨. 플랫폼 소스는 작동하지만 SSN에서 휴대전화로 가는 출력 경로가 연결되지 않았습니다. 세션 ID, 연결 모드, SSN 출력 설정을 확인하세요.
같은 세션 ID로 한 PC에서는 작동하지만 다른 PC에서는 작동하지 않음. Peer-to-Peer 모드에서 SSN은 세션 ID를 VDO.Ninja 스트림 ID로 사용하여 송출합니다. 같은 ID는 한 번에 하나의 SSN 인스턴스만 송출할 수 있습니다. 첫 번째 PC에서 Social Stream을 닫거나 끈 뒤 두 번째 PC에서 SSN을 다시 시작하세요. 또는 다른 세션 ID를 사용하세요.
Server 모드에서 채팅이 전혀 수신되지 않음. 휴대전화는 SSN API 서버 채널에서 수신을 기다리지만 SSN이 해당 채널로 채팅을 게시하지 않습니다. 활성화 API 서버로 채팅 메시지 전송 (Send chat messages to API server) 을 SSN의 Global > Mechanics에서 켜세요.
소스 창에는 채팅이 표시되지만 아무것도 전달되지 않음. 소스가 답변 전용 또는 캡처 안 함 모드일 수 있습니다. 비활성화할 항목: 봇 답장 전용(캡처 없음) (Bot reply-only (no capture)) 을 해당 소스에서 끄세요.
원격 휴대전화에서 로컬 서버 모드를 사용할 수 없음. 로컬 서버 모드는 컴퓨터 또는 LAN 안에서만 사용되며 대개 방화벽 밖에서는 접근할 수 없습니다. Peer-to-Peer를 사용하거나 SSN의 API 서버 채팅 출력을 켜고 공개 Server 모드를 사용하세요.

BTTV, 7TV, FFZ 이모티콘

채팅을 전달하기 전에 SSN에서 BTTV, 7TV 또는 FFZ 이모티콘 옵션을 켜세요. SSN이 휴대전화에 도착하기 전에 메시지에 이모티콘을 적용합니다.

앱 버전에서 채팅 안의 이미지를 렌더링하지 않는다면 네이티브 앱의 채팅 화면에 이미지 이모티콘 대신 대체 텍스트가 표시될 수 있습니다.
