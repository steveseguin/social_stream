Discord StreamKit 및 TikFinity 소스

외부 오버레이 링크를 Social Stream Ninja의 읽기 전용 채팅 소스로 사용하세요.

두 링크 이해하기

이 설정에는 서로 다른 두 링크를 사용합니다:

  • 입력 링크: Social Stream Ninja에 붙여넣는 Discord StreamKit 또는 TikFinity URL입니다. Social Stream이 이 링크에서 메시지를 읽습니다.
  • 출력 링크: Social Stream 도크 또는 오버레이 URL입니다. 도크를 열어 메시지를 테스트한 다음 오버레이 URL을 OBS에 추가하세요.

원래 Discord 또는 TikFinity 디자인만 화면에 표시하려면 링크를 OBS 브라우저 소스에 직접 붙여넣으세요. 통합 채팅, 음성 읽기, 필터링, 메시지 강조 표시 또는 다른 Social Stream 기능을 원하면 Social Stream 소스로 사용하세요.

어떤 옵션을 사용해야 하나요?

Discord StreamKit

Discord 공식 Chat 위젯을 통해 Discord 서버 채널 하나의 새 텍스트 메시지를 읽습니다.

  • Discord 데스크톱 앱이 계속 열려 있어야 합니다.
  • 서버에 봇을 설치할 필요가 없습니다.
  • 읽기 전용: Social Stream은 StreamKit을 통해 Discord에 답장할 수 없습니다.

TikFinity OBS Dock

TikFinity를 TikTok LIVE 채팅 및 이벤트의 대체 수신기로 사용합니다.

  • TikFinity가 계속 열려 있고 연결되어 있어야 합니다.
  • 직접 TikTok 모드에서 메시지가 누락되거나 끊길 때 유용합니다.
  • 읽기 전용: 답장이 필요하면 직접 TikTok 모드를 사용하세요.
중복 방지: 같은 채팅을 직접 소스와 이 대체 소스로 동시에 캡처하지 마세요.
Discord

Discord StreamKit 설정

  1. 다음을 여세요: Discord StreamKit Overlay.
  2. 선택: OBS용 설치(Install for OBS) 그리고 Discord가 요청하면 StreamKit을 승인하세요.
  3. 선택: 채팅 위젯을 선택한 다음 캡처할 서버와 텍스트 채널을 선택하세요.
  4. Chat 위젯의 설치 링크를 복사하세요. 시작 부분은 다음과 같아야 합니다: https://streamkit.discord.com/overlay/chat/.
  5. Social Stream 데스크톱 앱에서 다음을 여세요: Sources and Settings -> Discord.
  6. 선택: Discord StreamKit URL 사용, 링크를 붙여넣고 소스를 추가하세요.
  7. 캡처하는 동안 Discord 데스크톱 앱을 계속 실행하세요.

Social Stream 브라우저 확장 프로그램에서 다음을 활성화하세요: Discord 를 선택적 채팅 서비스에서 활성화하고 생성된 StreamKit Chat 링크를 브라우저 탭에서 여세요.

  • Social Stream은 페이지를 처음 열었을 때 이미 보이던 메시지를 건너뜁니다. 소스가 준비된 뒤 새 테스트 메시지를 보내세요.
  • 새 텍스트, 이름, 기본 서식, 이모지, 표시된 이름 색상을 캡처합니다.
  • Discord 통화나 이전 메시지 기록은 캡처하지 않으며 모든 아바타, 첨부 파일, 답장, 역할 정보를 항상 제공하지는 않습니다.
TikTok 대체 방식

TikFinity OBS Dock 설정

  1. TikFinity를 열고 TikTok LIVE 계정에 연결하세요.
  2. 이동할 위치: Overlays -> OBS Docks.
  3. 톱니바퀴 버튼으로 채팅을 포함해 도크가 표시할 이벤트를 선택하세요.
  4. Dock 1 또는 Dock 2의 URL을 복사하세요.
  5. Social Stream 데스크톱 앱에서 다음을 선택하세요: 다른 채팅 사이트.
  6. TikFinity 도크 URL을 붙여넣고 새 소스를 활성화하세요.
  7. 방송 중 TikFinity를 열고 연결된 상태로 유지하세요.
  • 설정에서는 소스가 TikFinity로 표시되지만 메시지는 일반적인 다음을 사용합니다: tiktok 소스 유형을 Social Stream 안에서 사용합니다.
  • 이는 대체 수신 방식이며 TikTok 답장을 보내는 방법이 아닙니다.
  • 브라우저 확장 프로그램 사용자는 다음이 포함된 지원 TikFinity Activity Feed 위젯 URL을 열 수도 있습니다: /widget/vite/src/activity-feed/.

다음을 따르세요: 스크린샷이 있는 TikFinity 설정 가이드 에서 사용자 이름, OBS Dock 설정, SSApp 단계를 확인하세요. 직접 TikTok 모드와 답장 옵션은 다음을 참조하세요: TikTok 가이드.

전체 작업 흐름 검증

  1. 세션 ID로 Social Stream 도크를 여세요.
  2. 선택한 Discord 채널 또는 TikTok LIVE 채팅에 새 테스트 메시지 하나를 보내세요.
  3. 올바른 이름과 텍스트로 Social Stream 도크에 한 번 나타나는지 확인하세요.
  4. 같은 세션 ID를 사용하는 원하는 Social Stream 오버레이 URL을 OBS 브라우저 소스에 추가하세요.
  5. 다른 메시지를 보내 도크와 OBS 양쪽에 한 번씩 표시되는지 확인하세요.
  6. 소스를 몇 분 동안 실행해 두고 이후 메시지도 계속 도착하는지 확인하세요.

참고: OBS 빠른 시작 에서 도크 및 브라우저 소스 단계를 확인하세요.

메시지가 나타나지 않을 때

  • 새 메시지로 테스트하세요. 기존 메시지는 의도적으로 가져오지 않습니다.
  • Discord 또는 TikFinity가 계속 열려 있고 로그인 및 연결된 상태인지 확인하세요.
  • 복사한 링크가 설정 페이지가 아니라 Chat 위젯 또는 OBS Dock 링크인지 확인하세요.
  • 선택한 서버, 채널, 도크 또는 이벤트를 변경한 뒤에는 Social Stream 소스를 다시 로드하거나 만드세요.
  • OBS 문제를 해결하기 전에 Social Stream 도크를 확인하세요. 도크가 비어 있다면 아직 OBS의 문제는 아닙니다.
  • 복사한 소스 링크는 비공개 설정 정보로 취급하세요. 게시하거나 화면 공유 중 노출하지 마세요.
