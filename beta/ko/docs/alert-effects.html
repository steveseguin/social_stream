애니메이션 및 소리 알림

스트림을 설정 중이신가요? 팔로우 알림, 채팅 명령 및 알림 설정 사용자 정의 사운드, 명령 응답 및 자동 알림용입니다.

첫 알림 설정하기

  1. Multi-Alerts → Event animations & sound effects를 여세요.
  2. 알림을 활성화한 다음 이벤트를 선택하세요. $100 후원 사전 설정은 두 금액 제한을 채우며, 선택된 소리가 없으면 합성된 Thank you 소리를 제공합니다.
  3. 선택적으로 GIF, 이미지, 동영상의 직접 URL을 추가하거나 미디어를 업로드하세요. GIPHY 페이지 링크는 미디어 직접 URL이 아닙니다. GIF 이미지에는 오디오가 없으므로 소리를 별도로 선택하세요.
  4. 소리를 선택하고 듣기(Listen)로 로컬에서 들어보세요. 사용자 지정 URL과 업로드 옵션은 선택기 아래에 있습니다.
  5. 알림 테스트(Test alert)를 사용한 다음 Multi-Alerts 링크를 OBS 브라우저 소스로 추가하세요.

금액 제한 및 우선순위

후원과 비트에는 통화 도우미가 추정한 USD 금액을 사용합니다. 정확히 $100에 맞추려면 두 제한을 모두 100으로 설정하세요. $100 이상이면 최댓값을 비워 두세요. 두 값을 비우면 모든 금액을 허용합니다. 다른 이벤트 유형에는 금액 제한을 두지 마세요.

처음 일치하는 알림이 적용됩니다. 구체적인 규칙을 일반적인 규칙보다 먼저 배치하세요. 플랫폼 및 카테고리 필터도 적용됩니다.

미리보기 및 소리

알림 테스트(Test alert)는 로컬 미리보기를 열고 포커스를 맞춥니다. 실시간 채널에 이벤트를 보내지 않습니다. 미리보기에는 현재 오버레이 설정, 필터, 미디어, 타이밍이 적용됩니다. 소리 크기는 Sound & Timing에서 설정합니다.

소리 지우기(Clear sound)는 사용자 지정 소리만 제거하며 기본 알림 오디오는 여전히 적용됩니다. 오버레이 오디오를 음소거하려면 알림 소리 재생(Play alert sound)을 끄세요. 알림 활성화(Enable alert)를 끄면 설정을 유지한 채 규칙을 일시 중지합니다. 알림 초기화(Reset alert)는 해당 규칙만 지웁니다.

음성 문구에는 합성 녹음이라는 라벨이 붙습니다. 이름이나 변하는 텍스트에는 Event Flow 편집기의 Speak Text 동작을 사용하세요.

Event Flow 및 OBS 효과

연속 동작과 OBS 효과에는 Event Flow 템플릿을 사용하세요. 해당 미디어와 소리 동작은 Flow Actions 오버레이에서 재생됩니다. 같은 소리가 두 번 들리지 않도록 이벤트마다 소리를 담당하는 오버레이 하나를 사용하세요. OBS 템플릿은 사용 전에 소스와 필터를 선택해야 합니다.
