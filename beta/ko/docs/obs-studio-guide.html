가이드 / OBS 스튜디오

첫 번째 OBS 설정.

카메라, 화면, 사운드를 함께 가져오세요. 테스트 녹음을 한 후 실시간으로 진행하세요.

여기서 시작하세요장면인코더플랫폼 설정오디오오버레이
01

OBS가 첫 번째 설정을 수행하도록 합니다.

  1. 설치: OBS Studio 그리고 열어보세요.
  2. 선택: 도구 → 자동 구성 마법사.
  3. 스트리밍 또는 녹화를 선택하고 안내에 따라 설정을 적용합니다.

컴퓨터에서 요청할 때 카메라, 마이크 및 화면 캡처 액세스를 허용합니다.

선택하면 스크린샷이 전체 크기로 열립니다. 라벨은 OBS 버전에 따라 약간 다를 수 있습니다.

장면 전환 및 macOS

macOS에서는 다음을 사용합니다. macOS 화면 캡처 창이나 디스플레이의 경우.

장면 변경은 일반적으로 바로 출력으로 이동합니다. 스튜디오 모드 장면을 준비한 다음 전환. 공유 소스 및 오디오 변경 사항은 여전히 ​​라이브 출력에 영향을 미칠 수 있습니다.

선택: 기존 추가 다른 장면에서 소스를 재사용합니다.

하드웨어 옵션이 없나요? 사용 x264 → 매우 빠름 720p30에서 시작하세요.

인코더가 없거나 컴퓨터에 과부하가 걸리나요?

하드웨어 지원을 확인하고 그래픽 드라이버를 업데이트하세요. OBS는 장면을 그리려면 여전히 GPU 용량이 필요합니다. 게임 FPS를 제한하거나 뒤처지면 출력 FPS를 낮추세요.

Mac의 하드웨어 인코더가 CBR을 제공할 수 없는 경우 x264를 사용하세요. 인코더 호환성.

05

수동 출력 설정의 경우 다음을 선택하십시오. 출력 → 고급 → 스트리밍: CBR, 2초 키프레임, 그리고 AAC 스테레오. 아래에서 플랫폼을 열어보세요.

06

목소리를 듣기 쉽게 만들어라

  1. 다음에서 마이크를 선택하세요. 설정 → 오디오.
  2. 평소대로 말하세요. 주변의 최고점을 목표로 하세요. −12~−6 dBFS; 0을 피하세요.
  3. 음성이 명확해질 때까지 게임, 음악 및 경고 슬라이더를 낮추십시오.

각 사운드를 한 번씩 캡처합니다. 전체 출력 장치에 데스크탑 오디오를 사용하거나 별도의 응용 프로그램 캡처를 사용하십시오. 둘 다 캡처하면 소리가 두 배로 커질 수 있습니다.

앱 오디오, macOS 및 마이크 필터

Windows: 사용 애플리케이션 오디오 캡처. macOS 13+에서는 OBS를 사용하세요. macOS 오디오/화면 캡처.

마이크 → 필터 (Filters): 가벼운 소음 억제를 시도한 다음 압축기와 리미터를 사용해 보십시오. 하나씩 추가해서 들어보세요.

에코를 피하세요: 데스크탑 오디오를 통해 모니터링 장치를 다시 캡처하지 마십시오. 시청자에게 "모니터 전용" 오디오를 보낼 수도 있습니다. 플랫폼의 라이브 플레이어를 음소거 상태로 유지하세요.

08

채팅 또는 알림 오버레이 추가

  1. Social Stream Ninja에서 오버레이 URL을 복사합니다.
  2. 선택: 소스 → + → 브라우저 붙여넣기 하세요. 세션 및 비밀번호 옵션을 유지하십시오.
  3. 오버레이 크기를 설정합니다. 사용하다 1920 × 1080 풀프레임 가로 오버레이의 경우. 실행 중인 이벤트 목록의 경우
  4. TTS 또는 알림의 경우 활성화 OBS를 통해 오디오 제어(Control audio via OBS).

게임이나 카메라 위에 놓습니다. 테스트 메시지를 보냅니다. 추천 메시지 오버레이를 사용하는 경우 SSN 도크에서 하나를 선택하세요.

빈 오버레이 또는 반복되는 오디오?

세션이 채팅 소스와 일치하는지 확인하세요. 브라우저 소스를 새로 고칩니다. TTS를 재생하는 사본 하나만 보관하세요.

지속적인 채팅의 경우 처음에는 자동 종료 및 장면 활성화 새로 고침을 꺼두세요. SSN 오버레이 설정 · TTS 설정.

09

1분을 기록하세요. 그런 다음 라이브로 이동하세요.

  1. 녹음 폴더를 선택하세요 설정 → 출력.
  2. 프레스 녹화 시작 (Start Recording). 말하고, 소리를 재생하고, 장면을 전환하세요.
  3. 잠시 멈추고 파일을 감상하세요. 볼륨, 프레이밍, 립싱크를 확인하세요.
  4. 플랫폼의 제목과 가시성을 설정한 다음 방송 시작 (Start Streaming). 미리보기와 스트림 상태를 확인하세요. 일부 플랫폼에는 다음 사항도 필요합니다. 라이브 시작.

스트리밍 시작을 통해 공개적으로 라이브를 즐길 수 있습니다. 가능한 경우 비공개 테스트를 사용하세요. 완료되면 스트리밍을 중지하고 플랫폼 이벤트가 종료되었는지 확인하세요.

녹음 형식 및 별도의 오디오 트랙

MKV는 녹화 중단을 허용합니다. 사용 파일 → 녹음 재다중화 . 현재 OBS는 탄력적인 하이브리드 MP4/MOV도 제공합니다.

트랙을 별도로 편집하려면 트랙 1에 전체 믹스를 유지한 다음 고급 오디오 속성의 추가 트랙에 마이크/게임을 할당하고 녹음에서 활성화하세요.
