Shopify 상품과 구매를 표시하세요.

QR 코드와 함께 상품을 표시하고 구매 시 알림을 받으세요.

상품 표시하기 구매 알림 OBS에 넣기 안전하게 테스트 문제 해결

5단계로 Shopify 상품 표시하기

  1. Social Stream Ninja에서 다음을 여세요: 수익화 → Shopify 구매 → 설정 (Monetization → Shopify purchases → Setup).
  2. 상점 주소를 입력하세요. 예: your-store.myshopify.com. 비밀키는 필요하지 않습니다.
  3. 열기 상품 가져오기에서 상품의 공개 링크를 붙여 넣고 다음을 클릭하세요: 상품 세부 정보 불러오기.
  4. 이름, 사진, 가격, 링크를 확인하고 다음을 클릭하세요: 상품 또는 링크 추가.
  5. 켜기: 상품 및 후원 링크 를 선택하고 다음을 클릭하세요: 설정 저장.
상품이 불러와지지 않나요? 추가: 공개 Storefront 토큰 (Shopify Headless 채널에서 만들고 상품을 해당 채널과 Online Store에 게시하세요). Admin API 또는 비공개 토큰을 붙여 넣지 마세요.
가져오기로 채워지는 내용
  • 한 번에 상품 하나를 불러옵니다.
  • 토큰은 한 번의 요청에 사용한 뒤 지웁니다.
  • 링크는 Shopify의 공개 상점 링크이며 Shopify가 제공하면 사용자 지정 도메인도 포함됩니다.
  • 모든 옵션의 가격이 같을 때만 가격을 채우고 아니면 비워 둡니다. 정확한 가격만 추가하세요.
  • 가져온 시점의 정보입니다. 가격과 재고는 자동 갱신되지 않으므로 상점이 바뀌면 확인하세요.
  • 판매 불가 상품이나 공개 Online Store 링크가 없는 상품은 가져올 수 없습니다.
  • 상품은 언제든 직접 입력할 수 있습니다.

구매 시 알림 받기

아직 켜지지 않았습니다. 구매 알림에는 SSN 서버의 Shopify 수신기가 필요하며 실제 상점 테스트를 통과할 때까지 꺼져 있습니다. 그전에는 설정 저장 에 오류가 표시됩니다. 상품 표시는 계속 작동합니다.
  1. Shopify에서 다음으로 이동하세요: Settings → Notifications → Webhooks. 웹훅의 다음 정보를 찾으세요: 서명 비밀키. Storefront 토큰이 아닙니다.
  2. Social Stream Ninja에서 다음을 여세요: 수익화 → Shopify 구매 → 설정 (Monetization → Shopify purchases → Setup).
  3. 입력할 값: myshopify.com 주소와 서명 비밀키를 입력하세요.
  4. 켜기: Shopify 구매 를 선택하고 다음을 클릭하세요: 설정 저장.
  5. 클릭: 수신기 URL 복사 (Copy receiver URL).
  6. Shopify에서 웹훅을 만드세요. 이벤트: 주문 결제 (Order payment). 형식: JSON. URL에는 수신기 URL을 사용하세요.
  7. 안정된 API 버전을 고르고 저장하세요. SSN은 2026-07 기준으로 제작되었습니다.
  8. Social Stream Ninja를 계속 실행하세요.
작동하고 있나요? 상태의 waiting, test received, event skipped, purchase received를 확인하세요. 수신기 URL이 있다는 것은 설정이 저장되었다는 뜻뿐입니다.

비밀키 저장 위치
  • 서명 비밀키는 SSN 수신기에 암호화되어 저장되고 저장 후 입력란은 비워집니다.
  • 별도의 비공개 읽기 키는 이 컴퓨터에 보관됩니다.
  • 어느 것도 OBS 링크나 시청자 QR 코드에 포함되지 않습니다.
  • 수신기는 주문을 받기 전에 Shopify 서명과 상점 이름을 확인합니다.
  • Shopify는 전용 수신기를 사용하므로 이전 Remote API Control 스위치는 필요하지 않습니다.

OBS에 넣기

  1. 다음 항목 아래에서: 대상 OBS 오버레이:에서 다음을 선택하세요: 상품 및 후원 링크.
  2. 열기 오버레이 링크 옵션 에서 다음을 선택하세요: 오버레이 보기: 상품 쇼케이스만 (Product showcase only) (사진, 가격, QR 코드), 후원 카드만 (Support card only) (작은 상점 링크) 또는 활동 알림만 (Activity alerts only) (구매).
  3. 클릭: OBS 링크 복사. OBS에 다음 소스로 추가하세요: 브라우저 소스로 추가하고 800 × 600으로 시작하세요. 보기마다 소스 하나를 사용하세요.
  4. 최종 방송 크기에서 휴대전화로 QR 코드를 스캔하세요.

multi-alerts 또는 활동 피드에 구매 표시추가 설정은 없습니다. 상품 목록 없이도 Shopify 구매를 받습니다.
구매 알림에 사진이 없는 이유 Shopify 주문에는 신뢰할 수 있는 이미지가 없어 알림은 텍스트만 표시합니다. 상품 카드의 이미지나 QR 코드를 가져다 쓰지 않습니다.
Event Flow와 기부 목표
  • Event Flow에서 Event Type을 선택하세요: purchase 를 선택하고 소스/유형 필터를 다음으로 설정하세요: shopify.
  • 주문 금액 규칙은 다음을 비교하세요: meta.commerce.orderTotal. 확인 meta.commerce.currency 를 먼저 완료하세요.
  • 구매는 기부가 아닙니다. 다음 값이 없으며 hasDonation 또는 donoValue가 없으며 기부 목표도 늘지 않습니다.
  • 상품 카드에 Gift 라벨이 있어도 주문 집계는 바뀌지 않습니다. 다른 사람에게 배송한다고 자신에게 온 선물이 되지는 않습니다.

안전하게 테스트

클릭: 샘플 미리 보기 (Preview sample) 로 외형을 확인하세요. 자신의 세션에 연결되지 않으므로 Event Flow 실행, 합계 변경, 결제 확인은 하지 않습니다. 전체 테스트는 Shopify 개발 상점을 사용하세요. 다음으로 표시된 주문은 test: true 는 상태에만 표시되고 알림은 나오지 않습니다.

Shopify 관리자 샘플을 주의해서 사용하세요. 테스트로 명확히 표시되지 않은 샘플을 보상 지급 설정에 보내지 마세요.
실제 상점 없이 테스트한 내용

실제 앱 테스트는 비영어 텍스트를 포함한 서명 메시지, 변조된 서명, 중복 전송, 테스트 주문, 통화 반올림, 과도한 요청 크기, 고객 비공개 정보 제거, 오프라인 후 따라잡기를 다룹니다. 실제 주문이나 판매자 계정은 사용하지 않았습니다.

Shopify CLI 샘플 웹훅은 메시지 처리를 테스트하지만 구독이나 재시도는 검증하지 못하며 앱 자격 증명도 필요합니다. 참고: Shopify CLI 웹훅 테스트 제한.

문제 해결

문제시도할 방법
Save setup에 오류가 표시됨서버에서 수신기가 아직 켜지지 않았습니다. 이전 세션 웹훅 URL을 대신 사용하지 마세요.
상태가 waiting에 머무름웹훅 확인: 주문 결제 (Order payment), JSON, 정확한 수신기 URL, myshopify.com 주소와 비밀키를 확인하세요. 사용자 지정 앱 웹훅은 해당 앱의 비밀키를 사용합니다.
이벤트를 건너뜀0보다 큰 전액 결제 주문 중 test: false로 표시되고 최근 7일 안에 갱신된 주문만 계산합니다. 미결제, 부분 결제, 취소된 주문은 건너뜁니다.
판매할 때 SSN이 꺼져 있었음주문은 최대 7일 기다립니다. SSN을 시작하면 전달됩니다.
작업이 두 번 실행됨7일 동안 중복을 차단하지만 작업 중 충돌하면 다시 실행될 수 있습니다. 중요한 자동화에는 자체 확인을 추가하세요.
구매자 이름이 없음의도된 동작입니다. 이름, 이메일, 주소, 메모, 사용자 지정 필드, 결제 링크, 주문 ID는 표시하지 않습니다.
환불해도 알림이 제거되지 않음환불, 취소, 수정으로 알림을 되돌리지 않습니다. 장부 관리 도구가 아닙니다.
대기 및 중복 주문 처리 방식
  • 시계 차이를 고려해 최대 5분 뒤의 주문 시각까지 허용합니다.
  • 주문 생성, 배송, 재고 변경으로 결제를 추측하지 않습니다. 테스트 플래그가 없으면 건너뜁니다.
  • 수신기가 재시작되어도 상태와 대기 주문은 유지됩니다.
  • 저장 공간은 제한됩니다. 주문을 안전하게 저장할 수 없으면 수신기가 Shopify에 나중에 다시 보내도록 요청합니다.
  • Shopify 전송 ID가 달라도 상점과 주문으로 중복을 판별합니다.
  • SSN은 수신 확인 전에 처리한 주문을 저장합니다.
