Kick 설정 및 인증

정확한 채널 URL 슬러그를 사용한 다음 간단한 페이지 캡처나 더 풍부한 WebSocket 알림 소스를 선택하세요.

Kick 소스 모드 선택표시 이름 대신 URL 슬러그 사용데스크톱 앱 설정브라우저 확장 프로그램 WebSocket 설정현재 Kick 로그인에서 요청하는 권한현재 소스가 구독하는 공식 이벤트연결되지 않는 Kick 소스 해결

Kick 소스 모드 선택

모드적합한 용도로그인
표준 (Standard) 일반 또는 팝아웃 채팅 페이지에 표시되는 Kick 채팅을 읽습니다. 공개 채팅 캡처에는 일반적으로 필요하지 않습니다. 그래도 페이지가 로드되고 채팅이 표시되어야 합니다.
WebSocket 구조화된 채팅과 공식 팔로우, 구독, 보상, KICKs, 관리 및 라이브 상태 이벤트입니다. 공개 채팅은 별도로 연결할 수 있지만, 공식 이벤트 구독, 채팅 전송, 채널/관리 기능에는 OAuth가 필요합니다.

표시 이름 대신 URL 슬러그 사용

예를 들어 https://kick.com/example-channel의 소스 값은 example-channel입니다. 전체 URL을 붙여 넣거나 이 슬러그만 입력할 수 있습니다.

Kick 표시 이름은 URL 슬러그와 다를 수 있습니다. 표시 이름에는 밑줄이 들어가지만 URL에는 하이픈이 쓰일 수 있습니다. 표시 이름을 다시 입력하지 말고 주소 표시줄에서 슬러그를 복사하세요.

데스크톱 앱 설정

  1. 선택: 소스 추가 → Kick (Add source → Kick).
  2. 전체 Kick 채널 URL을 붙여 넣거나 URL 슬러그를 입력하세요.
  3. 유지: WebSocket 선택 상태를 유지하면 구조화된 알림을 받을 수 있습니다. 현재 앱에서는 Kick의 기본 모드가 WebSocket입니다.
  4. 선택: 소스 활성화(Activate source).
  5. Kick 소스 창에서 다음을 선택하세요: Kick으로 로그인 (Sign in with Kick) 을 선택하고 요청된 권한을 허용하세요.
  6. 소스 창을 열어 두고 Channel, Chat socket, Bridge, Subscriptions 상태 표시를 확인하세요.

브라우저 확장 프로그램 WebSocket 설정

  1. 최신 Social Stream Ninja 확장 프로그램을 설치하고 활성화하세요.
  2. 다음을 여세요: Kick WebSocket 소스 페이지.
  3. 바꿀 값: example-channel 을 해당 채널의 정확한 URL 슬러그로 바꾸세요.
  4. 선택: 채널 연결 (Connect channel) 을 선택하세요(페이지가 자동으로 연결되지 않은 경우).
  5. 선택: Kick으로 로그인 (Sign in with Kick) 을 선택하여 공식 이벤트 구독과 계정 제어를 활성화하세요.
  6. 방송 중에는 페이지를 열어 두세요.
https://socialstream.ninja/sources/websocket/kick.html?channel=CHANNEL_SLUG

표준 캡처를 사용하려면 다음을 여세요: https://kick.com/CHANNEL_SLUG 또는 해당 팝아웃 채팅을 열고 채팅을 보이게 유지하세요.

현재 Kick 로그인에서 요청하는 권한

권한 그룹용도
사용자 및 채널 읽기로그인한 사용자, 채널, 카테고리 및 현재 채널 정보를 확인합니다.
채널 쓰기고급 제어에서 방송 제목/카테고리를 업데이트합니다.
보상채널 보상 정보를 읽고 보상 사용 이벤트를 정규화합니다.
채팅 쓰기소스에서 방송자 또는 봇 계정으로 채팅을 보냅니다.
이벤트 구독Kick의 공식 실시간 이벤트를 구독합니다.
관리계정에 권한이 있으면 사용자를 차단/차단 해제하고 채팅 메시지를 관리합니다.
KICKsKICKs 관련 후원 정보를 읽습니다.

현재 Kick의 OAuth 흐름은 PKCE를 사용하는 인증 코드 로그인을 이용합니다. 액세스 토큰, 새로 고침 토큰, 클라이언트 비밀 키 또는 브라우저 쿠키를 가이드, 채팅, 지원 요청에 붙여 넣지 마세요.

공식 참고 자료: OAuth 2.1, 범위, Kick API 참고 문서.

현재 소스가 구독하는 공식 이벤트

  • 채팅: chat.message.sent.
  • 팔로우: channel.followed → Social Stream new_follower.
  • 구독: 신규, 갱신, 선물 → new_subscriber, resub, 그리고 subscription_gift.
  • 보상: channel.reward.redemption.updated → reward.
  • KICKs 선물: kicks.gifted → donation 이며 KICKs 금액을 포함합니다.
  • 관리: moderation.banned.
  • 방송 상태: livestream.status.updated → stream_online 또는 stream_offline.

레이드/호스트 참고: 현재 Kick의 공식 웹훅 목록에는 레이드/호스트 이벤트가 없습니다. Kick이 연결된 피드를 통해 이를 제공하면 Social Stream에서 호환 처리할 수 있지만, Kick 레이드 알림을 항상 받을 수 있다고 생각해서는 안 됩니다.

Kick의 최신 공식 자료인 웹훅 이벤트 목록 및 Social Stream의 이벤트 및 알림 호환성 가이드.

연결되지 않는 Kick 소스 해결

  1. Kick URL에서 정확한 채널 슬러그를 복사하세요.
  2. 다음을 확인하세요: 채널 (Channel) 에 원하는 슬러그가 표시되는지, 그리고 채팅 소켓 (Chat socket) 이 연결 해제 상태에서 바뀌는지 확인하세요.
  3. 채팅은 되지만 공식 알림이 오지 않으면 다시 로그인한 뒤 다음 항목을 기다리세요: 브리지 (Bridge) 그리고 구독 (Subscriptions) 이 연결될 때까지 기다리세요.
  4. 내장 로그인이나 CAPTCHA가 작동하지 않으면 다음을 사용하세요: 외부 브라우저 (External browser) 를 데스크톱 앱에서 사용하세요.
  5. 메시지 전송/관리 기능을 시험하기 전에 로그인한 계정이 해당 채널의 소유자이거나 관리 권한이 있는지 확인하세요.
  6. OBS 문제를 해결하기 전에 Social Stream 도크를 확인하세요. 도크에서 Kick 데이터를 받는다면 남은 문제는 오버레이 또는 OBS URL에 있습니다.
