내 이름을 잘 지켜보세요

Quick Call(빠른 응답)

이름 세 개와 매번 새로운 네 글자 코드. 내 차례가 오면 준비하세요.

미리보기 체험 →

플레이 방법

입력: !quick 를 입력해 참가하세요. 호명되면 30초 안에 본인의 코드를 입력하세요. 맞게 답하면 대기열 뒤로 돌아가며 차례를 놓치면 다시 참가해야 합니다. 오버레이는 개인 최고 기록이 가장 빠른 다섯 명을 표시합니다. 코드는 대소문자를 구분하지 않습니다.

투명한 OBS 배경입니다. 추가: &clean 를 추가하면 진행자 제어가 숨겨집니다. 일시 중지는 게임을 멈추며, 점수 지우기 또는 새로고침은 처음부터 시작합니다. 점수는 이 페이지에만 유지됩니다. 봇 메시지, 포인트, 구매는 없습니다. 시간에는 방송과 채팅 지연이 포함되므로 가볍게 즐기는 경쟁입니다. 무작위 코드는 미리 답을 준비하기 어렵게 하지만 자동 읽기를 막을 수는 없습니다.

OBS 레이어에 맞춘 설계

방송 화면 위에서 플레이

Firefly Catch와 Comet Rally는 주변 페이지가 투명하며 Maze Raid는 소스를 채웁니다. 1280 × 800 브라우저 소스로 시작하세요. 추가: &clean 를 추가하면 진행자 버튼과 연결 상태가 숨겨집니다. 미리보기 페이지는 투명 영역을 알아볼 수 있도록 체크무늬를 표시합니다.

새로운 플레이 방식 세 가지

Firefly Catch(반딧불이 잡기): 입력: !catch 로 시작한 다음 반딧불이가 고리 안에 들어오면 잡으세요. 한 번 날아갈 때 시청자당 한 번 시도할 수 있으며 중앙에서 잡으면 3점, 고리 안의 다른 위치에서 잡으면 1점입니다. 여섯 번 날아간 뒤 승자가 정해집니다.

Comet Rally(혜성 경주): 입력: !boost 를 입력하면 자동으로 배정되는 팀에 참가합니다. 시청자마다 3초에 한 번 가속할 수 있습니다. 먼저 20번 가속하거나 60초 뒤 앞선 팀이 승리합니다.

Maze Raid(미로 습격): 더 빠른 자동 탐험가가 SSN 벽 표지판이 있는 벽돌과 금속 질감의 복도를 탐색합니다. 일반 채팅은 채팅 참여자마다 아바타 적 하나를 생성하며 라운드당 최대 40명입니다. 침입자는 복도 3~8칸 거리에 나타나 추격하고 공격하며, 마지막 타격을 가한 사람이 승리합니다. 아바타 이미지를 불러오지 못하거나 이미지가 없으면 이니셜을 표시합니다. 미로는 OBS 브라우저 소스 전체를 채우므로 장면에 맞게 소스 크기를 조절하세요.

세 게임 모두 8초간의 결과 화면 후 다시 시작됩니다. 진행자는 OBS 상호작용에서 일시 중지와 새 라운드를 사용할 수 있습니다. 포인트를 소모하거나 봇 메시지를 보내지 않습니다.

01 / 함께 풀기

Signal Lock(신호 해독)

1?4?

채팅 참여자들이 90초 안에 네 자리 숫자를 맞힙니다. 추측할 때마다 모두에게 단서가 제공됩니다. 퍼즐 팬, 공부 중 휴식, 게임 대기실, 작은 커뮤니티에 어울립니다.

플레이 방법

입력: !code 1234. 숫자는 1~6이며 중복될 수 있습니다. 'Exact'는 숫자와 위치가 모두 맞았다는 뜻입니다. 다른 숫자는 맞는 숫자가 다른 위치에 있는 개수를 나타냅니다.

첫 유효한 추측으로 시간이 시작됩니다. 시청자마다 추측 사이에 5초를 기다려야 하며 같은 추측은 무시됩니다.

02 / 시청자들의 선택에 맡기기

Crowd Quest(시청자 퀘스트)

채팅이 이끄는 다섯 정거장의 우주여행입니다. 경로를 선택하고 공동 보급품을 관리하며 발견한 것을 가지고 돌아오세요. 토크, 그림, 음악, 편안한 게임, 다양한 콘텐츠 방송에 잘 어울립니다.

플레이 방법

입력: !vote 1, !vote 2, 또는 !vote 3. 각 장마다 승무원에게 선택할 시간 30초가 주어집니다. 시청자당 한 표이며, 가장 최근의 유효한 선택으로 이전 투표가 바뀝니다.

첫 투표로 각 장이 시작됩니다. 결과는 투표 전에 표시됩니다. 동률은 무작위로 결정되며, 승무원이 가진 것보다 많은 보급품이 필요한 경로는 선택할 수 없습니다.

두 팀 / 하나의 줄

Tug of War(줄다리기)

친근한 두 괴물이 코럴 팀과 민트 팀을 위해 줄을 당깁니다. 팀원이 정답을 맞히면 줄이 우리 쪽으로 이동합니다.

미리보기 체험 →

플레이 방법

입력: !join 를 입력하면 인원이 적은 팀에 배정됩니다(같으면 무작위). 양쪽에 한 명씩 있으면 경기가 시작됩니다. 해당 경기 동안 팀은 고정되며 늦게 참가해도 됩니다.

12초마다 단어나 간단한 산수 문제가 나타납니다. 단어나 정답을 채팅에 직접 입력하거나 다음을 사용하세요: !answer 뒤에 답을 입력하세요. 플레이어마다 문제당 한 번 당길 수 있으며 같은 답을 반복해도 추가로 당겨지지 않습니다.

20회 당기기만큼 앞서면 승리합니다. 그렇지 않으면 3분 뒤 앞선 팀이 이기며, 줄이 가운데면 무승부입니다. 결과 화면 이후 시청자들은 다음 경기의 새 팀에 참가합니다. 참여 포인트는 소모되지 않습니다.

여러 손이 함께 만드는 즐거운 주방.

Crew Kitchen(협동 주방)

재료마다 두 번씩 채우면 주문을 완성합니다. 네 주문을 완성하면 잔치가 열립니다.

미리보기 체험 →

플레이 방법

시청자마다 6초에 한 번 재료를 추가할 수 있습니다. 이미 채운 재료는 무시됩니다. 모두 같은 주방을 돕습니다.

첫 유효한 참여로 90초 라운드가 시작됩니다. 진행 상황은 라운드마다 초기화됩니다.

누구도 혼자 빛을 나르지 않습니다.

첫 유효한 참여로 90초 라운드가 시작됩니다. 진행 상황은 라운드마다 초기화됩니다.

함께하면 승무원은 더 강해집니다.

Meteor Shield(유성 방패)

여섯 번의 유성 웨이브 동안 우주선을 지키세요. 날아오는 색과 방패 색을 맞추세요.

미리보기 체험 →

플레이 방법

입력: !shield red.

시청자당 웨이브마다 방패 하나를 사용할 수 있습니다. 1초마다 위치를 바꿀 수 있습니다. 방패 하나는 같은 색의 유성 하나를 막으며, 막지 못한 유성마다 선체 내구도가 하나씩 줄어듭니다. 웨이브는 승무원 수에 맞춰 조절되며 유성은 최대 12개입니다.

각각 12초인 웨이브 여섯 번입니다. 선체 내구도를 남긴 채 살아남으면 승리합니다. 진행 상황은 라운드마다 초기화됩니다.

Memory Parade(기억 행진)

진행 상황과 점수는 경기마다 초기화됩니다. 포인트는 소모되지 않습니다.

작은 덧셈, 큰 협동.

Sum Squad(덧셈 팀)

함께 정확히 20, 그다음 30, 그다음 40을 만드세요.

미리보기 체험 →

플레이 방법

!add 1부터 !add 9까지 입력하세요. 목표마다 서로 다른 시청자가 번갈아 참여하며 각자 3초에 한 번 더할 수 있습니다. 목표를 초과하는 값은 무시됩니다. 90초 안에 세 목표를 모두 달성하세요.

진행 상황과 점수는 경기마다 초기화됩니다. 포인트는 소모되지 않습니다.

방송에 넣기

  1. SSN에서 다음을 여세요: Interactive Games → Select Game.
  2. 위 게임 중 하나를 선택하고 세션 링크를 OBS 브라우저 소스로 추가하세요. 1280 × 900으로 시작하세요.
  3. SSN과 채팅 소스를 계속 실행하세요. 화면에 명령을 표시하고 시청자들이 라운드를 시작하게 하세요.

진행자는 OBS의 상호작용 창에서 일시 중지하거나 다시 시작할 수 있습니다. 추가: &clean 를 추가하면 진행자 버튼이 숨겨집니다. &transparent 를 사용하면 페이지 배경이 투명해지고, 또는 &chroma 를 사용하면 초록색이 됩니다. 추가: &demo 는 별도 미리보기에만 사용하세요. 라운드는 10초 결과 화면으로 끝난 뒤 자동으로 다음으로 넘어갑니다.

이 게임들은 참여 포인트, 구매, 외부 미디어, 시청자 로그인 페이지를 사용하지 않습니다. 선택한 SSN 채팅 세션을 읽기만 하며 채팅으로 명령을 보내지 않습니다. 진행자 버튼은 로컬에서 작동합니다. 같은 사람이 두 플랫폼에서 참여하면 두 플레이어로 집계됩니다. 라운드당 서로 다른 플레이어는 최대 1,000명입니다.

익숙한 게임, 새로운 순간

Word Chain(끝말잇기) 는 점수를 더 명확히 보여주고 단어 흐름을 읽기 쉽게 만든 새 레이아웃을 사용합니다. 익숙한 규칙은 같습니다. 이전 단어의 마지막 글자로 시작하는 알파벳 세 글자 이상의 단어를 이어 가세요. 사전이 아니라 글자 패턴을 확인합니다.

사용해 보세요: Chat Garden(채팅 정원) 로 창의적인 휴식을 즐기고, Pixel Battle(픽셀 배틀) 로 함께 그림을 그리거나, Pet Race(반려동물 경주) 로 짧은 쉬는 시간을 즐기세요.

채팅 그 이상

시청자에게 결정을 맡기고 직접 실행하세요. 다음 그림의 색, 후보 목록 중 다음 노래, 스트레칭 시간을 고를 수 있습니다. SSN의 기존 투표, 대기열, 진행자 승인 스티커 보상도 또 다른 참여 방식입니다. 세션과 제어 링크는 비공개로 유지하세요. 시청자에게는 채팅 참여 방법만 필요합니다.
