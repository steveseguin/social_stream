TikTok 가이드

Social Stream Ninja에 TikTok을 연결하고 적절한 모드를 선택하여 답변을 보내는 방법과 필요한 경우 TikFinity를 대안으로 사용하는 방법.

개요

여기서 시작하세요

TikTok은 동작 방식이 자주 바뀌고 계정마다 다르게 작동하므로 안정적인 연결을 유지하기 가장 어려운 플랫폼 중 하나입니다.

빠른 추천:
  • 다음으로 시작하세요: TikTok WS + Auto.
  • 답변을 보내려면 다음으로 전환하세요: 표준 (Standard).
  • Standard가 불안정하다면 다음을 시도하세요: 로컬 서명기 (Local Signer).
  • TikTok 채팅이 계속 누락된다면 다음을 사용하세요: TikFinity OBS Dock 경로: 다른 채팅 사이트.
중요: TikTok 문제의 원인이 항상 SSN에 있는 것은 아닙니다. 메시지 누락, 인증 실패, 속도 제한은 TikTok 자체, 계정 상태 또는 지역별 제한 때문에 발생할 수 있습니다.
모드

어떤 TikTok 옵션을 사용해야 하나요?

옵션 적합한 대상 답변
TikTok WS + Auto 대부분의 사용자에게 권장하는 기본값입니다. 먼저 WebSocket을 사용하고 필요하면 Polling으로 전환합니다. 아니요
표준 (Standard) SSN에서 답변을 보내고 앱 안에서 실제 TikTok 라이브 페이지를 사용하려는 경우에 적합합니다. 예
TikTok WS + Local Signer Standard가 불안정하지만 답변 기능이 필요한 경우의 대안입니다. 예
폴링 (Polling) 호환성 모드입니다. 속도는 느리지만 WebSocket 연결이 실패할 때 유용합니다. 아니요
Euler Proxy / Euler Signing 자체 API 키나 사용자 지정 구성을 사용하는 사용자를 위한 고급 서명 옵션입니다. 대개 불가
TikFinity OBS Dock TikTok 자체 연결 모드에서 채팅이 많이 누락되거나 연결되지 않을 때 사용하는 읽기 전용 대안입니다. 아니요
1단계

SSN에 TikTok 연결

  1. 독립 실행형 앱을 여세요.
  2. 다음을 클릭하세요: TikTok 버튼은 왼쪽 사이드바에 있습니다.
  3. TikTok 사용자 이름, 라이브 URL 또는 요청된 값을 입력하세요.
  4. 원하는 TikTok 모드나 프리셋을 선택하세요.
  5. 클릭: 소스 활성화(Activate source).
2단계

답변 기능이 필요할 때

  1. 사용: 표준 (Standard) 모드를 먼저 사용하세요.
  2. 클릭: 로그인 (필요한 경우).
  3. 열기 캡처 페이지 표시 (Show capture page).
  4. 메시지를 보낼 TikTok 계정에 로그인되어 있는지 확인하세요.
3단계

Standard가 불안정할 때

  1. 사용해 보세요: 로컬 서명기 (Local Signer).
  2. 서명 창을 열어 두세요.
  3. WebSocket이 계속 실패한다면 다음을 시도하세요: 폴링 (Polling).
  4. TikTok 채팅이 여전히 많이 누락된다면 아래의 TikFinity 대체 연결로 전환하세요.
답변

TikTok 채팅에 답변 보내기

답변을 보내려면 유효한 TikTok 로그인 세션이 있어야 합니다.

  • 권장 답변 모드: 표준 (Standard)
  • 대체 답변 모드: 로컬 서명기 (Local Signer)
  • 답변용이 아닌 모드: Auto, Polling, TikFinity 대체 연결
선택 기준: 안정적인 읽기가 가장 중요하면 Auto나 Polling으로 시작하세요. 답변이 가장 중요하면 Standard나 Local Signer를 사용하세요.
대체 연결

TikFinity OBS 도크 사용 방법

TikTok 자체에서 채팅을 많이 누락하거나 숨기는 경우 TikFinity를 예비 소스로 사용할 수 있습니다.

  1. TikFinity를 여세요.
  2. 이동할 위치: Overlay -> OBS Docks.
  3. 도크 슬롯을 선택하고 채팅용으로 설정하세요.
  4. 도크 URL을 복사하세요.
  5. SSN에서 다음을 클릭하세요: 다른 채팅 사이트.
  6. TikFinity 도크 URL을 붙여 넣으세요.
  7. 새 소스를 활성화하고 방송 중에는 TikFinity를 열어 두세요.
  • 예비 읽기 소스이며 답변 도구는 아닙니다.
  • 이미 TikFinity 활동 피드 위젯을 사용하고 있다면, 브라우저 기반 구성에서도 지원되는 TikFinity 위젯 페이지를 SSN과 함께 사용할 수 있습니다.

이 대체 연결과 Discord StreamKit의 전체 안내: Discord StreamKit 및 TikFinity 소스를 참고하세요. 이벤트 페이로드의 자세한 내용: 이벤트 참고 문서.

문제 해결

자주 발생하는 TikTok 문제

"오프라인이라고 나와요"

  • TikTok 채팅은 해당 계정이 실제로 방송 중일 때만 작동합니다.
  • 먼저 방송을 시작한 뒤 다음을 시도하세요: 다시 로드 (Reload).
  • 방송 종료 후 테스트하면 실패하는 경우가 많습니다.

"인증 창이 닫혀요"

  • 사용: 캡처 페이지 표시 (Show capture page) 를 사용하면 로그인이나 CAPTCHA 화면을 볼 수 있습니다.
  • 사용해 보세요: 다시 로드 (Reload) 를 로그인 후 사용하세요.
  • 가능하다면 같은 기기의 다른 TikTok 탭이나 앱을 닫으세요.

"메시지가 누락돼요"

  • 항상 SSN 버그인 것은 아니며 TikTok 측 제한일 수 있습니다.
  • 한 가지 방식이 언제나 가장 좋다고 판단하기 전에 다른 모드도 사용해 보세요.
  • 본인 계정에서 TikFinity가 더 잘 작동한다면 대안으로 사용하세요.

"다시 연결하면 메시지가 중복돼요"

  • 먼저 최신 앱 버전으로 업데이트하세요.
  • 소스를 완전히 중지한 뒤 새로 연결하세요.
  • 계속 중복된다면 모드를 변경하거나 임시로 TikFinity를 사용하세요.

"계속 요청 속도 제한에 걸려요"

  • 같은 기기의 다른 TikTok 탭, 앱, 중복 시청 창을 닫으세요.
  • 몇 분 기다린 뒤 다시 시도하세요.
  • 다른 모드나 서명 경로를 시도하세요.

"무엇부터 해 봐야 하나요?"

  • 읽기에는 Auto
  • 답변에는 Standard
  • Standard가 불안정하면 Local Signer
  • TikTok 자체의 문제라면 TikFinity
확장 프로그램

브라우저 확장 프로그램을 사용하는 경우

  • 브라우저에서 방송 진행자의 TikTok 라이브 페이지를 열고 확장 프로그램을 활성화해 두세요.
  • 본인 방송에서 로그인 사용자나 호스트 전용 페이지 이벤트가 필요하다면 로그인하세요.
  • TikFinity 활동 피드 페이지는 브라우저 기반 SSN 구성에서도 사용할 수 있습니다.
  • 독립 실행형 앱은 여전히 가장 다양한 TikTok 모드와 간편한 대체 연결 옵션을 제공합니다.
