'ChatGPT'의 두 가지 의미

옵션설명대화
ChatGPT API 제공자SSN은 API 키와 선택한 모델을 사용해 OpenAI로 프롬프트를 보냅니다.chatgpt.com과 별개인 SSN/API 대화입니다.
ChatGPT 브라우저 소스확장 프로그램은 열려 있는 다음 페이지에 표시된 새 사용자 및 ChatGPT 발화를 읽습니다: chatgpt.com 탭.사용자가 연 브라우저 대화이며 API 키는 사용하지 않습니다.

중요: OpenAI API를 연결해도 SSN이 기존 ChatGPT 웹 또는 음성 대화에 연결되지는 않습니다. OpenAI API는 자체 대화 상태를 관리합니다.

옵션 1: ChatGPT 브라우저 도우미(실험적)

이미 Chrome에서 ChatGPT를 사용하고 API 키를 쓰고 싶지 않을 때 가장 적합한 옵션입니다. SSN은 페이지의 새 텍스트 발화를 다음 소스 유형으로 캡처할 수 있습니다: openai, 채팅 소스를 캡처하는 것과 같은 방식입니다.

ChatGPT 대화 캡처

  1. Social Stream Ninja Chrome 확장 프로그램을 설치하고 활성화하세요.
  2. 팝업에서 사용자가 직접 선택하는 다음 옵션을 활성화하세요: ChatGPT 소스.
  3. 열기 https://chatgpt.com/ 그리고 소스를 활성화한 뒤 페이지를 새로고침하세요.
  4. 같은 세션으로 SSN 도크를 여세요.
  5. 새 ChatGPT 메시지를 보내세요. 새 사용자 및 ChatGPT 발화가 도크에 나타나야 합니다. 기존 기록은 의도적으로 무시합니다.

열려 있는 ChatGPT 탭으로 실시간 채팅 보내기

  1. 비공개 또는 일부 공개 방송과 일반 ChatGPT 텍스트 대화로 테스트하세요.
  2. 다음 항목 아래에서: 관리, 활성화하세요: 모든 메시지 릴레이.
  3. 설정: 릴레이 대상 선택 대상: openai 를 선택하면 캡처된 시청자 메시지가 ChatGPT 탭으로만 전달됩니다.
  4. ChatGPT 탭을 열어 두세요. 새 답변은 SSN에 다음 형식으로 전달됩니다: openai 메시지.
  5. ChatGPT 오디오 또는 SSN 음성 읽기/오버레이 출력으로 답변을 방송에 넣으세요.

실험적 기능: 웹페이지 제어 요소는 바뀔 수 있고, 전체 릴레이로 대화에 메시지가 너무 많이 유입될 수 있으며, ChatGPT Voice 모드는 일반 텍스트 페이지처럼 삽입된 텍스트를 받지 못할 수 있습니다. 모든 시청자 메시지를 보내기 전에 필터나 테스트 방송을 사용하세요.

AI 웹사이트 캡처 상태

웹사이트현재 지원 상태
ChatGPT새 텍스트 발화를 실험적으로 캡처하며 기존 기록은 무시합니다. 일반 브라우저 릴레이로 프롬프트 입력창을 대상으로 지정할 수 있습니다.
Claude대화를 캡처하지 않습니다. 포함된 Claude 스크립트는 페이지 스타일 도우미일 뿐입니다.
Gemini, Copilot, Perplexity 및 기타 AI 사이트현재 SSN에는 전용 웹사이트 캡처 소스가 포함되어 있지 않습니다. SSN 제공자 목록에 있는 경우 해당 API는 사용할 수 있습니다.

옵션 2: SSN 안에서 AI 제공자 설정

SSN으로 답변 생성, 메시지 관리, 채팅 번역, 지식 베이스 검색 또는 오버레이 제작을 하려면 제공자를 사용하세요.

제공자 유형옵션참고
로컬Ollama; Local Gemma; Local Qwen클라우드 API 키가 필요하지 않습니다. 성능은 컴퓨터와 모델 자산에 따라 달라집니다.
사용자 지정/로컬 서버사용자 지정 OpenAI 호환 APIllama.cpp, LM Studio, vLLM 및 호환 게이트웨이에 사용합니다. Ollama는 전용 옵션을 사용해야 합니다.
클라우드OpenAI, Gemini, DeepSeek, xAI, AWS Bedrock, OpenRouter, Groq, OpenCode Zen키, 접근 권한, 결제, 할당량, 모델 이름은 각 제공자가 관리합니다.
체험판SSN Hosted Trial LLM실험적 기능으로 비활성화되거나 사용량이 제한될 수 있습니다.
  1. 열기 챗봇 및 AI 서비스 (SSN 팝업).
  2. 열기 LLM 서비스 제공자 설정 그리고 실제로 사용하는 제공자를 선택하세요.
  3. 엔드포인트, 모델, API 키 또는 로컬 자산 설정을 입력하세요.
  4. 선택: 선택한 챗봇 테스트. 연결됨 결과는 제공자가 테스트에 응답했다는 사실만 확인합니다.
  5. 이를 사용할 개별 기능인 기본 봇, 비공개 봇, 공동 진행자, 채팅 관리, 번역, RAG 또는 빌더를 활성화하세요.

옵션 3: 음성 AI 공동 진행자

공동 진행자는 '실시간 채팅도 볼 수 있는 AI와 대화하기'라는 작업 흐름을 위해 설계되었습니다. 마이크와 선택한 실시간 채팅 메시지가 같은 공동 진행자 세션에 입력되고, 응답을 방송에서 음성으로 재생할 수 있습니다.

  1. 열기 cohost.html?session=YOUR_SESSION.
  2. 음성/실시간 제공자 또는 SSN 팝업에서 설정한 LLM을 선택하세요.
  3. 마이크와 다음을 명시적으로 선택하세요: 음성 응답(Audio Response), 그런 다음 누르세요: 공동 진행자 시작.
  4. OpenAI Realtime에서는 실시간 채팅을 다음으로 두세요: 문맥만 — 요청받으면 답변 를 선택하면 AI가 끼어들지 않고 최근 시청자 메시지를 기억합니다. 선택: 질문 및 멘션 또는 모든 메시지 를 선택하면 자동 답변을 음성으로 읽습니다. 이 모드들은 플랫폼 채팅에 게시하지 않습니다.
  5. OpenAI Realtime의 경우 OBS에서 공동 진행자 브라우저/앱의 오디오를 캡처하고 다음을 사용하세요: cohost-overlay.html?session=YOUR_SESSION 를 무대 아바타와 말풍선에 사용하세요. 오버레이는 동일한 WebRTC 음성 스트림을 받지 않습니다. 지원되는 경우 공동 진행자의 출력 장치 선택기로 가상 케이블을 선택하세요. &forcetts 는 별도의 오버레이 음성을 명시적으로 추가합니다.
  6. 선택적 방송 도구는 기본적으로 꺼져 있습니다. SSN 팝업에서 Spotify, 허용된 OBS 장면 이름 목록 또는 채팅 강조 표시 제어를 활성화한 다음, 다음에서 같은 도구를 사용 준비 상태로 설정하세요: 공동 진행자의 방송 제어 (공동 진행자 페이지).
  7. OpenAI 지연 시간을 줄이려면 Mini 모델, 낮은 추론(Low), 빠른 발화 전환(Fast)을 선택하세요. 전체 품질과 높은 추론 수준은 어려운 답변의 품질을 높일 수 있지만 지연 시간과 API 비용도 늘어납니다. 빠른 발화 전환은 자연스러운 말 사이의 쉼을 끊을 수 있습니다. 진단에 측정된 첫 출력 지연 시간이 표시됩니다.
  8. OpenAI 카메라 및 화면 공유 입력은 선택 사항이며 기본값은 다음과 같습니다: 영상 없음. 선택하면 SSN은 직접 말하거나 입력한 요청마다 현재 이미지 한 장을 보냅니다. 연속 영상 스트림이 아니며 API 비용과 지연 시간이 늘어날 수 있습니다.
  9. 말풍선을 계속 표시하거나 자막을 제공해 시청자가 AI 음성을 듣지 않아도 대화를 따라갈 수 있게 하세요.

OpenAI Realtime은 다음에서 설정한 OpenAI 프로젝트 키를 사용합니다: ChatGPT API (SSN 팝업). 표준 키는 SSN 확장 프로그램/데스크톱 백그라운드에 유지되며, 백그라운드에서 공동 진행자 페이지용 수명이 짧은 Realtime 클라이언트 비밀 키를 생성합니다. 이후 마이크와 AI 음성 오디오는 WebRTC로 전달됩니다. 답변은 출력 토큰 512개로 제한되며 진단에 누적 사용량과 지연 시간이 표시됩니다. SSN은 활동이 없는 세션을 확인하고 실패한 전송 연결을 다시 연결합니다. 복구된 세션에는 지침과 성능 설정이 다시 적용되지만 이전 음성 대화는 복원할 수 없습니다. 이 기능은 SSN 공동 진행자 세션을 생성하며, ChatGPT 웹사이트나 ChatGPT 데스크톱 앱의 기존 대화를 제어하지 않습니다.

옵션 4: 기본 실시간 챗봇

기본 봇은 캡처된 시청자 메시지를 평가하고 오버레이, 음성 읽기 또는 지원되는 플랫폼 채팅으로 답변할 수 있습니다.

  1. AI 제공자를 설정하고 테스트하세요.
  2. 다음을 활성화하세요: 기본 AI 챗봇.
  3. 트리거 단어, 관리자 전용 동작, 요청 제한, 대화 기록, 프롬프트 지침을 선택하세요.
  4. 안전한 첫 테스트를 위해 다음을 활성화하세요: 봇 답변을 봇 오버레이 페이지로만 보내기.
  5. 열기 bot.html?session=YOUR_SESSION 그리고 답변을 소리 내어 읽으려면 음성 읽기를 활성화하세요.
  6. 대상 플랫폼이 메시지 게시를 지원하는지 확인한 후에만 오버레이 전용 모드를 해제하세요.

플랫폼 답변은 보통 로그인한 계정을 사용합니다. 별도 계정을 사용하려면 지원되는 플랫폼에서 전용 YouTube, Twitch 또는 Kick 봇 계정을 사용하세요.

옵션 5: 비공개 일대일 봇

chatbot.html 은 비공개 도우미 및 프롬프트 테스트 페이지입니다. 다음을 활성화하세요: 챗봇 - 비공개 인터페이스, 세션으로 페이지를 열고 설정한 LLM 제공자를 사용하세요.

비공개 봇은 기본 실시간 챗봇과 별개이며 현재 기본 봇의 RAG 데이터 세트나 다른 채팅 기록을 공유하지 않습니다.

AI 오버레이 빌더 가이드 열기

일반적인 해결 방법

  • 연결되었지만 실시간 답변이 없음: 기본 봇 또는 필요한 AI 기능을 활성화하세요. 제공자를 설정하기만 해서는 채팅이 처리되지 않습니다.
  • 공동 진행자에게 채팅은 보이지만 말하지 않음: 맥락만(Context only) 모드는 방송자가 채팅에 관해 질문할 때까지 의도적으로 기다립니다. 자동 답변을 받으려면 질문 및 멘션(Questions and mentions) 또는 모든 메시지(Every message)로 전환하세요.
  • ChatGPT 브라우저 소스에 아무것도 나타나지 않음: ChatGPT 사용 옵션을 활성화하고 다음을 새로고침하세요: chatgpt.com, 기존 대화 기록 대신 새 발화로 테스트하세요.
  • 봇이 대부분의 메시지를 건너뜀: 트리거 단어, 관리자 전용 모드, 요청 제한, 선택적으로 답변하도록 지정한 모델 지침을 확인하세요.
  • 텍스트는 표시되지만 소리가 없음: 음성 읽기를 생성하는 페이지가 열려 있고 OBS가 해당 페이지의 오디오를 캡처하는지 확인하세요.
