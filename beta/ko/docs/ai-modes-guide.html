5단계로 AI 연결하기

ChatGPT 탭을 제외한 모든 옵션은 이 설정을 먼저 해야 합니다.

  1. Social Stream 팝업에서 다음을 여세요: 챗봇 및 AI 서비스.
  2. 열기 LLM 서비스 제공자 설정 에서 사용하는 AI를 선택하세요.
  3. 주소, 모델, API 키 또는 다운로드 설정을 입력하세요.
  4. 클릭: 선택한 챗봇 테스트.
  5. Primary 봇이나 번역처럼 AI를 사용할 기능을 켜세요.
연결만으로 설정이 끝나지는 않습니다. AI가 테스트에 답했다는 뜻일 뿐입니다. 기능을 켜기 전까지는 채팅을 읽지 않습니다.

‘ChatGPT API’와 ChatGPT 탭의 차이

ChatGPT API 제공자Social Stream은 사용자의 API 키로 OpenAI에 프롬프트를 보냅니다.chatgpt.com과 별도의 자체 대화입니다.
ChatGPT 브라우저 소스확장 프로그램은 열려 있는 다음 탭에서 새 메시지를 읽습니다: chatgpt.com 탭.탭에 있는 대화입니다. API 키는 필요하지 않습니다.

OpenAI API 키를 추가해도 Social Stream이 기존 ChatGPT 웹사이트나 음성 대화에 연결되지는 않습니다.

음성 공동 진행자

방송 중 AI와 대화하세요. 마이크 소리를 듣고 공유한 채팅을 읽으며 음성으로 답할 수 있습니다.

  1. 열기 cohost.html?session=YOUR_SESSION.
  2. 음성 AI 또는 팝업에서 설정한 AI를 선택하세요.
  3. 마이크와 다음 항목을 선택하세요: 음성 응답(Audio Response), 그런 다음 누르세요: 공동 진행자 시작.
  4. OpenAI Realtime에서는 공동 진행자 페이지 오디오를 OBS에서 캡처하세요.
  5. 추가: cohost-overlay.html?session=YOUR_SESSION 를 OBS에 추가하여 아바타와 말풍선을 표시하세요.
Live Chat 설정역할
문맥만 — 요청받으면 답변채팅을 기억하며 물어볼 때까지 조용히 있습니다. OpenAI Realtime에서 작동합니다.
질문과 멘션에 음성으로 답하기해당 메시지에 자동으로 음성 응답합니다.
모든 메시지에 음성으로 답하기모든 메시지에 음성으로 답합니다.

어떤 방식도 플랫폼 채팅에 게시하지 않습니다. 시청자가 읽으며 따라올 수 있도록 말풍선을 표시하세요.

OpenAI Realtime 세부 정보
  • 다음에 저장한 OpenAI 키를 사용합니다: ChatGPT API. 키는 Social Stream에 보관됩니다. 공동 진행자 페이지에는 단기 인증 정보만 전달되며 오디오는 WebRTC를 통해 전송됩니다.
  • 오버레이에는 OpenAI 음성이 전달되지 않습니다. 지원되는 경우 공동 진행자 출력 선택기에서 가상 오디오 케이블을 선택하세요. &forcetts 는 별도의 오버레이 음성을 추가합니다.
  • 속도를 원하면 Mini 모델, Low 추론, Fast 대화 전환을 사용하세요. Full quality와 높은 추론 수준은 더 똑똑하지만 느리고 비용이 더 듭니다. Fast는 잠깐 멈추면 끼어들 수 있습니다.
  • 카메라와 화면 공유는 선택 사항입니다. 기본값은 영상 없음. 켜면 요청마다 사진 한 장을 보내며 실시간 영상은 아닙니다. 비용과 지연이 늘어납니다.
  • Spotify, OBS 장면, 강조 채팅 도구는 기본적으로 꺼져 있습니다. 팝업에서 켠 뒤 다음에서도 켜세요: 공동 진행자의 방송 제어.
  • 답변 출력은 최대 512토큰입니다. Diagnostics에서 사용량과 지연을 볼 수 있습니다.
  • 자동으로 다시 연결됩니다. 새 세션에서도 지침과 설정은 유지되지만 음성 대화 내용은 잊습니다.
  • ChatGPT 웹사이트나 앱의 기존 대화를 이어받지 않습니다.

AI 공동 진행자 전체 가이드

기본 챗봇

시청자 메시지에 오버레이, TTS 음성 또는 지원되는 플랫폼 채팅으로 답합니다.

  1. AI 연결 를 설정하고 테스트하세요.
  2. 열기 챗봇 - 기본(Chat Bot - Primary) 에서 다음을 켜세요: LLM AI 챗봇 활성화.
  3. 트리거 단어, 관리자 전용 설정, 사용량 제한, 기록, 지침을 설정하세요.
  4. 첫 테스트는 안전하게 진행하도록 다음을 켜세요: 봇 답변을 봇 오버레이 페이지로만 보내기.
  5. 열기 bot.html?session=YOUR_SESSION. 답변을 읽어 주게 하려면 TTS를 켜세요.
  6. 플랫폼의 게시 지원 여부를 확인한 뒤에만 overlay-only를 끄세요.

답변은 로그인한 계정으로 게시됩니다. 별도 이름을 쓰려면 지원되는 YouTube, Twitch 또는 Kick 봇 계정을 사용하세요.

AI 오버레이 빌더 전체 가이드

ChatGPT 탭(실험적)

Chrome에서 ChatGPT를 쓰고 있고 API 키를 원하지 않나요? Social Stream은 다른 채팅 소스처럼 ChatGPT 탭의 새 메시지를 가져올 수 있습니다(유형: openai).

ChatGPT 탭 캡처

  1. Social Stream Ninja Chrome 확장 프로그램을 설치하고 켜세요.
  2. 팝업에서 다음을 켜세요: ChatGPT 소스.
  3. 열기 https://chatgpt.com/를 다시 로드하세요.
  4. 같은 세션으로 Dock을 여세요.
  5. ChatGPT에 새 메시지를 보내세요. 양쪽 메시지가 Dock에 표시되어야 합니다. 이전 메시지는 의도적으로 건너뜁니다.

실시간 채팅을 ChatGPT에 보내기

  1. 비공개 또는 일부 공개 방송의 일반 텍스트 채팅에서 테스트하세요.
  2. 다음 항목 아래에서: 관리에서 다음을 켜세요: 모든 메시지 릴레이.
  3. 설정: 릴레이 대상 대상: openai로 설정하여 시청자 메시지가 ChatGPT로만 가도록 하세요.
  4. 탭을 열어 두세요. ChatGPT 답변은 다음 유형으로 돌아옵니다: openai 메시지.
  5. ChatGPT 오디오, Social Stream TTS 또는 오버레이로 답변을 방송에 내보내세요.
실험적 기능입니다. ChatGPT 사이트는 변경될 수 있습니다. 모든 채팅을 전달하면 대화가 메시지로 가득 찰 수 있습니다. 음성 모드가 입력한 텍스트를 받지 않을 수 있으므로 먼저 필터나 테스트 방송을 사용하세요.

문제 해결

문제시도할 방법
연결되었지만 채팅에 답하지 않음Primary 봇이나 원하는 기능을 켜세요. AI를 연결하는 것만으로는 채팅에 아무 일도 일어나지 않습니다.
공동 진행자가 채팅을 보지만 말하지 않음Context only에서는 정상입니다. 채팅에 관해 물어보거나 답변을 읽어 주는 모드를 선택하세요.
ChatGPT 탭 내용이 표시되지 않음ChatGPT 소스를 켜고 다음을 다시 로드하세요: chatgpt.com를 선택하고 새 메시지를 보내세요.
봇이 대부분의 메시지를 건너뜀트리거 단어, 관리자 전용 설정, 사용량 제한, 지침을 확인하세요. 의도적으로 대상을 엄격하게 고르도록 설계되었습니다.
텍스트는 표시되지만 소리가 없음소리를 내는 페이지가 열려 있고 OBS에서 해당 오디오를 캡처하는지 확인하세요.
