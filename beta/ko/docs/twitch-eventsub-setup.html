Twitch 설정과 EventSub

간단한 채팅은 일반 페이지 캡처를, 팔로우, 구독, Bits, 보상, 레이드, Hype Train, 채널 제어는 EventSub/WebSocket 모드를 사용하세요.

Twitch 소스 모드 선택데스크톱 앱 설정브라우저 확장 프로그램 EventSub 설정Twitch가 요청하는 권한현재 소스가 처리하는 이벤트이벤트 누락 시 먼저 확인할 사항

Twitch 소스 모드 선택

모드적합한 용도중요한 차이
표준 (Standard) Twitch 채팅 또는 팝아웃 페이지에서 기본 공개 채팅을 캡처합니다. 페이지에 표시되는 내용을 읽습니다. 간단하지만 전체 EventSub 이벤트를 제공하지는 않습니다.
WebSocket / EventSub 팔로우, 구독, Bits, 보상, 레이드, 방송 상태, Hype Train, 관리 동기화, 채팅 전송, 채널 정보. Twitch OAuth가 필요합니다. 로그인한 계정, 채널 역할, 채널 자격, 부여된 권한 범위가 허용할 때만 이벤트가 활성화됩니다.

데스크톱 앱 설정

  1. 선택: 소스 추가 → Twitch.
  2. URL에 사용되는 Twitch 채널 로그인 이름을 입력하세요. 예를 들어 twitch.tv/examplechannel의 경우 입력할 값: examplechannel.
  3. 유지: WebSocket 을 선택하면 더 많은 기능의 EventSub 소스를 사용합니다. 현재 앱에서 Twitch의 기본 모드입니다.
  4. 선택: 소스 활성화(Activate source), 그다음은 Twitch에 로그인.
  5. 요청된 권한을 승인하고 Twitch 소스 창을 열어 두세요.

브라우저 확장 프로그램 EventSub 설정

  1. 최신 Social Stream Ninja 확장 프로그램을 설치하고 활성화하세요.
  2. 다음을 여세요: Twitch EventSub 소스 페이지.
  3. 바꿀 값: examplechannel 을 URL에서 모니터링할 채널의 로그인 이름으로 바꾸세요.
  4. 선택: Twitch에 로그인 을 선택하고 요청된 접근 권한을 승인하세요.
  5. 해당 페이지를 열어 두세요. 알림을 테스트하기 전에 User와 Channel 입력란이 올바른지 확인하세요.
https://socialstream.ninja/sources/websocket/twitch.html?channel=CHANNEL_LOGIN

기본 Standard 캡처를 사용하려면 일반 Twitch 채팅이나 팝아웃 채팅 페이지를 열고 채팅이 보이도록 유지하세요.

Twitch가 요청하는 권한

Social Stream은 지원하는 컨트롤과 구독에 필요한 권한을 가진 사용자 토큰을 요청합니다. 범위를 허용해도 계정이 방송 진행자나 관리자가 되는 것은 아닙니다. Twitch는 선택한 채널에서 계정의 역할을 확인합니다.

권한 그룹용도
채팅채팅 읽기, 채팅 전송, 채팅 참여자 목록 조회.
팔로워와 구독자팔로우 이벤트, 구독자 이벤트, 선물 구독, 재구독 메시지.
Bits, 보상, Hype TrainCheer, 사용자 지정 채널 포인트 보상 사용, Hype Train 상태.
관리계정에 채널 관리 권한이 있는 경우 메시지 삭제, 차단/임시 채팅 금지, 차단 동기화.
채널 관리제목과 카테고리 조회/수정, 광고 조회/관리, 채널 지표 표시.

Twitch 공식 문서: 권한 범위 참조 그리고 EventSub 구독 유형.

현재 소스가 처리하는 이벤트

  • 팔로우: new_follower.
  • 구독: new_subscriber, resub, 그리고 subscription_gift.
  • Bits: cheer 후원 값 포함.
  • 채널 포인트: reward.
  • 레이드: raid.
  • 방송 및 광고 상태: stream_online, stream_offline, 그리고 ad_break.
  • Hype Train: hype_train 시작, 진행, 종료 업데이트.
  • 관리: 권한이 허용되는 경우 차단과 메시지 삭제 업데이트.

Twitch 구독자 이벤트에는 자격을 갖춘 제휴/파트너 채널과 방송 진행자 권한이 필요합니다. 팔로우와 관리 구독은 이벤트에 따라 로그인한 사용자가 방송 진행자이거나 권한이 부여된 관리자여야 합니다.

후속 처리에 사용되는 알림 이름과 페이로드 필드: 이벤트 및 알림 호환성 가이드 그리고 이벤트 참고 문서.

이벤트 누락 시 먼저 확인할 사항

  1. 소스 페이지에서 올바른 값인지 확인하세요: 사용자 그리고 채널 (Channel).
  2. 소스 페이지/창을 열어 두고 채팅 연결이 활성화되어 있는지 확인하세요.
  3. 채팅은 작동하지만 팔로우/구독/보상이 작동하지 않는다면 로그아웃 후 다시 승인하여 최신 권한 범위를 부여하세요.
  4. 로그인한 계정이 해당 채널의 방송 진행자 또는 권한이 있는 관리자인지 확인하세요.
  5. 도크와 알림 오버레이가 같은 Social Stream 세션 ID를 사용하는지 확인하세요.
  6. 팝업의 가짜 테스트 메시지나 Multi Alerts 미리보기를 사용하여 캡처 문제와 오버레이 문제를 구분하세요.

EventSub는 알림을 두 번 이상 전달할 수 있습니다. Twitch는 최소 한 번 전달 방식을 명시합니다. Social Stream에는 중복 방지 기능이 있지만 사용자 지정 API 소비자도 가능한 경우 이벤트/메시지 식별자로 중복을 제거해야 합니다. 공식 문서: EventSub 개요.
