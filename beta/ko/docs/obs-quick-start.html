OBS 빠른 시작

최소한의 설정으로 채팅을 OBS에 표시하세요.

1. 세션 ID 하나 선택

짧은 세션 ID 하나를 정하고 모든 곳에서 사용하세요. 채팅 소스, 도크, OBS 오버레이가 서로를 찾는 데 사용합니다.

YOUR_SESSION_ID

2. 채팅 소스 시작

  1. Social Stream Ninja를 설치하거나 여세요.
  2. 사용하는 플랫폼의 채팅 소스를 열고 열어 두세요.
  3. 채팅 메시지를 하나 보내거나 도착할 때까지 기다려 소스가 작동하는지 확인하세요.

어떤 소스 모드를 사용할지 모르겠다면 다음을 참고하세요: 플랫폼 설정 선택기.

3. 도크 열기

도크는 테스트 화면입니다. OBS 설정을 변경하기 전에 여세요.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

4. OBS 브라우저 소스 추가

OBS에 브라우저 소스를 추가하고 오버레이 URL을 붙여 넣으세요.

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

일반 채팅 오버레이 배치는 다음의 템플릿을 사용하세요: 템플릿 갤러리.

5. OBS가 비어 있는 경우

이 순서대로 한 번에 하나씩 확인하세요.

  • 도크가 메시지를 받는지 먼저 확인하세요. 도크가 비어 있다면 아직 OBS의 문제가 아닙니다.
  • OBS URL에 같은 값이 있는지 확인하세요: session.
  • URL 옵션을 변경한 뒤 OBS 브라우저 소스를 새로고침하세요.
  • 소스 채팅 페이지 또는 앱 소스 창이 여전히 실행 중인지 확인하세요.

자세한 내용: 문제 해결.
