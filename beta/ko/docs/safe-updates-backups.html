안전한 업데이트, 백업 및 복구

업데이트, 재설치, 초기화 또는 릴리스 채널 변경 전에 사용할 수 있는 백업 하나를 만드세요.

안전한 원칙

  1. 먼저 설정을 내보내세요. 내보낸 파일은 앱이나 압축을 푼 확장 프로그램 폴더 밖에 보관하세요.
  2. 업데이트만 하려고 브라우저 확장 프로그램을 제거하지 마세요. 확장 프로그램을 제거하면 해당 설치에 저장된 설정이 삭제됩니다.
  3. 정상 사본 하나를 보관하세요. 손상된 설정을 복구하는 동안 유일한 백업을 덮어쓰지 마세요.
  4. 업데이트 후 소스 페이지를 다시 로드하세요. URL이 바뀌었다면 생성된 도크/오버레이 링크를 다시 열고 저장된 OBS 브라우저 소스를 새로고침하세요.

브라우저 확장 프로그램 백업 (Chrome, Edge, Firefox)

  1. Social Stream Ninja 제어 패널을 열고 다음으로 스크롤하세요: 전체 설정 및 도구.
  2. 열기 내보내기 / 가져오기.
  3. 선택: 디스크로 내보내기를 선택하고 안전한 위치를 고른 뒤 다음을 유지하세요: .data 파일 확장자입니다.
  4. 저장된 .data 파일이 있는지 확인한 뒤 업데이트, 제거 또는 초기화를 진행하세요.
  5. 사용: 설정 가져오기 (Import settings) 로 나중에 해당 파일을 복원하세요.

Chrome 웹 스토어 및 다른 스토어에서 설치한 확장 프로그램: 업데이트는 보통 기존 위치에 설치되며 설정을 유지합니다. 업데이트를 강제로 적용하려고 확장 프로그램을 제거했다가 재설치하지 마세요.

압축 해제 방식 수동 업데이트: 새 빌드를 다운로드하고 압축을 풀어 이전 확장 프로그램 파일을 교체한 뒤 다음을 선택하세요: 다시 로드 (Reload) 위치: chrome://extensions를 선택하세요. 압축을 푼 폴더를 그대로 두고 열려 있는 채팅 탭을 다시 로드하세요. 참고: 수동 설치.

백업 파일을 비공개로 보관하세요. 설정 내보내기에는 세션 비밀번호, 웹훅 또는 소스 URL 및 기타 비공개 설정이 포함될 수 있습니다. 공개적으로 게시하지 마세요.

데스크톱 앱 백업

백업메뉴용도
설정 백업 (Settings Backup) File → Settings Backup → Export Settings… 일반 업데이트, 설정 이동, 초기 복구에 사용합니다. 가져오기 메뉴: 설정 가져오기… (Import Settings…).
전체 세션 전송 File → Advanced Full Session Transfer 로컬 세션과 로그인 상태를 포함한 전체 데스크톱 프로필을 이동하거나 보존합니다. 암호화된 .ssappbk 파일을 만듭니다.

대부분의 업데이트에는 일반 설정 내보내기가 적합합니다. 전체 세션 전송은 데스크톱 앱에서만 사용할 수 있으며 파일이 더 크고 복원 시 대상 프로필을 교체합니다. 앱은 먼저 다음을 보관합니다: pre-restore-* 형태의 현재 프로필 사본입니다.

데스크톱 앱은 자동으로 업데이트되지 않습니다. 기존 설치 위에 새 버전을 설치하면 기존 프로필이 유지되어야 합니다. 그래도 먼저 내보내세요. 특히 재설치, 포터블/설치형 간 이동, 릴리스 채널 변경, 초기화 시도 전에는 꼭 내보내세요.

설정이 이미 사라진 경우

  1. 초기화와 재설치를 중단하세요. 추가 변경으로 가장 좋은 복구 사본이 덮어써질 수 있습니다.
  2. 앱이나 확장 프로그램에 유용한 상태가 남아 있다면 다른 작업 전에 내보내세요.
  3. 정상임을 확인한 가장 최근의 .data 또는 .json 설정 백업을 가져오세요.
  4. 데스크톱 전체 프로필 백업에는 다음을 사용하세요: 고급 전체 세션 전송 (Advanced Full Session Transfer).
  5. 데스크톱 소스 목록만 손상되었다면 다음을 시험하세요: 모든 소스 지우기 (Clear All Sources)를 시험하세요. 전체 초기화보다 범위가 좁으며 세션, 쿠키, 설정을 보존하도록 설계되었습니다.
  6. 백업을 만들었거나 전체 로컬 정리를 받아들이기로 한 후에만 전체 초기화를 사용하세요.

내보내기 파일은 없지만 이전 도크 URL이 있다면 도크 링크 복구 도구 로 해당 링크의 세션 ID, 비밀번호, URL 기반 설정을 복원할 수 있습니다. URL에 없던 설정이나 소스 계정은 다시 만들 수 없습니다.

일반 설정 백업에 포함되는 내용

현재 데스크톱 설정 전송 테스트는 캐시된 Social Stream 상태와 일부 앱 설정의 왕복을 검증합니다. 브라우저 확장 프로그램 내보내기에는 세션 ID, 선택적 비밀번호, 상태, 설정 객체가 포함됩니다.

  • 저장된 상태에 포함된 소스 및 전역 설정.
  • Social Stream 세션 ID 및 선택적 세션 비밀번호.
  • 앱에서 사용하는 일부 데스크톱 기본 설정.

브라우저 확장 프로그램의 .data 백업에는 브라우저 쿠키나 사이트 로그인 세션이 포함되지 않습니다. 데스크톱 앱에서도 일반 설정 내보내기는 모든 쿠키나 사이트 로그인을 복사하지 않습니다. 전체 앱 프로필을 옮겨야 한다면 데스크톱 전용 전체 세션 전송을 사용하세요.
