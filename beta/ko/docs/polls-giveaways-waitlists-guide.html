투표, 경품 추첨, 참가 대기열

채팅 투표, 무작위 당첨자 선택, 시청자 순서 대기열을 운영하세요.

모든 가이드 사용할 도구 투표 진행 경품 추첨 진행 빠른 당첨자 추첨 시청자 대기열 테스트와 문제 해결

어떤 도구가 필요한가요?

원하는 작업…팝업에서 열 위치
채팅으로 투표받기그래픽 투표 → 투표 옵션 (Graphical Poll → Poll Options)
공개 연출과 함께 당첨자 뽑기경품 추첨 도구 → 경품 추첨 옵션 (Giveaway Tool → Giveaway Options)
간단한 목록에서 무작위로 이름 뽑기대기 목록 / 당첨자 추첨 (Wait List / Winner Draw), 당첨자 추첨 모드 켬
시청자를 순서대로 받기대기 목록 / 당첨자 추첨 (Wait List / Winner Draw), 당첨자 추첨 모드 끔
모든 도구 공통: 도구 링크를 OBS의 다음 소스로 복사하세요: 브라우저 소스로 추가하고 Social Stream Ninja와 채팅 소스를 계속 실행하세요. 세션이나 비밀번호를 지우지 마세요.

5단계로 투표 진행

  1. 열기 그래픽 투표 → 투표 옵션 (Graphical Poll → Poll Options)를 여세요. 다음을 설정하세요: 투표 유형 (Poll Type) 대상: 객관식 (Multiple Choice).
  2. 질문을 입력하세요. 예: 다음에는 무엇을 할까요?을 입력하고 선택지는 쉼표로 구분하세요. 예: Adventure, Puzzle.
  3. 설정: 투표 일치 방식 (Vote Matching) 대상: 정확한 투표만 (Exact vote only). 다음을 켭니다: 투표 활성화 (Enable Poll).
  4. 투표 링크를 OBS에 복사하세요. 시청자는 다음만 보냅니다: 1 또는 2 (또는 선택지 이름)만 보냅니다.
  5. 클릭: 투표 종료 (End Poll) 으로 투표를 종료하세요. 결과를 기록한 뒤 다음을 누르세요: 투표 초기화 (Reset Poll) 로 다음 회차를 시작하세요.

알아 두면 좋은 내용

  • 시청자당 한 표입니다. 다음을 켜세요: 사용자당 복수 투표 허용 (Allow multiple votes per user) 으로 바꾸세요.
  • 자유형 투표는 해시태그를 사용합니다. 예: #yes. 해시태그 위치 무관 (Hashtag anywhere) 은 긴 메시지 안의 해시태그도 집계합니다.
  • 현재 투표 저장 (Save Current Poll) 는 결과가 아닌 설정을 저장합니다.

사용자 지정 색상 또는 글꼴: 그래픽 설문조사를 사용자 정의하세요.

경품 추첨 진행

처음 사용한다면 첫 경품 추첨 에서 스크린샷과 함께 설명합니다.

  1. 열기 경품 추첨 도구 → 경품 추첨 옵션 (Giveaway Tool → Giveaway Options).
  2. 다음을 설정하세요: 참가 키워드, 예를 들어 !enter.
  3. 다음을 선택하세요: 당첨자 카드, 이름 릴, 또는 커뮤니티 룰렛과 여섯 가지 스타일 중 하나를 설정하세요.
  4. 클릭: 표시 미리보기을 설정한 뒤 링크를 OBS 브라우저 소스로 복사하세요.
  5. 클릭: 참가 접수 시작. 준비되면 다음을 클릭하세요: 당첨자 추첨.
  • 추첨하면 접수가 자동으로 닫힙니다.
  • 새 라운드 는 참가자 목록을 비우고 이전 당첨자를 기록에 남깁니다. 접수는 닫힌 상태로 시작합니다.
  • 모든 응모의 당첨 확률은 같습니다. 후원해도 유리하지 않습니다.
  • 다음이 켜져 있지 않으면: 중복 당첨 허용 이 켜져 있지 않으면 같은 회차에서 당첨자가 다시 당첨될 수 없습니다.
  • 회원만 참가 가능 에는 회원 정보를 보내는 플랫폼이 필요합니다.
유료 티켓, 포인트 상품 또는 게임을 원한다면 참고: 경품 추첨, 참가권, 포인트 경품.
자세히: 확률, 저장, 제한
  • 미리 보기는 가상 이름을 사용하고 세션에 접속하지 않습니다. OBS 표시 화면에는 컨트롤이 없습니다.
  • 스타일과 제목은 링크에 저장됩니다. 참가 규칙은 접수를 열 때 팝업에서 가져옵니다.
  • Giveaway ID가 같은 화면은 같은 참가자와 당첨자를 표시합니다.
  • 유료 티켓은 티켓 수에 따라 당첨 확률을 가중합니다.
  • 플랫폼별로 1인 1회 참여입니다. 같은 사람이 두 플랫폼에서 참여하면 두 번으로 셉니다.
  • 최대 10,000명까지 참여합니다. 룰렛에는 최대 120명이 보이지만 추첨 대상은 전체입니다.
  • 오래된 메시지, 다시 재생한 메시지, 비공개, 봇, 이벤트 전용 메시지는 무시됩니다.
  • 회차는 이 브라우저나 앱 프로필에 세션별로 저장됩니다. 재시작하면 검토를 위해 열린 회차를 닫습니다. 데이터는 지워지지 않습니다.
API, Stream Deck 또는 Event Flow로 조작

팝업, HTTP/WebSocket API, Stream Deck은 이 동작을 공유합니다. 표시 페이지를 열 필요는 없습니다. Event Flow에서는 다음을 쓰세요: 경품 추첨 / 참가권 (세부 정보).

동작역할
startgiveaway접수를 열거나 재개합니다. 선택 값: {"giveawayId":"default","config":{"keyword":"!enter","match":"exact","membersOnly":false,"removeWinner":true}}. 다음이 없으면: config이 없으면 해당 회차의 규칙을 유지합니다(새 회차는 팝업 설정 사용).
closegiveaway접수를 닫습니다. 참가자 목록은 유지합니다.
drawgiveaway접수를 닫고 당첨자를 뽑습니다. 참여자가 없으면 오류가 납니다.
resetgiveaway참가자 없이 닫힌 새 회차를 만듭니다. 이전 당첨자는 기록으로 이동합니다. 유료 티켓은 먼저 환불하세요.
getgiveawaystate참가자 수, 접수 상태, 규칙, 최근 당첨자를 가져옵니다.
 
{"action":"drawgiveaway","get":"draw-1"}

Stream Deck(프로토콜 2)도 같은 이름을 씁니다. 응답은 추첨 상태를 뜻하며 OBS 표시 여부를 뜻하지 않습니다.

예전 독립형 커뮤니티 룰렛(링크에 managed 이 없는 것)은 자체 참가자 목록을 유지하며 이 동작을 무시합니다.

대기열에서 빠르게 당첨자 뽑기

  1. 열기 대기 목록 / 당첨자 추첨 (Wait List / Winner Draw) 의 설정을 펼치세요. 트리거를 켜고 명령을 정하세요. 예: !join.
  2. 켜기: 대기열 대신 당첨자 추첨 모드로 설정 (Configure as winner-draw mode instead of queue). 갱신된 링크를 OBS에 복사하세요.
  3. 시청자에게 명령을 알려 주세요.
  4. 접수가 끝나면 다음을 누르세요: 참가 접수 중지 (Stop entries), 그다음은 당첨자 선택 (Select winner).
  5. 클릭: 목록 다운로드 (Download list) 으로 참가자를 유지한 뒤 추첨 초기화 (Reset draw) 으로 지우세요.

시청자 대기열 운영

당첨자 추첨과 같은 설정에서 추첨 모드를 끔. 시청자는 정한 명령으로 참여합니다.

버튼용도
맨 위 항목 강조다음 차례 표시.
맨 위 항목 제거차례가 끝나면 다음으로 넘어가세요.
이름 선택순서 대신 무작위로 사람을 고릅니다.
참가 접수 중지 (Stop entries)새로운 사람의 대기열 참여를 막습니다.
목록 다운로드 / 대기열 초기화사본을 TSV 파일로 저장하고 끝나면 지우세요.

제거한 사용자 재참여 허용 은 다시 줄을 설 수 있는지 결정합니다.

관리자용 채팅 명령

켜기: 대기열 제어 명령 활성화 을 켜면 채팅 관리자, 진행자, 운영자가 채팅에서 대기열을 조작할 수 있습니다.

!wlstop · !wlremove · !wlreset · !wlpick · !wlhighlight

일부 명령은 숫자를 받습니다. 예: !wlpick 3 또는 !wlremove 2.

먼저 테스트하고 문제 해결

방송 전에 몇 개의 테스트 메시지 을 서로 다른 가상 사용자로 보내고 OBS에 결과가 나오는지 확인하세요.

문제시도할 방법
투표가 집계되지 않음Enable Poll이 켜져 있고, 투표가 끝나지 않았으며, 입력이 정확히 일치하고, 아직 투표하지 않은 사람인지 확인하세요.
아무도 참여하지 못함트리거가 켜져 있고, 명령이 정확하며, 접수가 중단되지 않았고, 회원 전용 설정이 막고 있지 않은지 확인하세요.
인원수는 보이지만 목록이 없음당첨자 추첨 모드입니다. 대기열 대신 참가자와 당첨자를 표시합니다.
OBS에 다른 내용이 표시됨링크를 OBS에 다시 붙이고 세션과 비밀번호를 확인하세요. 설정이 다른 투표 페이지 두 개를 동시에 실행하지 마세요.

물리 버튼은 다음을 참조하세요: Stream Deck 설정 및 OBS 제어 도크.
