감열 프린터와 방송 라벨

구매, 후원, 채팅 이벤트를 실제 영수증, 스티커, 티켓 또는 수령 태그로 바꾸세요.

설정하기 기부 시 인쇄 판매 인쇄 Whatnot 라벨 용지 선택 라벨 크기 아이디어 문제 해결

6단계로 설정하기

시작하기 전에: Windows 독립 실행 앱이 필요합니다. 프린터가 일반 Windows 프린터로 표시되어야 합니다. Social Stream은 Windows 드라이버로 인쇄하며 원시 ESC/POS, ZPL, 제조사 SDK 명령을 보내지 않습니다.
  1. USB로 프린터를 연결하고 켠 뒤 Windows 드라이버를 설치하세요. Windows 테스트 페이지를 인쇄해 작동을 확인하세요.
  2. Social Stream에서 다음을 여세요: Global settings and tools → Mechanics - Connections & Integrations → Printer Control.
  3. 클릭: 프린터 찾기 (Find printers). Windows에 표시된 이름으로 프린터를 선택하세요.
  4. 다음을 입력하세요: 용지 너비(mm). 일반적으로는 58, 80, 또는 62.
  5. 유지: 고정 라벨 길이 (Fixed label length) 값: 0 으로 영수증을 인쇄하세요. 규격 라벨은 용지 공급 방향의 길이를 mm로 입력하세요.
  6. 클릭: 인쇄 테스트. 가장자리가 잘리면 해당 안전 여백을 늘리고 다시 테스트하세요.

기본 좌우 안전 여백 2mm는 저렴한 58mm 영수증 프린터 다수에 적합합니다. 실제 인쇄 영역은 드라이버가 정하므로 다음을 인쇄 가능 영역 사용 (Use printable area) 를 선택해 두세요. 다른 설정을 검증한 경우에만 바꾸세요.

누군가 기부하면 라벨 인쇄

💰 후원 / 팁최소 금액: 10
→
🖨️ 감열 라벨 인쇄{username}
{donation}
24 pt · 굵게 · 가운데 정렬
  1. 다음을 여세요: Event Flow 편집기 에서 새 흐름을 만드세요.
  2. 추가할 항목: 후원 / 팁 (Donation / Tip) 트리거를 추가하세요. 설정할 항목: 최소 금액 (Minimum Amount) 를 큰 기부만 인쇄할 때 설정하세요.
  3. 추가: 감열 라벨 인쇄 (Print Thermal Label) (Integrations 아래)를 선택하고 트리거를 연결하세요.
  4. 입력: {username}, 줄바꿈, 이어서 {donation}. 글꼴 크기, 굵기, 정렬, 매수를 선택하세요.
  5. 작업의 프린터 및 고정 길이 재정의는 빈칸 또는 0. Printer Control 설정을 사용합니다.
  6. 클릭: 흐름 테스트 (Test Flow). 이름을 입력하고 다음을 켜세요: 후원 금액 (Has Donation)를 선택하고 금액을 넣어 실행하세요. 실제 라벨이 인쇄됩니다.

다른 유용한 자리표시자: {message}, {source}, {donationAmount}, 그리고 {counterValue}. 흐름의 앞 단계에서 만든 값도 사용할 수 있습니다.

판매, 선물, 주문 번호 인쇄

인쇄하려는 항목…할 작업
판매사용: 이벤트 유형 포함: purchase. 후원 / 팁 (Donation / Tip) 에 필요한 항목: hasDonation만 처리하므로 대부분의 판매를 놓칩니다.
완료된 선물사용: gift 또는 giftfunded. 필요하면 제공업체별로 필터링하세요.
연속 주문 번호추가: 카운터 (Counter) 를 인쇄 작업 전에 넣으세요.

다음을 참조하세요: 커머스 이벤트 필드 에서 각 판매의 포함 항목을 확인하세요.

구매자는 굵게, 상품은 보통으로

  1. 설정: 굵기 대상: 선택한 텍스트.
  2. 라벨 텍스트로 다음을 입력하세요:
**{username}**
{subtitle}
  • 다음 안의 텍스트만 ** 가 굵게 표시됩니다. HTML이나 JavaScript는 필요하지 않습니다.
  • 중괄호는 한 쌍을 사용하세요. 판매의 상품명은 다음에 있습니다: {subtitle}. 수량은 다음에 있을 수 있습니다: {meta.commerce.quantity}.
  • 앞 단계에서 다음을 만든다면 buyer에서 다음을 사용하세요: **{buyer}** 를 대신 사용하세요.
  • Shopify와 eBay는 구매자 이름을 보내지 않습니다. 주문 카운터나 상품명 전용 표를 사용하세요.
  • 이미 All bold나 Normal로 설정된 라벨은 모양이 유지됩니다.
흐름 제작자를 위한 인쇄 결과와 구매자 번호

작업이 추가하는 값: meta.thermalPrintResult.success와 실패 시 오류 또는 코드를 다음 단계에 전달합니다. 성공은 작업이 Windows로 전송되었다는 뜻이지 종이가 나왔다는 뜻은 아닙니다. 중복 라벨을 피하려면 재시도 전에 Windows 인쇄 대기열을 확인하세요.

Counter는 고유 구매자가 아니라 구매 건마다 번호를 매깁니다. 한 구매자의 모든 구매에 같은 번호를 주려면 별도의 구매자-번호 목록을 만들고 방송 시작 때 초기화해야 합니다. User Memory의 reason 필드는 일반 텍스트이며 구매자 번호 카운터가 아닙니다.

Whatnot 상품 라벨

Whatnot 예제 흐름 다운로드. 구매자를 굵게 표시하고 상품명과 주문 ID가 있으면 인쇄합니다. 결제가 실패하면 별도의 결제 실패 라벨에 해당 안내의 세부 정보를 인쇄합니다.

  1. 독립 실행 앱에서 다음을 설정하세요: 프린터 제어 를 설정하고 테스트 인쇄를 실행하세요.
  2. 다음을 여세요: Event Flow 편집기에서 다음을 클릭하세요: 가져오기 (Import)를 선택하고 다운로드한 파일을 고르세요.
  3. 선택: Whatnot: 상품 라벨 + 결제 경고 (Whatnot: Item Labels + Payment Warnings). 두 인쇄 작업 모두 확인하세요. Printer Control의 프린터와 라벨 길이를 사용합니다.
  4. 흐름을 켜고 저장하세요. 가져올 때는 꺼져 있습니다.
  5. Whatnot 소스를 열고 방송 이벤트 캡처를 켜 두세요.
판매 라벨이 결제 완료를 뜻하지는 않습니다. 안내가 도착할 때마다 인쇄합니다. 결제를 기다리거나 이전 라벨을 수정하거나 구매자 번호를 부여하지 않습니다. 없는 필드는 빈칸으로 인쇄됩니다. 구매자, 상품, 주문 정보가 없는 실패 안내는 어느 라벨인지 알려 줄 수 없습니다.
예제 흐름 작동 방식

사용하는 항목: 이벤트 유형(고급) → 사용자 지정 이벤트 (Event Type (Advanced) → Custom Event) 대상: product_sold 그리고 payment_failed를 Whatnot으로 필터링하세요. 입찰과 경매 종료 안내는 인쇄하지 않습니다. 참고: Whatnot 이벤트 필드.

용지 선택

영수증 롤

길이 제한 없는 구매 전표, 대기표, 영수증용입니다. 고정 라벨 길이를 0으로 두세요.

연속 스티커 롤

길이 제한 없는 이름 스티커용입니다. 영수증 용지처럼 작동하지만 절단은 프린터나 드라이버가 해야 합니다.

규격 재단 라벨

규격이 같은 배지와 상품 라벨용입니다. 정확한 고정 길이를 설정하고 Windows 인쇄 기본 설정에서도 같은 용지를 선택하세요.

프린터 예시

프린터적합한 용도참고
일반 'POS-58'저렴한 58mm 영수증보통 USB입니다. 이름과 드라이버는 판매자마다 다릅니다. 기본 POS-58로 Social Stream을 테스트했습니다.
Epson TM-T20III더 튼튼한 영수증 프린터USB. 80mm 용지 또는 포함된 어댑터로 58mm 지원.
Brother QL-800스티커와 이름 라벨USB. 최대 62mm, 규격 또는 연속 용지, 자동 절단기.
Brother QL-820NWB공유 또는 네트워크 라벨 인쇄 환경USB, Ethernet, Wi-Fi, Bluetooth.
Zebra ZD220더 넓은 상품, 배송, 손목밴드 라벨USB. 약 25~112mm 용지. 감열 및 열전사 모델.

테스트 완료 목록이 아닌 예시입니다. 구매 전에 정확한 모델의 최신 Windows 드라이버, 라벨 크기 지원, 일반 Windows 프린터로 인식되는지 확인하세요.

고정 크기 라벨 정확히 설정하기

3 × 1인치 라벨(Munbyn BT320 포함): 너비를 76.2 mm, 고정 길이는 25.4 mm로 설정하세요(1인치 쪽이 공급 방향일 때). Windows에서도 같은 용지와 방향을 선택하고 12~14pt로 시작하세요.
규칙이유
용지 공급 방향으로 측정62 × 29mm 라벨은 보통 너비 62mm, 고정 길이 29mm입니다.
Windows 설정도 맞추기드라이버 인쇄 기본 설정에서 용지, 방향, 간격/마크 감지, 절단기를 동일하게 설정하세요.
고정 길이는 변하지 않음추가 용지 공급은 하지 않습니다. 텍스트가 너무 길면 드라이버에 따라 잘리거나 다음 장으로 넘어갈 수 있습니다.
가장 긴 텍스트로 테스트긴 이름, 상품 옵션, 추가 줄에는 더 넓은 공간이나 작은 글자가 필요합니다.
아주 짧은 라벨은 작동하지 않을 수 있음Social Stream은 최소 20mm를 요청하지만 드라이버가 짧은 페이지를 제한할 수 있습니다.

테스트 인쇄의 양쪽 테두리는 안전 너비를 보여 줍니다. 높이는 테스트 텍스트에 따라 달라지며 라벨 전체 테두리가 아닙니다.

방송 아이디어

  • 벽, 소품, 지도, 진행 보드에 붙일 후원자 이름 스티커.
  • 주문이 들어올 때 상품, 의뢰, 음료 또는 수령표.
  • 추첨권. 인쇄 단계 전에 빈도 제한과 자격 확인을 추가하세요.
  • VIP 배지, 팀 선택표, 도전 토큰, 목표 달성 라벨.
  • 옆에 앉은 제작자를 위한 짧은 할 일 목록.
비공개 정보를 인쇄하지 마세요. 주소, 이메일, 결제 정보, 비공개 메시지는 제외하세요. 감열지는 열, 빛, 시간에 따라 흐려집니다.

문제 해결

문제시도할 방법
프린터가 표시되지 않음Windows 테스트 페이지가 인쇄되는지 확인하세요. Social Stream을 재시작하고 Find printers를 다시 누르세요.
성공이라고 하지만 인쇄되지 않음Windows 프린터 대기열에서 일시 중지, 오프라인, 용지, 드라이버, 포트 오류를 확인하세요.
가장자리가 잘림Use printable area를 켜고 해당 쪽 안전 여백을 늘리세요.
빈 종이가 너무 많이 나옴영수증은 고정 길이 0을 쓰고 아래 여백과 추가 공급을 줄이세요. 라벨은 정확한 길이를 설정하세요.
라벨 하나가 두 장으로 인쇄됨텍스트가 라벨보다 높거나 Windows 용지 크기가 잘못되었습니다. 텍스트를 줄이거나 글꼴, 간격, 여백을 작게 하세요.
Test Flow가 잘못된 프린터를 사용함Print Thermal Label 단계에서 프린터 재정의를 선택하세요. 비어 있으면 편집기 테스트는 Windows 기본 프린터를 사용합니다.
