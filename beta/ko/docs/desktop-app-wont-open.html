데스크톱 앱이 열리지 않음

화면에 표시된 정확한 메시지에 따라 Social Stream Ninja를 안전하게 실행하세요.

여기서 시작

Windows와 macOS는 앱 스토어 외부에서 다운로드한 앱을 실행하기 전에 추가 확인을 요청하기도 합니다. 새 릴리스, 다운로드 횟수가 적은 앱, 비공개/맞춤 빌드에서 특히 흔합니다.

무엇을 허용하는지 충분히 이해하고 직접 진행해도 괜찮다고 판단한 경우가 아니면 보안 경고를 우회하지 마세요. 공식 Social Stream Ninja 릴리스 페이지에서 앱을 다운로드했거나 신뢰하는 사람에게 맞춤 빌드를 받은 경우에만 계속하세요. 확실하지 않으면 중단하고 경고를 보고하세요.

경고가 앱에 악성코드가 있거나 컴퓨터를 손상시킨다고 하거나 특정 위협 이름을 표시하면 허용하지 마세요. 스크린샷을 저장하고 아래 문제 해결 섹션을 확인하세요.

1. 출처 확인공식 릴리스 페이지 열기 그리고 확실하지 않으면 새 사본을 다운로드하세요.
2. 메시지 확인경고의 문구에 따라 아래에서 적용할 단계가 달라집니다.
3. 경고 보관지원이 필요할 때를 대비해 닫기 전에 스크린샷을 찍으세요.
WindowsSmartScreen, Defender 또는 Smart App Control macOSGatekeeper, 개발자 또는 공증 경고 LinuxAppImage 권한 또는 샌드박스 오류

Windows: 'Windows의 PC 보호'

메시지 예시 Microsoft Defender SmartScreen이 인식할 수 없는 앱의 시작을 막았습니다.

이 경고는 보통 Windows에 해당 다운로드의 평판 정보가 아직 충분하지 않다는 뜻입니다. 악성코드 탐지와는 다릅니다.

  1. 파일을 다음에서 받았는지 확인하세요: 공식 릴리스 페이지.
  2. 파란 경고 창에서 다음을 선택하세요: 추가 정보.
  3. 앱 이름이 Social Stream Ninja이거나 다음으로 시작하는지 확인하세요: socialstreamninja.
  4. 경고를 이해하고 계속 진행해도 괜찮다고 판단했다면 다음을 선택하세요: 실행. 그렇지 않으면 경고를 닫고 아래 대안 중 하나를 사용하세요.

Windows 빌드는 자체 서명되며 추가 안전성 및 평판 확인을 위해 VirusTotal에 제출됩니다. 자체 서명 인증서는 Windows가 신뢰하는 상용 인증 기관의 인증서와 동일하게 취급되지 않으므로 Windows가 다음을 표시할 수 있습니다: 알 수 없는 게시자 또는 새로 출시된 파일에 다시 확인을 요구할 수 있습니다.

Windows: Defender가 파일을 차단하거나 제거함

표시될 수 있는 메시지 위협 발견, 사용자 동의 없이 설치된 앱 발견, 이 앱이 차단됨 또는 위협 격리됨
  1. 열기 Windows 보안 를 시작 메뉴에서 여세요.
  2. 선택: 바이러스 및 위협 방지, 그다음은 보호 기록.
  3. Social Stream Ninja 설치 프로그램 또는 포터블 앱을 언급한 항목을 여세요.
  4. 탐지 이름과 영향을 받은 파일 경로를 읽으세요.
  5. 앱 평판 또는 사용자 동의 없이 설치된 앱 관련 경고일 뿐이고, 파일이 공식 릴리스 페이지에서 왔으며, 선택을 충분히 이해하고 진행해도 괜찮다고 판단했다면 다음을 선택하세요: 작업 > 디바이스에서 허용. 파일을 다시 다운로드해야 할 수 있습니다.
Windows가 특정 악성코드 위협 이름을 표시하면 중단하세요. 다운로드 출처를 확인하고 탐지 이름이나 스크린샷을 지원팀과 공유하기 전에는 허용을 선택하지 마세요.

Microsoft 보호 기록 지침

Windows: Smart App Control이 앱을 차단함

Smart App Control은 일반 SmartScreen 경고와 다릅니다. Windows는 앱 하나만을 위한 다음 예외를 제공하지 않습니다: 실행 예외.

  • 회사나 학교 컴퓨터에서는 관리자에게 앱 승인을 요청하세요.
  • 개인용 컴퓨터에서는 다음을 사용하세요: 브라우저 확장 프로그램 또는 Lite 웹 앱 를 장치 전체 보안 설정을 변경하고 싶지 않을 때 사용하세요.
  • Smart App Control은 다음에서 관리할 수 있습니다: Windows 보안 > 앱 및 브라우저 컨트롤, 하지만 변경하면 모든 앱의 보호에 영향을 줍니다. 결정하기 전에 Microsoft 설명을 검토하세요.

기타 Windows 메시지

메시지해결 방법
"보안 및 성능을 위해 이 Windows 모드에서는 Microsoft에서 확인한 앱만 실행합니다"컴퓨터가 Windows S 모드일 가능성이 큽니다. 이 모드에서는 Microsoft Store 앱만 실행합니다. S 모드 해제는 장치 전체에 적용되고 되돌릴 수 없는 선택이므로 브라우저나 Lite 버전을 먼저 고려하세요. Microsoft S 모드 가이드 읽기.
"시스템 관리자가 이 앱을 차단했습니다"회사, 학교, 가족 또는 보안 정책이 컴퓨터를 관리하고 있습니다. 관리 담당자가 앱을 승인해야 합니다.
"Windows Defender 방화벽이 이 앱의 일부 기능을 차단했습니다"이는 앱 시작 허용 여부가 아니라 네트워크 접근에 관한 것입니다. 접근을 허용하기로 했다면 신뢰할 수 있는 개인 네트워크만 사용하세요. 공용 네트워크 접근은 보통 필요하지 않습니다.
"이 앱은 PC에서 실행할 수 없습니다"해당 사본을 삭제하고 최신 Windows x64 빌드를 다시 다운로드하세요. 다운로드가 완료되었는지, macOS나 Linux 파일을 선택하지 않았는지 확인하세요.

macOS: 개발자 또는 공증 경고

표시될 수 있는 메시지 Apple이 앱에 악성 소프트웨어가 있는지 확인할 수 없거나 개발자를 확인할 수 없음

공식 macOS 릴리스는 서명 및 공증을 거치도록 되어 있습니다. 비공개 또는 제3자 맞춤 빌드는 공증되지 않았을 수 있으며, 새로 다운로드한 앱은 처음 열 때 여전히 승인이 필요할 수 있습니다.

  1. 앱을 다음에서 받았는지 확인하세요: 공식 릴리스 페이지 또는 맞춤 빌드를 신뢰할 수 있는 사람에게서 받았는지 확인하세요.
  2. 앱을 한 번 열어 본 다음 경고를 닫으세요.
  3. 다음을 여세요: Apple 메뉴 > 시스템 설정 > 개인정보 보호 및 보안.
  4. 아래로 스크롤해 보안 섹션에서 차단된 앱에 관한 메시지를 찾으세요.
  5. 경고를 이해하고 계속 진행해도 괜찮다고 판단했다면 다음을 선택하세요: 그래도 열기, 요청하면 인증한 다음 다음을 선택하세요: 열기.

해당 앱에 예외를 만듭니다. 모든 앱에 대해 Gatekeeper를 끌 필요는 없습니다.

다운로드한 앱을 안전하게 여는 Apple 가이드

macOS: '앱이 손상됨' 또는 '컴퓨터를 손상시킴'

터미널 명령으로 앱의 격리 정보를 제거하지 마세요. 이 메시지는 다운로드가 불완전하거나 수정되었거나, 서명이 유효하지 않거나, macOS가 보안 문제를 탐지했다는 뜻일 수 있습니다.

  1. 해당 사본을 휴지통으로 옮기세요.
  2. 공식 릴리스 페이지에서 최신 macOS 빌드를 다시 다운로드하세요.
  3. 앱 번들을 수정하지 않고 새 사본을 여세요.
  4. 메시지가 다시 나타나면 전체 문구와 macOS 버전이 보이는 스크린샷을 찍고 지원팀에 문의하세요.

다음 경우: 그래도 열기 가 없다면 앱을 한 번 더 열어 보고 개인정보 보호 및 보안을 다시 확인하세요. 관리되는 Mac에서는 관리자가 이 설정을 제어할 수 있습니다.

Linux: AppImage가 시작되지 않음

AppImage에 실행 권한이 필요할 수 있습니다:

  1. AppImage를 마우스 오른쪽 버튼으로 클릭하고 다음을 여세요: 속성.
  2. 권한에서 다음을 활성화하세요: 파일을 프로그램으로 실행 허용. 문구는 데스크톱 환경마다 다릅니다.
  3. AppImage를 다시 여세요.

터미널에서도 권한을 부여할 수 있습니다:

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

오류에 다음이 언급되면: chrome-sandbox, SUID sandbox, AppArmor 또는 비특권 네임스페이스가 오류에 언급되면 다음을 따르세요: AppImage 샌드박스 가이드.

경고 우회보다 안전한 대안

Social Stream Ninja를 사용하기 위해 운영체제 경고를 반드시 무시해야 하는 것은 아닙니다.

  • 경고 보고: 조사할 수 있도록 스크린샷과 아래에 나열된 정보를 보내세요.
  • 이전 공식 릴리스 사용: 새 버전만 차단되거나 실패한다면 공식 릴리스 페이지로 돌아가 이전에 작동했던 가장 최근 버전을 사용하세요. 가능하면 먼저 설정을 내보내세요.
  • Chrome 확장 프로그램 사용: 설치: Chrome 웹 스토어 버전 를 데스크톱 앱 대신 사용하세요.
  • 웹 앱 사용: 열기: Social Stream Ninja Lite 를 더 적은 기능으로도 충분할 때 사용하세요.
이전 릴리스에는 최신 수정 사항이 없습니다. 공식 릴리스 페이지에서만 다운로드하고 문제를 파악하면 최신 버전으로 돌아오세요.

여전히 열리지 않는 경우

지원팀에 다음 정보를 보내세요:

  • 전체 경고가 보이는 스크린샷.
  • 운영체제와 버전.
  • 다운로드한 정확한 파일 이름.
  • 설치 프로그램, 포터블 앱, AppImage, 공식 macOS 릴리스 또는 맞춤 빌드 중 무엇인지.
  • 같은 사본이 이전에는 정상적으로 열렸는지 여부.
  • Windows에서는 표시되는 경우 보호 기록의 탐지 이름.
