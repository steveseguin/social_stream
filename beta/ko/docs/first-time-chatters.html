첫 채팅 참여자 가이드

처음 참여한 채팅 사용자를 강조 표시, 잎사귀 배지 또는 선택적 소리로 표시하세요.

이 기능의 역할

첫 채팅 참여자 감지는 다음을 추가합니다: firsttime=true 를 해당 소스에서 시청자의 첫 저장된 채팅 메시지에 추가합니다. 도크는 이 플래그를 배경 강조, 첫 참여 전용 알림음, 선택적 잎사귀 배지에 사용할 수 있습니다.

필수 설정

  1. Social Stream Ninja 팝업을 여세요.
  2. 유지: 로컬 메시지 데이터베이스 비활성화 를 꺼 두세요.
  3. 켜기: 첫 채팅 참여자 감지.
  4. 같은 세션 ID로 도크 또는 오버레이를 열어 두세요.
중요: 로컬 데이터베이스가 필요합니다. 데이터베이스가 비활성화되면 Social Stream Ninja는 새 참여자인지 알 수 없습니다.

표시 옵션

  • 배경 강조: 도크에서 기본적으로 활성화됩니다. 유지: 첫 채팅 참여자 배경 강조 없음 를 강조 표시를 원할 때 꺼 두세요.
  • 잎사귀 배지: 켜기: 사용자 지정 배지로 첫 채팅 참여자 표시 를 사용하면 채팅 참여자의 배지 앞에 작은 잎사귀 배지가 붙습니다.
  • 첫 채팅 참여자 도크 알림음: 첫 채팅 참여자에게만 도크 알림음을 내고 싶으면 켜세요.
  • 새 참여자 또는 복귀 참여자 알림음: 8시간 이상 조용히 있다가 돌아온 시청자에게도 소리를 내고 싶으면 켜세요.

사용자 지정 오버레이에서 플래그 사용

사용자 지정 오버레이는 다음을 확인할 수 있습니다: data.firsttime === true. 잎사귀 배지 옵션을 활성화하면 배지가 다음에 포함됩니다: chatbadges 를 메시지가 오버레이에 도달하기 전에 추가합니다.

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

표시되지 않을 때

  1. 확인: 로컬 메시지 데이터베이스 비활성화 가 꺼져 있는지 확인하세요.
  2. 확인: 첫 채팅 참여자 감지 가 켜져 있는지 확인하세요.
  3. 확인: 첫 채팅 참여자 배경 강조 없음 가 강조 표시를 원할 때 꺼져 있는지 확인하세요.
  4. 확인: 사용자 지정 배지로 첫 채팅 참여자 표시 가 잎사귀 배지를 원할 때 켜져 있는지 확인하세요.
  5. 로컬 데이터베이스에 아직 저장되지 않은 사용자 이름/소스 조합으로 테스트하세요.
