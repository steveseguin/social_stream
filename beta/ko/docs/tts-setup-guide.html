음성 읽기 설정 가이드

방송에서 채팅을 소리 내어 읽습니다. 무료이며 계정이나 API 키가 필요 없습니다.

설정하기 OBS에서 재생 음성 듣기 제공자 선택 문제 해결 제공자 설정 더 활용하기

5단계로 설정하기

아직 채팅을 연결하지 않았나요? 여기서 시작하세요 를 먼저 완료하세요.

  1. 다음을 여세요: SSN 확장 프로그램 팝업, 또는 소스 및 설정 를 데스크톱 앱에서 사용하세요.
  2. 다음 항목 아래에서: 기본 채팅 오버레이 및 제어 도크에서 다음을 펼치세요: 메시지 – 텍스트 음성 변환.
  3. 켜기: 수신 메시지 텍스트 음성 변환.
  1. 다음으로 스크롤하세요: 텍스트 음성 변환 서비스 제공자. 다음을 선택하세요: Piper TTS. 그다음 음성을 고르세요.
  2. 클릭: 링크 복사 (다음 항목 옆에 있음): 기본 채팅 오버레이 및 제어 도크.
처음 사용한다면 Piper는 처음 사용할 때 음성을 내려받습니다. 잠시 기다리세요.

OBS에서 재생

  1. 추가: 브라우저 소스 에 복사한 링크를 붙이세요.
  2. 속성에서 다음을 켜세요: OBS를 통해 오디오 제어(Control audio via OBS).
  3. 채팅 메시지를 보내세요. 소스의 오디오 미터가 움직여야 합니다.
  4. 짧게 테스트 녹화한 뒤 재생해 보세요.
직접 들어 보고 싶으신가요? OBS에서 고급 오디오 속성 (Advanced Audio Properties)에서 해당 소스를 다음으로 설정하세요: 모니터링 및 출력.
메시지가 두 번 들리나요? 채팅은 한 페이지만 읽게 하고 다른 곳에서는 TTS를 끄세요.

샘플 제작 방법

영어 샘플의 문장: 방송에 오신 것을 환영합니다! 함께해 주셔서 감사합니다. 다음에는 어떤 게임을 할까요? 이름 읽기는 껐습니다. 샘플에는 로딩 시간이 포함되지 않습니다.

2026년 9월 7일 Windows 11의 OBS 32.2.2에서 테스트했습니다. 실제 채팅이 Dock에 도착해 읽혔고, 브라우저 소스 미터가 움직였으며 녹화에도 소리가 담겼습니다. CPU에서 Kokoro의 시작은 눈에 띄게 느렸습니다.

테스트 PC의 System TTS 목록에는 음성 다섯 개가 있었지만 OBS 녹화에서는 소리가 나지 않았습니다. PC마다 다르므로 본인의 링크를 반드시 시험하세요. 유료 계정이 없어 클라우드 음성은 시험하지 않았습니다.

Fish Audio

채팅 Dock, 선택 메시지 오버레이, TTS 페이지, Flow Actions에서 작동합니다.

  1. 선택: Fish Audio 을 TTS 제공자로 선택하세요.
  2. 다음을 붙여 넣으세요: Fish Audio API 키.
  3. 선택 사항: 다음을 붙여 넣으세요: 음성 ID 출처: Fish Audio. 이름이나 페이지 링크가 아닌 음성 모델 ID를 복사하세요. 비우면 기본 음성을 사용합니다.
  4. 프레스 TTS 테스트.

기본 모델은 s2.1-pro-free. 무료 범위와 공정 사용 조건은 Fish Audio가 정합니다. 유료 모델에는 계정 크레딧이 필요합니다. 무료 요청이 실패해도 SSN이 유료 모델로 전환하지 않습니다. 속도는 0.5~2입니다. Fish Audio가 언어를 감지하며 채팅 텍스트가 Fish Audio로 전송됩니다.

OBS에서는 로컬 브리지 실행

Fish Audio는 웹페이지의 직접 요청을 막으므로 OBS에는 SSN의 다음 기능이 필요합니다: 로컬 브리지 (Node.js 필요). OBS를 실행하는 컴퓨터에서 실행하세요.

  1. 다음을 설정하세요: SSN_TTS_TARGET_BEARER 환경 변수에 Fish API 키를 설정하세요.
  2. SSN 폴더에서 다음을 실행하세요: node scripts/local-tts-bridge.cjs --mode fish. 계속 실행해 두세요.
  3. Fish Audio 패널에서 다음을 설정하세요: 브리지 URL 대상: http://127.0.0.1:8124/v1/audio/speech.
  4. 터미널에 표시된 브리지 토큰을 다음에 붙여 넣으세요: API 키 필드.
  5. 음성을 시험한 뒤 오버레이 링크를 OBS에 추가하세요. 다음을 켜세요: OBS를 통해 오디오 제어(Control audio via OBS).

Kokoro와 Kitten 속도 개선

Kokoro나 Kitten에서 다음을 여세요: 생성과 재생. 이 옵션은 음성을 백그라운드에서 생성해 페이지가 부드럽게 작동하게 합니다.

자세한 내용과 링크 설정

자동 은 지원 GPU가 있으면 사용하고 없으면 CPU를 씁니다. 자동 품질은 호환 GPU에서 FP16, 다른 지원 GPU에서는 전체 정밀도, CPU에서는 소형 모델을 선택합니다. GPU를 강제했는데 없다면 오류가 납니다.

Kitten 0.8은 CPU에서 실행하며 영어만 지원합니다. 각 모델은 처음 사용할 때 내려받고 브라우저와 OBS가 각각 보관합니다. 어느 방식이든 NeuroSync에는 완전한 오디오 파일이 전달됩니다. 이 옵션을 바꾸지 않으면 이전 링크는 기존 방식으로 작동합니다.

Kokoro: &kokororuntime=worker, 선택적 &kokoroplayback=stream, &kokorodevice=wasm 또는 webgpu, &kokorodtype=q8, fp16 또는 fp32. 스트리밍이나 FP32를 켜면 백그라운드 생성이 자동으로 켜집니다.

Kitten: &kittenmodel=nano (또는 micro, mini), 선택 사항인 &kittenplayback=stream.
