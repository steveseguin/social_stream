1. 채팅 읽기 켜기

아직 채팅을 연결하지 않았나요? 여기서 시작하세요. SSN을 설치하고 소스를 추가한 뒤 도크를 여세요.

다음을 여세요: SSN 확장 프로그램 팝업 또는 데스크톱 앱의 소스 및 설정.

다음 항목 아래에서: 기본 채팅 오버레이 및 제어 도크에서 다음을 펼치세요: 메시지 — 음성 읽기. 여기에 표시된 스위치를 켜세요:

2. 무료 음성 선택

같은 섹션에서 아래로 스크롤하여 다음을 찾으세요: TTS 서비스 제공자. 선택할 항목: Piper TTS. 그다음 음성을 고르세요.

사용: 링크 복사 (다음 항목 옆에 있음): 기본 채팅 오버레이 및 제어 도크 로 업데이트된 링크를 받으세요.

3. OBS에서 재생

  1. OBS에 다음 소스를 추가하세요: 브라우저 소스 를 추가하고 해당 링크를 붙여 넣으세요.
  2. 활성화 OBS를 통해 오디오 제어(Control audio via OBS) 을 속성에서 켜세요.
  3. 채팅 메시지를 보내세요. 소스의 오디오 미터를 확인한 뒤 짧게 녹화하세요.

직접 들어 보고 싶으신가요? OBS 고급 오디오 속성에서 선택하세요: 모니터링 및 출력 을 해당 소스에 선택하세요. 채팅을 읽는 페이지는 하나만 유지하세요.

예시 문구와 테스트 세부 정보

네 영어 예시는 다음 문장을 읽습니다: 방송에 오신 것을 환영합니다! 함께해 주셔서 감사합니다. 다음에는 어떤 게임을 할까요? 이름 읽기는 꺼져 있습니다.

2026년 9월 7일 Windows 11의 OBS 32.2.2에서 확인했습니다. 채팅 메시지가 실제 도크에 도착하여 음성이 생성되었고, 브라우저 소스 미터가 움직였으며 녹화에도 포함되었습니다. 이 CPU 테스트에서는 Kokoro가 말하기 시작하기까지 확연히 더 오래 걸렸습니다. 이 클립은 음성 미리보기이며 대기 시간은 포함하지 않습니다.

이 컴퓨터에서 시스템 TTS는 음성 5개를 표시했지만 브라우저 소스 녹화에는 오디오가 생성되지 않았습니다. 이 결과는 해당 환경에 한정되므로 최종 URL과 녹화를 항상 테스트하세요. 유료 인증 정보를 사용하지 않아 클라우드 음성은 포함하지 않았습니다.

도움이 필요하신가요?

제 채팅 플랫폼에서도 TTS를 사용할 수 있나요?

SSN이 채팅을 텍스트로 받으면 소리 내어 읽을 수 있습니다. YouTube, Twitch, TikTok 등의 소스가 같은 기능을 사용합니다. 채팅 플랫폼 자체에 TTS 지원이 없어도 됩니다.

음성이 들리지 않나요?

도크에 채팅이 수신되는지 확인한 뒤 TTS 스위치, 제공업체, 필터를 확인하세요. 새로 복사한 링크를 사용하세요. 첫 모델 다운로드가 끝날 때까지 기다리세요.

Chrome/Edge에서는 되지만 OBS에서는 안 되나요?

OBS는 별도의 브라우저와 음성 목록을 사용합니다. 음성이 목록에 표시되어도 시스템 TTS가 작동하지 않을 수 있습니다. Piper, Kokoro, Kitten 또는 eSpeak를 사용해 보세요. 가상 오디오 케이블로는 음성 생성 실패를 해결할 수 없습니다.

미터는 움직이는데 녹화에 소리가 없나요?

OBS에서 음소거 상태와 녹음 트랙 지정을 확인하세요. 본인도 들으려면 모니터링 및 출력을 사용하되, 모니터링 출력을 다시 캡처하지 않도록 하세요. OBS 오디오 가이드.

OBS 도크나 강조 채팅을 대신 사용할 수 있나요?

OBS 사용자 지정 브라우저 도크는 조작 패널이며 위에서 사용하는 장면의 브라우저 소스와 다릅니다. 강조 채팅을 사용하려면 해당 오버레이의 팝업 옵션에서 TTS를 켜고 링크를 복사하세요. 음성이 겹치지 않도록 한 페이지만 읽게 하세요.

Fish Audio

선택: Fish Audio 를 채팅 도크, 강조 오버레이, TTS 페이지 또는 Flow Actions의 TTS 제공업체 메뉴에서 선택하세요. 본인의 Fish Audio API 키를 입력한 뒤 기존 Test TTS 버튼을 사용하세요. 선택 항목인 Voice ID로 다음 사이트의 음성을 지정할 수 있습니다: Fish Audio. 이름이나 페이지 URL이 아닌 음성 모델 ID를 복사하세요. 비워 두면 서비스의 기본 음성을 사용합니다.

고급 옵션에는 모델과 말하기 속도(0.5–2)가 있습니다. SSN의 기본값: s2.1-pro-free입니다. 무료 등급의 제공 여부와 공정 사용 조건은 Fish Audio에서 정합니다. 유료 모델에는 계정 크레딧이 필요합니다. SSN은 무료 요청이 실패해도 유료 모델로 다시 시도하지 않습니다. 시청자에게 들리는 볼륨은 More TTS options에서 조절하세요. 텍스트는 Fish Audio로 전송되며 언어는 서비스에서 감지합니다.

OBS / 브라우저 설정: SSN의 기존 도구인 Fish 모드의 로컬 TTS 브리지 를 OBS 컴퓨터에서 실행하세요. 다음 설정: SSN_TTS_TARGET_BEARER 환경 변수를 Fish API 키로 설정한 뒤 실행하세요: node scripts/local-tts-bridge.cjs --mode fish를 실행하세요. Fish Audio 패널의 설정: OBS / 브라우저 브리지 URL 대상: http://127.0.0.1:8124/v1/audio/speech로 설정하세요. 터미널에 표시된 로컬 브리지 토큰을 팝업의 API 키 입력란에 붙여 넣으세요. 재시작해도 토큰을 유지하려면 다음 값을 설정하세요: SSN_TTS_BRIDGE_TOKEN 에 길고 무작위인 비밀 값을 지정하세요. 토큰이 포함된 오버레이 링크는 비공개로 유지하세요. 브리지를 계속 실행한 상태에서 음성을 테스트하고 생성된 오버레이 URL을 OBS에서 사용하세요. OBS 믹서에 오디오를 표시하려면 브라우저 소스 설정에서 Control audio via OBS를 켜세요. 호스팅된 브라우저 페이지의 직접 Fish 요청에는 CORS 권한이 없으며, 브리지가 브라우저에서 접근 가능한 오디오 응답을 제공합니다.

브리지를 사용할 때는 &fishendpoint=http%3A%2F%2F127.0.0.1%3A8124%2Fv1%2Faudio%2Fspeech 를 URL에 추가하고 다음은 생략하세요: fishkey . 브리지에 키가 저장되어 있으면 생략할 수 있습니다.

URL 매개변수: &ttsprovider=fish&fishkey=YOUR_KEY&voicefish=VOICE_ID&fishmodel=s2.1-pro-free&fishspeed=1을 지정하세요. 평소 사용하던 컨트롤로 TTS를 켜세요. 키가 포함된 생성 URL은 비공개로 유지하세요. 수신 페이지가 Fish Audio를 사용하는 경우 Event Flow의 기존 Speak Text 음성 재정의에 Fish 음성 ID를 입력할 수 있습니다.

사용자 지정 / 로컬 TTS

이 옵션은 OpenAI 호환 컨트롤을 재사용하므로 제목이 여전히 OpenAI로 표시됩니다. 서버 엔드포인트와 지원되는 음성/모델을 입력하세요. 인증 방식은 서버에 따라 다릅니다. 참고: 로컬 서버 가이드.

고급: TTS URL 직접 편집

처음 테스트하기 좋은 음성:

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=kokoro
dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper
dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=kitten

포르투갈어 또는 스페인어에는 다음 중 하나로 시작하세요:

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=espeak&espeakvoice=es

고급: 자체 로컬 TTS 서버 실행

비공개 음성, 특정 음성 모델 또는 Kokoro-FastAPI나 openedai-speech 같은 서버를 사용하려면 로컬 TTS 서버가 유용합니다. TTS를 재생하는 페이지에서 엔드포인트에 접근할 수 있어야 합니다.

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=customtts&openaiendpoint=http://127.0.0.1:8124/v1/audio/speech&voiceopenai=af_bella

localhost 는 페이지를 실행하는 컴퓨터를 뜻합니다. TTS 서버가 다른 컴퓨터에 있다면 해당 컴퓨터의 LAN IP를 사용하거나 OBS 컴퓨터에서 브리지를 실행하세요.
