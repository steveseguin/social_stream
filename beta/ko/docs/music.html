Music and Now Playing

Show the current song from Spotify, DJ software or a text file in an overlay, chat commands and Event Flow.

One input at a time: Music reads the single source you select and uses it for the Music overlay, song commands and Event Flow. Existing Spotify overlay links keep showing Spotify.
빠른 시작Choose a source오버레이Chat commandsEvent Flow

빠른 시작

  1. 열기 Interactive > Music > Now Playing 에서 다음을 켜세요: Enable Music.
  2. Select a 소스 and connect it as described below. The status line under the toggle shows the track being read, or what is missing.
  3. 다음 위치에서: Now Playing Overlay를 선택하고 다음을 설정하세요: Overlay input 대상: Selected Music source.
  4. Copy the overlay link into an OBS Browser Source. Choose a style and the hide options in the same panel.

Choose a source

Spotify

Enable and connect Spotify in Spotify Setup & Configuration. Playback controls and song requests continue to use that account.

What's Now Playing

Connect your DJ software or media player in What's Now Playing, then enable its web server. Enter its address in Music, usually http://127.0.0.1:8899. For a DJ computer on your local network, use that computer's address and web server port.

File (SSApp)

Set your player or DJ helper to overwrite a current-song file, then choose that file in Music. Select one of these formats:

  • Artist - Title: one line, for example Example Artist - Example Song.
  • Separate lines: artist on line 1 and title on line 2.
  • JSON: the object below. Only title 이 필요합니다.
{"title":"Example Song","artist":"Example Artist","album":"Example Album"}

JSON can also include a string id, an HTTPS imageUrl, status (playing, paused or stopped), and numeric durationMs 그리고 progressMs in milliseconds. Leave unknown values out. An empty file clears the track. Files must be 64 KB or smaller. The selected path stays on the SSApp computer.

Track expiry

For What's Now Playing and file inputs, SSN clears a track that the source has not updated within Track expiry, so old information does not linger when the source stops. The default is 900 seconds; raise it if your sets include longer tracks.

오버레이

  • The Music overlay uses the same styles and hide options as the Spotify overlay.
  • Sources that do not report playback timing show artist and title without a progress bar or playback badge.
  • The overlay clears the track if it loses contact with SSN for about 35 seconds, and restores it when contact returns.
  • The song-request queue is Spotify-only and needs Overlay input 설정값: Spotify.

Chat commands

When Music is enabled, its Song commands setting owns Spotify's !song, !np and their configured aliases. Playback and queue commands remain Spotify-specific.

  • Built-in dock replies: a simple response shown in SSN. It uses the existing Spotify command permissions.
  • Event Flow: custom responses, including replies sent to the platform chat.

For a platform chat reply, choose Event Flow and add the Music Song Command template in the editor. It starts disabled. Review the command and destination, then enable it. Configure permissions and a Rate Limiter in your flow as needed.

Event Flow

Get Now Playing adds the selected track to the current flow without changing the originating chat. Use {meta.music.message} for a complete response, including when no song is available, or format {meta.music.track.name}, {meta.music.track.artist} 그리고 {meta.music.track.album} yourself.

Track Changed can drive Show Text, OBS Set Text, TTS or a webhook. Playback Changed works when the selected source reports playback status. Initial connection and reconnect snapshots do not announce tracks. Music updates do not trigger Any Message flows.

Keep automatic Spotify dock announcements off if a flow already announces the same Spotify track.

Field details are in the 이벤트 참고 문서.
