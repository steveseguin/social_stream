음성 읽기 음성 가이드

모든 TTS 옵션을 한곳에: 제공자, 링크 설정, 시스템 음성, OBS 오디오.

여기서 시작하세요 제공자 링크 설정 제공자 설정 시스템 음성 OBS의 System TTS 문제 해결

여기서 시작하세요

TTS가 처음이라면 다음을 따르세요: 음성 읽기 설정 가이드. 5단계면 됩니다. 이 페이지는 전체 참조 문서입니다.

SSN은 텍스트로 캡처한 채팅을 읽습니다. 플랫폼 자체 TTS는 필요 없습니다. TTS가 켜진 Dock이나 오버레이가 자체 필터에 따라 읽습니다.

가장 간단한 링크는 시스템 음성으로 TTS를 켭니다:

dock.html?session=YOUR_SESSION&speech=en-US

OBS에는 페이지를 통해 재생하는 무료 음성을 추가하세요:

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper

페이지를 열고 연결한 상태로 유지하세요. 한 페이지만 읽어야 합니다.

System TTS와 무료 TTS는 같은 것이 아닙니다. 시스템 음성은 브라우저와 컴퓨터에서 옵니다. Chrome에서 되어도 OBS에는 없는 경우가 많습니다. Kokoro, Piper, Kitten, eSpeak는 무료이며 자체 오디오를 만들어 OBS에서 작동합니다. OBS TTS에 돈을 낼 필요는 없습니다.

TTS는 다음에도 있습니다: CAPTION.Ninja에도 있으며 자막, 받아쓰기, 번역에 사용합니다. 둘 다 무료와 유료 음성을 제공합니다.

시스템 음성

System TTS는 브라우저와 컴퓨터의 음성을 사용합니다. 아래는 일반적인 예이며 보장되지는 않습니다.

브라우저시스템 음성
Chrome가능. Google 음성과 시스템 음성.
Edge가능. Microsoft 음성과 Windows 언어 팩.
Firefox제한적. 로컬 시스템 음성만 지원.
Opera제한적. 설치 환경에 따라 다름.
Safari오디오 재생 전에 클릭이 필요합니다.
OBS자체 브라우저입니다. Chrome이나 Edge의 음성을 받지 않습니다. SSN 앱 테스트는 OBS 테스트가 아닙니다.

이 브라우저의 시스템 음성 확인. 연 브라우저의 System TTS 음성만 나열합니다. OBS나 Kokoro 같은 제공자는 테스트하지 않습니다. 목록이 비어도 다른 제공자가 작동하지 않는다는 뜻은 아닙니다.

Windows에 음성 추가

  1. 열기 시작 > 설정 > 시간 및 언어 > 음성.
  2. 다음 항목 아래에서: 음성 관리에서 다음을 클릭하세요: 음성 추가.
  3. 언어를 고르고 다음을 클릭하세요: 추가:.
  4. 브라우저를 재시작하세요.

Windows 11 설명입니다. Windows 10은 다음을 보세요: Microsoft 가이드. 일부 타사 음성은 브라우저에 나타나지 않습니다. Firefox는 Chrome 계열보다 더 많은 시스템 음성을 표시하는 경우가 있습니다.

System TTS를 OBS로 보내기

다른 제공자를 쓴다면 이 과정은 필요 없습니다. 다음을 켜세요: OBS를 통해 오디오 제어(Control audio via OBS) 을 브라우저 소스에서 켜세요. 가상 케이블은 필요 없습니다.
  1. 먼저 System TTS가 실제로 말하는지 확인하세요. OBS에는 사용 가능한 음성이 없을 수 있습니다. 소리가 생성되지 않으면 라우팅으로 해결할 수 없으므로 다른 제공자를 쓰세요.
  2. 다른 브라우저에서 소리가 나면 OBS 앱 오디오나 데스크톱 오디오 캡처로 해당 브라우저를 캡처하세요.
  3. 해결되지 않으면 아래의 가상 오디오 케이블로 브라우저를 연결하세요.
가상 케이블로 오디오 보내기(Windows)

다운로드: VB-Audio Virtual Cable (무료) · Voicemeeter · Audio Router (레거시)

방식할 작업
PC 전체설정: CABLE Input 을 Windows 기본 출력으로 설정하세요(소리 설정 > 출력).
앱 하나, Windows 11설정 > 시스템 > 소리 > 볼륨 믹서. 브라우저 출력을 다음으로 설정하세요: CABLE Input.
앱 하나, Windows 10소리 설정 > 앱 볼륨 및 장치 기본 설정. 브라우저 출력을 다음으로 설정하세요: CABLE Input.
Audio Router오래된 소프트웨어입니다. 브라우저를 다음으로 보내세요: CABLE Input.
VoicemeeterWindows 기본 출력으로 설정하세요. 하드웨어 출력은 스피커로, 가상 출력은 OBS로 보내세요.

그다음 OBS에서 추가하세요: 오디오 입력 캡처에서 다음을 고르세요: CABLE Output (또는 Voicemeeter 출력)을 고르고 모니터링을 다음으로 설정하세요: 모니터링 및 출력. 사용: 모니터링만 을 다른 소스가 이미 방송에 보내고 있을 때 설정하세요.

TTS를 재생하고 OBS 미터와 실제 소리를 확인한 뒤 음량을 조절하세요.

문제 해결

문제시도할 방법
소리가 나지 않습니다.TTS가 켜져 있고 읽는 페이지가 열려 있으며 브라우저 소스가 음소거되지 않았는지 확인하세요. 일반 브라우저에서는 페이지를 한 번 클릭하세요.
OBS에서 무음전혀 말하지 않으면 제공자부터 확인하세요. 소리가 나면 다음을 확인하세요: OBS를 통해 오디오 제어(Control audio via OBS), 믹서 음소거, 출력 트랙을 확인하세요. 또는 읽고 있는 브라우저를 캡처하세요.
클라우드 음성이 작동하지 않음API 키와 제공자 이름을 확인하세요. 키가 없으면 SSN은 System TTS로 돌아가며 OBS에서는 무음일 수 있습니다.
로컬 서버가 앱에서는 되지만 OBS에서는 안 됨OBS는 별도 브라우저입니다. OBS 컴퓨터에서 서버를 확인하세요. 특히 다음을 쓸 때: 127.0.0.1. 참고: localhost 규칙.
첫 글자나 단어만 읽음제거 ttsquick 을 OBS 링크에서 제거하세요.
새 음성이 나타나지 않음언어 팩을 추가한 뒤 브라우저를 재시작하세요.
Safari가 읽지 않음Safari는 자동 TTS가 제한적입니다. 페이지를 한 번 클릭해 오디오를 허용하세요.

사용 습관

  • 페이지에서 재생하는 제공자를 쓰세요. 가장 쉬운 OBS 설정이며 무료 선택지도 있습니다.
  • 방송 전에 짧은 메시지로 시험하세요.
  • 시청자는 무엇이든 입력할 수 있습니다. TTS를 빠르게 끌 수 있게 준비하세요.
