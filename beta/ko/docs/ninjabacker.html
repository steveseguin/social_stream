Social Stream Ninja에서 NinjaBacker 팁 받기

SSN에서 팁을 받고 OBS에 알림이나 Tip Jar를 추가하세요.

실시간 피드웹훅OBS 표시테스트 및 문제 해결

1. 계정 연결

SSN 데스크톱 앱이나 Chrome 확장 프로그램에서 시작하세요. 방송 중에는 SSN을 켜 두세요.

  1. NinjaBacker 열기. 계정을 만들고 Stripe 설정을 완료하여 결제를 받으세요.
  2. NinjaBacker 대시보드에서 Social Stream Ninja를 열고 Private Tip ID를 복사하세요.
  3. SSN에서 수익 > 상점 및 지원 > 연결된 플랫폼 > NinjaBacker 후원 > 설정을 여세요. 사용자 이름과 비공개 Tip ID를 입력하세요.
  4. 전송을 실시간 피드(간단)로 두고 NinjaBacker 후원을 켠 뒤 설정 저장을 클릭하세요.

연결된 플랫폼이 숨겨져 있으면 SSN에서 전체 모드로 전환하세요.

실시간 피드에는 웹훅이 필요 없습니다. 연결 중 새 팁을 표시하며 SSN이 꺼져 있을 때 받은 팁은 다시 표시하지 않습니다.

2. 선택 사항: 웹훅 사용

SSN이 꺼져 있을 때 팁을 최대 7일간 대기열에 보관하려면 안정적인 웹훅을 선택하세요.

  1. NinjaBacker에서 Webhook을 여세요. Webhook Signature Secret에서 Generate를 클릭하고 비밀 키를 복사하세요. 이미 키를 사용 중이면 기존 키를 복사하세요.
  2. SSN의 NinjaBacker 설정에서 안정적인 웹훅을 선택하고 서명 비밀 키를 붙여넣은 뒤 설정 저장을 클릭하세요.
  3. SSN에서 수신 URL 복사를 클릭하세요. NinjaBacker의 Webhook URL 필드에 붙여넣고 Save를 클릭하세요.

수신 URL은 다음으로 시작합니다:

https://api.socialstream.ninja/v1/ninjabacker/webhook/...

Tip Jar, 채팅 도크 등 화면 URL은 OBS에 사용합니다. 웹훅 요청을 받을 수 없습니다.

실시간 피드로 돌아가기

전환하면 SSN 수신기의 대기 중인 팁이 삭제됩니다. NinjaBacker의 기존 Webhook URL도 비우고 저장하세요.

3. OBS에 화면 추가

  1. 알림을 표시하려면 상점 및 지원의 OBS 오버레이 대상에서 NinjaBacker 후원을 선택하세요. 오버레이 링크를 복사하세요.
  2. 누적 목표를 표시하려면 수익 > Tip Jar 및 목표 미터를 여세요. 스타일과 목표를 선택한 다음 링크를 복사하세요.
  3. OBS에 브라우저 소스를 추가하고 화면 링크를 붙여넣으세요. SSN과 화면은 같은 세션을 사용해야 합니다.

Tip Jar 스타일 및 목표 설정

공개 NinjaBacker 팁 페이지를 시청자와 공유하세요. 오버레이 링크는 OBS에, 수신 URL은 웹훅 필드에 넣으세요.

4. 설정 확인

SSN의 NinjaBacker 알림 오버레이를 여세요. NinjaBacker에서 Testing을 열고 Send Test Tip을 클릭하세요. 해당 오버레이에 테스트 알림이 표시되어야 합니다.

Send Test Tip 아래의 결과를 확인하세요. Webhook accepted는 요청 수신을 확인하며 OBS 알림 표시를 의미하지는 않습니다. 실패하면 URL 또는 서명 비밀 키를 수정하고 새 테스트를 보내세요. 대시보드 테스트는 5분 동안 재시도됩니다.

테스트 팁은 Tip Jar에 금액을 더하지 않고, 채팅에 유료 후원으로 표시되지 않으며, 유료 보상을 실행하지 않습니다.

테스트 알림이 없나요?

SSN을 켜고 NinjaBacker 후원을 활성화하세요. 사용자 이름과 Tip ID가 같은 계정인지 확인하세요. 웹훅은 NinjaBacker에서 Delivery History를 새로고침하고 수신 URL과 서명 비밀 키를 확인하세요.

HTTP 405 또는 화면 URL 오류인가요?

SSN의 안정적인 웹훅 설정에서 수신 URL을 복사해 NinjaBacker에 저장한 뒤 새 테스트 팁을 보내세요. 새 URL을 저장하면 이전 주소로의 재시도가 중단됩니다.

채팅에는 팁이 보이는데 목표에 반영되지 않나요?

Tip Jar 세션과 소스, 후원 유형, 유료 이벤트 필터를 확인하세요. 팁 금액에는 금액 목표를 사용하세요. 환불은 SSN 알림이나 목표에서 차감되지 않습니다.
