오버레이로 채팅 가져오기

Lite는 브라우저나 OBS에서 지원되는 채팅 소스를 연결합니다. 일반 오버레이 링크를 사용할 때는 Lite를 탭이나 OBS 도크에서 계속 실행하세요. 실험적인 OBS 독립 실행 모드는 하나의 브라우저 소스에서 채팅을 캡처하고 표시합니다.

설정 · OBS 전용 구성 · 소스 · 기존 구성 · 문제 해결

1. 오버레이 설정

  1. Lite를 여세요. 세션 ID와 오버레이 URL이 자동으로 생성되어 이 브라우저에 저장됩니다.
  2. 아래 소스 중 하나를 연결하세요. 해당 소스의 옵션 버튼으로 채널을 설정하세요.
  3. 선택: 링크 복사 (Copy link). OBS에서 다음을 추가하세요: 브라우저 소스를 추가하고 URL 입력란에 링크를 붙여 넣으세요. 다음 기능도 사용할 수 있습니다: 도크 오버레이 열기 (Open dock overlay) 로 브라우저에서 확인하세요.
  4. 선택: 테스트 메시지 보내기 (Send test message) 를 Lite에서 클릭하세요. 열린 오버레이에 표시되는지 확인하세요. Lite 활동 피드에 메시지가 보이는 것만으로는 오버레이 수신을 확인할 수 없습니다.

투명한 오버레이나 다른 메시지 순서를 사용하려면 다음 옆의 옵션을 여세요: 채팅 오버레이 링크 (Chat Overlay Link)을 설정하세요. 옵션을 바꾼 뒤 업데이트된 URL을 OBS에 복사하세요.

2. 소스 선택

OBS만 사용하는 구성에서는 아래 두 방식 중 하나를 선택하세요. OBS에서 캡처하면 별도의 데스크톱 브라우저 탭이 필요하지 않습니다.

소스할 일
YouTubeYouTube로 로그인하세요. Lite가 본인의 라이브 방송을 찾습니다. Options에서 Video ID 또는 Live Chat ID를 입력하여 특정 방송을 지정할 수 있습니다. 폴링이 기본값이며 선택적인 스트리밍 API에는 베타 표시가 있습니다. 방송에서 라이브 채팅을 사용할 수 있어야 합니다.
TwitchTwitch로 로그인하세요. Lite는 기본적으로 본인의 채널을 사용합니다. 다른 채널은 Options에서 지정하세요. 인증이 만료되면 다시 로그인하세요.
KickOptions에 채널 이름을 입력하고 연결하세요. 자동 조회가 실패하면 채널 철자를 확인하고 필요할 경우 수동 채팅방 설정을 사용하세요.
TikTok현재 이 연동은 기본 Lite 패널에서 숨겨져 있습니다. 호환되는 TikTok Chat Reader 프록시가 필요하며 미리 입력된 주소가 서비스 가용성을 보장하지 않습니다. 사용할 수 있는 TikTok 캡처 옵션은 전체 앱에서 확인하세요.

연결 해제 은 해당 소스를 중지합니다. YouTube와 Twitch는 로그인 상태를 유지하므로 다음을 사용할 수 있습니다: 연결 (Connect) . 로그아웃 (Sign out) 은 이 브라우저에 저장된 인증 정보를 제거합니다.

3. 기존 Social Stream 구성 사용

기존 도크나 오버레이로 보내려면 Lite의 세션 옵션을 열고 해당 세션 ID를 입력하세요. 선택할 항목: 세션 ID 저장 (Save session ID) 를 누르거나 Enter를 누르세요. ID를 바꾸면 Lite의 메시지 전송 대상이 바뀝니다. 함께 변경되어야 할 브라우저 소스 URL도 업데이트하세요.

같은 세션에서 채널마다 하나의 캡처 방식만 사용하세요. Lite와 함께 같은 채팅을 확장 프로그램이나 데스크톱에서 캡처하면 중복될 수 있습니다. 한 채널은 Lite로, 다른 소스는 전체 앱으로 사용할 수 있습니다.

Lite가 생성하는 링크는 기본 세션 비밀번호를 사용합니다. 비밀번호로 보호되거나 사용자 지정 서버를 사용하는 구성에는 전체 앱의 연결 컨트롤이 필요할 수 있습니다. Lite는 전체 앱의 캡처, 자동화, 관리, 오버레이 사용자 지정 기능을 대체하지 않습니다.

활동 화면의 후원만 그리고 텍스트 음성 변환 컨트롤은 Lite 활동 화면에 적용됩니다. 활동 팝아웃을 사용할 때는 메인 Lite 페이지를 열어 두세요. 다른 사람이 세션에 참여하는 것을 원하지 않으면 오버레이 URL을 비공개로 유지하세요.

OBS 안에서 모두 실행

옵션 A: Lite 도크 + 일반 오버레이

  1. 열기 OBS 안에서 모두 실행 를 Lite에서 선택하고 다음을 복사하세요: OBS 사용자 지정 도크 URL (lite/index.html?view=dock).
  2. OBS에서 추가할 위치: 사용자 지정 브라우저 도크 (Custom Browser Docks)에 추가하세요. 해당 도크에서 로그인하고 소스를 설정하세요. 소스 옵션과 세션 설정도 그곳에서 계속 사용할 수 있습니다.
  3. 도크의 일반 오버레이 URL을 OBS 브라우저 소스에 복사하세요. 캡처 중에는 Lite 도크를 열어 두세요. 소스는 메시지만 표시하므로 자체 제공업체 로그인이 필요하지 않습니다.

가장 간단한 OBS 전용 방식입니다. 도크가 캡처하고 브라우저 소스가 표시합니다. 도크를 닫으면 캡처가 중지됩니다. 설정이 끝나면 데스크톱 브라우저는 필요하지 않습니다.

옵션 B: 캡처와 오버레이를 합친 브라우저 소스 하나 (실험적)

  1. 추가할 항목: 독립 캡처 + 오버레이 URL (Standalone capture + overlay URL) (lite/index.html?view=overlay)를 OBS 브라우저 소스로 추가하세요.
  2. 열기 상호 작용 (Interact) 로 소스를 설정하세요. 이미 설정했다면 다음을 누르세요: Escape 를 Interact에서 누르면 설정을 다시 엽니다. 로그인 페이지와 설정 컨트롤이 이 소스에 표시되므로 방송에 나오지 않을 때 설정하세요.
  3. 선택: 오버레이 표시 (Show overlay)를 선택하세요. 이제 페이지가 자체 수신 채팅을 투명 배경에 표시합니다. 다른 Lite 탭, 도크, 릴레이 연결이 필요하지 않으며 다른 세션 오버레이로 메시지를 보내지 않습니다.
  4. 유지: 보이지 않을 때 소스 종료 (Shutdown source when not visible) 그리고 장면이 활성화되면 브라우저 소스 새로고침 을 꺼서 장면 변경 시 캡처가 중단되지 않게 하세요. 참고: OBS 브라우저 소스 속성.

저장된 유효한 YouTube/Twitch 인증 정보는 시작 시 다시 연결됩니다. Kick에서는 다음을 켜세요: OBS 모드에서 이 Kick 채널 자동 재연결 를 Options에서 켜세요. 먼저 채널을 설정하세요. TikTok은 계속 숨겨집니다. 레이아웃은 일반 활동 화면의 저장된 설정과 별개로 모든 메시지를 표시하고 음성은 끈 상태로 시작합니다.

OBS 도크, OBS 브라우저 소스, 데스크톱 브라우저는 서로 다른 쿠키/저장소 프로필을 사용할 수 있습니다. 도크에서 설정했다고 별도의 브라우저 소스도 로그인되었다고 가정하지 마세요. OBS 브라우저 소스 안에서 로그인을 완료할 수 없다면 옵션 A를 사용하세요. OBS 내 제공업체 인증은 실제 환경 검증이 더 필요하며 이 모드는 실험적입니다.

채널마다 캡처 위치를 하나만 사용하세요. 독립 캡처/오버레이 소스와 같은 채널을 도크에서도 캡처하지 마세요. 여러 장면에서 같은 캡처 소스를 재사용할 때는 OBS의 기존 소스 옵션을 사용하세요.

문제 해결

오버레이가 비어 있음
Lite가 계속 열려 있고 오버레이가 같은 세션 ID를 사용하는지 확인하세요. 테스트 메시지를 보내세요. 테스트는 도착하지만 실제 채팅은 도착하지 않으면 소스 상태와 채널을 확인하세요. 둘 다 도착하지 않으면 오버레이 URL과 네트워크의 릴레이 연결 차단 여부를 확인하세요.
링크 복사가 차단됨
표시된 오버레이 URL을 클릭한 뒤 키보드나 기기의 복사 메뉴로 선택된 텍스트를 복사하세요.
소스가 대기 중이거나 오류를 표시함
옵션과 오류 문구를 확인하세요. 설정을 수정한 뒤 다시 연결하세요. YouTube와 Twitch 인증이 만료되었다면 다시 로그인해야 할 수 있습니다.
메시지가 중복됨
같은 채널과 세션을 캡처하는 다른 Lite 탭, 확장 프로그램, 데스크톱 캡처가 있는지 확인하세요. 의도한 캡처만 실행해 두세요.
설정이 사라짐
설정은 이 브라우저의 로컬 저장소에 보관됩니다. 다른 브라우저, 비공개 창 또는 사이트 데이터를 지운 환경에서는 다른 설정을 사용합니다.
