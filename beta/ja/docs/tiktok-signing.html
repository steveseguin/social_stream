TikTokの署名

署名サーバーの役割、失敗することがある理由、再接続する方法を説明します。

TikTokの署名とは？「Sign Server Unavailable」（署名サーバーを利用できません）自分のEuler APIキーを追加する署名サーバーを使わないモードTikTokへ返信する関連情報

TikTokの署名とは？

TikTokでは、ライブチャットフィードへの接続リクエストに暗号学的な署名が必要です。デスクトップアプリは、次が運営する第三者の署名サービスを通じて署名します： Euler Stream。通常の使用にアカウントやAPIキーは不要です。アプリがEulerの無料枠を自動的に使用します。

このサービスはアプリとTikTokの間にあるため、自分の環境に問題がなくてもTikTokソースが止まることがあります。署名サーバーの停止、レート制限、TikTok側の変更による一時的な不具合などが原因になります。

「Sign Server Unavailable」（署名サーバーを利用できません）

このステータスは、アプリが署名サービスから有効な署名を取得できなかったことを意味します。よくある原因：

  • レート制限。 無料枠はIPアドレスごとに制限されます（毎分数接続で、時間単位と日単位の上限もあります。参照： Eulerのレート制限）。ソースの削除と再追加を繰り返したり、短時間にモードを切り替えたりすると、割り当てを使い切り、エラーが続きます。
  • 署名サーバーの障害。 Eulerは時々停止したり過負荷になったりします。通常は数時間以内に解消し、自分の設定を変更する必要はありません。
  • TikTokの変更。 TikTokがライブ配信の基盤を更新すると、Eulerが修正するまで全ユーザーの署名が動作しなくなる場合があります。

順番に試すこと：

  • After an Euler connection fails, the desktop app checks TikTok directly without using Euler quota. If it cannot reconnect, Euler mode pauses; Auto tries the available non-Euler methods instead.
  • When Euler retries are paused, activate the source to try again. If you reached an Euler rate limit, wait for that limit to reset first.
  • アプリが最新版か確認してください。TikTok向けの修正は頻繁に提供されています。
  • TikTokソースを次へ切り替えます： 標準（Standard） モード（ページ取得）を安定した一時的な代替手段として使えます。ライブページを直接読み込み、署名サーバーを一切使いません。
  • 頻繁にレート制限にかかる場合は、自分の無料Euler APIキーを追加してください（下記参照）。

自分のEuler APIキーを追加する

自分のキーを使うと、匿名ユーザー向けのIP単位の枠を共有する代わりに、専用の割り当てを利用できます。

  • 次で無料のアカウントとキーを作成します： Euler Streamダッシュボード.
  • デスクトップアプリでTikTokソースを編集し、接続プリセットの選択欄を開きます。
  • 選ぶ項目： Euler Signing（Advanced） を選び、APIキーを貼り付けます。 Euler Proxy（API Key） も動作しますが、返信の送信には対応していません。
  • 保存後にソースを1回だけ再接続します。

署名サーバーを使わないモード

モード仕組み考慮する点
標準（Standard）TikTokライブページを読み込み、そこからチャットを取得します。署名サービスは使用しません。ライブページを開いたままにする必要があり、TikTokのログインや確認操作を求められる場合があります。
ローカル署名（Local Signer）Eulerの代わりに、軽量なTikTokウィンドウでリクエストにローカル署名します。アプリ内でTikTokにログインすると最も安定します。匿名モードでは一部のチャットを取得できない場合があります。

互換モード（WebSocket）（旧称： ポーリング（Polling） ）は、現在のデスクトップアプリでは署名付きWebSocketを使用します。署名なしのHTTPポーリングは提供せず、返信もできません。Eulerの署名を使うため、そのサービスの障害や制限の影響も受けます。

TikTokへ返信する

ドックからTikTokへチャットメッセージを送るには、デスクトップアプリ内でTikTokアカウントにログインする必要があります。アプリがあなたとして投稿するためにTikTokセッションを使います。ログインしていない場合やTikTok接続が切れている場合、送信メッセージは他のプラットフォームにしか届きません。

Euler Proxyモードは、ログイン状態に関係なく返信に対応していません。
