よくある問題への短い回答です。手順全体が必要な場合は、ガイドを参照してください。

OBSオーバーレイが空

まずドックを確認してください。ドックが空なら、ソース／プラットフォームを直します。ドックが動くなら、同じオーバーレイURLを通常のブラウザーで開き、次が一致することを確認します： sessionを確認し、OBSのブラウザーソースを再読み込みします。

OBSのトラブルシューティングを開く

セッションが違う

ソース、ドック、オーバーレイ、Bot、Event Flowの各ページでは、同じセッションIDを使用する必要があります。セッションIDは部屋の名前のようなもので、綴りが違えば別の部屋になります。

dock.html?session=YOUR_SESSION

セッション、パスワード、リレーモードを開く

設定を失わずに更新する

先に設定を書き出し、通常の更新で拡張機能をアンインストールしないでください。Cookieとログインも移す必要がある場合は、デスクトップアプリの暗号化された完全なセッション転送を使用します。

安全な更新、バックアップ、復元を開く

OBSにTTSの音が入らない

通常のシステムTTSは、コンピューターからは聞こえても、OBSのブラウザーソースには入らないことがあります。Kokoro、Piper、Kitten、eSpeak、OpenAI互換、クラウドプロバイダーなど、プロバイダー／ブラウザーのTTSモードを使うか、システム音声を別途取り込んでください。

TTS設定ガイドを開く

Kokoroがポルトガル語やスペイン語を話さない

組み込みのKokoro音声は英語の音声です。ポルトガル語ではPiperで次を使用します： pipervoice=pt_BR-faber-medium、またはeSpeakで次を使用します： espeakvoice=pt-br。スペイン語ではPiperで次を使用します： pipervoice=es_ES-davefx-medium、またはeSpeakで次を使用します： espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

TTSプロバイダーの設定を開く

Chromeでは動くがデスクトップアプリでは動かない

デスクトップアプリは、通常のChromeプロファイルではなく、Electronのセッションを使用します。アプリのソースウィンドウ内でサインインしてください。プラットフォームが埋め込み／アプリのブラウザーをブロックする場合は、Chrome拡張機能の経路を使用します。

単体アプリのモードを開く

どのローカルサーバーが必要ですか？

ローカルサーバーを有効化（Enable Local Server） は、対応するSSNページ用のWebSocketリレーです。 ローカル制御API は、同じマシン上のスクリプトとAIツール向けです。ヘッドレスホスティングは、Linuxサーバー上で完全なデスクトップアプリを動かします。Event Flowのメディアサーバーは、承認されたローカルメディアだけを配信します。

ローカルサーバーとサービスの説明を開く

TikTokが失敗する、またはモードが変わる

アプリのモード、署名プロバイダー、状態テキスト、アプリのバージョン、Standardモードでチャットが見えるかを記録してください。TikTokのモードは1つずつテストします。

TikTokのアプリモードを開く

YouTubeのチャットが届かない

配信がライブで、ライブチャットが表示され、YouTubeの正しい経路（ライブチャット、静的コメント、標準キャプチャ、WebSocket／APIモード）を使用していることを確認してください。

YouTube設定ガイドを開く

Botの返信が送信されない

チャットを読み取れることと、投稿できることは別です。プラットフォームの返信対応、アカウントのログインと役割、ソースモード、プロバイダーの応答、レート制限を確認してください。

AIチャットボット設定ガイドを開く

Event Flowが動かない

ソースのイベントがドックに届くことを確認してください。音声、メディア、OBSのアクションには、次を開いたままにします： actions.html?session=YOUR_SESSION を同じセッションで開いておいてください。

Event Flowレシピを開く
