概要

SSNは、対応するどのソースから取得したチャットテキストでも読み上げられます。チャットプラットフォーム独自のTTS機能は不要です。 TTSを有効にしたドックやオーバーレイは、フィルターとTTS設定に従って受信メッセージを読み上げます。まず次をご覧ください： 簡単な設定ガイド。このページでは音声の選択肢と詳細設定を説明します。 プロバイダーを比較し、サンプルを聞いて、設定を確認します。

クイックスタート： 使う項目： dock.html?session=YOUR_SESSION&speech=en-US。標準ではSystem TTSを使います。OBSで無料のプロバイダーを使うには、次も追加します： &ttsprovider=kokoro。このページを開き、接続したままにしてください。読み上げる画面は1つだけにします。

TTSが使われる場所

  • Social Stream Ninja： 複数の場所で視聴者のチャットメッセージを読み上げます
  • CAPTION.Ninja： 字幕、文字起こし、翻訳とTTSを提供します
  • 両サービスに無料と有料のTTSオプションがあります
無料のTTSがすべてSystem TTSというわけではありません：
  • システム音声はブラウザとOSによって異なります。Chrome/Edgeで動いても、OBSでは使える音声がない場合があります。
  • 音声が生成されない問題と、OBSの音声取得範囲外で再生されている問題は別です。音声経路を変えても、読み上げ自体が未対応の問題は解決しません。
  • Kokoro、Piper、Kitten、eSpeakなどの無料プロバイダーは、ページ内の音声を生成します。OBSでのTTSに支払いは必須ではありません。
  • まず音声の利用可否を確認し、その後音声取得を確認してください。

TTSプロバイダーの選択肢

System TTS（無料）

  • OS組み込みの音声を使います
  • インストール済みのシステム言語に応じて対応が制限されます
  • 音声の利用可否と音声経路はブラウザとOSによって異なります。実際に再生する環境でテストしてください
  • 互換性はブラウザによって大きく異なります

ローカル / 無料TTSの選択肢（APIキー不要）

完全にローカルなAI TTSを使いたい場合 高品質なAI音声がいくつかSocial Stream Ninjaに組み込まれ、ブラウザ内で動作します。APIキー、クラウド、追加インストールは不要です。参照： ローカルAI読み上げガイド で設定手順と自分でホストするサーバーの選択肢を確認してください。

システム音声の利用可否

これは一般的な対応状況で、すべての環境での保証ではありません。OBSは独自の内蔵ブラウザを使い、インストール済みのChrome/Edgeの音声一覧を引き継ぎません。SSNアプリでのテストが成功しても、別のOBSブラウザソースをテストしたことにはなりません。

ブラウザの制限：
  • TTSへの対応はブラウザごとに異なります（一部のFirefoxでは音声の種類が限られます）
  • ChromeではGoogleのTTS音声を利用できます
  • EdgeはMicrosoft TTSとWindows言語パックの音声に対応します
  • Safariでは、音声の開始にユーザー操作が必要です
  • 確認する項目： 利用可能な音声 （使用中のブラウザー）

OBS用Windows TTS音声の取得方法

ページ内音声：無料ローカルプロバイダーとクラウドプロバイダー

SSNのブラウザ内ローカルプロバイダーとクラウド音声プロバイダーは、生成した音声をページ内で再生します：

  • ブラウザソースで「OBSを介して音声を制御する」を有効にするだけです
  • 仮想オーディオケーブルは不要です
  • SSNアプリとOBSブラウザソースで動作します

System TTSの取得方法

重要： まずSystem TTSが音声を生成することを確認してください。OBS内蔵ブラウザでは、利用可能なシステム音声が提供されない場合があります。音声が生成されないなら、音声経路を変えても解決しません。別のプロバイダーを選ぶか、対応ブラウザで読み上げ、そのブラウザの音声を取得してください。

System TTSの場合：

  • OBSでChromeやEdgeと同じ音声を利用できるとは限りません
  • ブラウザによって対応に制限があります（Firefoxでは一部のTTS音声がない場合があります）
  • ChromeにはGoogleの音声、EdgeにはMicrosoftの音声があります
  • シーンのブラウザソース外で音声が再生される場合は、その出力を別途取得してください

音声経路用ツールのダウンロード： VB-Audio Virtual Cable | Voicemeeter | Audio Router（旧版）

対応している環境では、まずOBSのアプリケーション音声またはデスクトップ音声で、読み上げているブラウザを取得してみてください。下の仮想ケーブル方式は任意の代替手段であり、OBSに読み上げ機能を追加するものではありません。

方法1：仮想ケーブルを使う既定の音声経路

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

方法2：Windows 10のアプリ別経路

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

方法3：Windows 11のアプリ別経路

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

方法4：Audio Routerソフトウェア

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

方法5：Voicemeeter（高度な設定）

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

設定をテストする

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
代替手段： Kokoro、Piper、Kitten、eSpeakなどの無料の組み込みプロバイダー、クラウドプロバイダー、自分でホストするTTSサーバーを使えます。

追加の言語パックをインストールする

Windows 11

  1. 次を開きます： スタート > 設定 > 時刻と言語 > 音声認識
  2. 次のセクションで： 音声を管理（Manage Voices）で、次をクリックします： 音声を追加（Add Voices）
  3. 希望する言語を選び、次をクリックします： 追加する項目：
  4. 利用可能な音声を更新するにはブラウザを再起動してください

Windows 10

次の資料の手順に従ってください： Microsoftの公式ガイド で言語パックのインストール方法を確認してください。

ヒント： 互換性の問題で、第三者の音声の一部がブラウザに表示されないことがあります。FirefoxはChromium系ブラウザより多くのシステム音声を表示することがよくあります。

TTS設定用のURLパラメータ

基本パラメータ

パラメーター 説明 例
&speech 言語コードを指定してTTSを有効にする &speech=en-US
&pitch 音声のピッチ（0.1〜2.0） &pitch=1.2
&volume 音量（0.0〜1.0） &volume=0.8
&rate 発話速度（0.1〜10.0） &rate=1.5
&voice 音声名の部分一致 &voice=google
&ttsprovider プロバイダーを選択：kokoro、piper、kitten、espeak、openai、customtts、localtts、elevenlabs、google、speechify、gemini &ttsprovider=customtts

詳細パラメータ

パラメーター 説明
&simpletts 「says」や「someone says」を読まない
&simpletts2 チャット名を一切読み上げない
&ttscommand カスタムTTSコマンドを有効にする（標準：!say）
&readevents TTSに配信イベントを含める
&skipmessages=3 3件に1件だけ読み上げる

TTSプロバイダーの設定

Kokoro TTS（無料、組み込み）

  • 次で有効にします： ?ttsprovider=kokoro
  • WebGPU/WASMでブラウザ内実行。サーバーは不要です
  • OBSブラウザソースで直接動作します
  • 音声の選択： &voicekokoro=af_bella
  • 速度の調整： &kokorospeed=1.2
  • 言語に合う音声を選んでください： &voicekokoro=ef_dora をスペイン語、または &voicekokoro=pf_dora をブラジルポルトガル語に使います。次を変更する &speech= だけを変えても、選択した音声は変わりません。既存の英語音声IDは引き続き使えます。

Piper TTS（無料、組み込み）

  • 次で有効にします： ?ttsprovider=piper
  • ブラウザ内で動作する、高速でCPU負荷の低いニューラルTTS
  • 音声の選択： &pipervoice=en_US-hfc_female-medium
  • ポルトガル語の音声： &pipervoice=pt_BR-faber-medium または &pipervoice=pt_BR-edresson-low
  • スペイン語の音声： &pipervoice=es_ES-davefx-medium または &pipervoice=es_MX-ald-medium
  • 速度の調整： &piperspeed=1.0

Kitten TTS（無料、組み込み）

  • 次で有効にします： ?ttsprovider=kitten
  • ブラウザ内で動作する軽量ONNXベースのTTS
  • 音声の選択： &kittenvoice=expr-voice-4-f

eSpeak-NG（無料、組み込み）

  • 次で有効にします： ?ttsprovider=espeak
  • 従来型のオープンソースTTS。どのハードウェアでも動作します
  • 音声の選択： &espeakvoice=en
  • ポルトガル語の例： &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • スペイン語の例： &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • 速度の調整： &espeakspeed=175

ポルトガル語とスペイン語のTTSの例

  • ポルトガル語：SSNで試した無料ローカル音声の中で最も高品質： ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • ポルトガル語：SSNで試した最速の代替手段： ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • スペイン語：SSNで試した無料ローカル音声の中で最も高品質： ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • スペイン語：SSNで試した最速の代替手段： ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • クラウド音声は、Google Cloud、ElevenLabs、Speechify、Gemini、OpenAI互換ローカルサーバーなどで、対象言語に対応した音声/言語を使用してください。

OpenAI / ローカルサーバーTTS

  • 次で有効にします： ?ttsprovider=openai
  • 使う項目： ?ttsprovider=customtts または ?ttsprovider=localtts を、自分でホストするエンドポイントに使います
  • 標準ではOpenAI APIを使い、互換性のあるローカルサーバーも使用できます
  • カスタムエンドポイント： &openaiendpoint=http://localhost:8880/v1/audio/speech
  • 重要： localhost および 127.0.0.1 はTTSページを再生するコンピューター自身を指します。OBSとTTSサーバーが別のコンピューターにある場合は、代わりにサーバー側のLAN IPを使ってください。
  • ローカルサーバーにはAPIキー不要
  • Chrome/OBSでローカルサーバーへのCORSやローカルネットワークの問題がある場合は、次を実行します： npm run local-tts-bridge をOBSのコンピューターで実行し、SSNの接続先を次にします： http://127.0.0.1:8124/v1/audio/speech
  • SSNは次を送信します： { model, input, voice, response_format, speed } 。バイナリ音声、JSONの音声URL、JSONのbase64音声に対応します
  • 現在、カスタム/ローカルエンドポイントの再生はバッファリング方式です。SSNはまだストリーミング音声の断片を順次再生しません
  • 音声： &voiceopenai=af_bella、速度： &openaispeed=1.0。サーバーが対応する音声名を使ってください。Kokoroの音声名の例： af_bella、openedai-speech/OpenAI形式の音声は次のような名前です： nova または echo.
  • 参照先： ローカルAI読み上げガイド で自分でホストするサーバーの設定を確認してください

Google Cloud TTS

  • 次で有効にします： ?ttsprovider=google&ttskey=YOUR_API_KEY
  • プロ品質の音声
  • 音声の選択： &voicegoogle=en-GB-Standard-A
  • 言語： &googlelang=en-US

Gemini TTS

  • 次で有効にします： ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • モデル： &geminimodel=gemini-2.5-flash-preview-tts
  • 音声： &voicegemini=Kore、言語： &geminilang=th-TH
  • スタイルの指示： &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • 次で有効にします： ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • 音声ID： &voice11=YOUR_VOICE_ID
  • モデル： &elevenlabsmodel=eleven_multilingual_v2
  • 調整可能なパラメータ：安定性、類似度、スタイル

Fish Audio TTS

Fish Audioを選び、APIキーと任意の音声IDを入力します。標準モデルは s2.1-pro-free. 設定、モデルの選択肢、ブラウザアクセスの制限.

Speechify TTS

  • 次で有効にします： ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • 音声： &voicespeechify=henry
  • モデル： &speechifymodel=simba-3.0 （標準）、または &speechifymodel=simba-3.2 を英語に使います。
  • 発話速度： &speechifyspeed=1.2 （範囲は0.5〜3.0、通常は1.0）。
  • Speechifyの設定、音声、速度、音量のガイド

トラブル対処

よくある問題

  • 音声が再生されない： TTSが有効で、音声を生成するページが開いており、ブラウザソースがミュートされていないことを確認してください。通常のブラウザではページを一度クリックします。
  • 音声が表示されない： 言語パックのインストール後はブラウザを再起動してください
  • OBSで取得できない： 音声が出ない場合は、まず音声/プロバイダーが使えるか確認してください。音声が出ている場合は、次を確認します： OBSで音声を制御する（Control audio via OBS）、ミキサーのミュート、出力トラックを確認するか、読み上げている外部ブラウザの音声を取得してください
  • ローカルエンドポイントがアプリのテストでは動くのにOBSでは動かない： OBSは独立したブラウザです。特に次を使用する場合は、OBSのコンピューターからエンドポイントを確認してください： 127.0.0.1.
  • 最初の1文字または数語しか読まれない： 削除する値： ttsquick がOBS URLに含まれている場合は削除してください。
  • Safariの問題： Safariの自動TTS対応には制限があります
  • 有料サービスが動かない： APIキーと、正しいプロバイダーが指定されていることを確認してください

利用のコツ

  • OBSを簡単に設定するには、ページ内音声を生成するプロバイダーを使ってください。無料のローカルプロバイダーもあります
  • ライブ配信の前に、簡単な文で設定をテストしてください
  • ユーザーが投稿した内容をTTSで読み上げるリスクを考慮してください
  • 必要なときにTTSをすぐ無効にできるスイッチを用意してください

このブラウザのシステム音声を確認

表示するのは、 このガイドを表示しているブラウザのSystem TTS音声のみ。OBS、別のSSNアプリウィンドウ、Kokoroなどのプロバイダーはテストしません。一覧が空でも、SSNの他のTTSプロバイダーが使えないという意味ではありません。
