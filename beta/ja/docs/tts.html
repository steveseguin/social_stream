TTS音声ガイド

TTSの全設定をまとめたページです。プロバイダー、リンク設定、システム音声、OBS音声を説明します。

ここから開始

初めてTTSを使う場合 次の手順に従ってください： TTS設定ガイド。5手順で設定できます。このページは全項目のリファレンスです。

SSNがテキストとして取得したチャットを読みます。プラットフォーム独自のTTSは不要です。TTSを有効にしたDockやオーバーレイが、そのフィルターに従って読み上げます。

最も簡単なリンクでシステム音声のTTSを有効にできます：

dock.html?session=YOUR_SESSION&speech=en-US

OBSには、ページから再生する無料音声を追加します：

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper

ページを開いて接続したままにします。読み上げるページは1つだけにしてください。

System TTSと無料TTSは同じ意味ではありません。 システム音声はブラウザーやコンピューターから提供されます。Chromeでは動いてもOBSにはないことがあります。Kokoro、Piper、Kitten、eSpeakは無料で独自に音声を作るためOBSで動きます。OBSでTTSを使うために料金を払う必要はありません。

TTSは次にもあります： CAPTION.Ninjaにもあり、字幕、文字起こし、翻訳に使えます。どちらも無料と有料の音声を提供します。

リンク設定

Dockやオーバーレイのリンクの末尾に追加します。

設定動作例
&speech言語コードを指定してTTSを有効にします。&speech=en-US
&ttsproviderプロバイダーを選択します（上記参照）。&ttsprovider=kokoro
&volume音量、0.0～1.0。&volume=0.8
&rate読み上げ速度、0.1～10.0。&rate=1.5
&pitch音声のピッチ、0.1～2.0。&pitch=1.2
&voiceシステム音声を名前の一部で選択します。&voice=google
&simpletts「says」「someone says」を読み上げません。&simpletts
&simpletts2名前を一切読み上げません。&simpletts2
&ttscommandコマンドで始まるメッセージだけ読みます（標準は !say).&ttscommand=!say
&readeventsサブスクや寄付などのイベントも読み上げます。&readevents
&skipmessagesN件ごとに1件だけ読み上げます。&skipmessages=3
&ttsquick指定文字数で読み上げを打ち切ります。途中で切れるなら削除してください。&ttsquick=100

システム音声

System TTSはブラウザーやコンピューターにある音声を使います。以下は一般例であり保証ではありません。

ブラウザシステム音声
Chrome対応。Google音声とシステム音声。
Edge対応。Microsoft音声とWindows言語パック。
Firefox制限あり。ローカルのシステム音声のみ。
Opera制限あり。インストール環境によります。
Safari音声再生前にクリックが必要です。
OBS独自のブラウザーです。ChromeやEdgeの音声は引き継ぎません。SSNアプリのテストではOBSの動作は確認できません。

このブラウザーのシステム音声を確認。開いたブラウザーのSystem TTS音声だけを一覧にします。OBSやKokoroなどはテストしません。一覧が空でも、ほかのプロバイダーが使えないという意味ではありません。

Windowsに音声を追加する

  1. 開く項目： スタート > 設定 > 時刻と言語 > 音声認識.
  2. 次のセクションで： 音声を管理（Manage Voices）で、次をクリックします： 音声を追加（Add Voices）.
  3. 言語を選び、次をクリックします： 追加する項目：.
  4. ブラウザーを再起動します。

これはWindows 11の手順です。Windows 10の場合： Microsoftのガイド。一部の外部音声はブラウザーに表示されません。FirefoxはChromium系より多くのシステム音声を表示することがあります。

System TTSをOBSに取り込む

ほかのプロバイダーを使う場合 これは不要です。次を有効にします： OBSで音声を制御する（Control audio via OBS） をブラウザーソースで有効にします。仮想ケーブルは不要です。
  1. まずSystem TTSが実際に読み上げるか確認します。OBSには使える音声がない場合があり、音が生成されなければ出力経路を変えても直りません。別のプロバイダーを使ってください。
  2. 別のブラウザーで音が出るなら、OBSのアプリケーション音声またはデスクトップ音声で取り込みます。
  3. まだ解決しない場合は、下記の仮想オーディオケーブル経由でブラウザーの音を送ります。
仮想ケーブル経由で音声を送る（Windows）

ダウンロード： VB-Audio Virtual Cable （無料）・ Voicemeeter · Audio Router（旧版）

方法操作
PC全体設定する項目： CABLE Input をWindowsの標準出力先にします（サウンド設定 > 出力）。
1つのアプリ、Windows 11設定 > システム > サウンド > 音量ミキサー。ブラウザーの出力先を次に設定します： CABLE Input.
1つのアプリ、Windows 10サウンド設定 > アプリの音量とデバイスの設定。ブラウザーの出力先を次に設定します： CABLE Input.
Audio Router古いソフトウェアです。ブラウザーの音声を次へ送ります： CABLE Input.
VoicemeeterWindowsの標準出力先に設定します。ハードウェア出力をスピーカーへ、仮想出力をOBSへ送ります。

次にOBSで追加します： 音声入力キャプチャ（Audio Input Capture）で、次を選びます： CABLE Output （またはVoicemeeter出力）を選び、モニタリングを次に設定します： モニターと出力（Monitor and Output）。使う項目： モニターのみ を、別のソースから既に配信へ送っている場合に設定します。

TTSを再生し、OBSのメーターと実際の音を確認して音量を調整します。

問題を解決する

問題試すこと
音が出ないTTSがオンで、読み上げページが開いており、ブラウザーソースがミュートされていないか確認します。通常のブラウザーでは一度ページをクリックします。
OBSで無音まったく音が出ない場合は先にプロバイダーを確認します。音が出るなら次を確認します： OBSで音声を制御する（Control audio via OBS）、ミキサーのミュート、出力トラックを確認します。または読み上げているブラウザーの音声を取り込みます。
クラウド音声が動かないAPIキーとプロバイダー名を確認します。キーがないとSSNはSystem TTSに戻り、OBSでは無音になる場合があります。
ローカルサーバーがアプリでは動くがOBSでは動かないOBSは別のブラウザーです。OBSのコンピューターからサーバーを確認します。特に次を使う場合： 127.0.0.1。参照先： localhostの意味.
最初の文字や単語しか読まれない削除 ttsquick をOBSのリンクから削除します。
追加した音声が表示されない言語パックを追加したらブラウザーを再起動します。
Safariが読み上げないSafariは自動TTSに制限があります。一度ページをクリックして音声を許可します。

使うときの習慣

  • ページから音声を再生するプロバイダーが、OBSで最も簡単に設定できます。無料のものもあります。
  • 配信前に短いメッセージでテストします。
  • 視聴者は何でも入力できます。すぐTTSを止められるようにしてください。
