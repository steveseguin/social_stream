ローカル制御APIとMCP

同じコンピューター上のAIツールやスクリプトから、Social Stream Ninjaデスクトップアプリの確認と操作を行います。

このサービスを選ぶ場合1. 通常のデスクトップアプリをダウンロード2. ローカルAIからの操作を有効化3. MCPに機能を検出させる利用可能なローカル操作ローカルスクリプトから直接HTTPでアクセスするローカル専用

このサービスを選ぶ場合

デスクトップアプリ→ローカル制御API→MCPクライアント

SSAppと同じコンピューター上のソフトウェアに、許可されたアプリとソースの操作が必要な場合、ローカル制御APIを使用します。対応するAIクライアントにその操作をツールとして渡す場合は、同梱のMCPアダプターを使用してください。

これは次とは別のものです： File > Enable Local Serverとは別です。こちらはSocial Streamページ用のWebSocketリレーを開始します。参照： ローカルサーバーとサービスの説明 で、どのサービスが必要か確認できます。

1. 通常のデスクトップアプリをダウンロード

最新版のSocial Stream Ninjaを、次からインストールします： Windows、macOS、Linuxのダウンロード。MCP対応はダウンロードしたアプリに含まれています。ソースリポジトリ、Node、Python、別のMCPパッケージは不要です。

2. ローカルAIからの操作を有効化

  1. 開く項目： ファイル > ローカルAI / 自動化（File > Local AI / Automation）.
  2. 有効化 ローカル制御API を選び、アプリを再起動させます。
  3. 同じメニューに戻り、次を選択します： MCP設定をコピー（Copy MCP Setup）.
  4. コピーしたJSONをAIツールのMCP設定に貼り付け、そのツールを再起動します。

コピーした設定には、インストールされた実行ファイルの正確なパス、ポート、プラットフォーム固有の引数が含まれます。AIクライアントが次を付けて起動すると、ダウンロードしたSocial Stream Ninja実行ファイルが自身の軽量MCPアダプターを開始します： --ssapp-mcp.

3. MCPに機能を検出させる

接続すると、MCPクライアントはSocial Stream Ninjaにツール一覧を自動で要求します。アダプターは実行中アプリの機能情報を読み取り、対応するツールのスキーマ、アプリ／APIのバージョン、操作指示をLLMに渡します。エージェントはまずcapabilities、次にstatusを呼び出し、アプリが返した安定したソースIDを使用してください。

通常のMCP利用には、Webサイトのスクレイピングやスキルのインストールは不要です。接続したエージェントに、Social Stream Ninjaを確認または操作するよう依頼するだけで利用できます。

利用可能なローカル操作

  • ソースの一覧表示、確認、追加、更新、削除を行います。
  • 1つのソース、またはフィルターで選んだソース群を開始、停止、再読み込みします。
  • ソースの表示、ミュート状態、接続モードを変更します。
  • 機能検出が返す、対応する全体設定を読み取り、更新します。
  • アプリ、セッション、ソース、プロセス、キャプチャ、ローカルメディアの状態を読み取ります。
  • 件数に上限のあるソース取得イベント、および再開可能な操作／状態イベントを受信します。
  • 対応するソースページとSSAppのウィンドウをキャプチャし、安全に確認します。
  • 確認を経て、許可されたページ、ウィンドウ、ダイアログの操作を行います。
  • 明示的な確認を経て、アプリを再読み込みするか正常終了します。

実行中のアプリが公開する機能情報が正式な基準です。古いバージョンでは、利用可能な操作が少ない場合があります。

ローカルスクリプトから直接HTTPでアクセスする

同じコンピューター上のスクリプトは、MCPなしでループバックAPIを使用できます。待ち受け先は次だけです： 127.0.0.1 で、トークンは不要です。

GET http://127.0.0.1:17777/api/v1/capabilities
GET http://127.0.0.1:17777/api/v1/status
GET http://127.0.0.1:17777/api/v1/events
POST http://127.0.0.1:17777/api/v1/command

すべてのアプリバージョンで同じ操作が使えると考えず、公開された機能情報を使用してください。コピーして使える次の例については： curl でソースを追加、一覧表示、開始、確認、停止する例は、次を参照してください： サーバーHTTP APIの操作ガイド.

Ubuntu VPS上のローカルAI

APIは、ヘッドレスSSAppと同じLinuxサーバー上で動くAIツールにも利用できます。待ち受け先をループバックに限定し、ダウンロードしたAppImageをMCPのコマンドとして使用してください。

フォロー Social Stream Ninjaを画面なしで実行する で、Xvfb、永続プロファイル、起動コマンド、systemd、別のリモート操作経路を確認できます。また、次の設定例も含まれます： Linux AppImageのMCP設定 を、VPS上のクライアントに貼り付けられます。

任意のエージェントスキル

スキルのインストールに対応するエージェントでは、次ができます： 完全なControl Social Streamスキルをダウンロード。次の方法も利用できます： オンラインで手順を読むで、次を使用します： APIリファレンス および バージョン履歴。スキルは操作手順のガイダンスを追加するもので、MCPの接続には必要ありません。

機械可読の機能検出リンクは、次にも記載されています： llms.txt.

ローカル専用

このインターフェースは、SSAppと同じコンピューター上で動くAIや自動化向けです。クラウドのリモート制御APIとして公開したり、トンネルで外部に接続したりしないでください。リモート利用者やStream Deckは、Social Streamの既存のWebRTCまたはWebSocket接続を使用してください。ローカルAPIは、任意のJavaScriptの実行、Cookie、サインインの秘密情報、無制限の設定変更、生のファイルシステムアクセスを提供しません。

すべてのエンドポイント、コマンドのスキーマ、バージョン検出、セキュリティ上の境界については、次を参照してください： 自動化の技術リファレンス.
