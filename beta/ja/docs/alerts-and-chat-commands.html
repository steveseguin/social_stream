アラート、チャットコマンド、リマインダーを設定する

1 つのコマンドと 1 つのアラートから始めて、残りを追加します。

コマンド視聴者が尋ねます。ボットが応答します。 リマインダータイマーで短いメッセージ。 アラートとサウンドストリームイベントが画面に表示されます。

1. チャットを接続する

  1. Social Stream Ninja を開き、キャプチャをオンにして、ライブ チャットに接続します。
  2. 視聴者のメッセージがソーシャル ストリーム チャット ドックに表示されることを確認します。
  3. ドックから目的のプラットフォームにメッセージを送信します。プラットフォーム自体のチャットに表示されることを確認します。

接続にサポートが必要ですか?を開きます セットアップガイド.

TikTok connection modes

チャットの返信には、サインインした標準接続またはデスクトップ アプリのローカル署名者返信パスが必要です。互換性 (WebSocket) モードでは応答は送信されません。を参照してください。 TikTok connection guide.

2. カスタム コマンド応答を追加する

デバイス、ロードアウト、ソーシャル リンク、または Discord の招待に対して固定返信を使用します。 AIボットは必要ありません。

検索設定...Auto-responder

  1. コマンド入力を有効にします。
  2. 入力する内容： !discord 格納先： トリガーコマンド.
  3. 招待状とリンクを入力してください 返信するメッセージ.
  4. 視聴者に送ってもらう !discord プラットフォームのチャットで。同じチャット内で 1 つの返信を確認します。

使う項目： + 新規追加 追加のコマンドごとに。

3. 自動リマインダーを追加する

検索設定...Send fixed messages

  1. メッセージ入力を有効にします。
  2. リマインダーを入力してください ブロードキャストするメッセージ.
  3. 設定する項目： ブロードキャスト間の間隔 (分単位) → 15.
  4. 次はそのままにします： 開始時間オフセット の値を 0 余分な遅延はありません。

時間指定されたメッセージは、対象となる接続されたチャットに送信されます。目的の送信先のみを有効にしておきます。

有効化 チャットが静かすぎる場合は自動メッセージをスキップする 静かな時間帯にリマインダーを一時停止します。

4. アラートと独自のサウンドを追加する

検索設定...Multi-Alerts

  1. アラートのカテゴリとスタイルを選択します。
  2. 開く項目： サウンドとタイミング。有効にする 警告音を鳴らす を押して音量を設定します。
  3. 展開する項目： タイプごとのカスタム サウンド (上記の上書き)。フォロー、サブスクリプション、寄付のサウンドを個別にアップロードします。
  4. 使う項目： 聞いてください それぞれの音を聞く。

GIF、画像、ビデオについては、次のリンクを参照してください。 アニメーションとサウンドアラート.

OBSにオーバーレイを追加

  1. 設定した Multi-Alerts リンクをコピーします。
  2. 追加する項目： ブラウザソース OBS にリンクを貼り付けます。 URL フィールド。
  3. OBSで映像と音声を確認します。オーバーレイ設定を変更した後、更新されたリンクを OBS にコピーします。

無料の YouTube 購読者は、 フォロー アラート カテゴリ。有料会員利用 サブスク.

サブスクライバー アラートには、チャネル所有者としてサインインした API 接続が必要です。これらは公開サブスクリプションを対象としており、遅延または不完全になる可能性があります。を参照してください。 YouTubeイベントガイド.

アラートには、スーパー チャットや TikTok ギフトなど、ソースから提供されたイベントが表示されます。外部チップ サービスには、サポートされる独自の接続が必要です。

うまく動かない場合

コマンド応答なし

エントリが有効になっていること、コマンドが一致していること、クールダウンが経過していること、アカウントがそのチャットに送信できることを確認します。ソース制限とメッセージ フィルターを確認してください。視聴者アカウントでテストします。

ライブアラートなし

イベントがソーシャル ストリームに到達したことを確認し、オーバーレイのセッション リンクとイベント/プラットフォーム フィルターを確認します。プレビューで外観をチェックします。プラットフォームには接続しません。

音が出ない

アラート音の再生、音量、および OBS ブラウザ ソースのオーディオ設定を確認します。カスタム オーディオ URL は、サインインせずに再生する必要があります。再生がブロックされている場合は、通常のブラウザーでオーバーレイをクリックします。

繰り返しの返事や音

重複したコマンド、同じコマンドに応答する別のボット、または同じサウンドを再生する 2 つのアラート ソースを確認します。
