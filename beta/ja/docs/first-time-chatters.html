初回チャットのガイド

初めてチャットする人を、強調表示、葉のバッジ、任意の通知音で知らせます。

この機能の動作

初回チャットの検出では、次を追加します： firsttime=true を、その視聴者についてそのソースで最初に保存されるチャットメッセージに追加します。ドックでは、このフラグを背景の強調表示、初回限定の通知音、任意の葉のバッジに使用できます。

必要な設定

  1. Social Stream Ninjaのポップアップを開きます。
  2. 次の項目は維持します： ローカルメッセージデータベースを無効にする（Disable the local message database） をオフにしてください。
  3. オンにする項目： 初回チャットの検出（First-time chatter detection）.
  4. 同じセッションIDのドックまたはオーバーレイを開いたままにしてください。
重要： ローカルデータベースが必要です。データベースが無効だと、Social Stream Ninjaは初めての人かどうかを判定できません。

表示オプション

  • 背景の強調表示： ドックでは既定で有効です。次の設定を維持してください： 初回チャットの背景を強調しない（No background shading for first-time chatters） をオフにすると、背景を強調表示します。
  • 葉のバッジ： 有効にする項目： 初めてチャットする人にカスタムバッジを付ける（Mark first-time chatters with a custom badge） を有効にすると、その人のバッジの先頭に小さな葉のバッジを追加します。
  • 初めてチャットする人へのドックの通知音： 初めてチャットする人にだけドックの通知音を鳴らす場合、有効にしてください。
  • 初めて、または久しぶりにチャットする人への通知音： 8時間以上発言がなかった視聴者が戻ってきたときにも音を鳴らす場合、有効にしてください。

カスタムオーバーレイでフラグを使用する

カスタムオーバーレイでは次を確認できます： data.firsttime === true。葉のバッジを有効にすると、バッジは次に含まれます： chatbadges メッセージがオーバーレイに届く前に追加されます。

{
  "chatname": "Ava",
  "chatmessage": "First message here!",
  "type": "twitch",
  "firsttime": true
}

表示されない場合

  1. 確認する項目： ローカルメッセージデータベースを無効にする（Disable the local message database） がオフであること。
  2. 確認する項目： 初回チャットの検出（First-time chatter detection） がオンであること。
  3. 確認する項目： 初回チャットの背景を強調しない（No background shading for first-time chatters） がオフであること。背景を強調表示する場合に必要です。
  4. 確認する項目： 初めてチャットする人にカスタムバッジを付ける（Mark first-time chatters with a custom badge） がオンであること。葉のバッジを表示する場合に必要です。
  5. ローカルデータベースにまだ保存されていない、ユーザー名とソースの組み合わせでテストしてください。
