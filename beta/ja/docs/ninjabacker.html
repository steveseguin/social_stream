Social Stream NinjaでNinjaBackerのチップを表示

SSNでチップを受信し、OBSに通知やTip Jarを追加しましょう。

ライブフィードWebhookOBS表示テストとトラブル対処

1. アカウントを接続

SSNデスクトップアプリまたはChrome拡張機能で始めます。配信中はSSNを起動したままにしてください。

  1. NinjaBackerを開く。アカウントを作成し、Stripeの設定を完了して支払いを受け付けます。
  2. NinjaBackerのダッシュボードでSocial Stream Ninjaを開き、Private Tip IDをコピーします。
  3. SSNで、お金 > ショップとサポート > 接続済みプラットフォーム > NinjaBackerの寄付 > 設定を開きます。ユーザー名と非公開のTip IDを入力します。
  4. 配信をライブフィード（簡単）のままにして、NinjaBackerの寄付を有効にし、設定を保存をクリックします。

接続済みプラットフォームが非表示の場合は、SSNをフルモードに切り替えてください。

ライブフィードにWebhookは不要です。接続中の新しいチップを表示しますが、SSN終了中に届いたチップは再生しません。

2. 任意: Webhookを使う

SSNを終了している間もチップを最大7日間キューに保存するには、信頼性の高いWebhookを選びます。

  1. NinjaBackerでWebhookを開きます。Webhook Signature SecretのGenerateをクリックしてシークレットをコピーします。すでに使用中のシークレットがあれば、それをコピーしてください。
  2. SSNのNinjaBacker設定で信頼性の高いWebhookを選び、署名シークレットを貼り付けて設定を保存をクリックします。
  3. SSNで受信URLをコピーをクリックします。NinjaBackerのWebhook URL欄に貼り付け、Saveをクリックします。

受信URLは次の文字列で始まります:

https://api.socialstream.ninja/v1/ninjabacker/webhook/...

Tip Jar、チャットドックなどの表示URLはOBSで使います。Webhookリクエストは受信できません。

ライブフィードに戻す

切り替えるとSSN受信先の待機中のチップが削除されます。NinjaBackerの古いWebhook URLも空にして保存してください。

3. OBSに表示を追加

  1. 通知には、ショップとサポート内のOBSオーバーレイの対象でNinjaBackerの寄付を選びます。オーバーレイのリンクをコピーします。
  2. 累積目標を表示するには、お金 > Tip Jarと目標メーターを開きます。スタイルと目標を選び、リンクをコピーします。
  3. OBSでブラウザソースを追加し、表示用リンクを貼り付けます。SSNと表示には同じセッションを使ってください。

Tip Jarのスタイルと目標設定

公開のNinjaBackerチップページを視聴者に共有してください。オーバーレイのリンクはOBSに、受信URLはWebhook欄に入れます。

4. 設定を確認

SSNのNinjaBacker通知オーバーレイを開きます。NinjaBackerでTestingを開き、Send Test Tipをクリックします。そのオーバーレイにテスト通知が表示されます。

Send Test Tip の下に結果が表示されます。Webhook accepted は受信を確認するもので、OBS でのアラート表示を保証しません。失敗した場合は URL または署名シークレットを修正して再度テストしてください。ダッシュボードのテストは5分間再試行されます。

テストチップはTip Jarの金額を増やさず、チャットの有料寄付として表示されず、有料報酬も実行しません。

テスト通知が表示されない？

SSNを起動し、NinjaBackerの寄付を有効にしてください。ユーザー名とTip IDが同じアカウントのものか確認します。Webhookの場合はNinjaBackerのDelivery Historyを更新し、受信URLと署名シークレットを確認してください。

HTTP 405または表示URLのエラー？

SSNの信頼性の高いWebhook設定から受信URLをコピーし、NinjaBackerに保存して新しいテストチップを送信します。新しいURLを保存すると、古い宛先への再試行は停止します。

チャットにはチップが表示されるのに目標に反映されない？

Tip Jarのセッションと、ソース、寄付の種類、有料イベントのフィルターを確認してください。チップ金額には金額目標を使います。返金はSSNの通知や目標から差し引かれません。
