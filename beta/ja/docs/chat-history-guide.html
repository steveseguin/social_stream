チャット履歴とロイヤルティポイント

メッセージのローカル保存が履歴、ポイント、視聴者の認識に与える影響。

すべてのガイド ローカル履歴 ポイントを動作させるには 既存のメッセージ履歴

ローカルのメッセージデータベースの役割

SSNは、メッセージを取得しているブラウザーまたはデスクトップ環境のデータベースに、取得したメッセージを保存します。チャット履歴ページはこのデータベースを使って過去のメッセージを検索します。

対象の ローカルメッセージデータベースを無効にする（Disable the local message database） の設定を有効にすると、新しいメッセージは保存されなくなります。ライブ取得とドック表示は継続できるため、ドックにメッセージが見えていても履歴が保存されているとは限りません。

初めてチャットに参加した人の検出や、履歴に基づく視聴者の認識もローカルデータベースを使用します。

ロイヤルティポイントを動作させるには

ポイントの付与と、次のコマンドの処理： !points, !leaderboard および !rewards は、取得したメッセージの保存時に実行されます。ローカルのメッセージデータベースを無効にすると、ポイントの設定が有効でもこれらの処理は停止します。

  1. 探す項目： ローカルメッセージデータベースを無効にする（Disable the local message database） をSSNの設定で探し、オフのままにします。
  2. 次の場所で： ポイントシステムで、ロイヤルティポイントと使用したいチャットコマンドを有効にします。
  3. 視聴者にメッセージを送ってもらい、続いて次のコマンドを送ってもらいます： !points。正しいプラットフォームのアカウントを確認してください。

残高はメッセージ履歴とは別に保存されます。バックアップには次を使用します： Points System → Backup & Restore → Export Points 。他の環境とセッションIDを共有しても、どちらのデータベースも同期されません。

参照先： ロイヤルティポイントガイド で、ポイントの獲得、ランキング、報酬、バックアップについて確認してください。

既存の履歴の利用方法

ポイント台帳が空で、まだ初期化もリセットもされていない場合、SSNは保存済みのチャット履歴から初期ポイントを計算できます。残高を初期化するために一度だけ実行されます。

過去の参加履歴にもライブ中と同じ付与ルールが適用されます。条件を満たす最初の参加には基本ポイントが付与され、その後の参加には連続参加ボーナスが付く場合があります。利用できるメッセージ履歴だけが対象です。環境を移行または復旧するときは、ポイントのエクスポートを保管してください。
