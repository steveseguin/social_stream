← เปิด Lite

นำแชตเข้าสู่โอเวอร์เลย์

Lite เชื่อมต่อแหล่งแชตที่รองรับจากเบราว์เซอร์หรือ OBS ของคุณ เมื่อใช้ลิงก์โอเวอร์เลย์ปกติ ต้องเปิด Lite ค้างไว้ในแท็บหรือแผงด็อก OBS โหมด OBS แบบทำงานแยกเชิงทดลองเก็บและแสดงแชตในแหล่งเบราว์เซอร์เดียว

การตั้งค่า · การตั้งค่าที่ใช้เฉพาะ OBS · แหล่งข้อมูล · การตั้งค่าที่มีอยู่ · การแก้ปัญหา

1. ตั้งค่าโอเวอร์เลย์

  1. เปิด Lite รหัสเซสชันและ URL โอเวอร์เลย์จะสร้างโดยอัตโนมัติและจดจำไว้ในเบราว์เซอร์นี้
  2. เชื่อมต่อแหล่งข้อมูลด้านล่างสักหนึ่งแหล่ง ใช้ปุ่ม ตัวเลือก เพื่อตั้งค่าช่อง
  3. เลือก คัดลอกลิงก์ ใน OBS เพิ่ม เบราว์เซอร์ แล้ววางลิงก์ในช่อง URL คุณยังใช้ เปิดโอเวอร์เลย์แผงด็อก เพื่อตรวจสอบในเบราว์เซอร์
  4. เลือก ส่งข้อความทดสอบ ใน Lite ตรวจสอบว่าข้อความปรากฏในโอเวอร์เลย์ที่เปิดอยู่ การเห็นข้อความเฉพาะในฟีด Activity ของ Lite ไม่ได้ยืนยันว่าโอเวอร์เลย์ได้รับแล้ว

หากต้องการโอเวอร์เลย์โปร่งใสหรือจัดลำดับข้อความต่างออกไป ให้เปิดตัวเลือกข้าง ลิงก์โอเวอร์เลย์แชต หลังเปลี่ยนตัวเลือกเหล่านี้ ให้คัดลอก URL ที่อัปเดตไปใส่ใน OBS

2. เลือกแหล่งข้อมูล

สำหรับการตั้งค่าที่ใช้เฉพาะ OBS ให้เลือกขั้นตอนใดขั้นตอนหนึ่งจากสองแบบด้านล่าง หากเก็บข้อมูลภายใน OBS คุณไม่ต้องเปิดแท็บเบราว์เซอร์เดสก์ท็อปแยก

แหล่งข้อมูลสิ่งที่ต้องทำ
YouTubeลงชื่อเข้าใช้ด้วย YouTube โดย Lite จะค้นหาการถ่ายทอดสดของคุณ ใน Options คุณสามารถระบุ Video ID หรือ Live Chat ID ของการถ่ายทอดสดที่ต้องการได้ ค่าเริ่มต้นใช้การดึงข้อมูลเป็นระยะ ส่วน API แบบสตรีมที่เลือกใช้ได้ระบุว่าเป็นเบต้า การถ่ายทอดสดต้องมีแชตสดที่ใช้งานได้
Twitchลงชื่อเข้าใช้ด้วย Twitch โดยค่าเริ่มต้น Lite ใช้ช่องของคุณเอง ตั้งช่องอื่นได้ใน Options หากการอนุญาตหมดอายุ ให้ลงชื่อเข้าใช้อีกครั้ง
Kickป้อนชื่อช่องใน Options แล้วเชื่อมต่อ หากการค้นหาอัตโนมัติล้มเหลว ให้ตรวจสอบการสะกดชื่อช่อง แล้วใช้การตั้งค่าห้องแชตด้วยตนเองหากจำเป็น
TikTokขณะนี้การเชื่อมต่อนี้ซ่อนอยู่ในแผง Lite มาตรฐาน ต้องใช้พร็อกซี TikTok Chat Reader ที่เข้ากันได้ ที่อยู่ซึ่งกรอกไว้ล่วงหน้าไม่ได้รับประกันว่าบริการพร้อมใช้งาน ใช้แอปเต็มเพื่อดูตัวเลือกเก็บข้อมูล TikTok ที่มี

ตัดการเชื่อมต่อ จะหยุดแหล่งข้อมูลนั้น สำหรับ YouTube และ Twitch จะเก็บการลงชื่อเข้าใช้ไว้เพื่อให้คุณใช้ เชื่อมต่อ (Connect) อีกครั้ง ออกจากระบบ จะลบการอนุญาตที่บันทึกไว้ในเบราว์เซอร์นี้

3. ใช้การตั้งค่า Social Stream ที่มีอยู่

หากต้องการส่งข้อมูลไปยังแผงด็อกหรือโอเวอร์เลย์ที่มีอยู่ ให้เปิดตัวเลือกเซสชันใน Lite และป้อนรหัสเซสชันนั้น เลือก บันทึกรหัสเซสชัน หรือกด Enter การเปลี่ยนรหัสจะเปลี่ยนปลายทางที่ Lite ส่งข้อความ ให้อัปเดต URL ของแหล่งเบราว์เซอร์ที่ควรตามไปด้วย

ใช้วิธีเก็บข้อมูลเพียงวิธีเดียวต่อช่องในเซสชันเดียวกัน การใช้ Lite ควบคู่กับส่วนขยายหรือแอปเดสก์ท็อปที่เก็บแชตเดียวกันอาจทำให้ข้อความซ้ำ คุณใช้ Lite สำหรับช่องหนึ่งและใช้แอปเต็มสำหรับแหล่งอื่นได้

ลิงก์ที่ Lite สร้างใช้รหัสผ่านเซสชันเริ่มต้น การตั้งค่าที่ป้องกันด้วยรหัสผ่านหรือใช้เซิร์ฟเวอร์กำหนดเองอาจต้องใช้ตัวควบคุมการเชื่อมต่อของแอปเต็ม Lite ไม่ได้แทนที่ตัวควบคุมการเก็บข้อมูล ระบบอัตโนมัติ การดูแลแชต หรือการปรับแต่งโอเวอร์เลย์ของแอปเต็ม

ตัวเลือกของ Activity ได้แก่ เฉพาะการบริจาค และ การอ่านข้อความเป็นเสียง ใช้กับมุมมองกิจกรรมของ Lite เมื่อใช้หน้าต่างกิจกรรมแยก ให้เปิดหน้า Lite หลักค้างไว้ หากไม่ต้องการให้ผู้อื่นเข้าร่วมเซสชันนั้น ให้เก็บ URL ของโอเวอร์เลย์เป็นความลับ

ทำงานทั้งหมดภายใน OBS

ตัวเลือก A: แผงด็อก Lite + โอเวอร์เลย์ปกติ

  1. เปิด ทำงานทั้งหมดภายใน OBS ใน Lite แล้วคัดลอก URL แผงด็อกกำหนดเองของ OBS (lite/index.html?view=dock).
  2. เพิ่มใน OBS ภายใต้ แผงด็อกเบราว์เซอร์กำหนดเอง (Custom Browser Docks) ลงชื่อเข้าใช้และตั้งค่าแหล่งข้อมูลในแผงด็อกนั้น ตัวเลือกแหล่งข้อมูลและการตั้งค่าเซสชันยังเข้าถึงได้ที่นั่น
  3. คัดลอก URL โอเวอร์เลย์ปกติของแผงด็อกไปใส่ในแหล่งเบราว์เซอร์ OBS เปิดแผงด็อก Lite ค้างไว้ขณะเก็บข้อมูล แหล่งเบราว์เซอร์นี้แสดงข้อความอย่างเดียว จึงไม่ต้องลงชื่อเข้าใช้ผู้ให้บริการแยกเอง

นี่คือขั้นตอนที่ง่ายที่สุดสำหรับการใช้เฉพาะ OBS: เก็บข้อมูลในแผงด็อกและแสดงผลในแหล่งเบราว์เซอร์ การปิดแผงด็อกจะหยุดการเก็บข้อมูล หลังตั้งค่าเสร็จไม่ต้องใช้เบราว์เซอร์เดสก์ท็อป

ตัวเลือก B: แหล่งเบราว์เซอร์เดียวที่เก็บข้อมูลและแสดงโอเวอร์เลย์ (ทดลอง)

  1. เพิ่ม URL สำหรับเก็บข้อมูลและแสดงโอเวอร์เลย์แบบทำงานแยก (lite/index.html?view=overlay) เป็นแหล่งเบราว์เซอร์ใน OBS
  2. เปิด โต้ตอบ (Interact) เพื่อตั้งค่าแหล่งข้อมูล หากตั้งค่าไว้แล้ว ให้กด Escape ใน Interact เพื่อเปิดการตั้งค่าอีกครั้ง หน้าลงชื่อเข้าใช้และตัวควบคุมการตั้งค่าจะมองเห็นได้ในแหล่งนี้ จึงควรตั้งค่าขณะไม่ได้ออกอากาศ
  3. เลือก แสดงโอเวอร์เลย์ ตอนนี้หน้าจะแสดงแชตขาเข้าของตัวเองบนพื้นหลังโปร่งใส โดยไม่ต้องมีแท็บ Lite แผงด็อก หรือการเชื่อมต่อส่งต่ออื่น และไม่ส่งข้อมูลให้โอเวอร์เลย์อื่นในเซสชัน
  4. คงค่า ปิดแหล่งข้อมูลเมื่อมองไม่เห็น (Shutdown source when not visible) และ รีเฟรชแหล่งเบราว์เซอร์เมื่อฉากเริ่มทำงาน ให้ปิด เพื่อไม่ให้การเก็บข้อมูลสะดุดเมื่อเปลี่ยนฉาก ดู คุณสมบัติแหล่งเบราว์เซอร์ OBS.

ข้อมูลรับรอง YouTube/Twitch ที่บันทึกไว้และยังใช้ได้จะเชื่อมต่อใหม่เมื่อเริ่มทำงาน สำหรับ Kick ให้เปิดตัวเลือก เชื่อมต่อช่อง Kick นี้ใหม่โดยอัตโนมัติในโหมด OBS ใน Options ตั้งค่าช่องก่อน TikTok ยังซ่อนอยู่ เลย์เอาต์เริ่มต้นแสดงทุกข้อความและปิดเสียงอ่าน โดยไม่ขึ้นกับค่าที่บันทึกไว้ของมุมมองกิจกรรมปกติ

แผงด็อก OBS แหล่งเบราว์เซอร์ OBS และเบราว์เซอร์เดสก์ท็อปอาจใช้โปรไฟล์คุกกี้/พื้นที่จัดเก็บต่างกัน อย่าสันนิษฐานว่าการตั้งค่าแผงด็อกจะทำให้แหล่งเบราว์เซอร์แยกลงชื่อเข้าใช้ด้วย หากลงชื่อเข้าใช้ภายในแหล่งเบราว์เซอร์ OBS ไม่สำเร็จ ให้ใช้ตัวเลือก A การยืนยันตัวตนกับผู้ให้บริการภายใน OBS โดยตรงยังต้องตรวจสอบในการใช้งานจริง โหมดนี้ยังเป็นการทดลอง

ใช้ตำแหน่งเก็บข้อมูลเพียงแห่งเดียวต่อช่อง อย่าให้แผงด็อกเก็บช่องเดียวกับแหล่งที่เก็บข้อมูลและแสดงโอเวอร์เลย์แบบทำงานแยก เมื่อใช้แหล่งเก็บข้อมูลเดิมในหลายฉาก ให้เลือกใช้แหล่งที่มีอยู่ของ OBS

การแก้ปัญหา

โอเวอร์เลย์ว่างเปล่า
ตรวจสอบว่า Lite ยังเปิดอยู่และโอเวอร์เลย์ใช้รหัสเซสชันเดียวกัน ส่งข้อความทดสอบ หากข้อความทดสอบมาถึงแต่แชตสดไม่มา ให้ตรวจสอบสถานะและช่องของแหล่งข้อมูล หากไม่มาทั้งคู่ ให้ตรวจสอบ URL ของโอเวอร์เลย์และว่าเครือข่ายบล็อกการเชื่อมต่อส่งต่อหรือไม่
การคัดลอกลิงก์ถูกบล็อก
คลิก URL ของโอเวอร์เลย์ที่แสดง แล้วคัดลอกข้อความที่เลือกด้วยแป้นพิมพ์หรือเมนูคัดลอกของอุปกรณ์
แหล่งข้อมูลไม่ทำงานหรือแสดงข้อผิดพลาด
ตรวจสอบ Options และข้อความข้อผิดพลาด เชื่อมต่อใหม่หลังแก้การตั้งค่า YouTube และ Twitch อาจต้องลงชื่อเข้าใช้อีกครั้งหากการอนุญาตหมดอายุ
เห็นข้อความซ้ำ
ตรวจสอบว่ามีแท็บ Lite ที่สอง ส่วนขยาย หรือแอปเดสก์ท็อปที่กำลังเก็บข้อมูลจากช่องและเซสชันเดียวกันหรือไม่ ให้ทำงานเฉพาะการเก็บข้อมูลที่ต้องการ
การตั้งค่าหายไป
การตั้งค่าเก็บไว้ในพื้นที่จัดเก็บภายในของเบราว์เซอร์นี้ เบราว์เซอร์อื่น หน้าต่างส่วนตัว หรือการล้างข้อมูลเว็บไซต์จะใช้ชุดการตั้งค่าคนละชุด
