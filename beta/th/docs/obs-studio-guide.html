คำแนะนำ / สตูดิโอ OBS

การตั้งค่า OBS ครั้งแรกของคุณ

รวมกล้อง หน้าจอ และเสียงของคุณเข้าด้วยกัน ทำการบันทึกทดสอบแล้วถ่ายทอดสด

เริ่มที่นี่ฉากตัวเข้ารหัสการตั้งค่าแพลตฟอร์มเสียงภาพซ้อนทับ
01

ให้ OBS ทำการตั้งค่าครั้งแรก

  1. ติดตั้ง OBS Studio และเปิดมัน
  2. เลือก เครื่องมือ → วิซาร์ดการกำหนดค่าอัตโนมัติ.
  3. เลือกการสตรีมหรือการบันทึก ปฏิบัติตามคำแนะนำ และใช้การตั้งค่า

อนุญาตให้เข้าถึงกล้อง ไมโครโฟน และการจับภาพหน้าจอเมื่อคอมพิวเตอร์ถาม

ภาพหน้าจอจะเปิดในขนาดเต็มเมื่อเลือก ป้ายกำกับอาจแตกต่างกันเล็กน้อยตามเวอร์ชัน OBS

ลากมุมเพื่อปรับขนาด แหล่งข้อมูลด้านบนครอบคลุมแหล่งข้อมูลด้านล่าง ใช้ตาเพื่อซ่อนและล็อคเพื่อป้องกันการเคลื่อนไหว

การสลับฉากและ macOS

บน macOS ให้ใช้ การจับภาพหน้าจอ macOS สำหรับหน้าต่างหรือจอแสดงผล

โดยปกติการเปลี่ยนแปลงฉากจะตรงไปที่เอาต์พุต โหมดสตูดิโอ ให้คุณเตรียมฉาก จากนั้นกด การเปลี่ยนแปลง. การเปลี่ยนแปลงแหล่งที่มาและเสียงที่แชร์ยังคงส่งผลต่อเอาต์พุตสด

เลือก เพิ่มที่มีอยู่ เพื่อนำแหล่งข้อมูลกลับมาใช้ใหม่ในฉากอื่น

ไม่มีตัวเลือกฮาร์ดแวร์ใช่ไหม? ใช้ x264 →เร็วมาก และเริ่มที่ 720p30

ตัวเข้ารหัสหายไปหรือคอมพิวเตอร์โอเวอร์โหลด?

ตรวจสอบการสนับสนุนฮาร์ดแวร์และอัปเดตไดรเวอร์กราฟิกของคุณ OBS ยังคงต้องการความจุของ GPU ในการวาดฉาก cap game FPS หรือ FPS เอาท์พุตต่ำกว่าหากตามหลัง

หากตัวเข้ารหัสฮาร์ดแวร์ของ Mac ไม่สามารถให้ CBR ได้ ให้ใช้ x264 ความเข้ากันได้ของตัวเข้ารหัส.

05

สำหรับการตั้งค่าเอาต์พุตแบบแมนนวล ให้เลือก เอาท์พุต → ขั้นสูง → สตรีมมิ่ง: ซีบีอาร์, คีย์เฟรม 2 วินาที, และ สเตอริโอ AAC. เปิดแพลตฟอร์มของคุณด้านล่าง

ช่วงล่างคือการทดสอบเริ่มต้นที่แนะนำ ลองใช้เสียง 160 kbps; ใช้สเตอริโอที่ไม่เกิน 48 kHz การตั้งค่าการเตะ.

ออกจากพื้นที่ว่างในการอัปโหลด 6,000 kbps ใช้ประมาณ 6 Mbps พร้อมเสียงและโอเวอร์เฮด บิตเรตหรือความละเอียดต่ำลงหากการเชื่อมต่อของคุณไม่สามารถตามทัน

คำแนะนำเดือนตุลาคม 2026 ปฏิบัติตามข้อกำหนดปัจจุบันของแพลตฟอร์มของคุณ สำหรับ Facebook หรือ TikTok ก่อนอื่นให้ยืนยันว่าบัญชีของคุณมีการเชื่อมต่อตัวเข้ารหัสภายนอก

06

ทำให้เสียงของคุณฟังง่าย

  1. เลือกไมโครโฟนของคุณเข้า การตั้งค่า → เสียง.
  2. พูดตามปกติ มุ่งสู่ยอดเขารอบๆ −12 ถึง −6 dBFS; หลีกเลี่ยงการกดปุ่ม 0
  3. ลดแถบเลื่อนเกม เพลง และการแจ้งเตือนจนกว่าคำพูดจะชัดเจน

จับแต่ละเสียงหนึ่งครั้ง ใช้เสียงเดสก์ท็อปสำหรับอุปกรณ์เอาท์พุตทั้งหมด หรือการแยกแอปพลิเคชันแยกกัน การจับทั้งสองอย่างจะทำให้เสียงเป็นสองเท่า

เสียงแอป, macOS และตัวกรองไมโครโฟน

หน้าต่าง: การใช้งาน แอปพลิเคชันบันทึกเสียง. บน macOS 13+ ให้ใช้ OBS's การจับภาพเสียง/หน้าจอ macOS.

ไมโครโฟน → ฟิลเตอร์: ลองใช้การลดเสียงรบกวนเล็กน้อย จากนั้นจึงใช้คอมเพรสเซอร์และลิมิตเตอร์ เพิ่มทีละรายการแล้วฟัง

หลีกเลี่ยงเสียงสะท้อน: อย่าจับภาพอุปกรณ์ตรวจสอบของคุณอีกครั้งผ่านเสียงเดสก์ท็อป ที่สามารถส่งเสียง "เฉพาะจอภาพ" ให้กับผู้ชมได้เช่นกัน ปิดเสียงผู้เล่นสดของแพลตฟอร์มไว้

08

เพิ่มการแชทหรือการแจ้งเตือนซ้อนทับ

  1. คัดลอก URL โอเวอร์เลย์จาก Social Stream Ninja
  2. เลือก Sources → + → Browser แล้ววาง เก็บตัวเลือกเซสชันและรหัสผ่านไว้
  3. ตั้งค่าขนาดภาพซ้อนทับ ใช้ 1920 × 1080 สำหรับภาพซ้อนทับแนวนอนแบบเต็มเฟรม
  4. สำหรับ TTS หรือการแจ้งเตือน ให้เปิดใช้งาน ควบคุมเสียงผ่าน OBS (Control audio via OBS).

วางไว้เหนือเกมหรือกล้องของคุณ ส่งข้อความทดสอบ เลือกหนึ่งรายการในท่าเรือ SSN หากใช้การซ้อนทับข้อความเด่น

การซ้อนทับว่างเปล่าหรือเสียงซ้ำ?

ตรวจสอบเซสชั่นที่ตรงกับแหล่งที่มาของแชทของคุณ รีเฟรชแหล่งที่มาของเบราว์เซอร์ เก็บสำเนาเดียวที่เล่น TTS

สำหรับการแชทอย่างต่อเนื่อง ให้ปิดการปิดเครื่องอัตโนมัติและรีเฟรชการเปิดใช้งานฉากตั้งแต่แรก การตั้งค่าการซ้อนทับ SSN · การตั้งค่า TTS.

09

บันทึกหนึ่งนาที จากนั้นจึงถ่ายทอดสด

  1. เลือกโฟลเดอร์บันทึกใน การตั้งค่า → สัญญาณออก.
  2. กด เริ่มบันทึก (Start Recording). พูดคุย เล่นเสียง และสลับฉาก
  3. หยุดและดูไฟล์ ตรวจสอบระดับเสียง การจัดเฟรม และลิปซิงค์
  4. ตั้งชื่อแพลตฟอร์มและการมองเห็นของคุณ เริ่มสตรีม (Start Streaming). ตรวจสอบตัวอย่างและสภาพการสตรีม บางแพลตฟอร์มก็ต้องการเช่นกัน ถ่ายทอดสด.

เริ่มสตรีมมิ่งสามารถทำให้คุณถ่ายทอดสดต่อสาธารณะได้ ใช้การทดสอบส่วนตัวหากมี เมื่อเสร็จแล้ว ให้หยุดการสตรีมและยืนยันว่ากิจกรรมแพลตฟอร์มสิ้นสุดลงแล้ว

รูปแบบการบันทึกและแทร็กเสียงแยกกัน

MKV ทนต่อการบันทึกที่ถูกขัดจังหวะ ใช้ ไฟล์ → การบันทึก Remux สำหรับ MP4 ในภายหลัง OBS ปัจจุบันยังมี Hybrid MP4/MOV ที่ยืดหยุ่นอีกด้วย

สำหรับแทร็กการแก้ไขแยกกัน ให้เก็บมิกซ์แบบเต็มไว้ในแทร็ก 1 จากนั้นกำหนดไมค์/เกมให้กับแทร็กเพิ่มเติมในคุณสมบัติเสียงขั้นสูง และเปิดใช้งานภายใต้การบันทึก
