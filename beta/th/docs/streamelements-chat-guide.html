ใช้สกินแชต StreamElements ของคุณ

นำเข้าวิดเจ็ตแชตกำหนดเอง ดูตัวอย่างด้วย Social Stream Ninja และดาวน์โหลดไฟล์สำหรับ OBS

เปิดตัวนำเข้าแชต

อะไรใช้ได้บ้าง?

ตัวนำเข้านี้สำหรับ วิดเจ็ตแชตกำหนดเอง ที่สร้างสำหรับ StreamElements หรือ Streamlabs รวมส่วนแชตของแพ็กธีม คุณต้องมีไฟล์ต้นฉบับวิดเจ็ต ไม่ได้นำเข้าทั้งบัญชี StreamElements หรือธีมจาก URL โอเวอร์เลย์

ใช้ได้ทั้ง แอป SSN เดสก์ท็อป Windows หรือส่วนขยาย Chrome เพื่อเก็บแชต สกินที่นำเข้าแสดงแชตนั้นใน OBS ความเข้ากันได้ขึ้นอยู่กับวิดเจ็ต ฟีเจอร์บัญชีอย่างเป้าหมาย คะแนนสะสม ร้านค้า และการแจ้งเตือนอาจต้องแปลงเอง

1. เตรียมไฟล์วิดเจ็ต

เริ่มจาก ZIP หรือโฟลเดอร์ต้นฉบับของผู้ออกแบบ หา HTML, CSS และ JavaScript พร้อม JSON fields/data รูป และฟอนต์ หากแพ็กมีหลายแบบให้เลือกวิดเจ็ตแชตหนึ่งแบบ

มีแค่ลิงก์ติดตั้งหรือไม่? ขอไฟล์ต้นฉบับวิดเจ็ตแชตจากผู้ออกแบบ หรือใช้โค้ดในตัวแก้ไขวิดเจ็ตกำหนดเองของ StreamElements ภาพหน้าจอ วิดีโอ หรือ URL แหล่งเบราว์เซอร์ไม่สามารถแปลงได้ด้วยตัวเอง

โค้ดวิดเจ็ตของฉันอยู่ในตัวแก้ไข StreamElements

เปิดตัวแก้ไขโค้ดวิดเจ็ตกำหนดเอง บันทึกแต่ละส่วนที่มีเป็นไฟล์ข้อความธรรมดาแยก: html.txt, css.txt, js.txt, fields.txt และ data.txt คัดลอกเนื้อหาโดยไม่เพิ่มการจัดรูปแบบหรือเปลี่ยน JSON หากไม่มีไฟล์ data ตัวนำเข้าจะใช้ค่าเริ่มต้นใน fields

เลือกไฟล์เหล่านี้ทั้งหมดพร้อมกันด้วย เลือกไฟล์ (Choose Files) รวมภาพหรือฟอนต์ในเครื่องทั้งหมดด้วย เลือกโฟลเดอร์ (Choose Folder) รักษาเส้นทางโฟลเดอร์ ดู เอกสารอ้างอิงตัวแก้ไขโค้ด StreamElements สำหรับโค้ดและโครงสร้างฟิลด์

นำเข้าเฉพาะโค้ดที่เชื่อถือ JavaScript ของวิดเจ็ตรันในตัวอย่างและโอเวอร์เลย์ที่ดาวน์โหลด

2. เปิดตัวนำเข้า

ในเมนู SSN ใต้ส่วน โอเวอร์เลย์แชตที่มีสไตล์สำเร็จ ให้มองหาตัวเลือก นำเข้าสกินแชต StreamElements / Streamlabs วิธีนี้เติมเซสชันปัจจุบันให้ คุณค้นหาเมนูด้วยคำว่า StreamElements หรือ เปิดตัวนำเข้าโดยตรง.

ใช้ เลือก ZIP (Choose ZIP), เลือกไฟล์ (Choose Files) หรือ เลือกโฟลเดอร์ (Choose Folder) ตัวอย่างสาธิตจะโหลดหลังประมวลผลไฟล์ ตรวจคำเตือนการนำเข้า ใช้ เลือกไฟล์ขั้นสูง หากตรวจพบไฟล์ต้นฉบับผิด

3. เชื่อมต่อและดูตัวอย่าง

  1. เปิด SSN ไว้และยืนยันว่ามีข้อความจริงปรากฏในแผงด็อกแชต
  2. ตรวจส่วนของตัวนำเข้า รหัสเซสชัน SSN / รหัสสตรีม หากว่าง ให้คัดลอกจาก ตัวเลือกเซสชัน ใน SSN ค่านี้ไม่ใช่ชื่อผู้ใช้ Twitch หรือ YouTube
  3. ป้อนรหัสผ่านเซสชันหากคุณใช้
  4. ใช้ ตัวอย่างสาธิต (Demo Preview) เพื่อดูข้อความตัวอย่าง แล้ว ตัวอย่างสด (Live Preview) แล้วส่งข้อความแชตใหม่เข้าสตรีม
  5. หาก ประวัติข้อความ (Message history) ปรากฏ ให้ปรับการลบตามเวลาหรือจำนวนข้อความสูงสุด

Demo Preview ใช้ได้โดยไม่มีเซสชันและใช้ข้อความตัวอย่างเท่านั้น Live Preview ต้องมีแชตเข้าจาก SSN ตัวอย่างว่างอย่างเดียวไม่ได้หมายความว่าเชื่อมต่อล้มเหลว

4. ดาวน์โหลดและเพิ่มใน OBS

  1. คลิก ดาวน์โหลด HTML สำหรับ OBS (Download OBS HTML) แล้วบันทึกไว้ในที่ถาวร
  2. ใน OBS เพิ่ม แหล่งเบราว์เซอร์ (Browser Source), เปิดใช้ ไฟล์ในเครื่อง (Local file) แล้วเรียกดูไฟล์ HTML นั้น
  3. ตั้งความกว้างและความสูงพื้นที่แชต แล้วส่งข้อความอีกครั้งเพื่อตรวจ

เซสชันของคุณฝังไว้แล้ว ไม่ต้องแก้ URL ใน OBS ใช้ไฟล์ที่ดาวน์โหลดเป็นแหล่งเบราว์เซอร์ เปิด SSN และแหล่งเก็บแชตไว้ โดยปิดตัวนำเข้าและ StreamElements ได้

ไฟล์ส่งออกมีรหัสเซสชันและรหัสผ่านหากมี เก็บเป็นส่วนตัว หากต้องการเปลี่ยนเซสชัน รหัสผ่าน หรือการตั้งค่าวิดเจ็ตภายหลัง ให้นำเข้าไฟล์ต้นฉบับใหม่และดาวน์โหลดไฟล์แทน แล้วรีเฟรชแหล่ง OBS

หากบางอย่างไม่ทำงาน

  • ไม่พบโค้ดวิดเจ็ต: ใช้ไฟล์ต้นฉบับจริง รูป ไฟล์ fields/data อย่างเดียว และไฟล์ SSN ที่แปลงมาแล้วไม่ใช่ต้นฉบับวิดเจ็ต
  • ตัวอย่างสาธิตว่างหรือดูผิด: ตรวจ HTML/CSS/JS ใน Advanced file selection ใส่ไฟล์ fields และ data ที่ตรงกัน พร้อมทรัพยากรทั้งหมด
  • สาธิตใช้ได้ แต่ Live Preview ว่าง: ส่งข้อความใหม่ ตรวจแผงด็อก SSN และให้รหัสเซสชันกับรหัสผ่านตรงกัน
  • ตัวอย่างสดใช้ได้ แต่ OBS ว่าง: ตรวจไฟล์ HTML ในเครื่องที่เลือก ขนาดและการมองเห็นแหล่งเบราว์เซอร์ แล้วรีเฟรชแคช
  • ฟอนต์หรือภาพหาย: ตรวจสรุปการส่งออก ทรัพยากรระยะไกลที่ฝังไม่ได้ยังต้องมี URL ที่เข้าถึงได้และอินเทอร์เน็ต
  • ข้อความหาย: ปรับ Message history หากวิดเจ็ตมีตัวเลือกนี้ บางวิดเจ็ตควบคุมการลบใน JavaScript ของตัวเอง
  • API บัญชีหรือปลั๊กอินใช้ไม่ได้: บางวิดเจ็ตต้องแก้โค้ด ใช้พรอมป์แปลงของตัวนำเข้าหรือ ขอความช่วยเหลือ พร้อมไฟล์วิดเจ็ตต้นฉบับและภาพหน้าจอปัญหา โดยไม่แชร์ข้อมูลรับรองเซสชัน

ตัวเลือกอื่น: สกินแชตในตัว, CSS กำหนดเอง, หรือ การแก้ปัญหา OBS.
