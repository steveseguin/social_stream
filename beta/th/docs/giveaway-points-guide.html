การแจกของรางวัล ตั๋ว และรางวัลแต้ม

จัดจับรางวัลฟรี ให้ผู้ชมซื้อตั๋วด้วยคะแนน SSN หรือแจกคะแนนเป็นรางวัล

คู่มือทั้งหมด จับรางวัลฟรี ตั๋ว รางวัลคะแนน เกม หลายการจับรางวัล หน้าจอ OBS Event Flow Stream Deck และ API การสำรองข้อมูล แก้ปัญหา
เพิ่งเริ่มใช้การจับรางวัล? เริ่มจาก การแจกของรางวัลครั้งแรก คู่มือพร้อมภาพหน้าจอ

จัดจับรางวัลฟรีใน 5 ขั้นตอน

  1. ในป๊อปอัป เปิด ตัวเลือกแจกของรางวัล คง ID เป็น default และคีย์เวิร์ดเป็น !enter ตั้งราคาตั๋วและรางวัลคะแนนไว้ที่ 0.
  2. เลือก การ์ดผู้ชนะ, วงล้อชื่อ, หรือ วงล้อชุมชน ดูตัวอย่าง แล้วคัดลอกลิงก์เข้า OBS เป็น แหล่งเบราว์เซอร์ (Browser Source).
  3. คลิก เปิดรับผู้เข้าร่วม ผู้ชมพิมพ์คีย์เวิร์ดในแชตเพื่อเข้าร่วม
  4. คลิก ปิดรับผู้เข้าร่วม, จากนั้น จับผู้ชนะ (หากลืม การสุ่มจะปิดรับให้เอง)
  5. คลิก รอบใหม่ สำหรับสุ่มรอบใหม่ ผู้ชนะเก่ายังอยู่ในประวัติ
เปิด Social Stream Ninja ไว้ ปุ่มจะสุ่มให้ ไม่ต้องคลิกภายในแหล่ง OBS

วงล้อชุมชนแบบแยกเดิมยังใช้ได้หากไม่ใส่ &managed ในลิงก์ คะแนนและรีโมตต้องใช้ลิงก์ที่จัดการโดยระบบ

ขายตั๋วด้วยคะแนน SSN

  1. เปิด ระบบสะสมแต้ม ในป๊อปอัป (นี่คือคะแนน SSN ไม่ใช่คะแนนช่อง Twitch)
  2. ใน Giveaway Options เปิด ตั๋วและรางวัลแต้ม ตั้งค่า คะแนนต่อตั๋ว และ จำนวนตั๋วสูงสุดต่อผู้ชม.
  3. คลิก เปิดรับผู้เข้าร่วม สำหรับการจับรางวัลชื่อ friday ผู้ชมซื้อตั๋ว 5 ใบด้วย !ticket friday 5.
  4. ดูผู้เข้าร่วมใต้ จัดการการแจกของรางวัลและประวัติ.
เมื่อเกิดสิ่งนี้…คะแนน…
ผู้ชมซื้อตั๋วถูกกันไว้ ใช้ที่อื่นไม่ได้
ผู้ชมมีไม่เพียงพอ:ไม่ถูกหัก และไม่ได้ตั๋ว
คุณสุ่มผู้ชนะถูกใช้ไป
คุณคลิก ยกเลิกและคืนเงินคืนให้ทุกคน
คุณนำผู้ชมหนึ่งคนออกก่อนสุ่มคืนให้ผู้ชมคนนั้น
กติกาล็อกหลังมีผู้เข้าร่วมคนแรก หากต้องการเปลี่ยน ให้ยกเลิกและคืนคะแนนก่อนเริ่มรอบใหม่ รอบใหม่จะไม่ทิ้งรอบที่มีการจ่ายแล้ว การปิดและเปิดใหม่เป็นเพียงพักรอบ

แจกแต้ม

  1. ก่อนเปิดรับ ตั้งค่า รางวัลแต้มต่อผู้ชนะ และ จำนวนรางวัล.
  2. เปิดรับตามปกติ
  3. สุ่มครั้งละหนึ่งคน แต่ละผู้ชนะจะได้รับรางวัลเพิ่มในคะแนน

คะแนนรางวัลเป็นคะแนนใหม่ ไม่ได้มาจากการขายตั๋ว ยอดจ่ายสูงสุดคือรางวัล × จำนวนรางวัล

ย้อนกลับการสุ่มที่เสร็จแล้วไม่ได้ หากผิดพลาด ให้แก้คะแนนผู้ชมเอง การเชื่อมต่อหน้าจอใหม่ไม่จ่ายซ้ำ

เกมพร้อมรางวัลแต้ม

Number Hunt

  1. ตั้งประเภทเป็น Number Hunt (ผู้ดำเนินรายการควบคุม), คะแนนต่อตั๋ว 0, และ จำนวนรางวัล 1 เพิ่มรางวัลคะแนนหากต้องการ
  2. Social Stream เลือกเลขลับตั้งแต่ 1 ถึง 100
  3. ผู้เล่นทายด้วย !guess friday 50 (ใช้ ID การจับรางวัลของคุณ)

คำตอบผิดช่วยลดช่วงเลขให้ทุกคน คนแรกที่ตอบถูกชนะ ผู้ชมแต่ละคนทายได้หนึ่งครั้งทุก 5 วินาที

แสดงผ่านหน้าจอจับรางวัลหรือ games/numberhunt.html?session=YOUR_SESSION&managed&giveaway=friday เกมปกติไม่ให้คะแนน SSN

Coin Flip Pot

  1. ตั้งประเภทเป็น Coin Flip Pot, คะแนนต่อตั๋ว 1, จำนวนรางวัล 1, และ รางวัลแต้มต่อผู้ชนะ 0.
  2. ผู้ชมเดิมพันด้วย !ticket friday 3 heads หรือ !ticket friday 3 tails.
  3. ปิดรับแล้วสุ่ม โอกาสออกแต่ละหน้า 50/50 ไม่ขึ้นกับยอดเดิมพัน

ผู้ชนะได้เดิมพันคืนพร้อมส่วนแบ่งจากผู้แพ้ตามสัดส่วนเดิมพัน ไม่มีค่าธรรมเนียมหรือคะแนนใหม่ ตัวอย่าง: ผู้ชนะเดิมพัน 2 และ 1 ผู้แพ้เดิมพัน 5 กองรวม 8 คะแนนจึงจ่าย 5 และ 3

ต้องมีผู้เล่นทั้งสองฝั่ง มิฉะนั้นจะสุ่มไม่ได้ ยกเลิกก่อนสุ่มเพื่อคืนคะแนนทุกคน

แบ่งคะแนนเศษที่เหลืออย่างไร

คะแนนที่เหลือให้ส่วนแบ่งที่มีเศษมากที่สุดก่อน หากเท่ากัน ให้คนที่เข้าร่วมก่อน

จัดหลายการจับรางวัลพร้อมกัน

  • กำหนดชื่อสั้นให้แต่ละอันใน รหัสแจกของรางวัล (ตัวอักษร ตัวเลข -, _) และเพิ่ม &giveaway=ID ในลิงก์ OBS
  • คำสั่งซื้อตั๋วและทายต้องระบุชื่อการจับรางวัล เช่น !ticket friday 5.
  • ใช้คีย์เวิร์ดต่างกันสำหรับแต่ละการจับรางวัลฟรี คีย์เวิร์ดเดียวไม่ทำให้เข้าร่วมทั้งสองอัน
  • ตั๋วทั้งหมดหักจากยอดคะแนนเดียวของผู้ชม
ป๊อปอัปตั้งค่ารอบใหม่ หากต้องการดูกติกาจริงของรอบที่กำลังทำงาน ให้ดูตัวจัดการ การแก้ลิงก์ OBS เปลี่ยนแค่รูปลักษณ์

หน้าจอ OBS

  • ใช้ 1280 × 720 พื้นหลังโปร่งใส เว้นแต่เลือก แผงตามธีม.
  • วงล้อแสดงได้ถึง 120 ชื่อ แต่สุ่มผู้ชนะจากตั๋วทุกใบ
  • เมื่อเชื่อมต่อใหม่ จะแสดงผลที่บันทึกไว้ การตั้งค่าลดการเคลื่อนไหวจะข้ามแอนิเมชัน
  • Social Stream ไม่รู้ว่าฉาก OBS กำลังออกอากาศอยู่หรือไม่
เก็บสิ่งเหล่านี้เป็นความลับ: ลิงก์ควบคุม session ID และไฟล์สำรอง

Event Flow

  1. เพิ่ม แจกของรางวัล / ตั๋ว (ใต้คำสั่งคะแนน)
  2. เลือกการทำงาน: เข้าร่วมฟรี ซื้อตั๋ว ให้ตั๋วฟรี ปิดรับ สุ่มผู้ชนะ ยกเลิกและคืนคะแนน หรือสอบถามสถานะ
  3. เลือก ID การจับรางวัลและจำนวนตั๋ว หากเป็นกองเดิมพัน ให้เลือกหัวหรือก้อย
Buy tickets ใช้แต้มอยู่แล้ว อย่าวางคำสั่ง Spend Points ก่อนขั้นตอนนี้

ทำงานแทนผู้ชมที่ส่งข้อความ ใส่ตัวกระตุ้นหรือตัวกรองที่เชื่อถือได้ก่อนคำสั่งแจกคะแนนและควบคุมโฮสต์

รายละเอียด Event Flow เพิ่มเติม
  • หากล้มเหลว คำสั่งที่พึ่งพาจะหยุด แต่ข้อความแชตยังแสดง
  • ผลอยู่ใน meta.giveawayControlResult.
  • แผงทดสอบจำลองเท่านั้น หากทดสอบจริง ใช้โฮสต์หรือโปรไฟล์แยก
  • ตรวจยอดคะแนนตอนรัน ดังนั้นข้อความเข้าร่วมไม่สามารถหาอีกหนึ่งคะแนนสุดท้ายให้ตัวเอง
  • การป้องกันซ้ำทำงานดีที่สุดกับแหล่งที่มี message ID ของตัวเอง
  • เหตุการณ์ตามกำหนดเวลาที่ไม่มีผู้ชมซื้อตั๋วไม่ได้

Stream Deck และ API

ปลั๊กอิน Stream Deck มี: เปิดการจับรางวัล, ปิดการจับรางวัล, สุ่มผู้ชนะ, ยกเลิกและคืนเงิน, รอบจับรางวัลใหม่, และ สถานะการจับรางวัล.

  • ใช้ default หากเป็นการจับรางวัลอื่น ให้ใส่ {"giveawayId":"friday"} ในช่องค่า Open giveaway รับค่า config อยู่ภายใน
  • ปุ่มยืนยันว่า Social Stream ตอบแล้ว ไม่ได้ยืนยันว่า OBS แสดง หากหมดเวลารอ ให้ตรวจสถานะก่อนสุ่มซ้ำ
ซื้อตั๋วผ่าน API 
{"protocol":2,"action":"buygiveawaytickets","get":"callback-1","value":{"giveawayId":"friday","roundId":"ROUND_ID","operationId":"purchase-123","count":5,"actor":{"chatname":"Avery","type":"youtube","userid":"SOURCE_USER_ID"}}}
  • operationId ตั้งชื่อการซื้อ; get ตั้งชื่อคำตอบ
  • ใช้ operation ID เดิมเมื่อลองซ้ำ ใช้ ID ใหม่สำหรับการซื้อใหม่
สิทธิ์ API ของโฮสต์ใช้คะแนนของผู้ชมคนใดก็ได้ อย่าเปิดเป็นแบบฟอร์มสาธารณะ

ประวัติและการสำรอง

จัดการการแจกของรางวัลและประวัติ แสดงรอบ ผู้เข้าร่วม และผู้ชนะ คุณสามารถ ส่งออกประวัติผู้ชนะ (JSON) หรือสำรองคะแนนและการจับรางวัลทั้งหมด ไม่มีการอัปโหลดข้อมูล

หลังรีสตาร์ต รอบที่เปิดจะกลับมาในสถานะปิด โดยตั๋วยังกันไว้ เปิดใหม่ สุ่ม หรือยกเลิกและคืนคะแนน

กู้คืนไฟล์สำรอง

ใช้ได้เฉพาะ โฮสต์ใหม่ ที่ไม่มีคะแนนหรือการจับรางวัล

  1. ปิดโฮสต์เดิมไว้ เปิด SSN ในโปรไฟล์เบราว์เซอร์ใหม่ แล้วเปิดตัวจัดการจับรางวัล
  2. ใน กู้บนตัวหลักใหม่ เลือกไฟล์สำรองเต็ม รอข้อความและจด session ID ที่แสดง
  3. ในส่วนของป๊อปอัป ตัวเลือกเซสชัน กรอก session ID นั้น
  4. กลับไปที่ตัวจัดการ เลือก ID การจับรางวัล แล้วคลิก รีเฟรช ตรวจ rules ผู้เข้าร่วม และผู้ชนะ รอบที่กู้คืนจะปิดรับไว้
  5. เปิดใหม่ สุ่ม หรือ ยกเลิกและคืนเงิน แล้วบันทึกสำรองใหม่
ห้ามรันโฮสต์เดิมและโฮสต์ที่กู้คืนพร้อมกัน ไฟล์สำรองไม่มีข้อมูลหลังเวลาที่บันทึก และไม่รวมการตั้งค่าป๊อปอัป
ข้อมูลเพิ่มเติมเรื่องตำแหน่งจัดเก็บ
  • คะแนนอยู่ในโปรไฟล์เบราว์เซอร์หรือแอปนี้ ไม่ซิงก์ไปที่อื่น รอบแยกเก็บตามเซสชัน
  • การล้างข้อมูลเบราว์เซอร์อาจลบข้อมูลเหล่านี้ เก็บสำรองไว้นอกโปรไฟล์นั้น
  • นำเข้าเฉพาะยอดคะแนนไม่สามารถกู้ตั๋วที่กันไว้ได้ ระบบไม่ให้รีเซ็ตคะแนนขณะมีตั๋วกันไว้ และไม่ลบประวัติการจับรางวัล
  • การซื้อสติกเกอร์ที่ยังไม่ยืนยันจะถูกปล่อยคืนเมื่อหมดเวลารอ
  • ไม่มีสำรองบนคลาวด์หรือแลกเป็นเงินสด การสำรองบนเซิร์ฟเวอร์อาจมาในอนาคต
