เชื่อมต่อร้านค้า แสดงสินค้าของคุณ

การแจ้งเตือนจาก Fourthwall, Ko-fi และ Buy Me a Coffee พร้อมสินค้าที่มีรหัส QR

เชื่อมต่อการแจ้งเตือน Fourthwall Ko-fi Buy Me a Coffee นำเข้าสินค้า แสดงบนสตรีม แก้ปัญหา

เชื่อมต่อการแจ้งเตือนใน 5 ขั้นตอน

  1. เปิด การสร้างรายได้ → การแจ้งเตือน Fourthwall, Ko-fi และ Buy Me a Coffee แล้วเลือก ผู้ให้บริการ.
  2. คลิก การตั้งค่าตัวรับ แล้วเปิด การควบคุมส่วนขยายจากระยะไกลผ่าน API.
  3. กลับไปที่การสร้างรายได้แล้วคลิก คัดลอก URL ของ webhook.
  4. วางในหน้าตั้งค่า webhook ของผู้ให้บริการ (ขั้นตอนด้านล่าง)
  5. เปิด Social Stream Ninja ไว้
ทำงานอยู่หรือไม่ “เชื่อมต่อตัวรับแล้ว” หมายถึง SSN กำลังรอรับเท่านั้น บรรทัดกิจกรรมล่าสุดจะอัปเดตเมื่อมีกิจกรรมจริงเข้ามา (รีเซ็ตเมื่อเริ่มใหม่)
เก็บ URL ของ webhook เป็นส่วนตัว นี่คือการป้องกันเพียงอย่างเดียวของการแจ้งเตือนเหล่านี้ (ไม่มีการตรวจสอบรหัสลับสำหรับลายเซ็น) เหมาะสำหรับการแจ้งเตือน ไม่ใช่หลักฐานชำระเงินสำหรับส่งสินค้า อย่าโพสต์หรือใส่ในรหัส QR

ดูตัวอย่างการแจ้งเตือน แสดงเฉพาะรูปลักษณ์ ไม่กระทบยอดรวม Event Flow หรือ webhook ของคุณ

สำหรับ NinjaBacker, Throne, Amazon และ eBay ดู คู่มือการสร้างรายได้สำหรับ Shopify ดู ตั้งค่า Shopify.

Fourthwall

  1. ใน Fourthwall เปิด การตั้งค่า (Settings) → สำหรับนักพัฒนา (For Developers) → Webhooks.
  2. สร้าง webhook แล้ววาง URL ของ Fourthwall จาก SSN
  3. เลือกกิจกรรมที่ต้องการ (ดูตาราง)
  4. บันทึกแล้วเปิด SSN ไว้

Ko-fi

  1. เปิด Ko-fi Webhooks.
  2. วาง URL ของ Ko-fi จาก SSN ลงใน URL ของ Webhook และบันทึก
  3. เปิด SSN ไว้

ทิปสาธารณะ สมาชิก คำสั่งซื้อ และงานคอมมิชชันใช้ลิงก์เดียวกันนี้ การชำระเงินส่วนตัวจะไม่รวม คำสั่งซื้อและคอมมิชชันแสดงเป็นการซื้อและไม่เพิ่มยอดบริจาค Ko-fi ไม่รายงานสมาชิกที่ยกเลิก

ทดสอบด้วยโหมดตัวอย่างของ SSN การชำระเงินทดสอบของ Ko-fi ดูเหมือนรายการจริงและอาจกระตุ้นการแจ้งเตือน ยอดรวม และแอ็กชัน อย่าใช้ขณะเปิดรางวัลที่ชำระเงิน

นำเข้าสินค้า Fourthwall

  1. ใน Fourthwall ไปที่ การตั้งค่า (Settings) → สำหรับนักพัฒนา (For Developers) แล้วสร้าง Storefront tokenอย่าใช้คีย์ API สำหรับผู้ดูแลระบบ
  2. ใน SSN เปิด สินค้าและลิงก์สนับสนุน → ตั้งค่าสินค้าและลิงก์ → นำเข้าสินค้า Fourthwall.
  3. วางลิงก์สาธารณะของสินค้าและโทเคน คลิก โหลดรายละเอียดสินค้า.
  4. ตรวจสอบชื่อ รูปภาพ ราคา และลิงก์ ลิงก์ต้องมาจากร้านเดียวกับโทเคน
  5. เลือกวัตถุประสงค์: ซื้อสินค้า ของขวัญ สนับสนุน หรือเข้าร่วม
  6. คลิก เพิ่มสินค้าหรือลิงก์ให้เปิด สินค้าและลิงก์สนับสนุนแล้วคลิก บันทึกการตั้งค่า.
การนำเข้าทำอะไรบ้าง
  • โหลดสินค้าสาธารณะที่พร้อมขายครั้งละหนึ่งชิ้น
  • โทเคนระบุร้านที่จะค้นหา ใช้ครั้งเดียวแล้วล้างออก ไม่บันทึกหรือส่งไปยังโอเวอร์เลย์
  • หากตัวเลือกสินค้าหรือชุดสินค้ามีราคาต่างกัน ช่องราคาจะเว้นว่าง
  • ข้อมูลเป็นภาพ ณ เวลานำเข้า ราคา สต็อก และรูปภาพไม่อัปเดตเอง ให้นำเข้าใหม่หรือแก้ไขเมื่อเปลี่ยนแปลง
  • บันทึกสินค้าได้สูงสุด 20 ชิ้น การเพิ่มสินค้าเดิมซ้ำจะสร้างสำเนาอีกชิ้น

แสดงสินค้าและรหัส QR บนสตรีม

คุณเพิ่มลิงก์สาธารณะด้วยตนเองได้ เช่น Shopify, Tiltify หรือ Patreon แต่จะไม่เชื่อมต่อการแจ้งเตือนชำระเงิน

  1. ใน โอเวอร์เลย์ OBS สำหรับ เลือก สินค้าและลิงก์สนับสนุน.
  2. เปิด ตัวเลือกลิงก์โอเวอร์เลย์ แล้วเลือก มุมมองโอเวอร์เลย์: แสดงสินค้าเท่านั้น การ์ดสนับสนุนเท่านั้น แจ้งเตือนกิจกรรมเท่านั้น หรือแสดงสินค้าและแจ้งเตือน
  3. คลิก คัดลอกลิงก์ OBS แล้วเพิ่มใน OBS เป็น แหล่งเบราว์เซอร์ (Browser Source)เริ่มที่ 800 × 600 ใช้หนึ่งแหล่งต่อหนึ่งมุมมอง
  4. ใน ตัวเลือกแสดงผลปักหมุดสินค้าชิ้นแรกหรือหมุนเวียนสินค้า แล้วเปิด แสดง QR code.
  5. สแกนรหัส QR ด้วยโทรศัพท์จากเลย์เอาต์ OBS สุดท้ายของคุณ
สแกนรหัส QR ไม่ได้ใช่ไหม อย่าย่อหรือตัดโอเวอร์เลย์มากเกินไป หากต้องการแชร์ลิงก์ในแชต ให้คลิก คัดลอกลิงก์สาธารณะ.
การแจ้งเตือน การแจ้งเตือนหลายรายการ และ Event Flow
  • หน้าต่างแสดงสินค้ามีรูปสินค้า แต่การ์ดสนับสนุนขนาดเล็กไม่มี
  • การแจ้งเตือนกิจกรรมทำงานได้เอง และไม่แสดงรหัส QR ของสินค้าที่ไม่เกี่ยวข้อง
  • การแจ้งเตือนหลายรายการและฟีดกิจกรรมใช้เซสชันเดียวกันได้โดยไม่ต้องมีรายการสินค้า มุมมองกิจกรรมในการสร้างรายได้ต้องเปิดรายการสินค้า
  • ใน Event Flow ทริกเกอร์การบริจาคยังครอบคลุมแถวที่มี hasDonationใช้ประเภทกิจกรรมสำหรับการซื้อหรือของขวัญที่เสร็จสมบูรณ์ ดู การจับคู่อีเวนต์.

สลับสินค้าแบบสดหรือแชร์ลิงก์ผู้ชมเดียว ดู การควบคุมสินค้าแบบสด.

หากไม่มีอะไรปรากฏ

ปัญหาลองวิธีนี้
ปิดตัวรับอยู่เปิด การควบคุมส่วนขยายจากระยะไกลผ่าน APIสวิตช์ API อื่นทำหน้าที่ต่างกัน
ไม่ได้เชื่อมต่อเปิด SSN ไว้และตรวจสอบอินเทอร์เน็ต นี่คือการเชื่อมต่อของ SSN ไม่ใช่ของผู้ให้บริการ
ไม่ได้รับกิจกรรมตรวจสอบผู้ให้บริการที่เลือก URL และการตั้งค่า webhook ของผู้ให้บริการ
ข้ามกิจกรรมแล้วไม่รวมการทดสอบ การชำระเงินส่วนตัว กิจกรรมที่ไม่รองรับ และยอดไม่ถูกต้อง
ได้รับกิจกรรมแล้ว แต่ไม่มีโอเวอร์เลย์ตรวจสอบเซสชัน รหัสผ่าน ตัวกรอง กฎ SSN และการมองเห็นแหล่งใน OBS การซื้อส่วนใหญ่ไม่ใช่การบริจาค
การแจ้งเตือนแสดงซ้ำอย่าส่งการชำระเงินเดียวกันผ่านทั้งผู้ให้บริการและบริการอื่น
นำเข้าไม่สำเร็จตรวจสอบลิงก์สินค้าและโทเคน Storefront รวมถึงว่าสินค้าเป็นสาธารณะและพร้อมขาย คุณกรอกเองได้เสมอ

นี่คือฟีดการแจ้งเตือนสด ไม่ใช่บันทึกคำสั่งซื้อ ใช้แดชบอร์ดของผู้ให้บริการจัดการการชำระเงิน การคืนเงิน และการจัดส่ง ยังไม่รองรับการแจ้งเตือน Tiltify และ Patreon
