เครื่องพิมพ์ความร้อนและป้ายสำหรับสตรีม

เปลี่ยนการซื้อ การบริจาค และเหตุการณ์แชตให้เป็นใบเสร็จ สติกเกอร์ ตั๋ว หรือป้ายรับสินค้าจริง

ตั้งค่า พิมพ์เมื่อบริจาค พิมพ์ยอดขาย ฉลาก Whatnot เลือกกระดาษ ขนาดฉลาก ไอเดีย แก้ปัญหา

ตั้งค่าใน 6 ขั้นตอน

ก่อนเริ่ม: ต้องใช้แอปสแตนด์อโลนบน Windows เครื่องพิมพ์ต้องแสดงเป็นเครื่องพิมพ์ Windows ปกติ Social Stream พิมพ์ผ่านไดรเวอร์ Windows ไม่ส่งคำสั่ง ESC/POS, ZPL หรือ SDK ผู้ผลิตโดยตรง
  1. ต่อเครื่องพิมพ์ผ่าน USB เปิดเครื่อง แล้วติดตั้งไดรเวอร์ Windows พิมพ์หน้าทดสอบของ Windows เพื่อยืนยันว่าใช้งานได้
  2. ใน Social Stream ให้เปิด Global settings and tools → Mechanics - Connections & Integrations → Printer Control.
  3. คลิก ค้นหาเครื่องพิมพ์ (Find printers) เลือกเครื่องพิมพ์ตามชื่อที่ Windows แสดง
  4. กรอก ความกว้างกระดาษ (มม.) ปกติคือ 58, 80, หรือ 62.
  5. คงค่า ความยาวป้ายคงที่ (Fixed label length) ที่ 0 สำหรับกระดาษใบเสร็จ หากเป็นฉลากไดคัต ให้กรอกความยาวเป็นมม. ตามทิศทางป้อนกระดาษ
  6. คลิก ทดสอบพิมพ์ หากขอบถูกตัด เพิ่มระยะปลอดภัยด้านนั้นแล้วทดสอบใหม่

ระยะปลอดภัยซ้ายขวาเริ่มต้น 2 มม. เหมาะกับเครื่องพิมพ์ใบเสร็จ 58 มม. ราคาประหยัดหลายรุ่น ไดรเวอร์เป็นตัวกำหนดพื้นที่พิมพ์จริง จึงควรคง ใช้พื้นที่พิมพ์ (Use printable area) ไว้ เว้นแต่คุณทดสอบค่าอื่นแล้ว

พิมพ์ยอดขาย ของขวัญ และเลขคำสั่งซื้อ

ฉันต้องการพิมพ์…ทำตามนี้
ยอดขายใช้ ประเภทอีเวนต์ พร้อม purchase. บริจาค / ทิป (Donation / Tip) ต้องใช้ hasDonation จึงพลาดยอดขายส่วนใหญ่
ของขวัญที่เสร็จสมบูรณ์ใช้ gift หรือ giftfunded กรองตามผู้ให้บริการหากจำเป็น
เลขคำสั่งซื้อต่อเนื่องเพิ่ม ตัวนับ (Counter) ก่อนคำสั่งพิมพ์

ดู ฟิลด์เหตุการณ์พาณิชย์ เพื่อดูว่าแต่ละการขายมีข้อมูลอะไร

ใช้ตัวหนาสำหรับผู้ซื้อ และตัวปกติสำหรับสินค้า

  1. ตั้งค่า น้ำหนักตัวอักษร เป็น ข้อความที่เลือก.
  2. กรอกข้อความฉลากนี้:
**{username}**
{subtitle}
  • เฉพาะข้อความภายใน ** จะเป็นตัวหนา ไม่ต้องใช้ HTML หรือ JavaScript
  • ใช้วงเล็บปีกกาเดี่ยว การขายใส่ชื่อสินค้าไว้ใน {subtitle} จำนวนอาจอยู่ใน {meta.commerce.quantity}.
  • หากขั้นตอนก่อนหน้าสร้าง buyer ให้ใช้ **{buyer}** แทน
  • Shopify และ eBay ไม่ส่งชื่อผู้ซื้อ ใช้ตัวนับคำสั่งซื้อหรือป้ายเฉพาะสินค้าแทน
  • ฉลากที่ตั้งเป็น All bold หรือ Normal อยู่แล้วจะคงรูปลักษณ์เดิม
สำหรับผู้สร้างโฟลว์: ผลการพิมพ์และเลขผู้ซื้อ

คำสั่งเพิ่ม meta.thermalPrintResult.success พร้อมข้อผิดพลาดหรือรหัสเมื่อล้มเหลวสำหรับขั้นตอนถัดไป สำเร็จหมายถึงส่งงานให้ Windows แล้ว ไม่ได้แปลว่ากระดาษออก ตรวจคิวพิมพ์ Windows ก่อนลองใหม่ ไม่เช่นนั้นอาจได้ฉลากซ้ำ

Counter นับการซื้อ ไม่ใช่ผู้ซื้อที่ไม่ซ้ำ หากต้องการให้ผู้ซื้อคนเดิมได้เลขเดิมทุกครั้ง ต้องมีรายการจับคู่ผู้ซื้อกับเลขแยกต่างหาก และรีเซ็ตตอนเริ่มแต่ละสตรีม ช่อง reason ของ User Memory เป็นข้อความธรรมดา ไม่ใช่ตัวนับเลขผู้ซื้อ

ฉลากสินค้า Whatnot

ดาวน์โหลดโฟลว์ตัวอย่าง Whatnot พิมพ์ชื่อผู้ซื้อเป็นตัวหนา ชื่อสินค้า และ ID คำสั่งซื้อหากมี หากชำระเงินไม่สำเร็จ จะพิมพ์ฉลากแยกชื่อ ชำระเงินไม่สำเร็จ พร้อมรายละเอียดที่แจ้งเตือนนั้นมี

  1. ในแอปแบบสแตนด์อโลน ตั้งค่า ควบคุมเครื่องพิมพ์ (Printer Control) แล้วสั่งพิมพ์ทดสอบ
  2. เปิด ตัวแก้ไข Event Flow คลิก นำเข้า (Import) แล้วเลือกไฟล์ที่ดาวน์โหลด
  3. เลือก Whatnot: ป้ายสินค้า + คำเตือนการชำระเงิน ตรวจคำสั่งพิมพ์ทั้งสองตัว ซึ่งใช้เครื่องพิมพ์และความยาวฉลากจาก Printer Control
  4. เปิดโฟลว์แล้วบันทึก เมื่อนำเข้าจะปิดไว้
  5. เปิดแหล่ง Whatnot ไว้พร้อมเปิดจับเหตุการณ์สตรีม
ฉลากขายไม่ได้หมายความว่าจ่ายเงินแล้ว แต่ละแจ้งเตือนจะพิมพ์ทันทีที่เข้ามา โฟลว์ไม่รอชำระเงิน ไม่แก้ฉลากก่อนหน้า และไม่แจกเลขผู้ซื้อ ช่องที่ไม่มีข้อมูลพิมพ์เป็นว่าง แจ้งเตือนล้มเหลวที่ไม่มีผู้ซื้อ สินค้า หรือรายละเอียดคำสั่งซื้อไม่สามารถระบุว่าเป็นของฉลากใด
โฟลว์ตัวอย่างทำงานอย่างไร

ใช้ Event Type (Advanced) → Custom Event สำหรับ product_sold และ payment_failed โดยกรองเป็น Whatnot การเสนอราคาและแจ้งจบประมูลไม่สั่งพิมพ์ ดู ฟิลด์เหตุการณ์ Whatnot.

เลือกกระดาษ

ม้วนใบเสร็จ

สำหรับใบซื้อ บัตรคิว และใบเสร็จทุกความยาว ตั้งความยาวฉลากคงที่เป็น 0

ม้วนสติกเกอร์แบบต่อเนื่อง

สำหรับแถบชื่อแบบติดกาวทุกความยาว ทำงานเหมือนกระดาษใบเสร็จ แต่เครื่องพิมพ์หรือไดรเวอร์ต้องตัดให้

ป้ายไดคัท

สำหรับป้ายและฉลากสินค้าขนาดตรงกัน กำหนดความยาวคงที่ให้ตรง และเลือกชนิดกระดาษเดียวกันใน Printing Preferences ของ Windows

ตัวอย่างเครื่องพิมพ์

เครื่องพิมพ์เหมาะสำหรับหมายเหตุ
รุ่นทั่วไป “POS-58”ใบเสร็จ 58 มม. ราคาประหยัดปกติเป็น USB ชื่อและไดรเวอร์ต่างกันตามผู้ขาย ใช้ POS-58 รุ่นพื้นฐานทดสอบ Social Stream

Brother QL-800สติกเกอร์และป้ายชื่อUSB กว้างสูงสุด 62 มม. แบบไดคัตหรือต่อเนื่อง พร้อมใบมีดอัตโนมัติ
Brother QL-820NWBจุดพิมพ์ป้ายที่ใช้ร่วมกันหรือเชื่อมต่อเครือข่ายUSB, Ethernet, Wi-Fi และ Bluetooth

นี่เป็นตัวอย่าง ไม่ใช่รายชื่อที่ทดสอบแล้ว ก่อนซื้อ ตรวจว่ารุ่นนั้นมีไดรเวอร์ Windows ปัจจุบัน รองรับขนาดฉลากของคุณ และแสดงเป็นเครื่องพิมพ์ Windows ปกติ

ตั้งฉลากขนาดคงที่ให้ถูกต้อง

ฉลาก 3 × 1 นิ้ว (รวม Munbyn BT320): ตั้งความกว้างเป็น 76.2 มม. และความยาวคงที่เป็น 25.4 มม. เมื่อป้อนด้าน 1 นิ้วก่อน เลือกกระดาษและทิศทางเดียวกันใน Printing Preferences ของ Windows เริ่มด้วยข้อความ 12–14 pt
กฎเหตุผล
วัดตามทิศป้อนกระดาษฉลาก 62 × 29 มม. ปกติกว้าง 62 มม. และยาวคงที่ 29 มม.
ให้ตรงกับ Windows ด้วยตั้งชนิดกระดาษ ทิศทาง การตรวจช่องว่าง/มาร์ก และใบมีดให้ตรงกันใน Printing Preferences ของไดรเวอร์
ความยาวคงที่ก็คือคงที่ไม่มีการป้อนกระดาษเพิ่ม ข้อความสูงเกินไปอาจถูกตัดหรือไหลไปฉลากถัดไป ขึ้นอยู่กับไดรเวอร์
ทดสอบข้อความที่ยาวที่สุดชื่อยาว ตัวเลือกสินค้า และบรรทัดเพิ่มต้องใช้พื้นที่มากขึ้นหรือตัวอักษรเล็กลง
ฉลากสั้นมากอาจใช้ไม่ได้Social Stream กำหนดขั้นต่ำ 20 มม. แต่ไดรเวอร์อาจยังจำกัดขนาดหน้าที่สั้น

เส้นขอบด้านข้างของหน้าทดสอบแสดงความกว้างปลอดภัย ความสูงขึ้นกับข้อความทดสอบ ไม่ได้ตีกรอบฉลากทั้งใบ

ไอเดียสำหรับสตรีม

  • สติกเกอร์ชื่อผู้สนับสนุนสำหรับผนัง พร็อพ แผนที่ หรือบอร์ดความคืบหน้า
  • ป้ายสินค้า งานคอมมิชชัน เครื่องดื่ม หรือรับของเมื่อคำสั่งซื้อเข้ามา
  • ตั๋วจับรางวัล เพิ่มการจำกัดอัตราและตรวจสิทธิ์ก่อนขั้นตอนพิมพ์
  • ป้าย VIP ชื่อทีม โทเคนภารกิจ หรือฉลากฉลองเป้าหมาย
  • รายการงานสั้น ๆ สำหรับโปรดิวเซอร์ที่นั่งข้างคุณ
อย่าพิมพ์ข้อมูลส่วนตัว ไม่ใส่ที่อยู่ อีเมล รายละเอียดชำระเงิน และข้อความส่วนตัว กระดาษความร้อนยังซีดจางจากความร้อน แสง และเวลา
