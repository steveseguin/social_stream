เครื่องพิมพ์ความร้อนและป้ายสำหรับสตรีม

เปลี่ยนการซื้อ การบริจาค และเหตุการณ์แชตให้เป็นใบเสร็จ สติกเกอร์ ตั๋ว หรือป้ายรับสินค้าจริง

พิมพ์อะไรได้บ้าง?

แอปแบบสแตนด์อโลนสำหรับ Windows สามารถส่งงานไปยังเครื่องพิมพ์ที่ติดตั้งใน Windows โดยไม่เปิดกล่องโต้ตอบ โฟลว์สามารถรวมค่าที่มีอยู่ เช่น ชื่อผู้ชม ยอดบริจาค สินค้า ข้อความ หรือค่าตัวนับ และควบคุมขนาดกับการจัดแนวข้อความ

หลักการตรวจสอบความเข้ากันได้: เครื่องพิมพ์ต้องปรากฏเป็นคิวเครื่องพิมพ์ Windows ที่ใช้งานได้ Social Stream พิมพ์ผ่านไดรเวอร์ Windows ที่ติดตั้ง ไม่ได้ส่งคำสั่ง ESC/POS, ZPL หรือ SDK ของผู้ผลิตโดยตรง

ตั้งค่าอย่างรวดเร็ว

  1. เชื่อมต่อเครื่องพิมพ์ผ่าน USB เปิดเครื่อง แล้วติดตั้งไดรเวอร์ Windows พิมพ์หน้าทดสอบของ Windows ก่อน
  2. ใน Social Stream ให้เปิด การตั้งค่าและเครื่องมือส่วนกลาง → ควบคุมเครื่องพิมพ์ (Printer Control).
  3. เลือก ค้นหาเครื่องพิมพ์ (Find printers) แล้วเลือกชื่อคิวให้ตรงตามที่ Windows แสดง
  4. กรอกความกว้างกระดาษจริง โดยทั่วไปคือ 58, 80, หรือ 62 มม. ขึ้นอยู่กับอุปกรณ์และวัสดุพิมพ์
  5. คงค่า ความยาวป้ายคงที่ (Fixed label length) ที่ 0 สำหรับใบเสร็จที่ปรับขนาดตามเนื้อหา สำหรับป้ายไดคัท ให้กรอกความยาวป้ายตามทิศทางป้อนกระดาษเป็นมิลลิเมตร
  6. เลือก พิมพ์ทดสอบการจัดแนว (Print alignment test)หากขอบหายไป ให้เพิ่มระยะขอบปลอดภัยด้านนั้นแล้วทดสอบอีกครั้ง

ระยะขอบปลอดภัยซ้ายและขวาเริ่มต้น 2 มม. เหมาะกับเครื่องพิมพ์ใบเสร็จ 58 มม. ราคาประหยัดหลายรุ่น แต่ไดรเวอร์เป็นตัวกำหนดพื้นที่พิมพ์จริง ให้คง ใช้พื้นที่พิมพ์ (Use printable area) เลือกไว้ เว้นแต่คุณได้ทดสอบการตั้งค่าอื่นแล้ว

ม้วนใบเสร็จ สติกเกอร์ต่อเนื่อง หรือป้ายไดคัท?

ม้วนใบเสร็จ

เหมาะสำหรับใบซื้อสินค้า บัตรคิว และใบเสร็จผู้สนับสนุนที่มีความยาวไม่แน่นอน ตั้งความยาวป้ายคงที่เป็น 0 และให้เนื้อหากำหนดความยาวกระดาษ

ม้วนสติกเกอร์แบบต่อเนื่อง

เหมาะสำหรับแถบชื่อแบบกาวที่มีปริมาณข้อความต่างกัน ทำงานเหมือนกระดาษใบเสร็จ แต่เครื่องพิมพ์หรือไดรเวอร์ต้องจัดการการตัด

ป้ายไดคัท

เหมาะสำหรับป้ายชื่อและป้ายสินค้าที่ต้องการขนาดสม่ำเสมอ ตั้งความยาวคงที่ให้ตรง และตั้งวัสดุชนิดเดียวกันใน Windows Printing Preferences

ตัวอย่างเครื่องพิมพ์เหมาะสำหรับหมายเหตุการเชื่อมต่อและวัสดุพิมพ์
รุ่นทั่วไป “POS-58”ใบเสร็จต่อเนื่อง 58 มม. ราคาประหยัดโดยทั่วไปใช้ USB และพิมพ์ความร้อนโดยตรง ชื่อรุ่นและไดรเวอร์แตกต่างกันตามผู้ขาย การทดสอบพิมพ์จริงระหว่างพัฒนา Social Stream ใช้คิว POS-58 พื้นฐาน
Epson TM-T20IIIตัวเลือกเครื่องพิมพ์ใบเสร็จที่เป็นที่แพร่หลายกว่ารุ่น USB รองรับกระดาษ 80 มม. และกระดาษ 58 มม. เมื่อใช้ตัวปรับความกว้างที่ให้มา
Brother QL-800สติกเกอร์และป้ายที่อยู่/ชื่อผ่าน USBพิมพ์ความร้อนโดยตรง รองรับวัสดุกว้างสูงสุด 62 มม. ทั้งม้วนไดคัทและม้วนต่อเนื่อง พร้อมตัวตัดอัตโนมัติ
Brother QL-820NWBจุดพิมพ์ป้ายที่ใช้ร่วมกันหรือเชื่อมต่อเครือข่ายรองรับ USB, Ethernet, Wi-Fi และ Bluetooth พร้อมป้ายไดคัทและป้ายต่อเนื่องของ Brother
Zebra ZD220ป้ายสินค้า ป้ายจัดส่ง สายรัดข้อมือ หรือป้ายทนทานที่กว้างกว่าเครื่องพิมพ์ป้าย USB ตั้งโต๊ะสำหรับวัสดุประมาณ 25–112 มม. มีทั้งรุ่นความร้อนโดยตรงและรุ่นถ่ายโอนความร้อน

นี่คือตัวอย่าง ไม่ใช่รายชื่อที่รับประกันความเข้ากันได้ ก่อนซื้อ ให้ตรวจสอบว่ารุ่นนั้นมีไดรเวอร์ Windows ปัจจุบัน รองรับขนาดป้ายของคุณ และปรากฏเป็นเครื่องพิมพ์ Windows ปกติ

  6. เปิด ทดสอบโฟลว์ (Test Flow)กรอกชื่อ แล้วเปิด มีการบริจาค (Has Donation)กรอกจำนวนเงิน แล้วทดสอบ การดำเนินการนี้ส่งงานพิมพ์จริงในแอปแบบสแตนด์อโลน

สำหรับการขาย ใช้ Event Type กับ purchaseโดย Donation / Tip ต้องมี hasDonation และจะไม่ตรงกับการขายส่วนใหญ่ ใช้ gift หรือ giftfunded เมื่อป้ายระบุของขวัญที่เสร็จสมบูรณ์ และกรองผู้ให้บริการหากจำเป็น เพิ่ม Counter ก่อนแอ็กชันพิมพ์เมื่อต้องการหมายเลขคำสั่งซื้อที่นับต่อเนื่องสำหรับสตรีม ดู ฟิลด์เหตุการณ์พาณิชย์.

แอ็กชันมีค่าให้ใช้คือ meta.thermalPrintResult.success และข้อผิดพลาด/รหัสถ้ามีสำหรับขั้นตอนถัดไปของโฟลว์ สถานะสำเร็จหมายถึงส่งงานแล้ว ไม่ได้หมายความว่ากระดาษพิมพ์ออกมาแล้ว ตรวจสอบคิว Windows ก่อนลองงานที่ไม่แน่ใจซ้ำ เพื่อหลีกเลี่ยงป้ายซ้ำ

Counter นับการซื้อ ไม่ได้นับผู้ซื้อที่ไม่ซ้ำกัน การใช้ ID เดียวกันกับทุกการซื้อของผู้ซื้อคนเดิมต้องมีการจับคู่ผู้ซื้อกับ ID แยกต่างหาก และรีเซ็ตอย่างชัดเจนเมื่อเริ่มแต่ละสตรีม ฟิลด์ reason ของ User Memory เป็นข้อความคำอธิบาย ไม่ใช่ตัวนับ ID ผู้ซื้อโดยเฉพาะ

ป้ายสินค้า Whatnot

ดาวน์โหลดโฟลว์ตัวอย่าง Whatnotระบบจะพิมพ์ชื่อผู้ซื้อเป็นตัวหนา ชื่อสินค้า และ ID คำสั่งซื้อเมื่อมีข้อมูล การแจ้งเตือนการชำระเงินล้มเหลวจะพิมพ์แยกเป็น ชำระเงินไม่สำเร็จ ป้ายพร้อมรายละเอียดที่มีในการแจ้งเตือนนั้น

  1. ในแอปแบบสแตนด์อโลน ให้ตั้งค่า ควบคุมเครื่องพิมพ์ (Printer Control) ให้เหมาะกับเครื่องพิมพ์และขนาดกระดาษของคุณ แล้วเรียกใช้การทดสอบการจัดแนว
  2. เปิด ตัวแก้ไข Event Flow เลือก นำเข้า (Import)แล้วเลือกไฟล์ JSON ที่ดาวน์โหลด
  3. เลือก Whatnot: ป้ายสินค้า + คำเตือนการชำระเงินตรวจสอบแอ็กชันพิมพ์ทั้งสอง ซึ่งใช้เครื่องพิมพ์และความยาวป้ายตามค่ากลาง
  4. เปิดใช้งานโฟลว์แล้วบันทึก เปิดแหล่งข้อมูล Whatnot ของคุณไว้พร้อมเปิดการเก็บเหตุการณ์สตรีม

ตัวอย่างจะอยู่ในสถานะปิดใช้งานเมื่อนำเข้า โดยใช้ Event Type (Advanced) → Custom Event สำหรับ product_sold และ payment_failedพร้อมตัวกรองแหล่งข้อมูล Whatnot การประมูลราคาและการแจ้งเตือนว่าการประมูลกำลังจะสิ้นสุดจะไม่พิมพ์ป้าย

ป้ายการขายไม่ได้ยืนยันการชำระเงิน ตัวอย่างนี้พิมพ์การแจ้งเตือนแต่ละรายการเมื่อมาถึง ไม่รอการชำระเงิน ไม่แก้ไขป้ายก่อนหน้า และไม่กำหนดหมายเลขผู้ซื้อ ฟิลด์ที่ไม่มีข้อมูลจะพิมพ์เป็นช่องว่าง การแจ้งเตือนความล้มเหลวที่ไม่มีรายละเอียดผู้ซื้อ สินค้า หรือคำสั่งซื้อจะไม่สามารถระบุป้ายก่อนหน้าได้ ดู ฟิลด์เหตุการณ์ Whatnot.

ป้ายความยาวคงที่โดยไม่มีปัญหาที่คาดไม่ถึง

ป้ายขนาด 3 × 1 นิ้ว (รวมการตั้งค่า Munbyn BT320): ใช้ความกว้าง 76.2 มม. และความยาวคงที่ 25.4 มม. เมื่อด้าน 1 นิ้วอยู่ตามทิศทางป้อนกระดาษ ตั้งวัสดุและการวางแนวให้ตรงใน Windows Printing Preferences เริ่มด้วยข้อความ 12–14 pt แล้วทดสอบชื่อผู้ซื้อและชื่อสินค้ายาว

ขอบด้านข้างของการทดสอบการจัดแนวระบุความกว้างปลอดภัยหลังใช้การตั้งค่าพื้นที่พิมพ์และระยะขอบปลอดภัยที่เลือก ความสูงของกรอบขึ้นอยู่กับข้อความทดสอบ ไม่ได้ล้อมรอบทั้งป้ายหรือแตะขอบกระดาษจริง

  • วัดตามทิศทางป้อนกระดาษ ป้ายขนาด 62 × 29 มม. โดยทั่วไปใช้ความกว้างกระดาษ 62 มม. และความยาวป้ายคงที่ 29 มม.
  • ตั้งค่า Windows ให้ตรงกันด้วย เลือกวัสดุป้าย การวางแนว การตรวจจับช่องว่าง/เครื่องหมาย และพฤติกรรมตัวตัดให้ตรงใน Printing Preferences ของไดรเวอร์เครื่องพิมพ์
  • ความยาวคงที่หมายถึงคงที่จริง ๆ Social Stream ไม่เพิ่มระยะป้อนกระดาษใบเสร็จให้กับงานที่มีความยาวคงที่ เนื้อหาที่สูงเกินไปอาจถูกตัดหรือล้น ขึ้นอยู่กับไดรเวอร์
  • ทดสอบข้อมูลที่ยาวที่สุดซึ่งอาจเกิดขึ้นจริง ชื่อผู้ชมยาว ตัวเลือกสินค้า ป้ายสกุลเงิน และข้อความหลายบรรทัดต้องการพื้นที่มากขึ้นหรือฟอนต์เล็กลง
  • ข้อจำกัดของไดรเวอร์ยังคงมีผล Windows หรือไดรเวอร์เครื่องพิมพ์อาจจำกัดหน้ากำหนดเองที่สั้นมาก Social Stream ขอความยาวขั้นต่ำ 20 มม.

ไอเดียสำหรับสตรีม

  • พิมพ์สติกเกอร์ชื่อผู้สนับสนุนสำหรับติดผนัง พร็อพ แผนที่ หรือกระดานความคืบหน้าจริง
  • สร้างป้ายคำสั่งซื้อสินค้า งานรับจ้าง เครื่องดื่ม หรือรับสินค้าเมื่อมีการซื้อเข้ามา
  • พิมพ์ตั๋วจับฉลากหรือส่วนบัตรเข้าร่วมแจกของ โดยจำกัดอัตราและตรวจสอบสิทธิ์ก่อนแอ็กชันพิมพ์
  • ทำป้าย VIP ป้ายจัดทีม โทเคนท้าทาย หรือป้ายหมุดหมายการบริจาค
  • พิมพ์คิวดูแลแชตหรือจัดส่งแบบสั้นให้โปรดิวเซอร์ที่ทำงานข้างผู้สตรีม
คิดให้รอบคอบก่อนพิมพ์ข้อมูลส่วนบุคคล หลีกเลี่ยงที่อยู่ อีเมล รายละเอียดการชำระเงิน หรือข้อความส่วนตัว กระดาษความร้อนยังซีดจางจากความร้อน แสง และเวลา จึงไม่เหมาะสำหรับเก็บถาวร

วิธีแก้ปัญหาที่พบบ่อย

  • ไม่พบเครื่องพิมพ์: ตรวจสอบว่า Windows พิมพ์หน้าทดสอบได้ แล้วเริ่ม Social Stream ใหม่และเลือก Find printers อีกครั้ง
  • งานรายงานว่าสำเร็จแต่ไม่พิมพ์: เปิดคิว Windows ของเครื่องพิมพ์นั้น แล้วตรวจสอบข้อผิดพลาดเกี่ยวกับการหยุดชั่วคราว ออฟไลน์ กระดาษ ไดรเวอร์ หรือพอร์ต
  • ขอบถูกตัด: เปิด Use printable area ไว้ และเพิ่มระยะขอบปลอดภัยด้านนั้น
  • มีกระดาษเปล่ามากเกินไป: ใช้ความยาวคงที่ 0 สำหรับใบเสร็จ ลดระยะขอบล่างและระยะป้อน หรือกำหนดความยาวที่ตรงกับวัสดุป้าย
  • ป้ายหนึ่งใบกลายเป็นสองใบ: เนื้อหาสูงกว่าป้ายคงที่ หรือ Windows ใช้ขนาดวัสดุผิด ลดข้อความ ขนาดฟอนต์ ระยะบรรทัด และระยะขอบ
  • Test Flow ใช้เครื่องพิมพ์ผิดเครื่อง: เลือกเครื่องพิมพ์ที่กำหนดทับในโหนด Print Thermal Label หากเว้นว่างไว้ การทดสอบโดยตรงในตัวแก้ไขจะใช้เครื่องพิมพ์เริ่มต้นของ Windows
