AI ใน Social Stream Ninja

เลือกระหว่างผู้ช่วยดำเนินรายการด้วยเสียง บอตแชตสด ผู้ช่วยส่วนตัว เพื่อนร่วมสนทนาในเบราว์เซอร์ การดูแลแชต การแปล การค้นหาความรู้ และโอเวอร์เลย์ที่สร้างด้วย AI

เลือกผลลัพธ์ที่ต้องการ

ฉันต้องการ...ใช้ต้องใช้คีย์ API หรือไม่?
พูดคุยกับ AI ที่รับคำถามจากแชตสดและตอบออกเสียงได้ด้วยผู้ช่วยดำเนินรายการ AI: cohost.htmlขึ้นอยู่กับผู้ให้บริการ
ใช้แท็บ ChatGPT ที่เปิดในเบราว์เซอร์เป็นเพื่อนร่วมสนทนาแบบทดลองแหล่งเบราว์เซอร์ ChatGPTไม่มี
ตอบข้อความแชตที่เลือกจาก YouTube, Twitch, Kick หรือแพลตฟอร์มอื่นโดยอัตโนมัติแชตบอต AI หลักผู้ให้บริการในเครื่องหรือคลาวด์
แสดงหรือพูดคำตอบ AI โดยไม่โพสต์กลับเข้าแชตบอตหลัก + เฉพาะโอเวอร์เลย์ + TTSผู้ให้บริการในเครื่องหรือคลาวด์
มีผู้ช่วยส่วนตัวแบบตัวต่อตัวchatbot.htmlผู้ให้บริการในเครื่องหรือคลาวด์
กรอง แปล สรุป หรือตอบจากเอกสารการดูแลแชต การแปล การสรุป หรือ RAGผู้ให้บริการในเครื่องหรือคลาวด์
อธิบายโอเวอร์เลย์แล้วให้ AI สร้างaiprompt.html + aioverlay.htmlผู้ให้บริการในเครื่องหรือคลาวด์

“ChatGPT” สองความหมายที่แตกต่างกัน

ตัวเลือกคืออะไรบทสนทนา
ผู้ให้บริการ ChatGPT APISSN ส่งพรอมป์ต์ไปยัง OpenAI โดยใช้คีย์ API ของคุณและโมเดลที่เลือกบทสนทนา SSN/API ที่แยกจาก chatgpt.com
แหล่งเบราว์เซอร์ ChatGPTส่วนขยายอ่านข้อความโต้ตอบใหม่ของผู้ใช้และ ChatGPT ที่แสดงในหน้า chatgpt.com แท็บบทสนทนาในเบราว์เซอร์ที่คุณเปิดไว้ ไม่ใช้คีย์ API

สำคัญ: การเชื่อมต่อ OpenAI API ไม่ได้เชื่อม SSN เข้ากับบทสนทนาเว็บหรือเสียง ChatGPT ที่มีอยู่ API ของ OpenAI จัดการสถานะบทสนทนาของตัวเอง

ตัวเลือก 1: เพื่อนร่วมสนทนา ChatGPT ในเบราว์เซอร์ (รุ่นทดลอง)

นี่คือตัวเลือกที่ใกล้เคียงที่สุดหากคุณใช้ ChatGPT ใน Chrome อยู่แล้วและไม่ต้องการคีย์ API SSN จับข้อความโต้ตอบใหม่จากหน้าเว็บได้ในประเภทแหล่งข้อมูล openai เช่นเดียวกับการจับข้อมูลจากแหล่งแชต

จับบทสนทนา ChatGPT

  1. ติดตั้งและเปิดใช้ส่วนขยาย Social Stream Ninja สำหรับ Chrome
  2. ในป๊อปอัป ให้เลือกเปิดใช้ ChatGPT แหล่งข้อมูล
  3. เปิด https://chatgpt.com/ และโหลดหน้าใหม่หลังเปิดใช้แหล่งข้อมูล
  4. เปิดแผงด็อก SSN ด้วยเซสชันเดียวกัน
  5. ส่งข้อความใหม่ใน ChatGPT ข้อความใหม่จากผู้ใช้และ ChatGPT ควรปรากฏในแผงด็อก โดยตั้งใจไม่อ่านประวัติเดิม

ส่งแชตสดไปยังแท็บ ChatGPT ที่เปิดอยู่

  1. ทดสอบกับสตรีมส่วนตัวหรือไม่เป็นสาธารณะ และบทสนทนาข้อความ ChatGPT แบบปกติ
  2. ใน การจัดการ, เปิดใช้ ส่งต่อทุกข้อความ.
  3. ตั้งค่า เลือกปลายทางส่งต่อ เป็น openai เพื่อให้ข้อความผู้ชมที่จับได้ส่งไปยังแท็บ ChatGPT เท่านั้น
  4. เปิดแท็บ ChatGPT ทิ้งไว้ คำตอบใหม่จะกลับมายัง SSN เป็น openai ข้อความ
  5. ใช้เสียง ChatGPT หรือเอาต์พุต TTS/โอเวอร์เลย์ของ SSN เพื่อนำคำตอบเหล่านั้นออกสตรีม

รุ่นทดลอง: ส่วนควบคุมบนเว็บอาจเปลี่ยน การส่งต่อทั้งหมดอาจทำให้ข้อความท่วมบทสนทนา และโหมด ChatGPT Voice อาจไม่รับข้อความที่แทรกเหมือนหน้าข้อความปกติ ใช้ตัวกรองหรือสตรีมทดสอบก่อนส่งทุกข้อความของผู้ชม

สถานะการจับข้อมูลเว็บไซต์ AI

เว็บไซต์การรองรับในปัจจุบัน
ChatGPTทดลองจับข้อความโต้ตอบใหม่ โดยไม่อ่านประวัติเดิม การส่งต่อผ่านเบราว์เซอร์ทั่วไปสามารถกำหนดเป้าหมายไปยังช่องเขียนพรอมป์ต์ได้
Claudeไม่มีการจับบทสนทนา สคริปต์ Claude ที่ให้มามีหน้าที่ช่วยปรับรูปแบบหน้าเท่านั้น
Gemini, Copilot, Perplexity และเว็บไซต์ AI อื่น ๆขณะนี้ SSN ยังไม่มีแหล่งจับข้อมูลเว็บไซต์เหล่านี้โดยเฉพาะ แต่อาจใช้ API ได้หากมีชื่ออยู่ในรายการผู้ให้บริการ SSN

ตัวเลือก 2: ตั้งค่าผู้ให้บริการ AI ภายใน SSN

ใช้ผู้ให้บริการเมื่อคุณต้องการให้ SSN สร้างคำตอบ ดูแลข้อความ แปลแชต ค้นหาฐานความรู้ หรือสร้างโอเวอร์เลย์

ประเภทผู้ให้บริการตัวเลือกหมายเหตุ
ในเครื่องOllama; Local Gemma; Local Qwenไม่ต้องใช้คีย์ API คลาวด์ ประสิทธิภาพขึ้นอยู่กับคอมพิวเตอร์และไฟล์โมเดล
เซิร์ฟเวอร์กำหนดเอง/ในเครื่องAPI กำหนดเองที่เข้ากันได้กับ OpenAIสำหรับ llama.cpp, LM Studio, vLLM และเกตเวย์ที่เข้ากันได้ ส่วน Ollama ควรใช้ตัวเลือกเฉพาะของมัน
คลาวด์OpenAI, Gemini, DeepSeek, xAI, AWS Bedrock, OpenRouter, Groq, OpenCode Zenผู้ให้บริการแต่ละรายเป็นผู้ควบคุมคีย์ การเข้าถึง การคิดค่าบริการ โควตา และชื่อโมเดล
ทดลองใช้LLM ทดลองที่ SSN โฮสต์ไว้เป็นรุ่นทดลองและอาจถูกปิดหรือจำกัดอัตราการใช้งาน
  1. เปิด แชตบอตและบริการ AI ในป๊อปอัป SSN
  2. เปิด ตั้งค่าผู้ให้บริการ LLM และเลือกผู้ให้บริการที่คุณใช้จริง
  3. ป้อน endpoint, model, คีย์ API หรือการตั้งค่าไฟล์โมเดลในเครื่อง
  4. เลือก ทดสอบแชตบอตที่เลือก ผล Connected ยืนยันเพียงว่าผู้ให้บริการตอบการทดสอบแล้ว
  5. เปิดฟีเจอร์ที่ต้องการใช้แยกต่างหาก เช่น บอตหลัก บอตส่วนตัว ผู้ช่วยดำเนินรายการ การดูแลแชต การแปล RAG หรือตัวสร้าง

ตัวเลือก 3: ผู้ช่วยดำเนินรายการ AI ด้วยเสียง

ผู้ช่วยดำเนินรายการออกแบบมาสำหรับการ “พูดกับ AI ขณะที่ AI เห็นแชตสดด้วย” โดยตรง เสียงไมโครโฟนและข้อความแชตสดที่เลือกจะเข้าสู่เซสชันผู้ช่วยดำเนินรายการเดียวกัน และพูดคำตอบออกสตรีมได้

  1. เปิด cohost.html?session=YOUR_SESSION.
  2. เลือกผู้ให้บริการเสียง/เรียลไทม์ หรือ LLM ที่ตั้งค่าไว้ในป๊อปอัป SSN
  3. เลือกไมโครโฟนอย่างชัดเจนและ คำตอบเสียง แล้วกด เริ่มผู้ช่วยดำเนินรายการ.
  4. เมื่อใช้ OpenAI Realtime ให้คง Live Chat ไว้ที่ ใช้เป็นบริบทเท่านั้น - ตอบเมื่อถาม เมื่อต้องการให้ AI จำข้อความล่าสุดของผู้ชมโดยไม่พูดแทรก เลือก คำถามและการกล่าวถึง หรือ ทุกข้อความ เพื่อพูดคำตอบอัตโนมัติ โหมดเหล่านี้ไม่โพสต์ลงแชตแพลตฟอร์ม
  5. สำหรับ OpenAI Realtime ให้จับเสียงจากเบราว์เซอร์/แอปผู้ช่วยดำเนินรายการใน OBS และใช้ cohost-overlay.html?session=YOUR_SESSION สำหรับอวาตาร์บนเวทีและกรอบคำพูด โอเวอร์เลย์ไม่ได้รับสตรีมเสียง WebRTC เดียวกัน ใช้ตัวเลือกอุปกรณ์เอาต์พุตของผู้ช่วยดำเนินรายการเพื่อเลือกสายเสียงเสมือนเมื่อรองรับ โดย &forcetts เพิ่มเสียงโอเวอร์เลย์แยกต่างหากโดยตั้งใจ
  6. เครื่องมือสตรีมเพิ่มเติมจะปิดอยู่ตามค่าเริ่มต้น เปิด Spotify รายการชื่อฉาก OBS ที่อนุญาต หรือการควบคุมแชตที่นำมาแสดงในป๊อปอัป SSN แล้วเปิดใช้เครื่องมือเดียวกันใน การควบคุมสตรีมของผู้ช่วยดำเนินรายการ บนหน้าผู้ช่วยดำเนินรายการ
  7. หากต้องการลดเวลาแฝง OpenAI ให้เลือกโมเดล Mini การให้เหตุผลระดับ Low และการผลัดกันพูดแบบ Fast ส่วน Full quality และระดับการให้เหตุผลที่สูงขึ้นอาจตอบคำถามยากได้ดีขึ้น แต่เพิ่มความล่าช้าและค่าใช้จ่าย API แบบ Fast อาจแทรกช่วงหยุดตามธรรมชาติ Diagnostics แสดงเวลาแฝงที่วัดได้ก่อนเริ่มตอบ
  8. อินพุตกล้องและ Screen Share ของ OpenAI เป็นตัวเลือกเพิ่มเติม โดยเริ่มต้นเป็น ไม่มีวิดีโอ เมื่อเลือกไว้ SSN จะส่งภาพปัจจุบันหนึ่งภาพต่อคำขอโดยตรงด้วยเสียงหรือข้อความ ไม่ใช่สตรีมวิดีโอต่อเนื่อง และอาจเพิ่มค่าใช้จ่าย API และเวลาแฝง
  9. แสดงกรอบคำพูดไว้ หรือจัดให้มีคำบรรยาย เพื่อให้ผู้ชมติดตามบทสนทนาได้โดยไม่ต้องฟังเสียง AI

OpenAI Realtime ใช้คีย์โปรเจกต์ OpenAI ที่ตั้งค่าใน ChatGPT API ในป๊อปอัป SSN คีย์มาตรฐานอยู่ในระบบเบื้องหลังของส่วนขยาย/แอปเดสก์ท็อป SSN ซึ่งสร้าง client secret ของ Realtime ที่มีอายุสั้นให้หน้าผู้ช่วยดำเนินรายการ จากนั้นเสียงไมโครโฟนและเสียง AI รับส่งผ่าน WebRTC คำตอบจำกัดที่ 512 โทเค็นเอาต์พุต และ Diagnostics แสดงยอดการใช้งานสะสมกับเวลาแฝง SSN ตรวจสอบเซสชันที่เงียบและเชื่อมต่อช่องทางรับส่งข้อมูลที่ล้มเหลวใหม่ เซสชันที่กู้คืนจะใช้คำสั่งและการตั้งค่าประสิทธิภาพเดิม แต่กู้บทสนทนาเสียงก่อนหน้าไม่ได้ การทำงานนี้สร้างเซสชันผู้ช่วยดำเนินรายการ SSN ไม่ได้เข้าควบคุมบทสนทนาเดิมในเว็บไซต์ ChatGPT หรือแอป ChatGPT บนเดสก์ท็อป

เปิดคู่มือผู้ช่วยดำเนินรายการ AI แบบละเอียด

ตัวเลือก 4: บอตแชตสดหลัก

บอตหลักประเมินข้อความผู้ชมที่จับได้ และตอบผ่านโอเวอร์เลย์ TTS หรือส่งกลับไปยังแชตแพลตฟอร์มที่รองรับได้

  1. ตั้งค่าและทดสอบผู้ให้บริการ AI
  2. เปิดใช้ แชตบอต AI หลัก.
  3. เลือกคำเรียกใช้งาน การจำกัดเฉพาะผู้ดูแล อัตราการใช้งาน ประวัติ และคำสั่งพรอมป์ต์
  4. สำหรับการทดสอบครั้งแรกอย่างปลอดภัย ให้เปิดใช้ คำตอบบอตส่งไปยังหน้าโอเวอร์เลย์บอตเท่านั้น.
  5. เปิด bot.html?session=YOUR_SESSION และเปิด TTS หากต้องการให้พูดคำตอบ
  6. ปิดโหมดเฉพาะโอเวอร์เลย์หลังจากยืนยันแล้วเท่านั้นว่าแพลตฟอร์มปลายทางรองรับการโพสต์

ปกติคำตอบบนแพลตฟอร์มใช้บัญชีที่ลงชื่อเข้าใช้อยู่ หากต้องการใช้ชื่อบัญชีแยก ให้ใช้บัญชีบอตเฉพาะสำหรับ YouTube, Twitch หรือ Kick ในกรณีที่รองรับ

ตัวเลือก 5: บอตส่วนตัวแบบตัวต่อตัว

chatbot.html เป็นหน้าผู้ช่วยส่วนตัวและทดสอบพรอมป์ต์ ให้เปิดใช้ แชตบอต - อินเทอร์เฟซส่วนตัว เปิดหน้าด้วยเซสชันของคุณ และใช้ผู้ให้บริการ LLM ที่ตั้งค่าไว้

บอตส่วนตัวแยกจากบอตแชตสดหลัก และขณะนี้ไม่ได้ใช้ชุดข้อมูล RAG หรือประวัติแชตอื่นร่วมกัน

เครื่องมือทำอะไรได้บ้างเริ่มต้นอย่างปลอดภัย
บอตเซ็นเซอร์จัดหมวดหมู่ ปรับข้อความให้เหมาะสม หรือบล็อกข้อความขาเข้าเริ่มจากโหมดที่ไม่บล็อกข้อความ แล้วตรวจสอบผลลัพธ์
การแปลแปลแชตขาเข้า และข้อความขาออกของผู้ดำเนินรายการหากเปิดใช้ทดสอบหนึ่งภาษาก่อน และหลีกเลี่ยงโหมดบล็อกจนกว่าจะเชื่อถือผลได้
ฐานความรู้ RAGให้บอตหลักค้นคืนข้อความที่เกี่ยวข้องจากไฟล์ข้อมูลที่อัปโหลดใช้ไฟล์ข้อความหรือ Markdown ที่เป็นปัจจุบันและเน้นเรื่องเฉพาะ
สรุปแชตให้ผู้ใช้เรียกสรุปด้วย AI ผ่าน !summary.ตรวจสอบขนาดประวัติ ค่าใช้จ่าย และเนื้อหาส่วนตัว

ตัวเลือก 7: AI Overlay Builder

ใช้ aiprompt.html เพื่ออธิบาย สร้าง ดูตัวอย่าง และบันทึกโอเวอร์เลย์ ใช้ aioverlay.html เป็นหน้าเอาต์พุต OBS หลังบันทึกแล้ว

เปิดคู่มือ AI Overlay Builder

วิธีแก้ปัญหาที่พบบ่อย

  • เชื่อมต่อแล้ว แต่ไม่มีคำตอบสด: เปิดบอตหลักหรือฟีเจอร์ AI ที่ต้องการ การตั้งค่าผู้ให้บริการเพียงอย่างเดียวไม่ได้ทำให้ประมวลผลแชต
  • ผู้ช่วยดำเนินรายการเห็นแชตแต่ไม่พูด: Context only ตั้งใจรอให้สตรีมเมอร์ถามเกี่ยวกับแชต เปลี่ยนเป็น Questions and mentions หรือ Every message หากต้องการคำตอบอัตโนมัติ
  • แหล่งเบราว์เซอร์ ChatGPT เงียบ: เลือกเปิดใช้ ChatGPT แล้วโหลดใหม่ที่ chatgpt.com และทดสอบด้วยข้อความโต้ตอบใหม่แทนประวัติเดิม
  • บอตข้ามข้อความส่วนใหญ่: ตรวจสอบคำเรียกใช้งาน โหมดเฉพาะผู้ดูแล การจำกัดอัตราการใช้งาน และคำสั่งให้โมเดลเลือกตอบบางข้อความ
  • มีข้อความแต่ไม่มีเสียง: ตรวจสอบว่าเปิดหน้าที่สร้างเสียง TTS อยู่ และ OBS จับเสียงของหน้านั้น
  • บอตโพสต์ไม่ได้: ตรวจสอบการรองรับส่งข้อความกลับของแพลตฟอร์ม สถานะการเข้าสู่ระบบ สิทธิ์บัญชี และการจำกัดอัตราการใช้งาน

เอกสารอ้างอิงเพิ่มเติม: ตั้งค่า TTS, AI TTS ในเครื่อง, และ การเชื่อมต่อ AI ผ่านคำสั่งและ API.
