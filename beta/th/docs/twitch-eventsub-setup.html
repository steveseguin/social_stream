การตั้งค่า Twitch และ EventSub

ใช้การเก็บข้อมูลหน้าเว็บปกติสำหรับแชตง่าย ๆ หรือโหมด EventSub/WebSocket สำหรับการติดตาม สมาชิก Bits รางวัล raid Hype Train และการควบคุมช่อง

เลือกโหมดแหล่งข้อมูล Twitchตั้งค่าแอปเดสก์ท็อปตั้งค่า EventSub ในส่วนขยายเบราว์เซอร์สิ่งที่ Twitch ร้องขออีเวนต์ที่แหล่งข้อมูลปัจจุบันรองรับสิ่งที่ควรตรวจสอบก่อนเมื่ออีเวนต์หาย

เลือกโหมดแหล่งข้อมูล Twitch

โหมดเหมาะสำหรับความแตกต่างสำคัญ
Standard เก็บแชตสาธารณะพื้นฐานจากหน้าแชต Twitch หรือหน้าต่างแชตแยก อ่านสิ่งที่หน้าเว็บแสดง วิธีนี้ง่ายแต่ไม่ได้ให้อีเวนต์ EventSub ครบชุด
WebSocket / EventSub การติดตาม การสมัครสมาชิก Bits รางวัล raid สถานะสตรีม Hype Train การซิงค์การดูแลแชต การส่งแชต และรายละเอียดช่อง ต้องใช้ Twitch OAuth อีเวนต์เปิดใช้เฉพาะเมื่อบัญชีที่ลงชื่อเข้าใช้ บทบาทช่อง คุณสมบัติช่อง และขอบเขตสิทธิ์ที่ได้รับอนุญาตให้ใช้

ตั้งค่าแอปเดสก์ท็อป

  1. เลือก เพิ่มแหล่งข้อมูล (Add source) → Twitch.
  2. ป้อนชื่อเข้าสู่ระบบของช่อง Twitch ที่ใช้ใน URL สำหรับ twitch.tv/examplechannel ให้ป้อน examplechannel.
  3. คงค่า WebSocket สำหรับแหล่งข้อมูล EventSub ที่มีข้อมูลครบกว่า ปัจจุบัน Twitch ใช้โหมดนี้เป็นค่าเริ่มต้นในแอป
  4. เลือก เปิดใช้งานแหล่งข้อมูล (Activate source), จากนั้น ลงชื่อเข้าใช้ Twitch.
  5. อนุญาตสิทธิ์ที่ร้องขอและเปิดหน้าต่างแหล่งข้อมูล Twitch ไว้

ตั้งค่า EventSub ในส่วนขยายเบราว์เซอร์

  1. ติดตั้งและเปิดใช้งานส่วนขยาย Social Stream Ninja เวอร์ชันปัจจุบัน
  2. เปิด หน้าแหล่งข้อมูล Twitch EventSub.
  3. แทนที่ examplechannel ใน URL ด้วยชื่อเข้าสู่ระบบของช่องที่ต้องการติดตาม
  4. เลือก ลงชื่อเข้าใช้ Twitch แล้วอนุมัติการเข้าถึงที่ร้องขอ
  5. เปิดหน้านั้นไว้ ยืนยันว่าช่อง User และ Channel ถูกต้องก่อนทดสอบการแจ้งเตือน
https://socialstream.ninja/sources/websocket/twitch.html?channel=CHANNEL_LOGIN

หากต้องการเก็บข้อมูลแบบ Standard พื้นฐาน ให้เปิดหน้าแชต Twitch ปกติหรือหน้าต่างแชตแยกและให้แชตมองเห็นได้

สิ่งที่ Twitch ร้องขอ

Social Stream ขอ user token พร้อมสิทธิ์ที่ตัวควบคุมและการสมัครรับที่รองรับต้องใช้ การให้ขอบเขตสิทธิ์ไม่ได้ทำให้บัญชีเป็นผู้ถ่ายทอดสดหรือผู้ดูแล Twitch ยังตรวจสอบบทบาทบัญชีในช่องที่เลือก

กลุ่มสิทธิ์ใช้สำหรับ
แชตอ่านแชต ส่งแชต และแสดงรายชื่อผู้แชต
ผู้ติดตามและสมาชิกอีเวนต์ติดตาม สมัครสมาชิก มอบสมาชิกเป็นของขวัญ และข้อความต่ออายุสมาชิก
Bits รางวัล และ Hype TrainCheers การแลกรางวัล Channel Points แบบกำหนดเอง และสถานะ Hype Train
การดูแลแชตการลบข้อความ แบน/พักการแชต และซิงค์การบล็อกเมื่อบัญชีมีสิทธิ์ดูแลช่อง
การจัดการช่องอ่าน/อัปเดตชื่อและหมวดหมู่ อ่าน/จัดการโฆษณา และแสดงสถิติช่อง

ดูเอกสารอย่างเป็นทางการของ Twitch เรื่อง เอกสารอ้างอิงขอบเขตสิทธิ์ และ ประเภทการสมัครรับ EventSub.

อีเวนต์ที่แหล่งข้อมูลปัจจุบันรองรับ

  • การติดตาม: new_follower.
  • การสมัครสมาชิก: new_subscriber, resub, และ subscription_gift.
  • Bits: cheer พร้อมมูลค่าการบริจาค
  • แต้มช่อง (Channel Points): reward.
  • Raid: raid.
  • สถานะสตรีมและโฆษณา: stream_online, stream_offline, และ ad_break.
  • Hype Train: hype_train การอัปเดตเริ่มต้น ความคืบหน้า และสิ้นสุด
  • การดูแลแชต: การอัปเดตการแบนและลบข้อความเมื่อมีสิทธิ์

อีเวนต์สมาชิก Twitch ต้องใช้ช่อง Affiliate/Partner ที่เข้าเกณฑ์และสิทธิ์ผู้ถ่ายทอดสด การสมัครรับการติดตามและการดูแลแชตต้องให้ผู้ลงชื่อเข้าใช้เป็นผู้ถ่ายทอดสดหรือผู้ดูแลที่อนุญาต ขึ้นอยู่กับอีเวนต์

สำหรับชื่อการแจ้งเตือนปลายทางและฟิลด์ข้อมูล ใช้ คู่มือความเข้ากันได้ของอีเวนต์และการแจ้งเตือน และ เอกสารอ้างอิงอีเวนต์.

สิ่งที่ควรตรวจสอบก่อนเมื่ออีเวนต์หาย

  1. ยืนยันว่าหน้าแหล่งข้อมูลแสดงค่าที่ถูกต้องของ ผู้ใช้ และ ช่อง.
  2. เปิดหน้า/หน้าต่างแหล่งข้อมูลไว้และยืนยันว่าการเชื่อมต่อแชตทำงานอยู่
  3. หากแชตทำงานแต่การติดตาม/สมาชิก/รางวัลไม่ทำงาน ให้ออกจากระบบแล้วอนุญาตอีกครั้งเพื่อให้ได้รับขอบเขตสิทธิ์ปัจจุบัน
  4. ตรวจสอบว่าบัญชีที่ลงชื่อเข้าใช้เป็นผู้ถ่ายทอดสดหรือผู้ดูแลที่ได้รับอนุญาตของช่องนั้น
  5. ตรวจสอบว่าแผงด็อกและโอเวอร์เลย์แจ้งเตือนใช้รหัสเซสชัน Social Stream เดียวกัน
  6. ใช้ข้อความทดสอบจำลองในป๊อปอัปหรือตัวอย่าง Multi Alerts เพื่อแยกปัญหาการเก็บข้อมูลจากปัญหาโอเวอร์เลย์

EventSub อาจส่งการแจ้งเตือนเดียวกันมากกว่าหนึ่งครั้ง Twitch ระบุว่ารับประกันการส่งอย่างน้อยหนึ่งครั้ง Social Stream มีการป้องกันข้อมูลซ้ำ แต่ผู้ใช้ API แบบกำหนดเองควรกำจัดข้อมูลซ้ำตามรหัสอีเวนต์/ข้อความเมื่อทำได้ ดูเอกสารอย่างเป็นทางการ ภาพรวม EventSub.
