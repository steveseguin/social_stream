กระดานช่องและการขายล่าสุด

ติดตามช่องที่ว่างและคงการซื้อล่าสุดไว้บนหน้าจอ ควบคุมจาก SSN และแสดงใน OBS

เปิดเผยช่อง ↓กระดานทีม ↓การขายล่าสุด ↓Whatnot / eBay Live ↓

กระดานช่อง

ช่องแบบมีหมายเลข

เปิดตัวอย่าง ↗
  1. สร้างกระดานใน การสร้างรายได้ → กระดานช่องและการขายล่าสุด, เลือกช่องแบบมีหมายเลข ใช้ 120 ช่องและ 20 คอลัมน์เพื่อได้ตาราง 20 × 6
  2. ทำเครื่องหมายการจองเลือกช่อง แล้ว บันทึกการขายสำหรับช่องนี้ หลังตรวจสอบการชำระเงิน ใช้ ทำเครื่องหมายว่าจองแล้วเท่านั้น สำหรับจองโดยไม่มีรายการขาย
  3. เปิดเผยสินค้าป้อนสินค้าที่จัดสรรไว้แล้วเลือก เปิดเผย ใช้ ตั้งให้ว่าง เพื่อแก้ไขช่อง หรือ คืนเงินและเปิดช่องใหม่ เพื่อนำการขายที่เชื่อมโยงออกด้วย

SSN แสดงการจัดสรรของคุณ ไม่ได้ขายช่องหรือสุ่มจัดสรรรางวัล

ช่องแบบมีชื่อ

การเปิดการ์ดแบบแบ่งทีม

การเปิดการ์ดแบบแบ่งทีมจะแบ่งการ์ดที่เปิดตามทีม ผู้เล่น หรือช่องที่ตั้งชื่อไว้อื่น ๆ

  1. เลือก ช่องแสดงทีม.
  2. วางชื่อทีม ทีละชื่อในแต่ละบรรทัด รายการนี้กำหนดจำนวนช่อง
  3. ทำเครื่องหมายช่องที่ซื้อแล้วว่าถูกจอง เปิดเผยเมื่อพร้อม
เปิดตัวอย่างทีม ↗

ผู้ดำเนินรายการเป็นผู้ควบคุมการจอง SSN ไม่อนุมานว่าซื้อทีมแล้วจากข้อความแชตหรือการประมูลจบ

ระหว่างรายการ Whatnot หรือ eBay Live

  1. จับข้อมูลรายการของคุณเปิดรายการของคุณใน SSN และเปิดใช้ จับอีเวนต์สตรีม (Capture Stream Events) Whatnot ต้องใช้หน้ารายการที่มองเห็นส่วนประมูลด้านล่าง eBay Live รองรับหน้าแชตหรือหน้าสตรีม
  2. ตรวจสอบการขายใน การขายล่าสุด, เลือก Whatnot หรือ eBay Live ใน ตัวช่วยสินค้าประมูล และบันทึก ใช้สินค้าประมูล คัดลอกชื่อล่าสุดที่จับได้ ตรวจสอบสินค้าและการชำระเงินบนแพลตฟอร์มขาย แล้วป้อนยอดขายรวมและสกุลเงิน
  3. ยืนยัน แล้วเปิดเผยสำหรับช่อง ให้เลือกช่องนั้นแล้วเลือก บันทึกการขายสำหรับช่องนี้ ก่อน ยืนยันการขายและจองช่อง บันทึกทั้งสองอย่างพร้อมกัน เพิ่มข้อความเปิดเผยเมื่อพร้อมแสดงสินค้าที่จัดสรร

ตัวช่วยเป็นร่างสำหรับผู้ดำเนินการ ไม่เปลี่ยนราคาเสนอหรือการประมูลจบให้เป็นการขาย การอัปเดตประมูลใหม่ไม่แก้ร่างของคุณ เปิดใช้ แสดงการขายล่าสุด เพื่อเลือกการแสดงสำหรับผู้ชม ใช้แหล่ง OBS แยกสำหรับกระดานและการขายหากต้องการทั้งคู่

สำหรับการคืนเงิน ให้ใช้ คืนเงินและเปิดช่องใหม่ กับการขายที่เชื่อมโยงเพื่อนำออกและคืนช่องให้ว่าง นำออก นำออกเฉพาะรายการขาย กระดานที่สร้างแทนแยกจากการขายของกระดานเดิม

การจับข้อมูลสดกับการเชื่อมต่อร้านค้า

การจับข้อมูล Whatnot และ eBay Live ให้ข้อมูลสินค้า ราคาเสนอ และสถานะประมูล ส่วนการเชื่อมต่อแยก การเชื่อมต่อผู้ขาย eBay รับอีเวนต์คำสั่งซื้อที่ชำระแล้วสำหรับประกาศขายที่เลือก และเพิ่มการขายล่าสุดโดยอัตโนมัติได้ หลีกเลี่ยงการยืนยันการซื้อเดียวกันด้วยตนเองหากการเชื่อมต่อร้านค้าบันทึกอยู่แล้ว แหล่งอัตโนมัติอื่นคือ Shopify, Fourthwall, Ko-fi และ Buy Me a Coffee

ตัวช่วยเก็บเฉพาะสินค้าล่าสุดที่จับได้จากแพลตฟอร์มที่เลือก หมดอายุหลังไม่มีอัปเดตห้านาที และล้างเมื่อเริ่มใหม่ ตรวจสอบสินค้าหากเปิดหลายรายการ ตัวช่วยที่ว่างต้องได้รับอัปเดตการประมูลใหม่หลังเปิดใช้

eBay: ตรวจสอบสถานะชำระเงินในคอนโซลผู้ขาย · Whatnot: การชำระเงินประมูลล้มเหลว

ประวัติการขาย

การซื้อล่าสุด

คงรายการซื้อจริงไว้ให้เห็นหลังการแจ้งเตือนหายไป เลือกรายการขนาดกะทัดรัด ผนังหกการ์ด หรือแถบข้างเนื้อหาหลัก

ตัวอย่างรายการ ↗ตัวอย่างผนัง ↗ตัวอย่างแถบ ↗

รวบรวมจากร้านค้า

เปิด แสดงการขายล่าสุด และ รวบรวมการซื้อจากร้านค้าที่เชื่อมต่อ แล้วบันทึกตัวเลือกการขาย

ใช้อีเวนต์ใหม่จาก Shopify, ผู้ขาย eBay, Fourthwall, Ko-fi และ Buy Me a Coffee ประเภท purchase ที่ SSN ได้รับ

ยืนยันการขายด้วยตนเอง

ป้อนสินค้า ยอดขายรวมถ้าต้องการ และสกุลเงิน เลือก ยืนยันการขาย.

เหมาะกับการขายผ่าน Whatnot, eBay Live หรือขายต่อหน้า หลังคุณตรวจสอบการซื้อแล้ว แถวเหล่านี้ระบุว่า ผู้ดำเนินรายการยืนยันแล้ว.

การแก้ไขและคืนเงิน

นำรายการผิดพลาดหรือการขายที่คืนเงินออก ล้างผนังเพื่อเริ่มรายการใหม่

ราคาเสนอ ทิป ของขวัญ และการทดสอบในพื้นที่ทดลองจะไม่เพิ่มรายการนี้ การจองช่องไม่สร้างรายการขาย

ราคา ประวัติ และความเป็นส่วนตัว

ฟีดการซื้อที่เชื่อมต่อไม่ได้ให้ราคาสินค้าสม่ำเสมอ แถวอัตโนมัติจึงเว้นราคาไว้ หากต้องการแสดงราคาที่ทราบ ให้ลบแถวนั้นแล้วยืนยันด้วยตนเอง สำหรับสินค้าหลายชิ้น ให้ป้อนยอดรวมของรายการนั้น ไม่ใช่ราคาต่อชิ้น ระบบไม่ใช้ราคาประกาศขาย ราคาประมูลสูงสุด หรือยอดบริจาคมาแทน

SSN เก็บ 100 รายการล่าสุดไว้ในการติดตั้งนี้ รวมถึงหลังเริ่มใหม่ การรวบรวมเริ่มเมื่อเปิดใช้ ไม่ใช่การนำเข้าประวัติคำสั่งซื้อทั้งหมด รหัสการส่งซ้ำจะถูกข้ามภายในชุด 2,000 รหัสที่บันทึกไว้ การคืนเงินต้องนำออกด้วยตนเอง

การแสดงนี้ไม่รวมชื่อผู้ซื้อ ที่อยู่ รายละเอียดการชำระเงิน และข้อความสินค้าที่ยังไม่เปิดเผย ลิงก์สาธิตใช้ข้อมูลสมมติที่ระบุไว้อย่างชัดเจน

ตั้งค่า OBS

  1. เลือกรูปแบบแสดงผลเลือก Spot / team board, Recent sales list, wall หรือ strip ในส่วนควบคุมกระดาน
  2. คัดลอกลิงก์ OBSเพิ่มแหล่งเบราว์เซอร์ที่ 1920 × 1080 พื้นที่โปร่งใสทำให้มองเห็นกล้องด้านหลัง
  3. ควบคุมใน SSNเปิด SSN ทิ้งไว้ การเปลี่ยนแปลงบันทึกทันที ส่วน แผงด็อกควบคุมสินค้าใน OBS มีส่วนควบคุมเหมือนกันหากคุณสะดวกใช้
การตั้งค่า URL เพิ่มเติม

&view=board, sales, wall หรือ ticker เลือกรูปแบบการจัดวาง &limit=6 แสดงรายการล่าสุดสูงสุดหกรายการ (สูงสุดที่ตั้งได้ 24) &prices=0 ซ่อนราคา &label=Recently%20sold ตั้งหัวข้อการขาย &onlytype=shopify,ebay กรองแหล่งการขาย

คงเซสชัน รหัสผ่าน และการตั้งค่ารีเลย์ไว้ในลิงก์ที่คัดลอก หากขาดการเชื่อมต่อหรือไม่มีรายการแสดงจะยังโปร่งใส ข้อความตั้งค่าจะไม่ปรากฏบนโอเวอร์เลย์ผู้ชม

ใช้เครื่องมือขายและจัดสรรที่แพลตฟอร์มอนุมัติ กระดาน SSN เป็นชั้นแสดงผล ไม่ได้แทนกฎหรือระบบชำระเงินของแพลตฟอร์ม

การเชื่อมต่อ API และ Event Flow

ตัวควบคุมเหล่านี้ต่อยอดจาก commerceControl API โดย SSN การกระทำ API กำหนดเองของ Stream Deck และแผงด็อก OBS ที่เลือกใช้ได้จะอ่านค่าเดียวกันจาก getCommerceState ผลตอบกลับ

{"action":"commerceControl","value":{"command":"boardSpot","data":{"id":"12","status":"claimed"}}}

คำสั่ง: boardSave (title, style, columns, count หรือ labels ที่แยกบรรทัด), boardSpot (id, status, result), boardVisibility (visible), saleAdd (title, amount/currency/quantity/platform หากต้องการ; ใช้ boardId และ spotId เพิ่มเพื่อจองช่องได้), saleRemove (id, reopenSpot หากต้องการ), salesClear, และ salesSettings (visible, automatic, auctionSource หากต้องการ: whatnot, ebay หรือสตริงว่าง) ใส่ช่องเหล่านั้นใน data การแก้ไขเหล่านี้ไม่ส่งอีเวนต์ซื้อหรือเรียกรางวัลแบบเสียเงิน

ใน Event Flow, ใช้ตัวที่มีอยู่ สินค้าและการสนับสนุน การกระทำ เลือกคำสั่งกระดานหรือการขายและป้อนช่องข้อมูลใน ช่องข้อมูลกระดาน / การขาย ค่าสตริงรับตัวแปรได้ เช่น {subtitle} จับคู่อีเวนต์การซื้อที่ยืนยันแล้วสำหรับการกระทำเกี่ยวกับการขาย ปิดการรวบรวมอัตโนมัติหากโฟลว์ของคุณเพิ่มการขายเดียวกันด้วยตนเอง
