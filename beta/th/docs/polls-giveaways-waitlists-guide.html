แบบสำรวจ การแจกของรางวัล และรายชื่อรอ

ให้แชตโหวต สุ่มผู้ชนะ หรือจัดคิวผู้ชมรอถึงตา

คู่มือทั้งหมด เครื่องมือไหน? เปิดโพล จัดการแจกของรางวัล สุ่มผู้ชนะด่วน คิวผู้ชม ทดสอบและแก้ไข

ต้องใช้เครื่องมือไหน?

ฉันต้องการ…เปิดส่วนนี้ในป๊อปอัป
ให้แชตโหวตGraphical Poll → Poll Options
สุ่มผู้ชนะพร้อมการเปิดเผยที่โดดเด่นGiveaway Tool → Giveaway Options
สุ่มชื่อจากรายการธรรมดารายการรอ / สุ่มผู้ชนะ เปิดโหมดสุ่มผู้ชนะ
รับผู้ชมตามลำดับรายการรอ / สุ่มผู้ชนะ ปิดโหมดสุ่มผู้ชนะ
ทั้งหมด: คัดลอกลิงก์เครื่องมือไปยัง OBS เป็น แหล่งเบราว์เซอร์ (Browser Source) และเปิด Social Stream Ninja กับแหล่งแชตไว้ อย่าลบเซสชันหรือรหัสผ่านออก

เปิดโพลใน 5 ขั้นตอน

  1. เปิด Graphical Poll → Poll Options ตั้งค่า ประเภทโพล เป็น หลายตัวเลือก.
  2. พิมพ์คำถาม เช่น เราควรเล่นอะไรต่อ? และตัวเลือกคั่นด้วยจุลภาค เช่น Adventure, Puzzle.
  3. ตั้งค่า การจับคู่โหวต เป็น เฉพาะข้อความโหวตที่ตรงเปิด เปิดโพล (Enable Poll).
  4. คัดลอกลิงก์โพลเข้า OBS ผู้ชมส่งเพียง 1 หรือ 2 (หรือชื่อตัวเลือก)
  5. คลิก จบโพล (End Poll) เพื่อหยุดโหวต จดผลแล้วคลิก รีเซ็ตโพล สำหรับรอบถัดไป

สิ่งที่ควรรู้

  • ผู้ชมแต่ละคนโหวตได้หนึ่งครั้ง เปิด อนุญาตให้ผู้ใช้โหวตหลายครั้ง เพื่อเปลี่ยนค่านี้
  • รูปแบบอิสระ โพลใช้การโหวตด้วยแฮชแท็ก เช่น #yes. แฮชแท็กอยู่ตรงไหนก็ได้ นับแฮชแท็กที่อยู่ในข้อความยาวด้วย
  • บันทึกโพลปัจจุบัน บันทึกการตั้งค่า ไม่ใช่ผลลัพธ์

สีหรือฟอนต์ที่กำหนดเอง: ปรับแต่งโพลกราฟิกของคุณ.

จัดการแจกของรางวัล

ใช้งานครั้งแรก? การแจกของรางวัลครั้งแรก อธิบายขั้นตอนพร้อมภาพหน้าจอ

  1. เปิด Giveaway Tool → Giveaway Options.
  2. ตั้งค่า คำสำคัญสำหรับเข้าร่วม เช่น !enter.
  3. เลือก การ์ดผู้ชนะ, วงล้อชื่อ, หรือ วงล้อชุมชน และหนึ่งในหกสไตล์
  4. คลิก ดูตัวอย่างหน้าจอ แล้วคัดลอกลิงก์ไปใส่ใน OBS เป็น Browser Source
  5. คลิก เปิดรับผู้เข้าร่วม เมื่อพร้อม คลิก จับผู้ชนะ.
  • การสุ่มจะปิดรับให้เอง
  • รอบใหม่ ล้างรายชื่อผู้เข้าร่วมและเก็บผู้ชนะเก่าในประวัติ เริ่มต้นโดยปิดรับ
  • ทุกสิทธิ์มีโอกาสเท่ากัน การบริจาคไม่เพิ่มโอกาส
  • เว้นแต่ อนุญาตให้ชนะซ้ำ เปิดอยู่ ผู้ชนะจะชนะซ้ำในรอบเดียวกันไม่ได้
  • เฉพาะสมาชิกเท่านั้นที่เข้าร่วมได้ ต้องใช้แพลตฟอร์มที่ส่งข้อมูลสมาชิก
ตั๋วที่ซื้อ รางวัลคะแนน หรือเกม? ดู การแจกของรางวัล ตั๋ว และรางวัลแต้ม.
รายละเอียดเพิ่มเติม: โอกาส การบันทึก และข้อจำกัด
  • ตัวอย่างใช้ชื่อสมมติและไม่เข้าร่วมเซสชันของคุณ หน้าจอ OBS ไม่มีปุ่มควบคุม
  • สไตล์และชื่อเรื่องอยู่ในลิงก์ กติกาการเข้าร่วมมาจากป๊อปอัปตอนเปิดรับ
  • หน้าจอที่ใช้ Giveaway ID เดียวกันจะแสดงรายชื่อและผู้ชนะเดียวกัน
  • ตั๋วที่ซื้อเพิ่มน้ำหนักโอกาสตามจำนวนตั๋ว
  • หนึ่งสิทธิ์ต่อคนต่อแพลตฟอร์ม คนเดียวกันบนสองแพลตฟอร์มนับสองสิทธิ์
  • รองรับสูงสุด 10,000 สิทธิ์ วงล้อแสดงได้ถึง 120 ชื่อ แต่สุ่มจากทุกคน
  • ระบบข้ามข้อความเก่า ข้อความเล่นซ้ำ ข้อความส่วนตัว บอต และข้อความที่มีแต่เหตุการณ์
  • รอบบันทึกแยกตามเซสชันในโปรไฟล์เบราว์เซอร์หรือแอปนี้ เมื่อรีสตาร์ต รอบที่เปิดอยู่จะปิดเพื่อให้ตรวจสอบ ไม่มีข้อมูลถูกลบ
ควบคุมจาก API, Stream Deck หรือ Event Flow

ป๊อปอัป HTTP/WebSocket API และ Stream Deck ใช้คำสั่งเหล่านี้ร่วมกัน ไม่ต้องเปิดหน้าจอแสดงผล ใน Event Flow ใช้ แจกของรางวัล / ตั๋ว (รายละเอียด).

resetgiveawayรอบใหม่ว่างและปิดรับ ผู้ชนะเก่าย้ายเข้าประวัติ คืนค่าตั๋วที่ซื้อก่อน
getgiveawaystateอ่านจำนวนผู้เข้าร่วม สถานะเปิดหรือปิด กติกา และผู้ชนะล่าสุด

Stream Deck (โปรโตคอล 2) ใช้ชื่อคำสั่งเดียวกัน ผลตอบกลับบอกสถานะการจับรางวัล ไม่ได้ยืนยันว่า OBS แสดงแล้ว

วงล้อชุมชนแบบแยกเดิม (ไม่มี managed ในลิงก์) เก็บรายชื่อของตัวเองและไม่ใช้คำสั่งเหล่านี้

สุ่มผู้ชนะด่วนจากคิวรอ

  1. เปิด รายการรอ / สุ่มผู้ชนะ แล้วขยายการตั้งค่า เปิดตัวกระตุ้นและกำหนดคำสั่ง เช่น !join.
  2. เปิด ตั้งเป็นโหมดสุ่มผู้ชนะแทนคิว คัดลอกลิงก์ที่อัปเดตแล้วเข้า OBS
  3. บอกคำสั่งให้ผู้ชม
  4. เมื่อปิดรับแล้ว คลิก หยุดรับรายชื่อ, จากนั้น เลือกผู้ชนะ.
  5. คลิก ดาวน์โหลดรายชื่อ เพื่อเก็บรายชื่อ แล้ว รีเซ็ตการสุ่ม เพื่อล้าง

จัดคิวผู้ชม

ตั้งค่าเหมือนการสุ่มผู้ชนะ แต่ตั้งโหมดสุ่มผู้ชนะเป็น ปิด ผู้ชมเข้าร่วมด้วยคำสั่งของคุณ

ปุ่มใช้เพื่อ
เน้นผู้เข้าร่วมลำดับแรกแสดงว่าใครเป็นคนถัดไป
นำผู้เข้าร่วมลำดับแรกออกไปคนถัดไปเมื่อจบตา
เลือกชื่อสุ่มคนแทนการเลือกตามลำดับ
หยุดรับรายชื่อปิดคิวไม่รับคนใหม่
ดาวน์โหลดรายชื่อ / รีเซ็ตคิวบันทึกสำเนา (ไฟล์ TSV) แล้วล้างเมื่อเสร็จ

อนุญาตให้ผู้ใช้ที่ถูกนำออกกลับเข้าร่วม กำหนดว่าคนที่ออกไปกลับมาต่อคิวได้หรือไม่

คำสั่งแชตสำหรับผู้ดูแล

เปิด เปิดคำสั่งควบคุมคิวรอ เพื่อให้ผู้ดูแล โฮสต์ และแอดมินจัดคิวจากแชตได้

!wlstop · !wlremove · !wlreset · !wlpick · !wlhighlight

บางคำสั่งรับตัวเลข เช่น !wlpick 3 หรือ !wlremove 2.

ทดสอบก่อน แล้วแก้ปัญหา

ก่อนถ่ายทอดสด ลองส่ง ข้อความทดสอบ จากผู้ใช้สมมติหลายคน แล้วตรวจว่า OBS แสดงผล

ปัญหาลองวิธีนี้
ไม่นับคะแนนโหวตตรวจว่าเปิด Enable Poll แล้ว โพลยังไม่จบ คำโหวตตรงทุกตัว และยังไม่ได้โหวตมาก่อน
ไม่มีใครเข้าร่วมได้ตรวจว่าเปิดตัวกระตุ้นแล้ว คำสั่งตรงทุกตัว ไม่ได้ปิดรับ และโหมดสมาชิกเท่านั้นไม่ได้กีดกันผู้ใช้
มีจำนวนแต่ไม่มีรายชื่อนั่นคือโหมดสุ่มผู้ชนะ ซึ่งแสดงรายชื่อผู้เข้าร่วมและผู้ชนะ ไม่ใช่คิว
OBS แสดงต่างออกไปวางลิงก์ใน OBS อีกครั้งแล้วตรวจเซสชันและรหัสผ่าน อย่าเปิดหน้าโพลสองหน้าที่ตั้งค่าต่างกัน

ปุ่มอุปกรณ์จริง: ดู ตั้งค่า Stream Deck และ แผงด็อกควบคุม OBS.
