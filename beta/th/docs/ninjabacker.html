ทิป NinjaBacker ใน Social Stream Ninja

รับทิปใน SSN แล้วเพิ่มการแจ้งเตือนหรือ Tip Jar ใน OBS

ฟีดสดWebhookหน้าจอ OBSทดสอบและแก้ปัญหา

1. เชื่อมต่อบัญชี

เริ่มจากแอปเดสก์ท็อป SSN หรือส่วนขยาย Chrome เปิด SSN ไว้ระหว่างสตรีม

  1. เปิด NinjaBacker. สร้างบัญชีและตั้งค่า Stripe ให้เสร็จเพื่อรับชำระเงิน
  2. ในแดชบอร์ด NinjaBacker เปิด Social Stream Ninja แล้วคัดลอก Private Tip ID
  3. ใน SSN เปิดการเงิน > ร้านค้าและการสนับสนุน > แพลตฟอร์มที่เชื่อมต่อ > การบริจาค NinjaBacker > ตั้งค่า กรอกชื่อผู้ใช้และ Tip ID ส่วนตัว
  4. ปล่อยการส่งไว้ที่ฟีดสด (แบบง่าย) เปิดการบริจาค NinjaBacker แล้วคลิกบันทึกการตั้งค่า

หากไม่เห็นแพลตฟอร์มที่เชื่อมต่อ ให้เปลี่ยนเป็นโหมดเต็มใน SSN

ฟีดสดไม่ต้องใช้ Webhook โดยจะแสดงทิปใหม่ขณะเชื่อมต่อ แต่ไม่เล่นซ้ำทิปที่ได้รับขณะปิด SSN

2. ทางเลือก: ใช้ Webhook

เลือก Webhook ที่เชื่อถือได้เพื่อเก็บทิปในคิวได้นานสูงสุดเจ็ดวันขณะปิด SSN

  1. ใน NinjaBacker เปิด Webhook ใต้ Webhook Signature Secret คลิก Generate แล้วคัดลอกคีย์ลับ หากใช้คีย์ลับอยู่แล้ว ให้คัดลอกคีย์เดิม
  2. ในการตั้งค่า NinjaBacker ของ SSN เลือก Webhook ที่เชื่อถือได้ วางคีย์ลับสำหรับลงลายเซ็น แล้วคลิกบันทึกการตั้งค่า
  3. คลิกคัดลอก URL ตัวรับใน SSN วางลงในช่อง Webhook URL ของ NinjaBacker แล้วคลิก Save

URL ตัวรับขึ้นต้นด้วย:

https://api.socialstream.ninja/v1/ninjabacker/webhook/...

URL ของ Tip Jar ด็อกแชต และหน้าจอแสดงผลอื่นใช้ใน OBS โดยไม่สามารถรับคำขอ Webhook ได้

เปลี่ยนกลับเป็นฟีดสด

การเปลี่ยนจะลบทิปที่รออยู่ในคิวของตัวรับ SSN ให้ล้าง Webhook URL เดิมใน NinjaBacker และบันทึกด้วย

3. เพิ่มหน้าจอแสดงผลใน OBS

  1. สำหรับการแจ้งเตือน เลือกการบริจาค NinjaBacker ในตัวเลือกโอเวอร์เลย์ OBS สำหรับ ภายในร้านค้าและการสนับสนุน แล้วคัดลอกลิงก์โอเวอร์เลย์
  2. สำหรับเป้าหมายสะสม เปิดการเงิน > Tip Jar และมาตรวัดเป้าหมาย เลือกรูปแบบและเป้าหมาย แล้วคัดลอกลิงก์
  3. ใน OBS เพิ่มแหล่งที่มาแบบเบราว์เซอร์แล้ววางลิงก์แสดงผล ให้ SSN และหน้าจอแสดงผลใช้เซสชันเดียวกัน

รูปแบบ Tip Jar และการตั้งค่าเป้าหมาย

แชร์หน้าทิปสาธารณะของ NinjaBacker กับผู้ชม ใส่ลิงก์โอเวอร์เลย์ใน OBS และ URL ตัวรับในช่อง Webhook

4. ตรวจสอบการตั้งค่า

เปิดโอเวอร์เลย์แจ้งเตือน NinjaBacker ของ SSN ใน NinjaBacker เปิด Testing แล้วคลิก Send Test Tip ควรมีการแจ้งเตือนทดสอบปรากฏในโอเวอร์เลย์นั้น

อ่านผลลัพธ์ใต้ Send Test Tip ข้อความ Webhook accepted ยืนยันว่าได้รับคำขอแล้ว ไม่ได้ยืนยันว่า OBS แสดงการแจ้งเตือน หากล้มเหลว ให้แก้ไข URL หรือข้อมูลลับสำหรับลงลายเซ็นแล้วส่งการทดสอบใหม่ การทดสอบจากแดชบอร์ดจะลองส่งซ้ำเป็นเวลาห้านาที

ทิปทดสอบจะไม่เพิ่มเงินใน Tip Jar ไม่แสดงเป็นการบริจาคที่ชำระเงินจริงในแชต และไม่เรียกใช้รางวัลแบบชำระเงิน

ไม่มีการแจ้งเตือนทดสอบ?

เปิด SSN และเปิดใช้งานการบริจาค NinjaBacker ตรวจสอบว่าชื่อผู้ใช้และ Tip ID เป็นบัญชีเดียวกัน สำหรับ Webhook ให้รีเฟรช Delivery History ใน NinjaBacker และตรวจสอบ URL ตัวรับกับคีย์ลับสำหรับลงลายเซ็น

HTTP 405 หรือข้อผิดพลาด URL แสดงผล?

คัดลอก URL ตัวรับจากการตั้งค่า Webhook ที่เชื่อถือได้ใน SSN บันทึกใน NinjaBacker แล้วส่งทิปทดสอบใหม่ การบันทึก URL ใหม่จะหยุดการลองส่งซ้ำไปยังปลายทางเดิม

ทิปแสดงในแชต แต่ไม่เพิ่มในเป้าหมาย?

ตรวจสอบเซสชันของ Tip Jar และตัวกรองแหล่งที่มา ประเภทการบริจาค และกิจกรรมแบบชำระเงิน ใช้เป้าหมายจำนวนเงินสำหรับยอดทิป การคืนเงินจะไม่หักออกจากการแจ้งเตือนหรือเป้าหมายใน SSN
