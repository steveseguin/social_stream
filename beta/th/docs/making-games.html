สร้างเกมและรางวัล

เปลี่ยนของขวัญ ยอดสนับสนุน หรือคำสั่งแชตให้เป็นสิ่งที่เกิดขึ้นในไลฟ์

วิธีทำงาน เลือกเทมเพลต เชื่อมต่อ ออกแบบเอง เลือกจำนวน แต่ละแพลตฟอร์มส่งอะไร มูลค่าเงิน สตรีกของขวัญ รางวัลแบบไม่เขียนโค้ด ทดสอบ

ใช่ เกมของคุณตอบสนองต่อของขวัญ TikTok ได้

ผู้ชมส่งของขวัญหรือแชต→ Social Stream Ninja จับข้อมูล→ หน้าของคุณตัดสินใจว่าจะเกิดอะไร

JavaScript ของคุณเลือกคำสั่ง เช่น เร่งจรวด ปลูกสวน สร้างศัตรู หรือเติมเป้าหมายร่วม คุณเลือกเกณฑ์เองด้วย SSN เปลี่ยนราคาของขวัญของแพลตฟอร์มไม่ได้

เลือกเทมเพลต

ทุกหน้าตัวอย่างมีปุ่มข้อมูลตัวอย่างและตัวตรวจ “Last received payload” ตัวอย่างเป็นเหตุการณ์จำลอง ไม่ใช่การซื้อ โหมดตัวอย่างไม่เข้าร่วมเซสชันสด

เทมเพลตทำอะไรเปลี่ยนค่านี้
จรวดเหรียญ10 เหรียญ TikTok, 100 Twitch Bits หรือ 100 Facebook Stars ให้แรงเร่งหนึ่งครั้ง ส่วนที่เหลือเก็บแยกตามผู้ชมและแพลตฟอร์มCOST
เป้าหมายการสนับสนุนร่วมกันมูลค่า USD โดยประมาณจากทั้งสี่แพลตฟอร์มสร้างฐานบนดวงจันทร์ได้ เปลี่ยนความคืบหน้าเป็นความเสียหาย เชื้อเพลิง หรือตัวจับเวลาได้GOAL_USD
สวนของขวัญและเหตุการณ์ของขวัญ TikTok ที่เลือกเพิ่มดอกไม้ การติดตาม TikTok เพิ่มต้นไม้ คำสั่งแชตฟรี !water จะเพิ่มน้ำGIFT_ID (ID ที่จับได้) หรือ GIFT_NAME (ชื่อตรงทุกตัว) “Demo flower” เป็นชื่อสมมติ
  • ใน HTML ค้นหา EDIT THIS RULE หรือ EDIT THESE RULES.
  • ใส่ตรรกะเกมใน receive(data) ฟังก์ชัน
  • ตัวช่วยเชื่อมต่อและนับอยู่ใน starter.js สไตล์อยู่ใน starter.css.

เชื่อมเทมเพลตใน 3 ขั้นตอน

  1. เปิด SSN และเชื่อมแชต ตรวจว่าแชตและของขวัญแสดงใน Dock สำหรับ TikTok ดู โหมดการเชื่อมต่อ.
  2. เปิดเทมเพลต โดยไม่มี ?demo โดยใช้ session ID ของคุณ และรหัสผ่านหากตั้งไว้
  3. ตรวจในเบราว์เซอร์ แล้วเพิ่มลิงก์เดียวกันใน OBS เป็น Browser Source เช่น 1000 × 800
https://socialstream.ninja/games/templates/coin-rocket.html?session=YOUR_SESSION&password=YOUR_PASSWORD&clean
  • &clean ซ่อนตัวตรวจข้อมูล สถานะเชื่อมต่อ และปุ่มโฮสต์
  • ไม่มีรหัสผ่าน? ไม่ต้องใส่ &password=….
  • บนเว็บไซต์ beta คง /beta/ ไว้ก่อน games/.
เก็บลิงก์เซสชันเป็นความลับ
เส้นทางเชื่อมต่ออื่น (WebSocket)

ค่าเริ่มต้นของเทมเพลตใช้ตัวเชื่อม iframe เดียวกับโอเวอร์เลย์ SSN

  • WebSocket ที่โฮสต์: เปิด ส่งข้อความจากส่วนขยายไปยังแผงด็อกผ่านเซิร์ฟเวอร์ ใน SSN แล้วเพิ่ม &server2.
  • เซิร์ฟเวอร์ในเครื่อง: เพิ่ม &server2&localserver, หรือ &localserverport=3000 ดู คู่มือ WebSocket.
  • localserver อย่างเดียวไม่เปิดเส้นทางเชื่อมต่อ
  • ฟีดรุ่นเก่า server ใช้คนละช่องทางและอาจต้องมี Dock ส่งข้อมูลไป

ทำสำเนาและรันจากดิสก์

ไม่ต้องติดตั้งเซิร์ฟเวอร์ คุณแก้ไฟล์ในคอมพิวเตอร์แล้วให้ OBS เปิดไฟล์นั้น

  1. ดาวน์โหลดซอร์ส beta แบบ ZIP แล้วแตกไฟล์
  2. คัดลอกเทมเพลตที่ต้องการไว้ข้างต้นฉบับ ตัวอย่าง: games/templates/my-rocket.html.
  3. คงโครงสร้างโฟลเดอร์ไว้ เทมเพลตโหลด js/local-server-url.jsส่วนเป้าหมายการสนับสนุนโหลด currency.js จากโฟลเดอร์หลัก เก็บรูปหรือเสียงในตำแหน่งเดิมด้วย
  4. ลาก HTML เข้า Chrome หรือ Edge แล้วคัดลอก file:/// ที่อยู่
  5. เพิ่มทุกอย่างตั้งแต่ ? เป็นต้นไปจากลิงก์เกมที่ใช้งานได้ (เซสชัน รหัสผ่าน ตัวเลือกการส่ง)
  6. ใน OBS ให้ออกไป ไฟล์ในเครื่อง (Local file) ออก วางที่อยู่เต็มในช่อง URL สนาม
  7. รีเฟรช Browser Source หลังแก้แต่ละครั้ง
file:///C:/SSN/social_stream-beta/games/templates/my-rocket.html?session=YOUR_SESSION&clean

ใช้พาธจริง อย่าย้ายโฟลเดอร์ที่แตกไฟล์ เซสชันคือ ID เชื่อมต่อ SSN ไม่ใช่ชื่อเกม ลบ demo สำหรับข้อมูลสด เปิด SSN และตัวจับข้อมูลไว้ ตัวอย่างเพิ่มเติม: คู่มือการตั้งค่าไฟล์.

กำลังแก้เกมที่มีอยู่? คุณคัดลอกหน้าใดก็ได้จาก games/. games.html และ battle.html มีตรรกะเกมของตัวเอง การตั้งค่ากฎของเทมเพลตไม่ใช่ API เกมร่วม

เลือกจำนวนเหรียญสำหรับการกระทำอย่างไร?

ตัดสินใจก่อนว่าจะวัดอะไร แล้วเลือกตัวเลข

สิ่งที่วัดอ่านค่านี้ตัวอย่าง
หน่วยดั้งเดิม (เหรียญ, Bits, Stars)TikTok meta.coinsPerGift × meta.tiktokGiftCount เมื่อมี หรือ hasDonation ป้ายข้อความ เช่น 10 coins, 100 bits, 100 Stars.ทุก 10 เหรียญ = แรงเร่งหนึ่งครั้ง
ของขวัญชนิดหนึ่งTikTok meta.giftId หรือ meta.giftNameพร้อมจำนวนทุกของขวัญที่ตรงกฎเพิ่มดอกไม้หนึ่งดอก ไม่ว่าราคาเท่าไร
มูลค่าเงินสำหรับเปรียบเทียบgetDonationValueUSD(data) จาก currency.js.ทุก $1 โดยประมาณเพิ่มเชื้อเพลิง 10 หน่วย $25 ทำให้ถึงเป้าหมาย
การกระทำฟรีหรือสมาชิกค่าจริงจากแหล่ง eventหรือคำสั่งแชตการติดตามทำให้ต้นไม้โต การสมัครใหม่เล่นแอนิเมชัน

จำนวนตรง ขั้นต่ำ หรือยอดสะสม?

  • จำนวนตรง: coins === 10 ของขวัญ 25 เหรียญจะไม่ทำอะไร
  • ขั้นต่ำต่อเหตุการณ์: coins >= 10.
  • ยอดสะสม: ที่จรวดใช้ 25 เหรียญ = เร่งสองครั้ง และเหลือ 5 เหรียญ

มีหลายระดับ? ตรวจระดับสูงสุดก่อน เพื่อไม่ให้ของขวัญเดียวเรียกทุกระดับต่ำกว่า

อาจไม่ทราบจำนวนเหรียญ TikTok หากตัวจับส่งมาแค่ชื่อ จำนวน หรือป้ายเพชร เกมจรวดเหรียญจะข้ามเหตุการณ์นั้น ใช้กฎของขวัญหรือเทมเพลต USD แทน อย่าหา “เหรียญที่แม่นยำ” จากการหารค่า USD โดยประมาณหรือถือว่าเพชรเท่ากับเหรียญ
ข้อมูลเพิ่มเติมเรื่องเหรียญ ของขวัญ และเพชร TikTok
  • ผู้ชมซื้อ Coins แล้วใช้กับ Gifts ราคาเหรียญแสดงพร้อมของขวัญ ดู คำอธิบายเหรียญและของขวัญของ TikTok.
  • ชื่อของขวัญ จำนวนของขวัญ Coins และ Diamonds เป็นสี่อย่างที่ต่างกัน
  • เลือกของขวัญที่มีใน LIVE ของคุณ และตรวจข้อมูลที่จับก่อนเผยแพร่กฎ
  • ค่าเหรียญอาจมาจากตารางของขวัญ SSN เทียบกับถาดของขวัญ LIVE ปัจจุบันหากต้องการราคาที่แม่นยำ
  • รายการของขวัญและวิธีจับข้อมูลต่างกัน ไม่รับประกันว่าทุกข้อความ TikTok จะมีช่องเหรียญ

แต่ละแพลตฟอร์มส่งอะไร

type ระบุว่ามาจากไหน event ระบุสิ่งที่เกิดขึ้นเมื่อมีค่านี้ ข้อมูลที่เข้าขึ้นกับโหมดจับ การตั้งค่า และแพลตฟอร์ม นี่สะท้อนโค้ดปัจจุบันของ SSN ไม่รับประกันว่าทุกบัญชีจะได้ทุกเหตุการณ์

แพลตฟอร์มสิ่งที่ได้ระวัง
TikToktype: "tiktok", event: "gift" การจับบริจาคอาจเพิ่ม hasDonation และ donoValue เมทาดาทาของขวัญอาจมี ID ชื่อ จำนวน เหรียญต่อชิ้น เพชรต่อชิ้น และ streak IDCoins ใช้ซื้อ Gifts ส่วน Diamonds เป็นรางวัลครีเอเตอร์ การจับ WebSocket ใน SSApp รวมสตรีกให้เสร็จก่อนส่ง แต่การจับเบราว์เซอร์อาจส่งยอดสะสม การปิดจับบริจาค TikTok อาจทำให้ของขวัญไม่มีช่องข้อมูลเงิน
TwitchCheers ใช้ Bits เช่น hasDonation: "100 bits" การจับผ่าน API อาจส่ง event: "cheer" และ donoValue: 1 การจับแชตอาจไม่มี eventการสมัคร การให้สมาชิกเป็นของขวัญ เรด และ Channel Points เป็นคนละอย่าง ตราสมาชิกบนข้อความปกติไม่ใช่การสมัครใหม่ Bits ใน Twitch Extensions เป็นอีกระบบ
Facebookแถว Stars ที่เห็นในแชตสดให้ข้อมูล เช่น hasDonation: "100 Stars" และ donoValue: 1โดยไม่มี event.เส้นทาง comments API ไม่อ่าน Stars จากข้อความแชต ต้องเห็นแถว Stars เพื่อให้การจับหน้าทำงาน ความคิดเห็นและปฏิกิริยาไม่ใช่การชำระเงิน
YouTubesuperchat และ supersticker มีสกุลเงินต้นฉบับใน hasDonationของขวัญใช้ jeweldonation พร้อม N Jewels, หรือ 1 YouTube Gift หากจำนวนเงินถูกซ่อนผู้ชมใช้ Jewels ส่วนครีเอเตอร์ได้รับ Rubies สมาชิกและสมาชิกที่ให้เป็นของขวัญเป็นเหตุการณ์แยก Super Thanks เป็นผลิตภัณฑ์แยก ไม่รับประกันว่าจะมีเหตุการณ์แชต

แหล่งอื่นอาจรายงานทิป ของขวัญ สมาชิก หรือการซื้อ ตรวจ เอกสารอ้างอิงเหตุการณ์ ก่อนเพิ่มลงตัวกรองของแม่แบบ isSupport การขายหรือให้สมาชิกเป็นของขวัญไม่ใช่ทิปโดยอัตโนมัติ YouTube ส่งทั้งการซื้อของขวัญและแจ้งผู้รับแต่ละคน การนับทั้งคู่จะให้รางวัลซ้ำ

ลิงก์อ้างอิงแพลตฟอร์ม

เพชร TikTok · Bits และการสมัครสมาชิก Twitch · ภาพรวม Stars ของ Meta · YouTube Super Chat และ Super Stickers · YouTube Jewels, Gifts และ Rubies.

ตรวจเงื่อนไขเมื่อ 29 กันยายน 2026 ตรวจหน้าแพลตฟอร์มปัจจุบันสำหรับคุณสมบัติผู้ใช้

ใช้ donoValue และ currency.js อย่างถูกต้อง

ช่องข้อมูลคืออะไร
hasDonationป้ายข้อความต้นฉบับ เช่น €5.00 หรือ 100 bits แสดงสิ่งนี้ให้ผู้ชม
donoValueค่า USD เสริมจากแหล่งข้อมูล หากถูกต้องแม้เป็นศูนย์ ให้ใช้ก่อนประมาณจากป้ายข้อความ
 
<script src="../../currency.js"></script>
<script>
// From games/templates/: use the existing helper, including its zero handling.
var usd = getDonationValueUSD(data);
// Use usd for your rule; display data.hasDonation for the original amount/unit.
</script>

อย่าทำแบบนี้

  • donoValue || convertToUSD(...) — เพราะทำให้ค่าศูนย์ที่ตั้งใจไว้ถูกทิ้ง
  • ดึงตัวเลขจาก chatmessage เพื่อระบุการชำระเงิน
  • การบังคับให้มี event === "donation" — Facebook Stars และ Cheers บางรายการไม่มี event

รางวัลโดยไม่ทำเกมเอง

ใน Event Flow:

  1. เพิ่ม เปรียบเทียบคุณสมบัติ.
  2. ตั้งเป็น donoValue, มากกว่าหรือเท่ากับ และจำนวน USD ของคุณ
  3. เชื่อมคำสั่ง เช่น เสียง แอนิเมชัน หรือควบคุม OBS

ใช้ค่าของแหล่งโดยตรงหากถูกต้อง มิฉะนั้นใช้การแปลงสกุลเงินของ SSN

  • ของขวัญ TikTok เฉพาะชนิด: เปรียบเทียบ meta.giftId หรือ meta.giftName และจำกัดโฟลว์เฉพาะเหตุการณ์ของขวัญ TikTok
  • ตรวจตัวเลขใน hasDonation แปลงเป็น USD ด้วย ไม่ใช่การตรวจเหรียญดิบ ใช้เมทาดาทาดั้งเดิมหรือโค้ดเองสำหรับกฎเหรียญ
  • แต่ละการตรวจทำต่อข้อความ ไม่ใช่ยอดสะสมหรือตัวนับสตรีก ใช้ โหนดสถานะ หากต้องการ หรือเก็บตรรกะนั้นในเกมของคุณ

ทดสอบก่อนเชื่อมคำสั่งที่ต้องจ่าย

  1. ปุ่มตัวอย่าง สตรีก 1 → 2 → 3 เพิ่มสามของขวัญ ตัวอย่างทับค่าเป็นศูนย์ไม่เพิ่ม USD ราคาที่ไม่ทราบไม่เพิ่มจำนวนเหรียญแบบแม่นยำ
  2. แหล่งจริง ดูข้อมูลที่จับได้จริง ตรวจชื่อ/ID ของขวัญ จำนวนเงิน หน่วย จำนวนชิ้น และ event ตัวอย่างทดสอบกฎ ไม่ใช่การจับสด
  3. ฉาก OBS ตรวจเหตุการณ์ซ้ำ การเชื่อมต่อใหม่ และการโหลดใหม่ อย่ารีเฟรชหรือปิด Browser Source หากต้องเก็บความคืบหน้าในหน่วยความจำ
ปัญหาลองวิธีนี้

ไม่มีเหตุการณ์ติดตามหรือสมัครต่างกันตามแหล่ง ดู เอกสารอ้างอิงเหตุการณ์.
กำลังรันเกมแบบไม่มีคนเฝ้า (AFK)? SSN ตัวจับข้อมูล และหน้าเกมต้องทำงานตลอด โหมดสลีป การล็อกอินหมดอายุ หรือฟีดหลุดทำให้คำสั่งหยุด เทมเพลตไม่ตามเก็บเหตุการณ์ที่พลาดหรือจัดการคืนเงิน ปฏิกิริยาอัตโนมัติไม่ได้ทำให้สตรีมไร้คนเฝ้ามีสิทธิ์สร้างรายได้ ตรวจข้อกำหนด LIVE และการสร้างรายได้ปัจจุบันของแพลตฟอร์ม
