สถิติวิดีโอและบิตเรต

แสดงบิตเรตสตรีมขาเข้าที่มุมขวาบนของแผงด็อก Social Stream Ninja

สำคัญ: SSN ไม่อ่านบิตเรตจาก OBS หรือแพลตฟอร์มสตรีมโดยอัตโนมัติ แต่สอบถาม API สถิติของเซิร์ฟเวอร์วิดีโอที่รับสตรีมของคุณเป็นระยะ
ใช้ทำอะไรความเข้ากันได้วิธีใช้หากไม่มีอะไรปรากฏขั้นสูง: โปรโตคอล รูปแบบ และหน่วย

ใช้ทำอะไร

ฟีเจอร์นี้แสดงบิตเรตสดแบบเล็กในแผงด็อกให้ผู้ดำเนินรายการหรือโปรดิวเซอร์ เหมาะเมื่อ OBS ตัวเข้ารหัสบนมือถือ หรือตัวส่งอื่นส่งไปยังเซิร์ฟเวอร์ส่งต่อหรือรับสัญญาณของคุณเอง

SSN ยังแปลงข้อมูลความล่าช้า บัฟเฟอร์ แพ็กเก็ตสูญหาย เวลาทำงาน โคเดก และผู้ชมที่มีให้เป็นอีเวนต์ข้อมูล video_stats แบบมาตรฐาน ส่วนแสดงค่าของแผงด็อกปกติแสดงเฉพาะบิตเรต

ความเข้ากันได้

  • SRT Live Server / SLS: JSON /stats ที่มีอ็อบเจ็กต์ publishers อยู่ภายใน
  • Belabox Cloud: การตอบกลับสถิติตัวรับ/ตัวส่งต่อ JSON แบบ SRT
  • NGINX RTMP: XML จากโมดูลสถานะ NGINX RTMP
  • Node Media Server: API สตรีม JSON พร้อม HTTP Basic authentication ตามต้องการ
OBS ไม่ใช่แหล่งข้อมูลสถิติ: OBS ส่งวิดีโอไปยังเซิร์ฟเวอร์ที่รองรับได้ แต่ OBS WebSocket และแหล่งข้อมูลเบราว์เซอร์ SSN ไม่ได้ให้ข้อมูลนี้

วิธีใช้

  1. เปิดปลายทางสถิติ HTTP ของเซิร์ฟเวอร์ที่รองรับ แล้วตรวจว่าคอมพิวเตอร์ที่รัน SSN เปิด URL นั้นได้
  2. ใน SSN การตั้งค่าส่วนกลาง, เปิดใช้ การสอบถามสถิติวิดีโอเป็นระยะ.
  3. เลือกประเภทแหล่งข้อมูลแล้วป้อน URL สถิติ
  4. สำหรับ SRT หรือ Belabox ให้ป้อนรหัสผู้เผยแพร่ให้ตรงทุกตัว เช่น publish/live/feed1 SSN ใช้ค่านี้โดยอัตโนมัติเมื่อการตอบกลับมีผู้เผยแพร่เพียงรายเดียว
  5. สำหรับ NGINX RTMP หรือ Node Media Server ให้ป้อนแอปพลิเคชันและคีย์/ชื่อสตรีม เช่น live และ feed1.
  6. เพิ่มการอนุญาตหากจำเป็น ช่องคีย์ SRT API จะถูกส่งเป็นค่าเต็มของเฮดเดอร์ Authorization ส่วน Node Media Server ใช้ชื่อผู้ใช้/รหัสผ่านเป็น HTTP Basic authentication
  7. เลือกช่วงเวลาสอบถามข้อมูล 1–60 วินาที ค่าเริ่มต้นคือห้าวินาที
  8. ในตัวเลือกแผงด็อก ให้เปิด แสดงข้อมูลบิตเรตหากมี ที่มุมขวาบน แล้วเปิดหรือรีเฟรชลิงก์แผงด็อก
  9. เริ่มส่งวิดีโอ บิตเรตจะปรากฏหลังได้รับการตอบกลับสถานะออนไลน์ที่ถูกต้อง

หากไม่มีอะไรปรากฏ

  • ยืนยันว่าเปิดตัวเลือกสถิติวิดีโอทั้งสองใน SSN
  • ยืนยันว่าปลายทางตอบภายในห้าวินาที และประเภทแหล่งข้อมูลกับตัวระบุสตรีมตรงกัน
  • 127.0.0.1 หมายถึงคอมพิวเตอร์ที่รัน SSN ใช้ที่อยู่ LAN ของเซิร์ฟเวอร์เมื่อเป็นอุปกรณ์อีกเครื่อง
  • ค่าที่แสดงจะหายไปเมื่อสตรีมออฟไลน์ ไม่มีบิตเรตหรือเป็นศูนย์ หรือไม่ได้รับสถิติใหม่ประมาณ 130 วินาที

ขั้นสูง: โปรโตคอล รูปแบบ และหน่วย

SSN ส่งคำขอ HTTP หรือ HTTPS แบบ GET ตามช่วงเวลาที่ตั้งไว้ โดยปิดแคชและหมดเวลาที่ห้าวินาที

SRT Live Server / SLS และ Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate มีหน่วย Kbps ส่วน RTT และบัฟเฟอร์รับเป็นมิลลิวินาที อัตรารับและแบนด์วิดท์เป็น Mbps เวลาทำงานเป็นวินาที และค่าการสูญหาย/ทิ้งเป็นจำนวนแพ็กเก็ตหรือไบต์

NGINX RTMP

URL ต้องส่งกลับ XML สถานะ NGINX RTMP SSN จับคู่แอปพลิเคชันและสตรีมที่ตั้งไว้ แล้วอ่าน bw_video เป็นไบต์ต่อวินาทีแล้วหารด้วย 1024 เพื่อให้ได้ bitrateKbps นอกจากนี้ยังอ่านเวลาสตรีมและข้อมูลโคเดกวิดีโอ/เสียงหากมี

Node Media Server

SSN ขอข้อมูลจาก STATS_URL/APPLICATION/STREAM_NAME ฟิลด์อาจอยู่ระดับบนสุดหรือภายใน data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

บิตเรตเป็น Kbps ผู้ชมเป็นจำนวนคน และระยะเวลาเป็นวินาที

อีเวนต์ SSN รูปแบบมาตรฐาน

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
ช่องข้อมูลหน่วย/ประเภท
bitrateKbpsKbps จำนวนเต็ม
rttMs / bufferMsมิลลิวินาที
recvRateMbps / bandwidthMbpsMbps
ฟิลด์การสูญหาย/ทิ้งข้อมูลจำนวนแพ็กเก็ตหรือไบต์
uptimeSeconds / durationSecondsวินาที
onlineบูลีน ค่า false จะซ่อนค่าในแผงด็อก

แผงด็อกรับค่า meta.bitrateKbps, พร้อม meta.bitrate และ meta.kbps เป็นค่าสำรอง ค่าต่ำกว่า 1000 แสดงเป็น Kbps ที่ปัดเศษแล้ว ค่ามากกว่านั้นแสดงเป็น Mbps ทศนิยมหนึ่งตำแหน่ง URL สถิติ คีย์สตรีม และข้อมูลรับรองจะไม่ส่งไปยังโอเวอร์เลย์
