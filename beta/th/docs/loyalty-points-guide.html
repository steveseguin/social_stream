แต้มสะสมและรางวัล

คู่มือแจกของรางวัล ตั๋วแบบเสียเงิน รางวัลเกม และการกู้คืน

ให้แต้มสำหรับการมีส่วนร่วม ให้ผู้ชมแลกรางวัลที่อนุมัติแล้ว และสำรองยอดแต้มของผู้ชม

คู่มือทั้งหมด 1. เปิดแต้มจากการมีส่วนร่วม 2. ตรวจสอบและจัดการยอดแต้ม 3. เพิ่มรางวัลสติกเกอร์ 4. เพิ่มรางวัล Event Flow ตามต้องการ 5. เก็บแต้มไว้เมื่อย้ายเครื่อง การแก้ปัญหา

1. เปิดแต้มจากการมีส่วนร่วม

  1. เปิด Global settings and tools → Points Systemเปิด เปิดระบบสะสมแต้ม (Enable loyalty points system).
  2. เริ่มจาก แต้มต่อการมีส่วนร่วม: 1 และ ช่วงเวลาการมีส่วนร่วม (นาที): 15 แล้วปรับให้เหมาะกับสตรีมของคุณ
  3. เปิดใช้ !points, !leaderboard, และ !rewards หากต้องการให้ตอบกลับคำสั่งเหล่านั้นในแชต
  4. ให้ SSN และแชตต้นทางเก็บข้อมูลต่อไป ขอให้ผู้ชมทดสอบส่งข้อความปกติ แล้วตรวจสอบ จัดการแต้มผู้ใช้ (Manage User Points).

แต้มตอบแทนการมีส่วนร่วมที่เก็บได้ ไม่ใช่เวลารับชมเงียบ ๆ หรือทุกข้อความ หลังได้รับแต้ม ผู้ชมต้องส่งข้อความที่เข้าเกณฑ์ครั้งถัดไปนอกช่วงเวลาการมีส่วนร่วมจึงจะได้แต้มอีก การมีส่วนร่วมต่อเนื่องอาจเพิ่มโบนัส ข้อความซ้ำในช่วงเวลาเดียวกันไม่ได้ให้แต้มซ้ำ ๆ

2. ตรวจสอบและจัดการยอดแต้ม

ผู้ชมใช้ !points เพื่อดูยอดแต้ม และ !leaderboard เพื่อดูอันดับเมื่อเปิดใช้ การตอบกลับต้องมีแหล่งข้อมูลที่ส่งกลับเข้าแชตได้ หากไม่มีคำตอบ ให้ตรวจสอบยอดแต้มผ่าน จัดการแต้มผู้ใช้ (Manage User Points) ก่อนสรุปว่าไม่ได้รับแต้ม

!points แสดงยอดที่ใช้ได้ คะแนนที่ได้รับ ยอดใช้จ่าย และยอดที่จองไว้ !leaderboard และตารางอันดับคะแนนสะสมจะจัดอันดับและแสดงคะแนนที่ได้รับทั้งหมด การแลกรางวัลจะลดยอดที่ใช้ได้ ส่วนอันดับยังอ้างอิงคะแนนที่ได้รับทั้งหมด

ใช้ จัดการแต้มผู้ใช้ (Manage User Points) สำหรับผู้ชมและแพลตฟอร์มที่เจาะจง หรือ ดูอันดับ (View Leaderboard) สำหรับภาพรวม บัญชีอ้างอิงด้วยชื่อผู้ใช้และประเภทแหล่งข้อมูล ชื่อเดียวกันบน Twitch และ YouTube มียอดแต้มแยกกัน อย่าสมมติว่าบัญชีของผู้ชมถูกเชื่อมกันโดยอัตโนมัติ

3. เพิ่มรางวัลสติกเกอร์

  1. ใน Points System → Sticker rewards เปิดรางวัลสติกเกอร์และเลือกแพ็กที่ต้องการให้ใช้ได้ ตั้งราคาแต้มให้เหมาะกับอัตราการสะสมแต้ม
  2. คัดลอก แหล่งข้อมูลเบราว์เซอร์ใน OBS ลงใน OBS และให้แหล่งข้อมูลสติกเกอร์โหลดอยู่เสมอ
  3. ใน เวลาและการตอบกลับแชต (Timing & chat replies) ตั้งเวลาแสดง คูลดาวน์รายผู้ชม คูลดาวน์รายสติกเกอร์ และช่วงเว้นว่าง เปิดการตอบกลับคำสั่งหากต้องการ
  4. ให้ผู้ชมทดสอบพิมพ์ !stickers เพื่อแสดงรหัสสติกเกอร์ที่เปิดใช้และราคา จากนั้น !sticker rocket หากเปิดใช้รหัสนั้นและมีแต้มพอ
  5. ตรวจสอบสติกเกอร์ที่แสดงและยอดแต้มคงเหลือก่อนประกาศรางวัล

การอนุมัติเกิดขึ้นตอนคุณเลือกแค็ตตาล็อก สติกเกอร์ที่เปิดใช้จะแลกได้โดยอัตโนมัติ ไม่มีคิวอนุมัติรายครั้ง สำหรับรูปภาพหรือ GIF แบบกำหนดเอง คุณเป็นผู้ระบุและอนุมัติ URL ไฟล์ HTTPS โดยตรง ผู้ชมส่งงานภาพใด ๆ ตามใจผ่านคำสั่งสติกเกอร์ไม่ได้

คูลดาวน์หรือโอเวอร์เลย์ที่ออฟไลน์จะปฏิเสธคำขอโดยไม่หักแต้ม หากส่งไปแสดงไม่สำเร็จหลังหักแต้ม SSN จะพยายามคืนแต้มและรายงานปัญหาที่ผู้ดำเนินรายการต้องแก้ไข การที่โอเวอร์เลย์เชื่อมต่ออยู่ไม่ได้ยืนยันว่า OBS กำลังแสดงฉากนั้น

ดู แพ็กสติกเกอร์และการตั้งค่า สำหรับตัวอย่าง งานภาพกำหนดเอง และตัวเลือก GIF !stickers คือคำสั่งแค็ตตาล็อกสติกเกอร์ ส่วน !rewards แสดงคำสั่งรางวัลแต้มทั่วไป

4. เพิ่มรางวัล Event Flow ตามต้องการ

สำหรับแอ็กชันกำหนดเอง ให้ใช้ตัวแก้ไข Event Flow ที่มีอยู่และแอ็กชัน ใช้แต้ม (Spend Points) วางเงื่อนไขคำสั่งที่ตรงทุกตัวไว้ก่อนการใช้แต้ม ตั้งค่า จำนวนแต้มที่ใช้ (Amount to Spend) แล้วเชื่อมแอ็กชันที่ต้องใช้แต้มหลังใช้แต้มสำเร็จ เพิ่มคูลดาวน์ในโฟลว์ด้วย

ทดสอบทั้งกรณีแต้มไม่พอและแต้มพอก่อนเปิดรางวัล แอ็กชันกำหนดเองที่ล้มเหลวหลังหักแต้มไม่ได้รับพฤติกรรมการส่ง/คืนแต้มของระบบสติกเกอร์โดยอัตโนมัติ ตรวจสอบการจัดการข้อผิดพลาดก่อนผูกคำสั่งใช้แต้มกับสื่อหรือแอ็กชันภายนอก ดู Event Flow.

5. เก็บแต้มไว้เมื่อย้ายเครื่อง

แต้มเก็บอยู่ในพื้นที่จัดเก็บภายในเบราว์เซอร์/แอป การใช้รหัสเซสชันร่วมกับคอมพิวเตอร์หรือการติดตั้งอีกชุดไม่ได้ซิงค์ยอดแต้ม

  1. ใช้ Points System → Backup & Restore → Export Points แล้วเก็บไฟล์ JSON ไว้
  2. ในระบบปลายทาง ให้ส่งออกแต้มเดิมก่อน แล้วใช้ นำเข้าแต้ม (Import Points) แล้วเลือกโหมดนำเข้าที่ต้องการ
  3. เลือกอย่างรอบคอบ: รวมข้อมูล (Merge) เก็บยอดแต้มที่สูงกว่าไว้ ส่วน แทนที่ เขียนทับข้อมูลแต้มเดิม ตรวจสอบผลนำเข้า สุ่มตรวจผู้ชมและแพลตฟอร์มใน Manage User Points และยืนยันยอดแต้มก่อนเปิดรางวัลอีกครั้ง

เก็บไฟล์ส่งออกแต้มเฉพาะไว้ควบคู่กับ ข้อมูลสำรองการตั้งค่า. รีเซ็ตแต้มทั้งหมด (Reset All Points) ล้างบัญชีแต้ม ใช้เฉพาะเมื่อตั้งใจรีเซ็ตหลังส่งออกข้อมูลแล้ว

การแก้ปัญหา

  • ยอดแต้มไม่เปลี่ยน: ตรวจสอบการเก็บข้อมูล สวิตช์หลัก ช่วงเวลาการมีส่วนร่วม และบัญชีแพลตฟอร์มของผู้ชม
  • ปิดใช้ประวัติแชต: การรับคะแนนและคำสั่งคะแนนต้องใช้ฐานข้อมูลข้อความในเครื่อง ดู คู่มือประวัติแชต.
  • สติกเกอร์แจ้งว่าไม่พร้อมใช้งาน: ตรวจสอบแพ็ก/รหัสที่เลือก แต้มที่เพียงพอ คูลดาวน์ และแหล่งข้อมูลสติกเกอร์ใน OBS ที่โหลดไว้
  • แต้มสูญหายหลังย้าย: นำเข้าไฟล์ส่งออกแต้มในระบบที่กำลังเก็บข้อมูล ลิงก์เซสชันเพียงอย่างเดียวไม่ใช่ข้อมูลสำรอง
