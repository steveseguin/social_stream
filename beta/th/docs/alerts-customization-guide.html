ออกแบบการแจ้งเตือนและฟีดเหตุการณ์ที่กำหนดเอง

เปลี่ยนสไตล์ Multi-Alerts และแถวกิจกรรมสำหรับการบริจาค การสมัครสมาชิก ของขวัญ การติดตาม และการดำเนินการอื่น ๆ ที่รองรับ

คู่มือการออกแบบภาพซ้อนทับทั้งหมดเลือกไฟล์ดาวน์โหลดเซสชันและ OBSการออกแบบพรอมต์ AIทดสอบ

หากต้องการให้การแจ้งเตือนล่าสุดปรากฏใน OBS หรือ Streamlabs Desktop ให้เริ่มต้นด้วย คู่มือการซ้อนทับเหตุการณ์ที่มีภาพประกอบ.

เลือกหน้าเริ่มต้นที่ถูกต้อง

ใช้ multi-alerts.html สำหรับการนำเสนอการแจ้งเตือนตามกำหนดเวลาและ events.html หรือ themes/events/index.html สำหรับรายการกิจกรรมที่กำลังดำเนินอยู่ มีพฤติกรรมการเรนเดอร์และคิวที่แตกต่างกัน เริ่มต้นด้วย URL ที่สร้างขึ้นสำหรับเครื่องมือที่คุณใช้อยู่แล้ว

เลือกรูปแบบฟีดกิจกรรม

เปิด ฟีดกิจกรรม / กิจกรรม → เปิดใช้งานและปรับแต่ง → สไตล์ฟีดเลือกเค้าโครง จากนั้นคัดลอกลิงก์ที่อัปเดตไปยังเบราว์เซอร์ของคุณหรือ OBS แหล่งที่มาของเบราว์เซอร์ เปิด ปรับแต่งรูปลักษณ์ฟีด เพื่อปรับสีและระยะห่าง เว้นช่องว่างไว้เพื่อใช้ค่าเริ่มต้นของสไตล์

สไตล์ตัวเลือก URLลักษณะที่ปรากฏ
การ์ด (ค่าเริ่มต้น)style=default หรือละเว้นมันการ์ดเหตุการณ์ต้นฉบับที่มีเส้นขอบแพลตฟอร์มและป้ายกำกับเหตุการณ์
กะทัดรัดstyle=compactแถวหนาแน่นพร้อมชื่อและข้อความอยู่ในบรรทัด
สไตล์ Twitchstyle=twitchรายการกิจกรรมแบบเรียบพร้อมไอคอนแพลตฟอร์ม ส่วนเน้นสีม่วง และตัวคั่นแถว
ไทม์ไลน์style=timelineการ์ดเหตุการณ์ที่เชื่อมต่อกับไทม์ไลน์สีทอง
แก้วstyle=glassการ์ดโปร่งแสงแบบโค้งมนพร้อมเงาอ่อนๆ
น้อยมากstyle=minimalข้อความแรเงาโดยไม่มีกล่อง สำหรับวางทับวิดีโอด้วย transparent.
ทิกเกอร์style=tickerเม็ดยาแถวแนวนอนหนึ่งแถว ใหม่ล่าสุดทางซ้าย สำหรับแถบที่สามล่าง ซ่อนการประทับเวลาและรายละเอียด

เพิ่มตัวเลือกเหล่านี้ให้กับที่มีอยู่ของคุณ events.html?session=YOUR_SESSION_ID เชื่อมโยงกับ &. รักษาเซสชัน รหัสผ่าน และตัวเลือกการเชื่อมต่อของคุณ

  • accent, pagebg, cardbg, textcolor, และ mutedcolor: CSS สี เข้ารหัสสีฐานสิบหก # เป็น %23 ใน URL หรือละเว้น #.
  • fontsize=14: ขนาดตัวอักษร 10–40 พิกเซล padding=8, gap=4, และ radius=6: การเติมแถว ช่องว่างระหว่างกิจกรรม และรัศมีมุม ละ 0–40 พิกเซล
  • noheader ซ่อนส่วนหัวของหน้า noanimation ปิดการใช้งานภาพเคลื่อนไหวรายการ
  • ผสมผสานสไตล์เข้ากับ lightmode, transparent, font, googlefont, scale, notime, และ hidemeta. โหมดโปร่งใสจะแทนที่พื้นหลังของหน้า พื้นหลังการ์ดยังคงสามารถปรับแยกกันได้

ตัวอย่างเช่น ผนวก &style=twitch&accent=%23e5b94f&padding=8&fontsize=14 สำหรับรายการกิจกรรมที่หนาแน่นยิ่งขึ้นพร้อมเน้นสีทอง

เลือกสิ่งที่ปรากฏในฟีดกิจกรรม

ใน ฟีดกิจกรรม / กิจกรรม → เปิดใช้งานและปรับแต่ง, เปิด เลือกเหตุการณ์ที่จะปรากฏ หรือ เนื้อหาและพฤติกรรมของแถว. ปล่อยให้ตัวควบคุมปิดและฟิลด์ว่างไว้เพื่อรักษามุมมองเริ่มต้น คัดลอกลิงก์ที่อัปเดตหลังจากเปลี่ยนแปลงแล้ว การควบคุมเหล่านี้มีผลกับฟีดนี้เท่านั้น การแชทแบบธรรมดายังคงไม่รวมอยู่

แต่ละแถวอยู่ในหมวดหมู่เดียวตามชื่อเหตุการณ์ การเป็นสมาชิก ของขวัญ และการซื้อที่มีชื่อจะคงหมวดหมู่ไว้แม้ว่าจะรวมจำนวนเงินแล้วก็ตาม เคล็ดลับด้วย hasDonation และไม่มีชื่อเหตุการณ์ที่เป็นที่รู้จักอยู่ในหมวดหมู่ข้อความที่ต้องชำระเงิน รวมถึงบิต Twitch DOM ป้ายสถานะสมาชิกในแชทธรรมดาจะไม่เปลี่ยนเป็นกิจกรรมสมาชิก

เพื่อการควบคุมที่ละเอียดยิ่งขึ้น ให้ใช้ filterevents=supersticker,watch_streak เพื่อซ่อนชื่อเหตุการณ์ที่แน่นอน การจับคู่จะละเว้นตัวพิมพ์เล็กและใหญ่และใช้ชื่อแทนเหตุการณ์ที่มีอยู่ของฟีด มันไม่ค้นหาข้อความ การยกเว้นหมวดหมู่และชื่อทุกประการจะรวมกับตัวกรองแหล่งที่มา ตัวกรองเฉพาะการบริจาค ผู้ติดตามที่เป็นของขวัญเท่านั้น และตัวกรองมูลค่าขั้นต่ำที่มีอยู่ การเปิดใช้งานตัวกรองหลายตัวจะทำให้ไม่มีเหตุการณ์ที่ตรงกัน ดู เอกสารอ้างอิงเหตุการณ์ สำหรับเพย์โหลดเฉพาะแหล่งที่มา

  • hidemessage, hidecontentimg, hideplatformicons, hideeventlabels และ hideamounts ซ่อนองค์ประกอบแถวที่เกี่ยวข้อง พวกเขาจะไม่ละทิ้งกิจกรรมหรือเปลี่ยนแปลงสิ่งที่การคลิกเพื่อใช้คุณสมบัติส่ง อิโมติคอนแบบอินไลน์เป็นส่วนหนึ่งของข้อความ จำนวนหรือชื่อที่เขียนลงในข้อความ ข้อมูลเมตา หรือรายละเอียด Hype Train จะไม่ถูกแก้ไขโดยการควบคุมเหล่านี้
  • nofeature ปิดใช้งานการคลิกเพื่อแสดงคุณลักษณะในฟีดนี้ รายละเอียดข้อมูลเมตายังคงเปิดได้
  • hidecategorytag hides only the generic category tag, such as Donation or Event, while keeping the descriptive event label. In the popup, enable Hide category tag ภายใต้ เนื้อหาและพฤติกรรมของแถว.
  • eventduration=60 ลบแถวออกจากฟีดนี้หลังจาก 60 วินาที ว่างหรือ 0 คงพฤติกรรมการเก็บรักษาที่มีอยู่ ค่าบวกอยู่ในช่วงตั้งแต่ 1 ถึง 86,400 วินาที การอัปเดต Hype Train รีสตาร์ทตัวจับเวลา รถไฟที่สิ้นสุดแล้วยังคงหายไปหลังจากผ่านไปไม่เกิน 30 วินาที การลบออกไม่ได้ล้างเหตุการณ์ที่ส่งไปยังโอเวอร์เลย์ที่แนะนำแล้ว
  • hideempty ซ่อนข้อความรอเมื่อไม่เห็นเหตุการณ์

ดาวน์โหลดและเก็บโครงสร้างไฟล์ไว้

  1. ดาวน์โหลด ZIP ต้นทาง แล้วดึงออกมา คำแนะนำเหล่านี้ใช้แหล่งเบต้า เก็บไฟล์จากการดาวน์โหลดครั้งเดียวไว้ด้วยกัน
  2. คัดลอก multi-alerts.html เป็น my-alerts.html ข้างต้นฉบับ หากเลือกหน้าหรือธีมอื่น ให้เก็บสำเนาไว้ในโฟลเดอร์ต้นฉบับของไฟล์นั้น
  3. เปิด HTML ที่คัดลอกและ CSS/JS ที่อ้างอิงในตัวแก้ไขหรือเครื่องมือ AI ของคุณ เพิ่มอาร์ตเวิร์ก/แบบอักษรที่ให้มาในโปรเจ็กต์เดียวกัน และใช้พาธแบบสัมพันธ์ เริ่มต้นด้วยการแทนที่ CSS รวมตัวแสดงผลเมื่อเปลี่ยนมาร์กอัปที่สร้างขึ้น

ไฟล์ต่อไปนี้ช่วยคุณค้นหาการออกแบบและลักษณะการทำงาน นี่คือรายการที่จะอ่าน ไม่ใช่ชุดการพึ่งพาที่สมบูรณ์: เก็บโฟลเดอร์ที่แยกออกมาไว้ครบถ้วน รวมถึงรูปภาพ แบบอักษร สคริปต์ และไฟล์ข้อมูลใดๆ

เชื่อมต่อสำเนาของคุณและเปิดใน OBS

เริ่ม SSN และทำให้ URL โอเวอร์เลย์ที่สร้างขึ้นดั้งเดิมใช้งานได้ก่อน ที่ session= ค่าเชื่อมต่อกับเซสชัน SSN นั้น ไม่ใช่ชื่อช่องของคุณหรือชื่อไฟล์นี้ ให้ SSN คุณลักษณะที่เกี่ยวข้อง และแหล่งข้อมูลทำงานต่อไป

  1. ลากไฟล์ HTML ที่แก้ไขของคุณไปที่ Chrome หรือ Edge คัดลอกที่อยู่จากแถบที่อยู่ มันเริ่มต้นด้วย file:///.
  2. คัดลอกทุกอย่างจาก ? เป็นต้นไปในลิงก์โอเวอร์เลย์ SSN ที่ทำงานของคุณ และเพิ่มไปที่ส่วนท้ายของที่อยู่ไฟล์นั้น เก็บการตั้งค่าทั้งหมดไว้ รวมถึงเซสชัน รหัสผ่าน และอื่นๆ # สิ้นสุด
  3. เปิดผลลัพธ์ในเบราว์เซอร์ จากนั้นตั้งค่า OBS Browser Source's URL ไปยังที่อยู่เดียวกันกับ ไฟล์ในเครื่อง (Local file) ไม่ได้เลือก จับคู่มิติข้อมูลแหล่งที่มากับการออกแบบที่คุณต้องการ

สำหรับไฟล์เริ่มต้นด้านบน ที่อยู่ภายในเครื่องจะเป็นดังนี้ ลิงก์จริงของคุณอาจมีตัวเลือกที่จำเป็นเพิ่มเติม:

file:///C:/SSN/social_stream-beta/my-alerts.html?session=YOUR_SESSION

ใช้ที่อยู่ไฟล์จริงบนคอมพิวเตอร์ของคุณ OBS จะบันทึกพร้อมกับแหล่งที่มา เก็บโฟลเดอร์ที่ดาวน์โหลดมาไว้ที่เดิม หลังจากบันทึกการเปลี่ยนแปลงการออกแบบแล้ว ให้รีเฟรชแหล่งที่มาของเบราว์เซอร์ ที่ คู่มือการตั้งค่าที่ใช้ร่วมกัน รวมตัวอย่าง Mac และตัวเรียกใช้งานเสริมสำหรับช่องทำเครื่องหมายไฟล์ในเครื่อง

จะเปลี่ยนการออกแบบได้ที่ไหน

เปลี่ยนกรอบการแจ้งเตือน การพิมพ์ ตำแหน่งไอคอน การตกแต่งความคืบหน้า/กำหนดเวลา และการเคลื่อนไหว ใน Multi-Alerts เค้าโครงส่วนใหญ่ถูกสร้างขึ้น multi-alerts.js; รวมไว้เมื่อขอให้ AI เปลี่ยนโครงสร้าง สำหรับการแยกส่วน ให้คัดลอกสคริปต์นั้นด้วยและอัปเดตเฉพาะการอ้างอิงสคริปต์ HTML ที่คุณคัดลอกไว้

รักษาการจัดหมวดหมู่และตัวกรองเหตุการณ์ แถวการแชทแบบชำระเงินอาจใช้ hasDonation โดยไม่มี event: "donation"; แพลตฟอร์มยังมีชื่อเหตุการณ์เฉพาะอีกด้วย ใช้ เอกสารอ้างอิงเหตุการณ์ และ คำแนะนำความเข้ากันได้ เพื่อเลือกตัวอย่าง แยกจำนวนเงินที่แสดงเดิมและตัวเลขแทนที่ USD ออกจากกัน

ทดสอบประเภทการซ้อนทับนี้

ใช้การตั้งค่าตัวอย่างหรือทดสอบก่อน ที่ คำแนะนำข้อความทดสอบ อธิบายวิธีการส่งเพย์โหลดสมมติผ่าน SSN การทดสอบที่ส่งไปยังเซสชันการใช้งานจริงของคุณสามารถทริกเกอร์การทำงานอัตโนมัติที่มีอยู่ได้

  1. ใช้เครื่องมือทดสอบข้อความเพื่อส่งข้อความติดตาม การสมัครสมาชิก ของขวัญ การจู่โจม หรือข้อความชำระเงินเฉพาะที่แหล่งของคุณสนับสนุน ตรวจสอบว่ามีฟิลด์ใดบ้างที่มีอยู่จริง
  2. ส่งการแจ้งเตือนสองตัวที่อยู่ใกล้กันเพื่อตรวจสอบคิวและออกจากแอนิเมชั่น ทดสอบข้อความเปล่าที่มีป้ายกำกับการบริจาคและชื่อยาว
  3. สำหรับฟีดกิจกรรม ให้ตรวจสอบการเลื่อน การกรอง และลักษณะการทำงานเมื่อคลิก สำหรับเอฟเฟกต์เสียง ให้ตรวจสอบเสียงต้นฉบับใน OBS รวมถึงรูปภาพด้วย

เรียกใช้ การตรวจสอบการเรนเดอร์อินพุต กับเส้นทางการเรนเดอร์ที่คุณเปลี่ยน หลังจากบันทึกการแก้ไข ให้รีเฟรช OBS Browser Source ระหว่างการซ้อม และทำซ้ำการโต้ตอบที่มองเห็นได้ การแสดงตัวอย่างเบราว์เซอร์ไม่ได้สร้างการจับภาพสดหรือพฤติกรรมของ OBS
