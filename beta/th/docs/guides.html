  • ดัชนีความช่วยเหลือขั้นสูงขั้นตอนขอความช่วยเหลือและเอเจนต์ AI

เริ่มต้นใช้งาน (ส่วนขยายเบราว์เซอร์)

1. ติดตั้ง

ก่อนใช้ Social Stream Ninja ต้องติดตั้งก่อน มีหลายวิธีติดตั้งส่วนขยายเบราว์เซอร์:

  • ติดตั้งด้วยตนเอง (แนะนำ): หากต้องการเวอร์ชันล่าสุด ให้ติดตั้งด้วยตนเองในโหมดนักพัฒนา
  • Chrome Web Store: ติดตั้งผ่าน Chrome Web Store เพื่อการตั้งค่าที่ง่ายที่สุด

สำหรับวิธีติดตั้งแบบละเอียด ดู หน้าดาวน์โหลด.

2. ตั้งค่าพื้นฐาน

เมื่อติดตั้งแล้ว ทำตามขั้นตอนเพื่อเริ่มใช้ Social Stream Ninja:

  1. เปิดแชตแพลตฟอร์มสตรีมในเบราว์เซอร์ (หรือใช้แชตป๊อปเอาต์หากมี)
  2. คลิกไอคอนส่วนขยาย Social Stream Ninja ในแถบเครื่องมือเบราว์เซอร์
  3. คลิก "Enable Extension" เพื่อเปิด (ไอคอนควรเป็นสีเขียว)
  4. เปิด "Dashboard Link" ที่ให้ในป๊อปอัปส่วนขยาย
  5. เปิด "Overlay Link" ใน OBS เป็นแหล่งเบราว์เซอร์

หมายเหตุ: เพื่อประสบการณ์ดีที่สุด ให้หน้าต่างแชตมองเห็นอยู่ (ไม่ย่อ) เมื่อใช้ส่วนขยายเบราว์เซอร์

Social Stream Ninja ใช้กับกว่า 100 แพลตฟอร์มได้ วิธีเชื่อมต่อแพลตฟอร์มยอดนิยมมีดังนี้:

YouTube

  • เปิดแชต YouTube Live
  • คลิกปุ่ม "Pop out chat" มุมขวาบน
  • ตรวจว่าส่วนขยาย Social Stream Ninja เปิดอยู่ (ไอคอนเขียว)

Twitch

  • เปิดแชต Twitch ของช่องคุณ
  • คลิกไอคอนเฟืองแล้วเลือก "Pop out chat"
  • ตรวจว่าส่วนขยาย Social Stream Ninja เปิดอยู่ (ไอคอนเขียว)

Facebook

  • เปิด Facebook Live ของคุณ (เป็นผู้ชมหรือผู้เผยแพร่)
  • ตรวจว่าเชื่อมต่อ WiFi หรือ Ethernet (ไม่ใช่เน็ตมือถือ)
  • ตรวจว่าส่วนขยาย Social Stream Ninja เปิดอยู่ (ไอคอนเขียว)

Discord, Slack, WhatsApp ฯลฯ

  • ก่อนอื่น เปิดแพลตฟอร์มเหล่านี้ในการตั้งค่าส่วนขยาย (สวิตช์)
  • เปิดเวอร์ชันเว็บของแพลตฟอร์มเหล่านี้ในเบราว์เซอร์
  • ตรวจว่าส่วนขยาย Social Stream Ninja เปิดอยู่ (ไอคอนเขียว)

การปรับแต่ง (ส่วนขยายเบราว์เซอร์)

พารามิเตอร์ URL

ปรับได้ทั้งแดชบอร์ดและโอเวอร์เลย์ด้วยการเพิ่มพารามิเตอร์ใน URL ตัวอย่าง:

พารามิเตอร์แดชบอร์ด:

&darkmode - เปิดโหมดมืดสำหรับแดชบอร์ด
&scale=2 - เพิ่มขนาด/ความละเอียดทุกองค์ประกอบเป็นสองเท่า
&hidesource - ซ่อนไอคอนแพลตฟอร์ม (YouTube, Twitch ฯลฯ)
&compact - ลบช่องว่างระหว่างชื่อกับข้อความ
&inline - วางข้อความต่อข้างชื่อโดยคงระยะห่างปกติ
&autoshow - นำข้อความมาแสดงเด่นอัตโนมัติเมื่อเข้ามา (ประมาณ 2 ข้อความต่อ 3 วินาที)

พารามิเตอร์โอเวอร์เลย์:

&showtime=20000 - ซ่อนข้อความที่เลือกอัตโนมัติหลัง 20 วินาที
&showsource - แสดงไอคอนแพลตฟอร์มข้างชื่อผู้ใช้
&fade - ทำให้ข้อความเด่นค่อย ๆ ปรากฏแทนโผล่ทันที
&swipe - ทำให้ข้อความเด่นเลื่อนเข้าจากซ้าย
¢er - จัดข้อความเด่นไว้กึ่งกลางจอ

เพื่อจัดการ URL ง่ายขึ้น ลอง เครื่องมือแก้ไขพารามิเตอร์ URL.

การปรับแต่ง CSS

ปรับหน้าตาด้วย CSS ได้หลายวิธี:

วิธีที่ 1: CSS แหล่งเบราว์เซอร์ OBS

ใน OBS คุณเพิ่ม CSS กำหนดเองให้แหล่งเบราว์เซอร์ได้:

  1. เพิ่มโอเวอร์เลย์เป็นแหล่งเบราว์เซอร์ใน OBS
  2. เลือกตัวเลือก "Custom CSS"
  3. ป้อน CSS กำหนดเองในช่องข้อความ
body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }

:root {
    --comment-color: #090;
    --comment-bg-color: #DDD;
    --comment-border-radius: 10px;
    --comment-font-size: 30px;
    --author-border-radius: 10px;
    --author-bg-color: #FF0000;
    --author-avatar-border-color: #FF0000;
    --author-font-size: 32px;
    --author-color: blue;
    --font-family: "Arial", sans-serif;
}

.hl-name {
    padding: 2px 10px !important;
}

วิธีที่ 2: การตั้งค่าเมนูส่วนขยาย

เพิ่ม CSS โดยตรงผ่านเมนูส่วนขยาย:

  1. คลิกไอคอนส่วนขยาย Social Stream Ninja
  2. หาส่วนตั้งค่า CSS/JavaScript
  3. ป้อน CSS หรือ JavaScript กำหนดเอง
  4. CSS จะถูกต่อท้าย URL เป็นข้อมูลเข้ารหัส base64

วิธีที่ 3: ใช้เทมเพลตกำหนดเอง

เลือกเทมเพลตตกแต่งสำเร็จที่มี CSS ในตัว:

  • ดู แกลเลอรีเทมเพลต
  • เลือกเทมเพลตที่เข้ากับสไตล์สตรีม
  • แทนที่ YOURSESSIONID ใน URL เทมเพลตด้วยรหัสเซสชันของคุณ
  • เพิ่ม URL เทมเพลตเป็นแหล่งเบราว์เซอร์ใน OBS

ตัวอย่าง: https://socialstream.ninja/themes/pretty.html?session=YOURSESSIONID

ใช้สีต่างกันสำหรับชื่อแชต

สีชื่อต้องตั้งสองส่วน: แหล่งสีทั่วไปใน ข้อความ - รูปแบบ (Message - Styling) และสวิตช์แสดงผลแผงด็อกใน ข้อความ - การมองเห็น (Message - Visibility).

เปิดคู่มือสีชื่อแชต สำหรับภาพหน้าจอ ตัวเลือกสี การแก้ปัญหา และตัวอย่าง CSS

ฟอนต์ที่โฮสต์เองและการตกแต่ง

นำฟอนต์ของคุณเองมาใช้กับ dock.html หรือ featured.html โดยไม่พึ่งฟอนต์ Google/ระบบ

  • โฮสต์ไฟล์ .woff2/.ttf/.otf และโหลดด้วย @font-face.
  • ใช้ CSS ผ่าน CSS กำหนดเองของ OBS หรือพารามิเตอร์ URL เช่น &css=, &b64css=, &font=, หรือ &googlefont=.
  • ทำงานเหมือนกันในส่วนขยาย Chrome แอป Electron และหน้าที่โฮสต์ไว้

เปิดคู่มือฟอนต์ที่โฮสต์เอง สำหรับวิธีโฮสต์ทีละขั้นและตัวอย่าง CSS

ฟีเจอร์ขั้นสูง (ส่วนขยายเบราว์เซอร์)

การแปลงข้อความเป็นเสียงพูด

Social Stream Ninja อ่านข้อความแชตออกเสียงได้ด้วยเทคโนโลยี Text-to-Speech:

ตั้งค่า TTS:

  1. เพิ่ม &speech=en-US ลงใน URL featured.html หรือ dock.html
  2. สำหรับภาษาอื่น ใช้ผู้ให้บริการและเสียงที่รองรับภาษานั้น เช่น ภาษาโปรตุเกสใช้ Piper ได้ &pipervoice=pt_BR-faber-medium หรือ eSpeak &espeakvoice=pt-br, ส่วนภาษาสเปนใช้ Piper ได้ &pipervoice=es_ES-davefx-medium หรือ eSpeak &espeakvoice=es.
  3. ปรับเสียงด้วยพารามิเตอร์ เช่น &pitch=1&volume=1&rate=1

ตัวเลือก TTS ในเครื่องฟรี (ไม่ต้องใช้คีย์ API):

  • Kokoro TTS: AI ในเบราว์เซอร์ คุณภาพยอดเยี่ยม — &ttsprovider=kokoro
  • Piper TTS: นิวรัล TTS ที่เร็วและเบา — &ttsprovider=piper
  • eSpeak-NG: ทางสำรองภาษาที่เบา รวมภาษาโปรตุเกส &espeakvoice=pt-br และภาษาสเปน &espeakvoice=es
  • Kitten TTS: ใช้ทรัพยากรน้อยที่สุด เฉพาะ CPU — &ttsprovider=kitten
  • เซิร์ฟเวอร์ที่โฮสต์เอง: เรียก Kokoro-FastAPI หรือ openedai-speech ในเครื่องผ่าน Docker — &ttsprovider=openai&openaiendpoint=http://localhost:8880/v1/audio/speech

ตัวเลือก TTS คลาวด์พรีเมียม:

  • Google Cloud TTS: เสียงคุณภาพมืออาชีพ (ต้องใช้คีย์ Google API)
  • ElevenLabs: เสียงสมจริงสูงพร้อมฝึกเสียงกำหนดเอง
  • Speechify: เสียงพรีเมียมเป็นธรรมชาติ

ต้องการให้ทำงานในเครื่องและเป็นส่วนตัวหรือไม่? ดู คู่มือ AI TTS ในเครื่อง สำหรับวิธีตั้งค่าครบถ้วน รวมเซิร์ฟเวอร์ที่โฮสต์เองและการจับเสียง OBS

ผู้ช่วยดำเนินรายการ AI แชตบอต และเพื่อนร่วมสนทนาในเบราว์เซอร์

Social Stream Ninja ใช้ AI ได้หลายแบบ เลือกขั้นตอนงานก่อนเลือกผู้ให้บริการ

  • ผู้ช่วยดำเนินรายการด้วยเสียง: พูดผ่านไมโครโฟนขณะที่คำถามแชตสดเข้าสู่เซสชันผู้ช่วยดำเนินรายการเดียวกัน
  • เพื่อนร่วมสนทนา ChatGPT ในเบราว์เซอร์: จับหรือทดลองส่งต่อแชตเข้า chatgpt.com แท็บที่เปิดอยู่โดยไม่ใช้คีย์ API
  • แชตบอตหลัก: ตอบผู้ชมที่เลือกในโอเวอร์เลย์ ผ่าน TTS หรือกลับเข้าแชตที่รองรับ
  • เครื่องมือประมวลผล: การดูแลแชต การแปล การสรุป ค้นความรู้ RAG และโอเวอร์เลย์สร้างด้วย AI

การเข้าคิวและปักหมุดข้อความ

จัดรูปแบบการปรากฏของข้อความในโอเวอร์เลย์:

การเข้าคิวข้อความ:

  1. กด CTRL (หรือ Cmd บน Mac) ค้างขณะคลิกข้อความในแดชบอร์ด
  2. คลิกปุ่ม "Next in Queue" เพื่อแสดงทีละข้อความ
  3. ข้อความจะปรากฏในโอเวอร์เลย์ตามลำดับเข้าคิว

การปักหมุดข้อความ:

  1. กด ALT ค้างขณะคลิกข้อความในแดชบอร์ด
  2. ข้อความจะปักหมุดอยู่ด้านบนแดชบอร์ด
  3. หากต้องการเลิกปักหมุด กด ALT ค้างแล้วคลิกข้อความที่ปักหมุดอีกครั้ง

การจับอีเวนต์สตรีม

จับอีเวนต์ที่ไม่ใช่แชต เช่น ผู้ติดตามใหม่ สมัครสมาชิก เรด และการบริจาคจากแพลตฟอร์มสตรีม

วิธีเปิดใช้:

  1. คลิกไอคอนส่วนขยาย Social Stream Ninja
  2. หา "จับอีเวนต์สตรีม (Capture Stream Events)" สวิตช์ในการตั้งค่า
  3. เปิดเพื่อเริ่มรับการแจ้งเตือน

หมายเหตุ: อีเวนต์แบบบริจาค (Super Chats, Bits, Tips) ส่งต่ออัตโนมัติไม่ว่าสวิตช์นี้เป็นค่าใด สวิตช์มีไว้หลัก ๆ สำหรับแจ้งเตือนผู้ติดตาม/สมาชิก

อีเวนต์ที่จับได้ตามแพลตฟอร์ม:

YouTube

  • สมาชิกใหม่และของขวัญสมาชิก
  • อัปเกรดสมาชิกและเหตุการณ์สำคัญ
  • การบริจาค Super Chat และ Super Sticker
  • จำนวนผู้ติดตามและผู้ชม

Twitch

  • สมาชิกใหม่ สมัครซ้ำ และสมาชิกแบบของขวัญ
  • ผู้ติดตามและจำนวนผู้ติดตาม
  • Bits/Cheers และการแลกแต้มช่อง
  • เรดพร้อมจำนวนผู้ชม

TikTok, Kick และอื่น ๆ

  • ผู้ติดตามและของขวัญ (TikTok)
  • การสมัครสมาชิกและทิป (Kick)
  • จำนวนผู้ชมในแพลตฟอร์มส่วนใหญ่

ดูรายการข้อมูลอีเวนต์และช่องข้อมูลทั้งหมดได้ใน เอกสารอ้างอิงอีเวนต์ เอกสาร

เปิดคู่มือผู้แชตครั้งแรก

ตัวแก้ไข Event Flow

ตัวแก้ไข Event Flow เป็นระบบอัตโนมัติแบบโหนดสำหรับสร้างขั้นตอนงานกำหนดเอง เป็นชั้น "ระบบอัตโนมัติขั้นสูง" ที่ให้คุณเขียนตรรกะกำหนดเส้นทางเอง

สิ่งที่ทำได้:

  • ส่งต่อแชตระหว่างแพลตฟอร์ม พร้อมตัวกรองอัจฉริยะ (เช่น ส่ง Twitch ไป Discord แต่บล็อกคำสั่ง)
  • สร้างคำสั่งกำหนดเอง ด้วยเกตตรรกะ AND/OR/NOT
  • เรียกโอเวอร์เลย์และเสียง ตามอีเวนต์หรือคำสำคัญที่ระบุ
  • ควบคุม OBS ฉากและแหล่งข้อมูลอัตโนมัติ
  • สร้างการจับและแจกของรางวัล พร้อมจัดการคิว

เริ่มต้นใช้งาน:

  1. เปิดตัวแก้ไข Event Flow จากเมนูแดชบอร์ดหลัก
  2. สร้างโฟลว์ใหม่และเพิ่มโหนดต้นทาง (เช่น "Twitch Message")
  3. เชื่อมโหนดตรรกะเพื่อกรองข้อความ (Contains Keyword, User Role ฯลฯ)
  4. เพิ่มโหนดการกระทำเพื่อตอบสนอง (Send Chat, Play Audio, Display Overlay)
  5. ทดสอบด้วยตัวจำลองในตัวก่อนถ่ายทอดสด

โอเวอร์เลย์ Flow Actions:

เพื่อให้เสียง โอเวอร์เลย์สื่อ และการกระทำ OBS ทำงาน ต้องเพิ่มหน้า Flow Actions เป็นแหล่งเบราว์เซอร์ใน OBS:

  1. ในป๊อปอัป หาส่วน "Flow Actions" แล้วคัดลอก URL
  2. เพิ่มเป็นแหล่งเบราว์เซอร์ใน OBS (แนะนำ 1920×1080)
  3. เปิดโอเวอร์เลย์ทิ้งไว้ (ซ่อนได้ แต่อย่าปิด)

สำคัญ: การกระทำ Relay Chat ปัจจุบันข้ามข้อความสะท้อนกลับที่ตรวจพบอัตโนมัติ ใช้ ตัวกรองข้อความสะท้อนกลับ (Reflection Filter) โหนดเพื่อควบคุมว่าข้อความสะท้อนที่จับกลับมาจะแสดงในแผงด็อกและโอเวอร์เลย์หรือไม่ ดู คำแนะนำส่งต่อแชต สำหรับตั้งค่า ดูเอกสารแบบละเอียดได้ใน คู่มือ Event Flow สำหรับเสียงหรือสื่อรางวัล Kick ใช้ คู่มือแต้มช่อง / รางวัล Kick.

การควบคุมด้วย MIDI และปุ่มลัด

ควบคุม Social Stream Ninja โดยตรงจาก Stream Deck คอนโทรลเลอร์ MIDI หรือปุ่มลัดแป้นพิมพ์

ตั้งค่า MIDI:

  1. เชื่อมต่ออุปกรณ์ MIDI (Stream Deck คอนโทรลเลอร์ MIDI ฯลฯ)
  2. เปิดป๊อปอัป Social Stream Ninja
  3. หาส่วนตั้งค่า MIDI
  4. เลือกอุปกรณ์ MIDI จากรายการแบบเลื่อนลง
  5. จับคู่โน้ต MIDI กับการกระทำเฉพาะ

การกระทำที่ใช้ได้:

  • เรียกโอเวอร์เลย์และสื่อกำหนดเอง
  • ส่งข้อความแชตที่ตั้งไว้ล่วงหน้า
  • สลับฉาก OBS
  • เล่นคลิปเสียงหรือ TTS
  • เรียกตัวเรียก Event Flow

เคล็ดลับ: MIDI เหมาะสำหรับควบคุมสตรีมโดยไม่ใช้มือ ใช้แป้นเหยียบเรียกการแจ้งเตือนหรือปุ่มหมุนปรับระดับเสียง

คำสั่งบอตและตอบกลับอัตโนมัติ

สร้างคำสั่งบอตโต้ตอบและคำตอบอัตโนมัติสำหรับแชต

คำสั่งในตัว:

  • !joke - ส่งมุกพ่อสายเนิร์ดแบบสุ่ม
  • !hi - ทักทายผู้ชมอัตโนมัติ
  • !cycle - ให้ผู้ชมเปลี่ยนฉาก OBS (เมื่อมีสิทธิ์)

ตั้งค่าตอบอัตโนมัติ:

  1. เปิดป๊อปอัปส่วนขยายแล้วหาส่วน Bot/Auto-Response
  2. เปิดคำสั่งที่ต้องการใช้
  3. ให้หน้าต่างแชตมองเห็นอยู่ (ไม่ย่อ) เพื่อให้คำตอบทำงาน
  4. ตรวจว่าเข้าสู่ระบบแพลตฟอร์มพร้อมสิทธิ์โพสต์

การสร้างคำสั่งกำหนดเอง:

สำหรับคำสั่งซับซ้อนขึ้น ใช้ตัวแก้ไข Event Flow:

  1. สร้างโฟลว์ใหม่ด้วยแหล่ง Message
  2. เพิ่มโหนด "Contains Keyword" เพื่อตรวจคำสั่งของคุณ (เช่น "!social")
  3. เชื่อมการกระทำ "Send Chat" พร้อมคำตอบของคุณ
  4. เพิ่มตัวกรอง User Role ได้หากต้องการคำสั่งเฉพาะผู้ดูแล

ข้อกำหนด: คำตอบอัตโนมัติทำงานดีที่สุดกับเบราว์เซอร์ Chromium หน้าต่างแชตต้องมองเห็นและคุณต้องมีสิทธิ์โพสต์บนแพลตฟอร์ม

Webhook และการเชื่อมต่อ

เชื่อมแพลตฟอร์มบริจาคภายนอกเพื่อแสดงทิปและการซื้อในโอเวอร์เลย์สตรีม

สิ่งที่ต้องเตรียม:

  1. จด Session ID จากป๊อปอัปส่วนขยาย
  2. เปิด Social Stream Ninja ทิ้งไว้
  3. ใน Global settings and tools → Mechanics, เปิดใช้ การควบคุมส่วนขยายจากระยะไกลผ่าน API
  4. ใช้ลิงก์แผงด็อกและโอเวอร์เลย์ปกติที่สร้างให้ อย่าเพิ่ม &server, &server2, หรือ &server3 สำหรับ webhook บริจาค
  5. โหลดแผงด็อกใหม่หนึ่งครั้งหากเปิดอยู่แล้ว
ต้องใช้สวิตช์ API เพียงตัวเดียว: remote API control ให้สคริปต์เบื้องหลังปรับรูปแบบ webhook บริจาคและส่งเหมือนข้อความปกติ สวิตช์ช่องทาง API อื่นปิดไว้ได้

ข้อมูลบริจาคที่ปรับรูปแบบแล้วใช้ร่วมกับแชต การแจ้งเตือน Event Flow และโหลทิป/มาตรวัดเป้าหมาย

แพลตฟอร์มที่รองรับ:

แพลตฟอร์ม URL ของ Webhook ประเภทอีเวนต์
Stripe https://io.socialstream.ninja/{sessionID}/stripe checkout.session.completed
Ko-Fi https://io.socialstream.ninja/{sessionID}/kofi ทิปสาธารณะ สมาชิก คำสั่งซื้อร้านค้า และงานคอมมิชชัน
Buy Me A Coffee https://io.socialstream.ninja/{sessionID}/bmac ทิป สมาชิก คำสั่งซื้อร้านค้า งานคอมมิชชัน และระดมทุนรายการอยากได้
Fourthwall https://io.socialstream.ninja/{sessionID}/fourthwall คำสั่งซื้อ ของขวัญ การบริจาค และการสมัครสมาชิกใหม่

ตั้งค่า Stripe:

  1. สร้าง ลิงก์ชำระเงิน Stripe
  2. สำคัญ: เพิ่มช่องกำหนดเองลงในลิงก์ชำระเงิน:
    • ชื่อที่แสดง หรือ ชื่อผู้ใช้ (จำเป็น) - หากไม่มีช่องนี้ การบริจาคจะถูกปฏิเสธ
    • ข้อความ (ไม่บังคับ) - ให้ผู้บริจาคฝากข้อความได้
  3. ไปที่ Stripe Webhooks และสร้าง endpoint ใหม่
  4. ตั้ง URL เป็น: https://io.socialstream.ninja/YOUR_SESSION_ID/stripe
  5. เลือกอีเวนต์: checkout.session.completed
  6. ไม่ต้องตรวจลายเซ็น (เก็บรหัสเซสชันเป็นความลับแทน)

การทดสอบ: ใช้ Test Mode ของ Stripe พร้อมบัตร 4242 4242 4242 4242, วันหมดอายุใดก็ได้ในอนาคต และ CVC ใดก็ได้

ตั้งค่าร้านค้าครีเอเตอร์

ใช้ คู่มือตั้งค่าพร้อมภาพ สำหรับ Fourthwall, Ko-fi และ Buy Me a Coffee รวมสถานะตัวรับ ตัวอย่างแยก และนำเข้าสินค้า

หมายเหตุด้านความปลอดภัย: เก็บรหัสเซสชันเป็นความลับ ใครก็ตามที่มีรหัสส่งอีเวนต์บริจาคปลอมเข้าโอเวอร์เลย์ได้

การส่งออกแชตผ่าน Webhook:

คุณส่งออกข้อมูลแชตไปบริการภายนอกได้ด้วย:

  • ตั้ง URL ของ webhook ขาออกในการตั้งค่า
  • ส่งข้อความแชตเป็นคำขอ POST พร้อมข้อมูล JSON
  • ใช้บันทึกแชต เรียกระบบอัตโนมัติภายนอก หรือซิงก์กับเครื่องมืออื่น

การแก้ปัญหา (ส่วนขยายเบราว์เซอร์)

วิธีแก้ปัญหาพบบ่อยของส่วนขยายเบราว์เซอร์

แชตหยุดเมื่ออยู่เบื้องหลัง/ย่อหน้าต่าง

ข้อความแชตหยุดปรากฏเมื่อหน้าต่างเบราว์เซอร์อยู่เบื้องหลังหรือย่อ เพราะเบราว์เซอร์ลดการทำงานของแท็บเบื้องหลังเพื่อประหยัดทรัพยากร

ปิดการลดการทำงานของเบราว์เซอร์
  • Chrome/Edge/Brave:
    1. เปิด chrome://flags/#enable-throttle-display-none-and-visibility-hidden-cross-origin-iframes
    2. ตั้งเป็น "Disabled"
    3. ปิดเพิ่มด้วยสำหรับ chrome://flags/#calculate-native-win-occlusion
    4. เริ่มเบราว์เซอร์ใหม่
  • ปิดการจำกัดประสิทธิภาพ:
    1. ไปที่ chrome://settings/performance
    2. ปิด "Throttle Javascript timers in background"
แนวทางอื่น
  • ให้หน้าต่างมองเห็นอยู่: จัดหน้าต่างไม่ให้ย่อ แม้เห็นเพียงส่วนเล็ก ๆ ก็ช่วยป้องกันการลดการทำงานได้
  • ใช้เดสก์ท็อปเสมือน: บน Windows ใช้ Win+Tab สร้างเดสก์ท็อปเสมือนสองชุด วางหน้าต่างแชตชุดหนึ่งและ OBS อีกชุด
  • ลองแอปแยก: แอปเดสก์ท็อป Social Stream Ninja หลีกเลี่ยงปัญหาเบราว์เซอร์ลดการทำงานได้หลายอย่าง

มีแถบสีน้ำเงิน / ระบบตอบอัตโนมัติไม่ทำงาน

มีแถบดีบักสีน้ำเงิน หรือคำตอบอัตโนมัติไม่ทำงานเมื่อใช้คำสั่งบอตหรือระบบตอบอัตโนมัติ

ตรวจการมองเห็นหน้าต่างแชต
  • เมื่อใช้ YouTube หรือ Twitch ตรวจว่าเปิดหน้าต่างแชตป๊อปเอาต์และมองเห็นอยู่
  • บางแพลตฟอร์มอาจต้องเปิดหน้าต่างหลักไว้พร้อมป๊อปเอาต์
ความเข้ากันได้กับเบราว์เซอร์
  • ระบบตอบอัตโนมัติทำงานดีที่สุดกับเบราว์เซอร์ Chromium (Chrome, Edge, Brave)
  • Firefox รองรับฟีเจอร์ส่วนขยายได้จำกัด

เริ่มต้นใช้งาน (แอปแยก)

1. ติดตั้ง

แอปแยกติดตั้งง่ายกว่าส่วนขยายเบราว์เซอร์:

  • Windows: ดาวน์โหลดและเรียกตัวติดตั้งสำหรับ Windows 10/11 (x64)
  • macOS: ดาวน์โหลดและเรียกแอป macOS
  • Linux: ใช้ไฟล์ AppImage สำหรับ Linux ส่วนใหญ่

สำหรับวิธีติดตั้งแบบละเอียด ดู หน้าดาวน์โหลด.

2. ตั้งค่าพื้นฐาน

เมื่อติดตั้งแล้ว ทำตามขั้นตอนเพื่อเริ่มใช้แอปแยก Social Stream Ninja:

  1. เปิดแอป Social Stream Ninja
  2. คลิกปุ่มแพลตฟอร์มที่ต้องการเพิ่มในแถบด้านซ้าย
  3. ป้อนชื่อผู้ใช้ Video ID หรือ URL ตามที่ขอ
  4. คลิก "Activate source" หรือ "Select Live Sources" เพื่อเชื่อมต่อ
  5. คัดลอกลิงก์ "Streaming Chat" และเพิ่มเป็นแหล่งเบราว์เซอร์ใน OBS

หมายเหตุ: แอปแยกหลีกเลี่ยงข้อจำกัดเบราว์เซอร์หลายอย่าง เช่น การลดการทำงาน และมีฟีเจอร์เพิ่ม เช่น ตรึงหน้าต่าง

3. เชื่อมต่อแพลตฟอร์มต่าง ๆ

แอปแยกช่วยให้เชื่อมต่อแพลตฟอร์มต่าง ๆ ง่ายขึ้น:

YouTube

  • คลิก "YouTube Username" ในแถบด้านซ้าย
  • ป้อนชื่อช่องหรือ Video ID
  • คลิก "Auto-find & Activate" สำหรับสตรีมสด

Twitch

  • คลิก "Twitch Username" ในแถบด้านซ้าย
  • ป้อนชื่อผู้ใช้ Twitch
  • คลิก "Activate source" เพื่อเชื่อมต่อ

Facebook, TikTok, Instagram

  • คลิกปุ่มของแพลตฟอร์มนั้น
  • ใช้ปุ่ม "Sign in" เพื่อยืนยันตัวตนหากจำเป็น
  • ไปยังสตรีมสดของคุณภายในหน้าต่างแอป
  • สำหรับโหมดเชื่อมต่อ TikTok การตอบ และทางสำรอง TikFinity ข้ามไปที่ คู่มือ TikTok

4. วิดีโอสอน

ดูวิดีโอนี้เพื่อเรียนรู้การใช้แอปแยกแบบเห็นภาพ:

คู่มือ TikTok

ต้องการความช่วยเหลือตั้งค่า TikTok ตอบกลับ โหมดเชื่อมต่อ หรือทางสำรอง TikFinity? ใช้คู่มือ TikTok โดยเฉพาะ

  • ใช้โหมดใด: TikTok WS + Auto, Standard, Local Signer, Polling, Euler Proxy หรือ Euler Signing
  • วิธีตอบแชต TikTok จาก SSN
  • วิธีใช้ TikFinity OBS Dock เป็นทางสำรองผ่าน Other chat sites
  • สิ่งที่ควรลองเมื่อ TikTok บอกว่าออฟไลน์ ข้อความตกหล่น แชตซ้ำ หรือหน้าต่างยืนยันตัวตนปิด

เปิดคู่มือ TikTok

TikTok (แอปแยก)

ความช่วยเหลือตั้งค่า TikTok โดยเฉพาะ รวมการตอบ เลือกโหมด และทางสำรอง TikFinity

เปิดคู่มือ TikTok ฉบับเต็ม

แอปแยกมีตัวเลือก TikTok มากที่สุดใน SSN คู่มือจึงย้ายไปหน้าเฉพาะแล้ว

  • ความช่วยเหลือเลือกโหมด: TikTok WS + Auto, Standard, Local Signer, Polling, Euler Proxy และ Euler Signing
  • วิธีส่งคำตอบเข้าแชต TikTok จาก SSN

พารามิเตอร์ URL

แอปแยกรองรับพารามิเตอร์ URL เดียวกับส่วนขยายเบราว์เซอร์ ปรับได้ทั้งแดชบอร์ดและโอเวอร์เลย์:

พารามิเตอร์แดชบอร์ด:

&darkmode - เปิดโหมดมืดสำหรับแดชบอร์ด
&scale=2 - เพิ่มขนาด/ความละเอียดทุกองค์ประกอบเป็นสองเท่า
&hidesource - ซ่อนไอคอนแพลตฟอร์ม (YouTube, Twitch ฯลฯ)
&compact - ลบช่องว่างระหว่างชื่อกับข้อความ
&inline - วางข้อความต่อข้างชื่อโดยคงระยะห่างปกติ
&autoshow - นำข้อความมาแสดงเด่นอัตโนมัติเมื่อเข้ามา

พารามิเตอร์โอเวอร์เลย์:

&showtime=20000 - ซ่อนข้อความที่เลือกอัตโนมัติหลัง 20 วินาที
&showsource - แสดงไอคอนแพลตฟอร์มข้างชื่อผู้ใช้
&fade - ทำให้ข้อความเด่นค่อย ๆ ปรากฏแทนโผล่ทันที
&swipe - ทำให้ข้อความเด่นเลื่อนเข้าจากซ้าย
¢er - จัดข้อความเด่นไว้กึ่งกลางจอ

การปรับแต่ง CSS

แอปแยกรองรับการปรับ CSS แบบเดียวกับส่วนขยาย:

วิธีที่ 1: CSS แหล่งเบราว์เซอร์ OBS

เมื่อใช้ URL โอเวอร์เลย์แอปใน OBS:

  1. เพิ่ม URL โอเวอร์เลย์ของแอปเป็นแหล่งเบราว์เซอร์ใน OBS
  2. เลือกตัวเลือก "Custom CSS"
  3. ป้อน CSS กำหนดเองในช่องข้อความ

วิธีที่ 2: การตั้งค่าเมนูแอป

เพิ่ม CSS โดยตรงผ่านเมนูแอป:

  1. เปิดเมนูตั้งค่าแอป
  2. หาส่วนตั้งค่า CSS/JavaScript
  3. ป้อน CSS หรือ JavaScript กำหนดเอง
  4. CSS จะถูกต่อท้าย URL เป็นข้อมูลเข้ารหัส base64

วิธีที่ 3: ใช้เทมเพลตกำหนดเอง

เลือกเทมเพลตตกแต่งสำเร็จที่มี CSS ในตัว:

  • ดู แกลเลอรีเทมเพลต
  • เลือกเทมเพลตที่เข้ากับสไตล์สตรีม
  • แทนที่ YOURSESSIONID ใน URL เทมเพลตด้วยรหัสเซสชันของคุณ
  • เพิ่ม URL เทมเพลตเป็นแหล่งเบราว์เซอร์ใน OBS

ตัวอย่าง: https://socialstream.ninja/themes/pretty.html?session=YOURSESSIONID

ตัวแก้ไข Event Flow

สร้างระบบอัตโนมัติที่ครบครันด้วยตัวแก้ไข Event Flow แบบโหนด

สิ่งที่ทำได้:

  • ส่งต่อแชต ระหว่างแพลตฟอร์มพร้อมตัวกรองอัจฉริยะ
  • เรียกโอเวอร์เลย์และเสียง ตามอีเวนต์หรือคำสำคัญ
  • ควบคุม OBS ฉากและแหล่งข้อมูลอัตโนมัติ
  • สร้างคำสั่งกำหนดเอง ด้วยเกตตรรกะ (AND/OR/NOT)
  • สร้างการจับรางวัลและเกม พร้อมจัดการคิว

เริ่มต้นใช้งาน:

  1. เปิดตัวแก้ไข Event Flow จากเมนูแอป
  2. สร้างโฟลว์พร้อมโหนดต้นทาง (Message, Timer, Manual Trigger)
  3. เพิ่มโหนดตรรกะเพื่อกรอง (Contains Keyword, User Role ฯลฯ)
  4. เชื่อมโหนดการกระทำ (Send Chat, Play Audio, Display Overlay)
  5. ทดสอบด้วยตัวจำลองก่อนถ่ายทอดสด

โอเวอร์เลย์ Flow Actions:

เพิ่ม URL ของ Flow Actions เป็นแหล่งเบราว์เซอร์ใน OBS เพื่อให้การกระทำเสียง/โอเวอร์เลย์ทำงาน หา URL ได้ในส่วน "Flow Actions" ของแอป

สำหรับเอกสารแบบละเอียด ดู คู่มือ Event Flow สำหรับเสียงหรือสื่อรางวัล Kick ใช้ คู่มือแต้มช่อง / รางวัล Kick.

ปัญหาเชื่อมต่อแพลตฟอร์ม

มีปัญหาเชื่อมต่อบางแพลตฟอร์มในแอปแยก

ปัญหาการยืนยันตัวตน
  • สำหรับ Facebook, TikTok และ Instagram ใช้ปุ่ม "Sign in" ก่อน
  • ตรวจว่าใช้ข้อมูลเข้าสู่ระบบเดียวกับเบราว์เซอร์
  • ตรวจว่าต้องให้สิทธิ์แอปเพิ่มหรือไม่

  • ตรวจการเชื่อมต่ออินเทอร์เน็ต
  • ปิด VPN หากรบกวนการเชื่อมต่อ
  • ลองเปลี่ยนผู้ให้บริการ DNS

การตั้งค่าไม่บันทึก

การกำหนดค่าหรือการตั้งค่าไม่ถูกบันทึกข้ามเซสชัน

ปัญหาสิทธิ์
  • ตรวจว่าแอปมีสิทธิ์เขียนในโฟลเดอร์ติดตั้ง
  • เรียกแอปในฐานะผู้ดูแลระบบ (Windows) หากจำเป็น
  • ตรวจว่าโปรแกรมป้องกันไวรัสบล็อกการเขียนไฟล์หรือไม่
ส่งออกการตั้งค่า
  • ใช้ฟีเจอร์ส่งออกเพื่อบันทึกการตั้งค่า
  • บันทึกไฟล์ส่งออกไว้ในที่ปลอดภัย
  • นำเข้าการตั้งค่าหากสูญหายหลังอัปเดต

  • มีฟีเจอร์ตรึงหน้าต่างและความโปร่งใส
  • มีประสิทธิภาพและความเสถียรดีกว่า
ส่วนขยายเบราว์เซอร์เหมาะกว่าหากคุณ:
  • ต้องใช้บนคอมพิวเตอร์หลายเครื่อง

  • ต้องการอัปเดตล่าสุดทันที (ติดตั้งเอง)

เราดูแลรายการมาตรฐานของข้อมูลอีเวนต์ทั้งหมด (ผู้ติดตาม สมาชิก เรด จำนวนผู้ชม บริจาค และอื่น ๆ) ใน เอกสารอ้างอิงอีเวนต์ ยังอธิบายว่าแหล่งใดต้องเปิด “Capture Stream Events” มีสิทธิ์เข้าสู่ระบบ หรือขอบเขตสิทธิ์เพิ่มเติมเพื่อรับข้อมูล
URL โอเวอร์เลย์ API แผงด็อก คำสั่ง WebSocket และจุดเชื่อมระบบอัตโนมัติทั้งหมดอธิบายไว้ใน คำสั่งและ API หน้า เป็นจุดเริ่มต้นที่เหมาะที่สุดเมื่อคุณต้องการเขียนพฤติกรรมกำหนดเองหรือเชื่อม Social Stream Ninja กับเครื่องมืออื่น
Social Stream Ninja มีชุมชน Discord ที่มีการพูดคุยต่อเนื่อง คุณขอความช่วยเหลือตรงจากผู้พัฒนาและผู้ใช้อื่นได้ เข้าร่วมที่ discord.socialstream.ninja คุณรายงานปัญหาได้ที่ คลังโค้ด GitHub.
