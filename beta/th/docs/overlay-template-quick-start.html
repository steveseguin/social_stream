เริ่มใช้เทมเพลตโอเวอร์เลย์อย่างรวดเร็ว

เลือกเลย์เอาต์ เพิ่มรหัสเซสชัน แล้ววางใน OBS

1. เปิดแกลเลอรีเทมเพลต

ใช้ แกลเลอรีเทมเพลต เมื่อต้องการรูปแบบแชตสำเร็จรูปแทนการสร้าง CSS ตั้งแต่ต้น

2. เพิ่มรหัสเซสชัน

URL โอเวอร์เลย์ทุกอันต้องมีรหัสเซสชันของคุณ แทนค่าตัวอย่างด้วยเซสชันเดียวกับแหล่งแชตและแผงด็อก

https://socialstream.ninja/sampleoverlay.html?session=YOUR_SESSION_ID

3. ดูตัวอย่างหน้าตา

เปิด URL เทมเพลตในเบราว์เซอร์ก่อน หากดูถูกต้องที่นั่น การแก้ปัญหาใน OBS จะง่ายขึ้น

4. เพิ่มใน OBS

  1. ใน OBS เพิ่มแหล่งเบราว์เซอร์ใหม่
  2. วาง URL เทมเพลตที่มีรหัสเซสชันของคุณ
  3. ตั้งความกว้างและความสูง ค่าเริ่มต้นที่ใช้บ่อยคือ 1920 คูณ 1080
  4. คลิก OK แล้วส่งข้อความทดสอบ

5. ยืนยันว่าแชตเข้ามา

หากโอเวอร์เลย์ว่าง ให้ทดสอบแผงด็อกก่อนเปลี่ยนการตั้งค่าเทมเพลต

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

วิธีแก้เบื้องต้น

  • ใช้รหัสเซสชันเดียวกันในแหล่งข้อมูล แผงด็อก และ OBS
  • รีเฟรชแหล่งเบราว์เซอร์ OBS หลังเปลี่ยน URL
  • เปิดหน้าแหล่งแชตหรือหน้าต่างแหล่งข้อมูลเดสก์ท็อปค้างไว้
  • เลือกเทมเพลตที่มีคอนทราสต์สูงหากอ่านข้อความยาก
