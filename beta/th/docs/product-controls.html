สินค้าสดและลิงก์ผู้ชม

เลือกสินค้าที่จะแสดงบนจอ ให้ผู้ชมใช้ลิงก์เดียวเพื่อดูทั้งหมด

เพิ่มสินค้า ควบคุมแบบสด ลิงก์ผู้ชม Stream Deck และ Event Flow API ระยะไกล แก้ปัญหา

เพิ่มสินค้าใน 5 ขั้นตอน

  1. เปิด การสร้างรายได้ → สินค้าและลิงก์สนับสนุน → ตั้งค่าสินค้าและลิงก์.
  2. วางลิงก์สาธารณะของ https:// แล้วคลิก โหลดรายละเอียดจากลิงก์.
  3. ตรวจสอบชื่อ รูปภาพ ราคา สกุลเงิน และ วัตถุประสงค์ของลิงก์ช่องราคาจะเว้นว่าง ให้กรอกเองหากต้องการแสดง
  4. คลิก เพิ่มสินค้าหรือลิงก์.
  5. เปิด สินค้าและลิงก์สนับสนุน แล้วคลิก บันทึกการตั้งค่า.
ลิงก์ใดโหลดได้เอง หน้าสาธารณะของ Gumroad, itch.io, Ko-fi, Buy Me a Coffee และ Fourthwall เว็บไซต์อื่นอาจต้องกรอกเอง ไม่ต้องมีบัญชีร้านค้า มีการนำเข้าแบบเต็มสำหรับ Shopify และ Fourthwall.

ซื้อสินค้า ของขวัญ สนับสนุน และเข้าร่วม เป็นเพียงป้ายกำกับลิงก์ ไม่เปลี่ยนการนับการชำระเงิน การ์ดเป็นภาพข้อมูล ณ เวลาหนึ่ง ราคาและสต็อกจริงอยู่ที่หน้าชำระเงิน

ควบคุมสิ่งที่แสดงบนจอ

เพิ่ม สินค้าและลิงก์สนับสนุน ไปยัง OBS (แสดงสินค้าและแจ้งเตือน แสดงการแจ้งเตือนด้วย) จากนั้นใช้ปุ่มเหล่านี้:

ปุ่มทำอะไร
แสดงตอนนี้ (บนสินค้าที่บันทึกไว้)แสดงสินค้านั้นทันทีโดยไม่สนกำหนดการ
สินค้าถัดไปแสดงสินค้าที่บันทึกไว้ชิ้นถัดไป
ซ่อนสินค้าซ่อนการ์ดสินค้า การแจ้งเตือนซื้อและของขวัญยังแสดงอยู่
กลับไปใช้ตารางเวลากลับไปใช้การหมุนเวียนที่บันทึกไว้หรือสินค้าชิ้นแรกที่ปักหมุด

ตั้งค่า ระยะเวลาแสดง/ซ่อนเป็นวินาที ก่อน 0 = จนกว่าคุณจะเปลี่ยน 1–3600 = กลับสู่กำหนดการหลังครบเวลานั้น

สิ่งที่ควรรู้
  • การเปลี่ยนแปลงแบบสดจะรีเซ็ตเมื่อ SSN เริ่มใหม่
  • บน Stream Deck สินค้าที่บันทึกไว้แต่หาไม่พบจะยังแสดงบนปุ่ม แทนที่จะสลับเองโดยไม่แจ้ง
  • สินค้าที่ไม่บันทึกจะมีเครื่องหมาย ปุ่ม แสดงตอนนี้ จะยังปิดใช้งานจนกว่าคุณจะคลิก บันทึกการตั้งค่า.
  • สถานะแสดงสินค้าที่เลือกและเวลาที่เหลือ ไม่สามารถบอกได้ว่า OBS กำลังถ่ายทอดสดหรือแหล่งนั้นมองเห็นอยู่หรือไม่
  • ค้นหาสินค้าด้วยลิงก์ที่ตรงกับที่บันทึกไว้ทุกตัวอักษร การเรียงรายการใหม่จึงไม่ทำให้ระบบอัตโนมัติเสีย

ต้องการปุ่มใน OBS หรือไม่ ใช้ แผงด็อกควบคุมสินค้าใน OBSเก็บปุ่มควบคุมออกจากโอเวอร์เลย์ที่ผู้ชมเห็น

ให้ผู้ชมใช้ลิงก์เดียว

  1. เปิด ตัวเลือกการแสดงผล → หน้าสาธารณะสำหรับผู้ชม.
  2. คลิก เผยแพร่ลิงก์ที่บันทึกการทำเช่นนี้ทำให้สินค้าที่บันทึกทั้งหมดเป็นสาธารณะ ทั้งชื่อ รูปภาพ ราคา และวัตถุประสงค์
  3. คลิก คัดลอกลิงก์ผู้ชม แล้วแชร์

รหัส QR ของสินค้าชี้มาที่นี่ ผู้ชมจึงหาสินค้าได้แม้สินค้าจะออกจากจอแล้ว การบันทึกและการควบคุมแบบสดอัปเดตลิงก์เดียวกัน หน้ารีเฟรชทุก 15 วินาที ระบุสินค้าที่กำลังแนะนำ และแสดงทั้งหมดแม้ซ่อนการ์ดอยู่

ฉันต้องการ…ทำตามนี้
นำหน้าออกจากการเผยแพร่คลิก ยกเลิกเผยแพร่ลิงก์เก่าจะหยุดทำงาน และรหัส QR จะกลับไปยังลิงก์ของสินค้าแต่ละชิ้น
เรียกคืนลิงก์เดิมเผยแพร่อีกครั้งจากคอมพิวเตอร์เครื่องเดิม
เก็บโปรไฟล์ SSN ของคุณไว้ เก็บคีย์ส่วนตัวที่ใช้ปรับปรุงหรือลบหน้าของคุณ
เมื่อ SSN ออฟไลน์หรือเซิร์ฟเวอร์หยุดทำงาน
  • หน้าที่เผยแพร่ล่าสุดยังคงอยู่เมื่อปิด SSN พร้อมเวลาที่บันทึก
  • “แนะนำ” หมายถึงตัวเลือกหรือการหมุนเวียนที่บันทึกล่าสุด ไม่ได้หมายความว่าคุณกำลังถ่ายทอดสด
  • หากเซิร์ฟเวอร์หยุดทำงาน การควบคุมใน SSN ยังใช้ได้ จะลองอัปเดตอีกขณะ SSN เปิดอยู่ และป๊อปอัปจะแสดงข้อผิดพลาด
  • การเผยแพร่ต้องใช้บริการร้านค้าสาธารณะที่เป็นตัวเลือกบนเซิร์ฟเวอร์ ไม่เกี่ยวข้องกับบัญชีร้านค้าหรือการชำระเงิน

Stream Deck และ Event Flow

Stream Deck

  1. เพิ่ม คำสั่งพรีเซ็ต (Preset Command) จาก สินค้าและการสนับสนุน: แสดงสินค้า สินค้าถัดไป ซ่อนสินค้า หรือแสดงสินค้าต่อ
  2. สำหรับ แสดงสินค้า คลิก รีเฟรชสินค้าและสถานะ แล้วเลือกสินค้า หรือวางลิงก์สาธารณะ หรือเว้นว่างเพื่อใช้สินค้าปัจจุบันหรือชิ้นแรก
  3. สำหรับ ถัดไป และ ซ่อนเพิ่มระยะเวลาเป็นวินาทีได้ตามต้องการ

ตัวเลือก สถานะสินค้า แสดงสิ่งที่เลือก ซ่อน หรือกำหนดเวลาไว้ (ทุก 5 วินาที ชื่อยาวจะย่อให้สั้น) ปุ่มใช้การเชื่อมต่อ P2P หรือ WebSocket เดิมของคุณและรอ SSN ยืนยัน

Event Flow

  1. เพิ่ม สินค้าและการสนับสนุน จากกลุ่มแอ็กชันโอเวอร์เลย์
  2. เลือกแสดง ถัดไป ซ่อน หรือแสดงต่อ เพิ่มลิงก์สินค้าที่ตรงกับที่บันทึกไว้และระยะเวลาเป็นวินาทีได้ตามต้องการ
  3. กระตุ้นด้วยสิ่งที่คุณควบคุมได้ เช่น คำสั่งผู้ดูแล แทนทุกข้อความในแชต
ตัวเลือกเหล่านี้เปลี่ยนเฉพาะสิ่งที่แสดง ไม่สร้างการบริจาค การซื้อ โพสต์แชต หรือทริกเกอร์ชำระเงิน

API ระยะไกล (ขั้นสูง)

API ควบคุมเซสชันระยะไกลรับค่า show, next, hide, หรือ resume. การควบคุมผู้ดำเนินรายการ ต้องเปิดอยู่ ไม่ต้องใส่ url สำหรับสินค้าปัจจุบันหรือชิ้นแรก

{"action":"commerceControl","command":"show","url":"https://example.com/product","seconds":30}
อย่าแชร์ลิงก์เซสชันหรือควบคุมส่วนตัว ส่งลิงก์สำหรับผู้ชมให้ผู้ชม
รู้เมื่อคำสั่งควบคุมเสร็จ
  • คำสั่งส่งเฉพาะ monetization_update สถานะการแสดงผลที่มีอยู่ hasDonation ยังทำงานเหมือนเดิม
  • แอ็กชันสินค้าและการสนับสนุนรอคำตอบจาก SSN ก่อนดำเนินโฟลว์ต่อ
  • ในข้อมูลกิจกรรม meta.commerceControlResult มี success พร้อมค่าใหม่อย่างใดอย่างหนึ่ง commerce หรือค่า error.
  • ความล้มเหลวจะหยุดแอ็กชันถัดไปในสายงานนั้น การซื้อหรือทิปเดิมยังส่งถึงโฟลว์และโอเวอร์เลย์อื่น
  • ผลยืนยันรายการที่เลือก สถานะซ่อน หรือกำหนดการของ SSN ไม่ได้ยืนยันว่า OBS กำลังแสดงอยู่
  • หากไม่มีคำตอบภายในแปดวินาทีถือว่าหมดเวลารอ การควบคุมอาจทำงานแล้ว ให้ตรวจสอบป๊อปอัปหรือ Dock ก่อนกดถัดไปอีกครั้ง
  • ไคลเอนต์ควบคุมระยะไกลภายนอกควรใช้โปรโตคอลคำขอ/คำตอบและตรวจสอบผล ไม่ควรถือว่าคำสั่งทำงานเพียงเพราะส่งแล้ว
  • แอ็กชันอื่นรายงานผลของตัวเอง: พิมพ์ฉลากความร้อนให้ค่า meta.thermalPrintResult (การส่งงานไม่ได้ยืนยันว่าพิมพ์แล้ว) และแอ็กชัน Webhook แบบรอผลสามารถคืนสถานะ HTTP กับคำตอบ และหยุดเมื่อผิดพลาดได้ ทั้งหมดนี้เป็นผลของแอ็กชัน ไม่ใช่กิจกรรมชำระเงินใหม่

ดู เอกสารอ้างอิงเหตุการณ์ เพื่อดูรูปแบบผลลัพธ์ทั้งหมด

แก้ปัญหา

ปัญหาลองวิธีนี้
ปุ่มแสดงตอนนี้เป็นสีเทาคลิก บันทึกการตั้งค่า ก่อน
การเปลี่ยนแปลงแบบสดย้อนกลับเองSSN เริ่มใหม่หรือหมดเวลาที่ตั้งไว้ ให้ตั้ง ระยะเวลาแสดง/ซ่อนเป็นวินาที เป็น 0 เพื่อคงการเปลี่ยนแปลงไว้
โหลดรายละเอียดจากลิงก์แล้วไม่พบข้อมูลกรอกรายละเอียดเอง
หน้าผู้ชมแสดงสินค้าเก่าเปิด SSN ไว้เพื่อให้ลองใหม่ได้ และตรวจสอบข้อผิดพลาดในป๊อปอัป
แอ็กชัน Event Flow หมดเวลารออาจทำงานสำเร็จแล้ว ตรวจสอบป๊อปอัปหรือ Dock ก่อนลองอีกครั้ง
