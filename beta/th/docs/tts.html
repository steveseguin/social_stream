คู่มือเสียง TTS

ตัวเลือกแปลงข้อความเป็นเสียงทั้งหมด: ผู้ให้บริการ ตัวเลือกลิงก์ เสียงระบบ และเสียง OBS

เริ่มที่นี่ ผู้ให้บริการ ตัวเลือกในลิงก์ การตั้งค่าผู้ให้บริการ เสียงระบบ System TTS ใน OBS แก้ปัญหา

เริ่มที่นี่

เพิ่งเริ่มใช้ TTS? ทำตาม คู่มือตั้งค่า TTS มี 5 ขั้นตอน หน้านี้เป็นเอกสารอ้างอิงเต็ม

SSN อ่านแชตใดก็ได้ที่จับมาเป็นข้อความ แพลตฟอร์มไม่ต้องมี TTS เอง Dock หรือโอเวอร์เลย์ที่เปิด TTS จะพูดตามตัวกรองของมัน

ลิงก์ง่ายที่สุดเปิด TTS ด้วยเสียงระบบ:

dock.html?session=YOUR_SESSION&speech=en-US

สำหรับ OBS เพิ่มเสียงฟรีที่เล่นผ่านหน้า:

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper

เปิดหน้านั้นและเชื่อมต่อไว้ ควรมีหน้าเดียวที่พูด

System TTS ไม่ใช่สิ่งเดียวกับ TTS ฟรี เสียงระบบมาจากเบราว์เซอร์และคอมพิวเตอร์ OBS มักไม่มี แม้ Chrome ใช้ได้ Kokoro, Piper, Kitten และ eSpeak ฟรีและสร้างเสียงเอง จึงใช้ใน OBS ได้ ไม่ต้องจ่ายเงินเพื่อใช้ TTS ใน OBS

TTS มีใน CAPTION.Ninja สำหรับคำบรรยาย การถอดเสียง และการแปล ทั้งคู่มีเสียงฟรีและเสียเงิน

เสียงระบบ

System TTS ใช้เสียงที่เบราว์เซอร์และคอมพิวเตอร์มี รายการนี้เป็นลักษณะทั่วไป ไม่รับประกัน

เบราว์เซอร์เสียงระบบ
Chromeได้ เสียง Google พร้อมเสียงระบบ
Edgeได้ เสียง Microsoft พร้อมชุดภาษา Windows
Firefoxจำกัด เฉพาะเสียงระบบในเครื่อง
Operaจำกัด ต่างกันตามการติดตั้ง
Safariต้องคลิกก่อนจึงเล่นเสียงได้
OBSมีเบราว์เซอร์ของตัวเอง ไม่ใช้เสียงจาก Chrome หรือ Edge การทดสอบในแอป SSN ไม่ได้ทดสอบ OBS

ตรวจเสียงระบบของเบราว์เซอร์นี้ แสดงเฉพาะเสียง System TTS ในเบราว์เซอร์ที่เปิด ไม่ได้ทดสอบ OBS หรือผู้ให้บริการอย่าง Kokoro รายการว่างไม่ได้หมายความว่าผู้ให้บริการอื่นใช้ไม่ได้

เพิ่มเสียงใน Windows

  1. เปิด Start > Settings > Time & Language > Speech.
  2. ใน จัดการเสียง (Manage Voices) คลิก เพิ่มเสียง (Add Voices).
  3. เลือกภาษาแล้วคลิก เพิ่ม.
  4. รีสตาร์ตเบราว์เซอร์

นี่คือ Windows 11 สำหรับ Windows 10 ดู คู่มือ Microsoft เสียงภายนอกบางตัวไม่แสดงในเบราว์เซอร์ Firefox มักแสดงเสียงระบบมากกว่าเบราว์เซอร์ที่อิง Chrome

นำ System TTS เข้า OBS

ใช้ผู้ให้บริการอื่น? ไม่จำเป็นต้องทำขั้นตอนนี้ เปิด ควบคุมเสียงผ่าน OBS (Control audio via OBS) ใน Browser Source ไม่ต้องใช้สายเสียงเสมือน
  1. ตรวจว่า System TTS พูดจริงก่อน OBS อาจไม่มีเสียงที่ใช้ได้ หากไม่มีเสียง การจัดเส้นทางเสียงแก้ไม่ได้ ใช้ผู้ให้บริการอื่น
  2. หากเสียงเล่นในเบราว์เซอร์อื่น ให้จับเสียงเบราว์เซอร์นั้นด้วย Application Audio Capture หรือ Desktop Audio ใน OBS
  3. ยังติดปัญหา? ส่งเสียงเบราว์เซอร์ผ่านสายเสียงเสมือน (ด้านล่าง)
ส่งเสียงผ่านสายเสียงเสมือน (Windows)

ดาวน์โหลด: VB-Audio Virtual Cable (ฟรี) · Voicemeeter · Audio Router (รุ่นเก่า)

วิธีทำตามนี้
ทั้งพีซีตั้งค่า CABLE Input เป็นเอาต์พุตเริ่มต้นของ Windows (Sound Settings > Output)
หนึ่งแอป, Windows 11Settings > System > Sound > Volume Mixer ตั้งเอาต์พุตของเบราว์เซอร์เป็น CABLE Input.
หนึ่งแอป, Windows 10Sound Settings > App volume and device preferences ตั้งเอาต์พุตของเบราว์เซอร์เป็น CABLE Input.
Audio Routerซอฟต์แวร์เก่า ส่งเสียงเบราว์เซอร์ไป CABLE Input.
Voicemeeterตั้งเป็นเอาต์พุตเริ่มต้นของ Windows ส่ง hardware out ไปลำโพง และ virtual out ไป OBS

จากนั้นใน OBS เพิ่ม เก็บเสียงขาเข้า (Audio Input Capture) เลือก CABLE Output (หรือเอาต์พุต Voicemeeter) แล้วตั้งการมอนิเตอร์เป็น มอนิเตอร์และส่งออก (Monitor and Output) ใช้ มอนิเตอร์เท่านั้น หากแหล่งอื่นส่งเสียงนี้เข้าสตรีมอยู่แล้ว

ทดสอบ: เล่น TTS ดูมิเตอร์ OBS ตรวจว่าได้ยิน แล้วปรับระดับ

แก้ปัญหา

ปัญหาลองวิธีนี้
ไม่มีเสียงตรวจว่าเปิด TTS หน้าที่พูดเปิดอยู่ และ Browser Source ไม่ได้ปิดเสียง ในเบราว์เซอร์ปกติ คลิกหน้าหนึ่งครั้ง
ไม่มีเสียงใน OBSไม่มีเสียงเลย? ตรวจผู้ให้บริการก่อน หากมีเสียงแล้ว ตรวจ ควบคุมเสียงผ่าน OBS (Control audio via OBS) ปุ่มปิดเสียงมิกเซอร์ และแทร็กเอาต์พุต หรือจับเสียงเบราว์เซอร์ที่กำลังพูด
เสียงคลาวด์ไม่ทำงานตรวจคีย์ API และชื่อผู้ให้บริการ หากไม่มีคีย์ SSN จะใช้ System TTS แทน ซึ่งอาจเงียบใน OBS
เซิร์ฟเวอร์ในเครื่องใช้ได้ในแอป แต่ไม่ได้ใน OBSOBS เป็นอีกเบราว์เซอร์ ตรวจเซิร์ฟเวอร์จากคอมพิวเตอร์ OBS โดยเฉพาะเมื่อใช้ 127.0.0.1 ดู กฎ localhost.
อ่านเฉพาะตัวอักษรหรือคำแรกนำออก ttsquick ออกจากลิงก์ OBS
เสียงใหม่ไม่แสดงรีสตาร์ตเบราว์เซอร์หลังเพิ่มชุดภาษา
Safari ไม่พูดSafari จำกัด TTS อัตโนมัติ คลิกหน้าหนึ่งครั้งเพื่ออนุญาตเสียง

แนวทางใช้งาน

  • ใช้ผู้ให้บริการที่เล่นเสียงผ่านหน้า ตั้งค่า OBS ได้ง่ายที่สุดและมีแบบฟรี
  • ทดสอบด้วยข้อความสั้นก่อนถ่ายทอดสด
  • ผู้ชมพิมพ์อะไรก็ได้ เตรียมวิธีปิด TTS อย่างรวดเร็ว
