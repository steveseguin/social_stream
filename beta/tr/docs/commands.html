Bot komutları

Yerleşik bot komutları

Social Stream Ninja, izleyicilerinizin sohbette kullanabileceği veya sizin API üzerinden tetikleyebileceğiniz çeşitli yerleşik komutlar içerir.

Komut Açıklama Nasıl etkinleştirilir?
!joke Yanıt olarak rastgele, teknoloji meraklılarına yönelik bir baba şakası anlatır Uzantı menüsündeki anahtarla etkinleştirin
hi Sohbette “hi” diyen herkesi otomatik olarak karşılar Uzantı menüsündeki anahtarla etkinleştirin
!cycle Etkinleştirildiğinde izleyicilerin OBS sahnelerini değiştirmesine izin verir Uzantı menüsündeki anahtarla etkinleştirin

Not: Bot komutları yalnızca otomatik yanıtlayıcı doğru yapılandırıldığında ve ilgili platformlarda mesaj gönderme izniniz olduğunda çalışır.

Otomatik yanıt yapılandırması

Cihaz ayrıntıları, sosyal bağlantılar, Discord davetleri ve yinelenen hatırlatıcılar için şu adresi takip edin: Uyarıları, sohbet komutlarını ve hatırlatıcıları ayarlayın.

Otomatik yanıtlayıcının doğru çalışması için:

  1. Platformda (YouTube, Twitch vb.) oturum açtığınızdan emin olun
  2. Sohbet penceresinin görünür olduğundan (küçültülmediğinden) emin olun
  3. İzinleri doğrulamak için önce elle bir test mesajı göndermeyi deneyin
  4. Uzantı menüsünde ilgili komut anahtarlarını etkinleştirin

Otomatik yanıtlar tetiklendiğinde mavi bir hata ayıklama çubuğu görüyorsanız Chrome'u şu seçenekle başlatarak gizleyebilirsiniz: --silent-debugger-extension-api .

Sunucu API'si

Genel bakış

Social Stream Ninja, yayın kurulumunuzun her yönünü programlı olarak kontrol etmenizi sağlayan güçlü bir API sunar. API sunucusu hem kurulumunuza komut gönderebilir hem de birleştirilmiş sohbet hizmetlerinden gelen mesajları dinleyebilir.

Katman yönetimi

Öne çıkan mesajları kontrol edin, katmanları temizleyin ve yayınınızdaki içeriğin görünümünü değiştirin.

Webhook entegrasyonu

Stripe, Ko-Fi ve Buy Me A Coffee gibi üçüncü taraf hizmetlerden etkinlikler alın.

Mesajları dışa aktarma

Özel entegrasyonlar için sohbet mesajlarını dosyaya aktarın veya webhook (POST) üzerinden iletin.

Gerekli ayarlar (Genel ayarlar → Mekanikler):

  • 🎮 Uzaktan kontrol (StreamDeck/Bitfocus): Şunu etkinleştirin: “Uzantının uzaktan API kontrolünü etkinleştir” (Anahtar 1) — Şuraya bağlanın: kanal 1
  • 📡 Sohbet dinleyicisi (Python/Node uygulamaları): Anahtar 1'i etkinleştirin + “Sohbet mesajlarını API sunucusuna gönder” (Anahtar 3) — Şuraya bağlanın: kanal 4

Bkz. tam API belgeleri ayrıntılı kurulum kılavuzları ve kod örnekleri için.

API uç noktaları ve bağlantı yöntemleri

HTTP GET/POST

https://io.socialstream.ninja/{sessionID}/{action}/{target}/{value}

Stream Deck veya özel betiklerden gönderilen basit komutlar için idealdir.

WebSocket

wss://io.socialstream.ninja:443

Otomatik yeniden bağlanmalı, gerçek zamanlı çift yönlü iletişim için.

WebSocket modunu etkinleştirmeden bağlantıları eşler arası tutmayı tercih ederseniz Social Stream Ninja WebRTC SDK'sını kullanabilirsiniz. Şu gibi Node ve tarayıcı örnekleri içerir: Social Stream Ninja dinleyicisi.

Sunucudan gönderilen etkinlikler

https://io.socialstream.ninja/sse/{sessionID}

Sunucudan tek yönlü gerçek zamanlı güncellemeler için.

Kanal sistemi

API, mesaj yönlendirme için bir kanal sistemi kullanır:

	- Channel 1: Remote control commands (default for StreamDeck/Bitfocus)
	- Channel 2: Dock page output
	- Channel 3: Extension receives commands from Dock
	- Channel 4: Chat messages from Extension (use this to receive Twitch/YouTube chat!)
	- Channel 5: Waitlist/giveaway communication
	- Channels 6-9: Reserved for future use

İstediğiniz kanalla bağlanın:

// To receive chat messages (listen on channel 4):
wss://io.socialstream.ninja/join/SESSION_ID/4

// To send commands (channel 1 default):
wss://io.socialstream.ninja/join/SESSION_ID

StreamDeck ve Companion

StreamDeck entegrasyonu

Social Stream Ninja, StreamDeck ile birden fazla yöntemle entegre olur: yerel HTTP işlemleri ve Bitfocus Companion entegrasyonu.

HTTP/API yöntemi

API'ye doğrudan komut göndermek için StreamDeck'in “Website” işlemini “GET request in background” etkin olacak şekilde kullanın.

Bitfocus Companion

Hazır işlemler, gerçek zamanlı geri bildirim ve dinamik içerik değişkenleriyle yerel entegrasyon.

Companion entegrasyonu

Bitfocus Companion, WebSocket veya HTTP API'lerini kullanarak Social Stream Ninja üzerinde güçlü kontrol sağlar.

İşlem Açıklama API yöntemi
Öne çıkan mesajı temizle Şu anda öne çıkarılan mesajı katmandan kaldırır WebSocket/HTTP
Kuyruktaki sonraki Sıradaki mesajı gösterir WebSocket/HTTP
Otomatik gösterimi aç/kapat Mesajların otomatik öne çıkarılmasını açar/kapatır WebSocket/HTTP
Sohbet mesajı gönder Bağlı tüm platformlara mesaj gönderir WebSocket/HTTP

Dinamik değişkenler

  • featured_message - Şu anda öne çıkarılan mesajın metni
  • featured_username - Şu anda öne çıkarılan kullanıcı adı
  • queue_size - Kuyruktaki mesaj sayısı

Yapay zekâ entegrasyonu

Yapay zekâ sohbet botu modu

Social Stream Ninja, yayınlarınızı yapay zekâ destekli sohbet yanıtları, moderasyon ve daha fazlasıyla geliştirmek için kapsamlı yapay zekâ entegrasyonu sunar. İhtiyacınıza uygun yerel veya bulut tabanlı yapay zekâ sağlayıcılarından seçim yapın.

Otomatik sohbet yanıtları

Siz içeriğinize odaklanırken bile yapay zekânın izleyicilerinizle otomatik olarak etkileşime girmesine, soruları yanıtlamasına ve sohbeti canlı tutmasına izin verin.

İçerik moderasyonu

Potansiyel olarak zararlı mesajları belirleyip tercihlerinize göre otomatik işleyerek sohbet moderasyonuna yardımcı olması için yapay zekâ kullanın. Engellemeyen mod ile sıkı engelleme modu arasından seçim yapın.

RAG araması

Bilgi getirmeyle desteklenen üretim (RAG), içeriğinize özel doğru yanıtlar sunmak için yapay zekânın özel bilgi tabanınızda arama yapmasını sağlar.

Birden fazla bot örneği

Farklı amaçlar için farklı bot örnekleri çalıştırın: herkese açık sohbet botu, özel bire bir bot, sansür botu ve hatta görüp duyabilen çok kipli bir yapay zekâ yardımcı sunucusu.

Desteklenen yapay zekâ sağlayıcıları

Social Stream Ninja, tamamen yerel tarayıcı/çalışma ortamı modellerinden barındırılan API'lere kadar birden fazla yapay zekâ sağlayıcısını destekler:

Ollama (Yerel API)

Ollama'nın kendi API'si üzerinden bilgisayarınızda çalışan ücretsiz, gizlilik odaklı, kendi barındırdığınız yapay zekâ modelleri.

Yerel Gemma 4

Model dosyalarını kendi dosya sunucunuza yansıttıktan sonra Gemma 4'ü tarayıcıda çalıştırın; SSN largefiles sunucusu şu anda Gemma dosyalarını içermez.

Yerel Qwen 3.5

Yerel ve özel yanıtlar için Qwen 3.5'i kendi barındırdığınız model dosyalarından tarayıcıda çalıştırın.

ChatGPT / OpenAI

Modern sohbet ve gerçek zamanlı ses modellerini içeren OpenAI API'leri.

Google Gemini

Güncel Gemini 2.5 metin ve canlı çok kipli seçenekleri dahil Google Gemini modelleri.

DeepSeek

Konuşma görevleri için optimize edilmiş verimli ve uygun maliyetli yapay zekâ modelleri.

xAI (Grok)

Geçici istemci sırları kullanıldığında gerçek zamanlı ses oturumları da dahil xAI Grok API'leri.

AWS Bedrock

Claude ve Llama dahil çeşitli sağlayıcılardan kurumsal düzeyde yapay zekâ modelleri.

OpenRouter

Tek bir API arayüzü üzerinden birden fazla yapay zekâ modeline erişim.

Groq

Hızlı sohbet yanıtları için düşük gecikmeli, OpenAI uyumlu sohbet çıkarımı.

Özel API (OpenAI uyumlu)

llama.cpp, LM Studio, vLLM veya başka bir OpenAI uyumlu uç noktaya bağlanın.

Not: Ollama kendi yerel API'sini kullanır. llama.cpp, LM Studio, vLLM veya diğer OpenAI uyumlu sunucular için şunu seçin: Özel API.

Metinden konuşma entegrasyonu

Social Stream Ninja, bot mesajları ve öne çıkan sohbet içeriği için kapsamlı TTS desteği içerir:

Sistem TTS

İşletim sisteminizin ses sentezleyicisini kullanan ücretsiz, yerleşik TTS.

Kokoro

Gizliliğe önem veren kullanıcılar için WebGPU/CPU ile yerel çalışan ücretsiz TTS.

Kitten TTS

Yerel ses üretimi için küçük bir model indiren hafif, tarayıcı tabanlı TTS.

ElevenLabs

Doğal duyulan, özelleştirilebilir seslerle ücretli konuşma sentezi.

Google Cloud TTS

Kapsamlı dil ve özelleştirme seçenekleri sunan yüksek kaliteli sesler.

Gemini (Önizleme TTS)

Seçilebilir ses ve dil seçenekleri sunan Google önizleme nöral ses modelleri.

Speechify

Doğal ses dönüştürme yetenekleri sunan yapay zekâ destekli metinden konuşma.

OpenAI TTS

Seçilebilir sesler, modeller ve isteğe bağlı uyumlu uç noktalarla OpenAI konuşma sentezi.

Not: TTS işlevi için ilgili katman sayfasının OBS'de açık olması gerekir. Her TTS sağlayıcısının ses seçenekleri, gecikmesi ve fiyatlandırma veya donanım gereksinimleri farklıdır.

Yapay zekâ entegrasyonunu kurma

Mevcut menüyle yapay zekâ entegrasyonunu kurmak için şu adımları izleyin:

1

LLM sağlayıcınızı seçin ve bağlayın

Sağlayıcınızı şu bölümde seçin: LLM hizmet sağlayıcısını yapılandır ve ilgili alanları doldurun:

  • Ollama: Yerel olarak kurun ve gerekirse uç noktayı ayarlayın
  • Yerel Gemma / Yerel Qwen: Barındırılan tarayıcı model dosyalarını ve isteğe bağlı model klasörü geçersiz kılmasını kullanın; Qwen SSN largefiles'ı kullanabilir, Gemma ise kendi yansıttığınız klasörü gerektirir
  • ChatGPT, Gemini, DeepSeek, xAI, Groq, OpenRouter, Bedrock: API anahtarınızı ve tercih ettiğiniz modeli ekleyin
  • Özel API: OpenAI uyumlu bir uç nokta, model kimliği ve isteğe bağlı API anahtarı girin
2

Seçili sohbet botunu test edin

Yerleşik düğmeyi kullanın: Seçili sohbet botunu test et . Canlı yayından önce sağlayıcınızı, modelinizi ve kimlik bilgilerinizi doğrulayın.

3

Bot davranışını yapılandırın

Botun sohbetteki davranışını özelleştirin:

  • LLM yapay zekâ sohbet botunu etkinleştir
  • Bot adını, tetikleyici sözcükleri ve yanıt hız sınırını ayarlayın
  • Yanıtların sohbete geri mi yoksa yalnızca bot katmanı sayfasına mı gideceğini seçin
  • Üslup, rol ve moderasyon kuralları için özel yönergeler ekleyin
4

İsteğe bağlı ek özellikleri etkinleştirin

Botla birlikte kullanmak istediğiniz özellikleri açın:

  • Bot yanıtları için TTS'yi etkinleştirin ve bir sağlayıcı seçin
  • Sabit süreli, mesaj uzunluğuna göre veya TTS sonrası otomatik gizleme davranışını şu sayfa için seçin: /bot.html; kullanın: clearBotOverlay elle temizleme için
  • Bilgiye dayalı yanıtlar için RAG'ı etkinleştirin ve belgeler yükleyin
  • Moderasyon veya sıkı engelleme modu için sansür botunu etkinleştirin
  • Açın: /bot.html, /chatbot.html, veya /cohost.html gerektiği şekilde OBS'de veya bir tarayıcıda

MIDI ve kısayol tuşlarıyla kontrol

MIDI entegrasyonu

MIDI kontrolcüleri, klavye kısayolları veya MIDI eklentili StreamDeck kullanarak Social Stream Ninja'yı kontrol edin.

Kurulum gereksinimleri

  1. Uzantı ayarlarında MIDI desteğini etkinleştirin
  2. Sanal bir MIDI geri döngü aygıtı kurun (ör. loopMIDI)
  3. MIDI kontrolcünüzü veya StreamDeck MIDI eklentinizi yapılandırın
CC numarası Değer İşlem Notlar
102 1 Sohbete “1” gönder Hızlı tepki
102 2 Sohbete “LUL” gönder İfade tepkisi
102 3 Şaka anlat Bot yanıtını tetikler
102 4 Katmanı temizle Öne çıkan mesajı kaldırır

İpucu: MIDI kontrolü en iyi fiziksel kontrolcülerle çalışır, ancak sanal MIDI aygıtlarıyla da tetiklenebilir.

Kısayol tuşu desteği

Yaygın işlevlere hızlı erişmek için klavye kısayollarını kullanın.

Kısayol tuşları menü ayarlarından yapılandırılabilir; tarayıcı odaktayken veya uygulama kullanılırken sistem genelinde çalışır.

Webhook entegrasyonu

Bağış hizmetleri

Social Stream Ninja, webhook'lar üzerinden üçüncü taraf hizmetlerden bağışlar ve etkinlikler alabilir; popüler olanlardan bazıları aşağıdadır:

Stripe

Kredi kartıyla yapılan bağışları doğrudan Stripe hesabınız üzerinden işleyin.

  • Şurada bir ödeme bağlantısı oluşturun: stripe.com
  • Stripe Dashboard'da Developers → Webhooks bölümüne gidin
  • Uç nokta ekleyin: https://io.socialstream.ninja/SESSIONID/stripe
  • Etkinliği seçin: checkout.session.completed
  • Ekleyin: &server panel URL'nize

Ko-Fi

Destekçilerinizden kahve bağışları alın.

  • Ko-Fi hesabınızda oturum açın
  • Şuraya gidin: Webhook ayarları
  • Ekleyin: https://io.socialstream.ninja/SESSIONID/kofi webhook URL'si olarak
  • Ekleyin: &server panel URL'nize
  • “Tek Bağış Testi Gönder” düğmesiyle test edin

Buy Me A Coffee

Popüler Buy Me A Coffee platformu üzerinden bağış toplayın.

  • Buy Me A Coffee hesabınızda oturum açın
  • Webhook ayarlarına gidin
  • Ekleyin: https://io.socialstream.ninja/SESSIONID/bmac webhook URL'si olarak
  • Ekleyin: &server etkinlikleri almak için panel URL'nize
  • Hem bağış hem de üyelik etkinlikleri desteklenir

Güvenlik notu: Oturum kimliğinizi gizli tutun; bu kimliğe sahip herkes katmanınıza sahte bağışlar gönderebilir. Webhook URL'si hassas bilgi olarak ele alınmalıdır.

Harici hizmet entegrasyonu

Social Stream Ninja, üçüncü taraf hizmetlere de veri gönderebilir:

Hizmet URL parametresi Açıklama
Singular Live &singular=IDENTIFIER Öne çıkan mesaj katmanı için seçili mesajları Singular Live'a gönderir
H2R &h2r=IDENTIFIER Seçili mesajları yerel bir H2R sunucusuna gönderir
Genel POST &postserver=URL Seçili mesajları POST ile özel bir uç noktaya gönderir
Genel PUT &putserver=URL Seçili mesajları PUT ile özel bir uç noktaya gönderir

Bu parametreler panel sayfasının URL'sine eklenmelidir.

Özelleştirilebilecek temel özellikler

  • Öne çıkan mesajlarla tüm mesajları gösterme arasında geçiş yapın
  • Görünümü CSS ile özelleştirin
  • Yeni mesajlar için özel animasyonlar ekleyin
  • Kendi mesaj filtrelemenizi uygulayın
  • JavaScript ile etkileşimli öğeler ekleyin

Uygulama adımları

  1. Örnek katman HTML dosyasını indirin
  2. Özel düzeniniz için HTML'yi düzenleyin
  3. İstediğiniz görünüm için CSS'yi özelleştirin
  4. Özel davranışlar için JavaScript'i gerektiği gibi değiştirin
  5. OBS'de tarayıcı kaynağı olarak kullanmak için dosyayı yerel olarak kaydedin

Zamanlayıcı API'si

Uzaktan kontrol: timer.html

Zamanlayıcı sayfasının kapsamı bilerek dardır: tek zamanlayıcı, isteğe bağlı operatör kontrolleri, uyarı durumları, süre aşımı ve birkaç görsel stil.

Yararlı işlemler şunlardır: starttimer, pausetimer, resettimer, timeradd, timersubtract, ve settimer.

{
  "action": "settimer",
  "value": {
    "seconds": 300,
    "label": "Interview",
    "mode": "countdown",
    "style": "stage",
    "warnSeconds": 60,
    "dangerSeconds": 15
  }
}

Mevcut zamanlayıcı durumunu sorgulamak için şunu kullanın: gettimerstate bir geri çağrı tokeniyle.

{ "action": "gettimerstate", "get": "timer-state-1" }

Sayfayı şu seçenekle kullanın: timer.html?session=YOUR_SESSION&server doğrudan API sunucusuyla kontrol edilmesini istiyorsanız.

Yönetilen çekiliş komutları

startgiveaway, closegiveaway, drawgiveaway, resetgiveaway, ve getgiveawaystate aynı API/Stream Deck kontrollerini kullanarak özel çekiliş havuzunu yönetir. Çekiliş, katılımı otomatik olarak kapatır. Yeni tur, önceki kazanan geçmişini korur ve ödenmemiş rezervasyonları reddeder. İptal et ve iade et, bekleyen bilet ödemelerini geri verir. Ücretli biletler, Sayı Avı, Yazı Tura Havuzu ve Etkinlik Akışı aynı yayıncı hizmetini kullanır. Kurulum, sunumlar, komut değerleri ve kurtarma.
