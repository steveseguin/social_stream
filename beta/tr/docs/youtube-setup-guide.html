Canlı Sohbet Kurulumu

  1. Yayının gerçekten canlı veya canlı sohbetin kullanılabilir olduğundan emin olun.
  2. YouTube canlı sohbet sayfasını veya moda özel kaynak sayfasını açın.
  3. OBS'yi açmadan önce panelin mesaj aldığını doğrulayın.
  4. Panel ve katmanda aynı oturum kimliğini kullanın.

YouTube giriş veya izin isterse bu adımı yakalamayı yapan aynı tarayıcı/uygulama ortamında tamamlayın.

API ve OAuth Notları

  • API modu, görünür sayfa yakalamasından farklı etkinlik grupları sunabilir.
  • Abone verileri YouTube tarafından geciktirilebilir ve yalnızca herkese açık abonelikleri içerebilir.
  • Yazma eylemleri, yalnızca sohbet okumadan daha güçlü kapsamlar gerektirir.
  • Masaüstü uygulaması normal Chrome çerezlerini otomatik paylaşmaz.

Tam kurulum: YouTube Proje Kurulumu.

Yaygın çözümler

  • Sohbet yok: Yayının canlı ve sohbetin görünür olduğunu doğrulayın.
  • Chrome çalışıyor ama uygulama çalışmıyor: Uygulama içinde YouTube'a giriş yapın veya uzantı yolunu kullanın.
  • API modu başarısız: OAuth'u, kapsamları, proje kimlik bilgilerini ve kotayı kontrol edin.
  • OBS boşsa: Önce paneli, ardından normal tarayıcıda katman URL'sini test edin.
