TikTok 簽章

了解簽章伺服器是什麼、為何有時失敗，以及如何重新連接。

什麼是 TikTok 簽章？「簽章伺服器無法使用（Sign Server Unavailable）」新增自己的 Euler API 金鑰不使用簽章伺服器的模式向 TikTok 傳送回覆相關

什麼是 TikTok 簽章？

TikTok 要求對其直播聊天串流的連接請求進行密碼學簽章。桌面應用程式透過第三方簽章服務簽署這些請求，該服務由以下方營運： Euler Stream。正常使用無需帳號或 API 金鑰，應用程式會自動使用 Euler 的免費層級。

由於此服務位於應用程式與 TikTok 之間，即使您這邊沒有問題，TikTok 來源也可能停止運作：簽章伺服器可能停機、受到速率限制，或因 TikTok 端變更而暫時失效。

「簽章伺服器無法使用（Sign Server Unavailable）」

此狀態表示應用程式未能從簽章服務取得有效簽章。常見原因：

  • 速率限制。 免費層級依 IP 位址限制（每分鐘少量連接，並設有每小時和每日上限，參閱 Euler 的速率限制）。反覆刪除並重新新增來源，或快速切換模式，會耗盡配額並使錯誤持續。
  • 簽章伺服器中斷。 Euler 偶爾會停機或過載。這通常會在數小時內解決，無需您變更設定。
  • TikTok 變更。 TikTok 更新直播基礎設施時，可能導致所有人的簽章失效，直到 Euler 發布修正。

依序執行：

  • After an Euler connection fails, the desktop app checks TikTok directly without using Euler quota. If it cannot reconnect, Euler mode pauses; Auto tries the available non-Euler methods instead.
  • When Euler retries are paused, activate the source to try again. If you reached an Euler rate limit, wait for that limit to reset first.
  • 確保使用最新應用程式版本，TikTok 修正會頻繁發布。
  • 將 TikTok 來源切換至 標準 模式（頁面擷取）作為可靠的臨時方案。它直接載入直播頁面，完全不使用簽章伺服器。
  • 如果經常遇到速率限制，請新增自己的免費 Euler API 金鑰（見下文）。

新增自己的 Euler API 金鑰

自己的金鑰提供專屬配額，無需共用匿名的每 IP 額度。

  • 在以下位置建立免費帳號和金鑰： Euler Stream 儀表板.
  • 在桌面應用程式中，編輯 TikTok 來源並開啟連接預設組合選擇器。
  • 選擇 Euler Signing（進階） 並貼上 API 金鑰。 Euler Proxy（API 金鑰） 也可使用，但不支援傳送回覆。
  • 儲存後重新連接來源一次。

不使用簽章伺服器的模式

模式運作方式取捨
標準載入 TikTok 直播頁面並從中擷取聊天。不涉及簽章服務。需要保持直播頁面開啟；可能提示進行 TikTok 登入或驗證。
本機簽署器在輕量 TikTok 視窗中於本機簽署請求，不使用 Euler。在應用程式內登入 TikTok 時效果最好；匿名模式可能遺漏部分聊天。

相容模式（WebSocket），舊稱 輪詢（Polling） ，在目前的桌面應用程式中使用帶簽章的 WebSocket。它不提供無簽章的 HTTP 輪詢，也無法傳送回覆。此模式使用 Euler 簽章，因此也會受到該服務中斷與限制的影響。

向 TikTok 傳送回覆

從停駐面板向 TikTok 回傳聊天訊息，需要在桌面應用程式內登入 TikTok 帳號；應用程式需要您的 TikTok 工作階段才能以您的身分發布。如果未登入，或 TikTok 連接中斷，傳出訊息只會抵達其他平台。

請注意，無論登入狀態如何，Euler Proxy 模式都不支援回覆。
