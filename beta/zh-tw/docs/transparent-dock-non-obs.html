移除停駐面板的灰色背景

不使用 OBS 時，讓聊天停駐面板透明並隱藏底部選單。

問題

在 MELD、Social Stream 桌面應用程式或其他瀏覽器容器中開啟停駐面板 URL 時，可能出現一個大灰色矩形及底部選單列。停駐面板正常運作；只是頁面背景尚未透明。

開啟這兩項設定

  1. 開啟 Social Stream Ninja 設定並找到 主聊天疊加畫面與控制停駐面板.
  2. 展開 停駐面板底部選單列 並啟用 隱藏選單列.
  3. 展開 疊加畫面 並啟用 強制透明背景.
  4. 複製更新後的停駐面板 URL，並在顯示它的應用程式中取代舊 URL。如果已開啟，請重新載入。

更新後的 URL 應同時包含 transparent 和 hidemenu。請保持你自己的 session 值不變。

預期顯示效果

灰色頁面及底部選單消失。聊天訊息仍顯示在停駐面板後方的影片或內容之上。

OBS 瀏覽器來源預設透明，因此此手動設定主要用於 MELD、桌面疊加畫面視窗及其他非 OBS 瀏覽器容器。

若灰框仍然存在

  • 確認正在顯示的 URL 包含 transparent 和 hidemenu.
  • 取代 URL 後，重新載入頁面，或移除後重新加入。
  • 將 半透明頁面背景, 綠色頁面背景, 白色頁面背景, 淺色模式，以及 深色模式 處於關閉狀態。
  • 檢查用於顯示該 URL 的應用程式是否支援透明瀏覽器背景。
