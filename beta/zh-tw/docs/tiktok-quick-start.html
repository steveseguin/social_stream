TikTok 快速入門

只需要讓 TikTok Live 聊天運作時，請先使用本指南。

1. 搜尋 TikTok

開啟 支援的網站 頁面並搜尋 TikTok。在開始變更 OBS 之前，先確認基本設定規則。

2. 開啟 TikTok 直播頁面

使用瀏覽器擴充功能時，開啟創作者的直播頁面，並保持聊天可見。

https://www.tiktok.com/@CHANNEL/live

如果瀏覽器分頁不斷暫停或隱藏聊天，請嘗試桌面應用程式方式。

3. 使用同一個工作階段 ID

選擇一個簡短的工作階段 ID。在 TikTok 來源、停駐面板和 OBS 中使用完全相同的 ID。

YOUR_SESSION_ID

4. 在 OBS 之前先檢查停駐面板

使用工作階段 ID 開啟停駐面板。傳送或等候一則 TikTok 聊天訊息。

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

5. 將疊加畫面新增至 OBS

在 OBS 中新增瀏覽器來源，並使用相同工作階段 ID。

https://socialstream.ninja/featured.html?session=YOUR_SESSION_ID

範本設定： 疊加畫面範本快速入門.

如果 TikTok 沒有顯示

  • 確認 TikTok 直播頁面確實正在直播。
  • 使用瀏覽器擴充功能時保持聊天可見。
  • 確認停駐面板和 OBS 使用相同工作階段 ID。
  • 變更工作階段 ID 後重新整理停駐面板。
  • 如果瀏覽器分頁受到節流限制，請嘗試桌面應用程式。
