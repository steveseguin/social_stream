從這裡開始

初次使用 TTS？ 請遵循 文字轉語音設定指南。只需五步，本頁則是完整參考。

SSN 可朗讀擷取到的文字聊天，平台不需要自帶 TTS。開啟 TTS 的 Dock 或疊加層按照自身篩選條件朗讀。

最簡單的連結使用系統音色開啟 TTS：

dock.html?session=YOUR_SESSION&speech=en-US

在 OBS 中加入透過頁面播放的免費音色：

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper

保持該頁面開啟並連線，只讓一個頁面朗讀。

系統 TTS 不等於免費 TTS。 系統音色來自瀏覽器和電腦。即使 Chrome 可用，OBS 也常常沒有。Kokoro、Piper、Kitten 和 eSpeak 免費且自行產生音訊，因此可在 OBS 使用。不必付費才能在 OBS 使用 TTS。

TTS 也在 CAPTION.Ninja中也可用於字幕、轉錄和翻譯。兩者均提供免費和付費音色。

連結設定

將這些加到 Dock 或疊加層連結末尾。

設定功能範例
&speech指定語言代碼並開啟 TTS。&speech=en-US
&ttsprovider選擇供應商（見上文）。&ttsprovider=kokoro
&volume音量，0.0 至 1.0。&volume=0.8
&rate語速，0.1 至 10.0。&rate=1.5
&pitch音高，0.1 至 2.0。&pitch=1.2
&voice按部分名稱選擇系統音色。&voice=google
&simpletts不朗讀「says」或「someone says」。&simpletts
&simpletts2完全不朗讀姓名。&simpletts2
&ttscommand只讀以命令開頭的訊息（預設 !say).&ttscommand=!say
&readevents也朗讀訂閱和捐款等事件。&readevents
&skipmessages每 N 則訊息只讀一則。&skipmessages=3
&ttsquick超過指定字元數時截斷語音。訊息被截斷時請移除。&ttsquick=100

系統音色

系統 TTS 使用瀏覽器和電腦已有的音色。以下是常見情況，不是保證。

瀏覽器系統音色
Chrome支援。Google 音色加系統音色。
Edge支援。Microsoft 音色加 Windows 語言套件。
Firefox有限，僅本機系統音色。
Opera有限，取決於安裝環境。
Safari需要點按後才能播放聲音。
OBS使用自己的瀏覽器，不共用 Chrome 或 Edge 的音色。在 SSN 應用程式測試不等於測試 OBS。

檢查此瀏覽器的系統音色。僅列出目前瀏覽器的系統 TTS 音色，不測試 OBS 或 Kokoro 等供應商。清單為空不代表其他供應商無法使用。

在 Windows 加入更多音色

  1. 開啟 開始 > 設定 > 時間與語言 > 語音.
  2. 位於 管理語音，點選 加入語音.
  3. 選擇語言並按 新增.
  4. 重新啟動瀏覽器。

這是 Windows 11 的方法。Windows 10 請參見 Microsoft 指南。部分第三方音色不會出現在瀏覽器中。Firefox 往往比基於 Chrome 的瀏覽器顯示更多系統音色。

將系統 TTS 送入 OBS

使用其他供應商？ 不需要此步驟，開啟 透過 OBS 控制音訊 ，在瀏覽器來源中開啟，不需要虛擬音訊線。
  1. 先確認系統 TTS 確實發聲。OBS 可能沒有可用音色；沒有語音時，調整音訊路由也無濟於事，請換其他供應商。
  2. 若語音在另一瀏覽器播放，請用 OBS 的應用程式或桌面音訊擷取。
  3. 仍有問題？透過下方虛擬音訊線方法路由瀏覽器聲音。
透過虛擬音訊線傳遞聲音（Windows）

下載： VB-Audio Virtual Cable （免費）· Voicemeeter · Audio Router（舊版）

方法執行操作
整台電腦設定 CABLE Input 作為 Windows 預設輸出（音效設定 > 輸出）。
單一應用程式，Windows 11設定 > 系統 > 音效 > 音量混音程式。將瀏覽器輸出設為 CABLE Input.
單一應用程式，Windows 10音效設定 > 應用程式音量和裝置喜好設定。將瀏覽器輸出設為 CABLE Input.
Audio Router較舊的軟體。將瀏覽器音訊送到 CABLE Input.
Voicemeeter設為 Windows 預設輸出。將硬體輸出送往喇叭，虛擬輸出送往 OBS。

然後在 OBS 中新增 音訊輸入擷取（Audio Input Capture），選擇 CABLE Output （或 Voicemeeter 輸出），將監聽設為 監聽並輸出。使用 僅監聽 ，如果其他來源已將該音訊送入直播。

測試：播放 TTS，查看 OBS 音量表，確認聽得到，再調整音量。

解決問題

問題試試這個
沒有聲音確認 TTS 已開啟、朗讀頁面保持開啟、瀏覽器來源未靜音。一般瀏覽器中請點按一次頁面。
OBS 中無聲完全沒有語音？先檢查供應商。已有語音則檢查 透過 OBS 控制音訊、混音器靜音和輸出音軌。或擷取正在朗讀的瀏覽器。
雲端音色無法運作檢查 API 金鑰和供應商名稱。沒有金鑰時 SSN 改用系統 TTS，而它在 OBS 中可能無聲。
本機伺服器在應用程式中可用，OBS 無法使用OBS 是獨立瀏覽器。請在 OBS 電腦上檢查伺服器，尤其使用 127.0.0.1。請參閱 localhost 規則.
只讀第一個字母或幾個單字移除 ttsquick ，從 OBS 連結移除。
新音色沒有出現加入語言套件後重新啟動瀏覽器。
Safari 不朗讀Safari 的自動 TTS 有限制。點按一次頁面以允許音訊。

良好使用習慣

  • 使用透過頁面播放的供應商，這是最簡單的 OBS 設定，而且有免費選項。
  • 開播前用短訊息測試。
  • 觀眾可以輸入任何內容，請準備快速關閉 TTS 的辦法。
