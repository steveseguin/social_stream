熱感印表機與直播標籤

將購買、贊助及聊天事件變成實體收據、貼紙、票券或取貨標籤。

進行設定 捐款時列印 列印銷售 Whatnot 標籤 選擇紙張 標籤尺寸 創意 解決問題

六步完成設定

開始前： 需要 Windows 獨立應用程式。印表機必須顯示為一般 Windows 印表機。Social Stream 透過 Windows 驅動程式列印，不傳送原始 ESC/POS、ZPL 或廠商 SDK 指令。
  1. 透過 USB 連接印表機、開機並安裝 Windows 驅動程式，列印 Windows 測試頁確認可用。
  2. 在 Social Stream 中開啟 Global settings and tools → Mechanics - Connections & Integrations → Printer Control.
  3. 點選 尋找印表機（Find printers）。依 Windows 顯示的名稱選擇印表機。
  4. 輸入 紙張寬度（公釐）。通常是 58, 80，或 62.
  5. 將 固定標籤長度 設為 0 用於收據紙。模切標籤請填寫進紙方向的標籤長度，單位為公釐。
  6. 點選 列印測試。邊緣被裁切時，增大該側安全邊界後重試。

預設左右 2 公釐安全邊界適合許多低價 58 公釐收據印表機。實際可列印區域由驅動程式決定，因此保持 使用可列印區域（Use printable area） 為選取狀態，除非已測試其他設定。

{donation}
24 pt · 粗體 · 置中
  1. 開啟 Event Flow 編輯器 並建立新流程。
  2. 加入 贊助 / 小費（Donation / Tip） 觸發器。設定 最低金額（Minimum Amount） ，僅在較大捐款時列印。
  3. 新增 列印熱感標籤（Print Thermal Label） （在 Integrations 下），並連接觸發器。
  4. 輸入 {username}，換行，然後 {donation}。選擇字型大小、粗細、對齊和份數。
  5. 將操作中的印表機及固定長度覆寫值留白或設為 0。會使用 Printer Control 設定。
  6. 點選 測試流程（Test Flow）。輸入名稱，開啟 含贊助（Has Donation），填寫金額並執行。這會實際列印標籤。

其他實用預留位置： {message}, {source}, {donationAmount}，以及 {counterValue}。流程前面步驟產生的值也可使用。

請參閱 商務事件欄位 ，查看每種銷售包含的內容。

買家使用粗體，商品保持一般字重

  1. 設定 字型粗細 為 選取的文字.
  2. 將以下內容作為標籤文字輸入：
**{username}**
{subtitle}
  • 只有包在以下符號中的文字 ** 會變成粗體，無需 HTML 或 JavaScript。
  • 使用單層大括號。銷售事件把商品名稱放在 {subtitle}。數量可能位於 {meta.commerce.quantity}.
  • 如果前面步驟產生 buyer，使用 **{buyer}** 作為替代。
  • Shopify 和 eBay 不傳送買家姓名，請使用訂單計數器或僅含商品的標籤。
  • 已設為 All bold 或 Normal 的標籤保持原樣。
流程製作者：列印結果與買家編號

操作會加入 meta.thermalPrintResult.success，失敗時還會提供錯誤或代碼，供後續步驟使用。成功只表示工作已送給 Windows，不代表已出紙。重試前檢查 Windows 列印佇列，避免重複標籤。

Counter 為購買逐筆編號，而非為獨立買家編號。若同一買家的每次購買要使用同一編號，需要另行維護買家與編號對應表，並在每次直播開始時重設。User Memory 的 reason 欄位是一般文字，不是買家編號計數器。

Whatnot 商品標籤

下載 Whatnot 範例流程。列印粗體的買家名稱、商品名稱及可用的訂單 ID。付款失敗時另外列印 付款失敗 標籤，使用該通知包含的詳細資訊。

  1. 在獨立應用程式中設定 印表機控制（Printer Control） 並執行測試列印。
  2. 開啟 Event Flow 編輯器，點選 匯入，選擇下載的檔案。
  3. 選擇 Whatnot：商品標籤 + 付款警告。檢查兩個列印操作，它們使用 Printer Control 的印表機和標籤長度。
  4. 開啟並儲存流程。匯入時預設關閉。
  5. 保持 Whatnot 來源開啟，並啟用直播事件擷取。
銷售標籤不代表已付款。 每則通知送達後立即列印。流程不等待付款、不修正舊標籤、不分配買家編號。缺失欄位留白。若失敗通知沒有買家、商品或訂單資訊，就無法判斷對應哪張標籤。
範例流程如何運作

它使用 事件類型（進階）→ 自訂事件（Event Type (Advanced) → Custom Event） 用於 product_sold 和 payment_failed，篩選為 Whatnot。出價和拍賣結束通知不會列印。參閱 Whatnot 事件欄位.

選擇紙張

收據紙捲

適用於任意長度的購買單據、排隊票和收據。固定標籤長度保持 0。

連續貼紙捲

適用於任意長度的姓名貼紙。與收據紙類似，但裁切由印表機或驅動程式負責。

模切標籤

適用於統一尺寸的名牌和商品標籤。設定確切固定長度，並在 Windows 列印喜好設定中選擇相同紙張。

正確設定固定尺寸標籤

3 × 1 英吋標籤（含 Munbyn BT320）： 將寬度設為 76.2 公釐，固定長度設為 25.4 公釐（1 英吋邊為進紙方向時）。在 Windows 列印喜好設定中選擇相同紙張和方向，從 12–14 pt 文字開始。
規則原因
依進紙方向測量62 × 29 公釐標籤通常設為寬 62 公釐、固定長 29 公釐。
同時符合 Windows 設定在驅動程式的列印喜好設定中設定相同紙張、方向、間隙／標記感應和裁刀。
固定就是固定不會額外進紙。文字過高時，可能因驅動程式而被裁切或溢出到下一張。
用最長文字測試長姓名、商品選項及額外行需要更多空間或更小字型。
過短標籤可能不適用Social Stream 要求至少 20 公釐，驅動程式仍可能限制短頁尺寸。

測試列印的側邊框表示安全寬度，高度隨測試文字變化，並非整張標籤的邊框。

直播創意

  • 用於牆面、道具、地圖或進度板的支持者姓名貼紙。
  • 訂單到來時列印周邊、委託、飲料或取貨標籤。
  • 抽獎券。在列印前加入頻率限制和資格檢查。
  • VIP 名牌、團隊選擇票、挑戰代幣或里程碑標籤。
  • 給身旁製作人員的簡短待辦清單。
不要列印私人資訊。 排除地址、電子郵件、付款資訊和私人訊息。感熱紙也會隨熱、光和時間褪色。

解決問題

問題試試這個
沒有顯示印表機確認 Windows 能列印測試頁，重新啟動 Social Stream，再點擊 Find printers。
顯示成功但不列印開啟 Windows 列印佇列，檢查暫停、離線、紙張、驅動程式或連接埠錯誤。
邊緣被裁切保持 Use printable area 開啟，並增大對應側的安全邊界。
空白紙過多收據使用固定長度 0，減少下邊界和額外進紙；標籤則設定確切長度。
一張標籤列印成兩張文字高度超過標籤，或 Windows 紙張尺寸錯誤。減少文字、縮小字型、縮短行距或減小邊界。
Test Flow 使用了錯誤印表機在 Print Thermal Label 步驟選擇印表機覆寫值。留白時，編輯器測試使用 Windows 預設印表機。
