五步連線提醒

  1. 開啟 營利 → Fourthwall、Ko-fi 與 Buy Me a Coffee 提醒 並選擇你的 提供者.
  2. 點選 接收器設定 並開啟 擴充功能的遠端 API 控制.
  3. 返回 Monetization 並點擊 複製 webhook URL.
  4. 貼到服務方的 Webhook 設定中，步驟如下。
  5. 保持 Social Stream Ninja 執行。
是否正常運作？ 「Receiver connected」只表示 SSN 正在監聽。實際事件送達時，最近事件一列才更新，重新啟動時重設。
請勿公開 Webhook URL。 此 URL 是這些提醒唯一的保護方式，不檢查簽章密鑰。它適用於提醒，不應用作出貨的付款憑證。切勿公開或放進 QR 碼。

預覽範例提醒 僅展示外觀，不影響累計值、Event Flow 或 Webhook。

NinjaBacker、Throne、Amazon 和 eBay 請參閱 營利指南。Shopify 請參閱 Shopify 設定.

Fourthwall

  1. 在 Fourthwall 中開啟 設定 → 開發者選項 → Webhooks.
  2. 建立 Webhook，貼上 SSN 提供的 Fourthwall URL。
  3. 勾選所需事件，參見表格。
  4. 儲存，並保持 SSN 執行。
Fourthwall 事件顯示為
ORDER_PLACED購買。為相容舊設定，仍會計入其捐款價值。
GIFT_PURCHASE禮物。
DONATION捐款。
SUBSCRIPTION_PURCHASED新會員。

禮品卡訂單不會重複增加價值。測試事件會被略過。

Ko-fi

  1. 開啟 Ko-fi Webhooks.
  2. 將 SSN 的 Ko-fi URL 貼到 Webhook URL 並儲存。
  3. 保持 SSN 執行。

公開打賞、會員、商店訂單和委託都用同一個連結。私人付款會被排除。商店訂單和委託顯示為購買，不增加捐款累計值。Ko-fi 不回報已取消會員。

用 SSN 預覽測試。 Ko-fi 測試付款看起來像真實付款，會觸發提醒、累計值和操作。啟用付費獎勵時不要使用。

Buy Me a Coffee

  1. 在創作者控制台開啟 整合 並選擇 新增 webhook.
  2. 設定名稱，貼上 SSN 的 Buy Me a Coffee URL。
  3. 勾選所需事件，參見表格。
  4. 儲存並保持傳送開啟。失敗時在該處查看傳送紀錄。
事件顯示為
donation.created捐款。
extra_purchase.created購買。
commission_order.created購買。
wishlist_payment.created禮物募款貢獻。
membership.started新會員公告，並非另一筆收費。

隱藏備註和匿名支持者保持隱藏。控制台測試（live_mode: false）會被略過。退款不會減少累計值。

匯入 Fourthwall 商品

  1. 在 Fourthwall 中進入 設定 → 開發者選項 並建立 Storefront 權杖。不要使用管理員 API 金鑰。
  2. 在 SSN 中開啟 商品與支持連結 → 設定商品和連結 → 匯入 Fourthwall 商品.
  3. 貼上商品公開連結和權杖。點擊 載入商品詳細資料.
  4. 核對名稱、圖片、價格和連結。連結必須來自與權杖相同的商店。
  5. 選擇用途：Shop、Gift、Support 或 Join。
  6. 點選 新增商品或連結，開啟 商品與支持連結，然後點擊 儲存設定.
匯入會做什麼
  • 每次載入一個公開、可購買的商品。
  • 權杖決定搜尋哪家商店。只使用一次，隨後清除，不儲存也不傳給覆蓋層。
  • 若款式或套組價格不同，價格留白。
  • 這是匯入時的快照。價格、庫存和圖片不會自動更新，變更時請重新匯入或編輯。
  • 最多儲存 20 個商品。再次新增相同商品會產生第二份。

在直播中顯示商品和 QR 碼

也可手動新增任何公開連結，例如 Shopify、Tiltify、Patreon。這不會連線付款提醒。

  1. 位於 OBS 覆蓋層適用於，選擇 商品與支持連結.
  2. 開啟 疊加畫面連結選項 並選擇 覆蓋層檢視：僅商品展示、僅支持卡片、僅活動提醒，或商品展示與提醒。
  3. 點選 複製 OBS 連結 ，然後作為以下來源新增至 OBS： 瀏覽器來源。從 800 × 600 開始，每種檢視使用一個來源。
  4. 在 顯示選項，固定第一個商品或輪換顯示，並開啟 顯示 QR 碼.
  5. 查看最終 OBS 版面配置時，用手機掃描 QR 碼。
QR 碼無法掃描？ 不要過度縮小或裁切覆蓋層。若要在聊天分享連結，點擊 複製公開連結.
提醒、multi-alerts 與 Event Flow
  • 商品展示會顯示商品圖片，較小的支持卡片不會。
  • 活動提醒可獨立使用，不會顯示無關商品的 QR 碼。
  • Multi-alerts 和活動串流在同一工作階段下即可運作，無需商品清單。Monetization 活動檢視需要啟用商品清單。
  • 在 Event Flow 中，Donation 觸發器仍處理包含以下內容的列： hasDonation。購買或已完成禮物請使用 Event Type。參閱 事件對應.

直播切換商品或分享一個觀眾連結，請參閱 即時商品控制.
