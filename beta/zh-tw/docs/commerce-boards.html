五步設定位置分配板

  1. 在 SSN 中開啟 營利 → 名額看板與近期銷售.
  2. 選擇 編號方塊。20 × 6 格線使用 120 個位置和 20 欄。點擊 建立分配板.
  3. 點選 複製 OBS 連結 ，然後作為以下來源新增至 OBS： 瀏覽器來源 ，尺寸為 1920 × 1080。
  4. 位置售出後，點擊其方塊，核對付款，再點擊 為此名額記錄銷售 並確認銷售。
  5. 要顯示獲得的商品，在以下欄位輸入： 揭曉文字 並點擊 揭曉.

球隊拆卡

團隊拆卡按球隊、球員或其他命名位置分配開出的卡片。

  1. 選擇 球隊方塊.
  2. 貼上團隊名稱，每行一個。清單長度決定位置數量。
  3. 將售出的位置標為已認領，準備好後再揭曉。
每個認領都由你手動標記。SSN 不會從聊天或拍賣結束推測團隊購買。

在 Whatnot 或 eBay Live 直播期間

  1. 在 SSN 中開啟直播並啟用 擷取直播事件。Whatnot 需要開啟底部拍賣欄可見的直播頁面。eBay Live 可使用聊天或直播頁面。
  2. 位於 近期銷售，設定 拍賣物品助手 為 Whatnot 或 eBay Live。點擊 儲存銷售選項.
  3. 商品售出後點擊 使用拍賣物品 以複製名稱。
  4. 在銷售網站核對商品和付款，再輸入銷售總額及幣別。
  5. 點擊對應位置的方塊，然後選擇 為此名額記錄銷售。確認按鈕變為 確認銷售並認領名額，可一次記錄兩者。
  6. 準備好展示商品時，輸入揭曉文字。
確認前不會記錄任何內容。 輔助工具只填寫草稿。出價或拍賣結束不會自動變成銷售，新的拍賣更新也不會覆寫草稿。

即時擷取與商店連線的差異

Whatnot 和 eBay Live 擷取提供商品、出價和拍賣狀態。獨立的 eBay 賣家連線 可取得所選商品的已付款訂單並自動填入最近銷售。不要再手動確認這些銷售，否則會重複顯示。其他自動來源包括 Shopify、Fourthwall、Ko-fi 和 Buy Me a Coffee。

輔助工具只保留所選網站的最後一個商品。五分鐘沒有更新或 SSN 重新啟動時會清除。多場直播同時開啟時請再次核對商品。如果空白，啟用後等待新的拍賣更新。

eBay：在賣家控制台檢查付款狀態 · Whatnot：拍賣付款失敗

顯示近期銷售

提示消失後仍在螢幕保留真實購買。可選擇短清單、六張卡片的卡片牆或橫條。

銷售來源如何設定
你的線上商店開啟 顯示近期銷售 和 收集已連接商店的購買記錄，然後點擊 儲存銷售選項。支援來自 Shopify、eBay 賣家、Fourthwall、Ko-fi 和 Buy Me a Coffee 的新購買。
你親自確認的銷售輸入商品，可選填總額和幣別。點擊 確認銷售。適合已核實付款的 Whatnot、eBay Live 或實體銷售。這些會顯示為 主播已確認.

修正錯誤或退款時，點擊 移除 ，針對該筆銷售。點擊 清空銷售 ，為新的直播重新開始。

不會顯示的內容： 出價、打賞、禮物和沙盒測試。認領分配板位置也不會新增銷售。
價格、歷史與隱私

商店資料不一定含價格，因此自動項目的價格留白。若要顯示價格，請刪除該項目並親自確認。多個商品填寫整個項目的總額，而非單價。SSN 不會用標價、最高出價或捐款額代替。

SSN 在本機保留最近 100 筆銷售，重新啟動後仍保留。只收集啟用後的銷售，不匯入舊訂單。重複接收會被忽略，系統記住最近 2,000 個 ID。退款需手動移除。

買家姓名、地址、付款資訊和未揭曉商品絕不會顯示。示範連結使用明確標示的虛構資料。

在 OBS 中顯示

  1. 在分配板控制中選擇顯示方式： 位置／團隊分配板，或把最近銷售顯示為清單、卡片牆或橫條。
  2. 點選 複製 OBS 連結。以 1920 × 1080 的 Browser Source 新增。空白區域透明，可顯示後方的攝影機畫面。
  3. 保持 SSN 執行，修改會立即顯示。

API 指令與 Event Flow

這些控制項擴充了現有的 commerceControl API。SSN、Stream Deck 自訂 API 操作和選用的 OBS 控制面板都讀取相同的 getCommerceState 回應。

{"action":"commerceControl","value":{"command":"boardSpot","data":{"id":"12","status":"claimed"}}}
指令欄位位於 data
boardSavetitle、style、columns、count 或以換行分隔的 labels
boardSpotid、status、result
boardVisibilityvisible
saleAddtitle；選填 amount、currency、quantity、platform；若要認領位置，可選填 boardId 和 spotId
saleRemoveid；選填 reopenSpot
salesClear無
salesSettingsvisible、automatic；選填 auctionSource： whatnot, ebay，或空字串

這些編輯不會傳送購買事件或觸發付費獎勵。

在 Event Flow，使用 商品與支持 操作。選擇分配板或銷售指令並填寫 看板／銷售欄位。文字值支援變數，例如 {subtitle}。銷售操作應對應已確認購買事件。如果流程手動新增銷售，請關閉自動收集，避免重複。
