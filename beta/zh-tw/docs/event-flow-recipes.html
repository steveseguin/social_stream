Event Flow 的用途

透過 Stream Deck 按鍵或 HTTP／WebSocket／P2P API 呼叫執行自訂工作流程.

Event Flow 是進階自動化編輯器。當彈出選單中的開關無法滿足需求時，可用它篩選聊天、觸發媒體、轉送訊息、呼叫 webhook 或控制 OBS。

開始任何範例前

  1. 使用一個測試平台和一個 Social Stream 工作階段。
  2. 開啟停駐面板，確認能收到聊天。
  3. 開啟 actions.html?session=YOUR_SESSION ，適用於範例播放音訊、媒體或控制 OBS 的情況。
  4. 正式開播前，使用模擬訊息或安全的觸發條件測試。
  5. 進行大幅編輯前，先匯出一個正常運作的流程。

常見解決方式

  • 沒有反應： 先確認來源事件到達停駐面板。
  • 音訊或媒體不播放： 保持 actions.html 使用相同工作階段保持開啟，然後檢查 Event Flow 媒體託管指南.
  • OBS 動作失敗： 檢查 OBS WebSocket v5、連接埠 4455、密碼和權限。
  • 流程觸發過於頻繁： 新增更嚴格的平台、事件、關鍵字或使用者篩選器。
