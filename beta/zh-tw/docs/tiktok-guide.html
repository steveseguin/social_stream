TikTok 指南

了解如何在 Social Stream Ninja 中連接 TikTok、選擇合適模式、傳送回覆，並在需要時使用 TikFinity 作為備援方式。

概述

從這裡開始

TikTok 是最難保持穩定的平台之一，因為它經常改變行為，而且不同帳號看到的內容並不總是相同。

快速建議：
  • 先使用 TikTok WS + Auto.
  • 如果需要回覆，切換至 標準.
  • 如果 Standard 不穩定，嘗試 本機簽署器.
  • 如果 TikTok 持續遺漏聊天，使用 TikFinity OBS 停駐面板 透過 其他聊天網站.
重要： TikTok 問題並不總是由 SSN 引起。訊息缺失、驗證失敗和節流限制可能由 TikTok 本身、帳號狀態或地區限制導致。
模式

應該使用哪個 TikTok 選項？

選項 適合 回覆
TikTok WS + Auto 適合大多數使用者的預設選項。先使用 WebSocket，必要時改用 Polling 作為備援。 否
標準 適合希望從 SSN 傳送回覆，並在應用程式內使用 TikTok 直播頁面的情況。 是
TikTok WS + Local Signer Standard 不穩定但仍需要回覆時的備援方式。 是
輪詢（Polling） 相容模式。較慢，但在 WebSocket 路徑失敗時有用。 否
Euler Proxy / Euler Signing 適用於擁有 API 金鑰或自訂設定的使用者的進階簽章選項。 通常不支援
TikFinity OBS 停駐面板 當 TikTok 原生模式遺漏太多聊天或無法連接時的唯讀備援方式。 否
步驟 1

在 SSN 中連接 TikTok

  1. 開啟獨立應用程式。
  2. 點擊 TikTok 按鈕，位於左側邊欄。
  3. 輸入 TikTok 使用者名稱、直播 URL 或所要求的值。
  4. 選擇所需的 TikTok 模式或預設組合。
  5. 點選 啟用來源.
步驟 2

如果需要回覆

  1. 使用 標準 模式，作為首選。
  2. 點選 登入（Sign in） （如有需要）。
  3. 開啟 顯示擷取頁面（Show capture page）.
  4. 確保登入的是應傳送訊息的 TikTok 帳號。
步驟 3

如果 Standard 不穩定

  1. 試試 本機簽署器.
  2. 保持簽章器視窗開啟。
  3. 如果 WebSocket 仍失敗，嘗試 輪詢（Polling）.
  4. 如果 TikTok 仍遺漏太多聊天，請切換至下方 TikFinity 備援方式。
回覆

如何向 TikTok 聊天傳送回覆

回覆支援取決於是否擁有有效的已登入 TikTok 工作階段。

  • 最佳回覆模式： 標準
  • 備用回覆模式： 本機簽署器
  • 不適合回覆： Auto、Polling、TikFinity 備援
實用原則： 如果最重視讀取可靠性，從 Auto 或 Polling 開始。如果最重視回覆，使用 Standard 或 Local Signer。
備援

如何使用 TikFinity OBS Dock

當 TikTok 本身遺失或隱藏太多聊天時，TikFinity 可以作為備用來源。

  1. 開啟 TikFinity。
  2. 前往 Overlay -> OBS Docks.
  3. 選擇一個停駐面板欄位，並將其設定為聊天。
  4. 複製停駐面板 URL。
  5. 在 SSN 中，點擊 其他聊天網站.
  6. 貼上 TikFinity 停駐面板 URL。
  7. 啟用新來源，並在直播時保持 TikFinity 開啟。
  • 這是備用讀取器，不是回覆工具。
  • 如果已經使用 TikFinity 活動動態元件，SSN 也可以在以瀏覽器為基礎的工作流程中使用支援的 TikFinity 元件頁面。

如需此備援方式和 Discord StreamKit 的完整教學，請參閱 Discord StreamKit 與 TikFinity 來源。有關事件承載資料詳細資訊，請參閱 事件參考.

疑難排解

常見 TikTok 問題

「它說我離線了」

  • 只有帳號確實正在直播時，TikTok 聊天才能運作。
  • 先開始直播，再嘗試 重新載入.
  • 直播結束後測試通常會失敗。

「驗證視窗關閉了」

  • 使用 顯示擷取頁面（Show capture page） 以便看到登入或驗證碼。
  • 試試 重新載入 登入之後。
  • 盡可能關閉同一裝置上額外的 TikTok 分頁或應用程式。

「有訊息缺失」

  • 這可能是 TikTok 端的限制，並不總是 SSN 錯誤。
  • 先嘗試其他模式，再決定是否某一條路徑始終最好。
  • 如果 TikFinity 對您的帳號表現更好，就將它用作備援方式。

「重新連接後訊息重複」

  • 先更新至最新應用程式版本。
  • 完全停止來源，然後重新建立乾淨連接。
  • 如果仍重複，請切換模式或暫時使用 TikFinity。

「我不斷受到速率限制」

  • 關閉同一裝置上的其他 TikTok 分頁、應用程式或重複的觀看視窗。
  • 等候幾分鐘再重試。
  • 嘗試其他模式或簽章路徑。

「我應該先嘗試什麼？」

  • 讀取使用 Auto
  • 回覆使用 Standard
  • Standard 不穩定時使用 Local Signer
  • TikTok 本身有問題時使用 TikFinity
擴充功能

如果改用瀏覽器擴充功能

  • 在瀏覽器中開啟實況主的 TikTok 直播頁面，並保持擴充功能啟用。
  • 如果需要自己直播中僅限已驗證使用者或主持人的頁面事件，請登入。
  • TikFinity 活動動態頁面也可用於以瀏覽器為基礎的 SSN 設定。
  • 獨立應用程式仍提供最廣泛的 TikTok 模式選擇和最清楚的備援選項。
