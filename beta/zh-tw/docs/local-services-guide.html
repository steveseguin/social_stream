1. 啟用本機伺服器

此「檔案」選單選項會在桌面應用程式內啟動支援房間和頻道的 WebSocket 轉送服務。支援的 Social Stream 頁面可用它在同一台電腦上交換聊天和指令。它是頁面專用伺服器路由的替代端點。

它不會託管 Social Stream 網站、獨立擷取平台，或提供 HTTP 自動化 API。請先閱讀 啟用本機伺服器指南.

2. 本機控制 API 與 MCP

此可選擇啟用的回送 API 讓 SSApp 電腦上的程式管理支援的來源和設定、讀取狀態和診斷、檢查應用程式或來源視窗，以及追蹤擷取事件。隨附的 MCP 轉接器將這些動作作為工具提供給相容的 AI 用戶端。

在下列位置啟用： 檔案 > 本機 AI / 自動化。它與下列功能分開： 啟用本機伺服器。請參閱 本機控制 API 與 MCP 指南.

3. 無頭家用伺服器或 VPS

無頭模式執行完整的 Electron 桌面應用程式，同時隱藏來源視窗。在 Linux 上仍需要 Xvfb 等顯示後端。它適合讓專用電腦在不連接顯示器的情況下持續擷取聊天。

無頭模式不會建立公開控制 API。遠端控制使用 Social Stream 的一般 WebRTC 或 WebSocket 傳輸。參閱 無頭託管指南.

4. 本機媒體伺服器

當本機 Event Flow 媒體可用時，桌面應用程式會自動啟動此服務。它透過每個設定檔獨有的隨機權杖路徑，僅提供經 SSApp 核准的檔案和選定的執行階段資源。

它不是通用網頁或檔案伺服器。參閱 Event Flow 媒體檔案 ，在本機檔案、上傳和雲端託管之間選擇。

伺服器備用模式有所不同

例如這些設定： 將聊天訊息傳送到 API 伺服器 和 停駐面板透過伺服器向擴充功能傳送指令 用於選擇聊天和指令的路由方式。產生的 URL 旗標包括 server, server2，以及 server3.

這些設定通常使用 Social Stream 的託管 WebSocket 服務。如果支援的頁面還帶有 localserver，則改用桌面應用程式的本機轉送服務。參閱 工作階段、密碼、轉送與伺服器模式 ，查看路由控制項。

使用剛產生的連結。 路由旗標因頁面而異。不要將一個頁面的伺服器旗標複製到另一個頁面，並假定含義相同。

其他暫時性本機連接埠

某些登入和帳號連結流程會短暫開啟回送回呼連接埠，並在流程結束後關閉。這些暫時性監聽器不是通用 SSN 伺服器或自動化 API。
