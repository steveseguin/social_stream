Windows 和 macOS 在執行從應用程式商店以外下載的應用程式前，有時會要求額外確認。對於新版本、下載量較少的應用程式或私人／自訂組建，尤其常見。

除非你願意這樣做並完全理解所允許的內容，否則絕不要略過安全警告。 只有當應用程式下載自 Social Stream Ninja 官方發佈頁面，或自訂組建來自你信任的人時，才繼續操作。如果不確定，請停止並回報該警告。

如果警告說應用程式包含惡意軟體、會損壞電腦，或指出具體威脅，請不要允許它。儲存擷圖，並查看下方的疑難排解部分。

1. 確認來源開啟官方發佈頁面 ，如果不確定，請重新下載一份。
2. 對照提示訊息警告中的具體文字決定下方哪些步驟適用。
3. 保留警告資訊關閉之前先擷圖，以便需要時尋求支援。

Windows：「Windows 已保護您的電腦」

訊息範例 Microsoft Defender SmartScreen 阻止了無法辨識的應用程式啟動。

此警告通常表示 Windows 尚未取得針對這個具體下載檔案的足夠信譽資訊，與偵測到惡意軟體不同。

  1. 確認檔案來自 官方發佈頁面.
  2. 在藍色警告視窗中選擇 更多資訊.
  3. 檢查應用程式名稱是否為 Social Stream Ninja，或以下列內容開頭： socialstreamninja.
  4. 如果你理解警告並願意繼續，請選擇 仍要執行。否則，請關閉警告並使用下方的替代方案之一。

Windows 組建使用自我簽署，並提交到 VirusTotal 進行額外的安全和信譽檢查。自我簽署憑證與 Windows 信任的商業機構簽發的憑證並不等同，因此 Windows 可能顯示 未知的發行者 ，或再次要求確認新發佈的檔案。

瞭解 Microsoft SmartScreen 信譽機制.

Windows：Defender 封鎖或移除了檔案

可能出現的訊息 「發現威脅」、「發現潛在不受歡迎的應用程式」、「此應用程式已被封鎖」或「威脅已隔離」
  1. 開啟 Windows 安全性 ，可從「開始」功能表進入。
  2. 選擇 病毒與威脅防護，然後 保護歷程記錄.
  3. 開啟提及 Social Stream Ninja 安裝程式或可攜版應用程式的項目。
  4. 閱讀偵測名稱和受影響的檔案路徑。
  5. 如果只是應用程式信譽或潛在不受歡迎應用程式的警告，檔案來自官方發佈頁面，且你充分理解並願意接受這一選擇，請選擇 動作 > 允許在裝置上執行。可能需要重新下載檔案。
如果 Windows 指出具體的惡意軟體威脅，請停止操作。 在確認下載來源，並向支援人員提供偵測名稱或擷圖之前，不要選擇「允許」。

Microsoft 的保護歷程記錄說明

Windows：智慧應用程式控制封鎖了應用程式

智慧應用程式控制與普通 SmartScreen 警告不同。Windows 不提供僅針對單一應用程式的 仍要執行 例外。

  • 在工作或學校電腦上，請管理員核准此應用程式。
  • 在個人電腦上，使用 瀏覽器擴充功能 或 Lite 網頁應用程式 ，適用於不想變更整個裝置安全設定的情況。
  • 智慧應用程式控制可在下列位置 Windows 安全性 > 應用程式與瀏覽器控制中管理，但變更它會影響所有應用程式的保護。決定前請閱讀 Microsoft 的說明。

其他 Windows 訊息

訊息處理方式
「為保障安全性和效能，此 Windows 模式僅執行經 Microsoft 驗證的應用程式」電腦可能處於 Windows S 模式。此模式僅執行 Microsoft Store 應用程式。退出 S 模式是影響整個裝置且不可逆的選擇，因此請先考慮瀏覽器版或 Lite 版。 閱讀 Microsoft 的 S 模式指南.
「此應用程式已被系統管理員封鎖」電腦受到工作、學校、家庭或安全性原則管理。需要由管理該電腦的人核准此應用程式。
「Windows Defender 防火牆已封鎖此應用程式的某些功能」這涉及網路存取，而非應用程式是否可以啟動。如果選擇允許存取，請僅允許受信任的私人網路；通常不需要允許公用網路存取。
「此應用程式無法在您的電腦上執行」刪除該副本並重新下載目前的 Windows x64 版本。確保下載已完成，並且沒有誤選 macOS 或 Linux 檔案。

macOS：開發者或公證警告

可能出現的訊息 Apple 無法檢查應用程式是否含有惡意軟體，或無法驗證開發者

官方 macOS 發佈版本旨在完成簽章和公證。私人或第三方自訂組建可能未經過公證，而新下載的應用程式仍可能需要首次開啟核准。

  1. 確認應用程式來自 官方發佈頁面 ，或來自你信任其自訂組建的人。
  2. 嘗試開啟應用程式一次，然後關閉警告。
  3. 開啟 Apple 選單 > 系統設定 > 隱私權與安全性.
  4. 向下捲動到「安全性」部分，找到被阻止應用程式的相關訊息。
  5. 如果你理解警告並願意繼續，請選擇 強制打開，按提示驗證身分，然後選擇 開啟.

這會為該應用程式設定例外，無需對所有應用程式關閉 Gatekeeper。

Apple 關於安全開啟已下載應用程式的指南

macOS：「應用程式已損毀」或「將損害您的電腦」

不要使用終端機指令移除應用程式的隔離資訊。這些訊息可能表示下載不完整或被修改、簽章無效，或 macOS 偵測到了安全問題。

  1. 將該副本移到垃圾桶。
  2. 從官方發佈頁面重新下載目前的 macOS 版本。
  3. 開啟新下載的副本，不要修改應用程式套件。
  4. 如果訊息再次出現，請擷取包含完整措辭和 macOS 版本的畫面，然後聯絡支援人員。

如果 強制打開 沒有出現時，請嘗試再次開啟應用程式，然後重新檢查「隱私權與安全性」。在受管理的 Mac 上，此設定可能由管理員控制。

Linux：AppImage 無法啟動

AppImage 可能需要執行權限：

  1. 以滑鼠右鍵點選 AppImage 並開啟 內容.
  2. 在「權限」中啟用 允許將檔案作為程式執行。不同桌面環境的措辭可能不同。
  3. 再次開啟 AppImage。

你也可以透過終端機授予權限：

chmod +x socialstreamninja_linux_*.AppImage
./socialstreamninja_linux_*.AppImage

如果錯誤提到 chrome-sandbox, SUID 沙箱、AppArmor 或非特權命名空間，請遵循 AppImage 沙箱指南.

比略過警告更安全的替代方案

使用 Social Stream Ninja 並不一定要忽略作業系統警告。

  • 回報警告： 傳送擷圖和下方列出的詳細資料，以便調查。
  • 嘗試較舊的官方版本： 如果只有新版本被封鎖或失敗，請返回官方發佈頁面，使用先前對你有效的最新舊版本。如可行，請先匯出設定。
  • 使用 Chrome 擴充功能： 安裝 Chrome 線上應用程式商店版本 ，代替桌面應用程式。
  • 使用網頁應用程式： 開啟 Social Stream Ninja Lite ，適用於其較精簡的功能已足夠的情況。
舊版本不包含最新修正。僅從官方發佈頁面下載，並在瞭解問題後恢復使用目前版本。

如果仍然無法開啟

向支援人員傳送下列詳細資料：

  • 包含完整警告內容的擷圖。
  • 你的作業系統及版本。
  • 所下載檔案的準確名稱。
  • 這是安裝程式、可攜版應用程式、AppImage、官方 macOS 版本，還是自訂組建。
  • 同一副本以前是否成功開啟過。
  • 在 Windows 上，如果「保護歷程記錄」中出現偵測名稱，也請提供。
