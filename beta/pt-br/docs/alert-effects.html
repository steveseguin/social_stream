Configure seu primeiro alerta

  1. Abra Multi-Alerts → Event animations & sound effects.
  2. Ative um alerta e escolha o evento. A predefinição de doação de US$ 100 preenche os dois limites e fornece um som sintético de agradecimento se nenhum estiver selecionado.
  3. Adicione uma URL direta opcional de GIF, imagem ou vídeo, ou envie um arquivo. Um link de página do GIPHY não é uma URL direta de mídia. GIFs não têm áudio; escolha um som separado.
  4. Escolha um som e use Ouvir (Listen) para escutar localmente. As opções de URL personalizada e upload ficam abaixo do seletor.
  5. Use Test alert e adicione o link de Multi-Alerts como fonte de navegador do OBS.

Limites de valor e prioridade

Doações e bits usam valores estimados em USD pelo conversor de moedas. Para exatamente US$ 100, defina os dois limites como 100. Para US$ 100 ou mais, deixe o máximo vazio. Limites vazios aceitam qualquer valor; outros tipos de evento devem ficar sem limites.

O primeiro alerta correspondente vence. Coloque regras específicas antes das gerais. Os filtros de plataforma e categoria continuam valendo.

Prévia e som

Test alert abre e coloca a prévia local em foco. Não envia eventos aos seus canais ao vivo. A prévia usa suas configurações atuais de overlay, filtros, mídia e tempos. O volume fica em Sound & Timing.

Limpar som remove o som personalizado; o áudio padrão do alerta continua valendo. Desative Play alert sound para silenciar o áudio do overlay. Enable alert pausa uma regra preservando as configurações. Reset alert limpa apenas aquela regra.

As frases faladas são identificadas como gravações sintéticas. Para nomes ou textos variáveis, use a ação Speak Text do editor Event Flow.

Event Flow e efeitos do OBS

Use modelos do Event Flow para sequências e efeitos do OBS. Essas ações de mídia e som tocam no overlay Flow Actions. Use apenas um overlay para o som de cada evento para evitar áudio duplicado. Os modelos de OBS precisam de uma fonte e um filtro selecionados antes do uso.
