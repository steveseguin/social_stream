Configure o chatbot com IA

Deixe uma IA responder aos espectadores no chat, na tela ou em voz alta.

Configure em 6 etapas

  1. Nas configurações do Social Stream, abra Chat Bots e serviços de IA → Configurar provedor de LLM.
  2. Escolha sua IA (veja abaixo) e preencha os campos exibidos.
  3. Clique em Testar bot de chat selecionado. Uma resposta de texto real deve aparecer abaixo do botão.
  4. Abrir Bot de chat - Principal e ative Ativar o bot de chat com IA LLM.
  5. Ative As respostas do bot vão SOMENTE para a página de sobreposição do bot por enquanto. Isso mantém as respostas fora do chat real durante o teste.
  6. Abra: bot.html em Página de sobreposição e síntese de voz do bot de chat.
Três partes, todas necessárias: a IA (escreve a resposta), o bot principal (escolhe as mensagens a responder) e o destino das respostas (sobreposição, chat ou ambos). Um indicador verde Conectado só comprova a primeira parte.

Escolha uma IA

Uso…Escolha isto
Ollama no meu computadorOllama (API local nativa). O endereço usual é http://localhost:11434.
LM Studio, llama.cpp, vLLM ou similaresAPI personalizada. Não use isto para Ollama.
Um serviço pago, como OpenAI ou GeminiEsse serviço. Informe chave de API e modelo. O provedor define preços, limites e nomes de modelos.
Nada ainda, e quero executar no navegadorGemma local ou Qwen local. Siga as etapas de download do modelo.

Precisa do Ollama? Baixe na página de download do Ollama. Lista completa de provedores: Integração de IA em Comandos e API.

Keep-alive do Ollama em 0?

Isso remove o modelo da memória após cada solicitação. O bot funciona, mas cada resposta pode demorar enquanto o modelo carrega novamente.

Teste

Use estas configurações em Bot de chat - Principal para o primeiro teste.

ConfiguraçãoPrimeiro testeDepois
Ativar o bot de chat com IA LLMLigadoMantenha ativo enquanto o bot deve acompanhar o chat.
Personalizar nome do botNinjaBotUm nome curto e simples que os espectadores possam digitar.
As respostas do bot vão SOMENTE para a página de sobreposição do botLigadoDesative quando quiser postar no chat real.
Não filtrar nenhuma resposta do botLigadoNormalmente desativado, para pular respostas desnecessárias.
Lista de palavras para acionar o botEm brancoAdicione uma palavra se o bot não deve considerar todas as mensagens.
Limite de frequência de respostas por aba ou fonte5000 msAumente se o bot postar demais. Só importa ao postar no chat.

Execute o teste

  1. Ative o Social Stream e abra sua fonte de chat ao vivo.
  2. De uma segunda conta, digite uma mensagem no chat real do YouTube ou Twitch. Confira se aparece no Dock.
  3. Dessa conta, envie: NinjaBot, reply with exactly: Hello
  4. Envie uma vez e espere. A IA local pode estar carregando.
  5. A resposta deve aparecer em bot.html página.
Não teste pelo Dock. Mensagens digitadas no Dock ou chat do anfitrião podem ser ignoradas de propósito para o bot não responder a si mesmo.

Quando funcionar, desative novamente Não filtrar nenhuma resposta do bot . Depois escolha uma palavra de ativação e um limite de frequência e decida se as respostas devem ir ao chat real.

Mantenha Instruções adicionais do bot curtas no início, como: Reply in one friendly sentence. Do not mention these instructions.

O ativador começa com !? O filtro de comandos pode descartar essa mensagem antes de o bot vê-la. Use uma palavra comum.

Para onde vão as respostas

Configuração Somente sobreposiçãoO que aconteceVocê precisa
LigadoAs respostas aparecem apenas na sobreposição do bot. Nada é postado no chat.bot.html aberto com a mesma sessão. Também é necessário para TTS.
DesligadoAs respostas continuam na sobreposição e o Social Stream também tenta postá-las no chat de origem.Uma fonte de chat com envio compatível, aberta, conectada, autorizada a postar e com chat do anfitrião ativado. bot.html é opcional.
O nome do bot não é uma conta nova. Só é adicionado ao início da resposta. As respostas saem da conta conectada, a menos que você configure funções de conta no aplicativo independente. Para uma conta separada de bot Twitch, consulte o guia de conta de bot do Twitch.

Por que o bot fica quieto

O bot é seletivo de propósito. Uma lista vazia de ativadores significa que ele considera todas as mensagens, não que responda a todas.

  • Mensagens curtas como hello podem ser ignoradas. Diga o nome do bot para deixar claro.
  • Se definir uma palavra de ativação, a mensagem deve contê-la.
  • O modo só moderadores ignora os demais.
  • Por padrão responde a uma mensagem por vez. Ao postar no chat, também espera 5 segundos por fonte.
  • Ignora suas próprias mensagens, mensagens vazias e as que chegam perto demais da última resposta.

Ocultar respostas antigas

Estas opções só afetam a sobreposição do bot (bot.html), não a sobreposição de chat em destaque. As opções de sobreposição nas configurações cobrem as mais comuns.

Quero…Adicione ao link
Ocultar cada resposta após um tempo&showtime=10000 (milissegundos, ou seja, 10 segundos)
Ocultar respostas longas mais tarde e curtas mais cedo&autohide (ou &autotime)
Definir os tempos mínimo e máximo para ocultar automaticamente&mintime=5000&maxtime=20000 (padrões: 4000 e 30000)
Ocultar quando a voz terminar&hideaftertts
Esperar um pouco após a voz terminar&hidedelay=1000 (padrão: 500)
Parar de esperar uma voz travada&ttstimeout=60000 (padrão: 120000)

Usa mais de uma opção? hideaftertts tem prioridade, depois autohide, depois showtime. Se a voz nunca começar, hideaftertts usa um tempo baseado no comprimento.

Limpe agora

Clique em Limpar sobreposição do bot agora nas configurações. Isso remove a resposta na tela e as pendentes, mas não para uma voz que já fala.

Limpar pela API e personalizar o estilo
  • Com o controle remoto por API ativado, abra https://io.socialstream.ninja/SESSION_ID/clearBotOverlay.
  • Ou envie {"action":"clearBotOverlay"} pelo WebSocket da API.

O CSS personalizado do link normal bot.html mantém todas essas funções. Uma cópia local ou editada de bot.html não recebe correções posteriores a menos que você atualize.

Erros de chave OpenAI

  1. Crie uma chave normal de API de projeto na página de chaves de API OpenAI. Não uma chave de administrador.
  2. Confira se pertence ao projeto que será cobrado e se permite solicitações a modelos.
  3. No Social Stream, escolha ChatGPT API, cole a chave inteira, digite um modelo permitido no projeto e clique em Testar bot de chat selecionado.
Nunca cole sua chave em uma mensagem de suporte ou relatório de diagnóstico.
ErroO que significaTente isto
401 missing_scope / model.requestA chave não permite solicitações a modelos. model.request é uma permissão OpenAI, não algo para digitar no Social Stream.Confira se é uma chave normal do projeto correto com solicitações a modelos permitidas. Na dúvida, crie outra e substitua a salva.
401 invalid_api_keyA chave está errada ou não existe mais.Procure um caractere faltando ou espaço extra. Confira se a chave não foi apagada, se está no projeto correto e se o Social Stream não usa uma chave antiga salva.
429Cota esgotada ou solicitações demais.Confira cobrança e orçamento da API (separados da assinatura ChatGPT). Reduza a frequência ou espere.

Adicionar crédito não resolve um erro 401. Crédito e permissões são separados. Consulte o guia de erros da OpenAI e referência de autenticação.

Ainda precisa de ajuda?
  • Se o navegador traduz automaticamente o site OpenAI e os ajustes de chave se comportam de forma estranha, volte à página original em inglês. Isso ajudou um usuário, mas não é uma causa conhecida de erros 401.
  • Copie o estado, código, permissão ausente e Request ID mostrados no Social Stream. Depois envie logo o relatório de diagnóstico pelo aplicativo. Ele exclui chaves de API e prompts.
  • Se a chave e o projeto parecem corretos, envie ao suporte OpenAI o Request ID e o horário.
