Seletor de configuração de plataformas

Escolha a forma mais simples de captura antes de abrir o OBS.

Comece pela página de sites compatíveis

Busque sua plataforma primeiro. Clique e leia a nota breve de configuração antes de tentar um método mais difícil.

Use a extensão normal do navegador quando

  • A plataforma funciona no seu navegador habitual.
  • Você já está conectado à conta certa.
  • A página de sites compatíveis orienta abrir o site ou o chat em janela separada.

Comece aqui para YouTube, Twitch, Facebook, Discord, Slack, WhatsApp e a maioria das fontes de navegador.

Use uma janela separada ou só de chat quando

  • A plataforma tem uma URL separada para o chat em janela própria.
  • A página normal da live é pesada ou pouco confiável.
  • Você quer uma janela menor que mostre apenas o chat.

Para ver as notas específicas de cada plataforma, consulte Sites compatíveis.

Use o aplicativo de desktop quando

  • As abas do navegador estão sendo ocultadas, limitadas ou descartadas.
  • Você quer gerenciar as janelas de fontes dentro do aplicativo.
  • Você usa uma integração específica do aplicativo, como alguns modos do TikTok.

Configuração no desktop: Guia do aplicativo independente.

Use uma página de fonte quando

  • A plataforma precisa de uma URL de fonte específica do Social Stream.
  • A configuração pede canal, sala, token ou login.
  • A plataforma não é capturada de uma aba normal do navegador.

Páginas de fonte são normais. Significam apenas que o Social Stream precisa de uma página especial para aquela plataforma.

Na dúvida, comece pela opção mais simples que se encaixe. Você pode mudar de método depois.
