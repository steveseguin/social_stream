Configuração do projeto do YouTube

Como criar um projeto do Google Cloud para o aplicativo SSN Standalone para desktop sem reduzir a segurança da sua chave.

Visão geral

Para que serve esta configuração

Use isto somente se quiser que o aplicativo para desktop use sua própria cota da API do YouTube em vez do projeto compartilhado padrão do Social Stream Ninja.

Importante: os três valores abaixo devem vir do mesmo projeto do Google Cloud:
  • ID do cliente OAuth
  • Segredo do cliente OAuth
  • Chave de API
Não confunda estes dois campos no Google Cloud:
  • Origens JavaScript autorizadas deve conter apenas a origem, sem caminho.
  • URIs de redirecionamento autorizados deve incluir o caminho /sources/websocket/youtube.html completo.
Etapa 1

Crie o projeto

  1. Abra o Google Cloud Console.
  2. Crie um novo projeto ou escolha um projeto existente dedicado.
  3. Ative YouTube Data API v3.
  4. Abra as configurações da tela de consentimento OAuth.
  5. Se o aplicativo estiver em teste, adicione sua conta Google como usuário de teste.
Etapa 2

Crie o cliente OAuth

  1. Crie as credenciais.
  2. Escolha ID do cliente OAuth.
  3. Use o tipo Aplicativo da Web.
  4. Adicione as origens e os URIs de redirecionamento exatos mostrados abaixo.
Campo Valor
Origens JavaScript autorizadas http://localhost:8181
http://localhost:8080
URIs de redirecionamento autorizados http://localhost:8181/sources/websocket/youtube.html
http://localhost:8080/sources/websocket/youtube.html
Etapa 3

Crie a chave de API com segurança

  1. Crie uma Chave de API no mesmo projeto.
  2. Abra as restrições dessa chave.
  3. Em Restrições da API, restrinja-a a YouTube Data API v3 somente.
  4. Não use restrições de referenciador HTTP para o aplicativo de desktop.

Regra do aplicativo para desktop: As restrições de referenciador HTTP são para páginas do navegador, não para este fluxo local de autenticação do aplicativo para desktop.

Etapa 4

Cole os valores no aplicativo para desktop

  1. Abra a página da fonte do YouTube dentro do aplicativo para desktop.
  2. Cole o ID do cliente OAuth, Segredo do cliente OAuth, e Chave de API.
  3. Clique em Salvar.
  4. Saia da conta, se necessário.
  5. Clique em Entrar com o YouTube.
  6. Conclua o login no Google na janela externa do navegador.
Resultado esperado: se tudo corresponder, o login no Google funcionará e o aplicativo para desktop usará seu projeto do YouTube salvo em vez do projeto compartilhado padrão.
Segurança

Mantenha as credenciais seguras

  • Trate o segredo do cliente e a chave de API como informações confidenciais.
  • Não os cole em capturas de tela, registros de chat ou relatos de erros.
  • Se você os expuser acidentalmente, substitua-os ou exclua-os.
  • Use um projeto de teste dedicado se estiver experimentando.
  • Exclua projetos temporários quando terminar os testes.
Solução de problemas

Problemas comuns

  • redirect_uri_mismatch: o URI de redirecionamento não corresponde exatamente.
  • invalid_client: o ID e o segredo do cliente não correspondem.
  • quotaExceeded: o projeto da sua chave de API esgotou a cota do YouTube.
  • Falha na validação da conta: em versões antigas, isso podia ocorrer quando o OAuth e a chave de API vinham de projetos diferentes.
