Comece aqui

Está começando com TTS? Siga o Guia de configuração de TTS. São 5 etapas. Esta página é a referência completa.

O SSN lê qualquer chat que capture como texto. Sua plataforma de chat não precisa ter TTS próprio. Quem fala é o dock ou a sobreposição com TTS ativado, seguindo seus filtros.

O link mais simples ativa o TTS com as vozes do sistema:

dock.html?session=YOUR_SESSION&speech=en-US

Para o OBS, adicione uma voz gratuita que reproduza áudio pela página:

dock.html?session=YOUR_SESSION&speech=en-US&ttsprovider=piper

Mantenha essa página aberta e conectada. Só uma página deve falar.

TTS do sistema não é a mesma coisa que TTS gratuito. As vozes do sistema vêm do navegador e do computador. O OBS muitas vezes não tem nenhuma, mesmo quando funcionam no Chrome. Kokoro, Piper, Kitten e eSpeak são gratuitos e geram seu próprio áudio, por isso funcionam no OBS. Você não precisa pagar para usar TTS no OBS.

O TTS também está em CAPTION.Ninja, para legendas, transcrição e tradução. Ambos oferecem vozes gratuitas e pagas.

Vozes do sistema

O TTS do sistema usa as vozes disponíveis no navegador e no computador. Estas são comuns, mas não são garantidas.

NavegadorVozes do sistema
ChromeSim. Vozes do Google e do sistema.
EdgeSim. Vozes da Microsoft e pacotes de idiomas do Windows.
FirefoxLimitado. Apenas vozes locais do sistema.
OperaLimitado. Varia conforme a instalação.
SafariPrecisa de um clique antes de reproduzir áudio.
OBSNavegador próprio. Não recebe as vozes do Chrome ou do Edge. Testar no aplicativo SSN não testa o OBS.

Confira as vozes do sistema deste navegador. Só lista as vozes de TTS do sistema no navegador em que você abrir. Não testa o OBS nem provedores como Kokoro. Uma lista vazia não significa que outros provedores não funcionarão.

Adicione mais vozes no Windows

  1. Abrir Iniciar > Configurações > Hora e idioma > Fala.
  2. Em Gerenciar vozes, clique em Adicionar vozes.
  3. Escolha os idiomas e clique em Adicione.
  4. Reinicie o navegador.

Isso é para Windows 11. Para Windows 10, veja o Guia da Microsoft. Algumas vozes de terceiros não aparecem nos navegadores. O Firefox costuma mostrar mais vozes do sistema do que navegadores baseados no Chrome.

Leve o TTS do sistema ao OBS

Usa outro provedor? Você não precisa disso. Ative Controlar áudio pelo OBS (Control audio via OBS) na fonte de navegador. Não é necessário cabo virtual.
  1. Primeiro confira se o TTS do sistema realmente fala. O OBS pode não ter uma voz utilizável. Se não houver fala, o roteamento não resolve. Use outro provedor.
  2. Se a fala tocar em outro navegador, capture esse navegador com a captura de áudio de aplicativo ou de desktop do OBS.
  3. Ainda não resolveu? Direcione o navegador por um cabo de áudio virtual (abaixo).
Direcione o áudio por um cabo virtual (Windows)

Downloads: VB-Audio Virtual Cable (grátis) · Voicemeeter · Audio Router (legado)

MétodoFaça isto
PC inteiroDefina CABLE Input como saída padrão do Windows (Configurações de som > Saída).
Um aplicativo, Windows 11Configurações > Sistema > Som > Mixer de volume. Defina a saída do navegador como CABLE Input.
Um aplicativo, Windows 10Configurações de som > Preferências de volume do aplicativo e dispositivo. Defina a saída do navegador como CABLE Input.
Audio RouterSoftware antigo. Direcione o navegador para CABLE Input.
VoicemeeterDefina como saída padrão do Windows. Envie a saída de hardware para os alto-falantes e a virtual para o OBS.

Depois, no OBS, adicione Captura de entrada de áudio, escolha CABLE Output (ou a saída do Voicemeeter) e defina o monitoramento como Monitorar e enviar (Monitor and Output). Use Apenas monitoramento se outra fonte já envia o áudio para a transmissão.

Teste: reproduza o TTS, observe o medidor do OBS, confira se consegue ouvir e ajuste os níveis.

Resolver problemas

ProblemaTente isto
Sem somConfira se o TTS está ativo, se a página que fala está aberta e se a fonte de navegador não está no mudo. Em um navegador comum, clique uma vez na página.
Sem som no OBSSem fala nenhuma? Confira primeiro o provedor. Se houver fala, verifique Controlar áudio pelo OBS (Control audio via OBS), o mudo do mixer e as faixas de saída. Ou capture o navegador que está falando.
A voz na nuvem não funcionaConfira a chave de API e o nome do provedor. Sem chave, o SSN usa o TTS do sistema, que pode ficar sem som no OBS.
O servidor local funciona no aplicativo, mas não no OBSO OBS é um navegador separado. Confira o servidor a partir do computador do OBS, especialmente com 127.0.0.1. Veja o regra do localhost.
Só a primeira letra ou as primeiras palavras são lidasRemover ttsquick do link do OBS.
As novas vozes não aparecemReinicie o navegador após adicionar pacotes de idiomas.
O Safari não falaO Safari limita o TTS automático. Clique uma vez na página para permitir o áudio.

Boas práticas

  • Use um provedor que reproduza áudio pela página. É a configuração mais simples no OBS, e existem opções gratuitas.
  • Teste com uma mensagem curta antes de entrar ao vivo.
  • Os espectadores podem escrever qualquer coisa. Tenha uma forma rápida de desativar o TTS.
