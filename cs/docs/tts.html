Přehled

SSN může číst zachycený text chatu z jakéhokoli podporovaného zdroje; chatovací platforma nepotřebuje vlastní funkci TTS. Dok nebo překryv se zapnutým TTS čte zprávy, které přijímá, podle svých filtrů a nastavení TTS. Začněte s stručným průvodcem nastavením; tato stránka popisuje možnosti hlasů a pokročilá nastavení. Porovnejte poskytovatele, poslechněte ukázky a prohlédněte nastavení.

Rychlý start: Použijte dock.html?session=YOUR_SESSION&speech=en-US. Výchozí je System TTS. Pro bezplatného poskytovatele v OBS přidejte také &ttsprovider=kokoro. Nechte tuto stránku otevřenou a připojenou; mluvit by měla pouze jedna instance.

Kde se TTS používá?

  • Social Stream Ninja: Čte zprávy diváků z chatu v několika částech aplikace
  • CAPTION.Ninja: Nabízí skryté titulky, přepis a překlad s TTS
  • Obě služby nabízejí placené i bezplatné možnosti TTS
System TTS není totéž co všechny bezplatné možnosti TTS:
  • Systémové hlasy závisí na prohlížeči a operačním systému. OBS nemusí poskytovat žádné použitelné hlasy, i když Chrome/Edge funguje.
  • Chybějící hlas je něco jiného než řeč přehrávaná mimo zachytávání zvuku OBS. Směrování zvuku nedokáže vyřešit chybějící podporu řeči.
  • Bezplatní poskytovatelé jako Kokoro, Piper, Kitten a eSpeak místo toho vytvářejí zvuk stránky. TTS v OBS nevyžaduje platbu.
  • Nejprve zkontrolujte dostupnost hlasu, potom zachytávání zvuku.

Možnosti poskytovatelů TTS

System TTS (zdarma)

  • Používá vestavěné hlasy operačního systému
  • Omezená podpora jazyků podle instalace systému
  • Dostupnost hlasů a směrování zvuku závisí na prohlížeči a operačním systému; testujte ve skutečném přehrávači
  • Kompatibilita prohlížečů se výrazně liší

Dostupnost systémových hlasů

Jde o typické možnosti, ne záruky pro každou instalaci. OBS používá vlastní vestavěný prohlížeč a nepřebírá seznam hlasů nainstalovaného Chrome/Edge. Úspěšný test v aplikaci SSN netestuje samostatný zdroj prohlížeče OBS.

Edge

Omezení prohlížeče:
  • Ne všechny prohlížeče podporují převod textu na řeč stejně (některé verze Firefoxu mají omezený výběr hlasů)
  • Chrome nabízí možnosti TTS od Googlu
  • Edge podporuje TTS Microsoftu a hlasy jazykových balíčků Windows
  • Safari vyžaduje pro spuštění zvuku interakci uživatele
  • Zkontrolujte dostupné hlasy pro váš prohlížeč

Metody zachytávání zvuku Windows TTS pro OBS

Zvuk stránky: bezplatní místní a cloudoví poskytovatelé

Místní poskytovatelé SSN běžící v prohlížeči a cloudoví poskytovatelé zvuku přehrávají vygenerovaný zvuk přes stránku:

  • Ve zdroji prohlížeče stačí zapnout „Control audio via OBS“
  • Není potřeba virtuální zvukový kabel
  • Funguje s aplikací SSN a zdroji prohlížeče OBS

Metody zachytávání System TTS

Důležité: Nejprve ověřte, že System TTS vytváří řeč. Vestavěný prohlížeč OBS nemusí poskytovat použitelný systémový hlas. Pokud řeč nevytváří, změna směrování zvuku nepomůže. Vyberte jiného poskytovatele nebo vytvářejte řeč v podporovaném prohlížeči a zachytávejte jeho zvuk.

Konkrétně pro System TTS:

  • Nepředpokládejte, že OBS nabízí stejné hlasy jako Chrome nebo Edge
  • Omezená podpora napříč prohlížeči (Firefox nemusí mít některé hlasy TTS)
  • Chrome nabízí možnosti Googlu, Edge má možnosti Microsoftu
  • Pokud řeč hraje mimo zdroj prohlížeče ve scéně, zachytávejte tento výstup samostatně

Ke stažení pro směrování zvuku: VB-Audio Virtual Cable | Voicemeeter | Audio Router (starší)

Nejprve zkuste zachytit mluvící prohlížeč pomocí zvuku aplikace nebo plochy v OBS, pokud je to podporované. Níže uvedené metody s virtuálním kabelem jsou volitelné alternativy; nepřidávají podporu řeči do OBS.

Metoda 1: výchozí směrování zvuku přes virtuální kabel

1. Set VB-Audio Virtual Cable as Windows default output - Sound Settings > Output > CABLE Input 2. OBS: - Add Audio Input Capture - Source: CABLE Output - Monitor: Monitor and Output, or Monitor Only if another source handles stream output

Metoda 2: směrování aplikace ve Windows 10

1. Sound Settings > App volume and device preferences 2. Find browser in list 3. Output: CABLE Input 4. OBS setup same as Method 1

Metoda 3: směrování aplikace ve Windows 11

1. Settings > System > Sound > Volume Mixer 2. Locate browser 3. Output: CABLE Input 4. OBS setup same as Method 1

Metoda 4: software Audio Router

1. Install Audio Router 2. Route browser to CABLE Input 3. OBS setup same as Method 1

Metoda 5: Voicemeeter (pokročilé)

1. Install Voicemeeter 2. Set as Windows default output 3. Route: - Hardware out > speakers - Virtual out > OBS 4. OBS captures Voicemeeter output

Testování nastavení

1. Play TTS 2. Check OBS meter 3. Verify system audio 4. Adjust levels if needed
Alternativy: Použijte bezplatného vestavěného poskytovatele, jako je Kokoro, Piper, Kitten nebo eSpeak, cloudového poskytovatele nebo vlastní server TTS.

Instalace dalších jazykových balíčků

Windows 11

  1. Přejděte na Start > Nastavení > Čas a jazyk > Řeč
  2. V části Spravovat hlasy, klikněte na Přidat hlasy
  3. Vyberte požadované jazyky a klikněte na Přidejte
  4. Restartujte prohlížeče pro obnovení dostupných hlasů

Windows 10

Postupujte podle pokynů v oficiálním průvodci Microsoftu pro instalaci jazykových balíčků.

Tip: Některé hlasy třetích stran se v prohlížečích nemusí zobrazit kvůli problémům s kompatibilitou. Firefox často zobrazuje více systémových hlasů než prohlížeče založené na Chromiu.

Parametry URL pro nastavení TTS

Základní parametry

Parametr Popis Příklad
&speech Zapnout TTS s kódem jazyka &speech=en-US
&pitch Výška hlasu (0.1 až 2.0) &pitch=1.2
&volume Hlasitost (0.0 až 1.0) &volume=0.8
&rate Rychlost řeči (0.1 až 10.0) &rate=1.5
&voice Částečná shoda názvu hlasu &voice=google
&ttsprovider Vyberte poskytovatele: kokoro, piper, kitten, espeak, openai, customtts, localtts, elevenlabs, google, speechify, gemini &ttsprovider=customtts

Pokročilé parametry

Parametr Popis
&simpletts Nevyslovovat „říká“ ani „někdo říká“
&simpletts2 Vůbec nečíst jména uživatelů chatu
&ttscommand Zapnout vlastní příkaz TTS (výchozí: !say)
&readevents Zahrnout události streamu do TTS
&skipmessages=3 Číst pouze každou 3. zprávu

Nastavení poskytovatele TTS

Kokoro TTS (zdarma, vestavěné)

  • Zapněte pomocí ?ttsprovider=kokoro
  • Běží v prohlížeči přes WebGPU/WASM — bez serveru
  • Funguje přímo se zdrojem prohlížeče OBS
  • Výběr hlasu: &voicekokoro=af_bella
  • Ovládání rychlosti: &kokorospeed=1.2
  • Vyberte hlas pro daný jazyk: &voicekokoro=ef_dora pro španělštinu nebo &voicekokoro=pf_dora pro brazilskou portugalštinu. Změna &speech= sama o sobě nezmění vybraný hlas. Stávající ID anglických hlasů stále fungují.

Piper TTS (zdarma, vestavěné)

  • Zapněte pomocí ?ttsprovider=piper
  • Rychlé neuronové TTS v prohlížeči s nízkými nároky na CPU
  • Výběr hlasu: &pipervoice=en_US-hfc_female-medium
  • Portugalské hlasy: &pipervoice=pt_BR-faber-medium nebo &pipervoice=pt_BR-edresson-low
  • Španělské hlasy: &pipervoice=es_ES-davefx-medium nebo &pipervoice=es_MX-ald-medium
  • Ovládání rychlosti: &piperspeed=1.0

Kitten TTS (zdarma, vestavěné)

  • Zapněte pomocí ?ttsprovider=kitten
  • Nenáročné TTS založené na ONNX běžící v prohlížeči
  • Výběr hlasu: &kittenvoice=expr-voice-4-f

eSpeak-NG (zdarma, vestavěné)

  • Zapněte pomocí ?ttsprovider=espeak
  • Klasické open-source TTS, funguje na jakémkoli hardwaru
  • Výběr hlasu: &espeakvoice=en
  • Portugalský příklad: &speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Španělský příklad: &speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • Ovládání rychlosti: &espeakspeed=175

Příklady portugalského a španělského TTS

  • Portugalština, nejlepší bezplatná místní kvalita testovaná v SSN: ?speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
  • Portugalština, nejrychlejší záložní možnost testovaná v SSN: ?speech=pt-BR&ttsprovider=espeak&espeakvoice=pt-br
  • Španělština, nejlepší bezplatná místní kvalita testovaná v SSN: ?speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium
  • Španělština, nejrychlejší záložní možnost testovaná v SSN: ?speech=es-ES&ttsprovider=espeak&espeakvoice=es
  • U cloudových hlasů použijte hlas/jazyk poskytovatele podporující cílový jazyk, například Google Cloud, ElevenLabs, Speechify, Gemini nebo místní server kompatibilní s OpenAI.

OpenAI / místní server TTS

  • Zapněte pomocí ?ttsprovider=openai
  • Použijte ?ttsprovider=customtts nebo ?ttsprovider=localtts pro vlastní hostovaný koncový bod
  • Ve výchozím nastavení používá API OpenAI nebo jakýkoli kompatibilní místní server
  • Vlastní koncový bod: &openaiendpoint=http://localhost:8880/v1/audio/speech
  • Důležité: localhost a 127.0.0.1 znamenají stejný počítač, který přehrává stránku TTS. Pokud OBS běží na jiném počítači než server TTS, použijte místo toho IP adresu serveru v místní síti.
  • Místní servery nepotřebují API klíč
  • Pokud má místní server problémy s CORS nebo místní sítí v Chrome/OBS, spusťte npm run local-tts-bridge na počítači s OBS a nasměrujte SSN na http://127.0.0.1:8124/v1/audio/speech
  • SSN odesílá { model, input, voice, response_format, speed } a podporuje binární zvuk, URL zvuku v JSON a zvuk base64 v JSON
  • Přehrávání z vlastního/místního koncového bodu se nyní ukládá do vyrovnávací paměti; SSN zatím nepřehrává streamované zvukové bloky průběžně
  • Hlas: &voiceopenai=af_bella, rychlost: &openaispeed=1.0. Použijte název hlasu podporovaný vaším serverem; hlasy Kokoro vypadají jako af_bella, zatímco hlasy openedai-speech/ve stylu OpenAI mohou vypadat jako nova nebo echo.
  • Podívejte se na Průvodce lokálním AI TTS pro nastavení vlastního serveru

Google Cloud TTS

  • Zapněte pomocí ?ttsprovider=google&ttskey=YOUR_API_KEY
  • Hlasy profesionální kvality
  • Výběr hlasu: &voicegoogle=en-GB-Standard-A
  • Jazyk: &googlelang=en-US

Gemini TTS

  • Zapněte pomocí ?ttsprovider=gemini&geminikey=YOUR_API_KEY
  • Model: &geminimodel=gemini-2.5-flash-preview-tts
  • Hlas: &voicegemini=Kore, jazyk: &geminilang=th-TH
  • Pokyny ke stylu: &geministyle=Read aloud in a warm tone.

ElevenLabs TTS

  • Zapněte pomocí ?ttsprovider=elevenlabs&elevenlabskey=YOUR_API_KEY
  • ID hlasu: &voice11=YOUR_VOICE_ID
  • Model: &elevenlabsmodel=eleven_multilingual_v2
  • Lze upravit parametry stability, similarity a style

Fish Audio TTS

Vyberte Fish Audio a zadejte API klíč, případně i ID hlasu. Výchozí model je s2.1-pro-free. Nastavení, možnosti modelu a omezení přístupu z prohlížeče.

Speechify TTS

  • Zapněte pomocí ?ttsprovider=speechify&speechifykey=YOUR_API_KEY
  • Hlas: &voicespeechify=henry
  • Model: &speechifymodel=simba-3.0 (výchozí) nebo &speechifymodel=simba-3.2 pro angličtinu.
  • Rychlost řeči: &speechifyspeed=1.2 (rozsah 0.5 až 3.0; běžná hodnota je 1.0).
  • Průvodce nastavením Speechify, hlasy, rychlostí a hlasitostí

Řešení potíží

Běžné problémy

  • Nepřehrává se zvuk: Ověřte, že TTS je zapnuté, stránka vytvářející řeč je otevřená a zdroj prohlížeče není ztlumený. V běžném prohlížeči jednou klikněte na stránku.
  • Hlasy se nezobrazují: Po instalaci jazykových balíčků restartujte prohlížeč
  • OBS nezachytává zvuk: Pokud není žádná řeč, nejprve ověřte dostupnost hlasu/poskytovatele. Pokud řeč existuje, zkontrolujte Ovládat zvuk přes OBS (Control audio via OBS), ztlumení mixéru a výstupní stopy, nebo zachytávejte externí prohlížeč, který mluví
  • Místní koncový bod funguje v testu aplikace, ale ne v OBS: OBS je samostatný prohlížeč. Ověřte koncový bod z počítače s OBS, zejména při použití 127.0.0.1.
  • Čte se jen první písmeno nebo první slova: odeberte ttsquick z URL v OBS, pokud je přítomné.
  • Problémy se Safari: Safari má omezenou podporu automatického TTS
  • Placená služba nefunguje: Zkontrolujte API klíč a správně nastaveného poskytovatele

Doporučené postupy

  • Pro jednodušší nastavení OBS použijte poskytovatele vytvářejícího zvuk stránky; k dispozici jsou bezplatní místní poskytovatelé
  • Před živým vysíláním otestujte nastavení jednoduchými větami
  • Zvažte rizika uživatelského obsahu při používání TTS
  • Mějte k dispozici přepínač pro rychlé vypnutí TTS v případě potřeby

Zkontrolovat systémové hlasy tohoto prohlížeče

Toto vypisuje Hlasy System TTS pouze v prohlížeči zobrazujícím tohoto průvodce. Netestuje OBS, samostatné okno aplikace SSN ani poskytovatele, jako je Kokoro. Prázdný seznam neznamená, že ostatní poskytovatelé TTS v SSN nejsou dostupní.
