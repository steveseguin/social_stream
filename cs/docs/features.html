Funkce

Spojte své chaty, ukažte diváky na obrazovce a přizpůsobte každé vysílání svému stylu.

Prohlédnout 126 nápadů pro vysílání · Náhled nálepkových odměn

Integrace chatu napříč platformami

Spojte se s diváky na všech svých vysílacích platformách současně. Social Stream Ninja slučuje zprávy chatu z desítek platforem do jednoho snadno ovladatelného panelu.

  • Živá obousměrná komunikace v chatu s Facebookem, YouTube, Twitch, Zoom a dalšími
  • Pro většinu platforem není nutné přihlášení ani klíče API
  • Ikony vícekanálových zdrojů pro rozlišení platforem
  • Automatické přeposílání zpráv mezi platformami

Překryv vybraných zpráv

Zobrazte nejlepší zprávy svých diváků přímo ve vysílání pomocí pěkných, přizpůsobitelných překryvů.

  • Vybírejte zprávy pomocí dokovatelného ovládacího panelu
  • Automatický nebo ruční výběr zpráv
  • Přizpůsobení pomocí CSS pro dokonalé sladění se vzhledem vysílání
  • Možnosti animací včetně prolínání a vysouvání
  • Fronta zpráv pro uspořádaný výběr k zobrazení

Příkazy bota a automatické odpovědi

Vytvářejte automatické interakce s diváky pomocí vlastních příkazů a odpovědí.

  • Vestavěné příkazy pro běžné interakce
  • Vlastní logika příkazů pomocí skriptovatelného souboru pluginu
  • Automatické pozdravy a odpovědi
  • Filtrování a moderování zpráv

Integrace AI a LLM

Vyberte si hlasového spolumoderátora, chatovacího bota, pomocníka v prohlížeči nebo cílené nástroje zpracování AI, aniž byste zbytek vysílání vázali na jediného poskytovatele.

  • Hlasový spolumoderátor, který vás slyší a může přijímat vybrané zprávy živého chatu
  • Hlavní a soukromí chatovací boti s vlastními pokyny a pravidly spouštění
  • Místní modely nebo cloudoví poskytovatelé včetně OpenAI, Gemini, xAI, Bedrock, OpenRouter, Groq a vlastních kompatibilních API
  • Moderování, překlad, souhrny, kontext RAG a tvorba překryvů
  • Volitelné zachytávání ChatGPT v prohlížeči bez klíče API
