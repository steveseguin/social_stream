Znalostní báze

Stručné odpovědi na běžné problémy. Pokud potřebujete úplný postup, použijte průvodce.

Prázdný překryv OBS

Nejprve zkontrolujte dok. Pokud je prázdný, opravte zdroj/platformu. Pokud funguje, otevřete přesnou URL překryvu v běžném prohlížeči a ověřte stejné sessiona potom obnovte zdroj Prohlížeč v OBS.

Otevřít řešení problémů OBS

Nesprávná relace

Stránky zdroje, doku, překryvu, bota a Event Flow musí používat stejné ID relace. S ID relací zacházejte jako s názvy místností: jiné znění znamená jiné místnosti.

dock.html?session=YOUR_SESSION

Otevřít relace, hesla a režimy přenosu

Aktualizace bez ztráty nastavení

Nejprve exportujte nastavení, při běžné aktualizaci rozšíření neodinstalovávejte a pokud je nutné přenést i soubory cookie a přihlášení, použijte šifrovaný přenos celé relace desktopové aplikace.

Otevřít bezpečné aktualizace, zálohy a obnovu

OBS neslyší TTS

Běžné systémové TTS často mluví přes počítač, ale ne přes zdroj Prohlížeč v OBS. Použijte režim TTS poskytovatele/prohlížeče, například Kokoro, Piper, Kitten, eSpeak, kompatibilní s OpenAI nebo cloudového poskytovatele, případně směrujte systémový zvuk samostatně.

Otevřít průvodce nastavením TTS

Kokoro nemluví portugalsky nebo španělsky

Vestavěné hlasy Kokoro jsou anglické. Pro portugalštinu použijte Piper s pipervoice=pt_BR-faber-mediumnebo eSpeak s espeakvoice=pt-br. Pro španělštinu použijte Piper s pipervoice=es_ES-davefx-mediumnebo eSpeak s espeakvoice=es.

dock.html?session=YOUR_SESSION&speech=pt-BR&ttsprovider=piper&pipervoice=pt_BR-faber-medium
dock.html?session=YOUR_SESSION&speech=es-ES&ttsprovider=piper&pipervoice=es_ES-davefx-medium

Otevřít konfiguraci poskytovatelů TTS

Chrome funguje, ale desktopová aplikace ne

Desktopová aplikace používá relace Electron, nikoli běžný profil Chrome. Přihlaste se v okně zdroje aplikace nebo použijte rozšíření Chrome, pokud platforma blokuje vložené prohlížeče nebo prohlížeče aplikací.

Otevřít režimy samostatné aplikace

Který místní server potřebuji?

Zapnout místní server (Enable Local Server) je přenos WebSocket pro podporované stránky SSN. Místní ovládací API slouží skriptům a nástrojům AI na stejném počítači. Hosting bez grafického rozhraní provozuje celou desktopovou aplikaci na linuxovém serveru. Mediální server Event Flow poskytuje pouze schválená místní média.

Otevřít vysvětlení místních serverů a služeb

TikTok selhává nebo mění režimy

Zaznamenejte režim aplikace, poskytovatele podepisování, text stavu, verzi aplikace a viditelnost chatu v režimu Standard. Testujte vždy jeden režim TikTok.

Otevřít režimy TikTok v aplikaci

Chybí chat YouTube

Ověřte, že vysílání běží živě, živý chat je viditelný a používáte správnou cestu YouTube: živý chat, statické komentáře, standardní zachytávání nebo režim WebSocket/API.

Otevřít průvodce nastavením YouTube

Odpovědi bota se neodesílají

Čtení chatu není totéž jako odesílání chatu. Zkontrolujte podporu odesílání zpět na platformě, přihlášení účtu, roli účtu, režim zdroje, odpověď poskytovatele a limity požadavků.

Otevřít průvodce nastavením AI chatbota

Event Flow nic nedělá

Ověřte, že zdrojová událost přichází do doku. Pro zvuk, média a akce OBS nechte actions.html?session=YOUR_SESSION otevřené se stejnou relací.
