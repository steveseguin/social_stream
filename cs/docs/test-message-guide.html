Vytváření testovacích zpráv

Posílejte do relace Social Stream řízené falešné zprávy a události.

Co tento nástroj dělá

Tento Stránka pro vytvoření testovací zprávy odesílá syntetická data Social Stream do doku, překryvů, upozornění nebo nastavení Event Flow. Můžete tak testovat bez čekání na skutečnou zprávu chatu, dar, členství, raid, odměnu nebo jinou událost.

Pokud je to možné, používejte testovací relaci. Odeslaná zpráva se chová jako příchozí provoz relace a může spustit upozornění, zvuky, webhooky, akce OBS nebo jiné automatizace.

Rychlý start pro SSApp nebo rozšíření

  1. Otevřete Social Stream Ninja a ujistěte se, že je služba aktivní.
  2. V části Globální nastavení a nástroje → Mechanika, zapněte vzdálené ovládání rozšíření přes API (remote API control of extension). SSApp používá stejný název nastavení.
  3. Zkopírujte ID relace ze Social Stream nebo z session= hodnotu v URL doku nebo překryvu.
  4. Otevřít Vytvořit testovací zprávu a zadejte toto ID relace.
  5. Ponechte Odeslat přes (Send Via) nastavené na Příjem přes API rozšíření (Extension API ingest) pro běžné testování.
  6. Vyberte předvolbu, upravte její pole a zvolte Načíst předvolbu (Load Preset).
  7. Zkontrolujte Payload JSON a zvolte Odeslat (Submit).
  8. Ověřte, že se položka zobrazí v doku nebo cílovém překryvu a spustí se očekávaná automatizace.

Relaci můžete zahrnout do URL: createtestmessage.html?session=YOUR_SESSION_ID.

Příklad: jedna falešná zpráva s 1,000 KICKs

Tím vznikne jedna zpráva podpory ve stylu Kick v hodnotě 1,000 KICKs. Nevytvoří se 1,000 samostatných zpráv.

  1. Vyberte Zpráva chatu (Chat Message) jako předvolbu.
  2. Nastavte Napište na Kick.
  3. Zadejte testovací jméno a zprávu.
  4. Nastavte Částka daru (Has Donation) na 1000 KICKs.
  5. Vyberte Aktualizovat JSON z polí (Update JSON from Fields), ověřte JSON a odešlete ho.

Minimální datový obsah je:

{
  "type": "kick",
  "chatname": "Test Supporter",
  "chatmessage": "Thanks for the stream!",
  "hasDonation": "1000 KICKs"
}

Použijte Zpráva chatu (Chat Message) pro tento příklad. Předvolba Dar / Cheer (Donation / Cheer) obsahuje pole Cheer specifická pro Twitch.

Používání předvoleb a vlastního JSON

Předvolby poskytují výchozí data pro běžné případy, jako jsou dary, předplatitelé, darovaná předplatná, raidy, odměny, aktualizace počtu diváků, první zprávy uživatelů a události vlaků.

  • Načíst předvolbu (Load Preset) nahradí JSON vybranou předvolbou a aktuálními hodnotami polí.
  • Aktualizovat JSON z polí (Update JSON from Fields) vytvoří základní zprávu z viditelných polí.
  • Můžete upravit JSON dat (Payload JSON) přímo při testování konkrétního pole nebo struktury události.
  • hasDonation obsahuje zobrazovanou částku podpory, například 1000 KICKs nebo $10.00.
  • Pole event zahrňte pouze při testování skutečné pojmenované události. Běžný řádek chatu s darem může používat hasDonation samostatně.

Definice polí a příklady ze skutečných platforem najdete v Referenční příručka událostí.

Běžná řešení

  • Nic se nezobrazuje: ověřte, že cílová stránka je otevřená a používá stejné ID relace.
  • Příjem přes API rozšíření selhává: zapněte vzdálené ovládání rozšíření přes API (remote API control of extension), poté znovu načtěte dok nebo překryv a zkuste to znovu.
  • Přímý režim hlásí odeslání, ale nic se nezobrazuje: použijte Extension API ingest, pokud cílová URL nemá odpovídající &server nebo &server2 režim.
  • Spouští se nesprávná událost: zkontrolujte Payload JSON, zda v něm nezůstala pole z jiné předvolby.
  • Test Kick se chová jako Twitch: použijte předvolbu Chat Message a nastavte type a hasDonation podle ukázky výše.
  • Automatizace se spustí více než jednou: zkontrolujte, zda ve stejné relaci není otevřeno více doků, stránek akcí nebo instancí Event Flow.
