Co je podepisování TikToku?

TikTok vyžaduje kryptografické podpisy požadavků na připojení k živému chatu. Desktopová aplikace tyto požadavky podepisuje prostřednictvím externí služby provozované společností Euler Stream. Pro běžné používání není potřeba účet ani API klíč — aplikace automaticky využívá bezplatnou úroveň Euler.

Tato služba stojí mezi aplikací a TikTokem, proto mohou zdroje TikToku přestat fungovat i tehdy, když je na vaší straně vše v pořádku: server podepisování může být nedostupný, omezený limity nebo dočasně nefunkční kvůli změně TikToku.

„Sign Server Unavailable“

Tento stav znamená, že aplikace nezískala platný podpis od služby podepisování. Časté příčiny:

  • Omezení četnosti. Bezplatná úroveň má limit podle IP adresy (několik připojení za minutu a hodinové i denní limity — viz limity četnosti Euler). Opakované odstraňování a přidávání zdroje nebo rychlé přepínání režimů spotřebovává kvótu a prodlužuje trvání chyby.
  • Výpadek serveru podepisování. Euler má občas výpadek nebo je přetížený. Obvykle se to vyřeší během několika hodin a na vaší straně není potřeba nic měnit.
  • Změny TikToku. Když TikTok aktualizuje infrastrukturu živého vysílání, podepisování může přestat fungovat všem, dokud Euler nevydá opravu.

Co udělat v tomto pořadí:

  • Nechte zdroj připojený v režimu Auto a umožněte mu opakovat pokusy samostatně. Nepřidávejte zdroj stále znovu.
  • Pokud připojení opakovaně selhává, na hodinu ho zastavte, aby se obnovil limit pro IP adresu, a poté se připojte jednou.
  • Ujistěte se, že máte nejnovější verzi aplikace — opravy TikToku vycházejí často.
  • Přepněte zdroj TikTok na režim Standard (zachytávání stránky) jako spolehlivé dočasné řešení. Načítá stránku živého vysílání přímo a server podepisování vůbec nepoužívá.
  • Pokud často narážíte na limity, přidejte vlastní bezplatný API klíč Euler (níže).

Přidání vlastního API klíče Euler

Vlastní klíč vám přidělí samostatnou kvótu místo sdíleného anonymního limitu podle IP adresy.

  • Vytvořte si bezplatný účet a klíč na ovládacím panelu Euler Stream.
  • V desktopové aplikaci upravte zdroj TikTok a otevřete výběr předvolby připojení.
  • Vyberte Euler Signing (Advanced) a vložte svůj API klíč. Euler Proxy (API Key) také funguje, ale nepodporuje odesílání odpovědí.
  • Po uložení zdroj jednou znovu připojte.

Kompatibilita (WebSocket), označovaný jako Dotazování (Polling) ve starších verzích aplikace, používá v současné desktopové aplikaci podepsaný WebSocket. Nenabízí nepodepsané dotazování HTTP a neumožňuje odpovědi. Používá podepisování Euler, takže jej ovlivňují i výpadky a limity této služby.

Odesílání odpovědí do TikToku

Odesílání zpráv z doku zpět do TikToku vyžaduje přihlášení k účtu TikToku uvnitř desktopové aplikace — aplikace potřebuje vaši relaci TikToku, aby mohla odesílat vaším jménem. Pokud nejste přihlášeni nebo připojení TikToku nefunguje, odchozí zprávy dorazí pouze na vaše ostatní platformy.

Režim Euler Proxy nikdy nepodporuje odpovědi, bez ohledu na stav přihlášení.
