Rychlý start šablon překryvů

Vyberte rozvržení, přidejte ID relace a vložte odkaz do OBS.

1. Otevřete galerii šablon

Použijte Galerie šablon pokud chcete hotový vzhled chatu místo psaní CSS od začátku.

2. Přidejte ID relace

Každá URL překryvu potřebuje vaše ID relace. Nahraďte zástupnou hodnotu stejnou relací, jakou používá zdroj chatu a dok.

https://socialstream.ninja/sampleoverlay.html?session=YOUR_SESSION_ID

3. Prohlédněte si vzhled

Nejprve otevřete URL šablony v prohlížeči. Pokud vypadá správně tam, hledání problému v OBS bude snazší.

4. Přidejte do OBS

  1. V OBS přidejte nový zdroj prohlížeče.
  2. Vložte URL šablony se svým ID relace.
  3. Nastavte šířku a výšku. Obvyklý začátek je 1920 × 1080.
  4. Klikněte na OK a odešlete testovací zprávu.

5. Ověřte příjem chatu

Je-li překryv prázdný, otestujte dok před změnou nastavení šablony.

https://socialstream.ninja/dock.html?session=YOUR_SESSION_ID

Jednoduché opravy

  • Ve zdroji, doku i OBS použijte stejné ID relace.
  • Po změně URL obnovte zdroj prohlížeče OBS.
  • Ponechte stránku zdroje chatu nebo okno desktopového zdroje otevřené.
  • Pokud je text špatně čitelný, vyberte vysoce kontrastní šablonu.
