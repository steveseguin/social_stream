Spustit OBS a Social Stream jako správce

Postupy pro jednorázový test nebo trvalé nastavení ve Windows s odpovídajícími příklady pro obě aplikace.

Používejte pouze při potvrzeném problému s oprávněními

OBS a Social Stream obvykle přístup správce nepotřebují. Obě aplikace spouštějte běžně, pokud nebyl potvrzen nesoulad oprávnění Windows nebo vás podpora výslovně nepožádala o tento test.

Prázdný sjednocený chat, starou URL zdroje prohlížeče nebo zastaralou mezipaměť OBS obvykle vyřeší nahrazení URL a obnovení mezipaměti, nikoli režimem správce.

Pokud jedna aplikace běží se zvýšenými oprávněními a druhá ne, Windows může omezit jejich vzájemnou spolupráci. Při testu nesouladu oprávnění nejprve obě zavřete a spusťte je se stejnou úrovní oprávnění.

Jednorázový test správce

  1. Zavřete OBS Studio a desktopovou aplikaci Social Stream.
  2. Klikněte pravým tlačítkem na zástupce OBS Studio a vyberte Spustit jako správce.
  3. Potvrďte výzvu Řízení uživatelských účtů Windows.
  4. Pokud testujete nesoulad mezi oběma aplikacemi, klikněte pravým tlačítkem na zástupce Social Stream, vyberte Spustit jako správce, a potvrďte také jeho výzvu.
  5. Zopakujte přesně postup, který předtím selhal. Po dokončení obě aplikace zavřete; jednorázové zvýšení oprávnění končí jejich ukončením.

Nejprve upřednostněte tento test. Ověříte tak vliv zvýšených oprávnění bez trvalé změny kterékoli aplikace.

Vždy spouštět Social Stream jako správce

  1. Zavřete Social Stream.
  2. Klikněte pravým tlačítkem na jeho zástupce a vyberte Otevřít umístění souboru. Pokud Windows otevře dalšího zástupce, klikněte na něj pravým tlačítkem a vyberte Otevřít umístění souboru znovu.
  3. Klikněte pravým tlačítkem na socialstream.exe a vyberte Vlastnosti (Properties).
  4. Otevřete Kompatibilita kartě.
  5. Vyberte Spouštět tento program jako správce, poté vyberte Použít a OK.

Typická instalace pro jednoho uživatele je:

%LOCALAPPDATA%\Programs\socialstream\socialstream.exe

Pokud jste zvolili jiné umístění instalace, cesta se může lišit.

Vždy spouštět OBS jako správce

  1. Zavřete OBS Studio.
  2. Klikněte pravým tlačítkem na zástupce OBS Studio a vyberte Otevřít umístění souboru.
  3. Klikněte pravým tlačítkem na obs64.exe a vyberte Vlastnosti (Properties).
  4. Otevřete Kompatibilita kartě.
  5. Vyberte Spouštět tento program jako správce, poté vyberte Použít a OK.

Výchozí cesta k 64bitovému OBS obvykle je:

%ProgramFiles%\obs-studio\bin\64bit\obs64.exe

U přenosných nebo vlastních instalací se cesta může lišit.

Opětovné vypnutí režimu správce

  1. Zavřete aplikaci.
  2. U spustitelného souboru otevřete Vlastnosti → Kompatibilita kartě.
  3. Vymažte Spouštět tento program jako správce, poté vyberte Použít a OK.
  4. Totéž proveďte u druhé aplikace, aby se OBS i Social Stream vrátily na stejnou běžnou úroveň oprávnění.

Nevypínejte Řízení uživatelských účtů. Další informace o aplikacích se zvýšenými oprávněními najdete v vysvětlení režimu správce od Microsoftu.
