K čemu slouží Event Flow

Spusťte vlastní pracovní postup klávesou Stream Decku nebo voláním API přes HTTP/WebSocket/P2P.

Event Flow je pokročilý editor automatizací. Použijte jej, když přepínače ve vyskakovacím okně nestačí: filtrujte chat, spouštějte média, přeposílejte zprávy, volejte webhooky nebo ovládejte OBS.

Před každým postupem

  1. Použijte jednu testovací platformu a jednu relaci Social Stream.
  2. Otevřete dok a ověřte, že přichází chat.
  3. Otevřít actions.html?session=YOUR_SESSION pokud postup přehrává zvuk, média nebo ovládá OBS.
  4. Před vysíláním vyzkoušejte falešnou zprávu nebo bezpečný spouštěč.
  5. Před rozsáhlejší úpravou exportujte funkční scénář.

Příklad médií pro odměnu Kick

Toto je nejběžnější praktický vzor Event Flow: rozpoznejte odměnu a poté přehrajte média pomocí Flow Actions.

Podrobný průvodce: průvodce zvuky/médii odměn Kick.

Běžná řešení

  • Nic se neděje: nejprve ověřte, že zdrojová událost přichází do doku.
  • Zvuk nebo média se nepřehrávají: nechte actions.html otevřené se stejnou relací a potom zkontrolujte průvodce hostingem médií pro Event Flow.
  • Akce OBS selhává: zkontrolujte OBS WebSocket v5, port 4455, heslo a oprávnění.
  • Scénář se spouští příliš často: přidejte přísnější filtr platformy, události, klíčového slova nebo uživatele.

Úplná referenční příručka: Průvodce editorem Event Flow.
