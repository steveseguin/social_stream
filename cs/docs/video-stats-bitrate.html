Statistiky videa a datový tok

Zobrazte datový tok příchozího streamu v pravém horním rohu doku Social Stream Ninja.

Důležité: SSN automaticky nečte datový tok z OBS ani streamovací platformy. Dotazuje se API statistik video serveru, který přijímá váš stream.

K čemu to slouží

To moderátorovi pořadu nebo producentovi poskytuje malý aktuální ukazatel datového toku v doku. Hodí se, když OBS, mobilní enkodér nebo jiný odesílatel vysílá na váš vlastní přenosový nebo přijímací server.

SSN také normalizuje dostupná data o latenci, vyrovnávací paměti, ztrátě paketů, době provozu, kodecích a divácích do video_stats události metadat. Běžný údaj v doku zobrazuje pouze datový tok.

Kompatibilita

  • SRT Live Server / SLS: JSON /stats koncový bod obsahující publishers objektu.
  • Belabox Cloud: jeho odpověď JSON se statistikami přijímače/přenosu ve stylu SRT.
  • NGINX RTMP: XML ze stavového modulu NGINX RTMP.
  • Node Media Server: jeho JSON API streamů s volitelným HTTP Basic ověřováním.
OBS není zdrojem statistik: OBS může odesílat video na kompatibilní server, ale OBS WebSocket ani zdroje prohlížeče SSN tato data neposkytují.

Jak to používat

  1. Zapněte HTTP koncový bod statistik kompatibilního serveru a ověřte, že počítač s SSN dokáže otevřít jeho URL.
  2. V SSN Globální nastavení, zapněte Dotazování statistik videa.
  3. Vyberte typ zdroje a zadejte URL statistik.
  4. Pro SRT nebo Belabox zadejte přesné ID vysílatele, například publish/live/feed1. SSN ho použije automaticky, pokud odpověď obsahuje pouze jednoho vysílatele.
  5. Pro NGINX RTMP nebo Node Media Server zadejte aplikaci a klíč/název streamu, například live a feed1.
  6. V případě potřeby přidejte ověření. Pole API klíče SRT se odesílá jako úplná Authorization hlavička. Node Media Server používá uživatelské jméno a heslo pro HTTP Basic ověřování.
  7. Vyberte interval dotazování od 1 do 60 sekund; výchozí je pět sekund.
  8. V možnostech doku zapněte Zobrazit metadata datového toku, jsou-li dostupná; vpravo nahoře, poté otevřete nebo obnovte odkaz doku.
  9. Začněte vysílat video. Datový tok se zobrazí po platné odpovědi se stavem online.

Pokud se nic nezobrazuje

  • Ověřte, že jsou v SSN zapnuté obě možnosti statistik videa.
  • Ověřte, že koncový bod odpovídá do pěti sekund a typ zdroje i identifikátory streamu se shodují.
  • 127.0.0.1 znamená počítač, na kterém běží SSN. Pokud je server na jiném zařízení, použijte jeho adresu v místní síti.
  • Údaj zmizí, když je stream offline, datový tok chybí nebo je nulový, případně když přibližně 130 sekund nepřijdou nové statistiky.

Pokročilé: protokol, formáty a jednotky

SSN provádí HTTP nebo HTTPS GET v nastaveném intervalu s vypnutou mezipamětí a časovým limitem pěti sekund.

SRT Live Server / SLS a Belabox Cloud

{
  "publishers": {
    "publish/live/feed1": {
      "bitrate": 4500, "rtt": 32.5, "msRcvBuf": 120,
      "mbpsRecvRate": 4.5, "mbpsBandwidth": 12.8,
      "pktRcvDrop": 2, "pktRcvLoss": 1,
      "bytesRcvDrop": 2632, "bytesRcvLoss": 1316, "uptime": 3600
    }
  }
}

bitrate je v Kbps; RTT a přijímací vyrovnávací paměť jsou v milisekundách; rychlost příjmu a šířka pásma v Mbps; doba provozu v sekundách; hodnoty ztrát/zahození jsou počty paketů nebo bajty.

NGINX RTMP

URL musí vracet stavové XML NGINX RTMP. SSN vyhledá nastavenou aplikaci a stream. Čte bw_video jako bajty za sekundu a dělí 1024 pro bitrateKbps. Čte také dobu streamu a volitelná metadata video/audio kodeků.

Node Media Server

SSN požaduje STATS_URL/APPLICATION/STREAM_NAME. Pole mohou být na nejvyšší úrovni nebo uvnitř data.

{ "data": { "isLive": true, "bitrate": 4500, "viewers": 3, "duration": 3600 } }

Datový tok je v Kbps, diváci jako počet a délka v sekundách.

Normalizovaná událost SSN

{
  "type": "generic",
  "event": "video_stats",
  "meta": {
    "provider": "srt-live-server", "source": "srt-live-server",
    "label": "SRT", "online": true,
    "updatedAt": "2026-07-13T14:45:00.000Z",
    "bitrateKbps": 4500, "rttMs": 32.5, "bufferMs": 120,
    "summary": "4500 Kbps, 33 ms, 120 ms"
  }
}
PoleJednotka/typ
bitrateKbpsKbps, celé číslo
rttMs / bufferMsMilisekundy
recvRateMbps / bandwidthMbpsMbps
Pole ztrát/zahozených datPočty paketů nebo bajty
uptimeSeconds / durationSecondsSekundy
onlineLogická hodnota; false skryje hodnotu v doku

Dok přijímá meta.bitrateKbps, s meta.bitrate a meta.kbps jako záložní hodnoty. Hodnoty pod 1000 se zobrazují jako zaokrouhlené Kbps; vyšší jako Mbps zaokrouhlené na jedno desetinné místo. URL statistik, klíč streamu a přihlašovací údaje se nikdy neposílají překryvům.
